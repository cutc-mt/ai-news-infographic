Part 2 遠くから動かす(その1〜その4)

③ スマホがリモコンになる

  • 学長が1番欲しかった機能。スマホからPCのClaude Codeに指示できる
  • スマホのClaudeアプリ 左の「コード」タブ を開くと、PCのセッション一覧が見られる
  • 外出中や、ベッドでゴロゴロしながら指示 → PCの中で実行して結果を確認
  • 8月22日の信頼性の改善もあって、今はかんたんに設定できる
ChatGPTのスマホ指示がうらやましかった…それがClaude Codeでもできるように!

④ リモコンの設定はトグル1つ

  • デスクトップアプリの設定を開く
  • Claude Code の項目へ移動
  • 「新しいセッションを Remote Control に接続する」をオンにするだけ
  • 公式説明にあった /slashコマンドは実は不要(トグル切替用のコマンドでした)
設定 → Claude Code
  [オン] 新しいセッションを
         Remote Controlに接続する

※ /slashコマンドは入れなくてOK
ドキュメントと違う発見 その1。むずかしいことは何も不要、トグル1つでOKです

⑤ 定期タスク(ルーティン)

  • ルーティン機能で 朝9時にニュースまとめ などを定期実行できる
  • 寝ている間もAIが動く。朝起きたらまとめができている

  • 結果は「要対応のものがあります」のように毎朝レポートされる
毎朝のルーティンが自動に。「今日もちゃんと動いたかな」のチェックが習慣になります

Part 3 見て、直す(その5〜その8)

⑦ 指差し修正 Cmd+Shift+S

  • アプリやHTMLのプレビュー画面で Cmd+Shift+S を押す
  • 画面の要素ごとにハイライトして選択できるようになる
  • 選んで「この縦軸を直して」と頼むだけで直る
  • 例: ポスト成果ダッシュボードの縦軸に数値を入れてもらう
指差して「ここ!」で直る。人に頼むのと同じ感覚で直せるのが便利

⑧ 指差し修正の実践

  • クリックした要素がそのまま指示に入る。「ここを直して」だけで通じる
  • スクショを撮って貼る必要なし。位置の説明も不要
  • 直した段落だけ読みやすく仕上げてくれる
  • 地味だけど、じわじわ効く機能
実際の頼み方の例:
「それぞれの図の縦軸に数値を
 入れて、見やすくしてください」

→ 選んだ要素が指示に自動で入り、
  縦軸の数字入りグラフに修正!
待ってたら縦軸の数字を入れてくれて、さっきよりめちゃくちゃ見やすくなりました!

⑨ 差分に付箋コメント

  • チャットを続けると差分 +12 / -1 などが出てくる
  • ここをダブルクリックすると、何を足して何を消したかが見られる
  • 気になる箇所を選んで、コメントを複数入れられる
  • 例: ノート記事を修正してもらったものを、全部チェックして表現の違いなどを指摘
気になったところに付箋をペタペタ。まとめて直してもらう準備ができます

⑩ まとめて送信で一括修正

  • コメントを入れたらまとめて送信。一気に修正してもらえる
  • 送信は Enter だけでOK。かんたん!
  • 公式ドキュメントには Cmd+Enter と書いてあったけど…
  • 実機で試すとCmdは不要でした(ドキュメントと違う発見 その2)
差分付箋の流れ:
  1. +12/-1 をダブルクリック
  2. 気になる箇所にコメント入力
  3. Enter でまとめて送信
  4. 一括で修正されて戻ってくる
公式ドキュメントも実機とは違うことがあるので、注意して使ってくださいね
Part 4 すぐ公開する(その9・その10)

⑪ アーティファクトでWeb公開

  • CSVファイルの集計を「ダッシュボードにしてアーティファクトにして」と頼む
  • YouTubeアナリティクスのデータなどを、見やすい形にまとめてくれる
  • 公開の直後は非公開。ログインしている自分だけが見られる状態
  • 設定で「リンクを知る全員」に表示の変更も可能(Googleの共有とよく似ている)
自分のWebページを持っていなくても、パッと公開して共有できるのが便利!

⑫ バージョンが積み重なる

  • 修正するたびにバージョン2、3…と積み重なっていく
  • 前の状態にもパッと簡単に戻せるので安心
  • Cloudflareなどで細かく権限を設定している人には、あまり必要ないかも
  • そういうものを使っていない人は、共有がぐっと楽になる
アーティファクトの共有:
  公開直後  : 非公開(自分のみ)
  変更可能  : リンクを知る全員
  履歴      : 修正のたびに版が積もる
             → 好きな版にすぐ戻せる
失敗しても元に戻せるのがありがたい。まず小さく公開してみるのにおすすめです
Part 5 画面まわりの小技(その11〜その14)

⑬ 別ウィンドウで2画面

  • セッションを Cmd+クリック すると別ウィンドウで開いてくれる
  • 学長はディスプレイ4枚で検証。開いた先にパッと現れる
  • 別のディスプレイに置いて監視しながら作業できる
  • すごく地味だけど、知っていると便利
操作: セッション一覧で
     Cmd + クリック
     → 別ウィンドウで開く
長く動かすタスクは別画面に置きっぱなしにして、本命の作業はメイン画面で!

⑭ 2画面の使いどころ

  • じっくり見たいタスクをサブ画面に置いて待つ
  • その間もメイン画面のセッションは止まらず進む
  • 進みっぱなしのタスクから目を離さないのがポイント
  • 監視と作業の同時進行ができるのが最大の利点
放置プレイのお供に。デスクトップ版ならではの小技です

⑮ サイドチャット

  • 本筋の会話を汚さずに、ちょっとした疑問を聞ける
  • 「この単語の意味なんだっけ?」を本チャットで聞くと、文脈がぐちゃぐちゃに…
  • Codexなどにもある機能だけど、デスクトップ版でも使える
  • 用語の確認や脇道の質問はサイドチャットに分けるのが正解
会話の筋をキープしたまま、知りたいことを横で解決できます

⑯ サイドチャットの開きかた2つ

  • その1: Cmd + セミコロン(;) で開く
  • その2: AIの回答の選択部分を右クリック → 「サイドチャットに送信」
  • 選んだ言葉がコピーされた状態で始まるので、そのまま「これは何?」と聞ける
  • 例: 「HTML」を選んで送るとハイパーテキスト・マークアップ・ランゲージと回答。聞き方が雑だと「特定できません」と言われることも(笑)
開きかた:
  A. Cmd + ; (セミコロン)
  B. 回答を選択 → 右クリック
     → サイドチャットに送信
右クリック送信がかんたん。質問の形を整えれば、ちゃんと答えてくれます
Part 6 図解で理解して、まとめ(その15・その16)

⑰ /eli5スキルで図解

  • ELI5 = Explain Like I'm 5。「5歳児でも分かるように説明して」の略
  • 大きな図と少ない言葉で、難しい概念を説明してくれる
  • 「何も知らない人向けに図で説明して」などの言葉で発動するように設定
  • スキルの入れかたは前回の動画や学長のノートに書いてある(とてもかんたん)
  • 「よく使うスキル」の投稿がバズるなど、スキル紹介が今ホット
発動のしかた(例):
「HTMLという単語を
 分かりやすく説明して」
「何も知らない人向けに
 図で説明して」
難しい話は、まず大きな図で大枠をつかむのが近道。1分ほど待つできあがります

⑱ まとめ: 1つでも試してみよう

  • eli5の実例: HTMLとは「ウェブページの設計図を書くための言葉」。職人が設計図を書き、ブラウザが読んでページが組み上がる
  • 特に便利な4つ: スマホ操作・定期タスク・指差し修正・差分付箋
  • 「これ使えるな」と思ったものがあれば、1つでも試してみてください
