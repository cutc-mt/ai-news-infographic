3ヶ月に1回の恒例シリーズ。今回は年内3回目。4つのサービスへの使いかたと、お金の出しどころをぎゅっとまとめました

Part 1 月5万円の内ひょう(①〜⑤)

① 課金は4サービス・月約5万円

  • チャンネル恒例の3ヶ月に1回の課金報告シリーズ。今回で今年3回目
  • 使っているサービスは前回と変わらず。ただし中身はけっこう進化している
  • 使うのは Claude と ChatGPT と Gemini と Aqua Voice の4つ
  • 新しいモデルが出たり、アプリや機能が追加されて、使いかたもちょっとずつ変わってきている
月5万円の内訳(ざっくり)
  Claude Max 20X   : $200
  ChatGPT Pro 5X   : $100
  Google AI Pro    : 2,900円
  Aqua Voice Pro   : $10(実質0円)
  ────────────────────
  合計 約5万円/月
サービスは変わっていないのに、中身が進化して使いかたが変わっているのが最近の流れ。これから課金する人にも参考になるように話します!

② Claude Max 20X(月200ドル)

  • いちばん高い枠。月額200ドル のMax 20Xプラン
  • 目的はFable 5。今リリースされているモデルの中で、にゃんたさんがいちばん使いたいモデル
  • 文章をひねり出すのがじょうずで、アイデアの壁打ちや動画の構成づくりに毎日使う
  • ただし利用量の制限が厳しいので、Maxプランでも使いすぎには注意(詳しくは⑪)
Fable 5なしでは仕事がつらい、というぐらい頼りになる存在。文章の系の仕事が多い人には特に合いそう

③ ChatGPT Pro 5X(月100ドル)

  • 月額100ドル のPro 5Xプランを使用中
  • 主役は調べ物・調査。Web検索の精度が高く、調べ事がはかどる
  • プログラムや文章のレビュー・ファクトチェックはGPT-5.6 Solに任せる
  • 使用量の上限が豊富で、コスパよく大量に使えるのが魅力
左脳系の正確さが強み。論理とロジックをまちがえず扱ってくれるので、検証のお仕事に向いています

④ Google AI Pro(月2,900円)

  • 日本円で 月2,900円。4つの中ではいちばん安い枠
  • 言語モデルはほぼ使わず、画像生成(Nano Banana) が主な使いみち
  • Google Cloud のクレジットが毎月10ドル(約1,600円)分もらえる
  • Drive 5TB や YouTube Premium Lite など、おまけが多いのもうれしい
モデルというより、プランにくっついてくる色々な機能が良い、という使いかた。付属品で元が取れる感じです

⑤ Aqua Voice(月10ドル・実質0円)

  • 音声認識アプリ。喋ったことを文字起こししてくれる
  • 月10ドルのプロプランだが、動画で紹介させててもらう関係で招待クレジットで実質0円
  • 「音声認識は何でもいい。標準のWindowsやMacの機能でもよい」というのが本音
  • ただ新しい機能が追加されて、とても便利になったのでおすすめ(詳しくは⑯)
「紹介するのはクレジットが欲しいからでしょ?」と思われがちですが、純粋に良いものを選んでいます。もちろん他のアプリでもOK!
Part 2 どれを選ぶ? 使い分けの原則(⑥・⑦)

⑥ 原則: 開発もとのサービスを選ぶ

  • これから課金する人へのおすすめは、AIモデルを開発している会社のサービスを使うこと
  • 主要なのは Anthropic(Claude)/ OpenAI(GPT)/ Google(Gemini) の3社
  • Grok(X社)も有名だが、会社で使えない人が多いので現実的ではない
  • 3つのうちどれが良いかは用途による。人それぞれAIにやらせることが違うはず
迷ったら、まずはこの3社のどれかを試すのがおすすめ。どれが自分に合うかは、実際に使ってみないと分からない部分もあります

⑦ にゃんた流・3サービスの役割分担

  • ChatGPT → 調べ物・調査。検索の精度が高いので調べ事がはかどる
  • Claude → 考えて書く。アイデアの壁打ちや動画の構成づくり。文章をひねり出すのがじょうず
  • Gemini → 言語はほぼ使わず、画像生成と付属機能が主戦場
  • レビューはChatGPTのGPT-5.6 Sol。プログラムだけでなく日本語の文章のファクトチェックにも
レビューのレビュー(2段がまえ)
  1. GPT-5.6 Sol でレビュー
  2. 指摘が多すぎるので…
  3. Fable 5 に
     「本当に直すべきものはどれ?」
     と聞く
  → 本質的なものだけ直せる!
Solでレビューすると重箱の隅をつつく指摘がいっぱい出てきて、全部直していると永遠に終わりません。ふるいにかけるテクが大事!
Part 3 ChatGPT 戦略(⑧〜⑩)

⑧ プランとモデルの選びかた

  • 個人向けプランは5つ: 無料 / Plus $20 / Pro 5X $100 / Pro 20X $200
  • 主要モデルは Luna / Terra / Sol の3種類。Solが最高精度
  • Solは無料版では使えない。「AIってあんまり…」と思う人はSolを一度試してみて
  • まずはPlus(月3,000円)でSolを使うのがおすすめ。十分実用的
プラン       料金        できること
無料         $0   モデル制限あり(Sol不可)
Plus        $20   Solが使える
Pro 5X     $100   使用量5倍+思考量5段階
Pro 20X    $200   さらに使用量アップ
無料版で「AI使えないな」と感じている人は、Solを試すと印象が変わるかもしれません。モデルの違い=持っている知識量の違いです

⑨ エフォートレベル(思考量)の設定

  • エフォートレベルとは、どれだけ頑張って考えるかの設定。Web検索の深さなどが変わる
  • Plus は「中程度・高い」まで。Pro は5段階で極高(非常に高い)まで設定できる
  • プロモードはいちばん頑張ってくれるが、時間がかかりすぎて非推奨
  • スマホでは送信ボタンを長押しすると思考量のメーターが出てくる
使いわけのコツ
  ふだん      : 非常に高い
  すぐ返事が欲しい : 低めに
  大事な調べ物 : 高めに
  ※ スマホは送信ボタン長押し!
「検索の精度がイマイチだな…」と感じたら、この思考量の設定を見直してみると意外と解決します。私の設定は基本「非常に高い」です

⑩ デスクトップアプリが大幅進化

  • PCにアプリを入れて、MyWorkspaceフォルダを起点に作業させている
  • 成果物がフォルダにたまっていくので、仕事の文脈をAIに正確に伝えられる
  • Obsidianのウェブクリッパーで英語記事を取り込み、翻訳HTMLレポート(30分)を作ってもらう
  • レポートに対して複数チャットを並列で質問。NotebookLMっぽい使いかたもできる
  • ブラウザ操作プラグインなど拡張機能も充実してきている
英語の記事を読むのがつらい時、訳して目次つきの読みやすいレポートにしてくれます。読みながら疑問をチャットでどんどん聞けるのが良い!
Part 4 Claude 戦略(⑪〜⑬)

⑪ Fable 5 と利用量・料金の注意点

  • Fable 5 は現状いちばん使いたいモデル。ただしMaxプラン($100〜)でないと使えない
  • MaxでもFable 5は利用量の50%しか使えない制限あり
  • キャンペーンで8月31日まで枠が1.5倍。7/20→8/19→8/31と延長が続いている状態
  • ドル表記に消費税10%が上乗せされる。Max=$110≒17,600円、Pro=$22≒3,600円
  • ChatGPTは円表記で申し込み可能。税込み考えてもクロードはちょっと高い
Fable 5 の枠まとめ
  Maxプラン必要 : $100〜(税込$110)
  利用できる量  : Max枠の50%
  キャンペーン  : 8/31まで1.5倍
                  (何度も延長中)
  画像生成      : できないので注意
動画公開が29日なので、明後日くらいにまた延長のアナウンスが出るかも。Maxを申し込む前に、この2日間で続報を確認するのがおすすめです

⑫ チャット/Cowork/Code の3タブ

  • チャット: PCのファイルには触れない。Web版とほぼ同じ
  • Cowork: 隔離サンドボックスで動くので安全。エンジニアでない人にもおすすめ
  • ただしCoworkも許可を出しすぎるとフォルダ外のデータをマウントされちゃうので注意
  • Code: 隔離なし。分かっている人が設定して使う想定。会社ではCode不可のところも多い
  • にゃんたさんはCodeタブ中心で157日連続利用中。3/22の結婚式以外は毎日仕事で使用
  • 画面の分割表示は2画面が現実的。4分割だと下が見えなくなる
利用記録が埋まっていくのが楽しくて、気づけば157日連続に。毎日何かしらClaude Codeで仕事しているんですよね…

⑬ VS Code と Remote Control

  • ファイルを見ながら作業したいなら、VS Code の Claude Code がおすすめ
  • 左でファイルの中身を見ながら、右でClaude Codeを使える。選んだ部分をそのまま指示できる
  • 新しいRemote Controlで、スマホからPCのClaude Codeを操作可能に
  • スマホのアプリからデバイスを選べば、新規セッションをいつでも起動できる(セッションはいくつでも)
使いわけの目安
  かんたんなタスク → デスクトップアプリ
  ファイルを見ながら → VS Code
  外出先・寝る前   → スマホのRemote Control
これまでスマホからはセッションを立てられなかったのが、自由にできるように。外からガンガン触る人は少ないかもしれませんが、操作性が上がって良い感じ!
Part 5 Gemini 戦略(⑭・⑮)

⑭ Gemini の使いどころは「画像と付属品」

  • 言語モデルはほぼ使っていない。GPT-5.6 SolやFable 5の方が性能が良い
  • Nano Banana の画像生成が強い。プログラムから画像を生成するときに大活躍
  • 実践例: Fable 5に図を提案させて→Nano Bananaで画像生成 の組み合わせ
  • Google Cloudクレジット月10ドル(約1,600円)でAPI利用ができる
  • Drive 5TB・YouTube Premium Liteなど付属サービスも充実
Claudeメインだと画像生成ができないので、この組み合わせがかなり便利。Geminiは「モデルより付属品」で元を取るタイプです

⑮ スライドのエンハンスと Workspace CLI

  • Googleスライドの「スライドを強化」で、骨格だけの資料をかっこよく仕上げてくれる
  • チャットで細かく指示すればスライドを修正してくれる。画像化(Nano Banana)も可能
  • Google Workspace CLI が最近のお気に入り。MCPより高速で使用量も少ない
  • GmailやDriveをCLIで直接操作。にゃんたさんはスキル化して快適に使っている
MCP vs CLI(なぜCLIが速い?)
  MCP : 仕様を理解→ツール選択→…
        内部の処理回数が多くなりがち
  CLI : コマンド1発でデータ取得
        → 処理回数が少なく高速!
  ※ セットアップは少し大変
Googleサービスの操作がなんだか遅い…と悩んでいる人はCLIを試してみる価値あり。セットアップはChatGPTのデスクトップアプリにやらせればOK(自己責任で)
Part 6 音声入力(⑯)

⑯ Aqua Voice「送って」が神

  • 文字起こしのあとに「送って」と喋るだけ。確定後に自動でエンターして送信してくれる
  • 送信を待つ間に別の作業ができる。長い指示を雑に喋って最後に「送って」でOK
  • 選択テキストの編集も可能。「これを短くしてください」と喋れば直してくれる
  • Deep contextで画面の画像も入力してくれている様子。精度も良い
  • 使用単語数はすでに77万単語。かなりヘビーに使っている
  • マイクはHyperX SoloCast(後継機がおすすめ)。マイクスタンドも大事
普段は文字起こしの確定を待ってから送信ボタンを押していましたが、「送って」さえ言っておけば勝手に飛んでいく。この間に別のことができるのが最高!
