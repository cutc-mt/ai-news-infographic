  • 5つのゴールを設定して、ひとつずつクリアしていく形式
  • いつもはAIのニュースを扱うカレーちゃんが、3Dソフトは初体験
初心者のつまずきも、そのまま配信に映っちゃうのがライブの魅力。安心して見てね!

下ごしらえをしておくと本番で止まらない。リグは先に落としておくのがポイント!

④ Blenderの考え方: 俳優と肉体

  • オブジェクトは「俳優」 — 舞台で動く主体
  • メッシュは「俳優の肉体」 — 見た目のカタチ
  • この例えで仕組みがぐっとわかりやすくなる
  • 操作はショートカット中心。マウスだけでなくキーボードと一緒に使う
たとえると…
  オブジェクト = 俳優(動かす主体)
  メッシュ     = 肉体(見た目のカタチ)
  アニメーション = 動きの指示
「俳優に動きを指示するのがアニメーション」と考えると、腑に落ちる!
Part 2 基本の操作とゴール1・2

⑤ 最初に覚えるのは6〜7個だけ

  • G = 移動(Move)、R = 回転(Rotate)、S = スケール
  • Shift+A = 物を追加
  • X / Delete = 削除
  • テンキーの0 = カメラ視点
  • ほかに覚えることは、あとで出てくる I キーだけ
G        : 移動 (Move)
R        : 回転 (Rotate)
S        : スケール (Scale)
Shift+A  : 物を追加
X / Del  : 削除
テンキー0 : カメラ視界
ぜんぶ覚えようとしない! 最小限から始めるのが、初心者向けの近道だよ

⑥ ゴール1: キューブが動く

  • タイムラインのフレーム1で位置を決めて、I キーでキーフレーム挿入
  • フレーム60でキューブを移動して、もう一度 I
  • 数値入力もOK: G X 5 Enter でX方向へ5m
  • スペースキーで再生。補間でなめらかに動く
手順
  フレーム 1 : 位置を決める → I
  フレーム60 : キューブを移動(G X 5)→ I
  スペースキーで再生!
I キーは「今の位置を記録する」ボタン。2回押すだけで、もう動きになる!

⑦ キーフレームって何?

  • キーフレーム = 特定の時刻のプロパティ値を記録したもの
  • あいだを Blenderが自動で補間してくれる
  • 30フレームかけて上に持ち上げると、放物線の動きになる
  • 始点と終点を決めるだけで自然な動きができあがる
キーフレームの考え方
  フレーム1  : Z = 0   ← 記録(I)
  フレーム30 : Z = 3   ← 記録(I)
  → あいだはBlenderが補間
最初と最後だけ決めれば、あとはBlenderがよろしくやってくれる。ラクちん!

⑧ ゴール2: ボールが跳ねる

  • Shift+A → メッシュ → UVスフィアでボールを作成
  • G Z 1 で少し浮かす。Plane を S 5 で広げて床に
  • フレーム1で地面、12で上へ(G Z 2.5)、24で地面。それぞれ I でキーフレーム
  • とりあえず跳ねるけど、初期設定のままだと動きがふわふわ…
フレーム 1 : 地面 (Z=0)
フレーム12 : 上へ   (G Z 2.5)
フレーム24 : 地面 (Z=0)
→ それぞれ I キーで記録
3点うちだけで、とりあえず跳ねる! でもまだ月みたいにふわふわ浮いちゃう…

⑨ グラフエディターで補間を直す

  • Shift+F6(またはタイムライン左上のアイコン)でグラフエディターを開く
  • Z Locationだけ表示にして見やすく
  • 着地のキーフレームを選んで V → ベクターでカーブを尖らせる
  • これでバウンド感が一気に出る!
補間の直しかた
  1. Shift+F6 でグラフエディター
  2. Z Location だけを表示
  3. 着地のキーを選択 → V → ベクター
  → カクッと尖ってポンッと跳ねる
V → ベクターでカーブをカギカクに。ふわふわが、これで「ポンッ!」に変わるよ
Part 3 ボールをもっと本物らしく

⑩ バウンドを追加(減衰)

  • フレーム32で低めの高さ(2m)へ
  • フレーム40で地面に戻す
  • 跳ねるたびに高さを下げて、時間も短く
  • この減衰があると本物っぽくなる
減衰の入れ方
  フレーム32 : 低め (Z=2.0)
  フレーム40 : 地面 (Z=0)
  高さも時間も減らしていく
だんだん小さく、だんだん短く。この減衰がリアルさのヒミツ!

⑪ スカッシュ&ストレッチ

  • 着地したら S Z 0.7 で縦に潰す
  • S X 1.2 で横に広げる
  • フレーム22・26あたりにキーフレームで「潰れ→伸び」を表現
  • アニメの基本テク。これでボールに生命感が出る
潰れと伸び
  着地 : S Z 0.7(縦に潰す)
       + S X 1.2(横に広げる)
  フレーム22・26 あたりにキー
潰れて、伸びる。たったこれだけで、ボールに命が宿るみたい!

⑫ 本物のボールの動き

  • 上に行くほど遅くなる
  • 頂点で一瞬だけ止まる
  • 落下ではどんどん加速する
  • 地面では一瞬で向きを変える(速度を0にしない)
放物線の速度メモ
  上昇 : だんだん遅く
  頂点 : 一瞬ストップ
  落下 : どんどん速く
  着地 : すぐ折り返す
物理の復習にもなる! 速度の変化を思い浮かべると、カーブ編集がはかどるよ
Part 4 ゴール3 カメラを動かす

⑬ ゴール3: カメラ視点の基本

  • アウトライナーでカメラを選んで、テンキー0でカメラ視点へ
  • 画面の枠の中が、最後に動画になる部分
  • Macは メニュー → ビュー → カメラ設定 → アクティブカメラ
  • ビューを揃える →「現在の視点にカメラを合わせる」が初心者に超便利!
カメラ視点への行き方
  テンキー0        : カメラ視点
  Mac の場合       : メニュー → ビュー
    → カメラ設定 → アクティブカメラ
「今見ている位置にカメラを持ってくる」機能、知らないと損。めっちゃ便利!

⑭ カメラを動かす+自動で追いかける

  • カメラ視点で N → ビュータブ →「カメラをビューに」をオン。いつもの操作でカメラが動く
  • フレーム1と60でカメラ位置をキーフレーム。ボールに寄って回り込む映像に
  • トラックToコンストレイント: プロパティ → コンストレイント(鎖アイコン)→ ターゲットをボールに
  • 軸は -Z / 上をY にすると自然。位置は自分、向きは自動で追いかける
  • カメラの動きもグラフエディターで調整できる(ボールと同じ考え方)
トラックToの設定
  カメラのプロパティ
   → コンストレイント(鎖アイコン)
   → トラックTo を追加
   → ターゲット: ボール
   → 軸: -Z / 上: Y
Lock Camera to View は初心者に神機能。カメラが勝手にボールを追いかけてくれるのも便利!
Part 5 ゴール4 キャラとリグに挑戦

⑮ リグ付きキャラで挑戦

  • 自作キャラより、最初からリグ付きキャラを使う方が成功率が高い
  • Blender Studio の Animation Fundamentals から Rick をダウンロード
  • キューブと違って、骨(アーマチュア)入りのキャラ
  • アウトライナーでアーマチュア(rig)を選び、モードを オブジェクト → ポーズモードへ
  • ポーズモードでボーンの回転をキーフレーム。仕組みはキューブと同じ(I キー)
仕組みはキューブとおなじ! ボーンを回して I キー。これだけでポーズが付けられるよ

⑯ FKとIK、手を振る難しさ

  • 手のボーンを直接 G で動かすと、変形するだけでうまく動かない
  • 正しくは 上腕のボーンを選んで R(腕全体が回る)
  • 次に 前腕を選んで R(肘の曲げ伸ばし)
  • Hand IKコントローラ(Hand.L など)を使う手もある → FK方式とIK
  • 配信ではポーズモードの操作に手こずり、手を振るところまでは完遂できず…
腕の動かしかた
  上腕のボーン → R : 腕全体
  前腕のボーン → R : ひじ
  Hand IK(Hand.L) : 手の位置で直接
理屈はわかっても、指が思うように動かない…。初心者の壁はここからだった!

⑰ Tripo AIで3Dモデル化に挑戦

  • 自分のキャラ画像(クロちゃんなど)から3Dモデルを作るなら Tripo AI(画像→3D生成AI)がおすすめ
  • 無料で200クレジット(3モデル程度)試せる。Vroid Studio も候補
  • アニメキャラ画像をアップして3Dモデル化に成功!(4Kテクスチャも綺麗)
  • ただし無料枠では GLBエクスポート不可(書き出しはサブスクライブが必要)→ Blenderに持ち込めず断念
  • 画像を板として置く Image as Plane や、動画生成AIとの組み合わせ構想も
モデルは作れたのに書き出せない! 課金の壁…ここは次回への宿題に
