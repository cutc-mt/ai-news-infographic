①Archify — コードを図に変える

  • コードベースを検証できる図に変換する、エージェントスキル
  • Cursor Claude Code Codex CLI OpenCode でそのまま動く
  • 5種類の図を生成: アーキテクチャ ワークフロー シーケンス データフロー ライフサイクル
  • ノードは実際のファクトに基づく。トポロジーを勝手にでっち上げない
  • PNG SVG WebM エクスポートの前にも検証を通す
codebase → interactive diagrams
  nodes = verified facts (no fake topology)
「図にうそをつかせない」姿勢が新しい。レビュー資料がそのまま信頼できるね!

②Scientific Agent Skills

  • 163このサイエンススキル集で、AIエージェントが研究者に早変わり
  • カバー範囲: 生物学 化学 医学 創薬
  • RDKit scanpy PyTorch Lightning をラップ
  • PubChem・UniProt・ClinicalTrials.gov など100以上のデータベースへ統一アクセス
  • 各スキルにドキュメント・例・テスト付き。セキュリティスキャンも済んでいる
実験系エージェントを作りたい人には、これ一国で道具箱がそろうお得セットだよ!

③Marin — 再現できる研究基盤

  • 再現できる基盤モデル研究のための OSS フレームワーク
  • データのきゅう選・フィルタ・トークン化・学習・評価の全ステップを記録
  • 失敗した実験も残して、研究プロセスを透明に
  • 実験を Makefile のように依存ステップとして定義
  • 小さい CPU モデルから大規模 TPU ポッドまでスケール
  • Llama Qwen DeepSeek を実際にトレーニング可能
「うまくいかなかった実験」まで資産にする思想が、研究向けにちょうどいいね

④Google Test — C++の定番

  • Google の C++テスト・モッキングフレームワーク
  • Google Test と Google Mock をマージ。XUnit アーキテクチャが土台
  • 手動登録なしでテストを自動検出・実行
  • デステスト・致命的/非致命的な失敗・値と型のパラメータ化テストに対応
  • CMake または Bazel でビルド
  • Chromium LLVM OpenCV でも採用の実績
大御所の定番ツール。C++書きなら、まず押さえておきたい一本だね

⑤Codex CLI — 端末の相棒

  • OpenAI の軽量ターミナル用コーディングエージェント
  • ローカルの端末で動き、コードを読み、編集し、実行までやる
  • ChatGPTプラン（Plus Pro Business Enterprise）か APIキーでサインイン
  • IDE・デスクトップアプリ・クラウド版 Codex Web でも利用可能
  • Rust製。Homebrew / npm からワンコマンドで導入（macOS・Linux・Windows）
$ brew install codex    # or
$ npm i -g @openai/codex
「まずは端末から」派にちょうどいい軽さ。3つの画面形態があるのも嬉しいね

⑥Macaka — 手元で完結

  • ローカルファーストの OSS AIエージェントワークスペース
  • 質問応答だけじゃなく、プロジェクトを検査。read write bash などのツールを権限ポリシーのもとで実行
  • セッション・設定・実行の記録は自分のマシン上に保持
  • モデルはクラウドAPI・ローカルモデル・ゲートウェイから選べる
  • 全メッセージとツール呼び出しはランタイムイベントログに入り、セッション・コンテキスト・リカバリを駆動
  • デスクトップアプリ・TUI・CLI から利用。今は初期リリース段階
「手元に残す」設計が徹底されてる。event log が肝っぽいね!

⑦OpenHuman — 第二の脳

  • ローカルファーストの個人AI。メモリ・オーケストレーション・研究を統合
  • ローカル SQLite 上にスコア付き markdown ツリーで私的メモリを構築
  • Obsidian ボールトにミラー。100以上の統合から供給
  • Claude・Codex などを暗号化されたエージェント間セッションで接続
  • 耐久性のあるグラフの上でエージェント艦隊を編成
  • Web検索・ブラウザ・17このメッセージングチャネルも追加
  • プライバシーモードなら推論もマシン上に留まる。初期ベータ
自分だけの「第二の脳」をエージェント付きで持てる。夢が広がるねぇ!

  • 1,000以上のエージェントスキルを集めたキュレーションリスト
  • 大量生成のAIエントリではなく、公式チームが公開した実際のスキルとコミュニティ貢献を収集
  • Anthropic Google Vercel Stripe Cloudflare Sentry HuggingFace Figma OpenAI Microsoft など
  • 各エントリに説明とソースへのリンク付き

スキルを探すときの、まず最初の「入口」にしたい一覧だね。資料性が高い!

⑨BookOrbit — 読書の拠点

  • 電子書籍・オーディオブック・コミック用のセルフホスト型ライブラリ・読書プラットフォーム
  • 内蔵 Web リーダーは EPUB MOBI PDF CBZ オーディオブック形式をプラグインなしで開く
  • 進捗と注釈は Kobo KOReader Web の間で双方向の同期
  • ハイライトを1つの検索できるハブに統合・エクスポート
  • Google Books・Goodreads などのメタデータで書籍を強化
  • OIDC OPDS Send to Kindle 対応。マルチユーザーも OK。Docker でデプロイ
「読書環境を自分のサーバーに」派に刺さる、全部入りっぷり。同期が強い!

⑩OpenViking — FS風コンテキスト

  • AIエージェント用のファイルシステム風コンテキストDB。メモリ・ナレッジRAG・スキルを統合
  • ベクターストアの代わりに、ファイルシステムの下にすべてを整理
  • メモリ・リソース・スキルを Viking D-sho パスにマッピング。エージェントはファイルシステムコマンドでブラウズ
  • コンテキストは抽象 概要 詳細 の階層に分かれ、必要なときだけロード
  • 検索はディレクトリを再帰。全検索の軌跡が見える
  • セッションは Vulks エンジンから自動でメモリを抽出。pip で入る
「ベクタDBの運用、やめたい」人向けの発想転換。中身が見えるのが安心だね

⑪book-to-skill — 本を部品に

  • 任意の技術書を、オンデマンドでロードできるエージェントスキルへ変換
  • PDF EPUB docx フォルダを指定するだけ
  • フレームワーク・意思決定ルール・アンチパターンを章ごとのファイルに蒸留。要約ではなく構造
  • エージェントが関連章を読み、実際の内容から答えるのでハルシネーションしない
  • ローカルで動作。Claude Code Copilot CLI AMP で利用可能
techbook.pdf → skills/ch01..N
  frameworks / decision rules / anti-patterns
本の内容を「読める部品」にする発想が秀逸。技術書がそのまま資産になるね!

⑫vgpu — 型付きWebGPU

  • 型付きシェーダーインポート付きのクロスランタイム WebGPU ライブラリ（TypeScript）
  • シェーダー・3Dシーン・GPUテンソル・ニューラルネット・数学の可視化をカバー
  • WGSL ファイルが TypeScript モジュールのように import / export できる
  • リフレクションでバインディングと型を正しく保つ。コード生成は不要
  • init 1回の呼び出しで GPU コンテキストを返す
  • ブラウザ・ヘッドレスNode（Dawn 経由）・決定論的モックで同じコードが動く
  • CLI と MCP エンドポイントでエージェント対応
import fx from './fx.wgsl'
const gpu = await init()  // typed bindings
GPUまわりの型と実行環境を1本にまとめる、WebGPU 時代の土台になりそう!

⑬Coolify — 自鯖PaaS

  • セルフホストできる PaaS。Vercel Heroku Netlify の代替
  • 自分のサーバー（VPS・ベアメタル・Raspberry Pi）をSSH接続だけで管理
  • 静的サイト・DB・フルスタックアプリ、280以上のワンクリックサービスをデプロイ
  • Let's Encrypt SSL・GitHub / GitLab / Gitea からの Git デプロイ・S3バックアップ・フル API
  • 設定はすべてサーバー上に存在。ベンダーロックインなし
「自分のサーバーで Vercel みたいな体験」をくれる、セルフホスト派の定番だね!

⑭Impeccable — AIの見た目を鍛える

  • AIコーディングエージェントのフロントエンドデザインを改善するデザインスキル
  • Claude Code・Cursor・Codex・Gemini などに導入し、23のコマンドを追加
  • audit 問題発見・polish 仕上げ・distill 複雑さ除去・critique 全体レビュー
  • 59の決定論的チェックで AI 特有のデザインの癖を検出
  • 「inter everywhere」や「紫から青のグラデ」などのお決まりを捕捉
  • ブラウザでライブに反復できる
「AIが作った感」を消したい人に。地味に嬉しいスキルなんだよね

⑮Vorsaint — メニューバー道具箱

  • 無料の macOS メニューバー・ツールキット
  • 音量・システムモニター・アプリ切替・ウィンドウスナップ・クリップボード履歴・テキストスニペット・ファイルシェルフ・アンインストーラーを1つのアイコンの後ろに詰込
  • アカウント・テレメトリ・サブスクなし
  • モジュラー設計。機能を消すとロードと消費電力も停止。入れ直せば設定も復元
  • コマンドバーで1つのショートカットから、どんなアクションでも実行
Macの小物を「無料で軽く」まとめたい人にぴったり。設計思想も美しいよ

  • ライブ WebGL シェーダーコンポーネントの無料閲覧カタログ
  • 3UI（React Three.js コンポーネントカタログ）のログイン不要エディション
  • ライブレンダラー・コントロール・バリアントピッカー・ソースコードタブ付きの閲覧グリッド
  • Pro とベータコンポーネントは除くけど、無料バリアントは完全動作
  • npm と vite でローカル実行
シェーダー素材を「触って確かめられる」形で公開してるのがえらい! 素探しに便利

⑰Walgit ＋ Workout Guide

  • Walgit — オブジェクトストレージ上で単一バイナリで動く Git サーバー（Rust製）
  • S3 / GCS バケットに直接リポジトリをホスト。DBも重要なローカル状態も不要
  • バケットを真実の源とし、サーバー機は使い捨てキャッシュ。プッシュは不変オブジェクトを書き、compare-and-swap で小さなマニフェストを反転。リーダーもクォーラムも不要で、どのインスタンスも安全に書き込みを受け付ける
  • スマートHTTP・git bundle URI クローン・Git LFS・Web UI・SDK付き JSON API・プッシュポリシー・Webフック・トークン/OIDC 認証に対応
  • Workout Guide — 302種のエクササイズに一貫した3フレームのアニメを提供する、型付き npm パッケージのイラストライブラリ
  • 正規化済み PNG と getExercise searchExercises getAssetURL の型付き関数。React Native 対応、Astro 製の検索できるギャラリーサイト付き。フィットネスアプリ開発に
Git のあり方を問う Walgit と、実務で地味に助かる Workout Guide。対照的な2本が楽しい!

⑱CarWatch ＋ BetterVoice

  • CarWatch — クルマがオフラインAIエージェントとしてチャットに参加する仕掛け
  • Raspberry Pi 5 をクルマに載せ、Group Mind のチャットルームに名前付き参加者として完全オフラインで参加。ローカルLLMで grounded な推論
  • クルマのマニュアルからページ引用付きで回答。温度やネットワーク状態などのライブなマシン状態も読み取る
  • 音声パイプラインでハンズフリー音声入力を常時リスニング。OBD ポートでエンジンデータを読み、ドライブレコーダーのクリップも取得。クルマ自体が提供するスマホダッシュボードとも同期
  • リポジトリから自己更新。ダイアルアウトトンネルで、直接の受信端口がなくても到達できる
  • BetterVoice — 画面を指で丸く囲んで視覚コンテキスト付きの音声ディクテーション（macOS メニューバーアプリ）
  • 音声認識は fluid audio でローカル実行。音声はマシンの外に出ない。Apple Silicon・macOS 14 以降対象
「クルマが話す」未来を OSS で組んでしまう強さ! BetterVoice のゼロ音声漏れ設計も偉い
