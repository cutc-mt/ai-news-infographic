1&8

I have ADHD × Context Mode

エージェントの「長話」と「圧迫」を止める

I have ADHD（スキル）

  • 前置きの壁を作らず、次のアクションを最初に言わせるAIコーディング用スキル
  • 多段階タスクは番号付き、リストは上限、時間の見積りも具体化
  • ADHD向けツールキット由来の10ルール。Claude Code / Codex へ導入

Context Mode（MCP）

  • 巨大なツール出力をローカルの全文書DBへ索引化し、ポインタだけを渡す
  • 圧縮をまたいでセッションの記憶を保持。17プラットフォーム対応
# 出力ルールのイメージ
1. 次のアクションを最初に
2. 手順は番号付き / 上限つき
3. 見積り時間を明記
「hope this helps」の山に
そろそろ別れを告げよう
2

God's Eye View

3D地球儀の空間インテリジェンス

  • ブラウザで動く空間インテリジェンスのコンソール。スパイ衛星シミュレータを現実データで
  • 3D地球儀に航空機・船舶・衛星・山火事・CCTVをリアルタイム重畳
  • 追跡中の便に「搭乗」、対象をロックして航跡を表示、近くのカメラへハンドオフ
  • ローカル実行で公開データのみ。追うのは資産とシステムで、人ではない設計
地球規模の view から
単一オブジェクトまで自在に
3

Armor Paint

3D PBRテクスチャペイント

  • 3Dモデルを読み込み、表面にPBRマテリアルを直接ペイント
  • 色・粗さ・金属感・法線を描き分け、レンダラーやゲームエンジンへ書き出し
  • Armory Engineベース。Windows / macOS / Linux で動作
  • Blender / Unity / Unrealとライブリンクするプラグイン
  • ソースからのビルドで無料利用
モデルに直接、絵を描く感覚！
書き出したらすぐ制作へ
4

Sonarr

セルフホストのPVR

  • TV番組のライブラリを管理。RSSを監視して新エピソードを自動で取得
  • 取得 → 整理 → リネームまですべて自動。Usenet / BitTorrent に対応
  • 欠け話をスキャンし、品質が良い版があれば自動アップグレード（DVD → Blu-ray）
  • ダウンロード失敗時は別リリースで自動リトライ
  • SABnzbd / NZBGet / Plex / Kodi と連携。Raspberry Piでも動作
番組の追跡は Sonarr に任せて
好きな話だけ見ればいい
5

Hyper Research

監査つきディープリサーチ

  • Claude Code を規律ある調査エージェントへ変えるハーネス
  • 16段階の適応パイプラインで収集 → 相互チェック → 敵対的監査を通した報告書
  • 引用は支える文と照合してから出荷。出典つき
  • 取得ソースは Markdown + SQLite の保存庫へ。次のセッションが再利用して調査が積み上がる
  • 壁のある論文は公開全文を追う。クラッシュから再開、調査から論文まで対応
裏取りを機械に任せて
人間は考察に集中できる
6

Spec Kit

GitHub公式のスペック駆動開発

  • プロンプトで頼む前にまず仕様を書く。GitHub公式のツールキット
  • 流れ: 仕様 → 計画 → タスク分解 → 実装。各フェーズはMarkdown成果物としてrepoに保存
  • specify CLIがプロジェクトを足場立て、スラッシュコマンドで進行
  • 30以上のエージェント対応: Copilot / Claude Code / Cursor / Gemini
  • 人間がループ内にいるHuman in the loop設計
$ specify init my-app
/constitution → /spec → /plan → /tasks
# 成果物はすべて repo のMarkdown
空振りするプロンプトより
先に「仕様」を書くほうが早い

Plugins (OpenAI)

Codexプラグインの公式例

  • OpenAI公式のCodexプラグイン集。マニフェストつきフォルダで配布
  • スキル・MCPサーバー・連携・コマンド・フックをインストール可能なバンドルに
  • Codexのアプリ / CLI / IDE拡張で横断動作
  • OpenAI厳選の Box / Cloudflare / Figma などを収録
  • マーケットプレイス形式を定義。自作は1つコピーから
配布の「型」がここに揃う。
自作スキルの雛形に最適

WeKnora

Tencentのナレッジ基盤

  • ① RAGのQ&A — ドキュメントへの検索・回答
  • ② ReActエージェント — 検索・MCPツール・Web検索を編成して多段階タスク処理
  • ③ Wikiモード — 資料を自己保守するリンク付きMarkdown wiki に蒸留。知識グラフつき
  • 10+形式を読み込み、Feishu / Notion / Yuque から自動同期
  • 20+のLLM、ベクタDBも差し替え。Dockerでセルフホスト
社内の資料を「生きたWiki」に
3つの使い方が嬉しい

Wansom GPT Image 2

プロンプト as コード

  • OpenAIの画像モデル GPT Image 2 用のプロンプト&テンプレート集
  • 530+の実例を20+のテンプレートに逆エンジニアリング
  • 対象: ポスター / 商品撮影 / UI / インフォグラフィック / ブランド / キャラ他
  • 完全なプロンプトと生成記録つき。npmで導入できるエージェントスキル
  • ライブギャラリーで検索・絞り込み・コピー
「いい感じに」ではなく
型から量産する画像生成

Modular Platform

Max + Mojo の統合AI基盤

  • AIの開発とデプロイ向けオープンなスイート。MAX framework + Mojo言語を同梱
  • MAXは高性能な推論サーバーでOpenAI互換endpointを公開
  • pipで入れて、Llama等のオープンモデルを NVIDIA / AMD GPU でコード変更なしにサーブ
  • 中身も公開: Mojo標準ライブラリ、MAX のGPU/CPUカーネル、サーブ層
$ pip install max
$ max serve --model llama
# OpenAI互換の endpoint が起動
言語からインフラまで
ひとつのrepoにまとまってる
13

Needle 2

14MBのツール呼び出しモデル

  • 45Mパラメータの小型モデル。用途はツール呼び出し・端末操作・構造化抽出
  • 全体で14MBの単一バイナリ、フルセッションが約28MBのRAMで動く
  • 収まる先はフォン・ウェアラブル・ロボット
  • スキーマから文法を生成してトークンを制約。応答はJSONの呼び出し
  • 応答にはそれぞれ信頼スコアつき。低ければ人間へエスカレーション
tools = {...}          # スキーマを渡す
→ {"call": "...",
   "args": {...},
   "confidence": 0.92}
クラウド不要。端末の中で
エージェントが完結する
14&15

Dokku × neko

セルフホストの花形ふた組

Dokku（ミニPaaS）

  • DockerベースのPaaS。Heroku代替として自分のサーバーで運用
  • git push でデプロイ。buildpack / Dockerfile でビルド、生活環も管理
  • 新規の Ubuntu / Debian VM に入れるだけ

neko（仮想ブラウザ）

  • Docker内のブラウザをWebRTCで配信。Webページから安全・私密に操作
  • 複数人で同セッションに参加し操作を共有。視聴会・共同作業・発表に
  • ブラウザ以外のLinuxアプリやデスクトップも配信、Playwrightで自動化
自前のサーバー1台で
アプリもブラウザも賄える
12&16

Public APIs × Retro Bios

厳選コレクション系ふた組

Public APIs（無料APIリスト）

  • コミュニティ管理の無料API一覧。金融・天気・機械学習・ジオコード・ゲーム・政府など数百
  • 各項目に認証要否 / HTTPS / CORSと直リンク。PRで誰でも追加

Retro Bios（BIOSパック）

  • エミュレータ用の検証済みBIOS/ファームウェア集。RetroArch・Batocera・RetroPie・EmuELEC・MiSTer FPGA 対応
  • エミュレータのソースコードを読んで必要ファイルを特定、本物と同じ方法で検証
  • 不足はギャップ分析で指摘、自動インストーラーが正しく配置
「探す時間」を「作る時間」に
変えてくれるリストたち
17

Bank MCP

銀行をつなぐ読み取り専用MCP

  • AIアシスタントが口座を読み取りだけできる、セルフホストのMCPサーバー
  • Enable Banking が ヨーロッパ2,700+銀行をPSD2 APIで一本化
  • Claude / ChatGPT / Cursor など任意のMCPクライアントから利用
  • サーバーが持つのは同意と口座IDのみ。残高も取引も保存せず、テレメトリーも送らない
  • 決済なし。npx かコンテナで実行
$ npx bank-mcp
# 読み取り専用で起動
お金の話は「見るだけ」でも
じゅうぶん役に立つ

OKF Agent Memory

Gitネイティブな永続メモリ

  • AIコーディングエージェントにプロジェクトの記憶を与えるエンジン
  • 記憶はYAML前付けのMarkdownとしてrepoの中に保存
  • 何を覚えたかplain gitで監査・復元。ベクタDB不要
  • BM25検索 + 段階的開示で必要な概念だけ読み込み、書く前に検索を強制
  • Goのバイナリ + 内蔵MCPサーバーで配布
エージェントの忘れっぽさを
gitで治す発想が上手い
18&20

its-giving-prick × Bot Crossing

遊び心のあるふた組

its-giving-prick（会議ミーム）

  • ビデオ会議のWebカメラにミームを重畳するPythonツール
  • MediaPipe で顔を追跡し約14の表情を認識、反応に合わせて表示
  • 固定の閾値ではなく自分の無表情を基準に正規化して適応

Bot Crossing（エージェント可視化）

  • エージェントのセッションをどうぶつの森風コロニーとして描くローカルダッシュボード
  • 六角タイル=エージェント、宇宙服=ジョブ。ハンマー=作業中 / ?=入力待ち / 赤=停滞
  • 各ハーネスのセッションファイルをアダプタで読み、全部を1つのコロニーに集約
仕事の道具にも遊びを一滴。
和むと捗るのだ
