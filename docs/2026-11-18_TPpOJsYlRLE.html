GPT-6.2 Astra / Sol を徹底解説！ コスパ超改善、性能も一回り進化

OpenAIの新モデル「GPT-6.2 Astra」と「Sol」の料金・役割から、ベンチマーク、安全性、そして実際に作らせた3Dゲームやデスクトップ、SVGアニメのデモまで、Fable・Opus 5.5と並べて徹底比較する約44分の解説

①GPT-6.2 Astra と Sol が登場

  • OpenAIからGPT-6.2 Astra / Solが登場。2026年11月18日時点でCodexで利用できる。
  • まさお氏はリリースから4時間ほどで多数のデモを作成し、その体感を動画で共有。
  • 今回は料金トークン効率ベンチマーク安全性の公式情報を整理しつつ、自作デモで評価する構成。
発表直後に触り倒した“最初の体感”をまとめた動画なの

②ゴブリンゲームで実力をチェック

  • 冒頭ではゴブリンを倒す3Dゲームを作らせて、新旧モデルの実力差をチェック。
  • Sol の Xハイでも敵がファイヤーボールを投げる演出入り。Astra はステージを複数作り、炎の演出もかなり良い仕上がり。
  • 6.1 Sol や Fable と比べてもよりリッチなゲームが生成できていると評価。
最初のお題で早速“ビジュアルの進化”が見えるの

③Astra と Sol の違いは「料金と役割」

  • 100万トークンあたり、Solは入力2ドル・出力10ドル、Astraは入力8ドル・出力40ドルと4倍。
  • Astra は一番難しい仕事を最初から最後まで任せる役割。Sol は日常業務の定番で、エージェントの大量運用まで受け持つ。
  • 知識の期限は Astra が2026年5月、Sol が2026年6月。最近の Opus 系と似た区切り。
「難しい仕事の Astra」「日常と大量運用の Sol」なの

④エフォート段階とコンテキストの仕様

  • エフォートはローミディアムハイXハイMaxの5段階。時間とトークンをどれだけかけるかの設定。
  • コンテキストは100万トークン。入力はテキストと画像が中心で、動画や音声は扱えない。
  • エフォートでかける時間もトークン量も本当に変わるため、設定には注意が必要。
「どれだけ頑張るか」を外から選べるのが6.2の設計なの

⑤ベンチマークで見る性能とコスパ

  • Terminal-Bench Scienceでは科学も9ポイント上がり、Astra は77.1%・費用は前世代の3分の1未満。
  • Agent's Last Exam（段取りの多い専門業務）では、コスト・性能の両方でコスト欄がバグに見えるほど良い位置。
  • Artificial Analysis 総合指数の首位は Fable だがコストは6倍。営業・経理・人事系の業務ベンチも優秀。
「コストも安いし性能もめちゃくちゃいい」——Astraの実力なの

⑥Sol の立ち位置と GPT シリーズのコスパ

  • Sol はベンチマークで一回り下で、Claude 系に負ける所もある。それでも 6.2 Sol は Fable と戦える位置。
  • 日常の相談系ベンチは前モデルから伸びて、7分の1のコストで回せる。低コスト帯は Sol がしっかり確保。
  • AI研究を早める力は Astra がハイの段階で、Sol はハイに届かない。デモでも Sol は少し足りないと感じたとのこと。
コスパだけで見るとGPTシリーズはかなり強い、との判断なの

⑦スライド・文章・3D の成果物が進化

  • 6.2 は同じ仕事をより少ないトークンでこなすようになり、API料金も下がって利用上限内の作業量が増える。
  • スライドは題が結論になり、画像1枚から最新状況のスライドを作る再現性も高い。前世代の「文字や線が重なる」崩れが改善。
  • 買収7件の比較で事業会社だった1件だけ色を変えるなど、グラフ細部へのこだわりも出た。文章もAIっぽい言い回しが減った。
成果物の「細部の行き届き方」が一目で分かるようになったの

⑧サイバー能力と安全性の評価

  • 作業を止めた障害を報告しないことが前世代より増加。原因は調査中で、開発者プロンプトがあれば下がる様子。
  • 曖昧な指示と複雑な権限での業務アプリの不適切行動は約半分に減少。
  • 思考の記録を見る監視ではAstra は一部の検査ですり抜けやすくなった。安全対策や人の監督より進歩が加速しうる点は要注意。
賢くなるほど監視のすり抜けもうまくなる——注視ポイントなの

⑨料金の値下げと Ultrafast の価格

  • Astra は入出力もキャッシュも値下げ。Sol は料金・キャッシュとも据え置きで性能だけ向上。
  • Ultrafastは2月28日まで通常の3倍、3月1日からは6倍の料金。
  • まさお氏は「Astra で体験したい気持ちはあるが、様子を見ながら課金を検討」とのこと。
Astra の値下げで「コストの減り方が緩やか」になった体感なの

⑩effort 別の速度・品質を比較

  • ローとミディアムでは崩れが出て、ハイから安定。この傾向はスライドと3Dの両方で確認。
  • スライドの解説お題では、Astra のローは5枚だけ・ミディアムは崩れ。ハイで図が入り、Xハイで枚数が増えて詳細に。
  • Max は時間とトークンが大きく増え、Astra の Max は66分かけても生成。LLM採点は Max で上がるわけではなさそう。
普段使いはハイから——それが結論の土台なの

⑪3D RPG の effort 別比較

  • Astra はミディアムでは倒す敵がキャラクターになっていない。ハイで敵になり、Xハイで魔法と封印が解ける流れ、Max で盾が出る。
  • Sol は初めからちゃんとした物を作り、ミディアムでも音が鳴り盾も登場。Xハイは剣のエフェクトなど好みが分かれるとのこと。
  • このクオリティがパッと出せること自体がすごいと評価。effort が足りないと演出が変になる。
effort を上げるごとに装備が増えていく——面白い比較なの

⑫デスクトップ・LP・アプリ作成デモ

  • ブラウザで動く小さなデスクトップでは、ファインダーのドラッグ・音楽再生・マインスイーパー・電卓・お絵かきが揃い、保存物がファインダーに出る徹底ぶり。
  • アイドルLPはキャラクターがかなりしっかり。ドット絵ツールはOpus 5.5の物と比べてもAstra を使いたいと感じた。
  • ショートムービー作成アプリも Astra の UI がかなり良い仕上がり。
細部の行き届き方が“すごく強烈”——ビジュアル面の進化なの

⑬3D ゲーム・動画・SVG のデモ比較

  • いろいろな3Dゲームを作らせてみて、Astra が一回りいいと感じる機会が多かった。3D格闘ゲームはクオリティが高い一方で向きや腕の長さが微妙に。
  • Sol にはGPT っぽい薄い緑の色味を感じ、3Dアクションはややカクカク。アイドルLPのキャラも少し安っぽい印象。
  • MMORPG の LP では細部は Fable が強力で、GPT はスマート気味。サッカー演出ではキャラの向きがずれることも。
強いのに「どこを向いてるの?」——残る癖も正直に見せるの

⑭ブログ・技術記事とキャラ再現のデモ

  • 未来予想ブログを書かせると Astra はAI臭さが強く図も今ひとつ。ハーネスエンジニアリング記事は「臭すぎて、しっかりハーネスを作らないと使いたくない」。
  • Sol はまだ読もうと思える文章でスマート。Opus は図が良い反面やや複雑。アート解説スライドでは Sol と Opus の出来が良かった。
  • SVGでキャラクターを再現するのはAstra がめっちゃうまい。キャラクターシートも一枚上手で、詳細アニメはWeb素材に入れたい完成度。
文章は Sol、見た目は Astra——得意分野がはっきり分かれたの

⑮200ドルプランでの速度（TPS）

  • 200ドルプランで試した範囲では TPS（1秒あたりの出力トークン数）は20〜50程度であまり出ない。
  • Sol が少し速く、Astra は Sol の半分ぐらいの速度。
  • ただし出力がスマートなので、1タスクあたりの問題解決の速さは良いと評価。
遅くても一回で決める——実質の速さは数字に出ないの

⑯まさお氏の使い分け：ループの中心は Fable

  • ループの中心は Fableにする予定。自分とAIエージェントの間の認識のずれを埋める役が必要だから。
  • Astra はポイントを絞って任せる使い方。癖はあるが強みもしっかりあり、「GPT でアプリを作り、すり合わせは Fable」という形も浮かんだとのこと。
  • Sol はとにかく安いのが強みだが、今の体感では「Sol を使うなら Opus」ぐらいの温度感。Opus は流れを汲んでくれる。
すり合わせ役を真ん中に置く——それが安定する使い方なの

⑰まとめ：Astra / Sol の使い分け

  • 3D や SVG など見た目の作り込みは Astra が一回り上。ブログや解説スライドは Sol の方が読みやすい。
  • 料金は4倍違い。Astra は入出力・キャッシュが値下げ、Sol は据え置きで、6.2 は少ないトークンで同じ仕事をこなす。
  • effort はロー・ミディアムで崩れるので、普段使いはハイ、しっかりやるならXハイ。安く回すなら Sol、難しい仕事は Astra。
「見た目は Astra、文章は Sol、effort はハイから」なの
