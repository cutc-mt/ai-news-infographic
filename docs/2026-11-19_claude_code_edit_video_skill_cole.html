第一部｜これが何か
🧠

AIセカンドブレインが動画を編集

  • Cole Medin氏のAIセカンドブレインが、この動画全体をたった1つのスキルで編集
  • そのスキル「edit-video」を無料・オープンソースで公開
  • 生 footage の入ったフォルダを渡すだけで仕上がった動画に変換
この動画自体が証明書です。人間の手ではなく、スキルが最後まで編集しました。
🛠️

Claude Code＋コーディングエージェントで動く

  • Claude Codeをはじめ、任意のコーディングエージェントで動作する設計
  • OpenRouterのAPIキー1本でパイプライン全体のモデルを賄える
  • スキルはGitHubリポジトリ（coleam00/skills）から入手可能
🎞️

コアパイプラインの仕組み

  • ①生動画フォルダを読み込み、素材の内容を解析
  • ② 問題箇所（言い淀み・無音・途中切れ）を自動検出してカット編集
  • ③トランジションを滑らかにつなぎ、音声の乱れも補正
映像の処理って実は「手順の問題」なんです。手順を言語化できれば、AIに丸ごと任せられます。
📼

対応する動画の種類

  • トーク系の長尺動画はもちろん、あらゆる種類の動画に対応
  • 長尺動画からShorts（ショート動画）を切り出す運用も可能
  • サムネイル生成までパイプラインに含まれる
🔍

スキルの中身を見る

  • スキルの中身は手順書（プロンプト）＋ヘルパースクリプトの構成
  • 動画処理の実行部はスクリプトに切り出し、LLMは判断に専念
  • 「AIに何を任せ、何をコードに固定するか」の設計が学べる見本
LLMに全部やらせない。判断はAI、作業はスクリプト。この切り分けが安定動作のコツです。
🎛️

自分のコンテンツ用にカスタマイズ

  • Brand Colors（ブランドカラー）を指定して見た目を統一
  • lessons.mdに編集上の学びを蓄積し、回ごとに賢くなる
  • 自分の話し方や番組フォーマットに合わせた調整が可能
失敗した編集メモを lessons.md に書き溜める。すると次の動画では同じ失敗をしません。
第二部｜実際の修正例
💬

言い淀みを単語の途中で修正

  • 言葉に詰まった瞬間を検出し、単語の途中でも自然につなぐカットを実現
  • 切れ目の音声波形をなめらかに繋いで違和感を排除
  • 視聴者が気づかないレベルの編集を目指す姿勢
🎵

音切れ・チョッピー音声の検出

  • 音が途切れ途切れになるチョッピーな音声を自動で発見
  • 文の途中で切れたクリップも検出して修正
  • 「聞いて不快な箇所」を機械的にリストアップする仕組み
人間の編集者は音の乱れを「なんとなく」見つけます。AIは全部に目を通すので漏れません。
🗣️

音声クローンで言葉を直す

  • 聞き取りにくい単語をボイスクローニングで再生成して差し替え
  • 撮り直し不要で、尺を変えずに発音だけ修正
  • 自分の声のクローンだから違和感が少ない運用
編集の最終兵器は声のクローンです。もう「そこだけ撮り直し」は要りません。
🖼️

サムネイルとShorts生成

  • 動画内容に合わせたサムネイルも自動で用意
  • 長尺動画から注目シーンを切り出しShorts化
  • 公開までの工程を1本のパイプラインに集約
🔀

OpenRouterで組むフルパイプライン

  • OpenRouterのAPIキー1つで編集パイプラインの全モデルを利用
  • 解析・判断・生成の各工程に最適なモデルを割り当て
  • モデルの差し替えも簡単で、コスト最適化しやすい構成
📦

ヘルパースクリプトの役割

  • 動画・音声の変換処理はヘルパースクリプトが担当
  • ffmpeg等の重い処理をLLMの外で高速実行
  • 処理の再実行や部分やり直しもスクリプト単位で可能
スキル設計の黄金ルール：LLMは指揮官、スクリプトは作業部隊。役割を混ぜないことです。
