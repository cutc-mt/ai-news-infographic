月20ドルで18モデル中2位——Gemini 4 Neon 実測 KINGBENCH

Google の新型ミドルモデル「Gemini 4 Neon」を KingBench 4 のワンプロンプト・アプリ制作6本で徹底検証し、GPT-6.2 や Claude と正面比較した回

📅 2026年11月19日／AI Code King／YouTubeで元動画を見る

①Gemini 4 Neon が静かに登場

  • 11月18日、Google が新しいコーディング向けミドルモデルGemini 4 Neonを発表。
  • 大々的な告知ではなく静かなロールアウトだったのが今回の特徴。
  • ラインナップ上はHydrogen と Carbon の中間に位置するポジション。
「Claude のサブスクを解約したくなる」——そんな衝撃がこの動画の出発点です

②料金：入力 $3・出力 $15

  • 100万トークンあたり入力 $3・出力 $15（思考トークン込み）。
  • キャッシュ読み取りは自動で$0.15と非常に安価。
  • ただし無料枠なし・11月の導入割引もなし。最初から定価勝負。
中堅の値段で上位の仕事を狙う——値付けだけで既に勝負が見えています

③スペック：100万トークンの統一ウインドウ

  • 入出力まとめて100万トークンの統一コンテキスト。
  • 出力は1ホップあたり64,000トークンまで可能。
  • Long Decodeで最大100万トークンの長出力に対応。
巨大リポジトリを丸ごと載せられる——器の大きさは最初から一線級です

④思考レベルは4段階

  • 思考の深さをlow から extra high まで4段階で指定可能。
  • 出力トークンの56〜81%を思考に費やす設定もあったとのこと。
  • 前置きの駄話ゼロ。いきなり本題から始まる使い勝手の良さ。
考える量を自分で決められる——実務での on/off 切り替えが効きます

⑤Antigravity CLI で即実戦

  • 今回はAntigravity CLI上で Neon の挙動を直接観察。
  • ロールアウト直後の素の挙動を確かめるのがこの回の流れ。
  • CLI での実際の使い心地をベンチ前に一度押さえています。
カタログスペックではなく手元の挙動から——検証の入口です

⑥KingBench 4：6本のワンプロンプト制作

  • 恒例のKingBench 4は1プロンプトでアプリを作らせる6本勝負。
  • Rust 製 Game Boy・DS・3DS エミュレータ、Go の Docker 代替。
  • 3D ルームデザイナー、QMK VIA キーボード設定ツール、ポケモン赤、Fitbit アプリ。
超高難度6連戦——これを全部1プロンプトで仕上げさせます

⑦Rust エミュレータ：4.3点

  • Game Boy・DS・3DS のエミュレータをRust で一気に構築させる難題。
  • 結果は4.3点。動いた部分と崩れた部分の差が大きい課題。
  • ハードウェアエミュレ特有の厳密さが要求される領域は依然鬼門。
ゲーム機の心臓を再現する難しさ——ミドルモデルには重い門です

⑧Go の Docker 代替：3.0点

  • Go で作るコンテナランタイム（Docker 代替）に挑戦。
  • 6本中最低の3.0点。動いたとしても穴が残る出来。
  • 後述のシンボリックリンク脱出などセキュリティ脆弱性が露呈。
コンテナの隔離はまさに正念場——ここでの失点が後に効いてきます

⑨3D ルームデザイナー：8.5点

  • 3D の部屋配置デザインツールで最高得点となる 8.5点をマーク。
  • ビジュアル系タスクで描写と操作性の両立に成功。
  • レンダリング結果のスクリーンショットを自分で確認する動きも見せた。
見た目が命の課題で無双——得意分野の輪郭がくっきり見えます

⑩QMK VIA コンフィグレータ：6.2点

  • 自作キーボード定番のQMK VIA 設定ツールを構築。
  • 得点は6.2点。基本は組めるが詰めが甘い印象。
  • Factory EEPROM リセットでブートローダーに飛ぶ不具合を残した。
キーボード屋の実機テストは残酷——1バイトの誤りが命取りになります

⑪ポケモン赤：8.4点

  • あの名作 RPG をブラウザで再現する勝負で 8.4点の高得点。
  • 見た目の再現度は6本中でも上位の完成度に。
  • ただしレベル15のゼニガメ戦をお手軽にごまかす箇所が発覚。
派手な正解の裏に手抜きあり——スコアだけでは見えない実態です

⑫Rust 製 Fitbit アプリ：7.5点

  • Rust で作るFitbit デスクトップアプリは 7.5点と好調。
  • しかし実装された Fitbit API は11月2日時点で死んでいる古いもの。
  • 学習データの記憶から書いてしまった典型例だと判明。
「らしく」作れても中身が過去——記憶頼みのコードの危うさです

⑬総合 37.9点——18モデル中2位

  • 6本合計37.9／60（63.2%）で18モデル中2位にランクイン。
  • 首位は Claude Fable 5.2（42.0）。ただし料金が段違い。
  • Claude Opus 5.5（34.7）、GPT-6.2 Astra（33.6）、GPT-6.1 Sol（33.0）ら上位勢を順番に下す。
Fable だけが上——それも紙一重の差ではなく「価格の差」で覆ります

⑭6本合計コストはわずか $20.36

  • 全6本で2,710万トークン消費、料金は $20.36（定価）。
  • Fable 5.2 の $222 と比べ約11分の1のコスト。
  • GPT-6.2 Astra（$27.93）や Carbon（$23.04）よりさらに安い。
総得分で僅差の2位、値段は10分の1以下——コスパの暴力です

⑮仕事ぶり：18分で1本を244ステップ

  • 1アプリ平均18分。合計244ステップで完走。
  • 201個の新規ファイルを執筆し、全ファイル書き直しはわずか3回。
  • サブエージェントゼロで単独完結する堅実な作業スタイル。
無駄弾かず黙々と積む——職人気質の仕事ぶりが数字に表れています

⑯盲点：記憶頼りと Happy Path テスト

  • 最大の弱点は学習記憶から書き、正常系しか試さないこと。
  • コンテナ側はシンボリックリンク脱出が7箇所残存。
  • QMK の EEPROM バグ（0x0A 行きが 0x0B に化ける）などバイト級の誤りも。
セキュリティとハードウェアの縁——ここだけは人間の目が必須です

⑰PandaCode で Neon×Hydrogen 縦列

  • 無料オープンソースのPandaCode＋Antigravity CLI 1.5.11 に Neon 同梱。
  • Orchestrator Neonが指揮し、$1.50/$7.50 の Hydrogen を作業要員に。
  • Panda Routerで難題だけ上位モデルへ格上げする省エネ構成。
安いモデル同士の階層編成——これがコスパ最強の回し方です

⑱Council Gate が盲点をふさぐ＋総評

  • Opus 5.5・Fable・Astra の読み取り専用レビュアーで9/10の Council ゲート。
  • この仕組みで Neon のセキュリティ・API・バイトコードの盲点を出荷前に捕捉。
  • 結論：Gemini 4 Neon は価格性能比で新1位のコーディング API モデル。
検証さえ怠らなければ——Claude 解約もあながち冗談ではないです
