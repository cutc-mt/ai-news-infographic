OpenAI の新モデル「GPT-6.2 Astra」「GPT-6.2 Sol」の「同じ仕事を少ないトークンで」「API料金2割引き」が何と比べてどこまでの話なのか、公式の料金表と開発者向け案内で確かめた回

①GPT-6.2 Astra と GPT-6.2 Sol 登場

  • OpenAI が2つの新モデル「GPT-6.2 Astra」「GPT-6.2 Sol」をリリース。
  • うたい文句は同じ仕事を少ないトークンで・API料金は2割引き。
  • 動画では何と比べて・どこまでの話なのかを公式資料で裏取りする構成。
ニュースの一言を原典で確認する——ずんめたラボのいつもの作法です

②Astra は最上位・Sol は毎日の仕事向け

  • Astra は難しい仕事向けの最上位モデルで、GPT-6 Astra の後継。
  • Sol は毎日の仕事向けで、GPT-6.1 Sol の後継という系譜。
  • まず2モデルの役割分担を押さえると、料金と評価の話が読みやすくなる。
尖った仕事はAstra・日常はSol——名前で役割が分かれています

③少ないトークンで同じ仕事を終える

  • OpenAI の発表では、両モデルとも前より少ない出力トークンで仕事を終えるとされる。
  • 具体例はGDPval v2 で出力トークン22%減などの数値。
  • 出力トークンが減れば課金もその分へる——料金値下げとセットで効く仕組み。
単価だけじゃなく量もへらす——二段構えの節約設計です

④Astra の料金：入力8ドル・出力40ドル

  • API料金は100万トークンあたり入力8ドル・出力40ドル。
  • キャッシュ済み入力は0.40ドルと大幅に安い設定。
  • この数字が前世代と比べてどう変わったのかが次のカードの本題。
公式料金表ベースの数字——噂ではなく一次情報で確認です

⑤値下げの内訳：GPT-6 Astra と比較

  • 比較対象は前世代のGPT-6 Astra。ここ比べでのはなし。
  • 入出力は2割引き・キャッシュ済み入力は6割引きという値下げ幅。
  • つまり「2割引き」はAstra 限定・前世代比という限定された話。
「何と比べて」を毎回確認する——数字の読み方の基本です

⑥Sol の料金は変わらず 2割引きはAstraだけ

  • GPT-6.2 Sol は入力2ドル・出力10ドルで GPT-6.1 Sol と同じ。
  • よって「2割引き」は Astra だけの話で、Sol は据え置き。
  • 見出しだけ読むと誤解しがちな適用範囲の境界を明示。
割引の範囲を先に確認——思わぬ勘違いを防ぎます

⑦OpenAI 自己測定の数字の読み方

  • 1課題の費用（Agents' Last Exam）や各種点数はOpenAI 自身の測定。
  • 発表側に有利な条件になりがちな自己申告ベースである点に注意。
  • だからこそ第三者の評価と見比べる次の視点が大事に。
誰が測ったかで重みが変わる——第一源の確認が鍵です

⑧第三者評価：Artificial Analysis では

  • 第三者のArtificial Analysis の総合指標ではGPT-6.2 Astra は2位。
  • Sol は前の GPT-6 Astra と並ぶ位置づけという結果。
  • 自己測定の強調点と外部評価のズレをあわせて見せる誠実な整理。
内側と外側の両方で測る——評価の常識が詰まったカードです

⑨コードエージェント指標は Astra 横ばい・Sol 微減

  • コードを書くエージェントの指標ではAstra は横ばい。
  • Sol は 6.1 Sol より少し下がっていると報じられています（ITmedia の報道より）。
  • 万能な進化ではなく得手不得手があるアップデートだと割り切って読む。
全部盛りの強化ではない——用途別に判断しましょう

⑩ChatGPT での使える場所

  • ChatGPT ではPlus・Pro・Enterprise・Edu の ChatGPT Work と Codex で利用可能。
  • 会社や学校のプランは管理者が有効にしてからという条件付き。
  • 発表資料には無料プランでの提供は載っていないと明示。
有料プラン向けの提供——職場ならまず管理者に確認です

⑪GitHub Copilot と API でも展開

  • GitHub Copilot ではPro+・Max・Business・Enterpriseで利用可能に。
  • 提供は段階的に展開なので、環境によってはまだ来ていない場合も。
  • もちろんAPI から直接呼ぶ経路も即日利用できる。
ChatGPT・Copilot・APIの三正面——試せる場所は多いです

⑬長い仕事の頼み方：「妥当な仮定を置いて」

  • 長い仕事は「迷う所は妥当な仮定を置いて進めて」と任せ方を書くのがおすすめ。
  • これでいちいち止まらず最後まで走ってもらえる。

⑭確認を挟むべき2つのタイミング

  • 取り消せない操作の前も必ず確認を挟む運用に。
  • 「進めてよい所」と「聞くべき所」を指示で明示するのがコツ。
任せる所と聞く所の境目——これが今回いちばん役立つ知識です

⑮Sol と Astra の使い分け指針

  • 難しい・重要な仕事はAstra（入力8ドル・出力40ドル）に。
  • 日々の定型作業はSol（入力2ドル・出力10ドル）で回すのが経済的。
  • 出力単価は4倍の差——量が多い仕事ほど使い分けの効果が大きい。
仕事の重さで模型を乗り換える——家計と同じ発想です
