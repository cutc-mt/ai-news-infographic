GPT-6.2「Astra」「Sol」独自スコアリング徹底解析

科学・研究タスクでClaude Fable 5.2・Opus 5.5と比較。AIチームの役割分担を考える

第一部｜比較の設計
🎯

今回のテーマは「精密比較」

  • GPT-6.2のAstra（アストラ）とSol（ソル）を科学・研究タスクでスコアリング
  • 比較対象はClaude Fable 5.2とClaude Opus 5.5の計4モデル
  • 「どのAIに何を任せるか」というAIチーム設計が最終ゴール
ベンチマークの点数じゃなくて、自分の仕事にどう生きるかで比べたい。それがこの企画の出発点です。
📏

AIを公平に比較する条件

  • 同じ指示・同じ文字数や行数の条件で提出させる統制の大切さ
  • 条件が違うと「書きやすいモデル」が得をするだけになる
  • 前置き・まとめの有無など、出力形式の揃え方のコツ
比較の条件を詰めるのに一番時間をかけました。ここが甘いと全部意味がなくなりますから。
🔬

「難しいタスク」で差が出る

  • 簡単なお題ならどのモデルもそれなり。差が見えるのは科学・研究タスク
  • 計算・推論・文献の扱いが絡む課題で得意不得意が明瞭に
  • 動画では前回の3D制作との比較テーマにも触れる
🧑‍⚖️

採点はMeta Museに依頼

  • 各モデルの提出物をMeta Museに渡して評価する二段構え
  • 作成者本人が採点するとバイアスが入るため、評価役を分離
  • 相対評価で各軸に4・3・2・1点を一つずつ割り当て
作った人以外に採点してもらう。人間の世界と同じで、AIの評価も第三者が一番です。
📊

6つの評価軸とは

  • 忠実性：指示に沿って進める力
  • 網羅性：必要な内容を広く扱う力
  • 厳密性：計算や説明の正確さ
  • 独自性：新しい発想ができるか
  • 再現性：同じ結果を再度出せるか
  • 検証可能性：第三者が確かめられる形で出すか
🏆

総合点だけでは見えないもの

  • 総合点が近くても項目別の顔つきが全く違うことがある
  • 「高得点だが独自性が低い」モデルの使いどころは自ずと限られる
  • 評価軸ごとの特徴から逆算する使い分けの発想
総合点の順位より、凸凹の形を見るほうが実用では役に立ちます。
第二部｜モデル別の特徴
✨

GPT-6.2 Astraの印象

  • 旧GPT-6 Astraと比べて操作性と創造性が変化
  • 応答の組み立て方がより柔軟になったという使用感
  • 科学タスクでの厳密性と発想のバランスが注目ポイント
6から6.2になって、 tool の扱いが一段自然になった印象です。数値でなく「使っていて気持ちいい」差です。
📝

Astraの提出物から見えたこと

  • 指示解釈の幅の広さが提出物の構成にそのまま反映
  • 難しい課題でも構成でまとめにくるプランナー気質を確認
  • 検証可能性の軸で、出典や確認手順を残す姿勢が評価
🧭

Solの忠実性とレビュー適性

  • Solは忠実性が高く、指示からブレない傾向
  • 出力の点検・まとめ直しのようなレビュー役に向く場面
  • 一方で発想の飛躍はAstraほどではない、という使い分け
Solは「言われたことを確実にやる」のが得意。レビューと仕上げに置くとチームが安定します。
🗺️

Claude Fableをプランナーに

  • Fable 5.2は計画を立てる役に据えると力を発揮
  • 企画の骨組みと論点整理の丁寧さが特徴
  • CodexやClaudeを組み合わせる運用との相性
🔧

Claude Opusは実務のワーカー

  • Opus 5.5は実務を黙々と進めるワーカーとしての使い方
  • 研究・計算・レビューなど確実性が求められる工程に最適
  • 出力の安定感で長文・多段階タスクを壊しにくい
Fableが設計図を描いて、Opusが現場を仕上げる。この分担が今のところ一番しっくり来ています。
⚖️

GPTとClaudeの厳密性・独自性

  • 厳密性の軸では計算処理の丁寧さが明暗を分けた
  • 独自性の軸ではGPT系とClaude系で発想の傾向が分化
  • どちらが上ではなく「どの工程に置くか」の違いとして整理
第三部|AIチームの作り方
🤖

役割分担のAIチーム設計

  • プランナー：アイデアを広げ、計画を立てる（Fable）
  • ワーカー：作業を淡々と進める（Opus）
  • レビュー役：提出物を点検してまとめる（Sol／Astra）
1体の神様AIを探すより、3体の役割分担のほうが早い。チームで考えると急に見通しが良くなります。
🔁

普段の利用経験をどう反映するか

  • スコアは参考値。最後は日々の使い心地で決める
  • 結果と実感がズレたときは条件設定を見直す
  • 自分の仕事向けに評価軸の重みを変える提案
📈

GPT-6 Astra→6.2 Astraの変化

  • 忠実性・創造性・操作性の3点で新旧を振り返り比較
  • 指示への追従が素直になり、手直しが減ったという体感
  • 創造的な課題でも構成が荒くならくなった変化
バージョンが上がると「言わなくても分かる」が増えます。評価軸もそれに合わせて見直すのが大事です。
🧑‍🔬
