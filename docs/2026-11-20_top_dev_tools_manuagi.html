今週のトップ開発ツール——Svelte・uv・nvm・n8n・Appwrite & Solid

Manu AGI が厳選した「今週トレンドのオープンソース開発ツール」20選を一挙紹介。エージェントスキル、Rust製パッケージマネージャ、セルフホストDocker管理、UIフレームワーク、MCPサーバーディレクトリまで開発者の生産性を上げる道具箱を総点検

📅 2026年11月20日／Manu AGI - AutoGPT Tutorials／YouTubeで元動画を見る

①Skills For Real Engineers（mattpocock/skills）

  • TypeScript 教育の第一人者 Matt Pocock が公開する実務エンジニア向けのClaudeエージェントスキル集。
  • チュートリアルではなく現場で鍛えた流儀をそのままスキル化した点が特徴。
  • GitHub：github.com/mattpocock/skills
有名講師の“腕前”をスキルとして拝借できる注目株です

②rea & raea——MCPサーバーを逆解析

  • rea（morluto/rea）はMCPサーバーのリバースエンジニアリングを支援するツール。
  • 兄弟プロジェクト raea（shinyobjectz/raea）も同系統で、既存ツール連携の解析を自動化。
  • ドキュメントの乏しいAPIをMCP化して調査したい場面で活躍。
ブラックボックスなサーバーの中身を覗く——解析屋さん向けの2作です

③Claude-BugHunter——セキュリティテスト特化

  • Claude に脆弱性探索・バグハンティングをさせる専門スキル（elementalsouls製）。
  • セキュリティテスト工程をエージェント化し、手動監査を補助。
  • GitHub：github.com/elementalsouls/Claude-BugHunter
見つける側に回るAI——防御の道具としても使い勝手です

④Cursor plugins——公式プラグインリポジトリ

  • AIコードエディタ Cursor の公式プラグイン集がGitHubに登場。
  • エディタ拡張の作り方・配布のエコシステムが整備されつつあるサイン。
  • GitHub：github.com/cursor/plugins
エディタがプラットフォームになる——拡張の波が来ています

⑤last30days-skill——知識の鮮度問題を解決

  • mvanhorn 製。直近30日間の情報を取得する Claudeスキル。
  • LLM の学習データが古い問題を検索で補う定番の一手をスキル化。
  • GitHub：github.com/mvanhorn/last30days-skill
「モデルは先月のことを知らない」——その穴を埋める部品です

⑥arcane——セルフホストDocker管理UI

  • arcane（getarcaneapp/arcane）はブラウザからコンテナ運用を丸ごと管理するUI。
  • Portainer 的な役割を自己ホストで軽量に実現する新顔。
  • GitHub：github.com/getarcaneapp/arcane
docker ps とおさらば——GUIで握る自前インフラです

⑦NVIDIA SkillEvaluator——スキルの採点者

  • NVIDIA 公式のエージェントスキル評価フレームワーク。
  • 自作スキルが本当に効くのかをベンチマークで測定できる。
  • GitHub：github.com/NVIDIA/SkillEvaluator
スキルを作る時代から「選別する」時代へ——大手も参入です

⑧nvm——Nodeバージョン切替の定番

  • nvm（nvm-sh/nvm）はプロジェクトごとにNode.jsのバージョンを切り替えする定番ツール。
  • シェルスクリプト1つで導入できる軽量さが長年の支持の秘密。
  • GitHub：github.com/nvm-sh/nvm
新兵器もいいけど安定兵器も良い——今週の再発見枠です

⑨uv——Rust製の爆速Pythonツール

  • Astral 製 uv は Rust で書かれたPythonパッケージマネージャ。
  • pip・venv・pyenv・pipx の役割を1本に統合しつつ桁違いに高速。
  • GitHub：github.com/astral-sh/uv
「pip install 待ち」が懐かしくなる——Python界の高速道路です

⑩paper-orchestra——Googleの論文オーケストラ

  • Google Research の paper-orchestra は複数エージェントで論文のトリアージ・要約を分担。
  • 日々届く論文をオーケストラのように役割分担で処理する研究プロジェクト。
  • GitHub：github.com/google-research/paper-orchestra
論文読みも分業の時代——研究部の味方です

⑪Stitch Design Skills——Google Labs発

  • UIデザイン生成ツール Stitch 向けの公式系デザインスキル集。
  • プロンプト→画面デザイン→コードの流れをスキルで精度向上。
  • GitHub：github.com/google-labs-code/stitch-skills
Google Labs の実験精神——デザイン×エージェントの最前線です

⑫Svelte——コンパイラ型UIフレームワーク

  • Svelte（sveltejs/svelte）はコンポーネントを効率的なJavaScriptにコンパイルするUIフレームワーク。
  • 仮想DOMなしの軽量・高速な描画が根強い人気。
  • GitHub：github.com/sveltejs/svelte
書くほど速くなる——ランタイムなしの刷新派です

⑬jQuery——今も進化する不滅の定番

  • jQuery（jquery/jquery）はDOM操作の元祖・至高の定番ライブラリ。
  • モダン時代になっても保守・更新が継続している点が驚き。
  • GitHub：github.com/jquery/jquery
「まだ現役？」ではなく「まだ進化」——語り継ぐべき存在です

⑭Appwrite——オープンソースのBaaS

  • Appwrite はDB・認証・関数・ストレージを丸ごと提供するオープンソースのバックエンドクラウド。
  • Firebase 代替としてセルフホスト可能なのが強み。
  • GitHub：github.com/appwrite/appwrite
ベンダーロックなしでバックエンド丸投げ——自前派に嬉しい一枚

⑮OpenVINO——Intelの推論ツールキット

  • OpenVINO（openvinotoolkit）はCPU・内蔵GPUでAI推論を高速化するIntel製ツールキット。
  • 最新版ではローカルLLM実行のサポートも強化。
  • GitHub：github.com/openvinotoolkit/openvino
GPUがなくても推論は速くできる——手元環境の底力です

⑯n8n——ビジュアルで組むAIエージェント

  • n8n（n8n-io/n8n）はノードをつなぐだけでワークフロー自動化を組めるビジュアルツール。
  • 近年はAIエージェント構築基盤として人気が再加速。
  • GitHub：github.com/n8n-io/n8n
コードを書かずにエージェントを編む——自動化のキャンバスです

⑰Solid——高速リアクティブUIライブラリ

  • Solid（solidjs/solid）はJSXで書ける細粒度リアクティビティのUIライブラリ。
  • React ライクの見た目で実行時の無駄を削ぎ落とす設計。
  • GitHub：github.com/solidjs/solid
React の書き心地、Svelte 並の速さ——職人好みの選択肢です

⑱awesome-mcp-servers——MCPの巨大ディレクトリ

  • punkpeyes の awesome-mcp-servers はMCPサーバーの決定的なカタログ。
  • 「どのMCPがあるか」を探すならまずここ、という情報の玄関口。
  • 元動画：Top Dev Tool Projects : Svelte, uv, nvm, n8n, Appwrite & Solid
道具は揃った——あとは使うだけ。毎週チェックしたいシリーズです
