週刊トップ開発ツール——Rails・VS Code・Ruff・MuJoCo・Sherlock & Agent Browser

Manu AGI が厳選した「今週トレンドのオープンソース開発ツール」20選を18カードに凝縮。定番WebフレームワークからRust製リンタ、DeepMind物理エンジン、OSINT検索、エージェント用ブラウザ自動操作まで、開発者の生産性を底上げする道具箱を総点検

📅 2026年11月20日／Manu AGI - AutoGPT Tutorials／YouTubeで元動画を見る

①Ruby on Rails（rails/rails）

  • Rubyの定番フルスタックWebフレームワーク。DB駆動アプリを少ないコード量で素早く構築できる「設定より規約」の代表格。
  • scaffolding・マイグレーション・ORM（Active Record）が標準装備で、アイデアから公開までの速度が最大の強み。
  • GitHub：github.com/rails/rails
20年選手の大御所も今週のトレンドに返り咲きました

②Visual Studio Code（microsoft/vscode）

  • MicrosoftがOSSとして公開する世界シェアトップ級のコードエディタ。edit-build-debugのサイクルを一つの画面で完結。
  • 拡張機能マーケットと統合ターミナル・Git・デバッガにより、言語を問わず日常開発の中心に置ける万能さ。
  • GitHub：github.com/microsoft/vscode
「エディタ界のLinux」とも言える存在感。トレンド常連です

③Ruff（astral-sh/ruff）

  • Rustで書かれた超高速Pythonリンタ／フォーマッタ。flake8・isort・Black相当を1ツールに統合。
  • 動作が桁違いに軽く、保存のたびに全体チェックしてもストレスなし。Pythonプロジェクトの新標準に。
  • GitHub：github.com/astral-sh/ruff
「速い」は正義。Rust製ツール旋風の先駆けです

④impeccable（pbakaus/impeccable）

  • 今週のピックのひとつで、GUI／Reactのデザインシステム構築に関わる注目プロジェクト。
  • 手作業になりがちなUIの見た目の整合をツールで担保するアプローチが話題。
  • GitHub：github.com/pbakaus/impeccable
フロントの「ダサくなる問題」に挑む新鋭です

⑤Raven（oscar-soirey/Raven）

  • 週次トレンドにランクインした新顔の開発ツール。詳細な解説は元動画で確認できます。
  • 作者個人の実験から生まれるユニークな道具がバズりやすい今のGitHubらしい1本。
  • GitHub：github.com/oscar-soirey/Raven
小さいプロジェクトこそ早めのウォッチがおすすめです

⑥astryx（meta/astryx）

  • Meta名義のリポジトリとして公開され注目を集める新プロジェクト。
  • 大手が公式に出す実験的リポジトリは将来のプロダクトのシグナルになることも。
  • GitHub：github.com/meta/astryx
「meta/org」の中身は要チェックです

⑦daily_stock_analysis（ZhuLinsen）

  • セルフホスト型のデイリー株価分析アプリ。データを手元に置いたまま自己責任の資産運用支援ができる。
  • 外部SaaSに口座情報を預けたくない人向けのプライバシー重視設計。
  • GitHub：github.com/ZhuLinsen/daily_stock_analysis
「self-hosted」勢の聖地、Dockerで気軽に試せます

⑧modern-web-guidance-src（GoogleChrome）

  • Google ChromeチームによるモダンWeb開発ガイダンスのソース一式。Web標準のベストプラクティスを公式視点で学べる。
  • 断片化しがちなWebの「今の正解」を一箇所にまとめる試みが価値。
  • GitHub：github.com/GoogleChrome/modern-web-guidance-src
迷ったら公式ガイダンスに立ち返るのが近道です

⑨agent-skills ＆ taste-skill——スキルパック2連発

  • Chrome界隈で著名な Addy Osmani の agent-skills など、コーディングエージェントに後付けできるエンジニアリング技能パックが今週のトレンドに。
  • taste-skill（Leonxlnx）は「センス／審美眼」をスキル化する変化球。エージェントの行動精度を育てる新ジャンル。
  • GitHub：github.com/addyosmani/agent-skills ／ Leonxlnx/taste-skill
「スキルを配る」時代。エージェントに履歴書を持たせる感覚です

⑩Agent Browser（vercel-labs/agent-browser）

  • Vercel Labsが放つエージェント専用のブラウザ自動操作ライブラリ。AIエージェントがWebページを操作・スクレイプするための足回り。
  • 壊れやすいセレクタ依存を減らし、LLMの判断で柔軟に画面遷移できる設計が狙い。
  • GitHub：github.com/vercel-labs/agent-browser
Webをエージェントの手足に。ブラウザ操作の決定版候補です

⑪sure（we-promise/sure）

  • 「promise」を名乗る組織 we-promise が公開したユーティリティ系プロジェクト。
  • 今週のトレンド入りの小型ツール。名前のユーモアもあって注目度上昇中。
  • GitHub：github.com/we-promise/sure
リポ名だけで覚えてしまう、いかにも今週らしい1本です

⑫HA-MCP（homeassistant-ai/ha-mcp）

  • Home AssistantをMCP経由で操作するサーバー。スマートホームの照明・センサー・家電をエージェントに委譲。
  • 「話しかけて家を制御」が標準プロトコルで実現する、実生活寄りのMCP活用例。
  • GitHub：github.com/homeassistant-ai/ha-mcp
MCPの入り口としても最適。まず照明から始められます

⑬codex-security（openai/codex-security）

  • OpenAI公式のセキュリティスキャナ。コード中の脆弱性を自動検出する開発者向けツール。
  • 生成AI時代は「書く速さ」より「見張る速さ」が命。公式メンテの信頼性が強み。
  • GitHub：github.com/openai/codex-security
AIで量産する時代こそ、自動セキュリティ監査を

⑭The Algorithms——Java（TheAlgorithms/Java）

  • 定番アルゴリズム実装コレクションのJava版。ソート・探索・グラフなど教科書的アルゴリズムが全部ソースで読める。
  • 「読んで動かして学ぶ」に最適な初学者のバイブル的リポジトリ。
  • GitHub：github.com/TheAlgorithms/Java
面接対策にも。今でも現役で育つコミュニティです

⑮Claude Code Game Studios ＆ claude-seo

  • Claude-Code-Game-Studios（Donchitos）は、Claude Codeをゲーム制作スタジオ化する野心作。
  • claude-seo（AgriciDaniel）はSEO分析・対策をClaudeに任せるツール。CLIエージェントの「職域」が拡大中。
  • GitHub：github.com/Donchitos/Claude-Code-Game-Studios ／ AgriciDaniel/claude-seo
Claude Codeの使い方はもう「コーディング」に止まりません

⑯MuJoCo（google-deepmind/mujoco）

  • DeepMindがOSS公開する高性能物理シミュレーションエンジン。ロボット工学・強化学習の標準環境。
  • 剛体・柔軟体・接触を高精度かつ高速に計算。研究者からホビイストまで利用範囲が拡大中。
  • GitHub：github.com/google-deepmind/mujoco
実機を壊さずに済む、ロボット開発の砂場です

⑰Sherlock（sherlock-project/sherlock）

  • ハンドルネーム一つで数百のSNS・サイトを横断検索するOSINTユーザー名検索ツール。
  • Python製CLIでインストール即実行。セキュリティ調査や名前被りの発見に便利。
  • GitHub：github.com/sherlock-project/sherlock
自分のハンドルがどこに残っているか、一度調べてみては

⑱GestaltX（huamidev/GestaltX）

  • 「ゲシュタルト」の名を冠した今週の注目株。全体を捉える設計思想のツールとして話題。
  • 動画ではラストを飾るピックとして紹介。詳細な使い方は元動画で解説。
  • GitHub：github.com/huamidev/GestaltX
締めの1本まで外しなし。全20プロジェクト、要チェックです
