#02

そもそもウェブサイトの「本当のコスト」The Problem: What a Website Really Costs

動画冒頭では、ウェブサイトを持つことの隠れたコストが整理されます。外注すればまとまった初期費用がかかり、自作すれば学習と制作の時間というコストを払うことになります。さらに公開後もドメイン・サーバー代といったランニングコストと更新作業が続きます。

  • 制作を外注 → 費用が高く、修正のたびに依頼が必要
  • 自力でコーディング → 学習コストが大きく時間がかかる
  • 公開後もドメイン・ホスティング・保守の費用と手間が継続

この3重のコストを一気に圧縮できる可能性が、ノーコードビルダーに寄せられる期待です。

#03

Webliumとは？What Is Weblium?

Webliumは、コードを書かずにドラッグ＆ドロップとブロック選択でウェブサイトを組み立てるノーコードWebサイトビルダー。制作・公開・運用に必要な機能を1つのプラットフォームに統合しているのが特徴で、後述の通りドメイン・ホスティング・SEO対策もプラットフォームに含まれます。無料で始められて、料金プランは動画の8:20からのセクションで詳しく検証されます。

#04

ブロックエディタの考え方How to Create a Website Without Coding: Building the Site

Webliumの制作の中心にあるのはブロックエディタ。ヘッダー、ヒーロー、特徴紹介、料金表、お問い合わせフォームといった「完成済みの区画（ブロック）」をページに積み重ねて、中身の文章や画像を差し替えていく方式です。レイアウトを1から設計する必要がなく、初心者でも破綻しないデザインに仕上がるのが利点です。

  • 目的別に用意されたブロックを追加・並べ替え・複製
  • テキスト・画像・ボタンなど要素単位でも直感的に編集
  • デザインの知識がなくても整った構成を作れる

#06

Flex Block：通常グリッドとの決定的な違いFlex Block: The Fix for Sites That All Look the Same

動画の目玉機能がFlex Block。一般的なノーコードビルダーの「グリッド（升目）レイアウト」は要素をマスに収めるため、どうしてもどのサイトも同じ見た目になりがちです。Flex Blockはフレキシブルな自由配置を実現し、マスの制約にとらわれないオリジナルデザインをノーコードで実現します。

項目通常グリッドFlex Block
配置マス目に沿った整列自由な位置・重ね合わせ
デザインの個性テンプレート感が出やすい他と似たサイトにならない
初心者への難易度低い慣れが必要だが直感的
#07

Flex Blockが解決する「画一化」問題Why Your Site Won't Look Like Everyone Else's

チャプター「The Fix for Sites That All Look the Same」が示す通り、Flex Blockは「ノーコードサイトはどれも似たようになる」という業界の弱点への処方箋として位置づけられています。セクション内で要素を重ねたり、非対称に配置したり、余白や比率を細かく制御でき、テンプレートを選んだ人たちと差をつけた表現が可能になります。Webliumを他のビルダーと隔てる主要な差別化ポイントです。

グリッドの制約→ Flex Blockで自由配置→ 独自の見た目へ
#08

レスポンシブデザイン対応Responsive Design（5:03）

作ったサイトはスマートフォンやタブレットでも自動的に最適化されるレスポンシブ設計に対応。エディタ内でデスクトップ／モバイルの表示を切り替えて確認でき、端末ごとに見た目が崩れないかをチェックしながら調整できます。現代のサイト運営では必須の機能で、コードを書く場合には面倒なメディアクエリの調整がノーコードで完結します。

  • PC・タブレット・スマホのマルチデバイス対応
  • エディタ上でプレビューしながら調整
  • 表示の崩れを公開前に確認できる

WebliumにはAIによる支援機能が組み込まれており、動画では「AI in Action」というチャプターで実際の動きが紹介されます。サイト制作の一部をAIが担うことで、文章の生成や構成の提案などの作業が楽になり、「何を書けばいいか分からない」という初心者つまずきの大きな壁を低くしてくれます。AIツールの進化により、ノーコード構築はさらに手軽になっています。

#12

制作前に準備しておくことWhat to Prepare Before You Build（7:35）

スムーズに制作を進めるために、動画は着手前の準備も紹介します。ツールが簡単でも、中身（コンテンツ）は自分で用意しなければなりません。事前にそろえておくと制作が一気にはかどります。

  • 載せる文章（会社紹介・サービス説明・料金など）
  • ロゴや画像などの素材
  • サイトの目的とページ構成の大枠（リード獲得なら導線設計）

「何を伝えたいか」が固まっていれば、ブロックを当てはめるだけで構成が決まります。

公開と結果：ドメイン・ホスティング・SEOはどうなる？Publish and Result（7:55）

サイトが完成したら、いよいよ公開。Webliumではドメインとホスティングがプラットフォームに含まれるため、別途サーバーを契約したりFTPでファイルをアップロードしたりする作業は不要です。さらにSEO対策の機能・設定も付属しており、検索エンジンへの最適化の入り口まで面倒を見てくれます。動画では公開までの手順と、実際に出来上がった結果が示されます。

  • ドメイン：プランに付属（別途手配不要）
  • ホスティング：プラットフォーム側で運用
  • SEO：基本対策を標準機能としてサポート

サポート体制：独学でも安心Onboarding / Knowledge Base / 24-7 Live Chat

初心者がつまずいたときの支援も充実しています。動画では次の3本柱が紹介されます。

  • オンボーディングサポート：開始時の手厚い案内で最初の壁を低くする

#16

弱点と物足りない点Where the Platform Falls Short

スポンサードレビューでありながら、動画はプラットフォームの短所にも踏み込みます。説明欄に「where the platform falls short（プラットフォームが及ばない点）」と明記されており、良い面だけの宣伝動画ではないことが分かります。

  • 自由度が高い一方で、細部の微調整には慣れが必要な場面がある
  • コードで書いた場合に可能な特殊なカスタマイズまでは届かない
  • プラットフォーム依存のため、将来の移行コストは念頭に置くべき

ノーコード全般に言える「手軽さと自由度のトレードオフ」を、実体験ベースで確認できます。
