Claude Opus 5 登場

① Claude Opus 5 ついにリリース！

  • AnthropicがClaude Opus 5をリリース — FA5（Fable）の最先端知能に匹敵するとアナウンス
  • 価格は半額と言っているが、実際は従来のOpusと同額 — Fableが単に2倍高かっただけ
  • 公式ベンチマークではFableに一部劣る部分もあるが、全体としては上位に位置
  • 公式ページでも「Fableの方が性能は上」と明記されている
価格据え置きと捉えれば、Fableの高さが際立つね

② Fable vs Opus 5: コストパフォーマンス勝負

  • 全体性能はFableが上だが、一部の領域ではOpus 5がFableを超えている
  • Fableはコストが非常に高い — それを考えると「もうOpusでいいじゃん」場面が増える
  • 実際の使い込みで検証していく必要がある — 体感値が重要
  • 日常の壁打ちならOpus 5で十分という印象
重い課題だけFable頼み、普段はOpus 5でOK！

③ Opus 5の改良ポイント: エージェント能力向上

  • 自立的に修正して改善していくエージェント的な動きが大幅に向上
  • フロントデザインの作り込み、3D立体表現・ゲーム描写が上達
  • 過去のOpusの中で最高という評価（過去最高）
  • 手戻り手数が減った — つまりトークン消費の節約にもつながる
手数が減る＝コスト節約！これは嬉しいポイント

Opus 5の新しい挙動

④ 意見を言うようになった: 設計への反対意見

  • Opus 5は設計に対して反対意見を出してくるようになった — 「これはちょっと違うのでは」と指摘
  • ユーザーが押しても引っ込めない場合がある — 自分の意見をある程度坚持
  • これが良いか悪いかは賛否両論 — 使い手の好み次第
  • 壁打ち相手としては的確な指摘を期待できるので有用
「それ間違ってますよ」って言ってくれるのは壁打ち的に有り難い！

⑤ FableとOpus 5の壁打ち比較: 指摘は同じ

  • 過去にFable 5で壁打ちした内容を、Opus 5にコピペして同じテーマで壁打ちを実施
  • 結果: 指摘してくれる部分は同じだった — 信頼性は十分
  • ただし回答が長い印象 — Fableに比べて出力が長くなる傾向
  • 必要な部分だけつまみ取る付き合い方の調整が必要
長い回答は裁量で切り取るスキルがいるね

⑥ Cursor BenchでFable 5とほぼ同等スコア

  • CursorのベンチマークでFable 5とほぼ同等のスコアを記録 — 差はほとんどない
  • 価格半分で同等の性能を実現していることが強調されている
  • APIが公開済み — Cursor、Perplexityなどで利用可能
  • Gensparkなども早々に対応する見込み — 様々なツールで利用可能に
ほとんどのタスクはOpus 5で十分なんじゃない？
