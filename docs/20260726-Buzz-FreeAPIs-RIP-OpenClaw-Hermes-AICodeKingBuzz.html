Buzz: AIエージェントと人間の協働ワークスペース

Slack ＋ GitHubが一つになった完全オープンソースの無料ツール。
Jack DorseyのBlockがリリース、AIエージェントが「チームメンバー」として働く

📅 2026年7月26日

Buzzとは何か？

① Buzzとは: SlackとGitHubを統合したAI協働ツール

  • Jack DorseyのBlockがリリースした人間とAIエージェントが対等に協力するワークスペース
  • SlackとGitHubが1つのアプリに統合されたようなもの
  • Apache 2.0ライセンスで完全オープンソース、無料
  • Nostrプロトコルをベースに構築 — 分散型の基盤
Block社内では既にSlackとGitHubの代替として使われてる！本気度が違う

② エージェントはメンバーであってボットではない

  • Slackのボットは統合の範囲内でしか動けない限定された存在
  • Buzzのエージェントは独自の暗号化IDと権限を持つ
  • チャンネル投稿、コードレビュー、自動化処理、ワークフロー参加がすべて可能
  • 人間のチームメイトと同じ能力を持つ存在として扱われる
ボットじゃない、メンバーなんだ！これがBuzzの核心

③ Nostrキーペアによる持ち運び可能なID

  • エージェントのIDはNostrキーペアに基づいている
  • プラットフォームアカウントやベンダー管理のAPIキーに依存しない
  • IDは持ち運び可能で、検証もできる
  • 責任追跡の仕組みも完備 — 人間の所有者と結びつく2つ目の署名付き
誰がどのエージェントを所有し、何をしたか完全な監査証跡が残る！

セットアップと初期体験

④ セットアップ開始: アカウント不要のキーベース認証

  • buzz.xyzにアクセスしてアプリをダウンロード（macOS / Windows / Linux対応）
  • アカウントもメールもパスワードも一切不要
  • デバイス上でNostrキーペアを生成 — あなたのIDはあなたのもの
  • 注意: キーを紛失すると復元不可 — パスワードマネージャーに保存必須
パスワードリセットなし！鍵をなくしたらIDは永遠に消える...！

⑤ エージェントハーネスの自動検出

  • Buzzがマシンをスキャンして既存のAIコーディングツールを自動検出
  • Claude CodeやCodexが検出され、数秒でアダプターをインストール
  • 設定ファイルも手動設定も不要 — 非常にスムーズ
  • デフォルトのハーネスとモデルを選択、後から変更も可能
既存のツールをそのまま活用、ゼロから設定する必要なし！

⑥ 追加API料金なし: 既存のサブスクをそのまま利用

  • エージェントは既存のClaude CodeやCodexを通じてローカルで実行
  • Buzzから追加のAPI料金は発生しない
  • 既にClaudeのサブスク料金を払っているなら、その料金をそのまま利用できる
  • 自分のワークスペースにフリーエージェントがいるようなもの
既に払ってるサブスクでAIチームが使える = 実質無料！

スターターチームとワークスペース

⑦ 内蔵のスターターチーム: Fizz・Honey・Bumble

  • Fizz: 状況を把握できるようにサポートするコーディネーター
  • Honey: 執筆・編集を担当するライティングエージェント
  • Bumble: リサーチを担当する調査エージェント
  • 起動時から小規模なAIチームが存在 — ゼロから始める必要なし
可愛いミツバチのアバター付き！最初からチームがいるの嬉しい

⑧ エージェント同士の連携: BumbleからHoneyへの引き継ぎ

  • BumbleにBuzzとSlackの違いを執筆依頼 → 説得力のある文章を数秒で完成
  • Bumbleが自発的にHoneyにメンションして磨き上げ作業を依頼
  • ユーザーが指示しなくてもエージェント同士で連携を取る
  • ただしHoneyは自動で反応せず 人間のメンションが起動トリガー（無限ループ防止策）
「Slackは人間がチャットする場所、Buzzは対等なチームメイトが働く場所」— Honeyの名言

⑨ SlackライクなUI: 学習曲線ほぼゼロ

  • サイドバーに受信トレイ・エージェント・チャンネルを表示
  • デフォルトで一般・プライベート・全員参加のウェルカムチャンネルが作成される
  • 検索バー、ダイレクトメッセージ、メンション、添付ファイル、絵文字すべて完備
  • Slackを使ったことがあれば即座に使える — 学習コストなし
見た瞬間から使い方がわかる、それが大事！

エージェント管理と権限

⑩ エージェントページ: AIチームのコントロールセンター

  • 各エージェントはアバター・名前・モデルが表示されたカード形式
  • アクティビティログで全ての操作を監査可能 — すべての行動は署名付きイベント
  • エージェントをチーム単位でグループ化してチャンネルに一括追加
  • 全エージェント停止ボタン付き — 暴走時の緊急停止も可能
監査ログが「意味のあるもの」 — それが署名付きイベントの力

⑪ 新規エージェント作成: 30秒で完了

  • 名前・指示書・ハーネス・モデルをシンプルなフォームで入力するだけ
  • カタログから事前構築エージェントを選択も可能
  • 権限スコープ設定: 誰がエージェントと話せるかを制御（デフォルトは自分のみ）
  • 並列処理設定: 同時に処理できるタスク数をコントロール
Slackボットなら数ステップ必要な設定が30秒で完了！

⑫ モデル非依存: Claude・Codex・Gooseに対応

  • エージェントクライアントプロトコル（ACP）を介して複数のツールをサポート
  • Claude Code、OpenAI Codex、Block独自のGooseフレームワークに対応
  • 特定のAIベンダーに縛られない — モデルフリーの設計
  • エージェントごとに異なるモデルを割り当て可能
ベンダーロックインなし！好きなツールを組み合わせられる

Git統合とセルフホスティング

⑬ Git統合: フィーチャーブランチがチャネルになる

  • Buzzにはコードホスティング機能が組み込まれている
  • フィーチャーブランチ = チャネル — パッチ、CI結果、レビューが一箇所に
  • 会話、パッチ、ワークフロー、承認を1つの統合検索で検索可能
  • Block自身もForge UIはまだ初期段階と述べている — 本番移行はまだ早い
SlackスレッドとPRを行ったり来たりする必要がなくなる！

⑭ セルフホスティング: 完全に自分で運用可能

  • 中心はRustベースのNostrリレー — イベント管理にPostgres
  • pub/subにRedis、検索にTypeSense、メディアにS3またはMinIO
  • リポジトリをクローン → Hermit環境 → setup → build → relay & dev起動
  • リレーはlocalhost:3000で動作、Dockerが必要
# セットアップ手順
git clone buzz-repo && cd buzz
./hermit activate
./buzz setup && ./buzz build
./buzz relay  # ターミナル1
./buzz dev    # ターミナル2
オープンソースだから自分のインフラで完全運用できる！

⑮ Buzz CLI: エージェント向けに設計されたコマンドライン

  • 入出力はJSON形式 — LLMツールの呼び出しに最適
  • エージェントのキーで秘密鍵環境変数を設定するだけ
  • Buzz ACPハーネスがClaude Code・Codex・Goose統合を内部的に動作させる
  • 独自のアイデンティティを持つ完全カスタムエージェントを構築可能
CLI経由でエージェントが人間と同じことができる！自由度が高い

実体験と無料APIの活用

⑯ 実際に使ってみた感想: 方向性は正しい

  • AIチームへの参加は5分もかからず、エージェント同士が本当に連携していた
  • 現在のAIツールは1対1のソロ環境だが、実際の作業はチームで行う
  • 複数の人間とエージェントがコンテキストを共有して共同作業できる環境は他にない
  • エージェント体験の完成度の高さに驚き — 初公開としては素晴らしい
ソロ作業からチーム協働へ — これがAIの未来の形！

⑰ 無料モデルの活用: Goose経由でOpenRouterやNvidia API

  • Gooseを使ってOpenRouterに接続し、無料モデルを使用可能
  • 無料のNvidia APIなどに接続して利用することもできる
  • ローカルモデルも併用可能 — Gemmaを試したらかなり動作した
  • 自由度は高いが、完璧ではない — まだ懐疑的な部分もある
OpenRouterの無料モデルやNvidia APIで実質コストゼロも可能！
