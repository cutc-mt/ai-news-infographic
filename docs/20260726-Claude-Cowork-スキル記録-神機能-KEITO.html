スキル記録機能とは？

① レコードボタンをポチッと押すだけ

  • Claude Coworkに「スキルを記録する」ボタンが新しく追加された
  • ボタンを押すと画面の録画が開始され、人間が操作する様子をClaudeが観察
  • 音声で説明を入れながら操作できるので、言葉と行動を同時に記録
  • 記録が終わるとそのままAIワークフローの手順書として保存される
話を聞いただけでめちゃくちゃ便利そう...！

② 高い再現性で同じ作業を自動実行

  • スキルとして保存すれば、後から同じ作業をClaudeが再現してくれる
  • 音声での説明もスキルの一部として記録される
  • 人間が手作業でやっていた手順を、そのままAIに任せられるようになる
  • 一度記録すれば何度でも実行可能 — 放置するだけで作業が完了
一度教えれば、あとは放置するだけ！

③ 今回検証する4つの作業を紹介

  • Nottaの目次作成 — 動画アップロード後に目次と共有リンクを作成
  • 不要データの一括削除 — Gemini NotebookやOpenAIのAPIキーを掃除
  • アプリの完全終了 — Macのバックグラウンドアプリを1つずつ終了
  • スクリーンショット集め — サンプルサイトを巡回してPDFで保存
全部地味な作業だけど、毎回やるのはめんどくさい...！

検証1: Nottaで目次作成

④ 音声で作業手順を指示していく

  • 「Braveブラウザを開いてNotta.AIにアクセスして」からスタート
  • 最新のアーカイブを開いて目次を生成 → 共有リンクを作成
  • パスワード保護をオンにしてリンクとパスワードをコピー
  • 目次をAIの文章整形でメインのタイムラインのみに整えてメモ帳に貼り付け
音声で説明しながら操作するだけでOK！

⑤ スキルはテキストベースで保存される

  • 記録完了後にスキルを確認すると、テキストのみの内容だった
  • 「これだけで本当に再現できるの？」と不安になるレベル
  • 録画映像も保存されていれば納得感があるが、テキストのみで果たして...
  • 一旦保存して実際に試してみることに
テキストだけ？！これで本当にできるの...？

⑥ 大成功: わずか2分で作業が完了

  • Chromeツールを読み込んで自動でブラウザを操作開始
  • 最新アーカイブの特定、目次生成、共有設定まで約2分で完了
  • 外部共有オン、パスワード保護オン、リンクコピーまで完璧
  • 実際にアクセスするとNottaのページが開けた — URLの発行は成功
  • 目次の整形はプロンプト次第で改善可能 — 全体的に大成功
2分で完了！テキストだけで再現できた！

検証2: 不要データの一括削除

⑦ 一括削除がないサービスの辛さ

  • Gemini Notebookには一括削除機能がない — 1個ずつ削除するしか方法がない
  • 有料プランでも上限は約300個 — 上限に達すると古いものを消す必要がある
  • OpenAIのAPIキーも大量に作りすぎて削除が面倒 — ここにも一括削除がない
  • こういう「地味だけど毎回やる」作業こそスキル化の対象にぴったり
一括削除がないサービス、意外と多いんですよね...

⑧ 音声指示で削除手順を記録

  • 「Braveブラウザを開いて notebooklm.google.com にアクセスして」
  • 一番下までスクロールして「無題のノートブック」を削除していく
  • 点々点（三点メニュー）をクリック → 削除 → デリートの繰り返し
  • 「Untitled Notebook」と「無題のノートブック」をすべて削除してってと指示
多分これうまくいくでしょう...！

⑨ 完全成功: リスト表示まで工夫してくれた

  • 「NotebookLM クリーンアップ」スキルを実行 — Sonnet 5で高速化
  • Claudeが作業効率を上げるためにリスト表示に変更するなどの工夫も自主的に実行
  • 「Untitled Notebook」と「無題のノートブック」をすべて削除完了
  • 放置しているだけで地味な反復作業が終わる — めちゃくちゃ便利
リスト表示に変えてくれたのは地味にすごい！

検証3: デスクトップアプリの終了

⑩ バックグラウンドアプリを1つずつ終了

  • Macの下のドックに並んでいるアプリを1つずつ終了させていく作業
  • アプリを開きすぎるとパソコンが重くなるので定期的に終了したい
  • 右クリックで「終了」を押していくだけの単純作業
  • 条件: OBSとClaudeのアプリは必ず残す — 配信と録画に必要
仕事終わりの5分10分を無駄にしたくない！

⑪ Computer Useでデスクトップ操作に挑戦

  • ブラウザ操作ではなくComputer Use機能を使ってデスクトップを操作
  • スキル記録時にテキストで回答が返ってきてしまい、追加指示が必要に
  • 「スキルとして保存してほしい」と追加で指示してようやく保存完了
  • Claudeから「未保存のアプリはどうする？」と質問が来る — ちゃんと対話できる
質問にもちゃんと答えてあげるのがコツ！

⑫ 結果: デスクトップ操作は微妙だった

  • Computer Use自体は起動したが、手作業でやった方が早かった
  • 今回の検証では失敗扱い — デスクトップの細かい操作はまだ難しい
  • ブラウザ操作（Browser Use）の方が相性が良いと判明
  • 一括終了の機能をターミナルで実装する方が現実的かもしれない
デスクトップ操作はまだ発展途上ってことか...！

検証4: サンプルサイトのスクショ集め

⑬ 拡張機能を使ってサイト全体をキャプチャ

  • BraveブラウザにGoFullPage拡張機能を入れてサイト全体のスクショを撮る
  • デスクトップに「ウェブサイトデータ」フォルダを作成してPDFで保存
  • 用意したサンプルサイト（ケース1〜ケース7）を1つずつ開いてキャプチャ
  • 1枚撮り終わったらタブを閉じて次のページへ — この流れを全サイト分繰り返す
UIデザインの参考集めに使える！

⑭ Browser Useで拡張機能を自動操作

  • 拡張機能のボタンをクリックするにはマウス操作が必要 — Computer Useなら可能
  • スキル実行時にフォルダも自動作成してくれた
  • スキル記録中はGoogleドライブに保存 — 実行時にデスクトップ保存を指定することも可能
  • 「デスクトップに新しいフォルダを作って」と実行時に柔軟に指示を変更できる
Googleドライブ保存も便利だけど、デスクトップも指定できるよ！

⑮ 大成功: PDFが次々とフォルダに保存

  • スキル発動でブラウザが開き、各サイトを自動巡回開始
  • 後半で一気にPDFがフォルダに保存されていく
  • 実際に確認すると全体のスクリーンショットとして完璧に撮れている
  • Webサイトの見本集めとして非常に見やすく実用的
かなりうまくいきました！これは嬉しい！

活用のポイントとまとめ

⑯ Computer Useを有効にする設定

  • 事前設定として「Computer Useを有効にする」をオンにしておくのがおすすめ
  • Excel作業やPowerPoint作成などは通常のAIスキルで十分
  • マウス操作を含む作業こそレコード機能の出番 — 従来のAIでは再現が難しかった領域
  • ブラウザ操作 + デスクトップ操作を組み合わせるのが最强
Computer Useをオンにするのを忘れずに！

⑰ 検証結果まとめ: 3成功1失敗

  • 成功 Nottaの目次作成 — 共有リンクとパスワード発行まで完了

  • 失敗 デスクトップアプリの終了 — 手作業の方が早かった
  • 成功 サンプルサイトのスクショ集め — PDF保存まで完璧
  • ブラウザ操作系が得意、デスクトップ操作はまだ発展途上
3/4成功なら十分すぎる実用性！
