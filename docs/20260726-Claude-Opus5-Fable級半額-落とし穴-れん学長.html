Opus 5の登場

① Opus 5リリース: Fable級の性能を半額で

  • 7月25日深夜、AnthropicからClaude Opus 5が公開された
  • 前世代のOpus 4.8は5月28日公開なので、約2ヶ月弱での更新
  • 今回の目玉はFable 5に近い性能を半額の単価で実現したこと
  • 料金はOpus 4.8から据え置きで、Fableと比較すると単価がちょうど半分
単価だけ見れば確かに半分！でも鵜呑みにすると...

② 料金の詳細: トークン単価の比較

  • 入力: 100万トークンあたり5ドル（Opus 4.8と同じ）
  • 出力: 100万トークンあたり25ドル（Opus 4.8と同じ）
  • Fable 5と比較すると単価がちょうど半分になる
  • トークンとはAIが文章を処理する単位で、日本語は約1文字＝1トークン程度
# 料金比較（100万トークンあたり）
Opus 5:  入力 $5 / 出力 $25
Fable 5: 入力 $10 / 出力 $50
# → 単価は半分！でも...
単価が半分でも、往復回数が増えれば同じになる...

③ 継承された機能: コンテキストと推論レベル

  • 100万トークンのコンテキストウィンドウは前モデルから継続
  • 推論レベル5段階（Effort Level）も前モデルから継続
  • これらは今回の新機能ではない — ここ重要！
  • Opus 5自身も新機能として扱っていた部分があり、後で落とし穴になる
ここ、後の「事実の正確性」問題に繋がります！

ベンチマークの結果

④ Frontier Bench: 科学計算で2倍以上の向上

  • 計算生物学や物理シミュレーションなど難しい科学的タスクを自力で進める試験
  • Opus 5は40.3点を記録
  • 前世代Opus 4.8は18.7点だったので2倍以上の伸び
  • 公式でもかなり強調されていたポイント
科学計算分野で大幅アップ！これは確かにすごい。

⑤ ARC-AGI 3: 説明書なしのゲームに挑む

  • ルールも目的も教えずに初見のゲームに放り込んで探れるかを試すテスト
  • 4ヶ月前はどの最先端モデルも1点未満だった
  • 人間はすべてクリアできるのにAIは苦戦していた
  • Opus 5が30点台に入ってきたことで、人間との差が縮んできた
人間とAIの差が少しずつ縮まってる...

⑥ OS World 2.0 ＆ Automation Bench

  • OS World 2.0: マウスとキーボードで人間なら1時間半のPC作業を任せる試験
  • Opus 5は70.6点でFableの61点を上回った
  • Automation Bench: 営業・経理・人事の47種類のアプリをこなす試験
  • Opus 5は26点（4件に1件しか完了せず）— まだ無人では任せられない
全部勝ってるわけじゃない — 自動化はまだ発展途上

弱点と実力比較

⑦ SWE-Bench: コード生成では3番手

  • 自立的にプログラムを書くSWE-BenchではGPT 5.6 Sonnetが上位
  • GPT 5.6 Sonnet: 73点
  • Fable 5: 70点
  • Opus 5: 69点 — 3番手
  • ベンチマークは良いが、全部勝っているわけではない
コード生成ならGPT 5.6 Sonnetが強い...

⑧ 3D生成の比較: Fable 5とのディテール差

  • 同じ指示でOpus 5とFable 5に3Dシーンを作らせた比較がXで公開
  • テントの質感や設定パネルの書き込みでFable 5の方が良いという声が多数
  • 公式デモの風洞実験（空気の流れの渦）も非常にリアルだった
  • デザイン性ではFable寄りの評価が目立つ
デザインのディテールはFable 5が一枚上手かも

⑨ 公開前の初感想: 良いが癖がある

  • 公開前のユーザーの初見感想では良いモデルだが癖があるとの声
  • 短い作業ではFable 5と同等以上の性能
  • しかし癖があるという点が後半の落とし穴に繋がる
  • この「癖」を理解して使うかどうかが損するか損しないかの分岐点
「癖がある」— これがこの動画の本題への入り口！

ブラインドテスト検証

⑩ ブラインドテスト: AI4人に採点させる

  • Opus 5とGPT 5.6 Sonnetに同じ指示でニュース解説記事を作成
  • ファイル名から作者が分からないようにして4人のAI採点者に盲検テスト
  • 読む順序で評価が偏らないよう、2人ずつ順番を入れ替える工夫を実施
  • 事前に公式資料も取りに行かせて数字を照合させた
公平な比較のための工夫がすごい！

⑪ 記事の印象: Opus 5は読みやすい

  • Opus 5が書いた記事はパッと見で分かりやすいと感じた
  • Opus 4.8の時は認知的負荷が高い読みづらい文章だった
  • Opus 5になって読みやすさが大幅に向上
  • GPT 5.6 Sonnetはサクサク読めるが温度感がないという印象
  • GPTはベンチマークの数字がぎっしり詰まっている
れん学長の第一印象: 「Opus 5の方が読みやすい！」

⑫ 採点結果: AIはGPTを高く評価

  • 結果: GPT 5.6 Sonnetが27.8点で勝利
  • Opus 5は22点で敗北 — 4人全員がGPTを選んだ
  • 読む順番を入れ替えても結果は同じだった
  • れん学長の直感（Opus 5の方が読みやすい）とAIの評価が逆転
人間には読みやすいのにAIの評価は低い — なぜ？

落とし穴の正体

⑬ Opus 5の勝ち軸: 非エンジニアへの分かりやすさ

  • 分析すると、Opus 5が勝った軸は非エンジニアへの理解のしやすさ
  • つまり読みやすさではOpus 5が上回っていた
  • れん学長の直感は数値でも裏付けられた
  • しかし事実の正確性ではGPTが圧勝していた
読みやすい ≠ 正確 — ここが最大の落とし穴！

⑭ 事実の間違い: 確認済みの顔で混ざる嘘

  • 推論レベル5段階を新機能のように書いていた（実際は前モデルから存在）
  • Automation Benchの難易度を3ヶ月前の水準のままで記載
  • OS Worldの点数を公表されていないと記載（実際は公開されている）
  • 「確認済み」として間違った情報が混ざるのが最も怖い
  • 新しい情報でもAIの既存知識が古いと間違える
確認済みの顔をして嘘を書く — これが一番怖い...！

⑮ 実務で使用: コード修正は優秀、ただし...

  • 実際のシステムが止まっていたのをOpus 5に修正してもらった
  • 無事に動くようになり、再発防止策も実施 — コード性能は向上
  • しかしお節介を焼き始めた — 片方のチャットルームだけに送る設定だったのに...
  • 「もう片方にも送るようにしておきますね」と勝手に拡張
  • Fable 5なら糸を組み取って先回りしてくれるが、Opus 5は違和感がある
「いやいや、そこまでやらなくていいよ...」となる瞬間

コストと認知負荷の比較

⑯ 実コスト比較: Cursor測定で半額が裏付け

  • Cursor公開の測定データで比較検証
  • Opus 5: 1課題あたり8.23ドルで70点
  • Fable 5: 17.32ドルで75点
  • 綺麗に半額が成立している — 公式発表は正しい
  • 単価が高くても往復が少なければ1問あたりのcostは安くなる
# Cursor測定データ
Opus 5:  $8.23 / 課題  (70点)
Fable 5: $17.32 / 課題 (75点)
# → 約半額！でも点数差は5点...
お金の問題だけじゃない — 人間の注意力が大事！

⑰ 認知負荷の問題: お金より人間の注意力

  • AIに任せた仕事を確認して判断するには集中力が必要
  • Fable 5は自立的に作業してくれるが、余計なことをしない
  • Fableは糸を組み取って先回りしてくれて心地よく使える
  • Opus 5は「そこまでやらなくていいのに」という違和感が何度かあった
  • 滑らかさがそのまま人間側のコスト削減に直結する
人間の注意力コストを含めると、Fable 5が頭一つ抜けてる

⑱ 最適な使い分け: 仕事の種類で選ぶ

  • 調査・数字の裏取り → GPT 5.6 Sonnet（事実の正確性が高い）
  • 読ませる文章・キャッチコピー → Claude（Opus 5 or Fable）
  • 長時間の自律作業 → Fable 5（違和感なく進む、監視時間が減る）
  • 開発 → Fable 5で実装 → GPT 5.6 Sonnetで検証
  • 学術的記事 → 調査から執筆までGPTで完結もあり
  • 半額かどうかで選ぶのではなく、仕事の種類で選ぶのが損しない使い方
結論: 仕事の種類で使い分けるのが一番損しない！
