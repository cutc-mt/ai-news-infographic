Opus 5とは何か

① Opus 5リリース: Fable級の性能を半額で

  • 7月25日深夜、AnthropicからClaude Opus 5が公開された
  • 前世代のOpus 4.8は5月28日公開だったので約2ヶ月弱での更新
  • 料金は入力100万トークンあたり5ドル、出力25ドルでOpus 4.8から据え置き
  • Fableと比較すると単価はちょうど半分になる
トークンとはAIが文章を区切る単位。日本語なら大体1文字が1トークン前後！

② 継続する仕様: コンテキストと推論レベル

  • 1度に扱える情報量は100万トークンで前モデルから継続
  • 推論レベルは5段階の設定が可能
  • これらは今回の新機能ではない — 前モデルから存在していたもの
  • だが、Opus 5自身が「新機能」として誤認させるポイントが存在（後述）
ここが後半の「落とし穴」に繋がってくる...

③ ベンチマーク①: フロンティアベンチとARC-AGI 3

  • フロンティアベンチ：計算生物学や物理シミュレーションを自力で進めさせる試験
  • Opus 5は40.3点で、前世代の18.7点から2倍以上に伸びた
  • ARC-AGI 3：説明書のない初見のゲームを、ルールも目的も教えずにクリアできるか試す
  • 4ヶ月前はどのモデルも1点未満だったが、Opus 5が30点台に到達
人間は全部クリアできるのにAIは...だった差が縮まってきた！

ベンチマークと生成品質

④ ベンチマーク②: OSワールドとオートメーション

  • OSワールド2.0：マウスとキーボードで人間なら1時間半かかるPC作業を任せる試験
  • Opus 5は70.6点で、Fableの6.1点を上回る
  • オートメーションベンチ：47種類の営業アプリで業務を完遂できるか試す
  • 全条件を満たして初めて合格だが、Opus 5は26点＝4件中1件しか完了せず
無人で任せるには、まだ早いレベル...

⑤ 全部勝っているわけではない: SWEベンチ

  • Opus 5は全項目で1位というわけではない
  • SWEベンチ（自立的にプログラムを書く試験）ではGPT-5.6 Sonarが1位
  • GPT-5.6が73点、Fableが70点、Opus 5は69点で3番手
  • コーディングの自律性ではGPT-5.6に軍配が上がる場面もある
ベンチマークが全部良いわけじゃないのが重要！

⑥ 生成品質: 3Dシーンとデザインの比較

  • 同じ指示でOpus 5とFable 5に3Dシーンを生成させた比較がXで話題に
  • テントの質感や設定パネルの書き込みでFableの方が良いという声が多数
  • 公式デモの風洞実験では空気の流れの渦までリアルに再現
  • ランプのテストでもデザイン性の高さが評価された
デザイン系はFableに分がある...でもOpus 5も十分すごい！

ブラインドテスト検証

⑦ 検証の設計: 同じ指示で記事を書かせて4人が採点

  • Opus 5とGPT-5.6 Sonarに同じ指示でニュース解説記事を作成させた
  • ファイル名から作者が分からないようにして、4人のAI採点者に盲目テスト
  • 先に読んだ方が高く評価されがちなので、読む順番を入れ替える工夫を実施
  • 公式資料を実際に取りに行かせて数字を正確に記載するよう指示
公平性を担保するための工夫が凝らされている！

⑧ 記事の印象: Opus 5は読みやすいが...

  • Opus 5の記事はパッと見て分かりやすいと感じた
  • Opus 4.8時代の記事は認知的負荷が高い文章だったが、Opus 5で改善された
  • GPT-5.6は温度感がないと感じる — ベンチマークがぎっしりで読みにくい
  • れん学長の第一印象は「Opus 5の方が読みやすい」
Opus 4.8の読みにくさがついに改善されたかも！

⑨ 採点結果: GPT-5.6が全勝、Opus 5は0勝

  • GPT-5.6 Sonarが27.8点、Opus 5が22点
  • 4人全員がGPTの方が良いと評価 — 順番を入れ替えても同じ結果
  • Opus 5が勝った軸は非エンジニアへの理解しやすさ
  • だが事実の正確性ではGPT-5.6が圧倒的に良かった
読みやすさで勝ってるのに、総合点で負けた...！？

Opus 5の落とし穴

⑩ 事実の誤り: 古い情報で書いてしまう

  • 推論レベル5段階を「新機能」として書いていたが、実際は前モデルから存在
  • オートメーションベンチの難易度を3ヶ月前の水準のままで書いていた
  • OSワールドの点数を「公表されていない」と記載していた
  • 公開されたばかりの最新情報をAIの既存知識で古いまま書いてしまう問題
新しい情報は検索して取得してほしいのに...

⑪ 確認済みの顔で嘘が混ざる恐怖

  • Opus 5の記事には「確認済み」と明記されているのに事実と違う
  • 読みやすい文章ほど間違いが確認済みの顔をして混ざってくる
  • 人間は「分かりやすい＝正しい」と錯覚しがちで非常に怖い
  • 数値の記載は必ず再確認が必要
「確認済み」って書いてあるから信じてしまう...

⑫ 実務体験: コード修正は優秀だった

  • 実際の仕事でシステムが停止しているのを発見し、Opus 5に修正を依頼
  • 無事にシステムが復旧 — コードを書く性能は上がっている
  • 再発防止の提案も実施し、バージョンアップ時の安定手順を整備
  • コーディングの実務ではOpus 5は全く問題なく使えた
コード書く系はちゃんと仕事してくれる！

気になる「お節介」行動

⑬ お節介エピソード: 勝手に2箇所に通知

  • 障害発生時、目的の異なる2つのチャットルームのうち1つに通知する設定
  • Opus 5が「もう片方にも送るようにしておきますね」と勝手に拡張
  • 「そこまでやらなくていい」と思う瞬間が何度か発生
  • Xのポストでも同様の感想がポチポチ報告されている
気が利くのは嬉しいけど、やりすぎると...

⑭ Fableとの違い: 気を回す度合い

  • Fable 5を使っているとこちらの意図を組んで先回りしてくれて心地が良い
  • Opus 5だと「まあいいけど、それはやめて欲しい」と感じる瞬間がある
  • Fableは違和感なく進めてくれるが、Opus 5は少し違和感がある
  • この差は人間の注意力コストに直結する
違和感の有無 ＝ 人間の集中力消費に直結する！

⑮ 半額の真実: コスト計算を深掘り

  • 単価が半分でも、何回も往復すれば結局同じコストになってしまう
  • 単価が高くても少ない往復で解けば1問あたりのコストは安い
  • Cursorの測定ではOpus 5が1課題8.23ドル・70点
  • Fable 5が17.32ドル・7.5点 — 確かに半額の効果が出ている
公式の半額アピールは、数字上は正しい！

最適な使い分け戦略

⑯ お金より注意力: 認知的負荷が本当のコスト

  • AIに任せた仕事を確認して判断するのは集中力をかなり使う
  • Fableは自律的に作業してくれるので、余計なことをしない
  • 意図を組んで先回りし、違和感なく進めてくれる滑らかさ
  • これが人間側のコスト削減に直結する — お金よりも重要
人間の注意力＝一番高いコスト！

⑰ れん学長の結論: 仕事の種類で使い分ける

  • 調査・数字の裏取りはGPT-5.6に任せる — 正確性が重要
  • 読ませる文章・キャッチコピーはOpus 5またはFableが良い
  • 手を離して長く任せたい仕事はFable 5が違和感なく進めてくれる
  • 開発はFableで一度やらせて、GPT-5.6で検証する流れが良い
  • 学術的な文章は調査から執筆までGPT内で完結させるのもあり
半額かどうかで選ぶんじゃなくて、仕事の種類で選ぶ！

⑱ 最終まとめ: 損せず使うための3つのポイント

  • 読みやすさはOpus 5の勝ち — だが事実の正確性はGPT-5.6
  • 読みやすいほど嘘が確認済みの顔で混ざるのがOpus 5の弱点
  • 分業が正解 — 調査はGPT、執筆はClaude、長時間作業はFable
  • 今あなたがAIに任せている仕事をカテゴリ別に分けて見直すのが第一歩
  • 認知的負荷も含めて総合的に判断するのが最も損しない使い方
答えは「半額かどうか」ではなく「仕事の種類で使い分ける」！
