Opus 5とは何か？

① Opus 5の正体: クロードの最新の主力頭脳

  • クロードにはいくつかの頭脳が用意されている — Opus、Sonnet、Haikuなど
  • その中でOpusは毎日の仕事のために作られた主力となる頭脳
  • Opus 5は2026年7月24日に発表された最新版
  • 前提知識ゼロの方に向けて、何なのかから丁寧に解説
新しいAIが出たと聞いても「自分は何をすればいいか」分からない人向け！

② 最大の事件: 最上位に迫る賢さを半分の値段で

  • Opus 5は最上位のフェイブル5に迫る賢さをその半分の値段で提供
  • コーディングと知識仕事のテストでこれまでの最高記録を更新
  • 1つ前のOpus 4.8と比べると性能が2倍を超えた
  • ただしサイバーセキュリティの分野だけはミトス5の方が上とはっきり書かれている
賢さが半額で手に入るって、すごい時代になったね！

③ エフォート設定: 頑張り具合を自分で決める

  • A4（エフォート）とは、日本語にすると「頑張り具合」の設定
  • しっかり考えさせたい時は高く設定
  • 速さと安さを優先したい時は低く設定
  • 同じOpus 5でも1つのつまみで賢さと費用のバランスを自分で決められる
エフォート＝頑張り具合！覚えやすいね 🎵

Opus 5を使う3つの入り口

④ 3つの入り口: ブラウザ・ターミナル・API

  • ブラウザのクロード — ウェブ画面から使う
  • ターミナルのClaude Code — PCの中で直接ファイルを触れる
  • プログラムから呼ぶAPI — コードの中から呼び出す
  • この3つを順番に実際の画面で見ていく
入り口が3つあるけど、どれも同じ頭脳が働いているよ！

⑤ ブラウザから使う: モデルを切り替えるだけ

  • クロードの画面を開いて、入力欄の下にあるモデル名をクリック
  • 使える頭脳の一覧が開くので、Opus 5を選ぶ
  • あとはいつも通り聞くだけ — 難しい設定はいらない
  • 返答の上に「Opus 5」と表示されるので、切り替わったか確認できる
モデル名をクリックして選ぶだけ！一番かんたんだね

⑥ Claude Codeの起動: フォルダで「claude」と打つ

  • 作業したいフォルダーに移動して「claude」と打つだけ
  • それだけで相棒が起動する
cd my-project
claude
# 相棒が起動！
  • 起動したら/modelと打つと、選べる頭脳がその場に並ぶ
  • Opus 5を選ぶと、一番下のバーの表示が切り替わる
  • このバーが今どの頭脳で動いているかの確認場所

  • 表面の症状ではなく根っこの原因まで直しに行く

⑨ ファストモード: 2.5倍の速さで返す

  • 同じOpus 5のままおよそ2.5倍の速さで返してくれる

プログラムから呼ぶAPI

⑩ PythonコードからAPIを呼ぶ

  • エディターを開いて短いPythonのコードを書く
  • 大事なのは6行目のモデルの名前
from anthropic import Anthropic

client = Anthropic()
response = client.messages.create(
    model="claude-opus-5",  # ← これ！
    max_tokens=1024,
    messages=[...]
)
  • この1行がどの頭脳を使うかの指定になる

⑪ コードからエフォートを指定する

  • 頑張り具合もコードから自由に設定できる
  • output_config にeffortを書く
response = client.messages.create(
    model="claude-opus-5",
    output_config={
        "effort": "high"
    },
    ...
)
  • 選べる段階: 低い → 中くらい → 高い → 超高い → 最大
  • 画面の前を上から順に追っていくだけでOK
コードでもエフォート＝頑張り具合を自分で決められる！

⑫ 同じ頭脳、違う入り口: 3つすべて共通

  • ブラウザで使っても
  • ターミナルで使っても
  • コードの中で使っても — すべて同じ頭脳が働いている
  • 入り口が違うだけだったと分かる
  • 保存したらターミナルで実行。数秒待つと答えが帰ってくる
どの入り口からでも同じOpus 5に会える！便利だね
