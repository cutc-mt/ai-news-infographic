Claude Code・Codex・Google Antigravityで無料で使える動画制作スキル

HyperFramesとは？

① HyperFramesとは: 無料の動画制作スキル

  • AIエージェント向けの無料で使えるオープンウェイトの動画制作フレームワーク
  • 「スキル」という仕組みでAIエージェントに専門知識や機能を付与できる
  • テキストの指示だけでBGMや効果音入りの動画が作れる
  • AIアバター生成で有名なエージェン社が開発
テキストを打つだけで動画ができるってすごくない？

② 動画生成の仕組み: HTMLを組み立ててMP4に変換

  • 一般的な動画生成AIとは違い、文章から直接映像を生成するのではない
  • AIエージェントがHTML・画像・動画・音声・アニメーションを組み立てる
  • それをフレーム単位でMP4動画に変換する仕組み
  • 自然言語で作りたい動画を指示するだけで動画が完成
直接生成ではないから、細かい制御ができるんだ！

③ 18種類の専門スキル: 目的に合わせて使い分け

  • /hyperframesが代表的なスキル — 依頼内容を整理して最適な動画を作成・実行
  • モーション作成やモーションフィックスなど計18種類の専門スキルが用意
  • GSAP・CSS アニメーション・Three.jsなどのWebアニメーション技術を利用可能
  • 7月時点で計19種類のスキルが用意され、継続的に追加されている
目的に合わせてスキルを選べるのが便利！

HyperFramesでできること

④ プロダクトビデオ: URLから自動でプロモ動画

  • /productvideoスキルでウェブサイトのURLを入力するだけ
  • ウェブサイトの情報を分析して自動でプロモーション動画を生成
  • アプリの機能アップデート動画や操作紹介動画も作成可能
  • 商品説明や台本からもプロモ動画を生成できる
URLを入れるだけって、本当にカンタン！

⑤ モーショングラフィックス: 10秒の短い映像表現

  • /motiongraphicsスキルで10秒以内のモーショングラフィックスを作成
  • 文字や図形、画像に動きをつけて情報を伝える映像表現
  • プレゼンでサービス名を紹介する際に活用可能
  • SNS動画やYouTube動画の作成にも使える

⑥ ミュージックビデオとスライドショー

  • /musictovideoスキルで音楽ファイルや動画内の音声を解析
  • ビートに合わせたミュージックビデオを自動生成
  • /slideshowスキルでインタラクティブなスライドも作れる
  • 動画ではなくブラウザ上で操作できるスライドを生成
音楽に同期した動画も自動で作れちゃう！

メディアライブラリとナレーション

⑦ 無料メディアライブラリ: 音楽・画像・効果音・ロゴ

  • /mediasスキルで動画制作に必要な素材をまとめて管理
  • ログインすることで無料でメディアライブラリを使える
  • 音楽、画像、効果音、ロゴなど豊富な素材が利用可能
  • これらの素材を動画内で自由に使える
素材探しの手間がゼロになるのが大きい！

⑧ ナレーション音声: ハイクオリティな読み上げ

  • HyperFramesでナレーション音声を入れることも可能
  • WindowsやMacのローカル音声生成アプリは性能は高くない
  • HyperFramesの音声生成ツールを使えばハイクオリティなナレーション付き動画が作れる
  • 音声生成ツールは有料プランが必要だが品質は高い

⑨ 完全無料で使える: スキルインストールも簡単

  • HyperFramesのスキルはスキルを入れたAIエージェントであれば無料で利用可能
  • ワンクリックでインストール完了
  • Claude Code、Codex、Antigravity、LMAgentなど主要なAIエージェントに対応
  • 作った動画はMP4形式でダウンロードできる
無料でここまでできるのはすごい！

4つのAIエージェントで使う

⑩ OpenAI Codex: GPT系モデルで高品質な動画生成

  • ChatGPTに登録すれば無料ユーザーも一応使えるが、本格利用には有料登録が必要
  • デスクトップアプリが一番使いやすい
  • フォームにスキルインストールコマンドを打つだけでインストール完了
  • / と入力すればスキルコマンドが表示され、日本語の指示で動画を作れる
# Codexでの手順
1. デスクトップアプリを起動
2. スキルインストールコマンドを実行
3. / と入力してスキルを選択
4. 日本語で動画の指示を入力
GPT系モデルはコーディング性能が高いから相性抜群！

⑪ Claude Code: クロード系モデルでCLIから動画制作

  • Anthropicが開発するAIエージェント — Claudeの有料ユーザーが利用可能
  • コーディング性能の高いクロード系のAIモデルを使える
  • 主力のインターフェイスはコマンドライン（CLI）版
  • CLI版を立ち上げてスキルを使い、日本語の指示で動画を作成
CLI版がメインだから、コマンドラインに慣れてないと少しハードルあるかも...

⑫ Google Antigravity: 無料でも使えるGoogle製エージェント

  • Googleが開発するAIエージェント — Googleアカウントで無料ユーザーも利用可能
  • 有料登録すると使える量が増える
  • Gemini系とClaude系の両方のAIモデルを使える
  • 5月にリニューアルされてデスクトップアプリが使いやすくなった
  • アプリを立ち上げてコマンドを打てばスキルをインストールできる
GeminiとClaudeの両方が使えるのはAntigravityならでは！

LMAgentとモデル相性

⑬ LMAgent: 好きなAIモデルを組み合わせて使う

  • ムースリサーチ社がリリースしている無料で使えるAIエージェント
  • デフォルトのAIモデルは実装されておらず、他者のAIモデルを使って動かす
  • デスクトップアプリに力を入れている
  • HyperFramesのスキルがデフォルトで入っている可能性もある
  • 自分の好きなAIモデルをセットして、スキル名を指定して動画生成を依頼
好きなモデルを組み合わせられる自由さが魅力！

⑭ コーディング性能と相性: GPT-5.6とClaude Opus 4.8

  • HyperFramesはHTMLなどで組み立てられているので、コーディング性能が重要
  • GPT-5.6を使えるCodexは特に相性が良い
  • Claude Opus 4.8を使えるClaude Codeも特に相性が良い
  • コーディング性能の高いAIモデルを使うと品質が大きく上がる
動画品質はモデル次第だから、強いモデルを選ぼう！

⑮ プロモ動画生成: 日本語サイトから30秒動画を作成

  • Codexに3つのスキルをセットして実験：/productvideo + /hyperframes + /medias
  • 日本語のウェブサイトを参考に効果音とサウンド入りの30秒プロモ動画を作成
  • 作った動画はチャット経由で編集可能
  • 「動画編集ツールを立ち上げて」と指示すると専用エディターが起動
  • オブジェクトの追加・削除、文字の色や大きさの変更が自由にできる
チャットで修正できるから、やり直しもラクラク！

活用事例と今後の展望

⑯ 解説動画生成: AIエージェントの仕組みを分かりやすく

  • /facelessexplainerスキルでテキストから解説動画を生成
  • 3秒ごとに画面が切り替わる解説動画を依頼
  • AIエージェントが動画の構成を決めて10画面に分割
  • 図解などを駆使してハイクオリティな解説動画を生成
  • 3つのスキルをセット：/facelessexplainer + /hyperframes + /medias
図解入りで分かりやすい動画が自動でできる！

⑰ モーショングラフィックス生成: 派手な文字登場アニメ

  • Codexに/motiongraphicsスキルをセットして依頼
  • 「文字が派手に登場する10秒のモーショングラフィックス」を指示
  • Codexが動きの構成を考えて自動生成
  • 質の高いモーショングラフィックス動画が完成
  • プレゼンやSNS動画で大活躍する映像表現
10秒のインパクトある動画が一瞬でできる！

⑱ 継続的アップデート: 新スキルが続々追加

  • HyperFramesは定期的にアップデートを繰り返している
  • 新しいスキルが継続的に追加されている
  • 自動で字幕をつける機能や動きのあるスライド作成も可能
  • 音楽ファイルからプロモーション動画を作ることもできる
  • 新スキルが気になる方は公式Xアカウントを定期チェックしよう
どんどん進化しているから、チェックし続けるのが大事！
