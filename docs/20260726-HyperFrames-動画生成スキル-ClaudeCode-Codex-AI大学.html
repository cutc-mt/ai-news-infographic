HyperFrames

AIエージェントに動画制作スキルを追加！
テキスト指示だけでBGM・効果音入り動画が作れる無料フレームワーク

📅 2026年7月26日

HyperFramesとは？

① HyperFramesとは: 無料の動画制作スキル

  • AIエージェント向けの無料で使えるオープンウェイトの動画制作フレームワーク
  • 「スキル」という仕組みでAIエージェントに専門知識や新機能を追加できる
  • 2026年に注目のAIエージェントにワンクリックでインストール可能
  • 開発元はAIアバター生成で有名な米国スタートアップ「エージェン」
AIエージェントに「動画を作る力」をプレゼントするスキルだよ！

② 仕組み: 映像を直接生成ではなく、組み立てる

  • 一般的な動画生成AIのように文章から映像を直接生成するモデルではない
  • AIエージェントがHTML・画像・動画・音声・アニメーションを組み立て、フレーム単位でMP4に変換
  • GSAP・CSS アニメーション・Three.jsなどのWebアニメーション技術を動画内で利用可能
  • 作りたい動画を自然言語で指示するだけで動画が作れる
直接生成型とは違う！部品を組み立てて動画にするアプローチ！

③ 19種類のスキル: 様々な動画ジャンルに対応

  • /hyperframes — 依頼内容を整理して最適な動画制作を選択・実行する代表スキル
  • その他、モーション作成やモーションフィックスなど計18種類の専門スキルが用意されている
  • 7月時点で計19種類のスキルが利用可能
  • 詳細はHyperFramesの公式サイトに掲載
スラッシュコマンドで呼び出すだけ！使い方はカンタン！

HyperFramesでできること

④ プロダクトビデオ: ウェブサイトから宣伝動画を生成

  • /product-videoスキルを使うと、ウェブサイトのURLを入力するだけで分析してプロモーション動画を生成
  • 商品説明や台本からアプリの機能アップデート動画なども作成可能
  • ウェブサイトの操作紹介動画も自動で作れる
URLを入れるだけ！製品の紹介動画が一瞬で完成！

⑤ モーショングラフィックス: 10秒の短い映像表現

  • /motion-graphicsスキルで10秒以内のモーショングラフィックスを作成
  • 文字や図形、画像に動きをつけて情報を伝える映像表現
  • プレゼンでサービス名を紹介する際やSNS動画・YouTube動画の作成に活用
  • ナレーションなしでデザイン重視の短い映像
派手な文字登場アニメもお手のもの！

⑥ ミュージックビデオ ＆ インタラクティブスライド

  • /music-to-videoスキルで音楽ファイルや動画内の音声を解析してビートに合わせたMVを生成
  • /slideshowスキルでブラウザ上で操作できるインタラクティブなスライドを生成（動画ではない！）
  • 音楽に同期した映像表現が自動で作れる
音楽に合わせて自動でビート同期！すごい！

⑦ メディアライブラリとナレーション機能

  • /mediaスキルで動画制作に必要な素材をまとめて管理
  • HyperFramesにログインすると音楽・画像・効果音・ロゴなどのメディアライブラリを無料で利用可能
  • ナレーション音声も追加できるが、ローカル音声生成は性能が低め
  • HyperFramesの有料音声生成ツールを使えばハイクオリティなナレーション付き動画が作れる
素材も音声も全部揃う！ワンストップで動画制作完了！

4つのAIエージェントで使う

⑧ 対応AIエージェント4選: どれでも使える

  • OpenAI Codex — GPT系モデルを使用、デスクトップアプリが一番使いやすい
  • Anthropic Claude Code — Claude系モデルを使用、CLI版がメイン
  • Google Antigravity — Gemini系・Claude系モデルを使用、5月にリニューアル
  • MoosResearch LM Agent — 無料で使える、他者のAIモデルを組み合わせて動作
どのAIエージェントでもスキルは無料でインストールできるよ！

⑨ OpenAI Codex: デスクトップアプリがおすすめ

  • ChatGPTに登録すれば無料ユーザーも一応使えるが、本格利用には有料登録が必要
  • デスクトップアプリが一番使いやすい — フォームにコマンドを打つだけ
  • スキルインストールコマンドを打てば即インストール完了
  • フォームに「/」と入力すればスキルコマンドが表示され、日本語で指示してMP4をダウンロード
スラッシュを打つだけ！あとは日本語で指示するだけ！

⑩ Claude Code: CLI版でスキルを使う

  • Claudeの有料ユーザーが利用可能、コーディング性能の高いClaude系モデルを使用
  • メインインターフェイスはコマンドライン（CLI）版で動作
  • Claude CLIを立ち上げ、フォームにスキルインストールコマンドを打てば即利用開始
  • 日本語で指示してMP4形式でダウンロード可能
CLIに慣れてる人にはClaude Codeがピッタリ！

⑪ Google Antigravity: リニューアルで使いやすく

  • Googleアカウントで登録すれば無料ユーザーも使える、有料登録で利用量が増加
  • 5月にリニューアルされてデスクトップアプリが使いやすくなった
  • Gemini系とClaude系のAIモデルを使い分け可能
  • デスクトップアプリで「/」と入力 → スキル選択 → 日本語指示のフローは他と同じ
リニューアル後はデスクトップアプリが超便利！

⑫ LM Agent: 無料で自分好きAIモデルを組み合わせる

  • MoosResearchの完全無料で使えるAIエージェント
  • デフォルトのAIモデルは実装されておらず、他者のAIモデルを組み合わせて動作させる
  • デスクトップアプリに力を入れていて、HyperFramesスキルがデフォルトで入っている可能性も
  • 自分の好きなAIモデルをセットして、スキル名を指定して動画生成を依頼するだけ
無料＆自分好きモデルを選べるのが最大の魅力！

モデル選びのコツ

⑬ コーディング性能が高いモデルがベスト

  • HyperFramesはHTMLなどで組み立てられるので、コーディング性能の高いAIモデルを使うと品質が大きく上がる
  • 特に相性が良いのは以下の組み合わせ：
  • GPT-5.6を使えるOpenAI Codex
  • Claude Opus 4.8を使えるClaude Code
動画品質を上げたいならCodexかClaude Codeがおすすめ！

活用事例：3つの動画を作ってみた

⑭ 事例1: ウェブサイトからプロモ動画を生成

  • Codexに/product-videoと/hyperframesと/mediaの3スキルをセット
  • HyperFramesの日本語ウェブサイトを参考に30秒のプロモーション動画を作成
  • 効果音とサウンドが入った完成度の高い動画が生成された
  • チャット経由で内容の編集も可能
  • 「エディターを立ち上げて」と指示すると専用の動画編集ツールが起動 — オブジェクト追加・削除、文字の色や大きさの変更が可能
編集ツールまで内蔵！チャットで修正できるのが便利！

⑮ 事例2: 解説動画を自動生成

  • /faceless-explainerスキルで任意のテキストから概念の解説動画を生成
  • 今回はAIエージェントの仕組みについて解説動画を作成
  • 3秒ごとに画面が切り替わる解説動画を依頼
  • AIエージェントが動画の構成を決定し、10画面に分割して図解を駆使
  • ハイクオリティな解説動画が完成！
テーマを伝えるだけで構成から図解まで全部自動！

⑯ 事例3: モーショングラフィックスを生成

  • Codexに/motion-graphicsスキルをセットして生成を依頼
  • 「OpenAI Codexの文字が派手に登場する10秒のモーショングラフィックス」を指示
  • AIエージェントが動きの構成を考えて生成
  • 質の高いモーショングラフィックス動画が完成！
派手な文字アニメが一瞬で完成！SNS映えバッチリ！
