OpenAI Presence

電話サポートをAIに置き換える新サービス全解説
企業のカスタマーサポートを丸ごとAIエージェントに任せる仕組み

📅 2026年7月26日

Presenceとは何か？

① Presenceとは: AIを現場に立たせる仕組み

  • OpenAIが発表した企業向けAIエージェントの新製品。電話やチャットの対応を丸ごと任せられる
  • Presence = 存在 — AIが企業の現場に「存在」して働く
  • 新しいAIモデルそのものではなく、AIを企業の現場で安全に働かせるための運用パッケージ
  • ターゲットはカスタマーサポートの丸ごと代行
賢いAIを売るんじゃなくて、AIを安心して現場に立たせる土台を売ってるのが特徴！

② 信頼性の壁: AIを現場に出す怖さ

  • AIが賢く受け答えすることはもう当たり前になってきている
  • 会社が本当に困っているのは実際の業務に任せて大丈夫かという信頼性の部分
  • お客さんへの対応をAIに任せて:勝手に変な約束をしないか
  • 答えちゃいけないことを答えないかという懸念
  • 無理そうな時にちゃんと人間に引き継いでくれるかが保証されてないと怖くて現場に出せない
AIが賢いだけじゃダメ。現場で信頼して使えるかが本当の壁なんだ...

③ 運用パッケージの中身: ルールと引き継ぎ

  • AIの受け答え能力に加えて会社のルールを組み込んでいる
  • 越えちゃいけない一線を明確に設定
  • 困った時に人間へ引き継ぐ条件をまとめて1つのパッケージに
  • AIの自律性と企業のコントロールのバランスを取る設計
ルール＋引き継ぎ＋権限管理＝安心して現場に出せる！

小さく始める設計

④ 1つの業務からスタート: 小さく始める

  • まずは1つの業務から小さく始めるようになっている
  • 例：料金の問い合わせ対応
  • 例：保険の請求サポート
  • 例：社員からのIT相談
  • 限定された仕事からスタートして、徐々に範囲を広げていく設計
最初は小さく、成果を見てから拡大していくのがポイント！

⑤ 必要な権限だけ付与: 最小権限の原則

  • AIにはその仕事に必要な知識と触っていいシステムだけが渡される
  • 何でもできる万能AIを置くのではなく、業務の担当者として必要な分だけの権限
  • AIに何をどこまでやらせるかは全部会社側が決められる
  • AIが暴走して勝手に判断する心配を抑えられる設計
必要な分だけ権限を渡す → 万能AIより安全で実用的！

⑥ 人間への引き継ぎ: いつ、どう渡すか

  • どういう時に人間が必要かを会社側が決められる
  • どのタイミングで人間が引き継ぐかも明確に設定
  • 任せられる仕事だけを任せられる設計になっている
  • 複雑な判断や込み入った相談は人間にエスカレーション
AIが勝手に判断しない → 人間が最終決定権を握ったまま！

自社で75%解決の実証

⑦ OpenAI自身が実践: 自社電話サポートで運用中

  • 他社に売る前にまず自分の会社で本番運用している
  • OpenAIの英語の電話サポートがすでにPresenceで動いている
  • かかってきた電話に対して要件を聞き取って本人確認
  • アカウント情報を調べて会社のルールに沿った対応をAIが自分でこなす
  • 専用の番号まで用意されていて、実際にアメリカの利用者がかけるとAIが出る
他人に売る前に自分で使って証明する → これが一番の説得力！

⑧ 75%をAI単独で解決: 4件中3件が無人完了

  • かかってくる電話のうち約75%を人間の助けなしで解決
  • 4件に3件はAIだけで完結している
  • これは実験レベルではなく実践レベルの数字
  • 数週間で現場の人間のサポートと同じ基準かそれ以上に到達
  • ただ電話に出られるだけではなく人間並みの品質で対応できている
75%解決はすごい！でもこれがスタートに過ぎない...

⑨ 10日間で15ポイント改善: 急成長の秘密

  • いきなり75%になったわけではなく改善を重ねて到達
  • 導入直後は人間に引き継ぐケースがもっと多かった
  • たった10日間で人間へのバトンタッチを15ポイント減少
  • この10日間の改善スピードは後で話す改善の仕組みがちゃんと効いている証拠
10日で15ポイント改善って、尋常じゃないスピードだよ！

出してからが本番の改善ループ

⑩ 導入がゴールじゃない: 出してからが本番

  • 普通のAIサービスは導入したらゴールになりがち
  • でもAIを現場に出した後は必ず想定外のことが起きる
  • お客さんが予想もしない聞き方をしてくる
  • 会社のルールが変わったり新商品が増えたりでAIがうまく対応できない場面が出てくる
  • 普通なら人間が原因を調べて設定を直してテストする面倒な作業が発生する
導入がスタート地点。ここから毎日成長していく仕組みがある！

⑪ Codexで自動改善: AIがAIを改善する

  • PresenceにはCodex（OpenAIのコーディングAI）が組み込まれている
  • 本番のやり取りや人間に引き継がれたケースを自分で分析
  • 「ここをこう直したらもっとうまくいきますよ」と改善案を提案してくれる
  • 勝手に反映するのではなく提案まで — 最終確認は人間
改善のアイデアはAIが出すけど、最終判断は人間が握る！

⑫ テストして確認して反映: 安全な改善フロー

  • Codexが提案した改善案を本番バージョンと比較してテスト
  • 人間が確認してから反映される流れ
  • AIが暴走して勝手にどんどん変わっていくわけではない
  • 改善のアイデアはAI、判断は人間というバランス
提案 → テスト → 人間の確認 → 反映。このループが安全を保証する！

使うほどに成長する仕組み

⑬ 導入瞬間が最小: 毎日成長していくAI

  • Presenceは導入した瞬間が一番未熟でそこから毎日成長していく
  • 使えば使うほど現場のデータが蓄積されていく
  • Codexがそのデータを元にどんどん賢くしていく
  • 1回作って終わりの普通のシステムとは根本的に考え方が違う
導入した日が一番未熟 → 毎日少しずつ賢くなっていく植物みたい！

⑭ 会社独自のノウハウが蓄積: 真似できない財産

  • 改善ループが回るほどその会社だけのノウハウがAIに蓄積される
  • お客さんの傾向、よくある質問、どう答えると喜ばれるか
  • 現場の癖を学んだAIは他社には簡単に真似できない財産になる
  • 長く使えば使うほど乗り換えにくくなる → 企業を囲い込む力
使えば使うほど独自のAIが育つ → 企業にとっての資産になる！

⑮ 他社との違い: 運用のパッケージで一歩先へ

  • 多くのAI企業はいかに賢いモデルを作るかで競い合っている
  • OpenAIはそこに加えてAIをどう現場で信頼して使わせるかという一歩先の課題に着手
  • 賢いAIを売るのではなくAIを安心して現場に立たせる土台を売っている
  • これがPresenceの最大の特徴であり他社との違い
モデルの賢さじゃなくて、運用の仕組みで差をつける。これがOpenAIの戦略！

日本への影響と注意点

⑯ ソフトバンクが参画: 日本語対応が進む

  • Presenceの最初のパートナー企業の中にソフトバンクが入っている
  • ソフトバンクは自然な日本語での顧客対応をPresenceでテスト中
  • 英語だけの話ではなく日本語のカスタマーサポートもAIが担う準備が進んでいる
  • 日本の大手が早い段階から関わっていることで変化は思ったより早く来るかもしれない
ソフトバンクがテスト中 → 日本のコールセンターも変わる日が近いかも！

⑰ 利用者への恩恵と不安: 待ち時間ゼロの未来

  • メリット: 待ち時間がなくなる — AIならいくらでも同時に対応できる
  • 深夜でも早朝でもいつかけても対応してもらえる
  • 不安: 今その仕事をしてる人はどうなるの？
  • 当面は簡単な問い合わせはAI、複雑な判断は人間という役割分担
  • ただし今後どこまでAI側に寄っていくかはまだ誰にも分からない
利用者には嬉しいけど、働き手にとっては大きな変化が来る...

⑱ 注意点2つ: まだ限定的 ＆ 設定次第

  • 注意1: まだ誰でも使える製品じゃない
  • 限られた企業向けの提供でセルフサービス申込みはできない
  • 導入にはOpenAIの専門エンジニアと提携業者が一緒に設定する必要がある
  • 注意2: AIに任せる範囲は会社次第
  • 利用者からは電話の相手がAIか人間か外からは見えにくい
  • 込み入った相談の時は「人間の担当者につないで」と伝える心構えが必要かも
気軽に導入できる段階じゃないけど、これからどんどん広がっていくはず！
