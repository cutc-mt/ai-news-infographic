Coolify、Pumpkin、OmniRoute、ReUI、Catch2、GigaTokenほか

エージェント協働 ＆ ブラウザ

① Buzz: 人間とエージェントが協働するワークスペース

  • Blockが提供するセルフホスティング型ワークスペースで、人間とAIエージェントが同じ部屋を共有
  • Nostrリレーとして動作し、すべてのメッセージや承認を1つの署名付きログに記録
  • エージェントはチームメイトと同様に独自のキーでチャネルに参加し、パッチ送付やコードレビューが可能
  • Rustリレー、デスクトップアプリ、エージェントファーストCLI、goose/codeex/claude code用ACPハーネスが同梱
人間もエージェントも同じ権限で参加できるのが画期的！

② World Monitor: リアルタイム全球インテリジェンス

  • ニュース、地政学、インフラ情報を1つの状況認識インターフェースに集約するダッシュボード
  • 15カテゴリ・500以上のフィードをAI要約に統合し、3D地球儀上にイベントをプロット
  • 軍事・経済・災害の相関分析、各国の不安定度スコア化、市場動向の追跡
  • APIキーなしでローカル実行可能、セルフホスト・MCPサーバー・REST API・CLI・SDK対応
世界情勢をひと目で把握できる強力なツール！

③ Pumpkin: Rustで書かれた超高速Minecraftサーバー

  • Rustで完全構築されたオープンソースのMinecraftサーバー、マルチスレッドで高速・効率的
  • JavaクライアントとBedrockクライアントの両方をサポート
  • 暗号化、パケット圧縮、ワールド読み込み、ライティング、チャンク生成、インベントリ、権限管理を網羅
  • タワーベース設定で不要なものは無効化可能、プラグインAPIを備えたRustクレートとして構成
  • DockerまたはNixで動作、Archon PlusとBungeeCordプロキシをサポート
Rustの力でMinecraftサーバーが圧倒的に速く！

ブラウザ ＆ ゲートウェイ ＆ CAD

④ Ego Light: 人間とエージェントが共有するブラウザ

  • macOS用ブラウザで、人間とAIエージェントが並行して作業できる設計
  • 各エージェントが独立したスペースを持ち、バックグラウンドでタスクを実行 — タブはそのまま保持
  • ego browserヘルパーがclaude code、cursor、codeexなどあらゆるエージェントCLIに接続
  • 閲覧データは端末にローカル保存、エージェントが「fill」をクリックしてナビゲート
自動化用に別ブラウザが不要に！ログイン情報も引き継げる

⑤ OmniRoute: 数百のAIプロバイダーを1つのローカルエンドポイントに

  • 数百のモデルプロバイダーの前に1つのローカルエンドポイントを配置するAIゲートウェイ
  • 割り当て量上限や障害時に自動フォールバック、19種類のルーティング戦略でモデルを連結
  • スタック型圧縮パイプラインでリクエスト送信前にトークンを削減
  • claude code、codeex、cursor、clinetと連携、鍵はローカルで暗号化保持
  • npm、Docker、Electron、termuxで動作
インストールすれば、もう制限に引っかかる心配なし！

⑥ CAD Skills: CAD・ロボット工学のためのエージェントスキル

  • CAD、ロボット工学、ハードウェア設計のためのエージェントスキルライブラリ
  • 平易な言語や画像からモデルを作成・編集し、STEP・STL・3MF・GB形式でエクスポート
  • URDF・SRDF・SDFロボットファイルの作成、2D・DXF描画、Gコードスライスも可能
  • 既製部品の検索や、ローカルブラウザビューアでのプレビューにも対応
  • skills CLIまたはcodeex/claude codeプラグインとしてインストール
部品を説明すると、組み立てられていく様を見られる！

求人検索 ＆ テスト ＆ オフィス

⑦ AI求人検索: Claude Codeベースの求人応募フレームワーク

  • 履歴書、LinkedInエクスポート、ガイド付きインタビューからプロフィールを入力
  • setup・scrape・applyの3つのコマンドを実行するだけ
  • 求人を検索してプロフィールと照合し、履歴書とカバーレターを自動作成
  • 2人目のエージェントが企業を調査し、原稿を批評して修正してからPDFをコンパイル
  • すべての申請内容が実際のプロフィールと照合される
フォークして、自信を持って応募しよう！

⑧ Catch2: モダンなC++ネイティブ単体テスト＆ベンチマーク

  • C++向けの単体テストフレームワークで、マイクロベンチマークとBDDマクロも提供
  • 使い心地が非常に自然 — テスト名は識別子ではなく文字列、アサーションは通常のC++ブール式
  • セクション機能でセットアップ・ティアダウンコードをローカル共有
  • C++14以降対象、マルチヘッダーライブラリとして提供
  • CMake、Bazel、Meson、Conanでビルド可能
マクロでテストケースを作成して、タグ付けも自在！

⑨ Office CLI: AIエージェント向けコマンドラインOfficeスイート

  • Word、Excel、PowerPointファイルを読み取り・編集・自動化するCLI版Office
  • 依存関係なしの単一バイナリで、安定したパスを提供
  • 内蔵レンダリングエンジンがファイルをHTMLまたはPNGに変換、エージェントが自分の出力を確認可能
  • Excel数式の評価、ピボットテーブル作成、テンプレート結合も対応
  • MCPサーバーとしても登録可能、Docker・CI環境でも動作
エージェントがドキュメントを作ってくれる時代に！

デスクトップ制御 ＆ トークン化 ＆ 動画編集

⑩ Desktop Commander: AIアシスタント向けファイル＆プロセス制御

  • AIアシスタントが端末のファイルシステムと実行中プロセスを制御できるMCPサーバー
  • プログラムの起動・操作、出力ストリーミング、長時間実行セッションの管理
  • ファイル名・内容で検索、テキスト・Excel・PDF・Wordファイルの読み書き
  • Python・Node・Rコードをメモリ上で実行して迅速なデータ分析
  • Dockerによる分離機能、Claude Desktop・Cursor・VS Code・codeexに対応
デスクトップPCをエージェントに委任しよう！

⑪ GigaToken: 毎秒ギガバイト級の超高速トークナイザー

  • 言語モデリング向けの毎秒ギガバイト級の処理速度を持つトークナイザー
  • 大規模訓練コーパスのトークン化は大きなボトルネックだった — これを解決
  • 手動調整されたSIMD上で動作、トークンマッピングは厳密な階層構造でキャッシュ
  • Hugging Face・tiktokenコードと互換モードで組み込み可能
  • x86・ARMアーキテクチャの主要トークナイザーをサポート
pipでインストールして、コーパスを一瞬でトークン化！

⑫ Palmier Pro: AIと共有するmacOSビデオエディター

  • ユーザーとAIエージェントが同じタイムラインで編集するmacOS用ビデオエディター
  • Swiftでゼロから開発、Premiere Pro級の本格エディターとして単体でも使用可能
  • Cance、Cling、Nano Banana Proなどの生成AIモデルをタイムライン内に配置
  • ローカルMCPサーバーを公開し、Claude Code・codeex・Cursor・Claude Desktopが連携
エージェントと一緒に動画編集ができる！

UIコンポーネント ＆ セルフホスティング

⑬ Canvas UI ＆ ReUI: WebGLエフェクトとShadcn拡張

  • Canvas UI: WebGLエフェクトがライブDOMを再描画、テキストは選択可能・リンクはクリック可能のまま
  • Liquid、Blaze、Glass、Shatter、VHSなど24種類のコンポーネントを提供
  • React・Vue・Svelte・Vanilla各ビルド付き、Shadcn互換レジストリでソースコピー方式
  • ReUI: Shadcn UIエコシステム向けの1000以上の構成例を提供
  • データグリッド、コンボボックス、フィルター、タイムラインなど17種類の自社開発コンポーネントで機能を補完
1つ追加するだけで、ページが波打つような効果が！

⑭ Coolify: 自分のサーバーで動かすセルフホスティングPaaS

  • SSH接続だけでサーバー・アプリ・データベースを管理するセルフホスティングプラットフォーム
  • VPS、ベアメタル、Raspberry Piもすべて同じように動作
  • 1つのダッシュボードから静的サイト、DB、フルスタックアプリ、数百のワンクリックサービスを展開
  • ベンダーロックインなし — 設定は自分のサーバーに書き込まれ、Coolifyがなくても動き続ける
  • 単一のインストールスクリプトでセットアップ完了
クラウドの手軽さを自分のハードウェアで！

⑮ Video Shotcraft: 映画級の製品プロモ動画を作るエージェントスキル

  • 既存のコードやcodeexをモーションデザインスタジオへと変換するエージェントスキル
  • 106枚の撮影レシピカードで目的・タイミング・パラメーター・落とし穴を網羅
  • 161種類のモーションプレビューをオンラインギャラリーで閲覧
  • 2.5Dカメラワーク、ビート同期カット、映画レベルエフェクト、実際のページキャプチャを使ったリモーション
  • 検証済みの36秒テンプレートにスクリーンショットとブランディングを反映
商品を映像で魅せる的最強ツール！

デプロイ ＆ セキュリティ ＆ 音楽 ＆ デバッグ

⑯ Open Ship: CI/CD内蔵のセルフホスト型デプロイプラットフォーム

  • リポジトリを指定するだけでスタックを検出・ビルド・設定・コンテナ出荷まで自動実行
  • パイプラインファイルやYAMLを書く必要なし
  • ローカルでビルドして完成コンテナをSSH経由でプッシュ、サーバー上ではアプリのみ実行
  • DB、ドメイン、SSL、CDN、メール、バックアップ、監視をすべて管理
  • デスクトップアプリ、Webダッシュボード、CLI、REST API、MCPを提供
どんなLinuxサーバーでも自分のクラウドに！

⑰ DeepSac: 大規模コードベース向けエージェント駆動の脆弱性スキャナー

  • 自社インフラ内で実行するエージェント駆動型の脆弱性スキャナー
  • 大規模リポジトリの全ファイルをレビューし、何年も放置された見つけにくい問題を発見
  • 高速なリグXマッチングで候補を発見 → AI調査で結果と推奨事項を生成
  • Git履歴との再検証、Markdown・JSON形式でエクスポート
  • ワーカーマシンやマイクロVM全体にワークロードを分散、全コマンドがべき等性を持つ
リポジトリを指定するだけで、隠れた脆弱性を一網打尽！

⑱ Muscriptor ＆ LLM Space: 音楽生成とエージェント開発ワークベンチ

  • Muscriptor: 音声ファイルをMIDIに変換する多楽器楽譜作成モデル
  • クラシックからヘビーメタルまで17万曲で学習、ピッチ・タイミング・楽器情報を含むノートイベントに変換
  • 貪欲復号・サンプリング・ビームサーチを選択可能、CPU〜GPUで動作
  • LLM Space: エージェント開発者向けデスクトップワークベンチ — プロトタイピング・トレース・デバッグ・評価を集約
  • エージェントループ内の全モデル呼び出しとツールをリアルタイム監視、履歴から再実行で原因特定
音楽もデバッグも、オープンソースで！
