Opus 5とは何か？

① Opus 5リリース: 猛スピードの4番目のモデル

  • Anthropicが約2ヶ月で4番目のモデルをリリース — ペースが異常に速い
  • 5月下旬: Opus 4.8 → 6月上旬: Fable 5 → 6月末: Sonnet 5 → 7月: Opus 5
  • Opusシリーズの新フラッグシップモデルとして位置づけられている
2ヶ月で4モデルって、リリースペースが凄すぎる...

② ポジショニング: Sonnet 5とFable 5の中間

  • 低価格帯のSonnet 5と最上位のFable 5の中間に位置づけられる
  • 価格は入力$5/100万トークン、出力$25/100万トークン — Opus 4.8と同額
  • Fable 5（$10/$50）の半額で提供される

③ 高速モードとコスト調整ダイヤル

  • 約2.5倍の速度で動作する高速モードを搭載（価格は2倍）
  • 低・中・高・最大の4段階の調整ダイヤル付き
  • タスクごとにコストと品質のトレードオフを自由に調整可能
  • Claude Code、Co-workアプリ、API（Bedrock、Google Cloud、Microsoft Foundry）で利用可能
