Opus 5の登場

① 猛速のリリースラッシュ: 2ヶ月で4モデル

  • 5月下旬にOpus 4.8、6月上旬にFable 5、6月末にSonnet 5、そしてOpus 5が立て続けにリリース
  • わずか約2ヶ月で4つのモデルを発表という異常なペース
  • Opus 5はSonnet 5とFable 5の中間に位置づけられる
リリースペースが速すぎて追うだけでも大変...！

② 価格設定: Fable 5の半額、でも安くない

  • 入力100万トークンあたり$5、出力は$25 — Opus 4.8と同価格
  • Fable 5は$10/$50なので、まさに半額
  • さらに約2.5倍高速で動作する高速モード搭載（価格は2倍）
  • 低・中・高・最大の4段階の調整ダイヤルでコストと品質のトレードオフが可能
半額と言っても、決して安いわけじゃない...

③ 利用可能プラットフォーム: Maxプラン標準モデル

  • Claude CodeとCo-workのClaudeアプリで利用可能
  • API経由でも提供 — Bedrock、Google Cloud、Microsoft Foundryに対応
  • 現在Maxプランの標準モデルに指定されている
  • Maxプラン加入者は自動的に利用可能
Maxプランの人は気づかないうちに切り替わってるかも

公式ベンチマークの数字

④ Frontier Bench: 前作の2倍以上のスコア

  • ハード・ソフトウェアエンジニアリングベンチマークで43.3%を獲得
  • Fable 5は33.7%、Opus 4.8はわずか18.7%
  • 前モデルの2倍以上で、より高価なFable 5をも凌駕
公式数字は圧倒的...でも本当？

⑤ ARC-AGI 3 ＆ OSWorld: 圧倒的な首位

  • ARC-AGI 3で30.2%の効率を達成 — 次点の約3倍
  • OSWorldコンピュータ利用率ランキングで70.6%で首位
  • Zapier業務自動化ランキングでもビジネスタスク部門トップ
数字だけ見ると完璧なモデルに見える...

⑥ 安全性の主張: 最も整合性が高い？

  • Anthropicは「これまでで最も整合性が高い」と主張
  • 安全監査における不正行為の発生率が最低と宣言
  • 建前上はFable 5レベルの性能が半額で得られるということ
  • しかしマーケティング数字を鵜呑みにしないのがこのチャンネルの流儀
公式ベンチマーク ≠ 実際の使い心地

King Benchで実検証

⑦ エレベーターシミュレーション: 満点スタート

  • 3基のエレベーターで1台1人乗車、ツールチップ表示を実装
  • 10点満点中10点 — 論理は完全に正しい
  • 待機中・乗車中・配達済みのリアルタイムカウンターも完備
  • 10点満点を獲得したのはOpusモデルだけ — 素晴らしいスタート
この調子なら行けるかも...！

⑧ 3JSコンタクトレンズケース: 歴代2位

  • 左右のキャップが区別でき、クリックで開く3Dモデル
  • 10点満点中8点 — ほぼ全モデルが苦戦するテスト
  • Qwen 3.8 Maxと並ぶ歴代2位、唯一10点のFable 5に次ぐ
  • Opus 4.8の7点を上回る評価
3D系でも強い！これは期待できる

⑨ 3JS折りたたみテーブル: 期待外れの退化

  • スライダーでテーブルを展開・折りたたみする3Dタスク
  • 10点満点中5点 — 折りたたみ動作がスムーズではない
  • Opus 4.8は8点だったのに、前作からの退化
  • Fable 5、Kimiko K3、GLM 5.2、Sonnet 5はすべて9点
前作より下がってるの、ちょっと変だよ...

残りのテスト結果

⑩ パンダSVG ＆ 弓矢ゲーム: 安定の性能

  • パンダがハンバーガーを食べるSVG画像：6点 — Opus 4.8やFable 5と同じ
  • 弓矢シミュレーターゲーム：10点満点 — 物理挙動とリーダーボード完璧
  • 弓矢はOpus 4.8、Grok 4.5、Qwen 3.8 Maxと肩を並べる
  • Opusシリーズはビジュアル生成が得意ではない傾向が継続
ゲーム系は強いけど、絵は変わらず苦手

⑪ 数学問題: 満点で論理思考を証明

  • 順序対の順列を数える難問（答え: 2460）
  • 10点満点中10点 — 多くのモデルが失敗する中で正解
  • Opus 4.8、Fable 5、Kimiko K3、Qwen 3.8 Maxと同じクラブ
  • 論理的思考能力は明らかに損なわれていない
推論力は本物。だからこそ後の結果が惜しい

⑫ 長期自律タスク: 歴代最高の出来

  • パンダの事実データセット生成 → Gemma 2B微調整 → ローカルWeb UI構築
  • 10ファイルに134個の事実を整理し、MLXでQLoRA微調整を約10分で完了
  • 99個のテストを作成し、カバレッジ約95%を達成
  • 設計判断を説明するREADMEまで作成 — 誰も頼んでいないのに
  • この問題における歴代最高の回答 — 自己検証行動が発揮された
自律型エージェントとしては最高峰！

最難関テストと総合結果

⑬ 3D腕時計テスト: 最難問で3点

  • 秒針・分針・時針、日付・曜日、2つのタイムゾーンを表示する3D腕時計
  • 10点満点中3点 — 実験台で最も難しい問題
  • Chronos GMTというモジュール式プロジェクトを構築 — 膨大な労力
  • デュアルタイムゾーン、夜間モード、テクスチャデバッグページまで作成
  • しかし完全に機能する3D腕時計は完成せず
  • Opus 4.8、Kimiko K3、GLM 5.2、Qwen 3.8と同点、Fable 5は4点
努力はすごいのに、最終成果物が完成しない...

⑭ 総合スコア: 77.5%で前作を下回る

  • King Bench総合スコア：80点満点中62点（77.5%）
  • Kimiko K3と同点で、Qwen 3.8 Maxの81.25%を下回る
  • Fable 5の82.5%にも届かない
  • なんと前作Opus 4.8の80%をも下回る結果に
  • 公式ベンチマークではFable 5を上回るはずが、実テストでは前作以下
公式数字と実態のギャップがすごい...

⑮ 結果のパターン分析: 推論は強い、ビジュアルは弱い

  • 論理・推論・長期自律タスクは満点 — エレベーター、ゲーム、数学、微調整
  • 純粋なビジュアル・3D完成度は後退 — 折りたたみテーブルは8点→5点
  • 主体的コーディングと推論に特化して調整されていると推測
  • Frontier BenchやARC-AGIの数値とも矛盾していない
  • ビジュアル生成面は変化なしか後退という結果
推論特化型として割り切れば強い！

実使用感と結論

⑯ 冗長すぎる動作: 無駄なトークン消費

  • 1つのファイルを操作するだけでも最低5つのファイルにアクセスし、ディレクトリをくまなく探索
  • 不要な儀式で大量のトークンを消費 — API利用なら金額が積み重なる
  • GPT-5.6 Soulでよく見られる現象と似たような挙動
  • 確かに答えにはたどり着くが、過程が長すぎる
トークン課金だと余計な出費がかさむ...

⑰ 汎用知能の低下と安全フィルター問題

  • 生の知識能力が著しく低下 — 雑談、一般質問、マルチモーダルすべてが物足りない
  • Fable 5は別次元、GPT-5.6 Soulでも通常質問はFableより優れている
  • 安全フィルターに引っかかるリクエストが旧型モデルで勝手に応答される報告あり
  • Fable 5発売時の苦情と似たパターン — 要注意
  • 優れた汎用アシスタントを期待するならこのモデルは不適切
エージェント特化の代償が汎用性の低下...

⑱ 最終評価: 良いが、おすすめはしない

  • 良いモデルだが、積極的におすすめするものではない
  • Fable 5の方が断然優れている
  • 日常使いならGPT 5.6 SoulやKimiko K3が適している
  • 最大の価値は「Fable 5の半額で使えるエージェント」という点
  • Maxプランなら自動的に使えるので、コスト意識が必要
  • 宣伝ではFable 5を上回るが、実態はそうではない
「Fable 5の半額で手に入る、頼りになるエージェント」
これが一番正確な表現かも
