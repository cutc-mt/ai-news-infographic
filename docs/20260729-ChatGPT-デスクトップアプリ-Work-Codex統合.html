新ChatGPTデスクトップアプリが登場

ChatGPT + Work + Codex が1つのアプリに統合された

📅 2026年7月29日

①アプリ概要: 3つの機能が1つに統合

  • OpenAI公式のデスクトップアプリがリリースされた。
  • ChatGPT（通常チャット）・Work（ファイル分析＋検索）・Codex（コーディングエージェント）を統合。
  • macOS と Windows の両方に対応している。
これまで別々だったツールが1つにまとまった

②3つのモード切替: シーンで使い分け

  • ChatGPTモード: これまでのWeb版と同じ通常チャット。
  • Workモード: ファイル分析・Web検索・Persistent Memoryを搭載。
  • Codexモード: ターミナルベースのコーディングエージェント。
1つのアプリの中でスッと切り替えられる

③ChatGPTモード: おなじみのチャット体験

  • これまでのWeb版とほぼ同じ使い勝手で利用できる。
  • GPT-5.6ソルをはじめとする最新モデルに対応している。
  • 画像生成のDALL-Eも統合されていてそのまま使える。
ブラウザを開かなくてもいつでもチャットができる

④Workモード: ファイル分析と検索の強力ツール

  • ファイルをドラッグ＆ドロップで簡単に読み込める。
  • PDFExcelPPTWord など幅広い形式に対応。
  • Persistent Memoryで過去のやり取りを覚えていてくれる。
  • Canvas機能でレポートや文章の作成もスムーズ。
仕事のファイルをそのままAIに分析させられる

⑤Codexモード: ターミナルで動くコーディングAI

  • ターミナル上で動くコーディングエージェントとして機能する。
  • プロジェクト全体の構造を理解してくれて、文脈を踏まえたコードを書く。
  • 複数のファイルを一括で編集できるのが大きな強み。
  • エラーを見つけると自動で修正もしてくれる。
Claude Codeの強力なライバルとして注目

⑥統合のメリット: ワンストップで完結

  • 1つのアプリでチャット→リサーチ→コーディングまで完結する。
  • モード間でコンテキストを共有できるのが大きな利点。
  • APIキーの設定も不要で、すぐに使い始められる。
ツールを切り替えるストレスがゼロになる

⑦Persistent Memory: 記憶で賢くなるAI

  • ユーザーの好みや文脈を記憶して、セッションをまたいで活用する機能。
  • 前回のやり取りを覚えているので、毎回説明をしなおす必要がない。
  • 「よく使う設定」や「好みのトーン」などをAIが学習していく。
使えば使うほど自分に合った回答が返ってくる

⑧ショートカットキー: キーボードでサクサク操作

  • Cmd+Shift+C（Mac）でChatGPTを一瞬で起動できる。
  • モード切替もキーボード操作でマウスなしでスムーズに。
  • 作業の途中でAIを呼び出す流れが極めて自然になる。
ショートカット1つでAIが手元に現れる感覚

⑨ファイル連携: ローカルファイルに直接アクセス

  • デスクトップにあるローカルファイルを直接参照・分析できる。
  • クラウドにアップロードする手間がなく、セキュリティも安心。
  • 作業中のドキュメントをそのままAIに読み込ませてフィードバックをもらえる。
ファイルを開かずに中身をAIに分析させる

⑩検索統合: Webの最新情報を取り込む

  • WorkモードでWeb検索の結果を取得して回答に反映できる。
  • 最新のニュースや情報を踏まえた回答が得られるのが強み。
  • 検索結果とファイル分析を組み合わせた高度なリサーチが可能。
AIの知識がリアルタイムに更新される感覚

⑪マルチモデル切替: 状況に合わせてモデルを選ぶ

  • GPT-5.6ソルやOpus 5など複数のモデルを切り替えて使える。
  • タスクの複雑さに応じて最適なモデルを選択する。
  • 速度重視か品質重視か、柔軟に調整が可能。
用途に合わせてAIの頭脳を切り替えられる

⑫エージェント機能: AIが自律的に動く

  • 複数ステップのタスクを自動で実行するエージェント機能を搭載。
  • 「〇〇を調べてレポートにして」と1つ伝えるだけで動き出す。
  • 途中経過を確認しながら、必要に応じて軌道修正もできる。
指示1つでAIが自律的に仕事を進めてくれる

⑬コーディング体験: Codexで開発が変わる

  • プロジェクトを開いて要件を伝えるとコードを自動生成する。
  • テストの実行まで自動で行って、エラーがあれば修正まで完了する。
  • 「要件→コード→テスト→修正」のサイクルをAIが自律的に回す。
開発者の作業の半分以上をAIが肩代わりしてくれる

⑭Workの実用例: ビジネスにもすぐ活用

  • レポート作成: データを分析して整理されたレポートを自動生成。
  • データ分析: ExcelやCSVを読み込んでグラフや解説付きで分析。
  • プレゼン資料作成: キーワードからスライドの構成を提案してくれる。
ビジネスの現場ですぐに役立つ実用機能が満載

⑮設定カスタマイズ: 自分好みに調整

  • テーマ切替: ダークモードとライトモードを自由に選べる。
  • 通知設定: 必要な通知だけを絞り込める。
  • ショートカットキーのカスタマイズも可能で自分好みに設定できる。
仕事環境に合わせて細かくカスタマイズできる

⑯パフォーマンス: ネイティブアプリの軽快さ

  • ネイティブアプリなのでWeb版より高速に動作する。
  • オフライン機能の一部対応で、通信環境に依存しにくい。
  • メモリやCPUの効率的な利用で、システムへの負荷も低い。
ブラウザを開く必要がないからサクサク快適

⑰他ツールとの比較: Cursor vs ChatGPTデスクトップ

  • Cursor: コーディングに特化したIDE。開発者向けに深く作り込まれている。
  • ChatGPTデスクトップ: チャット・分析・コーディングを汎用的にこなす。
  • 用途に応じて使い分けるのが良さそう。どちらも一長一短がある。
コーディング特化 vs 汎用、どちらも魅力的

⑱今後の展望: さらに進化していくAIデスクトップ

  • より多くのツール統合が予定されていて、機能が拡張されていく。
  • チーム機能の追加で、複数人での共同作業にも対応する見込み。
  • APIの改善により、外部サービスとの連携もさらに強化される。
AIのデスクトップ体験はまだ始まったばかり
