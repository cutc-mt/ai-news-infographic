Claude Code on Azure でスリングショットゲームを開発する話

インテント駆動開発で、意図を伝えるだけでゲームができる

📅 2026年7月29日

①プロジェクト概要: Claude Code + Azureでゲーム開発

  • Azure上のClaude Codeを使ってスリングショットゲームを開発するプロジェクト。
  • インテント駆動開発という手法で、コードを書かずに意図を伝える。
  • Angry Birds風の物理パズルゲームをクラウド環境で構築する。
クラウド × AI × ゲーム開発の実践デモ

②Azure環境のセットアップ: クラウド開発ワークスペース

  • Azureの開発環境にClaude Codeを導入してクラウドベースのワークスペースを構築。
  • ローカル環境の構築不要で、ブラウザやターミナルからすぐに開発開始。
  • セキュリティとスケーラビリティがAzureによって保証される。
環境構築の手間をゼロにして開発に集中できる

③Claude Codeとは: ターミナルで動くAIコーディングエージェント

  • Anthropicが提供するターミナル上で動くAIコーディングエージェント。
  • コードベース全体を理解して、複数のファイルを一括で編集できるのが特徴。
  • 自然言語の指示を受け取って自律的に開発タスクを遂行する。
IDEの代わりにターミナルで直接開発ができる

④インテント駆動開発とは: 意図を伝える新しい手法

  • コードの詳細な指示ではなく、開発者の「意図」を伝えるのがポイント。
  • AIが実装の最適な方法を自律的に判断してコードを生成する。
  • 「どう作るか」ではなく「何を作りたいか」に集中できる。
プログラミングの知識がなくても始められる開発手法

⑤ゲームデザイン: スリングショットゲームの仕様定義

  • Angry Birds風のスリングショット物理パズルゲームを設計。
  • 重力・反発・衝突の物理エンジンと複数レベルの構成を定義。
  • スコアシステムやフィードバック演出も含めた全体仕様を策定。
物理パズルならではの面白さを目指す

⑥インテントの記述: 自然言語でゲームの振る舞いを定義

  • 日本語や英語で「鳥を弾いてブロックを崩す」などの振る舞いを記述。
  • 「重力と反発を実装」「ブロックの配置をランダムに」など意図を箇条書き。
  • コードのシンタックスを気にせず、やりたいことをそのまま書く。
「こう動いてほしい」を言葉で伝えるだけ

⑦Claude Codeとの対話: ターミナルでインテントを伝える

  • ターミナル上でClaude Codeに自然言語のインテントを直接入力する。
  • 対話的な開発サイクルで、結果を見ながら追加の指示を出せる。
  • 質問や修正の要求にも柔軟に応答してくれる。
チャットのようにやり取りしながらゲームが育っていく

⑧コードの自動生成: HTML5 Canvas + JavaScriptで実装

  • Claude CodeがHTML5 CanvasとJavaScriptでゲームエンジンを自動生成。
  • 物理計算、衝突判定、描画システムなどが一気に出力される。
  • 複数ファイルにまたがるコードの整合性も自動で保たれる。
指示1つで数十行のゲームコードが生成される

⑨物理エンジンの実装: 重力・速度・衝突のシミュレーション

  • 重力・速度・弾道計算・衝突検知をClaude Codeが自動で構築する。
  • 物体同士の衝突判定と反発の物理シミュレーションを実装。
  • リアルな物理挙動を再現するためのパラメータ調整もAIが担当。
物理の計算は全部AIにお任せ

⑩スリングショットメカニクス: 引いて弾く操作感

  • タッチやクリックでスリングを引いて弾く直感的な操作を実装。
  • ドラッグの距離と方向で発射の威力と角度が調整される。
  • 弾道予測線の表示で、プレイヤーに次弾の軌道を分かりやすく提示。
指を引くだけで飛んでいく感覚が大事

⑪レベルデザイン: ブロック配置と障害物の設計

  • ブロックの配置、障害物、ターゲットの複数レベルを自動生成。
  • 各レベルで異なる難易度と配置パターンでプレイヤーを挑発。
  • ランダム要素を取り入れて、毎回違う配置を楽しめる仕組み。
何度遊んでも飽きないレベルバリエーション

⑫スコアとフィードバック: ブロック破壊の爽快感

  • ブロックを破壊するとポイントが加算されていくスコアシステム。
  • 破壊時のエフェクトやサウンドでプレイヤーにフィードバックを提供。
  • クリア時の評価やスター獲得でやり込み要素を付加。
ブロックが崩れる瞬間が一番気持ちいい

⑬デバッグと修正: エラーを自動で検出して修正

  • Claude Codeがエラーを検出して自動修正してくれるデバッグサイクル。
  • 動作確認→修正→再確認のループをAIが高速で回す。
  • 人間が手動でデバッグする時間を大幅に削減できる。
エラーが出てもAIが即座に直してくれる

⑭インテントの反復改良: 意図レベルでチューニング

  • 「鳥の飛距離を長く」「ブロックをもっと壊れやすく」など意図レベルで調整。
  • パラメータの数値を直接いじるのではなく、感覚的な指示で変更可能。
  • 結果を見て「もっとこうしたい」というフィードバックでゲームを磨き上げる。
「微調整」も言葉で伝えるだけでOK

⑮Azureとの連携: クラウドホストとデプロイ

  • 完成したゲームをAzure Static Appsなどにデプロイして公開。
  • クラウド環境でのホスト・プレビュー・共有まで一貫したワークフロー。
  • デプロイ後も即座にブラウザで動作確認ができる。
作ったゲームを世界にすぐ公開できる

⑯パフォーマンス最適化: 60fpsでのスムーズな動作

  • Claude Codeによるレンダリング最適化で60fpsの目標を達成。
  • メモリ管理や描画の負荷を最小化するコードが自動生成される。
  • 物理演算と描画のバランスを取って快適なプレイ体験を実現。
プロの最適化ノウハウがAIに詰まっている

⑰インテント駆動のメリット: 開発のハードルを下げる

  • 詳細なコード指示が不要なので、開発スピードが大幅に向上する。
  • 非エンジニアでもプロトタイプの制作が可能になる。
  • アイデアを形にする過程に集中できるので、クリエイティビティが活きる。
アイデアのある人が誰でもクリエイターになれる

⑱今後の展開: さらに複雑なゲームやマルチプレイヤーへ

  • より複雑なゲームロジックやマルチプレイヤー対応への応用が期待される。
  • Claude CodeのSkill機能を活用して、開発パターンの再利用性を高める。
  • インテント駆動開発がソフトウェア開発全体の新スタンダードになる可能性。
意図を伝えるだけでどんなアプリも作れる未来
