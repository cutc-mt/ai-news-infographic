AIエージェントと毎日使う便利ツール5選

VS Code、Obsidian、Raycast、音声入力でAI作業を加速させる
2026年8月1日

①公式デスクトップアプリ: AIを毎日開く入り口

  • OpenAIとAnthropicが公式提供するデスクトップアプリ
  • チャット画面が常に立ち上がり、すぐにAIに話しかけられる
  • スケジュール機能で定期的なタスクを自動実行できる
  • スマホ連携（Dispatch）で外出先からも指示を出せる
ブラウザを開く手間が不要！デスクトップに常駐させるだけでAIが身近になる 🚀

②デスクトップアプリの限界: 主役はあくまでチャット

  • 提供元はAI開発の企業なので、主役はチャット機能
  • ファイルの閲覧や編集は追加機能レベルにとどまる
  • 複数ファイルを横並びで見比べるのが難しい
  • 本格的な編集作業には別のツールが必要
デスクトップアプリは便利だけど、作業の中心にはなりきれない… 😅

③VS Codeとは: エンジニア以外も使える万能エディタ

  • Microsoftが提供する無料のコードエディタ
  • プログラマーだけでなく一般ユーザーにもおすすめ
  • テキストファイルの確認や編集がサクサクできる
  • 拡張機能で自分好みにカスタマイズ可能
「プログラムを書かない人でも使える」— これがVS Codeの魅力！ ✨

④Office Viewer: ExcelもWordもVS Codeで見られる

  • Word文書をVS Code内で綺麗に表示
  • Excelの表もインラインで確認できる
  • PowerPointのスライドもプレビュー可能
  • PDFやMarkdownも同じ画面で表示
わざわざOfficeを起動しなくて済む！VS Code一本で完結する 🎯

⑤Material Icon Theme: ファイルの種類が一瞬で分かる

  • ファイルの拡張子ごとに専用アイコンを表示
  • 一瞬でファイルの種類が視覚的に分かる
  • .pyなら蛇、.jsなら黄色い四角、見分けが簡単
  • カラフルで探しているファイルを素早く見つけられる
地味に見えて作業効率が劇的に上がる、おすすめの第一歩！

⑥Japanese Language Pack: メニューを日本語化

  • VS Codeの表記をすべて日本語に変更できる
  • 英語のメニューに抵抗がある人に最適
  • 設定画面も日本語なので迷わず操作できる
  • 公式が提供する無料拡張機能で一瞬で導入
英語が苦手でも大丈夫！まずは日本語化してはじめの一歩を 😊

⑦拡張機能の安全な選び方: 公式と10万ダウンロード

  • 公式マークの付いた拡張機能を優先的に選ぶ
  • ダウンロード数が10万以上を目安にする
  • 不審な拡張機能はセキュリティリスクの原因に
  • 評価の星の数やレビューも参考に判断
「人気がある＝多くの人が検証済み」— 安心できる基準で選ぼう！

⑧Claude Code拡張機能: VS Code内でAIを起動

  • VS Code内でClaude Codeを直接起動可能
  • ファイルを見ながらAIに指示を出せる
  • エディタとチャットの行き来が不要
  • コードの修正や作成が一つの画面で完結
「このファイルを見て〜」がその場で伝わる、最強の連携！ ✨

⑨選択テキストのAI渡し: @でファイル指定も

  • VS Code内でテキストを選ぶと自動的にClaude Codeに渡る
  • @を使って特定のファイルを指定可能
  • コピー＆ペーストの手間がゼロに
  • 思考の流れを途切れさせずにAIと対話
選ぶだけでOK！作業のテンポが全然違う ⚡

⑩Obsidianとは: リンクで繋ぐ高性能メモ帳

  • Obsidianは高性能なメモ帳アプリ
  • メモ同士をリンクで繋いで関連付けができる
  • 繋がりをグラフで可視化して全体像を把握
  • 知識がネットワークのように蓄積されていく
「メモが繋がってアイデアが生まれる」— 第二の脳を作れる！ 🧠

⑪Callouts機能: 背景色で分かりやすく整理

  • 文章の背景色を変えて分かりやすく表示
  • 注意点や補足、引用を見分けやすく整理
  • AIに文章を整理させるのに最適な形式
  • 後で読み返したときに要点が一目で分かる
AIに「Calloutsで整理して」と頼むだけで、見やすいメモが完成！

⑫Obsidian Markdown Skill: AIで自動変換

  • CEOが公開している専用スキル
  • あらゆる文章をObsidian形式に変換できる
  • Claude Codeと組み合わせて自動実行
  • リンクやCalloutsもいい感じに付けてくれる
面倒な整形作業をAIに丸投げできる、時短の救世主！ 🚀

⑬Web Clipper: 記事を画像付きで保存

  • Chromeで開いている記事をワンクリックで保存
  • 画像付きで見た目もそのままObsidianへ
  • インプットの収集効率が劇的にアップ
  • あとで読み返す際も元の記事の雰囲気を保持
「いい記事見つけた！」が一瞬で自分の知識になる 📚

⑭Aqua Voice: タイプより5〜10倍速い入力

  • Aqua Voiceで音声から直接テキスト化
  • タイピングより5〜10倍早くAIに指示を出せる
  • すでに65万単語の入力実績あり
  • 話すようにAIへ指示、思考のスピードで入力
「喋った方が早い」が本当になる！AIとの対話が会話レベルに 🎤

⑮無料の代替手段: 標準機能でも音声入力できる

  • WindowsならWin + Hで標準音声認識
  • Macにも標準の音声入力機能が用意されている
  • ChatGPT Desktopの音声機能も活用可能
  • 本格派にはマイク（HyperX SoloCast）がおすすめ
有料アプリがなくても今の環境で始められる！ 😊

⑯Snippets機能: よく使うプロンプトを瞬時呼出

  • よく使うプロンプトを辞書登録できる
  • セミコロン＋キーワードで瞬時に呼び出し
  • 変数機能でクリップボードの内容を埋め込み可能
  • 同じ長文を何度も打つ無駄をゼロに
「;code」だけで一発！プロンプトの入力が魔法のように ⚡

⑰Window Management: ウィンドウを瞬時に整列

  • ウィンドウを一瞬で配置変更できる
  • 並列開発で複数のターミナルをきれいに整理
  • 好きなショートカットキーを割り当て可能
  • マウスでドラッグする手間が一切不要
複数ウィンドウの整理が一瞬で完了、快適すぎる！ 🖥️

⑱Focus機能: SNS誘惑を指定時間ブロック

  • XやYouTubeなど特定のサイトをブロック
  • 指定した時間だけアクセスを制限
  • AIエージェントの待ち時間にSNSを見ちゃう問題を解決
  • 集中力を守って作業の質を維持
「つい見ちゃう」をシステムで防ぐ、最後の集中ツール！ 🎯
