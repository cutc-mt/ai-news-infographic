⑦第3の柱: コスト制御（Flash-first）

  • 3本柱の3つ目はコスト制御の仕組み。
  • 基本はFlash-firstで安いモデルを優先使用。
  • 難しい処理だけ/proや/preset maxでProに切替。
  • 「必要な時だけ強いモデル」で無駄な出費を防ぐ設計。
日常は安く、難所だけ強力に

⑧Flash-firstアプローチ: 日常はFlash、難所はPro

  • 普段のコーディングはV4 Flashが十分に強力。
  • 複雑な推論や大規模リファクタはV4 Proの出番。
  • この切替をワンコマンドで実行できる。
  • 結果として月額コストを大幅に抑えられる。
「強いほど高い」を当たり前に変える

⑨セットアップ手順: 3ステップで起動

  • Step 1: npm installでReasonXを導入。
  • Step 2: DeepSeekのAPIキーを環境変数に設定。
  • Step 3: reasonxコマンドで起動するだけ。
  • 所要時間は数分。すぐにコーディングを始められる。
$ npm install -g reasonx
$ export DEEPSEEK_API_KEY=sk-...
$ reasonx
たった3行で公式エージェント起動

  • ReasonXのデフォルトはDeepSeek V4 Flash 0731。
  • このモデルはエージェント能力が大幅に強化済み。
  • 日常的なコーディングならProなしでも十分戦力になる。
  • 高速・低コストでありながら高精度を維持。
デフォルトで強い、それが理想

⑪/proコマンド: 次の1ターンだけProに切替

  • /proを打つと次の1ターンだけV4 Proに切替。
  • 難しい1問だけ最強モデルで解きたい時に便利。
  • 1ターン終われば自動でFlashに戻る。
  • Proを使うのは最小限のコストで済む。
> /pro
[次の1ターンをV4 Proで実行]
> この関数をリファクタして
[Flashに自動復帰]
