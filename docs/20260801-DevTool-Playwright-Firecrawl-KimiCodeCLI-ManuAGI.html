トップ開発ツールプロジェクト 2026

Playwright, Firecrawl, Temporal, LikeC4, Kimi Code CLI & Strix

📅 2026年8月1日 | ManuAGI - AutoGPT Tutorials

今週のトレンドオープンソース開発ツールをまとめました。ターミナルベースのコーディングエージェント、ローカルコードナレッジグラフ、ウェブ自動化、音声認識、セルフホストプラットフォームなど、デベロッパーの生産性を向上させる実用的なプロジェクト18個を紹介します。

①Playwright: 1つのAPIで3大ブラウザを制御

  • ChromiumFirefoxWebKit を単一のAPIで操作するテストフレームワーク
  • テストランナーが各テストを独立したブラウザコンテキストで実行
  • 要素のアクション可能状態を自動待機し、タイミングバグを大幅削減
  • トレース機能でスクリーンショット・DOM・ネットワークログをキャプチャ
  • CLIとMCPサーバーも搭載し、コーディングエージェントがブラウザ操作可能
npx playwright test
TypeScript, Python, .NET, Java対応。Linux/macOS/Windowsで動作！

②Firecrawl: あらゆるサイトをエージェント対応データに変換

  • 検索・スクレイピング・ウェブ操作をスケールで実行するオープンソースAPI
  • JavaScript重いページをレンダリングし、プロキシローテーションとレートリミットに対応
  • クリーンなMarkdownJSONスクリーンショットを出力
  • クリック・スクロール・入力後にデータを抽出。サイト全体のクロールも可能
  • セルフホスト対応。Python・Node・Go・JavaのSDKを提供
自然言語プロンプトからデータ収集もできる。MCPでエージェントに直結 🚀

③Temporal: 信頼性の高いワークフローのための永続的実行プラットフォーム

  • ワークフローを実行し、障害時に自動リトライ・リカバリー
  • カスタムリトライ・タイムアウト・リカバリーの定型コードが不要
  • ワークフロー・アクティビティ・ワーカーをサポート言語で記述
  • CLIツールとWeb UIで実行状態をインスペクト可能
  • UberのCadenceフォーク。Go製。1コマンドでローカル開発サーバー起動
temporal server start-dev
長時間実行・分散処理に最適。バックエンド開発者の強い味方！

④LikeC4: アーキテクチャをコードとして記述してライブダイアグラム生成

  • ソフトウェアアーキテクチャをテキストファイルで記述し、リアルタイムにダイアグラム化
  • コード変更に合わせてダイアグラムが自動的に同期
  • C4モデルとStructurizr DSLベース。独自の記法と要素タイプを定義可能
  • ネストされた複数レベルのビューでシステム全体を表現
  • VS Code拡張あり。npx likec4 start でプレビュー
npx likec4 start
手描きのアーキテクチャ図が古くなる問題を解決！TypeScript製 ✅

⑤Kimi Code CLI: ターミナルで動くAIコーディングエージェント

  • Moonshot AIのターミナルネイティブコーディングエージェント
  • コード読み書き・シェル実行・ファイル検索・ウェブ取得を自律的に実行
  • フィードバックから次のステップを自動判断し、自然言語リクエストを実行
  • スクリーン録画をチャットにドラッグして動画入力として使用可能
  • MCPサーバー・スキル・プラグインのマーケットプレイスあり
Node.js不要の単一バイナリ。ZedやJetBrainsからACPで駆動可能！

⑥Strix: 自律型AIペネトレーションテストエージェント

  • AIエージェントが自律的に脆弱性を発見・検証
  • 手動ペンテストの遅さと静的スキャナーの誤検知のギャップを解消
  • コードを動的に実行し、動作するエクスプロイトで発見を証明
  • HTTP interception proxy・ブラウザ・シェル・Pythonサンドボックス搭載
  • 偵察・エクスプロイト・ポストエクスプロイトを連携するエージェントグラフ
Dockerサンドボックスで安全にスキャン。CI/CDに組み込んでPRチェック 🔒

⑦code-review-graph: AIコンテキストを最適化するローカル知識グラフ

  • コードベースの構造マップを永続構築するCLI・MCPサーバー
  • AIが毎回プロジェクト全体を再読みするトークン浪費を解消
  • Tree-sitterでパースし、関数・クラス・インポートのコールグラフをSQLiteに保存
  • ファイル変更時、影響範囲を自動トレースして最小レビューセットを提示
  • 24言語＋ノートブック対応。Cloud Code・Cursor等で利用可能
大規模モノレポで真価を発揮！保存・コミットごとに増分更新 ✨

⑧DeepTutor: 自身の学習材をAIチューターに変えるセルフホストプラットフォーム

  • セルフホストのエージェントネイティブ個別学習アシスタント
  • チャット・問題解決・クイズ生成・研究・数式アニメーション・インタラクティブ図解の6モード
  • PDF・Office・MarkdownからRAG対応のナレッジベースを構築
  • 永続的メモリが学習状況を追跡。自律チューターボットがTelegram・Discordで稼働
  • PythonNext.js製。複数LLMプロバイダ対応。Dockerでセットアップ
インタラクティブなライブブックの作成も可能。学習者と教育者向け 📚

⑨Jcode: Rust製のマルチセッション対応ターミナルハーネス

  • Rust製の低リソース・高カスタマイズなターミナルコーディングエージェント
  • 各ターンをベクトル埋め込みし、関連する過去のエントリを自動リコール
  • スウォームモードで複数エージェントを1つのリポジトリで並列実行
  • ファイル変更時にサーバーが通知し、エージェント間でメッセージをルーティング
  • Claude・OpenAI・Gemini等の多プロバイダ対応。Mermaidダイアグラム表示あり
セルフビルドモードで自身のソースを編集・再構築も可能。パラレルセッションに最適 🔧

⑩Pi Web: Piコーディングエージェントのローカルブラウザワークスペース

  • PiコーディングエージェントのターミナルセッションをブラウザUIに変換
  • プロジェクトごとに過去の会話を閲覧し、途中から再開やセッションのフォークが可能
  • ファイルパネルでソース・ドキュメント・画像・音声・PDFをプレビュー
  • モデル・APIキー・スキルの管理をWeb UIで操作
  • TypeScriptNext.js製。npxで起動し、全データはローカルに留まる
ターミナル履歴を掘り返さずに過去の作業にアクセスできる 🖥️

⑪Pi Agent Harness: 自己拡張可能なコーディングエージェントツールキット

  • エージェント構築をクリーンなパッケージに分割するAIエージェントツールキット
  • 統一LLM APIでOpenAI・Anthropic・Google等を1つのインターフェースで利用
  • エージェントランタイムがツール呼び出しと状態管理を処理
  • 差分更新のターミナルUIライブラリでインターフェースを描画
  • Linux microVM・Docker・ポリシー制御サンドボックスで安全にコンテナ化
npm配布。Slackやチャット自動化の別パッケージも。エージェント構築者向け 📦

⑫NPCpy: マルチモーダルAIエージェント構築のためのPythonライブラリ

  • マルチモーダルLLM・エージェント・ナレッジグラフの研究開発用ビルディングブロック
  • ペルソナ「NPC」をディレクティブとツール付きで定義し、マルチエージェントチームに構成
  • テキストからナレッジグラフを構築。覚醒・睡眠・夢のフェーズで進化
  • 画像・音声・動画の生成とSFT強化学習によるファインチューニングに対応
  • Ollama・llama.cpp等のローカルランタイムとLiteLLM経由のクラウドに対応
JINXテンプレートで多段プロンプトパイプラインを構築。研究者向け 🧪

⑬Kandev: コーディングエージェントをオーケストレーションするセルフホストカンバン

  • コーディングエージェントを並列実行し、カンバン＋パイプラインで作業を整理
  • ターミナルエージェントは実行できるが変更のレビューが困難な問題を解決
  • ファイルエディタ・ツリー・ターミナル・ブラウザプレビュー・Git変更を1つのワークスペースに集約
  • Git worktreeでパラレルエージェントの競合を防止。各ステップで異なるエージェントをチェーン
  • GoNext.js製。自インフラで稼働。テレメトリなし。VPN経由でどこからでもアクセス
エージェントフリートのオーケストレーションに最適。ローカル/Docker/SSH/Cloud対応 📋

⑭Deja Vu: コーディングエージェントの過去の作業ログを検索可能にするメモリレイヤー

  • コーディングエージェントの過去の作業を検索可能なローカルインデックスに変換
  • 解決済み問題を再デバッグする無駄を解消。「数週間前に直したよ」を覚えている
  • ゼロ依存の単一バイナリ。Go製で軽量
  • MCPリコールツールでエージェントに直接統合可能
  • APIキーとトークンをインデックス時に自動マスキング。マシン間同期対応
オートリコールフックでセッション開始前に関連メモリを自動注入 🔍

⑮img2threejs: 参照画像を手続き型Three.jsコードで再構築

  • 1枚の画像からコードのみの手続き型3JSモデルを再構築するエージェントスキル
  • フォトグラメトリやメッシュ抽出ではなく、TypeScriptファクトリで構築
  • プリミティブ・手続きシェーダー・生成ジオメトリでオブジェクトを再現
  • 機械的な作業を標準ライブラリのみのPythonスクリプトに丸投げしてトークンを節約
  • ブロックアウト→マテリアル→サーフェス→ライティングの段階的パイプライン
ピボット・ソケット・コライダーのランタイム階層付き。アニメーション準備完了！ 🎮

⑯PortalJS: AIネイティブなデータポータル構築フレームワーク

  • コーディングエージェントの支援でデータポータルを構築するオープンソースフレームワーク
  • ポータルの要件を記述するとClaude Codeスキルがアーキテクチャ設計とコード生成を実行
  • ホームページカタログデータセット別ショーケースの3サーフェスで構成
  • 1つのデータプロバイダコントラクトで静的ファイル・CKAN・GitHub・レイクハウスに対応
  • 生成コードは編集可能なNext.js。ロックインなし。データセット・チャート・マップ追加スキルあり
データチームがオープンデータを公開するのに最適 📊

⑰i-have-adhd: エージェントの出力を即行動にフォーカスするスキル

  • エージェントが回答を埋もれさせる問題を解決するコーディングアシストスキル
  • 「良い質問ですね」などの余計な前置き・要約・結びを排除
  • 10のルールで出力を再構成：次のアクションを先頭に、多段タスクを番号付け
  • 現在の状態を毎ターン再提示し、具体的な時間見積もりを付与
  • Claude CodeやCodeexのプラグインマーケットプレイスからインストール可能。skill.mdを編集してカスタマイズ
「要点は？」の答えを最初に持ってくる。スキャン可能な出力を実現 ⚡

⑱USBridge Remote: BIOSレベルからリモート制御する統合クライアント

  • ハードウェアKVMとソフトウェアリモートデスクトップを1つのインターフェースに統合
  • ネイティブMoonlight統合で2Kまでのビデオストリーミング
  • 内蔵Tailscaleでポート開放不要の暗号化P2Pトンネリング
  • LinuxエージェントがWaylandに対応（権限プロンプトなし）
  • 主にGoで開発。Windows/macOS/Linux/Android/iOSで動作
クライアント＋エージェントの2部構成。リモートマシン管理に最適 📡
