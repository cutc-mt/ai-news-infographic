有料プランの方はGeminiのサイドバーをチェック！

②Gemini Spark とは？

  • Googleが提供するAIエージェントサービス
  • 単なるチャットAIではなく、実際に仕事をこなしてくれる
  • ChatGPT WorkのGoogle版と考えると分かりやすい
  • 非エンジニア向けの日常業務サポートに特化
Claude Code Work → ChatGPT Work → Gemini Spark。各社からAIエージェントが続々登場中！

③通常のGemini との違い

  • 通常Gemini：質問に答える、文章を作る、アドバイスする相談相手
  • Spark：ファイルを読み、アプリを操作し、複数の成果物を一括生成
  • 複数ステップの作業を自律的に踏んで処理可能
  • 条件や時間を設定して自動実行することもできる
会話AI → 仕事を任せられるAIへ。この数ヶ月で急速に進化中！

④Googleサービスとの連携

  • Gmail - メールの受信監視、返信作成、要約
  • Googleカレンダー - スケジュール確認、予定通知
  • Googleドライブ - ドキュメント、シート、スライドにアクセス
  • スプレッドシート - データ整理・保存
  • Googleスライド - プレゼン資料の自動生成
Googleサービスをガッツリ使ってる人なら相性抜群！

⑤クラウド上で動き続ける

  • 仕事を依頼するとクラウド上で継続的に処理
  • 依頼後にPCやスマホを閉じてもOK
  • 完了したら通知でお知らせ
  • 処理時間は10分〜30分、複雑な作業では1時間程度
  • Sparkに仕事依頼中でも、別チャットや別タスクを同時実行可能
仕事を頼んでコーヒー飲んでる間に終わる。AIエージェントの醍醐味！

⑥利用できるプラン・条件

  • Google AI Pro または Ultraプラン（月額約3,000円以上）
  • 18歳以上であること
  • 個人のGoogleアカウントを使用していること
  • Geminiのアクティビティ保存がオンになっていること
⚠️ 法人アカウント（Workspace）や教育向けアカウントではまだ使えません

⑦利用できる環境

  • Web版 Gemini - ブラウザから利用可能
  • スマホ版 Geminiアプリからも利用可能
  • Mac版 デスクトップアプリ - ローカルフォルダーの設定も可能
スマホからSparkに仕事を頼んで、ほったらかしてOK！

⑧複数アプリを横断する作業

  • 例：メール受信 → AIで内容抽出 → 要約 → シートに保存 → 返信下書き作成
  • 人が複数アプリを切り替えていた作業を1つのタスクとして処理
  • 情報収集 → Googleドキュメントに保存 → Googleスライドで視覚化
  • ファイルの整理・分類作業も自動で可能
Gmail → シート → Gmail の行ったり来たりがゼロに！

⑨スケジュール①：時間ベース

  • 1回、毎日、毎週、毎月、毎年 から選択
  • 毎朝：カレンダーのスケジュール確認 → 本日の予定を通知
  • 毎週：最新のAI情報をリサーチ → ドキュメントに保存
  • 定期レポート作成、定期的な情報収集などに最適
月曜の朝6時に「過去3日間のAIニュースをまとめて」を自動実行！

⑩スケジュール②：Gmailモニター

  • 特定条件のメール受信をトリガーにして実行
  • 特定の送信者からのメールが届いたら自動起動
  • メール内容を分析 → 返信文の下書きを自動作成
  • 重要な情報を抽出してスプレッドシートに保存も可能
クライアントからのメールが来たら、返信下書きが出来上がってる。便利すぎ！

⑪スケジュール③：トピックモニター

  • 監視対象：ニュース、金融、スポーツ、地域イベント
  • 新しい情報が見つかったら通知してくれる
  • 超リアルタイム性には不向き（秒単位の即時対応は不可）
  • コンサートチケットの販売開始通知などには向いていない
「この日ぐらいにこういうニュースがありました」程度の情報提供に最適

⑫基本構造：タスク・スケジュール・スキル

  • タスク（最重要）：何をさせるか。ゴールの設定
  • スケジュール：いつ動くか。毎朝？毎週？特定条件時？
  • スキル：どうやってやるか。自分の文体や型を事前登録
  • スケジュールとスキルは必須ではない、必要に応じて追加
「何を」が中心。「いつ」「どうやって」はおまけ程度。まずはタスクから始めよう！

⑬初期設定：チュートリアルが自動で始まる

  • 最初に「Gemini Sparkの設定」というタスクが用意されている
  • 開始すると、連携しているGoogleアカウントの情報を自動で読み取る
  • Gmail、ドキュメント、スライド、スプレッドシートなどの利用状況を分析
  • 言語、職業、仕事内容、人間関係などを自動的にパーソナライズ
  • 自分にぴったりのおすすめタスクを提案してくれる
使い方が分からなくても、このチュートリアルだけで大体把握できる！

⑭実演①：タスク作成の流れ

  • Gemini Sparkの画面左上「新しいタスクを作成」から開始
  • 実演例：講義録のテキストを渡して、提案書とGoogleスライドを一括作成
  • 複雑な仕事なので10分〜30分程度かかる。クラウドで処理される
  • GoogleドキュメントとGoogleスライドの両方が自動生成される
1つの指示で提案書とスライドの両方が出来上がる。これがエージェントの力！

⑮実演②：画像入りGoogleスライドの自動生成

  • Gemini SparkにImagen 3の画像生成も指示可能
  • 「リサーチ内容をGoogleスライドにして、Imagen 3の画像を配置して」と指示
  • 編集可能なGoogleスライドに画像生成AIで作った画像が入った状態で完成
  • それなりのクオリティのスライドが自動で出来上がる
AI画像生成 + スライド作成を1つのタスクで完結！すごい時代になった

⑯自分の文体や仕事の型を「スキル」に登録

  • いつも使っている文体や表現の型を「スキル」として事前登録可能
  • 例：メールの文面を作る際、自分らしい文体で自動作成
  • スキルを適用するだけで、毎回統一されたトーンで出力される
  • タスク実行時にスキルを選択して適用する仕組み
毎回「こういう感じで書いてね」って言わなくていい。スキル登録が超便利！

⑰予約アクション・Workspace Studioとの違い

  • 予約アクション（通常Gemini）：シンプルな定期作業向け
  • Gemini Spark：複雑な仕事にスケジュールを追加できる
  • Workspace Studio：チーム・法人向けの業務自動化ツール
  • Gemini Spark：個人向けの仕事をサポートするAIエージェント
個人はSpark、チームはWorkspace Studio。用途で使い分けよう！

⑱ChatGPT Workとの比較とおすすめな人

  • できること：ChatGPT Workとほぼ同じ
  • 個人の感想ではChatGPT Workの方が成果物の精度は高い
  • SparkはGoogle連携がやや強み。どちらも好みの問題
  • おすすめな人：Googleサービスをガッツリ使う人、定期業務を自動化したい人、非エンジニア
