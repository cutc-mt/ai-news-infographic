Gemini Notebookの性能を格段に上げる
8つのカスタム指示

1度設定すればすべての回答に反映 — プロンプトが苦手な人にもおすすめ

2026年8月1日 ／ 21:43

① カスタム指示とは

  • 1度設定すれば全ての会話・生成物に反映される
  • 毎回プロンプトを打つ手間がなくなる
  • 初心者プロンプト苦手にもおすすめ
  • ノートブックの設定画面から登録する
毎回同じ指示を書かなくて済むから、本当にラクになるよ！

② 設定1: 新入社員教育担当

  • ベテラン社員の立場で回答を作る
  • 専門用語を例えに変換して説明
  • 3分で読める分量に収める
  • 新人が理解しやすい構成を自動で作る
専門用語を「例え話」にしてくれるから、新人でも分かりやすい！

③ 実演: 事業計画書を分析

  • 事業計画書をアップロードして分析
  • 解約率を「バケツの穴」に例えて解説
  • 水が漏れるイメージで顧客流出を可視化
  • 数字だけより圧倒的に分かりやすい
「バケツの穴」の例えで、解約率の問題がスッと腹落ちする！

④ 設定2: マークダウン表形式

  • 競合比較を表形式で出力
  • 星評価（★★★）を付けて視覚的に
  • 各項目の勝ち筋を明記
  • パッと見て強み・弱みが分かる
// 出力イメージ
| 項目 | 自社 | 競合A |
| 価格 | ★★★★★ | ★★★ |
表と星評価で、比較が一目で分かる！

⑤ 設定3: 信号機ダッシュボード

  • 緑: 順調な項目
  • 黄: 注意が必要な項目
  • 赤: 要対応の項目
  • 赤には今週やることを添える
色分けだから、どこが危ないか一瞬で分かる！

⑥ 設定4: 進捗ゲージ

  • 10マスのゲージで達成度を可視化
  • 例：████████░░ 80%
  • プロジェクトの進み具合が一目で分かる
  • 目標とのギャップも明確に
ゲージで見ると、「あとどれくらい」なのが超分かりやすい！

⑦ スタジオ機能とは

  • チャット以外の生成機能をまとめた場所
  • プレゼン資料
  • レポート
  • インフォグラフィック
  • 音声生成
チャットで相談するだけじゃない！スタジオで色々作れる！

⑧ 設定5: プレゼン資料

  • 銀行融資申し込みの資料を20枚で生成
  • スライドごとにデザインを指定
  • 表紙・目次・数値・まとめの構成も自動
  • 手作業なら数時間かかる作業が一瞬で
銀行融資の資料が、スライドデザインまで自動で作れる！

⑨ スライド生成のクオリティ

  • 現在最高峰レベルの生成品質
  • 色使いや表のデザインがそのまま使える
  • 手直しがほぼ不要
  • 実務で即戦力になるレベル
生成されたスライドが綺麗すぎて、そのまま使える！

⑩ 設定6: FAQレポート

  • 社外パートナー向けのリスク説明書
  • よく聞かれる質問を10問にまとめる
  • 聞かれる順に並べて回答
  • 事前のリスク説明に活用
パートナーから聞かれそうなことを、先回りしてまとめられる！

⑪ Googleドキュメント連携

  • ワンクリックでGoogleドキュメントに書き出し
  • チームでの共有がカンタン
  • 書き出し後に自由に編集可能
  • Google Workspaceとシームレスに連携
ワンクリックで書き出せるから、チーム共有もスムーズ！

⑫ 設定7: インフォグラフィック

  • 展示会用パネルとして活用
  • 3秒で目を引くデザインを生成
  • 通行人の足を止める訴求力
  • 情報を視覚的に整理して魅力的に
展示会で「3秒で惹きつける」パネルがAIで作れる！

⑬ カスタム指示で文字を絞る

  • ソースが多いと回答がごちゃごちゃする
  • 文字数を制限してスッキリさせる
  • 要点だけを抽出する指示
  • 読み手に負担をかけない回答に
「短くまとめて」と指示するだけで、劇的にスッキリする！

⑭ 設定8: 音声生成

  • 記者会見形式で音声を生成
  • 経済記者 × 広報責任者の対話
  • 通勤中でも耳で学べる
  • 自然な対話形式で臨場感あり
記者会見みたいな音声が作れるから、聞いていて面白い！

⑮ ポッドキャスト形式からの脱却

  • 従来のポッドキャスト形式から一歩進んだ使い方
  • 2人でテーマを設定して討論形式も可能
  • 目的に合わせて形式を自由に
  • 情報発信の幅が広がる
ポッドキャストっぽいだけじゃない！討論形式も作れる！

⑯ カスタム指示の保存場所

  • ノートブック設定画面を開く
  • 「カスタム」の項目へ進む
  • 指示文を登録するだけ
  • いつでも編集・更新可能
// 保存の手順
ノートブック設定 → カスタム
→ 指示文を入力 → 保存
設定画面の「カスタム」から登録するだけ、とってもシンプル！

⑰ 2つのカテゴリーで使い分け

  • チャット編: 会話で回答を得る
  • スタジオ編: 資料・音声などを生成
  • 8つのプロンプトを用途別に使い分け
  • 2つを組み合わせるのが最强
チャットとスタジオ、両方のプロンプトを使いこなそう！

⑱ Gemini基礎講座

  • ミキミIKブックスクールで基礎から学べる
  • Geminiの使い方を体系的に習得
  • 初心者でも安心して始められる
  • 今日から実務に活かせるスキルへ
基礎からしっかり学んで、Geminiを使いこなそう！
