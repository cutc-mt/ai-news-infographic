Gemini Notebooksで
自分専用の天才AI集団をつくる

カスタム指示とソース管理で、まるで優秀な部下を育てるようにAIを使いこなす

2026年8月1日 ／ 26:23

① Gemini Notebooksとは

  • Googleが提供するAIノートブック機能
  • 資料を読み込ませてAIと対話しながら分析
  • 読み込んだソースに基づいて回答を生成
  • notebooklm.google.com から無料で利用可能
自分の資料をAIに読ませて、質問したり分析させたりできるよ！

② 「天才AI集団」とは

  • 複数のAIを役割別に使い分ける概念
  • まるで優秀な部下を持つように活用
  • リサーチャー・ライター・レビューアー等
  • 一人の人がチームを率いる感覚
AIを1人だけじゃなく、チームで使うのがこの動画のテーマ！

③ Gemini単体 vs Notebooks

  • Geminiチャット：会話ベースで回答
  • Notebooks：ソース材料に基づいた回答
  • Notebooksは根拠が明確
  • ハルシネーションを抑制できる
Notebooksは資料に基づいて答えるから、ブレない回答ができる！

④ 設定の重要性

  • デフォルト設定のままではもったいない
  • カスタム指示で品質が格段に変わる
  • 1度設定すれば全ての会話に反映
  • 設定画面から簡単に登録できる
設定を変えるだけで、同じAIが別物みたいに賢くなる！

⑤ カスタム指示1: 役割定義

  • 「あなたは〇〇の専門家です」で人格を設定
  • 例：マーケティングの専門家
  • 例：データアナリスト
  • 役割が明確だと回答の精度が上がる
// 役割定義の例
あなたは中小企業診断士です。
事業計画書を専門家の視点で
分析し、改善点を指摘してください。
「あなたは〇〇の専門家」と書くだけで、回答の質が劇的に変わる！

⑥ カスタム指示2: 出力形式

  • 表形式で比較しやすく
  • レポート形式でまとめて出力
  • 箇条書きでスッキリ
  • 星評価（★★★）を追加するのも効果的
出力形式を指定すると、見やすい資料が一瞬でできる！

⑦ カスタム指示3: 制約条件

  • 専門用語を使わずに説明させる
  • 文字数制限で読みやすく
  • 対象読者を明確に指定
  • 初心者にも分かりやすい表現を徹底
「専門用語禁止」「500文字以内」など、ルールを決めるのがコツ！

⑧ ソース材料の活用

  • PDFをそのまま読み込ませる
  • WebサイトのURLを指定
  • YouTube動画もソースに可能
  • Googleドキュメントと連携
様々な形式の資料を読ませられるから、情報整理が超はかどる！

⑨ 複数ソースの組み合わせ

  • 複数の資料を同時に読み込ませる
  • 資料同士を統合して分析させる
  • 矛盾点や共通点を自動で抽出
  • 立体的な分析が可能に
まとめて読ませると、AIが複数の資料を横断して答えてくれる！

⑩ 「右腕」の作り方

  • 自分の仕事スタイルに合わせて育成
  • 普段の指示のクセを書き出す
  • それをカスタム指示として登録
  • 自分に一番合ったAIが完成
自分の働き方をAIに教え込むと、本当の「右腕」になる！

⑪ 定期タスクの自動化

  • 定期レポートの作成を自動化
  • データ分析もAIにお任せ
  • 同じ作業を繰り返し実行
  • 作業時間を大幅に短縮
毎週のレポート作成など、ルーチン作業をAIに任せよう！

⑫ チーム編成の考え方

  • リサーチャー：情報収集・分析担当
  • ライター：文章作成担当
  • レビューアー：品質チェック担当
  • 役割を分けると精度が上がる
Notebookを分けて、それぞれに役割を持たせるとチームになる！

⑬ Geminiチャットとの連携

  • Notebooksで作ったコンテンツを持ち出す
  • Geminiチャットでさらに洗練させる
  • 2つを行き来しながら作業
  • それぞれの得意分野を活かす
Notebooksで作って、Geminiで磨く。この往復が最強の組み合わせ！

⑭ 実用例1: 市場調査

  • 複数ソースから市場データを収集
  • 競合分析レポートを自動生成
  • 比較表で強み・弱みを可視化
  • 戦略の方向性を導き出す
競合の情報をまとめて読ませれば、分析レポートが一瞬で完成！

⑮ 実用例2: コンテンツ作成

  • 資料からブログ記事を自動作成
  • SNS投稿もまとめて生成
  • プレゼン資料も一瞬で
  • 目的に合わせて使い分け
一つの資料から、ブログもSNSも資料も全部作れる！

⑯ 実用例3: 学習・教育

  • 複雑な資料を初心者向けに要約
  • 分かりやすく解説してくれる
  • 新入社員の研修資料として活用
  • 学習のハードルを下げる
難しい資料もAIが噛み砕いて解説してくれるから勉強に便利！

⑰ 指示の保存と再利用

  • ノートブック設定画面から登録
  • 「カスタム」の項目へ進む
  • 1度作れば何度でも使える
  • いつでも編集・更新可能
// 保存の手順
ノートブック設定 → カスタム
→ 指示文を入力 → 保存
設定画面から登録するだけ。一度作ればずっと使える！

⑱ AI集団を運用するコツ

  • Notebookを目的別に作り分ける
  • 例：市場調査用・記事作成用
  • 定期的に見直しと改善を行う
  • 自分だけの最強AI集団を完成
目的ごとにNotebookを分けて、チームとして管理するのが成功の鍵！
