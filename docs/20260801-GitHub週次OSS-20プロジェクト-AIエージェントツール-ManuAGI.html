週次GitHubオープンソースプロジェクト20選

OpenWork · Bitchat · Box3D · Native SDK · Doku · Rayel他

📅 2026年8月1日 | Manu AGI

今週GitHubで注目を集めたオープンソースプロジェクトを厳選しました。AIエージェントのスキル共有、分散型メッセージング、3D物理エンジン、ローカル会議録画、コンテキスト最適化など、開発者の生産性を支える20の実用的プロジェクトを18枚のカードで紹介します。

①OpenWork: AIワークフローをクロスOSで共有

  • MacWindowsLinux 間でAIワークフローを共有するOSSデスクトップアプリ
  • MCPを1つ追加するだけで、Codex・Claude Code・Cursorでスキルやサービスを再利用可能
  • エージェントのワークフローをプラットフォームを超えて使い回せる
  • チーム間で構築したエージェント設定をそのまま共有
  • プロバイダー非依存で、複数のAIコーディングツールを統合的に管理
ツール間の切り替えコストをなくす！1つのワークフローを色々なエージェントで 🔄

②Last 30 Days: 複数ソースを横断検索するエージェントスキル

  • RedditXHNPolymarketGitHub を横断検索してブリーフを生成
  • 結果に引用付きで出力するため、情報の裏付けが明確
  • リアルなエンゲージメント指標でスコアリングを実施
  • 直近30日間のトレンドを素早く把握できるエージェントスキル
  • 調査結果を要約ブリーフとして構造化して提示
複数サイトを巡る手間をエージェントが肩代わり！引用付きで信頼性も高い 📊

③Kano: シンプルさ重視の自己ホスト型プロジェクト管理

  • OSS自己ホスト型のプロジェクト管理ツール。シンプルさを最優先
  • Docker ComposeHelmKubernetes に対応し、環境を選ばずデプロイ
  • スタックは ReactTypeScriptHonoPostgreSQL
  • 過剰な機能を省き、チームがすぐに使い始められる軽量さ
  • 自社インフラで完結するため、データは外部に漏れない
Jiraが重すぎるチームに最適！必要十分な機能でサクサク動く 📋

④BookToSkill: 技術書をエージェントスキルに変換

  • 本やドキュメントからフレームワークやパターンを抽出してスキル化
  • 内容を章ごとにファイル化し、エージェントが参照しやすい形に整理
  • Claude CodeCopilot CLIAMP に対応
  • 読んだ本の知識を、エージェントが実行できる再利用可能なスキルに変換
  • ベストプラクティスや設計パターンを構造化して保存
本棚の知識がエージェント経由で即戦力に！読書がそのままスキルに 📚

⑤GeoLibra: 軽量クラウドネイティブなデスクトップGIS

  • GeoJSONGeoParquetShapefile に対応するデスクトップGIS
  • 軽量かつクラウドネイティブな設計で、モダンな地図作業を実現
  • スタックは TauriReactTypeScriptMapLibre GL JS
  • プラグインシステムで機能を拡張可能
  • Python FastAPI サイドカーを内蔵し、高度な分析にも対応
QGISが重い人に嬉しい！モダンスタックでサクサク動く地図ツール 🗺️

⑥Bitchat: Bluetooth meshとNostrの分散型メッセージング

  • Bluetooth mesh + Nostr プロトコルで動く分散型P2Pメッセージング
  • アカウント登録不要で、すぐに使い始められる
  • エンドツーエンド暗号化でプライバシーを保護
  • iOSmacOS ネイティブアプリを提供
  • インターネット接続がなくても、近距離ならBluetoothで通信可能
災害時や圏外でも使える！サーバーがいらない真のP2Pチャット 📡

⑦Box3D: 依存ゼロのOSS 3D物理エンジン

  • C17で記述されたオープンソースの3D物理エンジン
  • 剛体シミュレーションで現実的な挙動を再現
  • 連続衝突判定で高速動作時の貫通を防止
  • マルチスレッド + SIMD で高速処理を実現
  • CMake 対応で組み込みやすく、依存関係はゼロ
cmake -B build && cmake --build build
依存ゼロは本当に珍しい！ゲームやシミュレーションに組み込みやすい 🎮

⑧Awesome LLM Apps: AIエージェント&RAGのテンプレート集

  • AIエージェントとRAGアプリのすぐ動くテンプレート集
  • マルチエージェント音声エージェントMCPエージェント など多彩な構成
  • Python 中心で、プロバイダー非依存の設計
  • OpenAI・Anthropic・Googleなど、好きなLLMに切り替え可能
  • 各テンプレートは学習材としても役立ち、ベストプラクティスを参照できる
ゼロから作る手間を省ける！クローンして少し書き換えるだけで動く 🌱

⑨Impeccable: AIコードのフロントデザインを改善するスキル

  • AIコーディングエージェントが作るUIのデザイン品質を引き上げるスキル
  • Claude CodeCursorGemini CLI 等にインストール
  • 46の決定論的ルールで、AI特有のデザイン問題を検出
  • 色のコントラスト、余白、タイポグラフィなど、細かな問題を指摘
  • 人力レビューの手間を減らし、一貫した見た目を自動維持
「AIが作った感」のあるデザインを撲滅！プロ並みのUIに仕上げる 🎨

⑩Shu: Mac向け完全ローカルの会議録画・文字起こし

  • メニューバーから1クリックで録音を開始できるMacアプリ
  • オンデバイスで文字起こしを行い、データは外部に送らない
  • Swift バイナリで軽量。Core Audio + Parakeet モデルを採用
  • 機密会議でも安心して使えるプライバシー重視の設計
  • クラウドAPI不要で、ネットワークがなくても動作
Otter等のクラウドサービスが使えない現場に最適！全部ローカルで完結 🎧

⑪Unsloth Zoo: LLM高速ファインチューニングの共有ユーティリティ

  • LLMの高速ファインチューニングを支えるライブラリの共通基盤
  • LoRA 4bit8bit でメモリ効率よく学習
  • DPOGRPO などの強化学習手法に対応
  • HuggingFace TRL互換で、既存のパイプラインをそのまま活用
  • Unslothの複数ツール間でユーティリティを再利用するための仕組み
Unslothの高速化ノウハウが詰まった共通基盤！学習コストを大幅削減 ⚡

⑫Mole & Disk Killer: Macを最適化する2つのユーティリティ

  • Mole: Mac向けのクリーン、アンインストール、分析、最適化、監視ツール
  • Moleは Homebrew で手軽にインストール可能
  • Disk Killer: アプリごとのディスク使用量をモニター
  • CPU・ディスクIO・ネットワーク・ファイル活動を個別に追跡
  • 両者ともローカル実行・テレメトリなしでプライバシーを保護
Macの重い原因を特定！容量不足や暴走アプリを素早く発見 🍎

⑬Hubble.MD: エージェントと共有するMarkdownノートパッド

  • エージェントとMarkdownノートを共有するノートパッド
  • Notion風エディタで、ブロック単位の編集が可能
  • スラッシュコマンドで素早く要素を挿入
  • エージェントがHTMLビューを構築して表示できる
  • 人間とエージェントが同じノート上でコラボレーション
メモとエージェント作業の境目が消える！共同編集が自然にできる 📝

⑭Native SDK: ブラウザ不要のネイティブデスクトップツールキット

  • ブラウザやWebViewを使わないネイティブデスクトップアプリ構築ツールキット
  • Zig ベースで、宣言的マークアップでUIを記述
  • 自動化サーバーを内蔵し、エージェントがアプリを操作可能
  • Electronのような重いランタイムが不要で、高速かつ軽量
  • エージェントフレンドリーな設計で、UIテストや自動化に最適
Electronの代替になるかも！Zigで書かれた真のネイティブアプリ 🖥️

⑮Doku: Dockerベースの自己ホストPaaS（Heroku代替）

  • Dockerを活用した自己ホスト型PaaS。Heroku代替として設計
  • BuildpacksDockerfile 両方に対応
  • UbuntuDebian のVMにデプロイ可能
  • git pushするだけでアプリをデプロイできる体験を、自前インフラで実現
  • クラウドPaaSのランニングコストを削減しつつ、柔軟性を維持
Herokuの料金に悩む人に！自サーバーでPaaS体験を再現 💰

⑯Desimon: 画面とカメラだけでファイルを転送

  • 光通信でQRファイル転送を実現するユニークな仕組み
  • 送信側の画面と、受信側のカメラだけでファイルを送信
  • フェウンテインコード化したQRアニメーションを連続表示
  • ネットワーク接続が不要で、エアギャップ環境でも機能
  • 物理的に隔離された端末間でのデータ移行に最適
セキュリティの厳しい現場で活躍！Wi-FiもBluetoothも不要 ✨

⑰Open Slides: コードをアニメーションスライドに変換

  • ソースコードからアニメーション付きスライドを生成するデスクトップアプリ
  • ステップハイライトで、コードの実行順に沿って注目箇所を強調
  • マジックムーブ遷移で、要素が滑らかに移動するプレゼンを作成
  • スタックは TauriRustReact
  • アルゴリズムの解説やコードレビューの資料作成に最適
コード解説動画が簡単に作れる！講師や技術ブログ執筆者に嬉しい 🎬

⑱World Model Optimizer & Rayel: エージェントを最適化する2つのCLI

  • World Model Optimizer: エージェントのトレースからモデルを継続改善するCLI
  • プロバイダー登録、ルーティングポリシーのチューニング、シミュレーション最適化を搭載
  • Rayel: コンテキストウィンドウに入るツールを選択するプラットフォーム
  • Rayelは BM25 で検索し、ベクトルDB不要を実現
  • Rayelの構成は Rust core + TypeScript SDK
エージェントが賢くなる仕組み！ルーティングもコンテキストも最適化 🎯
