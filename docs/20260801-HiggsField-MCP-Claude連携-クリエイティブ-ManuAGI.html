① Higgs Field MCPとは

ClaudeやChatGPTのチャット画面から、Higgs Fieldのクリエイティブモデルに直接アクセスできるMCP接続機能です。

  • MCP（Model Context Protocol）でAIと外部ツールを接続
  • 動画・画像・音声の生成がチャット内で完結
  • ツールの切り替えが不要に
これまで別々だったクリエイティブツールを、
ひとつの会話に統合できる！

② ツール切替の煩わしさを解消

従来は画像生成サイト、動画生成サイト、音声生成サイトを個別に行き来する必要がありました。

  • 画像生成：別タブでプロンプトを入力
  • 動画生成：また別のサイトに移動
  • 音声生成：さらに別のプラットフォーム
タブを何個も開いて、プロンプトを
コピペし直す作業から解放される 🎉

③ セットアップは簡単4ステップ

ClaudeにHiggs Fieldのコネクターを追加する手順はわずか4ステップで完了します。

  • Settings（設定）を開く
  • Connectors → Custom Connector を追加
  • Higgs FieldのURLを貼り付け
  • アカウントに接続して完了
複雑な設定は不要。
数分で使い始められる！

  • 音声入力でナレーション付き動画も
  • マルチショット動画をネイティブ音声同期で生成
複数ショットをつなげて、
長尺シーンも作れる！
