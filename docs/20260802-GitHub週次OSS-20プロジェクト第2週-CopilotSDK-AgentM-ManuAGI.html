週次GitHub OSSプロジェクト20選（第2週）

Manu AGIが厳選した注目のオープンソース開発ツール
2026年8月1日

①GitHub Copilot CLI SDK: エージェントを組み込む

  • マルチプラットフォーム 6言語に対応
  • Python、TypeScript、Go、.NET、Java、Rust向けに提供
  • Copilot CLIと同じエンジンを自分のアプリに埋め込める
  • 計画・ツール呼び出し・ファイル編集をCopilotが自動処理
開発者がやることは「振る舞いを定義」だけ。残りはCopilotにおまかせ！

②Chatwoot: オムニチャネルでサポート統合

  • Intercom代替 Zendeskの置き換えも
  • ライブチャット・メール・WhatsApp・Instagramを1つの受信箱に集約
  • AIエージェント「Captain」とヘルプセンターを内蔵
  • Rails + Vue製で、データは自社で管理できる
SaaSに縛られない。データは自分のものという安心感！

③Pascal Editor: ブラウザで3D建築設計

  • WebGPU React Three Fiberで構築
  • 壁・床・屋根・ゾーンをブラウザ上で直接描画できる
  • ドア・窓・家具の配置も対応。プラグイン式で拡張可能
  • 公開可能なビューアパッケージを同梱
インストール不要でブラウザから設計開始。建築の民主化だ！

④Instatic: クリーンなHTMLを出力するCMS

  • 自ホスト型 ビジュアルCMS
  • リアルなマルチブレークポイントキャンバスで設計
  • 完成物は意味的なHTMLとコンパクトなCSSとして出力
  • SQLiteまたはPostgres対応。1つのBunサーバーで完結
ノーコードの手軽さとクリーンな出力を両立した！

⑤Orca: コーディングエージェントを並列実行

  • IDE 並列エージェント開発環境
  • Claude Code、Codex、Cursorに対応。各エージェントが独立したgit worktreeを使用
  • ターミナル、VS Codeエディタ、差分レビューを統合
  • SSHワークツリーとモバイルコンパニオンも同梱
複数のAIエージェントを同時に走らせる新しい開発スタイル！

⑥Speech-to-Speech: モジュラー音声エージェント

  • Hugging Face製 パイプライン構成
  • 音声検出 → 音声認識 → LLM → 音声合成をチェーン接続
  • 各ステージが交換可能で柔軟性が高い
  • OpenAIリアルタイム互換APIで利用できる
LLMはホスト型・ローカルVLM・llama.cppサーバーから自由に選べる！

⑦Vibe Trading: 自然言語で金融分析

  • 研究用 トレーディングワークスペース
  • 自然言語の質問を実行可能な分析に変換
  • 市場データローダー、バックテスト、レポート、メモリを接続
  • 株式・暗号・先物・FXでマルチエージェントチームが稼働
実取引は許可したブローカー経由のみ。安全設計！

⑧Turbo-Fieldfare: Gemma 4 26Bを8GBで実行

  • Swift/Metal Apple Silicon最適化
  • Gemma 4 26B（A4B）を8GB RAMのMacでも実行可能
  • コアとKVキャッシュを常駐させ、トークンごとのエキスパートをSSDからストリーミング
  • MacアプリとCLIの両方を提供
モデル全体をメモリに読まない工夫が秀逸！

⑨General Translation: Reactアプリを自動で国際化

  • i18n React向け自動翻訳ツール
  • 辞書へのリファクタリング不要。コンポーネントをタグで囲むだけ
  • Next.js、React、素のJavaScript向けパッケージを提供
  • CLI、ビルドプラグイン、MCPサーバーも同梱
文字列だけでなくコンポーネント全体を翻訳する新アプローチ！

⑩Harkinian Pad: ゼルダをiPhone/iPadへ

  • iOS移植 Ship of Harkinianベース
  • 時のオカリナをネイティブのiPhone/iPadアプリとして提供
  • 横画面タッチコントローラー、キーボード、ポインター、コントローラー対応
  • ROMフリーで再現可能なビルド。自分のROMを取り込み
Metalレンダリングでスマホで名作をプレイ！

⑪ntfy.sh: HTTPリクエストだけで通知送信

  • 超シンプル pub/sub通知サービス
  • PUTやPOSTリクエストだけでスマホやデスクトップに通知
  • トピックを購読すれば受け取り完了。登録不要
  • オープンソースのAndroid/iOSアプリ。Goサーバーも自ホスト可能
curl一行で通知が送れる手軽さが最高！

⑫lichess.org: フリーのチェスサーバー

  • 広告なし 完全無料のチェスサーバー
  • リアルタイム対戦に特化した使いやすさが魅力
  • StockfishとFishNetによるコンピューター解析
  • 大会、パズル、学習、フォーラム、APIを140以上の言語で提供
Scala + TypeScript製。自分でもチェスサーバーを構築可能！

⑬Persona: 音声チャット用の3Dキャラ

  • VRMアバター リアルタイム3Dキャラ
  • アプリの音声出力を聴き取って表情豊かにアニメーション
  • マイクをキャプチャせず、音声を外部に送信しない設計
  • フローティングウィンドウで表示。MCPサーバー経由で接続
音声だけの会話に顔と表情を添える体験！

⑭Numbat & H-Newswear: エージェント監視とHN連携

  • Perplexity製 NumbatはAIエージェント監視
  • デスクトップ・CLI・IDE・ゲートウェイのエージェント活動を可視化
  • 危険な挙動を検出し、事前ブロックも可能
  • H-Newswearは記事の横にHacker Newsの議論を表示するユーザースクリプト
NumbatはGoバイナリ1つで動く。エージェントの用心棒！

⑮Miridor: ターミナルで常に開くダッシュボード

  • Rust/Ratatouille ターミナルUI
  • 世界時計・カレンダー・天気・タスク・メモ・市場・CPUを8パネルで配置
  • アカウント登録もAPIキーも不要なのが嬉しい
  • すべてプレーンなTOMLで設定できる
ターミナルのタブに置きっぱなしで使う設計！

⑯Kim K3 MLX: MoonshotのモデルをApple Siliconへ

  • 2.78兆パラメータ マルチモーダルMoE
  • テキストとビジョンの両方を提供するMLXポート
  • モデル全体を読まずに量子化するストリーミングコンバーター
  • 言語やドメインごとにエキスパートを刈り込む機能
標準のMLX-LMで動く。Macで巨大モデルを試せる！

⑰Temporal Ruby SDK & Open Science

  • 耐久性ワークフロー Temporalの公式Ruby SDK
  • ワークフローとアクティビティをクラスとして定義可能
  • Open Scienceは研究者向けのデスクトップAIワークベンチ
  • 自然言語でタスクを記述すると、コード実行やライフサイエンス連携を実行
TemporalはRustコア採用。Open Scienceはモデル非依存！

⑱AgentM: Firecrackerサンドボックスを大規模に

  • 分散プラットフォーム エージェントサンドボックス
  • 多数のFirecrackerマイクロVMを複数マシンで実行
  • OCIイメージをオンデマンドで読み込み、スナップショットとフォークで並列化
  • E2B互換APIとCLIを提供。Kimi K3のRL訓練でも使用
実際の大規模AI訓練を支える本番級のインフラ！
