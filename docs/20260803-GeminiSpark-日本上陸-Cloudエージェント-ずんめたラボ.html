Gemini Spark が日本上陸

閉じても動く クラウドのAIエージェント — ずんめたラボ
2026年8月3日

①Gemini Spark が日本に上陸

  • 提供拡大 対象が 160カ国以上 に広がりました
  • 日本でも使えるようになり、日本語にも対応
  • ずんだもんとめたんが わかりやすく解説
ついに日本で！まずは試してみるのが大事なのだ

②これまでのAIと何が違う？

  • これまでは 「開いて・聞いて・閉じる」 道具だった
  • Spark は 閉じていても動き続ける のが最大の違い
  • 「使うときだけ呼ぶ」から「ずっと置いておく」へ変化
パラダイムが変わったのだ！ここが 本質 なのだ

③クラウド基盤で動き続ける

  • PC を閉じていても動く
  • スマホがロックされたままでも OK
  • 処理は Google のクラウド側で進む
自分の端末じゃなくて 雲の上 で動くのだ！

④自分から起動する 動き方

  • 特定の話題のメールが来たらトリガーで起動
  • 指示を待たず 先回りで処理 を進める
  • 「言われたことだけ」から「予測して動く」へ
こっちが気づく前に やっておいてくれる のが凄いのだ

⑤「呼ぶ道具」から「置く道具」へ

  • 核心概念 Gemini Spark の一番大事な言葉
  • 今まで：必要なときに「呼ぶ」
  • これから：いつでも動くように「置いておく」
この一言で 全部が腑に落ちる のだ！

⑥AI Ultra / AI Pro 向けに提供

  • AI Ultra と AI Pro のプランで利用可能
  • プランによって使える範囲が違う
  • 自分のプランで動くか、まずは確認を
高めのプラン向けだから 設定を見直そう なのだ

⑦使えるかの 確認方法

  • Gemini のサイドバー上部を見る
  • チャットとエージェントの 切り替えスイッチ がある
  • スイッチがあれば、もう使える状態
まずは スイッチがあるか 探すのだ！

⑧チャットとエージェントの違い

  • チャットは 「話し相手」
  • エージェントは 「留守番を頼める人」
  • 答えてもらうか、作業を任せるかの違い
雑談相手より 頼れる助手 になったのだ

⑨Tasks：作業を 任せる

  • 公式3要素 その1
  • Workspace に繋いで仕事をさせる
  • メール整理やドキュメント作成などを代行
Gmail や Docs と 連携 して動くのだ！

⑩Skills：動き方を 自分で定義

  • 公式3要素 その2
  • よくやる操作のやり方を自分で教える
  • 一度覚えさせれば何度でも同じように動く
私の手順を そのまま覚えさせる のだ！

⑪Schedules：時刻で 自動実行

  • 公式3要素 その3
  • 決まった時刻に動かす
  • 条件を満たしたら起動、と組み合わせも可
毎朝のニュース収集とか 放っておける のだ

⑫連携できる サービスいろいろ

  • Google 系（Gmail・Calendar・Docs 等）
  • Canva・Dropbox・OpenTable などサードパーティ
  • 独自 MCP サーバ も接続可能
自分好みに 繋げられる のが強みなのだ！

⑬Chrome 統合で 代行予約

  • ログイン済みアカウントと保存パスワードを使う
  • 内見予約やフライト予約を代行
  • ブラウザの画面を操作して、人間の代わりに進める
予約作業まで 任せられる のは大きいのだ

⑭日本にまだ来てない 機能

  • Chrome 統合は 「まずは米国から」
  • 日本では 順次展開 される見込み
  • 今は Tasks・Skills・Schedules から試すのが現実的
全部はまだ無いけど 来る途中 なのだ！

⑮安全設計①：連携は 既定でオフ

  • サービス連携は 最初はオフ
  • 自分が意図してオンにしたものだけ動く
  • 勝手に繋がる心配は 設計段階で防ぐ
デフォルトで安全、安心設計 なのだ！

⑯安全設計②：重要操作は 確認

  • 支払いの前には必ず確認が入る
  • メール送信の前にも事前チェック
  • 取り返しのつかない行動を 人間が承認
お金や送信は 止めて確認 してくれるのだ！

⑰安全設計③：インジェクション対策

  • プロンプトインジェクション への対策あり
  • 悪意ある指示で 騙されにくく なっている
  • 3つの安全設計で 段階的に守る
攻撃への備えも 忘れてない のが地味に大事なのだ

⑱明日から試す 3ステップ

  • まずは 1つの Schedule を組んでみる
  • 小さな自動化で 動きを確かめる
  • 慣れたら Skills・Tasks に 広げていく
まずは1つ！小さく始めるのが正解なのだ！
