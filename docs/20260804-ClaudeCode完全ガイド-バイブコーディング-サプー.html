Claude Code 完全ガイド

〜バイブコーディングで、家計簿アプリをつくろう〜
2026年8月4日 ｜ サプー（Python VTuber）

① Claude Codeとは

  • Anthropic社の、コーディング特化AIエージェント
  • ターミナル（黒い画面）で動く。ファイルの読み書きも自分でこなす
  • 日本語で話しかけるだけで、コードを書き・直し・動かす
  • 「AIに つくらせる」新しい プログラミングの かたち
ターミナルで はなしかけるだけで、
アプリが できあがる魔法 🔮

② バイブコーディング

  • 自然言語（ことば）で 指示するだけで、アプリ開発が 進む
  • 「こんな感じで」の バイブ（雰囲気）を AIが読み取る
  • 細かい文法を 覚えなくても OK。意図が 大事
  • プログラミング未経験でも、アイデアを形にできる
ことばで オーダーするだけ。
まさに 新しい開発の 波 🌊

③ ほかのAIエージェントとの 比較

  • Codex／Copilot：エディタ内 補完タイプ
  • Gemini CLI：Google版の ターミナル仲間
  • Claude Codeは 自律的に ファイル操作までこなす点が 強み
  • 選び方の 目安：用途と 好みで 使い分け
どれも 強い。Claude Codeは
「おまかせ度」が 高い ⚡

④ 料金プラン

  • Pro：月額 $18。個人で じゅうぶん使える
  • Max：$110／月 〜。使い込み派 向け
  • API従量課金：使った分だけ お支払い
  • まずは Proで 体感するのが おすすめ
はじめは おてがる Proから。
のめり込んだら Maxへ 🐷

⑤ インストール手順

  • ターミナルを 開いて、コマンドを 1行 実行するだけ
  • クロードの アカウントで ログインして ひもづけ
  • 認証が すめば、すぐに つかえるように 
$ npm install -g @anthropic-ai/claude-code
$ claude   # 起動して ログイン
準備は かるい。あとは
ことばを 打つだけ 🚀

⑥ 基本的な 操作の 流れ

  • プロンプト（指示）を 日本語で 入力
  • AIが コードを 生成して こちらに 提示
  • 人間が 承認（よければ OK）
  • 承認されたら、ファイルに 書き込んで 実行
人間の「承認」を はさむから、
まかせっぱなしでも あんしん ✅

⑦ モデルの 選び方

  • Haiku：高速・軽量。サクサク 動かしたい ときに
  • Sonnet：標準。バランス良く なんでも こなす
  • Opus：高精度。むずかしい 課題に
  • 考え方（速さ vs くわしさ）で 使い分け
はやさ・ふつう・くわしさ。
3段階で えらべる 🎚️

⑧ 動作モード（4つ）

  • 確認モード：都度 人間が 承認。一番 あんしん
  • 自動編集：編集は おまかせ。実行は 別途
  • プラン：まず 計画だけ。承認してから 進む
  • フルオート：人間を見守り役に。高速
まずは「確認」で ならって、
だんだん まかせていく 💡

⑨ セッション管理

  • 会話は セッション単位で まとめて 保存
  • /exit：今の会話を 終了（残しておける）
  • /resume：前回の続きから 再開できる
  • 途中でやめても 文脈を 取り戻せる
きのうの続きを、きょう。
しおりを はさむ感覚 📖

⑩ 家計簿アプリを つくる

  • プランモードで、まず 機能を 洗い出す
  • 「入力」「一覧」「集計」など 要件を 可視化
  • 計画が 決まったら、ステップごとに 実装へ
  • 本動画の メイン教材：お金の 記録を つける アプリ
まずは「なにをつくるか」
まとめるのが コツ ⚡

⑪ 段階的に つくる コツ

  • 一度に 全部を たのまない。失敗の もと
  • ステップ1→2→3→4で すこしずつ
  • 1つ 動かして 確認、つぎへ 進む リズム
  • 小さく まとめるほど 成功しやすい
いっきに すすまず、
かめの ほうが はやい 🐢

⑫ テストコード

  • アプリの 品質を 保つ ための 検査
  • カバレッジ測定：どれだけ 担っているか 可視化
  • テストを 書いておくと 壊れにくく なる
  • テストの 作成も、AIに まかせられる
かくれた バグを つかまえる、
アプリの ぼうぐ 🛡️

⑬ Gitで バージョン管理

  • コミット＝セーブ。いい状態を 残しておく
  • いつでも 前の状態に 戻れる 安心感
  • 実装の くぎりごとに 保存する 習慣が 大事
  • Git操作も Claude Codeに まかせて 楽らく
こわしても もとに 戻る。
ゲームの セーブ地点 🎮

⑭ CLAUDE.md

  • プロジェクトの 取り扱い説明書
  • AIが 自動で読み込む。毎回 教え直す 不要
  • ルール・構成・好みの 進め方を 1枚に まとめる
  • 書いておくほど、AIの 見当違いが 減る 
# CLAUDE.md
このプロジェクトは家計簿アプリ。
- Pythonでつくる
- テストを必ず書く
あらかじめ 書いておけば、
AIが きき手に 💡

⑮ スラッシュコマンド

  • /rewind：会話を 巻き戻す（やりなおし）
  • /compact：文脈を 圧縮（長くなりすぎた ときに）
  • /security-review：安全の あやまりを チェック
  • 「/」で 呼べる かんたん操作の 数々
「/」を 打つだけで、
裏技が つかえる 🪄

⑯ MCPサーバー

  • 外部の サービスと 連携する しくみ
  • Playwright：ブラウザを 自動で 動かせる
  • データベース・APIとも、つなげて 利用
  • できることの 範囲が ぐっと 広がる
プラグを さすだけで、
AIが 世界と つながる 🧩

⑰ Skills 機能

  • 作業の 手順を マニュアル化して 再利用
  • 一度 まとめれば、なんども 教えなくて OK
  • マーケットプレイスで、人と 共有できる
  • 他人の Skillを 取り込んで 時短も
くりかえしを、スキルに。
ふえる・わける・ つたえる 🔄

⑱ セキュリティと サンドボックス

  • settings.jsonで、できることを きびしく 制限
  • 権限（アクセス範囲）を こまかく 設定できる
  • サンドボックスで 隔離。外に 影響を 与えない
  • あんしんして、まかせられる 環境づくり
危ない操作は さえぎり、
あんしんの 仕切りを 🛡️
