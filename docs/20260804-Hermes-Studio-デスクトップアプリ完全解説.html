セクション1：Hermes Studioの概要と基本

①Hermes Studioとは？

  • Hermes Agentを、もっと使いやすくするためのデスクトップアプリ
  • ターミナルやコマンドではなく、GUIで直感的に操作できる
  • Hermesをゴリゴリ使う人に、便利な選択肢を提供
コマンド不要で、
Hermesを扱える！💡

②Mac/Windows/Linux対応

  • Windowsでも、Macでも動く
  • Linuxにも対応、環境を問わない
  • 自分の好きなOSで、そのまま使える
どの環境でも、
動くのが嬉しい ✨

③Hermes Agentの GUIフロント

  • もともとCUIで動くHermes Agentの、人間向けの窓口
  • 人間が操作しやすいインターフェースとして優秀
  • 裏側はHermesが動き、表側はStudioが整える
人間にやさしい、
操作画面 ⚡

④チャット機能の基本

  • Hermes Agentと、普通にチャットできる機能
  • 普段のAIチャットと同じ感覚で、対話ができる
  • 難しい操作なし、すぐに使い始められる
いつものチャット感覚で、
Hermesと話せる 💡

⑤プロジェクトパスを選択

  • チャットごとにプロジェクトパスを選べる
  • 作業対象のフォルダを、ひもづけて指定
  • Hermesが、その範囲でファイルを扱える
対象を明示して、
仕事を任せる 📁

⑥モデル・プロバイダー選択

  • Grok 4.5など、好きなモデルを選べる
  • プロバイダーも切り替え可能
  • 用途に合わせて、最適な構成を選択
好きなモデルを、
すぐ切り替え 🔧
