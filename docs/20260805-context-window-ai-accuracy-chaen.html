AIの精度が落ちる本当の理由

入力が長くなるほどボケる…その現象の原因と、すぐ効く4つの対策

チャエン【AI研究所】 プロンプト工学 約1分で分かる

① 落ちる原因は「窓」にあり

  • AIが賢くないと感じる本因
  • その正体はコンテキスト窓
  • 入力が長いほど精度が低下
  • 仕組みを知れば対策は簡単
モデルのせいじゃない！
入力の「詰め込みすぎ」が原因💣
見直そう

② コンテキスト窓とは

  • AIが一度に読める量のこと
  • 窓の大きさには限界あり
  • 会話・資料・前回返答も全部格納
  • この枠を超えると挙動が怪しくなる
つまり「作業机」
机が狭いと書けないのと同じ📖
基本概念

③ 机の上に全部積まれる

  • 過去の会話も載る
  • 渡した資料も載る
  • AI自身の返答も載る
  • 全部が同じ場所に混在
会話が続くほど
机の上が散らかっていく📦
要注意

④ 18モデルで検証済み

  • 18種類のモデルで実験
  • 入力長と精度低下の相関を確認
  • 全モデルで同じ傾向
  • モデル違いでも共通の問題
18 / 18 モデル全てで精度低下を確認
特定モデルだけじゃない！
普遍的に起きる現象🔬
研究結果

⑤ 真ん中の情報が消える

  • 冒頭と末尾は覚えやすい
  • 中間に書かれた内容はスルーされがち
  • 正答率が急落する場所
  • これが「Lost in the Middle」
75% → 57% 冒頭の正答率から真ん中で急落
重要な指示は
真ん中に置かないのが鉄則🎯
最重要

⑥ 「真ん中迷子」現象

  • 論文で名付けられた有名現象
  • 長文の中央部が抜け落ちる
  • 情報の連続性が途切れる
  • この名前を覚えておくと便利

⑦ トークン数と精度の関係

  • 文章はトークンという単位で処理
  • トークン数が増えるほど精度が下がる
  • 「量」より質が重要
  • 無駄なトークンは削る価値あり
# トークン＝AIの言葉の単位
"りんご" → [り, ん, ご]
# 短く伝える方が精度が上がる
長文は敵！
シンプルに伝えるのが勝ち✂️
削る勇気

⑧ 対策1：新チャットを開く

  • 話題が変わったら新規チャット
  • 机を綺麗に掃除する感覚
  • 古い履歴の悪影響を遮断
  • 一番簡単で効果的
めんどくさがらずに！
「＋」ボタンを押す癖を🧹
即効性あり

⑨ 対策2：要点を引き継ぐ

  • 長引いたら要点だけメモ
  • 新しいチャットに貼り付け
  • 不要な会話は捨てる
  • 「決めたこと」「残課題」を残す
# 引き継ぎメモの例
決定: 記事は「3章構成」
次回: 冒頭文を「作成」
引き継ぎメモで！
文脈をコンパクトに運ぶ📋
中級テク

⑩ 対策3：資料は必要な分だけ

  • 資料をそのまま全投げしない
  • 必要箇所だけ切り出す
  • 要約や表形式に整える
  • 目的に合う情報だけ精査
全文コピペは厳禁！
必要な所だけ抜き出す📄
作業効率UP

⑪ 対策4：大事な指示は最後に

  • プロンプトの末尾が最も注目される
  • 「〜して」は最後に書く
  • 真ん中迷子を回避できる
  • 冒頭は背景、末尾は命令
# 良いプロンプトの順序
1. 背景・前提を述べる
2. 資料やデータを貼る
3. 最後に命令を書く ✓
順番を変えるだけ！
無料で即効果が出る📣
必須テク

⑫ 実践的なプロンプト設計

  • 指示は箇条書きで簡潔に
  • 役割を先に与える
  • 出力形式を明示
  • 曖昧さは削り取る
設計次第で！
同じモデルでも結果が変わる✍️
設計力

⑬ チャット履歴の整理術

  • テーマごとにチャットを分ける
  • タイトルを分かりやすく命名
  • 重要な会話は保存・固定
  • 終わった話題は潔く削除
整理整頓で！
探す時間も激減する🗂️
習慣化しよう

⑭ コンテキスト圧縮の重要性

  • 情報を凝縮して伝える
  • 表や箇条書きで密度を上げる
  • 処理速度も向上
  • トークン＝コスト、節約にもなる
詰め込みすぎず！

  • 冒頭に置けば認識しやすい
  • 繰り返し入力の手間を削減
