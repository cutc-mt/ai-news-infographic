導入

①ターミナルで動く、コマンド1行

  • Muse Codeは黒い画面の中で動く。GUI画面を持たない
  • 入れ方はコマンド1行。あっという間に準備完了
  • 対応OSは macOS と Linux。今のところ Windows は別
  • 専用アプリが要らない、その分軽くて速い
起動画面すらない。けれど、その分素早く呼べる！
導入

②CodexやClaude Codeのような画面はない

  • 専用のアプリ画面を開かない。CLI一本で進む
  • 派手な UI より、実利を優先する設計
  • マウス操作より、キーボード中心の作業に合う
  • 地味に見えて、裏はかなり動くのが特徴
見た目より中身。エンジニア向きの硬派な作り！
仕組み

③実装役が並列、レビュー役が回る

  • 実装担当が、複数の作業を並行して進める
  • その横で レビュー役 が、ぐるぐると回り続ける
  • 書く人と見る人が分かれている。これが精度の源
  • 直列で待つ時間を、どんどん消化していく
分業が自动で回る。まるで小さなチーム！
仕組み

④セッションを越えて記憶が生きる

  • セッションを変えても、前の作業を覚えている
  • 「毎回、覚え直し」が起きないのが大きい
  • 数日前の相談も、途切れず参照できる
  • 文脈が残る分、指示の手間が減る
一から説明し直す手間が消える。これが嬉しい！
仕組み

⑤全部の動きが記録に残る

  • どの モデル を呼んだか、すべて残る
  • どの 道具 を使ったか、こちらも記録
  • どこで 承認 したかも、はっきりと
  • 何を書き換えたかまで、丸わかり
見直したい時にすぐ戻れる。透明性が高い！
中身

⑥中身はMuse Spark 1.2

  • コードを書くのは Muse Spark 1.2。最新の頭脳
  • Muse Code と 一緒に訓練 された組み
  • 一度に 100万トークン まで扱える
  • 長いファイルも、丸ごと読める余裕
専用の学習で鍛えた組み。だから相性がいい！
本題

⑦料金は「二つの段」に分かれる

  • 同じモデルなのに、値段は2段階に分かれる
  • 標準段：学習に使われない、安心な方
  • 貢献する側：安い代わりに、やりとりを提供
  • 性能は同じ。差は「扱い」だけ
安いから劣る、じゃない。ここがミソ！
標準段

⑧標準段：学習に使われない

  • 入力も出力も、学習データに使われない
  • 入力は 100万トークン$1.25
  • 出力は 100万トークン$4.25
  • 仕事やお客さんのコード向け
入力 $1.25 / 1M
出力 $4.25 / 1M
外に漏らさない。これが本命の段！
安い段

⑨貢献する側：圧倒的に安い

  • 入力は $0.10、出力は $0.20（100万トークン）
  • 代わりに、やりとりを Meta の学習に 使わせる
  • 性能は標準段とまったく同じ
  • 練習や公開予定のコードなら十分
入力 $0.10 / 1M
出力 $0.20 / 1M
コスパ最強。ただし、データは共有する！
差を見る

⑩入力12.5倍、出力21倍の差

  • 入力で 12.5倍 の開き
  • 出力はさらに大きく、21倍 に開く
  • これだけ違うのに、中身は同じ
  • 差の理由は 性能ではなく、扱い

なぜ安い

  • 安い段のやりとりは、モデル改善のネタになる
  • ユーザーの作業が、そのまま学習データに
  • 性能で負けているわけでは一切ない
  • 「データを渡す見返り」が、値段の差
安さの裏には、値踏みがある！
