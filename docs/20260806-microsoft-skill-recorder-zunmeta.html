Skill Recorder とは何か

①録画する だけ

  • やることは、いつもの作業を 画面ごと録るだけ
  • しゃべりながら解説しても OK。その 文字起こし も残る
  • コードを書いたり、設定をいじる 必要はない
録画ボタンを押して、いつも通り作業するだけなのだ

②GitHub で 無料公開

  • MIT ライセンス で公開中
  • 商用利用も OK。会社でも使える
  • 出しているのは Microsoft 公式
  • リポジトリ: microsoft / skill-recorder
Microsoft 謹製が 無料・商用OK で手に入るのだ

③録画が 手順書に

  • GitHub Copilot が録画を読み込む
  • 「結局 なにがしたかったのか」という意図を汲む
  • 「何をどの順で」を 手順に起こす
  • AIエージェントが そのまま実行できる "スキル" になる
録画 → 意図理解 → 手順化、全部 AI がやるのだ

録画から スキル化 までの 4ステップ

④Step1: 録画する

1 いつもの作業を 画面ごと録画
  • 録画ボタンを押して、ふだん通りに作業
  • 声で解説を入れてもよい（文字起こし つき）
  • 録画データは 手元のPCに保存
特別な準備はいらない。いつも通り動くだけなのだ

⑤Step2: 分析する

2 「分析」ボタンを 押す
  • 外に出るデータは この瞬間だけ
  • 渡るのは 手順の記録 + 画面の画像
  • パスワードや APIキーは 絶対に映さない（警告あり）
送信されるのは分析ボタンを押した 1回だけ なのだ

⑥Step3: 意図を 読み取る

3 Copilot が 意図と手順に起こす
  • 「なにがしたかったのか」意図 を解釈
  • 「何をどの順で」手順 に展開
  • エージェントが 元から持つ道具 を優先して使う
クリックを再生するんじゃない。意図を読む のだ

⑦Step4: スキル に

4 AIエージェントが 実行できる "スキル"
  • できあがった手順は そのまま再利用 できる
  • 同じ作業なら 2度目から録画不要
  • 種類は Skill と Automation の2種
一度スキル化すれば、あとは AI が勝手に回すのだ

従来の マクロ・RPA と 決定的に違う点

⑧従来: 座標 で覚える

昔のマクロ

画面の「どこを押したか」を 座標 で記録
  • ボタンの位置が 少しずれただけ で壊れる
  • やることは 同じ動作の再生 だけ
  • 「こうしたかった」ではなく 「ここを押した」 しか残らない
UIが変わったら、全部作り直し。もろいのだ

⑨Skill Recorder: 意図 で動く

Skill Recorder

クリックは再生せず 意図 を使う
  • エージェントが 元から持っている道具 を優先
  • ボタンがずれても 意図が同じなら動く
  • 「何をしたかったか」を 抽象化 して持つ
位置じゃなく 意図 を記録。ここが最大の違いなのだ

⑩1つから 一般化

  • 1つの例から パターンを学ぶ
  • フォームを 1枚 出す ところを録るだけで
  • 同じ種類のフォームは 全部出せる ようになる
  • 特定の1回だけでなく 類似作業全体 をカバー
1回録れば、仲間全体に 効く のだ。これが一般化なのだ

プライバシー の 設計

⑪手元のPCで 完結

  • 録画 は手元のPCの中だけ
  • 保存 もすべてローカル
  • しゃべった解説の 文字起こし れもローカル
  • 普段は 外に何も出ない
なにもしなければ、データは 1ミリも外に出ない のだ

⑫外に出る 瞬間

  • 外に出るのは 「分析」を押した瞬間 だけ
  • 送られるのは 手順の記録 + 画面画像
  • パスワード・APIキー は映さない（公式警告）
  • 線引きは はっきりしている
機密情報は録画に映さない。これが 鉄則 なのだ

始めるのに 必要なもの

⑬道具は 無料

  • アプリ自体は 無料
  • MIT ライセンス
  • 商用利用 も可能
  • GitHub で配布中
道具（アプリ）の お金は 0円。ここは太っ腹なのだ

⑭頭脳は 契約制

  • 動かすには GitHub Copilot のアカウントが必須
  • 録画を解読するのは Copilot の頭脳
  • 道具は無料 / 頭脳は契約
アプリが無料でも、Copilot 代は別。分けて考えるのだ

⑮ビルド式 で導入

  • ダウンロードして開く 形式ではない
  • コマンドを 1つ実行 して手元でビルド
  • 手順は INSTALL.md に書いてある
  • 対応OSは同梱の ドキュメント を参照
ワンクリック導入じゃない。コマンド1発 で組むのだ

2種類の スキル と 本当の 価値

⑯Skill と Automation

  • Skill エージェントが呼んで使う手順
  • Automation 決まった条件で自動で回す
  • 用途に合わせて 2つの形 を選べる
  • それぞれ 動かせる先 が決まっている
「AIに任せる」と「決めて回す」の 2通り が作れるのだ

⑰録って 初めて 言葉に

  • 録ってみると、毎週 何をやっていたか が見える
  • 自分の作業が 初めて言葉になる
  • 「手順にできない」作業は AI にも渡せない
言葉にできない作業は、そもそも AI に任せられない のだ

⑱本当の 効きどころ

  • 最大の価値は 自動化 ではない かもしれない
  • 「自分は毎週 何をしていたのか」が見えること
  • 手順化できた作業だけ AI に渡せる
  • つまり 自己理解 の道具 でもある
自動化より 「自分を知る」 がいちばんの収穫なのだ
