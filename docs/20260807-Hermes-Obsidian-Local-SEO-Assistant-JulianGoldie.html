二つの道具が出会う時

Hermes Agent × Obsidian
  • エージェント型 AI の Hermes と、メモアプリの Obsidian を連携
  • クラウドを使わず、自分の PC の中だけで完結
  • メモを読んで SEO 戦略 を自動で組み立てる
  • データは 外に漏れない、速さも抜群
クラウド不要の 100% local。 これが今回の主役です！

プライベート AI の魅力

自分だけの、壁のないアシスタント
  • 会話の log も、メモも、すべて手元 に残る
  • ネットの往復がないぶん サクサク動く
  • 書きかけのアイデアを、AI が整えてくれる
  • 月額料金も 気にしなくて OK
だれにも見られない安心感が、 けっこう大きいんです。

Hermes Agent ってなに？

自分で考えて動く、エージェント型 AI
  • コマンドひとつで、ファイル読み書き までこなす
  • プラグイン & Skill で機能をどんどん追加
  • ローカルモデルで動くから 通信ゼロ
  • Obsidian や他のアプリと つなげやすい 設計
# 起動の例
hermes --model local \
  --skill obsidian-scan

Obsidian ってなに？

自分の頭を、そのままメモに
  • すべて Markdown の text file で保存
  • メモ同士を link でつなぐ、知識の web
  • 保存場所は 自分の PC。見たい時にすぐ開ける
  • plugin が豊富で、AI とも相性〇
メモ同士がつながると、 アイデア が育ちやすい！

連携すると、何が起きる？

メモの山が、戦略のかたまりに
  • Obsidian の vault を Hermes が読み込む
  • メモの内容を AI が 分析・整理
  • テーマに沿った キーワード案 を出力
  • 結果も 同じ PC の中 に書き戻す
入れて、待つだけ。 あとは AI が 構成 を組んでくれます。

メモを丸ごとスキャン

あなたの言葉を、AI が読む
  • vault 内の 全 note を順に走査
  • 頻出語や タグ から、関心領域を推定
  • 自分の 文体 や語彙も学習
  • 不要な file は 除外設定 も可能
# 除外の例
exclude:
  - "*/draft/*"
  - "00-inbox.md"

SEO 戦略を自動で

メモから、検索に効く言葉を
  • 主要 キーワード を複数抽出
  • primary / secondary の 階層 も提案
  • 記事の 構成案 まで一気に出力
  • メモが増えるたびに 再生成 可能
思いつきのメモが、 そのまま 記事設計 になります。

完全オフラインで動く

電波がなくても、AI は働く
  • モデルも PC の中 で動かす
  • 初回だけ model を download。あとは手元
  • 外出先の ノート PC でも稼働
  • 通信費も server 代も ゼロ
機内でも山小屋でも、 AI がそばにいる状態。

「つなげなくていい」の価値

依存しない自由
  • 回線が細くても 止まらない
  • API の 待ち時間 がない
  • 使った分だけ課金、という 不安 なし
  • 外部 service の 規約変更 に左右されない
「オフラインで動く」＝ 強い ということ。

完全なプライバシー保護

秘密は、自分の机の中だけ
  • 内容が 外の server に送られることはない
  • 社外秘や個人の記録も 安心 して扱える
  • log も 手元 に蓄積。削除も自分次第
  • 学習データに勝手に流用される 心配なし
内緒のプロジェクトも、 これなら AI に任せられる。

速さも、かなりのもの

ローカル ≒ 待ちなし
  • ネットの ラグ が発生しない
  • 最近の 小さな model は軽くて高速
  • 何度も 再生成 しても、コストを気にしない
  • アイデアの 勢い を止めない
「考えた瞬間に、答えが出る」 これが local の強み。

データは自分の机で

所有権は、いつも自分にある
  • note も出力も PC の disk の中
  • 暗号化や backup も自分で管理
  • 消したくなったら 完全に消せる
  • service 終了で データを失う リスクも少ない
# 保存先のイメージ
~/Obsidian/
  └ SEO-out/
     └ 2026-08-07.md

制作フローを磨く

メモ → 戦略 → 記事、まで一本道
  • 書き散らした アイデア を AI が集約
  • 構成案 → 下書き の流れを自動化
  • 読者目線の 見出し 修正もお任せ
  • 「構成を考える時間」を ぐっと短縮
くり返し作業は AI に。 人間は 着想 に集中。

戦略を、自分好みに

プロンプト次第で変わる結果
  • 対象は 長文 か short か、指示で切替
  • 日本語 / 英語の 切り替え も自由
  • 想定 読者像 をメモに書いておくだけ
  • 競合の 強さ も考慮に入れた提案
設定を変えるたびに、 別の 角度 が見えます。

local vs クラウド 比較

どっちが、何に強い？

ローカル

プライバシー ◎
通信費ゼロ ◎
オフライン動作

クラウド

最新モデル ◎

  • 用途で 使い分け るのが現実的
  • 機密度が高いほど local が有利
どちらも捨てがたい、 だから 併用 が正解かも。

導入の流れ（ざっくり）

難しくはない、4 step
  • 1Hermes Agent を install & 起動
  • 2local model を 取り込む
  • 3Obsidian の vault の path を設定
  • 4skill で SEO 生成 を呼ぶだけ
# 実行のイメージ
hermes run seo-from-vault \
  --vault ~/Obsidian/MyNotes
最初の一回だけ設定すれば、 あとは ずっと使える。

ブログ以外にも広がる

メモがあれば、応用は利く
  • marketing の訴求軸を、メモから発掘
  • mail の文面や LP の構成案も
  • 発表資料の 柱 を、議事録から生成
  • 個人 study の まとめ も自動化
「メモがある」だけで、 展開 の種は尽きない。
