　ハーネス戦国時代が幕を開ける

⑥ハーネスとは何か

  • Anthropicの定義: Agent = Model + Harness
  • Karpathy（カルパシー）が提唱した概念
  • モデルを制御する「馬具」のような存在
  • 広義と狭義の2つの意味がある
モデルは馬。ハーネスはそれを操る手綱！

⑦狭義のハーネス

  • ツール連携：外部APIや機能を、うまく組む
  • データ管理：渡す情報を、整理して最適化
  • キャッシュ再利用で、無駄を省く
  • 結果として速度とコストが、劇的に改善
小さな工夫の積み重ねが、大きな差を生む！

⑧広義のハーネス

  • オーケストレーション：複数Agentを束ねる
  • ガバナンス：ルールと監視の仕組み
  • アクセス権限：誰が何を使えるか、制御する
  • 監査記録：あとで追えるログを残す
大企業で使うなら、管理と監視が必須！
