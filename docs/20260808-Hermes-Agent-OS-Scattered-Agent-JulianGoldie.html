AI エージェント

  • 窓を行ったり来たり
  • 記憶がバラバラに
  • 切り替えで時間が消える
ツールは揃った。
でも連携していないから、
結局 使いにくい 🔍

5 アプリ使っても
記憶はゼロ

穴
  • アプリごとに別人格
  • 前に言った事が伝わらない
  • 会話がリセットされる
  • 同じ説明を何度も
「え、それ知らないの?」
このもどかしさが、
毎日起きる 💬

文脈が

断絶
  • 流れが繋がらない

中盤: Hermes が用意した「作業台」

Command Desk が
その答え

解決
  • 全部を1 画面に集約
  • エージェントを束ねるOS
  • 中央の司令塔ができる
  • 情報が1 箇所に集まる
タブを増やすのではなく、
1 つにまとめる。
これが Hermes の発想 ✅

チャット・音声・
ボードを統合

統合
  • チャットで会話
  • 音声で指示
  • カンバンでタスク管理
  • 全部が同じ場所に
まるでコクピット。
必要なものが
すべて目の前に 🖥️

Command Desk の
全体像

構成
  • 会話もここで
  • 仕事もここで
  • 記憶もここに
  • すべてが繋がる
command-desk
├─ 💬 chat
├─ 🎙️ voice
├─ 📋 kanban
└─ 🧠 memory → shared

中盤: ひとつにまとまる 3 つの機能

チャットで
その場に指示

機能 1
  • 文章で即、指示
  • すぐ返事が来る
  • やり取りが全部残る
  • 思いつきから即、実行
いつものチャット感覚。
でも相手は動いてくれる
エージェント 💬

音声で
サッと命令

機能 2
  • 話しかけて操作
  • 手を止めずに指示
  • 動きながら伝える
  • 入力の時短になる
「あれやって」と
声に出すだけで、
作業が動き出す 🎙️

カンバン式で
仕事を見える化

機能 3
  • ボード形式で一覧
  • カードが自動で渡る
  • 終わったら次へ流れる
  • 一連の流れを組める
「やって → 確認 → 完了」
この流れを
ボード上で回せる 📋

後半: 目標を渡せば、勝手に進む

ゴールモードで
「目的」を渡す

自動化
  • 「何を」したいかだけ指定
  • 道筋はエージェントが考える
  • 手順を自分で組み立て
  • 人が細かく指示しなくて OK
「これやって」の一言で、
中身は任せられる。
これがゴールモード 🎯

複雑な仕事も
裏で進む

バックグラウンド
  • 指示後は勝手に進行
  • 複数の工程を同時に
  • 待つ間に別の作業ができる
  • 人が見守らなくていい
命令して、
あとは任せっぱなし。
これが本来の姿 ⚙️

自分が寝てる間も
動き続ける

夜間
  • 就寝前の指示だけで OK
  • 朝には結果が届く
  • 空き時間も無駄にしない
  • 朝一番で次へ進める
寝ている間に、
仕事が進む。

終盤: すべての AI が「同じ記憶」を持つ

全 AI が
同じ記憶を共有

共有
