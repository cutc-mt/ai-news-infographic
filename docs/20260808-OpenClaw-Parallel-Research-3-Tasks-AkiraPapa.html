問題は「順番待ち」

手作業の 待ち時間

1つ頼んで 終わるまで 待つ
  • まず1つ目を AIに頼む
  • 結果が戻るまで じっと待つ
  • やっと2つ目を頼める
  • また待つ… の繰り返し
待ち時間が どんどん積もる のが問題！

直列実行の 罠

順番にこなすと 時間が伸びる
  • 調べ物A → 待つ → 調べ物B
  • 調べ物C → また待つ…
  • 合計時間 = A+B+C の和
調べ物A
調べ物B
調べ物C
本当は 同時に 進められるはず…

同じAI でも 違う

やり方で 30分が 10分に
  • 同じAI、同じ3つの調べ物
  • なのに結果が大きく違う
順番に頼む 30分
並行で頼む 10分
3倍速い 同じAIなのに！

OpenClawの 仕組み

OpenClawとは

裏で担当を 立ち上げる
  • Discordでまとめて一言頼むだけ
  • 調べ物ごとに別の担当を起動
  • 担当たちが同時に走り出す
ユーザーは 一言頼むだけ あとは任せる！

Discord連携

チャットから そのまま指示
  • いつものDiscordチャットでOK
  • 「3つ並行で調べて」と送る
  • 終わった順にチャットへ報告
# Discordでの頼み方
「この3つをそれぞれ並行して
  調べて、終わったら
  ここに報告して」
特別なアプリは いらない！

  • 調べ物A → 担当α が担当

  • 調べ物C → 担当γ が担当
  • 3つが同時スタート
担当α

担当γ

動き方の イメージ

本体は 止まらない

メインが止まる ことはない
  • メインは止まらず動き続ける
  • 担当たちは裏で並行に処理
  • 本体の作業は止まらない
メインは 止まらず進む！

終わった順に 報告

早く終わった 担当から戻る
  • 速い担当が先に報告
  • 遅い担当は後から追いつく
  • 全部揃えば完了
待つ時間ゼロ で結果が来る！

従来型 との 違い

従来：順番待ち

1つずつ こつこつと
  • 合計時間 = A+B+C
  • 待ち時間が積み重なる
  • 時間あたりの効率が低い
待っている間は 何も進まない

OpenClaw：並行

3つ同時に スタート
  • 合計時間 = 一番遅い担当の時間
  • 待ち時間がほぼゼロ
  • 時間あたりの効率が高い
同時スタート で一気に進む！

注意点と まとめ

コストの 注意点

担当を増やすと 費用も増える
  • 担当が増えるほど費用が増える
  • 並行数 ≒ コストの倍率
  • 速さと費用のバランスが鍵
費用 は担当の数だけ増える！

並行が 得な時

調べ物が 複数ある時
  • 調べ物が3つ以上ある時
  • それぞれが独立した問題の時
  • 時間を急いでいる時
複数ある時は 並行が正解！

並行が 損な時

短い調べ物が 1つだけ
  • 調べ物が1つだけの時
  • とても短い作業の時
  • 起動の手間が無駄になる
1つだけなら 普通に頼むのが早い！
