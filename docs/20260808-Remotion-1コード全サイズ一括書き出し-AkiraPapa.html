Composition とは

Composition = Setting
  • 設定 のひな形
  • 幅・高さ・FPS を持つ
  • 長さ も決まる
  • 増やせば書き出し増える
// 1つの定義 = 1つの動画
<Composition
  id="Vertical"
  component={MyVideo}
  width={1080} height={1920}
  fps={30} durationInFrames={150}
/>

パラメータ で サイズ制御

Parametric Size
  • width / height を渡す
  • 文字サイズ も連動
  • 余白 も比率で
  • 計算 で整う
// 文字サイズ = 幅に比例
fontSize: width / 12
// 余白 = 高さに比例
padding: height / 20
