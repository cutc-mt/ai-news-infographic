進化の全体像

改名を発表

  • 2025年7月16日に Josh Woodward が公表
  • Google Labs の責任者としての発表
  • NotebookLM → Gemini Notebook へ刷新
  • ブランド名に Gemini を冠して統一
名前の変更は、Gemini ブランドへの
一本化の流れですね！

何が進化したか

  • 従来の ノート機能 はそのまま継承
  • セキュアなクラウド を内蔵して完結
  • ノートブック内で コード を書いて実行
  • 安全な環境で 自動処理を実行可能
ただのノートから、
「作業環境」へと進化！

三つの大きな柱

  • Notebook Agent：自律型のエージェント
  • データ分析：表やグラフを自動で処理
  • 多様な出力：音声・画像・スライドまで
// 大きく三つの力が合わさる
const pillars = {
  agent:  '自律処理',
  analyze:'データ可視化',
  output: '多フォーマット'
};
三本の矢が 揃った状態！

Notebook Agent の進化

単独QAから 進化

  • 従来は 1つの質問 に1つ回答
  • いまは プロジェクト全体 を自律処理
  • 複数の工程を 連続して実行
  • 人間の指示で タスクが連鎖
「1問1答」から、
「任せて完了」へ！

自動でこなす仕事

  • リサーチ：資料を集めて整理
  • コンテンツ企画：構成を提案
  • 比較分析：複数案を並べて検討
  • 下書き作成：文章も自動で生成
調べる→比べる→書く、
までを 一気通貫！

エージェントの動き

  • 計画：目標を分解して手順化
  • 実行：必要なツールを呼び出し
  • 検証：結果を確認して修正
// ループで自律的に動く
while (!done) {
  plan();   // 計画
  act();    // 実行
  review(); // 検証
}
計画→実行→検証 の
サイクルを回すよ！

データを分析する力

アップロードだけで

  • スプレッドシート をそのまま読み込み
  • PDF の レポート にも対応
  • 複数ファイルを まとめて投入
  • 質問は自然な ことばでOK
難しい設定は不要。
投げるだけ！

見つけて 計算する

  • パターン発見：傾向を抽出
  • 計算：合計・平均・比率を算出
  • 平易な説明：難しい数字を翻訳
  • 結果の 根拠も提示
数字の意味を、
人間の言葉で教えてくれる！

チャートを自動で

  • 折れ線グラフで 推移 を可視化
  • 棒グラフで 比較 を表示
  • 円グラフで 構成比 を提示
  • 画像を保存して 再利用も
グラフ作成の
手間が消える！

日常で役立つ場面

レシートを整理

  • レシートの 写真 をアップロード
  • 日付 を読み取って記録
  • 取引先 の名前を抽出
  • 金額 を数値として整形
  • カテゴリ を自動で分類
写真を投げるだけで、
経費の表が完成！

学習教材を作る

  • ノートや コース を読み込ませる
  • フラッシュカード を自動生成
  • クイズ 形式で出題
  • 学習ガイド で要点を整理
教材作りを AI に任せて、
学習に集中できる！

リサーチから企画まで

  • 複数資料を 1本の糸 に
  • 構成案を 自動で提案
  • 選択肢を 比較 して整理
  • 下書きも まとめて生成
企画書のたたき台が、
あっという間に！

多様な出力フォーマット

音声で会話

  • 音声会話：内容を語ってくれる
  • ポッドキャスト風の 聞き心地
  • 通勤中も 学習できる
  • 日本語にも 対応
読むのが面倒なときは、
「聞く」のが楽！

スライドと画像

  • スライド：発表資料を生成
  • 画像：図解を 自動で添える
  • 視覚的に 伝わりやすい
  • そのまま 会議で使える
プレゼン準備の
時間を大幅に短縮！

レポートと表

  • レポート：文章でまとめて出力
  • 表：データを行列入れ替え
  • チャート：数値を 図で表現
  • 形式を 選んで書き出し
目的に合わせて、
形を変えられる！

  • 「読む・まとめる」からスタート
