Hermes Agent OS が変える「無料で動かすAIチーム」のかたち

完全無料で稼働 ローカルモデル対応 ワンクリック導入

はじまりの主張

Julian Goldieが、まずはっきり伝える。「無料のAIエージェントOSがすべてを変える」と。

  • 有料ツールをそろえないと、AIチームは回せない ― その思い込みを否定する。
  • 彼の環境は1つのデスクで完結し、Agent OSが仕事を動かす。
  • 強力なマシンも不要、アプリの掛け持ちもなし。まだほとんど誰もやっていない領域。
「使わないチュートリアル」ではなく、本当に仕事で使うAIを渡したい、というのが彼の立場。

タブだらけの「古いAI生活」

多くの人のAI利用は、ブラウザのタブの山に散らばっている。

  • チャット用のウィンドウ
  • ビルド用のウィンドウ
  • メモ用のウィンドウ ― それぞれが孤立している。
例えるなら、優秀な助手を雇っておきながら、タスクごとに別の建物へ走らせ、毎回話を最初から説明し直すようなもの。

「オフィス」を直す発想

Agent OSが直すのは、ツールそのものではなく「オフィスのつくり」。

  • 1人のエージェントが、デスクのすべてのドアの奥に立つ。
  • その背後には、1つの記憶がそびえている。
  • どのドアから入っても、同じ記憶にアクセスできる。
「仕事はできる、環境が悪い」を逆転させた、という見方。

実例: 初日体験を1枚のチケットで

新規メンバー向けのAI Profit Boardroom初日体験を、Agent OSで構築した実例。

  • チケット1つで、ウェルカムメッセージを執筆。
  • 最初の通話の準備も、自動で仕上げ。
  • リソースツールまで一式、まとめて配置。
新メンバーは迷わず「次にやること」がわかる状態でスタートできる。

最大の誤解を消す

「こんな仕組みには、高いパソコンと有料プランの山が必要」― これが最大の誤解。

  • 実態はダッシュボード。zipファイルを1クリックで導入。
  • 無料のローカルモデルだけで全体が動く。
  • そのなかの1つは爆速で、Hermesエージェントで学習済み。
「使い切ってしまうのでは」という心配が、ここで消える。

デスクの「ドア」を歩く

Hermes Command Deskには、仕事の種類ごとにドアが並ぶ。

  • 音声エージェント: 話しかけて答えが返る。
  • チャット: タイプしたいとき用のHermesとの対話。
  • Oracle: ライバルの動きを監視。
  • Astros: 業界の問いを集めてネタ化。
どのドアも、背後では同じ記憶を共有している。

秘密のタネは「共有メモリ」

すべてのドアの奥にあるのは、Obsidianボールトという1冊のノート。

  • セッションごとに、発言と結果がひっそり書き込まれる。
  • Claude Code、Qwen 3.8、無料モデルも同じノートを読む。
  • 何千ものセッションが積み重なり、背景説明が不要に。
毎朝、文脈をゼロから組み立て直す時間が消え、何時間も戻ってくる。

AI Profit Boardroomの役割

このAgent OSの完成版は、コミュニティAI Profit Boardroomの中に置かれている。

  • zipを1クリックで入れて、自作の手間を省略。
  • 30日ロードマップで、何から配線するか順序が決まる。
  • 毎週のコーチング通話で画面共有し、詰まりを解消。
全ドア分の出来合いのプロンプトも用意されている。

ゴールモードの衝撃

数時間かかる重い仕事は、ゴールモードに任せる。

  • ゴールを1つ書き込み、「実行」を押す。
  • エージェントが自律ループで進捗を確認し続ける。
  • ゴールが本当に達成されるまで、止まらない。
達成するまで回り続ける
夜にゴールを放り込んでPCを閉じ、朝には完成品が待っている、という体験。

「腰を据えない」働き方

プロンプトを1つずつ投げて待つ、というやり方から離れる。

  • ゴールを渡して立ち去る。退屈な中盤は任せる。
  • AIをベビーシッターしない。デスクに座らせる。
  • 一度この感覚を知ると、手作業に戻るのが苦痛に感じるように。
あなたが離れていても、仕事は動き続ける。

「脳」の差し替えが簡単に

メインのモデルを変えるのも、ほぼ2クリック。

  • 「管理」タブ →「モデル」で、本体を切り替え。
  • 現在はQwen 3.8が稼働中で、切替は数秒。
  • ターミナルを開いてコマンドを打つ、従来の手間が消える。
// 新しいやり方
manage → "models" → change
// 旧方式: ターミナルでリストをスクロール&入力

一番好きな「ジョブボード」

プロンプトを打ち続ける代わりに、チケットを file する。

  • ディスパッチャーが各チケットを読み、ワーカーを起動。
  • 1枚のチケットで、1週間分のチュートリアル構成を一括出力。
  • ボードだから、チケットを並べて順に処理できる。
何枚かを file して立ち去り、戻ると進捗ができている。

スケジュール巡回でネタ拾い

Agent OSをcronで定期的に巡回させる運用。

  • 本人がいなくても、勝手に発火して動く。
  • 業界を走査して、新鮮なコンテンツの種を集める。
  • 寝ている間に更新が終わり、朝には完成済み。
常に新しいネタが待機状態で、手間ゼロ。

古い世界 vs 新しい世界

2つを並べると、まるで夜と朝ほどの差が出る。

  • 旧: タブの山、共有メモリなし、都度ゼロ説明。
  • 旧: 画面に張り付いていないと何も動かない。
  • 新: 話す・書く・チケット、いつも同じワーカー。
  • 新: 寝ている間にもビルドが出荷される。

複利で利く「静かな強み」

月曜のチャットで生まれた良いアイデアは、金曜には消えているのが常。

  • ここでは起きた瞬間に保存され、タグ付きで残る。
  • 数秒で検索できる同じ場所に集約。
  • 使うほどにデスクが賢くなり、新タブごとのリセットが起きない。
この複利効果は、誰も声を大きくしない利点。

ガードレールで信頼を得る

「AIを勝手に動かすのは怖い」という声は、もっともだと受け止める。

  • 削除や不確実なステップでは、一旦止まって確認。
  • 背後で勝手に暴走して壊さない設計。
  • 安全な時は速く、危うい時は慎重、というバランス。
重い仕事を預けつつ、大事な場面では自分が運転席にいられる。

詰め込みすぎない自由

さらに多くの仕組みが忍ばせてあるが、全部使う必要はない。

  • 音楽生成、動画エージェント、SEOコンテンツ機構。
  • ループエンジニアリング設定、もう1つのコーダー。
  • 使わないものは隠すか削除。デスクには開けるドアだけ。
「わたしのデスク」をあなた色に作れる。

一人で悩まないために

導入の分岐点 ― どの無料モデルか、記憶の組立、最初の自動化 ― はBoardroomが支える。

  • 導入済みのAgent OSのzipと30日ロードマップ。
  • 4,000人以上が隣で構築中のコミュニティ。
  • 画面共有の毎週コーチングで、詰まりを即解消。
SOPと100以上のユースケースは、AI Success Labで。
