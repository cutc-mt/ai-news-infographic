Cloudflare Computer & OS

エッジ上の“本物のパソコン”を渡す
  • AIエージェントに Durable Object 内の実コンピューター を与える
  • SQLite 仮想ファイルシステムを搭載
  • 実行バックエンド: Linux コンテナ bash JS モジュール
  • Cloudflare OS は Workers 上の エージェント作業空間
エージェント → DO 内の本物PC → 実行・永続化
サンドボックス越しじゃなく “本物の環境” を渡せるから、 エージェントができることが爆増するよ！

Authentik

セルフホストできる認証の“総本山”
  • 自前サーバーで動く シングルサインオン (IdP)
  • 対応プロトコルをずらり:
SAML OAuth2 OIDC LDAP RADIUS
  • クラウド依存なしで 自社管理 が完結
  • ユーザー・グループ・ポリシーを GUI で設定
複数アプリのログインを 一元管理 したい職人に最適。 月額費用ゼロで運用できる！

GrokAPI

Grok の機能を OpenAI 互換へ
  • Grok Web の機能を OpenAI 互換 API に変換
  • チャット機能をそのまま取り込める
  • 画像生成 画像編集 に対応
  • 動画生成までゲートウェイ経由で呼べる
1既存の OpenAI SDK をそのまま流用
2エンドポイントを GrokAPI に差し替え
3Grok の強みをアプリへ
OpenAI 形式だから、 コードの書き換えが最小。 乗り換えハードルが低い！

Excel

Cloudflare を自宅マシンで再現
  • Workers / Durable Objects を 自前ハード で動かす分散デーモン
  • SQLite で状態を保持
  • S3 にレプリケーションして耐障害性UP
クラウド縛り・従量課金
手元で完結・データを自分で持つ
Cloudflare の開発体験を 自宅サーバー で。 レイテンシも自由自在！

DeepSeek Razenix

人間 ⇄ エージェント → Nostr 中継

Embabel

  • JVM 言語でエージェントを構築できる
  • 動的プランニング でタスクを柔軟に再編
1目標を与えるとエージェントが計画を立案
2状況に応じて工程を動的に組み替え

Java/Kotlin の資産を活かしたまま エージェント化 できる、 企業向けの強い味方。

iHaveADHD

Soup

ファインチューンを“コマンド1発”に
  • LLM の ファインチューニング を簡略化する CLI
  • YAML 設定 だけ書けば準備完了
  • あとは コマンド1本 で学習スタート
# config.yaml
model: meta-llama/Llama-3
dataset: ./my_data.jsonl
epochs: 3

# 実行
$ soup train config.yaml
学習スクリプトを毎回書かなくてOK。 独自モデル への道が短くなる！
