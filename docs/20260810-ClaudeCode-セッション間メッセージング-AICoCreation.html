第5章：3層構造で連携を組み立てる

Layer 1：長期記憶

Shared Files as Memory
  • RULES.mdで基本ルールを共有
  • STATUS.mdで進捗を一元管理
  • DECISIONS.mdで決定事項を記録
  • 全員が同じ記憶を持つ
# 共有ファイルの例
RULES.md     # ルール
STATUS.md    # 進捗
DECISIONS.md # 決定履歴

Layer 2：専門家 の 頭脳

Independent Expert Sessions
  • Planner（企画・計画）
  • Worker（実装・作業）
  • Reviewer（監査・確認）
  • それぞれ独立したセッション
役割ごとに、
別々の頭脳を用意。
分業

Layer 3：リアルタイム 通信

SendMessage Lines
  • SendMessageで直接連絡
  • 必要な瞬間に即、届く
  • 双方向の連絡ライン
  • 3層が組み合わさる
記憶 頭脳 通信

3層 が 重なる 強み

The Whole Is Greater
  • 記憶が共有される
  • 頭脳が専門別に動く
  • 通信が瞬時に届く
  • 小さな組織が大きな成果
一人ひとりは小さくても、
3層で巨大な力に。
