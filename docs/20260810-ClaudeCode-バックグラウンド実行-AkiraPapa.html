待ち時間の問題と、解決策

待ち時間の 問題とは？

画面の前で、ただ待つ時間
  • AIの作業が終わるまで、ただ待つだけ
  • その間、自分は何もできない
  • 分単位の待ちが、積み重なる
  • 一度に1つずつしか進まない
ずっと待つのは、
本当にもったいない！
時間の無駄

バックグラウンド セッションとは

ターミナルを離れても、裏で走る
  • 指示を出して、すぐ離れられる
  • AIは裏で動き続ける
  • 戻ってきたら、結果を見るだけ
  • 複数の仕事を同時に進められる
あなたは別の作業をして、
AIには裏で頑張ってもらう。
時間の再利用

claude agents コマンド

すべてのセッションを、1画面で
  • claude agents を打つだけ
  • 動いているものが、一覧で見える
  • 返事待ちのものも、分かる
  • 終わったものも、一目で
$ claude agents
# 実行中 / 返事待ち / 完了 が一覧表示
1画面で、全部の状態が
分かるのが最大の強み！

並行処理

claude --bg の 使い方

1行打つだけで、すぐ手元が空く
  • claude --bg のあとに指示
  • プロンプトがすぐ戻る
  • 裏でAIが、作業を開始
  • 手元は、別の作業に使える
$ claude --bg "調べたいこと"
# プロンプトが即座に返る
# 調査は裏で進行中
--bg が、魔法のスイッチ。
これで待ち時間ゼロ！

  • 手元が、軽くなる
待たない＝止まらない。
リズムが崩れないんだ。

限界も、正直に知っておこう

利用量の 消費に注意

裏で動いても、消費は同じ
  • 裏で動く分も、利用量は同じ
  • 便利さの代償はある
  • 使いすぎると早く減る
  • 速さと消費のバランス
無料で増えるわけでは
ないよ。ここは要注意！
トレードオフ

10個同時 ＝ 約10倍

速さの裏にある、現実
  • 10個同時に回せば約10倍の速さ
  • でも消費も約10倍で減る
  • 速さは比例して増える
  • コスパを意識しよう
