Claude Code｜もう片方の案、消さずに試せます

別の案を試すために、今までの会話を消す必要はありません。分岐すれば、元はそのまま残る
2026年8月10日 ／ チャンネル：あきらパパのAI活用学習部屋

会話の分岐 とは？

いままでの流れを、そのままコピー
  • そこまでの会話を、まるごと複製する
  • 元の流れから、別ルートが伸びる
  • 元の会話は、手つかずで残る
分岐すれば、
別の案を存分に試せるよ！

これまでは消すしかなかった

別の案を試したい時につらい
  • 別の案を試すには、会話を消すしかなかった
  • 今までの流れが、パーになる
  • やっぱり元が良かった、と戻れない
消してからだと、もう
元に戻せないんだよね…

／branch と打つだけ

会話の途中で、ひとこと
  • 会話の途中で、／branch と打つ
  • その瞬間に、新しいルートが生まれる
  • 名前をつけることも、省略もできる
# 会話の途中で打つだけ
> /branch
たった／branch の
ひとことで分岐するよ

名前は 省略してOK

最初の指示から名前が付く
  • 名前を省くと、自動で名付けされる
  • 最初の指示の内容が、名前のヒントに
  • 後で一覧を探すとき、この名前が便利
# 名前をつけても、省いてもよい
> /branch 実装案B

# 省略すると自動で名前が付く
> /branch
考えるのが面倒なら
省いてしまって大丈夫！

ターミナルからも いける

起動時に fork セッション
  • --continue で前回の続きから
  • --fork-session を足して、複製を作る
  • 黒い画面から、直接 分岐できる
# 前回から継続しつつ、分岐を作る
$ claude --continue --fork-session
--fork-session が
分岐の本体だよ

元の会話は そのまま残る

手つかずで保存される
  • 分岐した瞬間、元は固定される
  • 元の会話は、一覧の中に残る
  • 安心して、別の案を試せる
元が消えないから、
失敗を恐れず試せるね！

／resume で 元へ戻る

一覧から名前を指定
  • 分岐前の会話は、一覧に残る
  • ／resume と打って、元の名前を指定
  • あっさりと、元の流れに復帰できる
# 元の会話に戻る
> /resume 元の会話の名前
／resume 元の名前
これで、すぐに戻れるよ

コピーして 切り替わる

分岐の中身の仕組み
  • 分岐の瞬間、会話をまるごと複製
  • 作業は、新しい方へ切り替わる
  • 元はそのまま、新しい道が伸びる
木の枝が分かれるように
ふたつの道ができるイメージ

権限は 引き継がれない

ここは限界のひとつ
  • 別プロセスになると、権限は切れる
  • 「このセッションで許可」が引き継がれない
  • 分岐したら、権限を再承認する必要
権限は新しいプロセスに
持ち越せない、と覚えておこう

再承認が 必要なとき

具体的な場面を知ろう
  • ファイルの書き換え権限を、もう一度
  • コマンドの実行権限も、再承認
  • 都度ポップアップで、許可を求められる
安全のためとはいえ、
ちょっと手間だね

ふたつの窓で 開かない

これは別の話、要注意
  • 分けずに、2つの窓で開くのは別問題
  • 両方のメッセージが、ひとつの記録へ
  • 混ざってしまうから、意図とちがう
分岐と、窓をふたつ開くのは
全然ちがうものだよ！

メッセージが 混ざる

窓を2つ開くと起きる
  • 両方の窓のやり取りが、ひとつの記録に
  • 会話の順序が、ごちゃまぜになる
  • 文脈が壊れて、AIも混乱する
並行で動かしたいなら
ちゃんと分岐を使おう

分岐 と 巻き戻し はちがう

目的で使い分ける

分岐

別の案を試すため

巻き戻し

時点を戻すため
  • ただ時点を戻したいだけなら分岐じゃない
  • 巻き戻し（チェックポイント）を使う
目的がちがうから
道具も、ちがうものを使おう

巻き戻しは チェックポイント

時点を戻すだけの機能
  • 過去の某地点に、戻れる機能
  • 別の案ではなく、時点を戻すのが目的
  • 道を増やすのではなく、やり直す
「やっぱあそこからやり直し」
という時は、こっちだよ

実践的な 使いどき

こんな時に分岐する
  • 実装の方針を、ふたつ試したい時
  • 冒険してみたいが、元は残したい時
  • 別のプロンプトで、試したい時
「もうひとつの案も試したい」
そんな時に、ぴったりだよ！

上手な使い方

3つのポイント
  • 1分岐には名前をつけておく
  • 2権限の再承認を、心得ておく
  • 3分岐と巻き戻しを、使い分ける
この3つを押さえれば
もう迷わないね！

チートシート

コマンドを ざっとおさらい
  • ／branch ／ 会話を分岐
  • ／resume 名前 ／ 元に戻る
  • --fork-session ／ 窓から分岐
# よく使う3つの操作
> /branch 実装案B
> /resume 元の会話
$ claude --continue --fork-session
この3つを覚えておけば
だいたいの場面は、対応できるよ

限界も まとめて

3つの注意点
  • 権限は引き継がれない（再承認が必要）
  • 窓を2つ開くと、記録が混ざる
  • 時点を戻すだけなら巻き戻しを使う
できる事と、できない事を
しっかり区別しておこう

キーワード

これだけ覚えよう
／branch 分岐 --fork-session ／resume 巻き戻し チェックポイント 権限の再承認 会話の複製 別プロセス セッション
このあたりの言葉を
頭に入れておこう！
