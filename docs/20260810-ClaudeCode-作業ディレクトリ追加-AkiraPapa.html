Claude Code｜2つのフォルダ、行き来しなくていい

別のリポジトリを見ながら実装するとき、窓の往復とコピペをゼロにする方法
2026年8月10日 ／ チャンネル：あきらパパのAI活用学習部屋

ふたつのフォルダを行ったり来たり

別リポジトリを見ながらの作業
  • 実装したい側と、仕様がある側がわかれている
  • 窓を切り替えて、中身を見比べる
  • この行き来が、じつは時間を食う
この往復を
なくす方法があるんだ！

Claude Code ってなに？

Anthropic 純正の CLI エージェント
  • Anthropic 純正のコーディングエージェント
  • ターミナル（黒い画面）から動かす
  • コードを読み書きして、かわりに作業する
いま動かしている場所が
そのまま「作業部屋」になるよ

ビフォー：窓をぐるぐる

いままでのつらいやり方
  • 仕様の窓と、実装の窓を行ったり来たり
  • 必要な所を、いちいち探しては見る
  • 見つけたら、コピーして、はりつける
これを何度も繰り返すから
ほんとに疲れるんだ…

コピペだらけの手作業

人の手が介在する問題
  • 仕様をコピーして
  • プロンプトにはりつけして
  • 貼り忘れや、はみ出しも起きる
人が介在すると、ミスも
一緒に入ってくるんだよね

アフター：窓を往復しない

もうひとつのフォルダを足す
  • 作業中の場所に、もうひとつフォルダを足す
  • AIがその中身も、自分で見にいける
  • もう窓の切替も、コピペもいらない
ひとつの部屋に、もうひとつ
本棚を足すようなイメージ！

① 起動時にフォルダを足す

一番シンプルな書き方
  • 立ち上げるときに、オプションをひとつ
  • これで、もうひとつの作業場所が見える
  • 起動と同時に、準備が終わる
# 起動時に追加フォルダを指定
$ claude --add-dir ../api-server
--add-dir をつけるだけ。
たったこれだけで済むよ

② 話している途中からでも足せる

スラッシュコマンドで追加
  • 会話の途中で、「あ、あのフォルダも」
  • スラッシュから始まるコマンドを打つ
  • 立ち上げ直さなくていいのが楽
# 会話の途中で追加
> /add-dir ../api-server
「やっぱり必要だった」
と気づいたときも、安心だね

③ 毎回同じなら設定に書く

何度も打つ手間を消す
  • いつも同じ場所を足すなら設定へ
  • 設定ファイルの permissions に書く
  • 書いておけば、次からは自動で
// settings.json の例
{
  "permissions": {
    "additionalDirectories": [
      "../api-server"
    ]
  }
}
毎回同じなら、設定へ。
打つ手間そのものを消すよ

3つの方法を ならべてみる

場面で使い分ける
  • 1--add-dir ／ 起動時に一回だけ
  • 2/add-dir ／ 途中から追加したい
  • 3設定 ／ 毎回同じものを使う
どれも目的は同じ。
ただタイミングがちがうだけ

結局、なにがうれしい？

3つのメリットを整理
  • 窓の切替が、ゼロになる
  • コピペも、ゼロになる
  • 作業の手間を、AIに任せられる
手戻りも減って、頭の切り替えも
ぐっとラクになるんだ

AIが 自分で見にいく

指示しなくても参照できる
  • 追加した場所は、AIから見える範囲に入る
  • 必要なとき、AIが自分で中身を読む
  • 人が「これ見て」と言わなくていい
「あの仕様、どこだっけ？」
と探す手間が、不要になるよ

注意：CLAUDE.md は読まれない

ここはよくつまずく所
  • 追加した側の CLAUDE.md は標準では読まれない
  • ファイルの中身は見えても、ルールは引継ぎされない
  • この差、知らないとはまります
「フォルダ足したのに、
ルールが効かない…」の原因はここ

ルールごと共有したいなら

.claude/skills/ に置く
  • ルールも渡したいなら .claude/skills/ へ
  • ここなら、AIが参照しにいける
  • 作業の場所と、ルールを分けて持てる
# ルールはこちらに置く
.claude/skills/
  └─ api-server-rules.md
ファイルを見せたいだけか、
ルールも渡したいかで変わるよ

よくある 誤解

ここを押さえておこう
  • 「ファイル全部を自動で読む」わけではない
  • 「書き換え自由」でもない（権限しだい）
  • 見える範囲が増える、というのが正しい理解
「全部まるごと」じゃない。
必要な時に見に行ける、だよ
