Remotion｜動画の演出、もう自作しません

毎回ゼロから作るのは終わり。部品を選んで、差し替えるだけ
2026年8月10日 ／ チャンネル：あきらパパ

演出を毎回ゼロから？

あるあるの悩み
  • 動画の演出を、毎回イチから作っていませんか
  • 背景、文字の出かた、カウンター……ぜんぶ手作り
  • 作るたびに時間がかかり、味がブレる
毎回ゼロから……
これ、本当に必要ですか？

自作のつらさ

演出を作るコスト
  • 動きを1つずつコードで書く必要がある
  • 似た演出を、別の動画で作り直し
  • 品質が、その日の調子に左右される
「部品があれば、
選ぶだけで済むのに」
ここが転換点

Remotion Elements

公式の動画部品ギャラリー
  • Remotion 公式が、部品をまとめて提供
  • 名前は Elements ／ 動画の部品を集めた場所
  • 欲しいものを、選んで差し替えるだけ
もう、演出は
自作しなくていいんです

Elements とは何か

公式が整備する部品集
  • Remotion 公式の動画部品ギャラリー
  • 背景・字幕・数字など、部品単位で置ける
  • 公式だから、品質と更新が保証される
テンプレ丸ごと、じゃない。
部品を選ぶのがポイント

公式が整備する強み

信頼できる部品の源
  • Remotion チーム自身が用意・保守
  • バージョン更新で、継続的に改善
  • 勝手に消えない ／ 突然の仕様変更も少ない
信頼できる部品を
土台にできる、という安心感

v4.0.506 で登場

リリースノートに登場
  • Remotion v4.0.506 のリリースに含まれる
  • 公式リリースノートで、Elements が言及される

公式が、部品の再利用を

部品の例：背景

Backgrounds 系の部品
  • 背景の演出を、部品として呼べる
  • グラデーションや模様を、選ぶだけに
  • 差し替えれば、見た目が切り替わる
背景 グラデ 模様
背景をイチから描く、
もう終わり

部品の例：字幕

Captions / 字幕の部品
  • 字幕の動きも、部品で置ける
  • 文字の入り方や見え方を、選ぶだけに
  • テキストを差し替えれば、そのまま使える
字幕の演出、
もう手作りしなくてOK

部品の例：数字表示

Counters / 数字の部品
  • 数字の表示も、部品として呼べる
  • カウントアップなど、動きつきで
  • 値を差し替えるだけで、完成
// 数字を渡すだけで動く
<Counter value={120} />

他にも、いろいろ

部品は3つだけじゃない
  • 背景・字幕・数字のほかにも、部品がそろう
  • 組み合わせて、複数の演出を同時に
  • 自分の題材に、合わせて配置
背景 字幕 数字 他

Studio へ送れる

コンポジションへ取り込み
  • 選んだ部品を、Studio のコンポジションへ送れる
  • ギャラリー → 自分の動画 の流れ
  • プレビューで、動きをその場で確認
ギャラリーで選んで、
Studio へポン、です

丸ごと vs 部品

使い方が違う

テンプレ丸ごと

ひとつの型に、
ぜんぶ乗せがち

部品使い回し

必要な分だけ、
自分の題材に
  • 部品単位だから、自由に組み合わせできる
「全部入り」じゃなく、
必要な分だけ使う

Sequence の中で

部品は Sequence 単位で置く
  • Sequence は、時間の区切り
  • その中に、部品を配置していく
  • 開始・長さを、自在に設定できる
// Sequence の中に部品を置く
<Sequence from={0} durationInFrames={60}>
  <Background />
  <Caption text={"差し替え"} />
</Sequence>

題材に合わせて差し替え

部品は器、中身は自分次第
  • 部品は器。中身は自分で差し替える
  • 文字・色・数値を、自分の題材に
  • 同じ部品でも、別の動画に化ける
部品を選んで、
中身を入れ替えるだけ

Sequence の基本形

公式ドキュメントの書き方
  • Sequence は公式ドキュメントに詳しく
  • from で開始、長さは frames で指定
  • 中に、部品を複数並べるのが基本
// 公式：Sequence の中に要素を置く
<Sequence from={10}>
  <MyScene />
</Sequence>

3ステップで完成

選んで・送って・差し替え
  • 1選ぶ：Elements から部品をピック
  • 2送る：Studio のコンポジションへ
  • 3差し替える：Sequence に並べて中身を変更
この流れを回せば、
演出を自作しなくて済む

こうして楽になる

  • 演出の所要時間が、ぐっと下がる
  • 部品を使い回すので、味がブレない
  • 中身の差し替えに、集中できる
