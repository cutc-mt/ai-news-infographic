何を AIが つくってる？

曲 は AIが つくる

制作の 内訳 ①
  • メロディ・コード・アレンジ まで AI生成。
  • 楽器が 弾けなくても 一曲が 仕上がる。
  • ジャンルや 雰囲気を 言葉で 指定 できる。
  • アイデアから 音になる まで が 圧倒的に 速い。
DTMの 知識が なくても、曲が 書ける。 これが AI作曲の 衝撃！

歌 も AIが うたう

制作の 内訳 ②
  • ボーカル まで AIが 担当。
  • 声の 質や 歌い回しも 選べて つくれる。
  • 「誰も うたわない」声が 生まれる。
  • 疲れも 風邪も ない、いつでも うたえる ボーカル。
歌手を 探す 必要が ない。 AIボーカル が その穴を 埋める！

画像・動画 も AIで 生成

制作の 内訳 ③

  • 撮影も 編集も ひとりで 完結 できる。
  • タッチや 色あいを 自由に 変えられる。
  • 予算が なくても 映像の 世界 を つくれる。
