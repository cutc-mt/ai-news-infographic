AI に デスクと 記憶を あげる

「訪問」する だけの AI から ずっと住む AI へ
🎬 Julian Goldie SEO  |  📅 2026-08-11 公開
共有の記憶 寝てる間も稼働 新モデルを 2クリック

考え方の しくみ替え

AIを「訪問」するのを やめる

発想の転換
  • これまでは AI のところへ 自分が行っていた
  • 逆に AI に 自分のデスク を あげる
  • AI が ずっと住める場所 を 用意する
  • 関係が 逆転 する
そこに「住む」AI は、通りすがりの AI とは まるで違う！

デスクを あげると すべて変わる

変化
  • AI が あなたを 覚えている
  • あなたの 仕事を 把握 している
  • あなたが 寝ている間 にも動く
  • 新しいモデルが すぐ使える
「デスク」ひとつで 関係が 根本から変わる。 それが この仕組みの こころ！

新モデルを 2クリック で差し替え

拡張性
2 クリック 新モデルの 取りつけ
  • 最近は 毎週 新モデルが 出る
  • まるで 新しいチップ のように はめ込む
  • はめ替えて おしまい
AI の進化が 速すぎても 置いていかれない。 これが 大きな強み！

Agent OS の 中身を のぞく

まず ミッション コントロール

ホーム画面
  • 開いた瞬間に ホーム画面 が出る
  • すべてのエージェント が ひと目で わかる
  • オンラインか どうか も 表示
  • いま 何をしているか も見える
さらに 活動の生配信 が 流れる。 全体を つねに 把握できる！

Hermes チャットで 文字で話す

チャット
  • なんでも タイプするだけ
  • Hermes が すぐに返事 を返す
  • やりとりは ぜんぶ保存
  • のちほど 記憶 として つながる
普段のチャットと 変わらないかんじ。 でも すべてが蓄積 される！

Hermes Apollo で 声で話す

音声
  • 声で 話しかけられる
  • アシスタントへの 電話 のような感覚
  • 「ねえ Hermes、これ オン にして」
  • タイプ不要 で 済む
手がふさがっていても 声だけで操作。 話しかけるだけで 仕事が 進む！

Hermes Oracle が 競合を 見張る

競合 監視
  • 競合の 動きを つねに 監視
  • スケジュール で 自動実行
  • 何をしているか 報告
  • 結果を こちらに 持ち帰る
「スケジュール」の しくみが いちばんの ポイント。 自動で 回り続ける！

Hermes Astros で ネタを 仕入れる

キーワード 監視
  • 業界の キーワード を 監視
  • コンテンツの ネタ を 届けてくれる
  • 何かを 作る人 には 特効薬
  • これだけでも 導入する かいがある
コンテンツ作りなら これだけで 元が取れる。 ネタに 困らなくなる！

チャット・音声・監視・ネタ が 1画面

集約
チャット ― 文字で やりとり
音声 ― 声で さしず
競合 ― 動きを 監視
ネタ ― キーワード を 収集
4つが 1つの記憶 を 共有している。 バラバラに ならない！

システムを 動かす「記憶」の しくみ

Obsidian は ただのノートの 箱

記憶の 場所
  • 正体は パソコンの ノートの フォルダー
  • これといって 特別な仕掛けは ない
  • ただの メモの 集まり
  • Agent OS が ここへ つながる
難しく 考えなくて OK。 「ノートの 箱」 と 思えば 十分！

話すたびに 自動で 書き込む

自動 保存
  • Hermes との 会話 が そのまま 保存
  • すべての タスク が 書き留められる
  • すべての 決定事項 も 残る
  • 仕事の 背景 も 一緒に 記録
自分で メモを とらなくていい。 勝手に ためてくれる！

ためた記憶は すべて 検索可能

検索
  • 書き留めたことは 探せる
  • 昔の 決定 を ひきだせる
  • 過去の 文脈 が 甦る
  • 忘れることが なくなる
人間は 忘れても 記憶の 箱は 覚えている。 いつでも よみがえる！

全エージェントが 同じ記憶 を 読む

共有
  • すべてのエージェントが 同じ Vault から読む
  • Claude Code が 引っ張る
  • Hermes が 引っ張る
  • Qwen 3.8 も 同じ場所 から
モデルが 違っても 記憶は 1つ。 ここが 最大の ポイント！

どのモデルも 同じ記憶 に つながる

連携
  • Claude Code が 記憶を 参照
  • Hermes も 同じ記憶 を 使う
  • Muse や Spark など なんでも
  • 使うものを 問わない
# どの AI も 同じ 箱を 読む
> Claude Code  →  Obsidian Vault
> Hermes       →  Obsidian Vault
> Qwen 3.8     →  Obsidian Vault
→ 記憶は いつも 同じ 場所 ✓
モデルを 取り替えても 記憶は そのまま。 切り替えの コストが ほぼ ゼロ！

モデルを 変えても 記憶は 消えない

切り替え
  • モデルを 乗り換えても
  • 新しいモデルが 仕事を 把握済み
  • 先週の 決定 も 覚えている
  • 顧客・提案・作風まで 引き継ぐ
「もう一度 説明して」が なくなる。 これが 共有記憶の ちから！

結局 なにが うれしいのか

二度と 説明 しなくて いい

最大の 利点
  • 「うちの 事業はね」が もう要らない
  • 顧客を 一から 説明 しなくて 済む
  • 商品や 提案 も 理解済み
  • あなたの 好み まで 覚えている
これが いちばん 楽 なところ。 AI が 先に すべてを 知っている！

あなたが 寝ている間 も 進む

自動 稼働
  • あなたが 休んでいる あいだも
  • Oracle が 競合を 監視 し続ける
  • Astros が ネタを 集めてくる
  • 朝には 新しい 情報 が 届く
朝のコーヒーを 入れる あいだに 仕事が 進んでいる。 これが デスクの ちから！

まとめ ― 3つの かざり

結論
  • デスク: AI に 住処を あたえる
  • 機能: チャット・音声・監視・ネタ
  • 記憶: Obsidian で 1つに
  • 継続: モデル替えても 記憶は 残る
  • 解放: 二度と 説明しない
AI を 訪問する 時代は もう おしまい。 デスクと 記憶を あげて、住まわせる 時代へ！
