ベビーシッターから マネージャー へ

AI の お世話係 をやめる

現状の問題
  • 毎回 クリックして ちまちま進める
  • 一行 ごとに プロンプトを 打つ
  • ずっと そばで 見守る 必要がある
  • これだと 時間を 使うだけ
AI を 育児する ような 日々。 これじゃ 楽にならない と 気づく！

AI を チーム として 扱う

発想の転換
  • あなたは マネージャー に なる
  • AI は 部下 のように 任せる
  • 指示を出して 結果を 受け取る
  • 丸ごと おまかせ する かたち
細かく 操作する じゃなく 仕事を まとめて まかせる。 これが 正しい AI の つかい方！

この動画が 教える 2つの鍵

構成
鍵1: かんたんな 設置 の 手順
鍵2: 自律で 回る Goal Mode
  • この2つで 世話焼きから 卒業
  • どちらも むずかしくない のが ポイント
設置 を すませて Goal Mode に 入れる。 これだけで 勝手が 変わる！

まず 壊すべき 思い込み

「技術的 すぎる、無理」は 間違い

思い込み
  • 「This looks technical. I can't set this up.」
  • こう あきらめる 人が 圧倒的に 多い
  • 実は 大げさな 心配
  • これが 最初の 壁 になる
「むずかしそう」で とまる のが 一番 もったいない。 次の カードで ほぐす！

全部 zip 1つ から 始まる

事実
  • システム全体が zip に まとまる
  • これを ダウンロード するだけ
  • 解凍して フォルダを コピー
  • むずかしい 準備は いっさい なし
# たった これだけ
$ unzip agent-os.zip
$ cp -r agent-os/ ~/work/
→ これで 箱は 用意できた ✓
専門知識は いらない。 zip を 開く のと 同じ かんたんさ！

コピー → 実行 → ページを 開く

3アクション
1 フォルダ を 1つ コピー
2 コマンド を 1回 実行
3 ウェブページ を 開く
  • この 3つ で ダッシュボード が立ち上がる
  • 設定ファイルの 編集は なし
「コピー して、うごかして、ひらく」。 3拍子 で 使える ように！

GitHub も クラウドも 不要

ハードル
  • GitHub の アカウント なしで OK
  • クラウド アカウントも 必要ない
  • 外部サービスへの 登録 ゼロ
  • 自分の 環境で 完結 する
登録の お手続きを ぜんぶ 飛ばせる。 こわいものが ない 設計！

設置 は たったの 30分

時間
約 30 分 設置 にかかる 目安
  • コーヒー 1杯 の あいだに 完了
  • 手順は 少なく シンプル
  • システム全体で 一番の 時短
「導入が 面倒」で 諦める人 が多い。 ここを 30分に した のが 功を奏す！

ゼロから そだてる ダッシュボード

エージェント ゼロ でも 動く

ダッシュボード
  • AI を 1つも 入れてない 状態で 起動
  • ダッシュボードは 空っぽから 使える
  • あとから 足していく だけ
  • 「全部 そろえないと」は 思い込み
空っぽの 箱から スタート。 まず 動かして みる のが 正解！

1つずつ 自分の ペースで 足す

追加
  • エージェントを 1つずつ 追加
  • 自分が 欲しいもの だけ 選ぶ
  • 使わない ものは 入れなくて OK
  • ちいさく 始めて そだてる
いっぺんに そろえない。 必要な 分だけ 足していく！

目玉 機能: Goal Mode の 衝撃

ゴール を 1つ 書いて 立ち去る

Goal Mode
  • 大きな 目標 を 1つだけ 入力
  • あとは その場を 離れて OK
  • Hermes が 自律ループ で 回る
  • 何時間も ひとりで 進む
「次 どうする？」と 聞かれない。 自分で 予定を たてて 進み続ける！

ふだんなら 1日 かかる 仕事

規模
  • 「大きくて たいへん」な ゴール を 選ぶ
  • 人間なら 1日がかり の もの
  • Goal Mode は 大きな仕事 向き
  • ちいさい 依頼より どんと 任せる
小さな こと じゃなく 1日分を まとめて まかせる のが こつ！

計画 → 実行 → 継続 の ループ

自律サイクル
計画 ― まず 何を やるか 整理
実行 ― 実際に 仕事を 進める
継続 ― 人が いなくても 回る
この サイクルが 勝手に 回る のが 最大の 違い。 エージェントが 自分で 進む！

あなたは いない。クリックも しない

放置 OK
  • その場を 離れて も いい
  • クリックも 1回も しない
  • ジムに 行ってる あいだも 回り続ける
  • 散歩 中も 仕事が 進む
あなたが いない あいだ に どんどん 作業が すすむ。これが 本当の 自動化！

戻ったら 完成品 が ある

成果
  • 外出から 帰って 画面を 開く
  • そこには 完成した 仕事 がある
  • 夜に 仕かけて 朝 できている
  • 確認するだけの 楽な 状態
「時間を 買う」って こういうこと。 自分の 代わりに 働く 存在！

Goal Mode が 変える 働き方

ゴール1つ → 何時間分 → ゼロタッチ

入出力
入 ゴール を 1つ だけ 書く
出 何時間分 の 仕事が できる
間 ゼロ 回の タッチで 済む
  • 入力は ちいさい。出力は でかい
  • この ギャップ が すごい
ちいさな 入力で 大きな 成果。 これこそ マネージャーの 働き方！

一行ずつ は ダイヤルアップ に 感じる

感覚
  • Goal Mode を 使った あと
  • 一行 ごとに 打つのが おそく 感じる
  • まるで ダイヤルアップ 回線に 戻る よう
  • 一度 知ると もどれない
速さを 知ると 遅さが 苦痛 に。 Goal Mode は それくらい 画期的！

まとめ — マネジメントの 時代へ

結論
  • 転換: お世話係 → マネージャー
  • 設置: zip・30分・アカウント 不要
  • 成長: ゼロから 1つずつ 足す
