Claude Code を 2窓で
  • 画面を2つ開いて、別々の作業を 同時に 進める
  • 片方が 何かを見つけても、もう片方は気づかない
  • 人間が コピペで運ぶしかなかった

セッション B

伝書鳩役は
もう いらない

人間のコピペが 不要に
  • Anthropic が Claude Code に 追加した 新機能
  • 起動中の セッション同士が メッセージを送り合える
  • 人間は「つなぎ役」から 解放される
前：人が コピペ
後：AIが 直接
機能の名前は cross-session messaging
「セッションをまたぐ 伝言」

頼み方は
日本語だけで OK

特別なコマンドは 不要
  • いつもの通り 日本語で お願いするだけ
  • Claude が いい感じに 解釈して動く
  • コマンドや API名を 覚える 必要なし
別のターミナルのセッションに、作業が 終わったか 聞いて
難しい 用語は 不要。
「隣に聞いといて」で 動き出す

  • 次に SendMessage で 届ける

Claude の 判断で
  • 「これ、向こうに 伝えた方が いい」と 自分で判断
  • 指示を 待たずに 自発的に 送信
  • セッション同士が 助け合う 動き
「必要だ」と思えば
人間に 聞かずに 伝言を 投函

渡るのは
テキスト 1枚だけ

Claude が 書いた 短い文
  • 中身は Claude が 書いた短い文 だけ
  • 会話の履歴は 渡らない
  • ファイルも 渡らない
渡るのは テキスト1枚。
履歴も ファイルも 共有されない

承認の 代わりには
ならない

権限確認は 別物
  • 伝言は 権限の承認の 代わりにならない
  • 設定ファイルの 書き換え依頼は 禁止
  • 危険な操作は 人が 直接 確認
「承認して」を 遠隔で出すことは
安全性の観点から NG

コマンドは
ただの 文字

実行されない 設計
  • 本文に コマンドが 書いてあっても 文字として扱う
  • 受信側が 実行することはない
  • 注入攻撃のような 悪用を 防ぐ 作り
⚠ 本文に書いても
$ rm -rf /
↑ ただの文字列。
実行は されない。
命令ではなく 伝言。
その線引きが しっかり
