半導体投資の歴史 — VC は みんな 席を 立っていった

Intel CEO が 振り返る、18年越しの「態度の 変化」
🎙️ No Priors Podcast  |  📅 2026-08-11 公開
時価総額で 証明 VC の 態度 180度 18年前 と 今

18年前 — だれも 聞いてくれなかった

18年前 も 半導体 に 投資していた

当時の 状況
  • 話し手は 半導体への 投資 を つづけていた
  • 相手は ティア1の VC ・仲のよい 友人 ばかり
  • パートナー会議に 全員が 集まっていた
  • その場で 半導体の 話を 切り出した
友人ばかりの 場だったからこそ、
あえて 本題 を 持ち込んだ。 勇気の 一步

半分は 言い訳 して 逃げた

最初の 反応
50% 話の途中で 部屋を 出た割合
  • 話が 終わらないうちに どんどん 席を 立つ
  • 「用事が ある」「すぐ 戻る」 と 言い訳
  • 聞く耳を 持たない 態度
親しい 友人でも、金と 種類 が 違うと
さっと 離れて いく。

残りも ソフトウェア？ と 去った

二番目の 反応
  • 残った 半分が 尋ねた ひとこと → 「ソフトウェア サービス？」
  • 答えが 「半導体」 だと 知ると すぐに 退出
  • 当時の 関心は SaaS 一色 だった
  • ハードより ソフト が 王道
ひとことで 空気は 変わる。
「ソフトウェア？」 が その 合図。

残ったのは たった2人

最後の 聞き手
2人 仮に 話を 聞いてくれた 人
  • 「仮に」と 表現 — 真剣度は 不透明
  • その2人だけが 席を 守った
  • 「全体」の なかの ごく少数
ほんの 数人が いたから こそ、
種は 消えなかった。

当時は ソフト が すべて

時代の 空気
  • SaaS ・ クラウド が 投資の 主役
  • 少額から 短期で 何倍 という 期待
  • 半導体は 重い・遅い・高い の 三重苦
  • 工場や 製造ではなく コード が 王道
VC の 「速さ」と 半導体の
「重さ」 が かみ合わなかった。

なぜ つづけられた のか

投資家の 信念
  • 先の 価値 を 見ていた
  • 人口の 少数派 でも 意地を 折らない
  • だれも ついてこなくても 種は まく
  • 時間が 解決する と 知っていた
周りに 合わせない 人だけが、
あとで 評価される。

歴史は 変わった — 時価総額が 証明

18年で 歴史が 反転

全体の 流れ
18年前 だれも 聞かない
現在 VC が 列を なす
  • 半導体が もう一度 ホット に
  • 時価総額が 逆転劇 を 演じた
  • あの 「2人」 が 正しかった
歴史は ゆっくり でも 曲がる。
その「曲がり角」が 今。

NVIDIA — 5.3兆 ドル

時価総額 第1位級
5.3兆$ ジェンスンが 率いる 会社
  • リーダーは Jensen Huang
  • AI ブームの 心臓 を 支える
  • GPU が 世界の 動脈 に
  • 半導体の 頂点 を 更新中
NVIDIA 時価総額
  = 5.3兆 ドル
  ≒ 最大規模 上場企業
AI の 波 を 一番に つかんだ。
その 波は まだ 続く。

Broadcom — 2兆 ドル

通信チップの 巨人
2兆$ 通信と カスタムチップの 重鎮
  • ネットワークと 通信半導体
  • 大手向け 専用チップ 設計
  • データセンターの 縁の下
  • AI 需要 で さらに 急伸
見えない 場所で 基盤 を 支える。
それが Broadcom 流。

TSMC — 2兆 ドル

世界の 工場
2兆$ 最先端 チップの 受託製造
  • 設計を 製造 に 変える 存在
  • 世界中の チップが ここ から
  • 台湾に 集積する 工場力
  • ナノ単位 の 精度が 勝負
設計する 人も、
つくる 人 が いなければ 止まる。

AMD / リサ・スー — ほぼ8000億

跃進の シンボル
~800億$ リサ・スーが 率いる 会社
  • 技術者出身の CEO
  • 数年で 躍進 を 遂げた
  • 高性能 CPU と GPU で 追い上げ
  • サーバー領域で 存在感
技術を わかる リーダーが、
古株の 会社 を 甦らせた。

Intel — ほぼ6000億

話し手 自身
~600億$ 「わたし」が 率いる 会社
  • 発言者 = Intel の CEO
  • 老舗 CPU の 顔 であり 続ける
  • 工場を 自前で つくる 方針
  • 過去の 重さを 背負いつつ 復活へ
18年前、だれも 聞かなかった 話が、
いまは 自分の 会社の 数字 に。

なぜ VC の 態度は 変わったのか

半導体が 必須 に なった

構造の 変化
  • AI の すべてが チップ に 依存
  • データセンター = 半導体の 塊
  • 端末から クラウドまで 経路
  • 国益・安全 にも 関わる 戦略品
1 AI の 広がり
2 チップ 需要の 爆発
3 VC の 関心が 逆転
「なくては ならないもの」に なった。
それが 最大の 変化。

15〜20年前 — だれも 来なかった

VC 側の 姿
  • VC は 一件も 合流しなかった
  • 「期間が 長い」「見えない」 敬遠
  • 投資額が 重い
  • 失敗時の ダメージ が 大きい
VC の 計算 (当時)
 半導体 = 重い・遅い・危険
 ソフト = 軽い・速い・何倍
リスク計算を すれば、
当然の 選択 だった わけだ。

ついてきたのは 大企業 だけ

例外の 勢力
  • Samsung ・ SoftBank など
  • 巨大資本を 長期で 動かせる
  • 事業の 一部 として 半導体を 評価
  • 戦略投資 なら 待てる
VC 見向きも しない
大企業 ついて きた
VC には 無理でも、
事業会社 には 見える もの。

いまは VC が 列をなす

現在の 状況
  • 逃げた VC が いまは 戻ってくる
  • 資金が 流れ込む ように 増加
  • プレゼンを 聞きたがる
  • 「仲間に 入れて」 の 空気
VC の 計算 (現在)
 半導体 = 必須・巨大・長期
 ソフト = 依然 人気、ただし 単独では 不足
昔は 逃げた 人たちが、
同じテーブル に 戻ってきた。

「とても 嬉しい」と 語る

発言者の 気持ち
  • 18年間の 孤独 が 報われた
  • 「嬉しい」 を 何度も 強調
  • 過去の 評価が 逆転
  • これから さらに 広がる と 期待
「わたしは とても 嬉しい」
ひとことで 18年の 重み が 伝わる。

教訓： 「少数の 正しさ」

この話の まとめ
  • 正しいと 信じる ことは 多数派と 違う
  • 時間は 味方に なる ことも ある
  • 「だれも 聞かない」は 始まり に すぎない
  • 需要の 波 が すべてを 変える
! 次の 「だれも 聞かない」は どこに？
いま さみしく 話している 人も、
10年後に 正しい かもしれない。
