1

Omniwork

Creative Desktop Agent OS
  • クリエイティブ 作業 向け のデスクトップ Agent OS
  • 動画 編集、音楽 制作、映画 監督 まで カバー
  • 専門 エージェント が協調 動作
  • 共有 メモリ で 好み や 基準 を 保持
クリエイター の 仕事 を
まるごと 支えるOS、
まだ Mac 向け だよ
2

AgentConnect

Self-Hostable Agent Layer
  • Claude Code、Codex、Gemini CLI を 統合
  • Slack・Discord・Telegram・GitHub へ 接続
  • 権限 と メモリ を 持たせて安全に
  • エージェント 同士 が協力する
オープンソース で
セルフホスト できる から
自分 の 環境で 動く よ
3

Argos

Chrome AI Assistant
  • Chrome 拡張 の AI アシスタント
  • ブラウザ 内 で タブ 操作・クリック・入力
  • Google Docs・Gmail・Sheets と 連携
  • フォーム 入力 や スクロール も自動
ブラウザ 上 の
お仕事 を そのまま
おまかせできる よ
4

Tines

Secure Team Automation
  • セキュア な 環境 で チーム が 構築
  • IT と セキュリティ が管理
  • アラート トリアージ、IT デプロイ 等
  • 財務 リクエスト 処理 まで 実行
企業 向け だから
ガバナンスが しっかり。
現場 と 管理 の バランス だね
5

DocsAlot

Docs for Humans & Agents
  • 人間 と AI の 両方 が 読める ドキュメント 基盤
  • GitHub・ヘルプセンター・API を 統合
  • MCPエンドポイント を 提供
  • ChatGPT・Claude・Cursor が 正確 に 取得
AI が 迷わず 読める
ドキュメントって
これから の 標準 かも
6

Fin (Intercom)

AI Customer Agent
  • Intercom の AI カスタマー エージェント
  • サポート・営業・EC の 全 工程 を カバー
  • Apexモデル で 複雑 な 問題 に 対応
  • 音声・チャット・メール・SNS に 対応
顧客 との やり取り を
全天候 型で こなす、
営業 チーム の 強い 味方
II 開発・運用・管理 を 支える エージェント 群
7

Soup CLI

Open-source Fine-tuning
  • 小さな GPU で 大モデル を ファインチューン
  • ストリーミング でVRAM 不足を 解決
  • Hugging Face・Ollama・vLLM・MLX 対応
  • オープンソース の CLI ツール
手元 の GPU が 弱く ても
大モデル を 育てられる、
個人 開発者 に うれしい
8

Bevel

Vendor-neutral Control Plane
  • ベンダー ニュートラル な コントロール プレーン
  • エージェント の 定義 をGitで 管理
  • コンテキスト・スキル・ツール・権限・ID を 所有
  • すべて を ファイル と して 持てる
特定 の 会社 に
縛られないから、
自分 で 支配権 を 持てる よ
9

Toolport

Local MCP Gateway
  • 全 MCP サーバー を1ポートに 集約
  • オンデマンド 検索 で トークン を 削減
  • セキュリティ フィンガープリント 付き
  • rug pull（すり替え）を 検知
ツール が たくさん あると
トークンが かさむ…
これ なら すっきり だね
10

Coldtea.ai

Post-code Software Delivery
  • コード の あと の「配送」を カバー
  • ターミナル・E2E テスト・本番 監視 を 統合
  • 自己 修復 テスト で PR を ゲート
  • 1つ の Mac アプリ に まとまる
コード を 書き 終わった
その あと が 本番。
テスト と 監視 を まとめて
11

Soloop

One-person Company OS
  • ソロ ファウンダー 向け の 1人 会社 OS
  • AI CEO・CTO・CMO・アナリスト が 協調
  • プロダクト を成長させる
  • ひとり なのに チーム の よう に
ひとり で 会社 を まわす
AI 役員たち、
なんだか 未来 っぽい…
12

Rindler

Post-login Web Automation
  • ログイン 後 の Web 作業 を 自動化
  • API の ない ポータル で 記録 を 取得
  • ステータス 確認・フォーム 送信 を 代行
  • ルート 変更 は 中央 で修復
API が ない 古い ポータル
こそ自動化 の
主戦場 なんだね
III ブラウザ・データ・CRM を 侵略 する エージェント たち
13

BrowserOS neo

Free AI-driven Browser
  • 無料 オープンソース の AI 駆動 ブラウザ
  • Chrome から ログイン を1クリックで 読込
  • Claude Code・Codex・Cursor が MCP で 接続
  • それぞれ の タブ で 並列 動作
複数 の AI が それぞれ
自分 の タブで 働く、
まさに 次世代 ブラウザ
14

Lightfield

AI-native CRM
  • 通話・メール・会議 から 顧客 を 構築
  • 顧客 の生きた 版を 管理
  • エージェント が パイプライン を 生成
  • 会議 の 準備 も 自動化
CRM が ただ の 名簿 じゃ なく
生きて 動くように なる、
営業 の 仕方 が 変わるね
15

Troopr AI

Slack Scrum Master
  • Slack ベース の スクラム マスター
  • スタンドアップ・レトロ・プランニング を 自動
  • 非同期 で実行
  • Jira と 連携 して 同期
毎朝 の スタンドアップ、
Slack でらくらく。
進行 役 も AI に まかせる

Firecrawl

Web Data API at Scale
  • Web データ API で 大規模 に 取得
  • 検索・スクレイピング・インタラクション
  • JS レンダリング・PDF 解析・Markdown 出力
  • MCP サーバー付き
エージェント に データ を 供給 する
ベース インフラ。
名前 の 通り 燃えてる よ

PromptBridge

Cross-LLM Context Transfer
  • 無料 の Chrome 拡張
  • ChatGPT・Claude・Gemini・Grok・DeepSeek 間 で 持ち運び
  • 会話 のコンテキストを 移動
  • 1クリック で 要約 と 注入
AI を 使い分ける 時代、
文脈が 飛んで しまう の を
これ で 解決 だね
