AI規制の 話に 原子力 を 持ち出す

議論の 枠組み
  • AIの 規制を 語る とき、過去の 技術 を 例にする
  • えらばれた 比較対象が 原子力 発電
  • 50年 ほどの 歴史の データ が ある
  • 「安全」と「成果」の バランス を 見える化
過去の 失敗を 知れば、
同じ 穴に 落ちなくて すむ。 歴史の 教訓

  • Elad Gil — 投資家 ・ 戦略家
  • Sarah Guo — 創業者 ・ 投資家

リスクの 先 に 何が あるか 見える。

フランス — 70% を 原子力 で

成功の 事例
70% 電力に 占める 原子力の 割合
  • 大きな 事故も なく 安全に 稼働
  • 豊富で クリーンな エネルギー を 実現
  • 国を挙げて 原子力 に 投資
「規制 ≠ 禁止」 の 見本。
うまく 回せば、リターンは 大きい。

米国 — わずか 18%、40年 停滞

停滞の 事例
18% 米国の 電力に 占める 原子力
  • 40年間、新しい 原子炉を 1つも 建設 していない
  • 規制が 重く、建設が 止まった
  • 結果、化石燃料 に 依存 しつづける
進まない ことが、
リスクを 増やす ことも ある。

日本 — 25% で 安全に 運用

中間の 事例
25% 日本の 原子力 シェア
  • フランスより 低いが 安全に 運用
  • 米国より は 前進 している
  • 規制と 実用の 中間点 を とる
極端に 走らない 国 は、
意外と 安定 することが ある。

3カ国 ならべると 見える

比較 一覧
🇫🇷 フランス 70%
🇯🇵 日本 25%
🇺🇸 米国 18%
同じ 技術 でも、国ごとに
結果が まるで 違う。そこに 答え が ある。

1970年代 — 安全 の 逆説

1970年代 — 安全 ロビー が 台頭

歴史の 転換点
  • 安全を 重んじる ロビー活動 が 活発化
  • 「リスクを 減らせ」 という 正しい 訴え
  • 規制が どんどん 厳しく なった
  • 結果的に 建設を 止めた のに 近い
動機は 正しくても、
結果 は 別物に なる。 パラドックス

安全が クリーンエネルギー を 阻害

皮肉な 結果
  • 原子力を 止めた 結果、化石燃料 へ 依存
  • CO₂ 排出が 減らなかった
  • 環境には マイナスの 影響
  • 「安全」が 環境を 傷つけた
リスクを 渡ぐために、
別の リスクを ふやしてしまった。

電力 ・ エネルギー での 代償

分野別の 影響
  • 電力の 安定供給 が 遠のく
  • 代替 エネルギーの 開発も 遅れる
  • エネルギー コストが 上がり 続ける
  • 産業の 競争力に しわ寄せ
目先の 安全 の ため に、
長期の コスト を 払う ことに。

医療 分野 でも 同じ 問題

同じ パターン
  • 承認 プロセスが どんどん 重く
  • 新薬の 開発コスト が 爆発的に 増加
  • 患者が 治療を 待つ 時間が 延びる
  • 承認されない こと による 犠牲 は 見えにくい
「見えない 犠牲」 が 一番怖い。
数字に 出ない から。

「安全」の パラドックス

本質的な 問い
  • 過剰な 安全 が 別の リスク を 生む
  • 目に 見える リスク だけを 避けようとする
  • 見えない 機会損失は 数えにくい
  • 「ゼロ リスク」 は 存在しない
安全と リスクは 表裏一体。
どちらか だけ は 選べない。

AI への 教訓 — 同じ 分岐点

AI は 同じ 分岐点 に 立つ

歴史の 繰り返し？
  • AIが いま、原子力 と同じ 場所 に いる
  • 規制の 強化を 求める 声が 大きく なる
  • いま の 選択が、50年 先 を 決める
  • 同じ パターン を 繰り返すか どうか
過去を 知っている のは、
私たち だけ。選べる のも 私たち。

3つの 軸 で 考える

考える 枠組み
  • 安全性 — リスクを どこまで 下げるか
  • リスク — 何を 許容 するか
  • 成果 — どんな 未来を つくるか
🔒安全 ↔ 針を どこに？ 🚀成果
3つ の 軸を 同時に 見る。
ひとつ だけ 見ると 必ず 失敗する。

針を どこ に 置くか

社会の 選択
  • 「針」の 位置 が すべてを 決める
  • 安全 に 倒しすぎると 停滞
  • 成果 に 倒しすぎると 無謀
  • 「ちょうど いい」 場所を 探す
正解は ない。でも、
場所を 選ぶ 責任 は ある。

無数の シナリオ が 可能

未来の 広がり
  • いま の 選択で 道が 分かれる
  • 対応できる 結果の 種類 が変わる
  • 医療 ・ 教育 ・ 科学 に 波及
  • 影響は 想像より ずっと 広い
AIは いま だけの 問題じゃ ない。
何十年も 続く 選択。

考察 — 賢い 選択 を する ために

バランスは 社会が 決める

だれが 決める？
  • 一部の 人だけ で 決めない 社会 全体の 問題
  • 立場の 違う 人が 話し合う 必要
  • 技術者 ・ 政策 ・ 市民 の 対話
  • 決めるのは 私たち 自身
「だれかが」 じゃ なくて、
みんなで 決める ルール が いる。

過剰規制の 本当の コスト

見えない 代償
  • 一番 大きな コストは 見えない
  • 治らなかった 病気、救えなかった 命
  • 減らせなかった CO₂、暖まった 地球
  • 失われた 時間 と 機会
請求書は あとで 届く。
払う のは 次の 世代。

賢い 選択を する ために

行動の ヒント
  • 歴史 から 学ぶ 習慣
  • 極端 に 走らず 中間点 を 探す
  • 見えない コストも 数えて 比べる
  • 前に 進む ことを あきらめない
安全も 成果も、
両方 目指して こそ 本当の 進歩。
