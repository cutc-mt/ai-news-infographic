① 大きな 転換 — 答える から 書く へ

従来は「質問に 答える」だけ

これまでの AI は、人が 聞いたことにだけ 反応する 受け身 の存在 でした。

  • ユーザーが 先に 質問 する 必要 が あった
  • 指示 が ないと 動き出さない
  • 過去 の 会話 は 文脈 として だけ 扱う
つねに「聞かれてから」
動く 仕組み だった

新しい AI は「物語を 書く」

Google は、あなたの データ から 人生 の ストーリー を 自動で 紡ぐ ツール を 静かに リリース しました。

  • あなたの 行動履歴 を 材料 に する
  • 誰も 聞いていない のに こちら から 提案
  • プロアクティブ が キーワード
答え を 待つのではなく
AI のほうから 語りかける

同じ エンジンで 2つの 形

ひとつの エンジン から、まったく 違う 2つ の 形 が 生まれます。

  • 朝の メール 今日 の 要約 を 朝 に 届ける
  • イラスト付き ストーリー 絵 と 文 で 一日の 物語
📭従来
受信箱 を 自分で 開く
✨新時代
AI が 朝 に 届ける
エンジンは同じ。
見せ方 だけ 変わる

② ひとつの アプリ ではなく、複数 製品で テスト

エンジン は 共通、皮 は 違う

Google は 単体 の アプリ として ではなく、同じ プロアクティブ エンジン を 複数 の 製品 に またがって 試しています。

  • 核 となる エンジン は 共通
  • Gmail・Calendar・Photos など に 組み込み
  • 場所 ごとに 効果 を 測る

③ 仕組み は 4つの ステップ

1

データ ソース を 1つずつ 接続

すべてを まとめて 渡す のではなく、ソース ごとに 個別 の トグル で オン/オフ できます。

  • Gmail メール の やり取り
  • Calendar 予定 と 予定表
  • Photos 写真 の履歴
  • YouTube 履歴 視聴 記録
  • 検索 履歴 調べた こと
まとめてではなく
1つずつ 指先で 選べる
2

無関係な 2シグナル から パターン 発見

ばらばら に 見える 情報 どうし を 組み合わせて、意味 のある パターン を 見つけます。

  • シグナルA: 購入 確認 メール
  • シグナルB: カレンダー の 予定
  • A+B → トレーニング ガイド を 生成
  • 同時に レストラン リスト も 提案
# 例: 2つの無関係シグナルを結合 if bought(gym_shoes) and has_event(marathon): make("training_guide") suggest("nearby_restaurants")
点と点 が つながって
新しい 価値 に なる
3

カスタム ビジュアル を 生成

ストック 画像 ではなく、その人 だけ の オリジナル アート を 描き出します。

  • 使い回し の 写真 は 使わない
  • Nano Banana 2 モデル で 生成
  • 文脈 に 合った 絵 が その場 で 出来上がる
誰かの 作品 ではなく
あなた専用 の ビジュアル
4

遅延 フィードバック ループ

間違い を その瞬間 に 直す のではなく、翌日 に 修正 を 反映 する 設計 です。

  • 即時 修正 は しない
  • 翌日 の 出力 に 修正 を 織り込む
  • 毎日 少しずつ 質 が 上がる
急がば回れ。
1日遅れで 確実に 進化

④ ビジネス 応用 — 4つの 使い方

応用1: リード スコアリング

読者 の 行動 を 見て、温かい 見込み客 を 自動で 見つけます。

  • ニュースレター を 開封 したか
  • チュートリアル を 見た か
  • 価格 ページ を 見た か
  • 3つ が 揃えば ウォーム リード
営業 が 自分で 判断 しなくて よくなる

応用2: コンテンツ 再利用

1つ の 録画 から、複数 の 形式 へ 自動で 展開 します。

  • 本編 の YouTube 動画
  • ショート 動画 に 短縮
  • ニュースレター の 記事 に 変換
# 1つの録画 → 3形式へ自動展開 source = "one_recording" outputs = [make_youtube(source), make_short(source), make_newsletter(source)]
撮るのは 1回。
広がるは 3方向

応用3: コミュニティ 維持

黙って しまった 会員 を 見つけ、最初に 興味 を 持った もの を もう 一度 提案 します。

  • 沈黙 した 会員 を 検知
  • 最初 の 関心 を 分析
  • その人 に 合った リソース を 提案
引き戻す のは
最初の ワクワク

応用4: オンボーディング

新しく 入った 会員 の 目標 に 合わせて、最初 の 進む道 を パーソナライズ します。

  • 会員 の 目標 を 最初に 把握
  • 目標 に 合った 開始 パス を 作成
  • 離脱 を 減らす 第一步
最初 の 一歩 が
人それぞれ 違う
