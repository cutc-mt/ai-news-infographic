レベル 1 — ノーコード（箱から そのまま）

Gemini App Enterprise

ノーコード
  • かつての Gemini Enterprise
  • ビジネス 向けの 完成品
  • 最小限の セットアップ で 起動
  • 導入 と ともに すぐ 使える
買ったら そのまま 動く。 開封の 手間いらず が 最大の 強み！

Conversational Agents

ノーコード
  • 会話型 の エージェント を 生成
  • チャットで 問いに 答える 形
  • 顧客対応や 社内 ヘルプ に
  • 開発 知識 ゼロで 構築 可能
「お客様と 会話する AI」を 簡単に 立ち上げられる 定番 道具！

箱から 出したら すぐ動く

レベル 1 の 強み
  • 手軽さ が 何よりの 売り
  • ビジネス ユーザーに 最適
  • セットアップの 時間を 短縮
  • 安定した 運用 を すぐ 享受
「作る」前に 使い始められる。 これが レベル 1 の 最大の 強み！

Gemini App の 中の 注目 機能 — NotebookLM

個人の AI リサーチ アシスタント

注目 機能
  • NotebookLM が 搭載
  • 膨大な 情報から 洞察 を 抽出
  • すばやく 理解 する のを 支援
  • 読む 量を ぐっと 減らす
まるで 専属の 調べ屋。 調べ物の 速度が 桁違いに なる！

学習 コンパニオン ＆ チューター

3 つの 顔
  • 学習 コンパニオン として
  • 個人 の スタディ チューター
  • 理解を 深める 対話
  • 分からない ところを ていねいに
勉強の 相棒 が ずっと そばに。 一人での 学びが はかどむ！

ビジネス ユーザーに ぴったり

こんな 人に
  • 現場の ビジネス 担当
  • コードは 書きたくない 人
  • すぐに 効果を 出したい
  • AI の 伴走 を 期待する 人
0行 書く べき コードの 量（レベル 1）

レベル 2 — ローコード（土台を 加工）

Agent Garden × Agent Builder

ローコード
  • Agent Garden で サンプル を 閲覧
  • Agent Builder で 形を 変える
  • プリビルドの ひな形 を 活用
  • 出発点 として すぐ 使える
種を まいて 育てる ように。 ひな形 から 自分仕様に 育つ！

用意された サンプル エージェント

ローコードの 強み
  • 既製品 の エージェント を 提供
  • それを カスタマイズ して 使う
  • 用途に 合うよう 微調整
  • 開発の 工数を 大幅に カット
「ゼロから」じゃ ないから はやい。 味付け だけで 自分流に！

データ 科学者 ＆ アナリスト 向け

こんな 人に
  • データを 扱い慣れた 人
  • 分析や モデリング の 経験者
  • アイデアを 形に したい
  • 本格 コードは まだ 不要
分析の 腕を AI に 拡張 したい 人のための ちょうどいい 道具！

レベル 3 — プロコード（すべて 自分で）

Agent Development Kit（ADK）

プロコード
  • ADK または SDK を 活用
  • コードを 書いて 構築 する 本格派
  • 細部まで 自分好み に 設計
  • 外部 システムと 深く 連携
# ADK で エージェント を 構築
from google.adk import Agent
agent = Agent(name="my_pro_agent",
              model="gemini-2.0")
agent.run() # 自由度は 最大化

熟練の 開発者・エンジニア 向け

ターゲット
  • コードを 書くのが 本分 の 人
  • 複雑な ロジック を 扱う 経験者
  • 既存の 基盤 に 組み込む
  • 制御を 自分で 握りたい
細部まで こだわる プロの 人に。 自由度 は この レベルで 最大！

高度な ロジック と 深い 連携

レベル 3 が 輝く 場面
  • 独自の 複雑な 処理 が 必要
  • 既存 システムと ディープ 連携
  • 社内の 基盤 への 組み込み
  • 挙動を 完全に 制御 したい
既製品では 届かない 領域。 こだわりの 一品 が 作れる！
