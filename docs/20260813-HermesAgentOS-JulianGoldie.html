Agent OS とは なにか

みんなで ひとつの脳 を つかう

Agent OS の かんがえ
  • 複数の AI が 同じ記憶 を 共有
  • 1箇所に すべてが ある
  • バラバラで 動く んじゃ ない
  • 記憶から 引き出す から 便利
それぞれの AI が おなじ記憶 で 動く。 これが Hermes の 最大の かくし味！

4つの 専門 エージェント

Chat ― 文字で はなす

その1
  • Hermes に 直接 メッセージ
  • いつもの チャット形式
  • 会話は 記憶に 蓄積
  • ほかの AI にも そのまま 引き継ぎ
一番 シンプルな 窓口。 ここから すべてが はじまる！

Apollo ― 声で はなす エージェント

その2
  • フル音声 エージェント
  • 声で 指示 → 声で 回答
  • キーボード 不要
  • 両手が あく 音声 操作
「ねえ Apollo」で 始まる。 話しかける だけで 仕事！

Oracle ― 24時間 リサーチ

その3
24h 自動 監視
  • 競合リサーチ を 自動で
  • スケジュールで 定期的に 実行
  • 変化が あれば お知らせ
  • 寝ている あいだも ずっと 監視
まるで 見張り番。 ライバルの 動きを 逃さない！

Astros ― キーワード 追跡

その4
  • キーワード を 追跡
  • コンテンツ アイデア を 自動収集
  • トレンドを 常時スキャン
  • ネタ切れの 不安が なくなる
星を 見上げる ように。 ネタを 勝手に 集めてくれる！

共有の 記憶 ― Obsidian Vault

Obsidian Vault が 記憶の 場

記憶の 中核
  • プレーン テキスト の 記憶層
  • 全エージェント が 読み書き
  • 一度 伝えれば 全モデルに 共有
  • 翻訳や 調整 は 自動
いわば 神殿の 書庫。 AI 全員が ここを 読みに くる！

どの モデルでも 同じ 記憶

モデル 超越
  • Claude でも 同じ 記憶
  • ローカル モデル でも 同じ 記憶
  • 無料の オープン モデル でも OK
  • 切替ても 文脈は そのまま
どの AI に きりかえても 覚えなおし いらず！

もう 同じ話を しない

最大の メリット
  • 説明の くり返し が 消える
  • 指示が 一瞬で 伝播
  • 時間の 節約
  • イライラ ゼロ
「前に 言った はず…」が ない。 心の しくみが 超すっきり！

Goal Mode と 安全の ガードレール

Goal Mode ― 1行 入れて 離れる

自律 実行
1 ゴール を 1行で 入力
2 あとは 席を はなれる だけ
3 何時間も かけて 自律的に 作業 
# ゴールの 例

目標だけ 伝えて まかせる。 まるで 弟子に いう よう！

危ない ことは 必ず 止まる

安全設計
  • リスク操作 は 一時停止
  • ファイル 削除 等 は 確認を とる
  • 「推測せず きく」設計
  • 確認後 は 自動で 再開
勝手に 壊さない。 安心して 離席 できる！

のんびり お茶を 飲める

離席の 余裕
  • 立ち去っても 大丈夫
  • 大事な 操作 は 必ず 戻って きく
  • 通知で 意思確認
  • ストレス なしの おまかせ
神話の 守り手 みたいに。 勝手に 進めて 時々 ききに くる！
