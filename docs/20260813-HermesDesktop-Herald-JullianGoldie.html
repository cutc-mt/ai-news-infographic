自分の ブラウザに つなぐ

Browser Connect ― そのまま 接続

接続機能
  • Chrome に 直接 接続
  • Brave も 対応
  • Edge も 対応
  • DevTools Protocol 経由
いつもの ブラウザに そのまま つなぐ。 ログイン状態も そのまま 活かせる！

Chrome 136+ の 落とし穴

注意喚起
  • デフォルトで debug port が開かない
  • そのままでは 接続 できない
  • 別の user-data-dir を 使う
  • これで 解決
# 別のプロファイルで 起動
chrome --user-data-dir=/tmp/hermes
  --remote-debugging-port=9222
新しい Chrome では ひと手間 必要。 この裏技を 覚えて おこう！

Session Recording ― 録画 つき

デバッグ支援
  • ブラウザ セッション全体 を 録画
  • そのまま 動画 で 保存
  • エラー箇所の 特定 に 便利
  • あとで 見かえせる
「どこで 失敗したか」が 映像で わかる。 デバッグが 圧倒的に 楽に！
