OpenClaw｜完了報告、もう手で送らなくていい

頼む時に一言そえるだけで、報告まで AI が届けてくれる
2026年8月13日 ／ チャンネル：あきらパパ
手作業の完了報告、どんなふうに?

結果を見て、要点をまとめる

報告を書く、いつもの流れ
  • 出てきた結果を、まずジックリ読む
  • 要点を、自分の言葉で書き出す
  • 伝える順番を、頭の中で組み立てる
  • この準備だけで、じわじわ時間がかかる
いま何が大事か、まとめる作業は人間のあれこれ

まとめたものを、チャットへ送る

書き終わったら、届ける番
  • 送り先のチャットを、探して開く
  • 文章を打ち込み、整えて送信
  • 届いたか、念のため見返す
  • これを、報告のたびに繰り返す
仕上げの一手間、毎回ちまちま積み重なる

報告のたびに、手が止まる

ちいさな割り込みの、積み重ね
  • いま進めていた作業が、途切れる
  • 頭の流れを、もう一度つなぎ直す
  • 報告が終わると、また元の作業へ戻る
  • この切り替えが、疲れのもと
報告そのものより、その前後の手間が重い
OpenClaw が報告を、届けてくれる

報告を書くのが、自分か AI かだけ

本質は、誰が報告を書くか
  • 自分で書く＝手動報告
  • AI に書かせる＝自動報告
  • 届く報告の中身は、おなじ
  • ちがうのは、誰が書くかだけ
報告を書く係を、AI に渡せるかどうか。それだけの話

Discord の DM やチャンネルで動く

OpenClaw が住むのは、いつもの場所
  • ふだん使う Discord の中で動く
  • DM でも、サーバーのチャンネルでも OK
  • 別のアプリに、乗り換える必要はない
  • いつもの場所で、頼んで、受け取れる
報告の港は、もうそこにある。新しく作らなくていい

結果を、そのまま同じ場所へ報告

報告の行き先は、ひとつ
  • 調査や資料チェックが、終わったら
  • 結果と次の行動を、短くまとめる
  • 同じチャットへ、そのまま届けてくれる
  • こちらは、通知を見るだけ

「結果と次の行動だけ」を、短く返す

報告の中身は、要点勝負
  • まず、いま終わった結果を伝える
  • 続けて、次にやることをそえる
  • 長々とは書かず、短くまとめる
  • 届いたら、すぐ次へ動ける
報告は結果＋次の手。この2つで足りる
手動報告 vs 自動報告

同じ報告でも、負担がちがう

書くのは誰か、それがすべて
項目手動で報告自動で報告
報告を書く人自分AI
送る手間毎回あるぜんぶ任せる
作業の途切れよく起きるほぼない
届く場所チャットおなじチャット
報告の中身自分の言葉結果＋次の一手
ちがいは「誰が報告を書くか」に、集約される

どんな時に、報告してくれる?

対象は、わりと自由
  • 何かの調査が、終わった時
  • 資料のチェックが、済んだ時
  • 時間のかかる処理が、終わった時
  • 要は「終わり」を、知らせられるものなら
報告したい作業を、言葉で伝えるだけで OK

頼み方のイメージ

頼む時に、ひとことそえるだけ
  • いつものように、作業を頼む
  • そのうしろに、報告のひとことをそえる
  • あとは、通知を待つだけ
// チャット欄に、そえるひとこと

頼む時に、ひと言そえるだけ

むずかしい設定は、いっさい不要
  • いつものように、作業を頼む
  • 「終わったら、結果と次の行動だけ報告して」と足す
  • それだけ。あとは、AI が届けてくれる
  • 通知が来たら、確認するだけ
今日は、たった1 つで十分。まず体験する

初めての 1 つ、候補まとめ

何を任せようか、迷ったら
  • ちょっとした調査を、頼む
  • 資料のチェックを、おまかせする
  • 時間のかかる処理を、任せる
  • どれも「報告」を、AI に書かせられる
まずは小さく1 つ。届いた時の軽さを味わう
先に決めておきたい、3 つのこと

1. 報告の送信先を、決める

どこへ届くか、はじめに決めておく
  • 報告を届ける場所を、決める
  • 自分宛ての DM が、いちばん手軽
  • チームなら、共有チャンネルもあり
  • あとで探す時に、迷わない場所を選ぶ
送り先さえ決まれば、あとは自動で届く

2. 公開して良い範囲を、決める

報告の中身は、誰の目に触れるか
  • 報告の中身に、秘密は含まれていないか
  • 届く場所が、誰に見える場所か
  • DM か、共有チャンネルかで、見え方が変わる
  • 迷う時は、まず自分宛てから
届く場所の公開範囲を、先に確かめておく

3. 失敗した時の止め方を、決める

いざという時の、非常口
  • 止める時の合図を、決めておく
  • 何かおかしければ、すぐ止められるように
  • 止めたあとのやり直しも、考えておく
  • これがあると、安心して任せられる
非常口を知っていれば、安心して走れる
報告で手を止める側に、もうならない

報告で手が止まる側に、なりがち

手動報告の、もどかしさ
  • いまの作業を、いったん止めて
  • 報告を、自分で書いて
  • 送って、また作業に戻る
  • このループが、ちりつもで重い
報告のたびに、集中が途切れるのがもったいない

AI に、報告まで任せる側になる

役割を、ひとつずつ分ける
  • 人間：作業する。通知を見たら、次へ進む
  • AI：結果をまとめ、同じ場所へ届ける
  • おたがい、得意なことだけやる
  • 結果、全体の作業が、スムーズに進む
報告まで任せると、自分は前に進むだけになる
