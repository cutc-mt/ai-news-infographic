「お願い」が一切不要。置くだけで完結するのが天才的なポイント！

Hooksとは何か

Claude Codeの便利機能

  • Claude Codeが持つイベント連動の仕組み
  • 指定したタイミングで好きな処理を自動発火
  • 設定は settings.json に書くだけ
「Hook＝針鉤」のように、特定の動作に引っかけて処理を走らせるイメージだよ

PostToolUse

ツール実行のあとに発火

  • AIがファイルをWrite（保存）した直後をフック
  • 対象はMarkdownファイルだけに限定できる
  • 保存 → 変換が一連の流れに
PreToolUse や Stop など、別の発火タイミングもあり汎用性抜群！

登録するのは1本だけ

変換スクリプトの設定例

  • 追加するPythonスクリプトはたった1本
  • Hookからその1本を呼ぶだけのシンプル設計
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Write",
      "hooks": [{ "command": "python md2html.py" }]
    }]
  }
}
※イメージです。実際はAIが環境に合わせて書いてくれます

賢い変換条件

フォルダが散らからない
