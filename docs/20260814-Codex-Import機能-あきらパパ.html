もう手で作り直さなくていい

設定も履歴も、そのまま引き継げる
2026.08.14 ／ あきらパパ
あきらパパが解説する Codex CLI の /import 機能。 別のAIで作った設定や履歴を、手作業なしで引き継ぐ方法です。

乗り換え時の 本当の課題

  • 新しいAIに変えるとき、一番つらいのはモデルそのものではなく設定の移し直し
  • これまでの指示や資料を、もう一度まとめ直す手間
  • 本来の作業に入る前に、準備だけで時間が溶ける
モデルは良くなったのに、
引っ越しで疲れちゃうんだよね……

手でコピーする 古いやり方

  • リファレンス、指示、ファイル設定を 1つずつ探して貼り直す
  • プロジェクトや過去のチャットも、手で探して持ってくる
  • 単純作業のくり返しで、ミスも増える
リファレンス 指示ファイル 過去チャット

集中力が 削られる問題

  • 移行作业だけで、頭のエネルギーが使われてしまう
  • 「本題」に入る前に、やる気が減っていく
  • 結果として、新しいAIの良さを活かしきれない
引っ越しだけで疲れるのは、
本当にもったいない！

Codex CLI の /import とは

  • 別のAIで作った設定や履歴を、そのまま持ち込める機能
  • Codex CLI 上で /import と打つだけではじまる
  • 手作業の貼り直しが、まるごと不要に
# Codex CLI を起動したら
/import
# 元のツールを選んで持ち込む

対応している ツール

  • Claude Code ／ Anthroph のCLIから引継ぎ
  • Cursor ／ エディタ型AIの設定を持ち込み
  • 選んだツールごとに、何を持ってくるか確認できる
Claude Code Cursor
まずは自分の使っているツールが
選べるか、見てみよう。

スラッシュコマンドでの 手順

  • 1Codex CLI を立ち上げる
  • 2/import と入力して Enter
  • 3元のツール（Claude Code / Cursor）を選ぶ
  • 4持ち込む項目を確認して、進める

何が引き継がれるの？

選んだツールごとに、持ってくる項目を自分で確かめてから進められます。

持ち込める 項目を確認

  • リファレンスや 指示のファイル
  • プロジェクトの 設定まわり
  • 過去のチャット（履歴）
何が移るか、自分の目で
確かめてから進められるよ。

直近 30日の チャット履歴

  • 公式ドキュメントでは 直近30日分 のチャットが対象
  • 最近の作業文脈を、そのまま新しい環境へ
  • 前回の続きから、スッとはじめられる
直近30日 チャット履歴

最大 50件 まで取込める

  • CLI では 最大50件 までチャットを取り込める
  • 件数の上限があるので、よく使う会話を意識して
  • 公式ドキュメントに書かれた、明確な制限
50件もあれば、ふだんの作業は
だいたいカバーできるね。

0から説明する 時間を減らす

  • 新しいAIに「前提」を 0から話さなくて済む
  • 準備の時間が減って、本題にはやく入れる
  • 引き継いだ状態ではじめるから、スムーズ

注意：設定を そのまま信じない

  • 取り込んだ設定も、必ず自分で見直す
  • 許可設定や接続まわりは、そのまま使わない
  • 使う前に、ひとつずつ確認するのが大事
持ってきたら終わり、じゃないよ。
ここからが本番だ！

許可設定の 見直し

  • ファイル操作や実行の 許可 がどうなっているか
  • 前のツール向けの権限が、新しい環境で適切か
  • 必要に応じて、緩すぎる設定は引き締める
許可設定 権限

MCP / Hooks / Plugins の確認

  • MCP 接続が、新しい環境で正しく動くか
  • Hooks（自動のきっかけ）の設定を点検
  • Plugins の接続も、使う前に見直す
接続まわりは、とくに念入りに。
勝手に動くと怖いからね。

公式ドキュメントを 参照

  • CLI の取込件数や期間は 公式ドキュメント に明記
  • 「直近30日／最大50件」も公式の説明
  • 仕様が変わることもあるので、本家をCHECK
