あきらパパが解説する Codex Remote の使いかた。 どこにいても、スマホひとつで開発タスクを進められる方法です。

コデックスに 頼んでも……

  • AIに仕事を頼んでも、何度もPCに戻る必要があった
  • 開始・承認・レビュー、そのたびに席を立つ
  • 結局、ずっとPCの前に張りついていないとダメ
外出しようと思っても、
途中で承認が必要だと帰らなきゃ……

開始するときも PCがいる

  • タスクをはじめるボタンを、PCで押す必要があった
  • 「よし、やろう」と思っても その場で開始できない
  • 戻るまでの時間が、もったいない
開始 PC必須

承認のたびに 席を立つ

  • コマンドの実行をその場で承認しないと進まない
  • 通知が来ても、確認はPCの画面で
  • 「承認 → 戻る → また承認」のくり返し
一番つらいのは、承認のたびに
帰らなきゃいけないこと！

差分レビューも PC画面で

  • 変更されたファイルの中身を確認するのもPC
  • 差分（どこが変わったか）を見るにも、その場で
  • テスト結果も、戻ってからチェック

ここで Codex Remote の登場

スマホがあれば、外出中でもタスクを止めずに進められる。

Codex Remote とは

  • 外出中でもスマホから開発タスクを進められる機能
  • 自宅のPCとつないで、遠隔で操作
  • PCの前にいなくても、仕事が前に進む
これで外出中でも、
開発が止まらなくなる！

ChatGPT アプリの リモート機能

  • ChatGPTモバイルアプリのリモート機能を使う
  • 外出先から、自宅のPCへ接続
  • アプリのなかから、リモートを選ぶだけ
モバイルアプリ リモート接続

PCと プロジェクトを選ぶ

  • 1接続済みの PC を選ぶ
  • 2取り組む プロジェクト を選ぶ
  • 3タスクの内容を入力して、開始
接続済みのPCから選ぶから、
すぐにはじめられるよ。

承認も スマホでできる

  • 途中でコマンドの承認が必要になったら……
  • スマホに通知が届く
  • 内容をスマホで確認してから、続けるか判断
帰らなくても、その場で
「OK」を出せる！

変更ファイルを スマホで確認

  • タスクが終わったら、変更されたファイルを確認
  • 差分（どこが書き換わったか）もスマホで見える
  • テスト結果も、いっしょにチェック
変更ファイル 差分 テスト結果

次に 進めるか決める

  • 結果を見て、このまま次へ進めるか決める
  • 問題なければ、次のタスクへ
  • 修正が必要なら、その場で指示
外でランチしながらでも、
次の判断ができる！

外出中の こんな場面で

  • ランチ待ちの時間に、承認をぽんっと出す
  • 電車のなかで、差分をざっと確認
  • 買い物の合間に、次のタスクを指示
すき間時間が、
開発の時間になる！

デスクトップアプリの 設定

  • まずはデスクトップアプリの設定を開く
  • Connections の項目へ進む
  • 「Control this Mac or PC」を確認
# 設定の流れ
Settings
  └─ Connections
       └─ Control this Mac or PC  ✓

動くための 前提条件

  • PCが起きていて（スリープしない）
  • PCがオンライン（ネットにつながっている）
  • 同じアカウントとワークスペースを使っている
この3つがそろってないと、
リモートが動かないよ！

PCは 起きたまま

  • スリープ設定だと、遠隔から呼べない
  • 電源をつなぎっぱなしで、起きておく
  • ネットも、切らさないように
スリープ禁止 常時オンライン

同じアカウント ＆ ワークスペース

  • スマホとPCで同じアカウントを使う
  • 同じワークスペースに属していること
  • これがそろって、はじめてリモート接続できる
アカウントが違うと、
つなげないから注意！

今日の 第一歩

  • 1デスクトップアプリの設定を開く
  • 2Connections → 「Control this Mac or PC」を見る
  • 3PCが起きていて、同じアカウントか確認
まずは設定を見るだけ！
今日は、それで十分。
