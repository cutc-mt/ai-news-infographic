土台 を つくる — 環境・ライブラリ・推論

④ Mise-en-Place — ひとつ で ざっくり

環境管理 CLI
  • ツール・環境変数・タスク を mise.toml に
  • Node・Python・Terraform・Go を 切替
  • 書かれている の は Rust — 軽くて 速い
  • 導入 と 切替 を 一本化
調理場 の 用意 の よう に、 開発環境 を 整頓。 名前 の 由来 も そこ から！

⑤ Guava — Google の Java の 玉手箱

コア ライブラリ
  • Google 謹製 の Java ユーティリティ 集
  • multimap・multiset 等 の 新コレクション型
  • イミュータブル な コレクション も 用意
  • 並行処理・IO・ハッシュ・グラフ
Java 書き なら ほぼ 必須 の 存在。 定番 の 困りごと を さらっと 解決！

⑥ DS4 — DeepSeek V4 を 手元 で

ローカル推論
  • DeepSeek V4 の flash・pro を 自前 マシン で
  • Mac なら Metal で 高速 動作
  • Nvidia は CUDA に 対応
  • KV cache を ディスク の 主役 に
クラウド に 頼らず、 手元 で 重い モデル。 データ を 外 に 出さない の も 強み！

どこ から 始めれば いいか わからない 人 に 最高 の 地図。 自己学習 の 強い味方！

  • OpenAI 互換 の エンドポイント で 統一
  • 接続先 の スコア を リアルタイム 計測
  • コスト・遅延・枠 で 経路 を 選ぶ
提供元 を いちいち 切り替えず、 好み の 条件 で 自動で 振り分け。 切り替え の 手間 が 消える！

コーディング AI が、 動画 まで 手がける 時代。 字幕 つき が 当たり前 に！
