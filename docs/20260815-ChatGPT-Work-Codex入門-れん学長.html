【Work・Codex入門】

探す・任せる・書き換える —— れん学長が普段の仕事でそのまま使っている手順
2026年8月15日公開
れん学長のAIツール実験室
01

ChatGPTが化ける

  • 「あの書類、どこに置いたっけ」を週に何回も言っていませんか?
  • 毎回アップロードして、完成した物は自分で保存し直す…これは慣れの問題ではなく、チャットには物理的にできない事が3つあるから
  • 放置すると、AIがどれだけ賢くても「探して・渡して・受け取る」の往復に時間を取られ続けます
ここを乗り越えると、名前を忘れた書類が1発で見つかり、完成した物がフォルダに「生えて」くるように!
探す→任せる→書き換える
02

チャットにできない3つの事

  • 探せない — 探す対象をアップロードできない
  • 置けない — 完成した物をあなたのフォルダに置けない
  • 書き換えられない — あるファイルをそのまま変えられない
探せない→探させる
置けない→置かせる
書き換えさせる
できない3つの裏返しが、今日の3段階です。この順番で実際の画面で進めます
03

土台:デスクトップのアプリ

  • ブラウザーで開くWeb版は賢いけれど、あなたのPCのファイルには触れられない
  • デスクトップのアプリなら、許可した範囲でPCの中のファイルに手が届く
  • MacでもWindowsでも使えます。ここが今日の土台
今日の話は機能を全部覚える話ではありません。入り口を選べるようになれば、ほぼそれで勝ち!
04

入口は3つ

  • チャット — 聞きたいだけならこれで十分
  • Work — PCのフォルダを直接いじってほしい時
  • Codex — さらに細かく、変更の過程まで見たい時
  • 左上の「ChatGPT」の部分で切り替え。チャットとWorkは2段構えで出てきます
ここで迷う方が多いので、分け方を2段階で整理します。これさえ分かれば使い分けはほぼ決まり!
05

WorkとCodex、どっち?

  • 完成した物だけ欲しい → Work
  • 差分や実行のコマンドまで見たい → Codex
  • できる事はほぼ重なる。違いは能力ではなく画面が何を中心に見せるか
れん学長は普段Codex。でも初めての人にはWorkがおすすめ。途中の結果を出してくれるので安心です
06

始め方と料金

  • chatgpt.com へ。右上の「サインアップ」から新しく登録(GoogleなどでOK)
  • デスクトップのアプリを入れたら、無料のプランでも Work / Codex は試せます
  • Plus(月1,400円ほど)なら追加の契約なしで両方とも使える。サブスクの中に実は入っている
使える回数の上限はプランごとに違います。まずは無料で試して、限界が来たら課金でもOK!
ちなみにClaudeも同じ型(チャット/CoWork/Claude Code)
07

学長が任せている日々

  • 収録した動画の文字起こしから記事の下書きまで作成
  • 記事に入れる絵やサムネも生成
  • YouTubeやノートの数字を夜ごと自動で記録。朝起きると分析のレポートが1枚できている
  • 案件のメールの整理や返信の下書きも任せる。判断だけ私がやる
本業は研究者。AIツールはほぼ毎日使い倒していて、今日の3段階はそのまま普段の仕事で使っている手順です
08

自作のダッシュボード

  • コンテンツ展開の表 — どの動画や記事をどこまで出したか一覧で分かり、出し忘れがすぐ分かる
  • 案件の管理の画面 — どの案件がどの段階かが画面だけですぐ分かる
  • 投資の記録 — 資産の推移をグラフで眺める画面まで自分好みに
一行もコードを書いていません。フォルダを開いて日本語で頼むだけで積み重ねました。市販のアプリに妥協する前提が崩れます!
09

段階1:探す

  • 普段のチャットで「PCの中から書類を探して」と聞くと、「Workで続けますか?」と提案してくれる
  • 「書類 / ダウンロード / デスクトップ」と広めに指定しても大丈夫
  • 全ファイルを開くのではなく索引と名前の両方で特定。約25,000件の中からでも
  • 2分49秒でCSVにまとめて、最新の資料も教えてくれる
依頼文の例:
書類・ダウンロード・デスクトップから
ChatGPT に関する書類を探して、
一覧を CSV にまとめて。
最新の物には対応して。
名前を忘れてふわっと頼んでも見つかる。ローカルのPCの中をAIが探してくれる実感が持てます!
10

権限とモデルの設定

  • モデルは GPT-5.6 の「Terra」(標準)と「Luna」(高速・精度は落ちる)などから選べる
  • フルアクセスがオンだと、承認なしにあらゆるファイルを編集してしまう
  • 最初は承認を求めるで1個ずつ。慣れたら代わりに承認(安全でない操作だけ確認)へ
権限の設定は安全の土台。許可を取る作業は時間がかかるので、慣れてきたら段階的に緩めるのがコツです
11

段階2:任せる

  • まず仕事の専用フォルダを切る。materials(入れ物)と output(完成した物の置き場)はAIが自分で作る
  • 覚えてほしいのはこれだけ:フォルダを選ぶことがAIへの許可になる
  • プロジェクトはローカルを選ぶ(PC上のファイルを編集・実行)
  • 読むだけなら広く、書かせる時は狭く。範囲の指定がポイント
許可 = フォルダの選択。この1行が「任せる」を安全にする鍵です
12

YouTubeの分析を任せる

  • 本物の分析のデータ(28日・90日・365日の3期間)を materials に入れてドラッグ
  • 依頼文:伸びたテーマのレポートを output へ + 来月の比較案を10本
  • 伸びた判断は「公開後30日の再生の数」「クリック率」「平均の視聴じかん」を提案
  • 4分11秒で完了。レポートと企画がフォルダに生えていた
無料のプランだと上限が来ました。Plus にして続行。CSVの集計のような大変な仕事こそAIに任せる価値あり!
13

魔法のひとこと

  • 依頼文に「始める前に不明点を教えて」を添えるだけ
  • 不明点を3つ挙げた上で、おすすめの進め方まで提案してくれる
  • 完璧な依頼文を頑張るより、聞き返させる方が楽で確実
依頼文の3つの部品:
① やってほしい範囲
② 最後に欲しい物
③ 始める前の質問
このひとことで依頼の精度が変わります。今日の依頼文はそのまま真似できるスタートキットに入れています
14

フォルダは育てる資産

  • AIの回答の質は、フォルダに何を貯めたかで決まっていく
  • CSVだけでなく、AIとの壁打ちの内容もファイルに書き出して貯める
  • 貯めるほど精度が上がり、分析の質も育っていく
フォルダはただの作業場ではなく、貯めるほど賢くなる資産。出力の結果もどんどん戻して育てよう
15

段階3:書き換える

  • Work から Codex へ切り替え。企画のリストを管理表に反映する作業を頼む
  • Git で管理され差分が見やすい。「+40 −0」のような変更がひと目で分かる
  • 「NotebookLM の企画を優先度3位へ」→ 変更前(赤)と変更後(青)を比較できる
  • デスクトップのアプリなら .md の表をその場で切り取って編集できる
変更の過程が見えるのが Codex の得手。どちらかというとエンジニア向けですが、差分が見える安心感は大きい!
16

Workでも差分は見られる

  • 「変更の前後の違いを比較のHTMLにして」と頼むだけ
  • 「変更前はこう、変更後はこう」と昇格の理由まで書いてくれる
  • できたページをプレビューで確認。すごく分かりやすい
差分の確認も Work で十分。プログラムを書かない人ならWork のままでOK!
17

つまずく5つの型

  • フォルダが大きすぎる → 限定して渡す。AIも迷わなくなり、消費も抑えられる
  • 依頼がふわっとしすぎ → 範囲・欲しい物・事前の質問の3点を思い出す
  • 完成した物を見ずに採用 → 検証を挟まないと良い資料にならない
  • いきなり権限を全開 → まずは承認を求めるモードで始める
  • 機能を全部覚えようとする → いま必要なのは「フォルダを1個作る」ことだけ
広いフォルダを渡す時は見られて困る物がないか必ず確認。秘密の文書は範囲から外しておこう
18

まとめとスタートキット

探す
任せる
書き換える
  • 安全の3点:フォルダを限定 / 自分で検証 / 差分を確認
  • スタートキット(概要欄と固定のコメント):依頼文3本・フォルダの型・練習用のデータ・つまずきの対処メモ
  • 人間の出番は判断だけ。使い方はAIに聞けばいい
身近な方に「一式を渡して、使い方はAIに聞いて」と伝えたら質問が来なくなった、という裏話も。次回はClaude Code編!
