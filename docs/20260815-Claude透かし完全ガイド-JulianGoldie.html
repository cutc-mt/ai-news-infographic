パート1: 何が起きたの?

Claudeの大型アップデート

  • Claudeが大きな変更を発表。生成テキストに不可視の透かしが入る方針
  • 対象は 2026年8月2日以降にリリースされる新モデル
  • きっかけは EUの新AI法への対応
  • 見た目は変わらない。でも内部にマークがひそむ
まず落ち着いて。動画全体を通じて「パニックは不要」が結論だよ!
安心して続きを読もう

「不可視ウォーターマーク」とは

  • 記事やテキストの内部に埋め込まれる目印
  • 人間の目では判別できない形でデータに残る
  • 目的は「AIが書いたもの」を外から検出できるようにするため
  • 実際の運用にはグレーな部分も多い、とJulianは補足
指紋みたいなもの。文章そのものは変わらなくても、そこに「サイン」が残るイメージ ✍️

背景にあるEUの新AI法

  • EUが定めた規制で、AI生成の見え方に透明性が求められる
  • Claude(Anthropic)は法対応として透かし導入を決定
  • 発表されたガイドラインには、まだ説明しきれていない部分も
  • 移行の区切りが 8月2日。この日を境に扱いが変わる
これはClaudeだけの話じゃなく、EU圏で動くAI全般に波及するルールのひとつなんだ 🇪🇺

パート2: 何がマークを残し、何を消す?

音声書き起こしでも付く?

  • 視聴者の質問:「たとえば音声の書き起こしをClaudeでやったら?」
  • 書き起こしでClaudeが内容を生成した部分には印が付く、という解釈
  • ポイントは「追加されたものすべて」に付くという考え方
  • ここは公式でも完全には説明されていないグレーゾーン
「丸ごとAI書き起こし」より「人間の下書き+α」の方が、印の範囲はせまくなるはず、という理屈だよ 🎙️

人間の記事+Claude編集の場合

  • 自分で書いた記事でも、Claudeに編集を依頼すると…
  • 編集が入った内容には透かしが残る
  • つまり「印がある=AI生成」では必ずしもない!
  • 印のせいでAI生成に見えてしまう誤シグナルも発生しうる
ここ大事!透かしの検出結果を鵜呑みにすると、人間の文章までAI扱いされちゃう落とし穴 😱

マークが「残る」ケース

  • 残る派リスト
  • Claudeの出力をそのままコピペした場合
  • 超長文ほど埋め込みやすく、印が強く出る
  • 下書きを文法の校正に通した場合も残る(これは厳しめ)
  • ドキュメント・ブログ・メールに貼り替えても消えない
「コピペ先が変われば消える」わけじゃないのがポイント。印はテキストと一緒に移動する 📋

マークが「消える/付かない」ケース

  • セーフ派リスト
  • 内容を自分の言葉で大幅に書き直すと消える見込み
  • 短いコンテンツ(2行くらいのSNS投稿)は埋め込みがむずかしい
  • ファイルの再フォーマットや変換で印が外れることも
  • 8月2日より前の旧モデルには適用されない(現時点)
公式ガイドラインでは「自分の言葉でしっかり書き直せば消える」と明言されてるよ ✨

旧モデルの扱いと今後

  • たとえば Fable 5 など現行の旧モデルには透かしが入っていない見込み
  • ただし遡って適用する方法をClaude側が模索中
  • 「今はセーフ」でもずっとセーフとは限らない
旧モデルを安心して使える期間は限られるかも。アップデート情報をときどきチェックしよう ⏳

削除ツールの登場予測

  • Julianの予想:透かしを除去するツールが今後いろいろ出るはず
  • 攻防は繰り返される、いわばいたちごっこ
  • だから今の段階で過度に怖がる必要なし
ツール頼みより先に、次のパートの「自衛の習慣」を身につける方が早いかもしれないよ 😊

パート3: Hermesを動かすベストモデル3選

Hermesとは?

  • 自律的に動くAIエージェント。Julianが日々運用している
  • 動かすモデルは自由に選べるのが強み
  • 用途に合わせて速さ・力・コストを使い分けるのが正解
「どのモデル1本で運用するか」より、役割ごとに最適な1本をあてがう発想だよ 🤖

① 速いモデル

  • スピード重視の1本
  • 応答が素早いので、チャットや軽い雑用に最適
  • 日常のルーチンタスクを滞りなく回す
  • 処理が軽いのでコストも控えめ
「とにかく聞いて、すぐ返して」を繰り返す使い方なら、速さが正義 ⚡

② 強力なモデル

  • パワー重視の1本
  • 推論力が高いので、複雑な指示も正確に処理
  • 長いエージェント作業や難しいタスク向け
  • 品質が求められる重要ジョブに投入
ここぞという場面だけ召喚して、あとは速いモデルに任せるのが賢い運用 🔥

③ 無料のローカルモデル

  • お財布にやさしい1本
  • 自分のパソコン上で動かせる無料モデル
  • データが外に出ないのでプライバシーも安心
  • API料金ゼロで好きだけ試せる
検証や学習、下書きはローカルで回して、仕上げだけ有料モデル。この組み合わせがコスパ最強 🏠

3モデルの使い分け比較

  • 速い:日常チャット・軽作業・頻度の高いタスク
  • 強力:難しい推論・重要なエージェント仕事
  • 無料ローカル:検証・学習・プライベート運用
  • 3本を状況で切り替えするのがJulian流
hermes_models = {
  speed:   "速さ最優先",
  power:   "品質しょうの勝負",
  local:   "無料で自宅サーバー",
}
モデル選びに「正解」はひとつじゃない。タスクに合わせて交換できるのがエージェントの自由さ 🔀

パート4: Obsidian活用とAgent OS

Obsidianを活用する

  • 動画で言及されたObsidianは人気のノートアプリ
  • ノート同士をリンクでつなぐことで知識がネットワーク化
  • エージェントの記憶置き場・第二の脳として使える
  • Markdownで書かれるので、AIとの相性が抜群
AIの成果物や指示をObsidianにためておくと、引き継ぎや再利用がぐっとラクになるよ 📓

Agent OSでスマホ管理

  • Agent OSを使えば、エージェントチームをスマホから丸ごと操作
  • 外出中でも指示・確認・停止が手のひらで完結
  • 複数エージェントの全体を一画面で把握
  • 進ちょくや完了の通知も受け取れる
動画の締めのオチはここ。「エージェントはPCの前で見張るもの」じゃなくなった、という話 📱

エージェント・チーム運用

  • 複数のエージェントに役割を分担させる
  • 速いモデルの担当・強力モデルの担当を分けて割り当て
  • オーナー(あなた)は監視と承認に専念
「自分が作業する」から「チームを率いる」へ。AI時代の働き方の中心はここにある 👥

安全に使うチェックリスト

  • Claude出力をそのまま公開しない。一度自分の言葉へ書き直す
  • 長文こそ注意。丸コピは印が残りやすい
  • モデルの切り替え(速い/強力/ローカル)を習慣化
  • ノートはObsidianに集約、運用はAgent OSでスマホから
透かしを「怖いもの」じゃなく「知っておけば対処できるもの」に。それがこの動画のメッセージ ❤️
