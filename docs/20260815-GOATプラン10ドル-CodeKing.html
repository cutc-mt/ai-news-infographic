フルウェイトと プライバシー

  • ゼロデータ保持（ZDR）を強制できる
  • 安い提供元では当たり前ではない品質の保証
会社のコードを扱う人も安心して使える設定
#13

セットアップは約2分

  • まず Node が入っているか確認
  • ターミナルで install コマンドを実行
  • Mac / Linux は cmd、Windows は cmdc
  • ブラウザのサインインで CLI を認可して完了
# install して起動
npm i -g command-code
cmd   # Mac / Linux
cmdc  # Windows
ほんとに2分。コーヒーが冷める前に終わる
#14

初期設定の流れ

  • /init で AGENTS.md を作成・更新
  • /model でモデルを選ぶ。途中の切り替えも自由
  • 雑用は安いモデル、難所は強いモデルへ、一撃で切替
# 最初に打つコマンド
/init
/model
モデルの切替がラクなのは、設定のうちで一番好きな部分

Taste 機能が凄い
