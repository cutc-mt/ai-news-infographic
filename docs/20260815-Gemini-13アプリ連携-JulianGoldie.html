13アプリの内訳

新しい13の連携を詳しく

仕事系: Granola & Otter.ai

会議 → ノート → アクション
  • 会議の内容を Granola や Otter.ai が記録
  • Gemini がそれを読んで、きれいな やることリスト に変換
  • 手書きメモの時間がまるごと不要に
コーチングや面談が多いチームは
効果がダイレクトに出やすい！

仕事系: Wix

Webサイトの編集とデザイン
  • Wix とつなげば、Gemini がサイトの中を直接編集
  • 「このページにこう書いて」と伝えるだけで ページ制作 が進む
  • コピーを書いて、形を整えて、公開までお任せ
「月に1ページ」が「週に1ページ」に。
見つかる機会がぐっと増える！

旅行・楽しみ系

5アプリで予定をまるごと
Fever GetYourGuide Localizer OpenTable Ticketmaster
  • 近くの 遊び・体験 をさがせる（Fever・GetYourGuide・Localizer）
  • OpenTable でレストランの予約をひとこと頼む
  • Ticketmaster でイベントのチケットを確保

音楽系

iHeartRadio & Pandora
  • iHeartRadio と Pandora が新登場
  • 「作業用のプレイリストをかけて」で 再生開始
  • Spotify とも並んで、音楽の選択肢がさらに増えた
聞きたい曲を探す手間も、
AIにおまかせできる時代に

家まわり系

Angie & Thumbtack
  • 家の修理や業者さがしは Angie と Thumbtack
  • 「水回りの修理を頼みたい」→ 信頼できる人 を提示
  • 実在の業者とのマッチングまで Gemini が仲介
仕事に使うツールだけでなく、
「日々のくらし」にも手が届き始めた！
ビジネスでの使いどころ

会議をまるごと自動化

Granola / Otter.ai 活用例
  • コーチング・導入の面談・作戦会議が毎週あるCommunityを想定
  • 以前: メモを取り → タスク化 に 何時間も
  • 更新後: Granola / Otter から会議を引き出し 自動でリスト化
  • 浮いた時間は制作やメンバー支援に回せる

サイト成長を加速

Wix 活用例
  • 新ページ: 執筆 → 整形 → 公開を手作業で 1日がかり
  • Gemini に伝えれば Wix 内で 自動で構築
  • 公開ペースが上がり、見つかる機会と申込みが増える
「1か月に1枚」が「1週間に1枚」。
これが積み重なると差になる！

イベント運営とリード獲得

GetYourGuide / OpenTable / Ticketmaster
  • メンバー向けの オフ会 開催を想定
  • 以前: 会場・食事・チケットを 5つのタブ で手さがし
  • 更新後: 3アプリ連携で 一括で候補を取得
  • 手間を減らして、集客の時間を増やす

1つの動画がコンテンツに変わる

制作の"エンジン"化
  • 動画1本には ノート・メルマガ・SNS投稿・Community投稿 が必要
  • 台本1つ → メルマガ + SNS + ふりかえり投稿 に展開
  • 1日の収録が コンテンツエンジン に化ける
「1本で終わり」から
「1本から何個も生まれる」へ！

サポートとコミュニティ運営

問い合わせの山を整理
  • Community拡大 → 毎週 数百の質問 が届く状況
  • AI が質問を仕分け → 返信の下書き → 前向きな人 に印付け
  • チームは「最も準備ができた人」に集中
  • 同じ質問のループに溺れずにすむ
採用を増やさずに、
規模を追いかける仕組み！
設定方法と注意点

オンにする手順

パソコンから数ステップ
// Gemini で連携をオンにする
1. Gemini を開く
2. 設定 → 接続済みアプリ
   (見つからないときは
    パーソナルインテリジェンス
    → 接続済みアプリ)
3. 好きなアプリを オン にする
4. 画面の指示に従って完了
  • オフに戻すのも いつでも好きなとき にできる
  • 入力欄に @Wix @Spotify と書くと使うアプリを直接指定できる

おことわり: すぐそろわない点

正直に知っておきたい3つ
  • 国・言語・機種・アカウントの種類で 見えるアプリが違う
  • 展開は 数週間がかり。一斉に全部ではない
  • アプリや情報に触れる前には あなたの許可 が必須
勝手に個人のデータを取らない仕組み。
主導権はちゃんと自分の手の中！
