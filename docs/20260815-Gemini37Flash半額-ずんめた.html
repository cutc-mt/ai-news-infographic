「ワークホース」とは

  • Google がこのモデルを呼ぶ名前が ワークホース
  • もとは毎日荷物を運ぶ馬のこと → 転じて 普段使いの主力
  • 一番賢いモデルは別にいる。これは毎日回す担当
  • 指示を受けると途中の手順は自分で進める エージェント 向け
  • もう一つの得意分野は コーディング
一番速い馬じゃなくても、
毎日走る馬が仕事をするのだ！

3週間での交代

  • 前の 3.6 Flash から、わずか 3週間 で入れ替え
  • 3週間前に買ったばかりの機械が交代する速さ
  • 入れ替えの速さそのものが、のちほど出る 落とし穴 の一つに
交代が早いのは良いことなのだ…
でも確認し直す手間が増えるのだ。

賢くなった根拠

  • 「安くした代わりに性能を落とした」のではなく 賢くして値段を下げた
  • 数字は Google が公式に出しているもの
  • 画面写真やデザイン案を渡した時の 再現性 も向上
  • 少ない指示で形になるようになった
見た目をそっくり作るのが
うまくなったのだ！

「導入価格」の期限

  • 公式の書き方は 導入価格
  • 意味は 最初だけの特別価格
  • 期限は 年内まで
  • 年が開けたらどうなるか → 今回の発表には書かれていない
硬い言葉には訳があるのだ。
「年内は試す期間」と考えるのが安全なのだ。

入り口は3つ

  • ① 開発者 API ／ Google AI Studio → 半額の恩恵をそのまま受ける
  • ② 会社向け Gemini Enterprise → 法人が丸ごと契約する窓口
  • ③ 個人 → Gemini アプリの中の Spark 経由のみ
  • 対象は 160カ国以上、ただし除かれる国もある
入り口が3つに分かれているのが
今回の一番の見どころなのだ。

個人の使える道

  • 個人向けの入口は Gemini アプリ内の Spark エージェント だけ
  • アプリを開けば誰でも、ではない → Pro / Ultra 加入の人限定
  • 160カ国以上で使える一方、対象外の国 もある
僕が払ってる分が安くなる話では
なかったのだ…

誰の値段が下がった？

  • 月額を払っている人の支払いは 変わらない
  • 安くなったのは 作る側が払う値段
  • API で仕組みを作る人・会社への値下げ
ここが一番間違いやすいところ！
「僕の支払いが半分」ではないのだ。

Spark の中身が交代

  • 発表と同じ日に、Spark の中身が地味に 3.7 Flash へ入れ替わり
  • いわば「中の人が交代」した状態
  • 値段はそのまま → 頭だけ良くなった 状態
  • 個人にとっては今回 一番おいしい変更
支払いは変わらず中身だけ賢くなるのは
ちょっと嬉しいのだ！

Workspace 連携

  • Spark は指示を受けて動き続けるエージェント
  • 今回 Google ワークスペースの道具の使い方がうまくなった
  • 公式が上げた例 ① ファイルの集約
  • ② メールの下書き
  • ③ 状況をまとめた 文書の更新
資料を集めて報告を書くのが
一続きでできるのだ。

作業をつなげる

  • 今回の改善点は 作業をつなげた依頼 の出来栄え
  • ① ファイル集約 → ② メール下書き → ③ 文書更新 を一つの流れで
Spark への依頼イメージ:
  1. 関係ファイルを集めて
  2. 状況をメールで下書き
  3. まとめ文書を更新して
月の終わりの報告仕事が
少し楽になるかもしれないのだ。

落とし穴3つ

  • ① 年内までの値段 — 年明けは未定のまま。戻ったら困る
  • ② 入れ替えの速さ — 前と同じ答えが返るとは限らない。確認し直す作業が増える
  • ③ 安全対策も更新 — 兵器の作り方やサイバー攻撃への悪用を防ぐ側も強化
  • 賢くなるほど、止める側も強くする必要がある
いいことばかりに聞こえたら
よーく確認なのだ！

値段で選ぶ・頼る

  • 値段で選ぶことと 値段に頼って作る ことは別
  • 選ぶのは今日決めて明日で戻せる
  • 仕組みに埋め込むと、値段が動いた日に 設計ごと崩れる
  • 年明けに値段が上がれば 作り直し
安さは試すには十分、
でもまだ前提にはできないの。

線引きの結論

  • 年内は試す期間
  • 仕組みに入れるのは 次の値段が出てから
  • 方針は「触るのは今、決めるのは後」

こうしておけば値段が動いても
慌てずに済むのだ！

まとめ3点

  • ① 賢くなって半額は本当 — 試験の点も前より上がっている
  • ② 半額は 年内までの導入価格 — 年明けはまだ分からない
  • ③ 個人の入口は Spark だけ — 支払いは変わらず中身だけ良くなる
