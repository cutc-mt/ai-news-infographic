Hermes・OpenClawとの違い

性能だけじゃなく とっつきやすさ で差をつけた、という話

「私自分でできるかな…」という不安を、ふきとばしてくれる 簡単さ

② セットアップ手順(実況どおり)

Step1: 名前をつける

  • test agentに新しい名前を付ける
  • 動画では 「CEO」 に変更
  • 役割に合わせた命名がおすすめ
agent name: "test agent"
        ↓ 変更
agent name: "CEO"
名前=役割にすると、あとで見返したとき分かりやすいよ

Step2: タイトルと説明

  • タイトル を設定
  • 説明 も一緒に入力
  • エージェントの担当を、ここで明確化
「何を任せるか」を書いておくと、挙動がブレにくい!

Step3: 通知のON/OFF

  • 通知を付けるか、切るか選べる
  • 動画では OFFに設定
  • 理由は「他の作業に集中したいから」
邪魔されずにすむ、って大事。自分のリズムで付き合える 通知コントロール

Step4: 最初の集中先を聞かれる

  • day-to-day ops(日々の業務)
  • SEO
  • inbox(受信箱)
  • calendar(カレンダー)
  • something else(その他)
「最初は何に集中する?」と聞かれたら、動画では inbox & calendar をチョイス!

③ Gmail・カレンダー連携と、細かい整理

接続先を選ぶ

  • どこにつなぐ? → Gmail を選択
  • カレンダー も同じ要領でOK
  • 選ぶと、アプリへのリンクが進む
動画ではまずGmailだけ接続。少しずつ増やしていくのが安全策

認証してログイン

  • authorize(認証)をクリック
  • メールアカウントのどれかでサインイン
  • これで連携は、ほぼ完成
connect Gmail
  → authorize
    → sign in (email account)
難しいトークン発行とかナシ。クリック数回でつながる!

整理のためのメニュー

  • ピン留め してすぐ開ける
  • 新しいセクション へ移動
  • 既読 にする
  • プロフィールを 編集
  • 複製 ・会話をコピー
  • サイドバーから 非表示
エージェントが増えても、ここで整理整頓。チャットツールみたいな感覚!

選んだらロード開始

  • inbox & calendar を選ぶと 読み込みスタート
  • しばらく待てば、準備完了
  • 以降は裏側で、よろしくやってくれる
待ってる間にコーヒーでも。セットアップはほんの数分

④ 使い心地と、活用シーン

チャットアプリみたい

  • 操作感は Telegram・WhatsApp に近い
  • 話しかけるだけで、仕事が進む
  • 「AIを操作」より「友だちに頼む」感覚
普段づかいのメッセージアプリと同じだから、ストレスがほぼゼロ 親しみやすさ

用途ごとに会話を分ける

  • inbox係の 会話ルーム
  • calendar係の 会話ルーム
  • テーマ別に、さい配が分かれる設計
chat: "CEO - inbox"   # メール担当
chat: "CEO - calendar" # 予定担当
「AI専用版テレグラム」を、用途の数だけ持てるイメージ!

ログオフ後も稼働

  • 画面を閉じても バックグラウンドで動作
  • 日々の業務(day-to-day ops)を、よろしく処理
  • 戻ってきたら、結果をチェックするだけ
寝てる間もメール整理&予定管理。専用クラウドPCがあるからこそ、できる芸当

任せられる日々の仕事

  • Gmail の読み込みと仕分け
  • カレンダー の確認・調整
  • daily ops のルーチンを自動化
まずは小さい作業から丸投げ。慣れたら範囲を広げよう

⑤ まとめ:何がすごいのか

市場リーダーへの対抗馬

  • いまの 市場リーダー への強力な挑戦者
  • 勝負軸は性能ではなく 使いやすさ
  • 名前・説明・通知・接続を、自分で決める
「強い」より「使える」を取った設計。多くの人に刺さるはず

今日から試せる4ステップ

  • test agentに 名前 を付ける(例: CEO)
  • タイトル・説明・通知を 設定
  • 集中先 を選ぶ(inbox / calendar など)
  • Gmailを 接続 して、あとは会話するだけ
手順はこれだけ。最初の一歩は、名前を付けることから Let's try!
