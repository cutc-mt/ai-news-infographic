#02

エージェントのチーム

1体ではなく「チーム」

  • Grokbot は チーム型 のAIエージェント
  • 複数のエージェントに、それぞれ役割を任せられる
  • 対象ごとに別の会話をもって進行
“部下をふやす”感覚で、エージェントを追加できる！
#03

クラウドの専用マシン

それぞれのコンピュータ

  • 各エージェントがクラウド上に自分の専用PCをもつ
  • あなたの手元のPCは、そのままでOK
  • ネット上の自分の部屋で、こっそり作業
手元のPCのパワーを使わないのがポイント！
#04

アプリへログイン

あなたの代わりに操作

  • Gmail やカレンダーなどに接続
  • 承認さえすれば、代理でログインして動く
  • こまかい手順もエージェントが処理
はじめて使うときだけ、自分でサインインして許可をだそう。
何ができる?
#05

複数ステップの作業

工程ごとこなす

  • 1つの依頼に multi-step で対応
  • 途中の工程も、自分で判断して進行
  • 終わったら結果をまとめて報告
#06

閉じても動き続ける

離れていてもOK

  • PCを閉じて、その場を離れても作業をつづける

  • そのあいだ、あなたはコーヒーでものんで待てる
「ふんだら、あとは任せる」ができる時代！

Gmail・カレンダー連携

つなぎ方はかんたん

  • 接続先を選ぶ(Gmail / カレンダー)
  • 承認して、メールにサインインするだけ
  • 「すべて選んで続行」で設定が完了
// 連携の流れ
1. 接続先を選ぶ → Gmail / カレンダー
2. 承認 → アプリへリンク
3. サインイン → すべて選択 → 完了!
