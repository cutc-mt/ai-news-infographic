パート2: バックグラウンドで動き続ける (01:52–04:12)

バックグラウンドエージェントとは

01:52 Background Agents
  • 画面を閉じても動作が継続
  • セッション切れで止まらない永続設計
  • 人の見守りを前提としない運用モデル
  • ローカルでもリモートでも稼働可
いままでのAIツールは「放置」すると止まっちゃった。常駐型はそれを解消！

メモリのしくみ

01:52 Background Agents & Memory
  • 作業内容を記憶として保存
  • 再開時に前の文脈をそのまま復元
  • プロジェクトの経緯も長期で保持
  • 「なにをやっていたか」を忘れない設計
金魚脳のAIじゃなくて、昨日の続きから始められるのが画期的。

インストール手順

06:48 How to Install
  • ターミナルからコマンド一発で導入
  • APIキーなどの初期設定は画面の指示に従う
