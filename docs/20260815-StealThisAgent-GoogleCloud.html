Steal this Agent 〜 金曜の午後を取り戻そう 〜

Gemini Enterprise の Agent Builder で、 AIチームメイト を作っちゃおう

2026.08.14 公開 / Google Cloud Tech / 動画レポート

#01

金曜の午後が消える

  • 週の締めにやる 週次レポート の下書き
  • Drive の資料をかき集めて確認
  • Gmail のやりとりを掘り返す
  • Chat の発言も拾い忘れチェック
  • 気づけば 午後いっぱい が溶けている…
「コーヒーを飲むひまもない」
これ、毎週やってない？
#02

AIチームメイトとは

  • 一緒に働く 仲間AI として設計する
  • 「お願いしたら下書きまで用意」してくれる
  • 人間は 確認と仕上げ に専念
  • 毎週くり返す作業を任せっぱなしに
ツールじゃなくて
「同僚」として育てるのがコツ！
#03

Agent Builder の概要

  • コードを書かずにエージェントを 組み立て
  • 指示・データ源・出力の形式を設定で指定
  • Workspace の各サービスと接続できる
  • 作ったら動かして、直して、を繰り返す
開発は不要。設定が主役の
ローコードな体験だよ
#04

Gemini Enterprise の位置づけ

  • 仕事向けの 法人プラン で使える
  • 社内データを安全に活かす前提の設計
  • Agent Builder はその中の 作る場所
  • 個人からチーム、全社へ広げられる
すでに Workspace を
使っている組織なら相性◎
#05

Drive 連携

  • プロジェクトの ドキュメント を参照
  • 設計書・議事メモ・数値データを収集
  • 必要なファイルを AI が探して読む
  • 見せていい範囲は 権限どおり
Drive の資料 → 参照 → レポートの材料に
#06

Gmail 連携

  • 週の メールのやりとり を振り返る
  • 依頼・決まった事・保留中を拾い上げる
  • 重要な一文を引用して根拠に
  • 見る相手・ラベルを絞るのも自在
「あの返事どうなったっけ？」
もAIが代わりに確認！
#07

Chat 連携

  • チームの スペース の流れを把握
  • その場で決まったことを拾う
  • 誰が何を進めたか一目で整理
  • 未読の山とおさらば
散らばった会話こそ
週次レポートの宝庫だよ
#08

下書きが生まれるまで

  • 金曜の朝にエージェントへ 依頼
  • Drive・Gmail・Chat を横断して収集
  • 進ちょく・課題・予定に 分類
  • レポートの形に整えて 下書き提出
頼む → 集める → まとめる → 下書き
#09

プロンプトの設計

  • 役割 を明示：「週報を任された仲間」
  • 見出し構成と項目を指定する
  • 長さ・口ぶり・読者を 固定
  • 動画のコメント欄で 全文 を公開中！
「Steal（盗む）」の名のとおり
プロンプトはコピペでOK！
#10

セキュリティと権限

  • エージェントは 自分の権限 の範囲で動く
  • 見えない資料は AI にも見えない
  • 人間が 最後の確認 をしてから送信
  • 社内のルールとも合わせて運用
権限の壁はそのまま守られる
安心して任せられる設計
#11

導入のステップ

  • Gemini Enterprise を 用意
  • Agent Builder で土台を作る
  • Drive・Gmail・Chat を 接続
  • 自分の週で 試し運用
  • 良くなったらチームへ広げる
#12

カスタマイズのコツ

  • 社内の 書式 に合わせて調整
  • 冒頭に「一言サマリー」を入れる
  • 課題は赤く、予定は箇条書きに
  • 英語チーム向けは 英語で出力 にも切替
出力を見て指示を直す
を2〜3回やれば形になる！
#13

他の業務にも応用

  • 会議の 議事メモ を自動で下書き
  • 数値を集めた KPIまとめ
  • 客様向けの日報・週報も同じ型
  • 職場の「毎週やる事」はぜひ候補に
週報で型を作れば
あとは流用するだけ！
#14

コストと効果

  • 毎週 数時間 の下書き作業を圧縮
  • 作るのは 設定だけ で開発費ゼロ
  • 確認は人がやるので 品質キープ
  • 浮いた時間を企画や対話に充てる
作業 3時間 → 確認 30分 に変えていく
#15

日本の職場で使うなら

  • 朝礼向けの ひとこと報告 作成
  • 上司への連絡も下書きから
  • 日報・週報・月次を同じ流れで
  • まずは 社内に公開した資料 から試す
「報連相」の報をAIが下支え
してくれる時代に！
#16

つまずきポイント

  • 指示が曖昧だと 長文 になりがち
  • 参照できる資料が少ないと薄くなる
  • 権限がないファイルは読めない
  • 初回は必ず 人手で確認 を
うまくいかない時は
「指示」より「材料」を見直そう
#17

始め方 まとめ

  • 動画のコメントから 手順と文面 を入手
  • プロンプトをそのまま 貼り付け
  • Drive・Gmail・Chat を接続
  • 今週の金曜から 実践
コメント欄 → コピー → 接続 → 実行
