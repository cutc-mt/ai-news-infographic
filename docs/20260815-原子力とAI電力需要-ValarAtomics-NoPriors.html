#01

Valar Atomics とは

  • 本拠地は米ユタ州 San Rafael の原子力施設。番組は施設内で収録
  • ミッション: 原子炉を「惑星規模」で広める planetary scale
  • 建設するのではなく 製造する 原子炉を目指す
  • 目標は人類のエネルギーコストを 10分の1 にすること
  • 原子力には Ford モデルT や Tesla の瞬間がまだ無い、と指摘
核分裂自体は1940年代からの古い技術。でも「大量生産」だけ、まだ誰も成し遂げていないんだ。
#02

創業者 Isaiah Taylor

  • 曽祖父が マンハッタン計画 の原子核物理学者。曽祖母も「秘密都市」に勤務
  • 6歳の頃から「何千台もの機械を作る」のが天命だと思っていた

高校生の頃に導いた「なぜ止まったのか」の答えは、今も同じ結論だと言う。
#03

なぜ米国は止めたのか

  • 原因は単純: スリーマイル島 事故（1979年）
  • 軽水炉は停止後も冷却が必須。冷却喪失で 炉心溶融 へ
  • しかし死者ゼロ・負傷ゼロ・住民への被曝もゼロ
  • 問題は失敗した 広報と世論。恐怖が原子力の支持を消した
  • 一度止めた産業は、再開がとても難しい。サプライチェーンも技能も失われた
技術が悪いのではなく、あの日から「止まったまま」だった。それが50年続いたわけ。
#04

土木から製造へ

  • かつての米国は橋・ダム・高速道路・巨大原発など 大型土木 の名手だった
  • その技能は 衰退。代わりに先進製造業が伸びた
  • 原子力の再起動は1960年代の再現ではない。工場で作る 方式になる
  • これが一般に言う SMR（小型モジュール炉）の発想
  • Valar が付け加えた点: そこに至る道は ハードウェア反復 でしかない
設計思想だけのSMRでは足りない。実際に小さい炉を回して、学んで、段階でかくのだ。
#05

「ペーパーリアクター」業界

  • 規制との間には 鶏と卵 問題があった
  • 認可には実機データが要る → 実機には認可が要る、という袋小路
  • 業界の解決策は モデリング&シミュレーション。つまり大半が「紙の原子炉」会社
  • 理論上の挙動を高精度で予測する美しい文書を作り続けてきた
  • Valar の対極: 実際に炉を回す ことでデータを生む
「会社は、その会社がしていることである」— 原子を割るまでは、自分たちを原子力スタートアップと呼ぶのを禁じたほど。
#06

DoE の隠された経路

  • 米国の原子力法には当初、2つの道があった: 商用(NRC) と 試験(ERDA→DoE)
  • 原子力委員会を分割し、商用量産はNRC、試験はERDA（後のDoE）と分離
  • この「試験の権限」は約40年、法の上で 忘れられた ままだった
  • トランプ政権の大統領令 EO 14301: 7月4日までに3基の先進炉を臨界に、と指令
  • Valar の炉は DoE 権限のもと、この令で 初点火。鶏と卵問題を打破
DoE の起源は「原子炉を試験する機関」。鍵は最初から法律の中に埋まっていたんだ。
#07

管制室ツアー

  • 入室には上級原子炉操作員の許可が必要な 管制区
  • 管制室ごと C-17輸送機 で空輸 — 過去に例のない搬入
  • 操作は1名の原子炉操作員＋監視する上級操作員の 2人体制
  • 例の 赤い大ボタン でスクラム（緊急停止）: 制御棒が落ち、炭化ホウ素が中性子を吸収
  • 収録時点でも毎秒 10の17乗個 の原子を分裂させ運転中
「ホーソーン（試験施設）の管制室そのままだよ。文字どおり機体に積んでここへ運んだ」
#08

スクラム実験: 受動的安全

  • 停止後も 崩壊熱 が出続ける（全出力の5〜6%）
  • 従来炉は停止後も約24時間、冷却ポンプを回し続ける必要
  • Valar の実験: スクラム直後に 全電源を落とす。循環器もポンプも全部停止
  • 炉心周の水ジャケット RCCS が自然循環へ移行。沸騰→凝縮で熱を除去
  • 可動部ゼロ・操作ゼロ。幾何学そのもの が2日かけて崩壊熱を捨てる
scram → 全安全系シャットダウン
  → RCCS 自然循環（可動部なし）
  → 2日間かけて崩壊熱を放出
  → 炉心は物理的に溶けない
ホーソーンで電気シミュレータ（LA市街15ブロック分の電力！）を使い、全電源喪失を事前に再現済み。今回は本物の中性子で実証。
#09

安全性の2つの誤解

  • 誤解1: 原子力は「安定的だが危険」→ 実は 実証上 最も安全 なエネルギー
  • 発電量あたりの死者数は 太陽光より少ない（屋根からの転落事故の方が多い）
  • 誤解2: リスク低減は「発生確率」を下げるもの、という思い込み
  • 先進炉は 帰結(コンセクエンス) を消す方向で設計
  • 安全審査の前提: 「炉内の全てが故障した」と仮定 しても公衆被曝なし
確率は確率的。想定外は必ず来る。だから「何が起きても物理的に溶けない」構造こそ量産に効く。
#10

ハードウェア実行の問題

  • 原子力企業を2種に分類: 設計問題派 vs 実行問題派
  • Valar は断然 后者。「作れるか・点火できるか・量産できるか」こそ問い
  • 例え話: 目指すのは ランボルギーニでなくトヨタ・カムリ
  • 複雑で希少材料に依存する「美しい設計」は供給網ごと作らねばならない
  • 1基の性能でなく 1000基のコスト で勝負。単純・低価・安全を大量に
少し効率の良い高級炉より、粗削りでも数を張る方が、結局 世界一の安さになる。
#11

Ward 250 の快挙

  • スタートアップ初 の発電に成功した先進炉
  • 国立研究所の外で作られた初の先進炉でもある
  • 2000年以降、米国で発電した 5番目 の新しい核装置
  • デルaware州での設立登記から初の原子核分裂まで 2年4ヶ月
  • 初分裂（Project Nova・旧11月臨界）から2回目まで 約7ヶ月
核分裂発見以降に生まれ、実際に発電した民間企業は Valar だけ。他は100年超の電力会社や防衛関連ばかり。
#12

Tick Rate（刻み率）

  • ゲーム用語から: 状態が更新される 間隔 の短さ
  • 会社の成績指標: 初分裂 → 2回目 → 3回目…の 間隔を最短に
  • ロードマップ: 7ヶ月 → 6ヶ月 → 4ヶ月 → 1ヶ月…最終的に 数分おきに新炉
  • 原子力の経済性は「炉をどれだけ速く安く作れるか」で決まる（燃料=ウランは安い）
  • CEO の仕事は組織を回って 戦争部屋（war room） を開き、6ヶ月を4週に縮めること
社内ペースには自動操縦がない。初日からCEOと最初の5人、20人の骨髄に染み込ませるしかない。
#13

モジュラー・シタデル

  • 巨大な生体遮蔽（バイオシールド）: 78インチの特殊コンクリート の壁
  • ソルトレイク市の自社工場で プレキャスト（工場成形）。年3000ブロックを生産可能
  • トラックで搬入しクレーンで積む。従来3ヶ月の遮蔽が 約42時間 で完成
  • 継ぎ目は全て サインカーブ（蛇行路）: γ線・中性子の直進経路を消す
  • モルタル無し・ボルト無しの 純積み。耐震フレームは念のための追加
顕微鏡レベルでは固体同士も触れ合っていない。隙間を rays に抜けさせないための、幾何学的な工夫なんだ。

AI需要と無限市場

  • 米国の電力需要増の主因は AI compute。Valar の前提を強く支える
  • エネルギーは商品。価格を下げれば需要は必ず生まれる（価格が需要を決める）
  • 1セント → 0.1セントと安くすればするほど 需要を自己創出。市場は無限
  • 大口buyer は「31〜32年まで誰もスケール供給できない」と見る → Isaiah は 指数曲線 で反論
  • SpaceX の衛星数を誰も予測できなかったのと同じ。2035年でも他社は届かない、と
エネルギーは宇宙で唯一の非可逆な資源。安くすることが、そのまま需要と豊かさになる。

垂直統合という武器

  • 発注を断られたベンダーが業界中にネガティブキャンペーン → 逆に 脅威の証
