イントロ

タブを閉じて作業を失うのは、もうやめよう
  • うっかりタブを閉じて、せっかくの作業が消える経験は誰にでもある
  • 他のデバイスに移ると、コピペで文脈が切れてしまう

「また最初からやり直し…」
このストレスから、もうおさらば！

何が変わったか

Chrome のサイドパネルが Cowork セッションに
  • サイドパネルの作業が フルの Cowork セッション として扱われる
  • セッションはクラウド側で続きから 再開できる
  • ブラウザ・スマホ・デスクトップが 1つの作業の流れ につながる
「ブラウザだけのツール」から
「どこでも続くワークスペース」へ！
00:43

Before vs Now

旧 Chrome 拡張が「行き止まり」だった理由
  • Before ブラウザの外に出られず、作業がそこで止まっていた
  • Now セッションがデバイスをまたいで続く
  • コピペも 文脈の喪失 もナシ
旧拡張は「専用の小部屋」。
外の世界との行き来ができなかった…
01:10

実例

ブラウザで始めて、スマホで仕上げる
  • PC の Chrome サイドパネルで リサーチを開始
  • そのまま外出 → スマホで 続きから再開
  • 会話の流れもファイルも そのまま引き継がれる
出かける途中でも、
作業の続きがそのままできる！

01:34

機能1

セッションがすべてのデバイスで追従
  • デスクトップアプリで開いたセッションが…
  • スマホのアプリでも 同じ位置で再開
  • 自分の作業の現場がまるごと追いかけてくる
「続きからどうぞ」が
どのデバイスでも同じ形で効く！
01:51

機能2

ブラウザ作業が履歴に保存される
  • Chrome で行った作業が 履歴にちゃんと保存
  • あとから 見返して再開 できる
  • 「あの作業、どこでやったっけ？」が解消
作業のログが自動で残るから、
探す手間がぐっと減る！
02:08

機能3

Skills とコネクタが Chrome で使える
  • Skills をブラウザ側から呼び出せる
  • コネクタ 経由で外部ツールとも連携
  • デスクトップと 同じ道具立て が使える
いつも使うスキルが
ブラウザでもそのまま動く！
02:25

隠れた利点

既存ログインでポータルやダッシュボードを使う
  • Chrome なら すでにログイン済み のサービスが多い
  • ポータルや ダッシュボード をそのまま操作できる
  • パスワードの再設定や 認証のやり直し が不要
「ログインしてください」の
手間がなくなると、作業が快適！

クイックウィン

まず1つの Skill を保存しよう
  • 最初の一手は Skill を1つ保存 すること

セクション4 ｜ リスクと安全な使い方 auto-approve をオンにする前に、ぜひ読んでほしい
04:44

リスク

プロンプトインジェクションを、やさしく解説
  • 悪意ある命令が Web ページ に仕込まれていることがある
  • AI がそれを 正しい指示 と勘違いするのが「プロンプトインジェクション」
  • 見た目は普通のページでも 見えない命令 が隠れる可能性
「AI が読む命令」と「人が見る表示」は
ちがう場合がある、と覚えておこう
05:16

Auto-Approve

安全チェックが実際にブロックするもの
  • 危なそうな操作は 確認なしでは実行しない
  • 承認を求める 安全チェック が間にはいる
  • auto-approve をオンにする前に 内容を理解 しておこう
「すべて自動」は便利だけど、
何を許可したのか把握が大事！
05:46

正直な話

Anthropic 自身の警告
  • Anthropic が自らリスクを認めている
  • プロンプトインジェクションは 完全には解決できない と明言
  • 便利さとリスクの バランス を自分で考える時代
作った側が「100% 安全」とは
言っていない、という事実が重要
セクション5 ｜ 制限とこれからの展望 できること・できないこと・向かう先
06:01

制限

デスクトップアプリのみ、モバイルなし、エンタープライズの既定値
  • セッションのフル機能は デスクトップアプリ が対象
  • モバイル側の対応は まだなし
  • エンタープライズでは 既定値の確認 を忘れずに
「全部できる」わけじゃない。
現時点での境界線を知っておこう
06:25

大きな図

AI はアプリではなく、ワークスペースになっていく
  • チャットボットのような 1つのアプリ ではない
  • ブラウザ・スマホ・PC をまたぐ ワークスペース へ
  • 作業の単位が セッション に変わっていく
「どこにいても、同じ仕事の続き」
それがこれからのあたりまえに！
