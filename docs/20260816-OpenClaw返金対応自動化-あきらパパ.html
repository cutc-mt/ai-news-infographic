使うほどに育つ

  • 一度教えた手順は、次から自分で再現

#05

返金対応という実務

地味だけど大事な仕事

  • 返金依頼が来たら、まず記録の確認から
  • 注文・支払い・対応の履歴を見直す
  • 小さなビジネスでも起こる日常業務
派手じゃないけど、
ミスだけはできない仕事。
#06

確認の重さ

返金まえの「確認」

  • 返金してよいか、見るべき項目が多い
  • 注文の記録と支払いの記録を照らし合わせる
  • この確認に、いちばん時間がかかる
#07

従来の流れ: 探し物

まず「探す」から始まる

  • メール、表、決済サービス…あちこち探索
  • 記録がどこにあるか探すだけで一苦労
  • 複数の場所を行ったり来たり
  • 本題の「判断」にたどり着くまでが長い
本来の仕事は判断なのに、
探し物で時間が消えていく…
#08

未確認のまま返すと?

省略できない理由

  • 二重返金や返しすぎのリスク
  • 不正な依頼を見逃すかもしれない
  • あとで間違いが分かると、手戻りが大きい
確認を省くと、あとで痛い目に…
だから「もう未確認で返さない」!
#09

時間と集中のコスト

積み重なると大きい

  • ひと件は短くても、積み重ねで効いてくる
  • 確認作業は本業の手を止めてしまう
  • 「いま何をしてたっけ」の集中の中断
// 負荷のかけ方
探す → 確認 → 判断 → 実行
前半の2つが重い → ここを任せたい
OpenClaw に任せると
#10

任せた場合の流れ

話しかけて、待つだけ

  • Discord で返金依頼のことを話しかける
  • OpenClaw が代わりに記録をあたり確認する
  • 結果が三行メモで返ってくる
  • 人はメモを見て判断するだけ
// 依頼のイメージ
@OpenClaw 返金依頼が来ました
件名: ○○の返金 (#1234)
確認して 結果を三行で!
#11

三行メモの意味

要約されて戻ってくる

  • 探し回った情報が三行に要約される
  • 内容: 何を確認して、問題はないか、次にどうするか
  • 読むのは三行、判断はすぐつく
「探す時間」が消えて、
「読む時間」だけになる!
#12

Discord 連携の利点

チャットのなかで完結

  • 依頼も結果も、いつものチャットの流れのなか
  • 確認の結果が通知で届く感覚
  • どこにいてもスマホで受け取れる
別の画面を見に行く手間が、まるっとない!
#13

比較シリーズの位置づけ

同じ型で比べていく

  • この動画は比較シリーズの1本
  • 面接準備を三行メモに変える回もあり
  • 「探し物 → 三行メモ」の型がいろんな仕事に効く
#14

変わるもの・残るもの

ちょうどいい分業

  • 減る: 探す手間と確認の時間
  • 残る: 最後の判断と返金の実行
  • 人は「決める側」に専従できる
  • AIが調べて、人が決める形に
任せるところは任せて、
決めるところに集中!
安全に使いこなす + まとめ
#15

注意: お金まわりの操作

危険な操作は人が最終確認

  • 返金の実行など、危険な操作は人が最終チェック
  • OpenClaw に任せるのは「確認」の部分
  • 「未確認で返さない」は AI にも同じ
  • 自動化するときほど止まる場所を決めておく
賢い道具ほど、ブレーキの置き場所が大事!
#16

返金以外にも広がる

  • 確認・調査をともなう作業なら応用がきく
  • 面接準備、情報まとめ、日々の調べごと
  • 使い続けるほど自己改善して、相性が上がる
「三行メモ化」できそうな仕事、
あなたのまわりにもあるかも!
