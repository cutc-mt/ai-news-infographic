#01

面接まえの「あるある」

直前にさわる人のリアル

  • 面接の前日: 履歴書をフォルダの奥から探す
  • 前回のメモはどこへ? あせって読み返す
  • 求人の条件を、画面を行ったり来たり
「あるある」で終わらせないのが、今回のテーマ！
#02

OpenClaw とは

どんなツール?

  • Discord に話しかけるだけで動く
  • セルフ改善型の、パーソナルAIエージェント
  • あなた専用の秘書のように、そばで育つ
特別な画面は不要。チャット感覚で使える！
#03

Discord で話しかけるだけ

手軽さが最大の武器

  • 起動も設定も、むずかしくない
  • 普段のチャットと同じ感覚で依頼
  • 返事が返ってきて、そのまま作業へ
// こんな感じで依頼
あなた   「面接の準備をまとめて」
OpenClaw 「わかりました！」
新しいアプリをおぼえる手間が、ほぼゼロ！

自分で育つエージェント

セルフ改善って何?

  • 使った記録を、次の準備に活かす
  • あなたの好みの型を、おぼえていく
  • 繰り返すほど、あなただけのものに
育てる楽しさがあるのが、エージェントの魅力！
準備の流れをくらべる
#05

自分だけのエージェント利点

パーソナルだからできること

  • あなたの文脈を、おぼえたまま続く
「誰かの」ではなく「自分の」エージェントであるのが大事！

三行メモへの近道

  • Discord に、ひとこと依頼するだけ
  • 資料は OpenClaw が、まとめておく
  • あなたは三行のメモを受け取る
// OpenClaw なら
1. 依頼は Discord でひとこと
2. まとめは 自動 で完成
3. できあがるのは三行メモ
準備のハードルが、ぐっと下がる！
#08

履歴書の管理

「探さない」が前提になる

  • 経歴の情報を、エージェントが保持
  • 更新も、伝えれば反映してくれる
  • 面接の前に、バタバタ探さない
「あのファイル、どこだっけ」から卒業！
まとめる対象は三つ
#09

前回メモの活用

経験をムダにしない

  • 前回の学びを、次に持ち越せる
  • よかった答え方を、おさえておく
  • 自分史になるほど、たまっていく
一回ごとの準備が、自分の資産になっていく！
#10

求人の条件を整理

なにを比べるか、はっきり

  • 必須の条件と、あるとうれしい条件
  • 給与や勤務地の現実チェック
  • 質問したいことも、同時にメモ
条件がクリアだと、面接での答えも定まる！
#11

三行の準備メモとは

しぼり込む力

  • 長いメモは、いざという時に読めない
  • 三行に収めて、優先度をはっきり
  • 見返すのは、面接まえの数分でOK
// 三行メモの例
1. 強み： 〇〇の経験が〇年
2. 相手： 〇〇を求めている
3. 今日： 〇〇を伝えたい
行数が少ないからこそ、頭に入る！
