毎日の再教育に、お疲れでは?
#01

「過剰資格の校正者」問題

あなたがやらされていること

  • なおすのは人間、ミスはAIという構図
  • 同じ注意を、何度も言い直す日々
  • 本業そっちのけで、チェックに追われる
気づけば、AIの専属こう正者になってない?
#02

同じミスが、何度でも

直しても、次の日には忘れる

  • きょう直した点を、あすにはリセット
  • 会話が終わると、指示も消えている
  • 毎朝ゼロから、おしえ直しのループ
「この前も言ったよね…」の連続!
#03

消えてしまう「教えたこと」

記憶に残らない指示

  • 指示は、その場のコンテキスト限り
  • セッションをまたぐと引き継がれない
  • 改善が蓄積されず、もとに戻る
どれだけ教えても、
ゼロからのやり直しに…
#04

Prime Agent の登場

悪循環を断つ新兵器

  • この悪循環を断つべく登場
  • self-refining な作りを採用
  • おしえるのは、一度だけでOK
「毎日の再教育」が、
はじめの一度だけになる!
仕組み: self-refining architecture
#05

self-refining とは

自分で自分を磨く設計

  • 忘れるだけでなく、活かす方向へ
  • 修正 → 学習 → ルール更新のループ
  • 使うほどに、賢くなっていく
// self-refining の流れ
あなたの修正 (correction)
  → ログに記録 (log)
  → 学びを抽出 (learn)
  → 内部ルールを更新 (update)
#06

修正をログに記録

なおした内容を、きちんと残す

  • あなたの直しを correction log に記録
  • いつ・何を・どう直したかが残る
  • 証拠としてためて、あとで活かす
「言った・言わない」のもめが、なくなる!
#07

フィードバックから学習

指摘を、ちしきにかえる

  • 直された内容から、好みのパターンを学ぶ
  • 一回の指摘が、次回の挙動に反映
  • 指摘は減って、精度は上がる
  • 結果: 直す回数が減る
#08

内部ルールを更新

学びを、かたちにする

  • 学んだことを rules に書き込む
  • 暗黙の了解を、明示的なルールへ
  • 更新は自動、手作業は不要
好みの書き方を、勝手に守ってくれる!
#09

教えるのは、一度だけ

teach it once の体験

  • 一度おしえれば、あとは任せられる
  • 毎日の再教育タイムから解放
  • 人間はレビューに集中できる
最初の一度だけ、
あとは信じて待てばOK!
メモリを、超える力
#10

メモリ機能

Beyond memory の土台

  • 対話の履歴だけでなく、判断の基準も保持
  • あなたの好みやクセを覚える
  • 経験が、層のようにたまっていく
覚えるのは「ことば」だけじゃない!
#11

agent-to-agent communication

エージェント同士の会話

  • エージェント同士で情報をやりとり
  • みずから仲間を呼んで、協力や分担
  • 人間がすべて仲介しなくてよい
// 連携のイメージ
Agent A: 「調査が終わった、結果を渡す」
  → Agent B: 「受け取った、執筆にかかる」
    → Agent C: 「検証してから完了にする」
#12

分業するチーム

役割をわけて攻略

  • 調査係・執筆係・検査係の役割分担
  • 成果物を相互に受け渡して進行
  • 大きなタスクも小分けに攻略
まるで小さな部署みたいに動く!
#13

strict gating mechanism

厳格なゲーティング機構

  • 「完了」と言う前に、関所を通す
  • 未検証の成果は外に出さない
  • この厳格さが、信頼の源
ゴールのまえに、必ず検問があるイメージ!
検証してから、完了へ
#14

自分の作業を、みずから検証

validate its own work

  • 自分の出力を、自分でテスト
  • 結果を確認してから次へ進む
  • 見直しを、人間に丸投げしない
提出のまえに、自分で品質チェック!
#15

完了を言うのは、最後

claim のまえに validate

  • 検証が済むまで、完了を主張できない
  • 「やったつもり」を排除
  • 信頼できる「完了」だけが残る
  • 作業 → 検証 → 完了 の順を守る
全部通って、はじめて「できました」!
#16

ユースケース

こんな場面で効く

  • ブランドのトーンに合わせた記事生成
  • コーディング規約を、一度だけ教える
  • 定型レポートの書式を学習させる
「好みを一度メモる」だけで、あとは任せる!
#17

メリットまとめ

うれしい変化

  • 同じ指摘の重複がなくなり、時短に
  • 品質がブレずに安定する
  • 人間の負担は、最初の一度だけ
  • あなたの好みに育つ、相棒になる

まとめ
