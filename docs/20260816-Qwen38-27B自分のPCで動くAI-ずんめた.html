何が公開された?
#01

ニュースの核心

クラウドの外に出せるAIが来た

  • Alibaba Cloud が AI モデル Qwen3.8-27B のウェイトを公開
  • 中身が丸ごと配られる オープンウェイト形式
  • 「サブスク、手元の無料でよくない?」へのひとつの答え
毎月払っているクラウドAIに、
「手元で動く版」が追いついてきた!
#02

だれでも入手できる

配布場所は2か所

  • Hugging Face と ModelScope で配布中
  • 申請も審査もなし、誰でもダウンロード可
  • 量子化版の配布元は Unsloth
// 入手までの流れ
Hugging Face / ModelScope へアクセス
↓ Qwen/Qwen3.8-27B を選んで DL
ローカル環境で即チャレンジ
#03

ライセンスは Apache 2.0

商用も堂々とOK

  • Apache 2.0 なので商用利用ができる
  • 社内ツールへの組み込みもハードル低め
  • 「ここ数年でいちばん試しやすい状況」に
重さの制限も細かい条件もなし。
まず動かしてみる、がしやすい!
#04

ちょうどいい大きさ

270億パラメータ

  • パラメータは 270億。いまどきでは小さい部類
  • GPU を1枚積んだデスクトップに収まる規模
  • 巨大モデルは無理でも、ここなら自宅マシンで勝負できる
「載るサイズ」であることが、
ローカル運用の前提条件!

#11

点差より「分かれ方」

確かな読み方

  • 点差の大小を追っても揺らぎやすい
  • 勝っている列と負けている列の分かれ方を見る
  • その分かれ方は測定条件を多少いじってもひっくり返らない
  • 結論: 「実務系に強い/思考系に弱い」という構図が本質
自分のPCで動く?
#12

まずは生のサイズ

BF16 は 54.7GB

  • 圧縮なし BF16 だと 54.7GB
  • 個人の機械にはまず載らない
  • そこで出てくるのが量子化という圧縮
生のままでは重すぎる…
圧縮が必須なんです。
#13

量子化でぎゅっと圧縮

4bit / 2bit で載る圏内へ

  • 4bit Q4_K_M なら 17.1GB
  • 2bit まで落とせば 9.01GB
  • 配布元 Unsloth の量子化版を使うのが手軽
// ウェイトのサイズ比較
BF16 (無圧縮)   54.7GB  ← 個人機には無理
Q4_K_M (4bit)   17.1GB
2bit             9.01GB
#14

必要メモリの目安

Unsloth の案内

  • 量子化版なら 16GB以上の VRAM かメモリで動く
  • ゲーミングPCのミドル〜上位クラスなら射程圏
  • ただし電気代とマシンのくたびれは自分持ち
#15

ひとつ落とし穴

コンテキストのメモリは別

  • コンテキストはネイティブで 262,144トークン
  • 設定次第で100万トークンまで
  • サイズ表は重みだけ。長い文脈を使うとメモリは別途必要
「入ること」と「使い切れること」は
別の話、なんです。
ライセンスの綱渡りと結論
#16

上位版は別ルール

Qwen3.8-2.4T-A95B

  • 8月12日公開の上位版 Qwen3.8-2.4T-A95B
  • 2.4兆パラメータ、アクティブ950億のMoE型
  • ライセンスは独自の Qwen3.8-Max。Apache 2.0 ではない
  • 外部提供する事業者は売上規模で別途契約が必要
  • 画像・動画の入力にも非対応
同じ Qwen3.8 でも、
兄弟でライセンスがちがう!

#18
