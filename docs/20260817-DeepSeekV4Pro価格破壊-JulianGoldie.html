01

DeepSeek V4 Proが静かに登場

  • 派手な告知なしで公開された新モデル
  • 性能は最上位モデルに迫る
  • それでいて費用はとても軽い
  • 動画は「結果が驚異的」と表現
告知は小さく、衝撃は大きい。
静かに来た本命です。

  • 業界トップは Claude Fable 5
  • V4 Pro はその0.1ポイント下

  • 差は誤差のレベルとも言える
0.1差って、
ほぼ引き分けでは？
03

「57倍安い」の衝撃

  • 特定のタスクで最大57倍も安い
  • 費用は数十分の1という計算

  • 単価が下がると、使い方が変わる
57倍って、
桁がひとつ違う世界…！
04

コスパ指標で他社を上回る

  • 価格と性能の比で他社を上回る
  • 評価を重ねても結果は一貫
  • 「安くて良い」を実証済み
  • 費用あたりの成果が良い
#コスパ最強 #価格÷性能

安いモデルの品質が上がる流れ

  • オープン系がどんどん追い上げ

12

コストの再計算（大量に回す時）

  • 計算式は単純：単価 × 回数
  • 高級モデル：$57 / 1,000回なら…
  • V4 Pro側：$1 / 1,000回の世界
  • 月額がまるごと変わる
# タスク1,000回あたりのイメージ
premium  = 57.0  # 高級モデル
deepseek =  1.0  # 最大57倍の差
print(f"差: {premium / deepseek}x")

ここまで違う！
