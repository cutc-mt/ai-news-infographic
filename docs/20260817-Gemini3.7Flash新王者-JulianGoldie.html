③ 考える深さと、Agent チーム

考える深さをダイヤルで調節

  • リーズニングダイヤルというつまみ
  • thinking を ON / OFF で切り替え
  • じっくり型 ↔ 秒答え型を使い分ける
04:11 Dial
モデルを乗り換えなくていいのが、地味にうれしいポイント！

ダイヤル調整のコツ（コスト最適化）

  • 軽い質問 → ダイヤル低めで節約
  • むずかしい判断 → ダイヤル高めで深掘り
  • 請求がぐっと下がる実感あり
# 使い分けの目安
if 簡単な質問:
    thinking = "low"    # 速い・安い
else:
    thinking = "high"   # じっくり

マルチエージェントでつくる

  • 複数の Agent で分業させる
  • 調査 → 執筆 → 編集の流れ作業
  • Flash の速さが多人数でこそ活きる
05:19 Multi-Agent
Agent が増えると待ち時間も増える…そこを速さでカバーする設計なんって。

エージェント分業の設計

  • 役割ごとに担当を分ける
  • 出力をパイプでつなぐだけ
  • 人間は監督役にまわる
# 分業の例
researcher = Agent("調査係")
writer     = Agent("記事係")
editor     = Agent("編集係")
pipeline(researcher > writer > editor)
