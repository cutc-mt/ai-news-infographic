#01

Macro 統合ワークスペース

チーム作業を 1 つにまとめる

  • メール・メッセージ・タスク・ドキュメント・通話・CRM・エージェントを 1 アプリに集約
  • キーボードファーストで高速に操作できる設計
  • メンションは双方向リンクで 2 つの項目をつなぐ
  • 共有チームメモリでエージェントが作業を記憶。受信箱はシグナルとノイズに分離
// 置き換え対象の例
Slack / Linear / Notion / Superhuman
→ Macro へ一元化
接続: MCP 経由で Claude Code とも連携
  • 中身は Rust + SolidJS 製
バラバラなツールを
これ 1 つにまとめられる!
macro-inc/macro

ブラウザとエージェントの共有

  • どちらも無料で始められる道具
Ego Lite − エージェントと使うブラウザ

  • メモリは自分のマシン上のプレーンファイル。エージェントが続きから再開
  • 100+ 統合と MCP サーバーで即接続
自分のPCを
エージェントとシェアする時代!
