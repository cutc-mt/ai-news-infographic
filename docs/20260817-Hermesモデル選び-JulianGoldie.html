Hermes向けAIモデルの選び方

Qwen 3.8 Max（API） vs DeepSeek V4 Flash（ローカル）

2026年8月17日 ／ Julian Goldie SEO の32秒ショートより

#Hermes #モデル選び #API #ローカル #VRAM

モデルを変えるだけで、速さも質もガラリと変わる。短い動画の内容を、18枚のカードにひろげてまとめました。

はじめに：なぜ選び方が大事？ カード 1 〜 3
01

なぜモデル選びが大事？

  • Hermes の頭脳に当たる LLM は、好みで交換できる
  • モデル次第で、速さと賢さがガラリと変わる
  • 「どれを選ぶか」が、結果の分かれ道
まずはここから！ 道具を選ぶのと同じで、
モデル選びは結果を左右します
02

速さと質に直結

  • 待ち時間が減ると、作業の集中が途切れない
  • 出力の質が上がると、手直しがぐっと減る
  • 2つが揃うと、Hermes がぐっと使いやすくなる
速さ × 質。この2つが
使い心地を決めます！
03

最初の分かれ道

  • API ＝ クラウド側で処理。準備が手軽
  • ローカル ＝ 自分のPCで処理。縛りが少ない
  • 先に「どちらで動かすか」を決めよう

どちらを選んでも、次のステップは同じ

最初の一歩は2択から。
迷ったら両方試すのもアリ！
Qwen 3.8 Max の話（API 向け） カード 4 〜 6
04

Qwen 3.8 Max の特徴

  • API 向けのトップクラス（フロンティア級）
  • 難しい指示も粘り強くこなす賢さ
  • 長めのコードや多言語も得意
API 派の本命！
賢さで選ぶなら、まずこの1つ
05

API で使う利点

  • キーを用意するだけですぐ動く
  • 高価なGPUがなくても賢い回答が返る
  • モデルの更新は向こうで済ませてくれる
  • 設定の例：
# API 側（イメージ）
provider = "openai-compatible"
model  = "qwen3.8-max"
api_key_env = "QWEN_API_KEY"
06

API 利用の注意

  • 使った分だけ課金。放っておくと膨らむ
  • 呼び出し回数には制限（レート制限）がある
  • 外部にデータを送る点も、事前に確認を
使い始める前に、 上限の設定を忘れずに！
DeepSeek V4 Flash の話（ローカル向け） カード 7 〜 9
07

DeepSeek V4 Flash の特徴

  • ローカル向けの軽量・高速タイプ
  • 手元のPCでサクサクと動く
  • 小さめのVRAMでも動く設計
手元で軽やかに。
これが Flash の持ち味！
08

ローカルで動かす利点

  • 会話が外に流出しにくい安心感
  • 応答が軽く、待ち時間が少ない
  • 通信が切れても使い続けられる
机の中で完結。
ローカルならではの安心！
09

VRAM という壁

  • GPU の VRAM が、実質の上限になる
  • モデルが大きいほど、VRAM を食う
  • 足りないと重い、または動かない

まず手持ちのVRAM量を測ってから選ぶ

まず自分のVRAMを確認。
ここが全ての土台！
選び方の軸：何を取る？ カード 10 〜 14
10

GPU 別の使い分け

  • VRAM たっぷり → ローカルの Flash
  • GPU が弱め → API の Qwen
  • どちらもあり → 併用がベスト
自分の道具に合わせて選ぶのが コツ
11

効率と知性のバランス

  • 軽さと賢さは、ちょっとしたトレードオフ
  • 用途に合わせて、重みを変える
  • 今はこの2つが効率面でリード
完璧な1つを探すより、
用途別がおすすめ！
12

速さで選ぶなら

  • DeepSeek V4 Flash が一択
  • 応答の軽さが最大の魅力
  • 長い対話でも、へこたれない
ちゃっちゃと動いてほしい
場面で大活躍！
13

質で選ぶなら

  • Qwen 3.8 Max が本命
  • 複雑な指示も、丁寧に処理
  • 長い出力もぶれにくい
ここは賢さで
決めたい場面向け
14

併用の発想

  • 日常は Flash、難所は Qwen
  • 用途ごとに切替える運用
  • 費用もほどほどに抑えられる

切替は設定を1行変えるだけ

2つ持てば、 迷いも減る！
実践：設定と移行の流れ カード 15 〜 17
15

endpoint の設定の基本

  • provider を選び、model 名を書く
  • キーは外に出して渡す（shell の変数など）
  • ローカルなら URL を差し替えるだけ
# API 側（イメージ）
base_url = "https://api.example.com/v1"
model   = "qwen3.8-max"

# ローカル側（イメージ）
base_url = "http://localhost:11434/v1"
model   = "deepseek-v4-flash"
16

文脈の長さも確認

  • 長い文脈が要る作業は注意が要る
  • 文脈が伸びると、メモリと費用も増える
  • 用途に合う長さを選ぼう
「長いほど良い」ではない。
ほどほどが大事
17

乗り換えの手順

3ステップ

  • 今の設定をバックアップ
  • 小さめのタスクで試す
  • 問題なければ常用に切替

失敗しても、すぐ元に戻せる

いきなり全振りせず、
少しずつ移ろう

  • 軽さなら DeepSeek V4 Flash（ローカル）
  • 持ちのVRAMと相談して決める
  • まずは触って、比べてみよう
