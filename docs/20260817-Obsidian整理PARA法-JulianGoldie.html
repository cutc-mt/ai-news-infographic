ClaudeでObsidianの第二の脳を整理

〜 PARAフレームワークで、散らかったVaultをAIに整えてもらう 〜

2026年8月17日 / Julian Goldie SEO / 英語の解説動画

パート1: 第二の脳と、散らかる原因

「第二の脳」とは？

  • ObsidianはMarkdownで書く人気のノートアプリ
  • ノート同士をリンクでつなげて、知識の網をつくる
  • アイデアやメモをため込む外付けの脳
  • AIエージェントの記憶の置き場所としても活躍
ノートを増やすほど賢くなる脳、それが第二の脳。AI時代の必需品だよ 🧠

どうして散らかるの？

  • 「とりあえず保存」がクセになる
  • フォルダのルールが決まっていない
  • 「あとで整理」を先送りにして、どんどんたまる
  • 検索に頼って、ファイル名が雑に
散らかりの正体は「ためるだけで終わる」こと。置き場所のルールがあれば防げるよ 📥

散らびが足を引っ張る

  • AIが目的のノートを探すのに時間がかかる
  • 関係ないノートまで読んで迷子になる
  • 古い情報をつかんで、間違えるリスク
  • 結果、エージェントの精度と速さがガタ落ち
散らかった本棚から1冊探すのと同じ。エージェントも迷うと疲れちゃう 📚

パート2: PARAの4つの引き出し

PARAフレームワークとは？

  • ノート術で有名なTiago Forte氏が考案
  • すべてのノートを4つの引き出しへ振り分け
  • 「どこに置くか」の迷いがゼロに
  • 使わないものは定期的に見直して移動
Vault/
├── 1-Projects/
├── 2-Areas/
├── 3-Resources/
└── 4-Archive/
P・A・R・Aの頭文字。迷ったノートは必ずこの4つのどれかに入るよ 🗂️

Projects: 進めている仕事

  • 目標と締め切りがはっきりした仕事
  • 例: サイトの立ち上げ、動画の企画
  • いちばんよく開く「今」のフォルダ
  • 完了したらArchiveへ移す
「今やっていること」だけを置く場所。ここが軽いとやる気も上がる 🚀

Areas: 続けて守る責任

  • 締め切りは無いけど、ずっと続く領域
  • 例: 健康、家計、スキルの維持
  • 「終わり」が無く、見直しが続く
  • はげみ具合を定期チェック
「終わらないテーマ」はここへ。完璧を狙わず回し続けるのがコツ 💪

Resources: 関心のテーマ

  • 興味や調べもののストック場所
  • 例: AIニュース、SEOのTips、デザイン参考
  • 未来の企画の種になる
  • あとで活かせそうな情報を集約しておく
いつか役立つネタ帳。ここが豊かだと企画がすぐ浮かぶ 🌱

Archive: 終わったものの保管

  • 完了した仕事や、離れたテーマの置き場所
  • 消さずに取っておく、資料のたまり場
  • 過去の記録を、あとでたどれる
  • 手前のフォルダを軽く保つ役割
「捨てないで、しまう」のがコツ。過去のノートは財産だよ 📦

パート3: Claudeに任せて自動で整理

Claudeへの読み込ませ方

  • Vaultのドキュメントをそのまま渡す
  • MarkdownはAIが読みやすい形式
  • フォルダの構成まで認識できる
  • あとはプロンプトでPARAを指定するだけ
プロンプト例:
「このVaultをPARAに沿って整理して。
 移動先と理由もいっしょに表示して。」
特別な準備は不要。読み込ませて、お願いするだけ 🤖

整理はClaudeにおまかせ

  • ノートの中身を理解して自動で分類
  • ファイルの移動とリネームを提案
  • 何時間もかかる手作業が数分に
  • 結果はリストで確認してから反映
「AIが提案 → 人が確認」の流れなら、失敗もこわくない ✨

履歴を残して整える意味

  • 大事な履歴を保ちながら整理できる
  • 元の場所や日付の記録を消さない
  • 過去の判断を、あとでたどれる
  • 「消して整える」ではなく「移して整える」
整理しても思い出は消さない。これがAIに任せる大きな利点 🕰️

パート4: Agent OSとOmniRootの落とし穴

Agent OSとは？

  • エージェントのチームをスマホから操作
  • 複数のエージェントを一画面で管理
  • Obsidianとつないで作業をさせる
  • 進み具合の通知も受け取れる
エージェントのリモコンが手の中に。PCの前での見張りから解放 📱

OmniRootのローカル問題

  • OmniRootをローカルで動かすと接続のトラブルが発生
  • localhostのURLにつながりにくい
  • ポートまわりの設定が原因になりがち
  • ローカル環境ならではの、つまずきポイント
「ローカルでだけ動かない」なら、こわがらず設定を疑おう 🏠

トラブルシューティングの手順

  • まずURLとポート番号を確認
  • 接続の再起動とキャッシュの削除
  • ログのエラー文を読んで原因を切り分ける
  • 問題を小さく分けて、ひとつずつ対処
全部一度に直そうとしない。切り分けが最短ルート 🔧

クラウドへ置くときの条件

  • ローカルのアドレスは外から届かない
  • 公開用のアドレスと鍵の設定が必要
  • 環境の違いを書き換える作業が必須
  • 安全のための設定も忘れずに
ローカルとクラウドは別の家と思って、引っ越しの準備を ☁️

パート5: 整えたあとの未来と続けるコツ

整えたあとの効果

  • エージェントが目的のノートを即つかむ
  • 読み込みと検索が高速に
  • 指示の精度が上がり、手戻りが減る
  • 第二の脳がそのまま「武器」に変わる
散らかりをなくすと、エージェントの実力がフルに発揮される 📈

整え続けるためのコツ

  • ノートを入れたら、その場で振り分け
  • 週1回のミニ整理タイムを設定
  • 完了したものは迷わずArchiveへ
  • 定期チェックをClaudeに頼むのもアリ
完璧より「続ける」が正義。1日3分だけでも習慣に 🔄

まとめ: 今日からの一手

  • 散らかった脳はエージェントの足かせ
  • PARAの4分割でルールを作る
  • Claudeに読み込ませて自動で整理
  • Agent OS / OmniRootは設定で解決
まずはVaultを見せるところから。今日から始めよう 🏁
