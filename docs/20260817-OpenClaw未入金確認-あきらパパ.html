OpenClaw｜未入金の確認を、三行のメモに

請求書を探して止まる毎日を「三行の確認メモ」へ変える話

2026年8月17日公開のショート動画より / あきらパパ（@akira_papa_IT）

OpenClaw Discord 未入金の確認 三行メモ 自動化
課題 — 請求書を探して止まる
#01

止まってしまう経理の現場

毎月の「入金されたかな？」

  • 出した請求の入金があるか・ないかが気になり始める
  • 確認しようとすると、請求書を探すところから始まる
  • 探している間、ほかの作業は手が止まる
  • 放っておくと、未入金のずれは大きくなるばかり
未入金 後回し
気にはなる…でも探すのが面倒、で後回しにしていない？
#02

請求書を探す時間のもったいなさ

毎回ゼロからの探し物

  • フォルダ・メール・会計ソフトと、あちこちを行ったり来たり
  • 請求の番号を思い出せず、検索の言葉に迷う
  • やっと見つけても、確認はそこからもう一度
  • 探すだけで力尽きて、確認が明日に回ることも
探す時間 手作業
探す時間は「毎回」かかる。ここがもったいない！
#03

未入金の見つけ方

入金と請求を見比べる

  • 出した請求の一覧と、入金の記録を突き合わせる
  • 金額や日付のずれから、未入金の一件を見つける
  • 見つかったら、次は「何を確認するか」に悩む
  • 動画の答え: 確認の内容を、三行に決める
  • 見つけ方より「確認の仕方」を固定するのが今回の核心
探し方の工夫より、確認の形を決めてしまうのが近道！
三行のメモという解決
#04

三行メモとは

「探す」が「読む」に変わる

  • 書くのは三行: 請求の番号・期限・確認の一文
  • 探す時間が、三行を読む時間に変わる
  • 毎月同じ形で書けるから、迷いがない
  • 請求書そのものは、必要になったら開くだけで良い
# 未入金の確認メモ（三行）
1. 請求の番号: INV-2026-0817
2. 期限: 8月31日
3. 確認の一文: 8月分の入金が見当たりません
「探す」から「読む」へ。この入れ替えがすべて！
#05

一行目: 請求の番号

どの請求かを一発で特定

  • 番号があれば、どの請求かが一目で分かる
  • 探し直す手間が、番号の一行でゼロになる
  • 相手に問い合わせるときも、番号が共通の言葉
  • 会計ソフトの記録とも、番号でつながる
請求の番号 特定
一行目の番号が、あとのすべてを速くする！
#06

二行目: 期限

いつまでの話かを書く

  • 支払いの期限を、日付ではっきり残す
  • 期限が分かると、催促の急ぎ具合も決まる
  • 「いつまで」がないと、相手も後回しにする
  • 期限を過ぎた一件から、順に確認していける
期限 催促
期限の一行が、未入金の緊急性を教えてくれる！
#07

三行目: 確認の一文

伝えたいことをそのまま

  • 例: 「8月分の入金が見当たりません」
  • 迷ったら、事実をそのまま一文にする
  • 確認の一文は、催促のメッセージにすぐ転用できる
  • 感情ではなく事実で書くから、角が立たない
確認の一文 事実
一文にまとめると、聞きたいことがクリアになる！
OpenClaw が担う部分
#08

OpenClawとは

Discord で動くAI

  • Discord に話しかけるだけで動く
  • 特別な画面も、難しい設定も要らない
  • 自分用のパーソナルAIエージェント
  • 日常のチャットの中に、そのまま溶け込む
OpenClaw Discord
導入の重さが少ないのが、続きやすいひみつ！
#09

Discordで話しかける

依頼はひとことだけ

  • 「未入金の確認メモを整えて」と頼むだけ
  • あとは OpenClaw が、三行をきれいに整理
  • 返ってきたメモを見て、催促に進む
  • 二回目からは、前の形をまねてさらに速い
ひとこと 確認メモ 
// Discord で話しかけるひとこと

話しかけたら、あとは待つだけ。依頼は軽く！
#10

パーソナルAIエージェント

決めるのは人、そろえるのはAI

  • AIの役割は、下書きと整理まで
  • 確認と催促の判断は、人が持ったまま
  • 三行のたたき台を作らせるのが良い使い方
  • お金の話だからこそ、人は最後の砦
役割の分担 下書き
丸投げではなく「下書きから頼む」が気持ちいい！
今日試すこと、そして実践
#11

今日試すこと（一つだけ）

動画からの宿題

  • 未入金の一件を、ひとつだけ選ぶ
  • 請求の番号・期限・確認の一文を、三行で書く
  • 今日の成功は、この一件だけでOK
  • 10分もあれば、書き終わる分量
一件だけ 三行
一件を三行にできたら、今日は十分！
#12

未入金の確認の流れ

四つのステップの型

  • 選ぶ: 未入金の一件にしぼる
  • 書く: 三行のメモに落とす
  • 整える: OpenClaw に下書きを頼む
  • 確認: 人が見て、催促へ進む
  • 毎月同じ流れで回すほど、速くなる
流れが型になれば、迷う時間がゼロになる！

経理の自動化への広がり

入口は小さくていい

  • 未入金の確認は、経理の自動化の入り口
  • 同じ型で、請求の発行や督促にも広がる
  • 経理は型が決まりやすいので、AIと相性が良い
  • まず一つの作業から。全部は後回しでOK
経理 広がる
経理こそ、AIが味方になる現場！

  • もめごとのときの、動かぬ記録になる
記録 振り返り
