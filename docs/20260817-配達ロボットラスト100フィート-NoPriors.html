倉庫 市街地 建物の入口 ドアの前

配達ロボット 最大の難問は
ラスト100フィート（No Priors）

「自動での配達で いちばん難しいのは、走ることではない。
最後の100フィート（約30メートル）だ」—— No Priors の警鐘を読み解く！
インフォグラフィック作成: 2026年8月17日

動画の論点

このショート動画の核心の一節
  • 「いちばん難しいのは走ることではない。ラスト100フィートだ」という指摘が出発点
  • 最後の100フィート＝約30メートル。建物の入口から届け先のドアまで
  • No Priors が、配達ロボットの本当の難所はどこかを突く内容
短い動画なのに、業界の本質を一言で斬る…! これからひも解いていくよ。
#01

ラスト100フィートとは

わずか30メートルの正体
  • 人が歩けば数十秒。ごく短い距離のはず
  • なのにロボットにとっては最大の難所という、逆転が起きる
  • 道の走行 → 建物へ → ドアの前で完了、の3段階のうち最後の部分
道を走る 建物に入る ドアの前へ
人なら当たり前に越えられる距離が、機械には高い壁になるんだ。
#02

自動での配達の現状

「走る」は進んでいるのに
  • 歩道を走る配達ロボットが、都市を中心に少しずつ増加中
  • センサーと地図の進化で、移動そのものは実用レベルに
  • でも「届けた」までいくと、まだ人の手を借りる場面が多い
「走る」はできても「届く」は別物。この落差こそ今回のテーマ！
#03

走ることは すでにほぼ解決

道の上は得意な領域
  • カメラとセンサーのコストが下がり、道の認識は安定
  • AIの進歩が、歩道レベルの走行にそのまま効く構図
  • 道順を決めるのも、地図さえあればさほど難しくない
技術の壁のちがい（イメージ）
道路の走行       ██████████ ほぼクリア
最後の30メートル ██░░░░░░░░ これから
長い距離は得意。問題はゴール直前のわずかな距離なんだ。
#04

最後の30メートルの壁

整備されていない世界
  • 段差、階段、砂利道。歩行者が前提の場所が連続する
  • 境目をどこに引くか自体があいまいで、判断が難しい
  • 屋外と屋内では、まったくちがうルールが待っている
30メートル進むたび、世界のルールが変わる気がする…!
#05

エレベーターの問題

小さな部屋は最大の難関
  • ボタンを押す・乗る・降りる、の一連の動きが必要
  • 人と同じ箱に乗るには、マナーと安全の両立が求められる
  • 建物ごとに機種や階数の表示がちがい、同じ仕組みで使い回せない
呼ぶ 乗る 階を選ぶ 降りる
エレベーターは「小さい部屋」。他人と一緒だと気まずさまで管理しないと（笑）
#06

ドアを開ける難しさ

たった一枚の扉が重い
  • 引き戸・押し戸・重い扉。種類ごとに力の加減がちがう
  • 手で「引いて」体を支える動きは、二本の足で歩く機体でも難しい部類
  • オートロックの解錠は、そもそも権限の問題も絡む
扉を一枚開けるのに、全身の協調が必要になるんだね。
#07

届け先の特定

住所だけでは見つからない
  • 住所が同じでも「A棟の2階の奥」など、現場は迷路だったりする
  • 玄関が裏側にある家、表札のない建物も少なくない
  • 地図のピンがずれるだけで、届け先を間違える
例: 「3丁目101」だけでは分からないこと
  ・玄関は表? 裏?
  ・届け先は何階?
  ・置く場所の指定は?
地図の上では1センチ、現場では迷路。このギャップが痛い…
#08

人とのやり取り

配達は対話でもある
  • 受け取り人が不在のとき、どうするかの判断が求められる
  • すれちがう人、子どもやペットへの注意も毎回、必要になる
  • 「ここに置きました」の報告と確認も体験の一部
挨拶や気配りまで含めて「配達」なんだと感じる回だったなあ。
#09

安全とセキュリティ

守るべきことが多すぎる
  • 置かれた荷物は、盗難やいたずらの的にされやすい
  • 閉じた空間に入る機械には、思いがけない動きへの備えが要る
  • カメラを載せた機体が建物に入る、プライバシーの論点も
技術だけでなく、ルール作りも同時に進める必要があるね。
#10

荷物を置く場所の判断

「とりあえず置く」はダメ
  • 雨に濡れる場所、日向、通行の邪魔になる場所は避けたい
  • 「玄関の横」でも、家ごとに正解がちがう
  • 写真を撮って残す報告も、信頼のために欠かせない
置くだけでも人並みの気配りが要る…! ここが奥深い。
#11

天候の影響

空模様が試験になる
  • 雨や雪でカメラの視界がふさがり、路面は滑りやすくなる
  • 真夏の強い日差しでは、機器の熱の管理まで課題に
  • 悪天候ほど配達の需要は増える、という皮肉な重なり
厄介な日の例
  雨   視界と滑りの悪化
  雪   道が消える・凍結
  猛暑 バッテリーと熱の負担
人は「今日は嫌だな」で耐える。機械は止まる。ここが差だね。
#12

都市と郊外のちがい

戦場で必要な力が変わる
  • 都市: 人が多く、エレベーターや大きな建物の課題が集中
  • 郊外: 距離は長いが、一戸建ての玄関までが主な戦場
  • 同じロボットでも、戦略がまるでちがう必要がある
「どこで戦うか」で、必要な技術の中身が変わるんだ。
#13

コストの壁

最後の一歩は高くつく
  • 最後の30メートルを担う仕組みは、量産が効きにくい
  • 対応する建物の数だけ、個別の調整が発生しがち
  • 人が担う最後の工程と、費用を比べられる日々が続く
道の走行: 低め 最後の30メートル: 高め
「人の手」より安く、速く、確実に。この3つが揃わないとね…。
#14

No Priors とは

AI界の重鎮が送る対談の番組
  • 司会は Sarah Guo と Elad Gil。投資家であり、AI界の重鎮
  • 研究者や起業家を迎え、AIの先端を行く話を深掘りする
  • ロボットとAIの掛け算も、たびたびテーマになっている
短いショート動画でも核心を突くのが、この番組の流儀なんだ。
#15

なぜ今 話題なのか

焦点が「最後の一歩」へ
  • 生成AIの進歩で、ロボットの頭脳が一気に賢くなった
  • 配達の人手の不足は、多くの国で共通の悩みに
  • 「走る」ができたからこそ、次は最後の30メートルに注目が集まる
AIが賢くなったぶん、最後の一歩の難しさがよく見える時代なんだね。
#16

ロボットとAIの今後

三方よしで進む改善
  • 言葉を理解するモデルが、曖昧な指示の処理を助ける
  • 建物側の設計や受け取りの工夫など、社会側の対応も進む
  • 配達だけではなく清掃や警備など、屋内での作業への波及も期待
機械が賢く 建物が協力し 人が気持ちよく
機械と建物と人、3者が一緒に賢くなる必要があるね。
#17

まとめ: 見えない難問

この動画が遺した核心
  • 自動での配達の主な戦場は、道路ではなく最後の100フィート
  • エレベーター、ドア、届け先、天候…小さな壁の積み重ね
  • 解決には技術だけでなく、建物や人との約束作りが必要
  • No Priors が指摘した「見えない難問」に注目が集まる理由が分かる回
走る＝クリア 最後の30メートル＝今後 届いた!（ゴール）
あなたの家の玄関も、実は技術の先端かもしれない…!
