静かに壁が壊れた

  • 8月11日、OpenAI が大きな前触れもなく更新を投入。これは毎年の小さな変更ではなく、仕事の持ち運び方そのものを変える内容
  • ChatGPT が、他の AI ツールからあなたのセットアップをまるごと持ってこられるようになった
  • 対象は スキル・プロジェクト・チャット。すべてがワンクリックで動く
  • 新しくて、巨大で、そしてバカほど簡単に使える
今日は、誰も予想していなかった壁を OpenAI が壊した話をします。最後までお付き合いください！

何ができるようになった？

  • ChatGPT・Codex・他の AI ツールの間で、仕事を同期したまま保てるように
  • プロジェクト・チャット・スキル・プラグインを、一つの動きで取り込める
  • いまこの瞬間から ChatGPT のデスクトップアプリの中で利用できる
最後まで見ていてね。終盤に、ほとんどの人が見落とす部分が出てきます。そこが、一番時間を節約できるところなんです！

これまでの課題

  • AI ツールの設定に何時間もかけたのに、新しいツールが出るとまた振り出しに戻っていた
  • 新しいツールへの乗り換えは、すべてをゼロから組み直すことを意味した。遅いし、面倒
  • だから多くのビジネスは「もっと良いもの」を試すことすらしない。閉じ込められた気持ちが最大の理由だった
  • これは、私たちの多くがずっと繰り返してきた経験。でも、もう終わり
「せっかく整えたのに、また最初から」— この感覚、覚えがありませんか？

動くコンテンツ運用の例

更新前

  • 新しい AI ツールを試すたび、誰かがすべてのワークフローを手で組み直し
  • コンテンツのテンプレート、コミュニティ返信のスクリプト、オンボーディングの流れ
  • より良いツールが現れるたび、何時間も失われる

更新後

  • 運用全体が一回の取り込みで移動。すべてのワークフロー、スキル、プロジェクトのフォルダがそのまま運ばれる
  • 「組み直しで1日止まるチーム」から、数分で制作に戻れるチームへ。閉じ込められた気持ちは、これで完全に消える
例に挙げるのは、AI Profit Boardroom のような、速さが命のコンテンツ運用です！

どこから持ってこれる？

  • デスクトップアプリが Claude Code・Claude の共同作業ツール・Cursorから、セットアップ全体を引き寄せる
  • 持ってこられるものは、指示・設定・スキル・プラグイン・プロジェクト・最近の仕事
  • 何が来るかは、あなたがちょうど選べる
  • 一番良い部分: 古いセットアップには触れないし、削除もしない。元のツールはそのまま残る
  • つまり、試すことにリスクはゼロ
「移したら元が消えるかも」という心配は、まったく要りません！

始め方はとても簡単

  • デスクトップアプリを開く
  • 設定へ進む
  • 取り込み（Import）をクリック。表示されない場合は、一般設定の中の Import other agent setup を探す
  • 元にするツールを選び、持ってくるものを選ぶ。それだけ
  • 1分後には、何も変わっていないかのように仕事に戻れる
ChatGPT デスクトップアプリ
 └ 設定 → 一般 → Import other agent setup
      → ツール選択 → 項目を選ぶ → 完了
難しい準備は何ひとつなし。アプリの中の、たった数クリックです！

コンテンツチームの例

  • YouTube チャンネル・メールマガジン・コミュニティを同時に回すチームを想像して
  • 以前は新しいツールのたび、台本作成スキル・サムネイルのアイデア出しスキル・コメント返信スキルをゼロから作り直していた
  • 動画を1本作る前に、実際に何時間も消えていた
  • 今は一回の取り込みで、それらのスキルが全部移る。組み直しの1日を、もっと多くの動画と投稿を世に出す時間に変えられる
  • 出ていくコンテンツが増えれば、新しい人が見つけて参加する機会も増える
失っていた制作日のぶんだけ、コンテンツが増える。これが今回の更新の威力です。

中身はどう対応する？

  • 取り込みの時、ChatGPT は少しだけ持ってくるのではなく、セットアップ全体を自分の形へ写す
  • 指示のファイル → エージェントのファイルへ
  • 設定 → Codex の設定へ
  • スキルはスキルのまま、プラグインもプラグインのまま
  • プロジェクトのフォルダは同じ構成のまま持ってこられる
  • プロジェクトの記憶も引き継がれ、直近30日のチャットも付いてくる
ここが、冒頭で言っていた「みんなが見落とす部分」。全体の仕組みがそっくり移ることが、一番の時間の節約になるんです！

1本の動画が4倍働く

  • 1本の YouTube 台本を、メールマガジン・SNS 投稿一式・リードマグネットへ自動で変えるスキルを例に
  • 更新前は、そのスキルは1つのツールの中にしか存在しなかった。別の AI モデルを試すにも、全部手で作り直す必要があった
  • 更新後は、同じスキルがそのまま移ってくる。どの AI ツールが書いていても、1本の台本がまるごとコンテンツのじょうごになる
  • チームが4倍働くわけではないのに、1つのコンテンツが4倍働く
仕組みを一度組めば、道具を替えても育ち続ける。これが今回の本質です。

さらに奥まで移る

  • MCP サーバーの設定も付いてくる
  • フック（hooks）も付いてくる
  • スラッシュコマンドは スキルへ変換
  • サブエージェントは Codex のエージェントへ変換
  • つまり、表面の薄いコピーではない。仕事のシステム全体が、一度の操作で移り住む
見える部分だけでなく、動きを支える土台まで一緒に運ばれます。

サポート体制の例

  • 1日に何百ものサポートと販売の質問が来るコミュニティを想像して
  • 以前は、大きなサポートチームか、創業者が深夜に返信するかのどちらかが必要だった
  • 質問を仕分けし、返信の下書きを作り、プレミアム指導を尋ねる人に印を付けるサブエージェントを組めば、その仕事は自動で回る
  • そのサブエージェントと、紐づくすべてのフックと自動化が、一度の操作で新しいツールへ移れる
  • サポートの仕組みは壊れない。ツールからツールへ、更新のたびに前へ運ばれ続ける
深夜の返信作業から解放されて、仕組みだけが働き続ける状態を目指せます。

賢く見つけて、賢く選ぶ

  • まず ユーザーレベルの設定、つまりあなたのマシンの中にあるファイルを確認する
  • 次に既存のプロジェクト、向けていたフォルダやリポジトリも見る
  • そしてきれいな一覧を見せて、持ってきたいものにちょうど印を付けられる
  • 選んでいないものがこっそり紛れ込むことはない
  • ログインがまだ必要なプラグインや接続は、当てさせずに教えてくれる
「何を移したらいいか分からない」を防ぐ、丁寧な作りになっています！

ターミナル派向けの方法

  • 2つ目の方法は、ターミナルで暮らす人向け。Codex でも取り込める
  • ローカルで Codix のセッションを開き、import コマンドを打つ
  • Claude Code か Cursorを選び、設定・プロジェクトのファイル・最近のチャットを選ぶ
$ codex          # ローカルでセッション開始
> import        # import コマンドを入力
  元にするツール: claude code / cursor
  対象: 設定 / プロジェクト / 最近のチャット
  • 注意: CLI では 直近30日分から最大50件のチャットまで
  • 仕事の途中や、リモートのセッションでは実行できない
取り込みは、仕事の途中ではなく、新しい仕事を始まるタイミングですっきりやるのが正解！

リード獲得の例

  • 特定のプロンプト一式、アプローチの手順、指導を受けたい人と無料の内容で満足する人を選り分ける方法で組み上げた、リード獲得の仕組みを想像して
  • その全体は、プロジェクトのファイルとチャットの履歴の中に存在している
  • CLI の取り込みなら、技術に強いメンバーが、その仕組み全体を1回のセッションで新しいツールへ引き入れられる
  • 昔のチャットを掘り返して「どう組んだっけ？」と思い出す必要はない
  • 仕組みは、一人の記憶ではなく、チームと一緒に育つようになる
属人化していたノウハウが、チームの資産として持ち運べる時代です。

うまくやる3つのコツ

  • 最初はテストと思え: 取り込みは古い設定を一切変えないので、まずは少し持ってきて、触って慣れる。損は一切ない
  • むやみに信用しない: 移ってきたスキルを開いて、権限（許可）を確認。ログイン付きのツールは、もう一度サインインが必要かも
  • 状態カードを見る: 取り込み後に表示されるカードが、まだ設定が必要なものを教えてくれる。手順に従えば完了
この3つを押さえておけば、初めてでも安心して試せます！

ビジネスへの影響

  • 更新前は、成長の上限が小さなチームが手で組み直す速さで決まっていた
  • 新しい AI の進歩のたび、古いツールに留まるか、新しい方で数日を失うかの選択を迫られていた
  • この更新で、そのトレードオフは消える
  • 少人数のチームが、最新の AI ツールをリリースと同じ週に試し、ワークフローをすべて保ったまま先へ進める
  • コンテンツは出続け、コミュニティの質問には答え続き、オンボーディングは回り続ける。チームは作り直しではなく戦略と成長に時間を使う
  • 持ち運べて速いビジネスは前へ、1つのツールに閉じ込められたビジネスは後ろへ。どちら側に立つかは、もう分かっているはず
これは現実的な競争優位になります。まだ組み直しで止まっている相手に、差をつけられます。
