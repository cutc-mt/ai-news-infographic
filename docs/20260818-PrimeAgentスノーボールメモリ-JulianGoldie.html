第一部: なぜ「また説明するの?」が起きるのか

①

同じ説明の
終わらないループ

  • 「この手順はこうでした」と 何度も言い直す
  • 説明のやり直しで、作業時間が倍増
  • 人の側の疲れだけが、どんどん積み上がる
「え、また最初から?
さっき教えたのに…」
毎回の悲劇
②

タスク完了で
エージェント消滅

  • 仕事が終わると記憶ごと消えるのが旧来の仕様
  • 次に呼んでも、それは別人格（新規さん）
  • 前回までの文脈が、きれいさっぱり途切れる
「使い捨てAI」だと、
育てる楽しさもゼロなんです
③

セッション
リセットの悪夢

毎回ゼロに戻るもの
  • 細かく決めた好みの設定
  • 共有した業務ノウハウ
  • 「前はこうしてね」の 約束ごと
白紙状態への後戻り…
これが生産キラーでした
④

そこへ登場
Prime Agent

  • 消える運命を、根本から変える設計
  • 記憶を担ぐ新しい骨組み
  • 中身はオープンソースで公開中
一度教えたら、
ずっと覚えている…!
夢の仕組み

第二部: 「スノーボールメモリ」って何?

⑤

雪だるま式に
育つ記憶

  • 名前の由来は雪玉（スノーボール）
  • 斜面を転がるほど、玉がどんどん大きく
  • 知識も同じ。経験が層になって積もる
小さな雪玉が、いつか
巨大な雪だるまになる感じ!
⑥

使うほど
賢くなる仕組み

使う 学ぶ 覚える 成長
  • 新しい知識を、既存の玉にくっつけて保存
  • 学びの勢いが止まらない
溶けてなくなる雪と違って、
時間が経つほど大きくなる記憶です
⑦

骨組みを
根っこから変革

  • 小手先のパッチでは解決できない問題
  • 記憶を持つよう設計思想を刷新
  • 「消える前提」から「残る前提」へ
architecture: {
  old: "task done -> agent dies",
  prime: "task done -> memory stays"
}
土台から作り直したから、
美しいくらい解決しちゃう!
⑧

セッションを
またいで保持

  • 画面を閉じても知識は退場しない
  • 昨日の学びを、今日もそのまま再利用
  • 記憶の置き場が、ずっとそこにある
「再起動＝白紙」の常識が、
いとも簡単に壊れました

第三部: これで何が変わるのか

⑨

再説明が
ゼロになる

  • 「この手順ね」の 説明を切る
  • 指示は1回だけで、あとはお任せ
  • 浮いた時間を本業に全振り
「前と同じで!」の一言で
済むようになる快感よ…
⑩

時間が経つほど
性能が向上

  • 初期より、1週間後の方が確実に仕事がうまい
  • 迷いが減って、回答が速く・正確
  • 成長カーブが、右肩上がりを描く
新人AIが、いつの間にか
ベテラン社員になるイメージ
⑪

旧タイプとの
徹底比較

旧エージェントPrime Agent
終了で消滅 記憶が継続
毎回の説明説明は1回だけ
性能は横ばい使い勝手が上昇
育てがいなし成長が見える!
違いは「続くか、消えるか」。
たった一行の差です
⑫

知識の
複利(ふくり)効果

  • 学んだ物が次の学びの土台になる
  • 貯金の利子みたいに、知識が増えていく
  • 終わりのない成長ループ
預けた知識に利子がつく。
それが複利のチカラです

第四部: オープンソースの実力

⑬

中身は全部
公開されている

  • オープンソースで誰でも閲覧OK
  • 改良をみんなで持ち寄れる
  • 特定の会社に、 縛られない自由
$ git clone prime-agent
$ # 好きに覗いて、好きに改造!
仕組みを丸ごと確認できるのが、
公開文化ならではの安心ポイント
⑭

教える手間が
消えていく

1回教える 覚えている 次回は即戦力
  • 引き継ぎ書を、毎回ゼロから書かない
  • 仕事の好みも、そっと記憶
こっちが楽になるほど、
AIへの愛着も深まる不思議
⑮

こんな場面で
活きる力

  • 毎週の記事やメールの下書き
  • 店舗サイトの定期更新
  • 決まった型のデータ整理・点検
  • 英語→日本語の翻訳リレー
「繰り返し + こだわり」がある
仕事ほど、効果が大きいです
⑯

始め方は
かんたん3-step

  • 公開リポジトリから入手
  • いつもの仕事を1つ任せてみる
  • 感想を伝えて記憶を育てる
小さな雪玉からでOK。
転がし始めれば、あとは任せて!

第五部: まとめと今後の視点

⑰

おさえておく
注意点

  • 覚える物が増えるほど、記憶の管理が大事に
  • いらなくなった知識は、ときどきお掃除
  • 人に見せてはいけない情報の扱いは慎重に
部屋と同じで、
整理しないと宝の山も迷子に…
⑱

まとめ:
雪玉は止まらない

  • 消える運命のAI → 記憶を持つAIへ
  • 鍵となるのはスノーボール型の記憶
  • 時間が経つほど、仕事ぶりが向上
  • もう 説明し直さなくていい時代へ
AIを「育てる」楽しさに、
今日から出会えますように!
