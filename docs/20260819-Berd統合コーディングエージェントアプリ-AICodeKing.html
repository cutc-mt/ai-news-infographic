ACP = Agent Client Protocol

接続の仕組み

  • Berdは全ハーネスと ACP 経由で通信
  • ACPを話せるエージェントなら誰でも接続可能
  • アダプターを挟む仕組みで拡張性が高い

「エージェント」＝ペルソナ

Berdの中核概念

  • エージェントとは 事前設定されたペルソナ
  • それぞれに 独自の指示 が与えられる
  • それぞれが 独自のキャラクターモデル を持つ
  • 直接チャット or チャット内で メンションして参加 させる
「指示+キャラ」のセットが エージェント！

内蔵エージェント6人組

個性派ぞろい

  • Berdy: Berd自体の操作を支援
  • Copycat: あなたの文体を学習し、AIっぽい文章を回避
  • Pushback: 原稿への批判的な視点を提供
  • Choosey: 代わりに決めるのではなく、意思決定を支援
  • Tinker: 必要な時に新しいエージェント/スキルを構築
  • Wildcard: 一人では思いつかない突拍子もないアイデア
6人の個性派を 使い分け！

プロジェクト機能

違いは「フォルダ付き」

  • 他のAIアプリのプロジェクト機能に近いが フォルダが付属
  • 「プロジェクトを作成」→ 名前付け（例: 映画レビューの共有）
  • 作業する フォルダを選択（新規の空フォルダでもOK）
  • プロジェクト内容を説明する コンテキストボックス
  • アイコン色のカスタマイズ など細かい作り込みもGood
# 動画内の設定例
Project: 映画レビューの共有
Folder : 新規作成の空フォルダ
コンテキストは 最初に書いておこう！

実践: 映画レビューアプリ

ちゃんとしたコーディングエージェント

  • プロジェクト内で Codex + GPT 5.6 Soul の新規チャットで「作って」と指示するだけ
  • 直ちに 構築戦略 を策定（自己完結型の映画レビューカードツール）
  • ワークスペースを検査 → 空フォルダ → 新規MVP として扱う
  • 勝手に進めず きちんと質問（組み込みカタログ or TMDB? APIキー対応?）
  • トークンがブラウザに渡らない サーバーサイドプロキシ を提案
  • モックアップ生成時は トークン大量消費の警告 も正直に表示
チャットボットではなく 本物のエージェント！

スキルシステム＆通知

Claude Codeと同じ考え方

  • チャットで 「/」 を入力するとスキルメニュー表示
  • 初期搭載: Agent Builder API / インターフェースデザイン / アバンギャルド フロントエンド / Berdヘルプ
  • スキル＝再利用可能な指示 を必要な時に呼び出す仕組み
  • 「追加」から エージェントやファイルを参照 可能
  • 応答完了で 音付きデスクトップ通知 が届く
