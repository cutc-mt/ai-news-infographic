ChatGPT Work + Codex が WILD に！ セットアップの丸ごと移行

2026年8月19日
OpenAI Just Made ChatGPT Work + Codex WILD ／ Julian Goldie SEO ／ 8分5秒

閉じ込めの時代の終わり

  • AI ツールを乗り換えるたび、せっかく整えた設定を作り直すハメになっていた
  • スキル・プラグイン・プロジェクト・チャット。育てたものほど、移すのが大変
  • 「使い慣れた道具から動けない」という閉じ込めが、多くの人の判断をにぶらせていた
  • OpenAI がこの縛りを、たったの数クリックで断ち切った
もっと良い道具が出ても、乗り換えの痛みが邪魔でした。その常識を、OpenAI が壊します！

新機能「agent imports」とは？

  • OpenAI が ChatGPT のデスクトップアプリに加えた新機能。名前は agent imports
  • ほかの AI ツールで作ったセットアップの全体を、ChatGPT 側へそのまま持ってこられる
  • 必要な操作は数回のクリックのみ。開発の知識はいらない
  • 「1つずつ作り直す」工程が消えて、何も作り直さずに移行が完了する
動画の説明文いわく「OpenAI が AI ツールの閉じ込めを終わらせた」。大げさじゃないんです！

対応するツールは3つ

  • Claude Code — ターミナルで動く、エージェント仕事の定番ツール
  • Claude Cowork — みんなで作業する向けの、Claude のアプリ
  • Cursor — 人気の AI コードエディタ
  • この3つが、いまの取り込み対象。今後さらに増える可能性も
ライバル会社（Anthropic 系）からの移行を、OpenAI が自らサポートしたのが面白いところ！

ライブデモの流れ

  • 動画では、実際のセットアップの全体を一気に移す様子を披露
  • スキル・プラグイン・プロジェクト・チャットが、一つの流れで引っ越す
  • 移し終わった ChatGPT 側で、すぐに仕事を再開できる
  • 今まで何時間もかかった組み直しの時間が、丸ごと消えた
デモを見れば、「1回の取り込みでどこまで動くか」がはっきりわかります！

移行は5ステップ

  • ChatGPT のデスクトップアプリを開く
  • 取り込み元のツールを選ぶ
  • 持ってくる項目を選ぶ
  • 取り込みを実行して、完了を待つ
  • 移った内容を確認しておしまい
  • ポイント: 古いセットアップには一切、触れない。削除もしない。つまりリスクはゼロ
コピーであって引っ越しじゃないので、元のツールはそのまま残ります！

何が移るの？

  • スキル（skills） — あなたが育てた、仕事の型
  • プラグイン（plugins） — 外に足す機能のまとまり
  • MCP — 外部のサーバーとつなぐ設定
  • プロジェクトとチャット — これまでの作業の歴史
  • ほかにも、セットアップを形作る部品のほとんどが対象
「これが移らないと困るのに…」というものまで、ちゃんと含まれています！

自動で最新に保つ

  • 取り込みは一度きりで終わらない。元のツール側の更新があれば、取り込んだ内容も自動で追従
  • 両方のツールを行き来しながら使う人に、ちょうどいい設計
  • 都度、手で取り直す必要がなく、手間が減る
  • 同期のさせ方については、自分で選べる部分もある
移して終わり、ではなく。その後もずっと、ついてきてくれるんです！

デスクトップで3クリック

  • ChatGPT のデスクトップアプリを開く
  • 設定の中の、取り込みのメニューへ進む
  • 元にするツールを選んで、実行するだけ
  • 全体で3回のクリック。迷う要素がない
ChatGPT デスクトップアプリ
 └ 設定 → Import
      → ツールを選ぶ → 実行 → 完了
対応しているのはブラウザ版ではなく、デスクトップアプリの方です。お間違いなく！

ターミナルの /import

  • デスクトップの画面とは別に、コマンド一発で進む道もある
  • ターミナルで /import と打つだけ
  • こちらの方が速いと感じる人も多い
  • CLI に慣れた人には、特に気持ちいい操作感
$ /import
→ 取り込み元を選択 → 実行 → 完了
ターミナル派の人は、こっちの道の方がしっくりくるはず！

CLI を使う前の注意

  • CLI 経路には、いくつかの制限がある
  • デスクトップ経路と比べると、扱える範囲が狭い部分もある
  • 実行の前に、何が移せて何が移せないかを確認
  • 迷ったら、まずはデスクトップからの取り込みが無難
速さだけを見て飛びつくと、あとで「あれ？」になりがち。最初に確認を！

移行した後のチェック

  • 権限（permissions） — 許可の設定が、そのまま移ってきたか
  • サーバー（servers） — MCP などの接続が、生きているか
  • hooks — 自動で走る処理の組み込みが、正しいか
  • ここを確かめないと、動いた「つもり」で止まっていることがある
動画で「ほとんどの人が飛ばす」と言及されるのが、まさにこの工程です！

付属のチェックリストカード

  • ChatGPT 側に、確認用のカード（The Card）が、もともと用意されている
  • 権限・サーバー・hooksを、画面の上で順に確かめられる
  • 外にメモを用意しなくていい。すべてアプリの中で完結
  • 取り込みが終わったらこのカードを開くのが、動画おすすめの習慣
移したら、まずこのカードを開く。それが動画からの教えです！

壁が取り払われる理由

  • ベンダーによる閉じ込め（ロックイン）が、実質的に機能しなくなった
  • 道具選びの基準が「乗り換えの痛さ」から、純粋な良し悪しへ変わる
  • どの会社も、本当に良いものを作るしかなくなっていく
  • 使う側にとっては、得になることしかない流れ
「移るのが面倒だから我慢」が消えると、各社は本気を出さざるを得ません！

次の一歩はここから

  • まずは自分のセットアップで、小さく試すところから
  • 取り込んだら、権限・サーバー・hooksの確認を忘れずに
  • 気に入らなければ、元のツールは無傷で残っている
  • 動画の概要欄から、さらなる案内へ進める
試すコストがほぼゼロの今が、触ってみる最高のタイミングです！

みんなが飛ばす1ステップ

  • 取り込みが済むと「終わった感」が出て、その後の確認を飛ばしがち
  • 見落とされやすいのは、権限・サーバー・hooksの3点チェック
  • この一手間で、あとからのトラブルが大きく減る
  • 動画の説明文でも、この「たった1つの見落とし」が強調されている
「動いたっぽい」で終わらせない。この癖が、仕事の差になります！

元の環境は無傷のまま

  • 取り込みは「コピー」であって「移動」ではない
  • Claude Code・Cowork・Cursor 側のデータは、一切、消えない
  • 失敗を恐れず、何度でも試せる
  • 元のツールに戻りたくなっても、何ひとつ失っていない
「元の環境が壊れるかも」という心配は、この設計では無用です！

道具を選ぶ自由が戻る

  • これまでの乗り換えは、コストが重すぎて「比べる」以前の問題だった
  • 移行が数クリックになると、道具をいつでも取り替えられる
  • 新しいツールが登場するたび、すぐ試して判断できる
  • 選べる立場にある人が、良い道具を手にする — 実務での強みになる
使う側に「選ぶ力」が戻った。これがこの更新の本質です！

まとめ: 自由に持ち運べる

  • ChatGPT のデスクトップアプリが agent imports に対応
  • Claude Code・Cowork・Cursorから、数クリックでまるごと取り込み
  • 対象はスキル・プラグイン・MCP・プロジェクト・チャット
  • 取り込みの後は、権限・サーバー・hooksの確認を忘れずに
  • 道具に閉じ込められる時代は、もう終わった
今日から、あなたのセットアップは自由に持ち運べます。まずは小さく試してみて！
