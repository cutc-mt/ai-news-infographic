DeepSeek Harnessとは

まずは全体像

  • DeepSeekが公開した公式 エージェントハーネス
  • OSS としてGitHubで公開
  • 「DeepSeekのハーネスってどうなってるの?」への答え
  • 公式ハーネスとして、ついに登場
中身が気になっていた 公式ハーネス がついに公開されたよ！

npxコマンドで起動

導入のしかた

  • npx コマンド1つでスタート
  • 事前に Node.js のインストールが必要
  • GitHubリポジトリにアクセスして手順を確認
  • セットアップの手間が少なく試しやすい
# Node.js を用意した上で
npx deepseek-harness
# → ハーネスが立ち上がる
導入はnpxで サクッと 立ち上げられる！

Webアプリ型のUI

ブラウザから使う

  • ブラウザ上で動く Webアプリ 型
  • ごく普通の チャット画面 で操作
  • アプリの見た目もかなり綺麗、との評価
  • ターミナルだけのツールより取っつきやすい
GUIで そのまま 会話できるのが楽ちん！

特徴的な4つのモード

使い分けの軸

  • スタンダード モード
  • PTC モード
  • ミニマル モード
  • クリエイター モード
  • 基本はスタンダードとPTCが中心
シーンに合わせて モード切替！

スタンダードモード

フル機能で使う

  • AIエージェントを 普通に使い倒す モード
  • Skills をフル活用
  • Web検索 もしっかり使える
  • 全部入りで使いたい人向けの設定
まず試すなら ここから！

PTCモード（目玉）

発想の転換

  • ツールを 1個ずつ呼ばない
  • モデルが Pythonプログラムを1本 書く
  • プログラムから 並列実行
  • LLMとの 往復回数を削減
# イメージ比較
通常: LLM ⇄ ツール を都度 往復
PTC : LLM → Python 1本 → 並列実行
「1本書いてまとめて処理」で ムダな往復 をなくす！

ミニマルモード

道具を絞る

  • Bash だけ
  • 文字を置き換える 置換エディタ だけ
  • 権限・影響を絞りたい場面に
  • シンプルに慎重に動かしたいときに便利
必要最小限で 慎重モード！

クリエイターモード

4つ目のモード

  • 作成系 の作業に寄せたモード
  • コンテンツ制作などでの利用を想定か
  • 動画では名称の紹介が中心
  • 詳細は公式リポジトリで確認するのがおすすめ
気になる人は README をチェック！

権限設定

無難で安心の作り

  • Read Only（読み取り専用）
  • Full Access（フルアクセス）
  • ごく普通に無難な権限体系
  • 他のエージェントツールと同じ感覚で運用できる
まずは Read Only で様子見が安心！

サブエージェント連携

他ツールを呼べる

  • Codex や Claude Code をサブエージェントとして使用
  • プラグイン として用意されている
  • 標準では 無効化 済み
  • 設定から有効化して連携
他社製エージェントを 部下 にできる！？

やり取りを「見られる」

地味にうれしい機能

  • チャット中の やり取り が見える
  • 仲間（並走エージェント）の様子を こっそり確認
  • 動画主も「これは便利」と評価
  • 何が動いているか把握しやすい設計
並走仲間のようすが 見える のは便利！

すべてがプラグイン設計

最大の特徴

  • セッションログ もプラグイン
  • エージェントループ すらプラグイン
  • コアに機能を「足していく」設計ではない
  • コア自体が交換可能
「核すら交換できる」 徹底ぷり がすごい！

いろんなモデルに接続

プロバイダーを追加

  • プロバイダー追加 でモデルが増える
  • Z.AI / xAI にも対応
  • OpenAI や Copilot も選択可能
  • 適用すると、いろんなモデルが使えるように
好きなモデルを つなぎ替え 可能！

位置づけを正しく理解

期待値の調整

  • 生活を変えるような 破壊的な何か ではない
  • Claude Code / Codex のような 完成品のOSS化 でもない
  • エージェントを 自分で組むためのベース
  • DeepSeekが公式に出した、という点に意義
完成品ではなく ベース の公開！
