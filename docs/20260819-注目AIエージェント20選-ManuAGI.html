Clears — 自律的デリバリー

  • 貯まりがちな バックログ を読んで着手。
  • PR まで自動で作ってくれる。
  • しかも レビュー済み の状態で提出。
backlog（やることリスト）
  ↓ Clears が自律的に着手
reviewed PR（査読済みの変更）
放置されがちなバックログが、形になって戻ってくるのだ。

TinyFish — Web への入り口

  • エージェントに Web への通行手形 をあたえる。
  • ページを 読んで理解 して操作。
  • 調べものを まるごと自動 に。
agent ──▶ TinyFish ──▶ Web
        （見る・さわる・調べる）
外の世界を見られないエージェントは、もったいないのだ。

「いちばん強いモデル＝正解」ではなく、ならべ替えが費用を救う。
