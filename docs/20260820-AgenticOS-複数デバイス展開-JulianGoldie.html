② Tailscale で どこからでも接続

Agent OS 置き場の マシンへ接続

  • Tailscale に 参加させた機械どうしは むすばれる
  • Agentic OS を セットアップしたのは どれか1台のマシン
  • 別のデバイスから そこに入って使うかたち
  • 「どこにいても 自分の OS に会える」
Agentic OS の 入り口が ひとつあれば
あとは Tailscale が 入り口まで案内してくれるイメージ

エンドポイントを 渡すだけ

  • つなぎたい相手には エンドポイント（つなぎ先の情報）を教える
  • これで 別の機械から そっくりアクセスできる
  • そのあとは スキル作成 → タブ作成へ すすむだけ
# つなぐまでの ざっくり流れ
1. Tailscale でマシンを むすぶ
2. エンドポイント（つなぎ先）を共有
3. "このエンドポイントで
    スキルを作ってね" と依頼
「アドレスを渡す」だけ。
むずかしい工事は いらないよ

自分だけの あんぜんな網

  • Tailscale は 仮想プライベートネットワークのしくみ
  • 入れるのは 自分が認めた機械だけ
  • Agentic OS の中身を 外に みだりにさらさない
  • リモート作業の 定番となっている道具
「外からつなぐ」のに まるごと公開しなくていいから
こわくないのが うれしいところ

VPS に置けば 24時間動く

  • デメトリウスの相談にあった VPS＝クラウド上の いつも動く機械
  • 自宅の電源を 入れっぱなしにしなくて OK
  • 夜も朝も エージェントが稼働しつづけられる
  • 手元のデスクトップ／ノートは 入り口役に専念
寝ているあいだも VPS の上で
ルーティンが まわってる…という図が みえてくるね

③ 定期じっこうは「ルーティン」にまかせる

ステップ1 スキルを作る

  • まず スキルを ひとつ作る（やりたい仕事の部品）
  • 渡した エンドポイント先で 働く形にする
  • 「コンテンツ分析」など 1つのかたまりにまとめる
スキル ＝ じどう化したい仕事の
「お道具箱」だと思えば わかりやすい

ステップ2 タブを作る

  • Agentic OS の画面に タブを追加する
  • タブがあると いつでも ようすを見にいける
  • 仕事の種類ごとに タブが ふえていく設計
# Agentic OS の ならびイメージ
[ Muse ] [ Astros ] [ 新しいタブ ]
   ↑        ↑
 毎日じっこう中 こちらは後半で紹介
タブ ＝ 仕事ぶりの 窓。
ここから のぞけば いまの状態がわかるよ

ステップ3 毎日の予定に登録

  • 最後に ルーティン（定期じっこう）として指定
  • 言い方は これだけ → 「これを毎日じっこうして」
  • あとは 毎日くりかえし じどうで走る
  • 手でボタンを押す じぎょうは ぜんぜん不要
# 依頼のことば（イメージ）
"このスキルを Agentic OS のタブで
 毎日 スケジュールじっこうしてね"
よくある 定期タスクと同じ発想。
エージェント相手でも 予定を渡せば守ってくれる

おさらい 3ステップ

  • ① スキルを作る
  • ② タブを作る
  • ③ ルーティンとして 予定に入れる
  • この 3つだけで 定期じっこうが完成
動画の終わりで Julian が
ちゃんとくりかえし言ってくれてる大事なまとめだよ

⑥ 全体像を ひと目で

マルチデバイス展開の全体像

  • 自宅のデスクトップに Agentic OS を セット
  • Tailscaleで 手元／VPS／ノートを むすぶ
  • VPSに置けば 24時間体制で放置できる

  • 実例 Muse／Astros のように 人が触らず毎日動く
