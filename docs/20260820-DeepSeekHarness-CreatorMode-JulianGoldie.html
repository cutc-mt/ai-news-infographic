Creator Mode の唯一の仕事

存在理由はひとつだけ

  • Creator Mode は1つの仕事のために存在する機能
  • その仕事とは プロンプトで新プラグインをビルドすること
  • 動画冒頭で「a feature I teased」と予告されていた目玉機能
  • 汎用チャットでも、コード編集モードでもない。プラグイン生成専用
So creative mode exists for exactly one job... building new plugins by prompting.
「多数の機能を詰め込んだモード」じゃなく、一点特化。だから迷わない！

plain English 一文でツールが生まれる

願いを書くだけ

  • 1つの平易な英文で、欲しいツールを記述するだけ
  • プログラミング用語は不要。普通の英語でOK
  • 「こんなツールがあったらいいのに」がそのまま出発点
  • 文章 → ツール。この短絡径路が衝撃
You can describe a tool that you wish existed in one plain English sentence.
「願う」→「動く」。仕様書も設計図もいらない、 一文がすべて！

待ち時間ゼロの体験

  • ハーネスがツールをセッション内でライブに構築
  • ビルド完了と同時に自動でスイッチON。手動設定なし
  • 再起動や再読み込みの待ち時間なし
  • 生成された瞬間から、そのセッションで使い始められる
一文 入力 ライブ ビルド 即 利用可
「作って→入れて→再起動」が不要。 書いた瞬間、もう動く！

手順① 新規セッションを開始

まずは＋ボタン

  • 画面の＋ボタンをクリックして新規セッション開始
  • 既存セッションの続きではなく、必ず新規で
  • セッションとは「作業部屋」。新機能は新しい部屋で生む
  • ここを飛ばすとCreator Modeが選べないので要注意
// 手順①: 新規セッション
click("+ 新規セッション ボタン");
// → 真っさらな作業部屋が用意される
＋を押すだけ。ここは迷う要素ゼロ！
6

手順② Creator Mode を選択

モードを切り替える

  • 新規セッション画面でCreator Mode を選択
  • 動画内でも「click on creator mode over here」と実演
  • モード選択を忘れると、通常のチャット扱いになる
  • モード＝ハーネスの仕事の切り替えスイッチ
// 手順②: モード選択
select("Creator Mode");
// 通常モード → プラグイン生成モード へ
クリックひとつで、ハーネスが 「作る側」に回る！
7

手順③ 一文をタイプするだけ

最後は入力してEnter

  • 作りたいものを1文で入力する
  • 「type a sentence describing something that you want to exist」がそのまま指示
  • 長い仕様は不要。シンプルな一文が最強
  • 送信後はハーネスがビルドを完走してくれる
// 手順③: 一文で記述
"存在してほしいツール" を1文で入力
submit();
// → ハーネスがビルド＆ONまで完走
＋ 新規 Creator Mode 一文入力 完成！
3ステップ、合計30秒くらい。 お試しが捗りすぎる！

「すべてがプラグイン」設計思想

Everything is a plugin

  • ハーネスの機能はすべてプラグインとして実装
  • コアは最小。機能は差し替え可能な部品の集まり
  • 自分で作った部品も、標準部品と同じ土俵で動く
  • だからCreator Modeで「増やす」ことが自然な操作になる
// 設計思想のイメージ
harness = { plugins: [ ... ] };
// 検索も、編集も、実行も、
// あなたの自作ツールも、全部 plugin
「特別扱いの機能」がないから、 自作も一等市民。美しい設計！

ハーネス（harness）とは何か

馬具に由来する名前

  • 原義は馬具。力を制御して仕事に変える道具
  • AI用語では モデルを包む実行環境を指す
  • チャットUI、ツール実行、プラグイン管理をひとまとめに統括
  • DeepSeek Harness はその環境をOSSで提供するもの
// ハーネスの役割
harness {
  ui: "対話画面",
  tools: "プラグイン実行",
  modes: "Creator / 通常 など"
}
モデルが「馬」なら、ハーネスは 操るための馬具。名前の由来も納得！
