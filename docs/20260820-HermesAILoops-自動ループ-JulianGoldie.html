02

Loops って何?

輪っかのように回り続けるコマンド

  • Hermes AI の新しい命令のひとつ
  • 決めた間隔で、同じ作業を何度もくり返す仕組み
  • セッション(お話の履歴)の中で動くのがポイント
  • 外にサーバーを用意しなくて OK
#ループ #間隔指定 #セッション内
「ループ=輪っか」。一度はじめると、
ぐるぐると回り続けるイメージだよ🎡

使い方は 3ステップ だけ

03

① コマンドを打つ

/loops と入力するだけ

  • チャットに /loops と入力するだけ
  • 普通におしゃべりする感じで OK
  • 準備はこれだけで終わり!
# 入力するのはこれだけ
/loops
# → ループの設定がはじまる
難しい設定ファイルはナシ!
スラッシュからはじまる、おまじないみたいなコマンドだね✨
04

② 間隔を決める

どれくらいのペースで回す?

  • 「どれくらいの間隔で回す?」と聞かれる
  • 動画で出てきた例は 5分ごと
  • 短くも長くも、自由に設定できる
  • 間隔=ループが一周する長さ
#5分ごと #間隔の指定 #自由設定
「5分ごと」が例として出てきたよ。
仕事の中身に合わせて、ゆるく調整しよう⏱️
05

③ やってほしいことを伝える

ひとことで OK

  • 動画の例: check if my blog post is indexed yet
  • 意味は「ブログの記事は、もう載った?」
  • ざっくり日本語で伝えても大丈夫
/loops
間隔: 5分ごと
タスク: ブログの記事が検索結果に
       載ったか、確認して
英語でも日本語でも OK。
確認してほしいことを、ひとことで伝えよう💬

中でどう動くの? — しくみと正直なところ

06

起きて、調べて、また眠る

目覚まし時計のような動き

  • 5分たつと、自分で起きる
  • 決められた作業をチェック
  • 終わったら、また待機に入る
  • これをひとまとまりとして回す
#定期チェック #待機 #再開
目覚まし時計みたいに、時間が来ると
自分で起きて仕事をするんだ⏰
07

止めるまで、ずっと続く

何かが止めるまで回り続ける

  • ループは基本的に半永続
  • 「止めて」と言うまで回り続ける
  • 止まるまでは同じ間隔でくり返す
  • 使い終わったら、きちんと止めよう
#続けて動く #止め方を決める
放っておくと回り続けるから、
終わりの条件もいっしょに決めておくと安心だよ🛑
08

作った側の人のことば

「セッションの中の cron」

  • Hermes をいっしょに作った人が説明
  • 「cron jobs but inside a session」
  • cron = 決まった時刻に作業を走らせる、昔からある仕組み
  • それが、チャットの中で手軽に使えるように!
難しそうに聞こえるけど、「時間で動く仕組みが
ここにあるよ」っていう、たとえ話だよ🧠
09

ふつうの cron とくらべると

何がうれしいの?

  • ふつうの cron → OS 側で設定。専門の知識が要る
  • Loops → 会話だけで設定できる
  • 設定ファイルを書かなくていい
  • セッションを閉じないまま、同じ場で回り続ける
「サーバーの中で動く無機質な仕組み」が
「話しかけられる相棒」になった感じ!🤝
