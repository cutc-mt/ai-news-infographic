セクション1：Loops コマンドの正体

新登場の Loops コマンド

  • Hermes AI に最近加わったLoops commandが本次題
  • 自律的に動くエージェントの動き方そのものを変える更新
  • 名前のとおり、処理をぐるぐる回し続けるのが使命
  • 「やる」だけでなく「ずっと見ている」のが新しい点
いままでの命令は「1回やる」型。
Loops は終わるまで回る型だよ!

ビジネスをオートパイロットに

  • 動画タイトルの願いはautopilot(自動での操縦)で回すビジネス
  • 人が手を添えなくても、仕事が勝手に前へ進む状態を目指す
  • その部品として、ループが常に見張る係を担う
  • 最後まで確実にやり遂げる信頼が大事
操縦かんを握らないのがポイント。
エージェントに任せて、人は見守るだけ✈️

常駐する番犬(watchdog)

  • 概要欄の表現は persistent watchdog(しつこく見張る番犬)
  • ビジネスの過程を、ずっと注視し続ける
  • 一度だけ設定すれば、あとは常駐で見守ってくれる
  • 異変や完了があれば、こちらに知らせてくれる
まるで番犬みたいに、
寝ずに見張り続けるのがお仕事🐕

「見張る」のであって「追わない」

  • 動画の一言: 「It's just keeping watch — like it's not chasing」
  • ゴールを追いかける(chase)のとは、動きがぜんぜん違う
  • その場に座って、じっと状態を観察し続ける
  • 必要になったら、ちゃんと動く
「追う」か「見る」か。
このさじ加減が
Loops のこころなんだ👀

セクション2：ループのしくみを詳しく

タイマーで回り続ける

  • 動画の説明: 「It runs on a timer」 — タイマー駆動
  • 決まった間隔で、またチェックしにいく
  • 「looping round」 — ぐるぐる循環して、何度でも確認
  • だから checking(確認の作業)と特に相性がいい
時計の針が進むたびに
「そろそろ見てくる?」と
立ち上がるイメージ⏱️

終わったら知らせて終了

  • 動画: 「once that's done, then tell me — and that's when the loop would finish」
  • 仕事が完了したら報告があり、そこでループ終了
  • 終わらない限り、回り続ける
  • 「終わったよ」の一言を待つだけの手軽さ

ながれのイメージ

loop: 仕事は終わった? → まだ
loop: 仕事は終わった? → まだ
loop: 仕事は終わった? → 完了!
# → 「終わったよ」と報告 & ループ終了
報告が来るまで、
ずっとループは回り続ける。
これがわかりやすい終わり方🏁

会話に寄り添うモード

  • 動画: 「This is more for a conversation」
  • ループは会話の流れの中で使う向きの機能
  • 自分がその場にいて、やりとりしながら使う場面
  • 話しかけたら応じる、近くにいる感じの距離感
「ちょっと見といて」って
お願いする感じの距離感で
使うのがコツなんだ💬

見張り続けるほど力を発揮

  • 1回きりではなく、連続した監視こそ本領
  • リアルタイムの追跡(実況)に、ぐっと効く更新
  • アンテナを張りっぱなしにして、変化を拾う
  • 「ほっとけば勝手に見てくれる」安心感
心電図みたいに、
ずっと波形を見続ける
イメージで考えてみて💓

セクション3：cron とゴールとは何が違う?

cron ジョブ(定刻の仕事)

  • いわゆるscheduled task(定刻に実行する仕組み)
  • 動画: 「on a schedule whether I'm here or not」
  • 自分が寝ていても、いなくても、定刻には必ず動く
  • 毎朝9時にまとめを送る、みたいな決まった仕事向き
cron は「時報」みたいなもの。
時刻が来たら、どんな時でも
ちゃんと鳴るよ⏰

ゴール(goal)はやり遂げる型

  • 動画: 「get it done and just keep going until it's done」
  • 目標に向かって追いかけ続けるモード
  • できていないなら、できるまで前に進み続ける
  • 「達成」そのものがゴールの終着点
ゴールは「マラソン走者」。
ゴールラインを割るまで
走り続けるんだ🏃

3つを並べて比べる

  • 動画でも「よく聞かれるから触れるよ」と前置きがある論点
  • loop / cron / goal の使い分けが鍵
種類動き終わり
loopタイマーで見張る完了を報告
cron定刻に実行決まった時刻
goal追いかける達成した時
表にすると、ちがいはひと目でわかる!
見張る・定刻・追う、
3つの動詞で覚えよう📋

何度も確認する仕事に強い

  • 動画: 「it's really good for checking」 — 確認こそが得意な分野
  • 状態が変わったか? 終わったか? を何度でも見る
  • 無理に完了させようと、追い立てたりはしない
  • あくまで静かに、淡々と見守るスタイル
「チェック係」を任せる感じ。
焦らず、丁寧に、
何度でも確認してくれる🕊️

セクション4：どんな場面で使う?

競合リサーチを自動で

  • 概要欄が挙げる例: competitor researchの自動化
  • 競合の動きや価格、投稿を、ループで定期的に観察
  • 変わったことがあれば、すぐ知らせてくれる
  • 調査員を1人雇ったような効率に

監視のイメージ

loop: 競合サイトをチェック
# → 新しい記事を発見したら通知!
ライバルの様子を、
こっそり毎日見ててくれる。
まるでスカウトだね🔍

SNS の通知をまとめて監視

  • もう1つの例: social media notificationsの管理
  • 反応やメンションを、ループが欠かさず拾う
  • スマホを何度も開いて確認する手間がなくなる
  • 気づきが早くなり、返事もすぐ打てる
SNS ばっかり見ちゃう日々に
さよなら。
大事なものだけ届くよ🔔

ビジネスの過程を見張る

  • 概要欄: ビジネス過程のための常駐の見張り役
  • 複数の仕事の流れを、それぞれ並行で監視できる
  • 進み具合をリアルタイムで把握できるのが強み
  • 抜けや止まりに、いち早く気づける
工程表を、常に誰かが
なぞってくれている状態。
抜け落ちがすぐ分かる📊

手出しなしで最後まで

  • 概要欄の結び: manual intervention(手での介入)なしで完走する agent
  • 途中で人が助け舟を出さなくてよい設計が理想
  • 言われたことは、止まることなく実行し続ける
  • 任せた側は、結果の報告だけ待てばいい
「あとは任せた!」の一言で
動き続けるのが
かっこいいところ🙌

セクション5：導入の考え方・まとめ

違いを知ることが一番の近道

  • 概要欄: 3つの違いを知ることは必須(essential)とまで言い切る
  • 仕組みを選び間違えると、agent の信頼が落ちる
  • 見張りたい → loop / 決まった時 → cron / 遂げたい → goal
  • 動画も「よく聞かれるから解説する」と押さえどころ
どれを使うか迷ったら、
「見張る? 定刻? 追う?」
と自問してみよう🧩

まとめ: 監視を任せてオートパイロットへ

  • Hermes の Loops は、タイマーで回り続ける見張り役
  • 追わない・見張る・終わったら報告、が一連のながれ
  • 競合リサーチや SNS 通知など、実務ですぐ生きる
  • cron とゴールとの使い分けを押さえて、オートパイロットを完成させよう
見張りを agent に任せて、
人はもっと大事な仕事へ。
それが Loops の提案だよ🚀
