MiniMax Design って何？

01

ついに登場！

MiniMax の新アプリ

  • MiniMax からデザイン用アプリが登場！
  • 動画や画像の生成を、ぐんとやりやすく
  • 台本は AIエージェントと対話しながら詰める
  • テンプレートやスキルも豊富に用意
#MiniMax #デスクトップアプリ #映像の生成
11分の動画で、この新しいアプリの魅力をたっぷり解説してるよ！
02

対応する環境

デスクトップアプリ

  • macOS にしっかり対応
  • Windows ももちろん OK
  • アプリを落としたら、すぐに制作スタート
DL ログイン 制作スタート
手元の PC でじっくり取り組めるのが、デスクトップアプリのいいところ！
03

画面は3つのエリア

直感でわかる画面づくり

  • 左側：選択用のメニューバー
  • 中央：キャンバス（作品を置く場所）
  • 右側：AIエージェントとの対話の画面
メニュー キャンバス AI対話
「真ん中で作って、右で相談」
この3画面が基本のカタチだよ！
04

制作の流れ

キャンバス上で一気に通せる

  • まずテキストをキャンバスに置く
  • 次に画像を生成（例：2枚）
  • 音楽の生成も MiniMax なら可能
  • 仕上げに動画へと組み立てる
テキスト 画像 音楽 動画
視覚的に整理しながら、1つの作品にまとめ上げられる！
05

Claude Design との違い

似てるようで、目指す先が違う

Claude Design UI やスライドの制作に強い
MiniMax Design 映像の作品づくりに特化

⇩ こう使い分ける ⇩

  • 資料や UI ならClaude側
  • 動画など映像の作品ならMiniMax側
  • まさおさんはラップするライオンの動画を制作したよ
映像の出身じゃなくても、僕なりの作品をお見せしたい、とのこと！

料金とコストのリアル

06

必要なのは加入

サブスク方式で利用

  • 生成はクラウド上のリソースを使うしくみ
  • MiniMax のデザイン用プランへの加入が必要
  • 入ったら、リソースを使ってどんどん生成
アプリ自体は誰でも入手できるけど、
利用にはサブスクが要る、ってのがポイント！
07

料金のしくみは2本立て

まちがえないように注意

  • 普通のサイトにはトークンプランがある
  • こちらは画像・ボイスの生成などに利用
  • デザイン用は別のサブスクとして存在
  • M3 モデルは日本語も上達、コスパ良好
# 料金のまとめ（イメージ）
plans = {
  "token":   "通常サイトのAPI向け",
  "design":  "MiniMax Design 専用",
}
# → デザインで使うなら専用プラン！
普通のプランとは別なので、加入し間違いに注意！
08

クレジットの目安

プラン別・作れる本数

  • スタータープラン＝1万クレジット
  • 15秒の動画なら8〜9本ぐらい作れる
  • プロプランなら250本前後も可能
1万C 8〜9本 プロ250本
目安はあくまで15秒換算。長さで本数は変わるよ！
09

コストの現実

安くはなった、でも…

  • 動画の生成は、やっぱりお金がかかる
  • 1,500円程度では 15秒動画は多くは作れない
  • 30分動画をポンポン生成、はまだ無理
  • でも1分動画の費用は昔よりかなり低下！
本格的にやりたくなったら課金、今は様子見、というスタンスもアリ！

技術のトレンド

10

今のトレンドは H3

動画の生成で主役のモデル

  • 動画の生成といえばMiniMax H3モデル
  • ローカルLLMと組み合わせる手法が人気
  • クラウドでコスパよく生成、も定番に
  • まさおさんもローカル環境への投資を検討中
#ローカルLLM #クラウド生成
自前の環境か、クラウドか。選択肢が増えたのが今！
11

API も充実

コードを書く人には朗報

  • テキストの生成（M3）も API で利用が可能
  • 音楽の生成はパラメーターが多彩
  • ボイスの生成にもしっかり対応
  • 画像の生成も、もちろん API から
# API でできること（例）
client.generate("video", model="H3")
client.generate("music", params={...})
client.generate("voice", ...)
プログラムを書ける人には、API 経由がかなり柔軟！

  • オーディオを渡すことも可能

  • 何度も試しながら個性的な動画へ
音を頼りに映像を作れるのはちょっと珍しい機能！

ノードでつなぐ

プログラム不要の柔軟さ

  • テキスト・画像・動画のノードを連結
  • 人気のモデル（Seedance 2.5など）も選択
  • アスペクト比などの設定も自由
  • ヒューマンインザループで確認しながら進行

  # コード不要・目で見ながら調整！
プログラムを組むのが面倒な時の、強い味方だよ！
