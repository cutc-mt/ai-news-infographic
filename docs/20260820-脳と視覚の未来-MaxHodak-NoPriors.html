PRIMA —— 目のための「人工内耳」

A cochlear implant for the eye

  • 主力製品は PRIMA という網膜のインプラント。いわば「目のための人工内耳」。
  • 人工内耳は医療全体の中でも最大級のインパクト。生まれつき聞こえない赤ちゃんのスイッチが入る映像は、衝撃的。
  • 対象は、光を感じる細胞(桿体と錐体)が死んで失明した人。
  • 臨床の試験は加齢による黄斑変性で実施。次は網膜の色素変性やシュタルガルト病なども計画中。
耳の人工内耳が「聞こえ」を取り戻したように、目でも同じことを起こしたい。

仕組み —— メガネが像を投影する

レーザーで網膜を直接刺激

  • 小さなチップを、目の奥の網膜の裏側に埋め込む。
  • 患者が装着するメガネのレーザー投影機が、画像をチップに映し込む。
  • チップが死んだ桿体・錐体をバイパスして網膜を直接刺激し、視覚の信号を脳へ戻す。
  • 由来: スタンフォードの発明家が開発 → フランスの Pixium 社が臨床の試験を実施 → 2022年末の後に買収。
# 見えなくなった目に「像」を戻す経路
メガネの投影機 → レーザー → 網膜の下のチップ
  → 網膜を直接刺激 → 視神経 → 脳に像が浮かぶ
脳への入口は網膜。視神経が残っているなら、網膜から入るのが正解なんだ。

課題と、次の「見え方」

ストローを覗く視野から、色へ

  • 今の視野は狭く、ストローを通して見るようなもの。
  • 白黒のみ。グレースケールの階調の深みを追加する必要がある。
  • 赤と緑までは道が見えている。青はもう少し難しい。
  • この経路のうえを工学のプロセスで積み重ねて、どんどん良くなる商品にしていく。
# 視覚の改善ロードマップ
今: 白黒・狭い視野(ストロー程度)
次: グレーの階調 → 赤・緑(見通しあり)
    → 青(もう少し難しい)
「もっと良くする方法が分かっている」—— 薬の開発との、決定的な違い。

事業としての視覚修理

市場の規模と価格の前例

  • 加齢による黄斑変性(AMD)は、80歳までに2人に1人が初期段階、85歳で約10人に1人が発症。
  • 前例: Second Sight 社は1人あたり約15万ドル(2010年代半ば)。ただし像ではなく光の閃きのみ。
  • 別の前例: 遺伝子の治療は1つの目でほぼ50万ドルの償還。対象は患者の5%、効果は0.1行程度。
  • 初代 PRIMA の市場は米欧で数十万人規模。次のバージョン(来年ヒトへ)で数百万人へ広がる見込み。
# 価格の前例(参考)
Second Sight(光の閃き)  $150,000 / 患者
遺伝子の治療(0.1行の改善) ≈ $500,000 / 目
視覚を失うのは、完全に打ちのめされること。最低限の視覚を戻すことにも、大きな価値がある。

意識・連続性・基質の独立性

コピーは「あなた」か

意識の境界をさぐる

  • 脳をスキャンしてソフトウェアの複製を作ったら、それは「あなた」なのか?
  • 肺がんと診断されて「じゃあ複製を残してホスピスへ行く」—— それで納得できる?
  • 全身麻酔には「断絶」がある。人は嫌がるけれど、受けて生還し、大丈夫だと学習する。
  • 物理学でいう生成・消滅の演算子のように、命や心は作られ、滅び、保たれたまま変化する。
  • 脳の2つの半球を1つに束ねる使い方と、他人と話すことは違う —— 「脳の境界の書き直し」への転換点がどこかにある。
「あなたの視覚と私の聴覚」は決して起きない —— なぜ体験が分離しているのか、根からの説明が必要。

連続性こそが重要

Continuity matters

  • Max の立場: 連続性があるかぎり、人はアイデンティティの大きな変化を受け入れる。
  • あなたとそっくりに応答するソフトウェアの複製 —— でも現象的に連続でないなら、満足は少ない。
  • Sarah: 「劇的な変化 + 連続した経験」なら、自分はそちらを選ぶ。
  • Laura Deming に聞かれた質問: 明らかに落ちたIQを受け入れられる? —— 数週で戻るなら、たぶん受け入れられる。
# アイデンティティのトレード
○ 大きな変化 + 連続性   → 受け入れられる
△ 完全な複製 + 断絶     → 満足度が低い
証明可能な特性を持つ人生は、前例のないもの
「証明可能な特徴を持つ人生」—— 人類が見たことのないものかもしれない。

基質の独立性

Substrate independence

  • 「あなた」を作る、唯一原理的に移植できない臓器は脳。心臓も膵臓も肝臓も肺も、脇役。
  • 「膵臓に殺されるのは、まあ残念だ」—— それが Max の世界観。
  • 体は、理解の足りないエイリアンのナノテク。生物学を解く代わりに、別の道具箱で同じ目標を達成できないか。
  • BCI と灌流の医学(Vessel)の組み合わせで、寿命だけでなく健康寿命を伸ばす。
  • 大きな欠けたピースはコネクトミクス。ヒトのコネクトームはまだ遠いが、マウスならもう近い。
基質の独立性に達したら、ほとんどどこへでも連れて行ける —— だから本当に面白い。

AI との類似と、人間の未来

AIモデルと脳は、似た幾何学を持つ

Platonic representation hypothesis

  • プラトニック表現仮説: 大きなAIモデルの内部に見える数学的な対象が、ニューロサイエンスの対象とよく似ている。
  • 概念を表す脳の領域と、概念を表すモデルの層 —— とても似た幾何学が見える。
  • 実利にも使える: 動物の神経の記録と AI モデルの内部の表現を整列(アライン)できる。
  • これは AI が正しい軌道にいることの大きな手がかり —— ギミックでも、壁でもない。
  • 物質に十分な計算をかけると知能みたいなものが出てくる —— 物理学っぽい何か。
  • ただし議論あり: 構造が大域的か局所的かなど、まだ分からないことも多い。
# 学びの経路
モデルの内部表現 ≈ 脳の概念表現
  → 両者を整列できる(実証済み)
  → AIは本物のデータの多様体をつかんでいる?
「モデルでニューロサイエンスをする方が、ずっと簡単」—— OpenAI / Anthropic の神経科学者の友達の言葉。

脆さが消える未来、そして宇宙へ

保存することと適応することは同じプロジェクト

  • 人間の条件には危うさがつきもの。成功すれば、その感覚は薄れていく。
  • 自分の部品をアップグレードし、交換できる存在になる。
