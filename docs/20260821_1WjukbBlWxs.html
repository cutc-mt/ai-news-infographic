DeepSeek SCALE parallel sessions creator mode
  Level 1 は道具の練習、Level 2 は作業の自動化 — そして Level 3 は SCALE(規模の拡大)。

Level 3 = SCALE

  • 動画の核心: Level 3 は SCALE(スケール)と呼ばれる段階
  • ここまで来ると DeepSeek は道具ではなくシステムになる
  • 3つの要素が積み重なる(スタック)ことで成立
「道具」は1つ1つ使うもの。
「システム」は勝手に回り続けるもの。
その境界線が Level 3 です。

道具からシステムへ

  • ツール段階: プロンプトを打つたびに1作業
  • システム段階: 複数のエージェントが同時稼働
  • 人の介入なしで仕事が並行して進む
使う側の意識も変わる。
「どう使うか」より
「何を任せるか」を考えるように。

3つの積み重ね

  • parallel sessions — 同じworkspaceで会話を並走させる
  • creator mode — 一文でツールをその場で生成
  • 2つが重なることで作業量が桁違いに伸びる
1つずつ見ると地味。
積み重ねた時に爆発するのが
SCALE の妙なんです。

SCALEの全体像

この動画の地図

  • Level 3 ← 今ここ
  • parallel sessions でSEOの3作業を同時化
  • creator mode で足りない道具を即生成
# SCALE の構造イメージ
workspace/
├─ session_1 → 記事 draft
├─ session_2 → keyword research
├─ session_3 → internal links
└─ skill file → 全員が参照

parallel sessions とは

  • 複数のエージェント会話を同時に走らせる機能
  • すべて同じworkspaceの中で動く
  • 「順番に待つ」が消えて全部いっぺんに
今までは1つの会話が終わってから
次を始めるしかなかった。
それが横並びになります。

Session 1: 記事のdraft

  • 1つ目のセッションは記事の執筆担当
  • アウトライン → 本文 → 推敲まで一本で仕上げる
  • あなたが見ていなくても書き進む
「記事を書いて」と待つのではなく、
書き終わった状態を受け取る。
これが Level 3 の感覚。

Session 2: keyword research

  • 2つ目のセッションはキーワード調查担当
  • サーチ意図・機会キーワードを同時に調査
  • 調查結果はworkspaceに共有される
リサーチと執筆が
同じタイミングで進むから、
筆が止まる理由がなくなります。

Session 3: 内部リンク修正

  • 3つ目のセッションはinternal links担当
  • サイト全体のリンク切れ・構造を横断して修正
  • 地味だけど効く作業を自動化に任せる
放置しがちな内部リンク整備。
「同時にもう1セッション」なら
苦にならないのがポイント。

全部、いっぺんに

  • draft・調查・リンク修正がall at once
  • 待ち時間ゼロの同時並行処理
  • それぞれ独立した会話が担当を分担
# イメージ: 3セッション同時起動
session --task "draft article"
session --task "keyword research"
session --task "fix internal links"
→ 3つとも同時に走り出す

同じフォルダを見る

  • 全セッションがsame folderを読む
  • 資料・下書き・調查メモが一元化
  • あるsessionの成果物を別sessionがすぐ参照
コピペ移動が不要になる。
同じ場所を見ているから、
情報が自然に合流します。

同じskill fileに従う

  • 全セッションがsame skill fileに従う
  • トーン・手順・ルールが全session共通
  • 品質のバラつきが出にくい
指示を何度も書き直す必要なし。
1つのskill fileが
すべてのsessionの共通ルールに。

1週間の仕事が、散歩の間に

  • 昔は1週間分だった作業量
  • 散歩に出ている間に横並びで完了
  • 戻ってきたらレビューするだけ
動画の一番いい言い回し。
仕事があなたの不在中に進む。
これが「システム」の証です。

creator mode とは

  • 積み重ねの2つ目: creator mode
  • 動画主が「今でも驚く」と言う機能
  • scaleをさらに伸ばす道具を量産する仕組み
「this is the one that still
surprises me」— 何度使っても
魔法っぽさが残る機能なんです。

一文で描写するだけ

  • 希望のツールをplain English 1文で説明
  • コードも仕様書も不要、普通の言葉でOK
  • 「こういう道具があったらな」をそのまま言う
例: 「内部リンクを監査して
提案まで出す道具が欲しい」
これだけで十分。

Harness がライブ構築

  • Harness がその場で道具を組み立てる
  • ファイルを探す手間もないリアルタイム生成
  • セッション内で即コード化・即デプロイ
# creator mode の流れ
you: "ツール〇〇が欲しい"
 Harness → その場で構築
 Harness → sessionに追加
 → すぐ使い始められる

スイッチを入れて即利用

  • 構築した道具をswitches it on
  • 再起動も設定作業もなしですぐ稼働
  • 必要になったら言う、が運用の最小単位
「作って接続してON」
までがワンセット。
手間は一文だけ。

今日から真似する手順

  • workspaceにskill fileを置く
  • 3つのsessionを同時起動(draft・調查・リンク)
  • 足りない道具はcreator modeに一文お願い
  • 散歩して帰ってレビューのみ
特別なスキルは不要。
手順をそのまま回すだけ。
小さく始めて数を増やそう。

まとめ: SCALEの核心

  • DeepSeek は Level 3 でシステムになる
  • parallel sessions: 同じworkspace・同じskill fileで3作業同時
  • creator mode: 一文依頼でHarnessがその場構築・ON
  • 結果: 1週間分の作業が散歩の間に
自動化の終点は「時短」じゃなく
「規模の拡大」。
