Project No.01

Spec Kit

スペック駆動開発ツールキット(GitHub公式OSS)

ここがポイント

  • エージェントにいきなりコードを書かせない。仕様書を正とした開発プロセスを回す
  • CLIツール specify を入れてプロジェクトを初期化
  • スラッシュコマンドで進行: 指針作成 → 何を・なぜ作るか定義 → 技術計画 → タスク分解 → 実行
  • 任意コマンドで曖昧さの解消・整合性チェック・品質チェックリスト生成
  • 30以上のコーディングエージェントに対応(CLI・IDE両方)
  • extensions / presets / ロールベースのバンドルで拡張・再構成できる
  • 動作環境: Linux / macOS / Windows(Python と Git)

導入イメージ

# GitHub公式のスペック駆動ツールキット
uv tool install specify-cli \
  --from git+https://github.com/github/spec-kit.git

specify init <あなたのエージェント>
# → /constitution /specify /plan /tasks /implement
プロンプトの「投げっぱなし」は卒業。 仕様が信頼の源になって、 AIが書くソフトにも構造を持たせられるよ。

X For You Feed Algorithm

Xのフィードを決めるコードがOSSに

ここがポイント

  • 視聴者の「For You」フィードに何を見せるかを決めるコードが丸ごと公開
  • フィードはリクエストごとに2つのプールから組み立て: ①フォロー中の最近の投稿(メモリ保持) ②非フォローの投稿(MLリトリーバル + クラスタ類似検索)

  • ランキング処理: 作者の多様性ディケイ / ネットワーク外ディスカウント / 新人作者ブースト → 別サービスが多様性順に並べ替え
  • 可視性フィルタ: 投稿とアカウントに安全ラベルを付け、表示 / 非表示 / 間挿入判定を下す
  • 学習用データ + 合成データ + 自分のアカウントのラベルを見られる透明性ツール付き
実運用のレコメンドシステムが 読めちゃう貴重な機会。 自分のフィードがどう組まれてるか見てみよう。

MAST(anti-slop)

  • AIが作りがちなテンプレ臭の汎用UIを防ぐ、単一markdownのルール文書
  • UI/UXタスクのときだけオンデマンド読込 — 毎セッション読み込ませない
  • 回避パターンを列挙: 青紫グラデ / 使い過ぎガラスモーフィズム / マーケティングバズワード
  • 30超の必須ルール + 職人基準(意図性・機能的完備・証拠ベース)。納品前はルールごとの検証質問チェックリストを実行
  • フィルタであってスタイルガイドではない — 色やフォントは自由。既存の指示ファイルに1行ポインタを足すだけで、ツール非依存

Project No.16

Wiser

メモリ・スレッド・ネットワークに「1つの所有権ルール」

ここがポイント

  • 発想: メモリエラー・デッドロック・ネットワーク障害は、すべて資源の所有権が曖昧なことに起因する
  • 静的型付け・コンパイル言語。Rustの安全性を急な学習曲線なしで狙う
  • メモリは Perceus参照カウント(Koka & Lean 4由来)— GCなし・borrow checkerなしでC速度
  • 並行・ネットワークはコレオグラフィックプログラミング: 1つの相互作用記述から全参加者分のコードを生成・検査し、実行前にデッドロックやメッセージ欠落をキャッチ
  • 同じ所有権ルールがスレッドとハードウェア割込みにも及ぶ
  • 構文は意図的に素朴: デフォルトimmutable / 明示的型 / struct / 標準的な制御構造 / エラーはResult値(例外なし)
  • メンテナは「早期研究・未解決問題あり」と正直に明記
言語好き & 研究者向けの好物件。 ドキュメントを読んで 1プログラム書いてみよう。

Airship & MCTIRS

Web開発を助ける2つのOSS

Airship — 実コードベース用ビジュアルエディタ

  • 既存WebアプリにFigma風のビジュアル編集を、プラグイン・依存追加なしで提供するCLI
  • 開発サーバーの前で動くリバースプロキシ — ライブアプリを無限キャンバスに表示、デスクトップ/モバイルフレームを並べる
  • 要素をクリックして変更を記述 → 連携コーディングエージェント(Claude / Codex / OpenCode)が実ソースを直接編集
  • すべてローカル実行、クレデンシャルは選んだエージェントの既存設定を利用

MCTIRS — AIつきディレクトリサイトのテンプレート

  • 業種・ツール・リソースをカテゴリとタグで一覧するディレクトリサイトのテンプレート
  • リスティング / 検索 / ユーザーアカウント / Stripe決済つきの有料・スポンサー投稿。投稿時にAIがコンテンツ生成をアシスト
  • スタック: Next.js + React / Sanity(ヘッドレスCMS) / Auth.js(認証) / Resend(メール & ニュースレター)
  • デプロイは Vercel or Docker — ディレクトリ機能を1から作らずに始められる
