Delta とは？

  • Zed が送る、新しい AIエージェントGUI
  • ほかの道具に頼らない 単独アプリ
  • スレッド形式の会話で、コードを書き進める

DeltaDB とは？

  • 新しい バージョン管理の層
  • コミットの「間」の操作も、すべて記録
  • エージェントの動きを、まるごと保存
// イメージ DeltaDB { commit_A ... commit_B ↑ この間も 全部の記録が残る }
Git は「結果」だけ。
DeltaDB は「過程」まで残す！
