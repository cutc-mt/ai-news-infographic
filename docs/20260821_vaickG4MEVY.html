#01

今話題の2大エージェント

動画の主題
  • AIエージェントの選び方が話題に
  • 注目の2つを徹底比較
  • 自分に合うのはどっち?
  • 正解は使い方次第
どちらも人気だけど、
中身はけっこう違うんだ!
#02

共通点①: どちらもOSS

  • ソースコードが公開されている
  • 無料で使いはじめられる
  • 自分好みに改造できる
  • 中身が透明で安心
お金の壁がないのは
うれしいポイント!
#03

共通点②: 学んで賢くなる

  • 使い込むほど賢くなる
  • 日々の操作から学習する
  • 自分の作業に最適化
  • 育てる楽しさがある
最初は不器用でも
だんだん相棒になる!
#04

Hermes ってなに?

  • チャット感覚で話しかける
  • 複数のプラットフォームで動く
  • 常にそばにいるアシスタント
  • 頼れる相棒タイプ
連絡手段がそのまま
命令口になるのがポイント!
#05

Hermes の入り口は多い

  • Telegram で呼び出せる
  • メールでも依頼できる
  • そのほかのプラットフォームにも対応
  • つながっていればどこからでも
スマホ1台あれば
OK なのが楽ちん!
#06

Hermes の強み: 常時アクセス

  • 24時間いつでも連絡できる
  • 移動中や外出先からもOK
  • 思いついた瞬間に即、依頼
  • PC の前にいなくていい
「あとでやろう」を
減らせるのが強い!
#07

Prime Agent ってなに?

  • ターミナルの中で完結する
  • 没頭作業のためのディープワークエンジン
  • 外部のノイズが入らない
  • 職人タイプの相棒
黒い画面が作業部屋、
っていうイメージ!
#08

Prime Agent の強み

  • 複雑なタスクを処理する
  • 孤立した作業に強い
  • 専用の自律パワーを発揮
  • 長時間の検討にも耐える
難しい仕事を
黙って引き受ける頼もしさ!
#09

対比の軸はここ!

Hermes ユビキタスな接続
どこにいても届く
Prime 専用の自律パワー
深く潜って作業

  • 設計思想が正反対
優先するのは「つながり」か
「パワー」か、それだけ!
#10

選び方の基準

  • いつ使いたいかを整理
  • こまめに連絡したい → Hermes
  • じっくり依頼したい → Prime Agent
  • 自分の優先順位で決める
迷ったら「1日の流れ」を
思い浮かべよう!
#11

Hermes が輝く場面

  • 仕事の合間のちょっとした依頼
  • 通勤中のリサーチをお願い
  • 予定の確認や変更
  • 文章の下書きを頼む
友だちに送る感じで
使えるのが楽!
#12

Prime Agent が輝く場面

  • 時間のかかるリサーチ
  • コードのまとまった修正
  • データの整形や集計
  • 依頼したら放置できる作業
結果を待つ間に
自分は別の作業をしよう!

コミュニティと拡張性

  • OSS なので開発者が集まる
  • 機能追加が活発
  • 自分で拡張することも可能
  • 知見の共有が早い
つまずいたら先人の知恵を
借りられるのが心強い!
