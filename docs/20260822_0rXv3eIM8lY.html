  • まず範囲を1つにしぼる
  • 入ってくるデータを書き出す
  • 守るもの・怪しい場所をメモする

メモ①入ってくるデータ

  • フォームからの入力
  • API へのリクエストの中身
  • DB から取り出す値
  • ヘッダーやクッキーも忘れずに

・メール / パスワード

メモ②守るもの

  • パスワードなどの秘密情報
  • 氏名や住所などの個人情報
  • 金額の改ざんをふせぐ
  • 権限の境界線を守る
「何を守るか」が
決まると検査もシャープに！

メモ③怪しい場所

  • SQL を文字列で組み立てる箇所
  • 入力をそのまま使う場所
  • 権限チェックが抜けてそうな経路
  • エラー時に中身を見せてしまう処理
入力接点 組み立て 境界

届く場所を思い描いてみて！
