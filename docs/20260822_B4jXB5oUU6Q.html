ハルシネーションとは？

  • AI が事実でない事を本当のように書く現象
  • 出どころがないのに自信満々の文章になる
  • そのまま公開すると信頼を失うリスク
  • SEO の記事では命取りにもなる
ハルシネーション ＝ AI の幻
  AI「〜らしいです」（出どころなし）
   → 読者がうその情報をつかむ
出どころのない文が、一番こわい！

なぜ起きる？見えない推論

  • 多くのツールは AI の考えを黒い箱に隠す
  • どこでまちがえたか外から分からない
  • 「結果」だけ見ていては原因が掴めない
  • 直し方を誤ると同じ失敗が続く
黒い箱の問題
  入力 → ［ ？ ］ → 出力
   → まちがいの地点が分からない
考え方が見えないのが、失敗の元！

DeepSeek Harness とは

  • オープンソースの作業ツール
  • Claude Code の代替として使える
  • SEO の仕事を AI に任せる仕組み
  • 中身が公開済みで自由に使える
DeepSeek Harness
  種類：オープンソース
  役割：AI 作業の司令塔
   → Claude Code の代わりに
無料で始められるのが、うれしい！

Trajectory View とは

  • AI の作業の軌跡（トラジェクトリ）を見せる機能
  • 読んだ物・使った物・考えた事が全部のこる
  • 行動が時系列でひとめで分かる
  • まちがい探し（デバッグ）の強い味方
Trajectory View
  記録：読む・呼ぶ・考える
  並び：時間どおりに
   → 全行動がログに
AI の行動ログが、丸見えになる！

完全な透明性

  • 他の道具と違い、考えを隠さない
  • 「なぜこの文にしたか」が追って確かめられる
  • 安心して AI に任せられる状態に
  • チームの信頼の土台になる
透明性のちがい
  他ツール：考え方は非公開
  Harness ：ぜんぶ公開
   → 納得して進められる
隠しごとゼロで、みんな安心！

読んだファイルの記録

  • AI が読んだ資料がすべてログに残る
  • 「本当にこの資料を見たか」をその場で確認
  • 引用のもとの確認が一瞬ですむ
  • 出どころ不明の文章を防ぐ第一歩
読み取りの記録
  14:02 read keywords.csv
  14:03 read rivals.md
   → 見た物が全部分かる
どの資料を見たか、すぐ分かる！

使った道具の記録

  • AI が使った道具（ツール）の履歴も残る
  • 検索・編集・実行…すべて記録される
  • 余計な道具を使っていないか確認できる
  • 想定外の動きをすぐ発見
道具の履歴
  14:05 web_search "SEO 検定"
  14:07 edit draft.md
   → 使った道具が全部残る
何を使ったかも、もれなく記録！

推論ステップの記録

  • 考える途中の手順も細かく残る
  • 「なぜそう判断したか」の流れが見える
  • 話の飛躍がある部分を見つけやすい
  • 根拠のない結論を早めに止められる
推論のログ
  ① 資料を確認
  ② 根拠を照合
  ③ 結論を立案
   → 飛躍があれば一目で分かる
考え方の途中が残るのが、大事！

まちがいをすぐ特定

  • エラーの場所が一瞬で分かる
  • 最初から調べ直す必要なし
  • ログの該当の行を見るだけ
  • 直す時間を大幅にカット
エラー探しの速さ
  今まで：全件、手で確認
  これから：ログの一行を確認
   → 数分で特定できる
まちがい探しが、あっという間！

裏付けのない文を防ぐ

  • うろんな内容が外に出る前に止まる
  • 公開前のチェックで事故を防止
  • 出どころ不明の部分は要確認の印を付ける
  • 記事の信頼性を守れる
公開前の門番
  下書き → ログ照合 → 公開
   → 裏付けなしは ストップ
   → 出せる記事だけ外へ
失敗記事を出す前に、止められる！

  • 人の確認が最小の手間で済む
  • 点検（レビュー）の習慣を作れる
確認のしかた
