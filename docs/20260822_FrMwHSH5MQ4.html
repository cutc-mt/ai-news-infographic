「会議で決めたのに、忘れてしまう…」をなくすのがゴール！

うっかりが起きる現場

  • 会議が続くと記憶があふれるのは自然なこと
  • 決めたはずの伝え忘れが信頼を削る
  • 「あとでまとめる」が後回しに積もる
  • 期限ぎりぎりでの駆け込みが増える
あるあるの図
  会議が終わる
   → メモは残った…
   → 確認する人が いない
   → 気づけば 期限オーバー
悪気はないのに漏れる。仕組みで防ぐのが正解！

手作業だとどうなる？

  • 議事録からやることを目で探す
  • 担当と期限を手で書き写す
  • カレンダーやチャットに自分で登録
  • これを会議のたびに毎回繰り返す
手作業の流れ
  ① 議事録を読む
  ② タスクを書き出す
  ③ リマインドを手で設定
  → 会議が増えると 破たん
「やること」ではなく「記録すること」に時間が消える！

手作業の限界

  • 作業の量が会議の数に比例する
  • 疲れている日は飛ばしがち
  • 長い議事録では見落としが出る
  • できる人の属人的な作業になりがち
限界の構図
  人の集中力には 限り がある
  手順は 口伝 されがち
   → 頼れるのは 仕組み だけ
人は忘れる生き物。だから機械に任せる発想へ！

OpenClaw とは何か

  • 公開されているAIエージェントの基盤
  • 開発の世界中で育てられている道具
  • エージェントに役割を持たせて動かす
  • 人へのつなぎ込みも簡単
かんたんにいうと
  自分の補佐役AIを
   好きなように組める 基盤
   → 議事録を読ませることも可
自分専用の「忘れない秘書」を作れるのが魅力！

公開の道具である強み

  • 中身が見えるので安心して任せられる
  • 自分の環境に合わせて改造できる
  • 公式の説明書（docs）が充実
  • 世界中の知見を借りられる
えらばれる理由
  使い方を 自分で決められる
  困ったら docs を読めばOK
   → 導入の壁が低い
ロックインの心配が少ないのも大きな利点！

エージェントの考え方

  • AIに役割を持たせて動かす
  • やることを手順で渡す
  • 話しかけると作業して返す
  • 判断の一部を丸ごと任せる発想
たとえると
  新人さんに指示書を渡す
   「議事録から課題を拾って
     担当と期限をまとめてね」
   → AIなら毎回同じ品質
「聞いたことを覚えて、必要な時に思い出す」のが得意！

会議メモの黄金テンプレ

  • メモの終わりに3つの要素を足すだけ
  • ① 担当：誰がやるか
  • ② 期限：いつまでにやるか
  • ③ 次にやること：最初の一歩
メモの末尾に書く例
  ─ 決めたこと ─
  担当: 田中
  期限: 8/28（金）
  次にやること: 見積りを依頼
たった3行が、あとで大きな差になる！

要素①「担当」を決める

  • 名前をはっきり書くのがこつ
  • 「みんなで」は実質 nobodyになる
  • 名前があれば指名で通知できる
  • 自動化の宛先としても必須
良い例 / 悪い例
  悪: 「だれか調べておいて」
  良: 「佐藤さんが調査」
   → AIが @佐藤 に紐づけ 可能
書いた瞬間から「見てるね」という合図になる！

要素②「期限」を決める

  • 日付まで書くのが正解
  • 「なるはや」は扱いにくい表現
  • 日付があれば前日に通知なども組める
  • 無理のない猶予を最初に決める
期限の書き方
  悪: できたらで大丈夫です
  良: 8/28 17:00 まで
   → 自動リマインドの基準に
期限こそ、自動化いちばんの得意分野！

要素③「次にやること」

  • 最初の一歩を具体的に書く
  • 大きな目標は動けない原因に
  • 「まず〇〇を頼む」まで落とす
  • 動き出せば残りは続くもの
例えの図
  「プレゼンを改善」
    ↓ これだけだと 動けない
  「まず3枚目の図を差し替え」
    ↓ 今日手をつけられる
一歩の具体性が、そのうちの大きな差になる！

Discord との連携

  • OpenClawは話す窓口を持てる
  • Discordのチャンネルに常駐させる
  • メンションで指名の通知が可能
  • みんなが見る場所だから共有も同時に
連携の絵
  OpenClaw ↔ Discord
   → 会議メモのチャンネル
   → 期限が近づくと @担当 に投稿
   → チーム全員が状況を把握
いつもの会話の場が、そのままリマインダーに！

automations 機能

  • 決まった時刻に自動で実行
  • きっかけ次第で発動する型も
  • 議事録を読ませる定期の仕事を組める
  • 一度組めば毎日勝手に回る
automations の型
  毎朝9時 → 議事録を確認
   → 期限が近い課題を抽出
   → Discord に 自動で投稿
「人間が覚える」から「仕組みが回す」へ変わる！

きっかけで動く型

  • 議事録が投稿されたら起動
  • メモから担当・期限・次の一手を抽出
  • やることの一覧に整えて保存
  • 担当者へ確認の通知を送る
流れの例
  議事録が届く（きっかけ）
   ↓ エージェントが読む
  3要素を 自動で整理
   ↓ 担当へお知らせ
手を止めなくても仕事が進むのが自動化の醍醐味！

抽出から通知までの一連

  • ① 議事録を読み込む
  • ② 3要素を拾い出す
  • ③ 一覧にまとめる
  • ④ 期限に合わせ知らせる
全体の流れ
  会議メモ
   ↓ 読む → 拾う → まとめる
  タスクの一覧
   ↓ 期限の1日前に通知
  担当者の頭上に Ping!
一連の流れを丸ごと任せられるのがOpenClaw！

手作業 vs 自動化

  • 手作業：その場限りで人による
  • 自動化：毎回同じ品質で動く
  • 会議が増えると差が開く
  • 浮いた時間を本業に回せる
比べてみると
  手作業: 忘れる / ばらつく
  自動化: 忘れない / 一定
   → 初期の手間だけで
     あとは 勝手に回り続ける
勝負は「継続力」。人には真似できない部分！
