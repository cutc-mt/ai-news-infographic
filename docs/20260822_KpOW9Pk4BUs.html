Smallville という実験

  • AIキャラクターが暮らす仮想の小さな町
  • 住人はみんな LLMで動くエージェント
  • それぞれが1日を自分で計画して過ごす
  • 研究の世界を変えた画期的な実験
Smallville の町
  AIキャラクターが暮らす
   記憶と計画をもつ
   → 町のなかで交流が生まれる
「Generative Agents」はここから始まった！

エージェントの仕組み

  • 記憶：経験をためて思い出す
  • 計画：1日の予定を自分で立てる
  • 社会化：他の住人と交流する
  • 振り返り：経験から意味をくみ取る
4つの部品
  記憶 ＋ 計画
  振り返り ＋ 交流
   → 人間らしい1日が組み立てられる
まるで人のように暮らすエージェント！

創発という驚き

  • 誰も指示していないパーティを開く流れが発生
  • 部品はシンプルな組み合わせだけ
  • 全体として新しい行動が生まれた
  • この現象を 創発 と呼ぶ
創発の不思議
  記憶と計画の積み重ね
   → 予想もしなかった 行動 が
   → 町全体に広がっていく
部品の合わせ以上のものが動き出す！

Simile の設立

  • 原点は「この世界を再現できたら？」
  • 研究の成果をもとに会社を立ち上げる
  • 対象は仮想キャラでなく実在の人間
  • 目指すは社会のシミュレーション
研究から会社へ
  論文のなかの小さな町
   → 実世界の 人 をモデル化する
   → 事業として動き出す
「この世界を再現できたら？」がすべての原点！

行動の基盤モデル

  • LLM は言葉の基盤モデル
  • こちらは行動の基盤モデル
  • Behavioral Foundation Models という構え
  • 目指すは社会の物理学
2つの基盤モデル
  LLM：言葉 を学習
  BFM：行動 を学習
   → 社会の 法則 が見えてくるかも
物理学が自然の法則を見つけたように！

分身に必要なもの

  • あなたの代役のエージェントにはあなた自身のモデルが要る
  • あなたでないと分からない好みや判断
  • 汎用のモデルではすり替えができない
  • 分身が自分らしく動くために
個人エージェントの条件
  あなたの好み
  あなたの判断のくせ
   → まるごと再現 したい
自分の分身には自分のモデルが必要！

Webデータの限界

  • Web のデータは人が「言うこと」を捉える
  • 「実際にやること」は捉えられない
  • 言葉と行動のあいだにはギャップがある
  • 投稿だけでは人が分からない
言う vs やる
  Web：発言 の記録
  現実：行動 の記録
   → この ギャップ をどう埋める？
言うことと、やることは違う！

人を知る3つのデータ

  • 長時間のインタビューで人生を深く聞く
  • 取引のデータ：何を選んで買ったか
  • 観察のデータ：何をしたかを見る
  • RCT：実際の場面での反応
データの3本柱
  話す（インタビュー）
  選ぶ（取引）
  動く（観察）
   → そこに 人間の輪郭 が見える
言葉・選択・行動を立体的に集める！

RCT で学ばせる

  • RCT ＝ ランダム化比較試験
  • 集団を分けて本物の反応を見る
  • 結果でモデルを事後学習させる
  • LLM の post-training と同じ発想
RCT の流れ
  集団を2つに分ける
   → 違いを比べる
   → モデルに 反映
   → 人の反応に近づく
実験の結果でモデルを鍛える！

1000人のデジタルツイン

  • 実在する1000人を対象にした試み
  • インタビューとデータで1人ずつ形にする
  • 本物の代わりとして回答を再現
  • 調査のパネルとして活用する
ツインの作り方
  実在の1000人
   → インタビューと行動データ
   → それぞれの 分身 が完成
本物の1000人の分身ができた！

85% の再現精度

  • 同じ場面で本人と同じ答えをするか
  • 行動の再現率は 85%
  • 人が自分の回答を再現する率と同水準
  • つまりツインは本人と同じくらいブレる
85% ってどのくらい？
  ツインの再現率：85%
  人間の自己再現：同程度
   → 見分けがつかない 水準
本人と同じくらい正確ってこと！

非合理性を再現する

  • 合理的に最適化したモデルでは人が再現できない
  • 人はバイアスを持ち
  • 間違いも犯す
  • その癖まで再現してこそ良いシミュレーション
合理 vs 人間
  経済学の理想：合理的な人
  現実の人：バイアス ＋ 間違い
   → 非合理ごと再現するのが正解
人らしさは、欠点も含めて！

2つのレベルの話

  • 人口レベル：集団の傾向が合えばOK
  • 個人レベル：1人ずつの行動まで再現
  • 平均が合っても個人はズレることがある
  • Simile が狙うのは個人レベル
2つのレベル
  人口レベル：集団の 統計 が合う
  個人レベル：一人ひとり が合う
   → 後者の方がずっとむずかしい
平均だけ合っても意味がない！

80億人シミュレーション

  • シミュレーションにもスケーリング則がある
  • 1000人 → 100万人 → ゆくゆくは80億人
  • データセンター規模の計算になる
  • 全人類のツインが長期の目標
スケールの夢
  今日：1000人
  この先：100万人
  目標：80億人
   → 社会まるごとを計算する
いつか、社会の実験を全部仮想で！

政策を実験する

  • 気候変動の政策を先に試す
  • 民主主義の崩れる兆しを見つける
  • UBI（ベーシックインカム）の実験
  • 市場調査のパネルを合成人口に置き換え
使い道の例
  気候変動 の政策
  UBI の効果
  市場調査 のパネル
   → 本物の人に 負担をかけず に試せる
社会の実験がそっくり仮想でできる！
