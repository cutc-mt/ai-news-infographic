Section 1: Workモードって何？基本を押さえよう

Workモードとは

  • ChatGPTデスクトップアプリの新モード
  • 自分のパソコン上のファイルに直接アクセスできる
  • AIが自分の代わりに作業を実行してくれる
  • 目的は仕事の効率化
ブラウザ版のChatGPTとは違って、
自分のPCの中を見ながら動いてくれるのが最大のポイント！

Chat と Work の違い

2つのモードを使い分けよう

  • Chat … いつもの会話モード。気軽に質問
  • Work … フイル操作や実作業を任せるモード
  • 会話の引き継ぎもできるので切り替えはスムーズ
「聞くだけなら Chat」「やってもらうなら Work」
と覚えるとわかりやすいよ！

できることの全体像

Workでできる主なこと

  • 議事録からレポート作成
  • 画像の生成・編集
  • Computer Use でブラウザ操作
  • スケジュールタスクで自動実行
  • ペット機能で進ちょく確認
今回の動画では
この全部をじっくり解説してるよ！

必要な環境と準備

  • デスクトップアプリをインストール
  • Workモードの利用には対象プランへの加入が必要
  • 使う前に対象フォルダを指定しておく
  • アクセス範囲は自分で管理できるので安心
まずは小さなフォルダで
試してみるのがおすすめ！

Section 3: セットアップから実践ワークフロー

プロジェクトとフォルダ設定

最初の設定手順

  • Workモードで新しいプロジェクトを作成
  • アクセスを許可するフォルダを選択
  • 作業内容を伝えて実行開始
  • 設定した範囲だけ読み書きされるので安全
  • フォルダの追加・変更はあとからでもOK
仕事の種類ごとに
プロジェクトを分けると整理しやすいよ！

議事録からレポート作成

実践例: 会議の記録を整形

  • 会議の議事録ファイルをWorkに読み込ませる
  • 「要点をまとめて」と日本語で指示
  • 出来上がるのはHTMLレポート
  • そのまま共有・報告に使える形
やること:
1. 会議フォルダを指定
2. 「議事録をまとめて
   HTMLにして」と依頼
3. 出力を確認して完成！
面倒な議事録まとめが
一瞬で終わっちゃう！

使い分けと会話の引き継ぎ

  • Chatで方針を相談 → Workで実行が基本の流れ
  • 会話はそのまま引き継ぎ可能
  • 行き来しても文脈が消えない
  • 切り替えはワンオペでらくらく
迷ったら「これは自分でやる？
AIにやってもらう？」と分けると明快！

サイドチャットで並列実行

同時に複数の作業を走らせる

  • 本体の作業中にサイドチャットが開ける
  • 並列実行で待ち時間がほぼゼロ
  • 「ここどうする？」という質問も即OK
  • 長い作業の待ち時間を有効活用
動画では実際に
同時進行で作業を進める様子が見られるよ！
