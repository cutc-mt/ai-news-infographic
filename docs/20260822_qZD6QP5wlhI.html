Launchとは何か

  • Ollamaに加わった新しい機能
  • ローカルAIとエージェントの環境をつなぐ
  • GemmaやQwenがそのまま使える
  • むずかしい設定はほぼ不要
Launch の役割
  ローカルAI（頭脳）
   × エージェント（手足）
   → この2つを ワンコマンド で接続
「頭脳」と「手足」の橋渡し役なんだ！

頭脳と実行の環境

  • Gemma・Qwenなど ＝ 頭脳の部分
  • Codex・Claude Code ＝ 動かす環境
  • Launch ＝ 2つをつなぐ仕組み
  • どちらか一方だけでは動けない
イメージで捉える
  頭脳：Gemma / Qwen / Llama
  手足：Codex / Claude Code
   → Launch が 橋 をかける
   → 初めて エージェント になる
頭脳がいて、手足がいて、初めて動ける！

起動は一行だけ

  • 打つのは ollama launch codex だけ
  • Codexの環境がすぐ起動
  • 面倒な設定は不要
  • 準備の時間をぐっと短縮
ターミナルでの流れ
  $ ollama launch codex
   → Codex × Ollama の環境が 起動
   → あとは普通に指示するだけ
覚えるのは一行。これだけ！

頭脳の切り替え

  • Gemma → Qwen → Llama へ交換
  • 同じエージェントの環境を使い回せる
  • 頭脳だけを取り替えるイメージ
  • モデルの違いを比べやすい
切り替えのイメージ
  環境はそのまま
   モデルだけ交換
   → 動きの違いを すぐ比較 できる
環境を作り直さなくていいのが楽！

注意：賢くはならない

  • LaunchはAIの性能を上げない
  • 賢くする機能ではなく環境を与える機能
  • 性能の高さは選んだモデル次第
  • 期待を正しく持つのが大事
よくある誤解
  × Launch で 賢くなる
  ○ Launch で 動けるようになる
   → 性能はモデルで決まる
「賢くする」ではなく「動けるようにする」！

手足の中身
