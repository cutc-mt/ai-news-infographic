DeepSeek Harness で、SEOの働き方が変わる

〜 無料・MITライセンスの agent harness が仕事を変える 〜
2026-08-23 ／ チャンネル: Julian Goldie SEO
DeepSeek Harness 並列agent creator mode MIT license

今回の要点

ニュースの概要
  • DeepSeek が新ツールを公開
  • 名前は DeepSeek Harness
  • 無料で MITライセンス
  • SEOの仕事がぐんと速くなる
SEOの毎日の作業が、このharnessで激変しそうです！

agent harnessとは？

ざっくり解説
  • agentを束ねるための枠組み
  • 指示を出すと agent が動く
  • 複数の agent を同じ土台で管理
  • 既存の設定をそのまま活用
いわば agent チームのまとめ役ですね！

無料で公開

オープンなライセンス
  • 料金はゼロで使える
  • ライセンスは MIT
  • 改造や配布も、もちろん自由
  • だれでも気軽に始められる
お試しのハードルが、一気にさがります！

並列セッション

同時に動くagent
  • 並列agent セッション対応
  • 複数の agent が同時に稼働
  • 待ち時間がどんどん減る
  • 作業を分けて同時に回す
1つの作業を順番に待つ時代は終わり！

記事を書くagent

writer agent の仕事
  • 記事の下書きを agent が作成
  • 文章のトーンも指定できる
  • 構成から本文まで対応
  • 担当は 記事の執筆
人が手を加える前提の下書きが出てきます！

キーワード調査

調査を担当
  • 検索語の調査を自動で行う
  • データを見て候補を提示
  • 狙い目の語を見つける
  • もう1つの担当は keyword研究
調査の最初の部分を、まるごとおまかせ！

内部リンクの整備

整備の担当
  • 関連ページ同士をつなぐ
  • サイトの構造をチェック
  • 回遊ルートを強化
  • 残る担当は 内部リンク
手間のかかる作業を agent が処理！

同時タスクの威力

はやくなる理由
  • 執筆しながら調査も進む
  • 待ち時間がほぼゼロに
  • 作業の時間をぐっと圧縮
  • 1人でチームみたいな働き
自分は最後のチェックに専念できます！

creator mode 登場

独特なモード
  • 独特なモードは creator mode
  • やりたいことを言葉で説明
  • harness がその場で構築
  • 説明したらすぐ動く
ちょっとした道具なら、その場で生まれます！

言葉で道具づくり

plain English でOK
  • 英語の文章でツールを指定
  • コードを書かなくてOK
  • アイデアが形になる速さ
  • コードが書けない人でも大丈夫
言葉で頼むだけで、道具ができちゃう！

移行ゼロで楽々導入

zero migration の意味
  • zero migration がうれしい
  • 乗り換え作業が不要
  • 今の環境にそのまま追加
  • 設定はほぼそのまま使える
面倒な引っ越し作業がひとつもない！

CLAUDE.md対応

設定を引き継ぐ
  • 既存の CLAUDE.md を完全サポート
  • ルールや好みの設定を引き継ぎ
  • 育てた指示がそのまま生きる
  • 二重の手直しが不要
# CLAUDE.md（設定の例）

- 記事: 2,000文字程度でまとめる

育てた設定がむだになりません！

コード例イメージ

実行イメージ
  • イメージはこんな感じ
  • 並列で動かすイメージ
  • 実際の指定は公式の情報で確認
# 並列実行のイメージ（一例）

  --agent writer  "SEO記事の下書きを作って" \
