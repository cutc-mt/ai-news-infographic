第1部：動画の全体像

01

この動画はどんな内容?

ヘルメスエージェントに「3つの巨大スキル」を組み込むと、AIのワークフローがガラリと変わる、という紹介動画です。
  • テーマは エージェントの組織化
  • 注目の 3つのスキル を順番に解説
  • めざすは 24時間稼働 の自律チーム
  • 人が最後に 意思決定 をおこなう設計
「スキル」を足すだけで、エージェントの仕事の幅が一気に広がるのがポイント！
02

24時間はたらく自律チームとは

人が寝ているあいだもエージェントがタスクを進めてくれる。それが「自律チーム」のゴールです。
  • 夜間も 処理をつづける
  • タスクの 割りふり→実行→報告 を自動でループ
  • 1体のエージェントが 複数役割 を兼ねる
  • 返事待ち・手すき時間を ゼロに近づける
一度セットすれば、あとはほったらかしで動きつづける。ここが最大の魅力！
03

3つの巨大スキル ざっくり一望

動画の主役はこの3つ。それぞれ役割がはっきり分かれています。
  • ① Kanban タスク管理のしくみ
  • ② Apollo 音声でのリアルタイム構築
  • ③ Outreach 営業リーチの自動化
組み合わせると
  • 単一エージェントが 組織 のように動く
単体でも強いけど、3つそろえると本領発揮。順番に見ていきましょう。
04

AIワークフローはこう変わる

スキル導入の前後で、仕事の流れがどう変わるかを比べてみます。
  • 変更前: 人が全部 指示だし する必要あり
  • 変更後: ボードが 次の作業 を自動で提示
  • 声で指示して 即つくる 開発スタイル
  • リーチ活動も 自動パイプライン 化
「人が動かすAI」から「AIが動いて人がジャッジする」へ。発想が逆転する動画です。

第2部：スキル① Kanbanボードで管理

05

スキル① Kanban ってなに?

かんばんボードを使って、エージェントの仕事をまとめて管理するスキルです。
  • やることを カード にして見える化
  • 進み具合が ひと目で分かる
  • 優先順位も ボード上 で管理
  • 新しい仕事は カード追加 だけでOK
工夫されたボードがあると、エージェントが「次に何をすべきか」迷わなくなる！
06

ボードの基本の流れ

典型的な3列づかい。カードが右へ進むほど、仕事がすすんでいます。
  • To Do これからやること
  • Doing いま取り組み中のもの
  • Done おわったタスク
列をふやして「待ち」「承認待ち」などを足すのもアリ。自分の仕事スタイルに合わせて。
07

エージェントのタスク消化

エージェントはボードを見て、自分でタスクをひろってすすめていきます。
  • To Do から 優先度の高い カードをピックアップ
  • 実行中は Doing へ移動
  • 終わったら Done にして結果を記録
  • これを 自動で繰りかえす
人が「これやって」と都度お願いしなくていい。ボードが single source of truth（情報のよりどころ）になる。
08

Kanban運用のコツ

動画で紹介されている運用面のポイントをまとめました。
  • 1カード 1作業 に分けて小さく
  • 種類ごとに ラベル をつける
  • 大事な案件は 承認ステップ をはさむ
# ボードのイメージ（YAML風）
board: "hermes-team"
columns:
  - todo      # 未着手
  - doing     # 対応中
  - review    # 人の確認待ち
  - done      # 完了
「review」列をおくと、人間の最終チェックを忘れずにすみます。

第3部：スキル② Apolloで音声ビルド

09

スキル② Apollo ってなに?

声で指示しながら、画面をリアルタイムに組みたてていくスキルです。
  • 音声 でのやり取りが中心
  • 話したそばから 即ビルド
  • 修正も 会話で 依頼できる
  • タイピング ほぼ不要
「こんな画面がいい」を口で説明するだけで、形にしてくれる。デモ映えするスキル！
10

音声でリアルタイム構築

「話す→できる→直す」のループがものすごく速い。これがApolloの強みです。
  • 要望を 声で伝える
  • エージェントが その場で実装
  • 気になる点は 即フィードバック
  • 完成まで 対話を繰りかえす
→ →
おためし→微調整のサイクルが速いので、試行錯誤がどんどんはかどります。
11

ハンズフリー開発の利点

手をつかわない開発がもたらす、意外なメリットの数々。
  • 移動中や家事のときも 作業がすすむ
  • 頭のなかの案を そのまま出せる
  • タイピングが苦手でも 参入しやすい
  • 手首などの 負担を軽く
スマホ1台で開発が完結するので、場所を選ばないのもうれしいポイント。
12

Apollo × Kanban の連携

音声ビルドとタスク管理を組み合わせると、流れがさらにスムーズに。
  • 声で カードを追加
  • 追加されたカードを 自動で着手
  • 進み具合を 音声で報告
# 音声指示のイメージ
> "ランディングページの
 ヘッダー直して、カード追加しといて"
→ board.add(card: "fix-header")
→ agent.start(card: "fix-header")
二つのスキルを組み合わせると、口で指示するだけでチームが回りだします。

第4部：スキル③ 自動アウトリーチ

13

スキル③ アウトリーチとは

見込み客への営業リーチ（アウトリーチ）を自動化するスキルです。
  • 相手を リスト化 して管理
  • 送信文を 自動で下書き
  • 送る時間も 最適なタイミング に
  • 反応は データ として記録
「きつい営業」ではなく、まず相手に合わせた内容をつくれるのが自動化の利点。
14

パーソナライズとスケール

「一人ひとりに合わせた文面」と「大量送信」を両立できるのが強み。
  • 相手の情報を 調査 して反映
  • 数百件でも 一括処理
  • 返信の下書きも 自動で用意
  • 成果は 振りかえり で改善ループ
ただし送りっぱなしじゃなく、人が内容を確認してから出すのがこの動画流のスタイル。
15

人間が最終ジャッジ役

3つのスキルすべてに共通する設計思想。人はループの外ではなく、最後の関門にいます。
  • 送信の前に 人が承認
  • 判断が要る案件は 人の確認待ち にする
  • 事故や誤送信を 防ぐ安全弁
  • AIと人の 役割分担 を明確に
「自動化＝丸投げ」ではない。信頼できるのは、最後に人が見ているから。
16

繰りかえし雑務を消す

3スキルの導入で、日常の単純作業がどんどんなくなっていきます。
  • 進み具合を確認する メッセージ → ボードを見るだけ
  • たたき台づくりの 手作業 → 音声におまかせ
  • 営業文の コピペ → 自動ドラフト
  • 空いた時間は 戦略や企画 に
消えたのは雑務だけ。人がやるべき「考える仕事」は残る。それが理想的な分担。

第5部：導入と実践のステップ

17

導入ステップとユースケース

いきなり3つ全部、ではなく小さくはじめるのがおすすめです。
  • Kanbanで 日々のタスク を管理
  • Apolloで 小さい画面 を声から作成
  • Outreachは 少数宛て で試運転
  • 活用例: 制作者 の納品管理
  • 活用例: 小規模事業者 の販路かくとく
まずは自分の「面倒だな」を1つ消すところから。効果は体感でわかります。
18

まとめ: 1体が組織になる日

ヘルメスエージェント × 3大スキル。単なる道具が、はたらく仲間にかわります。
  • Kanbanで 見える化と自動着手
  • Apolloで 音声ビルド
  • Outreachで リーチの自動化
  • 最後の 意思決定は人 が握る
「24時間はたらく相棒」を手に入れるかどうかは、今夜のセットアップ次第！
