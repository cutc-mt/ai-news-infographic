セールスの困りごとをエージェントで解決する回だよ！

アウトリーチが失敗する理由

  • 初回のメールだけで終わる…
  • 返信なしで放置される
  • フォローのタイミングを逃す
  • 面倒で続かない → 機会ロス
敵はライバルじゃなく 忘れた なんだ…！

フォローアップは地味で大変

  • 送る日時をいちいち管理
  • リストの更新が後回し
  • 誰に送ったか分からなくなる
  • 同じ作業の繰り返しで疲れる
単純作業ほど、人間は忘れる生き物なんです…

手動トラッキングは続かない

  • 表のメンテが数日で止まる
  • 忙しい日は後回しに…
  • 記憶にたよるのは無理ゲー
  • 機会をどんどんロスする
スプレッドシートの更新、できてます…？

自律エージェントが得意なこと

  • 決まった手順を正確にこなす
  • 忘れない・休まない
  • 状況を見て次の一手を判断
  • 長時間でも品質が落ちない
繰り返し作業こそ、エージェントの花形！

Hermes Agent って何？

  • 自律型の AI agent
  • ツールや API を自分で操作
  • スキルを足して機能アップ
  • 公式ドキュメントも充実
# hermes.yaml（※イメージ）
agent:
  name: "outreach-agent"
  skills:
    - lead-search
    - draft-writer
    - follow-up
  voice:
    tone: "friendly"
営業以外にも使い回せるのが嬉しい！

リードを自動で見つける

  • 条件を先にセットするだけ
  • 新規の lead を検出
  • リストへそのまま追加
  • 見込みの管理もラクラク
リードを探す手間が、まるごと消える！

ひな型を超える文面

  • 相手の情報を読み込んで起案
  • 1 通ずつちゃんと下書き
  • コピペ感をゼロに
  • 開いてもらいやすい一通に
その人に合わせた一文で、返信が変わる！

ブランドの「声」で書く

  • 口調とトーンを先に指定
  • 例: casual / polite / short
  • 売り文句がブレない
  • 指定の voice をずっと守る
声がそろうと、先方の信頼が育つ！

フォローアップはおまかせ

  • 何日後に送るか設計できる
  • 返信が来たら検知
  • リマインドも自動で回す
# follow-up sequence（※イメージ）
steps:
  day0:  初回メール（承認つき）
  day3:  リマインド 1 通目
  day7:  リマインド 2 通目
  day14: 最後のフォロー
sequence 全部を、期限なしで回しっぱなし！

24 時間 365 日、休まない

  • 深夜でも早朝でも稼働
  • 長期のランも OK
  • 止まりにくい体制をつくる
  • 人の都合に左右されない
寝ている間に、仕込みが進んでる…！

human in the loop

  • 送信の前に必ずチェック
  • 文面を直してから OK
  • 判断の最後は人間が持つ
  • 安心の 承認 ステップ
品質の砦は、人間が持つのが安心！

grunt work は丸投げ

  • リストの整理を任せる
  • 送信の処理もおまかせ
  • 日々の記録も残す
  • 人は 戦略 に集中！
地味な作業を手放して、得意なことに時間を！

バーンアウトを防ぐ

  • あふれるタスクを減らす
  • 心の余裕がもどってくる
  • 続けられる体制をつくる
  • 営業が「つらい」から「楽」へ
無理をしない営業が、いちばん強い！

24/7 のリード生成マシン

  • 止まらずに動きつづける
  • 機会のロスがぐっとへる
  • 数字も追いやすくなる
  • 規模もラクラク拡大
アウトリーチが「資産」に変わる！

導入は 4 ステップ

  • 目的と「声」を決める
  • リードの条件を設定
  • 下書き → 承認 → 送信の流れ
  • 回しながら改善を重ねる
小さく始めるのが、いちばんのコツ！

before → after

  • before: 忘れる・燃えつきる・止まる
  • after: 続く・そろう・育つ
  • 人の負担はぐっとダウン

一人では無理でも、エージェントとなら続く！
