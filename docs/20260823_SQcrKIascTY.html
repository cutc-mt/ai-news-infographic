1. まずは全体像をつかもう

Deepseek Harness とは？

What is the Harness?
  • DeepSeek系モデルを動かす、エージェントの作業台
  • モデル・ツール・画面を、ひとつにまとめる基盤
  • 起動して、ブラウザ上で操作するスタイル
  • プラグインで機能をどんどん足せる
ただのチャット画面じゃなくて、操縦席に近い存在！

ミッションコントロールって？

Mission Control Concept
  • 複数タスクの状態を、ひと目で確認
  • 実行のログと進み具合を、その場で追跡
  • モデルや道具を、画面から切り替え
  • 「打ち上げから着地まで」を自分で管制
宇宙開発の管制室を、机の上に再現するイメージ！

標準設定からの脱皮

From Default to Personal
  • まずはそのままで動かして、感触を確かめる
  • 少しずつ自分仕様に改造していく
  • 最終形は、自分だけのAI操縦席

プラグイン・アーキテクチャ

Plugin Architecture

  • 配色や配置も、自分好みに調整
  • できた画面は、あとで直接編集も可能

Build Interfaces Live

  • 使いながら直す、漸進式の開発
完成図を最初に描かなくていいのが、楽ちん！

その場でカスタマイズ

Customize On the Fly

使い心地は「育てるもの」と考えるとラク！

3. エージェントOSとして動かす

エージェント的OSとは

Agentic Operating System
  • AI・道具・データを、OSのように統べる
  • アプリを乗せて動かす、土台の役割
  • 各パーツをつなぐ、パイプ役にもなる
  • 全体の動きを、中央から指揮
OSがソフトを管理するように、AIを管理する！

アプリを速攻デプロイ

Rapid App Deployment
  • 思いついたら、すぐ動かす
  • 小さな道具を、ぽんぽん量産できる
  • チームにも、そのまま共有しやすい
  • 改修して出し直すのも、軽やか
「作る」より「使い始める」までの距離がちがう！

カスタムモデル設定

Custom Model Settings
  • 対話用と推論用のモデルを、切り替え
  • 速度・コスト・性能のバランスを選ぶ
  • APIキーと接続先を、設定画面で管理
# モデル設定のイメージ

  model: 対話向けモデル   # 速い返し

  model: 推論向けモデル   # じっくり型
用途に合わせて「頭」を付け替える感覚！

シームレスな統合

Seamless Integration
  • モデル設定が画面と、自然につながる
  • 外部サービスとも、接続しやすい
  • 手元のデータも、呼びこめる
  • 設定の書き換えで止まらず、続けて使える
部品同士がスッと結びつくのが、統合の醍醐味！

4. 比較して、安全に使いこなす

DeepSeek系モデルの使い分け

Model Switching Guide
  • 定番の対話モデル：日常のやりとりに
  • 推論モデル：じっくり考える案件に
  • 速さ重視なら、軽量な型を選ぶ
  • コストと品質を見ながら、使い分け
モデル名は動画公開時の情報です。最新は公式を確認してね！

チャットボット実装との比較

Chatbot vs Mission Control
観点チャットボットミッションコントロール
画面会話の窓が1つパネルを自由に配置
拡張会話で置くだけプラグインで無限に
改造できることが限定的UIから設定まで自由
運用毎回、手で操作自動化と連携が主役
「話す相手」から「働く相棒」へ！

安全に使いこなすために

Safety and Security Tips
  • APIキーは環境変数でしっかり管理
  • 機密データを、むやみに読ませない
  • 実行のログを、こまめに確認する
  • まず小さなタスクで試してから本番
自由度が高いぶん、鍵の管理はきっちりと！
