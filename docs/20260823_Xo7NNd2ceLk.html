🧒 ELI5ってどういう意味？

名称の由来

  • Explain Like I'm 5
  • 訳すと「5歳児のように説明して」
  • ネットの掲示板で生まれた定番フレーズ
  • それをスキル化したのがこのアイデア
むずかしい言葉をやさしい言葉に
置き換えるのが大事なんです！

📄 中身はたった3行！

スキルの中身を見てみよう

  • 開けてみたらまさかの3行
  • 複雑な設定はゼロ
  • あるのはシンプルな指示文だけ

指示文のイメージ（意訳）:

# ELI5 スキル（イメージ）
複雑な文書を、5歳の子どもにも
わかる言葉と例え話で説明して。
大きな見出しと図解付きの
1ページにまとめてね。
この「薄さ」が後で効いてくる
不思議なポイントなんです！

⚡ 並列生成の仕組み

自作スキルの舞台裏

  • 自作はパラレルインフォグラフィック方式
  • 複数の生成を同時に走らせる
  • 専用の下ごしらえや調整あり
  • そのぶん時間と設計のコストもかかる

イメージ:

# 並列生成のイメージ
記事 → 分解 → [パート1] ─┐
              [パート2] ─┼→ 合体 → 1枚に
              [パート3] ─┘          完成！
同時に作るから速い…でも
仕組みはけっこう本格派なんです。

⚠️ 注意点：言い切りに注意
