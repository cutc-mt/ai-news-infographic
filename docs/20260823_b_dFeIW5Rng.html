Mission Control とは？

Your AI Command Center

  • タスク・記憶・お知らせを、ひとつの画面にまとめる
  • 宇宙開発の管制室みたいに、すべてをここから指揮
  • 自分のマシン上で動かすから、安心

Cost vs. Quality

3. 動画が見せる、3つのコア機能

コンテキスト注入

Context Injection
  • 仕事を頼む前に、背景となる情報を流しこむ
  • 行動指針や記憶ファイルを、よみ込ませられる
  • 毎回ゼロから説明しなおさなくていい
  • おかげで、返事の精度がぐっと上がる
予習をさせてから、本題を頼むかんじ！

ターミナルの実行

Terminal Command Execution
  • AI が、シェルのコマンドを直接実行できる
  • ビルド・テスト・Git 操作までお任せ
  • 出力をみながら、次の手を自分で判断
  • 「話すだけ」のAIとの、一番のちがい
命令したら、ちゃんと手が動くのがエージェント！

自動ワークスペース設定

Automated Workspace Setup
  • 新しい現場（フォルダ）を、AI が自分で整える
  • 設定ファイルや記憶の入れ物を、自動で用意
  • プロジェクトごとの境界線が、きちんと保てる
  • 人間は「使いはじめる」だけですむ

4. 作り込みと、安全な運用

構築の流れ

Build Workflow
  1. Hermes を、ローカルにインストール
  2. 使うモデルを、用途ごとに指定
  3. ダッシュボードの部品を、頼んで組みたてる
  4. 動かしながら、指示を磨いていく
手順はシンプル。あとは会話しながら育てるだけ

安全に使うコツ

Safety First
  • まずはテスト用フォルダで、練習する
  • 危なそうなコマンドは、承認ステップをはさむ
  • 見せたくない情報は、対象から外しておく
  • 最初のうちは、動きのログをしっかり確認
権限は少しずつあげるのが、鉄則だよ！

カスタマイズのアイデア

Make It Yours

  • お知らせやリマインダーも、追加自由
自分の働き方に合わせて、育てるのが楽しい！
