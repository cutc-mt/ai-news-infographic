2. SeeDance2.5で、その場で動画を作る

SeeDanceってどんなAI？

What is SeeDance?
  • テキストや画像から動画を生み出す、動画生成AI
  • プロンプト（お願い文）で、動きやカメラを指定
  • 短いクリップを、まとめて量産できるのが強み
  • バージョンが上がるたびに、クオリティが向上
話すより見たほうがはやい！ライブで実際に動かして、確かめていくよ

バージョン2.5の新しところ

What's New in 2.5
  • 画像1枚から動画をつくる image-to-video
  • カメラワークの指定が、いっそう自然に
  • 生成のはやさと、動きのなめらかさが向上
  • 細かいパラメータで、絵づくりを制御
新機能の詳細は、ライブで実際に触りながら確認する予定です
「何ができるようになった？」を、その場でためすのがライブの醍醐味！

ライブ制作のながれ

Live Workflow
  1. ネタや構成を、チャットと相談してきめる
  2. プロンプトを書いて、生成スタート
  3. できた動画を、みんなでチェック
  4. 直したいところを直して、もう1回
失敗も含めてライブの見どころ。生成を待つ時間は、そのまま雑談タイム！

プロンプトを書くコツ

Prompt Tips
  • 主語・動き・場所・カメラを、わけて書く
  • 「ゆっくり寄る」「右上から見おろす」など動きを具体的に
  • うまくいかなければ、言い方をかえて再挑戦
  • うまくいったプロンプトは、メモして使いまわす
頭の中の映像を、ことばにおとす作業。むずかしく考えすぎないでね

みんなで検証する時間

Try It Together
  • チャットに、プロンプトのアイデアを書きこんでもらう
  • 生成結果を、みんなで批評しあう
  • 同じお題で、書き方をかえて比べてみる
  • お気に入りの作品は、SNSでシェア
視聴者のアイデアが、思いがけない名画をうむこともあるんだよ

Claude Codeとは

What is Claude Code?
  • ターミナルで動かせる、Anthropicのエージェント
  • コードを読み、書き、直してくれる開発の相棒
  • AIと組んで開発するスタイルを、大きくかえるツール

「Claude Codeの本」を、視聴者のみんなと読みすすめる読書会スタイルだよ

読書会のすすめかた

How We Read Together
  • 気になるところから、順番に読みすすめる
  • わからない箇所は、その場で議論して解消
