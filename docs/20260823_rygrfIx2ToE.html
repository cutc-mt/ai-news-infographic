1. まずは問題を知ろう

AIは「わすれっぽい」

The Memory Problem
  • 多くのAIエージェントは長く覚えるのが苦手
  • 会話がおわると、細かい文脈をどんどん失う
  • 同じ説明を何度もくり返す → 時間のムダ
  • 「あれ、前はどうしたっけ？」が頻発…
きおくがないと、毎回ゼロからのスタートになっちゃう！

Hermes Agent ってなに？

What is Hermes Agent?
  • Nous Research がつくる自律タイプのAIエージェント
  • お話し＋道具づかいがじょうず
  • ファイルの読み書きも、コマンド実行もお手のもの
  • あなたの環境で、指示を待たずに動ける
「話すAI」じゃなくて動くAIなんだ！

Obsidian ってなに？

What is Obsidian?
  • 人気の高い知識の管理ツール（ノートアプリ）
  • メモはすべて Markdown のテキストで保存
  • データは手もとのフォルダ（Vault）に、そのまま入る
  • リンクでメモ同士を、自由につなげられる
アイデアの「箱」が、そのまま手もとにのこるんだ

セカンドブレインとは

The "Second Brain" Idea
  • 頭だけに頼らず、外部に記憶を置くしくみ
  • やったこと・考えたことを、すぐメモにためる
  • 脳はひらめきに、外の箱は保存に専念
  • 「思い出す」手間を、ガクッとへらせる
頭は「考える専用」にして、保存はまかせちゃおう！

2. Obsidian のここがスゴい

Vault という保管庫

Your Knowledge Vault
  • Vault は、メモをまるごと入れるひとつのフォルダ
  • 中身は普通のファイル。アプリが変わってもデータは無事
  • バックアップも同期も、フォルダごとで OK
  • 複数の機械で、同じ Vault を共有できる
「自分のデータは自分のもの」——これが大きい！

Markdown で書くメモ

Notes in Plain Markdown
  • 書式は軽いテキスト（.md）だけ
  • # の見出しや - のリストで、すぐ構造化
  • 特別なアプリがなくても、誰でも読める
  • AIとも相性バツグン（テキスト＝読み放題）
# 進行中のプロジェクト
- 目標：作業をじどう化する
- 進みようす：80%
- [[きめたこと]] とリンク済み
軽いテキストだから、AIもすぐに読み込めるよ！

リンクで広がる知識の網

Linked Knowledge Network
  • [[ 二重括弧 ]] でメモとメモを接続
  • 逆向きのリンク（バックリンク）も自動で見える
  • グラフ画面で、知識の地図をながめられる
  • 調べたことが、クモの巣みたいにふくらむ
「関連」が見えると、ひらめきもふえるんだよね

なぜ AI と相性いい？

Why Obsidian Fits AI
  • 中身がすべてテキスト → AIがそのまま読める
  • フォルダを直接さわれるから、検索も速い
  • ロックインなし。将来も安心して使える
  • 人間とAIが、同じファイルを共有できる
「人の道具」と「AIの記憶」が重なる場所なんだ！

3. Hermes × Obsidian の統合

つなぎかたはシンプル

Simple Integration
  • Vault のあるフォルダを、Hermes に教えるだけ
  • 面倒な設定や、難しいコードは不要
  • これだけで Hermes がメモを読み・書きできるように
  • 動画でも「シンプルな統合」と強調されていました
# 設定のイメージ
[memory]
type = "obsidian"
vault = "~/Notes/MyVault"
準備はほんの数分。つなげば、その日に完成！

共有ナレッジベースのできあがり

One Shared Knowledge Base
  • 複数のエージェントが、同じ Vault をのぞける
  • エージェントAのメモを、Bがすぐ参照
  • 知識が分散せず、ひとつの場所に集まる
  • 「みんなの頭脳」が、ひとつにまとまる
まるでオフィスの共有ドライブみたい！

ビルドをしっかり追跡

Track Your Builds
  • 何をつくって、どこまで進んだかを記録
  • 変更の履歴が、メモとしてのこる
  • あとから「いつ・なにをしたか」を確認できる
  • やり直しも、メモを見ればすぐ分かる
「前回、どこで止まったっけ？」がなくなる！

進みようすを記録

Log the Progress
  • エージェントが作業の様子をメモにかきこむ
  • おわったタスクには、チェックが入る
  • 日付つきのログで、流れを追跡できる
  • 人が様子を確かめるときにも、とっても便利
「見えない作業」が「見える記録」に変わるんだ

4. チームで動くエージェントたち

複雑なタスクで協働

Agents Working Together
  • 大きい仕事を、役割でわけて進められる
  • 調べる係・書く係・確かめる係のような分業
  • Vault を仲介して、成果をバトンタッチ
  • ひとりでは重い仕事も、チームで軽く！
みんなが同じメモを見れば、認識もそろうよね！

大切な細部が、二度と消えない

Nothing Gets Forgotten
  • きめたこと・気づいたことが、すべてのこる
  • 会話がおわっても、メモは消えない
  • 新しいセッションでも、過去を参照できる
  • 忘れないAIは、使うほど賢くなっていく
「あのときのあれ」を、もう一度探さなくていい！

Vault 構成の例

Example Vault Structure
  • 用途ごとにフォルダをわけるのが基本
  • 名前のルールを決めると、さらに探しやすい
MyVault/
├── 00_inbox/      … とりあえずのメモ
├── 01_projects/   … 進行中の仕事
├── 02_decisions/  … きめたことの記録
└── 03_daily/      … 日々のログ
まずはシンプルに。使いながら育てていこう！
