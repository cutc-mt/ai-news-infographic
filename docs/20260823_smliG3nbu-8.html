API コード例

呼び出しのイメージ
  • Python SDK での例
  • モデル名を指定するだけ
  • キーは環境変数で管理
from google import genai

client = genai.Client()  # APIキーは環境変数で
resp = client.models.generate_content(
    model="gemini-3.7-flash",
    contents="猫のQiita風記事を書いて"
)
print(resp.text)
