DeepSeek Harness で作る
最強の「無料SEOスタック」

オープンソースのエージェント基盤で、SEOのやり方をまるごと組みかえる

2026年8月23日 ／ 動画メモ: Julian Goldie SEO

第1部: そもそも DeepSeek Harness って何？

01

DeepSeek Harness とは

  • DeepSeekが公開したエージェント基盤のこと。AIに仕事をさせて、その流れを管理できる
  • いわば「AI作業の操縦席」。指示を出すと、必要な手順を自分で考えて動く
  • SEOの作業（調査・執筆・チェック）を丸ごと自動化できる下地がある
  • 中身は公開されていて、誰でも自由に使えるオープンソース
「ハーネス」は馬の「引き綱」から来た名前。AIの力を、思いどおりの方向へ導くイメージだよ！
02

MITライセンスの意味

  • MITライセンス＝とてもゆるい決まりごと。商用利用も無償でOK
  • クライアントワーク（受託のSEO業務）にもそのまま使ってよい
  • 改造して自社ツールに組み込むのも自由。フォークも放出も制限なし
  • 求められるのは著作権表示だけ。月額料金は一切なし
有料SEOツールの月額とくらべると、ランニングコストは ほぼゼロ。これが最大の強み！
03

プラグイン設計のすごさ

  • 機能がプラグイン（差し込みパーツ）で並ぶ設計。必要なものだけ足せる
  • キーワード調査・記事の生成・チェック…各工程を部品として差し替え可能
  • 自分で作ったプラグインを入れて、オリジナルの流れを組める
  • 本体を壊さずに機能追加できるので、更新もラク
レゴブロックみたいなもの。「調べる」「書く」「直す」の部品を、すきな順番にはめ込めるんだ！
04

CLAUDE.md の移行ゼロ対応

  • すでに CLAUDE.md（作業ルールを書いたファイル）を持っている人も多数
  • Harnessはそのまま読み取って動く。書き直しは不要
  • 移行作業ゼロ＝導入のハードルが一気に下がる
  • 他のエージェントツールから乗り換えても、資産がムダにならない
# CLAUDE.md の例（そのまま使える）
- 記事は必ず「結論ファースト」で書く
- 見出しには疑問形を使う
- 出典にはリンクを付ける
「今までの設定ファイル、捨てるの？」→ 大丈夫、そのまま使えます！

第2部: なぜ「透明さ」が武器になるのか

05

エージェントの思考が見える

  • ふつうのAIツールは「黒箱」。中で何を考えたか見えない
  • Harnessは推論の過程まるごと表示。どこで判断したか追跡できる
  • 「なぜこの記事構成？」という問いに根拠つきで答えられる
  • クライアントへの説明責任も、これでクリア
AIの「考えてる途中」が見えるから、変な方向へ進んだら途中で止められる。安心感がちがう！
06

Trajectory View（軌跡ビュー）

  • エージェントの作業の流れを、時系列の線として可視化する機能
  • 記事の正確さの確認が「数分」→数秒に短縮
  • どの工程で誤りが入ったか、一目で特定できる
  • まちがった工程だけやり直せばOK。全部作り直さない
ファクトチェックの時間が激減！ 「この数字、どこから？」も即答できるよ。
07

SEOワークフローを組みかえる

  • これまで: 人が順番に調査→執筆→チェック（時間のかかる直列作業）
  • これから: エージェントが自律的に複数工程をまとめて処理
  • 人の仕事は最終チェックと方針づけに専念できる
  • 同じ時間で扱える記事の本数が倍以上に
  • キーワード調査
  • 構成の下書き
  • 本文の執筆
  • 品質チェック → 公開
「AIが下ごしらえ、人が味つけ」。今までより早く、今までより丁寧に！
08

GitHubで急成長中の理由

  • 公開まもなくスターが急増。開発者の注目が一気に集まる
  • 理由①: 無料でここまでできる基盤は他に少ない
  • 理由②: 推論が見える透明性への信頼
  • 理由③: 既存ルールをそのまま使える移行のラクさ
  • 世界中の開発者がプラグインを共有し、機能がふくらむ好循環
「みんなで育てるツール」だから、進化のスピードがすごい。放置されるOSSとは違う！

第3部: 実質タダで組む SEOスタック

09

無料スタックの中身

  • 基盤: DeepSeek Harness（指揮役）
  • 調査: キーワード・競合をあさるリサーチ系プラグイン
  • 執筆: 構成案と本文をまとめるライティング系
  • 検品: 事実確認と品質点検のチェック系
基盤＋部品ぜんぶ合わせても、出費はゼロ。自分の時間だけがコスト！
10

有料ツールとのコスト比較

  • 市販のSEOツール群: 毎月数万円〜続くサブスク
  • Harness構成: 基本月額ゼロ円（API利用時のみ少額）
  • 浮いた予算を広告や外注に回す選択も可能に
  • 機能は劣る？ → 透明な推論とプラグインで十分戦える粒ぞろえ
年間にすると数十万円の差。個人でも法人でも、これはうれしい差だよね！
11

導入の手順（かんたん）

  • GitHubからリポジトリを取得
  • CLAUDE.mdを置く（手持ちがなければ新規に作成）
  • 使いたいプラグインを選んで有効化
  • 指示を出して、Trajectory Viewで流れを確認
# たったこれだけで動く
git clone https://github.com/deepseek-ai/harness
cd harness
# CLAUDE.md を同じ場所へ置く
# エージェントに最初の指示を出す
難しい設定ファイルの書き直しはナシ。持ってるものはそのまま、がこの道具のポリシー！
12

自分好みにカスタマイズ

  • 口調・文体・構成のルールをCLAUDE.mdに書くだけで反映
  • 足りない機能は自作プラグインで拡張
  • 社内のガイドラインをそのまま機械のルールにできる
  • 作ったプラグインは共有してもよい（MITライセンスの恩恵）
「うちの社風に合わせた文章」を AI に書かせる。これがようやく現実になった！

第4部: 実際のSEO業務での使いみち

13

キーワード調査を任せる

  • seed語（種となる語）を渡すと、関連語をどんどん展開
  • 検索意図（知りたい？買いたい？）の仕分けも自動
  • 勝てそうな語だけを厳選して提出してくれる
  • 調査リストの更新も、指示ひとつでやり直し
「種まき→仕分け→厳選」まで一気通貫。朝に頼んで、昼にはリストができてる！
14

記事の執筆と構成案

  • まず見出しの構成案を作らせて、人間がOKを出す二段構え
  • 構成が通れば、各セクションを順に本文化
  • 出典まわりの指示も CLAUDE.md に書いておけば守る
  • 文体のブレも、ルール通りで揃う
「構成を先に見せる」のがコツ。下書きを全部読み返す手間がなくなるよ！
15

品質チェックと事実確認

  • 「この数字、本当？」→Trajectory Viewで根拠を即チェック
  • 表記ゆれ・リンク切れの点検も任せられる
  • E-E-A-T（経験・専門性・権威・信頼）の観点も機械的に点検
  • まちがいを見つけたら、その工程だけやり直す
AIの書いたものを「そのまま信じない」。確認を速くする道具、それがこのビューの役目！
16

内部リンクとサイト改善

  • 既存記事を走査して、リンク候補をあげてくれる
  • サイトのカタマリ（クラスタ）構造の漏れも指摘
  • title・description の改善案をまとめて生成
  • 古い記事の更新（リライト）候補も一覧化
新規記事ばかりじゃなく、資産の「手入れ」も大事。そこも機械に任せられる！

第5部: ここからの展望とまとめ

17

おさえておきたい注意点

  • 最終的な人の目のチェックは省かない（品質の生命線）
  • MITライセンスの著作権表示だけは忘れずに
  • APIキーなど秘密情報の管理は自己責任で丁寧に
  • OSSなので更新が速い。変化を追う前提で使う
「無料＝なんでもアリ」じゃない。ルールを守ってこそ、長く使える道具になるよ！
18

まとめ: 今日から動くには

  • DeepSeek Harness ＝ 無料・透明・拡張自由のエージェント基盤
  • CLAUDE.md移行ゼロで、今日から試せる
  • Trajectory View で確認は数秒。品質と速度を両立
  • まずは小さな作業（見出し案づくり等）から預けてみよう
完璧な準備は不要。GitHubから取ってきて、ひとつ指示を出す。それが最初の一歩！
