② video director のじっさいの手順

video director をひらく

  • 実演で使うのは video director
  • プロンプトを タイプするだけ
  • 台本（スクリプト）を書くのも自分でOK
  • あとは全部そっちで組み立ててくれる
人間の仕事は「書く」ところまで。
仕上げはエージェント任せ！

ナレーションのかたちを選ぶ

  • 選択肢1: voiceover（音声ナレーション）
  • 選択肢2: presenter（画面に出る話し手）
  • 使うボイスの種類も選べる
  • 動画のトーンに合わせてきまる
声だけか、顔出しか。
はじめにサクッと指定できるのが楽！

Bロールのつくり方も選択

  • B-roll（説明用の映像）の生成方法を選ぶ
  • 画像素材ベースか、生成系かなど指定可能
  • ナレーションと素材の組み合わせも自動
  • 見せたい雰囲気に合わせて調整できる
「Bロールどうする？」も
選ぶだけ。素材さがし不要！

アバターも選んで組み立て

  • 画面に立てる アバター を作成・選択
  • 声との組み合わせもここで決める
  • 選ぶ項目: ナレーション形式・Bロール・ボイス・アバター
  • 選択が終われば、あとは生成を待つだけ
設定はメニューから選択式。
むずかしい知識はいらないよ

完成品は1か所にまとまる

  • 編集ずみの完成動画 が1か所に出てくる
  • すぐ使える ready to go の状態
  • 元になるのは 1つのウェブページ
  • ページを組み立てて → 動画に変換
あちこち探さなくていい。
完成品はぜんぶ同じ場所へ

シーンはタイミング込みで整う

  • シーン 単位で 時間が自動で合わせになる
  • ワークフローの中に納まる構成
  • 動画版の「スーパースキル」と呼べる存在
  • 音声・字幕・場面切り替えがそろう
タイミング合わせって地味に大変…
なのに、ここも自動なんだ

③ スキルを3つ重ねるしくみ

3つのスキルをスタック

  • 1段目: hyperframes（構成・組み立て担当）
  • 2段目: editor スキル（編集担当）
  • 3段目: video agent builder（統合担当）
  • この3つが 積み重ね で動く
各スキルは1役ずつ。
重ねたら動画スタジオになる！

スタックのイメージ

  • 命令1つが、下の層へ流れていく
  • 各層が自分の担当をこなして次へ
  • 最後に 動画ファイル が出てくる
# スキルスタックの層
video agent builder   ← 統合
editor skill          ← 編集
hyperframes           ← 構成
------------------------
1 command → 完成動画
3層構造って感じ。
シンプルだけど強い！

従来の動画制作は「スーパーメッシー」

  • 工程1: 収録（recording）
  • 工程2: 編集（editing）
  • 工程3: タイミング調整
  • 工程4: 全部をまとめて組み立て
  • 結果: 「super messy」な手作業の山
収録して、切って、合わせて、まとめて…
これを毎回やるのは大変だった…

  • スタジオといっても 機材も部屋も不要
  • 収録から納品まで、ぜんぶエージェント内で
  • 実態は「1つのシステムの中の動画工房」

出現する、って言い方だね

動画は「ファイル」だから強い
