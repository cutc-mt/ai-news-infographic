2. セルフホストのセカイ — 自分の機材で動かす

#2

Immich

セルフホストの写真・動画バックアップ
クラウド写真の「自分ち版」
  • サーバーは自分の機材で、写真をまるごと管理
  • スマホアプリは裏で自動バックアップ、重複は防いでオフラインでも動く
  • 検索がすごい: 顔 場所 被写体 で探せる
  • アルバム、共有、OAuth、世界地図ビューもあり
  • 中身は NestJS ＋ Svelte ＋ Flutter
プライバシーを気にする人にうってつけ！Dockerで手軽にはじめられる
#3

Omarchy

お仕立て済みのArch Linux
ぜんぶ入りで届くLinuxデスクトップ
  • Arch Linux ＋ タイル型WM Hyprland ＋ Quickshell
  • Neovim、Chromium、Obsidian、LibreOffice、OBS などを最初から同梱
  • 設定ファイルをいじるターミナル中心の使い心地
  • ISOかスクリプトですぐ使える状態に
  • DHHが中心、37signalsが育てるプロジェクト
「Archを1から組み立てるのがムズい」という悩みを一刀両断！
#13

HQBase

Cloudflareで動くチームの共有メール
メールも自分のインフラで
  • 自分のCloudflareアカウントの中で共有メールボックスを運用
  • メンバーごとのアクセス制御、複数ドメイン、下書き、監査ログつき
  • OAuthで守られたリモートMCPサーバーで他ツールと安全に接続
  • Workersへワンクリックでデプロイできる
外部のサービスにたよらない、自分たちのメール基盤を作れる！
#20

Halcyon Video

歩ける3Dビデオレンタル店
Jellyfinが90年代の店内に！
  • Three.jsで、自分のメディアライブラリがお店に早がわり
  • 1本ずつがVHS/DVDケースで再現され、棚を歩いてながめられる
  • ケースを手に取れば裏面とスペックが読める、カウンターでレジの儀式も
  • 再生は専用プレイヤーか、MPVへロスレス渡し
  • Raspberry Pi向けの軽い2.5Dモードも同梱
平たいリストのUIにあきていた人へ、懐かしくてあたらしい体験！

3. AIエージェントのナカマ — 人と機械がいっしょに

#4

Buzz

人とエージェントが協業する場
人間もエージェントも同じ部屋で
  • nostrリレー上で、メッセージもレビューもgitイベントも署名つき1本のログに
  • エージェントは自分の鍵を持って、チームメイトのように参加
  • リポジトリを開き、パッチを送り、レビューして、音声ハドルまで
  • 裏は Rust ＋ Postgres ＋ Redis、アプリは Tauri ＋ React
  • CLIやACPハーネスで Claude Code や Codex を接続
チャット、レビュー、自動化を別々の道具に分けたくない人へ！
#5

Pi エージェントハーネス

コーディングエージェントを作る金型
クローズドな道具に頼らない
  • コーディングエージェントのCLIと、自作用の部品一式を提供
  • 統一APIで OpenAI、Anthropic、Google など複数LLMに対応
  • ツール呼び出しと状態をにぎるランタイムつき
  • 対話的な画面を作るターミナルUIライブラリも同梱
  • 起動ユーザーの権限でローカル実行、コンテナ化で隔離もOK
「エージェントをじぶんの好みに組み立てたい」人向けの土台！
#6

DeepTutor

エージェント型の学習つくえ
1つのループで学びをつなぐ
  • 個別指導、問題をとく、クイズ作成、リサーチ、図示を1つのエージェントループで
  • 知識ベース、ノート、記憶がモードをまたいで共有される
  • LlamaIndex、GraphRAG、PageIndexで根拠のある回答を引き出す
  • 会話の途中で Claude Code や Codex を呼べる
  • ローカルでもDockerでも動く、WebアプリとCLIの両方あり
学習用の道具をばらばらにそろえるのは、もうおわりかも！
#11

Cumora

エージェントが正メンバーのチームチャット
エージェントは「外付け」じゃない
  • 名簿、DM、グループ会話、カンバンとカレンダーを人間と共有
  • エージェントはペルソナを覚え、タスクを取り、メールまで送る
  • クラウドのマルチホップ実行か、自分のマシンを脳にするBYOエージェントかを選べる
  • BYOならAPIキーをサーバーに置かない設計
  • 裏は Express ＋ Postgres ＋ Redis、クラウド側はKubernetesのポッドで
チャットの中でAIの同僚と協働したいチームにぴったり！
#16

macOS Harness

Macをじか操りする道具一式
アプリ別の連携はもういらない
  • アプリごとの道具を作らず、6つの基本操作だけでMacを制御
  • スクショ、キーと座標の入力、アクセシビリティ情報へ直接アクセス
  • Appleイベントと、ログイン済みの本物のブラウザも操れる
  • 裏のウィンドウも前面に出さず操作できる
  • doctorコマンドで権限チェック、カーソルは勝手に動かさない
普通のPythonを書くだけで、なんでも操作できるエージェントに！
#15

sloptrim

AIの書きぐせを見つける番人
保存した瞬間にチェック
  • ファイルを保存するたび、Claude Codeで自動で起動
  • 71この書きぐせパターンを、標準ライブラリだけ(ネットワークなし)で採点
  • docx、pptx、xlsx、epubなど20の形式に対応
  • 結果は0〜100点と、直すべき箇所のフラグで戻る
  • 誤検出の率や精度を公開、新しいモデルに弱い点も正直に明記
エージェントがこっそり残す機械っぽい言い回し、気になりませんか？

4. 開発の道具ばこ 前半 — すごい道具が目白押し

#1

Nautilus Trader

Rust製のアルゴ取引エンジン
研究コードがそのまま本番に
  • Rustが実行を、Pythonが戦略と設定をにぎる二段構え
  • バックテストと本番で同じイベント駆動エンジン、書き直しが不要
  • 暗号資産、FX、株、先物、オプションを1つのインターフェースに正規化
  • ネットワークはTokio、Linux/Mac/Windowsで動きDockerでも
量解析トレーダーと開発者に待たれていた一本！
#7

airllm

小さいGPUで大きなLLMを
巨大モデルを手元の機材で
  • 1層ずつ読み込み処理すれば、必要メモリは層の大きさぶんだけ
  • 量子化も蒸留も枝刈りも使わないのがミソ
  • Llama、Qwen、DeepSeek、Mistral、Gemma など人気どころに対応
  • Apple Silicon の Mac でも動く
pip install airllm
# HuggingFaceのモデルを1呼び出しで
model = AutoModel.from_pretrained("...")
大きなGPUクラスタがなくても、でっかいモデルが試せる！
#8

terminal-browser

ターミナルの中の本物Chromium
画面の行き来をなくす
  • Chromiumのオフスクリーン描画で、ピクセルをターミナルに直描き
  • マウス、キーボード、トラックパッドの入力もそのまま送られ滑らかにスクロール
  • Kittyのグラフィックス手順に対応した Ghostty、Kitty、VS Code などで動作
  • アクションコマンドでエージェントがページを開いて読むことも
  • SSH越しのリモート機でもプレビュー可能
エージェントと同じタブで Webプレビューを見られる！
#9

OpenLogi

Logitechマウスのローカル設定
アカウント登録なしでボタン設定
  • 公式アプリやログインを経ず、HID++手順でマウスと直接やりとり
  • 対応はレシーバー、Bluetooth、有線の3とおり
  • 設定はローカルのTOMLファイル1つに保存
  • GUIではクリック式のマウス図でボタン割り当てやDPIを指定
  • クラウド依存ゼロ、更新チェックも自分で許可した時だけ
ボタンを変えるだけなのに雲のアカウントが要る、をやめられる！
#17

dgit

Cloudflareだけで立つgitサーバー
倉庫ごとに独立した小部屋
  • 各リポジトリがDurable Objectで、私設のSQLiteを1つずつ持つ
  • 使っていないリポジトリはほぼ無料、混雑も互いに影響しない
  • gitのスマートHTTP手順をTypeScriptで自前実装
  • ログ、blame、diff、スナップショットつきのWeb画面も表示
  • 読み取りは公開、pushはトークン制。知らない名前へのpushで新倉庫ができる
GitHubのような中央の舞台に頼らない、軽い自分のgit置き場！

5. 開発の道具ばこ 後半 — まだまだあるぞ

#10

blobatar

文字列から生まれる幾何学アバター
名前が同じなら顔も同じ
  • 名前やメールなどの文字列から決定的にアバターを作る
  • 依存はゼロ、画像の用意もホスティングも不要
  • Reactコンポーネントと、SVGやdata URIを返す関数の2つの顔を持つ
  • 形や色などの特徴は固定指定もできる
  • アニメや表情は別読み込みでバンドルは小さいまま
仮の顔画像をデザインする手間を、文字列1つに置きかえられる！
#12

Aura

ふわっと光る背景メーカー
手調整だった背景作りを楽に
  • CSSのブレンドモード重ねで、やわらかく光るグラデ背景を作る
  • ギャラリーをホバーでプレビュー、その場で色やぼかしを調整
  • 書き出しは CSS、Tailwind、変数、PNG/SVG に対応
  • ChatGPTやClaudeに投げる再現プロンプトも自動生成
  • Next.js ＋ React ＋ Tailwind で動くWebツール＆ライブラリ
平たい色の背景にさよなら、すぐ使える上品さを手に入れよう！
#14

NorthCinder

広告が順位をゆがめない買い物MCP
あなたの基準で並べる
  • ホスト型ではなく自分のマシンで動くMCPサーバー
  • 出稿料やアフィリエイト報酬が順位に影響しない設計
  • Shopify、WooCommerce、eBay、Etsy、Amazon の店舗アダプターを検索
  • 結果は理由つきの順位表と、却下した候補、検索できた店の報告
  • 購入には使い捨ての署名付き許可が必ず必要
「おすすめ」の裏にあるお金のヒモを切り離せる！
#18

Core Framework

見て作るデザイントークン
手で整えるCSSとはお別れ
  • 色、流れる文字サイズ、余白、レイアウトを画面で見ながら定義
  • そこからコンパクトな本番CSSを自動で書き出し
  • ブラウザアプリ、WordPressプラグイン、Figma版で同じ編集機を共有
  • 持ち運び可能なファイルで書き出し、口座もライセンスキーも不要
  • Gutenberg、Bricks、Oxygen との連携つき
デザインの正しい情報源を1か所にまとめられる！
#19

morphnext

Flutterのアイコンがモーフする
パッと入れ替わるを、するりと
  • アイコンの組み合わせごとに素材を用意せず、形が流れるように変化
  • 割り込みが来てもいまの形からやり直すから自然
  • iconを変えるだけで自動のimplicitと、好きな動きで駆動するcontrolledの2種
  • pubspec.yaml のフォント情報から輪郭を解決、なければ普通のアイコンに戻る
  • IconTheme や MediaQuery など Flutter の流儀を尊重
ボタンの中のアイコンに品のある動きを、少ない手間で！
