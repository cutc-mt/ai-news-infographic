問いかけ

  • 「どうしていま、モジュール型の AI エージェントが要るのか？」
  • 答えはひとつ: 部品をはめ替えられること
短い動画なのに、
核心はしっかり伝わるのだ

ほかの製品は
「ふたの閉じた車」

  • 世の中のエージェント製品は密閉ボディみたい
  • 外側はきれいでも、中は開けられない
  • 動画がくり返し使う、強い比喩（たとえ）
この例え話、
一度聞いたら忘れないでしょう

変えられるのは
ラジオと電話マウント

  • ラジオの局を変える — できる
  • スマホのマウントを付ける — できる
  • でも、それは飾りの領域を出ない
自由があるように見えて、
中身はさわれないのだ

エンジンはエンジン、
シートはシート

  • 走りの核（エンジン）は最初のまま
  • 座り心地（シート）も最初のまま
  • 性能の良い部品へ替えたい？ → できません
買った瞬間に、
未来の性能まで決まってしまうのだ

会社のまずい選択に
縛られる

  • 車体を作った会社が悪い選択をしたら？
  • 利用者はそれを飲み込むだけ
  • 動画は言い切る — 「That's it.」（それでおしまい）
異を唱える手段すら、
用意されていないのだ

DeepSeek Harness の発想

DeepSeek Harness とは

  • モジュール型の設計を持ち込んだエージェントの基盤
  • エンジン・メモリ・調べる道具を、すべてはめ替え式に
  • 概要欄のタグに #OpenSourceAI の文字
オープンな世界の流れを
くむ設計なのだ

車輪も、シートも、
ハンドルもポンと外れる

  • タイヤが ポン と外れる
  • シートが ポン と外れる
  • ハンドル（ステアリング）さえも
  • クリックで カチッとはめ直せる
すべてが「部品」に
見えてくるでしょう

交換のあいだも
車は走り続ける

  • 部品を外している間も走行は続行
  • 止まって待つ時間が発生しない
  • 仕事の流れを止めないのが最大のポイント
エンジンをかけ直す
必要がないのだ

モジュール設計の
考え方

  • modular architecture ＝ 部品単位の設計
  • すべてを溶かして1つの塊にしない
  • 部品同士は取り替え可能な接点でつながる
レゴブロックみたいに
組めるものなのだ

3つの部品は
ぜんぶプラグイン

  • エンジン — 考える力（モデル）
  • メモリ — 覚えておく仕組み
  • ブラウジング道具 — 調べる手段
  • どれも差し替え自由のプラグイン扱い
「社の標準部品」という
しばりが存在しないのだ

部品ごとに見る「交換」の場面

エンジンを
交換する

  • 新しいモデルが登場したらエンジンだけ替える
  • 車体（作業の場）はそのまま
  • これまでの設定や流れを引き継げる
モデルの進化に
ついていくのがラクになるのだ

メモリを
交換する

  • 動画の予言: 「来月、もっと良いメモリ機構が出たら」
  • その部品だけをスワップすればよい
  • 覚えた内容を保ったまま強化できる
「覚え方」まで、
あとから進化させられるのだ

調べる道具を
交換する

  • もっと良いブラウジング道具が出たら same thing（同じこと）
  • 調べる力・集める力だけを底上げ
  • ほかの部品に影響しない
情報をつかむ「手」だけを
取り替えるのだ

プラグイン機構の
イメージ

  • 設定を書き替えるだけで切り替わる
  • 入れ替えはクリック1回の世界

こんな感じ：

# 部品はプラグインとして差し替え
engine:  deepseek-v3   → newer-model
memory:  sqlite-store  → vector-db
browser: playwright    → agent-browser
設定を書き替えるだけで
生まれ変われるのだ

ロックインからの解放と、これから

ロックインとは
何か

  • 概要欀の言葉: locked ecosystems（閉じた生態系）
  • 1社の囲い込みの中に閉じ込められること
  • 気づけば古い機能のまま使い続けるはめに
置き土産が、古い機能だけ
……なのだ

会社の更新を
待たなくていい

  • 従来: 改善は会社の気まぐれ待ち
  • Harness: 自分のタイミングで交換
  • 待つ時間 ＝ 出遅れの原因
主導権が自分に
戻ってくるのだ

丸ごと乗り換えが
不要になる

  • 従来は新製品への引っ越しが必須
  • 設定もデータも、ぜんぶ持ち出す羽目に
  • Harness なら必要な部品だけ更新
引っ越し荷物が
1つの箱で済むのだ

1部品だけ直して
走り続ける

  • 動画の結び: upgrade one piece and keep moving
  • ぜんぶやり直す必要はない
  • 直したところからすぐ再開
「進み続ける」が
当たり前になるのだ

誰かがもっと
良い部品を作る

  • 動画の予言: Someone will build better parts
  • オープンな世界では改良が止まらない
  • そのたびに、あなたの車も速くなる
未来の部品を、
まるごと受け取れるのだ
