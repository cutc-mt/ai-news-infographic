Section 3：セットアップは超カンタン

最短3ステップ

① opencode を入れる

  • 公式スクリプトを1行叩くだけ
  • npm派はグローバルinstallでもOK
# 公式インストーラー
curl -fsSL https://opencode.ai/install | bash

# または npm で
npm install -g opencode-ai
どちらか片方だけで大丈夫。
好みの方でどうぞ

② つないで選ぶ

  • /connect で OpenCode Zen 認証へ
  • /models から Ox Alpha を選択
  • これで準備完了。カード情報すら不要
# opencode 起動後
> /connect   # OpenCode Zen と連携
> /models   # Ox Alpha を指定
APIキーの発行も不要。
認証はぜんぶOpenCode Zenが引き受けてくれる
　次は相棒の Open Design の紹介です　

Section 4：Open Design とは

「あの」デザインツールのOSS代替

オープンソースの
デザインワークスペース

  • Claude Design 風ツールの OSS代替
  • ライセンスは Apache 2.0 で商用も安心
  • ローカルファースト。データは手元に残る
  • モデル非依存。どのLLMでも動く設計
サブスクでもエコシステム閉じ込めでもなく、
ちゃんと「自分のもの」になる道具なんだ

積み上がった資産

  • 100以上のデザインスキル
  • 約 150のデザインシステムを内蔵
  • 大規模な プラグイン ライブラリ
  • コミュニティで育ち続けるエコシステム
個人がゼロから集めるには
何年もかかるボリュームが最初から同梱！

何がつくれる？

  • Webサイトの プロトタイプ
  • モバイルUI の設計
  • ダッシュボード 画面
  • スライド資料 まで対応
アイデアの見せ方を変えたい時、
まず形にして確認するのが速くなる

出力は本物のHTML/CSS

  • その場で プレビュー ・ 編集 ができる
  • 当然 エクスポート 可能
  • コーディング エージェントへそのまま引き継ぎ
  • React / Next.js / Vue に統合して仕上げ
/* 出力イメージ: モックではなく実HTML */
.hero {
  padding: 96px 24px;
  font-family: "Inter", sans-serif;
}
「絵」で終わらず、実装まで一直線。
この距離の短さが最大の強み！

Section 5：デザインシステム＝「視覚的契約」

破れないルールが美しさをつくる

契約が守る5つのルール

  • パレット: 使っていい色の範囲
  • タイポグラフィ: 字の大きさと種類
  • 余白: スペーシングの一定のリズム
  • コンポーネント形状: 角丸や枠の統一
  • モーション: 動き方の規則
ルールを先に決めてAIに渡すから、
最後まで一貫した見た目に仕上がる、という仕掛け

有名どころ風が揃う

  • Linear 風の隙間のないUI
  • Stripe 風の洗練された美しさ
  • Vercel の黒ベースUI
  • Airbnb ・ Apple ・ Notion 風も収録
ブランドの「服」を着せ替える感覚で
土台のデザインを選べるのが便利

エージェントを自動で発見

  • Open Design が環境をスキャン
  • Claude Code Codex Cursor opencode に対応
  • 一覧から opencode ＋ Ox Alpha をえらぶだけ
  • 設定ファイルの書き換えは不要
どのツールを普段使いしていても
すぐ組み合わせられるのが嬉しい
　いよいよ実演。2つのランディングページを作ってみた
