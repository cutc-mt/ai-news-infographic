DirecTVの事例

大型ストリーミング配信のQA

  • プラットフォームをまたぐ、大型の配信ローンチ
  • 品質チェックを、自動で回すQAテスト
  • 従来は壊れやすいテスト用スクリプトに悩み、人の目も大量に必要
  • 画面キャプチャで、AIが直接 判断する方式へ
// 従来: 座標を固定する、こわれやすい書き方
click("#play-btn", x=320, y=240)

// AIなら:
agent.do("Enterを押して")  // 場所はAIが判断
「Enterを押して」のひと言でOK——
前はできなかったことが、できる時代です
