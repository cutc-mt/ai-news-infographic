第1部：AIは想像以上に賢かった 実験の内容

01

今回の実験はこれ

  • チャットGPTのコーデックス（Codex）に、設計解析ツールCAEの操作を丸ごと任せた実験
  • 出てきた答えは合っていた。でも、作り方が人間と全然ちがう
  • AIに仕事を頼む人なら、専門の現場でなくても同じことが起きる
  • 実験した人のことば：「AIは人間と『楽』の定義がそもそもちがう」
この3段で見ていく
  • AIは想像以上に賢かった
  • それなのに、やり方が人間とちがった
  • じゃあ頼み方をどう変えるか（持ち帰り）
ずんだもん AIに計算を頼んだら、ちゃんと答えが出たのだ！もう完璧なのだ！
02

CAEってどんな道具？

  • 部品を実際に作る前に、画面の中で引っ張ったり潰したりして壊れないか試す道具
  • 実物を壊さずに試せるのが最大の利点
  • 車も家電も、これで先に確かめてから作られている
  • 設計の現場では当たり前の道具
ずんだもん 実物を壊さなくていいのだ。それは助かるのだ！
03

Codexは「書くだけ」じゃない

  • 使ったのはチャットGPTアプリのコーデックス。できたものはVSコードで確認
  • 書いたコードを自分で実行して、結果まで受け取る
  • 出てきたログやエラーを読んで、次に何をするかも自分で決める
  • それを延々と繰り返す
書く 実行 受け取る 読む 決める 
# ひとりで回し続けるループ
while True:
    code   = write_code()   # コードを書く
    result = run(code)      # 自分で実行
    read_logs(result)       # ログとエラーを読む
    decide_next()           # 次の手を自分で決める
ずんだもん 書く・動かす・読む・決めるを、ぜんぶひとりで回すのだ！？
04

人間の仕事は「最後のレビュー」だけ

  • いきなり解析させなかった：まず計画を立てさせて、分からないところがあれば聞いてから頼んだ
  • その方が安全だから。低い所から段階的に任せる進め方
  • 実行が終わったら、最後に人間がレビューする
  • そこだけは人の仕事として残してある
解説者 いきなり解析を実行させてはいないの。安全第一よ
05

「10」って、どの10？

  • 「右端に10の力をかけて」と書いたら、AIが本当に聞き返してきた
  • その10が「どの10か」を確認してきた。次の3つは全部ちがう話：
  • 全体で10 …部品全体に合計10
  • 1mmあたり10 …かける場所の長さで考える
  • 面圧力として10 …面で押す圧力として10
  • しかも、それぞれの意味を説明した上でおすすめまで出してきた
ずんだもん 10は10なのだ！他に何があるのだ？……言われてみれば全然ちがうのだ
06

計画も報告書も自分でまとめた

計画の使い分け
  • 板が薄いから簡単な計算方法で行く、と判断
  • 熱くなったら別の方法に切り替える —— 使い分けまで自分で決めた
報告書
  • 誰も指示していないのに、目的 → 条件 → 結果 → 考察の順でまとめてきた
ずんだもん 完璧なのだ！文句のつけようがないのだ。そのまま出していいのだ！
解説者 そこなのよ。よく見たら、人間なら絶対にしない作り方をしていたの

第2部：それなのに、やり方がちがった 人間なら絶対にしない作り方

07

① 専用ボタンを無視して自作

  • 力を配る作業には、その道具に専用のボタンが用意されている
  • ボタンを押せば終わり。のはずだった
  • でもAIは使わず、力を1点ずつ配るプログラムをわざわざ自分で書いた
  • ボタンがあるのに自分で書く。手間が増えている
解説者 「手間が増えてる」……それは、あなたが人間だからそう思うのよ
08

② 結果の図は別の道具で書き直し

  • でも中身はPyVistaという別の道具で書き直していた
  • 見た目がそれっぽいだけで、出どころがちがう
ずんだもん 綺麗な色の図なのに、わざわざ書き直したのだ……？あれも変なのだ
09

③ 極めつけは三角の網

  • 本当は四角い網（メッシュ）で計算していた
  • なのに出てきた図は三角の網 —— グラフ道具 matplotlibの「三角の編みを描く機能」を使っていた
  • 数字は合っている。絵だけがちがう。
  • だから、パッと見では絶対に気づけない
計算した網（四角）
→ なのに →
出てきた図（三角）
ずんだもん 四角いはずが、三角に見えるのだ！1番大事なところじゃないのだ！？
10

なぜ遠回り？ 労働コストがない

  • 実験した人の説明：「AIには労働コストという概念がない」
  • 人間は面倒なく手段を選ぶ —— 手数が少ない方を選ぶ。ボタン1個で済むならボタンを押す
  • AIにはその「面倒くさい」がない
  • だから自分が書きやすい方を選ぶ → ボタンを無視してプログラムを書いた
解説者 あなたが面倒だと思う作業を、AIは全然面倒だと思わないの。逆に、簡単なことを遠回りするわよ
11

AIはコーディングの世界の住人

  • もう1つのことば：「AIはコーディングの世界の住人である」
  • 住んでいる世界がちがう —— 人間の常識が通用しない
  • 「人間なら多分こうするだろう」という思い込みは、AIの世界では通用しないと実験者は言い切っている
ずんだもん ずんだもんが簡単だと思うことを、AIは遠回りするのだ……住む世界がちがうのだ

第3部：じゃあ頼み方をどう変えるか ここが持ち帰りどころ

12

レビューを頼んだら、自分で直した

  • 実験で面白い場面：AIが精度の甘いやり方を選んでいた
  • 「もう1度レビューして」と頼んでみた
  • そうしたら自分で見直して「ここを細かく見るなら、もっと精度の高いやり方にすべき」と自分で指摘した
  • 知っていたのに、最初からはやらない
解説者 それを知っているなら、最初からそうして欲しいって思っちゃうわね
13

直す場所はAIじゃなく、こっち側

  • 実験した人の整理：これはAIの問題ではなく使う人間側の環境設計の問題
  • つまづく場所が入れ替わった：
  • 昔（人が操作） 単位のまちがい / 条件設定のミス
  • 今（AIが操作） 無駄に計算を回す / 勝手に計画を変える / 古いやり方のコードを使う
  • だから見張る場所も変わる
ずんだもん 人が操作してた頃とは、つまづく場所が入れ替わったのだ
14

頼み方を3つ変える＋AGENTS.md

  • いきなりやらせないで、先に計画を出させる
  • 出てきたものにも、もう1度レビューしてと頼む
  • 毎回決まっている手順は、先にルールとして書いておく
  • CodexにはAGENTS.mdというルールを書くファイルがある
書いておくべき例
  • 「レポートを作る作業と計算を回す作業は分ける」—— 分けないと、全部1つのプログラムにまとめられて、レポートを少し直して頼むだけで時間のかかる計算をもう1度回し始める
# AGENTS.md（頼む前に決めるルール）
1. いきなり実行せず、先に計画を出して確認を取る
2. 出てきた結果は、もう1度レビューしてから渡す
3. レポート作成と計算実行は、別々の作業として分ける
解説者 これは実験の中で効いた3つよ。明日からでもできるわ

第4部：続編チャレンジ ゴムのドームを、制限時間1時間で

15

出された課題はこれ

  • ゴムのドームを上から10mm潰す
  • 潰した時に押し返してくる力が、ちょうど30Nになる形を探す
  • 同じ力になるなら、使う材料が少ない方がいい
  • 制限時間は1時間。過ぎたら「その時点で1番良かった答え」を出す
ずんだもん 締め切り付きなのだ……ぴったり30は難しそうなのだ
16

1時間で14通りの作戦

  • AIは自分で作戦を立てた：厚みを増やす / 幅を小さくする / 背を低くするの3つを組み合わせる
  • 結果を見ながら作戦を直し、残り時間から次に試すものまで決めた（時間配分も自分で）
  • 時間が余ったら計算の細かさを変えて、もう1度見直した
  • 結果：1時間で14通りを試した
ずんだもん 14通り……ずんだもんなら1通りで力尽きるのだ……

第5部：人間に残る「決める仕事」 どこまで渡して、何を残すか

17

AIが担えた5つ・人間に残る4つ

AIが担えた5つ
  • プログラムを書く
  • 道具を動かす
  • やり方を選ぶ
  • ある程度まで結果を評価する
  • 報告書を作る
  • 教科書に載っている範囲なら、AIでも対応できる
人間に残る4つ
  • そもそもなぜこの計算をするのか、目的を決める（目的は誰も教えてくれない）
  • どんな条件で計算させるか決める
  • 結果を見て「これ、変じゃない？」と違和感を見抜く（三角の編みに気づくやつ）
  • 計算する形そのものを用意する
  • 手を動かす仕事ではなく「決める仕事」が人間に残る
ずんだもん ずんだもんは全部渡したいのだ！楽したいのだ！
18

1つだけ、渡さない方がいいもの

  • AIは「結果を並べて整理する作業」を丸ごと引き受けた（14通り全部）
  • でもその作業は、これまで新人が経験を積むためにやってきた仕事
  • 違和感を見抜く目は、教科書ではなく自分で一度つまづいた時に身につく
  • 面倒な作業を全部渡すと、つまづく機会まで一緒に渡すことになる → 渡した先で違和感を見抜けなくなる
  • 全部やる必要はない。でも1回は自分でやる
解説者 つまづいた記憶が「目」になるのよ。面倒な作業を全部渡すと、その目を育てる機会まで渡しちゃう
