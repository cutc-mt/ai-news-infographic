なぜプロンプトより「音声入力」が効くのか

2026年8月26日公開レポート ／ 池友（いけとも）チャンネル
基本スタンス

AI活用は音声入力が9割

  • パソコンでも スマホでもほぼ100%音声入力
  • キーボード入力は ほとんどしていない（コピペなど一部だけ）
  • 音声にすることで、AIとのコミュニケーションがめちゃくちゃ楽になる
打つのをやめると、AI活用そのものが変わる、がこの動画の主張だよ！

3ヶ月の使用データがすごい

  • Claudeだけでも約4,497回音声入力（ログ確認では4,353件）
  • ChatGPT・Perplexity・Geminiなど込みなら1万回近くと推定
  • 総量は約50万単語。1日に50回以上話しかける日も
「この3ヶ月でどれぐらい喋ったか、セッションログで確認できるかな?」と分析まで音声で依頼しちゃう

なぜ音声の方が効くのか

  • 元リサーチ会社経営者の経験: キーボードの自由回答は ざっくりになる（「このバグがいまいちでした」…）
  • 音声なら「この画面のこの部分で」といった細かい内容も簡単に言える → 情報量が増える
  • AIはこちらの背景を知らない。キーボードだと入力が面倒で情報が削られ → 背景が減り → 回答精度が下がる
伝える量が、そのままAIの精度になる…だから音声で大量に伝えるのが正義！
Typeless（タイプレス）の特徴

Typelessとは

  • この動画は音声入力ツールTypelessのPR（スポンサー）動画。その点は冒頭で正直に説明されている
  • 池友氏は普段「単独スポンサーはやらない」スタンス。ただ実際にめちゃくちゃ使ってるから今回引き受けた、と率直に告白
  • WindowsならAltキー一発で立ち上げ、話すだけ
  • 最大9分まで連続入力できる。無料プランあり
実際の使い方をそのまま見せるから、宣伝だけじゃない動画だよ（←動画のトーンもこんな感じで正直！）

話した内容が整った文章になる

  • 話した内容をそのまま入れず、まとめて分かりやすい文章に整形してくれる
  • 「あー」「Aとか」みたいなフィラーは消え、話し言葉が読める文章に
  • 言い直しても後から言い直した方を採用して整理
  • 辞書登録機能あり。登録した内容が優先されて使われる
🗣 話した内容:「Aかな、Bかな…やっぱりAかな」
📝 Typelessの出力:「Aです」
📄 分析依頼も: 3つのポイントを話す → 1番・2番・3番に整理してくれる
頭の中を雑に話していいのがTypelessの価値。整理は任せればOK！

精度が桁違い

  • PC・スマホの標準音声入力とは明らかにクオリティが違う（特にスマホ）
  • 入力が短いほど誤変換が致命的になる…でもTypelessは短い単語でも高精度
  • 「マークダウンファイルにまとめて」も誤字なく一発で通る
  • スマホの標準音声入力だと「短い入力をする気になれない」レベルだったのが、バンバン使えるように
等分な長文なら誤字も吸収できるけど、短いほど1文字の誤字が命取り。そこをクリアしてるのがでかい！

マルチデバイス対応

  • Windows / Mac / iPhone / Android 全対応
  • 音声入力はアプリ関係なし。AI・メモ帳・ドキュメント、どこにでも同じ入力
  • 池友氏の端末: Windows＋iPhone（メイン）＋折りたたみ2台（Pixel 11 Pro・Galaxy）＋Mac mini など
  • OSごとに入力方法が違うストレス → 全部Typelessで同じ操作に統一できるのが便利
本人曰く「パソコンよりスマホでの利用が多い」。移動中に立ち上げて バーッと依頼するのが最高に快適なんって！
3ヶ月ログの分析結果（Claude Codeに分析させた）

小さい声でも よく聞こえる

  • 電車の中でも、隣の人に聞こえないぐらいのこそこそ声でも認識精度が高い
  • 歩きながらの依頼もできる。移動時間がそのままAI時間に
  • 音声データの扱いはtypeless.comでセキュリティポリシー公開。会社の方針がある人も確認できる
「このくらいの小さい声でも、まあなんとかなる」…電車の中で使えるの、地味にでかい！

用途の85%は「AIとの往復」

  • 用途の85%は入力ではなく、AIからの返答に対してバンバン往復すること
  • 長さで分けると: 10秒以内が5割 1分以内が45% 1分超が5%
  • 分析自体もClaude Codeに音声で指示: 「サブエージェントのプロンプトは抜いて」「時間じゃなくて目的で分類して」
  • いまいちと思ったら すぐ「これ違うんじゃない?」「もっとこうして」と言える → タイピングなら止めてたコミュニケーションが続く
短い秒数と文字数が合ってない、軸を3セット作って…なんて分析へのダメ出しも全部音声でやってたよ！
10秒パターン（全体の5割）

① 短い依頼を言うだけ

  • 思ったことをそのまま言うだけ。迷いなく バーッと
  • あった例: マークダウンファイルにまとめて 入力例は別ファイルにして
  • このアイデア、なんとかしといて ← これだけで依頼完了
🗣 10秒の口癖:「まとめて」「別ファイルにして」「なんとかしといて」
⏱ 所要時間: 10秒以内 ＝ 全体の約50%
短い入力ほど標準音声入力だと誤字で死ぬ。でもTypelessなら短い単語でも精度が高いから、この速攻パターンが回る！

② 気になることを言いまくる

  • 終わった後に ふと気になる「あれ、これどうなってたっけ?」も音声でパッと聞く
  • 本（同人誌）の構成を見ながら: 「この列ぜんぶ白背景で見づらいから色つけて」
  • 「素材A/Bとセルが離れてるからタブで切り替えて」など、見たままを口に出す
  • 本1冊あたり何百回。イベントページの直しも音声で叩きまくる（縦幅が長い・開閉が分かりづらい…）
目で見た違和感を、そのまま口にするだけ。思いついた順で言ってどんどん直すのが日常に！
30秒〜1分パターン（45%）

① 見ながら直す

  • 資料やページを見ながら、直しを思いついた順に言っていく
  • 10秒パターンの「ちょっと長い版」。見て → 話して → 直る のループ
  • 依頼だけでなく思考しながら話す系の用途も この帯に多い
画面と会話しながら直す感じ。黙って考えるより、喋りながら見つけた方が早い！

② 資料を渡して口頭で補足

  • Excelなどの資料を渡した上で、後から口頭で説明・補足を追加していく
🗣 実際の依頼:「このExcelの内容で、責任者の合意はもう取れてるので文字は変えずにスライド5枚ぐらいにしてね」
  • ファイルの中身 ＋ 背景の事情を組み合わせて伝えられる
  • キーボードだと書くのが面倒で省いてしまう詳細も、音声なら全部言える
資料 ＋ 補足音声 が最強の依頼セット。 Files→Voice→Done！

③ 方針を変えて作り直す

  • イベントページを「初心者向け」→「2日がかりの本格イベント」に方向転換して作り直し
  • 方針変更は タイプすると言うのが面倒…でも音声なら言うだけで超スムーズ
  • 今のAIは要望が3個じゃなく10個でも平気で対応。伝えるほど精度が上がる
  • 1個ずつ吟味すると重要なものしか言わなくなる → 細かい内容も全部音声で
伝えれば伝えるほど精度が上がる。遠慮は要らない、のが音声入力のいいところ！
1分以上パターン（5%・最重要）

① 答えが定まってない思考を吐き出す

  • 事業内容など答えが定まってないことを「あー」「うん」と言いながら迷って考える
  • 悩み例①: 月額5,000円のコミュニティをやるべきか（責任・継続的な価値提供がハードル…）
  • 悩み例②: イベントアーカイブの値段設定。安くする? 参加者に申し訳ない?と葛藤しながら話す
  • 誤字があっても確認せずそのまま送る。確認の手間すら省く（Typelessが整形してくれるから）
🗣 迷いの声:「アーカイブって買う人いるのかな?…1回5,000円なら、アーカイブはいくらにするかな?…参加してくれた人より安いのも申し訳ないし…」
📤 送信: そのまま バーッと喋って バーンと送る
迷ってる最中の脳内を、そのまま吐き出してOK。それをまとめるのがAIの仕事！

② 思考が整う前に使える

  • 長文の最大の壁は「整理するのが面倒」。これまで依頼を後回しにしていた原因
  • メモ帳を開いて構造的にまとめて…という作業が不要に。思いつく範囲で話して「まとめて」だけでいい
  • 提案書も会議終了後に、会議の要点と自分の考えを音声で入れて「提案メモ作って」でOK（作った後にチェックはする）
  • 2時間のオンラインイベントの企画構成も、最初から最後まで全部音声で。喋り終えたら送信してまとめてもらう
思考が整う前に話しちゃえ…それだけで仕事が爆速になる、のが最大のメリット！
コツとまとめ

コツ: 完璧に喋る必要はない

  • ちゃんと整理して話そうとするからハードルが上がる
  • 考えずに バーッと喋れば、いろんな情報が出てくる
  • 喋った後のまとめはAIに頼めばいい。完璧でなくても内容を踏まえて処理してくれる
口を酸っぱく言いたい: まず喋ろう。整理はあとでいい。それだけで入力のハードルが下がる！

打つのをやめるとAI活用が変わる

  • 10秒でパッと依頼 30秒で見ながら言う 1分以上で思考を吐く
  • 特に30秒〜1分以上のシーンは多くの人がAIに依頼できていないゾーン。ここを音声が埋める
  • スマホ・PCのデフォ音声入力は精度が悪い → まず無料プランで試すのがおすすめ。短い所から、長いのも試して
  • 池友氏の実感: Typelessの有無でAI活用の頻度は数倍差。作るもの・アウトプットの精度・仕事に効いて生産性を底上げ
