素材の準備

  • パソコンのフォルダに素材を保存：雪女の顔アップ・全身、ヘッドホン、マイクスタンド、ギター男性のバストアップ
  • Claude Codeはフォルダに直接アクセスできるので、素材のアップロード → 生成 → ダウンロード → 名前をつけて保存までぜんぶ1回で実行
  • 素材のアップロードも保存もコピペ一切なし。これがMCP＋Claude Codeの便利ポイント
納得いかないときは、チャットでお直しをお願いして再生成すればOK！

参考にした動画を分析

  • 自作のファーストテイク風MVの分析を依頼。カットの切り替わりを自動で検出して、1枚ずつ画像に分解して分析
  • Claude本来には動画カット検出の機能はないが、オープンソースのツールを自分で入れて使いこなす！
  • 分析の結果：全58カット・平均3.1秒の高速なカット切り替え。冒頭は準備の演出 → 歌が始まったらギターを差し込む構成
  • 必要な画像はボーカル4枚＋ギター2枚だけで足りる。ヘッドホン画像を参照に、画角違いを一括4枚生成（顔もロゴもキープ）
ツールが入っていなくても「入れて」と頼めば、Claudeが勝手にそろえてくれるよ。

生成できる時間は2倍

  • 生成できる時間が前回の15秒から倍増し、30秒まで作れるように
  • 15秒だと使えるカットが限られ、つなぎ合わせの素材に困って何度か生成し直しが必要だった
  • 30秒になると素材として使えるカットが多めに取れるので、カットでつなぐ映像がとても作りやすくなった
長い時間を一気に作れることの恩恵は、かなり大きいらしい！

渡せる素材が大幅増

  • 画像・動画・音声をまとめて渡せるようになった
  • 音声をリファレンスとして渡せるのは、リズム感を合わせたいBロールなどで活きる
素材の自由度が上がると、キャラの一貫性もキープしやすくなるね。

音源の下ごしらえ

  • 曲の元データと歌詞テキストをそのまま投げる。ボーカル / 伴奏に分離して、歌詞とタイムコードの対応表を作成（文字起こしもOSSツールにお任せ）
  • 対応表を元に、モデルごとの上限 — miniMAX H3は15秒まで・Seedanceは30秒まで — に収まるようフレーズの区切りが良いところで分割案を出してもらう
  • 歌詞の区切りなど調整したい点は、この段階で伝えておけばClaude側で調整
  • 音声の編集ソフトで波形とにらめっこする作業がまるごと不要に！

画像とカット済みの音源がそろったら、あとは生成を進めるだけ！

イントロを生成

  • 新搭載のSeedance 2.5で、まず冒頭のイントロ部分を生成
  • プロンプト追従性を確認するため、指示には少しの演技も入れてみた
  • 結果は微妙な仕草や表情まで再現。30秒生成のおかげで、使えるカットもたっぷり
まずはイントロから。できたら確認して、次へ進もう！

Bロールを生成

  • 間奏の差し込み用に、ギターパートをBロールとして生成
  • Seedanceには音源をリファレンスとして渡せる機能がある。演奏までは再現しないが、リズム感を合わせたいので伴奏だけを画像と一緒にアップロード
  • 注意点：プロンプトだけで照明を指示すると照明の雰囲気が変わってしまう。カットとしてつなげると違和感が目立つ
  • 対策：イントロ動画からスタジオが映っているスクリーンショットを1枚抽出して、照明のリファレンスとして一緒に渡す → 色味がそろう（スクショ抽出もClaudeに依頼）
自分でスクショを取る必要すらないのがスゴいところ…！

なぜBロールが必要?

  • 同じようなアングルが続くと、そのままつなげた時の継ぎ目がどうしても目立つ
  • 動画を延長して作らない限り、顔アップ → 顔アップのような似たカットの切り替わりでは差が生まれる
  • 対策1：映像の切り替えにBロールをはさむことで、つなぎ目をごまかす
  • 対策2：寄りのアングル → 次は引きのアングルなど、カメラが切り替わった演出でごまかす
  • ただしマイクとの距離・表情の違いから、一続きの映像としては人間が違和感を感じることも。うまく使い分けよう
映像を飽きさせない効果もあるよ。Bロールはマスト！

リップシンクは miniMAX H3

  • 歌唱パートはminiMAX H3を使用。リファレンスで渡した音源をそのままの音声で返してくれる
  • なので元の音源のままリップシンクが可能で、今回の用途に最適
  • マルチカットに対応。1回15秒の生成の間にカメラアングルを切り替える映像が作れる
  • H3は渡した音声をちゃんと聞いているので、歌詞のところでクローズアップ、高い音で目を細める・フレーズの間に微笑む、などの演出もプロンプトで聞く
  • 対してSeedanceは音源を渡すと全く別の音源になって帰ってくる（音声と映像を同時に生成する設計）。ここは次回モデルに改善してほしいポイント
「この歌詞の部分から生成」と指示するだけで通じるよ。分析が終わっていればね！

秒数のワナと仕上げ

  • H3にリファレンス音源を渡しても、結果の音声が変わってしまうことがある
  • 原因：音源が9.5秒だと、H3は最初から設けられた10秒の生成に合わせようとする。空いた0.5秒を埋めようと本来ない音を無理やり補完してしまう
  • 対策：半端な秒数の音源には、後ろに無音の部分を足して端数が出ないようClaudeに調整してもらう。これでかなり防げる
  • 仕上げは、残りのパートも同じ要領で生成して動画の編集ソフトに並べ、元の音源を上から重ねるだけ。作業のほとんどはClaudeがやってくれる
手間は減って、自分のクリエイティブにリソースをさける！
