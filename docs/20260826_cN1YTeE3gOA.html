つくる・はなす：創作と音声

① MiniMax Design

  • デスクトップ創作プラットフォーム。AIの製作チームを1つの司令塔から指揮
  • アイデアやブリーフを渡すと、メインエージェントが意図を読んでタスク分解＋モデル選択
  • コピー・画像・動画・ナレーションを4つの専属エージェントが並行制作
  • スクリプト・絵コンテ・動画・音楽・編集が1つのキャンバスに。ノードは自動で接続
  • チェックポイントで一時停止し、指示を仰いでから再開
  • ワークフローをスキルとして保存・再利用。人のスキルも導入できる
  • ローカルのファイルは手元に残り、プロ向けツールへ1クリックで書き出し
短編ドラマ・EC用のコンテンツ・広告に好適。MacとWinの両方で動くよ！

⑭ Vois 2.0

  • ローカルAI音声スタジオ。音声合成と処理が自分のマシンで完結
  • 文字数課金・クレジット残高・プライバシーの心配を解消
  • 100以上の自然な声。15秒ほどの音声から声のクローンも
  • 編集した行だけ再レンダリング。やり直しの収録は不要
  • SpotifyやApple向けのラウドネス調整を1クリックで
  • Claude・ChatGPT・Geminiとスキル連携し、スタジオを丸ごと任せられる
  • 定額で使い放題。データはPCの外に出ない
ポッドキャスト・朗読・動画やゲームの声当てをやっている人に刺さる一本！

⑦ Wispr Flow

  • 話した内容が整形されたテキストになって、どのアプリでもカーソル位置に出現
  • 「えー」などの埋め草や誤字は自動で編集済み
  • 人名や専門用語を個人辞書に登録。繰り返すフレーズは音声スニペット化
  • 100以上の言語に対応
  • Mac・Win・iPhone・Androidでネイティブ動作。設定は端末間で同期
  • Cursor・VS Code・Slack・メールの中でそのまま使える
一日中キーボードに向き合う人なら、入力が「話すだけ」になるのはかなり楽！
開発の現場を速くする5本

② Aloud

  • Macアプリ。話しながらアプリを回すと、コーディングエージェントが実行できる計画になる
  • 「あのボタン」みたいな曖昧な指示でエージェントを迷わせる問題を解消
  • 録画ボタンで声・画面・文字起こしを同時に記録（録画面は映らない）
  • 文字起こしを「実際に言いたかったこと」へ書き直し、言い直しや間は除去
  • 「これ・ここ」と言った箇所にはスクリーンショットを提案
  • タスクにまとめて、1つのファイルに。Claude Code / Cursor / Codexへドロップするだけ
  • 書き起こしはWhisperで端末内処理
エージェントに作らせる人への「口頭での指示出し」がそのまま通るようになる！

③ Checksum AI

  • CI/CDに並走して、テストを生成・実行・修復する継続的な品質のしくみ
  • 解決するのは「AIが書く方が速いのに、テストが追いつかない」問題
  • 対話型ではなくバックグラウンドエージェント。渡したら結果が返ってくる
  • 「200個のテストを生成」のような依頼に、本番で使えるPlaywrightコードで応える
  • 3つの担当：E2E（利用の流れ全体）／CI（変更ごと）／API（数千エンドポイント）
  • 画面の変化で壊れたテストは大半を自力で修復し、緑をキープ
コードは自分のものになるのがポイント。保守で溺れたいエンジニアはもういない…！

④ Shape

  • デザイン・コード・Git・AIチャットを1つのデスクトップアプリに
  • エディタ／デザインツール／GitHub／ターミナル／AIタブの行き来を解消
  • 高速なコードエディタ＋リポジトリの中で直接働くAIエージェント
  • 動いているアプリをコードを探さず視覚的に編集
  • ライブプレビューで変更がその場で見える
  • Tailwindとモダンな言語に最初から対応。Gitはエディタから出ずに管理
デザイナーとプログラマーの「1つの作業場所」がようやく現実になったね！

⑤ bitdrift

  • モバイルアプリ向けのエージェント型リアルタイム観測
  • 解決：ログを変えるだけでもリリースを約10日待つ必要があった問題
  • 軽量なRust SDK（iOS・Android・React Native）
  • 端末上のリングバッファにすべて記録し、送るかどうかはリアルタイムで判断
  • 必要なテレメトリだけ送信。ログ超過の課金もなし
  • 個人情報を見せない配慮付きリプレイで利用の流れを再現
  • 公開APIとスキルで、エージェントが自律的に調査
フリーズや無音の失敗も見える化。クラッシュの報告は無料から始められるよ。

⑨ Origin by Cursor

  • Cursorによるコードホスティング。リポジトリ・PR・エージェントを1か所に
  • 解決：コードとエージェントが別のツールにいて、文脈が失われる問題
  • codebaseタブでリポジトリを作り、CLIでpushするだけ
  • GitHub同期：GitHubを正として、リアルタイムに更新
  • 同期したリポジトリではコメントとレビューが双方向・数秒で反映
  • 全リポジトリにエージェント：見ているコードに質問→変更・PR更新・ブランチpushまで
  • 拡張でVercelのプレビュー、BuildkiteなどのCIと接続
「エージェントの数で働く」開発者向けの新しいおうち、という感じ！
チャットの中で働く3本

⑥ Zoho Cliq 7.0

  • 検索・ミーティング・自動化・AIを1つのウィンドウにまとめるチーム向けアプリ
  • 背後のAIモデルを自分で選ぶ：Claude / Gemini / ChatGPT / Cohere / Zia
  • 動画・音声・録音の要約や音声の書き起こし、社内の口調でのプロンプトも
  • ノーコードのD&Dでボットとワークフロー作成。webhookで外部とも接続
  • MCP対応＋LLM向けAPIで、ClaudeやCursorがCliqの中で実作業
  • ガバナンス：AI機能は既定でオフ、管理者の管理下に
  • 会議にはライブ字幕・要約・空き状況の表示が加わった
「モデルを選べる」のが新しい。社の規則に合わせてAIを使い分けられるよ。

⑬ Viktor

  • Slack / Teamsで働く「AI社員」。アプリ一覧から同僚のように追加
  • 解決：雇うほどでもない、でも自分でやるには重いタスクの山
  • クラウドに自分専用のコンピュータを持ち、コードを書いて実行
  • 調査から納品まで：レポート・ダッシュボード・コード・キャンペーンを届けてツールを更新
  • HubSpot・Notion・Linear・Stripeなど3,200以上のアプリと接続
  • 使い込むほど手順や好みを学習していく
  • 自律しつつ監視あり：承認ゲートと人ごとの権限で、元に戻せない作業は事前確認
「スレッドで頼んだら帰ってきた」が当たり前になる。少人数チームには強い味方！

⑰ Antibot

  • Discordコミュニティ向けのAIマネージャー
  • 解決：普通のボットが苦手な静かなチャンネルと、覚えきれないスラッシュコマンド
  • 3ステップで導入：名前・アバター・性格を選ぶだけ
  • メンバーはふつうの会話で話しかける。説明書いらず
  • モデレーション・アンケート・音楽・出どころ付きのWeb調査・これまでのまとめ
  • メンバーの興味や内輪ネタを記憶して、気のきいた様子づかい
  • 管理用の画面・日次のまとめ・自動スレッド化も装備
AIの利用はコミュニティで補充する共有トークンプール制。無課金でも大丈夫！
お客様と話すAI：営業とサポート

⑧ Fin（Intercom）

  • サポート・営業・ECを横断するAI顧客エージェント
  • 解決：人だけでは回らない24時間の問い合わせの波
  • Apexモデル：数十億件の実際のやりとりで学習
  • 多段階の問題を推論で解き、支払いや返金の処理まで実行
  • API・データ接続・MCPで生きたデータを取得して行動
  • 音声・チャット・メール・SNSに対応し、数十言語で運用
  • 課金は解決した会話ぶんだけ。公開前に変更をテスト可能
Zendesk・Salesforce・Freshdeskとも接続。「返信するだけ」を超えた対応ができる！

⑲ Clara AI SDR

  • 顔出しビデオのAI営業担当。サイト訪問者を商談につなげる
  • 解決：営業時間外やフォームでせっかくの見込みが冷めるロス
  • 訪問者にリアルタイムで応対し、業種・役割・ニーズに合わせたデモを放映
  • 意図を読み、良い質問で有望な見込みを判定
  • 自力でミーティング予約。主要言語で昼夜なく動く
  • 顔はアップロードか生成。資料・台本・FAQで育てて1日で公開
  • CRMと同期し、顧客情報と通話を記録。企業級のセキュリティ
反論への答えもばっちり。「価値」を軸に会話を続けるのが得意だよ。
知識と研究をまとめる2本

⑩ Cluing

  • チームのナレッジレイヤー。集めた文脈の上で、ホストされたエージェントを動かす
  • 解決：調べ物がタブ・ドキュメント・メモに散らばる問題
  • 見ている途中に1クリックで保存：ウェブページ・PDF・動画・SNSから出どころ付きで
  • どんなAIモデルやClaude Codeも、Cluingの基盤の上で動く
  • サイト・ダッシュボード・アプリを1クリック公開（自分のドメイン＋HTTPS）
  • 生きた文脈・動くスキル・暗号化された接続情報・タスクを1つの頭脳で共有
  • 役割ごと・モデルごとのアクセス制御つき
「文書」ではなく「文脈」を共有するのが新しい。調べたものがそのままチームの資産に！

⑮ Research AI

  • 再現できる科学ワークスペース。会話1つで研究の流れをエージェントが実行
  • 解決：チャットボット・Python・R・文献管理・検索・ワープロの行き来で再現性が壊れる問題
  • 文献の検索・データ取得・PythonとRでの統計分析・図表・執筆まで
  • どの段階も追跡と査読が可能
  • 隔離サンドボックスで実行。ファイルは非公開で、導入するソフトなし
  • 60の学術ソース：PubMed・Semantic Scholar・arXiv・臨床試験など
  • 表・図・学術的な文体を含むWord文書を出力
バイオ系を中心に、分野や言語にも合わせてくれる。研究者の「作業場所」が一つに！
組織と毎日を回す2本

⑯ Tines

  • AIエージェントと自動化のためのガバナンス付きワークスペース
  • 解決：個人アカウントで勝手に作られるシャドーIT（キーの露出など）
  • チームは自由に構築、ITとセキュリティは全体を見渡せる
  • アラートの仕分け・ITの展開・財務の承認・採用など機密性の高い業務を運用
  • 異常には修正案を提示。本番に出すかは人が決める
  • ベンダー非依存：モデルの実行場所も選べて、データは自分の管理下
「勝手に使うAI」を「見える化して正しく使うAI」に変える土台の道具！

⑪ Expert Chase 2.0

  • パーソナルAI「EYE」が毎日をひとつにまとめるアプリ
  • 解決：やること・カレンダー・メモ・食事・睡眠・習慣・家計・運動がアプリごとに散らばる問題
  • 実データから回答。汎用の返事ではなく、自分の世界に即した答え
  • アプリでできることはEYEが代行
  • Apple / Googleと接続（カレンダー・リマインダー・タスク・ヘルス）
  • 1つのサブスクでAI使い放題＋連携込み。iOS / Android
「あれ、どのアプリに書いたっけ…」から卒業できるかも！
エージェントを売る・買う：市場の2本

⑫ OmniVibe

  • 仕事・創作・学び・遊びの専用エージェントの市場
  • 解決：課題ごとに別々の道具を探し回る手間
  • 調査・ビジネス・デザイン・映像・金融・法務・開発と目的別に整列
  • 作業画面で複数エージェントとグループチャット。Slackで同僚に頼む感覚で分担
  • スタジオで自作エージェント：流れを組み立ててデータをつなぐだけ
  • 機械学習の知識なしで市場へ公開。利用はクレジット制
複数のAIに同じ作業を相談して、いいとこ取り…みたいな使い方ができる！

⑳ Taku AI

  • AIアプリ・エージェント・スキルをスタックに組み上げる市場＆ビルダー
  • 解決：良いAIの構成を見つけても実際には使わないまま終わる問題
  • 目標をふつうの言葉で伝えると、最適な道具をその場で組み立て（設定なし）
  • 良い組み合わせはスタックとして配布。相手はインストール不要で実行・アレンジ
  • 作り手は1回公開するだけで、動くたびに収益
「埋もれた名ワークフロー」がみんなの道具になる。良い循環が生まれそう！

⑱ Cherry Blossom

  • 自然言語から基板を設計するAIエージェント。言葉の仕様が「製造できるファイル」に変わる
  • 解決：難しい基板で破綻し、複雑さを人に押し戻す従来のAIツール
  • 物理・部品の選定・配置配線を端から端まで処理
  • 編集できる回路図・配線済みPCB・製造用ファイルを生成
  • DRC / ERC（設計・電気の検査）をクラウド上で毎回実行
  • 失敗はその場で見える。報告を鵜呑みにしなくて済む
  • ノートPCを閉じてもサンドボックスで実行継続
  • KiCadプロジェクト＋Gerber＋BOMで書き出し。閉じ込めなし
  • 既存の設計環境の上でも単独でも動く。従量課金で席あたりの費用なし
エンジニアにも趣味の人にも。「言葉で基板ができる」時代が本当に来た…！

選ぶときの視点

  • 手元で完結するか（データ・課金・プライバシー）
  • 逃げ道があるか：書き出し形式・既存ツールとの共存
  • 危ない作業に承認の工夫があるか（Viktor・Tinesがお手本）
  • 課金の形：定額・従量・解決したぶんだけなど様々
  • MCPやAPIで他の道具とつながるか
新しくても「出ていける道」がある道具をえらぶのが、結局いちばん安心！
