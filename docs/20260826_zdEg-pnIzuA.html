M6を解剖する

Apple初の2nm

  • M6はApple初の2nmプロセスチップ
  • トランジスタがより小さく、より密集
  • 電力を抑えながら性能が向上
「2nm」って…もうそんな時代なんだね！

12コアCPU

  • 2スーパーコア＋4高性能コア＋6高効率コア
  • マルチスレッドはM5比 最大1.2倍・M1比 最大2.4倍
  • シングルスレッドは世界で最速のCPUコア
速いのは当たり前、でも「世界一」はやっぱりすごい！

GPUとNeural Engine

  • 12コアGPU＋各コアにNeural Accelerator
  • デュアル16コアNeural Engine（合計32コア）
  • ピーク演算は前の世代比 最大2倍
M6 = 12C CPU | 12C GPU | 32C NE
      + Neural Accelerator / core
GPUの各コアまでAIの計算を手伝う設計なんだって！

AIの演算が進化

  • AIのピークGPU演算はM5比 約30%向上
  • M1比 8倍以上という進化
  • LLMのプロンプト処理が大きく高速化
生成AIの「待ち時間」が短くなるのは、地味に嬉しい！

  • プライバシーを守りつつ、デバイス上でLLMが動く
  • 学生・開発者・AI好き・企業の仕事など、幅広い層に向けた位置づけ
miniを置きっぱなしにして、AIに常に働いてもらう時代が来るかも！
M5 Ultraのすごさ

クアッドダイ＋UltraFusion

  • Appleシリコンで初のクアッドダイ構成
  • UltraFusionで2つのデュアルダイM5 Maxを接続
  • ダイ間は4.4TB/s以上、つながる密度は6倍
4つのダイが、まるで1枚のチップのように動くの、すごくない？

36コアCPU＋80コアGPU

  • 最大36コアCPU（12スーパーコア＋24高性能コア）
  • 最大80コアGPU＋32コアNeural Engine
  • AIのGPU演算はM1 Ultra比 6倍以上
M5 Ultra = 36C CPU | 80C GPU | 32C NE
          quad-die @ UltraFusion
スペックを見るだけで、飲み込めない量になってきた…！

512GBのメモリ

  • 最大512GBのユニファイドメモリ
  • 帯域幅は1.2TB/s（M3 Ultra比で50%高速）
  • 数千億パラメータのLLMを完全にローカルで動かせる
クラウドなしで、手元だけで巨大なモデルが動く未来がもうある！

メディアエンジン

  • H.264 / HEVCの専用HWを搭載
  • ProResのエンコードとデコードは4エンジン
  • AV1デコードにも対応
動画の編集をしている人には、たまらない仕様だね！
