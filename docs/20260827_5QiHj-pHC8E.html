中身はスパースMoE

アーキテクチャ

  • 総パラメータ 320B
  • 活性化 18B のスパースMoE（混合エキスパート）
  • 使う専門家だけを切り替えて動くから軽くて速い
GLM-5.3-Flash:
  total params   : 320B
  active params  : 18B  // sparse MoE
「大きな頭脳」を持ってるのに、動かすのはその一部だけ。だから安くて速いんだ✨

「端末の専有確保」はそうでもない説

テーマ2の主張

  • 問いは「どれだけ高価な端末を自分専用に確保できるか」
  • でも実はそうでもない、という説
  • ハイエンド GPU や最高スペックのサーバーを独占しなくても、実用のAI環境は作れる
  • 必要な設備は用途しだいで変わる

CPU＋量子化でも実用
