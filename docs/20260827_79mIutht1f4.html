Part 1 — スピーカーと思想

Anima Anandkumar の歩み

  • 20年以上AI研究に従事。深層学習が流行る前は確率モデルの理論を構築
  • Amazon Web Services でクラウドAIチームを共同創設、初のクラウドAI製品を開発
  • NVIDIA でAI研究部門の責任者を歴任
  • 現在は Caltech の Breene Professor（数学・計算機科学）
  • startup Accelerated Understanding を共同創業
  • UN（国連）の科学諮問委員会メンバーにも就任
大学と産業の〈両方の足〉で歩んだ経験が、理論と実践を結ぶ視点をくれた、という本人の弁。

AI for Science の核心

  • 言語モデルは仮説の生成に便利。しかしアイデアだけでは前進しない
  • 本当のボトルネックは検証 — 現実世界で本当に動くかの実証
  • 物理法則を保ち世界をモデル化 → Neural Operator
  • 定理やNNの主張を記号的に確かめる → Lean
  • 目指すのは〈保証つきのAI〉— 動作に確信が持てる科学AI
アイデアはもう十分あふれている。問われるのは「ほんとうに動くか？」の保証なんだ。

TorchLean — NNを形式検証

  • ニューラルネットを Lean 形式言語で記述する枠組み
  • PyTorchライクな書き心地で、定義から証明まで一貫して記述
  • CROWN など、保証つきロバスト性のアルゴリズムを実装
  • 学習と検証を同じ場で回せるのが最大の強み
  • 課題は規模 — LeanはまだCPUベースでGPUとの相性に工夫が要る

Lean でのイメージ

-- TorchLean で NN の層と性質を宣言
def layer (x : Tensor) : Tensor :=
  (relu ∘ linear W b) x

-- 「この層は摂動に強い」を定理として証明
theorem robust : ∀ ε ≤ 0.1,
  dist (layer x) (layer x') ≤ K * ε := ...
ネットワーク自身が「こう動く」と主張することを、数式として証明できてしまう。

制御ループを守る保証

  • 入力が少しずれても出力の変化を上界で押さえる
  • これは感度分析 (sensitivity analysis) とも呼ばれる
  • ドローンや原子炉の制御ループにNNを入れる場面で必須
  • 有限精度で学んだ影響（丸め誤差）も評価できる
  • 安全性・頑健性・安定性を制御系として包括的に設計
原子炉は「たぶん大丈夫」では動かせない。保証があって初めて制御に組み込める。

Part 2 — 中核技術：PINNからNeural Operatorへ

PINN の限界

  • Physics-Informed NN（PINN）: PDEを損失に入れ、毎回ゼロから解く
  • 時間依存の問題では最適化が非常に困難に
  • 乱流・カオスでは細かいスケールの影響が支配的
  • 「あらゆる時点でPDEを解く」景観は、手に負える形ではない
  • 物理制約だけに頼る発想の限界がここに現れた
もし最適化が常に成功するなら万能なのに…。でも現実の方程式は、そう甘くない。

Neural Operator とは

  • 関数空間どうしの写像（operator）を学習する
  • 入出力を「連続した関数」として扱う — 解像度の束縛を受けない
  • 推論時にはどんな解像度でも出力できる
  • 現実の世界は本質的にマルチスケール — 決め打ちは無理
  • 通常のNNは固定ピクセル。ズームするとボケて終わり
関数として表しているから、どこまでもズームできる。ピクセルの壁がないんだ。

データ × 物理のハイブリッド

  • Neural Operator は学習データで解答パターンを先に覚える
  • 最適化の袋小路にはまり込まない — 答えを知った状態で学ぶ
  • テスト時、未知の方程式インスタンスにも即答できる
  • 物理制約は損失関数として加える（厳密制約は現実的でない）
  • データ駆動＋物理の制約 — 両輪で初めて強くなる
PINN＝毎回一から問題を解く。Operator＝答え方を学んでから解く。この差が大きい。

ゼロショット超解像度

  • 学習データより細かい解像度でそのまま予測できる
  • 保存則などの物理制約を高解像度側で課して正則化
  • なめらかに高解像度へ延長するような推論になる
  • 粗い天気図しかなくても、細かい現象を読み直せる
  • 学習時の忠実度を超える精度での利用が可能
物理という〈補助線〉があるから、見たことのない細かさへも安全に伸ばせる。

Fourier Neural Operator (FNO)

  • Fourier空間で非局所な現象を効率よく捕捉
  • 流体・材料の変形・量子化学は、みな非局所の現象
  • 微分は局所、その逆（積分）は非局所 — 解は遠くとつながる
  • FFTにより準線形の計算量を実現
  • Transformerの2乗オーダーとの対比が効いている

層のイメージ

v ← v + W · σ( FFT⁻¹( R · FFT(v) ) )
# Fourier層 × 非線形σ × residual で
# 「全局つながり」を低コストで表現
シカゴの出来事が、やがてサンフランシスコに届く。空間にも時間にも、つながりを見る。

アーキテクチャの工夫

  • Fourier層のあいだに非線形性を挟み、表現力を担保
  • residual connection で深い学習を安定化
  • チャンネル空間への高次元リフティングで表現を豊かに
  • 基底を人が選ばず、学習で正しい基底を発見させる
  • 潜在空間 (latent space) でFourier変換すると、より効率的
古典的な数値解法は基底を固定する。深層学習は「最良の見方」を探すところから始める。

なぜ物理には別の模型か

  • 言語は1次元でもコンテキストは限界ぎりぎり
  • 物理は3D＋時間。各軸1000点で兆オーダーの文脈長
  • 画像・動画の模型は解像度が低く、見た目重視で精密でない
  • 流体・プラズマ・材料は高精細さが必須 — 落とせない
  • 天気の学習データは約5万サンプルどまり。言語とは桁が違う
  • だからこそ帰納の偏り（inductive bias）を設計に盛る
Transformerをそのまま持ち込むと、世界中の計算資源を集めても足りない計算になる。

Part 3 — FourCastNet が変えた気象予測

FourCastNet 誕生

  • ECMWF の再解析のデータ（ERA5）が公開されていた
  • 2021年、気象学者は「数十年の積み重ねに勝てない」と警戒
  • ところが精度は従来模型に迫るレベルで判明
  • スパコンが必要だった計算が市販のGPU1枚で
  • 数万倍の高速化 — 皆の考え方が一変した
  • 真っ先に寛容なライセンスで公開 → DeepMind・Huawei が1年後に追従
公開したから世界中の気象機関が築ける。南半球の小さな機関も同じ精度を持てるように。

極端気象と「寛容な物理」

  • ハリケーン Lee の上陸を数日早く正確に予測
  • 希少なイベントにも特有の物理的な署名がある
  • 構造があるから、少ないサンプルでも学習が成立
  • 1本の決定的な予測では不十分 → 確率で表す
  • 初期条件にノイズを加え、多数の軌道を展開（アンサンブル）
  • 上陸の確率からリスク評価へ — 高速だから大規模に実行できる
番組タイトルの由来: 物理世界は、こちらが思うよりずっと寛容で、構造を貸してくれる。

v2・v3 — 球面とアンサンブル

  • v1: 平面的な投影で短期予測にとどまった
  • v2: 球面の幾何を導入 — 長いロールアウトが安定
  • 矩形の仮定では数ヶ月で破綻していた（極域が難所）
  • v3: アンサンブル予測そのものを学習目的に最適化
  • 1ステップ6時間。学習は「次の6時間」だけ、あとは自己回帰で数ヶ月先まで
  • Allen AI が気候モデルへ応用 — 機能する唯一のAIエミュレータ
地球は球だ。たったそれだけの幾何の情報で、長期予測の安定が手に入る。

Part 4 — 核融合とさまざまな応用

核融合デジタルツイン

  • トカマク内のプラズマ（MHDの方程式）を模型化
  • 従来比100万倍の高速なシミュレーション
  • 英国の原子力機関 UKAEA との共同研究
  • サンプル数千点でも disruption を高精度に予測
  • 次の一手: 破局を防ぐ制御の設計を模擬内で完結
  • ステラレータなど別方式にも展開 — 「勝者」を決めつけない
実験は高価で危険。デジタルツインで設計まで一気に回せるのが大きな強み。

産業への応用いろいろ

  • 地下のCO2貯留: 圧力の蓄積と移動を数十年スケールで予測
  • 車・飛行機の空力: 潜在空間で形状をドーナツ型に変換して計算
  • 逆リソグラフィ: マスクの逆問題を設計
  • 量子ドットのゲート設計: 手作業の試行錯誤を超える効率
  • 順方向の物理＋逆問題の設計を同じ模型でこなす
  • 人は非線形な設計が苦手 — AIが物理のガードレール付きで最適化
車をドーナツに、ドーナツを車に。位相幾何の軽口が、そのまま実装の鍵になる。

Part 5 — ファウンデーションモデルと社会

物理の基盤模型へ

  • 単一物理の狭い代理模型から、マルチフィジックスへ
  • 熱伝導＋材料の変形など結合した現象は、少ない例で微調整可能
  • 逆問題: 「最良の設計は何か」を直接に問える
  • 物理というガードレール付きで設計を最適化
  • 現象をカリキュラムのように積み上げ、結合して学ばせる
  • 完全に未知の物理への転移は不可能 — ただ結合は現実的
言語には基盤模型があるのに、物理にはまだない。そこが次の大きな戦場になる。

UN 諮問委員会と提言

  • UN 科学諮問委員会の一員として、証拠に基づく提言を目指す
  • 「AI＝言語モデル」の一律の規制には異議 — 科学AIは別枠で
  • 世界中がAI研究にアクセスできる環境づくりを
  • 魔法をひとつなら計算資源 (compute) — 実験と革新の源泉
  • neuraloperator ライブラリで今日から体験可能（PyTorch生態系）
  • 天気・農業・食など、UNの現場機関との連携にも期待
言語モデルやエージェントは「外側の包装」にすぎない。物理を理解するAIこそ、まだ欠けている一片。
