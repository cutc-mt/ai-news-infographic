Descript とは？

テキストを編集するだけで動画が直る
  • AIで動く 動画・音声の編集ソフト
  • 普通の編集ソフトは タイムライン をいじる。Descript はそのまま 文字を編集 する方式
  • 録画を 文字起こし して、単語ひとつひとつと映像の一瞬を 同期 させる
トランスクリプト編集のイメージ
// 文中の単語を消すと…
今日は えーっと Descript の
新機能を 紹介します

// 「えーっと」の映像も一緒に消える！
文章を直す感じで動画が編集できる。発想の転換だね

Word が使えれば編集できる

初心者にもやさしい設計
  • Word 文書が扱える人なら、動画も編集できる――それが理念
  • トランスクリプトの単語を 削除 すると映像も削除。文を移動 すると映像も移動
  • はじめてでも 数分で最初のカット ができる
  • タイムラインは 微調整のため に、ちゃんと残っている
「動画の編集はむずかしい」という常識を、ふっとばしてしまう考え方

案内役は AIアバター

Pippa（ピッパ）がナビゲート
  • この動画では Pippa という AIアバターが進行を担当
  • Descript 自身の機能で AIアバター を使い、商品を実演しながら解説
  • 実際に 使っている様子 を見せることで、性能を実感できる構成
紹介している本人もAIで動いてる……のがもう「scary good」な見本かも

始めかた ① その場で録画

ツール内から直接撮る
  • Descript の ツール内でそのまま録画 できる
  • 録り終えると 数秒で文字起こし され、すぐ編集にとりかかれる
  • 撮る→文字がつく→直す、の流れが 一瞬でつながる
録画ボタンを押してから、編集を始めるまでの待ち時間がほぼゼロ！

始めかた ② 持っている映像を入れる

ドラッグ＆ドロップだけ
  • 撮りためた 既存のフッテージ をドラッグ＆ドロップで投入
  • 対応は Zoom 通話 や デスクトップの古い録音 など幅ひろい
  • 変換や移行は不要。入れるだけで文字起こしから始まる
「昔とったあの会議の映像、活かせないかな？」が、すぐ実験できる

Studio Sound

ワンクリックでスタジオ品質
  • ワンクリックで 背景ノイズを消して 声をくっきり強調
  • スタジオも高級マイクも不要。普通の部屋で収録してOK
  • 仕上がりは ブース収録のように 聞こえる
防音にお金をかけなくても、音だけはプロの現場っぽくなっちゃう

Filler Words 削除

「えー」「あの」を一括で除去
  • トランスクリプトをなめて 「um」「uh」「like」 をすべて検出
  • 見つけたら 一括で除去。ひとつずつ探す手間がない
  • 仕上がりは 自信のある話しぶり に聞こえる
言いよどみが消えるだけで、説得力がぜんぜんちがって聞こえるから不思議

アイコンタクト修正

カメラを見ているように見せる
  • つい画面やメモを見てしまう瞬間を カメラを見ているように 修正
  • 視線がそれていると 信頼感が落ちる が、これで解消
  • 撮り直さなくていいのが うれしい点
台本をちら見しちゃっても、視線はずっとお客様へのアイコンタクト……！

AI編集者 Underlord

ふつうの言葉で編集を指示
  • Underlord と呼ばれる AI編集者に、ふつうの言葉で指示
  • 音声クリーニング から フィラーワード削除、編集まで一式を搭載
  • 専門の用語や操作を覚えなくていいのが 最大の強み
Underlord への指示例
> この動画を 2分に短縮 して
> ジャンプカットを ズームで隠して
> SNS用に ベストクリップ を抜き出して
編集アシスタントに口頭で頼む感じ。操作マニュアルいらずなのが楽すぎる

Regenerate とは

言い間違いを、もう一度つくり直す
  • 言い間違えの部分を 音声ごと切り取る と、前後のトーンが合わなくなる
  • その隙間を AIが 再生成して自然につなぐ のが Regenerate
  • 再録は不要。これが「scary good」と言われる理由
切り取った穴を、声のつながりごとなおして埋めてくれる……恐ろしい

Regenerate の効果

トーン調整とノイズ除去
  • 平坦なセリフにエネルギー を与えられる
  • 外の 葉刈り機の音 や 犬の吠え声 もきれいに除去
  • 撮り直しの時間を まるごと節約
隣の庭で芝刈りが始まっても、もう撮り直さなくて大丈夫……！

Overdub

自分の声のクローン
  • 自分の声から 声のクローン をつくれる
  • 台本の タイプミスや単語の交換 をトランスクリプトに入力するだけ
  • 仕上がりは メールの文を直す感覚。自分の声で生成して挿入される
Overdub の流れ
// 文字を打ちかえるだけで…
価格は 五千円 → 価格は 三千円

// 自分の声で「三千円」が生成・挿入
文章を直すように声が直る。録音ブースに戻る必要がないんだよね

なぜ「恐ろしい」のか

再録の呪縛からの解放
  • 今までは 言い間違え＝撮り直し しかなかった
  • 今は 切り取って、AIに生成してもらう だけで直る
  • 「もう一回いく？」のやり直しループが ゼロになる
声まで作り直されちゃうと、「本物どれ？」って怖くなる……のが正直な感想

Underlord にできること

平易な言葉で何でも指示
  • 「2分に短縮して」――長さの調整をおまかせ
  • 「ジャンプカットをズームで隠して」――見た目の補正も言葉だけで
  • 「SNS用にベストクリップを抜き出して」――宣伝用の短い動画も生成
  • 台本を読み、動画を見て、退屈な作業を代行 してくれる
「短く」「目立たせて」「切りぬいて」……欲しい言葉を渡すだけの簡単お仕事

何度でもやり直せる

疲れない相棒
  • 気に入らなければ 何度でもやり直し を頼める
  • 人間の編集者だと気を遣う頼み事も、AIなら 遠慮がいらない
  • 夜ふかしの仕上げ作業も 根気よく付き合って くれる
「ごめん、やっぱ最初のやつで……」と言える相手がいるのは大きいよ

得意な動画

この4ジャンルに最適
  • トーキングヘッド動画――話しながら進める形式
  • チュートリアル――手順を解説する動画
  • ポッドキャスト――話し声を中心とした番組
  • SNS用ショートクリップ――短く切りぬく系
「喋り」が主役のコンテンツなら、ほぼ無双できる相手だね

苦手な動画

向かない場所を知る
  • 重厚なシネマティック作品 には不向き
  • カラーグレーディング のような映像の味つけも得意ではない
  • すなわち 速さ重視 の道具であり、映像を芸術に仕上げる道具ではない
道具は目的に合わせて選ぶ。映画の世界には別の専門ツールがいるよ

結論：摩擦を減らす

公開までのスピードが本質
  • 編集・クリーンアップ・再録は 「動画が死ぬ場所」 と呼ばれる
  • その摩擦を削って 公開までのスピード を上げるのが本質的な価値
  • 考えすぎず 撮って、直して、出す リズムを作れる
最高の機能よりも「途中で投げださなくなる」ことの方が、大事だったりする
