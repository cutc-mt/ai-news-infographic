第2部 ターミナルで走るエージェント

i-have-adhd

返事を「次の一手」から始めるスキル
  • エージェントの返信を 短く・動ける形 に作り変えるOSSスキル。前置きと水増しをやめさせる
  • 中身は 10個の平易なルール: まず行動を言う／手順は番号付き／末尾に次の一手ひとつ／脱線を切る
  • 毎ターン 現状を再掲、所要時間の見積もり付き、リストは5つまで、エラーは淡々と報告
  • 名前に診断は不要。Claude Code / Codex / Cursor / Gemini / Qwen / Kimi / OpenCode に対応
  • 導入はリポジトリを向けるだけ。スキル1ファイル をフォークして口調も調整できる
今まで「いい質問ですね!」から始まって、考え方を長々と…答えはその奥
これから「次にすること: ○○」が1行目。残りは番号付きの短い手順
賑やかな返事にうんざりしている人には、すぐ効く一品だよ

jcode

Rust製・記憶持ちの高速エージェント
  • Rust製 のターミナルコーディングエージェント。起動はほぼ一瞬、セッションを多く開けても軽いまま
  • 目玉は 自動メモリ: 各ターンを意味ベクトルで埋め込み、関係する過去の文脈をそっと呼び戻す
  • メモリ呼び出しをしなくても前の作業を覚えていて、過去セッション横断検索 もできる
  • スウォームモード: 1つのリポジトリで複数エージェントが連絡を取り合い、ファイル衝突を解消しながら編集
  • エージェントが自分で 子エージェント を呼んで並行作業。親子で分業できる
  • 手持ちのサブスクとAPIをそのまま使う: Claude / OpenAI / Gemini / Copilot のほか Ollama や LM Studio などのローカルも
  • 別ハーネス（Codex / Claude Code）で始めたセッションを 再開できる のも珍しい
  • 自分のソースを自分で編集・ビルド・再読込する 自己開発モード や、画面内ブラウザツールも搭載
# Linux / macOS / Windows / Termux で動く
$ jcode
> 自動メモリ: 前回の作業文脈を復元
> swarm: エージェント3台が並行で修正中…
「呼ばなくても覚えている」記憶が主役のエージェント。いくつ開けても軽いのもRustならではだね

herdr

エージェントを常駐させるランタイム
  • いつも使うコーディングエージェントを1か所に集めて 生かしたまま 管理するターミナルランタイム
  • 仕組みは エージェント向けターミナル・マルチプレクサ。壊れやすいタブではなく、裏で走るサーバーが端末を所有
  • サーバーが動き続けるので、蓋を閉じても・ネットが切れても・再起動しても エージェントは稼働中
  • 同じセッションを別の端末や SSH先 からつなぎ直せる
  • 各ペインに working / blocked / idle のラベル。止まって返事待ちのエージェントがひと目で分かる
  • Claude Code・Codex・Cursor・OpenCode・Grok を ラップせずそのまま 実行
  • エージェント自身がCLIとソケットAPIでペインを作り、お互いに指示を出し合う ことも
  • tmux風のキー操作とマウス対応、プラグイン市場も。単一Rustバイナリ・Electronなし（macOS / Linux / Windows beta）
「寝てる間にエージェントに仕事を続けてもらう」を実現する道具。朝すぐ状態を見られるのが良いんだ

AI Coding Assistant Data Extraction

10種の履歴をJSONLで書き出し
  • AIコーディング助手の ローカルの会話履歴 を取り出して、ひとつのきれいな形式にまとめるPythonツール
  • 各ツールは自分専用のDBに履歴を溜める。アプリが消せば 数年分が消える —— それを防ぐ
  • 対応は 10ソース: Claude Code・Codex CLI・Cursor・Windsurf・Trae・Continue・Gemini CLI・OpenCode・Klein（+Roo Code）・Aider
  • 書き出したデータは バックアップ・分析・モデルの学習 に使える
  • DBは 読み取り専用 で開くので動作中のエディタを止めない。壊れたファイルは飛ばして続行
  • 必要なのは Pythonの標準ライブラリだけ。macOS / Linux / Windows を自動で見つける
# 1会話 = 1行のJSONLで保存（マージも可）
{"ts":"…","assistant":"claude-code",
 "messages":[…],"diffs":[…],"tool_calls":[…]}
履歴は自分の財産。消える前に「よそへ出せる形」で持っておく発想は大事だよ

ai-memory

長期記憶とハンドオフの wiki
  • 課題: エージェントは セッションをまたぐと全部忘れる し、別のツールと学んだことを共有できない
  • これに 長期記憶 を与え、別ベンダーのエージェントへ 文脈ごとハンドオフ できるようにする
  • 使い方はローカルサーバー（多くは Docker、loopback限定＋データボリューム）。数コマンドでMCPサーバーとフックを導入
  • 以後、すべてのプロンプトとツール呼び出しを自動で記録。次に開くセッションには 「どこまでやったか」の引き継ぎ が見える
  • 記憶の正体は Git管理のmarkdown wiki。まとめ処理のたびにコミットが残る
  • 手で編集しても ウォッチャーが反映。全文検索＋グラフのリンク近傍ランク＋任意の埋め込み検索
  • 対象: Claude Code・Codex・OpenCode・Cursor・Gemini CLI。Rust製・ベータ版
# 記憶の置き場所イメージ
~/.ai-memory/wiki/
  ├─ project/xxx-app/handoff.md  ← 引き継ぎメモ
  └─ lessons/rust-async.md       ← 学んだこと
「Claude Codeで始めてCodexで仕上げる」みたいな乗り換えが、文脈を失わずにできるのが新しいんだ
第3部 つなぐ・まわす・支える

free-claude-code ＆ FreeLLMAPI

プロキシ2種でモデルを選び放題
  • free-claude-code: Claude Code と Codex を既定の課金先でなく、好きなプロバイダへ向けるローカルプロキシ
  • 各クライアントの話すAPI（Anthropic形式 / OpenAI形式）をそのまま受け、設定先へ転送。本体は書き換え不要
  • 対応は 18種: Nvidia NIM・OpenRouter・Gemini・DeepSeek・Mistral・Grok・Cerebras・Fireworks・Z.AI・Kimi・LM Studio・llama.cpp・Ollama など
  • Opus / Sonnet / Haiku の階層を 別々のプロバイダ に振り分けることも。設定はブラウザの管理UIで
  • FreeLLMAPI: 逆に「無料枠」の山を束ねる方向。多数プロバイダの無料枠を1つの OpenAI互換エンドポイント にまとめる
  • ルーターが各リクエストに 最良の空いているモデル を選び、規制に当たれば次へフェイルオーバー。キーごとの使用量も追跡
  • ツール呼び出し・構造化出力・画像生成・音声合成・複数モデルで答えを合成するfusion まで。ダッシュボードとデスクトップアプリ同梱
  • 位置づけは 個人の実験用。本番運用には向かないので注意
「高い階層だけよそに流す」「無料枠を串刺しにする」。両方向の省钱テクがひと目で分かる1枚だよ

OpenClaw

自前サーバーで動くAIアシスタント
  • 自分のデバイスで動く 個人用AIアシスタント。1人オペレーター向けで、データは手元に置きっぱなし
  • 中心は ゲートウェイ というローカル部品。セッション・ツール・イベント・チャネル接続をひとまとめに管理
  • チャネルで WhatsApp / Telegram / Slack / Discord / Signal / iMessage につながる。いつものチャット画面から話しかける
  • コンパニオンアプリと端末ノードが 音声・カメラ・画面・ローカル操作 を追加
  • ホスト型もローカルのモデルもOK。道具・スキル・プラグインで拡張（SDK＋ハブで共有）
  • 届いたメッセージは 最初は信頼しない 設計。知らない送信者はペアリングしてから動く
  • 導入はスクリプトか npm。ウィザードがモデル接続を確認。非営利財団 が公開開発
「うちのサーバー、うちの鍵、うちのデータ」。秘密を外に出さないアシスタント派の人にぴったりだ

Modular（Max + Mojo）

書く・走らせるを1つのスタックで
  • AIを書いて配るための 統合プラットフォーム。2つの部品から成る
  • Mojo: AIとシステム向けの言語。リポジトリにはコンパイラと標準ライブラリが入る
  • Max: 推論と加速の側。GPU/CPUカーネルのライブラリ、Pythonグラフで組むモデルパイプライン、推論サーバー
  • サーバーは OpenAI互換エンドポイント を出すので、いつもの標準クライアントから呼べる
  • ばらばらの道具を繋ぐのではなく、高速なAIコードを書き・モデルをサーブする のを1スタックで
  • 順次オープンソース化中。Apache 2.0（LLVM例外付き）、Maxの配布は別規約
「AIのために作られた言語」と「その実行基盤」が対で公開されていくのは大きい。続きに注目だね
第4部 学ぶ・探す・まとめる

ai-engineering-from-scratch

511レッスンでAIをゼロから
  • 511レッスン・20フェーズ のカリキュラム。線形代数と古典ML → 深層学習 → トランスフォーマー → LLM → エージェント → 本番まで
  • 流儀は 生の数学から組み立てる 方式。まず手で導き、それからフレームワークに触れる
  • 毎回同じ輪: 問題を読む → 数式を導く → コードを書く → テスト → 再利用できる成果物 を残す
  • 各題材は build-it（手実装） と use-it（PyTorchなど本番庫） の2段構え
  • 教材は Python / TypeScript / Rust / Julia で用意
  • 学習スキルを Claude Code / Codex に入れると 家庭教師モード: 到達度クイズ → 1セッション1レッスン
  • 成果物はプロンプト・スキル・エージェント・MCPサーバー。6冊の本 にも編まれ、Claude認定の無料準備トラック付き
「写経して終わり」じゃなく、毎回あとに残る部品を作る設計が秀逸。コレクションが資産になるよ

AI Job Search

Claude Code で転職活動を自動化
  • リポジトリをフォーク → プロフィールを記入 → /commands で運転。職歴データは全部自分のマシンに置く
  • setup: 文書フォルダ・貼ったCV・対話形式のどれかから経歴を作る
  • scrape: 求人ポータルを検索し、適合度つき で一覧。rank で短い一覧を構造化評価で一括採点
1apply: 適合度を評価し、LaTeXでCVとカバーレターの下書き
22台目のエージェントが企業を調査して 批評、それを受けて改訂
3PDFを コンパイルして目視点検。ATSでも読める体裁を確認（無い技能は捏造しない）
  • そのほか面接の準備・結果の記録・Notion / Gmail 同期・スキル不足の分析まで
  • 同梱の検索スキルは デンマーク市場 向けだが、自分の地域のボードに差し替えられる設計
下書き→批評→改訂の「二段構え」が人間臭い。経歴データが外に出ないのも安心ポイントだね

Plane

Jira 代替のOSSプロジェクト管理
  • Jira / Linear / Monday / ClickUp の代替 を目指すOSSのプロジェクト管理プラットフォーム
  • ワークアイテムは リッチテキストエディタ で作成。ファイル添付・サブプロパティ・関連issueどうしのリンクに対応
  • サイクル は期間ごとの進みをバーンダウン図で表示。モジュール は大きな企画を小さく割る
  • ビューは自由に絞り込み・保存・共有できて、大事なissueだけ に注目できる
  • Pages はAI支援つきのメモ置き場。アイデアを行動可能な項目へ落とし込む
  • アナリティクス画面は全データの リアルタイムの読み を見せる
  • Plane Cloud のほか Docker / K8s で自前ホスト も。Django + React + Postgres + Redis、AGPLライセンス
🌿
ヨモギ:「クラウドで使うか、自前で握るか」が選べるのがOSSの強み。縛られたくないチームに嬉しい一本だよ🍀

PostHog

製品分析をひと箱に詰めるOSS
  • 製品を作り・理解する道具を 1か所に詰め込む OSSプラットフォーム。別々のサービスを繋ぎ合わせなくていい
  • プロダクト分析（イベントと行動）・ウェブ分析（トラフィックと転換の画面）
  • セッションリプレイ で本物のユーザーの操作を再生して問題を診断
  • 安全に出すための フィーチャーフラグ、効果を測る実験、エラー追跡、ログ取り込み、ノーコード調査
  • データウェアハウス は Stripe や HubSpot と同期でき、製品データと並べて問える。変換・迂回のパイプラインも
  • AI観測は LLMのトレース・遅延・コスト を記録。self-driving は信号から調査レポートとPRを作って review を促す
  • 計装はJSスニペットか各種SDKかAPI。Slack・Web・デスクトップ、さらに MCP対応エージェント（Claude Code / Cursor） からも操作
  • 月次無料枠のあるクラウドか、Dockerで自前運用 かを選べる
分析・再生・フラグ・調査・倉庫…と、バラ買いしがちな道具が全部入り。「製品の持ち主」向けの万能箱だよ
第5部 生態系・安全・小道具

Claude Plugins Community

審査を通った公式プラグイン市場
  • Claude Cowork と Claude Code 用の 公式コミュニティ市場。GitHubでは読み取り専用ミラーとして公開
  • 動かすコードではなく 「厳選された一覧」。毎晩、Anthropic社内の審査の流れから同期される
  • 載るまでの道: 公式ページへ提出 → 自動セキュリティ検査 → 配布承認。すなわち「誰でも投げ込める場所」ではない
  • 導入: Cowork は製品のプラグイン画面から。Claude Code は 市場を追加して名前指定 でコマンドラインから入れる
  • ミラー本体へのPRは 自動で閉じられる。変更はすべて審査の流れを通る
「よく分からないプラグインを入れさせない」作り。生態系が大きくなるほど、こういう門番が大事になるんだ

AI-Infra-Guard

Tencent製・AI基盤の診断台
  • Tencent が作った、AI基盤・エージェント・接続された道具を検査する セルフホストの診断基盤
  • 運用は Dockerで立ててWeb画面 で操作。診断はプログラムからAPIでも起動できる
  • 稼働中のAIサービス（vLLM / Ollama / ComfyUI）を指紋照合し、既知のCVEと付き合わせる
  • MCPサーバーとエージェントスキル のリスク判定は、ソースでも遠隔URLでも可能
  • Dify / Coze 上で組んだエージェントの流れを評価
  • 設定したLLMエンドポイントへ ジェイルブレイク評価 を実行
「攻撃者に先回りして自分のAI基盤の弱点を知る」ための道具。AIを外に晒す人は一度通しておきたいね

AWSの最新2連弾

async SDK ＋ エージェント用プラグイン
  • AWS SDK for Python（awscrt流）: Boto3と違い サービス単位で配布。使う分だけ入れて軽く保てる
  • 設計は async向け。AWSへのリクエストがアプリの他の処理を止めない
  • 各サービスのクライアントは AWS APIモデルから自動生成 された個別パッケージ
  • Agent Plugins for AWS: Claude Code・Codex・Cursor にAWS専門知識を着せるプラグイン市場
  • 1プラグインに スキル + MCPサーバー + フック + 参照ドキュメント を同梱
  • サーバーレスの配備・DB設計・コード基地の文書化など 手順書つき。長い貼り付けプロンプトが不要に
  • MCPで 最新のAWS文書と料金 に接続。SAMテンプレートを編集後に検証するフックも
雲の巨大メーカーが公式でエージェント向けに回し始めたのが今回の本質。対応の速さに注目だよ

Sylva

25万本の苔が育つWeb風景
  • Three.jsで 苔に覆われた小道 が育っていく、編集デザイン風Webページのインタラクティブ作品
  • 全体が HTML1枚。モデル画像も事前レンダリングもなし。乱数の種から全部を実行時に生成
  • 根のアーチ・シダ・花・蛾、そして 最大25万本の苔 を instanced 描画でリアルタイムに
  • カーソルに合わせて苔が 割れて道を開け、花粉の跡を残す。まるで生きているみたい
  • 近づくと拡大するドック、場面の文字、2つの液体金属ボタン（WebGL2）も仕込み多数
  • ビルド不要、読み込み後は ネット通信ゼロ。ただし ライセンスは付与なし（鑑賞と学習用）
「1枚のページからどこまで作れるか」を見せてくれる参考作品。創作コードの指針にもなるんだ

Iris ＆ Wake ＋ まとめ

小粒2種で今週を締める
  • Iris: Rust製のスクリーンショットCLI ＋ MCP。本物のChrome系ブラウザをDevToolsプロトコルで駆動する
  • フォント・画像・アニメが 落ち着くまで待って 撮る。全画面・モバイル・CSS指定の要素、URLの一括撮影に対応
  • MCP経由なら エージェントが撮影を1回呼ぶだけ。作った画面の視覚FBをその場で受け取れる
  • Wake: macOS向けのネイティブアプリ（Rust + GPU UI）。散らばったエージェントの セッション履歴を1つの窓に
  • Claude Code・Codex CLI・OpenCode・Kira・Gemini CLI のデータを読み取り専用で収集。SQLite全文検索（日本語もコードも）
  • 当たったメッセージへ飛んで、1クリックで元の作業フォルダから再開。スター・書き出し・削除も
  • 記録は独自DBに保存、ネット通信はゼロ
