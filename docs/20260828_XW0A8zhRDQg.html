第1部 Descript という道具

文字を消すと動画も消える

Descript の考え方
  • 動画を読み込むと、まず中身が 文字 におきかわる
  • 文章の一文を消すと、その部分の 動画も一緒に消える
  • 段落を動かせば、動画の切れ端も 同じように動く
  • 初めて使うと「不思議だけど便利」と感じる仕組み。この部分は昔から変わらず
「5つのメニューを順にクリックして…」という単調な作業が、どんどん自動に置きかわっていくのが今回の流れだよ

今回の3つの新機能

数ヶ月ぶりの大きな更新
  • カットの 飛びをなめらかに なおす Regenerate
  • 絵を 描くだけ で写真の一部を編集できる機能
  • YouTube の サムネイルを自動で作る 機能
  • すべて自分の動画でその場から試して、結果を見せてくれる
この中に「え、そうくる?」と本当に驚いた部分がひとつあったんだ。それは最後のお楽しみ

AIの相棒 Underlord

編集のお手伝いAI
  • Descript の編集する画面に組み込まれた AIヘルパー
  • 考え方は「隣に 編集をお手伝いする人 が座っている」のと同じ
  • 5つの道具を1つずつクリックして回る必要がなくなる
  • 人に話すように普通の言葉で「こうして」と頼むだけで動き出す
ここ数ヶ月で 頭がよくなり・速くなり・操りやすく なったのが下地になっているよ

難しい仕事とAPIの公開

外への連絡口が開くと、道具と道具を組み合わせられる幅が一気に広がるんだ

大きな案件でも使いやすく

  • 過去の会話を覚えている。案件を開き直しても 最初からやり直し ではない

ここまでが静かに続いていた「下積み」。ここからが8月5日の本番だよ
第3部 8月5日に届いた新機能

ジャンプカットをなめらかに

今回いちばんの目玉: Regenerate
  • 話し動画でミスをカットすると、頭の位置や手が 急に飛んで 見える
  • 音がつながっていても、見た目は 「壊れた」印象 になってしまう
  • Descript はこの問題のために Regenerate を作り直した
  • カットした場所の 映像・音声・またはその両方 を、その場でなめらかに
これまで カットの跡が「ガクッ」と飛んで見えた
これから つなぎ目がやわらかく、自然な動きにととのう
話し動画の悩みトップクラスの「カットの飛び」。これをワンクリック圏内に持ってきたのが今回の目玉だよ

実際に試した手順

誰でも同じテストができる
1同じ文を2回、少し違う言い方で わざと録画 する
2文字の上で先頭の分を消す → 明らかな飛び ができる
3その編集点をクリックして Regenerate を選ぶ
4音声と映像の両方 をなめらかにするよう指定
5かたい切り替わりがやわらいで、自然なつなぎ になった
このテストは自分でも再現できる。まずは短い動画で試してみるのがおすすめだよ

Regenerate の注意点

先に正直に伝えておく話
  • 今のところ 英語のみ の対応
  • 1回でなおせる長さには 上限 がある。小さなつなぎ目向けの道具
  • 2人以上が交互に話す 場面はまだ苦手
  • Bロールを多用する場面や、複数シーンの複雑な流れ も苦手
「全部なおる魔法」ではなく、小さな飛びをきれいにする道具。使いどころを理解して使おう

描くだけで直る写真

編集ソフトがまさかの進化
  • 写真の中のいらないものを 大まかに丸で囲む だけ
  • 「こう変えて」と 文章で書き込む と…
  • 囲んだ部分だけが編集されて、他は手つかず のまま
  • テストはデスクの写真: ノートPCの横のコーヒーマグを消す注文 → マグだけきれいに消えた
  • サムネイルや簡単な画像を作るときの 時短 に
わざわざ別の画像ソフトを開かずに済むのが、地味にうれしいポイントなんだ

サムネイルを自動で作る

編集中にその場で生まれる
  • 作りたい感じを言葉で説明: 太い文字・色のテイスト・雰囲気 など
  • YouTube の画面サイズに 合わせた画像 を生成してくれる
  • 「見やすくて対比のはっきりした、短く力強い見出しで」とお願い → 数秒で使える画像 に
  • よそのソフトは 不要
サムネイル作りって毎回の重労働。それが数秒は、本当に大きいよ

最後の設定は自分で

ここは喜びすぎ注意
  • 画像までは作れるが、YouTube への 自動アップロードはしない
  • 完成した画像は YouTube Studio でいつも通りに設定する
  • 位置づけは 「速くデザインを生み出す道具」
  • 公開まで丸ごと代行する仕組みではない
「サムネを作る」と「公開する」は別の仕事。最後のひと押しだけは自分で、という話だよ
第4部 地味だけど効く更新

Underlord に的を渡す

大きな案件での改善
  • 「どの部分を見るか」を 自分で指定 できるように
  • 特定のシーンやファイルに 集中 して動いてくれる
  • 長いタイムライン全体で、AIが意味を 当てずっぽうで探す 必要がなくなった
  • 過去の会話も残るので、数日後に開き直しても 最初からではない
長い動画では「どこの話?」をはっきり渡すだけで、仕事の精度が上がるんだ

AIが自分の仕事をチェック

編集のあとの自動レビュー
  • 編集が終わると 自分の仕事をふり返る 工程が入った
  • 頼んだ範囲を 超えていないか を確認
  • お願いの内容に 漏れがないか も確認
  • 完璧ではないが、人が見る前に もう一段 チェックがある状態に
まるで「セルフ採点」を先にやってくれるようなもの。見落としが減るのは助かるね

「えーと」消し、5つの言語に

フィラーワード除去が広がる
  • 「えーと」「あー」のような フィラーワード を自動で消す機能
  • 今回、対応が 5つの言語 に広がった
  • それまでは英語のみ。いろんな言語で作る人 にも届いた
スペイン語 ドイツ語 フランス語 ポルトガル語 イタリア語
今回の更新でいちばん静かだけど、多言語で作る人には一番大きかったりするんだ
第5部 速さの改善とまとめ

スクロールが2〜5倍速く

タイムラインが軽くなった
  • タイムラインの スクロールが高速 に
  • 速くなったのは公式の社内テストで 2〜5倍
  • 長い動画の編集での ストレスが減る
  • 派手さはないけれど、毎日さわる部分 の改善
編集の快適さは「待ち時間の少なさ」できまる。この改善は使えば使うほど実感できるよ

こんな人に効く更新

いちばん得するのは話し動画の人
  • カメラに向かって 1人で話すクリエイター
  • 知識を教える立場の コーチ など
  • 自分で動画を作る 事業主
  • 「ミスをカットして、サムネイルも自分で作る」人ほど 効果を感じやすい
話し動画の「飛び」と「えーと」を、ひとつの道具でまとめて面倒を見てくれる。対象はかなり広いんだ
