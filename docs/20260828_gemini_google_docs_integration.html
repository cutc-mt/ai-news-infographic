【神アプデ‼】「Gemini」が「Google Docs」に完全統合

AIエージェント化で、ドキュメント仕事ががらりと変わる ／ mikimiki web スクール（みき先生）が解説

2026年8月28日 ｜ 動画の内容をグラレコ風にまとめました

セクション1｜まず、全体像をつかむ
1

今回のニュース

  • Geminiが Google Docs に統合される神アプデ
  • サイドパネルのアシスタントから、自分で動くエージェントへ進化
  • ドキュメント作りがDocs の中で完結
  • 手順がぐっと減って、業務の速さが変わる
「Gemini アプリで作って、あとで Docs に移す」…その手間が、なくなるんだ！
2

進化は7つのポイント

  • 立ち位置: アシスタント → エージェント
  • 参照範囲: プロンプトのみ → ワークスペース全体
  • 資料の渡し方: コピペ → 直接 添付
  • フォーマット: 説明 → お手本1つ
  • 表の再現: 毎回指示 → ボタン1発
  • 既存資料の修正: 作り直し → 差分つき承認
  • 画像: 自分で探す → その場で生成
このあと、ぜんぶ Before → After でくらべていくよ！
3

進化① 立ち位置

Before サイドパネルで質問にこたえるアシスタント
After 必要な資料を自分で取りに行くエージェント
  • 待っているだけでなく、自分から動く存在に
  • 「何を渡すか」より「何がいるか」を伝える時代に
聞かれたことだけ答える子が、自分で資料棚へ取りに行く子になった、という感じ！
4

進化② 参照範囲

Before プロンプトに書いた内容 のみ
After ワークスペース全体（Google ドライブ）を読み込める
  • ドライブ内の資料を、そのまま参照できる
  • 自分の手持ち資料ぜんぶが、AI の引き出しになる
ここが今回の最大のヤマ。他のAIにはまねできない強みにつながるよ（カード17へ）！
セクション2｜7つの進化を Before → After で見る
5

進化③ 資料の渡し方

Before 本文をコピペして貼り付け
After ＋マークでドキュメントを直接 添付
  • 長文のコピペ作業から、おさらば
  • ファイル指定だから、精度もそのまま上がる
チャットにファイルを添付する感覚で、そのまま渡せるようになったんだね。
6

進化④ フォーマット再現

Before 形式を文章で長々と説明
After お手本ファイルを1つ渡すだけ
  • 「見出しはこう、箇条書きで…」という説明が不要に
  • お手本どおりの形で、アウトプットが出てくる
「この資料と同じ形でね」のひと言で通じるのは、楽すぎる…！
7

進化⑤ 表の再現

Before 毎回、列や行を細かく指示
After ボタン1発で表を再現
  • 表の形がくずれず、きれいに反映
  • 指示ぜんぶが、ワンクリックにまとまった
表づくりって地味に時間がかかる作業だから、これはうれしい進化だね。
8

進化⑥ 既存資料の修正

Before 気が変わると全部 作り直し
After 変更箇所を1件ずつ提示 → 承認して反映
  • diff 形式で、どこが変わるか見える
  • 自分が OK したものだけ、反映される
# Gemini が提示する変更イメージ（diff）
- 売上目標: 1,000万円
+ 売上目標: 1,500万円
  期間: 2026年度 上期
→ 承認ボタンを押すと反映される
書き換えは勝手にやらない。人間が押さえてから、が新しいルール！
9

進化⑦ 画像の挿入

Before フリー素材サイトを自分で探して挿入
After ドキュメント内で画像生成
  • タブを行き来せず、その場で挿し絵がつくれる
  • 素材探しの往復がなくなって、作業が途切れない
しかも一括生成できるから、しごとの使い方が変わるレベル（カード13で詳しく）！
セクション3｜見た目の変化と、実演6例
10

UI の変化

  • ドキュメントの下に Gemini マークが表示
  • サイドパネルを閉じても、使える
  • マークにカーソルを合わせれば、そのまま入力できる
  • 編集画面をせまくせず、広々使える
「パネル、開けっ放しにしなきゃ…」という気づかいが不要になったのが地味にでかい！
11

実演① 過去資料からマーケ資料

  • ドライブの3つを参照: 企画書 市場調査レポート キックオフ資料
  • A4 約23ページの資料が、わずか1分で完成
  • 手順が減り、Gemini アプリで作って Docs で開く必要なし
# こんなふうに渡すイメージ
＋ 企画書
＋ 市場調査レポート
＋ キックオフ資料
→ この3つを参照して、
   マーケティング資料をつくって
過去の資料3つを渡すだけで、23ページが1分。もはや魔法に近い…！
12

実演② お手本から新リリース

  • プレスリリースを1つ、添付
  • 同じ形式のまま、新商品のリリース文をつくらせる
  • 進化④のお手本渡しが、そのまま効く実例
社内の「いつもの書式」がある職場では、これがいちばん効きそうだね。
13

実演⑥ 挿し絵を一括生成

  • 記事の10案それぞれに、モチーフを指定
  • 条件は3つ: 柔らかいフラット調 文字なし 横長
  • 一気に10枚生成、ドキュメント内で完結
  • クオリティはナノバナ級との評価
素材サイト巡りがゼロになって、記事づくりの帰り道が一気に短くなった！
14

実演まとめ: 6例をふり返る

#じつ演効く進化
1マーケ資料を1分で②④
2お手本の新リリース③④
3〜5そのほかの活用例③〜⑤
6挿し絵10枚を一括生成⑦
  • 全部の共通点: Docs の中で終わる
どの例でも「別アプリへ移動」がない。これが統合の本質だよ。
セクション4｜使う条件と、この先の話
15

使う条件: 個人

  • 個人で使うなら、Google One AI拡張プラン（AI Premium）に加入
  • 月々の定額で、Gemini の高度な機能が使える状態に
まずは自分のアカウントで、この統合が届いているか確認してみよう。
16

使う条件: 法人

  • 会社で使うなら Google Workspace を利用
  • 職場のドライブ資料がそのまま参照対象に
社内のナレッジを丸ごと引き出せるので、組織こそ効果が大きいかも。
17

他のAIにない強み

  • Google ドライブのデータを直接 参照できる
  • 自社データとの接続が、はじめから組まれている
  • この土台を持つのは、Google ならではの強み
どうやって資料をAIに渡すか…で悩む時間ごと、ゼロにできるのが強い！
18

  • 作成も修正も、ぜんぶ Docs の中で
  • ドライブ参照は、他AIにはない強み
