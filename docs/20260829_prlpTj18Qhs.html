なぜ サブスク2冊目?

発想のスタート地点
  • Claude Code や Codex を契約中でも
  • outer loop（外側のループ）や日常の自動化に
  • メインのトークンを使うのはもったいない
  • 安いサブスクを1本持っておくと、試しが気軽に動ける
「本命は温存、ザル用は別に持つ」。エンジニアの財布にやさしい考え方だね。
CommandCode「GOATプラン」— 月$10の実力
4

GOATプランとは

月$10 のサブスク
  • 料金は 月$10。手が出しやすい価格帯
  • 目玉は新モデル DeepSeek V4 Flash
  • 5時間あたり 18,200リクエスト も使える
  • まさお氏いわく「プロプランよりお得に見える」
「GOAT（最強）」の名に恥じない、リクエスト枠の大きさが最大のウリだよ。
5

リクエスト数を比べる

5時間あたりの使える量
CommandCode GOAT DeepSeek V4 Flash が
18,200リクエスト/5時間
OpenCode 5 場面により約7,600リクエスト制限の枠あり
≈ 2.4倍 の余裕
  • 会社によってモデルの利用可能量が違う
  • 同じモデルでも、どこで契約するかで使い勝手が変わる
枠が大きい = 検証やバッチ処理を気にせず回せる。開発者にはうれしい差だね。
6

モデルごとの差がある

ぜんぶが増えるわけじゃない
  • DeepSeek系は OpenCode 5 だと少なめ…
  • CommandCode ならたっぷり使えるモデル
  • GLM 5.3 Flashは OpenCode 5 と比べても圧倒的ではない
  • 「どのモデルをよく使うか」で選ぶ会社が変わる
得意モデルがサービスごとに違う。自分の常用モデルで比べるのが正攻法だよ。
7

キャンペーンがすごい

今だけのおトク枠
  • MiniMax M3 がキャンペーン中は無料で使える
  • Qwen（クエン）系モデルが 99%オフの枠あり
  • Gemini Flashも提供あり（期間限定 50%オフ）
  • おトク枠は期間限定なので、チェックの価値あり
無料と99%オフが同時にあるのはかなりレア。試すなら今がチャンスかも!

10

好きなハーネスに組み込む

APIキー提供タイプ
  • CommandCode はAPIキー提供でも使える
  • Claude Code に「ベンダー登録して」と依頼すれば…
  • 自分のハーネスのモデル一覧に並べてくれる
  • まさお氏はパイプラインエージェントに実際に組み込み済み
  • 専用CLIの cmd も存在（今のところ使う予定なし）
# 任意のハーネスへ組み込む手順
1) CommandCode の APIキーを取得
2) Claude Code に依頼:
   「このベンダーを登録して」
3) GOATプランのURLとキーを渡す
4) モデル一覧に追加されて 完了!
専用ツールを覚えなくても、いつもの作業場にそっと並べられるのがいいね。

B.AI とは

登録だけで使える無料API
  • 動画のコメント欄で教えてもらったサービス
  • 登録すると 6モデルが無料で使えるAPI
  • 期間限定の Limited Time Free 枠
  • ここまで無料で開放するサービスは今は少ない
視聴者からの情報も動画のネタに。コメント欄も要チェックだね。
12

無料ラインナップ

6モデルを無償で
  • DeepSeek Flash — 速い新モデル
  • Hy3 — 話題の系列モデル
  • なんと GLM 5.3 Flash まで無料で使える
  • 計 6モデル を0円で試せる太っ腹ぶり
GLM 5.3 Flash が無料って…! 課金できない人には神対応だね。
13

制約をおさえておく

無料の代わりのルール
101分あたりリクエスト上限
6無料で使えるモデル数
  • 1分間に10リクエストまでの制限あり
  • モデルを切り替えても枠は共有・解除されない
  • 連続バッチよりこまめな確認向きの使い方
レート制限さえ守れば、お試し検証には十分すぎる内容だよ。
他サービスとの比較 — 位置づけを整理
14

Z Code（ZAI）

無料 GLM 枠の先行例
  • ZAI の Z Code で GLM 5.3 Flash が無料
  • ただし使える量は少なめ
  • B.AI と近い発想の無料GLM枠という立ち位置
「無料でGLM」はZ Codeが近い例。量を求めるならB.AI、かな。

ClinePass は不透明

情報が見えにくい課金枠
  • どのモデルがどれだけ使えるか明記されていない
  • まさお氏は契約はしていないとのこと
  • 条件が見えないと比較しづらい、という判断
使える量が書いてあるかどうか。サブスク選びでは意外と大事なポイントだね。

OpenCode 5 の役割

手放すのではなく使い分け
  • 新モデル検証の「まず試す場所」として常用
  • ただし今回の2選を見て、GOATプランの方が好きになった
  • Hy4 のように両方に載るモデルも登場
  • 棲み分け:検証は OpenCode 5、常用は GOAT へ
敵味方じゃなくて、用途ごとに持ち替える。それが今の最適解っぽい。

GOATプランの結論

月$10 のコスパ
  • 月$10なのにプロプランよりお得に見える構成
  • 週末開発の人に最適な価格と枠
  • 節約気味にいきたい人にもちょうどいい
  • 18,200リクエスト/5時間 ＋ 130 TPS の快適さ
「安いのに速い、枠も大きい」。三拍子そろった今旬のプランだね。
