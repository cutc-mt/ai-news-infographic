Apify + AI Agents Is an Automation Cheat Code

セクション1: まずは基本を おさえる
01

①そもそもApifyとは？

  • Webスクレイピングと自動化のためのクラウドプラットフォーム
  • 重いインストールは不要。ブラウザーからすぐ使える
  • 夜通しPCを付けっぱなしにする必要もない
  • 裏でせっせと雑務を処理してくれる
クラウドインストール不要自動化
面倒な裏方仕事を、まるごとおまかせできる道具です！
02

②Actor（アクター）のしくみ

  • クラウド上で動く小さなプログラム
  • URLやキーワードを入力ボックスに入れる
  • お使いに行くように、1つの仕事をしてくれる
  • 整理されたきれいなデータを返してくる
  • Runを押すだけで起動する
  • ノートPCを閉じて放置しても、動き続ける
RunActor放置OK
入力して Run を押すだけ。あとはノートPCを閉じて待つだけです！
03

③構造化データへの変換

  • ページの文字をただコピーするのではない
  • 散らかったWebサイトを、読み取り可能な形に変換
  • きれいな行とフィールドに整理される
  • 普通のWebページが、いつでも取り出せるデータソースになる
構造化行とフィールド
散らかったページが、そっくりそのままデータの山になります！
04

④内蔵プロキシでブロック回避

  • 頻繁なアクセスをブロックするサイトもある
  • 回転プロキシが別々のアドレスからアクセスする
  • 通常のトラフィックに見せかけて、すり抜ける
  • 設定は不要。内蔵されていて勝手に動く
回転プロキシ設定不要ブロック回避
難しい設定ゼロで、ブロックをうまく回避してくれます！
セクション2: 保存・通知・連携の 部品たち
05

⑤Dataset（データセット）

  • 実行結果の保存先
  • 賢いフォルダーが、Actorが取得したすべてを受け止める
  • JSONCSVExcelHTMLなど好きな形式でエクスポート
  • 表計算で使うならExcel
  • 他のツールへ渡すならJSON
形式を選べば、好きなツールにそのまま渡せます！
06

⑥スケジューリングで自動実行

  • 毎朝・毎週など、好きな間隔でActorを自動実行
  • 一度スケジュールを設定するだけでよい
  • 寝ている間にApifyが処理してくれる
  • 起きたら新しいデータが届いている
毎朝毎週自動実行
朝起きると、新しいデータがもう届いています！
07

⑦Webhookで完了を通知

  • 実行完了時に、別のアプリへ知らせる小さなalerts
  • 「データの準備ができた」と通知を送る
  • 手を上げなくても、フローが回り続ける
Webhook通知
完了を自動で知らせて、次の処理へバトンを渡します！
08

⑧APIでどこからでもアクセス

  • すべてのActorとDatasetは、APIで到達可能
  • 他のアプリから実行を直接トリガーできる
  • 簡単なリクエストでデータを取り出せる
  • スクレイプしたページが独自のデータフィードを持つようなもの
APIリクエストデータフィード
取ったデータが、そのまま生きたフィードになります！
