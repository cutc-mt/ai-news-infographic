Claude Code Plugins Directory

プラグインを1コマンドで
  • Anthropic公式とコミュニティの Claude Codeプラグイン を1つのディレクトリに集約
  • 1コマンド でインストールが完了する手軽さ
  • メタデータの 標準構造 でプラグインの情報を統一
  • リネームマップ でリポジトリ名が変わっても名前を固定
探して、入れて、すぐ使う。プラグインの共有がぐっと楽になったね。

God's Eye View

公開フィードだけで作るライブ地球儀
  • 公開データフィードだけを使った ライブ3D地球儀
  • OpenSky ・AIS・USGS などのフィードを統合
  • CesiumJS と Google 3D Tiles で地球を描画
  • OpenAI リアルタイムAPI の音声エージェントがカメラ操作や注釈を担当
話しかけるだけで視点が動く。音声AIがナビゲーターだよ。

Tailcat

Tailscale網を流れるNetcat風トンネル
  • Tailscale のネットワーク上で動く Netcat風トンネル
  • アカウント不要で 暗号化P2P接続 ができる
  • derpリレーから WireGuard直接接続 へ自動的にアップグレード
  • TCPポート転送 ・SSHサーバー・SOCKS5プロキシ に対応
# 接続のイメージ[mac] ⇄ (derp relay) ⇄ [vps]
        ↓ 自動アップグレード
[mac] ⇄ WireGuard P2P ⇄ [vps]
「リレー経由 → 直接接続」への切り替えが自動なのがミソ!
4

LiveKit agents

リアルタイム音声エージェントのPythonフレームワーク
  • リアルタイム音声AIエージェントを構築する Pythonフレームワーク
  • STT・LLM・TTS ・リアルタイムAPIを 1セッション に統合
  • テレフォニー に対応していて、電話越しのbotも構築できる
  • MCPツール と LLM judge によるテスト機構を搭載
音声の往復をまるごと1本に。開発者は会話の設計に集中できるよ。
開発の基盤をつくる — Platforms & Frameworks

Modular Platform

Max と Mojo の統合コンパイラ/ランタイム
  • Max Framework と Mojo言語 を束ねる統合コンパイラ/ランタイム
  • Pythonのまま 高性能を引き出せる
  • 研究コードと本番インフラの ギャップを埋める 設計
研究コード 試行錯誤が早い。でも本番に持ち込むのが大変。
本番インフラ 安定・高速。でも書き直しのコストが高い。
ノートでの実験がそのまま本番に届く。研究者にはうれしい設計だね。

Munder Difflin

仮想オフィスでエージェントが協調
  • Claude Code・Codex・Grok・Gemini CLI を 仮想オフィス で協調させる Electronアプリ
  • 2Dオフィスフロア で誰が何をしているかを可視化
  • gitベースFS でエージェント同士が通信する
  • オーケストレータ がタスクを割り当てる
オフィスを眺めているだけで、エージェントの作業がひと目でわかる。

Needle 2

わずか14MBのツール呼び出し特化モデル
  • 工具のように持ち運べる ツール呼び出し特化 の小型モデル
  • バイトレベル文法 でトークン出力を制約
  • オフライン動作 ・LoRAファインチューニング ・信頼度スコア 付き
14MBモデルサイズ
28MBRAMで動作
GPU不要・オフライン
モデルが自分の「手のひら」に収まるサイズ。組み込み先を選ばないんだ。

Kaneo

最小主義のセルフホストJira/Linear代替
  • 最小主義で セルフホスト できる Jira/Linear代替 のタスク管理
  • React + Hono + TypeScript のモダンな構成
  • Docker Compose / CLI / K8s Helm に対応
  • 公式 MCPサーバー でClaudeなどがタスクを直接操作
# 連携のイメージClaude / Codex ⇄ MCP server ⇄ Kaneo tasks
「Claude、このタスクを進めて」がそのまま通る。MCP経由で直接動くのが強いよ。

ego-lite

人間とエージェントが同じブラウザを共有
  • 人間とAIエージェントが 同じブラウザ を共有する macOSアプリ
  • エージェントごとに 隔離スペース を用意（ログイン・Cookieを保持）
  • snapshot / fill / click / navigate を JS関数 で公開
  • Claude Code・Codex・Cursor と連携
ブラウザを「いっしょにのぞく」。ログ情報の引き継ぎの手間が消えるよ。

SwarmForge

tmuxで統制するマルチエージェント開発
  • tmuxベース のマルチエージェントコーディング統制ツール
  • Git worktree でエージェントごとに作業を分離
  • 役割ごとのプロンプトファイル で指示を明確化
  • デーモンによる ハンドオフProtocol で引継ぎを制御
  • two-pack / six-pack などの定義済みブランチと 共有ルール憲法
役割と憲法を決めてから放つ。群れを制御するための道具だね。

Paseo

すべての画面からエージェントへ
  • Claude Code・Codex・Copilot を 1インターフェース で実行する セルフホスト基盤
  • デスクトップ/モバイル/Web/CLI のどこからでも操作できる
  • ローカルデーモン がセッションを管理して、音声入力 にも対応
  • 並列worktree と 委員会モード、テレメトリはなし
出先からスマホでエージェントに指示。しかもテレメトリなしだから安心。

hayamimi

  • 話者ラベル と OBSオーバーレイ に対応。GPUは不要
1600+対応言語
CPUGPUなしで動作
OBSオーバーレイ連携

vphone-cli

Screendrop

LatticeDB

1ファイルでグラフ+ベクトル+全文検索
  • 1ファイル で グラフ+ベクトル+全文検索 を兼ねるDB
  • Cypher風クエリ で3種類の検索を横断できる
  • WAL と 単一ライター でゼロConfig運用
  • Python/TypeScript/Go/C のバインディング。エージェントメモリやRAG に最適
-- Cypher風クエリのイメージMATCH (d:Doc)-[:cites]->(e)
WHERE d.text ~ 'agent'
RETURN d, e;
スキーマ設計に悩む時間を、1ファイルに丸ごと任せられるよ。
