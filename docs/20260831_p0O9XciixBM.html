セクション2: 看板コース「AI活用力」と4D

看板コース「AI活用力」

FRAMEWORK & FOUNDATIONS

  • 正式名称はAI Fluency: Framework and Foundations
  • 全14レッスン
  • 時間にして約4時間
  • 14回に切られているので1日1本でも進められる

4時間は長いのだ…。でも一気に見る必要はないわ。休みの日が丸ごと消えることはないの。

4Dフレームワーク

FOUR D's

  • 委任 Delegation
  • 説明 Description
  • 見極め Discernment
  • 責任 Diligence
  • 英語だと4つとも頭文字がD → まとめて4D
const fourD = {
  "1": "委任 Delegation",
  "2": "説明 Description",
  "3": "見極め Discernment",
  "4": "責任 Diligence",
}; // 4つとも頭文字は D
待って! 順番が逆じゃないのだ? …いいえ、そこが今回の肝なの。

① 委任 Delegation

WHAT TO HAND OVER

  • 何を任せて、何を自分でやるかを決めること
  • 仕事を人に振るときの「委任」と同じ。相手がAIになっただけ
  • 指示文の書き方は2番目に置かれている
  • プロンプト集を100個集めても上達しなかった理由はたぶんここ
頼み方より先に決めることがあったのだ…。考えたこともなかったのだ。

② 説明 Description

HOW TO TELL

  • 何を作ってほしいか
  • どう進めてほしいか
  • どんな調子で書いてほしいか
  • 硬い議事録と、雑談まじりのメモでは出来上がりが全然ちがう
  • 「調子」まで伝えるのがこつ
調子まで言うのだ? …そう、トーンの指定で結果が変わるのよ。

③ 見極め Discernment

DON'T TRUST BLINDLY

  • 返ってきたものをそのまま信じないこと
  • まず疑うのは数字
  • 次に疑うのは固有名詞
  • 直すときはまた「説明」に戻る
  • 説明と見極めは行ったり来たりするもの
ここを省くと、うっかりそのまま世に出しちゃうのだ…。

④ 責任 Diligence

CHECK BEFORE SHIP

  • 世に出す前に、自分で確かめること
  • 出す前に止まれるのは自分だけ
  • 感想には責任は宿らない…食べた人にしか言えないことも
  • 4Dの最後の関門が「責任」
食べてない人の感想に責任は宿らないわよ。最後は自分の手なのだ。

3つの関わり方

NOT ALL-OR-NOTHING

  • 丸ごと任せる
  • 並んで一緒にやる
  • 自分の手でやる
  • 丸投げか自力かの2択じゃない
  • 2択にした瞬間、どっちを選んでも損をする
// 全部任せる ≠ 手伝ってもらう
const levels = [
  "丸ごと任せる",
  "並んで一緒にやる",
  "自分の手でやる",
]; // 状況で使い分ける
作業によって、任せる度合いを変えられるのだ。

セクション3: 実践と始め方

実例: 会議メモを議事録に

4D IN ACTION

  • 人称や時制を整えるところは任せていい
  • どの発言を残してどれを落とすかは自分が決める
  • そこを任せると、大事な一言が消える
  • 見極めて直すときは「説明」へ戻る

4Dで通すと、自分の仕事として残る場所が見えてくるのだ!

どれから始める?

  • 長い作業でどう記憶を持たせるかまで学べる

土台に置かれた考え方
