Opus 5 が既定に

Takeaway #1（その1）

ここがポイント
  • Claude Code の既定の Opus モデルが Claude Opus 5 に
  • 何も指定しなくても、自動で Opus 5 が使える
  • コーディングの質と安定性が底上げ
# モデル指定なし → 自動で Opus 5
$ claude "この関数をリファクタして"

# 従来どおり明示もOK
$ claude --model opus
もう面倒な設定は不要！
最初から最新のモデルで書けるんだ 😊

100万トークンの文脈

Takeaway #1（その2）

どれくらいすごい？
  • 文脈の窓（context window）が最大 1M tokens に
  • ファイルまるごと・リポジトリ規模の読み込みも視野に
  • 対象は eligible plans（条件を満たすプラン）
  • 長い作業でも、途中で話が切れにくい
1,000,000 tokens 長文OK
大きなコードも丸ごと読めるから、
「さっき何やってたっけ？」が減るよ 📖

Fork mode

Takeaway #4

並列で動かす仕組み

  • いまの会話の途中から、そのまま分岐できる
  • prompt cache も引きついで、むだなく高速
  • バックグラウンドで、複数の処理を同時に回す
# 会話を保ったまま裏へ分岐
> /fork このAPIの使い方を調べていて
本体は止まらない！
裏で別の作業を、どんどん回せるよ 🌙

「25%アップ」の意味

Takeaway #9

数字を比べてみよう
  • 当初の週あたり上限 からは、恒久で +25%
  • でも、いまの一時的な増量枠よりは −17%
  • つまり現状と比べると、実質マイナスなんだ
  • 「増えます」の文面だけだと、読みちがえやすいよ
当初の上限
100 いま（一時的ボーナス）
150
恒久の新上限
125（+25%） いまより
−17%
増えるのは「元の上限」と比べての話。
いまよりは、ちょっと減るというわけ ⚖️
