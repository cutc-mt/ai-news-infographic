1. 遂に登場 ─ 基本情報を総チェック

Cards 1-5

待ち望まれた登場

  • Opus 5 の登場から 1ヶ月以上 あいてのリリース
  • 8月は新モデルが来ず、「いつ来るんだ」と待たされた1ヶ月
  • リリース直後からまさお氏は並列で使い倒して検証
  • GPT の新モデルが 破壊的な衝撃 を出さない限り、当面は Fable 5.1 の環境で回す方針
「フェイブルってやっぱり最高やな」と思わせてくれる。5 からさらに良くなっている、というのが数時間使い倒した所感。

同時に出た Mythos 5.1

  • 審査を通った 米国の組織（サイバー・生命系）だけに提供される版
  • 安全の枠を緩めたモデルで、一般ユーザーとは無関係
  • つまり一般ユーザーは Fable 5.1 だけ見ればOK
  • Fable は6月に一旦使えなくなり、7月に期間限定で解放 → 延長を繰り返した過去も
今回は「期間限定で終わり」という話は出ていないので、安心して環境を組める。

知識の期限は 2026年6月

Fable 5 / Sonnet：26年1月 Opus 5：26年5月 Fable 5.1：26年6月
  • モデルの知識の期限（カットオフ）がこの順で新しい
  • Opus の登場から effort の扱い が変わり、使うトークン量が大きく変わるように
  • Fable 5.1 にも同じ傾向。設定は最初にきちんと整えるべき
スラッシュで開く設定や effort の選択まで気にしておかないと、処理時間がふくらんで意外と痛い、との指摘。

基本のスペック

  • コンテキストは 1M（100万トークン）
  • 出力は最大 12.8万トークン
  • シンキングは 常に 4 のまま
  • effort は Low / Medium / High / X-High / Max の5段階のまま
  • API でも解放。Devin・Cursor など各ツールに早速登場
仕様面は「今まで通り」なので、移行の迷いが少なくて素直に使いやすい。

使えるプラン

  • 無料プランでは使えない
  • Max / Team / Enterprise プランで利用できる
  • 週あたり上限の 半分まで という条件は前のモデルと同じ
今はサブスクの使用量がキャンペーン中で、いつもより多めに回せる様子。

2. 実力 ─ ベンチマークで何が変わった？

Cards 6-8

Terminal-Bench Science

Fable 5 Max：24.7% Fable 5.1 Low：26.3%
  • 一番軽い Low でも旧の最上位を超える 衝撃の数字
  • 1タスクあたりのコストも改善。より効率よくタスクを完走する
  • 早期アクセスの企業からは「100万回に1回のクラッシュを4年誰も説明できなかった」原因を当てた、という報告も
まさお氏自身もハーネスの分析をさせてみたが、ウルトラコード経由で鋭い意見が出てくるとのこと。

ベンチが全面アップ

  • Agentic Coding：High ≒ X-High。Medium は僅かに X-High に負ける程度
  • Cursor Bench：Max で一気に伸びる
  • Computer Use も着実に向上
  • Humanity's Last Exam（道具なし）は 60%。かつては10%に届かなかった
  • ナレッジワーク系は 1700 超え
「ラストエグザムってなんやねん」と言いたくなる領域まで来た、と。

価格は据え置き＋キャッシュ

  • Input $10 / Output $50（1Mトークンあたり・前モデルと同じ）
  • キャッシュの読み込みが 75% 引き に
  • エージェント系のコーディングはキャッシュ料金の比重が大きいので、ここが効く
  • サブスク側の条件は変わらず
体感としては Fable 5 より実質のコストが下がる見込み。長く回すほど嬉しい変更。

3. 注意点 ─ 転送・API・トークンのくせ

Cards 9-12

残る安全の枠 ─ 自動転送

  • サイバー系の依頼で止まると Opus 4.8 へ自動転送
  • 生物系の依頼だと Opus 5 へ転送
  • 止められる判定は 60% 減。初歩的な生物学の質問の誤転送も減った
  • 一方でサイバー能力は歴代で最強クラスと言われる
「監視をすり抜ける性能もかなり高い」と業界では評判の模様。

知らぬ間に転送される罠

  • スキルや CLAUDE.md に特定のワードが入っているだけで転送が起きることがある
  • 転送されたら /context で最初に読み込まれた文脈を確認
  • まさお氏はスロップ対策のスキルを入れており、強いくせは感じなかった
確認の流れ
# 転送が起きたら最初に打つ
/context

# → ロード済みの文脈と
#   転送の原因をチェック
データの保管まわりの新しい話もあるので、念入りに確認を。

API に非互換の変更

  • API に 互換性のない変更 が入った
  • キャッシュまわりに 新機能 が追加
  • Anthropic API でサービスを作っている人は 要確認
慌てず公式の変更履歴を一読しておきたい場所、とのまとめ。

速さとトークンのくせ

  • 体感は TPS 70 前後。サブスクでは速い方
  • effort を X-High / Max にすると、タスクによっては 20万トークン 消費
  • シューティングのデモ：Low ≒ 2.5万 vs X-High ≒ 20万
  • Opus は Low との差が出にくいタスクもあるが、Fable は「しっかり書く所では出す」
力を入れる所でトークンを溶かす性格が、数字にもはっきり出るモデル。

4. 実演デモ ─ 全て effort「X」で作成

Cards 13-15

ゲーム系のデモ

  • WASD のエイムトレーナー。Opus 5（High）と並べても遜色ない出来
  • MMRPG。細部まで作り込み、トークンもしっかり使う
  • 3D ファイティング：クオリティは 1000 超え。敵AIも普通に強い
  • アクアリウム・3D ゴブリン・ピンボール・ボール落下のゲームも高得点
3D ゴブリンは周囲の物まで作り込んできて、まさお氏もびっくり。「一昔前はどのモデルも無理だった」レベル。

Web ツール・LP のデモ

  • LP：世界観とアニメ込み。163k トークンを消化して完成度は上位
  • イヤホンSNS：Opus はやや上付き、Fable は程よく見やすい
  • Figma 風エディター は完成度が高い
  • ブロックエディターは 書き出し機能 まで付く
  • ハーネス設計のスライドは装飾がリッチ。サムネ・3Dマサオキャラ・マオ画像の再現も
所感を一言で：「細部への注意が一線を超えた」。

SVG アニメのデモ

  • ライオンのSVG：首の動きに難はあるが、詳細度が上がった
  • 電気ネズミのSVG：目の位置が惜しい（Gemini 5.3 Flash は近い出来）
  • 歩く人形：Opus は大げさにトークンを使い、Fable は X-High でもスマート
  • 交通SVG：信号が赤 → 青 → 歩行者が渡る、まで作り切った
交通SVG はタイムアウトしかけたのに最後まで作り切る根性を見せた、とのこと。
