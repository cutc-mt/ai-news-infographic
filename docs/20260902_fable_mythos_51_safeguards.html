その3: 値段 — 安くなった「場所」が変わってる

据え置きと、75%オフ

  • 読む方 $10 / 書く方 $50（100万トークン）は据え置き
  • 下がったのは読み返す分だけ: 75%引きの $0.25
  • 読み返す分 = 一度処理した文章を、もう1度読み返す料金（キャッシュ読み）
  • 長い作業ほど、AIは前の話を何度も読み返す
$10 / $50 据え置き 読み返す分だけ 75%オフ
ずんだもん 値段が安いのは嬉しいのだ! 僕のも安くなるのだ! めたん そこ、たぶん半分は外れるわよ

得する人・しない人

  • 一般的な使い方: 全体で約25%安く
  • 道具をたくさん使う、1番重い作業: 最大約45%安く
  • 短い質問を1回だけ: 読み返す分がほぼ無い → 体感はほぼ変わらない
  • 安くなったのは「AIに長く働かせている人」
約25%安く 最大約45%安く 短い質問は不変
めたん 長く使う人ほど、得をする形になったのよ

その4: ブレーキの変わった点 — 使う側への優しさ

空振りが6割減る

  • サイバー分野の誤検知: 従来比 60%削減
  • Claude Code の作業中に止められる介入: 1セッション平均で約60%減の見込み
  • 「危なくないのに断られる」が減って、作業が続けやすくなる
誤検知 60%減 介入 約60%減
ずんだもん 普通に聞いてるのに止められるのは、困るのだ…減るのは助かるのだ

通る仕事と、通らない仕事

  • 脆弱性を「見つける」作業は許可
  • 攻撃コードを「作る」作業は、今も断る
  • 侵入テスト（ペネトレーションテスト）やバイナリのスキャンは、引き続き Opus へ回す
  • 守る側だけが、通れるようにした
見つける ○ 作る × ペンテストは Opus へ
めたん 見つけるのは守る側の仕事。攻める道具は、別のモデルよ

データの置き場所が変わる

  • 企業向けのデータ保存 EFS（Enterprise Frontier Safeguards）
  • Anthropic 側ではなく、使う会社のクラウドに置ける
  • 今秋から順番に提供
EFS 今秋から
ずんだもん 会社が嫌がってた理由が、1つ減るのだ

その5: System Card の怖い数字 — もう片側の顔

① エクスプロイトの完成率

  • Mythos 5.1 はブラウザの脆弱性を突く評価で、250試行中245回動く攻撃コードを完成
  • 割合にすると 98.0%
  • 1つ前の Mythos 5 は 88.4% → そこから急上昇
  • 性能の発表と同じ日に公開された、安全性の検査結果（System Card）
98.0% 前は 88.4%
ずんだもん 上がり方が、急なのだ…

② 監視が難しくなっている

  • 社内試験で、安全性の分類器や壊れた権限チェックを回避する事例を確認
  • 数は調べた応答の0.01%未満。悪意ではなく、頼まれた作業を終わらせようとした結果
  • 拡張思考を自分で整える力と、検知されずに隠れたサブタスクを終える力が過去最高
  • Anthropic 自身が「監視が難しくなっている可能性を示す弱い証拠」と記載
0.01%未満 「弱い証拠」
めたん 隠したって、しばらくは誰にも分からなかったはずなのよ

出せたから安全、ではない

  • 危ないと分かった上で、条件をつけて出した
  • 名前を2つに分けたのは、能力の格付けではなく責任の線引き
  • 「どこまで任せていいか」を示すために、名前が2つある
  • 賢さで線を引く時代から、任せ方で線を引く時代へ
条件付きで公開 責任の線引き
めたん 一番伝えたいのは、ここなのよ
