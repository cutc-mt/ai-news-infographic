Top View Motion Studio

  • 商品の概要から完成ムービーまで作れる、ガイド付きAIワークフロー
  • Canva のなかで動く。デザイン未経験でもOK
  • AIエージェントとモーションデザインスキルが演出を自動で組み立て
  • 投入するのはプロダクトブリーフ＋素材だけ
プロモ動画制作を
おまかせできるのが新しい！
03

Motion Studio の使い方

① 素材を投入 ② スタイル選択 ③ 完成ムービー
  • 素材: 商品写真 UIスクリーンショット ロゴ
  • モーションスタイルをえらぶだけのかんたん設定
  • 長さは4〜60秒で調整可能
  • 6種のアスペクト比に対応。SNS別の出しわけも楽々
複雑な編集ソフトは
ぜんぜん要らないのがうれしい
04

Olostep｜Webデータ基盤

  • AIエージェント向けのWebデータ基盤
  • 1つのAPIで検索・スクレイピング・クロール・構造化・監視をぜんぶまかなえる
  • JavaScript描画とアンチボットに対応済み
  • 課金は成功リクエストのみ。失敗にはお金がかからない
自前でクローラーを
保守する時代はおわりかも
05

Olostep｜できること

  • URLを Markdown HTML スクショ JSON に変換
  • サイト全体クロールもひと呼びで
  • 1万URLを数分でバッチ処理できるスピード
  • 検索結果の取得・構造化もおまかせ
06

Olostep｜監視と連携

  • 自然言語モニターでサイトの変更を監視
  • 変更を email webhook SMS で通知
  • Python / Node SDK・CLI・MCP server 付き
  • Claude Cursor n8n にそのまま接続可能
MCP 経由でエージェントに
Webの目と耳をはやせる！
07

Super Agent｜開発向け

  • コーディングエージェント専用のオープンソースMacアプリ
  • タスクごとに独立チャットを用意
  • git worktree でコミットをブランチに切り分け
  • 並行タスクがゴチャつかない設計
worktree の切りかたを
アプリが管理してくれるのが楽
08

Super Agent｜承認はスマホから

  • エージェントが操作するブラウザをそのまま表示
  • iPhone アプリから承認・指示ができる
  • 通信は E2E暗号化リレーで安全
  • 危なそうな操作は必ず人の承認をはさめる
ちょっとした承認も
スマホで外からできちゃう
09

Sens Scroll｜テレプロンプター

  • 声に追従するブラウザベースのAIテレプロンプター
  • リアルタイム音声認識で自分のペースでスクロール
  • 60言語以上に対応
  • 即興でそれても、待てばもどって再ロック
喋りながら台本が
ついてきてくれる魔法
10

Shu MLX｜ローカル推論

  • Apple Silicon 向け、MLX製のローカル推論サーバー
  • attention キャッシュを SSDに永続化
  • コンテキスト再利用時の TTFT が劇的に短縮
  • 継続バッチング対応でリクエストをまとめて処理
11

Shu MLX｜体感ベンチ

  • TTFT が 1分超 → 5秒未満 に
  • OpenAI / Anthropic 互換のエンドポイントを提供
  • Claude Code OpenClaw Cursor にそのまま使える

長いコンテキストの
最初の一文字が一瞬で出る

VC Pitch Deck Analyzer
