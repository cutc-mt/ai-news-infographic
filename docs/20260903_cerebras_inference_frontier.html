競合分析 — それぞれの立ち位置

Card 10-13

Groq への批判

「非常に疑わしい」点

  • SRAM 設計がメインストリームになるのは素晴らしい——NVIDIA さえ受け入れ、伝統的 GPU ではウルトラスファーストに届かないと認識
  • しかし奇妙な点: なぜ 310億パラメータモデルでローンチ？
  • Jensen が GTC で30分かけて説明した attention / FFN 分離（Ruben LPX）に言及がなかった
  • フル生産中の製品で、非分離の31Bモデルの数字しか見せないのは 「非常に疑わしい」
本気の数字なら、
分離モデルでも見せてほしい——
という鋭いツッコミ。

メモリの桁違い

スケールで2桁の差が「無料」

  • 非ウエハースケールの SRAM 設計では、各チップのメモリが足りないという課題が表れやすい
  • 数兆パラメータのフロンティアモデルには、重みの保持だけで数千個の LPU が必要
  • Cerebras の1チップは Groq の1チップの約 100倍のメモリ
  • スケールで 2桁の差が無料でつく
  • Groq は今後より小さいモデルに集中していくはず。買収後も第一近似では変わらない
ウェハーごとまるごと1枚——
だからメモリで圧勝できる。

NVIDIA・AMD・TPU・Trainium

「新しいバッチモード」への警告

  • NVIDIA はみんなが予想した通りのことをしている——ドープではなく、トークンをより安く・より多くは現実のニーズ
  • ただし 100-200 TPS はすぐに「新しいバッチモード」になる
  • プロンプト処理や超並列ワークロードには適するが、それだけでは不十分
  • 従来型アーキテクチャは「より良い Ruben を作る」トレッドミルの上（良い意味で）。AMD・Trainium・ある程度 TPU も同様
  • 別のベクトルで限界を押し上げる価値もある——それが Cerebras の立ち位置
安さを追う道と、
速さで攻める道。
両方に価値がある。

Etched について

差別化が見えにくい

  • 非常に多くは語らない——語ったことも当初から大きく変わった（彼ら自身も認める）
  • Web サイトのグラフィックデザインは印象的……
  • しかし伝統的 GPU より良いものを作ろうとしている以上のものが見えない
  • 「分散型だから速い分散ストレージ」という主張は理解できない
  • ラックを出していたので何かは作っているが、差別化の位置が見えにくい
  • ベストケースに望むのは、チップの外での革新的な統合（ラック・ノード・パッケージ・相互接続・工場）の限界を押し上げること
次のフロンティアは
単一チップの外の統合——
そこに挑んでほしい。

次のフロンティア — チップの外の統合

Card 14-17

異種分散エコシステム

データセンター全体を1台のコンピュータに

  • 市場は大きく、さまざまなハードウェアに役割がある
  • 推論はもはや単一のワークロードではない——prefill・decode・KVキャッシュのロード・attention・エキスパートの分散とバランシングなど多数のサブワークロード
  • それぞれに適したハードウェアを使うべき
  • 小さいスケールでは意味がないが、数百メガワット〜マルチギガワット規模なら簡単に元が取れる
  • その規模ではデータセンター全体を「1台のコンピュータ」のように考える——配分できる能力をコントロール
建物まるごと1台のPC——
それはコンピュータ・アーキテクトの夢！

モデル × ハードの共同設計

最も開拓されていない機会

  • いま最も開拓されていない機会
  • 誰もが NVIDIA GPU 向け（特定の1機種——B200・GB200・MBL72）に設計されたモデルを動かしている
  • そのまま（別アーキテクチャで実行）でも 14倍速いのに、モデルをわずかに調整するだけで巨大なゲインが得られる
  • 共同設計（co-design）を進めれば機会はほぼ無限
  • AIコード生成（カーネル生成）は過小評価されている
モデルをちょっと直すだけで
何倍も速くなる——
まだ誰も掘っていない鉱脈！

給電・冷却・信頼性

本当の戦いはそこにあった

  • ウエハースケールで最初に「難しい」とされたのはダイ間の接続と歩留まり
  • 実際に最大の課題だったのは 給電・冷却・スケールでの信頼性
  • パワーポイントに描くのと、実際に給電・冷却して動かすのは別物
  • Cerebras の backpack（給電）は3Dパッケージに近い発想——電力をチップの表面に直接
  • 歩留まりと3Dパッケージはすでに解決済み——3D DRAM 技術も同じ道をたどる
図面は誰でも描ける。
動かして冷やすのが本番——
経験の差が出るところ。

D-Matrix・Samsung・3D DRAM

注目の統合アプローチ

  • アプリ・問題・モデルは単一チップに収まらない大きさに——すべては統合に行き着く（計算・メモリ・相互接続をどうまとめるか、スケジューリング、パイプライニング）
  • 計算・相互接続・メモリの3つが AI チップの構成要素
  • 低レイテンシ領域ではメモリ帯域が鍵
  • Hot Chips で興味深かったのは D-Matrix（3D DRAM パッケージングに本気）と Samsung の ZHBM
  • Cerebras も2年前から DRAM スタッキング（3D積層）プログラムを開始済み
次の勝負は
チップの外の統合——
3D DRAM が主戦場に！

業界の未来 — 競争と節目

Card 18

中国モデルと最大の IPO

国レベルの課題と個人の節目

  • オープンソースモデル市場は 95% が中国製——高品質な大型オープンモデルの大半が中国のラボから
  • 共有が起きること自体はグローバルコミュニティに良い面もあるが、あの依存度は戦略的に非常に難しい立場
  • これらのモデルを支えるハードウェアインフラも独自に構築されつつある（Huawei 等）
  • 国家利害レベルのイニシアチブで解決すべき問題——単一企業や単一ファブでは解けない。米国の主導を続ける取り組みを支持
  • 史上最大の半導体 IPO——「今でも自分をつねって確認するレベル」。それでもまだまだ初期
歴史的な IPO を経ても
「まだ序章」——
この勢いは続く！
