PRDを入れる、コードが出てくる

No.01

dark factory とは

  • Cole が今年チャンネルで呼んできたAI工場の愛称
  • AIコーディングの究極の進化形という位置づけ
  • 人間がコードを一切見ずに完結させる構え
  • 今年はじめた実験で reliability（信頼性）を検証中
「スパイシーな自動補完」から始まった進化の、その先のゴールだよ！
No.02

入口は PRD だけ

  • 書くのはPRD（要件定義書）という高レベル計画だけ
  • システムが PRD を個別タスクへ自動分割
  • 分割されたタスクを順に全自動で構築
PRD タスク分割 構築 製品へ
人間の仕事は「何を作るか書く」ことだけ。あとは機械の番！
No.03

レビューもマージも自動

  • プルリクエストのレビューを AI が実施
  • 問題なければそのままマージへ進む
  • 成果物はそのまま本番へ deployされる
  • この間、人間はコードを一行も見ない
「本当に reliable なの？」という疑問は当然出る。それを実験で確かめるのがこの話！
No.04

企業でも導入が進む

  • 左右の企業が開発の一部に正攻法で導入し始めた
  • Cole 自身も数社の構築を支援した実績あり
  • 懐疑派にも理解できる話だと本人は強調
「うちでは絶対無理」派も、プロトタイプ用途ならいけるかも、という着地。
No.05

なぜ今、実現できる？

  • コーディングエージェントのハーネスが進化
  • LLM自体も性能向上が続く
  • 大規模ワークフローの制御技術も成熟
  • 3つが並行して良くなっているのがポイント
単独の進化ではなく「そろった」こと実現させた、という分析。

実験：dark factory と Dynachat

No.08

1年続けた実験

  • 構築過程はライブ配信と動画で全部公開
  • 完全な dark factory を一式構築
  • その上でアプリを1本最後まで作り切った
  • Cole はコードを書いても見てもいない
「作る様子」自体をコンテンツにするあたり、この人の流儀だね。
No.09

AIチューーター Dynachat

  • 作ったのは Dynachatというエージェント型チャット
  • Cole の YouTube チャンネル全編にアクセス可能
  • Dynamis コミュニティなら講座・ワークショップも検索できる
  • 質問すれば彼の知識に根ざして答える
今も本番で動いてて、あなたが今すぐ試せるらしい。リンクは概要欄！
No.10

成功、しかし足りず

  • 実験は全体として成功と自己評価
  • ただし決して複雑なアプリではない
  • ミッションクリティカルでもないので信頼性は未検証
  • 次はもっと厳しい試練に挑む予定
「動いた」から「どこまで reliable か」へ。問いが一段深くなった。
No.11

あなたにも作れる

  • skills リポジトリにbuild dark factoryを公開
  • 彼が使ったのと同じ手順を一から案内
  • 解説動画もチャンネルに用意済み
「自分も試したい」人への入門キット。ここまでは前回の実験の話。
No.12

（スポンサー）Data Impulse

  • 従量課金のプロキシで9,000万IP超を提供
  • 195か国をカバーする住宅IPネットワーク
  • 転売なしで高速・安定、1GBごとの課金
  • スクレイピングの規制ブロックを回避
# コードは proxy URL を足すだけ
scraper = Scraper(
  proxy="http://dataimpulse:****@host:823"
)
エージェント開発で即ブロックされる悩みへの解、という文脈で紹介。
