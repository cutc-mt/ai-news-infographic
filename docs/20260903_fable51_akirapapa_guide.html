  • low/mediumに下げると大幅安く同結果

Claude Code 起動

$ claude --version
$ claude --model claude-fable-5-1
# 起動後: /model で一覧→fable選択
# Enter=既定保存 / S=セッションのみ
  • モデル一覧は/modelで切替
  • 作業途中でも気軽に乗換可
正式名を指定するだけで5.1が立ち上がります

effort切替と設定

# /effort → low〜max の段階
$ claude --effort low
# ~/.claude/settings.json
{ "model": "claude-fable-5-1[1m]",
  "effortLevel": "low" }
  • 簡単な作業はlowで十分
  • 難しい作業はhigh/maxへ
  • 設定ファイルに書けば次回から既定
[1m]は100万トークン長文脈の印、覚えておくと便利

API呼び出し

curl https://api.anthropic.com/v1/messages \
 -H "x-api-key: $KEY" \
 -d '{"model":"claude-fable-5-1",
   "output_config":{"effort":"low"},
   "messages":[...],
   "system":[{"type":"text",
     "text":"長い前置き...",
     "cache_control":{"type":"ephemeral"}}]}'
  • cache_controlがキャッシュ読取の合図
  • usageの3種トークン×単価で計算
input / cache_read / output の3つを見れば費用が分かる
