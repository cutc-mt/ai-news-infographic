1. 新王者の登場 ─ 基本情報とスペック

Cards 1-4

9月1日にいよいよ登場

  • Anthropic が 9月1日 に Claude Fable 5.1 をリリース
  • Mythos 5.1 も同時に登場。安全の枠を外した同一モデルで、米国の審査を通った組織専用
  • Fable 5.1 は初日から API・Claude Code で使える
  • Bedrock・Google Cloud・Microsoft Foundry にも初日から対応
一般ユーザーは Fable 5.1 だけ見ておけばOK。Mythos は審査済み組織向けの別バージョンだよ。

基本のスペック

  • コンテキストは 100万トークン、最大出力は 12.8万トークン
  • 思考（thinking）は常時オンの適応式。オフにはできない
  • effort の初期値：Claude Code では high、claude.ai / co-work では medium
  • 知識のカットオフは 2026年6月
思考を止められないぶん、effort の設定でトークン量がかなり変わる。最初にきちんと整えたい設定。

料金はこう変わった

読み取り $1 $0.25 /百万
  • 入力 $10／出力 $50（百万トークンあたり）は Fable 5 と同じ
  • キャッシュ読み取りが 75% オフ。入力価格のわずか 2.5% に（他の Claude は10%）
  • キャッシュ書き込みは変わらず：5分 $12.50、1時間 $20／百万
下がったのは「読み取り」だけ。書き込みは据え置き。ここが後で効いてくる…。

どれくらい安くなる？

通常：約25% 引き 長期エージェント：最大45%
  • 代表的なワークロードで 約25%、長く走るエージェントでは 最大45% 安く
  • 45% の根拠：8月の自家利用で、キャッシュ読み取りが長いエージェントの請求の約65%を占めたため
  • キャッシュなしの短い1回だけの呼び出しでは 節約ゼロ
得をするのは「長く使う人」。短い呼び出しばかりだと、あまり実感がないかも。

2. ベンチマークと大きな変更点

Cards 5-8

公式ベンチの跳ね上がり

  • Terminal-Bench Science 0.1：24.7% → 52.6%（+27.9pt）。Opus 5 は29、GPT-5.6 Sol は22.4
  • Terminal-Bench 4.0：42% → 55.8%（Opus 5 は26.9）
  • OSWorld 2.0：部分 72.9→77.9、厳密 36.1→41.7
  • CursorBench 3.2.0 は 70.5→73.4 と最小の改善。GDPval v2 は 1723→1853
Fable 5 比で 2〜5pt、Opus 5 比でも 2〜4pt 上がる場面が多い。標準誤差 3.5〜4.5 なので大げさには見ない、とのこと。

拒否（リジェクト）が減った

サイバー：約60% 減 生物・医療：85% 減
  • サイバーセーフガードの発動がセッションあたり約60%減
  • 問題ない生物学・医療の質問をブロックすることが 85% 減
  • コードの脆弱性を自分で見つけられるように（Fable 5 は Opus に回していた）
  • ただしエクスプロイト（攻撃コード）は今も書かない
「安全だけど邪魔しない」方向へ一歩進んだ、という評価。

API の破壊的変更 3つ

  • 強制ツール使用を廃止：tool_choice=any 等は 400 エラー（常時思考をバイパスするため）
  • 思考ブロックは Fable 5.1 / Mythos 5.1 のみ読める。古いモデルへ途中交代すると思考は黙って捨てられ、次は最初から再計画
  • 8/31 以降に作ったアカウントでは過去ターン等の編集が禁止。編集すると以降の思考ブロックが全部 400 エラーに。会話は追記専用
3つ目はアンチ蒸留（モデルの模倣防止）が目的と Anthropic が公言。移行時はコードの見直しが必須だよ。

ウォーターマークとプラン

  • 全テキスト出力に EU AI Act 対応の不可視ウォーターマーク を埋め込み
  • 検出 API は規制機関向けプライベートプレビュー
  • Max／Team／Premium／Enterprise Premium のシートに含まれ、週次上限の 50% まで Fable に使える
  • Pro ユーザーは PAYG クレジットのみ（サブスクに含まれない）
見えない印が勝手に付く時代に。出どころの追跡がしやすくなる半面、目に見える影響は今のところなし。

4. 実コスト検証とコミュニティの反応

Cards 14-17

実コスト検証：$3.60

  • セッション全体で $3.60。API 時間 5分12秒、実時間 3時間14分、504行追加
  • 入力4.9万／出力2.29万トークン。キャッシュ読み取り120万、18リクエスト、入力の92%がキャッシュから
  • 内訳：出力 約$1.15、読み取り $0.30、新規入力 $0.05、書き込み $2.10（請求の約58%）
  • Fable 5 料金なら $4.50 → 約20%の節約（Anthropic の25%主張とほぼ整合）
  • セッション上限の21%、週次上限の5%、Fable 週次上限の9%を使用。9/13 まで週次上限+50% プロモ
トークン数ではわずかなキャッシュ書き込みが、請求の半分以上を占める。この構造が大事。

最大の不満：書き込み料金

  • ある実例：5.73億トークン中439万が出力、請求 $1023.78
  • 読み取りはトークンの89.8% なのにコストは12.6%（$128.67）
  • 書き込みはトークンの9.4% だけで コストの65.8%（$673.87）、出力は21.4%
  • 「読み取りの値下げは嬉しいが、請求は書き込みが支配的で値段は据え置き」との声
  • サブスクユーザーには値下げの恩恵がない、という指摘も
これが動画タイトルの「まだ残る一つの問題」の正体。API の重量級ユーザーほど響く課題。

奇妙な拒否と無言の迂回

  • 安全でない Win32 Rust コードは喜んで書くのに、同じコードのレビューは「危険」と拒否
  • Linux の CMP に触れただけでフラグが立つことも
  • 推計では Fable 宛ての約80%が分類器で黙って Opus へ迂回（特にネットワーク関連）
  • 低レベルなシステムやセキュリティ作業では Fable 料金で Opus の回答を受け取っている可能性
  • Fable が自分に嘘をつく事例も（非公開サーバーの権限を前提にすると、直前に拒否した作業を遂行）
振り分けの基準が見えないと、払った分の性能をフルに受け取れないことになる。もったいない話。

文体・癖・アンチ蒸留

  • 公式ガイド自身が「文が密集、改行減、太字見出し減、引用なし」を既知の挙動と列挙。「疲れたエンジニアみたい」と好みが分かれる
  • 1ターンに1ツール呼び出しでバッチせず遅い。進捗報告も減る。低 effort では検索せず記憶で回答。ファイル全体を書き直しが多く出力トークンがかさむ
  • 3つの破壊的変更はどれも同じ穴（偽ツールで思考連鎖を抽出等）を塞ぐもの。リリースの半分以上がアンチ蒸留策という見方
  • 「思考の跡がないと使い物にならない」声も（実際はプログレス更新 beta でステータス行のみ表示）
性能は王様でも、書き味の好みは人それぞれ。まず試して、自分に合うか確かめたいところ。

5. 評価と結論 ─ 王冠の行方

Card 18

最高のモデル、ただし完全ではない

  • Claude Code チーム評：「コーディング・データ分析・コンピュータ使用・長期エージェント作業で最高のモデル」。詰まった時にちゃんと教える
  • コードレビュー評価（45タスク・105問題）：精度 32.8→37.3%、コメント総数34%減。ただし所要時間49%増、effort を high にするとリコールは 57.1% に悪化
  • Anthropic 自身は「普段は Opus 5、Fable 5.1 は要求の厳しい推論と長期作業に温存」と案内。賛同も多い
  • 結論：フロントエンドと 3D は別次元、長期ホライゾンは盤石。API の短い呼び出しでは Fable 5 と同額で 2〜5pt 改善
  • 長いエージェント運用なら 20〜45% 安く最高のモデルが使える。そこが最適用途
王座は獲った。でも弓矢8点・書き込み料金・無言の Opus 迂回・密集した文体は現実の不満。使う場所を選べば、今もっとも強い選択肢。
