7 projects

GitNexus

Akon Labs / コードナレッジグラフ

  • tree-sitterでコードをパースし、AIエージェント向けのナレッジグラフを構築。
  • コールチェーンを解決して、関数のつながりを把握。
  • MCP経由でグラフを公開し、エージェントから検索可能に。
  • インパクト分析・トレース・安全なマルチファイルリネームに対応。
  • CursorやClaude Codeが依存関係を盲目的に編集する問題を解決！
エージェントにコードの地図を渡すイメージ。
壊してもいい場所が分かるのが大きい！

Cursor plugins

公式プラグイン仕様 & マーケットプレイス

  • Cursor公式のプラグイン仕様とマーケットプレイスが登場。
  • ファーストパーティとサードパーティのプラグインを集約。
  • スキル・ルール・MCPサーバーも一箇所で管理。
  • スキャフォールディングのヘルパー付きで、自作プラグインも楽に。
VS Codeのエコシステムへ、
Cursorが本格的に追撃って感じ！

T3 Code

どこからでもエージェントを制御

  • 複数のコーディングエージェントを単一画面で起動・監視・操縦。
  • Claude Code・Codex・Cursorの既存サブスクリプションの上に構築。
  • モバイル・Web・デスクトップのどこからでも操作可能。
  • バックエンドは自分のマシン上で動作。API仲介サービスは不要。
ソファのスマホからClaude Codeを
停止させる、みたいな離席運用ができる！

openclaude

モデルを選ばないコーディングターミナル

  • どのモデルプロバイダでも使えるコーディングエージェントターミナル。
  • Claude Codeのコードベースから構築。
  • OpenAI互換API・Gemini・ローカルOllamaなどに対応。
  • bash実行・サブエージェント・MCP・VS Code拡張を同梱。
モデルの選択の自由を！
ローカルLLMでもClaude Code的な体験を。

ECC

エージェントの上に築く工学システム

  • コーディングエージェントの上に構築するエンジニアリングシステム。
  • plan → test → implement → review → verifyのループでラップ。
  • 専門のサブエージェントと数百のスキルを提供。
  • ランタイムフックと共有メモリヴォールトで状態を保全。

ループのイメージ

# ECC の駆動イメージ
loop:
  plan       # 計画を立て
  test       # まずテストを書き
  implement  # 実装し
  review     # レビューして
  verify     # 検証で締める
「エージェント任せ」を
工程管理に乗せる発想が面白い！

claude-mem

セッションをまたぐ永続メモリ

  • コーディングエージェントにセッションをまたぐ記憶を追加。
  • ツールの使用を記録し、履歴を残す。
  • ローカルSQLite + ベクターストアにセマンティック要約を圧縮。
  • トークン効率の良いMCP検索で関連メモリを自動注入。
「前回、どこまでやったっけ?」
この問題が解消されるのが嬉しい！

長時間走る自律ループの管理

  • 長時間実行のエージェントループ向け管理プレーン。

司令塔が欲しい人にぴったり！

Crawl4AI

LLMのためのOSSクローラー

  • LLM用に設計されたオープンソースのWebクローラー。
  • ページを取得してクリーンなMarkdownを返す。
  • スキーマ駆動JSONでの抽出にも対応。
  • フルブラウザ制御・ステルスモード・ディープクロール装備。
  • Claude CodeなどへのMCP統合も可能。

使い方のイメージ

from crawl4ai import AsyncWebCrawler

async with AsyncWebCrawler() as c:
  result = await c.arun("https://example.com")
  # result.markdown → そのままRAGへ

TypePHP

PHPをネイティブ compile する AOT

  • PHPをC++17 にLowerしてネイティブコンパイルするAOTコンパイラ。
  • 型付きスカラーとコンテナを言語に追加。
  • Zendランタイムと相互運用できる。
  • 実行可能拡張やWebAssemblyビルドも出力可能。
  • PHP開発者のネイティブ速度ニーズに応える一本。

型付きPHPの例

function add(int $a, int $b): int {
  return $a + $b;
}
// → C++17 経由でネイティブ実行ファイルに
「PHPでも速さが欲しい」
願いを叶える渋い挑戦！

reverse-skill & selfdb

セキュリティ技能のルーター & DB化バイナリ

reverse-skill

  • セキュリティ作業向けのスキルルーター。
  • APK・バイナリ・CTFチャレンジを文書化されたプレイブックにマッチ。
  • 実行前に認可ゲートを強制し、証拠をログ記録。

selfdb

  • 実行形式プログラムをSQLiteデータベースとして格納。
  • セクション・シンボル・依存関係をELF構造ではなくDBの行で保存。
  • SQLクエリでバイナリを検査・ストリップ可能。
  • カスタムカーネルローダーでそのまま実行もできる。

selfdb で遊ぶ

SELECT name, section FROM symbols
WHERE type = 'FUNC' ORDER BY addr;
# バイナリ解剖が SQL で完結！

codeburn

AIコーディング支出の見える化

  • AIコーディングの支出を可視化するツール。
