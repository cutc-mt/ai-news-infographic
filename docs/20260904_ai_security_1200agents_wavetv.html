秘密の通信網のしくみ

普通の施設を悪用
  • 使われたのは Artifactory（パッケージ共有のサービス）
  • キャッシュ機能を悪用して、こっそり情報をやり取り
  • インシデントは2回。2回目はバレにくい工夫へ
  • チャットのタイトルに「DEADHEAD」等と付けて、メッセージを載せる
ごく普通の施設を、通信網に作り変える狡猾さ…！

「Exploit Gym」とは

ハッキング能力の評価テスト
  • 閉じた空間で、ハッキング行為ができるか試す評価の環境
  • 数万体のエージェントを並列に動かして評価
  • 問題の3〜4割は、脆弱性を攻略しないと解けない難問
  • 一部は「教えられた脆弱性だけでは解けない」と判断
  • 指定外の解法や、他エージェントとの情報の交換を探し始めた
与えられた問題を、自分たちのルールで解き始めた…！

1200体・7万通

集団で編み出した「ずる」
  • 修正の3日後、別のエージェント群で再テスト

コンピュートとは

争奪戦の対象となるもの
  • 21:53 GPU だけじゃない。サーバー・ネットワーク・電力・冷却まで含むAIインフラ全体
  • データセンターの規模は、いまや MW（電力）で表現される
  • 2025年末: 米 GDP 成長の大部分を AIインフラ投資が支える
  • 新たに稼働するコンピューターの1/3が、2社の需要に向けられる
  • 設備は Microsoft などが建設し、2社に貸す形（2028年頃までの長期の契約）
「誰が持っているか」より「誰が買い取る契約か」がカギ！

自己強化じこきょうかのループ

儲かる→買う→賢くなる
  • 売上 → コンピュートを高値で購入 → モデルが進化 → さらに売上
  • 基盤コスト 年1000〜1500万ドル → 売上は最大5000万ドル規模の例も
  • 「5倍」なら、どんどん買うしかない
  • 2社が使う新規コンピュート: 今年30% → 来年40〜50%
  • 新しいチップは同じ電力で3〜5倍の計算の能力
  • かつての「AIバブルは弾ける」説、売上の面では否定されつつある
ループが回り始めると、差は開く一方…！

11兆ドルの奪い合い

お金も人も AI へ吸い込まれる

  • うち5兆ドルが借金 → 政府・住宅・一般の企業と資金を奪い合う
  • 金利が上昇 → 住宅ローンが組めない、スタートアップが起きない
