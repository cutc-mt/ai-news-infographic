実験の設計: 記事を4本

2モデル × スキルなし・あり
  • 素材は全員同じ 検証ずみの素材 を渡す
  • note 記事を合計 4本 作成
  • 「スキルなし」2本 ＋ 記事作成スキルあり 2本
  • 仕上がりは条件を伏せて、盲検へ回す
スキルには16項目の指示を盛り込んでおく！

仮説かせつが結論にされた

動画タイトルの由来
  • 学長が仮説として話した分業案を…
  • Gemini は 「決めました」と断定に変えて記事化
  • 「仮定の話」を確定した事実のように書くのは危険
  • 15:47 書き上がった2本を読んで気づく
断定口調は、記事の信頼を静かに削る！

指示は16項目のうち4

守れた項目を数える
  • note 記事スキルの指示は全部で 16項目
  • Gemini が守れたのは わずか4項目
  • Fable は 16項目すべてを守って完成
  • さらに Gemini はスキルの有無で骨格がほぼ同じ
指示を守る力も、採点の材料に入れる！

Fable 5.1 の2本を読む

じっくり型の仕上がり
  • 19:35 所要時間は 4分 と 19分
  • 19分には別のAIによるレビュー工程が含まれる
  • 頼んだ分はきちんと2本とも作成
  • 仮説は仮説のまま、断定に変えず記述
遅いけど丁寧。読み直しまで含めた時間だ！

盲検で採点する仕組み

  • 採点者は Claude と Codex の2者
  • 軸は 速さ・点数・忠実さ の3つ

日本語の自然さは割れた

  • Codex の判定: 4本とも同点の扱い
  • Claude の判定: Fable をやや上と採点

「決めました」が増える

言い切りの回数を数えた
  • 数えたのは 「決めました」 「明確な方針」 などの言い切り
  • Gemini の2本: 6〜7回
  • Fable の2本: 1〜2回 にとどまる
  • 速く書けるほど断定が増える傾向が見えた

かかった時間を比べる

スキルの有無での差

モデルごとに反応が違う
  • 「スキルなし」と「スキルあり」で 同じモデルの2本 を比較

  • つまりスキルが効く相手は決まっている
