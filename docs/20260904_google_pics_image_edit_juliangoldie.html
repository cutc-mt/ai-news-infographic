Card 02

2年間の「再生成」ストレス

  • 画像の9割は良いのに、1か所だけ違う…
  • 例: 見出しの誤字、商品の背景、椅子の色
  • 再生成すると構図まで全部変わる。良い部分が消える
  • Googleも「結果が一定しない」「プロンプトの試行錯誤」「複数アプリに分かれた作業」を公認
本当のコストは「生成」ではなく、再生成のほうだったんですね…。
Card 03

Google Pix とは?

  • 2026年9月1日に公開された、画像の生成&編集ツール
  • 中身はGoogleの nano banana モデル
  • ブラウザで pix.new と入れるだけ
  • ダウンロード不要・インストールも不要
アクセス手順:
ブラウザを開く
  ↓
pix.new に入れて移動
  ↓
そのまま編集スタート
専用アプリは無し!いつものブラウザで、すぐ始められます。
Card 04

最重要機能: Object Segmentation

  • 動画でいちばん覚えてほしい機能はこれ!
  • 画像の中のモノを別々に理解してくれる
  • 椅子・ロゴ・上着などをホバーで選択
  • 選んだものだけ変更。他はそのまま残る
  • もう「最初から作り直し」は無し!
1単語・1オブジェクトだけ直せるのが、他のツールとの決定的な違い!
Card 05

コメント & 複数の編集をスタック

  • 特定の場所にテキスト・コメントを残せる
  • 「ここだけ直して」という指示が、画像の上で完結
  • 複数の編集をスタックして同時実行
  • 1つずつ待つ時代は、もう終わり
修正の依頼をメールで書かなくてOK。画像そのものが指示書になります。
Card 06

画像の中の「文字」を直接編集

  • AI画像ツールの弱点は、ずっと文字だった
  • きれいなポスターなのに WORKSHOP が崩れていたら台なし
  • Pix では画像の中の文字を直接、修正
  • デザインやフォントを壊さずに、書き直しOK
文字の修正・装飾の変更まで、画像のままでできるのが新しい!
Card 07

ワンクリックで、デザインを翻訳

  • デザインはそのまま、言語だけ交換
  • 複数の国向けに作り直す手間が、ごっそり消える
  • Google公認の用途: 世界市場向けのSNS・Web素材
  • 動画いわく「みんな見逃している」機能
海外展開する人には、これが一番うれしいかも。レイアウトの再構築が不要です!
Card 08

切り抜き・高画質化・もとに戻す

  • Crop: Web・SNS・印刷・デジタル向けに切り抜き
  • Upscale: 2K / 4K まで引き上げ
  • Revert: 気に入らない変更を、いつでも元に戻す
  • 地味に見えるが、失敗した1時間を救う保険
「元に戻せる」安心感があるから、大胆に編集できますね。
Card 09

Google公式デモは必見

  • デモ1: 芝刈り機の商品写真（背景なし）→ 屋外のシーンへ。処理は Slides の中
  • デモ2: ロゴを上げて → ギフト箱の試作 → 4K化 → Docs の企画書へ
  • 一連の流れ: アイデア → 画像 → 編集 → 文書
  • すべてが1つのタブで完結
Pix の製品ページに、デモ動画が公開されています。ぜひ本家も見てみて!

Workspace に組み込み済み

  • Docs と Slides は公開日から利用可能
単体ツールとの最大の違いは、この統合なんです。
