結論から: めちゃくちゃいい

自分の環境でついに解禁
  • 結論 Astra めちゃくちゃいい
  • GPT-6 Astra がまさお氏の環境でも使えるようになった
  • デモ作成から各種タスクまで、ある程度しっかり触ってきた
  • 「Fable がやばいんじゃないか」と正直思ったくらいのデキ
多少 Fable が良いくらいなら、
もう Astra でいいんじゃない?

一番の驚きはトークン効率

同じ仕事なのに消費が違う
  • 同じ 1 タスクでも、Claude だと大量のトークンを消費していた
  • Astra は X-High effort でもスマートに解決してくる
  • トークンが少ないのに待ち時間も短いまま
  • 「無駄なく問題を片付ける」のが Astra の個性
Claude Fableトークンを
どかっと消費
GPT-6 Astra少ない消費で
スマートに完成
effort を上げてもムダ遣いしない。
ここがいちばん衝撃だった!

デモ完走でも消費は少なめ

「1アカウント溶ける?」の不安
  • 実測 いつものデモを一通り回してみた
  • 「1垢くらい溶けちゃうかな…」と覚悟していた
  • 結果は消費 10〜20% で、リミット内に全部作り切った
  • OpenAI がいう「API コスト低め」のアピールは本当だった
Terminal-Bench 比較での「コスト安」アピール、
触ってみたらそのとおりだった。

ベンチマークは Fable 超え

主要 4 項目で 1 位を主張
  • Terminal-Bench: ターミナル操作で Fable を超える
  • コンピューターズ: 画面の操作まわりで 1 位という触れ込み
  • プロフェッショナル: CAD などビジネス道具での評価
  • コーディングでも Fable 超えをマーク
前回の動画で話題にした
「コンピューターズが1位」がポイント!

Computer Use が一段上

マサオキャラの SVG で実感
  • 実測 マサオキャラクターの SVG 再現率が高い
  • Fable や Gemini Flash の出来とは差が歴然
  • Opus も頑張ってはいるが、今回は別格
  • 「やばい」と思ったのは Computer Use とトークン効率
画面を見て操作する系の仕事で、
あきらかに精度が上がった印象。

3Dゲーム「青い森林」

HTML でサクッとできた
  • 作成 青い森林という 3D ゲームを生成してみた
  • HP 表示のような仕組みもちゃんと用意されている
  • 背景の効果音までしっかり作り込まれていて「すげえな」となる
  • F を連打したら勝てた(笑) ゲーム性はまだ伸び代
3D ゲームが サクッと HTML で
できちゃうのがもうすごい。

シューティング × effort レベル

気合の入れ方で出来が変わる
  • 比較 effort レベルを変えて 3D シューティングを作成
  • 敵の雰囲気が High / X-High でがらりと変わる
  • マウス移動の感触も effort しだいで変化
  • 作り込み・粘り強さを求めるなら X-High 一択
X-High はトークンをしっかり組んで、
周りの部分まで頑張って作るんだよね。

日本語とブログの文章

Muse Spark の解説ブログ
  • チャットで日本語をやり取りするぶんにはいい感じ
  • まさお氏の HTML フォーマットで Muse Spark の解説ブログを作成
  • 見出しの書き方やパフォーマンスの切り分けが明瞭
  • AI っぽさは多少あるものの、文章の密度が良いと好評価
ハーネスなしでここまでできる。
しっかり書かせるならハーネスが欲しい。

  • 実測 お願いしてもいないのに SVG でアイドルLPを作ってきた

  • レスポンシブ対応もいい感じ

マーブルランが半端ない

アクアリウムは余裕

SVG 素材としてもう使える

まとめ: 最も AGI に近い

今後の使い分けはこうなる
  • Codex のリセットが頻繁に発動、プランにも優しい
  • ハーネスのベースはいったん Claude ベースで(ウルトラコード好き)
  • Claude の 5 時間制限は、やっぱりきつい
  • 契約は Fable 中心から、しだいに Codex 比率を上げる方針
  • 結論: かなり良い。最も AGI に近いモデルと感じた
Fable が何もしなかったら、このまま
Astra 時代が来るかも…!
