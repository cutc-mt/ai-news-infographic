  • 「アライメント」とは、人間の意図に沿って動くように調整されている、という意味
「Sol の後継」と銘打つだけあって、
中身がガラッと新しくなった一本らしい！

最大の進化は Computer Use

人間みたいにPCを操作する
  • クリック、フォーム入力、アプリ起動を自分でやってのける
  • 社長の言葉: 「PCでできることは、Astra がだいたい代わりにやれる」
  • あなたの画面を見ながら、仕事を最後まで進めてくれる
  • 別のことをしている間のバックグラウンド作業も可能
  • 前のモデルより速く画面を制御できるようになった
相談相手から仕事の担当者へ。
みんなが騒いだのも納得の進化！

長い仕事でも軌道に乗り続ける

  • コンテキスト ＝ AI が一度に覚えていられる情報の量

強すざるセキュリティ能力

  • セキュリティ試験で OpenAI 自身の安全ラインを超過
  • 堅く守られたシステムへの動く攻撃手法（exploit）を構築

  • 本気の能力は審査済みの少数にだけ解放
