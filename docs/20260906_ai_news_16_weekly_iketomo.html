セクション1: 最強モデルの座をめぐる争乱

01

GPT-6 Astra ついに登場

実務の力がぐっと上がった新モデル

  • GPT-5 が長く続いたあとの大型アップデート。実務で使える力が一気に向上
  • 難しいタスクの数値がどれも桁違いに上がり、ベンチマーク視点では圧倒的なナンバーワンに
  • セキュリティ面の基準も高く、引っかけてはいけない罠への耐性が強い
主なベンチマーク
・ターミナルベンチ science: 52.6 → 60.70（Fable 5.1 を超える）
・Arc-AGI（難タスク実行）: 成功率 99.9%
・FrontierMath（難問数学）: ほぼ100% ← ほぼ異常値レベル
・ハニーポット（罠検知）: 5.6 で出ていた失点が 0% に
長らく「最強」と言われてきたクロードを、数値の面では大きく超えてきたよ、という週でした。 新時代の幕開け
02

GPT-6 Astra のすごいデモ

ワンショットでここまで作れる

  • 3Dモデルを1回の依頼で作成し、実際に動かせる
  • マリオカート級のゲームをその場で生成。カーソルキーで操作できてしまう
  • コンサル品質のきれいな資料もワンショットで仕上げる
  • ツール接続・ブラウザやPC操作のエラーが減り、エージェント作業が安定
ツールを連携して仕事を最後まで終わらせる エージェントアプリ時代 の主役になるモデル、という位置づけです。
03

Claude Fable 5.1 リリース

資料の見た目が1〜2段上へ

  • 4月の上位モデルを一般公開した Fable 5 が、5.1 に進化。さまざまな指標が向上
  • SVGで作る図解資料が1〜2段クオリティ上に。エージェントの仕組み図やアイコンも洗練
  • 処理の流れを見せるアニメーションも、同じ依頼でも出来がかなり違う
  • コスト試算シミュレーターの見た目も、5 よりぐっとかっこよく
Astra と 5.1、どっちが強い？
・画面操作・業務の自動化・サイバー能力 → Astra が上（公表値）
・難しい論理問題 Humanity's Last Exam や長い推論・文章 → 5.1 が勝ち
→ 結論: 物による。使い分けがポイント
どちらも上位プランだと使い切れないので、 月20ドルで両方キープして、ここぞという時に使い分けるのがおすすめ。
04

Gamma でスライド作成

中身は人間、見た目はAI（スポンサー）

  • ワークスロップ（見た目だけきれいで中身がスカスカ）が社会問題に。逆に中身があっても見た目で信頼を失うことも
  • 解決策は中身は自分で考え、スライドはAIに任せる分担
  • 文章を貼り付けるだけで、内容を保ったまま適切にページ分割。テーマも選べる
  • AI画像の挿入や、後からのPowerPoint形式で出力にも対応。無料でも使える
作っている様子をリアルタイムで見られるのが小気味いい、とのこと。 提案書・事業計画などにも使えます。
05

Gemini 3.8 Flash

「よく働く馬」的なコスパモデル

  • 3.7 Flash のわずか3週間後に登場という速さ
  • 100万トークンあたり入力 $0.75。Astra や Fable 5.1（$10）の約1/15
  • Google 自身がワークホースモデルと呼ぶ、安くてまあまあ賢い大量仕事向け
  • 3.5 Flash と比べても出来上がりの品質が1〜2段上。日常タスクのコスパ選択肢に
なぜこんなに早く出せる？
社内の学習処理能力が 1日 5000億トークン → 3兆トークン へ。
新モデルを出してはすぐ学習→次のモデルへ、という回転が効くようになった、と推察。
一方で 3.5 Pro クラスの大型モデルは未だ…という課題も。 体力と仕組みは整ってきたので、今後に期待。

Google Pix

画像生成が前提の編集ツール

  • Canva のような画像編集ツール。AI画像生成を主軸にした設計
  • 生成したあとにパーツを分解して、一部分だけ後から変更できる
  • みんな待っていた文字だけ差し替え機能。テキストを選んでそこだけ変更可能
  • Google スライドなどGoogle ツールと連携して軽やかに編集
  • 9月1日から順次リリース。2週間ほどで使える見込み
Google 系ツールを日頃から使っている人には、特に便利な一本になりそう。

サイドパネルのカスタム指示

毎回の指示入力が不要に

  • 各ツールの右側に出る Gemini サイドパネルに、特別な設定ができるように
  • これまでは毎回プロンプトを入れる必要があったが、パーソナライズ設定で解消
  • 対応範囲が Drive・Chat・Slides・Sheets・Gmail にも拡大
  • 9月2日から随時、2週間ほどで全体へ展開の見通し
「いつも同じ書き方で」「この形式で」という要望を、 いちいち言わなくてよくなるのが地味にうれしい。
08

OpenCrow 2.0

常駐AI社員がチーム対応へ

  • スラック連携が主だった旧版と違い、Web上のUIが主役に。導入も軽やか
  • チャット欄で個別に依頼でき、各所のやり取りを一覧で管理できる
  • チーム共有機能が新登場。依頼の途中から他のメンバーが介入・確認できる
  • 中国でも流行中の常駐型AI社員の先駆け。Gemini Spark や Grok Bot など類似サービスが続々
OpenAI アカウントでログインすれば、 既存のサブスクの範囲で運用できる模様。 情報を渡したくない作業なら安い中国製モデルで、という使い分けも面白い、とのこと。

OpenRouter 画像ベンチマーク

画像AIを実力で比べられる

  • 同じプロンプトを各モデルに投げて、出来を並べて比較できるサービス
  • Nano Banana 2 をはじめ、今ある画像モデルがずらりと勢揃い
  • 画像だけでなく動画の比較もある
  • 「このシーンではどのモデルがいい？」を自分で作らずに判断できる
画像モデルは日々塗り替わる世界。 選ぶときの参考ツールとして持っておくと便利です。

セクション3: すぐ効くビジネス活用

10

Grok Bot で経費のムダ削除

SpaceX の事例と、試したら月数万円カットの実践記

  • SpaceX が Grok Bot に未使用のアカウントやサービスを調査させた結果、10万ドル（約1500万円）の節約に成功
  • やり方は簡単: 会計ツールや各種サービスを接続して「使っていないものは？」と聞くだけ
  • 池友氏も実践: 会計ツール freee を接続してコストを一覧化。AI関連だけで年間120万円など細かいサブスクが判明
  • Microsoft 365 のメンバー付与ライセンスも整理し、月に数万円・年間で数十万円をカット
  • エージェントが自分で探し、契約の確認や解約まで処理。毎月の厳しい経理担当として運用できる
Grok Bot は Cursor の $200 プランで使えるほか、 Claude Code や Codex など他のエージェントでも同じことが可能。 クラウド費用・外注・広告などいろんなコストにも応用できて、多くの企業がすぐ真似できる即効性のある活用です。
11

NEC がコワークを全社展開

12万人規模への全社導入

  • 12万人規模へ Claude コワークを展開し、開始2ヶ月で1万人が利用開始
  • デスクトップアプリを配り、接続先を AWS 上に。データを国内で処理して安心を確保
  • 外部ツール接続の MCP 管理ツールも数週間〜1ヶ月という短期間で整備
  • 目標は半年後に1人あたり3体のAI社員。12万人が50万人分のパワーに
「うちは無理」と止まっていると差が開く一方。 チャットアプリからエージェントアプリへの移行を、大企業でもセキュリティを保ちながら実現できる実例。
12

クラウド×ローカルの使い分け

ハイブリッドAIが大事な理由

  • ① コスト削減: AIを大量に使うと月々の料金がすごいことに。ローカルで済む処理を振り分けて抑制
  • ② データを社外に出さない: 社内情報をローカルで処理できる
  • ③ 処理の振り分け: 難しいものはクラウド、そうでないものはローカル
  • 大手製造業が組み合わせで高騰していたクラウド費用を抑えた事例も
Mac mini 約50万円でできること
Gemma（Google）・Qwen（アリババ）・Meta のモデルなどをローカルで稼働。
バランス型の GPT-5.6 と比べても遜色ない SVG資料・エージェントフロー図・アイコンを作れる。 場面によっては評価が上回ることも。
「ローカルは品質が低いでしょ」という思い込みはもう古い、 かなり有力な選択肢になっている模様。

セクション4: テクノロジーの最前線

13

Perplexity ハイブリッド PC

個人情報の判断もAIにお任せ

  • メインはクラウドの賢いモデル。Mac に入れておくと働く仕組み付きサービス
  • 賢いAIが個人情報っぽいと検知したら、クラウドでは読まずローカルAIが代読
  • ローカル側がマスキング（まずい部分を消して）してから、クラウドへ渡す
  • クラウドとローカルの振り分け判断自体をAIが行う点が新しい
これまでは組み合わせの仕組みを人間が考えていたのが、丸ごとサービス化。 安く・安全にローカルを使う動きが加速しそう。

1枚の写真が3D空間になる

  • 写真や映像1枚から空間を生成。カメラをぐるぐる動かして確認できる
  • ただの動画生成ではなく、物理法則を踏まえた3D空間として理解・構築
  • ロボットを空間に入れて歩いたらどうなるかを試す、学習環境として活用

AIがAIの安全性を調べる

Anthropic の効率化の取り組み

  • モデル作成後の安全性チェックをAIに任せる実験が進行。速く・安く・効率的に
  • 2週間ほど前には OpenAI と Anthropic のエージェントが外部のテスト回答を盗んで解く問題が発覚
  • 人間だけでは検査に限界。網羅性・深さ・角度で踏み込めるのがAIの強み
  • ただし「AIの判断が正しい」の証明は難しく、完全放置は怖いという見方も
検査するエージェントを育てて地道に叩き、 安心して出せる新モデルを作る体制づくりが進んでいます。

セクション5: ビッグテックとマネーの動き

16

EC向けエージェントの設計図

Anthropic が GitHub で公開

  • 実装方法・スキル・エージェントの定義をまとめたブループリントを公開
  • 社内向け: 社内データの分析・在庫の管理・アラート発報
  • 顧客向け: 商品提示からカートまでを支援（購入は本人が操作）
  • 金融・弁護士向けに続く展開で、コワークのプラグインからもワンクリック導入の方向
重要な発見（検証結果）
① 複数のサブエージェントに分割 → ×
② 1つのプロンプトに全部盛り → ×
③ 1つのエージェント＋複数スキル（必要時に自分で選択） → ◎ 一番精度が高い
※ 担当を分けすぎると伝達コストが増える。1人が全体を知り、必要なスキルだけ参照する形が効率的。
この学びはEC以外の社内エージェント設計にも応用できるはず。 エンジニアでなくても「これを真似して」と渡せば導入できる時代に。

ChatGPT広告、10億ドルペースに

リリース200日で到達

  • スタートから200日ほどで年間10億ドル（月あたり8000万ドル）のペースに到達
  • 広告が出るのは無料版などのユーザー向け。上位プランでは出ない

  • B2B・高単価商材は苦戦: クリックはされても問い合わせにつながらないケースが多い
  • 一方で一般消費向けは成果が出ている例も。向き不向きがはっきり分かれる段階
  • OpenAI はこの事業を1000億ドル規模（約15兆円）へ育てる構え
かつて Google のリスティング広告を使いこなした事業者が伸びたように、 いまは競合が少ない開拓期。 試すなら今がチャンス、との考察でした。
