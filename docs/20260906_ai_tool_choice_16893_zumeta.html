はじまりは、いつもの風景

01

「いい感じに作って」

  • AIにアプリを作ってもらう。頼み方は一言、いい感じに作ってだけ。
  • 本当に早い。あっという間に形になる。
  • でも メールを送る機能に、自分が選んだ覚えのない会社の名前が入っていた…？
ネタン:「AIが選んだのだから、1番いいやつなのだ」

今日の主役は「AIがあなたの代わりに何を選んでいるか」。勝手に選んでいる部分こそ、ちゃんと見ていきます。
02

  • 3つとも同じものを選んだのは、じつは 42% だけ。

03

頼む人が4段階ある

  • 症状だけ言う人…「調子が悪い」
  • 分野まで言う人…「〇〇系のアプリが欲しい」
  • 条件を言う人…「ここは外さないで」
  • 避けたいことまで言う人…「これは絶対やめて」
  • 悪い頼み方、ではない。ただ 言わなかった分は全部AIが決める のよ。
  • 避けたいことまで言う人には、AIは条件に合うものを探しに行く。
細かく言うほど、AIが勝手に決める部分は減っていきます。
04

AIの「良い」基準

  • 何も言わないと、AIが好きに決める…ように見えるけれど。
  • 正しくは AIが良いと思う基準 で決めている。
  • 今日はその基準の中身を見に行きます。
頼み方 × AIの基準 = 選ばれる道具
      ↑                ↑
  ここは自分で      ここは今日
  決められる        はっきり見える
「AIが選んだ＝世界一」ではない。そのAIが知っている中で、1番よく見えたものです。

14

ゼロという扱い

  • もっと極端な例。置き場所を貸す会社（倉庫系）で調べたら…
  • 片方の現場では、ある道具が選ばれ続けた。
  • もう片方では、1度も名前が上がらなかった。ゼロ。
  • 同じ会社なのに扱いが真逆。AIは よく使われている組み合わせ＝相性 で決めている。
倉庫会社の例
  現場A → 毎回えらばれる ◎
  現場B → 名前すら出ない  〇回（ゼロ）
順位表を覚えても自分の場合には当てはまらない。覚えるべきは「変わる」という事実のほう。
15

当て馬になる名前

  • 支払いの分野で、ある会社（PAL系）は 139回 も名前が上がった。
  • 選ばれたのは 0回。139回も話に出たのに1回もない。
  • そのうち 124回 は Stripe が選ばれた。
  • 候補には上がる、でも選ばれない。比べるための当て馬 になっている。
  • いちばん多い 194回 名前が出た道具も、選ばれたのは 4回 だけ。
人が選ぶ世界では「目に入る回数」に意味があった。広告を見せても、AIには効かないのです。
16

書いてある一文で決まる

  • メール系の道具。無料枠の説明に 「記録は1日で消えます」 の一文。
  • AIはそこを読んだ時点で、次の候補へ 行ってしまった。
  • 人間なら「有料にすればいいのでは？」と聞き返す場面。AIは聞き返さない。
  • Supabase の例。置場だけ欲しい場面でも、頼んでいない機能まで束にした料金 説明 →「余計が多い」と不利に。
書いてあること ＝ そのまま判定材料になる
  「1日で消えます」 → 不利と判断
  「全部入り料金」 → 余計が多い、と判断
つまり、書き方しだいで直せる負け。中身が悪いわけじゃないのです。

18

まとめ：明日からの3つ

  • AIに任せているのは 作る手間だけじゃなく「選ぶこと」も。
  • その選び方は AIごとにも、置く場所ごとにも変わる。割れるのはAIが悪いからじゃなく、見ている世界が違うだけ。
  • 作ってもらったら、「何を使うことにしたの？」と1回だけ聞いてみる。
  • それだけで、名前も知らないものが黙って入るのを防げる。答えは普通に返ってくる。
  • 気になるなら別のAIに同じ文章で頼む。違う名前が出たら、そこは 迷っていい場所。
  • 「いい感じのやつです」と返ってきたら、ちゃんと名前で答えてと頼み直すのも一手。
教訓: 入る前に名前を見ておくのが、いちばん安い保険。
聞き方を変えると、返ってくるものが変わる。今日の1番の収穫なのだ。
