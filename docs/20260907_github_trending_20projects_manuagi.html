スキルでひろがる Claude のとくいわざ Agent Skills の世界

01

Skills

anthropics/skills

Claude用公式リポジトリ
  • Claude を特定のタスクにとくい化させるエージェントスキルの公開まとめ場所
  • 中身は skill.md に指示・コード・リソースを同梱
  • 同じ作業を何度も安定して繰り返せるのが強み
  • Claude Code のプラグイン市場や API から登録できる
skill.md
├─ 指示 (instructions)
├─ コード / スクリプト
└─ リソース類
「いつもやる手順」をまるごとskill.mdにまとめて、Claudeに任せてみよう！
02

caveman

トークンをくい止めるスキル

Claude Code スキルトークン削減
  • エージェントの応答を原始人風の省略語にさせて出力を圧縮
  • 技術の中身はそのまま、ムダな言葉だけをそぎ落とす
  • 30以上のエージェントで動作：Claude Code、Codex、Cursor、Copilot
  • ローカルプロキシ経由で、読み込み側のトークンも圧縮
「ウッ、長い。短くする。」…で、コストも一緒にやせ細るのがミソ。
03

diagram-design

雑誌クオリティの図づくり

Claude Code スキルHTML/SVG
  • エディトリアル品質の図を HTML / SVG で生成
  • 27種類×3バリアント：アーキテクチャ、フローチャート、シーケンス、タイムライン…
  • サイトのパレットとフォントを読み取って、ブランドに合わせる
  • PNG / SVG でそのまま書き出し可能
ブログの図が10秒で仕上がる。配色まで読み取ってくれるのが賢い！
04

Chinese patents.skill

特許のとりきめをまるごと支援

中国特許エージェントスキル
  • プロジェクトの文書から特許性のある要点を抽出
  • 新規性の検索から、明細書のドラフト作成まで一気に
  • 中国の特許庁 CNIPA の書誌レコードを検索できる
  • 拒絶理由の通知への対応案も用意してくれる
  • Claude Code / Cursor で動き、Obsidian vault に保存
専門家の作業をエージェントが下支え。スキルの威力がよくわかる一本。

声と耳の、ローカル革命 クラウド不要の音声たち

05

VoiceStudio

ElevenLabs の完全ローカル代替

646言語APIキー不要
  • 音声クローン、音声デザイン、吹替、ディクテーション、文字起こし、オーディオブック生成をすべてローカルで
  • アカウント・APIキー・クラウドが一切不要
  • CPU / GPU ルーティングで処理を賢く振り分け
  • 複数の声をかけ合わせられるオーディオブックエディタ搭載
音声の生成が全部自分のマシンで完結。月々の支払いともおさらば！
06

OpenWhispr

WhisperFlow / Granola の代替

プライバシー重視音声入力
  • ホットキーを押して話すと、カーソル位置に文字が浮かぶ
  • Whisper / Nvidia Parakeet でローカル文字起こし。音声はデバイスの外に出ない
  • 会議の文字起こしは話者分離つき
  • API / MCPサーバーも同梱で、ほかの道具から呼べる
「話した内容がどこかのクラウドに飛ぶ」不安がゼロになる設計。

モデルを鍛える、伸ばす、ほどく ポストトレーニング三兄弟

07

miles

大手向けの RL フレームワーク

エンタープライズ向け強化学習
  • 大規模モデルのポストトレーニング用。Slimeからフォーク
  • eskel langで高スループットなロールアウト
  • Megatron LMでスケーラブルな学習
  • ロールアウトと学習ワーカーを非同期に分離
  • エンジンが落ちても自動で復帰する設計
大規模な学習を回し続けるための、炭鉱夫のような頑丈さ。
08

Heretic

拒否挙動をほどく CLI

CLIツール再学習なし
  • 言語モデルの拒否挙動（安全のアライメント）をポストトレーニングなしで除去
  • directional ablation（obliteration）とパラメータの自動的な最適化を組み合わせる
  • 元のモデルの能力をできるだけ残す工夫
  • 密モデル・マルチモーダル・MoE にも対応
強力な道具。使い道と責任は使う側にある、という一言を添えて。
09

axolotl

ファインチューニングの名脇役

YAMLで設定1GPU〜複数ノード
  • 言語モデルのファインチューニング / ポストトレーニングを効率化
  • run を YAML で書くだけで学習の設定が整う
  • Llama / Qwen / Mistral / GLM などをフルFT・LoRA・QLoRA・DPOで学習
  • Flash Attention、RoPEスケーリング、マルチパッキング対応
  • FSDP / DeepSpeed / テンソル並列でスケール
load_model: meta-llama/Llama-3-8B
adapter: lora        # or qlora / full
method: dpo
...
axolotl は「ウーパールーパー」の仲間。地道な再学習の心強い友。

エージェントの新しいかたち 長く働き、賢く回る

10

prime-agent

自分を磨き続ける RLM

長時間タスク自己改善
  • 長時間のコーディングを任せる、みずから改善を重ねる RLMエージェント
  • コンテキストを変数に、ツールとサブエージェントを Python REPL 内の関数呼び出しとして扱う
  • プロンプト / メモリ / スキルを永続状態として磨き続けるハーネス
  • サブエージェントは並列実行、デタッチ後もセッションが続く
仕事を重ねるほど自分の道具が育つ。「見習い」がいない現代の救い。
11

Cloudflare OS

Workers 上の仕事スペース

Cloudflare社内利用エージェント対話
  • Cloudflare Workers 上で動くエージェントの仕事場
  • 会社のコンテキストを先に読み込ませたエージェントと対話
  • gadgets というサンドボックスアプリをその場で構築
  • Gatekeepers セキュリティ層が GitHub / Google / Slack をラップ
  • 許可はあとから承認することもできる
セキュリティの見張り番つきで、エージェントを会社に住まわせる試み。

開発者と作家の、道具箱 手元で動くいい道具

12

OpenLogi

Logitech Options+ の代替

Rust製テレメトリ不要
  • ローカルファーストなマウス設定ツール
  • Bolt / Unifying レシーバー、Bluetooth、USB の接続経由で HID++ に対応
  • ボタンのリマップ、DPI、SmartShift、アプリごとのプロファイル
  • アカウント / テレメトリ不要、設定は TOML に書き出し
マウスの設定ひとつとっても、クラウドのアカウントは要らないという主張。
13

dotenvx

dotenv の安全な後継

クロスプラットフォーム公開鍵による暗号
  • コマンドの前に dotenvx run -- を付けるだけで .env 変数を注入
  • .env ファイルを公開鍵で暗号化して、そのままコミットできる
  • 秘密鍵があれば手元で復号
  • 複数環境、バリデーション、シークレットの自動マスキングに対応
$ dotenvx run -- node index.js
[dotenvx] injecting env (2) from .env
.env を git に入れたい…そんな背徳の願いを、暗号で安全にかなえる。
14

NEO

Hugh Howey 作の執筆アプリ

無料執筆に特化
  • 小説家 Hugh Howey が作ったデスクトップの執筆アプリ
  • 書くことだけに特化し、よけいな機能はなし
  • 原稿が本のように見える、読み心地の画面
  • ローカル保存（プレーンなファイル）で、アカウントもサブスクも不要
  • 本棚ライブラリ、EPUB / Word / PDF / Markdown の書き出し
「Wool」の作者が好みで作った道具。書く人への贈り物みたい。
15

trustmebro

Mac の付せんアプリ

Swift / SwiftUIドックに置かない
  • ドックアイコンなし・ウィンドウ管理なしの割り切り設計
  • 画面の端にスリムなピル状に置いて、ポインタで扇状に展開
  • 好きな行をショートカットひとつでチェックボックスのタスクに変える
  • SQLite でローカル保存 + AES-GCM 暗号化
名前はふざけているのに、暗号化は真面目。この落差がいい。

知識・統計・ロボット、その先へ 個性派ぞろいの5つ

16

Utopia

事実の寿命を覚える知識ベース

セルフホストナレッジグラフ
  • 「その事実はいつ正しかったのか」を記憶する仕組み
  • RAG をナレッジグラフ上で実行、各事実に有効期間を持たせる
  • 修正は前バージョンを閉じて新しく追加する形
  • PDF / Word / Excel / Web / RSS を取り込み
  • 全文＋ベクトル検索を RRF で統合、引用つきの回答をストリーミング
「今はちがうけど、当時は正しかった」を残せるのが新しい。
17

TokensBurned

プロフィール用の統計カード

GitHubプロフィールプライバシー保護
  • AIコーディングのトークン数とモデル情報を収集
  • 15分バケットに集約して、SVGカードを生成
  • 24時間 / 週 / 月 / 全期間の合計を表示
  • ヒートマップ、ハーネス比較、匿名ランクつき
  • プロンプト / コード / リポジトリ名はローカルから出ない
「今月どれだけトークンを燃やしたか」見せるのが楽しくなる統計。
18

LightNav-0

からだのための小さな模型

Qwen3-VLベースゼロショット転移
  • 小型の汎用身体ナビゲーションモデル
  • タスク別の予測ヘッドなしで、指示追従・オープンボキャブラリの物体検索・視覚追跡を実現
  • すべてを 1つの共有トークン インターフェースに集約
  • 一人称カメラの履歴と言語指示から、空間指示トークンとアクショントークンを出力
  • 人型・四足・車輪・飛行ロボへゼロショット転移
「小さくて、どこでも動く」。ロボットの共通言語への近道かも。

ABYSSAL

natural-disasters

Three.js + WebGL2GPU数学のみ
  • ブラウザで動く海洋・天気のシミュレーション
  • 波・雲・雨つぶ、すべて GPU の数式で生成。アセット読み込みなし
  • マルチカスケードFFTの波、レイマーチのボリュメトリック雲
  • シネマティックストーム or サンドボックスで、ハリケーン・津波・竜巻・落雷を発生
テクスチャ一枚なしで海を作る職人芸。目が肥えるデモ。

LLMが苦手な「組み合わせ最適化」を専用機に任せる分業の形。
