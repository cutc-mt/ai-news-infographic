01

そのマシン、もうある

  • 本格的な AI モデルに、どれくらいのマシンが要る？
  • ほとんどの人は大きく見積もりすぎ
  • 最低ラインは 7GB メモリだけ
  • その機械は、もうデスクの上にあるはず
7GB あれば動く。それが最低ライン！
02

誰にも止められない

  • 一度ダウンロードすれば、ファイルは自分のもの
  • アカウントの停止もない
  • ドライブに保存したコピーは自分のもの
  • 誰の許可もいらず、動かし放題
手元に置いたモデルは、誰にも止められない！
03

初心者の落とし穴

  • 初めて使うと「モデルが壊れている？」と感じる
  • 原因はあるデフォルト設定
  • 警告してくれる人は、ほとんどいない
  • 答えは後半の「設定のヒント」にあり
遅い・壊れた？ それは設定のせいかも！

方法 1: QwenStudio（かんたん・2分）

04

本番の性能とは別物と、心得よう！

07

  • メモリと GPU があれば OK
  • ネットがなくても動作する
  • 完全に自分のものとして運用できる
無料で、手元で、限りなく自由！

09

Apache 2.0 の意味

  • Apache 2.0 は最もオープンなライセンス
  • 重みデータのダウンロードが可能

  • 自分の製品への組み込みも OK
時間の制限なし、停止もなし！
10

自由の内訳

  • 実行・変更・調整 すべて自由
  • ファインチューニングや、製品への組み込みも可
  • 期限なし・停止なし・利用の打ち切りなし
  • ドライブのコピーは、ずっと自分のもの
「使っていいよ」の期限は、永遠にない！
11

機能の削減なし

  • 画像をネイティブで認識
  • 動画もそのまま理解（1時間の映像まで）

  • 後付けのアダプターは不要
見えるものは、だいたいそのまま分かる！

外に出さない強み

機密が外に出ないのが、ローカルの価値！

設定のヒント: トラブル回避

15

ヒント 1: 推論の努力

  • デフォルトの「推論の努力: 超高」は負荷が高すぎる
  • 単純な質問でも考え込み、コンテキストを無駄に消費
  • Unsloth のガイドどおり ミディアム へ
  • 簡単な質問なら、思考のプロセスを完全オフにもできる
「遅い・壊れた」の正体は、たいていこれ！
16

ヒント 2: 上限の引き上げ

  • ローカルのアプリには、独自の上限があり
  • ある例では既定が 8,000トークン強（低すぎ）
  • モデル自体は 262,000トークンまで処理できる
  • 他のせいにせず、設定を探して引き上げる
# 設定のイメージ
reasoning_effort: "medium"   # 超高 → ミディアム
context_length: 262000       # 8,000 → 引き上げ
上限が低いと、モデルの力が出ない！
17

ヒント 3 と 4: ファイル選び

  • 量子化ファイルは、メモリ表から自分のマシンに合うものを
  • コメント欄の推奨を、そのまま信じない
  • 100万トークン拡張は、必要な時だけオンに
  • 一度オンにすると常に適用され、短いプロンプトでは結果が悪化
自分の環境に合わせるのが、正解！
