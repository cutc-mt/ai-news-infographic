③ スキルファイル機能

Skill Files

スキルファイルとは

  • エージェントが作業の手順を 学習
  • 「スキルファイル」として保存
  • 次回の同じ作業に活かせる
  • 使うほど 上手になる エージェント
操作を「育てる」感じが新しいですね！

個人スキル

  • あなた専用のスキル
  • 好みやワークフローを記録
  • よく使う手順が自動で定着
  • 自分の環境向けに最適化
「いつもこの順番でやってね」が保存されます。

共有サイトスキル

  • ウェブサイトの操作の知識を 利用者みんなで共有
  • サイト側の仕様が変わったら運営チームが更新
  • 壊れた手順は最新へ置き換わる
みんなの知恵を借りられるのが強み！

Markdown で自由に編集

  • スキルファイルは Markdown 形式
  • 自分で読む・書く・直す が自由
  • おかしな手順は手で修正できる
# skill: 求人サイトの検索の手順
1. キーワードを入力する
2. 「リモート可」でしぼり込む
3. 結果を表にまとめる
中身が見えるから安心。自分好みに直せます！
