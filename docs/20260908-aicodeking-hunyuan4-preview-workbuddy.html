WorkBuddy の仕事ぶり

タスクを分解して、並行で動く

  • 与えたタスクを サブタスクに分解
  • 複数エージェントを並行 で動かして一気に進行
  • ブラウザ操作・ローカルファイルの読み込み・コード実行をこなす
  • 仕上げに レポート・スライド・スプレッドシート・Webアプリ を生成
task: "経費の監査をして"
  ├─ plan()    # サブタスクへ分解
  ├─ agents()  # 並行実行
  └─ output()  # 成果物を作る
指示は1つ。あとは部下たちが勝手に動いて書類まで仕上げてくれるイメージ！

デモ1: マリオ風ゲーム

Canvas API だけで再現

  • HTML5 Canvas API ＋ プレーン JavaScript のみ。Phaser などゲームエンジンは一切なし
  • 画像ファイルなしで、ピクセルアートのキャラやタイルを直接描画
  • 重力・慣性・ダッシュ、キーを押す長さでジャンプの高さも変わる
  • 地形・レンガ・アイテムブロックの完全な当たり判定、敵の踏みつけも再現
  • ゲームループは requestAnimationFrame で自前実装
  • まず計画を立てて段階に分解 → そのまま一気にコードを書き切った
1回の出力で完成！大きいクローズドモデルでも当たり判定でコケるのに…これは驚異的！

デモ2: ネオン街の3Dレース

17

デモ3: 経費の監査報告

このモデルの真骨頂

  • 教材は 24件の経費精算 ＋ 複数バージョンの規定 ＋ 従業員記録 ＋ 予算 ＋ 手当の使用状況 ＋ 請求履歴 ＋ 大量メール
  • 「経費監査の専門家」として、全額承認 / 一部控除 / 差し戻しの3つに分類
  • 規定が2種類あることを見抜き、申請日で適用バージョンを判定
  • 同じ請求書番号が別の日で2回 → 重複3件を検出
  • 手当の上限到達1件・古い規定で出された請求2件も特定
  • 要約の Word 文書 ＋ 全申請の調査結果を載せたスプレッドシートを生成。合計控除額も手動確認で全部正解
  • 根拠のない捏造なし。24件すべてで一貫性をキープ
人間なら丸1日以上かかる仕事。長期タスクでブレないのがいちばん難しいのに、完璧！

デモ4: 調べて10枚のスライドへ

リサーチ → 資料まとめ

  • テーマは「オープンウェイト系コーディングモデルの現状」を詳細に調査
  • ブラウザ機能で多くのソースを読み、数値を表にまとめるところから開始
  • デザインと比較表入りの 10枚のスライド に整理して完成
  • 表の数値を抜き打ちで確認 → ソースと一致。「AI製にしては見た目も悪くない」レベル
調べる・まとめる・きれいに仕上げる。オフィス仕事のフルコースを1本で完走！
