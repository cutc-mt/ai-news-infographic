GPT-6 Astra と Claude Fable 5.1
どっちを使う？

まず、結論から

結論を先に話すと

  • 複雑・メタなタスクは Claude Fable 5.1 中心
  • Astra は ハーネスに組み込んで 併用していく
  • これは「AIエージェントに無茶ぶりしがち」な彼自身の使い方の結論
  • 数日間、Astra も Fable も使い込んだ上での主観ベースの感想
正解は人それぞれ。自分のタスクに合う方を選ぶのがいちばん大事!

Fable の強み: 直感の良さ

  • 未知の問題や 複雑すぎる問題に向き合ったとき、いちばんいい直感を見せてくれる
  • 対話していても「とにかく難しいことにチャレンジしたい」感がある
  • 彼の仕事はメタより・ハーネス作りが多い → Fable でやっていくと決断
天井の高さは断然 Fable。むずかしい問題ほど本領発揮!

みんなが Fable 向きとは限らない

  • メタなハーネス作りや、むちゃなタスクばかりやる人は少数派
  • 万人受けするモデルとしては GPT-6 Astra が結論
  • 0から今から始める人には、おそらく Codex の方が使いやすい
ハーネスがしっくり来ない人には Fable もしっくり来ない、という話も納得。

Fable の弱点: トークン消費

  • 使っていると トークンが本当にすぐなくなる
  • X-High エフォートを使おうものなら 速攻で枯渇
  • Medium エフォートでも、Astra と比べるとかなり減りが早い
  • サブスク費用がかさむ。実際、複数アカウント課金が求められるレベル
高性能だけどガソリン食い。財布と相談が必要…
Claude Fable 5.1 の特徴

エフォート別のトークン消費

同じ X-High エフォートでも消費が全然ちがう(彼のログ調査より)

たっぷり使う
Fable 5(旧)基準 ×1.0

  • 同じ X-High 同士でも Fable 5.1 は旧 Fable 5 比で 約1.8倍 消費
高いエフォートの Fable は「全然使えない」環境になっている、とのこと。

5時間制限と週制限

  • 5時間制限 の枠がある
  • 週50%制限 など、Claude のサブスクは制限が「激しめ」
  • トークンが使えない × 課金が必要 → 万人受けしない理由に
限界が来るのが早い。へビーな人ほど週制限がネックに。
GPT-6 Astra の特徴

Astra はトークン効率がいい

  • Fable に比べると トークンをあまり使わない
  • ただし前のモデル(GPT-5.6 Solo など)よりは使う印象
  • 1つの問題に向き合うときのトークン効率が Fable とは全然ちがう
  • 「1問題あたり」の消費が少なく、長く使い続けられる
燃費がいいので、がんがん投げても安心して使える。

Low エフォートでも直感がいい

  • Astra は基本的にどのエフォートでも スマート に動く
  • Low エフォート でもいい直感を出してくれる → 使いやすい
  • 一方 Fable は Medium くらいは欲しいと感じる
エフォートを落としても賢い。これが Astra の使いやすさ。

エフォート戦略の使い分け

  • Low: 日常の軽いタスク・まず直感をもらう
  • Medium: 検証や作り込み
  • X-High: しっかり作り込む・アプリを厳しく検証したいとき
  • 彼自身は「しっかりやってほしい」派なので High / X-High 設定が多め
いい直感が出たら、あとはエフォートを上げてリッチに作り込むのが流れ。

ハーネスの積み上げ: クロードの上に

  • Claude には スキル / サブエージェント / コンテキストフォーク などの仕組みがある
  • ウルトラコード や エージェントチーム など、いろんな概念が実装済み
  • それらを活かす設計でハーネスを積み上げてきた → クロードのベースに乗り続けるのが得
  • Codex 側に同じものを0から積むコスト vs そのまま Astra を呼ぶコスト → 後者でいく
Claude Code のハーネスは作れすぎている。この積み上げが強み!

Codex ハーネスの印象

  • Codex ハーネスは彼には しっくり来ていない
  • ただし ボイスはめっちゃいい
  • 0から始める人は Codex の方が使いやすいだろう、との見立て
  • ChatGPT アプリで全部解決したい人・リアルタイムボイスで整理しながらタスクを投げたい人は OpenAI 系が強い
ボイス最強・積み上げは Claude。使い手の好みで分かれるところ。

得意分野のすみわけ

  • 答えのある問い → 差を感じない。似た使用感で使える
  • コンテキストが十分ある 数処理・分析 → Astra が得意。鋭い仮説をデータから出すのがうまい
  • 発散方向 のタスク → Fable が強い
  • 収束方向 のタスク → Astra がいい
発散は Fable、収束は Astra。迷ったら方向で選ぶ!

視野の広さと自走力

  • 旧 GPT シリーズは「視野は狭いけど深い」印象だった
  • Astra はその視野の狭さが Fable のように広くなっている
  • 使用感は GPT-5.6 Solo を賢くした感じ。使い勝手が良くて強力
  • 自走力も高い。ハーネスなしでもモデル自力で十分なパフォーマンス
  • /goal で永遠にゲームや 3D を作らせる使い方でも活きる
昔のような認知ドリフトの悪さはかなり薄れている、との評価。

ハーネス構成: 使い分けの設計

  • Planner(計画) → Fable が担う。全体のオーケストレーション
  • Generator(実装) → Fable / Astra / Opus を使い分け。Claude ハーネスなら Opus、別に Astra でもいい
  • Evaluator(検証) → 軽めの検証・テストは Opus へ流す。重い判定は Fable
  • 最後の判断は コンテキストが豊富な Fable + オーケストレーターも参照
  • ループの中に マルチ Evaluator を入れる設計。問題によって重みを変える
Fable が計画して、Astra / Opus が実装して、Fable がレビューする、みたいな分担。

発散と収束で使い分ける

  • 発散方向: Fable。メタ認知・むずかしい問題・自己改善の議論に強い
  • 収束方向: Astra。決まったことをスマートにまとめるのが上手
  • レンジとしては Fable は全部いける。ただトップ(発散)だけ Fable、そこから先は Astra に任せるのが効率的
  • シミュレーションを外側からどんどん抽象化していくような むちゃな問題は Fable がしっくり
上の層だけ Fable、あとは Astra。コスパ最強の使い分け!

まとめ: あなたはどっちタイプ？

  • 万人受け・効率重視 → GPT-6 Astra。Low でも賢く、燃費もいい
  • 天井の高さ・発散重視 → Claude Fable 5.1。ただしトークン消費と制限に注意
  • へビーに Fable を使い倒すなら 複数アカウント課金も視野に
  • 彼の今後は Fable オーケストレーター × Astra 組み込み。Delegate Codex スキルで任せる仕組みを継続
  • みんなの感想はコメント欄で教えてほしい、とのこと
正解はひとつじゃない。自分のタスクと財布で選ぼう!
