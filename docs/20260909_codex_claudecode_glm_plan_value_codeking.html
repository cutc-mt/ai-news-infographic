失敗談: モックのグリーン

— 2日間の教訓 —
  • ループを2日間ほったらかし、毎回テストが全部グリーン
  • アプリを開いたらチェックアウトの導線が死んでいた
  • ボタンを押しても無反応、エラーすら出ない状態
  • 原因: エージェントが自分のモックに対してテストを回していた
  • 自分のマシンでのグリーンは何も証明しない
「できました」の報告どおりでも、実ユーザーには使い物にならない……。だから検証を外注できないか考え始めた。

モデル群と Ultra mode

— エージェント機能 —
  • 主力は GPT-6 Astra。多くのタスクで Fable に迫る出来
  • サブモデル: Sol Terra Luna(用途別に使い分け)
  • Ultra mode: タスクの一部を追加エージェントへ委任できる
  • 表示される選択肢はプランと展開の状況で変わる
  • fast modeは応答が速い代わりにクレジット消費が増える
「委任できるかどうか」は大きい。一人で回すより、一段上のスループットが出せる。

API 換算の価値とは

— 計算のルール —
  • 記録された入力・キャッシュ入力・出力を API 単価で値付け
  • 「そのトークン活動を API 経由でやったらいくらか」の意味
  • サブスクが API 口座にお金を入れてくれるわけではない
  • API で同じ結果が出るとも限らない
  • 計算はシンプルに保つ、が今回の方針
// 換算のイメージ
apiValue = input*rate_in
         + cached *rate_cached
         + output*rate_out
あくまで「同じ量を API で買ったら」の目安。保証された月額でもなんでもないよ。

$200 プランを実測

— 43分のサンプル —
  • 調査・開発の作業 約43分を実施
  • 週次メーターが 0% → 3% に移動
  • 記録を監査して API 換算 約$34 の活動と判明
  • $34 ÷ 3% で週の満枠まで外挿 → 30日換算へ
  • 安いプランは公称の比率で按分(直接テストは未実施)
これは検証していない外挿。最初のサンプルから「こう見える」ってだけの試算だよ。

検証のゆらぎと限界

— メーターのクセ —
  • 追試: Astra リクエスト20回分(≈$35)を投げて確認
  • 週次メーターは最初は動かず、後から増えた
  • 他の作業が並走していて、増分をテストだけに割り当てられない
  • 丸められた読み値 + 更新タイミングの不確かさ = 換算は信頼性が低い
  • 結論: 活動は計測したが、固定の月額の保証は確立できていない
「最初のサンプルが示唆する値」であって、「全アカウントが受け取る約束」ではない。ここ大事。

banked resets(払い戻し枠)

— プロモーション機能 —
  • OpenAI が対象ユーザーに配る取っておける一回分の補充
  • 使うと5時間+週次のリミットが両方リフレッシュ
  • 週次のリセット日も変わる(期限があるので注意)
  • 有無は usage の設定から確認できる
  • プロモーションなので提供は不定期・未来の保証なし
  • 今回の計算にはリセットも購入クレジットも不使用(公平性を確保)
切れたときに1回分の補充があるのは地味に便利。ボーナス頼みの計算じゃないのがポイント。

デスクトップアプリ & 画像の生成

Fable はレイアウトの好みが勝つけど、素材をどこから調達するかは自分で考えないといけない。Codex はそこがラク。

  • 問題の調査 → 修正 → 動作の確認まで一人で回す

Codex の気になる点

— 予測のしやすさ —
  • ルールや特典が変わる頻度が高い
  • ある時は太っ腹 → 上限が変わる → また別のプロモーション
  • 改善のテンポは速く、意見にも応答しているのは好評価
  • でもサブスクにはもっと安定した予測しやすさが欲しい
成長の速さと安定感はトレードオフ。今の数字を「永遠」と思い込まないことが大事。

キャッシングの効果

— 同じ案件を続けるほど —
  • 過去リクエストの一致した文脈を低い入力コストで再利用できる
  • サンプルの割合: Astra 入力の 94%、Sonnet 入力の 79% がキャッシュ
  • 98% 再利用を仮定すると、Codex は+25%、Claude は+9.3%多くのトークンを処理できるように
  • Claude は出力に価値が偏り、入力系の割引が効きにくい
  • API のドル換算は不変。単位の作業が安くなり、同じ枠で多くこなせるイメージ
$200枠通常98%再利用
Codex28億36億 tk
Claude4.66億5.10億 tk
トークン総数にはキャッシュの重複が含まれるし、「新規コードの量」でも「完了した仕事」でもない。モデル化であって計測じゃない点に注意!

GLM と最終的なおすすめ

GLM と最終的な結論

— 予算別の選び方 —
  • GLM Coding Plan: $18 / $80 / $168(割引もある。請求サイクルに注意)
  • ZCode は無料でダウンロード可能、新規はトライアル枠も
  • $18 プランの用量の太っ腹さが際立つ($100 相当と同列には語らない)
  • ZCode との相性が良く、ブラウザ自動化で動作を確認、長めのタスクも継続可
  • 結論: 多くの開発者 → Codex。CLI 中心で Fable が効くなら Claude Max。安さ重視 → GLM $18
  • 最小のプランから始めて、使い切ってから段階的に上げる
大きい枠の数字は魅力的でも、使わない容量にお金を払っても何も完成しない。「自分の作業に合う一番小さい枠」から始めよう!
