16 How to

OpenCode Harness の使い方

今回の検証方法

  • DeepSeek の API を直接接続してデモを実行
  • いつものデモをそっくり同じ条件で回して比較
  • ハーネス解説のスライドも1枚HTMLで作成可能 
# イメージはこんな感じ
harness connect --provider deepseek \
  --model deepseek-v4.1-flash \
  --demo keyboard_lp,idol_lp,mmorpg_lp,blocks
# → TPS 198 / 2min / 24K tokens 🚀
詳しい使い方は、まさおch の ハーネス解説動画へGO！
