Tucky

Macの画面の端に住むノート＋エージェント

  • 画面の端に細い帯としてドッキング。タイトルは横向きで読みやすく、手を伸ばすと扇状に広がる
  • ショートカット長押しで、どんなアプリからでも質問 → エージェントがノートを検索書き込み会話
  • すべてMac上のローカルファイルに暗号化。本文は許可したときだけ読まれる
  • 60言語以上の音声入力に対応
  • Gmail・Calendar・ドキュメント・スプレッドシート・GitHub・Notionのコネクタ
  • 最適なモデルを内蔵、設定は不要。Apple SiliconとIntelで動作
ノートとAIが別ウィンドウで迷子になる問題、これで解決！
ノート1つの保存は無料だよ

ClipNote

AI会話を、共有できるクリップで残すメモ帳

  • タブを閉じるとChatGPTやClaudeの回答が消えてしまう問題を解決
  • 保存形式はプレーンテキストMarkdownHTML。見たままの姿でその場に保存
  • Claudeはボタン1つでMCP接続。ChatGPTは開発者モードで接続、キー不要
  • AIがクリップを閲覧・返信に取り込み・名前で更新することも
  • HTMLクリップは操作できるまま。割り勘ツールや小さなゲームがURLの裏で動き続ける
  • 検索できるライブラリ、コレクション、バージョン履歴、30日間のゴミ箱
プライベート／パブリックのリンクで共有できるよ。無料で始めて最初のクリップを保存！

Snitch

Slackで組織図を自動で組み立てるボット

  • 全員に「あなたは誰に報告する？」とDM → 2タップで回答
  • プロフィールの推測ではなく、本人が答えた情報で組織図を作る
  • 参加・報告先の変更・退職のたびに再質問、いつも最新の状態をキープ
  • ループ・空席・「2人目のCEO」みたいな不自然さを検出
  • 読み取るのは送られたDMだけ。組織図は認証済みワークスペース限定で表示
チャンネルでSnitchをタグ付けして「報告系統は？ チームの規模は？」と平易に質問OK。Slackに無料で追加できるよ

Airuncode

音声で操る、ローカルファーストのランタイム

  • コードエージェントが自分のマシン上で完結。実行はローカルに留まり、作業は外に出ない
  • タイピングの代わりに音声で操作。ハンズフリーなコーディング
  • 主要なAIプロバイダーすべてを原価のまま利用。支払いにマークアップなし
  • クラウド実行の「プライバシー vs コスト」のトレードオフを解決
自分のハードウェアで、プライベートに。エージェントをローカルで動かしたい人向け

Routines by Databox

定期的な分析を自動操縦に乗せる層

  • やり方をスキルとして記録（手順・文脈・基準を保存）。誰でも同じように実行できる
  • 毎日・毎週・毎月など、決めた頻度でスキルを自動実行
  • 完成したレポートはメール・Slack・アプリ内へ。件名で「対応が必要か」が分かる
  • 実行履歴はすべて保存。チャットでフォローアップ質問もできる
  • 130以上の統合 ＋ ワークフロー全体を回すエージェントとのMCP接続
  • スキルを記録する
  • スケジュールに載せる
  • レポートが届く！
「誰かがレポートを作るのを覚えている」ことに頼る日々ともお別れ。最初の1件は無料で自動化できるよ

Scriptly ＆ AI Toolbox 3.0

撮影とAIチャットを、ぐっとラクにする道具

Scriptly（iOS）

  • 音声追従テレプロンプター。話すペースをリアルタイム認識で追いかけてスクロール
  • Apple Watchの連携アプリで、スマホに触れず録画の開始・停止やテキスト調整
  • 内容はデバイスのローカル保存。縦型のショート動画に好適。パブリックベータは無料

AI Toolbox 3.0（Chrome拡張）

  • ChatGPT・Gemini・Claude・Grokにフォルダ検索プロンプト集書き出しを追加
  • 4つのプラットフォームを横断して全文検索。ピン留め・スマートタグで整理
  • 会話をテキスト・Markdown・JSON・PDFで書き出し。アカウント不要で、会話はブラウザの中に残る
どちらも「いつもの画面に、ちょっと足すだけ」で使える軽さが魅力！

Tadata

Slackに常駐する、AIの同僚

  • 毎朝、通話の内容と変更点をブリーフィング
  • フォローアップメールの下書き・CRMへの入力・次のステップの記述を代行
  • 承認するまで何も送らない。対応すべき事項があるときだけ通知
  • 繰り返しの作業を学習し、自動化を提案（事前に確認・接続した道具だけ）
  • MCP/APIでHubSpot・Notion・Linear・GitHub・Gmailなどへ。企業サイトやLinkedInからも文脈を取得
  • モデルに依存しない設計。レシピと設定はプロバイダー間で持ち運びできる
通話の合間に積もる雑務を、そっと引き受けてくれる味方。営業・GTMチーム向け。クレジット付きで無料開始！

Fal.ai

  • 画像・ビデオ・音声・3Dモデルを1つのAPIで実行
  • 1,000以上の本番対応モデルにアクセス。微調整や設定は不要
  • 独自の重みとLoRAの持ち込みもOK

  • サーバーレスは出力ごと、コンピューティングは時間ごとの課金。ロックインなし
モデルごとにGPUや運用をそろえる負担が、APIを1回呼ぶだけで解決！

  • 借りた認証情報で本番に入り込む「シャドーAI」の問題を解決

  • Claude・ChatGPT・Cursor・任意のMCPエージェントと連携。クラウド or オンプレ

dif.sh

機能フラグとABテストを、Gitの中へ

  • フラグとテストはMarkdownファイル1つ（dif.md）。Gitで管理し、プルリクエストでレビュー
  • フラグ・ABテスト・ホールドアウト・段階的ロールアウトが同じ構造で使える
  • 対象の属性を宣言すると実行時に解決。顧客リストはコミットしない
  • 型付きクライアントをコンパイル。1人で2つのテストが重なる場合はビルドを拒否
  • コーディングエージェントが読む文脈ファイル（活動中のテストと過去の学び）を再生成
  • CLIでドラフト→検証→プレビュー→完了。学びをログに残して次に活かせる
$ npx dif.sh init
  flags/checkout-v2.dif.md を作成
  → Git でレビュー → 型付きクライアント生成
サインアップなし、コマンド1つで導入できるのがうれしい！

Reflexio ＆ Ponytail

コーディングエージェントを、賢く・引き算

Reflexio（学ばせる）

  • 軽量SDKでモデル呼び出しを包み、失敗した道筋と良い結果から学びを抽出
  • 次の実行からは再学習なしで読み戻し。同じ失敗を繰り返さない
  • 役立った度合いで学びを調整。矛盾があれば古いレッスンを廃止、監査もできる
  • ポータブルなスキルでCodex・Claude Code・Cursorに組み込み、セルフホストも可

Ponytail（書かせすぎない）

  • 「怠惰なシニア開発者」のように、段階を上がり最初の段で停止。1行で足りることを50行にしない
  • 優先順位: 標準ライブラリ → ネイティブ機能 → 既存の依存 → 1行 → 最小の新規コード
  • 検証・エラー処理・セキュリティ・アクセシビリティは省略しない
  • Claude Code・Codex・Copilot・Gemini・Cursorへプラグイン導入。オープンソース
「学んで賢くなる」×「書きすぎない」。エージェントの過剰設計への、二つの答え！

HyperProbe

本番を、再デプロイなしでデバッグ

  • PagerDuty・Datadog・Slackのページから、ログとトレースを読んで正確なファイルと行を特定
  • コーディングエージェントが、そこに読み取り専用の仮想ブレークポイントを置く。再デプロイ・再起動は不要
  • プローブはライブ通信で非同期に起動 → その行の変数の値をキャプチャして消える。サービスは止まらない
  • 推測ではなく根本原因を確認。サイレント障害・無視された例外・競合状態を検出
  • キャプチャ前にPIIを削除。自社インフラやVPCで実行し、監査の跡も残す
  • JS・TS・Java・Python・Ruby に対応し、Cursor・Claude Code・Codex と一緒に
ログに残らない値のせいで数時間悩む…ウォール・ルーム状態とお別れ！

Experiential Labs

オープンソースのAIゲートウェイ

  • キーは1つ。すべてのモデルをプロバイダー価格で、その裏に置く
  • 変更はベースURLだけ。OpenAI互換のエンドポイント1つで、ホスト・自分のキー・自前GPUに届く
  • 新モデルが初日から使える。ルーティングのトークンにマークアップなし
  • モデルの切り替え成功に旗を立て、キャッシュで繰り返しトークンを安く取り戻す
  • 自社トラフィックでモデルを微調整。出す前にシミュレーションで検証
  • 1つのコンソールで、エージェント・人・モデル・日ごとのリクエストをドル表示。キーごとの上限と許可リストも
  • Rust製。セルフホスト or ホスト版
APIキーの乱立と予測できない支出、エージェントごとの費用が見えない問題を一気に解決！

あなたの代わりに働く、AIネイティブCRM

  • 電話・メール・会話から、すべての顧客の生きた全体像を組み立てる
  • エージェントがその文脈からパイプラインを生成。会議前の準備や、止まってしまった商談の再開も
  • 平易な言葉で質問すると、元の会話つきの引用で答える。ブラックボックスにならない

「記入をお願い」をあきらめた、新しいCRMのかたち。初期の急成長チーム向けで、無料トライアルあり！

GitWarren

エージェントのコードを、コミット前に読む

  • ローカルのGitレビュー用デスクトップアプリ。プルリクエストを待たないギャップを埋める
  • ディスクのどこにあっても作業ツリーを見つけ、ステージ済み・未ステージ・未追跡を1つの差分にまとめる
  • MCPサーバー同梱。Claude Code・Codexなどを向かわせると、エージェントも同じ道具を使える
  • レビューを開き、スレッドで返信し、行への質問に答える。回答はレビューの中に残る
  • マシンのコメントは常にはっきり表示。同時に働く2つのエージェントは別々に管理
  • アカウントもキャッシュも不要。レビューは1つのSQLiteファイルに保存。macOS・Windows・Linuxで無料OSS
コミットされていない変更も、その場で読める。プッシュする前に一目、「読む」習慣を！

GPT-6 Astra

OpenAIの新フラッグシップ ＝ エージェント作業のための最先端モデル

  • コンピュータ利用・コーディング・プロの業務向け。従来モデルが苦手だった「推論から実行へ」のギャップを埋める
  • コンピュータを直接操作: フォーム入力・CRMの更新・カレンダーの整理・ネット調査・データ分析・グラフ作成
  • Webサイトの構築と品質チェック、ソフトの導入とトラブル対応まで
  • テンプレートとスタイルに沿った、整ったドキュメント・スプレッドシート・スライドを作成
  • 作業の方向性を保ち、ルーチンの隙間を埋める。結果が変わりそうな場面では、的を絞った質問を返す
  • Codexでは、すべてを1つの要約に圧縮せず検索できるメモを文脈全体に保持
  • タスクの境界を尊重し、限界をより正確に伝える。OpenAIのモデルの中で最も整合性が高い。科学と数学の研究も後押し
  • ChatGPT（Plus / Pro / Business / Enterprise）と、OpenAI API・Azure・Bedrockで提供
今回のまとめの中でも、ひときわ大きな話題！ChatGPTで試すか、APIで作り始めよう。

  • 役割ごとのアクセス・暗号化・署名付きURL配信のREST APIを基盤にした、完全管理型SaaS
