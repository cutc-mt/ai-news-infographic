Microsoft 365 CopilotでAIを選べるように
増えたのは選ぶ自由じゃなかった

キーフレーズ：「選べるようになった」と「自分が選べる」は別
01

今回のテーマ

仕事で使うAIに「AIを選ぶ」ができた
  • Microsoft 365 Copilotで使うAIが選べるように
  • 会社で使う人も、個人でAIを使う人も選び方の基準が変わる
  • 「選べるようになった」と「自分が選べる」は別の話
メタン：できたのだ！…ただし、あなたの画面に出ているとは限らないのよ。
落とし穴があるのだ。
02

見ていく順番は3つ

  • 何が並んだのか
  • 何が支えているのか
  • なぜあなたの画面にはないのか
同じ意味に聞こえるのが、いちばん危ないところなのよ。

Phase 1：何が並んだのか

03

並んだのは2つの器

Copilotの中に、いくつも器がある
  • AIを選ぶ欄ができたのはCopilot CoworkとCopilot Studioの2つ
  • WordやExcelのCopilotとは別もの
  • 全部が変わったわけじゃない。今回入ったのはこの2つだけ
ネタ：Copilotが2つあるのだ！？…中に器がいくつもあるのか。
04

2つの器のちがい

Cowork 仕事を丸ごと渡すと
完成品が帰ってくる場所
Studio 自分専用のAI担当を
組み立てる道具
  • 「頼む場所」と「組み立てる道具」では役割が違う
渡し方の違う2つの器、ってことなのよ。
05

AIが並んだ順番

  • 先に入った：Claude Fable 5.1（Anthropic）
  • 数日後に追加：GPT-6 Astra（OpenAI）
  • 名前だけは聞いたことあるのだ、という人も多いはず
並び順は性能順じゃないのよ。点数の勝負じゃなかった。
06

同じ日に3か所へ配られた

GPT-6 Astraは一気に広がった
  • Copilot Cowork / Studio
  • GitHub Copilot（開発者が使う側）
  • Microsoft Foundry
ネタ：そんなに一気に配られるのだ！

Phase 2：何が支えているのか

07

公式が書いたのは性能比較じゃない

「指示を減らして、任せる量を増やす」
  • 最初に書いたのは性能の比較じゃない
  • 点数の勝負でもない
  • 書いてあったのは指示を減らす・任せる量を増やすという話
「どっちが賢い」の話じゃなくて、「どう任せる」の話だったのよ。
08

仕事の渡し方が変わる

  • 今まで：作業を小さく割って、1手ずつ導く。細かく言わないと変なものが帰ってくる
  • これから：大きい仕事をそのまま渡す
  • 人は帰ってきたものを見て、確かめる側に回る
  • 途中の進み方が見えて、間で舵を切れる
  • 承認の関所は残る。お任せで勝手に終わるわけじゃない
ネタ：承認が残ると聞いて安心したのだ。
09

Work IQ という仕組み

会社のファイル・会議・チャットにAIをつなぐ層
  • 名前は「頭の良さ」っぽいけど、中身はつなぐ仕組み
  • うちの資料を見た状態で答えられるようになる
  • 同じAIでも、自社資料を見た状態と何も見ていない状態では返事が変わる
賢さよりつなぎ方。ここが今回の核なのよ。
10

つなぎ方は「10個の動詞」だけ

  • 数百あった操作を、10個ほどの単純な動詞にまとめた
  • 取ってくる／作る／更新する…それくらい単純な言葉だけ
  • 相手は住所みたいな指定で決める
ネタ：10歩だけなのだ！？少なすぎないのだ？
11

権限のよくある誤解

見せているだけで、権限は増えない
  • 「見えるようになる」ではなく「見せている」だけ
  • 動くのは、その人が元から見ていいものの範囲だけ
  • ここを間違えると怖い話になるから覚えておいて
メタン：会社の中身が全部見える、じゃないのよ。ここ大事。

Phase 3：なぜあなたの画面にはないのか

12

欄が出ないのは不具合じゃない

会社の管理者が開けていないだけ
  • 管理センターに「外部のAI会社を使うか」の設定がある
  • Anthropic側のスイッチは、初め切れている
  • OpenAI側は入った状態で配られている
  • 同じ画面なのに、扱いがちがう
「選べるようになった」と「あなたが選べる」は別なのよ。
13

開ける時の範囲

  • モデルごとに別の申し込みはいらない
  • 今のユーザー・グループの割り当てが、そのまま使える範囲になる
  • 管理者に頼むなら「何に使いたいか」も一緒に言う
ネタ：管理者にお願いすれば話なのだ！…と思ったら、もう1つぶつかるものがあるのよ。
14

お金の払い方は4通り

  • Cowork：今のCopilot料金に上乗せで、1人あたり月30ドル
  • Studio：クレジットを消費する形
  • Foundry：使った文字の量で課金
  • Work IQのつなぎ口：Copilotの契約とは別で、使った分だけ請求
「開けて」は誰かの予算の話なのよ。頼むなら、そこまで分かって頼むこと。
15

画面を操作する機能の注意書き

初めて「正面から」の注意書きが出た
  • 人の代わりに画面をクリックして進める機能のこと
  • 画面に表示されている中身が、AIの動きを誘導しうる
  • 不完全だったり、誤解を招いたり、わざと作られていたりもありえる
  • 見た目は普通の画面でも、中身には引きずられる
メタン：画面に書いてある文字に、AIが引っ張られるのよ。
16

任せる範囲は自分たちで決める

戻せないことだけ、自分の目を通す
  • 送る／買う／消す…この3つは自分の目を通す
  • それ以外は任せていい
  • 新しいAIが届く速さに、会社のルール作りが追いついていない
  • 道具だけが先に来る。任せる範囲は自分たちで決めるしかない
「任せる仕事」と「目で見る仕事」を分けるのよ。

Phase 4：どう選び、何を持って帰るか

17

個人の選び方が変わる

「一番賢いやつ」はもう決め手にならない
  • 賢さで選ぶ時代は終わり。会社が売っているのもつなぎ方
  • 選ぶ基準は何を見せているか
  • 同じ仕事を両方に投げて比べる
  • しかも自社の資料を見せた状態で比べて初めて答えが出る
3つ目は個人で使っていても、すぐできるのだ。
18

結論と持ち帰り3つ

増えたのは選ぶ自由じゃなく、選んだ責任
  • 誰かが開けて、誰かが払って、誰かが確かめる。その「誰か」が増えただけ
  • 自分の画面にAIを選ぶ欄が出ているか見る
  • 出ていなければ「壊れてる」ではなく外部AIの設定の名前で聞く
  • 選べるなら点数じゃなく、同じ仕事を両方に投げて比べる
