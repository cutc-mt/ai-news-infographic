ChatGPT Images 2.5 賢くなったのは「残す力」

描く力ではなく、動かさない力・壊さない力
OpenAI ChatGPT Images 2.5 残す力 Flare / Sunburst C2PA
2026.09.10 ｜ ずんめたラボ「今知っておきたいAI」

① 髪型だけ直して、の悲劇

  • ぬいぐるみのレタンが AIに描いた絵の 髪型だけ変えたい と頼んだ
  • 戻ってきたのは… 顔まで別人 になった絵
  • なぜ 触っていないところまで動く のか？ そこが今日の謎
「画像あるある」
触っていない場所まで動いちゃうのよ…

② 発表されたその日から全プランへ

  • OpenAI が画像生成・編集AI ChatGPT Images 2.5 をリリース
  • 発表された日から すぐ全プランに配布（普通は少し待たされる）
  • 対象は ChatGPT Work Codex の全部、無料プランも対象
  • パソコン・スマホ・ブラウザ、どれでも同じ日に使える
無料のままでも大丈夫！
試した記事でも無料プランで動いていたのよ

③ 待ち時間は最大で半分に

  • 前の Images 2.0 と比べて、待ち時間が 最大で半分（公式）
  • この待ち時間こそ、画像生成をやめる 1番の理由 だった
  • 「3回直す前に飽きる」問題が、解消に近づく
待ってる間にお茶を入れられなくなる、は笑い事じゃないのよ

④ 見た目も上がった

  • 光の当たり方 と 物の手触り が自然に
  • 参考に渡した写真の 人やものの特徴が崩れにくい
  • 細かい文字がたくさん入っても崩れにくい → 日本語も大丈夫
  • 前は看板の字がぐにゃぐにゃ…試した記事では画面いっぱいの日本語がそのまま読めた
手触りが伝わる絵、いいのだ…

⑤ なぜ触っていない所まで動く？

  • 今までの画像AIは、一部を直す時も 丸ごと書き直し に近いことをしていた
  • 「直す」ではなく「書き直す」→ 頼んでいない髪型以外も書き換えられていた
  • これが 別人が出てくる理由
直すんじゃなくて書き直していたのだ！
理由がやっと分かったのだ

⑥ 2.5が強化した「残す精度」

  • 指示したところを変え、それ以外の構図を保つ 精度を強化
  • 公式の例1: 立ち位置はそのまま 上着だけ変える
  • 公式の例2: 商品の見た目はそのまま 背景だけ差し替え
  • 公式の例3: 構図は動かさず 文字だけ直す
全部やりたかったことなのだ！
髪型だけ、は最初から想定の内側だったのね

⑦ 一発勝負が「下書き」に変わる

  • 何度直しても それまでの変更と細部を保ちやすい
  • 前は 2回目で全部やり直し、3回目には気に入っていた部分が消えていた
  • 一発で当てに行く道具から、何度も往復できる下書き に変わった
  • 少し直して見て、また少し直す繰り返しが成り立つ
試した記事では、作らせ直しても
キャラクターの目の色や小物が残っていたのよ

⑧ 画像の上に直接コメント

  • 出てきた画像の上に 直接コメントを置ける ようになった
  • 「ここを変えて」と差しながら書ける → 差した場所がそのまま指示
  • スマホでも可能。全画面で開いてコメントを追加
  • 上向き矢印でコメントを積み、まとめて送信 で一気に直す
「右上の梅の花みたいな形」と言わなくていいのだ！

⑨ スケッチで始める

  • 何を作るか浮かばない時は、まず スケッチ
  • 棒人間で十分。ChatGPT の中で描いた下書きを手がかりに生成
  • 呼び出し: スマホは入力欄の @ から、パソコンはサイドバーの画像から
  • 描いて確定すると「下書きを参考に大胆に作り直して」の文言が自動で入る
言葉より描いた方が早い時があるのだ

⑩ テンプレート機能

  • もう1つの入口は テンプレート: ポスター・チラシ・グッズ・商品写真のひな型
  • ひな型を選び、伝えたい内容と色や雰囲気を足すだけ。白紙から始めなくていい
  • ただし ワークモードでは未対応（公式）→ 会社で使う人はそこだけ待つ
選ぶだけで良いのだ、楽なのだ

⑪ プロンプト添付を選べる

  • 画像を人に渡す時、使ったプロンプトを一緒につけるか 選べるように
  • 再現してもらいやすい・渡し方のマナーとしても便利
便利すぎてお金が心配になってきたのだ…

⑫ 料金の話

  • ChatGPT の中で使う分は いつものプランのまま
  • お金がかかるのは、自分のアプリに組み込む時（開発者向け）
いつものプランのままよ、と良いところに気がついたわね

⑬ 開発者向け API 2つ

  • Flare = 速さ重視
  • Sunburst = 編集の細かさ重視（時間はかかる）
  • 値段は2つとも同じ: $30 / 100万枚（画像出力あたり）
  • 公式の案内: まず Flare、もっと細かい編集が要る時に Sunburst
ただし Flare の説明は公式内でも書き方が割れているの…
ブログは「品質・編集・速さを同じく持つ」、プロンプトの手引きは「速さ重視の小さいモデル」と呼ぶ

⑭ 名前のワナ: 前の世代は2種類

  • ChatGPT 側の前の版 = Images 2.0
  • API 側の前のモデル = GPT Image 2（別物！）
  • 名前が紛らわしいので、デ選ぶと転ぶ → 選ぶ前に確認を
名前が新しい方が強い、と覚えるのだ

⑮ C2PA と不可視ウォーターマーク

  • できた画像には C2PA という記録が入る
  • 目に見えないウォーターマーク も今も入る
  • 人に渡す前に、この2つが入っていることを思い出す
生成物だと分かる仕組み、
渡す相手のことも思い出してね

⑯ うどんの例: 「絶対」ではない

  • 公式は 「絶対そのまま」とは一度も言っていない
  • 試した記事の例: うどん写真で「肉を増やして」→ 肉はちゃんと増えた
  • でも離れた所にあった海苔の色が少しだけ変わっていた
  • ほとんど合っている分、気づきにくいのが落とし穴
頼んでいないところがまた少し動いたのだ…

⑰ 残る仕事: 確かめ方こそ大事に

  • 公式の手引き: 編集を重ねると残したい細部まで変わることがある
  • → 残したい条件をもう1度書いて
  • → 出てきた画像を 毎回確かめる
  • 「確かめなくていい」にはならない。確かめ方が大事になった
これが AIが賢くなっても残る、
あなたの新しい仕事なのよ

⑱ 今日の持ち帰り 3つ

  • 画像を直す時は 変える所 / 残す所を分けて書く（顔と背景はそのまま、も書く）
  • 出てきたら 頼んでいない場所が動いていないか見る。ほとんど合っている時ほどよく見る
  • 人に渡す前に C2PA と見えないウォーターマーク を思い出す
良い頼み方の例:
髪型を短めに変えて
顔・目の色・背景はそのまま / 海苔の色もそのまま
今日の教え: 賢くなったのは残す力
描く力ではなく、動かさない力・壊さない力
この3つは他の画像AIでも使えるのだ!
