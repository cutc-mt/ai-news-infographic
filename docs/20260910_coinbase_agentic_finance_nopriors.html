暗号×AI×バイオ、3つのフロンティアを1人の経営者が語る貴重な対談!
#02

Everything Exchange 構想

  • 株式商品暗号が1つの場所に集約
  • デリバティブ・永久先物・予測市場まで取引可能に
  • 規制が明確になり、対応国が拡大中
  • 収益の 88% はすでに Bitcoin 取引以外(決算資料)
  • 株価は Bitcoin と連動しがちだが、実態はずっと多角化
「Bitcoin は大好き。デジタルゴールドとしてずっと生き残る。でも Coinbase は『すべての取引所』へ進化中」
#03

ステーブルコイン決済が急成長

  • Bitcoin が下落しても 成長が止まらない
  • 1秒未満・1セント未満で世界のどこへでも送金
  • 「情報の速度でお金が動く」— WhatsApp のメッセージのように
  • 世界中の企業が続々と導入、Coinbase が支援
送金はもう「メッセージを送る」感覚。速くて、安くて、どこまでも届く!
#04

Agentic Finance(AiFi)とは

  • AI がすべてを変える。金融も例外ではない → Coinbase は AiFi と呼ぶ
  • 柱①: すべての人に AI アドバイザー
  • 柱②: AI エージェント自身の口座
  • crypto のレールが、AI 決済にうってつけの土台
「crypto は人類にとって良かった。そして AI にとっては不可欠になる」
#05

みんなの AI アドバイザー

  • 富裕層だけの投資アドバイザーを 全員に 開放
  • ポートフォリオ構築・積立投資・税損売却までまるごと提案
  • 市場が5〜15%下落したら、時間をかけて段階的に買い付ける戦略も
  • 遊休資金には利回りをつけて手数料を節約
  • 人間のように話しかけるだけで完結 — すでに製品ローンチ済み
「10%下がったらどうする?」もうプロの相棒に聞けばいい!
#06

「AI をバンクさせる」

  • 「AI を unbanked のままにしない。金融サービスを受ける資格がある」
  • コピペ1コマンドでエージェント自身の口座を開設
  • セルフカストディアル・ウォレット + crypto レール → KYC 不要
  • 方式A: 人間の ID に紐づく分離資金口座(代理で取引・決済)
  • 方式B: 完全独立ウォレット。資金調達やトークン発行すら可能
  • 後方互換용の「ステーブルコイン決済クレカ」も登場へ
> AI エージェントに貼り付けるだけ:
  "Create my financial account"
  ✔ wallet 生成 (self-custodial)
  ✔ KYC 不要 / crypto rails
  ✔ USDC 残高を保持できる
エージェントにも、社員みたいに「自分のお小遣い口座」を。ホテル予約や AWS 起動で立ち往生しなくなる!

X42 プロトコル

  • Linux Foundation に寄贈して中立化
  • Google・Cloudflare・AWS などが参画

エージェント経済の「計測器」が、すでに動き出しているのがすごい。
#08

76% が30セント未満

  • エージェント間取引の 76% は30セント未満
  • カード決済は最低約30セント+率 → 1セントの送金は大赤字
  • 中身は情報の収集: 有料データの調査、LinkedIn のスクレイピング
  • 特化型エージェント同士の「ツールコール的」売買も増加中
  • ベンチャー企業のリサーチやリクルーターの調査にも活用
既存の決済では採算が合わない「ミクロな経済」が、いま誕生した。
#09

小型モデルが逆転勝負

  • フロンティアモデルは「何でもそこそこ」のゼネラリスト
  • 小型のオープンウェイトモデルが特化タスクでフロンティア超え
  • 例: コンプライアンス審査。自社データ 10万件 で学習すれば逆転可能
  • 「ピザ注文だけ超得意なエージェント」も登場しうる
  • Figma データを大量に学んだ「デザイナー専員」の未来も
市場には「専門家エージェント」がズラリと並ぶ時代へ。
#10

エージェント経済が人間経済を超える

  • そう遠くない未来、エージェント数 > 人類 に
  • ならば エージェント経済 > 人間経済 になるのも当然
  • 稀少性は消えない: 土地・エネルギー・チップ(ダイソン球はまだ高い!)
  • 交換手段(お金)は、これからも必要
  • crypto と AI のコミュニティはもともと近親者(MIT 卒の行き先が年度で入れ替わった)
「両方やればいい」— crypto と AI が交差する瞬間が、いま来た。
#11

社内 AI: チームの「ブレイン」

  • チーム・リポジトリ・個人 ごとに「ブレイン」を配置
  • 中身: インシデント履歴・財務コントロール・AB テスト・PR の全履歴
  • 実体は今のところ markdown ファイル。エージェントが変更前に摂取
  • 人間の修正を必ずブレインに還元 → 全未来の案件で再発防止
  • 効果: 1ショット PR 承認率 が向上。リカーシブな自己改善
  • 個人ブレインは退職時に持ち出せるポリシー作りも
# brain.md (repository)
- incidents: 過去の全インシデント
- fin_controls: 財務コントロール
- ab_tests: 実施済み AB テスト
- prs: 採択 / 却下 履歴
→ 修正したら必ず here へ書き戻す
直すたびに賢くなる会社。「今回だけ」で終わらせない仕組みがポイント。
#12

ハーネス「Toshi」と10並列体験

  • 社内エージェント・ハーネス Toshi が全ツールと統合
  • X42 経由で外部ベンダーへの自動支払いも可能に
  • CEO 自ら: 機能を3フェーズに分解し、フェーズ1の10項目を10並列エージェントへ
  • 安いモデルを自動チョイス。オープンソース + Grok を起動
  • 収録の2分前、Slack に「フェーズ1の10個、全部完了」と通知
  • Slack でエージェントにタグ → チームを困らせず完成 PR が返る
@toshi この機能を3フェーズに分解して
  ├ phase 1 を10タスクへ分解
  ├ 10 agents 並列実行 (OSS + Grok)
  └ 完了 → PR 10通が Slack へ ✨
「魔法の瞬間。正直、もうやみつき」— 現場にいた CEO の実感。
#13

トークン化がレールを更新

  • 最初の大ユースケースは ステーブルコイン(銀行預金と1:1)
  • トークン化株式を米国外で開始。SEC と国内展開を協議中
  • 実券を1:1で保管する担保付きで発行
  • 次はプライベートクレジット・国債・銀行預金…ぜんぶトークン化
  • 甥っ子への株式プレゼントも、ウォレット送信だけで完了
  • 世界中の 40億人 が質の高い投資への扉を求めている
金融サービスが、最新のレールに載り替わる。古い手続きはもう要らない。
#14

予測市場が爆発中

  • ローンチから数ヶ月で $1億 の収益ランレート到達
  • 成長率は四半期比 100%超(決算で公表)
  • 選挙だけでなく、政策の効果予測へ:「この政策で失業率はどうなる?」
  • 人生の大きな問いにも市場が形成される可能性(意見市場)
  • 解決日のない賭けも OK — 株式の「先行き」への賭けと同じ構造
「まだ表面をひっかいた程度」— 拡張の余地が巨大。
#15

New Limit の誕生

  • 2021年の上場後、友人たちとのディナーで「次の大きなトレンドは?」
  • 宇宙・AI・核融合・BMI は強力なチームが既にいる → 独自の勝ち筋を探す
  • 出会ったのは エピジェネティック・リプログラミング(Yamanaka ラボの初期成果)
  • Bitcoin と出会ったときと同じ「3ヶ月考えが離れない」状態に
  • 共同創業者: Jacob Kimmel(CEO)・Blake Buyers・Greg Johnson
  • 現在は South San Francisco にラボ、50〜60名体制
  • AI が転写因子の組み合わせ(数百万仮説)を探索 — 業界最先端のモデルを構築し次の実験を提案
ひらめきは生もの。消えてしまう前に、動き出すことが大事。
#16

New Limit の治療戦略

  • 最初の3細胞: 肝細胞・血管・免疫(T細胞)
  • GLP-1(Ozempic)と同じ戦略: まず治療薬のない病気から
  • フェーズ1はアルコール性肝疾患(ALD): 移植以外に選択肢がなく12ヶ月生存率が極めて低い
  • ALD 単独で $200億 市場
  • ゴールは健康な人の若返り: 40歳で20歳の肝臓・免疫・血管へ
  • 肌の若返りは 兆ドル 規模の市場
  • このプラットフォームから今後数年で3〜10の候補が創出予定
「治す薬」から「若返る薬」へ。カクテル療法で細胞を若い頃へ。
#17

認知を上げ、病を消す

  • 葉酸などの栄養で子どもの IQ が上がる例も(国によって差)
  • 投資先 Preventive は胚編集で遺伝病を予防
  • 米国人の 80% が「病気予防目的の胚編集」を支持
  • Elad の懸念: 「知能の Ford Model T」で神経の多様性が減る?
  • Brian の反論: 親の好みは無限 → むしろ多様性は増える
  • 床を上げるだけなら、その子はその子のまま(統合失調症やうつにならない)
AI が賢くなる時代、人間も進化の主導権を取り戻すべき — それが Brian の考え。
#18

実験の場と、建設者の心

  • 進歩を遅らせる最大の要因は過剰な規制(欧州など)
  • ホンジュラスの Prosper に Coinbase が投資。地元との紛糾も解決目前
  • Freedom Cities 構想: 連邦土地10〜100平方マイルを規制の砂場に
  • 原発・創薬・暗号・ドローン配送など、戦略分野に特化した特区
  • 「批判者より建設者であれ」— 転んでも共感と学びが得られる
  • 文明の進歩に、誰もが何かを加えられる
批判は簡単。作るのはむずかしい。だからこそ、作る人になろう。
