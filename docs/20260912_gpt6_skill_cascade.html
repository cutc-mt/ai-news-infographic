① まず、みんなが抱えるモヤモヤ

すごいけど…どこで使う？

  • GPT-6は3Dゲームまで作れる超性能
  • 難問を解くデモも目を見張るレベル
  • でも実務で使う機会は ほぼ無い…
  • 高いのに「毎日使うもの」でもない
デモはすごい。でも自分の仕事に
どう組み込めばいいの…？

費用の現実

  • GPT-6 Astra: 入力 $10 / 出力 $50（100万トークンあたり）
  • GPT-5.6 Tera: 入力 $2 / 出力 $12
  • ざっくり5倍のコスト差
  • 賢い分、処理量が増える案件も多い
高いモデルを毎日回すと、
人件費より高くつく仕事もある！

GPT-6で何が変わる？

  • PC画面ごと操作して仕事をする
  • Blender（3Dソフト）を直接動かす
  • 動画の編集ソフト Premiere まで操作
  • コミュニティロボ「アイザック君」の3D模型も作製
この動画の1分デモ編集も
AIに頼んで作ってもらった！

これまでの常識

  • 安いAIに任せるには人間が手順を作る
  • 作業の様子を録画して AIに渡す方式
  • 最初の開拓は人間の仕事だった
この「開拓」をAI自身に
やらせたら…？ が今日の主役です

② 「スキルカスケード」という答え

カスケード＝滝

  • cascade は「段々に落ちる滝」の意味
  • 賢いAIが作った仕事のやり方を、下のAIへ落としていく
  • 池友さん作成の造語として提唱
滝のように上から下へ、
スキルを流すイメージで

基本の型（肝はここ）

一言でいうと——

「賢いAIに仕事のやり方を作らせ、
実行は軽いAIに任せる」

賢いAI → 仕組みを作る
スキル化: 手順のパッケージ
軽いAI: 毎日の実行
賢いAIで仕組みを作り、
軽いAIで業務を回す——これが急所！

「スキル」とは？

  • 手順書＋出力テンプレート＋プログラム
  • それらを1つにまとめた仕事のパッケージ
  • 2025年10月に Anthropic が発表
  • 12月に 他のAIでも使える開かれた形式に
  • ChatGPT / Claude / Gemini も使える状態に
「仕事のやり方」を箱にして、
誰でも・どのAIでも使えるように！

3つの役割分担

流れ
  • 攻略: 上位モデルが未知の仕事を解決
  • 定義: やり方をスキルとして書き出す
  • 実行: 軽いモデルが安く 毎日の処理を担う
攻略→定義→実行 の分担で、
コスパがグッと上がる

③ 実例で見るスキルカスケード

資料づくり

  • 同じ指示でも 賢いモデルの資料はワンランク上の出来
  • 初回のかっこいい型を作るのは上位モデル
  • 2回目からは中身や色を変えるだけ
  • なら安いモデルでも十分こなせる
この動画で使ったスライドも
自作ツール＋同じ発想で制作！

初回だけ「難問」

  • 未知の仕事は探索が必要で難しい
  • 1回解けば手順が固定される
  • 2回目は“やるだけ”なので安いAIで十分
初登坂だけ強い車で走り、
2回目からは軽い車でOK

X（Twitter）投稿

  • 毎朝9時にAIニュースを自動で投稿
  • APIがあるので 仕組みさえあれば簡単
  • X版の仕組みは軽いAIで回せる状態
Xへの投稿は仕組み化済みで
ほぼ毎日ふつうに運用できています

note 記事の投稿

  • note は そういう仕組みが無い
  • ブラウザ操作で画像を貼り 記事を組む必要あり
  • 最初は文字ずれ・画像ミスで失敗続き
  • Claude で開拓 → 手順をまとめてもらう
  • 今は Sonnet クラスで 毎日トラブルなく運用
開拓1回 → スキル化 →
あとは安いAIで 時間通りに運用！

RPA の設計まで

  • RPA＝ソフトを操作する自動化の仕組み
  • 設計が面倒で 敬遠されがち
  • GPT-6の画面の操作に設定まで丸ごと任せる
  • 完成した瞬間、AIなしで勝手に動き続ける
ボタンを5つ押せば設計は終わり→
以後は人手もAIも不要な自動化！

費用の考え方

  • 賢いモデルを使い続けると人件費を上回ることも
  • 時給1,000〜2,000円の人に頼んだ方が安い領域も
  • 初回だけ高く、2回目からは安く＝コスパ重視

④ 今日から始めるステップ

Step 1: 業務を1つ選ぶ

  • 自分だけでは面倒な作業を探す
  • これまでのAIではできなかったことを選ぶ
  • GPT-6やClaude系でまず試し撃ち
やってみると意外と
できちゃうことが多い！

Step 2: スキル化する

  • 1回成功したらやり方は確定
  • 手順をまとめてスキルとして保存
  • 別のAIモデルでも動く可能性が一気に上がる
「スキルにした瞬間」が
持ち運べるようになる境界線！

Step 3: 安いAIへ移す

  • 2回目からは安いモデルに切り替え
  • 手順が決まれば処理も高速・低コスト
  • プラン上限を気にせず回せる
高いAIは「最初の1回」だけ。
あとは軽やかに 毎日の運用を！

将来像：天井が上がる

  • GPT-7など次のモデルでできることが拡大
  • 1回やらせれば やり方は決まる→旧モデルでも実行可
  • デジタル業務をAIに任せる範囲が広がる一方
上位AIの進化＝あなたの武器が
増えると同じ。恐れず試そう！

まとめ

「GPT-6やClaude系の賢いモデルは、スキルカスケードの最初の1回目で使う。」

  • 賢いAIで一度、仕事のやり方を開拓
  • やり方をスキル化して保存
  • 2回目からは安いAIで毎日さっと回す
  • この繰り返しで、AIに任せる範囲がどんどん広がる
