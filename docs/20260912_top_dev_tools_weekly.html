01
ターミナルエージェント

OpenCode

  • プロバイダー非依存のターミナル用AIコーディングエージェント
  • 任意のモデルを接続して、コードを書く・さがす・編集する
  • build = フルアクセス / plan = 読み取り専用 / サブエージェント = 複雑タスク対応
モデルの乗り換えも自由自在。縛られないのが気持ちいい!
MIT
02
ナレッジグラフ

Code-Graph-RAG

  • モノレポをナレッジグラフで照会・編集するしくみ
  • tree-sitterで多言語コードを解析し、Memgraph上にグラフ化
  • 自然言語で質問 → 意図で関数を取得 → AIパッチ適用 + diffプレビュー
  • デッドコード検出も可能。MCPサーバーとして動作
「この関数、どこで使われてる?」に
グラフで即答してくれるのが画期的!
03
スキル集

Agent Skills (Google)

  • Google公式のコーディングエージェント用スキル集
  • カバー範囲は GCPの基礎 AI/ML Kubernetes データベース Dev セキュリティ ホスティング
  • 精査されたMarkdown手順書を選んでインストール
  • MCPサーバー同梱のプラグインもあり
公式がお手本を用意してくれたのは心強い。
GCPまわりの作業がラクになりそう!
Apache 2.0
04
スキル集

Skills for Real Engineers

  • 「バイブコーディング」ではなく、規律あるエンジニアリングを重視した合成可能なスキル集
  • 要件の明確化インタビュー
  • 共有語彙ドキュメント
  • テスト駆動のフィードバックループ
  • アーキテクチャ → 仕様へ落とすツール
「ちゃんと設計してから書く」文化を
エージェントにも持ち込む姿勢が爽快!
MIT
05
ブラウザ内LLM

WebLLM

  • LLMを完全にブラウザ内で実行。WebGPU経由でデータはプライベートのままサーバー不要
  • OpenAI API互換 / ストリーミング / JSON出力 / Function Calling 対応
  • Llama Phi Gemma Mistral Qwen などをネイティブロード
const engine = await WebLLM.CreateEngine(
  "Llama-3.1-8B-Instruct-q4f16_1-MLC");
const reply = await engine.chat.completions.create({
  messages: [{ role: "user", content: "こんにちは!" }]});
APIキー不要・送信先ゼロ。
機密データを扱う社内ツールに最適かも!
Apache 2.0
06
ターミナルエージェント

Codewhale

  • Rust製のプロバイダー非依存ターミナル用エージェント
  • ファイル編集・コマンド実行を、目標指向で対話 or 単発実行
  • プランモード + 段階的な承認 + undo / restore
  • OSサンドボックスで安全に実行。MCPサーバー・スキル・フック対応
サンドボックスとundoの二重の安全装置。
Rust製で軽快なのもポイント!
MIT
07
チーム共有

TeamAI (Tencent)

  • チームでエージェントスキルとナレッジを共有するしくみ
  • スキル・ルール・ドキュメント・フックをGitで同期
  • Claude Code Codex Cursor など横断で改善を自動配信
  • セッションの摩擦スコアから検索可能なナレッジベースを構築
「あの人だけが知ってる」をなくしたい。
エージェントの知恵をチームの資産に!
MIT
08
3Dエディタ

Pascal Editor

  • ブラウザで3Dの建物を設計するオープンソースエディタ
  • React Three Fiber + WebGPUで構築
  • サイト・建物・レベル・壁・備品を設計。壁の自動マイター処理や編集時の床の再生成つき
  • 50ステップのundo、ローカル保存、プラグインシステム
インテリア提案やゲームのレベルデザインに
そのまま使えそうな完成度!
MIT
09
CAD生成

text-to-cad

  • 自然言語からCAD・ロボットファイルを生成
  • 出力は STEP STL DXF URDF など
  • 市販パーツの調達 + ファイルプレビュー
  • レーザーカット検証やG-codeスライスにも対応
"M3ボルトで固定できるブラケット"
   ↓ (text-to-cad)
bracket.step / bracket.stl
言葉から部品が生まれる時代。
自作ロボットの壁がまた低くなった!
Python製 MIT
10
シェーダー共有

openshaders

  • Web用シェーダーの共有ライブラリを目指すプラットフォーム
  • ライブエディタで書きながら即プレビュー
  • React / JSコンポーネントとして利用可能に
  • shaders.npmレジストリを計画中
現時点ではユーザー名の予約ができる段階。
シェーダー版npmが来たら面白そう…!
MIT
11
デスクトップアプリ

PI-Desktop

  • コーディングエージェント用のローカルファースト・ネイティブアプリ
  • クラウドアカウントやテレメトリ不要。鍵とセッションはローカルに保持
  • 任意のモデルプロバイダーに対応
  • 承認ゲートつきのエージェント / プランモード + diffワークベンチ
  • 構成は Electron + Rust + TypeScript
認証情報を手元に置きたい人にうれしい
「引きこもり派」向けのGUI!
12
エンジニアリング基盤

ECC

  • コーディングエージェントの上に構築する完全なエンジニアリングシステム
  • 計画 → テスト → 実装 → レビュー → 検証 → 記憶 → 改善のループ
  • 専門特化のサブエージェント + 数百のスキル + 強制フック + 共有メモリボールト
  • Claude Codeで最適動作。Codex・Cursor・Gemini用アダプタも
エージェントに「思い出」と「型」を与えて
ひとりのエンジニアのように育てる構え!
MIT(プライベートリポ向け有料ホスティング)
13
動画生成

hyperframes (HeyGen)

  • HTMLを書くだけで決定論的な動画をレンダリング
  • HTML・CSS・GSAP / Three.jsなどのアニメーションをそのままMP4へ変換
  • プロプライエタリなタイムライン不要
  • ヘッドレスChrome + FFmpegでレンダリング。ローカル / Docker / Lambda 対応
<div class="scene">HTML + CSS</div>
  + GSAP timeline
  ↓ hyperframes
final.mp4 (決定論的・再現OK)
同じソースから同じ動画が何度でも。
動画のバージョン管理が現実になるかも!
Apache 2.0
14
エージェント協調

Ruflo

  • コーディングエージェントの群れ(スウォーム)を協調させるレイヤー
  • Claude CodeとCodexの上に、メモリ + 計画ループ + 自己組織化ロールを追加
  • 軽量プラグイン、または CLI + MCPサーバー + フック + デーモン
  • マルチプロバイダー routingとマシン間フェデレーション
エージェント同士が役割を決めて動く。
「蜂の巣」みたいな開発が近づいてる…!
MIT
15
コンパイラ基盤

LLVM

  • 共有中間表現(IR)を中心に、コンパイラ・オプティマイザ・ランタイムを構築するモジュール式ツールキット
  • 同梱は Clang libc++ LLD Flang LLDB MLIR
  • 多数の言語フロントエンドが1つの最適化・コード生成バックエンドを共有
各言語のフロントエンド
   ↓ LLVM IR (共通の中間表現)
最適化 → コード生成 → 機械語
OSSコンパイラ界の大御所。
SwiftやRustの心臓部でもあるよ!
Apache 2.0 with LLVM exceptions
16
アニメーション

manim

  • 3Blue1Brown作者による、数学動画用のプログラマチック・アニメーションエンジン
  • タイムラインツールの代わりに、Pythonで正確で再現可能なアニメーションを構築
  • シーンをPythonクラスとして定義
  • FFmpegとOpenGLでレンダリング
class SquareToCircle(Scene):
    def construct(self):
        s = Square()
        self.play(Transform(s, Circle()))
あの美しい数式動画を自分でも作れる。
説明動画の質が上がる一歩!
MIT
17
スキル蒸留

Distilly

  • 実人物のノウハウをエージェントスキルに蒸留
  • メッセージ・ドキュメント・インタビューから専門知識・判断・声を抽出
  • インストール可能なスキルとしてパッケージ化
  • 同僚・関係者・セレブのバリアントを用意
  • 8つのエージェントホストで動作。バージョンのロールバック対応
「あの人に聞けばわかる」を丸ごと保存。
退職する前に蒸留しておきたい…!
MIT
18
デプロイ + ライブラリ

Aspire & Sugar High

  • Aspire (Microsoft): セルフホスト可能なデプロイプラットフォーム。.NET向けアプリのオーケストレーション
  • Sugar High: ゼロ依存の軽量シンタックスハイライター。React向け
  • どちらも「軽やかで実直」な今週の締めくくりナンバー
import highlight from 'sugar-high';

const html = highlight(codeString);
// → 依存ゼロでReactにハイライト表示
大物から小粒まで詰め合わせのラストカード。
.NET周りの人はAspireを要チェック!
