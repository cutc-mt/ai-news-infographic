第1章：エージェントが、もっと身近になる

① Gemini がデスクトップに

  • Mac版に続いて、いよいよWindows版が登場
  • 中身はほぼWeb版と一緒。サイドパネルでチャット＋Geminiスパーク
  • Windows版はまだローカルファイルを操作できず、開きやすいだけの状態
  • Mac版ならパソコン上のファイルを直接いじれる
  • ChatGPT・Claudeはファイル操作OK。Geminiブランドはエージェントアプリ化が今後の鍵
チャットではなく、AIが仕事をする エージェント時代が来る！

② OpenAI の Agents API

  • 自分で組むAgent SDKに対し、今回はAPIとして丸ごと提供
  • プログラムから依頼すると、OpenAI側がエージェントで処理して完走までやってくれる
  • エージェントの仕組み（ハーネス）はCodexと同じもの→能力が高くて安定
  • Claude の Managed Agents は5ヶ月先行。OpenAIが追いついた形
  • APIプラットフォームの左メニュー「エージェント」から対話的に作成可能
// OpenAI Agents API のイメージ
const run = await openai.agents.run({
  harness: "codex",       // Codexと同じハーネス
  task: "長時間の調査とまとめ",
});
// クラウド側でデータを管理しながら
// 仕事が終わるまで世話してくれる
自分専用エージェントをクラウドに置いて、 どこからでも呼び出し！

③ 拡散型LLM「Mercury」

  • Inception社の拡散型LLM、なんと毎秒1100トークンという速さ
  • 普段のAIは回帰型（一文字ずつ作る）。Mercuryは画像生成のように一気に全体を作って直す
  • 精度はGPT-5.6 Luna と比べるとやや雑で、昔のGemini 2.5 Flashクラス
  • 賢いモデルが設計を担い、簡単な処理だけ拡散型へ。速さと精度の両立が狙い
  • APIやOpenRouter経由で試せる
モデル特徴
Mercury超高速・ライトな作り
GPT-5.6 Luna少し丁寧なアウトプット
Gemini 2.5 Flash若干こちらが上かも
人間が目でチェックできない速さ！ エージェントのかんたんな判定を任せるのがコツ

第2章：国内ベンチャーに学ぶ、AI前提の会社づくり

④ LayerX「Bet AI Day」投資額

  • 一人あたり月30万円のLLM利用！
  • 社員750人で月あたり2億円、なんと年20億円をAIに投入
  • その結果、コミット数として開発速度3倍以上
  • 登壇の様子と資料が全部公開されているのも太っ腹
一人 月30万円のLLM利用
750人 → 月2億円・年20億円
開発速度 3倍以上
AIコスト以上に利益が出るかはまだ分からない。 国内の先例として注視したい実験です。

④ LayerX 組織のつくり方

  • 中央管理はしない。中央はコストと情報管理だけ、使い方は各部署の自律性に任せる
  • 手続きと判断を分ける：見極める仕事はAI、決める仕事は人間
  • 判断のやり方は文書化して、AIと人間の境界をはっきり聞く
  • 任せっぱなしにせず人間とAIのアウトプットを比べて直す。分からない時は正直に言わせる
  • 呼び名は違うけれど似た構造に：経理=プレイブック・デザイン=ハーネス・人事=3層構造
月30万円の投資はすぐ真似できないけど、 見極める仕事→AI／決める仕事→人間 は今日から始められる！

⑤ メドレーの新職種

  • アプライドAIデベロッパーという新しい職種を発表
  • 対象は一定以上の職務等級のエンジニア・デザイナー・PDM（エンジニアだけじゃない！）
  • AIで業務のつくりを根本から変え、非連続な事業成果を生む役割
  • 外注すれば数千万・半年かかるシステムを一人で1ヶ月で作れる時代
  • 基本給＋目標連動の賞与で、最高年収6000万円超。社内応募と外部スカウトも
評価の仕組みがないと、すごい人は 外に出てしまうよなあ…。

⑤ AIプロリーグ型人事（提言）

  • 野球やサッカーのプロのように、AI活用のプロリーグ型人事を！
  • ポイントは機会は平等に、評価は能力と実績で
  • AIを使いこなす人の成果の差は、今の何十倍から何百倍へ広がる
  • 報酬はお金だけでなく社内での評価もセットで設計
  • くすぶっている優秀な人を引きとり、スーパーカンパニーへの飛躍へ
「評価されて月5000円」じゃ人は辞める。 制度づくりがこれからの経営の鍵！

第3章：メガテックとスタートアップ、AIが生活に染み込む

⑥ Meta の「Muse」専用アプリ

  • パーソナルAIエージェントMeta AIを独自アプリで提供（今は米国限定）
  • メール作成や旅行の予約など、いわゆるエージェント役を担当
  • Instagram・Messenger・WhatsApp などMetaサービスと接続
  • 面白い仕組み：実行役のMuseと門番のSentinelを分立。Sentinelは無効化できず、悪い指示を弾く
  • 個人データは誰も入れない専用マシンで管理（Metaの社員も不可、Appleと同じ方向性）
  • 勝ち筋は2つ：SNSとRay-BanのAIグラス
データが心配な層に届ける 分立と専用マシンの設計がミソ！

⑦ Apple の Siri がAI化

  • 新しいSiriは米国では9月、日本公開はもう少し先
  • メール・写真・メッセージを見られて、端末内で処理。データは外に出ない設計
  • 裏側はなんとGemini。約10億ドルの契約と言われる
  • エージェント利用者はまだ少数：Codex 2500万人÷ChatGPT 10億人＝2.5%
  • iPhoneならデータも最初からある。Siriがエージェントの入り口になる可能性
チャットAIでは出遅れたAppleだけど、 実行までやるSiriなら逆転もある！

第4章：ビジネスと課金のかたちが変わる

⑧ アクセンチュア×Google の1000人

  • 2社が組み、1000人体制のFDEを企業に展開していく取り組み
  • FDE＝Forward Deployed Engineer。現場に入って成果を出すエンジニア（Palantir発祥）
  • マッキンゼー調査：使用は9割なのに成果は6%。このギャップを埋める役割
  • 現場の知見を社内に持ち帰り、他案件へ横展開するのも仕事
  • AIをなんとなく導入した状態と、ビジネス成果の間にある大きな溝
効率化だけじゃなく 売上につなげる人が足りない—— だから高年収の人材の獲得合戦になる！

⑨ OpenAI の成果課金じっけん

  • 狙いは高単価の領域：半導体設計・ライフサイエンス・金融
  • 従来の成果課金は「問い合わせ1件1ドル」等のシンプルなもの。今回は桁が違う難しさ
  • プロジェクト・マーキュリー：外資金融の専門家に時給150ドルで仕事をしてもらい学習データを作成
  • 「1人月100万円」の人月モデルが限界へ。クライアントが変更要望
  • 知る業界で成果を定義し、第三者が判定できる形へ。早く挑んだ者がリード

  • ビジネスへの転用：営業リスト（重複・住所チェック）や提案書（社名の残り・金額の不一致）
  • 1万体×一人100社なら100万社ぶんを一気に処理できる！

⑫ 米国が中国AI6社を告発

  • 名指しされたのはDeepSeek・Moonshot・Alibaba Qwen・MiniMax・StepFun・ZAI
  • 手口は「蒸留」：思考の過程まで答えさせ、数百万件のデータを取得して学習に使う

  • チップ規制・モデルの海外利用制限に続く、3つ目の締め付け
