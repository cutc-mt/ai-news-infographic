仕組みを、ひもとくわ

蒸留（じょうりゅう）とは

  • 学校でたとえると: できる先輩に問題を全部解いてもらう
  • その答案を教材にして、後輩に同じ解き方を覚えさせる
  • つまり 答えを集めて自分のAIを鍛えるやり方
  • 「蒸留」はお酒と同じ字。煮詰めた中から、エキスだけ取り出す意味ね
ずんめ「先輩の答案が、そのまま参考書になるのだ」
めたん「転送の目的はまさにこれ。賢さを写し取りたいのよ」

線はどこにあるの?

  • 蒸留じたいは どこもやっている普通の手法
  • 悪いのは方法ではなく、この2つの点
  • ① 相手に断っているかどうか
  • ② 正面から入らず、裏口を使っていないか
めたん「泥棒かどうかは、入口と許可で決まるのよ」

中継サービスの仕組み

あなた 中継（代理窓口） Claude 等へ到達
  • 本人の代わりに注文を出してくれる 代理の窓口
  • 使えない国からでも、この窓口を通せば届く（リバースプロキシ）
  • 形は「まとめて安く使えるサービス」とそっくり。安く・早くが売り
ずんめ「それ、ぼくが最初に見つけたサービスと同じなのだ」
めたん「同じ形のものもある。だから油断は危ないの」

安さの正体

  • 偽の身元でアカウントを量産
  • 盗んだクレジットカードで決済
  • よそから盗んだ APIキー（プログラム呼び出しの鍵）も利用
  • それらでアカウントを 数千 個 作っていた
  • 盗まれた鍵の利用料は、契約している本人に請求が行く
めたん「誰かの盗まれた鍵が、その値段を作っていたことがあるの」
ずんめ「全然関係ない人が、お金を払うのだ。ひどいのだ…」

欲しがられる「質問の形」

  • 「ぼくの質問なんて、誰も欲しがらない」— それはまちかい
  • 欲しがられるのは悩みの中身ではなく、人が本当に困った時に書く質問の形
  • それこそが、いちばんいい教材になる
  • 一生けん命書いた質問ほど、価値が高い
めたん「『困った』の形をしたものが、いちばん高く売れるのよ」

守り方と、まとめ

無料の期間を延長?

  • DeepSeekは無料で試せる期間を延長していた
  • 蒸留が本格化したのは、その期間が終わる頃だったとレポートは見る
  • 「なぜ無料なのか」も、一度疑ってみる価値あり
ずんめ「無料の理由も、疑った方がいいのだ」

身を守る3か条

  • AIの名前じゃなく 誰が運営しているか で選ぶ。名前は看板、規約に書いてある扱いが本体
  • 鍵・パスワード・社内の資料は中継に投げない。遊びの質問と仕事の資料は、窓口を使い分ける
  • 自分のAPIキーを預けない。請求が行くのは、鍵を持っている本人
めたん「試すのはいいのよ。大事なのは、投げるものを選ぶこと」
ずんめ「使い分けなら、できそうなのだ!」

Claude側の対策

  • 考えた過程（思考過程）をそのまま出さず、省いて返すよう変更
  • 答案の“下書き”を渡さない → 盗んでも教材にしづらい
  • 怪しい使い方を見つけたら本人確認。応じなければ止める仕組み
ずんめ「これでもう大丈夫なのだ?」
めたん「‘大丈夫’とは言いきれないわね。続けて聞いて」

エンジンは映る、ブレーキは映らない

  • 蒸留でコピーされるのは 賢さ（エンジン） だけ
  • 元のAIが持つ 「やらない」という判断（ブレーキ） は、コピー先についてこない
  • Anthropic自身の実験でも同じ結果: 危ない話を一言も教えていないのに、危ないことができる側に育つ
めたん「これが私のいちばんの引っかかり。安全の部分は、写らないのよ」

教訓と、まとめ

  • ZAIの「フェーブル」は守りが固くて攻撃が通らず、犯行側は諦めて標的を変えた
  • 固く守ることは、邪魔ではなく盗まれない理由になる
  • 同じ被害は OpenAI も Google も報告済み。起きていることは複数社で一致
  • ただし報告書はAnthropic側の話。名指しされた会社の言い分は載っていない

要点は3つ

  • AIの名前は、答えた中身の保証にならない
  • 安さの出所が、誰かの盗まれた鍵だったことがある
  • 映るのは賢さだけ。ブレーキは映らない
めたん「投げる相手は名前じゃなく、運営と約款で選ぶ。それだけ決めておけば迷わないわ」
