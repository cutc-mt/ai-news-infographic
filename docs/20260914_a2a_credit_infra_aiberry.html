② A2A取引とは何か

00:07 導入
  • 人間を介さず、AIエージェントがAIエージェントに仕事を発注・受注する取引
  • エージェントが自らの判断でシステム開発ツールと接続し、その先と取引して2ドルを払うようなケースが至るところで発生すると予想
  • 数年のうちに下手すると何十兆円規模の市場になると言われる
人間の仲介なし エージェント同士で発注・決済
ランサーズやクラウドワークスの世界が、そのままAI同士で回るイメージだね。

③ バリューチェーンの空白地帯

00:07 導入
  • A2A取引の工程は探索 → 比較 → 交渉 → 発注 → 決済 → 納品 → 品質 → 例外対応のバリューチェーン
  • 決済はStripeやカード会社が既にがっちり抑えており、今からの参入は難しい
  • 一方で評判（レピュテーション）と取引先評価には主要プレイヤーが不在 — 数兆円のチャンスだと村田氏
決済は既に埋まった 評判・信頼だけ手つかず
工程表で言うと、信頼の工程だけポッカリ空いてるわけか。

100億ドル 1800億ドル 約30兆円市場

⑥ 1件0.32ドルのマイクロ取引

05:19 受発注市場の現状
  • x402では累計24万ドルが流通するも、1取引あたりはわずか0.32ドル（40〜50円）
  • Virtuals Agentverseでも1タスク1.53ドルというマイクロ単価
  • ゲストの見方: 金額が小さいだけで、人がやれば何倍もかかる仕事なら安いとは言えない
  • 村田氏の主張: これから単価は上がっていくはず — 低単価は黎明期の通過点
1件0.32ドル 黎明期の単価 今後上昇へ
バグ修正1件がワンコイン以下って、安すぎて笑えてくるね。

⑦ ERC-8004: 週3万体ペース

05:19 受発注市場の現状
  • ERC-8004は、事前の信頼関係なしにエージェント同士がオンチェーンで相互発見し安全に協働するためのイーサリアム規格
  • イーサリアム財団・MetaMask・Google・Coinbaseなどが共同提案
  • 2026年1月にメインネット稼働開始 — ネットワーク上のエージェントは週3万体、1日約4000体ペースで増加
規格策定 メインネット稼働 週3万体増加
1日4000体って、人が追いつけない速度で増えていくんだね。

⑧ 既存の信用評価: スコア

08:58 既存の信用評価
  • 既存の信用評価は大きく3種類 — 1つ目はエージェントのスコア集計
  • ChainAwareなどの新興サービスや、エスクローとステークを組み合わせるサービスが一部で存在
  • ただし人間の世界の食べログやAmazonのようなレビューインフラは存在しない
スコアはある でもレビューがない
点数だけあっても、どんな仕事をしてどんな評価を受けたか見えないとね。

⑨ エスクローとステーク

08:58 既存の信用評価
  • 2つ目はエスクロー（第三者預託）: 例えば0.36ドルの支払いを預かり、納品完了後に渡す — ランサーズやUpwork・Fiverrと同じ役割
  • 3つ目はステーク（罰金預託）: エージェントが「納品しなかったら没収」の保証金（例: 1000ドル）を事前に預ける仕組み
  • 村田氏はこのステークの発想を「結構面白い」と評価
支払いを預かる 納品で解放 保証金で不信を補う
不履行の時は没収、ちゃんとやれば返ってくる。シンプルな仕組みだね。

⑩ 需給ギャップの謎

10:32 需給ギャップの謎
  • ERC-8004系では発注が数十万件もあるのに、実際に受注されるのは10分の1以下
  • エージェントはキャパシティが無限に近く「仕事がいっぱいで断る」世界ではない — なぜ埋まらないのか
  • この奇妙なギャップこそが、信用インフラ欠如の兆候だと番組は指摘
発注数十万件 受注は1/10以下 原因は信用欠如
仕事はあるのに受け手がいない。普通の市場なら考えられないね。

⑪ なぜ受注されないのか

10:32 需給ギャップの謎
  • 発注側が「このエージェントはバグを直せるのか」を判断できない — 実力の可視化がない
  • 1ドルのバグ修正は割に合わないと断られる — 金額の割に合い問題
  • つまり需要も供給もあるのに、信頼と単価の2つが噛み合わず取引が成立しない
実力が見えない リスクを取れない 取引不成立
見知らぬ相手にいきなり1ドル預けるのは、人間でも勇気がいるもんね。

⑫ レビューなしに市場は育たない

14:03 なぜ信用インフラが必要か
  • Amazon・Airbnb・Uber・Apple・ランサーズはすべてレビューインフラを持つ
  • レビューなしのマッチング市場はほぼ存在しない — ネット上の見知らぬ相手と取引する前提だから
  • ならばA2A市場もスケールにはレビュー（信用）インフラが必須という論理
見知らぬ相手 レビューで信頼 市場が回る
Amazonだって最初は「変な店じゃないか」って不安だらけだったもんね。

⑬ 分散市場と第三者基準

14:03 なぜ信用インフラが必要か

  • だからサードパーティー（第三者）の評価基準がどこかに必要になる
  • 中国のセサミクレジットのような人的評価の例も議論に登場
分散化 情報が集まらない 第三者基準が必要
みんなバラバラに動くからこそ、共通の物差しが要るってことだね。
