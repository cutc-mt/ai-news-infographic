AIに「会社」を渡した

00:00 –
  • AIに役職を与えた
  • 報告するボスも設定
  • 率いるチームまで任せた
  • ノートPCを閉じても働き続けた
今週すこし「狂ってる」ことをやりました、という紹介から始まる動画です。

Agent OS とは

00:39 –
  • 2つのツールを配線して1つに
  • Paperclip＋Hermes＝単一ダッシュボード
  • AIチーム全体のコントロールルーム
  • チャットツールではなくワークスペース
「OS」と呼ぶのは、会話1つで終わらず 丸ごとの作業場だから！

Paperclip の役割

00:39 –
  • エージェントを本物の会社のように運営
  • 組織図・部門・チケットを管理
  • タスクの割り当てと進ちょく把握
  • エージェントの「採用」もここから
いわば「経営側」の役割。会社のしくみを丸ごと動かします。

Hermes の役割

00:39 –
  • 袖をまくってじっさいに作業する側
  • 文章・Webサイト・調査などをこなす
  • 単体のデスクトップ版だと壁にぶつかる
  • 他ツールを接続できない問題も
単独では音声アシスタント構築も できなかった → Agent OSが解決！

生きた組織図（Org Chart）

01:03 –
  • てっぺんにCEOエージェント
  • 下は3部門へ分岐
  • 箱のすべてが役職と仕事を持つ
  • スライドの図ではなく動いている生きた図
CEOエージェント

Engineering / Marketing / Operations
Agent OSを開いた瞬間、最初に目に入るのがこの組織図です。

Engineering 部門

01:03 –
  • 開発・構築を担当する部門
  • Webサイトを丸ごと制作
  • 完成品のスクリーンショットも自主的に
  • 自分の仕事を自分でチェック
仕事→検品→証拠の提出まで、ダッシュボード外に出ずに完結！

Marketing 部門

01:03 / 01:46 –
  • 「書くこと」だけが仕事のエージェント
  • 2通のメールを最初から最後まで作成
  • キーワード調査を1式実行
  • 人の監視ゼロで完成品を提出
ウェルカムメールシーケンスが いつの間にか完成してた、という実例の紹介です。

Operations 部門

01:03 –
  • 日々の運営・管理を担当
  • 成果物をチケットに結びつけ
  • issuesタブに結果を保管
  • どこにも消えず迷子にならない
キーワード調査の結果も issuesタブに現れて、すぐ読めました。

ライブアクティビティフィード

01:03 –
  • 全エージェントの作業がリアルタイムで流れる
  • すべての動きにタイムスタンプ付き
  • 更新ボタンは不要
  • 行が次々に追加され、終了も見守れる
「ほんとに動いてる？」という不安が ゼロになる画面です。

単独で成果①: メールシーケンス

01:46 –
  • メール1通目から
  • 2通目まで完全自動で執筆
  • 人は1行も触っていない
  • 作業時刻も自分で記録
マーケ部門のライター:
  ✅ ウェルカムメール ×2 完了
  📅 09:12 / 09:41 (自動記録)
  📥 完成品 → 承認待ちへ
これが Agent OS のリズム: 任せる → できてる → 届く。

単独で成果②: Webサイト丸ごと

01:46 –
  • エージェントがサイト全体を構築
  • 完成後、自分でスクショを撮影
  • その画像をダッシュボードへドロップ
  • ほぼ全タスクで証拠（レシート）付き
仕事→検品→証拠提出を 自分でやるのがすごい！

音声アシスタント「Hermes Jarvis」

03:01 –
  • 声で話すと声で即答
  • 「ウォールモード」にも切替可能
  • 声の種類を差し替え自由
  • 専用のウェイクワードを設定
  • 呼ぶと起きて聞き始める
エージェントのダッシュボードに 音声アシスタント内蔵は初見、とのこと。

内蔵スタジオ

03:01 –
  • 動画制作がその場で可能
  • 画像生成も同じ場所から
  • 音声制作も1画面で
  • セッションは自動保存・履歴をさかのぼれる
  • アプリを行き来する必要なし
制作物が全部「1つの屋根の下」に まとめて置けます。

Claude Code 統合

03:01 –
  • Claude Codeが同じ画面で起動
  • 構築中の様子をライブプレビュー
  • 組織図・フィードと同画面
  • 対話しながら開発を見守れる
「チャットツール」でなく「OS」と呼ぶ ゆえんがここにあります。

統制①: スケジュール（heartbeat）

04:52 –
  • 全エージェントがスケジュールで駆動
  • いつでも一時停止できる
  • 再開してタスクを追加も自由
  • 実行履歴から完了内容を確認
「どこまで終わったか」が はっきり見えるのが安心ポイント。

統制②: トークン上限

04:52 –
  • エージェントごとにトークン上限を設定
  • 上限到達で即ストップ
  • 勝手な暴走を未然に防止
  • 「どこまで行くか」を人が決める
「急にコストがふくらむ」のような 驚きを防げます。

統制③: 承認フロー

04:52 / 05:58 –
  • あなたは創業者（founder）
  • 承認なしでは外に出ない
  • ダメ出しはコメントで差し戻し
  • エージェントがもう一度挑戦
  • 最終判断は常に人間
完成品 チケット 承認 リリース
一番よく聞く質問「AIが勝手に投稿するの?」→ しません！

まとめ & はじめ方

05:58 –
  • 「にんじんぶら下げ」不要の導入
  • hireボタン → 役割を選ぶ → 完了
  • 無料モデルでも実行可能
  • 普段使いのタスク管理ツール感覚
  • 大部隊でなく少数でOK
  • 後は静かに回り続けるだけ
