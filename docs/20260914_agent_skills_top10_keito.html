② スキル＝手順書の概念

00:17 基本概念
  • スキルとはAIエージェントが読み込む手順書のこと
  • 特定タスクを再現性高く・いつも通りこなせるようになる
  • 作成の肝はいかに簡単に仕事を任せられる手順書にするか
  • スライド資料作成スキルなどが有名どころのパターン
手順書を書く AIが読み込む 再現性のある作業
スキルの本体は「再現性」。決まった仕事を毎回同じ品質で回すための仕組みです。

③ スキルの作り方

01:20 スキル作成方法
  • 作成手順は過去の解説動画で詳しく紹介済み
  • Claude Codeなら/skill-creatorが標準搭載
  • Codexにもスキル作成用のスラッシュコマンドが用意
  • 「スキルを作るスキル」を活用して自分用に作成
作成用スキル起動 指示 スキル完成
スキルを作るためのスキルがデフォルトで入っているので、意外とすぐ作れます。

④ スキル1：メモ保存スキル

01:50 1つ目
  • KEITO氏はObsidianと連携したメモ保存スキルを運用
  • スキルが増えると「どう使うんだっけ？」と忘れる
  • スキル作成時に自動でメモが貯まる仕組みを先に用意
  • 人に勧める時もまとめノートがあると伝えやすい
スキル作成 自動でメモ保存 後から検索可能
自分の頭でメモしようと考える前に、AIがメモを取っておいてくれる状態を目指します。

⑤ Obsidian連携の実態

01:50 1つ目（詳細）
  • Obsidianの公式CLIをラッパー経由で呼び出し
  • 保管庫（Vault）の読み書きをコマンド1発で実行
  • 全文検索・デイリーノート操作・プロパティ編集も可能
  • 保管庫はルール・ガイド・テンプレ・CSSスニペットの置き場
Claude Code CLIラッパー Vault操作
ノートやEvernoteなど別のメモアプリでもOK。ただ個人的にはObsidianがClaude Codeと相性抜群とのこと。

⑥ スキル同士の自動連鎖

01:50 1つ目（応用）
  • フック（Hooks）や他スキル内にも保存処理を組み込み
  • skill-creatorで生成後にメモスキルが自動起動
  • 新しいスキルを作るたびメモが自動蓄積される連鎖
  • 実演ではリッチなテキスト表現のサンプルを即座にVaultへ保存
スキル生成 フック発火 メモ自動保存
「AIにメモを取らせる」習慣ができると、スキル資産が勝手に育っていきます。

⑦ スキル2：日本語スキル

06:18 2つ目
  • 自然な日本語で回答を調整するスキル
  • 「絶対に作った方がいい」と断言するおすすめ度
  • 基本的な日本語ルールはネット上の情報を取得して調整
  • 自分で独自ルールを決めて運用してもOK
指示 日本語スキル適用 自然な回答
AIっぽい言い回しの出力に悩んでいる人は、まずここから作るのが近道です。

⑧ NG表現リスト運用

06:18 2つ目（詳細）
  • Obsidian内にNG表現リストのノートを常設
  • 例：「安全です」「今後の展望」「ここからが本編」等の定型句
  • 「この使い回しやめて」と伝えるとリストへ自動追加されていく
  • 日本語スキルがリストを全文読み込んでから回答生成
ダメ出し NGリスト更新 次回から反映
使わない言い回しを溜めていくほど、出力が自分の好みに近づいていきます。

⑨ 設定ファイルとの連携

06:18 2つ目（応用）
  • Claude CodeのCLAUDE.mdに設定を追記
  • Codex側はAGENTS.MDに同じ役割を持たせる
  • 「日本語のやり取りでは必ず日本語スキルを読み込む」と明記
  • 音声入力の誤字脱字も自然文に整形してから指示に変換
音声入力 自動整形 適切な指示へ
話した内容をそのまま投げても、AIがきれいな日本語に直して理解してくれます。

⑩ スキル3：デザインスキル

09:00 3つ目
  • 自分のコーポレートサイトのデザインを丸ごとスキル化
  • Web制作・PowerPoint資料・画像生成に共通利用
  • 1個用意するだけでブランド感を統一した制作物が作れる
  • 実演ではリッチ表現のサンプル集へ自社デザインを追加生成
サイトのデザイン スキル化 全制作物で統一
「何かを作る時すべて」に効くのがデザインスキル。ブランドの一貫性が保たれます。

⑪ デザインパーツの作り方

09:00 3つ目（詳細）

  • skill-creatorでスキル作成時にパーツをアップロード
  • スラッシュコマンドなしでも文脈で自動的にスキルが発動
Claude Design DL スキル化 常時呼び出し
「このスキル使えばいいだろう」とAIが判断すれば、コマンドを打たなくても動いてくれます。

⑫ スキル4：スキルサーチ

13:02 4つ目
  • 依頼内容に対してどのスキルを呼ぶべきか提案してくれる
  • DLしたもの・自作・未使用などスキルが大量化しがち
  • 使うべきスキルを瞬時に検索できるようになる
  • スキル選定を任せればコンテキストの節約にも直結
指示 スキル検索 最適なスキルを提案
スキルが増えすぎて困ったら、まず「スキルを探すスキル」を作りましょう。

レイアウト在庫 当てはめ ブランド統一の資料
