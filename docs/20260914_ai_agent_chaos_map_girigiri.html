AIエージェントツールのカオスマップ全貌

つくる・つなぐ・うごかす・ささえる — 約100個（公開版140個）のツールを4ゾーンに整理した地図を全員で読み解く
2026-08-21 ／ ギリギリ開発会議 by ボイスアップラボ ／ 15分59秒

① カオスマップ誕生の背景

序盤: 番組オープニング
  • AIエージェント関連ツールが急増し続けて到底把握できない状況——「誰も全部把握してない」と出演者
  • メンバーの一人がAIエージェントツールのカオスマップを作成、番組で全員で見ながらレビューする回に
  • 動機は「業界の全体像をなんとなく理解したい」——分野として知らないものも多いと告白
  • ツール数約100個に対し「3つぐらいしか触れない」とジョークが飛び交う
ツール急増 全体像不明 カオスマップ化
「100ぐらいあったんで3つぐらいしてください」——全部は無理という自覚から始まる回。

② 4ゾーンの分類軸

序盤: マップの構造説明
  • マップはつくる・つなぐ・うごかす・ささえるの4軸（ゾーン）で構成
  • 各ゾーンの中に分野ごとのカテゴリが入り、ツールがバッジ（先駆者・主力・新興・専門家・セキュリティ）付きで配置
  • 各カテゴリはクリックで拡大可能——番組内でも触りながら確認
  • 基盤モデルは収録対象外——あくまでエージェント周辺ツールの地図
つくる つなぐ うごかす ささえる 4ゾーン
「作る・繋ぐ・動かす・支える」——シンプルな4軸に100個が収まるのがすごい。

③ マップ公開と実装

序盤: 公開の経緯
  • 「全部見えるように公開してよ」の流れで概要欄で一般公開（rsasage.com）へ
  • 実装は素のJavaScript、フレームワーク不使用——出演者「JSでここまでやっちゃうんだ」
  • 動画収録時は約100個、公開版は140個まで拡充（収録基準あり）
  • 視聴者へ一押しツールの募集——「詳しい人教えてください」と番組側
社内レビュー 公開判定 概要欄リンク
「Reactで動いてるなと思ったら素のJSだった」——モダン環境ゼロで地図を作り切った話。

④ 自立型開発エージェント

つくる系: 1番重いゾーン
  • Claude Codeが現在の主力——Codexが対抗馬という構図
  • OpenCodeはClaude Code系のオープンソース版的存在で、タグにOSS・ビッグテック等の属性が付与
  • OpenHands（旧OpenDevin）はDevinのOSS版的存在——2024年登場でDevinとほぼ同時期
  • Devin自体はSaaSで今も現役利用——「懐かしい」のに「全然使われてる」
Claude Code 主力 Codex 対抗 OSS勢が続々
「OpenCode有名ですよね」——作った側が知らないツールをリストで発見する回でもある。

⑤ Pi Agentの立ち位置

つくる系: 注目の新参
  • Pi Agentはオープンソースのコーディングエージェントで、4ツールのみの超ミニマル構成
  • 軽く動いてトークンをあまり消費しない——後から欲しいスキルを足していく設計
  • OpenClawの基盤エンジンとして採用、Pi Agent単体での利用も多い
  • AIクロー系ユーザーへの言及——ミニマル志向の人気を裏付ける
ミニマル構成 低トークン消費 スキル後追加
4ツールだけなのに人気——「シンプルに使える」がエージェント時代の武器になるんだね。

⑥ アプリ生成ツール群

つくる系: 口コミを聞く
  • v0（Vercel製）は「先駆者かもしれない」——周辺ツールが追いつくきっかけに
  • Replit Agentは「最近聞かないけどまだ元気なのかな」と声が割れる
  • Bolt.newは出演者にも「聞いたことある」程度の認知
  • 今いちばんの注目はGoogle AI Studio——MCPと繋げられプロンプトから製品レベルのアプリが作れると口コミ
v0 先駆 Replit・Bolt.new Google AI Studio注目
「普通に製品レベルのものができちゃって」——アプリ生成はもう玩具ではない完成度らしい。

⑦ エージェントフレームワーク

つなぐ系: 土台を作る
  • エージェントを構築するためのツール群——LangChain / LangGraphが定番の名前
  • MastraはTypeScript向けフレームワークで「最近たまに聞く」新顔
  • Google ADK（Agent Development Kit）は2025年登場の公式フレームワーク
  • A2A（Agent2Agent）プロトコルも登録——「どうなってるんだろう？」と動向が話題に
LangChain 系定番 Mastra・Google ADK 新SDK続々
フレームワークだけでもう把握しきれない——「新しめのSDKが次々出る」のがこの地図の地勢。

⑧ ワークフロー自動化

つなぐ系: 一時期ブーム
  • n8n・Dify・Zapier・Makeが主要どころ——「一時期ぐわっと盛り上がった」
  • FlowiseはノードベースのLLMフロービルダー——一時代築いたが今は聞かなくなった
  • 国産ノーコード自動化のYoomが「結構元気」と紹介される
  • 流れとしてはOpenAI AgentKit / Agent Builder——「Zapierの代わりに使える」評も
Zapier時代 n8n・Dify台頭 AgentKit登場
Zapierが「狙い撃ちにされる」時代——入れ替わりの激しさが自動化ゾーンの特徴だね。

⑨ Dify移行の評価

つなぐ系: 意見が割れる話題
  • OpenAIモデル前提のロックインを嫌う層は多い——AgentKit活用の落とし穴
  • しかしZapierからDifyへの移行には至っていないというのが現場の評価
  • Flowiseの退潮も含め「1年〜1年半前はやっていた」と振り返る出演者
  • カテゴリ横断で実際に使った人の声がまだ少ない領域と分析
ロックイン懸念 移行検討 まだ至らず
「便利そう」と「移行するほどでも」の間——新しいツールの判断は現場の声次第なんだね。

⑩ エージェントメモリ

つなぐ系: 全員知らない領域
  • エージェント向けにコンテキスト・会話を記憶しておくサービス群——出演者「全部知らなかった」
  • Mem0が2024年登場以降事実上の定番に——「新しいのあんま出てない」
  • 出演者の一人はMem0のアカウント保有——ただし「使ってない」と告白
  • 「使った方がいいのか？」セッションメモリ管理の是非は番組内でも未解決
会話・文脈 メモリ層に保持 エージェント再利用
アカウントだけ作って放置——新しいツールの正しい距離感がこれかもしれない。

⑪ MCP・ツール連携

つなぐ系: 認証の壁
  • MCP・ツール連携のサービス群——複数AIからの作業支援と認証部分を支える
  • 「パッケージ導入するだけでは？」の直感に対し認証周りは作るのが難しいという解説
  • 外部サービスとの安全な接続を代行するツールが並ぶカテゴリ
  • 名称の割に地味な存在——縁の下の力持ちゾーンと位置づけ
MCP接続 認証を代行 ツール連携完了
「導入するだけじゃないんだ」——地味なのに必修単元っぽいカテゴリだね。

⑫ 複数エージェント業務管理

うごかす系: 注目の最前線
  • Multicaは「チームメイトを増やす感覚」でAIを導入できるツールとして前回紹介済み
  • LinearはエージェントをIssue・プロジェクトに割り当てる先発かつ新しめの存在
  • GitHub Agent HQ——Issueの週回しをエージェントに委任、ほぼGitHub完結の開発が可能に
  • 「登録して使うとGitHubだけでだいたい完結しちゃう」と開発組織の選択肢への言及
エージェント Issue担当割当 開発完結
「リニア？ライナー？」——名前の読み方で盛り上がるのも地図あるあるなんだね。

⑬ 耐久ワークフロー

うごかす系: 長時間処理の保険
  • AIに長時間処理させると途中で止まる等の問題が起きる——それを防ぐサービス群
  • カテゴリ名は耐久ワークフロー / Durable Execution——処理の中断耐性を保証
  • Temporalは2020年起源の耐久実行エンジン——「結構使われている」
  • 登場はやや古めでピボットを重ねて現在にという評価も
長時間AI処理 中断リスク 耐久実行で保証
「2020年？ちょっと古すぎるな」——地図の中にちゃんと歴史があるのも面白い。

⑭ サンドボックス

うごかす系: 面白いと注目
  • AIの仕事ごと・セッションごとに隔離されたコンピューターを立ててその中だけで作業させる
  • 基盤はmicroVM——めっちゃ軽量で並行して大量のVMを起動可能
  • 軽さとセキュリティ保持を両立——開発時によく使われるという
  • 難点は「トークンが偉いことになりそう」——大量並列のコスト面を懸念
セッション単位 隔離VM起動 並列実行
隔離されて安全でも課金は残る——「トークンが偉いことになりそう」はもっともな心配なんだね。

⑮ クラウドAIエージェント基盤

うごかす系: 企業導入の定番
  • Amazon Bedrockが企業導入の筆頭——生成AI基盤として使う会社が多い
  • 各クラウドベンダーごとに基盤を用意——違いの理解は出演者も「そこまでできてない」
  • Cloudflare OSは隔離ランタイム＋Gatekeeperで統制——界隈で久々に騒がれた新顔（詳細は専用回で）
  • 基盤間の違いより「Bedrockが強い」という印象論が先行する状況
自社エージェント クラウド基盤選定 導入・運用
会社で導入するならここから選ぶ——地図の中で一番「お堅い」ゾーンかもね。

⑯ 常駐型AIエージェント

ささえる系: ブームの火付け
  • OpenClawが2025年11月に登場——常駐型エージェントブームの火付け役に
  • Hermes Agent（Nous Research）は経験からスキルを自動獲得する自己学習型で人気
  • セキュリティ懸念への回答として安全側に振った選択肢も登場
  • NemoClaw（NVIDIA製）はOpenClawにサンドボックス・監査ログを追加した構成
OpenClaw登場 ブーム発生 安全系が追従
ブームを作った側と、安全を突き詰める側——常駐型はまだ始まったばかりなんだね。

⑰ 持ち帰りと視聴者参加

終盤: 振り返り
  • 「全部は触れない」——100個中3つ厳選のジョークで締めくくる収録
  • 収録を通じ「分野として知らないものがあった」という学びが持ち帰りに
  • 番組から視聴者へ一押しツールの募集——「詳しい人教えてください」
  • マップは概要欄からアクセス可能——視聴者も自分でズームして探索可能
番組レビュー 概要欄公開 視聴者の一押し募集
地図を作った本人も全部は把握していない——完璧な地図より、共有する地図が価値を持つんだね。

⑱ まとめ: 地図としての価値

結末: エンディング
  • カオスマップでAIエージェント周辺の全体像を一望——4ゾーン×カテゴリで整理
  • 所属組織でのツール選定の地図として活用できる構成
  • マップ本体は概要欄のリンク（rsasage.com）から——収録約100個→公開版140個
  • 番組はSpotify・Apple Podcast・YouTube・YouTube Musicでも配信中
カオス 4ゾーン整理 選定の地図へ
「誰も全部把握してない」からこそ地図が必要——カオスを共有する価値の回だった。
