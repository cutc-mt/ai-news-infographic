② Obsidianとは

00:00 基礎解説
  • iPhoneの純正メモやEvernoteに似たメモアプリ
  • 最大の特徴：ローカルPCのフォルダーをそのまま美しく表示
  • 中身はマークダウン記法のただの文字列
  • 色付け・チェックボックス・表形式も記法で整えられる
ローカルフォルダー Obsidianが表示 綺麗なメモに
結論、ローカルのフォルダーにメモを入れておけば、Obsidianが勝手に綺麗に見せてくれるだけのシンプルなアプリです。

AIがファイル作成 Obsidianに即反映 性能向上

⑥ 保管庫（Vault）を作る

05:13 セットアップ
  • まず「保管庫」と呼ばれるフォルダーを作成・指定
  • 保管庫管理→「保管庫を新規作成」で名前と保存場所を決める
  • 実演ではデスクトップに「テスト」という保管庫を作成
  • 初期ファイル「ようこそ.md」は削除しても復元可能
保管庫を新規作成 場所を指定 フォルダーと同期
ファイルを削除・復元すると、Obsidianの表示も即座に同期されます。中身はローカルのただのフォルダーです。
