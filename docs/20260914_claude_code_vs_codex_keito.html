③ Claude Codeは「センス」

1:02 モデルの話
  • スライド資料を作り込むと本当に綺麗 — 手順を用意すれば安定して一級品が出る
  • Webサイト・Webツール・画像・動画も雰囲気のいいものが簡単に
  • エッセイ等の文章もセンスのある言い回し — ただしFable 5を使っている場合の話
手順を用意 安定して綺麗な成果物
「クリエイティビティ高い人」っぽい出力、ちゃんとあるんだ！

④ Codexは「堅実」

1:02 モデルの話
  • とにかく最後までやり切ってくれる強さ — 細かいところもちゃんと実装する感覚
  • ただしパッと見の印象やデザインの雰囲気はClaude Codeに劣ると明言
  • 性格で例えると堅実で真面目・コツコツ型 — ただ少し「かた苦しい」
見た目は Claude 細部の実装は Codex
「センスの人」と「真面目な職人さん」って分け方、しっくりくる…！

⑤ デスクトップアプリはCodex圧勝

1:02 使い勝手 UI/UX
  • Codexのデスクトップアプリは完成度が異常に高い — ボタンをポチポチするだけで直感的に理解できる
  • サイドパネルなどVS CodeやCursorに近いIDE感覚で使える
  • 設定・プラグイン類も整理されていて、パッと見で使い方が分かる設計
分かりやすいUI 非エンジニアでも安心
ChatGPT系のUI設計の上手さ、Codexにも受け継がれてるんだ！

⑥ Claude Codeアプリは難しい

1:02 使い勝手 UI/UX
  • 最近良くはなってきたが、依然エンジニア向けに見えてしまうアプリ
  • 英語表記の文字列がずらっと並び、設定項目の言葉も分かりづらい
  • Codexは非エンジニア寄りの言葉遣い — サブエージェントの作業状況も視覚的に分かりやすい
エンジニア向け感 初心者にはハードル
「なんかエンジニアの人が使うアプリっぽい」って見え方、わかる…！

⑦ CLIならClaude Code圧勝

1:02 使い勝手 UI/UX
  • Macのターミナル／WindowsのPowerShellで使うCLIだとClaude Codeが圧倒的に使いやすい
  • CodexはCLIだとメニューもコマンドも少なく、ファイル構造の設計も Claude Code並みでない
  • Claude Codeは細かいカスタマイズ・設定コマンドが豊富で、表示も見やすい
GUIならCodex CUIならClaude Code
「Codexはアプリ前提、Claude CodeはCLI前提」って棲み分けなんだ！

⑧ リモート接続の体験差

1:02 使い勝手 UI/UX
  • Codexはスマホで「接続」をポチるだけで完了 — 一般アプリ並みの簡単さ
  • Claude CodeはCLIで/remote-control コマンドを打って接続 — 慣れれば簡単だが操作が難しい人も
  • リモートを一度使い始めると、ない世界には戻れないレベルの便利さ
ポチで接続(Codex) コマンド入力(Claude)
繋げるだけならどちらも簡単、でも“押すだけ”は強い…！

⑨ 機能の多さはCodex

1:02 機能とエコシステム
  • GPT Image 2による画像生成を標準機能として搭載 — Claude Codeは一切できない
  • 音声入力アプリを内蔵 — AIリライトで綺麗な文章化、他アプリ上でも入力可能
  • メモ・Excel・PowerPoint・ブラウザーなどあらゆる場面で音声入力が可能
画像生成 音声入力 Codexだけの標準機能
音声入力アプリ1つで音声AIが完結するの、地味にでかい！

⑩ Claude Code側の迂回策

API取得＋自作(Claude) 標準装備(Codex)
