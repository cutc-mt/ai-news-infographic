② Cloudflareとは

00:49 概要
  • ウェブサイトやWebツールを配信するクラウドネットワークサービス
  • サイトのみならずWebアプリ・MCPの配信なども可能
  • 世界中のウェブサイトの約4分の1がCloudflare経由で表示
  • 画像や動画の保存もできるサーバーレス型サービス
サイト アプリ MCP 1つで配信
世界のサイトの1/4が通る巨大ネットワーク。それでいて無料枠が広い！

  • 画像・動画などファイルの保存にも対応

⑥ 用語: Workers

03:23 主要用語
  • サイト・アプリを表示する配信の役割を持つ
  • 世界中に拠点（東京・中国・韓国・ロシアなど）
  • ユーザーの最寄り拠点から配信される仕組み
  • 結果としてめちゃくちゃ速い表示が実現
最寄り拠点 近い = 速い 高速表示
世界中に散らばった拠点の一番近くから配信してくれるから、表示が爆速なんだ。

⑦ 用語: R2

03:50 主要用語
  • ファイル保存を担うストレージ
  • 画像・動画・PDFなどのファイルを保存
  • 保存した素材をサイトから配信する流れで活用
  • 後述のWrangler経由で設定・操作可能
素材ファイル R2に保存 配信
画像や動画の「置き場所」。デモでは無料素材をR2に入れて使ってました。

⑧ 用語: D1

04:10 主要用語
  • Cloudflare上のデータベース
  • イメージはExcelのような表
  • アプリのデータを構造化して保存
  • D1もWrangler経由で作成・設定できる
アプリデータ D1に保存 読み書き
データベースといってもExcelみたいな表のイメージでOK。難しく考えない！

⑨ 用語: KV

04:30 主要用語
  • 1行程度のメモを保存する場所
  • 秘密鍵・ちょっとした暗号などの保存に向く
  • 小さな設定値をどんどん置いておくイメージ
  • KVもWranglerで設定できる対象の1つ
秘密鍵や設定 KV 1行メモ
秘密鍵とか小さな値のメモ置き場。D1が表なら、KVは付箋みたいなもの。

04:50 主要用語
  • Cloudflareを操作するためのコマンドツール（CLI）
  • いわゆる黒い画面で操作するハッカー風ツール
  • R2・D1・KVの設定や新規登録がコマンドで可能
  • コマンド操作＝Claude Codeに使わせられるということ！
