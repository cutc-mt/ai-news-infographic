  • 声のサンプルを渡せば、好みの書き味に上書きできる
  • 貼り付けテキスト / ファイル / インラインで実行

OpenVikingエージェント用コンテキストDB

  • メモリ・ナレッジ・RAG・スキルをひとつにまとめるコンテキストデータベース

  • セッションからメモリを自動抽出（Vulc engine）
  • pip でインストール可能

anything2explainerなんでも解説動画に

  • Claude Code / Codex用スキル: トピックや文書をナレーションつきの解説ムービーに変換
  • 流れ: リサーチ → ナレーション執筆 → フレーム正確な音声生成 → 絵コンテ → 並列ビルドエージェントがアニメをコード化

  • レンダリングはヘッドレスChromiumでCPUのみ・GPU不要
  • 中国語 / 英語ナレーションに対応、文字組みとTTSも声に合わせる
Vincentwei1021/anything2explainer
