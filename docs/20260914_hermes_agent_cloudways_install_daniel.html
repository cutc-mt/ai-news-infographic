Cloudways に Hermes Agent を入れる手順

①Hermes Agentとは: 自分で育てるAI相棒

まずは正体から
  • Hermes Agent は、Nous Research が公開しているオープンソースのAIエージェントです。
  • APIキーを設定するだけで、会話・ファイル編集・検索などを自律的にこなす相棒になります。
  • 手元のPCだけでなく、クラウドのサーバー上でも稼働させられるのが特徴です。
  • お好みのLLMと組み合わせられるので、料金と性能を自分で選べるのが大きな魅力です。
APIキーを入れる 自分専用のAI 育てて強くする
「エージェントを飼う」感覚を掴むのが、この動画の出発点です。

②Cloudwaysとは: 面倒を見てくれるクラウド

土台の紹介
  • Cloudways は、VPSの構築や運用を丸ごと代行してくれるマネージドホスティングのサービスです。
  • バックエンドは DigitalOcean や AWS などから選べます。
  • サーバー作成やSSH接続などの操作が、管理画面のボタンで完結します。
  • 手ごろな月額プランから始められるので、個人でも気軽に試せる点が評価されています。
サーバー構築・保守が丸ごとお任せ
→ 本体の設置に集中できるのが最大の利点
難しいサーバー知識の代わりに、「おまかせ」を選ぶ発想ですね。

③なぜクラウドで: 24時間稼働のすすめ

構成の狙い
  • 手元のPCを付けっぱなしにしなくても、エージェントが常に待機してくれます。
  • スマホから接続すれば、外出先からでも指示出しが可能になります。
  • 定期実行と組み合わせて、夜の間に情報収集をさせる使い方もあります。
  • 「自分の分身をクラウドに置く」のが、この構成の目的です。
PCの電源 サーバーが常に稼働 いつでも話せる
寝ている間に仕事を進めてもらえるのは、夢がありますね。

④必要なもの: 事前の準備リスト

用意するもの
  • Cloudways のアカウント。登録は無料で、画面の案内に沿えば数分で終わります。
  • 使いたいLLMのAPIキー。OpenAI や Anthropic、Google などから発行します。
  • SSHで接続できるターミナル。Windows の PowerShell でも大丈夫です。
  • 動画の手順をなぞるだけなら、専門的なサーバー知識はほとんど不要とのこと。
事前にAPIキーだけ手元に置いておくと、作業が詰まりません。

⑤サーバー作成: まずは土台を用意

手順その1
  • Cloudways の管理画面から Add Server を選びます。
  • 基盤は 最安のプランで十分に動作する、と動画では解説されていました。
  • リージョンは自分に近い場所を選ぶと、通信が速くて快適です。
  • サーバー名を決めて起動すれば、数分で土台の完成です。
Add Server プラン選択 リージョン選択 起動
最初から大きなプランにしないのが、コスト管理のコツです。

⑥SSH接続: サーバーの中に入る

手順その2
  • 管理画面の Master credentials から、ユーザー名とパスワードを確認します。
  • ターミナルに ssh ユーザー名@サーバーIP を入力して、ログインを実行。
  • 接続できれば、自分のPCと同じ感覚でコマンドが打てる状態になります。
  • 初回ログイン時にパスワードの変更を求められるので、強いものを設定しましょう。
$ ssh app@xxx.xxx.xxx.xxx
（パスワード入力 → サーバー内へ）
ここで出てくる認証情報は、後でまた使うので控えておきます。

⑦Node.js環境: 動作の土台を作る

手順その3
  • Hermes Agent は Node.js 製なので、まず実行環境を導入します。
  • 公式の手順に沿って推奨バージョンをインストールすればOK。
  • node -v と npm -v でバージョンが表示されれば、準備は完了です。
  • 必要な依存パッケージも、この段階でまとめて入れておきます。
リポジトリ追加 Node.js導入 バージョン確認
表示されたバージョン番号は、トラブル時に役立つのでメモしておくと安心です。

⑧本体の導入: いよいよ設置

手順その4
  • npm 経由で Hermes Agent をインストールします。
  • 導入が終わったら hermes --version を叩いて、動作の確認をしましょう。
  • グローバルに入れておけば、どのディレクトリからでも起動できて便利です。
  • ここまで来れば、完成はもう目の前です。
$ npm install -g hermes-agent（例）
$ hermes --version → 数字が出れば成功
番号が返ってきた瞬間が、一番うれしい瞬間ですね。

⑨初期設定: ウィザードに従うだけ

手順その5
  • hermes setup を実行すると、対話形式で設定が進みます。
  • 使いたいプロバイダーを選び、APIキーを貼り付けます。
  • モデルの好みや名前も、この場で質問に答えるだけで決められる設計です。
  • 迷う項目は既定値のまま進めてOK、と動画では補足されていました。
setup開始 質問に回答 設定ファイル生成
対話形式なので、初心者さんでも迷いにくい作りになっています。

⑩頭脳との接続: APIキーの登録

手順その6
  • OpenAI・Anthropic・Google などのキーを、各社のコンソールで発行します。
  • 発行したキーはコピーして貼り付け。これで頭脳とつながります。
  • 複数登録しておけば、用途ごとにモデルを切り替えられて便利です。
  • キーは絶対に公開しない。共有や投稿は厳禁です。
各社コンソール → キー発行 → 設定に貼り付け
（漏洩すると勝手に使われるので要注意）
鍵は「合鍵」。誰にも渡さないのが、大前提ですね。

⑪起動と確認: いよいよ対話開始

手順その7
  • hermes start でエージェントを起動し、チャットができる状態にします。
  • まずは軽い挨拶や質問を投げて、応答が返るかを確認しましょう。
  • 応答が遅いときは、モデルや設定を見直すのが得策です。
  • 返事が届けば、クラウド上の分身が誕生した瞬間です。
起動 挨拶する 応答確認 完了！
初めての返事は、どうしてもちょっと感動します。

⑫Web UI: ブラウザから話す

便利な入口
  • Web UI を有効化すれば、ブラウザ越しに対話できるようになります。
  • スマホからも開けるので、移動中でも指示出しが可能です。
  • ログイン用のパスワードを設定して、しっかり保護しましょう。
  • 手元のPCに何も入れなくていいのが、この構成の利点です。
ネットさえつながば、どこからでも話せるのが強いですね。

⑬セキュリティ: 玄関を閉める

公開前の必須作業
  • Web UI へのアクセスには認証を必ず有効化します。
  • Cloudways のファイアウォールで、不要なポートを閉じておきましょう。
  • SSH を鍵認証に切り替えると、さらに安心です。
  • 「自分だけが入れる部屋」にするのが、公開サーバーの鉄則です。
認証 ON ＋ 不要ポートは閉鎖
＋ 可能なら鍵認証へ → 三重の鍵
「動いた！」で喜んで終わらず、鍵かけまでが作業です。

⑭常時稼働: 止まらないエージェント

運用の工夫
  • tmux などの仮想端末を使えば、切断後もプロセスが存続します。
  • クラウドだからこそ、電源を気にせず24時間の待機が可能です。
  • 定期ポーリングを設定すれば、自律的にタスクをこなす動きもできます。
  • 「夜の間にリサーチをまとめておく」という使い方が現実的になります。
tmux起動 Hermes起動 切断しても動き続ける
朝起きたら資料ができている、未来がすぐそこにあります。

⑮スキルと拡張: 育てる楽しみ

成長させる要素
  • Skills を追加すれば、得意分野をどんどん増やせます。
  • プラグインで、外部のサービスとも連携できます。
  • 使うほど記憶が蓄積されて、自分好みの応答に育っていく設計です。
  • 「初期設定で終わり」ではなく、運用しながら成長させる道具だと紹介されていました。
使い込むほど手に馴染む、良い道具の形をしていますね。

⑯コスト感: どれくらいかかる？

費用の目安
  • サーバー代は最小プランから始められるので、最初の負担は小さめです。
  • LLMのAPI料金は従量課金なので、使い方次第で大きく変わります。
  • 軽い雑用は安いモデルや無料枠に回すと、ぐっと節約になります。
  • 動画のおすすめは、「小さく始めて、様子を見ながら増やす」進め方。
サーバー代（固定）＋ API利用料（変動）
→ 最初は最小構成で様子見が吉
毎月の請求を一度眺めてから、量を調整するのが賢い方法です。

⑰トラブル対策: つまずいた時は

よくある悩み
  • SSHで入れない時は、まずサーバーの稼働状態と認証情報を確認。
  • 起動しない時は、Node.js のバージョンが古いケースが多いとのこと。
  • APIのエラーなら、キーの文字列と残高をチェックしましょう。
  • Cloudways のサポートに相談できるのも、マネージドならではの安心です。
状態確認 バージョン確認 キー確認 サポート相談
慌てず「繋がり・版本・鍵」の三点から疑うと、原因が見つかりやすいです。

⑱まとめ: クラウドに分身を置く

結論
  • Cloudways × Hermes Agent で、24時間稼働する自分専用AIが持てます。
  • 流れは「サーバー作成 → SSH → 環境構築 → 設定 → 起動」の一本道。
  • セキュリティだけは、公開前に必ず丁寧に仕上げましょう。
  • まずは小さく始めて、自分の仕事に合うように育てるのがおすすめです。
土台を作る 入れる つなぐ 育てる
自分の分身が常時待機している生活、ぜひ試してみてください！
