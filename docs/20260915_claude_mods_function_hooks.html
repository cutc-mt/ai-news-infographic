Claude Codeの新機能『Claude Mods』 — 内部ハーネスに干渉できる面白い機能

実験版の function hooks を旗を立てて試す。フックスの進化系にざっくり触ってみた

※本インフォグラフィックは動画の内容（文字起こし・説明欄）をもとに、Claude Code の新機能 Mods（function hooks）をまとめたものです（まだ実験版の機能です）

Mods とは

  • Claude Code に登場した新機能（実験版）
  • フラグを立てることで使い始められる
  • 位置づけはフックス（hooks）の進化系
  • ざっくり: Claude Codeの中に自作関数を差し込む仕組み
  • 差し込むのは自分で書いた TypeScript の関数
外から命令するだけでなく、本体の中に「自分の手」を入れる！

話題のデモ

  • 公式 Boris さんの投稿デモが話題に
  • なぜか Claude Code にテトリスが登場
  • こんな感じで画面に干渉していける
  • 出典: x.com/bcherny の投稿＋GitHub issue
ターミナルの中でゲームが動く。可能性を感じるデモ！

従来の hooks の使い方

  • 定義は settings.json で設定
  • 用途例: 通知を飛ばす
  • 特定の制御を決定論的に実行したい時
  • 使い方はざっくり 止める・通す・文言を足す
「ゲートを開けるか閉じるか」の予約係だった！

function hooks でできること

  • 値を覚えていられる（状態を保持）
  • デモのように画面に干渉
  • ボタンや入力でユーザーの入力を受け付けられる
  • 本体の内部イベントに自作関数を差し込める
  • これらは従来のフックスではかけなかった処理
ツールの結果や画面や「人への質問」まで関数内で書ける！

最大の違い: 「ずっと残る」

方式寿命
従来 hooks毎回 起動して終わる
function hooksずっと残り続ける
  • hooks.json の modules に register.ts(x) を指定
  • 読み込まれた関数が本体の中で生き続ける
「都度実行」から「常駐」へ。できることが一気に広がる！

導入方法

  • 現状はプラグインとして使う形
  • フラグ: CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude
  • plugin.json ＋ hooks.json が必要
  • modules で register.ts を参照させる
環境変数を1つ立てるだけで入口が開く！（実験版）

イベント駆動で動く

  • コードは on<イベント名> の形で定義
  • 全イベントを記録するなら on'*' のような書き方
  • 起動時1回系: engine create やフックス登録
  • 発生のたび系: UIのレンダリング等
  • イベント名の暗記が必要な面も
プログラム経験者なら直感的に読める書き味！

$（ドルマーク）は本体機能の窓口

  • $ = Claude Code 本体の機能を呼ぶ窓口
  • $.ui: 画面描画まわり
  • $.store: 値の保持
  • $.http: HTTP通信
  • $.tool: ツール呼び出し
UI部品はドルマークから借りてきて組み立てる！

next(e) の仕組み

  • next は 次に控えた処理を呼ぶ関数
  • 例: プラグインA → プラグインB → 本物のbash実行
  • Aにとっての next は自分より内側を全部動かして結果をもらうこと
  • 処理が入れ子（回送）構造になっている
  • 呼ぶか・何を渡すかは自分で決められる
「入力を変える・出力を変える・止める」の3択で制御！

応用① ツール結果を書き換える

  • ツール結果のイベントで next を呼ぶとbashが実行され結果が返る
  • 返ってきた結果を匿名化してから返すことも可能
  • コードで定義して細かく制御
AIが見る情報を、プログラム側でフィルタできる！

応用② ui.render で画面を描く

  • UIレンダリングのイベントで自前の表示を定義
  • 部品はドルマークから借りる
  • 最後に next を置けば元の表示が下に続く
  • input や button も設置可能
テトリスデモもこの延長線上の技術！

応用③ rm -rf の確認画面を自作

  • rm -rf 等の危ないコマンドを検知
  • 実行するかどうかの確認を動的に自作
  • 特定コマンド時の選択肢を作ることも
  • 注意: フックの持ち時間 10秒超でコマンドが通ってしまう
  • 長く待つ承認は $.ui.ask を使う
安全装置を自分でプログラミングできるのが面白い！

できることの整理

  • TypeScript で Claude Code 内部に触れる
  • プロンプト等の渡ってくる値を把握しながら処理
  • AIエージェントに渡す値をコードで改変
  • TUI上で質問・回答の往復も可能
  • AIに教えてもらいながら書くのもアリ
「細かく制御したい」人向けの武器になる機能！
