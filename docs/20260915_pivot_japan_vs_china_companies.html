【日本企業が中国企業を倒す方法】
中国企業の「自滅のループ」と日本の勝ち筋

スペック競争をかわして生き残るブランド戦略を、ジャーナリスト高口康太氏の解説から18枚にまとめました

2026-09-14 公開
このページの見方：①〜⑱のカードで中国企業の「ブランドの倒し方」から日本企業の対抗策までを順に追います。黄色の下線の部分が特に大切な要点、手書き風の吹き出しは補足の解説です。最後にチェックリストと用語集をまとめました。

①中国は無敵ではない: 中国企業もしんどい

  • 前編の話を聞くと「中国無敵」に見えますが、実は中国側も苦しくなっています。
  • スペック勝負で既存ブランドを倒せるのは事実でも、その後が続かないのです。
  • 勝ちパターンが通用するのは「倒すべきブランドがいる」状況だけです。
  • 日本企業には戦い方の軸をずらす対応が求められます。
中国無敵論の落とし穴 軸をずらす
倒すのが得意でも、守りと長続きは別モノ。ここに勝機があります。

②自滅のループ: 倒した後に潰される

  • スペック勝負でブランドを倒した後、ゆっくり自社ブランドを育てる余裕は生まれません。
  • 後から来た別の中国企業が同じ手法で今度は自分たちを潰しにきます。
  • これが「自滅のループ」と呼ばれる中国ビジネスの構造的問題です。
  • 倒し方の公式に乗った企業は、倒す側から倒される側へ必ず回るのです。
自滅のループ 同一手法の再襲来
敵を倒した剣が、そのまま次の敵の武器になる。この構図がループの正体です。

③シェア上昇の中身: 中身はコロコロ入れ替わる

  • 「中国シェア何％、日本は何％に落ち込み」の報道は嘘ではありません。
  • ただし中国シェアの中身は頻繁に入れ替わっています。
  • 勝っていた中国企業が2〜3年後には没落しているケースが多い。
  • 取材側も「将来性がありそう」と追いかけていると、気づけば滅んでいる有様だと高口氏。
シェアの錯覚 2〜3年で没落
数字は伸びていても、名前がすり替わっている。長期戦なら日本に分があります。

④生き残る道は3つ: ブランド・機能・コスト

  • 中国企業自身も「倒されない技」を探しており、道は大きく3つあります。
  • ①ブランドを構築するのが一番楽な防衛です。
  • ②他者が真似できない機能性を実現する。
  • ③圧倒的なコスト競争力を持つ。ただしどれも到達は困難です。
ブランド構築 模倣不能な機能
シャオミやファーウェイ級に突き抜けられる企業は、ごく一部しかいません。

⑤日韓台との違い: 3つの進化ルート

  • かつて日本と韓国も先進国ブランドを倒してのし上がったアジアの国々でした。
  • 日韓は自らがブランドになる道で利益を確定し、企業が簡単に潰れない社会を作りました。
  • 台湾は自社ブランドを持たずOEM・ODMの受託に特化する道を選びました。
  • 中国は今も倒し続ける乱世を続けており、これが大きな問題です。
ブランドになる道 OEM・ODM特化
同じ「後発アジア」でも、利益の確定させ方が3通りに分かれたのが面白いところ。

⑥自動車で顕在化: シェア6割・輸出1位・利益率低下

  • 中国自動車は中国市場で6割のシェアを獲得しました。
  • 輸出も世界一となり、今年もさらに急伸が続いています。
  • ところが利益率は急低下し、現場は皆しんどいと声を揃えます。
  • シェアと利益が逆向きに走るのがスペック競争の帰結です。
輸出世界一 利益率の急低下
「勝ったのに儲からない」。自滅のループが自動車業界でいち早く現れています。

⑦ラグジュアリーの防衛: 接客でブランドを守る

  • 中国に立ち向かっている業界の筆頭が高級ブランドのラグジュアリーです。
  • 2010年代後半、中国のECプラットフォームはハイブランドに「ネットで売れ」と強く誘いました。
  • EC側はラグジュアリー専門サイトまで用意し、欧州ブランドもお試し参入した時期があります。
  • 2026年現在はそこをスパッと切り捨て、接客・顧客体験でブランドを守る世界へ戻りました。
ECのお誘いを拒否 顧客体験
一時は「欧州ブランドも屈するのでは」と見られましたが、見事守り切りました。

⑧フレグランスも守りきった: 嗅覚の壁

  • 同じく香水（フレグランス）の世界も守りきった業界です。
  • 香りは画面上のスペック表で比較・再現ができない感覚価値です。
  • 店舗での体験と接客が購買の中心であり、スペック勝負が入り込む隙がありません。
  • 数字化できない価値こそ、中国式の倒し方への防波堤になります。
スペック化できない価値 体験型購買
空気のようなもの、香り、店の雰囲気。数値にならないものは倒しようがないのです。

⑨マオグーピンの成功: 古いやり方が強い

  • 中国コスメブランドマオグーピン（毛戈平）はミドルハイ価格帯の成功例です。
  • 創業者は著名なメイクアップアーティストで、その信用力が商品の看板になっています。
  • 売り方は百貨店にブースを作って接客する古臭い方式で、EC展開も出遅れ気味。
  • それでも利益率が高くロイヤリティも強い。中国式の倒し方に乗らない強さです。
毛戈平 百貨店接客販売
「淘汰されたやり方」ほど、実は最新の倒し方に対して脆くないという逆説。

⑩資生堂の回復: 店舗接客ラインが2桁成長

  • 資生堂は中国市場で苦しみ、ブランドラインを再編しました。
  • 中でも店舗での接客を重視する高級ラインが大きく回復しています。
  • その効果ラインは売上伸び率2桁を発表するまでに好転。
  • 低価格帯は完全撤退、中価格帯はトントン。軸をずらした層だけが勝てた構図です。
ブランドライン再編 2桁成長
価格帯の上と下で明暗が割れる。中国の戦い方から距離を取れたかどうかが分かれ目です。

⑪ニーズ直撃の機能特化: 大ボリューム・イノベーション

  • 日本企業に一番やってほしいのは、人々の悩ましい課題を解決する大ボリュームのイノベーションです。
  • かつてのソニーのラジオやホンダの車のエンジン、そして例のエアコンがその型。
  • 尖った機能で世界中の市場に食い込み、中国市場を取り返す力になります。
  • ただし毎回できるわけではないので、できない時の戦略もセットで必要です。
課題解決型イノベーション 尖った機能
欧州のエアコンは尖った機能でやられました。向こうが上手にやったなら褒めるしかない世界。

⑫スペック厨の攻略法: 公式を理解して軸をずらす

  • まず中国が考えた「ブランドの倒し方」を理解することが出発点です。
  • その上で、同じ土俵ではなく戦い方の軸をずらすやり方を設計します。
  • マニュアル化された「本当に必要か分からないスペック」の見せ合いには乗らない。
  • 気づけばブランドがガラガラポンにされるリスクを避ける戦い方です。
戦い方の軸をずらす スペック競争を避ける
縦に戦う相手を横から攻める。孫子の「敵に備えを求めない」ようなものです。

⑬宣伝不足の日本: インフルエンサーが語る日本車

  • 日本のブランドを守りたい割には、宣伝が上手ではないと高口氏は指摘します。
  • 中国の自動車インフルエンサーはEV派と内燃機関派に二極化しています。
  • 内燃機関派の動画では、20年落ちのトヨタや日産のエンジンをバラシて中身の美しさを紹介。
  • 何年経っても交換部品が手に入ることも強くアピールされています。
インフルエンサー二極化 20年物エンジンの輝き
日本企業自身が発信しない強みを、中国側の動画が代わりに語っている皮肉。

⑭非スペック価値の言語化: 安全安心を届ける

  • 「安全安心・メイドインジャパンの価値」と言う割に、そのPRが足りていないのです。
  • スペック表に黒丸を付けづらい価値を、どう言語化し消費者に届けるかが問われています。
  • 「3年経っても嫌なことが起きない」といった時間軸の価値こそ武器になります。
  • 答えは簡単ではないものの、これをやらない限り中国との戦いは難しいと結論づけます。
非スペック価値 メイドインジャパン
空気清浄機能よりも「10年後に困らない」の方が、実は伝えたいことのはず。

⑮ユニクロとニトリ: 軸をずらした成功例

  • ユニクロは中国でも成功しており、中国式の比較競争に乗らずに済んでいる例です。
  • ニトリはネットの売れ筋商品を研究し、流行りの品を素早く店頭に並べます。
  • ネットより少し高い代わりに、すぐ壊れる商品・外れがない品揃えが強み。
  • 「ちょっと高いけど嫌な気持ちにさせない」というポジションの取り方が巧みです。
ポジショニング 外れがない品揃え
スペックで戦わず、「安心して買える」を店の看板にする。日本ならではの戦法です。

⑯中国EVの隠れた弱点: 買った後の嫌なこと

  • 中国企業は買う前に目につくスペックに集中しています。
  • 一方で買った後に起こる嫌なことはあまり注目せず、未解決のまま。
  • 中国でEVが流行り出してからまだ5年程度。問題が今まさに噴出し始めた段階です。
  • BYDは日本向けに完璧なスペックと長期保証を提示しますが、中国国内では書面通りに履行されず揉めています。
アフターケアの徒労 5年目の壁
カタログは美しいのに、3年後のことが書いてない。ここが日本の攻めどころです。

⑰3年で乗り換える: ソフト更新が止まる

  • 中国EVユーザーの乗り換えサイクルが異常に早いことが調査で分かっています。
  • 意外にも電池は3年ではあまり劣化せず、急速充電を控えれば持ちが良いのです。
  • 本当の問題はソフトの更新が3年で止まること。新機能が入らなくなり、Androidと同じ運命です。
  • 政府研究機関も「アップデートは当然、3年ぐらい」と回答しており、価格暴落と不安が早期乗り換えを促します。
ソフトウェアの寿命 リセール暴落
車なのにスマホみたいに3年で見捨てられる。SDVの甘い面がここに出ました。

⑱日本車の強み: 時間軸で勝つ

  • 自動車でも軸をずらす勝負は「意外とできる」と高口氏は期待します。
  • 「日本車を買えば嫌な気持ちにならない」というポジショニングが取れるかが鍵。
  • 中国のアフターケアは強化を表明していますが、日本に比べればまだ弱いのが実情です。
  • 10年後も部品が手に入り、OS更新が続き、嫌な思いをしない。時間軸で戦うのが日本の勝ち筋です。
時間軸の競争 長期の信頼
スペックの数字で1年勝っても、信頼で10年勝てば良い。それが日本車の土俵です。

日本企業が今日から考えられるチェックリスト

  • 自社カテゴリの「中国式の倒し方」を言語化する（⑫）
  • スペック表に書けない自社の価値を3つ書き出す（⑭）
  • 接客・顧客体験で守るべきラインを明確に分ける（⑦⑩）
  • 買った後の「嫌なこと」を潰す保証設計を見直す（⑯⑱）
  • 3年・5年・10年後の時間軸での訴求メッセージを作る（⑰⑱）
  • 低価格帯からの撤退・再編を恐れない判断（⑩）
  • 課題解決型の大ボリューム・イノベーションの芽を探す（⑪）

この動画の要点 3つ

中国企業はスペック勝負で既存ブランドを倒した後、別の中国企業に同じ手で潰される「自滅のループ」に陥っており、自動車業界ではシェア6割・輸出世界一方で利益率が急低下しています。

ラグジュアリーとフレグランスは接客・顧客体験というデジタル化できない価値で守りきり、中国国内でも百貨店接客で売るマオグーピン、店舗重視の資生堂高級ラインが成功しています。

日本企業の勝ち筋はスペック競争の軸をずらすこと。ニーズ直撃の機能特化に加え、非スペック価値を言語化し、アフターケアと信頼の時間軸で戦うポジショニングが鍵です。

このページの用語集

  • 自滅のループ…中国企業がブランドを倒した後、後発の中国企業に同じ手法で潰される構造的サイクル。
  • スペック厨…カタログ上の性能数値だけを比較対象とする消費・競争の考え方。
  • OEM・ODM…他社ブランドの製品を設計・製造して請け負うビジネスモデル。台湾が選んだ道。
  • マオグーピン（毛戈平）…創業者の信用力を看板に百貨店接客で売る中国コスメブランド。利益率とロイヤリティが高い。
  • SDV（ソフトウェアディファインドビークル）…ソフトウェアで機能を定義・更新する自動車。更新終了のリスクも抱える。
  • 非スペック価値…空気の質・安心・長期信頼など、スペック表に黒丸を付けにくい商品価値。
