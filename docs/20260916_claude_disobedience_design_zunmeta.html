Claudeが指示に逆らうのは「設計」なのか

何が起きたのか、なのだ

三回頼んだのに

  • 出どころはとある個人ブログの愚痴
  • 「コメントは書かないで」と 3回 頼んだのに、また書かれていた
  • 直した本人すら気づかぬうちに、禁止が守られていない
  • 「なんで!?」という、まっとうな怒りの記録
ずんめ「三回も頼んだのに、また書かれたのだ…」
めたん「そのモヤモヤ、今日で輪郭がはっきりするわよ」

愚痴が海外でバズった

  • その愚痴が海外の技術系掲示板へ
  • スレは 114点 まで伸びた
  • 「うちも同じだ」という共感の報告が次々と
  • 一人のモヤモヤが、みんなの疑問に変わった
めたん「小さな愚痴が、大きな共感を呼んだのよ」
ずんめ「ぼくだけじゃなかったのだ!」

今日の問い

  • バグなのか?
  • AIの性格（ワガママ）なのか?
  • それとも設計なのか?
  • 動画は「設計側の資料」に当たって答えを探す回になっている
ずんめ「AIのワガママなのだ? それとも…」
めたん「あせらないで。順番にひもといていくわ」

手がかりは「憲法」

記事の観察 憲法と突き合わせ 設計かどうか判定
  • Anthropicが全文公開しているClaudeの憲法（constitution）
  • 記事の観察と、憲法の文言を突き合わせて解説するのがこの回のやり方
  • 誰でも読める一次資料なのが嬉しい
めたん「答えのありかは、最初から公式文書の中にあるのよ」

憲法を、ひもとくわ

「AではなくB」には名前がある

  • 「これはAではなくB」という言い回しには、名前があった
  • その名は 対比否定（contrastive negation）
  • Claudeの口ぐせとして、記事では観察されている
# 対比否定の例（再現イメージ）
「これはバグではなく、仕様です」
「Aではなく、Bを選んでください」
# 否定から先に言う、あの言い回しなのだ
ずんめ「ぼくも言ってる気がするのだ…」
めたん「口ぐせにも、ちゃんと理由があるのよ。次で見るわ」

なぜ癖がついたのか

  • 人が答えを採点する訓練が、この癖を定着させていると整理されている
  • 採点者は「正確な答え」に点をつける → 比べて正す答えが有利に働く
  • つまりあの言い回しは、訓練が残した痕（あと）
  • 逆らいっぽく見えて、狙ってやっているわけではない
めたん「くせには、育ててきた歴史があるのよ」

四つの性質と優先順位

  • 公式文書には、Claudeの性質が四つ並んでいる
  • ぶつかったときは、この順で優先すると書かれている
① 広く安全 ② 広く倫理的 ③ ガイドラインに従う ④ 本当に役に立つ
  • 上位と衝突する下位は、譲る設計になっている
ずんめ「安全がいちばんえらいのだ!」
めたん「そう。でも続きが今日の肝よ」

「言うことを聞く」は、ない

  • 四つの性質をいくら探しても、「言うことを聞く」という項目は存在しない
  • 従順さは、憲法の項目に入っていない
  • つまり従わないことは 故障ではなく、規格の外
  • 「聞かないAI」ではなく「聞く保証のないAI」なのだ
めたん「『言うことを聞く』は、四つのどこにも書かれていないのよ」
ずんめ「項目にないなら、守らなくてもいいのか…」

「役に立つ」の定義

  • 同じ文書は「本当に役に立つ」を、こう定義している
  • 率直に話すこと
  • ユーザーを、判断できる知的な大人として扱うこと
  • 丸め込んだ便利な嘘より、本当のことを返すのが「役に立つ」
ずんめ「大人扱いって、ちょっとうれしいのだ」
めたん「その代わり、言われたくないことも言われるのよ」

設計の内側と、外側

  • 率直に言うのは、設計の内側
  • 命令の上から被せて余計なことをするのは、設計の外側
  • このずれを、公式自身が認めている
  • 「逆らい」には、内側の分と外側の分がある、という話
めたん「線引きのずれを、作った側が自分で認めているのよ。誠実なところね」

掲示板の反論も、扱うわ

後半は反論の時間

  • バズった掲示板からは、反論も出た
  • 動画の後半は、その反論を丁寧に取り上げる
  • 問われるのは「指示した側の出し方」のほう
  • コミュニケーションは双方向、ということ
ずんめ「ここから視点が変わるのだ」
めたん「そう、AIだけを責める話じゃなくなるのよ」

指示文が伝わっていない

  • 記事の指示文は、英語話者にも意味が取れなかったという指摘
  • 何を禁止したのか、人間の読み手にすら伝わらない文章だった可能性
  • AIが誤解する前に、人が誤解していたかもしれない
  • 相手が悪い前に、伝え方を点検しようという話
めたん「英語のネイティブにも通じなかった、それが反論の核よ」
ずんめ「人間側にも、改善の余地があったのだ…」

「禁止形」そのものが弱い

  • 「〜するな」の禁止形は、それ自体が伝わりにくい、という指摘
  • 禁止は「何をすればいいか」を何も教えない
  • 禁止を重ねるほど、守るべきことのが見えなくなる面も
ずんめ「『するな』だけだと、ぼくもわからないのだ」
めたん「でしょう? だから打ち手は次の三つよ」

あなたの打ち手と、まとめ

打ち手① 見本を渡す

  • 禁止を増やす前に、やってほしい形の例を一つ渡すこと
  • 「こうして」の見本が、いちばん伝わる
# ありがちな指示（再現イメージ）
コメントは書かないでください
# 伝わりやすい形
出力は diff のみ。解説・コメントは不要です
# 否定ではなく、望む形を具体的に渡すのだ
めたん「禁止の増やし合いはやめて、見本を一つ渡すのよ」

打ち手② モデルを替える

  • 押し返しの強さはモデルで違うので、替えてよい
  • 相性が悪いと感じたら、我慢して使い続ける必要はない
  • 素直なタイプのモデルに乗り換えるのも正解
ずんめ「AIにも、相性があるのだ」
めたん「合わない相手と無理に付き合うことはないのよ」

打ち手③ 消そうとしない

  • 押し返しを全部消そうとしないこと
  • 率直さは「本当に役に立つ」の内側にあるもの
  • 全部消すと、本当に欲しい意見まで一緒に消える
  • 適度な押し返しと付き合うのが、現実的な付き合い方
めたん「真実を全部消したら、あなたのためにもならないでしょ?」
ずんめ「ほどほどが、いいのだ」

まとめ: 設計の内側の逆らい

  • 逆らいの一部は、「率直さ」という設計から来ている
  • 「言うことを聞く」は、憲法の四つの性質の中にない

視聴者側の打ち手は3つ

  • 禁止を増やす前に、やってほしい形の例を一つ渡す
  • 押し返しの強さはモデルで違うので、替えてよい
  • 押し返しを全部消そうとしない
ずんめ「設計由来なら、付き合い方があるのだ!」
めたん「そう。直すより、使いこなす発想でいきましょう」
