検索・メール・API基盤を、エージェントが担う

①今週のまとめ動画の見どころ

  • 毎週恒例の週次プロジェクト紹介。今週は20個のAIエージェントツールを約24分で紹介
  • 対象は検索・メール・コーディング・議事録・マーケまで多岐にわたる
  • あわせて新チャンネル「AI Agents Studio」の開設も発表。エージェント構築のチュートリアル専門
  • 説明欄に全ツールのタイムスタンプと公式リンクが付いているので、気になった道具だけ拾い読みできる
ポイント: 今週の選定基準は「自律性・プライバシー・ワークフロー自動化」の3軸。この記号で読むと整理しやすい

②Nimble: 自己学習する検索エージェント

Web Search Agents by Nimble
  • ドメインとスキーマを定義すると、深いクロールを組み合わせて他ツールが見逃すサブページまで到達
  • 独自インデックスに文脈を蓄積し、精度がクエリごとに積み上がる自己学習型
  • 監査可能な検索プランで「どこを・なぜ検索したか」を提示。ガードレールは自分で設定
  • Anthropic・OpenAI・LangChain・Vercelへのネイティブ統合＋MCPサーバ。ゼロリテンションで学習にも不使用
ドメイン定義 深クロール スキーマ通りの結果
企業調査・不動産・金融・製品インテリジェンス向け。データセット構築やページ上の数値のリアルタイム監視も可能

③Hello Inbox: AI到達率スタック

Hello Inbox
  • AI専門家＋9つの道具を組み合わせた、メール送信者の到達率プラットフォーム
  • せっかく書いたメールがスパムに埋もれ、売上を静かに失う問題に狙いを定める
  • 送信ドメインを数分で接続し、DNS・認証・オーディエンス・ポストマスター情報の送信者プロファイルを構築
  • テストメールを解析して修正案を提示。スパム引き語句の検出と書き換え、リストの無効アドレス検証も
  • DMARCを常時監視し、Gmail・Outlook・Yahooでの受信箱配置テストを実行。ブラックリストIPや評判低下はアラート
AIがプロファイルと過去の対話を記憶するので、毎回同じ説明を繰り返さなくてよい。マーケター向け

④Slashy: 自分で動くメールクライアント

Slashy Assistant
  • AIネイティブのメールクライアント＆アシスタント。送信済みメールから学び「あなたの声」で返信を下書き
  • 重要なメールのトリアージとノイズの除去、返信待ちの追跡で抜け漏れを防止
  • メール・カレンダー・MTGメモを横断し、通話前のブリーフィングや空きスロットでの会議設定も
  • 高速クライアントのキーボードショートカットとコマンドパレット。iMessageやSlackから下書き・要約を即座に発射
  • Claude Desktop・Cursor・CodexなどのMCPクライアントから受信箱とカレンダーを操作可能
ボットが「新聞記事みたいな文章」を書いて終わり、の失敗を避けたい創業者・営業向け。訂正するたびに賢くなる

⑤Elva: APIを発見し、エージェントに公開

Elva
  • リポジトリを指定するだけでルート登録・バリデータ・シリアライザを読み、全エンドポイントを検出
  • specが無くてもOpenAPI specを自動生成。設計・セキュリティ・AI準備度をスコア化
  • APIコントラクトで公開対象とPIIを除外し、コミットごとに差分検査して破壊的変更をブロック
  • OAuthゲートウェイ越しのホストMCPサーバを生成。ツール別スコープキーと全呼び出しログ付き
  • プレイグラウンドで検証でき、呼び出したエージェント自身が「どのツールに混乱したか」を報告
APIがリポジトリのあちこちに散らばり「仕様も所有者も不明」になりがちな開発・プラットフォームチーム向け

ブラウザとコーディングの仕事を、エージェントと一緒に

⑥Aside: 本当に仕事をするAIブラウザ

Aside
  • あなたとエージェントの両方がログイン済みサイトで仕事を終えられるよう再設計されたAIブラウザ
  • 統換ではなく、ウェブサイトとアカウントをあなたと同じように直接利用。メール・ダッシュボード・社内ツールへのサインインからコメント・返信・支払いまで
  • 閲覧履歴をメモリ化し「どのサイトを使うか」を覚える。文脈の再説明が不要で、メモリはデバイス内に保持
  • Vaultが認証情報をAIに見せずオートフィル。支払い・投稿・メッセージは承認待ちで、全利用にログ
  • タスクとデータはサンドボックス化・暗号化。ChatGPT/ClaudeのAPIキーを持ち込み
「統換がないから無理」と言われ続けた領域に、アカウント直利用で切り込んだ1枚。操作・採用・営業・調査チーム向け

⑦TryCase: PRを出すとデモ動画が返る

TryCase
  • プルリクエストを開くと実ブラウザで検証し、証拠をGitHubに投稿するビジュアルE2Eテストエージェント
  • diffは問題なく見えても、機能が実際に動くか誰も見ていないというレビューの盲点を解消
  • 変更を読み、影響するユーザージャーニーを選んで人間のようにクリック。PRに判定・字幕付き動画・スクリーンショットを残す
  • マージ前に割引が適用される瞬間・購入完了を動画で確認できる
  • テストスクリプトの保守不要。既に支払い済みのAI（ChatGPT購読 or OpenRouterキー）で動作
PRオープン 実ブラウザで巡回 判定+動画を投稿
ブラウザテストスイートの維持が独自の仕事になっている問題への答えでもある

⑧Juggler: コーディングエージェントの作業台

Juggler
  • AIコーディングエージェント用のビジュアルワークベンチ。モデルがコードに何をしたかを見て制御
  • 会話はログではなく永続的なツリー。任意の点で分岐し、結果だけ親に返すので文脈が溢れない
  • 全ツール呼び出しが専用ビューで開き、システムプロンプト・メッセージ・トークン・停止理由まで検査可能
  • コンテキスト・サージャンで履歴の折りたたみ・移動・取り消し
  • デスクトップでローカル実行、またはコードのあるマシンで起動してブラウザやスマホから同じセッションへ。セッションはディスクに保存
  • Claude Code・Codex・Copilot・Gemini・Ollama対応。コアはOSS・アカウント不要
「流れ続けるターミナルログでエージェントの実態が見えない」問題への対抗馬。実務でエージェントを触る開発者向け

⑨OzBrain: 全エージェントの共有脳

OzBrain
  • 使っている全AIエージェントが読み書きできるホステッド型ナレッジベース
  • 文脈がチャットごとに閉じ、同じ背景を何度もコピペする問題を解消
  • 決定と調査を構造化されたネスト記事で保存。エージェントは必要なスライスだけ取得し、高速で安く幻覚も減る
  • 新しい考えが着地すると旧情報に置き換え済みマークと最新版への参照を自動付与
  • 変更はエージェント単位で理由付きステージング。複数エージェントが同時実行でも上書きしない
  • ChatGPT・Claude・Cursor・Claude Code・Geminiのコネクタからコード不要で追加。暗号化・学習不使用・Markdownで書き出し可能
「最新版の計画が誰が最後に保存したかによって変わる」状態を終わらせる、個人とチーム両用の道具

⑩QApilot MCP: 話すだけでAndroid試験

QApilot MCP for Android
  • Claude・CursorなどMCPクライアントと会話してAndroidテストを自動化するサーバ
  • モバイルテストのためにAppiumコードを書き続ける壁を解消
  • CLIを入れてMCP設定、実機やエミュレータを接続するだけ
  • 「検索をタップ、入力、最初の結果を選び、詳細が出るか確認」のように話すと構造化プランを生成して実行
  • 読みやすいステップ名とライブプレビューURLでブラウザから実行を監視
  • 通過した流れはテストケースとして保存し、ID・バッチ・Excelから再実行。Gherkinファイルも生成
全部自分のデバイスに対してローカル実行。QAエンジニアとモバイル開発者向け

ローカル処理・音声・プライバシーの時代の流れ

⑪ボット不入の議事録アプリ2種

Oats（Ariso） Epilude Notetaker
  • どちらも会議にボットを入れず、Mac側で録音するオンデバイス方式
  • Oats: 無料OSS。Zoom・Meet・Teams・電話・雑談まで、Macが聞こえる音すべてを記録しローカルモデルで処理
  • Oatsは要約・責任者付きアクション・品質スコアを生成。ノートはMarkdownでObsidianの保管庫に、全コードをGitHubで公開・セルフホスト可
  • Epilude Notetaker: 通話開始をワンクリックで録音。会議タイプを分類し、決定・阻滞・コミットメントを抽出して根拠をトランスクリプトに提示
  • Epiludeのアクションは担当者と期限付きで、勝手に推測しない。Mac再起動からも録音を復旧
「参加者一覧にボットがいると会話が変わる」問題への答えが今週は2つも出た。録音データが他社のクラウドに置かれない点も共通

⑫Resurf: 手放せる文脈ライブラリ

Resurf
  • Mac・iPhone・iPad向けの完全ローカルなパーソナル文脈ライブラリ
  • リンク・ノート・画像・音声・文書をショートカットやドラッグ＆ドロップで捕捉し、1つの受信箱に集約して後から整理
  • ビジュアルカードで閲覧、タイプ別検索、集中リーダー、PDFネイティブ表示。すべてキーボード操作可能
  • 横のAIペインが自分の捕捉から回答。自分のOpenAIキーで動きコストが見える
  • 保存した文脈はMCPやCLIでエージェントに渡せる。データはMac内、オフライン動作、自分のiCloudで同期
「保存が面倒で結局ため込まない」摩擦への回答。アカウント登録なしで使い始められる

⑬Perplexity ハイブリッド演算

Hybrid Compute
  • 1つのタスクをクラウドモデルとMacのローカルモデルに分割するPerplexityの新機能
  • 最先端の推論はクラウド、機密ファイルは端末外に出さないという二律背反を両立
  • 送信前にオンデバイスのPII分類器が名前・住所・口座番号を一時置換し、返答時に復元。特定ファイルを「Mac限定」に強制も可能
  • iPhoneでタスクを開始し、Macに保護ステップを実行させられる。Slack・Mail・ローカルアプリ横断
  • Gemma・Qwen・Perplexityモデルをワンクリック設定。Ollamaや実行環境の設定不要で、ローカル処理は無料
  • オンデバイスPII分類器はOSSとして公開済み。Apple Siliconで動作
タスク受付 PII置換(端末内) クラウド推論 復元して統合
金融・法務など機密を扱う専門職向け。今週の紹介20種の中でも特に大手ならではの発表

⑭Loqua: 文脈を理解する音声入力

Loqua
  • Mac/Windowsの音声入力アプリ。言ったことではなく意味を理解して書き起こす
  • ショートカット1つで起動し、ターミナル・Slack・Notion・メール・コードエディタなど任意のアプリで利用
  • フィラー除去・繰り返し削除・表現の推敲をリアルタイム処理。話の構造から見出しやリストも自動構築
  • 約100言語に翻訳。自分の言語で話して相手の言語で送れる
  • 画面の一部を捕捉して質問・分析・要約。テキストを強調して音声で書き直し、リマインダーやアプリ起動も音声で発動
「タイプより考えたい人」のための道具。選択文の読み上げもでき、手を離して聞きたい時にも使える

⑮GhostWriter: 画面を読んで返信

GhostWriter by MyHandler
  • MyHandlerのデスクトップ機能。画面に出ている内容から下書きを書く
  • テキスト欄にカーソルを置きホットキーを2回 → 上のスレッド・横の質問・書きかけの文まで読む
  • 書く前に「どんな書きものか」を推論: 返信か、続きの文か、空欄への回答か
  • 各メッセージを送信者に対応させ、日程を提案する場合は先にカレンダーを確認
  • 自分では何も送信しない。画面捕捉と保管庫はPC内に留め、執筆のみゼロリテンションのクラウドモデルへ（Windows向け・無料）
「欲しい返事を説明する作業こそ避けたい作業」という逆説に着目した設計。受信箱とチャットで暮らす人向け

マーケ・サイト成長と、今週のまとめ

⑯AI検索と営業を制する2種

Visiby Youkti

Visiby: AI可視性プラットフォーム

  • ChatGPTなどのエンジンが自社ブランドをどう語るかを追跡
  • プロンプト群をChatGPT・Claude・Perplexity・Gemini・AI Overviewで継続実行し、引用シェアと勝敗プロンプトを報告
  • レシピヒートマップで各エンジンが読む要素（見出し・FAQ・表）を把握し、週次の優先度付き行動計画にまとめて配信

Youkti: 行動するアウトバウンド

  • エージェント「Arya」と会話するだけでキャンペーン全体を構築。トリガー・ペルソナ・配信サイクルを会話しながら設定
  • 資金調達・採用・経営陣変更・訴訟などのシグナルに理由・影響・タイミング窓を付けて提示
  • 毎朝の優先アカウント一覧（コックピット）から1クリックで送信。Outreach・Salesloft・CRMと自動同期
買い手の調査がAI会話に移った今、「AIに選ばれる」対策は順位トラッカーだけでは見えない。その盲点を埋める2種

⑰サイト構築・画像・広告の3種

Neopress ABrush Wisry

Neopress: 会話で育つウェブサイト

  • デザイン・公開・成長まで会話で完結。CMSと分析のエージェント2体が内容と改善案を出す
  • SSR HTML・サイトマップ・構造化データ・LLM.txt自動生成で検索とAI探索の両方に対応
  • AI引用クロールも閲覧数として集計し、どのモデルが巡回したか追跡

ABrush: Photoshop内の画像生成

  • アプリを切り替えずキャンバス上で生成・編集・拡大。20以上のモデル（Stable Diffusion・FLUX・Qwen Image等）
  • ControlNet・IP-Adapter・LoRAスタイルに対応。生成画像は所有・学習不使用

Wisry: 勝ち広告の複製

  • URLからブランドDNAを構築し、市場で勝っている広告の構造を自社製品に合わせて再構築
  • AI登壇者・Bロール・字幕・音楽付きで動画広告も生成し、MetaとGoogleへ直接投入して最適化
「制作が各工程で孤立する」問題を、それぞれの領域で解消する3種。簡易な依頼→AI実行→人間の手仕上げ、の流れが共通している

⑱まとめ: 今週を貫く3本柱

  • ①自律: 下書きではなく「実行まで終わらせる」道具が主流化（Slashy・Aside・TryCase・Youkti・Wisry）
  • ②プライバシー: ローカル処理・ゼロリテンション・PII分類が当たり前の選択肢に（Oats・Resurf・Hybrid Compute・GhostWriter）
  • ③接続: MCP対応が事実上の標準に。Nimble・Elva・Slashy・OzBrain・Resurf・QApilot・Neopressが対応を明記
  • 新潮流はAI検索への最適化: Visibyの引用シェア追跡、NeopressのLLM.txt生成が同じ問題を見ている
  • 継続的に追うなら、チャンネルの無料ニュースレター登録が便利。毎週のまとめが届く
20プロジェクト 3本柱で整理 自分の作業に接続
全部を試す必要はない。自分の一番の摩擦（検索・メール・議事録…）に当てはまる1つから始めるのが近道
