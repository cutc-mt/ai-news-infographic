第一章: Codexの隠れ機能 ～基本編～

BASIC 8選
②

①音声入力・文字起こし機能

設定→音声
  • Codexの音声入力は、Codex以外の場面でも使える汎用の音声テキスト入力機能
  • 設定画面の音声カテゴリーでショートカットキーを2種セット可能
  • 押している間だけ入力するパターンと押すたびに開始・停止を切り替えるパターン
  • 専用の音声入力モデルより性能は落ちるが、日本語も無難に文字起こししてくれる
長文の指示を話して入力したい時に、いちばん手軽に試せる機能です
③

②内蔵Webブラウザ

7月リニューアル後
  • Codexで会話してスレッドを作った後、会話画面右上の右サイドパネルのボタンを押す
  • 「ブラウザー」を選択すると内蔵ブラウザが立ち上がる
  • 上部のフォームでGoogle検索やURL入力ができ、Webサイトを直接開ける
  • Webアプリやサイトを立ち上げてそのまま検証したい場面で便利
作った物を確認するためにブラウザを行き来する手間がなくなります
④

③スマホシミュレーター

デバイスツールバー
  • 内蔵ブラウザ右上の3点ボタン→「デバイスツールバーを表示」を押す
  • iPhone・Samsung Galaxy・Surface・iPad mini など仮想デバイスを選択可能
  • Webブラウザの上部でスマホやタブレット画面を再現して挙動を確認できる
  • Webサイトを各フォーマットで表示チェックしたい時に重宝
実機を何台も用意しなくても、レスポンシブ確認がその場で完結します
⑤

④fastモード

左上の雷アイコン
  • CodexはGPT-6 AstraなどGPT系モデルで会話しながらアプリ・サイト・資料を生成
  • 画面左上の雷アイコンを押すとfastモードに切り替わり、回答速度が1.5倍に
  • モデル選択時には思考の強さをスライダーで調整することも可能
  • ただしトークン消費が増えて利用制限が早く尽きるため要注意
急ぎの仕事のときだけ速攻切り替える、が賢い使い方です
⑥

⑤テキストを選択して注釈を追加

8月実装
  • Codexの回答の一部を選択→「チャットに追加」で青い吹き出しが出現
  • 吹き出しを押すとその箇所に注釈を入力して保存できる
  • 「詳細を表示」で選択テキストの内容をCodexが調査
  • チャットに/sideと入力しても起動できるサイドチャットは、メインの会話を邪魔せず質問できる
「ここ気になる」という場所にメモを残しながら作業を進められます
⑦

⑥セクション機能

8月下旬
  • 左サイドバーのプロジェクトやタスクを自分好みに整理できる機能
  • プロジェクトのフォルダー右側にマウスオーバー→3点ボタン→セクション→新しいセクション
  • セクション名を入力して作成し、ドラッグ&ドロップでプロジェクトやタスクを整理
  • Codexに直接セクションの生成を依頼することも可能
仕事が増えてきたら、まずセクションで仕分けすると見通しが良くなります
⑧

⑦画像の編集

Image Gen + ChatGPT images 2.5
  • Image Genスキルをセットすると、ChatGPT images 2.5で画像を生成
  • 生成した画像を押すと、フォームからテキスト指示で編集できる
  • 編集ボタンのコメント機能で一部を選び、ピンポイント編集が可能
  • 背景を削除・画像内の一部を削除・比率の変更にも対応
生成→微修正を繰り返せるので、素材の作り直しがぐっと減ります
⑨

⑧閲覧専用スレッドの共有

8月下旬
  • 各スレッド上部の「共有」→「リンクをコピー」でリンクを生成
  • 閲覧専用リンクなので、受け取った相手が内容を壊す心配なし
  • アプリの生成過程でどんな指示を使い、どんな回答が返ったかを丸ごとシェア
  • チームやフォロワーに作り方ごと共有したい時に役立つ
「どう作ったの?」と聞かれたら、リンクを渡せばOKになります
⑩

一章まとめ基本編8選をひと巡り

  • ①音声入力　ショートカット1つで話しかけて入力
  • ②内蔵ブラウザ＋③スマホシミュレーター　作ってすぐ検証
  • ④fastモード　速度1.5倍（トークン消費に注意）
  • ⑤注釈とサイドチャット／⑥セクション整理
  • ⑦画像編集／⑧スレッド共有　成果物を磨いて共有
設定をのぞく 今すぐ1つ試す いつもの仕事に組み込む
基本編はすべて「ボタンと設定だけで試せる」難易度です

第二章: Codexの隠れ機能 ～応用編～

ADVANCED 5技
⑪

①ペット機能を使いこなす

5月実装
  • ペットと呼ばれるキャラクターをPCのデスクトップ上に配置できる機能
  • 当初は進捗を教えてくれるだけ→現在は音声会話やチャットも可能に改良
  • キャラクターを表示しないシンプル仕様の「ミニ」ペットも登場
  • 設定→ペット→「ペットを作成」でオリジナルのペットを生成できる
作業の合間に話しかけられる相棒がいるのは、案外楽しいものです
⑫

②サイト機能でWebサイトを生成・公開

サイトプラグイン（6月）
  • プラグインストアから「サイト」プラグインをインストールしてチャットで使用
  • 普通に作るよりも品質の高いWebサイト・Webアプリを生成
  • 生成物は左サイドバーの「サイト」から一覧で確認できる
  • 3点ボタン→共有→アクセス権を「インターネット上の誰でも」に変更→公開で、URLとして共有可能
プラグイン導入 チャットで生成 公開してURL共有
「作る」から「公開する」までをCodexの中だけで完結できます
⑬

③ワンクリックでローカルAIモデルを使う

Ollama連携
  • Ollamaのデスクトップアプリで、オープンウェイトのAIモデルをPCのローカル環境で起動
  • 最新版ならスイッチ1つでローカル/クラウドモデルを切替、ChatGPTデスクトップアプリのCodexから利用可能
  • 現在はOllamaのmacOS対応アプリのみで利用できる機能
  • 手順はOllama側でAIモデルを設定→スイッチをオンにするだけ
外に出したくないデータもある人にとって、ローカルモデル切替は大発見です
⑭

④プラグインを使って動画生成

2プラグインとも完全無料
  • プラグインはCodex内で機能を使い、より高品質なアプリ・サイト・資料を作れる仕組み
  • RemotionとHyperframesのプラグインで、テキスト指示による動画生成が可能
  • 解説動画や製品のプロモーション動画を手軽に作成
  • Hyperframesの詳細はAI大学の別動画で解説されている
「動画はハードルが高い」と思っていた人こそ試す価値があります
⑮

⑤パソコンの画面を取り込んで質問

Appshots
  • 今開いているアプリの画面と文字情報をCodexに取り込んで、そのまま質問できる機能
  • 設定画面のAppsカテゴリー→ホットキーでショートカットキーをセット
  • アプリ操作中に押すだけで画面＋文字情報がチャットにセットされる
  • 公式ドキュメントはcodex-docs.comのAppshotsページで公開中
「この画面、どう直せばいい?」をそのまま聞けるのが強みです

番外編: 知って得する小ネタと活用のポイント

EXTRA
⑯

番外お遊びから実用小ネタまで

  • 設定→一般カテゴリーの一番下にある「花吹雪きクラッカー」をオンにすると、達成時に紙吹雪が打ち上がる
  • 今回の機能の一部はChatGPTやChatGPT Workのデスクトップアプリでも使える
  • 動画で紹介のツールや参考サイトのリンクは概要欄とコメント欄にまとまっている
仕事の合間の紙吹雪も、やる気のスパイスになります
⑰

活用隠れ機能の組み合わせ術

  • fastモードは急ぎの仕事だけに使い、通常時はトークン温存。緩急をつけると制限に届きにくい
  • 本題と関係ない疑問はサイドチャット(/side)に逃がして、メインの流れを守る
  • 生成物は内蔵ブラウザ＋シミュレーターでその場で検証。行き来の手間を削減
  • 完成したら閲覧専用リンクで共有し、チームに使い方ごと引き継ぐ
音声で指示 fastで生成 その場で検証 リンク共有
単体でも強い機能同士を組み合わせると、Codexがさらに手放せなくなります
