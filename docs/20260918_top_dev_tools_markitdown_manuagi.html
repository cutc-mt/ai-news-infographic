①今週のラインナップ: DevTool20選と新チャンネル発表

毎週リリースされるパワフルなオープンソースの開発ツールを1本にまとめる週次DevTool更新動画です。今週はドキュメント変換、ローカルモデル、コードレビュー、セルフホスト、ブラウザ自動化の20プロジェクトを取り上げました。

冒頭ではAI Agent Studioという新しいYouTubeチャンネルの発表もありました。AIエージェントのプロジェクト・チュートリアル・ツールに特化したチャンネルで、週次動画、詳細ガイド、リアルタイムのプロジェクト分解を提供していく予定です。

02

②Chrome DevTools for Agents: エージェントに本物のChromeを操作させる

Webページをデバッグするエージェントは、これまで実行時の挙動を推測するしかありませんでした。このMCPサーバーはPuppeteer経由でリアルなChromeブラウザをそのまま駆動します。

  • クリックや画面遷移をエージェントが直接実行
  • パフォーマンストレースの取得とネットワークリクエストの検査
  • Lighthouse監査もエージェントから実行可能

MCPの外でも使えるCLIが付属しており、クライアントに追加して生きているページをそのまま検査できます。

第2章: ドキュメント・学習・エディタ・ローカル環境

CHAPTER 02
03

③MarkItDown: あらゆる文書をクリーンなMarkdownに変換

乱雑なPDFやスライド、スプレッドシートをそのまま言語モデルへ渡すと、トークンも構造も無駄になります。MicrosoftのMarkItDownは、この問題を一括で解決する変換ツールです。

  • PDF、Officeファイル、画像、音声、HTMLなどに対応
  • CLIとPythonインターフェースのどちらでも利用可能
  • 高精細な抽出にはオプションのAzure統合も選べる

出力はトークン効率の良いクリーンなMarkdownなので、AIシステムに文書を食べさせる前処理に最適です。

04

④Agent: 経験からスキルを磨く自己改善型パーソナルAI

多くのAIアシスタントはセッションごとに記憶がリセットされ、あなたについて学んだことを忘れてしまいます。Nous ResearchのAgentは違います。

  • 経験を通じて独自のスキルを生成・改良し続ける
  • 過去の会話を思い出し、あなたのモデルを時間とともに構築
  • ターミナルに加え、TelegramやDiscordからも会話可能

自分と一緒に成長していくプライベートなエージェントが欲しい人に向けています。インストールして会話を始めるだけで使い始められます。

05

⑤Open NA: どんなトピックも対話型のAI教室に変える

新しい分野の学習法として、受動的に読むだけの学習は弱いという問題意識から作られました。Open NAは、どんな教科やドキュメントでもAI教師とクラスメートが登場する対話型レッスンに変換します。

  • スライド、クイズ、シミュレーション、ホワイトボード議論を自動生成
  • 2段階パイプライン（アウトライン → シーン）で教材を構築

対話的に生成されるコースで学びたい人、教える側の人のどちらにも役立ちます。クローンして自分向けの講義を生成してみましょう。

06

⑥Cursor Plugins: 公式プラグイン形式でCursorエージェントを拡張

Cursorに新しいツールや統合を追加するとき、標準的な構造が存在しませんでした。この公式リポジトリがプラグインのフォーマットを定義します。

  • ファーストパーティとサードパーティのプラグイン・スキル・ルール・MCPサーバーを1つのマーケットプレイスに集約
  • 自作プラグイン開発用のスキャフォールディングヘルパーも付属

Cursorユーザーならマーケットプレイスを眺めるだけでも収穫があります。自分のプラグインを公開したい人にも公式の土台が整ったのが大きなニュースです。

07

⑦Vphone CLI: Apple Siliconで実iOSの仮想iPhoneを起動

iOSの挙動を確認するには、これまでシミュレータに頼るしかありませんでした。Vphone CLIはAppleの仮想化フレームワークを使い、本物のiOSをVMとして起動します。

  • ファームウェア設定、DFUリストア、起動を1コマンドで自動化
  • パッチレベルはストックから完全脱獄まで選択可能

iOSのセキュリティ研究者や開発者に最適です。VMを作って仮想iPhoneをすぐに起動できます。

08

⑧LLM Fit: あなたのマシンで動くローカルモデルを判定

何百ものオープンモデルと量子化版が存在する中で、自分のハードウェアで実際に動くものはどれかを知るのは難しい問題です。

LLM Fitはハードウェアを検出し、カタログ内の全モデルをメモリ適合・速度・品質・コンテキスト長の4軸で採点して、そのマシン向けにランク付けします。

  • 見積もりは透明で検証可能な形で提示
  • ローカルLLMを運用する開発者のモデル選定を一気に効率化
「どのモデルを入れれば動く？」の悩みが
適合スコア順でひと目で分かるようになります。

CHAPTER 03
09

⑨Coder ＆ Worktrunk: コーディングエージェントの並列運用を支える

Coder: セルフホストのクラウド開発環境

  • Terraformテンプレートからクラウドワークスペースをプロビジョニング
  • AIコーディングエージェントを中央コントロールプレーンから自分のインフラで実行
  • モデルガバナンス・コスト追跡・監査ログを一元管理

Worktrunk: git worktreeを簡単に

複数のエージェントを並行させると、gitのworktreeコマンドの使いにくさが邪魔になります。Worktrunkは管理をswitch・list・removeの3コマンドに圧縮し、ブランチ名で指定するだけで操作できます。フック、AIコミットメッセージ、1ステップのマージワークフローも付属です。

10

⑩PR Lens: プルリクエストをアニメーション図に描く

AIが生成したプルリクエストを、結果の表だけ見てレビューするのは時間がかかり、全体像も掴めません。PR LensはPRの中にアニメーション付きのアーキテクチャ図とデータフロー図を直接レンダリングします。

  • 変更のブラスト半径（影響範囲）とパイプラインの順序を表示
  • すべてを1つの検証済みグラフとして統合
  • GitHub App・エージェントスキル・Action・CLIのどれでも利用可能

変更を「リストで読む」のではなく「図で見る」レビューを実現したい開発者・レビュアー向けです。

11

⑪Deep Select ＆ Colibri: 巨大モデルをローカルで速く動かす2つの手法

Deep Select: TopKカーネルの高速化

スパースアテンションのインデックス構築とトークンサンプリングでは、標準のTopK実装がボトルネックになります。Deep Selectはこの2つのワークロード専用にチューニングしたGPUカーネルで置き換え、内蔵演算の数倍から最大20倍のスループットを報告しています。テンソルIN → テンソルOUTの単一関数として利用できます。

Colibri: 1兆パラメータ級MoEをディスクから読む

1兆パラメータ級のMixture of Expertsモデルの実行は、多くのハードウェアで高速メモリが足りません。純Cで書かれたColibriは、モデルの密な部分をRAMに保持し、ルーティングされるエキスパートだけをディスクからオンデマンドでストリーミングします。よく使うエキスパートを学習してキャッシュし、精度を変えずにフロンティアモデルをローカルで動かせます。

12

⑫Open Code Review: 行レベル精度のハイブリッドAIレビュー

純粋なLLMコードレビューには、出力がノイジーで、コメント位置が不正確になりやすい課題があります。AlibabaのOpen Code Reviewは発想を変えました。

  • ファイル選択とコメント配置は決定的な処理が担当
  • 文脈と判断はエージェントが担当
  • 汎用レビューエージェントよりはるかに少ないトークンで正確な行レベルのフィードバックを生成

一貫性のある自動レビューを導入したいチームに適しています。

第4章: 創作・音楽・センシングと実用ツール

CHAPTER 04
13

⑬Whiteboard Animator: 静止画を手描き風の解説動画に変える

ホワイトボード風の解説動画を作るには、通常は手作業のアニメーションが必要です。Whiteboard Animatorは完成したマーカー風の画像を入力すると、テキストを書き、輪郭をなぞり、図形をストロークごとに塗っていく映像をMP4として書き出します。

  • レンダリング時はCPUのみで動作し、モデルを一切使わない
  • 解説動画を作る教育者・クリエイターに最適

一枚描いてあとは自動、という手軽さが魅力です。

14

⑭YuE: 歌詞からフル楽曲を生成するオープン基盤モデル

ボーカルと伴奏入りのフル楽曲の生成は、これまでSunoのようなクローズドサービスに頼るしかありませんでした。YuEはこれを置き換えるオープンな基盤モデルです。

  • 歌詞とスタイルタグから数分のトラックを生成
  • 多数のジャンルと言語に対応
  • 参照曲からのインコンテキスト学習でスタイル転送も可能

AI音楽を実験したいミュージシャンや開発者に向けています。ジャンルと歌詞を設定して曲を生成するだけで試せます。

クローズドサービス頼みだった「フル楽曲生成」が
オープン weightsで手元に来るのは大きな変化です。
15

⑮System Prompts Leaks: チャットボットの隠された指示のアーカイブ

最初のメッセージを送る前にチャットボットへ与えられる指示は、普段目に見えない存在です。このコミュニティ管理リポジトリは、その実態を集めたアーカイブです。

  • Anthropic・OpenAI・Googleなど数十社のプロバイダのシステムプロンプトを逐語のまま収録
  • 企業別に整理され、新モデルの登場に合わせて更新
  • 注入されたリマインダーやエージェントスキルも一緒に収集

アシスタントがどう設定されているのか知りたい研究者やプロンプトエンジニアに最適です。

16

⑯Oh My Hermes: ルーティングとメモリを追加する運用層

エージェント単体では、タスクの難易度でモデルを切り替えず、実際に何が実行されたかも検証しません。Oh My Hermesはその上にガバナンス付きの運用層を重ねます。

  • タスクを採点してモデルレーンに振り分け
  • 計画した作業と実行した作業を区別して記録
  • セッションをまたいで予算付きの長期メモリパックを構築

規律あるモデルエージェントのワークフローが欲しいHermesユーザー向けです。インストールして最初の管理されたワークフローを走らせてみましょう。

17

⑰Ru View: Wi-Fiの電波を非接触センシングに変える

部屋の在室検知やバイタルのモニタリングには、通常はカメラやウェアラブルが必要です。Ru Viewは低価格なESP32センサでWi-Fiのチャネル状態情報（CSI）を読み取り、在室・呼吸・心拍・転倒・睡眠を壁越しに検出します。

  • エッジハードウェアだけで完動作し、クラウド不要
  • ネイティブのスマートホーム統合にも対応

プライバシーを保つセンシングに興味あるメイカーや研究者に向いています。センサに書き込んで自分の空間の計測をすぐ開始できます。

18

⑱Spotifast ＆ Slowbooks: 重い公式アプリを置き換える2つ

Spotifast: Rust製の軽量ネイティブSpotifyクライアント

  • バンドルブラウザなしのRust実装で1秒未満で起動、メモリ消費はごくわずか
  • ギャップレス再生、フルライブラリ、Spotify Connectに対応
  • Winamp風ミニプレーヤーとビジュアライザーを搭載（プレミアム加入者向け）

Slowbooks Pro 2026: セルフホストの会計ソフト

古いQuickBooks 2003は、アクティベーションサーバーの停止で最終的に使えなくなる恐れがあります。Slowbooks Pro 2026はゼロから書き直した代替で、複式簿記・給与・在庫・税フォームをカバー。改ざん検知のできるPDFを出力し、PythonとPostgreSQLの構成をDockerで1コマンド展開できます。手元で帳簿を管理したい人に最適です。
