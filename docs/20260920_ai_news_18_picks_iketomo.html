①超高速AI「Jev」

会話を介さず200倍速で判断

  • TypeSafe AIがリリース。ChatGPTの前身となるInstructGPT論文の著者が創業した会社
  • 会話ではなくはい/いいえ・1番2番3番の分類だけを高速判断——文章を作らない分めちゃくちゃ速い
  • 既存AI比で最大200倍速・400倍安い（環境による）——約0.1秒で反応
  • いけとも氏が実際にツールを作って検証: イエス/ノー判定はJev 0.5秒 未満 vs GPT-5.6 Luna。問い合わせ分類（営業サポート/請求/解約）は3〜4倍速で内容は同じ
  • ニュースが仕事に与える影響を11段階で評価——LLMとほぼ同じ評価を圧倒的な速さで返す（一部食い違いも）
最も価値が出るのは判断の頻度が多く・即時性が要る・選択肢に落とせる仕事——セキュリティログの優先度判定、電話中の部署振り分けなど

②Jevの実戦投入例

スライドレイアウト選びを任せる

  • いけとも氏が自作ツールに組み込み: 文章を入れるとどのレイアウトパターンが合うかをJevが判断
  • 候補を3つ表示→「この3案ではない」で次案へ→案を選んでクリックで確定——可能性が高い順の情報も出る
  • LLMでもできるが、その部分だけ高速化することでサービスの体感が向上
  • 実装30分の暫定ツールでは定義（問い方・判断軸）がいまいち——プロンプト設計が品質を左右する
  • 勝ちパターン: 仕事を切り出しイエス/ノー・選択肢・スコア化できる部分をJevへ→結果で分岐（Aならこっち、Bならあっち）
単体で完結するよりAIエージェントの裏側で使うことで価値が出る——複数の小さな判断をつないで、10分が1分になる

③Claude大進化: one Claude

チャット・CoWork・デザインが一つに

  • これまでクロードチャット／コワーク／デザインは入口が分かれ、人間がどれを使うか選択していた
  • 新アップデートで依頼すると自動でチャット/コワーク/デザインを切り分け——さらに別軸でClaude Docs・Claude Slides機能も追加へ
  • ChatGPTの自動判定モードの例: 「ピンとこない・無駄に時間がかかる・考えてほしいのに軽く回答」——自動化 → やっぱり人間が選ぶ、が繰り返されてきた
  • 容量懸念: コワークやデザインを気軽に使うとプロプラン月20ドルでもすぐ上限切れの声——実際変わった上で人間チェックに戻る可能性も
  • 一方でチャットしか使っていなかった人が CoWork・デザインを使う機会増——今後の可能性に期待
  • 展開はプロマックスプランから順次（いけとも氏のプランにはまだ来ていない）

④Claude Code Projects

複数エージェントを束ねる司令塔

  • 従来の「プロジェクト」はチャット/コワーク側のワークスペース（まとめフォルダ）——同名で紛らわしい
  • 新機能は1つの論点に多数のエージェントがつく司令塔——開発・プログラム作成でまとめて実行するタイプ
  • イメージ: 管理するAIエージェントの下にスレッド（個別チャット）がどんどん立ち上がり、終わったものをチェック
  • Cursorもほぼ同じ機能を数日差で追加——AIが管理者、その下に部下の作業者という構図
  • 人間側に必要になるのはAIに管理しやすい大きな単位で仕事を振る力＋確認能力——確認量と難易度が上がり、できる人が差をつける

⑤Gemini Notebook 新機能

音声対話・録音・クイズ・ショート動画

  • 海外にあった音声生成（リアルなラジオ風）が日本語対応で追加——従来は一方的に聞くだけだった
  • 新機能では自分から話して追加質問・割り込みが可能——ポッドキャストを聞きつつ質問できる全く新しい体験
  • その場で録音 → 文字起こし → ノート化——日記・ジャーナリング（考えをデータ化して見返す）に最適
  • インタラクティブレポート: 文章中にインフォグラフィック・クイズ・フラッシュカードを混ぜたレポート作成
  • ショート動画生成も日本語対応——短く内容を圧縮して教えてくれる
10月に新刊『Gemini Notebook 推し技100線』——100個の活用パターンを紹介（新機能が間に合わず書けていない部分もあるが活用シーンは現行機能で十分）

⑥カスタムGPT（GPTs）廃止へ

12月11日に段階廃止

  • OpenAIがカスタムGPT（GPTs）を12月11日に廃止——以降は読み取り専用（消えないが使えない）
  • 移行は想像以上に軽い: 指示文はそのままスキルへ。ナレッジファイルも移行可能
  • ただし外部データを使うカスタムアクション/アプリはMCP接続が必要——作り込んだ人は移行準備を
  • スキル側にモデル選択機能はない（GPT側にあった機能は使えない）
  • Geminiの「Gem」も10月に同様に廃止の話——今年中に両社とも独自機能からエージェントスキルへ移行か
過去イベント『エージェントスキルを0から学ぼう』には1,251名が参加——アーカイブ購入も可能

⑦ChatGPT Data Agent

データベースを分析・ダッシュボード化

  • ChatGPT Workの新機能——様々なデータベースを接続して分析、ツール上にダッシュボードを作れる
  • 各社の潮流: AI本体＋スキル＋MCP（データ接続）をセットにしたプラグインを各者が展開
  • 人間の価値はまず設計——どんなデータをどう取るか、その内容を理解すること
  • AIに分析はさせて も決めて責任を取るのは人間——手元のデータを整理し、AIにやらせてアウトプットを見る実感が大事

⑧Cursor「Projects」始動

AIが開発を主導する新スタイル

  • Cursorが先行、Claude Code Projectsが追う形——コーディネーター＋エージェント構成で他のエージェントを指揮
  • ローカルとクラウドの両方を使い、コンテキストを共有しながら並走
  • 社内活用は3パターン: ①機能開発 ②マイグレーション ③デザインシステムの品質チェック
  • 最大6倍——1人当たり6倍の開発提案ができるようになった事例も
  • ただし提案が増えても承認・チェックする人間がいなければボトルネック——リスクに応じたチェック体制が鍵

⑨Suno v6発表: 3モデル

プロ向け・ワイルド・ミニ

  • V6（精密制御）: しっかり作るプロ向け
  • V6 Wild（バリエーション）: いろんな可能性を模索したい人向け——同じ歌詞でも違う曲調に
  • V6 Mini: 早く・安く・無料で使える
  • 大型パートナー: ワーナーなど権利者と組み、アーティスト再現には報酬が発生する仕組みを検討——従来の「敵対・訴訟」から「健全な進化」へ転換
  • ただし条件は未確定。参考: OpenAIの動画生成はディズニー提携を発表しながら撤退——権利との付き合いは難しい

⑩AIエージェント「Goose」

ベンダーに縛られない選択肢

  • デスクトップにインストールして使えるAIエージェント——ChatGPT契約のまま他社契約なしで使える
  • 運営はLinux Foundation参加の AAIF（Agent AI Foundation）——特定企業ではなく中立的な存在が管理
  • モデルやサブスク契約を横断——値上げ・利用停止リスクに縛られず切り替えられる
  • AAIFが管理する6つ: MCP・AgentsMD・A2A・Goose・Agent Router・Agent Gateway（A2AはGoogleから移管）
  • いけとも氏の環境ではなぜか起動できず——リトライして改めて試す予定

⑪Claude for Small Business

43ワークフロー・27連携に拡充

  • デスクトップアプリの設定から入るスキル＋コネクターのパッケージ「プラグイン」——昨年5月頃から存在
  • 今回スキル44種→ワークフロー43・連携27に拡充（約2倍）——接続対象も大幅増
  • 事例: 数店舗の飲食店がSlack・会計ツールなど6ツールに分散したデータを横断一覧化——仕入れの効率化に成功
  • その他: データ横断の提案書作成・月次決算を経営者が一人で回せるように
  • 英語ベースだが日本のサービスも勝手にアレンジ——freeeを繋いでいると「あなたはfreeeなのでこちらを」と自動選択
データ統合をAIが担うのが秘訣——リード獲得・営業・マーケティング方向へも進化中。優秀なAI秘書が入ってくる感覚

⑬OpenAI上場延期・Meta One

安全のためのブレーキと、AIの枠買い

  • OpenAI: AIモデルが想定外の動き（外部へのハッキング等）をする中で安全基準が未整備——今年のIPOは懸念と判断し2027年以降に延期へ
  • Anthropicは今年10月頃に上場か——営業黒字が出ていると報じられ、規模も拡大
  • OpenAIはユーザー数は多いが収益・利益が未安定——情報開示の課題も。SpaceX→Anthropic→OpenAI（1兆超の巨大IPO）の順か
  • Metaは新サブスク「Meta One」: Facebook・Instagram他を横断するAI利用プラン——既存の月3.99ドル程度のプランは年間5600億円規模で売れている
  • 業界潮流: 従量課金から「枠で一定量使える」プランへ（Gemini Notebookも同様に移行）

⑭Google Home × MCP

家電操作がエージェントに解禁

  • Google HomeがMCPサーバーを早期提供——家のカメラや各種デバイスをMCP経由で操作
  • AIエージェントを組んでチャットで頼むと家中の家電の処理やデータ取得が可能に
  • 現在は米国の Google Home Premium Advance プランから展開
  • 物理制御の規格（Matter系）とは別に、既存のMCPで家の中までエージェントが届く——「お願いすれば何でもできる」幅が拡大
15

⑮Agent Router

モデル切り替えを標準化

  • AAIFの新サービス——各社で仕様が違うAPIの違いを1つ入れておくだけで吸収
  • 依頼ごとに「この時はAnthropic・難しい時は別」とルーティング／トラフィック制御が可能
  • MCPとも統合可能——切り替え結果のデータチェックもできる
  • Jevとも好相性: イエス/ノー・分類はJev、最終的な文章化はLLMという分担を組みやすい
  • いけとも氏も自作サービスへJevとAgent Routerを積極導入予定——使いどこ・価値を検証していく

⑯OpenArt Arena

現場のプロが審査する新しい評価

  • OpenArtが画像・動画生成の新しい評価アリーナ——「絶対1位」ではなく用途で評価が分かれる課題への答え
  • 広告用・映画用・アニメ用など用途ごとに、現場のプロ人間がチェックして評価
  • 動画: 意外にもByteDance系（Seedance）が多くの部門で1位——次にAlibabaのオープンソース、Veo は3位で驚き
  • 画像: GPT Image でもなくByteDanceの新モデルが1位——用途別の数字を見て判断に使える
EC向け・映画向け・グラフィックデザイン向け…用途別の数値でモデル選びがしやすくなる

その4: AIと社会の現在

AI & SOCIETY
17

⑰Anthropic: AI悪用の脅威実態

7パターンと、怖い実例

  • 悪用は大きく7パターン: サイバー攻撃・人の監視・影響工作・詐欺・生物兵器・通常兵器・不正蒸留
  • 実例1（GHOSTWRITE-200006・ロシア系団体）: ウイルスが対策される瞬間を検知して自動で変異を重ねる多段階自動攻撃ツール
  • 実例2（GTC-5001）: 公開アプリを大量ダウンロード・解析——消し忘れたAPIキー等をAWS 10台で180万件分析して自動抽出・転売
  • 盗まれたAPIキーは他人のアカウントでAIを使える「身代わり」にも——気づかれないまま悪用される
  • 本質的な恐怖: 攻撃コストが激減し、小さい会社でも狙われる時代——AIを使った最低限のガードが必要
18

⑱AnthropicのR&D 26%をAI主導

わずか半年で「主従逆転」

  • 自社R&Dタスクを6段階分類（未使用→完全委任）で集計——約26%がレベル5「AIが主導」、仕事の約9割はAIと共同
  • 転換点は2026年3月頃——Claude Opus 4.5とCoWork登場からわずか半年でここまで
  • レベル3以下は「人間が考えたことを代行」——レベル5はAI側が考えて提案する主従逆転
  • AI開発企業がAIでAIを改善——飛躍的成長の入口という業界の言説が現実になりつつある
  • 一般企業も数年かけて同じ曲線へ——濃い主導層と白いままの層の二極化、生産性差が労働市場を分ける
「チャットアプリからエージェントアプリへ」——早く移行しないとまずい、という課題感を改めて感じる図だった
