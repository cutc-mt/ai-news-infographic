02

②BrowserSkill 〜 ブラウザを貸す

TencentCLI＋拡張機能
  • ログイン済みブラウザをそのままAIエージェントに使わせるOSS。あなたの作業は止まらない
  • Cursor・Claude Code・Codexなどシェル対応エージェントなら何でも利用可。モデル/フレームワークのロックインなし
  • タスクは別の可視エージェントウィンドウで実行。開いているタブは「借りて返す」方式で衝突しない
  • ログイン状態を再利用しつつ、CAPTCHAが出たら人間に操作を返す設計
エージェント BrowserSkill CLI あなたのブラウザ
03

③Knowledge Work Plugins 〜 11の専門職

AnthropicClaude Code / Co-work
  • Anthropic公式のOSSリポジトリ。Claudeをあなたの職種の専門家に変えるプラグイン集
  • 11個のプラグイン: 生産性・営業・サポート・製品・マーケティング・データ分析・運用・財務・法務ほか
  • 各プラグインがその分野のワークフローを凝縮したコマンドとスキルを同梱
  • MCP経由でSlack・Notion・Jira・Snowflakeなどを接続するとさらに強力になる

営業・法務・財務…職種ごとにClaudeが「その道のプロ」に化けるのが面白い！

04

④Superpowers 〜 仕様はじめの開発手法

obraスキル集
  • AIコーディングエージェント向けのスキル集＋ソフトウェア開発手法のOSS
  • いきなりコードを書かせない。会話から仕様を抽出し、短い読みやすいチャンクで承認してから構築
  • 同梱スキル: ブレストTDD4段階デバッグ完了前検証サブエージェント review
  • Claude CodeとCodexのプラグインとしてインストールするだけで導入完了
05

⑤Agent Reach 〜 無料Webアクセス

CLIAPI費用ゼロ
  • AIエージェントに「目」を与えるOSS CLI。Twitter・Reddit・GitHub・Bilibili（ビリビリ）・小紅書（RED）・動画サイト・任意Webページを読み取り・検索
  • API費用は一切なし。プラットフォームごとに優先バックエンド＋フォールバックを持ち、片方壊れても自動切替
  • 無料検索をセットアップしスキルを登録。エージェントがどの道具を使うべきか把握できる
  • Cookieはローカル保持。Claude Code・Cursor・OpenClaw で動作
06

⑥Munder Difflin 〜 エージェントのオフィス

ローカルファーストデスクトップアプリ
  • AIエージェントのオフィスを走らせるローカルファーストのOSSデスクトップアプリ
  • 既に支払い済みのターミナルCLI（Claude Code・Codex・Gemini・Grok・Copilot等）を自律的に協調するチームに変換
  • 各エージェントは長期記憶・メールボックス・2Dオフィスフロアのデスクを持ち、あなたの分身が作業を振り分け
  • 各エージェントは独立プロセスのターミナルで実行。まだ早期プロトタイプなので注視度×成長度が高い

いわばエージェント版オフィス。2Dのフロアで働くAI社員たちを眺めるのが楽しい！

07

⑦OpenBot 〜 ガバナンス付きAI同僚

CopilotKitAG-UI protocol
  • AI同僚（co-worker）に専用のコンピュータ（ブラウザ・ファイル・道具）を与えるOSS基盤
  • すべての操作は実行前に検査、実行後に記録。権限の範囲でしか動かない
  • 各ボットはAG-UI protocolで会話。LangGraph・CrewAI・Mastra・Google ADK・手作りエージェント全部プラグイン可能
  • サーバーゲートウェイがポリシー評価と監査ログをブラウザ操作の前に実行。統制はフレームワークではなくプロトコル側に

08

⑧Ghidra 〜 NSAの逆解析フレームワーク

NationalSecurityAgencyJava製セキュリティ
  • 米国家安全保障局（NSA）研究部門が開発・保守するソフトウェア逆解析フレームワーク
  • Windows・macOS・Linux上のコンパイル済みバイナリ解析のための道具一式
  • 逆アセンブル、アセンブル、デコンパイル、グラフ化など多数の機能を命令セット・実行形式の幅広い範囲で提供
  • 対話式でも自動化でも運用可。Java / Pythonで独自コンポーネントを追加拡張できる大規模チーム分析向け設計

諜報機関製ツールが全世界に公開されているという、OSS界でも屈指の異色プロジェクト！

09

⑨supervision 〜 コンピュータビジョン統一API

RoboflowPythonCV
  • Roboflow製のOSS Pythonライブラリ。モデル非依存のコンピュータビジョン・アプリ構築用ツールキット
  • 中核は統一detections API: Ultralytics YOLO・Roboflow Inference・HF Transformers・SAM・Detectron2・VLMの出力を変換
  • モデルを入れ替えてもコードを書き直さない——これが最大の売り
  • 画像/動画アノテーション、オブジェクト追跡、ゾーン内検出カウント、データセットの読込・分割・評価。box・mask・labelの注釈スタイルも自由
YOLO 統一 detections API SAM / VLM …
10

⑩Coder 〜 セルフホスト開発環境＋AIエージェント

coder/coderTerraformWireGuard
  • クラウド開発環境とAIコーディングエージェントのためのセルフホスト基盤のOSS
  • ワークスペースをTerraformで定義: EC2 VM・Kubernetesポッド・Dockerコンテナを自由に選択
  • WireGuardトンネルで安全に接続。アイドル中のワークスペースは自動シャットダウンしてコスト削減
  • AIエージェントを自社インフラで実行。資格情報をワークスペースの外に置き、全操作をユーザーに紐付け
  • AIゲートウェイが統制・コスト追跡・監査ログを一元化。オンプレでもクラウドでも運用可
11

⑪Home Assistant 〜 ローカルファースト住宅

home-assistant/corePythonOpen Home Foundation
  • ローカル制御とプライバシー最優先のOSSホームオートメーション。その中核となるPythonアプリ
  • Raspberry Piやホームサーバーなど自前のハードウェアで実行し、数千のスマートホーム機器・サービスを接続
  • Zigbee・Z-Wave・Matter・MQTTなど生態系の壁を越えて統合
  • すべてローカルで動くのでクラウド不通でも家は止まらない。オートメーション・ダッシュボード・音声制御を自作
  • Open Home Foundationの中核プロジェクトとして持続的開発

スマートスピーカーに「聞かれる」生活からの脱却。家の頭脳を自分のサーバーに置く王道！

12

⑫LibreChat 〜 自宅で動くChatGPT代替

danny-avilaDocker導入マルチプロバイダ
  • セルフホスト可能なChatGPT代替のOSS。1つのUIで多数のAIプロバイダを横断利用
  • 対応: OpenAI・Anthropic・Google・Azure・AWS Bedrock・Grok・Mistral・DeepSeek・OpenRouter・あらゆるOpenAI互換エンドポイント
  • 会話の途中でモデルを切替えられる柔軟さが最大の特徴
  • エージェント・MCP・スキル・サブエージェント、コードインタプリタ、アーティファクト、画像生成、ファイル検索、Web/メッセージ検索を装備
  • 安全なマルチユーザー管理とSSOでチーム運用にも耐える。Dockerで手軽に導入

⑬Ever Gauzy 〜 ビジネス管理の統合基盤

ever-coERP/CRM/HRM

  • 作業/プロジェクト追跡、スクリーンショット付きの時間管理と活動監視、請求書発行、チーム管理を網羅
  • バラバラの道具を繋ぐのではなく1つのシステムで会社を回す思想

  • Angular＋NestJSで構築され、Kubernetesにセルフホスト可能

⑭awesome-gpt-image-2 〜 プロンプトの図書館

freestyleflyprompt as code
  • OpenAIの画像生成モデルGPT Image 2専用の「プロンプト・アズ・コード」ライブラリ
  • 実例530以上を分析し、20以上の再利用可能な構造化テンプレートに逆工学して収録
  • 各テンプレートには完全なプロンプトと生成記録が付属。ポスター・商品撮影・UI・インフォグラフィック・ブランド・キャラクター等を網羅
  • テンプレート群をエージェントスキルに蒸留。「こういう画像が欲しい」を即座に本番品質のプロンプトへ変換
  • npmでインストール可能。絞り込み・コピーできるライブギャラリーも搭載

⑮Diagram Design 〜 ブランド一致の図解

Claude Code用スキルHTML/SVG出力
  • 編集部品質のダイアグラムを自己完結型のHTML/SVGとして生成するClaude Code用OSSスキル
  • 27種類の図解タイプ: アーキテクチャ、フローチャート、シーケンス、タイムライン、クアドラント、ピラミッド等。各3バリアント、ビルド手順なし
  • Webサイトを指定するとパレットとフォントを読み取り、意味的トークンに対応付け、コントラストまで検査してブランドに合わせる
  • PNG / SVG出力。Claude CodeまたはCodexにインストール

「社内資料の図が会社の色と合ってない」問題を、エージェントが勝手に解決してくれる！

⑯minimind 〜 2時間でLLMを一から訓練

jingyaogong教育目的
  • 小さな言語モデルを完全にゼロから訓練するOSSプロジェクト。LLMの仕組みを「作って」学ぶ
  • 約6,400万パラメータをわずか2時間・低スペックハードで訓練可能。CPUでも訓練・推論できる
  • モデルコードはdense と MoE の両方式で、Qwen3生態系と互換。トークナイザも同梱
  • 訓練段階を全部収録 —— アルゴリズムは自作で、transformers・VLM・Ollamaでも動作

⑰Securo ＆ Hister 〜 お金と検索を自宅に

プライバシーペアセルフホスト

Securo 〜 パーソナル・ファイナンス

  • プライバシー最優先のセルフホスト式個人財務管理。あなたと金融データの間に企業を挟まない
  • 複数口座の残高管理、OFX / QIF / CAMT / CSVの明細取り込み、ルールエンジンによる自動分類、継続取引と予算の追跡
  • パスキー・TOTP・OIDC SSO対応。Dockerなら1コマンドで導入

Hister 〜 プライベート検索エンジン

  • 訪問したページと手元ファイルをローカルで全文索引。タイトルやURLだけでなく中身から再発見できる
  • Web UI・ターミナル・MCP経由のAIアシスタントから検索可能
  • Firefox / Chrome拡張がページを自動索引。サイト巡回や履歴取り込みも。フィルタ・フレーズ・ワイルドカード・否定条件・意味検索に対応
18

⑱pgrust・open-compute・fugleramme 〜 3連発

Rust勢挑戦作

pgrust 〜 PostgreSQLをRustで再実装

  • PostgreSQLをRustでゼロから書き直すプロジェクト。ワイヤ・SQL互換で46,000以上の回帰テストを通過
  • 既存PostgreSQLのデータディレクトリからそのまま起動可能。ベクトル化JITコンパイル実行器、スレッド活用、内蔵OOMキラー等を再設計。※本番利用はまだ未対応

open-compute 〜 Cloudflare Workers自前運用

  • Workersのプログラミングモデル（KV・D1・R2・Durable Objects・Cron・Workflows）を単一のRustバイナリで自前マシンに。Wranglerでそのままデプロイ。pre-1.0

fugleramme 〜 電子ペーパーの野鳥図鑑

  • Raspberry Pi＋電子ペーパーフレーム。Birdnet-Goがマイクの音で鳥を識別し、パブリックドメインの1800年代の手彩色版画（図版800枚・種400以上）に照合して紙面のように再構成。体の大きい鳥ほど中央へ配置

データベースから電子ペーパーまで、「自分で作る」精神に満ちた今週の締めくくり。次回の更新もお楽しみに！
