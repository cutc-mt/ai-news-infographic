②Claude と Claude Cowork が統合

Anthropic 9/17発表
  • Anthropicは9月17日、AIチャット「Claude」と業務向けAIエージェントClaude Coworkを統合すると発表
  • 統合はCoworkがClaudeに吸収される形。単独プロダクトからClaude内部の機能へと位置づけが変化
  • 提供はまず数週間かけて、ClaudeのWebブラウザー版・デスクトップアプリ・モバイルアプリで展開
  • 対象はまずProプランとMaxプランのユーザーから順次
Claude Cowork Claude に吸収・統合 Pro / Max へ順次
チャットと業務エージェントの「別ツールを行き来」が不要に。作業の起点がClaudeに集約される

③Claude Designs / Docs / Slides 実装

生成特化ツール
  • Claude Designs: Claudeのチャット内で使えるAIデザインツール
  • Claude Docs: ドキュメント生成に特化した機能
  • Claude Slides: スライド生成に特化した機能
  • これらの機能はClaudeアプリ内へ順次提供（Pro/Maxプラン対象）
ツール特化分野
Claude DesignsUI/ビジュアルのデザイン生成
Claude Docsドキュメントの生成
Claude Slidesスライド資料の生成
「デザイン・資料・スライド」が会話だけで完成する方向へ。ビジネス文書制作が大きく変わる

⑤新型AI「Jev」発表 — Typesafe AI

Typesafe AI System One
  • ChatGPTの開発に携わっていたAI研究者リオゴアルメダ氏が手掛けるAI企業Typesafe AI
  • LLMとは異なる仕組みのAIシステムSystem Oneを発表し、その最初のAIモデルを公開
  • LLMのようにテキストを生成するのではなく、高速で低コストにタスクを処理できる目的で設計
  • いわば「文章を書けない・判断に特化した」新型AI
LLM以外の道。「速く・安く・的確に判定する」新ジャンルが登場した

⑥Jevの実力と入手方法

競争デモ API提供
  • 公式ニュースリリースではOpenAIとAnthropicの高速AIモデル vs Jevの競争動画を公開。Wikipedia記事内のリンクだけを使い、あるページから別のページへたどり着く競争

「判断だけ任せる」AIの活用が現実に。リスト登録して早めに試したい

⑦Claude Code プロジェクト機能

9/18発表 並列処理
  • Anthropicは9月18日、AIエージェントClaude Codeにプロジェクト機能を展開すると発表
  • Claudeが作業を複数スレッドに自動で分割し、クラウド上で並行処理
  • スレッド間で情報を共有しながら作業を進行
  • ユーザーが離れても作業を継続できる仕組み
  • ClaudeのProとMaxユーザーに、Webブラウザー版とデスクトップアプリで展開
タスク投入 自動分割 並列実行 統合
「放置して帰ってきたら終わっている」エージェント開発が現実に近づく
08

⑧agent.md を正式サポート

共通指示書
  • Claude Codeが、AIエージェント向けの共通の作業指示書agent.mdを正式サポート
  • 最新版から、フォルダー内にCLAUDE.mdがない場合は自動的にagent.mdを探し、その内容を設定や指示として利用
  • エージェント間で同じ指示書を使い回せる標準化の流れ
# agent.md（イメージ例）
- 作業手順と前提条件をここに記述
- プロジェクト固有の規約も共有可能
→ CLAUDE.md が無いとき自動で読み込まれる
「Claude専用ファイル」から「エージェント共通の指示書」へ。ツール移行コストが下がる

⑰規制・ガバナンスをめぐる動き

重要ニュース
  • 中国紙がAnthropicを批判（ロイター）: ダリオ・アモデCEOのAI開発原則提言について「安全性を理由にしつつ、実際には中国を狙った冷戦的な手法」と批判する記事を掲載。記事は「規制や技術的な壁で中国のAI開発を抑え、米国の技術的優位を維持し、中国を世界のAIガバナンスから排除する狙いだ」と主張
  • EUが15歳未満のAIチャットボット利用禁止を提案へ（ロイター）: SNS・動画共有サービス・AIチャットボット・オンラインゲームの利用を制限する包括的な禁止措置を提案する見通し。オンライン上の危険から子供を守る取り組みとしてこれまでで最も包括的な計画
  • MicrosoftのAI部門責任者ムスタファ・スレイマン氏は「ClaudeのようなAIに人間らしい特性を持たせることで制御不能になるリスクが高まる」と警告（ブルームバーグ）。クロードの憲法は、クロードが道徳的かどうか明確な結論を避けつつ、何らかの機能的な感情や気持ちを持つ可能性があるとしている
  • メタのザッカーバーグCEOは「AIの安全対策は各社が担うべき」と反論（日経）。AI開発原則論でAI企業各社の意見が割れる
  • 政治的立場が大きく異なる米国のバーニーサンダース上院議員とスティーブ・バノン氏が、AIの安全対策を求める点で一致（ブルームバーグ）
「開発を減速すべきか」をめぐるオピニオンが割れた一週間。安全論が地政学と絡み始めている

⑱ビジネス&業界の大きな動き

業界動向
  • OpenAIが評価額1兆2000億ドルで資金調達を検討（ロイター）: IPO前の企業価値が約1.2兆ドルに達する可能性。投資家との協議は初期段階で、今回の協議はOpenAI側ではなく投資家側から持ちかけ
  • デンマークの製薬大手ノボノルディスクがAnthropicと協力し医薬品開発を加速（ブルームバーグ）: 競争が激しい肥満症治療薬市場での巻き返しを目指し、まず研究向上が期待される科学的課題へ研究向けAIClaude for Scienceを活用

  • AnthropicはAIを活用した医薬品開発を本格化するため、米サンフランシスコに生物学研究用の実験施設を開設
  • Anthropicは2026年7〜9月期も調整後営業損益の黒字を見込み、上場前に収益性の改善が進んでいると報じられる（日経）
