02

②Tinycast: 軽量macOSランチャー

ネイティブmacOSRaycast代替
  • 小さくて無料のオープンソースなネイティブmacOSランチャー。Raycastの軽量代替として注目を集めています
  • グローバルホットキー1つでパレットを呼び出し、あいまい検索でアプリを起動。実行中のアプリの確認と終了もできます
  • アプリごとにホットキーを割り当てて、フォーカスをトグルすることも可能です
  • テキストと画像のクリップボード履歴（検索可能）、スニペット、電卓、辞書、Spotlight経由のファイル検索（インデックス不要）を同梱
  • Raycast拡張もそのまま動作。厳格なメモリ予算で設計され、Homebrewでインストールしてすぐ起動できます
03

③Cilium: eBPFでK8sの網を張る

CNCFプロジェクトeBPFCNIプラグイン
  • Kubernetes向けのネットワーク・セキュリティ・観測性を担うOSS。eBPFを土台にしたCNIプラグインとしてクラスタにフラットなL3ネットワークを提供します
  • ネイティブルーティングかオーバーレイモードかを選べ、クラスタをまたぐ構成も可能です。ネットワークポリシーはL3からL7まで強制できます
  • IPアドレスから切り離したアイデンティティベースのポリシーが特徴。ポッドの入れ替わりに強い設計です
  • eBPFによるロードバランシングでkube-proxyを完全に置き換え可能。イングレス・エグレスゲートウェイ、帯域管理、サービスメッシュも備わります
eBPF Cilium (CNI) L3〜L7 ポリシー

コーディングエージェントとその強化

CODING AGENTS
04

④ECC: エージェントを鍛える

Claude Code / Codex 対応Cursor / OpenCode
  • AIコーディングエージェントを「より良いエンジニア」に鍛えるためのオープンソースシステムです
  • スキル・メモリ・スタックごとのルール・セキュリティをレイヤーとして重ね、リサーチファーストのワークフローを強制します
  • 構築の前に計画を立てさせ、テストで変更を検証させ、新しいコンテキストで自分の作業をレビューさせ、重要なことを記憶させる設計です
  • review peerlearnconsultなどのコマンドに加え、セキュリティレイヤーAgent Shieldも同梱。プラグインとしてインストールできます
05

⑤Cline: 自律コーディングエージェント

VS Code / JetBrainsCLI・SDK
  • オープンソースの自律コーディングエージェント。IDE拡張・CLI・SDKの3つの形で利用できます
  • プロジェクトを読み込み、ファイルをまたいで調整の取れた変更を行います。リンターとコンパイラのエラーを監視して、自動で修正まで行います
  • ターミナルコマンドを実行し、その出力にリアルタイムで反応する安定したループを持ちます
  • プlanモードで戦略を立ててからactモードで実行。すべての編集とコマンドにはユーザーの承認が必要です
  • モデル非依存で、MCPで拡張可能。好みのLLMと組み合わせられます
06

⑥Octop: マルチユーザーAIアシスト

Tencent Cloudセルフホスト
  • Tencent Cloudが公開した、複数ユーザー・複数エージェント対応のセルフホスト型AIアシストです
  • 自分のマシン上のプロセスとして動き、Webダッシュボード・CLI・cronオートメーションを提供します
  • Feishu・DingTalk・Discord・WeComなどのチャネルとも接続できます
  • 各ユーザーにはエージェントのチームが与えられ、タスクごとに切替え。それぞれが独自のワークスペースを持ちます
  • エキスパートライブラリ・MCPコネクタ・ACPでIDEツールとも連携。ユーザーごとの分離とデータのローカル保持が前提の設計です

⑦n8n: AIネイティブな自動化

フェアコード400の統合
  • ネイティブAIを備えたフェアコードのワークフロー自動化プラットフォームです
  • ビジュアルなノードベースのキャンバス上でアプリやサービスを接続し、必要な箇所だけカスタムコードを差し込めます
  • 400のインテグレーションを同梱。AIノードでLLMエージェントをワークフローの中に組み込めます
  • ソースが公開されているため、DockerやKubernetesでセルフホストしてデータを自分で管理できます。n8n Cloudを使う選択肢もあります

Zapier的な手軽さと、自前運用の自由さを両立。AIノードでエージェントも組めるのが強い！

⑧FirstMate: 1人が指揮するCrew

エージェントCrewtmux対応
  • ターミナルのコーディングエージェントを指揮官（ディスパッチャー）に変えるエージェントディストリビューションになっています
  • 1人のFirstMateに話しかけるだけで、隔離されたGitワークツリーの中にcrewmateを生成して並走らせます
  • ゼロトークンのイベント駆動ウォッチャーで彼らを監督し、完成したPR・マージ・レポートを手元に返します
  • Claude Code・Grok・Codex・OpenCodeなどと、tmuxなどのセッションバックエンド上で連携可能です
09

⑨Orca: エージェント並列実行IDE

Stably AIデスクトップ・モバイル・VPS
  • たくさんのコーディングエージェントを並べて実行するためのIDEです。デスクトップ・モバイル・VPS向けアプリとして提供されます
  • Claude Code・Codex・Grok・CursorなどのCLIエージェントを、それぞれ隔離されたGitワークツリーで実行できます
  • 1つのプロンプトを複数エージェントに展開して結果を横並びで比較できるのも魅力です
  • 組み込みターミナルとデザイン用ブラウザーを装備し、GitHubとLinearのレビューにもネイティブ対応しています

⑩Omarchy: エージェンティックなLinux

Linuxディストリマニュアル同梱
  • 楽しくエージェントと付き合えることを目指したLinuxディストリビューションです
  • リポジトリ内に膨大なマニュアルを同梱。テーマやホットキーからAI・開発ツール・ネットワークまで網羅しています
  • モダンなデスクトップをゼロから組み立てる負担を解決し、ナビゲーション・音声入力・スクリーンショット・dotfilesを事前設定済みで提供します
  • Macハードウェア・デュアルブート・無人インストール・システムスナップショットにも対応。ターミナルフレンドリーなLinuxをすぐ使い始めたい人に最適です
11

⑪OpenLogi: Logitechをローカル制御

Rust製Options Plus代替
  • LogitechのOptions Plusに対するローカルファーストなRust代替のネイティブアプリです
  • HID++とUVCでLogitechのマウス・キーホード・ウェブカメラを制御。アカウント登録もテレメトリもありません
  • ボタン・DPI・ジェスチャーのリマップを1つのプレーンテキスト設定ファイルでローカルに管理できます
  • 本物のCLIを備え、macOS・Linux・Windowsで動作。Litraライトの調光やカメラのピント・露出調整にも対応しています
12

⑫VoiceStudio: 完全ローカル音声

音声クローン・ダビング646言語
  • ホスト型音声サービスの代替となる完全ローカルの音声スタジオです
  • 音声クローン・音声デザイン・動画ダビング・音声入力・文字起こし・オーディオブック作成を646の言語とロケールでカバーします
  • TTS 16エンジンASR 11エンジンをCUDA・Apple Silicon・Rockchip・CPUで実行。音声とプロジェクトはデフォルトでマシン内に保持されます
  • デスクトップアプリに加えてOpenAI互換APIとMCPサーバーを提供し、エージェントとの統合も可能です

⑬TimesFM: ゼロショット時系列予測

Google Research基盤モデル
  • Google Researchが開発した時系列予測の事前学習済み基盤モデルです
  • 履歴データを与えると、タスクごとの学習なしに未来の値を予測します。データセットごとにモデルを作る手間をゼロショット汎化で解決します
  • 単一系列にも多変量入力にも対応し、過去と未来の共変量もオプションで渡せます
  • Pythonパッケージとしてインストールし、PyTorchまたはApple Silicon向けMLXで動作。NumPy配列にpredictを呼ぶだけで分位点付きの予測が返ります
履歴データ TimesFM predict() 分位点付き予測
14

⑭FreeLLMAPI: 無料枠を1つのAPIへ

セルフホストルーターOpenAI互換
  • 34社のLLMプロバイダーの無料枠を単一のAPIに集約するセルフホスト型ルーターです
  • OpenAI互換の/v1エンドポイントと任意のカスタムエンドポイントを提供します
  • 個別SDKとレート制限の管理という煩わしさを解決。リクエストごとに最適なモデルを選び、キーごとの使用量を追跡し、制限時には自動でフェイルオーバーします
  • APIキーはAES-256で暗号化。Claude CodeやCodexなどのコーディングエージェントでもそのまま使えます
# インストールスクリプトを実行してキーを登録するだけでOK
POST /v1/chat/completions  ← 自動で最適な無料枠へルーティング
15

⑮Jevlike: 選択肢を一括スコア化

スターターモデルワンパス推論
  • テキストと変化する選択肢リストを渡すと、各選択肢の確率を1回のパスで返すスコアリング用のOSSモデルです
  • 選択タスクでは、トークンを逐次生成するより一括でスコアする方が遥かに高速。デコーダーモデルの速度コストを解消します
  • 各選択肢はクエリベクトルとなってコンテキストに注意を向け、共有の内積とsoftmaxで確率を出力します
  • JSONLデータセットから学習でき、スクラッチのバイトエンコーダーか凍結Hugging Faceエンコーダーを選択可能。CPU・Apple MPS・CUDAで動作します

⑯Noto Emoji & Rakazo: 絵文字とAIボット

Noto Emoji 〜 絵文字フォント一式

  • Unicode準拠のカラー絵文字フォントと、完全なSVG・PNGのソース一式を提供するGoogleのOSSです
  • 絵文字が欠けて空白箱「トウフ」と表示される問題に、完全な標準フォントで対処します
  • CBDT/CBLC形式でAndroid・Chrome・Chromium OSでネイティブ対応。モノクロの可変フォントも別途保守されています

Rakazo 〜 自分のコンピュータを持つAIボット

  • ホスト型AIボットの代替となるOSS。各ボットに1スレッド・1コンピュータ・メモリ・ルーティンを与えます
  • AIプロバイダーは持ち込み可。サンドボックスもDocker・E2B・ホスト直結から選へます
  • コンピュータペインには、ボットが操作するライブなLinuxデスクトップが表示されます
17

⑰lint & Plexo: 規律と高速ダウンロード

@shadcn/lint 〜 エージェント用リンター

  • Tailwindに絞ったESLint・OxLintプラグイン。コーディングエージェントの勝手なスタイル変更を防止します
  • 型チェックと違って、違反ごとに直し方のガイダンスを添えるのが特徴。エージェントが自分で修正できます
  • コンポーネントごとに「許可するクラス」を契約として定義。Tailwind v4ならshadcn/uiがなくても動作します

Plexo 〜 全回線同時ダウンロード

  • macOSのElectronアプリ。Wi-Fi・有線LAN・USBテザリングのスマホなどすべてのネットワーク回線から同時に同じファイルのチャンクを取得します
  • 8MBチャンクに分割し、HTTP Rangeリクエストとワークスティーリングキューで速い回線が多くを引き受けます
  • サーバーのバリデーター確認後に安全に再開でき、進捗グリッドでどの回線がどのチャンクを取得したかを見られます
18

⑱PizzaBot & BG0: 受信箱と背景除去

PizzaBot OSS 〜 エージェントの受信箱

  • 長時間走るAIエージェントの作業を仕分けるローカルファーストの受信箱です
  • 完了作業は「未読」に、あなたの決断が必要なものは「要アクション」に仕分け。ページを移動してもエージェントは動き続けます
  • ステートフルなDeep AgentsとLangGraphランタイム上に構築され、Electron・ブラウザー・CLIの3形態から利用できます
  • Bedrock・Anthropic・Gemini・OpenAI・OpenRouter・Ollamaに対応。ローカルフォルダへのアクセスは明示許可制です

BG0 〜 ブラウザから出ない背景除去

  • WebGPUを活かし、なければWebAssemblyにフォールバック。完全にブラウザ内だけで背景を除去します
  • ONNXモデルをローカル実行するため、サーバーへのアップロードもアカウントも利用制限もありません
  • モデルは一度だけダウンロードしてキャッシュ。ソース画像からそのまま透過PNGを出力します。再利用可能なnpmパッケージも提供され、自分のWebアプリに組み込めます
