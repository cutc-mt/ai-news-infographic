⑮予想を上回る進化と再帰的自己改善

コードネーム Belrecursive self-improvement
  • この内部モデルのコードネームがBelです。OpenAI自身の予想を上回る速度で進化していると伝えられます。まさにタイトル通りの「止まらない」状態です
  • さらにBelは自分自身の訓練にも使われています。つまり再帰的自己改善（recursive self-improvement）が、OpenAIで現に稼働しているのです
  • モデルがモデルを鍛え、鍛えたモデルがさらに良いモデルを生む。開発の速度そのものが上がり始めたことを意味します
// 再帰的自己改善のイメージ

Bel' → さらに訓練 → Bel''… // 自動で回り続ける
