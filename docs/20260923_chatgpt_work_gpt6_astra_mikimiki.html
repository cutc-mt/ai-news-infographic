⑤デモ②：フォルダ整理

ハンズオン2仕分けの精度
  • デモ②では既存フォルダの中身を、命名規則や用途に沿って再配置します。「このファイルはどこに入る？」という判断をAIが続けます
  • Astraの優秀なところは、曖昧なファイル名から中身を推測して適切な分類先を選ぶこと。単純なキーワード一致を超えた整理が可能です
  • とはいえ結果は必ず人が確認するのが作法。AIの仕分けに任せきりにせず、最後のチェックを挟む運用が推奨されます

「フォルダ整理なんてAIに任せていいの？」と思うかもしれません。でも一度体験すると、手作業に戻れなくなりますよ。

⑩指示は「基準」まで書く

プロンプトの型曖昧さを消す
  • ハンズオン全体を貫く原則は、「何を・どこへ・どんな基準で」を指示に含めること。「きれいにして」ではAIも迷います
  • 分類の基準・命名規則・例外の扱いを箇条書きで渡すと、Astraがほぼブレずに実行してくれます
  • うまくいかなかったら基準の指示を直して再実行。手で修正するより、ルールを更新する方が早い世界になりました
# 良い指示の例
- 対象: 指定フォルダ内の全ファイル
- 基準: 種類別／日付の新しい順
- 命名: YYYYMMDD_案件名_内容
- 例外: 判断不能なものは「要確認」へ

⑪業務データを扱う前提の確認

セキュリティ利用規約の確認
  • Workに社内ファイルを接続する前には、所属組織のAI利用規程とデータの扱いの確認が前提です。個人情報・機密情報の扱いは特に慎重に
  • 顧客データを含む業務はマスキングしてから渡すなど、現場のルールとすり合わせて進めましょう
  • 動画も「まずは個人の作業フォルダなど影響の小さい範囲で試す」ことを推奨しています

便利さの裏側には必ず「何を預けるか」の判断がついて回ります。ここは急がず慎重に。

⑫「任せる」と「確認する」の切り分け

人間の仕事最終チェック
  • AIが得意なのは大量・単純・繰り返しの処理。人が残すべきは判断の妥当性の確認と承認です
  • フォルダ整理にせよ書類生成にせよ、完成品を斜め読みする数十秒が品質を保証します
  • 「AIに任せたから確認しない」が一番危険。任せるところと確認するところを決めておくのが業務設計のコツです
