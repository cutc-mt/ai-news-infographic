OVERVIEW
01

①スイスから緊急解説

速報解説Opus 5.5公開
  • Claude Opus 5.5が公開。チャエン氏は出張先のスイスから緊急で解説しました
  • 性能は第三者の総合指数で世界No.1を獲得。公式・第三者評価の両方で首位です

  • 注意：公式ベンチは自社測定、実機比較は各お題1回（n=1）の参考値です

海外出張中でも即解説せずにいられないインパクト——それが今回のOpus 5.5です。

02

②既定のeffortが high→medium

破壊的変更既定値変更
  • 大きな変更点：既定のeffort が high → mediumに。何もしなくても中間設定で動きます
  • mediumのままでもGPT-6 Astra級の性能が出るため、多くの場面で追加設定が不要に
  • 「とりあえずmax」はお金をかけて点が下がることもある落とし穴あり
  • 損しないコツ：迷ったら medium のまま。公式Docsの「What's new」に明記されています
旧: effort=high 既定 新: effort=medium 既定

「強くするほど良くなる」時代は終わりました。既定値が最適解です。

03

③いつ使える？提供条件

提供タイミング5時間枠
  • Opus 5.5は有料プランから利用可能。発表直後から順次切り替わります
  • 5時間枠のアップ・リセットに関する仕様も合わせて解説されています
  • 利用できない場合は、アプリ再起動やプラン確認で反映を待つのが定石です
  • Claude 5.5ファミリーの1本目。今後の兄弟モデル展開にも注目です

新しいClaudeは「いつから使えるか」も重要な情報。すぐ確認しましょう。

04

④料金：単価−20%・キャッシュ−60%

API単価Opus 5比
  • API単価はOpus 5より20%安い。入出力で$4／$20という価格設定です
  • キャッシュ利用時はキャッシュ料金が−60%。長文コンテキストの反復利用が大幅に安くなります
  • Fable 5.1級の性能に対して圧倒的に安いコスト構造。コスパ最強クラスです
  • 「高性能＝高額」の常識を覆す、値下げしながらの性能No.1という異例のリリースです

性能世界一を取りながら値下げ。——利用者にとって理想のアップデートです。

05

⑤公式ベンチ：9項目中7つで1位

公式ベンチ7/9首位
  • 公式ベンチマーク9項目中7つで1位。ほぼ全カテゴリでトップを獲得しました
  • 第三者評価Artificial AnalysisのIntelligence Indexでも首位を獲得
  • コーディングやエージェント系タスクでもGPT-6 Astra越えのスコアをマーク
  • 自社測定とはいえ、公式・第三者の両方で1位という結果は説得力があります
公式ベンチ 7/9で1位 第三者指数でも首位

「自社ベンチだけ」ではなく第三方でも1位——これが今回の決め手です。

06

⑥落とし穴：maxよりxhigh、最高点はmedium

要注意effort設定
  • effortを上げすぎると逆効果：maxよりxhigh、最高点はmediumという測定結果が出ています
  • つまり「とりあえずmax」はお金をかけて点が下がることもある、ということ
  • 損しない使い方の結論：迷ったら Opus 5.5・effort は medium
  • 破壊的変更・既定のeffortの詳細は公式DocsのWhat's new in Claude Opus 5.5に記載

課金額と性能が比例しない時代。設定の常識を見直すタイミングです。

07

⑦プロンプト：大事なことを最初の1行に

Prompting実践テク
  • Opus 5.5で大事なのは重要な指示を最初の1行に書くこと
  • 構造化された指示（箇条書き・番号）が応答精度を安定させます
  • 長文の前置きや繰り返しは逆効果。要点前置きのシンプル指示が最適です
  • effort=mediumと組み合わせれば、低コストで高精度な運用が完成します
# 損しないプロンプトの型
1行目：最重要の指示（出力形式・制約）
2行目〜：背景資料・補足情報
設定：effort=medium のまま変更しない

「最初の1行」に命を懸ける——それが5.5世代のプロンプト作法です。
