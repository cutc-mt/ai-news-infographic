01

①Ami AI — 自走するGTMエージェント

AISDR製▶ 00:58
  • ウェブサイトのURLを渡すだけで約20分でビジネスを学習し、ターゲットリストを構築してキャンペーンを開始します
  • メール+LinkedInのライブキャンペーンを自動実行。多くのツールが投げ出す「ロンチ後」からが本番です
  • 結果を常時監視して停滞箇所を修正し、次の一手を提案。ICP(理想顧客像)はセッションをまたいで記憶されます
  • HubSpotと同期し、初回キャンペーンは承認待ちで安全に開始。創業者と営業チーム向けです

「URLを渡すだけで、次の一手が見えてくる」——与えるのは住所だけ、あとはAmiが走ります。

aisdr.com/ai-gtm-agent-ami

②Clarify — 自分で回すCRM

AIネイティブCRM▶ 06:01
  • 手入力とCRMの維持管理という、営業担当を売り場から引き離す雑務を丸ごと自動化します
  • メールとカレンダーを同期し、リード・会議・商談を一か所に集約。エージェントRepが商談前にブリーフを用意します
  • 通話を録音・要約し、新しい商機を検出、案件ステージを更新、フォローアップの文案まで起草します
  • フィールド名を言うだけで型を推測して自動入力。ICPに合う見込み客の発見と情報補充もこなします
  • SOC2・HIPAA・GDPR準拠。GTMチーム向けに無料で開始できます

clarify.ai

③AINA — CVからオファーまでのAIコーチ

AI採用基盤▶ 01:36

  • CVをアップロードすると項目を自動入力し、具体的な修正提案まで返してくれます

  • 無限に開くタブ・同じフォームの再入力・音信不通になる応募という散らばった就活を解消。GDPR準拠で求職者は無料で開始できます

④Ari by Ariso — リーダーのAI参謀

AI管理システム▶ 04:11
  • プロジェクト・フォローアップ・優先順位を参謀(チーフオブスタッフ)のように運用するArisoのAI管理システムです

  • 自然言語で質問でき、会議前にブリーフを準備。アクションアイテムを追いかけ、実際の根拠に基づく報告とレビューを起草します
  • Slack・Teams・Webで動作しGoogle Workspaceと接続。ユーザーデータでは学習しない設計です。個人・管理者・経営者向け

会議を Capture して、尋ねれば答える分身。リーダーの「覚えておく負担」を預かります。

⑥Pushary — ノッチから即承認

許可リクエスト通知▶ 05:23
  • AIコーディングエージェントの許可リクエストをMacとスマホに届けるコントロールパネル。1回の「はい」待ちで止まる時間の無駄を無くします
  • リクエストはMacのノッチに表示されスマホが振動。承認・拒否・返信をすれば作業が続行します
  • ルールを一度設定すれば危険な操作だけが届きます。Claude Code・Codex・Cursor・MCPエージェントに対応
  • コードは自分のマシンから出ません。1コマンドでセットアップして無料で開始できます
agentが許可要求ノッチ+スマホ承認/拒否/返信作業続行

pushary.com/mac-notch-app

07

⑦Yoetz — 「完了」を検証する台帳

ローカルファースト▶ 11:26
  • オープンソースの作業台帳。コーディングエージェントの「完了しました・テスト通過」が本当かを検証します
  • 主張どおりでも実行が最終編集より前なら話にならない——この信頼ギャップを埋めるのが目的です
  • MCP経由の主張と、フック・セッション・ツール呼び出し・編集の実績という2つの記録を保持。ローカルルールで照合し、不一致は指摘事項(findings)となり、agentが修正して再チェックします
  • 何が・どの網羅率で検証済みかの領収書(レシート)を出力。Codex・Claude Code・Cursor対応で、アカウント不要・データは外部に出ません
// Yoetz の二重記録
主張 = MCP経由で agent が報告
実績 = hooks / sessions / tool calls / edits
→ ローカルルールで照合 → 不一致は finding

yoetz.dev

⑧ContextsBase — エージェント向けバックログ

MCPで仕様を供給▶ 12:15
  • エージェントネイティブのプロジェクト作業場所。散らばったmarkdownメモを置き換え、人間向けツールが毎回推測させるスキーマと業務ルールの欠落を解消します
  • 機能・仕様・データモデル・業務ルール・試験項目を一度だけ構造化すれば、agent がMCPで引き取ってくれます
  • 機能を反復単位にまとめて開放すれば、1コマンドで順番に claim → build → test
  • Claude Code・Cursor・Copilot・Windsurfほか任意のMCPクライアントに1設定ブロックで接続。1プロジェクトまで無料です

contextsbase.com

⑨Simple Commenter AI — 顧客の声を直結

フィードバック→MCP▶ 13:04
  • クライアントのWebサイトへのコメントをMCP経由でコーディングエージェントに直結。別々の道具でページや要素の文脈が消える問題を解消します
  • クライアントはページをクリックしてコメントするだけ。開発者向けメモにURL・要素・技術詳細が記録されます
  • ChatGPT・Claude・Cursor・Claude Code・Codexが未対応コメントの一覧表示・返信・ステータス更新(書込権限を与えた時だけ)を実行します
  • 本番サイトは自動では編集しません。接続ごとに見せるプロジェクトを選べます。Web制作会社・受託開発者向け

simplecommenter.com

⑩Tines — 統制下のエージェント作業場

セキュリティ担保▶ 09:56
  • 全チームがAIエージェント・アプリ・自動化を構築し、ITとセキュリティ部門が監視を維持できる安全な作業場所です
  • 個人アカウントの鍵・リポジトリ・アプリに散らばる見えないAIリスクを解消。何が存在し、誰が作り、何に触れるかを把握できます
  • 警報の仕分け、IT展開、財務承認、採用などの機密性の高い業務フローをエージェントが実行。修正案を出しつつ、公開の可否は人が決めます
  • 特定ベンダーに依存しない構成で、モデルの実行場所を選択可能。セキュリティ・IT部門と、それに頼るチーム向けです

「1人で黙って作る」から「統制された道で全員が作る」へ。shadow AI の心配が要らなくなります。

tines.com

⑭MosMos — 文脈に合わせる音声入力

Mac音声入力▶ 02:16
  • 話し言葉を書き先に合わせたすぐ使える文章に変換するMacアプリ。文脈を無視して口調の手直しを人任せにする通常のディクテーションを改善します
  • 任意の入力欄でクリック、Fnを押して自然に話す、もう一度押すだけ。チャット・メール・文書・端末向けに整形されて貼り付きます
  • 自分の口調をどれだけ残すかを選択でき、独自のキーワードも登録可能。会議を録音すれば要約とToDoを生成します
  • 履歴は端末内に保存。一日中文章を書く人のために、無料でダウンロードできます

mosmos.io

⑮Keysake — 打ちながら英語を学ぶ

学習向け入力メソッド▶ 04:49

  • 中国語を打つと対応する英語表現が入力の隣にリアルタイム表示。スペースバーの2連打で文章全体を保存できます
  • 見直し画面では文の構造と文法を解説。貯めたコレクションがそのまま教材になります
  • 翻訳は端末内で実行され、入力はローカルに留まります。毎日打つ言葉の練習をしたい人向けです

⑯WhaleRead — 書籍翻訳を手元で

書籍の翻訳と読書▶ 09:05

⑰キャラとサイトを磨く2作

Bring Them to Life ▶ 08:17

マスコット動画化
  • 持っているキャラ・マスコット・挿絵を、サイトやアプリ向けの綺麗な動きに変えるWeb道具。動画制作の費用と技術の壁を下げます
  • PNG/JPG/WEBPを上げ、明暗・色彩・輪郭の背景で切り抜きを確認。反応(手を振るなど)を選ぶと20〜30分で動画を生成します
  • 透明WEBP・静止画・Lottie形式で納品され、主要画面や広告に自然に組み込めます。クレジット制で、まずは無料で試せます

Polishory ▶ 14:00

AIデザインレビュー→修正
  • 公開URLを貼るだけで本物の画面を開き、読む順・階層・余白・ボタンを審査。「何かが違う」を根拠のある指摘に変えます
  • 事実と提案を分離し、各指摘には計測値と次の一手が付く。ロゴ・配色・内容は保持し、元の code には触れません

bringthemtolife.xyz ｜ polishory.design

⑱Macで遊ぶ2作

GameToMac ▶ 10:42

MacでWindows game
  • Apple SiliconのMacに人気のWindowsゲームを1つのライブラリに集めるMacアプリ。自分のSteamでサインインして起動します
  • 対応は10タイトル: AoE2/4、Company of Heroes 3、CS2、Diablo II、Overwatch、Path of Exile 2、Hogwarts Legacy など。Windows勢との対戦も確認済みです

VoiceChanger.Live(Echo) ▶ 14:46

即時声変換
  • PC・Mac・携帯で使える無料のリアルタイムAIボイスチェンジャー&サウンドボード。1分以内に仮想マイクを導入し、話しながら性別・スタイル・キャラクターを切り替えます
  • 数十万の既製ボイスの取り込み、短いサンプルからのクローン、フィルター・ピッチ・残響をかき混ぜた自作に対応。Discord・OBS・Zoomなどマイクを受け付ける全てのアプリで動作し、低遅延でローカル実行です

仕事の自動化ばかりでなく、遊びの道具もAIで裏打ちされる——今週の流れを象徴する2作です。
