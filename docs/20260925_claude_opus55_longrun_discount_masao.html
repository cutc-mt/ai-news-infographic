3つの改善 — 価格・モデル・ハーネス

3本柱の全体像 (05:52)

  • ① 価格: トークン・キャッシュの値下げ
  • ② モデル挙動: 長時間向けの学習・挙動改善
  • ③ Claude Codeハーネス: キャッシュ保持の最適化
  • 3つが揃ってロングラン費用が下がる設計
値下げだけじゃない — ハーネス側の改善がもう一つの肝

キャッシュ読み込み60%安

  • 入出力トークン価格も20%減

  • キャッシュ読みは費用の大半 — 下げ方が妙にしてある

実践習慣とまとめ — キャッシュを守る

/usage でキャッシュ率を見る (08:59)

  • Claude Codeで/usageを実行
  • 使用量のうちキャッシュ読み取り比率を確認
  • その数値を「守る」という発想で運用
  • 価格改定の恩恵を見える化できる
$ claude
> /usage   # キャッシュ読み取り比率を確認
まず計測 — キャッシュヒット率があなたの財布の健康状態

キャッシュを守る3つの習慣

  • モデルはセッション開始時に選ぶ — 途中で切り替えない
  • 離席する前に/compactを実行する
  • 長いセッションには1時間キャッシュライフタイム設定
  • 習慣が複利で効く — 特にオープンな長期作業で
「切り替えない・先にcompact・寿命1時間」— 公式推奨の型はこれ!
