Gemini 3.8 Flash TTS とは

00:00〜

読み上げ特化の新世代TTS

  • テキスト読み上げ専用に設計された新世代モデル
  • 従来の「機械っぽさ」を感じさせない自然な発話
  • つぎ目のない滑らかな読み上げと自然な間（ま）
  • Google AI Studio API OpenRouter から利用可能

2モデル構成

  • Flash ─ 品質重視タイプ
  • Flash-Lite ─ 速度・コスパ重視タイプ
  • 用途と予算に応じて使い分ける設計
「品質で選ぶか、速さと価格で選ぶか」──この2軸の選択ができるのが現行世代のポイント。

どこが「驚愕」なのか

00:00〜

人間と聞き分けが難しい

料金の考え方 ─ 値下げで実用域へ

02:05〜

コスト構造

  • テキスト入力＋音声出力で課金（出力が主体）
  • 前世代（Gemini 3.1 Flash TTS Preview）比で値下げ
  • 世代交代で「値下げ＋機能強化」が同時に実現

体感的な価格帯

  • 動画1本ぶんのナレーション丸ごとを数十円程度で生成可能
  • 個人開発者でも気軽に試せるコスト感覚
  • 長尺コンテンツ量産のコスト障壁が大きく低下
「20分読み上げて数十円」──収益化とコストのバランスがようやく合い始めた。
5

性能 ─ Flash / Flash-Lite の使い分け

02:05〜

2タイプの性格

  • Flash：高品質・価格はやや高め
  • Flash-Lite：低価格・高速な生成
  • 品質重視の納品物なら Flash、量産・速度重視なら Flash-Lite

速度の実用性

  • Flash-Lite の生成速度は十分実用的
  • 待ち時間の少なさは対話用途でも有利
  • バッチ生成なら Flash の品質を余裕を持って使える

アプリ・エージェント組み込み

  • AIエージェントの「声」としての利用が現実的

PART 3 ─ AI Studio 実演（06:11〜）
7

Google AI Studio で音声生成

06:11〜

GUI で手軽に試す

  • ブラウザ上でモデルと音声を選んですぐ生成
  • コード不要で TTS の品質体感が可能
  • プロンプト＝「台本」として書くのがコツ
まずは AI Studio で数分触ってみるのが最短ルート。設定項目は驚くほど少ない。

台本の書き方

  • 読み上げたい文章にト書き・指示を混ぜる
  • 話者や情景を指定すると演技が変わる
  • 「生成系AIのプロンプト力」がそのまま音声に効く
8

感情表現 ─ 演技タグで演出

06:11〜

感情をタグで指定

  • 笑い・喜びなどの感情をタグで演出
  • 「悲しげに」「楽しげに」等の演技指示が通る
  • タグ付き台本を書くだけで抑揚がつく
# 感情表現のイメージ（台本に埋め込む）
[楽しげに] 今日は良いニュースがあります！
[真剣に] ただし、注意点がひとつ。
[笑いながら] それでは聞いてください。

方言・アクセントも指定

  • 台本に方言・アクセントの指定を記述できる
  • キャラクターの個性付けに好都合
  • ラジオ風・雑談風コンテンツの演出の幅が広がる
9

カスタムボイス ─ 声をつくる

06:11〜

プリセット30種

  • 30種類のプリセットボイスを搭載
  • 雰囲気の違う声で演じ分けが可能
  • 声の保存期間には注意して運用（期限切れに注意）

文章で新しい声を生成

  • 「落ち着いた成人男性」のように言葉で声を描写
  • オリジナルのカスタムボイスを生成できる
  • 音声サンプルから話し方を再現するボイスクローンも（権利・許可に配慮）
「声のデザイニング」が文章でできる時代。キャラ設計がより大事に。
PART 4 ─ API×日本語ツール（13:00〜）
10

Gemini TTS API で音声生成

13:00〜

API 組み込みの基本

  • API キーを取得すれば自作アプリから直接呼べる
  • 台本をリクエストすると音声ファイルが返るシンプルな構造
  • OpenRouter 経由でも利用可能
# イメージ：台本を送って音声を受け取る
POST generateContent
  model: "gemini-3.8-flash-tts"
  voice: "Kore"
  script: "ようこそ、AI音声の世界へ"
→ audio (PCM/WAV)

開発のポイント

  • 音声フォーマット・保存期間の仕様を先に確認
  • 変換（WAV→MP3等）は自前パイプラインで用意
  • 料金・速度を踏まえ Flash / Flash-Lite を切り替え

日本語向け音声ツール制作

13:00〜

日本語コンテンツとの相性

コンテンツ制作への展開

  • 台本タグ付けを LLM に任せる半自動化も可能

自動化ワークフローの全体像

13:00〜

文章→音声→映像

  • 記事・原稿を用意
  • LLM で台本化＋感情タグ付与

  • 誤認識の少なさ＝聞き取りやすさの証拠
  • 音声品質は「人の耳」と「往復テスト」の両面で評価
PART 5 ─ ChatGPT Voice（17:45〜）
13

ChatGPT Voice の進化と使い方

17:45〜

音声対話モードの強化

  • 会話の自然さ・応答の体感品質が向上
  • 話しかけるだけで操作が完結する体験
  • 「生成」のTTSに対し、こちらは「対話×実行」が主戦場

ハンズフリー活用

  • 手が離せない作業中・移動中に強い
  • 声だけでタスクを投げて結果を受け取る
  • 入力の手間ゼロ＝操作の速度アップ
「話すだけで仕事が進む」──音声UIはもう将来の話ではなく現役戦力。
14

実演① ─ 音声で Gmail 操作

18:23〜

メール作業を声で

  • 音声指示でメールの検索・確認
  • 返信文の下書きも音声の指示で作成
  • 一連の流れを会話しながら完結
  • キーボード操作なしで inbox 処理が進む

実演から見えたこと

  • 認識精度・応答速度が実用に足る印象
  • 複数ステップの指示も崩れずに実行
  • 日常業務への「音声アシスタント定着」の兆し
15

実演② ─ 音声で資料作成

18:23〜

話すだけで資料化

  • 資料の方向性を口頭で指示
  • 構成案・ドラフトを音声での対話ベースで生成
  • 修正も「ここをこう変えて」と会話で反映

生産性の変化

  • 企画→ドラフトの初速が大幅に短縮
  • 考えを言語化する練習にも最適
  • 「音声で命令、AIで下書き、人が仕上げ」の分担

Gemini TTS vs ChatGPT Voice

22:14〜

用途で分かれる2つの音声AI

観点Gemini 3.8 Flash TTSChatGPT Voice
得意分野台本→音声の「生成」リアルタイム「対話」とタスク実行
制御声・感情・方言を台本で指定会話の流れで自然に指示
組み込みAPI でアプリ・パイプラインにアプリ内の音声UIとして利用
コスト出力量ベース・長尺に強い対話セッションで利用
向く用途ナレーション・オーディオブック・量産メール操作・資料作成・調査
17

まとめ ─ 使い分けの指針

22:14〜

結論の整理

  • ナレーション制作・量産は Gemini 3.8 Flash TTS
  • 音声アシスタント作業は ChatGPT Voice
  • 2つを組み合わせれば「制作×実行」をAI音声で完結

今日から試すには

  • AI Studio でプリセット声を数個聞き比べ
  • 自分の記事を1本、台本化して音声生成
  • ChatGPT Voice でメール1件を声だけで処理
小さく始めて「リアルさ」を自分の耳で確かめるのが一番の近道。
