④security-audit-skill

Cloudflare製▶ 01:04
  • coding エージェントに組み込む多段階セキュリティ監査スキル。Cloudflareが公開した公式スキルで 2.1万★を獲得
  • 監査は計画→調査→検証の複数フェーズで構成。各調査は独立に実行され、発見事項は機械可読な形式で出力されます
  • 結果は独立した検証をパスした事実のみを報告。「らしい」で終わらない、エビデンス付きの監査を実現します

⑥Claude Code

Anthropic公式▶ 03:07
  • ターミナル上で動くエージェント型coding ツール。リポジトリ全体を理解し、日常タスクの実行・複雑なコードの説明・gitワークフローを自然言語で処理します
  • 公開リポジトリは14.8万★。CLI だけでなく VS Code / JetBrains 拡張や SDK も展開される、エージェントcoding の事実上の標準
  • 周辺ツールとの相性も良く、MCP 経由の外部連携やスキル機構で拡張。今週の他の pick からも“前提の道具”として言及されます

⑧OpenSpec

仕様駆動開発（SDD）▶ 07:42
  • AIコーディング支援のためのspec-driven development（仕様駆動開発）フレームワーク。7万★の人気作
  • 実装の前に仕様書を書き、変更は提案→承認→反映の流れで管理。AIが勝手にコードを書き換えるリスクを構造的に抑制します
  • 複数のcoding エージェントで同じ仕様を共有できるため、ツールを切り替えても文脈がブレない開発が可能に

「AIに書かせるなら、先に仕様を固めよう」——地味だけど、これが今の一番の安定剤かもしれない。

Fission-AI/OpenSpec

⑨GitDiagram

リポジトリ図解▶ 10:25
  • 任意のGitHubリポジトリにインタラクティブな図を即座に生成するツール。1.7万★
  • URL の github を gitdiagram に変えるだけ。モジュール構成と依存関係がクリック可能な図で表示されます
  • 新規参画時のコードベース把握が数分に短縮。「どこに何があるか分からない」問題への即効薬です

ahmedkhaleel2004/gitdiagram

10

⑩Birdview

アーキテクチャ先行▶ 11:07
  • 「AIに blind なコードを書かせない」を掲げ、変更の前にアーキテクチャを地図化するツール
  • リポジトリの構造を俯瞰して把握してから作業に入ることで、影響範囲の見落としを防ぐ設計です
  • GitDiagram が“読む図”なら Birdview は“書く前の図”。README 日本語対応で 608★の新鋭

Qiuner/birdview

⑬rustfs

Rust製 S3互換▶ 08:55
  • Rust で書かれた高パフォーマンスの S3 互換オブジェクトストレージ。3.4万★と急成長中
  • MinIO や Ceph など他のS3互換環境との移行・共存に対応。乗り換えの壁を意図的に低く設計されています
  • Rust らしい高速・省メモリな処理で、AIデータパイプラインやバックエンドの格納先として安定動作

ローカルAI時代の「データの置き場所」を支える一番星。MinIOからの移行もスムーズだよ。

rustfs/rustfs

14

⑭Supabase

Postgres開発プラットフォーム▶ 09:41
  • 専用の Postgres データベースを提供する開発プラットフォーム。Web・モバイル・AIアプリのバックエンドとして定番化。11.1万★
  • オープンな Postgres を土台に、認証ストレージRealtimeEdge Functionsを一体化。Firebase の代替として紹介されます
  • CLI でローカル開発→クラウド展開がそのまま繋がる。「DB に縛られない」選択肢として開発者の信頼を集める存在です

⑮bend（Bend 2）

証明でAIミスを防ぐ言語▶ 03:41
  • Bend 2 は「証明」によってAI的なミスを防ぐ高速言語。2.3万★
  • 書いたコードが意図を満たすことを証明で保証するアプローチで、AI生成コードの品質という今どきの課題に正面から挑みます
  • インストールは curl 1行。高速な処理系と検証の組み合わせが、次世代の開発言語を提示します
