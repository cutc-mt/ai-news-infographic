序章: 冒頭の4人トークはどう作った？

①

オンライン打ち合わせの正体

  • 水野さん: 進行と司会を担当する頼れるまとめ役
  • 田中君（AD）: 冒頭でミュート解除を忘れるおっちょこちょい
  • 坂口さん: 「今日は何でも突っ込ませてもらいます」というツッコミ担当
  • 実はこの3人の声、すべてAIが生成した声でした
あきらパパさんの「本物の声」を含めて4人。ミュート忘れだけはAIのせいじゃない!? と種明かしで笑いに。
②

3人の声は「文字」から作った

  • 使ったのはGemini 3.8 Flash TTS。テキストから音声を生成するモデルです
  • キャラ設定の文章を渡すだけで、しゃべり方まで含めて声が完成
  • この打ち合わせを「作った順番どおり」に動画内で全工程が解説されます
例: 「大阪出身・40代のお笑い芸人。ネイティブの大阪弁を早口のツッコミで話す」→ これだけで坂口さんの声に！
③

今日の問いと5つの検証

  • 問い1: AIの声だけで番組は作れるのか？
  • 問い2: そのとき自分は何をすればいいのか？
  • 検証1 コードなしで作れるか（AI Studio）
  • 検証2 前のモデルと何が違うか
  • 検証3 自分のアプリに組み込めるか（API）
  • 検証4 4人はどう繋いだか
  • 検証5 仕事で使えるか
1つずつ「判定」を付けながら進めるのが、この動画の痛快なところです。
④

最大の変化は「声の在庫」

  • 前のモデル: 用意された30の声から選ぶだけ
  • 今回: ライブラリの声が2,000以上に増加
  • 欲しい声がなければ、言葉で注文して新しく作れる時代に
  • 声のデザイン（発注）は約1分で足ります
「声を選ぶ」から「声を発注する」へ。ここがGemini 3.8 Flash TTSの最大の目玉です。

検証1: コードなしで作れるか（AI Studio）

⑤
判定 ◎

AI Studioの画面の流れ

  • Google AI Studioを開き、左メニューからプレイグラウンドへ
  • 「文章を自然な声に」の画面でCreate new dialogを押す
  • セリフ枠に台本を入力（まだただの文章の状態）
  • 隣のスタイルで「明るく少し早口で」など話し方を指定
  • エクスプレッションで笑いやため息の合図を文の途中に挿入
  • Add speech blockで2人目のブロックを追加（色はオレンジに変化）
スタイルの選択肢には「ささやき」「フレンドリー」「ナレーション」「プロモーション」「ポッドキャスト」などが並びます。
⑥

スピーカー設定と声の検索

  • 声を変えたいときはスピーカー1のボタン→ 右側のスピーカー設定へ
  • 検索窓には2,000以上の声が表示され、言語や用途で絞り込める
  • 既存の声から選んでもよし、なければ新しい声を作ることも可能
「日本語」「ポッドキャスト向き」などで絞れるので、2,000声の海で迷わずに済みます。
⑦

実演: 「ラジオDJヒカ」を作る

  • 右上のNew voice → Voice designを選択
  • 名前: ラジオDJヒカ（説明は日本語でOK）
  • 説明文: 「深夜ラジオの人気DJ・30代の女性。明るく少しハスキーな声でテンポよく語りかける」
  • Generate voiceを押すと約30秒で候補が3つ並ぶ
  • 聞き比べて一番近いものを選び、Continue → Use voiceで確定
最後に右下のRun command（Enterでも可）で数秒待てば、下にプレイヤーが出て完成です。
⑧

Get Code と1つの伏線

  • 右上のGet codeで、今の設定がPythonコードとして出力される
  • セリフと声の名前はコードに含まれている
  • ただしスタイルに書いた話し方はコードに出てこない…！
  • この伏線は検証3（API）で回収されます
「え、画面で効いてた演出がコードにない！？」──このギャップがAPI解説への見事な引きになっています。

検証2: 前のモデルと何が違うか

⑨
判定 ◎

違うのは「演技」の3点セット

  • 演技の細かさ: 笑いや間（ま）の演技が本物っぽくなった
  • 声の高さの選び方: キャラに合う高さを細かく指定できる
  • 気遣い: 相手に合わせた話しぶりの余裕が出た
  • これらは前のモデルにはなかったもの
検証トークでは「3.8のはぁ〜は本物やったな。俺より生き生きとうまいやん」とAI同士で褒め合う一幕も。

検証3: 自分のアプリに組み込めるか（API）

⑩
判定 ◎

準備は2ステップ

  • ターミナルで pip install google-genai
  • APIキーはAI Studio右上の鍵アイコンから作成し、環境変数に入れる
  • VS Codeで作った hello_tts.py は30行もないコンパクトさ
pip install google-genai
export GEMINI_API_KEY="（AI Studio右上の鍵から作成）"
python hello_tts.py
コードを書かない方は画面の流れだけ見ればOK、という優しい導入です。
⑪

話し方はセリフの「外」へ書く

  • 本文の頭に「明るく言って」と書いて送ると…そのまま読み上げてしまう
  • 「明るく言って、こんにちは。あらパパです。明るく言いました」という残念な結果に
  • 解決策: 話し方はスピーチメタデータというセリフとは別の欄に書く
  • ここさえ守れば迷わない: 本文には読ませたい言葉だけ
AI StudioのGet codeに出なかった「話し方」の正体が、ここで回収されました。
⑫

2人の会話モード

  • speakersにセリフと話し方を添えて会話を作れる
  • 会話モードはconversational、声はKoreとCharonを指定
  • 1回のリクエストで話せるのは2人まで（ここが後の検証4の壁に）
resp = client.models.generate_content(
  model="gemini-3.8-flash-preview-tts",
  contents=[role_a_line, role_b_line],   # 2人のセリフ
  config={
    "response_modalities": ["AUDIO"],
    "speech_metadata": {"style":
      "明るくワクワクした調子で"},       # 話し方はセリフの外へ
  })
実行すると「蒼太さん、新しい声のモデルもう試しました?」「試しましたよ。正直びっくりしました」というトーク音声が完成します。
⑬

声のデザインもコードから

  • voices.create に説明文を渡すだけでOK
  • 返ってくるのは声のIDとサンプル音声
  • 音声はWAV形式なので、そのまま保存して再生できる
  • 結果: 30秒で組み込めた
1人分・2人分の声なら、このレシピだけで作れる──検証3の判定は◎でした。

検証4: 4人はどう繋いだか

⑭
判定 ◎

「2人まで」の壁を破る

  • AI Studioで3人目のブロックを足そうとすると、スピーカー1に戻ってしまう
  • 4人を1度のリクエストでは呼べない
  • 解決策: 台本を2者の組み合わせで分ける
  • 2人が続けて話すところは2人分のリクエスト、1人の部分は1人分のリクエスト
冒頭の打ち合わせは「私の実声 + AIの声3人」の4人。部分部分を作って最後に組み立てます。
⑮

自分の声を入れる2つの道

  • Geminiでも自分の声を複製できる（ボイスレプリケーション）
  • 見本の声は10〜30秒＋声の持ち主が同意を読み上げた録音が必要
  • 作った声には透かしが入る＝誰かの声を勝手には作れない設計
  • 今回はfish audioという別の音声AIで、自分の声から作成
同意録音と透かし──声の権利を守る仕組みが標準で入っているのは大事なポイントです。
⑯

FFmpegで「間」まで設計する

  • 部品はFFMPEG（無料の音声編集ツール）でつなぐ
  • 返事の間は0.2〜0.4秒を基準に設計
  • 田中君のミュート沈黙は2秒の演出だった！
  • 一行直せばその部分だけ作り直して再接続できる
# 部品をつなぎ、間（ま）も添えて
ffmpeg -i a.wav -i b.wav -filter_complex \
 "[0:a]apad=pad_dur=0.3[a0];[1:a][a0]concat=n=2:v=0:a=1"
 out.wav
台本と間（ま）──ここが作り手の腕の見せどころ。判定は「作れる・繋げる」で◎です。

検証5: 仕事で使えるか

⑰
判定 ◎

料金と5つの実務ユースケース

  • 10分の音声で約0.135ドル、Flash-Liteなら約0.09ドル
  • 計算: 600秒 ÷ 10秒 × 10秒あたりの単価
  • 2027年1月から単価は2倍予定 → 今年のうちが試しやすい
  • マニュアル動画の多言語版: 英語原稿を渡せば同じ声の調子で130言語対応
  • ブログ記事を2人の対談に: 台本化して聞き役・話し役へ。通勤中に聞ける番組に
  • 子供向けの読み聞かせ: おばあちゃんと小さな竜など、登場人物ごとに声をデザイン
  • お店の電話受付: 営業時間と空き状況を落ち着いた声で。聞き取りやすさ重視ならLiteで十分
  • 語学の会話練習: 同じ一文をアメリカ／イギリスのアクセントで。アクセントまで言葉で指定できるのが今回の強み
「経費精算は月末までに申請してください / Please submit expenses…」日本語も英語も同じ1人の声で読むので、マニュアルの雰囲気が揃ったまま。
⑱

結論: あなたの仕事は「演出家」

  • 検証1: コードなしで作れた（AI Studio）
  • 検証2: 違うのは演技の細かさだった
  • 検証3: 30行で組み込めた（話し方はメタデータへ）
  • 検証4: 2人ずつ作って自分で繋いだ
  • 検証5: 仕事にも使える（5例とも今日の道具だけで可）
  • 共通の教訓: 台本は自分、声はAI
  • 自分は演出家になる: 何を言わせるか・どう言わせるか・どこで間を取るか
  • それを決めた瞬間、AIの声はあなたの番組になります
新しい道具が出るたびに全部試さなくて大丈夫。まず1人、声を作ってみるのが1番早い理解です。…そして田中君、最後はちゃんとミュート外れてました。
