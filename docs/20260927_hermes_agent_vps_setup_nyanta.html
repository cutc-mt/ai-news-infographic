Hermes Agentの全体像

1
1/18

①Hermes AgentはAI秘書として動く

  • 米国のNous Researchが開発した、自己改善するAIエージェントです
  • にゃんたさんが注目する理由は、AI秘書のように振る舞ってくれる点にあります
  • 自分の仕事を覚えさせて、業務の効率化に活かすのが基本的な使い方です
「エージェント」とは、指示を待つだけでなく自分で考えたり、覚えたりするAIの仕組みのことです。
2/18

②単なるモデルではなく「動かす仕組み」

  • Hermes AgentはAIモデルそのものではありません
  • 正体は、AIを動かすためのハーネス（胴輪）と呼ぶ仕組みです
  • モデル・記憶・ツール・チャット界面を、ひとつの骨組みにまとめています
馬で例えると、モデルが馬で、ハーネスが人と馬をつなぐ道具。うまく制御するのがHermes Agentです。
3/18

③学習ループが内蔵されている

  • 経験からスキルを自動作成し、使いながら改善を重ねます
  • 定期的なナッジ（合図）で、大事な知識を記憶に残すよう自分を促します
  • セッションを重ねるごとに使い手の人物像が深まっていく設計です
使えば使うほど、自分専用に育つのが最大の魅力とのこと。

Claude Codeとの違いと導入の判断

2
4/18

④Claude Codeとの違い

  • Claude Codeは開発支援に特化した、いわばコーディングの相棒です
  • Hermes Agentは開発以外の秘書業務・自動化全般を担う方向性です
  • 自己学習の作りも違い、Hermesは動かし続けることを前提にしています
端末でコードを書くならClaude Code、仕事を任せて育てるならHermes、という住み分けです。
5/18

⑤デメリットも正直に解説

  • 動き続ける分、APIの利用料金が発生し続ける点には注意が要ります
  • 仕組みの理解がある程度必要で、最初は学習コストがかかるとのこと
  • 自律的に動くぶん、権限の管理と確認の仕組みを押さえることが大切です
「良いことずくめ」ではなく、費用と手間の両面から判断する動画になっています。
6/18

⑥導入前にそろえる条件

  • 利用するにはモデルのAPIキーなどの準備が要ります
  • Nous PortalやOpenRouterなど、複数のプロバイダーから選べる設計です
  • まずは自分のパソコンで試して、慣れてから本格運用へ進むのがおすすめ
動画前半はデスクトップ、後半はVPS。段階を踏む構成なので初心者でも追いやすいです。

操作方法とデスクトップアプリの導入

3
7/18

⑦操作方法は3つの入口

  • CLI：端末に向かってコマンドで対話する形式です
  • Desktop：アプリを起動して、画面から操作できます
  • Slack：チャットツール経由で話しかける方法もあります
公式によるとTelegramやDiscordなど20以上のプラットフォームに対応しているそうです。
8/18

⑧Desktopアプリの導入手順

  • 公式サイトからインストーラーを入手して実行するだけです
  • 自分のパソコンで動かすので、最も手軽に始められる方法です
  • セットアップではChatGPTなど既存サービスとの連携も扱います
# Linux / macOS / WSL2 の場合はこちら
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
WindowsとmacOSなら、公式サイトのインストーラーを落として実行するだけでOKです。
9/18

⑨ポータルひとつで初期設定が完了

  • hermes setup --portalコマンドで初期設定を進めます
  • OAuth認証を一度通すだけで、モデルと4種類のツールがそろいます
  • ウェブ検索・画像生成・音声読み上げ・ブラウザ操作が最初から使える状態に
面倒な鍵の管理がいらないのは、初心者にうれしい設計ですね。

記憶とスキルで自分専用に育てる

4
10/18

⑩人格と記憶は「ファイル」でできている

  • SOUL.md：人格や話し方の軸を定義するファイルです
  • AGENTS.md：守るべき作業ルールを書いておく場所です
  • MEMORY.md：経験を書き足していく、いわば日記帳です
人格も記憶もテキストファイル。だからこそ、中身を見て直せるのが面白いところ。
11/18

⑪標準スキルと自己学習の流れ

  • 最初から標準スキルがひとそろい入っています
  • 作業を重ねると、独自の手順が新しいスキルとして保存される仕組みです
  • スキルは持ち出し可能な形式で、コミュニティーでの共有もできます
覚えた仕事のやり方を、他の人のHermesでも使えるのが開放的ですね。
12/18

⑫プラグインと拡張の自由度

  • プラグインを足せば、対応する機能を後から拡張できます
  • MCPという外部ツール接続の規格にも対応しています
  • 60種類を超える内蔵ツールが、最初から利用可能です
土台がしっかりしているので、必要になったら足す。拡張の考え方がわかりやすい設計です。

VPSで24時間稼働する環境づくり

5
13/18

⑬24時間動かす意味と自動化

  • 自分のパソコンと違い、VPSなら寝ている間も動き続けます
  • cronで時刻を指定した定期タスクを組み込めます
  • 定期的に自分で目覚めて作業するハートビートの仕組みもあります
朝のニュースまとめや、昼の予定の確認を任せる使い方が想像できますね。
14/18

⑭HostingerのVPSで運用する

  • 動画ではHostingerのVPS料金と、必要性を比較して解説します
  • 実演では画面を見せながら、Hermes Agentをデプロイする手順を進めます
  • 公式の説明でも、月額数ドルクラスの安いVPSで動くと紹介されています
高価な機材は不要。「安いサーバーに置いて放置」が現実的なラインです。
15/18

⑮リモート接続とモデルの設定

  • SSHでVPSに接続して、インストールと初期設定を進めます
  • どのモデルを割り当てるかも、設定ファイルで自由に選べます
  • 公式には7種類の実行環境（Docker・SSH・サーバーレスなど）が紹介されています
使わない間は眠って費用がほぼゼロになる、サーバーレスな選択肢もあるそうです。
