GitHub週間トレンド総ナメ — 20の注目オープンソースプロジェクト

TensorFlow・PyTorch・LLVM・Univer・quiche・ZCodeから最新エージェントツールまで | Manu AGI #295
2026年9月28日

①Paperclip: エージェントの「会社」を自前サーバーで運用

  • オープンソースのセルフホスト型アプリで、AIエージェントのチームを統括。
  • 「エージェントが社員なら、Paperclipは会社」——Node.jsサーバー＋Reactダッシュボードがエージェント群を指揮して業務を回す。
  • エージェントは任意のプロバイダ・ランタイムを持込みOK。目標を割り当て、予算を設定し、作業とコストを追跡。
  • タスク管理に加えて組織図・ガバナンス・承認ゲート（ロールバック付き）・監査ログを装備。Postgres上でセルフホスト可能。
「エージェントの勤務管理システム」——会社 metaphor がすべてを語るユニークな設計だよ！

②Univer: AIエージェント時代のフルスタック・オフィスフレームワーク

  • スプレッドシート・ドキュメント・プレゼンをWebとサーバーの両方で扱うオープンソースのフルスタックフレームワーク。
  • シートは数式・ピボットテーブル・チャート・条件付き書式まで対応。ドキュメントはテキスト・表・コメント、さらにスライド・キャンバス・リレーショナルテーブル・PDFも。
  • Node.jsでヘッドレス実行でき、計算処理をサーバー側で回せるのが特徴。
  • プラグインシステム・レンダリングエンジン・数式エンジン・ファサードAPIで拡張自由。リアルタイム共同編集とインポート/エクスポートも標準装備。
「AIエージェントのためのオフィス runtime」を標榜するのが今どきっぽいね！

③TensorFlow: 機械学習のエンドツーエンド基盤（元Google Brain）

  • Google Brain発の機械学習向けエンドツーエンド・オープンソースプラットフォーム。
  • 研究から本番まで、モデルの構築・学習・デプロイを支えるツールとライブラリの生態系を提供。
  • Pythonの高レベルAPI（Keras）でモデルを定義し、CPU・GPU・TPUで実行可能。
  • Python/C++ APIに加え、ブラウザはTensorFlow.js、スマホやIoTはTensorFlow Liteでカバレッジ。
  • pipでインストールしてすぐ学習開始できる手軽さも魅力。
定番中の定番——IoTからクラウドまで「どこでも動く」が売りの老舗だよ！

④Buzz（Block）: 人間とAIエージェントが同棲するワークスペース

  • Block（Square/Cash Appの親会社）が公開したセルフホスト可能なワークスペース。
  • 人間とAIエージェントが自分が所有するリレー上の部屋を共有する設計。
  • Nostrリレーとして動作し、メッセージ・リアクション・ワークフロー・レビューなどの全イベントが単一ログに署名付きで記録——統一IDと監査証跡を実現。
  • エージェントは自分の鍵でチームメイトのようにチャンネルに参加し、リポジトリを開き、パッチを送り、コードレビューし、ワークフローを実行。
「全員が同じ部屋で、すべての行動に署名が付く」——透明性の作り方が独特だね！

⑤LLVM: 多言語コンパイラを支えるモジュラー基盤

  • モジュラーで再利用可能なコンパイラ＆ツールチェーン技術のオープンソースコレクション。
  • 中核は共通の中間表現（IR）と、それをオブジェクトファイルへ最適化するツール群——アセンブラ・逆アセンブラ・ビットコード最適化器。
  • ClangフロントエンドがC・C++・Objective-CをIRにコンパイル。
  • さらにLLDリンカ・LLDBデバッガ・libc++標準ライブラリ・MLIR（C++実装）が同梱。
  • 多数の言語・プラットフォームのコンパイラを支える、業界の基盤技術。
SwiftやRustの裏にもLLVM——知らずに使っている開発者は相当多いはず！

⑥GitHub Actions Runner Images: CI用VMイメージのビルドソース

  • GitHubホステッドのActionsランナーVMイメージとAzure Pipelinesエージェント用イメージをビルドするオープンソース。
  • 各イメージはUbuntu・Windows・macOSごとに、CIジョブが必要な言語・SDK・ツール・パッケージをプリインストール済み。
  • おかげでワークフローが毎回ゼロからインストールせずに動く。
  • イメージは週次で再ビルドされ、-latestタグが現行リリースを追跡、フィードバック用のベータイメージも提供。
  • 「ランナーに何が入っているか」を確認したいときの一次情報源。
CIが遅い原因やツールのバージョン違いを調べるとき、この repo を開くと解決することが多いよ！

⑦Claude for Financial Services: 金融業務向けエージェント集

  • Anthropicが公開した、金融ワークフロー向けのエージェント・スキル・データコネクタのリポジトリ。
  • 投資銀行・株式リサーチ・プライベートエクイティ・ウェルスマネジメントを想定。
  • 財務分析プラグインはcomps・DCF・LBO・3表モデルに対応し、エージェントとMCPコネクタを同梱。
  • 中身はプレーンなMarkdownとYAML——編集しやすく、プラグインとしてインストール可能。
  • エージェントの役割は専門家がレビューする成果物のドラフト作成であって、助言そのものではない点に注意。
「プロがレビューする前提のドラフト生成」——責任の切り分けがはっきりした設計だね！

⑧PyTorch: GPU加速のテンソルと動的ニューラルネット

  • テンソル計算と深層学習のためのPython製OSSライブラリ。
  • NumPyライクなテンソルがCPUでもGPUでも動作し、テープ方式の自動微分でNNを構築。
  • 「定義して実行（define-by-run）」設計で逆モード自動微分を採用——ネットワークの挙動を実行中に変更でき、再ビルド不要。
  • NumPyやSciPyのライブラリを再利用可能で、C++やCUDAで拡張もできる。
  • 研究から本番まで使える深層学習プラットフォームの代表格。
「書いた通りに動く」直感性が研究者に愛される理由——TensorFlowと並ぶ二大巨頭だね！

⑨quiche: CloudflareのQUIC/HTTP3実装（Rust製）

  • CloudflareによるQUICトランスポートプロトコル＋HTTP/3のオープンソース実装（IETF仕様準拠）。
  • 低レベルAPIでQUICパケット処理と接続状態管理を提供し、ソケットとイベントループはアプリ側に任ける設計。
  • Rustで書かれたHTTP/3モジュールには薄いC APIが付属し、libquiche.aとしてC/C++アプリにリンク可能。
  • TLSハンドシェイクにはBoringSSLを使用。
  • Cloudflare自身のHTTP/3スタックを支え、curlにもHTTP/3機能を提供している実績のライブラリ。
Webの配信インフラを支える縁の下の力持ち——「キッシュ」と読むよ！

⑩オープンルーター（Tre）: エージェントツールを1呼び出し単位で課金

  • AIエージェントに有料・ゲート付きツール群へのアクセスを与えるオープンソースのゲートウェイ。
  • 個別契約が必要なAPIをまとめて提供し、1呼び出しあたり1セント未満の端数課金を実現。
  • カタログのAPIは専用キーで利用、プロバイダー契約不要のパブリックルートも用意——匿名呼び出しは無料。
  • チームメイトは自分のツールをAPIアカウントやOAuth設定で登録可能。
「ツールのサブスクを何本も契約する」時代の出口戦略っぽい仕組みだね！

⑪Archify: コードベースを検証済みの対話的ダイアグラムへ

  • コードベースやシステム記述をインタラクティブな図に変換するオープンソースのエージェントスキル。
  • Cursor・Claude Code・Codex CLI・OpenCodeで動作。
  • システムやリポジトリを記述すると、検索・共有できる自己完結型のHTMLマップを生成。
  • 図の種類はアーキテクチャ・ワークフロー・シーケンス・データフロー・ライフサイクルの5種。
  • ノードは根拠のある事実に基づき、トポロジーを捏造しない設計。エクスポート前に図を検証し、PNG・SVG・WebM出力に対応。
「AIが図を作るけど、根拠のない線は引かない」——ハルシネーション対策が売りだね！

⑫OpenMake: ワンクリックでAIマルチエージェント教室を生成

  • トピックや教材からAIが教えるレッスンを生成するオープンソースプラットフォーム。
  • 学びたい内容を記述するか、PDF・スライド・音声・動画を添付するだけ。
  • 2段階パイプラインでアウトライン→授業を構築。
  • AI教師は音声ナレーション・スポットライト・レーザーポインタで講義。自動採点クイズや物理シミュレータなどのHTML実験で体験学習。
  • プロジェクトモードではAIエージェントと並走して制作できる。
「教材を投げたら授業ができあがる」——教育×エージェントの最前線って感じ！

⑬コーディングエージェント支援: 「結論ファースト」スキルとCursor Plugins

  • 「8HD」系スキルは、コーディングAIが長い前置きで答えを埋もれさせるのを防ぐ OSS スキル。
  • 「次に取るべき行動」を冒頭に提示し、多段階タスクに番号・リスト上限・具体的な所要時間を付け、最後を明確な次の一手で締める——10のルールで構成。
  • Cursor Pluginsは、Cursorのプラグイン仕様と公式プラグインの公開場所。各プラグインは独立ディレクトリ＋マニフェストで、スキル・エディタルール・MCPサーバー定義を同梱可能。
  • 公式プラグインの例: 継続学習（agents.mdへのメモリ書込み）・PRレビューのキャンバス表示・並列エージェントへのタスク分散・SDK開発用プラグイン。
出力の「読みやすさ」をルール化しちゃう発想、地味だけど効きそうだね！

⑭Company Brain: チームの全記憶を持つSlackの同僚AI

  • Slack上でチームの発言と仕事をすべて記憶し、作業もこなすオープンソースのAIチームメイト。
  • 元はSupermemoryの商用製品だったが、自分のCloudflareアカウント上で動かせる形で公開。
  • 参加チャンネルから意思決定・プロジェクト・担当者の最新状態を維持し、その記憶から回答。知っていることがあれば自発的に発言する。
  • 記憶は権限グラフとして管理され、聞いた人のアクセス権限しか参照できない——権限の昇格なし。
「便利さ」と「権限の厳密さ」を両立させた設計が商用出身ならではだね！

⑮決定モデル特集: AlleiaとTogether AIのTAV1-4B

  • Alleiaは、オープンな決定モデルをローカル実行するツール——いわゆる「決定モデル版Ollama」。
  • 状態（メッセージ・メール・チケットや任意のJSON）と型付き質問を与えると、テキストを生成せず1順伝播で較正済み確率を返す。
  • LeiaやDeciderなどのモデルを名前指定で取得し、ローカルデーモンの型安全なAPIから提供。変数1つで切り替え可能で、MCPサーバー経由でエージェントにも公開。
  • TAV1-4B（Together AI）はQwen 4Bベースのクイズ番組風の実験的オープンウェイト決定モデル。文脈と質問、2〜24個の選択肢を与えるとルーティング・分類・トリアージ用に1文字の答えを返す（雑談向けではない）。
  • データレシピ・学習例・結果を同梱しファインチューニング可能。重みはHugging Face公開だが実験段階で、高リスク判断の単独判断には使わないこと。
「文章を生成しないLLM」——確率だけを返す決定専用モデルという新ジャンルだよ！

⑯Leia MLX: Appleシリコンで動く決定モデルランタイム

  • Appleシリコン向けのLeia系決定モデル用ネイティブMLXランタイム。
  • テキスト生成なし・PyTorchなし・クラウドAPIなしを明言する潔い設計。
  • 選択・ルーブリック採点・確率が必要な場面で、トークンのデコードもJSON出力もなしに制約付きの質問へ1順の方向伝播で回答。
  • 状態＋型付き質問をエンコーダ経由で決定ヘッドへ通じて確率として出力。MLXへの独立ポートで、FP16チェックポイントをHugging Faceで公開。
Mac内で完結する「即断」専用エンジン——省電力でプライベートなのが強みだね！

⑰Unreal Agent: 非同期・クラッシュ安全なGo製ハーネス

  • Unreal LabsによるGo言語製の非同期ファースト・エージェントハーネス。
  • すべての入力を安定した一意IDを持つイベントとして扱い、重複を排除。
  • 追記専用のセッション履歴はフォーク可能で、クラッシュしても続きから再開できる。
  • コーディネータがLLMの各ターンを管理し、ツールはスキーマ記述→検証→操作への変換、実行トレースは分離記録。
  • 目的はエージェントの信頼性向上とランニングコスト削減。
「落ちても止まらないエージェント」——長時間運用の肝は結局ここだね！

⑱ZCode（Z.AI）: デスクトップ・Web・ターミナルで動くOSSコーディングエージェント

  • Z.AIが公開したオープンソースのコーディングワークスペース＆エージェントハーネス。
  • デスクトップ・ブラウザ・ターミナルの3インターフェースを備え、リポジトリにはクライアント・バックエンド・共有UI・エージェントCLIとランタイムを収録。
  • ターミナルではzcodeコマンド一発でTUIが起動。--webでWeb UIを開き、引数でエージェントに指示。Electronなしで全部ローカル動作。
  • 公式＋コミュニティのプラグインマーケットプレイスで拡張可能——クラウド開発・セキュリティ・GitHubワークフローなど幅広くカバー。
  • 今週の目玉の一つ。セルフホスト派のコーディングエージェント選択肢がまた増えた。
CLI派・GUI派どちらにも優しい構成——ローカル完結で試せるのが嬉しいね！
