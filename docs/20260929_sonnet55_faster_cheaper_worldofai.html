Sonnet 5.5 は Opus 5.5 より速く・安く・強い？ 何が起きているのか

① DevDay 前日の強襲リリース

  • Anthropic がSonnet 5.5を月曜日にリリース。火曜日は OpenAI DevDay。
  • 強力な新モデルの投入で、OpenAI のパーティーを少し台無しにしたい意図が見えるタイミング。
  • 公称スペック通りならかなり競争力のあるモデルだと言える。
ライバルの晴れの前日に発表——AI業界の宣戦布告はもう定番の一手なんだね！

② 何が新しい？ 高速化と低価格の「Sonnet 高速版」

  • 旧 Sonnet 5 よりはるかに高性能でありながら高速化。モデル効率が向上。
  • ほとんどの作業でコストが約30%安くなる価格設定。
  • 近年の Anthropic の方向性。Opus 5.5でも前世代比 約20%の値下げを実施済み。
  • 今回は30%と、さらに攻めた価格設定になっている。
「速い・安い・賢い」の三拍子——利用者には大歓迎の方向性だね！

③ TerminalBench 4.0: Sonnet 5.5 が Opus 5.5 を超える

  • Sonnet 5.5 は TerminalBench 4.0 で 70.6% を記録。
  • Opus 5.5 の 66.4% を上回るスコア。
  • ただし注意点: Opus 5.5 の数値は最高スコアが報告される「極めて高い負荷」設定でのもの。
  • ベンチマーク側がなぜその設定でモデルを微調整したのかは興味深いところ。
下位モデルが上位モデルを超える——でも条件書きはしっかり確認しよう！

④ FrontierCode 1.1 では Opus 5.5 が優位

  • FrontierCode 1.1 最大値: Sonnet 5.5 は 46.2%。
  • 対する Opus 5.5 は 54.4% を記録し、こちらは明確に Opus 5.5 が上。
  • つまりベンチマークによって優劣は入れ替わる。一つの結果だけで判断しないこと。
得意・不得意があるのはモデルも人間も同じ。用途に合わせた選択が大事！

⑤ Sonnet 5 ユーザーにとっては祝日

  • Sonnet 5.5 は Sonnet 5 より賢く、少し安価。普段使いには純粋な向上。
  • Sonnet 5.5 は Sonnet 5 と同じ価格設定。
  • 同じ作業に必要なトークン数が通常かなり少なくなるため、理論上はさらに安い。
  • タスクあたりコストは最大30%削減、出力速度も30%以上向上で最速の Sonnet に。
設定価格が同じでも消費トークンが減れば、実質的な値下げになるんだね！

⑥ デモ① 圧倒的な出力の高速化

  • 画面上で 左: Sonnet 5 / 右: Sonnet 5.5 を並べて比較。
  • Sonnet 5.5 の出力はあらゆる面で Sonnet 5 よりはるかに高速。
  • 使用トークン数も大幅に少なく、少ないトークンで高品質な出力を達成。
目に見える速度差にトークン削減——効率化の実感がすごいデモだ！

⑦ デモ② 絵の再現度が別次元に

  • 両モデルに同じ絵を描かせるテスト。Sonnet 5 の結果は「まあまあ」。
  • Sonnet 5.5 の出力レベルと詳細さはSonnet 5 とは明らかに別次元。
  • 実写真との比較では Opus 5.5 の出力が最高。
  • ただ Sonnet 5.5 は多くのケースでOpus 5.5 レベルに匹敵しつつ、少ないトークンで処理。
旗艦に迫る品質をコスパ良く——これが「期待の理由」そのものだね！

⑧ デモ③ 走る動物——未解決テストでの進化

  • きれいに走る動物の映像は、どのモデルもまだ完全に解決できていない難問。
  • Sonnet 5（上部）はかなりブロック状の見た目。
  • Sonnet 5.5（下部）は明らかに滑らかさが向上。
  • 今後の新モデル評価にも使える継続テストになるだろう。
全問正解じゃなくても、進歩の度合いを測れる課題は貴重なんだね！

⑨ デモ④ ルービックキューブ: 時間も費用も勝つ

  • Claude 管理エージェントが1オーケストレーター＋4並列エージェント構成で挑戦。
  • Sonnet 5.5 は10秒で完了、コスト約11セント。
  • Sonnet 5 は15秒で完了、コスト15セント。
  • ほとんどのユースケースで時間と費用の両方を節約できると明確化。
速くて安いのは売り文句じゃなくて、実測でも証明されたってこと！

⑩ Artificial Analysis 指数: 前モデル比で大きく躍進

  • Artificial Analysis 指数で前モデル（スコア38）から大きな飛躍。
  • 新しい Sonnet 5.5 はスコア56で2位を獲得。
  • 同社の別モデル（53）より3点高く、最上位の Opus より約2点低い位置。
  • 現在 1位・2位・3位を Anthropic が独占。次点は OpenAI のモデルで、厳密には3位と同率。
上位をひとつの会社が独占するのは異例——Anthropic の絶好調が数字に出てる！

⑪ コスト vs スコア: 理想は「高スコア・低コスト」象限

  • 目指すべきはタスクあたりコストが低く、スコアが高い領域。
  • Sonnet 5.5 は高スコア側だが、ほとんどの面で依然として少し高コストな位置。
  • GPT-4o は最も魅力的な象限に位置し、効率比較では Sonnet 5.5 が高価な部類。
「賢い」だけじゃなく「1ドルあたりの賢さ」で見るのが本当の評価なんだね！

⑫ 裏の顔: 計測史上最重のトークン消費

  • Artificial Analysis チーム自身の指摘: 最大性能で最上位モデルに迫る際、計測史上最も重いトークン消費。
  • インデックスのタスクごとに 19万3000トークンを出力（計測史上最大）。
  • 最上位モデルの最大値より約60%多い消費。
  • 「トークンあたりの知能」で測るとそれほど賢くない可能性。理論上は安くても運用では違うかも。
公称30%安いのに、最後の一滴を絞ると爆食いする——ここが矛盾する情報の正体！
