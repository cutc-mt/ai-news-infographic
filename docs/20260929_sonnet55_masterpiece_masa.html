①開幕の結論: 「これは名作」

  • まさお氏が「マジでめっちゃいいモデル」と断言する Claude Sonnet 5.5 の登場。
  • Opus 5.5全盛の今は「Opusでいいじゃん」と見られがち — ところが一部ベンチマークはOpus超え。
  • 実力はソネット5.6・5.7と呼びたくなるレベルの完成度。
同じ「5.5」の看板でも中身は別物 — それが今回の肝なのだ！

②立ち位置: 最新カットオフの世代

  • ナレッジカットオフは2026年6月と最新系。前世代Sonnet 5は2026年1月。
  • Opus 5.5やフェイブル5.5/5.1と同世代の名前だが、実態は1世代上に感じる差。
  • コストはOpusより安く、気軽に回せる日常主力になれる位置。
エフォートの取り扱いが前世代よりさらに重要になる、それが5.5世代！

③ベンチ①: 通用度が一気に上がった

  • Terminal-Benchは前世代が10%台で「正直使えない」→ 今回は別物。
  • ナレッジワーク系ベンチ: 前世代1400台 → 1844でほぼOpus圏。
  • Humanity's Last ExamやOSWorld(80%級)も強気の数字。
ベンチ全体が「5から5.5」で一段抜けた — 雑談じゃなく数字が語る！

④ベンチ②: コンピューターユース

  • スクショだけでポケモン赤をクリアした初のSonnetと紹介。
  • コンピューターユース系ベンチが1000超えに到達。
  • ボット搭載・outer-loop運用の現実味が一気に増した。
画面を見て操作する系が実用域に — 安いモデルで済むのがでかい！

⑤価格: 「ほぼOpus・半額」の衝撃

  • API単価は入力$2 / 出力$10(1Mトークン) — 予定されていた$3/$15への値上げを回避し現行継続。
  • Opus 5.5比で入出力約半額。キャッシュライトも半額。
  • キャッシュリードはOpusと同額。最大出力は128K。
ロングランのエージェント回すほど効く — キャッシュの内訳まで押さえよう！

⑥スピード: TPSで体感する速さ

  • 前世代Sonnet 5比で約30%高速化。
  • まさお氏の実測はTPS 150〜180、時に300台も。
  • 激速で名高いDeepSeek V4.1(220)・Gemini Flash(250)と戦える域。
「早いと感じるのは200近く」— そのラインを余裕で超えてくるのだ！

⑦エフォート運用術: 使い分けが鍵

  • 普通の仕事はmedium、しっかり=high、難問=xhigh、全力=max。
  • サクッと済ませたい時はlow/medium — それでもlowで前世代の最高点超え。
  • effortでトークン消費が激変。フロンティアコードではmaxが逆効果の場面も。
品質はmedium→highの間で一段上がる — ここをコスパの主戦場に！

⑧表現力: SVGで見る「新世代感」

  • 電気ネズミのSVGアニメ比較で細部まで作り込まれた新世代を直感。
  • GPT-6系など同価格帯と比べても行き届き方が違うと分析。
  • 資料・スライドも初回から「いい感じ」の仕上がりに。
数値より先に「おっ」となる質感 — それが5.5の表情なのだ！

⑨実演①: ゲームで見る品質の階段

  • 宇宙シューティング: low→medium→high→xhigh→maxで光の演出・作り込みが段違い。
  • 迷路ゲーム: high以上は音付き、ボールの物理演出もリッチ。
  • LLMジャッジでもeffortに応じてスコアが積み上がる構図。
同じプロンプトでも努力量で別物 — まずlowで試して階段を上がるのが正！

⑩実演②: LP・大作デモが強い

  • キーボードLP・アイドルLP: Opus 5.5に食らいつく完成度で、色使いが映える。
  • MMORPG風デモ: ローディング演出から裏側の3Dまで作り込み。
  • イヤホンSNS: 「これソネットっすよ」と唸るクオリティ。
ワンショットでここまで — 実演を見ると「5.6」と呼びたくなる気持ちが分かる！

⑪実演③: アーケード勢も仕上がる

  • ピンボール・3Dファイティング・マーブルランを続々生成。
  • アクアリウムのディテールは「今までのソネットと思うと痛い目」レベル。
  • ゴブリンゲームには「もうソネットでこれかよ」と驚きの声。
1〜2年前は不可能だった領域 — ガチで安いから雑に量産できる！

⑫文章力: 見やすさが効く

  • GPT-6系と比較しても見やすさ・読みやすさで優る印象。
  • 哲学・アート論のような読みにくいテーマも比較的平易に。
  • LMジャッジでは87点 — 未来予測系は一部高評価。
数字より「情報が入ってくる感じ」— 文章の気配りも新世代なのだ！

⑬外界の反応: 期待が先行

  • CodeRabbitが「癖が解消」と評価 — よりスマートで高速に。
  • アーティフィシャルアナリシス等でもコスト・品質の良いラインに着地。
  • OpenAI側の新作が乱立する直前の先手の一手にも見える。
「癖がない」は実務で地味にでかい — 外部検証が追いつくのが楽しみ！

⑭運用戦略: ハーネスに組み込む

  • outer-loop・汎用ボットへの搭載が一気に現実的に。
  • ウルトラコード / Best-of-Nの1枠にSonnet 5.5を投入。
  • 分担案: ジェネレーター(80点)をSonnet、イテレーター・プランナーで95点を狙う設計。
「妥協の1手」が「妥協じゃない」に変わる — ハーネス設計がさらに面白く！

⑮注意点: ここはまだ未知数

  • メタ認知・長期運用での認知ドリフト耐性はこれから検証。
  • API仕様が一部変更 — キャッシュを保持したままeffort切替などの新機能に注意。
  • Sonnet 5を組み込んだ既存アプリは移行確認を忘れずに。
賢さは相当でも「自分の限界を知る力」は別枠 — そこは地理を固めて見よう！

⑰次世代を読む: 分担の時代へ

  • Opus 5.6/5.7・フェイブル5.6が来るまでは「Sonnet併用」が最適解。
