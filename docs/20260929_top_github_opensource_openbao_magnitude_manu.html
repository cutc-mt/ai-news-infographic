①hindsight: 学習するAIエージェントに「長期記憶」を

  • 学習するAIエージェント向けのオープンソース長期記憶。
  • コーディングエージェント用には、git履歴と過去セッションからリポジトリごとのメモリバンクを構築し、エージェント起動時に注入。
  • 知識ページ・SDK・REST APIを備え、100以上のモデルをカバーする軽量LLMで記憶を公開・保持・呼出・反映。
  • Claude Code・Codex・Cursor・LangGraph・CrewAIと統合済み。
  • ローカルデーモンが1コマンドで全部実行——インストールしてエージェントに記憶を割り当てるだけ。
「エージェントが毎回記憶喪失で始まる」問題への一本道な解だね！

②NVIDIA Model Optimizer: GPU推論を高速化するモデル圧縮

  • NVIDIA GPUでの推論を高速化するため、モデル圧縮・最適化技術を集めたOSSライブラリ（ModelOpt）。
  • PyTorch / ONNXモデルを入力し、Python APIで技術をスタック可能。
  • 量子化はPTQ・QATでFP8 / INT8 / INT4 / NVFP4に対応し、スパース性・プルーニング・蒸留も組み合わせられる。
  • チェックポイントはTensorRT-LLM・SGLangなどへデプロイ可能。transformers/diffusers向けのHugging Faceエクスポートも装備。
  • pipでインストールしてすぐモデルを最適化。
「GPUはそのまま、モデルを軽くする」——推論コスト削減の王道アプローチだね！

③OpenBao: HashiCorp Vaultからフォークしたシークレット管理 ★

  • 今週の目玉。HashiCorp Vaultからフォークされた、オープンガバナンス下で機密データ・シークレット・証明書・キーを保管・配布するOSSプラットフォーム。
  • 任意のキー値シークレットをディスク書き込み前に暗号化して保存。
  • AWS・SQLデータベース向けにオンデマンドで動的な短期有効の認証情報を生成し、リース後に自動失効。
  • 暗号化 as a serviceで、アプリはキーを管理せずにデータを暗号化可能。
  • 監査ログ・PKI・トランジットエンジンに加え、HSM/KMSでバックアップされたキーにも対応。デプロイして秘密を一元管理。
Vaultのライセンス変更騒動から生まれた「本物のオープン版」——秘匿情報の管理はここに集約だね！

④reverse-skill: リバースエンジニアリング用スキルルーター

  • AIコーディングエージェントをリバースエンジニアリング・承認済みペネトレーションテスト・セキュリティ研究のアシスタントに変えるOSSスキルルーター。
  • エージェントがAPK・バイナリ・フロントエンドJS難読化・CTF・ペンテストタスクに遭遇すると、適切な方法論へ自動ルーティング。
  • Ghidra・Radare2・Fridaなどの定番ツールを呼び出し。
  • ルーティングはクライアント非依存の構成で、スコープと発見事項の読み取り専用ケースレビューレイヤーを搭載。
  • Claude CodeとCursorで動作。インストールしてセキュリティ作業をルーティング。
「守りの専門家」をエージェントにインストールする感じ——脆弱性診断の下働きが捗りそう！

⑤Mobile Next＋vphone-cli: モバイル自動化と仮想iPhone

  • Mobile Next（mobile-mcp）はiOS/Androidのエミュレータ・シミュレータ・実機を横断するモバイル自動化・スクレイピング用MCPサーバー。プラットフォーム非依存の単一API。
  • アクセシビリティ最優先——ビジョンモデルなしでネイティブアクセシビリティツリーからアプリを駆動し、必要時のみスクリーンショット＋座標にフォールバック。
  • フォーム入力や画面からのデータ抽出をLLMが実行。Claude Code・Codex・Gemini・Copilotと連携。
  • vphone-cliはApple Silicon Mac上で仮想iPhoneを作成・実行するCLIツール。Appleの仮想化フレームワークを利用。
  • ファームウェアの準備・復元はバンドルが処理し、ファイル転送・IPAインストール・画面録画・位置情報、オプションのLaunchpad GUIにも対応。
「実機を借りずにアプリ試験」がMac1台で完結——実機farmの置き換えが見えてくるね！

⑥WeKnora: Tencentのドキュメント→知識プラットフォーム ★

  • Tencentが公開したLLM搭載知識プラットフォーム。ドキュメントを知識に変える3つのモードを搭載。
  • ①RAGベースのQ&Aによる検索、②検索・MCPツール・Web検索をオーケストレーションするReActエージェントによる多段階タスク。
  • ③エージェントがドキュメントをナレッジグラフ付きの自己維持型・相互リンクMarkdown wikiへ抽出するwikiモード。
  • 10種類以上のフォーマットを取り込み、Feishu・Notionなどから自動同期。
  • 20種類以上のLLMプロバイダに対応しベクタDBは差し替え可能。Dockerでセルフホストしてドキュメントを質問しよう。
「RAG・エージェント・wiki」の3スタイルを1つに——社内ナレッジの行き先が全部入ってるね！

⑦OpenCodeReview: AlibabaのAIコードレビューCLI

  • Alibaba発のAI搭載コードレビューCLI。
  • 決定論的パイプライン＋LLMエージェントのハイブリッド設計——git diffを読み込み、エージェントがファイル全体を読み、コードベースを検索して変更を検査。
  • 結果は行レベルのコメントとして返却。
  • 多言語ルールセットでnullポインタバグ・スレッドセーフティ・XSS・SQLインジェクションなどを検出し、修正の自動適用も可能。
  • OpenAI・Anthropicと連携し、Claude Code・Codex用プラグインも同梱。インストールしてコードをレビュー。
「ルールで確実に、LLMで文脈を」——レビューの二段構えが地味に効きそうだね！

⑧God's Eye View: 3D地球儀上のライブ空間インテリジェンス

  • ブラウザベースのOSS空間インテリジェンスコンソール。実データを使ったスパイ衛星シミュレーター。
  • 3D地球儀上にライブの航空機・船舶・衛星・山火事・CCTVを重畳表示。
  • グローバルビューと単一オブジェクトを切り替え、追跡中のフライトに「搭乗」したり、あらゆるものにロックオンして軌跡を確認し、最寄りのカメラへ引き渡し。
  • 公開データ上でローカル実行。設計上「人ではなく資産とシステム」を追跡するのが明確なスタンス。
公開データだけでここまでできるのか…！プライバシーへの配慮もポイントだね。

⑨Magnitude: ローカルモデル内蔵・完全オフラインのAIエージェント ★

  • 今週の目玉。推論エンジンでローカルモデル上で動くOSS AIエージェント——トークンコストもAPIキーも不要のプライベート＆オフライン。
  • ハードウェアをプロファイリングしてそのマシンで動くモデルを推奨し、ダウンロード・構成・調整まで自動。
  • llama.cpp上に構築されたRustエンジンが、ロード前にメモリを計算し並列エージェントの応答性を維持。
  • シェル経由でExcel・PowerPoint・PDF・Chromeのファイルやスキルを編集。インストールしてエージェントをローカル実行。
「月額ゼロ・外に出さない」エージェント——機密資料を扱う人に刺さる設計だね！

⑩DeskcommCRM: チャットで売るセルフホストAIセールスCRM

  • チャット営業の企業向けセルフホスト型OSS CRM。Kommo・Octadesk・Intercomの代替を掲げる。
  • WAHA経由でWhatsAppを接続し、セールスパイプライン＋AIエージェントを統合。
  • リードはチャットとフォームから流入し、AIが応答してアポイントメントを予約。人間への引継ぎでボットを停止可能。
  • MCP対応・マルチテナント・自動化・スケジューリング・Googleカレンダー同期・LGPD準拠。
  • 1コマンドでスタックごとVPSにインストール。デプロイしてチャットで売る。
「営業チャットをAIが一次受付」——問い合わせから商談化までの導線がまるごとOSSに！

⑪Soup: 4GBラップトップGPUで8Bモデルをファインチューニング

  • YAMLファイルからLLMをファインチューニングするOSSツール。1つの設定・1つのコマンド・SSH不要。
  • レイヤーストリーミングにより凍結されたベースをVRAMから除外し、デコーダレイヤーを1枚ずつGPUへ供給。
  • その結果、8Bモデルが4GBのラップトップGPUでファインチューニング可能に。
  • バッチ処理と量子化は自動で処理され、チャット・コード・推論・ビジョン用テンプレートを同梱。
  • チャット・マージ・GGUFエクスポートにも対応。1つのファイルから学習を始めよう。
「GPUがないから学習できない」が言い訳にできなくなる1本——省VRAM技術が進化しすぎ！

⑫Compositor: Mac用の無料Photoshop代替 ★

  • Mac向け無料・オープンソースの画像エディター。合成と後処理のためのPhotoshop代替。
  • Photoshopのブレンドモード・レイヤーマスクに加え、カーブ・レベル・グラデーションマップなどの調整レイヤー、ドロップシャドウ等のGPUレンダリングレイヤー効果を装備。
  • レイヤーとフォルダはいつでも編集可能で、移動・拡大縮小・回転は非破壊。
  • ブレンドモードを保持したままPSDファイルをインポート可能。
  • AIエージェントもプロジェクトを作成できる設計。保存形式の.compはPNGレイヤー＋マニフェストのフォルダ。ダウンロードして合成開始。
PSDがそのまま読める無料エディタは貴重——サブスク疲れのデザイナーに届いてほしいね！

⑬Search: macOS用の小さく速いミニマルWebKitブラウザ

  • ツールバーなし・スタートページなし・アカウントなしのmacOS用高速OSS WebKitブラウザ。「タブとページだけ」。
  • 1つのフィールドで全部——アドレスを入力して移動、単語を入力して検索、履歴から補完。
  • 入力は戻るまで送信しない設計。静かなブラウジングを実現。
  • Mac標準のWebKitエンジンのみでアプリわずか3MB。Chromiumを載せないので即起動。
  • パスワードはキーチェーンに保持し、Chrome拡張機能も実行可能。
「ブラウザはもう重くなくていい」——3MBという数字がすべてを語るミニマル路線だね！

⑭qm: YC発・会社全体で使うマルチプレイヤーエージェントハーネス

  • Y Combinatorがオープンソース化し、YC内部でも使われているマルチプレイヤーAIエージェントハーネス。
  • 企業向けに設計され、各従業員に隔離されたワークスペースとスコープ付きのメモリ・ファイル・認証情報・cron、耐久性のあるサンドボックスを提供。
  • 人々はSlackチャンネルやプロジェクトでエージェントと共同作業。
  • 複数のコーディングエージェント（OpenCode・Codex・Claude Codeなど）が同じコアを駆動——ハーネスとモデルを選んで使える。
  • セキュリティスタンスは呼び出しごとの承認からスクリーニングされた自律性まで選択式。ただしまだ初期段階で、クラウドへのデプロイが推奨。
「従業員全員にAI同僚を1人ずつ」——会社の規模でエージェント運用する発想だね！

⑮herdr: コーディングエージェント常駐ターミナルランタイム ★

  • コーディングエージェントのためのOSSマルチプレクサ＆ランタイム。エージェントのターミナルを所有するバックグラウンドサーバー。
  • ラップトップの蓋を閉じても・ネットワークが切れても・再起動してもエージェントは動作継続し、任意のターミナルやSSHから再接続。
  • すべてのペインが作業中・ブロック中・アイドルとしてマークされるため、止まっているペインを探す手間がない。
  • エージェントはCLIとソケットAPIから駆動し、実行内容をそのまま再実行。Claude Code・Codex・Cursorなどに対応。
  • 実体はRustバイナリ1つ。インストールしてエージェントを管理。
「エージェントを閉じても殺さない」——長時間タスクを投げっぱなしにできるのが最大の魅力！

⑯OpenMuse: ブラウザ・ターミナル・ファイル付きのパーソナルエージェント

  • CopilotKit発のOSSパーソナルエージェント。ブラウザ・ターミナル・ファイルを備える。
  • 結果を要求し、計画に従い、結果に戻るというループで動作。
  • サーバーとワーカーを実行し、エージェントにChromiumとLinuxワークスペースを提供——ページ閲覧・コマンド実行・ファイル処理をこなす。
  • いつでもブラウザやターミナルを人間が制御可能。
  • AG-UIプロトコルで通信するためエージェントハーネスを交換可能。iOS・Android・Web用テンプレート付き。
「AIに渡すけど、いつでも手元に取り戻せる」——主導権の置きどころが絶妙だね！

⑰Open Glean: HydraDB上に構築されたAI知識ワークスペース

  • 知識作業向けOSSAIワークスペース。分散データベースHydraDB上に構築され、セルフホスト可能。
  • 記憶・ファイル・接続したアプリを横断して質問すると、コンテキストを取得しインライン引用とソースパネル付きの回答をストリーミング。オプションでWeb検索も。
  • ディープリサーチモードではサブクエスチョンのDAGを計画して並列実行し、調査結果を1つの引用付き回答に統合。
  • OpenAI互換モデルを持ち込み（BYOM）。デプロイして知識を尋ねよう。
「社内のあらゆる知識に、出典付きで聞ける」——引用が出るのがRAGの信頼の要だね！

⑱番外編: BongoCat ＋ mini-AGI — 遊び心と実験の2作

  • BongoCatはキーボードとマウスの入力に合わせて遊ぶデスクトップペット・オーバーレイ。入力とクリックに反応して猫が演奏。
  • SDL3＋OpenGLのC/C++ネイティブアプリで軽量。入力はアニメーション駆動のためローカルで読み取るのみ——キーストロークの記録・アップロードなし、広告・分析・追跡なし。
  • Live2Dモデルをサポート。Windowsで動作し、macOS/Linuxはテスト中。
  • mini-AGIは8GBのノートPC GPUでゼロから学習し、読み込んだデータから継続的に学習し続けるバイトレベル言語モデルの実験的プロジェクト。
  • 重みをディスク上のファイルとして保存し必要時にGPUへページング——モデルのサイズ制限はVRAMではなく空きディスク容量。クローンして学習の様子を見てみよう。
締めは猫と Tiny LM——楽しさと研究の「おまけ」が2つも付いてくる今週のトレンドでした！
