発車前: この列車はどこへ向かう？

①

夜も走り続ける列車の例え

  • 基調講演をリアルタイムで視聴。発表は20を超えるので、スライドの文字と公式ページまで確かめて全体を並べ直した
  • 並べると1本の線（＝大きな流れ）が見えてきた
  • 例えの対応: 列車＝AI 駅＝仕事の手順 指令室の席＝自分
  • 問いはこれ: 「AIは道具から同僚になったのか？」——答えは最後に出します
道具は使うたびに手を動かすもの。同僚は役割を渡すと自分で進めるもの。この差を5つの検証で確かめます。
②

確かめ方は5つ、駅を順に停車

  • 検証1 役割を任せられるか（dots）
  • 検証2 チームに入れるか（ChatGPT Space）
  • 検証3 早く安くなったか（GPT-6.1 Sol・Astra Ultrafast）
  • 検証4 開発者も同じ道具を使えるか（Codex・Agents API）
  • 検証5 作ったものを届けられるか（配布の3ルート）
第1駅 役割
第2駅 チーム
第3駅 速さと安さ
第4駅 開発者
第5駅 配布
5つの駅ごとに○◎△で判定を出していきます。判定の見方はカード右上のラベル。
1

検証1: 役割を、任せられるか（dots）

③

最大の目玉「dots」

  • dotsはChatGPTの中で24時間動き続けるエージェント
  • 名前をつけて使うほど、こちらの働き方を覚えていく
  • 中で動くのはOpenAIで最も賢いモデルAstra
  • 1体ずつ専用のクラウドのコンピューターを持ち、繋いだアプリを自分で操作して作業を進める
「使うたびに手を握る道具」から「働き方を覚える相棒」へ。ここが同僚論の主役です。
④

任せ方が分かりやすかった

  • 例: 古い仕組みからの移行を頼む
  • dotsは繋がりを調べ → 資料を読んで → 計画を立てて → 直して → テストするところまで自分で進める
  • 最後は人が確かめる番
  • 作業を1つずつ頼むのではなく、役割ごと渡す感じ
「この作業やって」ではなく「この係をお願い」——任せ方の単位が変わったのが今回のポイント。
⑤
判定 ○

ただし上のプランから

  • ここは正直にお伝えします: 使えるのはPro・Business・Premium・Enterpriseのプランのみ
  • 無料やPlusのプランではまだ使えません
  • 判定: 任せられる。ただし今は上のプランから → 判定は○（まる）
機能面は合格。ただし乗れる人が限られた特急券なのが実情です。
2

検証2: チームに、入れるか（ChatGPT Space）

⑥

ChatGPT Space という新しい拠点

  • ChatGPT Spaceは、チームのメンバーとdotsとChatGPTが同じ場所で仕事を進める新しい拠点
  • 中心にあるのはリビングページという新しい種類の書類
  • コメントでdotsに声をかけると、その場で作業を始める
  • グラフや表は繋いだツールの情報で自動で最新に保てる
  • スライドもチームとChatGPTで一緒に作れる
⑦

Slack・Teams から直接声かけ

  • SlackやMicrosoft Teamsの中でも、ChatGPTに直接声をかけられるように
  • 講演ではOpenAI社内でdotsが毎日数十件の不具合を直しているという話も
  • これはOpenAI自身の社内事例として聞いておく（一般事例ではない点に注意）
AIとの会話が専用アプリの中だけのものではなくなる。仕事場のチャットに同僚が増えた感覚です。
⑧
判定 ◎

机を並べて働ける

  • 判定: 入れる。机を並べて一緒に働ける
  • この検証は判定◎（二重丸）——5つの中でも最も素直に合格
  • 「リビングページ」という書類の置き場所が共有されたのが大きい
同僚の条件は「同じ部屋で同じ書類を見る」こと。Spaceはまさにそれを用意しました。
3

検証3: 速く、安くなったか（新モデル）

⑨

GPT-6.1 Sol: 賢さのわりに安い

  • 新しいモデルGPT-6.1 Solは、賢さはAstraに近いのに料金は大きく下
100万トークンあたり入力出力
GPT-6.1 Sol2ドル10ドル
Astra10ドル50ドル
  • 講演の料金表では出力はAstraの5分の1
  • ただし公式ページの日本語説明では4分の1と書かれている——動画では公式の料金表の数字を載せています
⑩

Astra Ultrafast という特急

  • Astra Ultrafastは、一番賢いAstraを特急で走らせるオプション
API
最大6倍
Codex
最大8倍
通常のAstraを1とすると、APIでは最大6倍・Codexでは最大8倍の速さに。
  • この特急が使えるのは新しい月500ドルのProプラン
  • もう1つ: あらかじめ決めた選択肢の中から一瞬で判断するAPIも限定プレビューで開始
⑪
判定 ◎

安い賢さと早い賢さを選べる

  • 判定: 安い賢さと早い賢さを選べるようになった → 判定◎（二重丸）
  • 列車の例えだと、各駅停車（安いSol）と特急（Ultrafast）が同じ路線に並んだ形
「賢さ＝高額」だった時代は終わり。目的に合わせて切符を選べるようになりました。
4

検証4: 開発者も、同じ道具を使えるか（Codex）

⑫

Codex がクラウドでも

  • Codexはクラウドでも動くようになりました
  • スマホで始めた作業をパソコンで続けられる
  • しかも全てのプランで使えます
手元の駅（ローカル）だけだった線路が、クラウドという幹線に繋がったイメージ。
⑬

土台ハーネスは設計図公開

  • Codexとdotsを動かしている土台ハーネスはオープンソース
  • 社内で使っている実際の設計図を誰でも見られるということ
  • Agents APIでは、その土台をOpenAIが運用してくれます
  • さらに今回、画面を見て操作する力もAPIで使えるように
⑭
判定 ◎

紙スケッチ→宇宙ゲーム実演

  • その他: リポジトリを定期点検するCodex Security、AWS上で動くマネージドエージェントも発表
  • ライブ実演: 紙のスケッチから立体の宇宙ゲームを作り、そのゲームをAI自身が遊んで確かめる
  • 判定: 使える。社内と同じ線路が解放された → 判定◎（二重丸）
思いついた速さで作れる——それが現実に近づいています。
5

検証5: 作ったものを、届けられるか（配布）

⑮

12億人へ届ける3つの道

  • ChatGPTの利用者は12億人。今回その人たちに届ける道がいくつも開かれた
  • 道1: プラグイン（拡張機能）——ChatGPTの中に自分の製品の画面を組み込める。会話の流れの中で役に立つプラグインが見つけてもらいやすくなった
作っただけで終わらない。12億人の乗客がいる駅にホームを建てる話です。
⑯

「ChatGPTでサインイン」

  • 道2: 個人的に1番気になったChatGPTでサインイン——新しいパスワードを作らず、ChatGPTのアカウントで他の製品に入れる
  • 講演デモではChatGPTのプランの利用枠をそのアプリで使うスイッチが映っていた
  • もし広く使えるようになれば、AIの利用量を作り手だけで抱えずに済む
  • ただし正直に: 公式ページの説明は名前とメールアドレスを渡す本人確認が中心。講演では16社のパートナーから開始、一般の開発者向けの手引きは9月30日時点では見当たらない
⑰
判定 △

Marketplace と総合判定

  • 道3: OpenAI Marketplace——企業がOpenAIとの契約の一部を社外のソフトに使える仕組み。最初は32社の企業向けβ版から
  • 判定: 道はできた。ただしまだ入り口 → 判定△（三角）
線路は敷かれたのに、まだ出入口が少ない。次のDevDayまでに広がるかが焦点です。
6

終着駅: 答えは出たか？

⑱
答え

同僚になりかけている

  • 役割を渡せて、机を並べて、しかも早く安くなりました
  • ただし、何を任せてどう確かめるかを決めるのは自分
  • 指令室の席に座るのは、これからも自分
  • 上のプランの人: まずdotsに小さな役割を1つ渡してみる
  • チームで働く人: Spaceで資料を一緒に育てる
  • 開発者: Solの安さとCodexのクラウドから試す
役割を渡すdots、机を並べるSpace、安さと速さを選べる新モデル、開発者に開かれた設計図、届ける道はまだ入り口。自分の仕事のどこを任せるか1つ決めてから試してみてください。あきらパパでした。
