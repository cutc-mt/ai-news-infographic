DEVDAY 2026 OVERVIEWDevDay 2026 で何が起きたか

01
OVERVIEW大量リリースを「使えるもの」軸で整理00:00
  • DevDay 2026 はリリースの量が膨大で「どれに注目すればいいか分からない」状態——そこでまさおさんがまず全体像を一本にまとめて解説。
  • 判断基準は「実際に僕らが使えるのはどれか」「僕が注目するのはどこか」の2軸。開発者目線の取捨選択がこの動画の主軸。
  • ピックアップされたのはDotsGPT-6.1 SolUltrafastPro 500CodexAPI群。
「すごい発表がいっぱい」で終わらせず、自分の開発に効くものを厳選するスタイルがこのチャンネルらしい入り口。
02
HEADLINE一番の目玉は「Dots」00:47
  • 今回の目玉はMac を閉じても動き続ける24時間稼働のエージェント「Dots」。競合としては xAI の Grokbot 的ポジション。
  • 「PCを閉じても動いてくれるエージェントがいて、使い勝手が良ければ嬉しい」という実務者の願いに応える形の登場。
  • Dots は情報量が多いため個別の深掘り動画を別途予定。この動画ではまず全体像の把握に集中。
「24時間働き続けるエージェント」——エージェント活用の常識が変わる発表だった！
03
MODELGPT-6.1 Sol は「プチAstra」00:47
  • 同日公開の別動画でも扱った GPT-6.1 Sol。プチAstra のように使えて、コストはめちゃくちゃ安い。
  • 中堅コスパ帯ならトップクラスの性能——普段使いの実用モデルとして即戦力との評価。
  • もうすぐに使える状態になっており、ベンチマークでも非常に強力な結果。
フラッグシップ「Astra」と実用モデル「Sol」の二段構え——OpenAI エコシステムを使い込む動機がさらに強まった。
04
PLAN & WORKSPACEPro 500 と ChatGPT Space はもう稼働中00:47
  • 月額500ドルの「Pro 500」プランが登場。まさおさんは既にアクセス可能な状態を確認済み。
  • Pro 500 / Enterprise 向けに専用機能が順次解放されていく予定で、課金する理由の一つになりそう。
  • ChatGPT Spaceという「綺麗に整理できる」新機能も登場。サイドバーに Space・dots の項目が出現し、Codex 周りの UI も整理された。
課金プランとワークスペース機能が同時に動き出す——上級プランの価値を実感できるかが今後の焦点。

CODEX & CLI UPDATESCodex CLI・ボイス・レビュー強化

05
CODEX CLICLI アップデートの要点は3つ03:50
  • /voice——AIエージェントと音声で会話しながらタスクを進められる新コマンド。
  • /tasks——タスクの一覧画面が見えるようになり、進捗管理がしやすくなった。
  • workspace 周りも使いやすく改善——手元環境でのエージェント開発体験が向上。
「タイプして指示」から「話して指示」へ——CLI の操作感が一段と人間的になったアップデート。
06
VOICE DEMO/voice を実際に実演03:50
  • 動画内で /voice を入力するとローディングが走り、まさおさんが「ちょっと今HTMLのアプリ作って欲しいんだよな」と音声で依頼。
  • AI がリアルタイムに音声で応答しながら会話を進行——_TEXT入力不要のエージェント操作が実現。
  • 応用として実行エンジンを Claude に任せる構成も試したところ、汎用エージェントにボイスを足す方法としてハマりそうとの報告。
デモのソースコードは公式LINEで『devday』と送るとプレゼント——実装者への気配りも仕事が早い！
07
CODE REVIEWコードレビューの選択肢が拡大05:42
  • CLI から呼び出し——コマンド一つで Codex にレビューを依頼。
  • ChatGPT デスクトップアプリからコードレビューを依頼できるように。
  • Git 連携で @codex-review を呼んでPR ベースでレビューしてもらう運用も可能に。
レビューの「形」が3通り以上登場——チームのワークフローに合わせて選べるのが今回の肝。
08
SECURITYCodex Cloud と Security Cloud05:42
  • Codex Cloudには引き続き力が入っており、クラウド側でコーディングエージェントを回せる体制が強化。
  • 新しく Codex Security Cloud も登場——セキュリティ文脈でのコード管理・監査に効きそうな地味ながら面白いアップデート。
  • まさおさんの一押しはやはりボイス（/voice）のインパクト。ただ Security Cloud も要注目とのこと。
CLI・クラウド・セキュリティの三方向強化——Codex が開発ライフサイクル全体を覆いにいく構え。
09
AGENTS APIAPI 経由で Codex に仕事を渡す06:31
  • API 系の1つ目は Agents API——自分のアプリからCodex の「箱（サンドボックス）」を提供してもらえる。
  • OpenAI 側が用意するlux サンドボックスやブラウザ操作環境を API 経由で利用可能。アプリから仕事を渡すと Codex がエージェントとして遂行。
  • 9月中旬からベータ提供されており、まさおさんも試用済み——「普通にいい感じに動く」との実評価。
  • 利用は Pro 500Enterprise 向け。500ドル課金の理由になるかも、との分析。
「ブラウザを操作する仕事」をAPIから投げる——アプリ開発者の武器庫がまた一つ増えた！

PLATFORM & APISプラグイン・MCP・課金の新常識

10
PLUGINプラグインでスキルを共有07:49
  • エージェントスキルMCPなどをパッケージ化して共通ディレクトリに共有——ChatGPT でも Codex でも使える仕組み。
  • 申請は ZIP で提出。自動チェックはAI が直してくれるというお手軽さ。
  • 作り方は Codex 内の create-plugin から。ChatGPT アプリの新着欄には既に様々なプラグインが並び始めている。
「自分用に組んだスキルを配る」——エージェント能力のマーケット化が着々と進行中。
11
MCP EVENTSイベント監視で自動で動く07:49
  • MCP Events——ChatGPT に「何かを監視」を頼むとイベント発生時に通知が飛び、指示通り自動実行される。
  • 実例：新しいタスクが届いたら Webhook で通知→リンク先を読んで計画の下書きを作成、という流れが既に組める。
  • 職場向けにも ChatGPT SpaceチームタスクSlack から @ChatGPTなど、共有プロフィール含め続々追加。
「頼んで待つ」から「起こったら勝手に動く」へ——エージェントの勤務形態が常勤に近づく。
12
ULTRAFASTUltrafast は速いがお高い09:27
Ultrafast 料金（100万トークンあたり・報道ベース）
入力 $60
出力 $300
  • GPT-6 Astra の新速度ティア Ultrafast——API は約6倍、Codex では約8倍の処理速度。
  • TPS（トークン/秒）がとにかく伸びる。「時は金なり」の速度課金という割り切り。
  • 従来 Pro 200 の枠は20倍→10倍に縮小。トークン効率改善で実質据え続ききの説明。ChatGPT/Codex での利用は Pro 500Enterprise 限定。
Astra を Ultrafast で使うのは「勇気が要る」値段——速さと財布の天秤が今回の論争点！
13
BILLINGChatGPT の利用枠を他社アプリで11:17
  • 提携サービスで「ChatGPT でログイン」→共有をオンにすると、ChatGPT のサブスク枠から API コストを支払える新体制。
  • 実例は Devin——「ChatGPT でログインしますか？」→利用枠から払うスイッチをチェックして利用。
  • まさおさんも自作アプリに統合して動作確認済み。API 従量課金の代わりにサブスク枠で済むのは「誰にとってもハッピー」。
  • 他社AIサブスクの従量プランを契約せずChatGPT サブスクに集約するムーブが来るとの読み。
個人的ベストポイントの一つ——課金モデルの「サブスク一本化」が業界の枠組みを変える可能性。
14
DECISIONSDecisions API は「選択専用」15:24
  • 注目が集まる Decisions API——ほぼリアルタイムで動く「選択専用」API。中身は Luna ベース。
  • なんと画像も渡せる。「これはログイン」「これは不具合」といった振り分け判断を高速に返す。
  • ルーティング分岐のような用途に最適で、Jevと並ぶ話題の仕組み——別アプローチで同じ問題を解くもの。
  • まさおさんの評：「出たらすぐ使いたい」。
巨大LLMに丸投げしない「判断だけ高速に返す」専用API——エージェントの分岐コストが激減する。

DOTS & BEYONDDots の正体と OpenAI の構想

15
DOTS INSIDEDots の中身と専用クラウドPC12:42
  • Dots の中身は GPT-6 Astra。レビューでも使用体験がかなり良さそうとの声。
  • 専用のクラウドPCを持ち、Grokbot のようにChromeターミナルFinderを操作。「アプリを開いて試して改善して」を指示どおり実行。
  • PC を閉じても画面はそのまま動き続け、人間が操作を交代できるUIも提供。
  • 話しかける経路は Slack音声通話ChatGPT アプリなど多様。先行テスタ―からは「Slack 連携は追加料金なしだが少し遅い」評も。
  • 自分の記憶を持つエージェント——中身がどう作られているかも注目ポイント。
高度なロールプレイには Astra 級が必要——将来 Sol への置き換えはあるか、が語りの見どころ！
16
SPACEChatGPT Space は「プチNotion」14:11
  • Space はとてもシンプルな機能。作ったページ・サイト・画像にここからアクセスできるようになる。
  • スライド作成も可能——いわばプチNotion的ポジション。
  • 新規作成からAIエージェントと一緒に生成しながら進められる体験が特徴。コメントで「dots」と打てばAIエージェントと共同作業に。
  • 海外の評価は「Space は過小評価・Dots は過大評価気味」という声も——まさおさんは Dots が今後の中枢になると読む。
スライドの共同編集やミーティング連携など、「作業場所としてのChatGPT」が今後も拡張予定。
17
VISIONDots が目指す「AI組織」16:07
  • ChatGPT から日常的に動く Dots が、専門AIエージェントの「チーム」として組織されていく構想。
  • Grokbot を触っていると実感できる「AI組織」の姿が、近い未来に来そうという手応え。
  • さらにプライベートインテリジェンス——議論まで守ってくれるプライベートな知性の登場予告も。
  • ロボットのデモもあり、Jibと比較する声が増える局面も。
単体の助手から編成される組織へ——エージェント設計のパラダイムが「チーム」に移りつつある。
18
NEXTまとめ: 押さえるべきポイントは絞れる16:07
個人ベスト：Devin で使える ChatGPT 利用枠の共用が一番面白かった
注目続報：Dots は早めに個別動画で深掘り予定

  • 大量リリースの時代こそ「抑えるべきポイントを見れば絞られる」——この動画自体がその実践例。
