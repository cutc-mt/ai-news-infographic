  • Sonnet 5.5に対抗できるモデルがまだないのは、少し残念だと率直に評価
現時点ではAnthropicがリード。ただしこうした状況は非常に速く変わります。
8/18

⑧この戦い、次はどう動く?

  • 状況は週単位で書き換わるため、特定社の優位は長くは続かない見込み
  • 価格1/5のGPT-6.1 Solが「コスパの主戦場」をどう塗り替えるかが焦点
安くて賢いモデルの投入合戦。利用者には追い風の時代です。

DevDay 2026 発表ダイジェスト

3
9/18

⑨「Dots」— 24時間稼働のAI執事

  • GPT-6 Astra搭載の常時稼働AIエージェント。それぞれ専用のクラウドコンピューターとブラウザを装備
  • プラグイン経由で4,000以上のアプリと連携。一緒に働くほど好みを学習し体験が最適化
  • 読み取り専用アクセスでバックグラウンドの先行調査も実行。ChatGPT・音声通話・Slack/Teamsからアクセス可
  • カスタムルールで操作の許可・承認必須・ブロックを制御。Pro/Business Premium向け展開、医療・教育機関はベータへ
まさに「専属の執事」。Microsoft Agent 365との統合も進行中です。
10/18

⑩Ultrafast Mode — 最大8倍速

  • プレミアム速度階層。Codexで最大8倍速・毎秒約300トークン、APIでは最大6倍
  • 用途は納期に追われて一気に出力したい場面や短時間での作業完了
  • Astra UltrafastはAPI・ChatGPT Work・Pro 500とEnterpriseのCodexで利用可能。Sol Ultrafastも近日登場予定
毎秒300トークンは「流れてくる」のではなく「飛んでくる」速度です。
11/18

⑪新最上位プラン「Pro 500」

  • 新しいプロ階層。Plusの25倍の利用枠を持ち、Ultrafastも含まれる最上位プラン
  • 狙いはCodexのヘビーユーザー。一日中複数のエージェントを並行稼働させたい人向け
  • 大量消費するほど速度特典の価値が増す設計です
エージェントを何体も回す開発者にとっては、待望のプランですね。
12/18

⑫Codexファミリー全面刷新

  • クラウドCodex: 再利用可能なチーム開発環境。ノートPCで開始→スマホで進捗確認が可能に
  • 刷新されたCodex CLI: 音声操作・複数タスク追跡のエージェントビュー・セッション復元・ワークツリー対応。全プランで利用可
  • コードレビュー機能: デスクトップで差分や問題を要約し、クラウドで自動の一次レビュー
  • Codex Security Cloud: リポジトリをスキャンし重複指摘を削除、修正案まで準備。Daybreak Blueモデルも同梱
毎週の全リポジトリ定期スキャン→修正案提示、まで自動でやれます。

開発者向けAPIの大進化

4
13/18

⑬Decisions API — 即答の自動化

  • Lunaのような高速モデルを使い、リアルタイムでアクションを起こすためのAPI
  • ユーザー定義の質問セットに対して有限の事前定義された回答を返す設計。テキスト・画像でコンテキスト提供可
  • 用途: サポートチケットを請求・技術・営業へ振り分け、ポリシー違反のフラグ立て
  • 現時点で限定プレビューだが、数日中に広く公開予定
「AIに考えさせる」ではなく「AIに即決させる」ための道具です。
14/18

⑭Agents API & Bedrock統合

  • Agents APIがコンピュータ操作に対応。エージェントがソフトウェアを直接操作可能に
  • マルチエージェントサポートに加え、ツール検索とコンテキスト圧縮機能も搭載
  • Bedrock管理エージェント: OpenAIのエージェントがAWS上で完全実行され、AWSリソースと接続可能に
  • API経由のほかCodexやChatGPTのPro・Team・Enterpriseプランでも利用可
すでにAWSで開発している企業には、うれしい追い風になります。
15/18

⑮プラグインプラットフォーム開放

  • プラグイン拡張機能: ChatGPTのサイドバーにプラグインの居場所を作り、インタラクティブなパネルを構築可能。全プラン対応
  • 開発者がプラグインを作成・提出し、利用者が発見しやすくする「App Store」構想が最終目標と分析
  • Sites機能でもプラグインをホスト可。チームメイトが各自のデータ・権限で同じアプリを利用
  • MCPイベント×自動化: 接続先アプリの変更を検知してプラグインから自動化をトリガー
ChatGPTが「店舗」になる。エコシステム戦争の次の章です。

人間×AIの協働とエコシステム拡張

5
16/18

⑯Space・Pages・Slides・Teams

Space=共有ハブ Pages=共同ドキュメント Slides=共同スライド
  • ChatGPT Space: チームメンバーとAIエージェントが同じ知識ベースで連携する共有ハブ
  • Pages: Word文書のように人間とAIエージェントが同時に同じドキュメントで共同作業
  • Teams: チーム作成・タスク共有で、AIエージェントにもタスク割り当てが可能に
人間もAIも同じ職場に置く。自然な流れを、そのまま製品化しました。
17/18

⑰ChatGPT Perks & Marketplace

  • ChatGPT Perks: サブスクに枠が設けられ、CognitionのDevin・Notion・Vercel・T3・OpenClawなど16社のパートナーで利用可
  • 別のサブスク料金を払う代わりに既存のChatGPTプランの枠を使える仕組みは非常に画期的と評価
  • OpenAI Marketplace: 32のローンチパートナーによるマーケットプレイス。HubSpot・Adobe・Lovableらが参加
  • Slack/Teams連携・会議プラグイン（メモ・要約・アクションアイテム）・GitHub的な共有プロフィールも登場
「1つの契約で多数のサービスを使う」。この方向性は大正解です。
18/18

⑱総括: 価格破壊とエコシステムで迎え撃つ

  • 中核は「Astra級性能を1/5の価格で」というGPT-6.1 Solによる価格破壊
