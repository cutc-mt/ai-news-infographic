Opus 5.5 の半額以下で動く「GPT-6.1 Sol」— コスパ検証と DevDay 2026 総まとめ

Ultrafast ・ Pro 500 ・ GPT-6.1 Sol ・ dots — 1時間近い基調講演の「どこへ課金するか」をれん学長が徹底解説

①深夜の DevDay 2026 基調講演

  • OpenAI DevDay 2026 の基調講演は日本時間の深夜2時頃から。れん学長もリアルタイムで視聴。
  • 本動画の音声はGemini 3.8 Flash TTS でクローンした声。深夜4時過ぎだったため、発表の熱が冷めないうちにこの声でお届け。
  • クローン音声でどこまで自然に聞かせられるかの実験も兼ねた一石二鳥の回。
深夜2時の講演を即日解説 — 熱量の高さが伝わるスタートなのだ！

②全体像: 発表20以上・4つの柱

  • 柱1新しいモデルと速さ — GPT-6.1 Sol・Ultrafast・新しい Pro 500 プラン。
  • 柱2AIと働く新しい形 — 24時間働くエージェント dots とチームで使う ChatGPT Spaces。
  • 柱3開発者向けの道具 — Codex のクラウド版や Agents API など。柱4は作ったものを12億ユーザーに届ける仕組み。
1回の講演にこのボリューム! 今回は「速さ」と「エージェント」に絞って掘り下げ！

③Ultrafast: Astra が最大8倍速く

  • れん学長が1番興奮した発表。OpenAI で最も賢い GPT-6 Astra をとんでもなく速く動かす新しい選択肢。
  • Codex と ChatGPT Work で最大8倍、API で最大6倍。毎秒最大300トークンを出力。
  • 料金は標準の6倍。講演では「Fast は2倍速で2倍料金、Ultrafast は8倍速で6倍料金」と並べて提示。
「速さ×価格×300トークン/秒」— 最強モデルをターボで回す時代が来た！

④衝撃のロケット比較映像

  • サム・アルトマンが同じプロンプトを2つの速さに渡す比較映像: 「DevDayの色のロケットを作って打ち上げて」。
  • 左の Ultrafast はもうロケットが飛び立っているのに、右の通常版はまだ組み立ての途中。
  • 同じプロンプトでここまで待ち時間が変われば、コードを書くたびの作業の体感そのものが変わりそう。
目で見て分かる速さ — これには誰もが「使いたい」となったはず！

⑤Codex CLI ライブデモ

  • 新しくなった Codex CLI で来場者から3人をランダムに選ぶアプリを生成するデモ。
  • その後「6人にして」と頼むと、画面が変わるまでほんの数秒。会場が沸いた場面。
  • 実は音声でも指示できるが、この日は会場で音声が不調で文字入力。Devin のデモらしいハプニングも。
ハプニングがあってもこの速さ — Ultrafast での作業が楽しみになるデモ！

⑥Pro 500: 月500ドルの新プラン

  • 月500ドル、日本円では税込み8万4000円。利用枠はPlus の25倍で Pro 3段の中で最大。
  • 個人向けプランで Ultrafast を使えるのは Pro 500 だけ。購入画面には5時間ごとの上限がないことも明記。
  • ChatGPT でサインした定型アプリでも同じ枠が使える一方、Pro 200 は新規受付を再開も新規組の枠は従来より少なくなる(既存は10月29日まで現行枠)。
「5時間上限なし」が最大の売り — 無限に使い続けられるのはここだけ！

⑦Pro 3段を徹底比較

  • 月額は Pro 100: 1万6800円〜(Plus比5倍) / Pro 200: (4月比20倍・新規は減) / Pro 500: 8万4000円(同25倍)。
  • Plus 1つ分の枠の値段は Pro 100 と Pro 500 が20ドル。Pro 200 は4月の20倍なら10ドルだったが、新規は枠が減り割安感低下。
  • 結論: Pro 500 は枠を安く買うプランではなく、Ultrafast の速さと5時間上限なしに払うプラン。
枠単価で選ぶなら Pro 100、速さで選ぶなら Pro 500 — 購入目的をはっきりと！

⑧X の報告: 枠の減りが早い?

  • X の BridgeMind さんが Pro 500 の Ultrafast を試したところ、プロンプト2分で週の利用枠の2%を消費と報告。
  • このペースだと週に100分ほどの作業で枠を使い切る計算。「完全な詐欺だ」とまで書いていた。
  • 1人の人の報告なので使い方によって変わるはず。れん学長は「短時間で成果を出せるなら価値」と感じ、Pro 500 の契約を決意。
契約前に知りたい情報 — 実際に試した人の声はチェックしておこう！

⑨GPT-6.1 Sol: Astra の5分の1

  • 公式は「Astra に迫る知能を5分の1の料金で」と説明。入力100万トークンあたり2ドル・出力10ドルで Astra のちょうど5分の1。
  • キャッシュ済み入力は95%引き — 長い作業を回すエージェント用途で特に安くなる。
  • サム・アルトマンは「いくつかの点では Astra より賢く、普段使いの主力になる」とまで発言 — かなり強気。
最強級の知能が5分の1の価格 — コスパ最強モデルの登場なのだ！

⑩Sol は今日からどこで使える?

  • 今日から Plus 以上で利用可能 — 対象は ChatGPT Work・Codex・API の3つ。
  • ただし普通のチャット画面ではまだ使えないので注意。まずは Codex で触るのがおすすめ。
  • Sol の Ultrafast 版も近日提供予定と発表済み。
Plus なら追加課金ゼロで今すぐ試せる — まず Codex でその実力を体感！

⑪vs Opus 5.5【費用編】

  • 公式ページのグラフから Claude Opus 5.5 が載っている3つの試験を抜き出し、最も点が高かった設定同士で並べ替えて比較。
  • 費用は3つの試験すべてで Sol が半額以下。試験によっては約5分の1も。
  • ただし公式グラフの Opus 5.5 には「フォールバックあり」の注意書きがあり、全く同じ条件の比較ではない点は割り引いて見る必要あり。
「公式が自社に有利な比較をする」のはどこの会社も同じ — 条件の注記まで読むのがれん学長流！

⑫vs Opus 5.5【点数編】

  • PDF を読んで答える専門業務の試験ではSol が Opus 5.5 を上回った。
  • 一方業務の自動化と科学研究の試験ではOpus 5.5 が約6ポイント上。公式は「中程度の設定同士なら2.2ポイント上」という比較方法だった。
  • 結論: 同じ予算で多く回すなら Sol、とにかく最高点が欲しい場面はまだ Opus 5.5の出番。
「コスパの Sol」「最高点の Opus」— 用途で使い分けるのが正解なのだ！

⑬目玉の dots: 24時間働く分身

  • ChatGPT の中で24時間働き続ける自分専用エージェント。OpenAI 版「OpenClaude(旧クロードボット)」のような存在。
  • GPT-6 Astra で動き、専用のクラウドPCとブラウザを持つ。コードを書いて試すことも可能。
  • プラグインで4000以上のアプリに接続。Slack・Zoom・音声通話からも話しかけられる。
目標と「進めて良い範囲」を決めておくと、頼む前に先回りして進めてくれる！

⑭dots 紹介映像が秀逸

  • 会の資料の更新まで dot が自分から進行。「見る前に今の製品と照らし合わせておいて」と返すだけでOK。
  • アプリ移行でも必要な変更を勝手に洗い出し。「人は進めていいよ」の一声で完結。
  • 映像の続きでは結婚式の景品手配や子供の習い事の予約までお任せ — 仕事も生活も1体の dot が見てくれるイメージ。
「頼む前にもう動いてくれている」感覚が dots の1番の良さなのだ！

⑮dots はいつから使える?

  • 公式ヘルプではPro と Business Premium から順次提供(Pro は欧州などを除く地域)。日本の Pro も対象のはず…
  • ところが実際に試すと「この地域ではまだ使えません」と表示され、日本での利用はもう少し待つ必要がありそう。
  • 料金面は嬉しい: 最初の1体はプランに含まれ、会話は上限にカウントされない。最初の1ヶ月は作業分も上限外。作成はデスクトップアプリか Webのみ。
AI秘書作りに挑戦中のれん学長 — dots が使えるようになったら必ず実験動画に！

⑯ChatGPT Spaces と開発者向け

  • ChatGPT Spaces: チームと ChatGPT と dots が同じページを一緒に編集。リビングページはグラフ・表が自動更新、スライド共同編集は近日(PowerPoint/Googleスライド書き出し可)。
  • 開発者向け: Codex がクラウドで動きスマホ→PC の継続が可能に。Codex CLI も刷新され音声指示・複数作業の一望に対応。
  • Agents API はコンピューター操作にも対応。Decisions API は選択肢から1秒未満で回答(限定プレビュー)。他社アプリをChatGPT アカウントでサインインでき、開発者がトークン台を持たなくてよい仕組みも。
スライド好きのれん学長は Spaces のスライド共同編集に注目 — 個人開発者追い風の発表揃い！

⑰いつから・どのプランで使える?

  • GPT-6.1 Sol: 今日から Plus 以上の ChatGPT Work・Codex・API で利用可(通常チャット画面は未対応)。
  • Ultrafast: 今日から Codex で利用可。個人向けはPro 500 のみ。Sol の Ultrafast 版は近日。
  • dots: Pro/Business Premium に順次提供(日本の Pro は未だ)。Spaces は Pro・Business・Enterprise で順次。Decisions API は数日中に広く公開予定。
まず Plus で Sol を Codex から触るのが今日できる最短ルートなのだ！

⑱まとめ: テーマは「速さ」と「任せる」

  • DevDay 2026 の大きなテーマは「速さ」と「AIに仕事を任せきる形」の2つ。Ultrafast と Pro 500で速さにお金を払う選択肢が一気に広がった。
  • GPT-6.1 Sol は費用で大きくリードするも、最高点ではOpus 5.5が上の試験も残る。dots は24時間働く分身 — 日本の Pro での利用開始が待ち遠しい。
  • れん学長はPro 500 の契約・Sol のベンチマーク・dots を使ったAI秘書を順次試して報告予定。講演の最後には会場でボタンを押して利用上限をリセットする演出も。
「どこへ課金するか」の材料はこの1本で — 次の一手は Pro 500 で Ultrafast 体感！
