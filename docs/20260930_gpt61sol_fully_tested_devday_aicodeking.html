カタログスペックではなく「実際にコーディングタスクを渡して開けてみる」——この動画の審査基準が最初に宣言される。

DOTSDots: 常時稼働エージェントの正体01:41
  • Dots は GPT-6 Astra 駆動の常時稼働エージェント——専用クラウドPCとブラウザを持ち続ける。
  • 継続的な責務を与え、道具を接続すればプロジェクトをまたいで働き続け、フィードバックから好みを学習。
  • 開発者なら顧客フィードバック追跡・バグ調査・レビュー準備、クリエイターなら資料整理を丸ごと任せられる。
  • 連絡経路は ChatGPTSlackTeams——ChatGPT では音声会話も可。承認ルールも設定できる。
  • 提供は Pro・Business Premium（対象市場）。企業向けに専門Dots・Microsoft Agent 365 連携も予告。
「頼んで待つ」のではなく「雇って持ち場に置く」——エージェントの雇用形態が変わる発表。

DEVDAY LAUNCHES IN DETAIL速度・Codex・API・ChatGPT の新機能

05
ULTRAFAST & PRO 500最大8倍のトークン生成と500ドル枠02:38
  • プレミアム tier Ultrafast は Codex で最大8倍・API で最大6倍のトークン生成。Astra Ultrafast は即日利用可、Sol Ultrafast は近日。
  • ただし生成速度≠プロジェクト全体がその倍率で完了するわけではない——冷静な注釈入り。
  • Pro 500 は月額500ドルでPlusの25倍の利用枠＋Ultrafastアクセス。企業向け API Ultrafast は別途プレミアム価格。
  • キング氏の判断基準:「自分の実務から待ち時間をどれだけ消せるか」で課金を決める。
「速い」の定義を疑う——トークン速度と体感速度を混ぜない判断軸が示される！
06
CODEX CLOUD & CLI再利用可能な開発環境と刷新CLI03:23
  • Codex Cloud に再利用可能な開発環境——リポジトリ・依存関係・道具を整えさせ、レビューして環境を「公開」して将来のタスクに使い回す。
  • 「毎回同じセットアップを繰り返すのはコーディングエージェント運用で一番面白くない部分」——タスクごとに独立した作業状態も付く。
  • 他端末から Codex の作業を remote 追跡できるように。
  • 刷新 Codex CLI は音声操作・/agentsビュー・プロンプト編集・セッション再開・ワークツリー強化と多岐。
「セットアップの再利用」——地味だが毎日効く改善としてキング氏高評価の由来。
07
REVIEW & SECURITYコードレビュー強化とSecurity Cloud04:21
  • レビューがデスクトップで完結する体験に——要約・diff・コメント・チェックを inspect し、Codex に問題調査を依頼可能。
  • GitHub は GA、GitLab マージリクエストはプレビュー。自動クラウドレビューの初回パスも設定可。
  • Codex Security Cloud（リサーチプレビュー）は接続 GitHub リポジトリをスキャンし、新コミット検査→調査→修正案をクラウドで準備。
  • 証拠と修正案をレビューでき、ノートPCを閉じていても作業が継続——Daybreak Blue モデル同梱。
エレベーター・レビュー・セキュリティの「閉じても動く」三重奏——エンジニアの離席不安を消す方向へ。
08
AGENTS / BEDROCK / DECISIONSエージェントAPI三種の神器04:48
  • Agents API にコンピュータユース追加——OpenAI ホストのブラウザでサイトを巡回・操作するエージェントを構築可。承認・サインイン要求はアプリ側で処理。
  • GPT-6.1 Sol は Responses API でベータのマルチエージェント対応——仕事をサブエージェントに分割。
  • Bedrock マネージドエージェント（Amazon と共同開発・プレビュー）: エージェント機能を AWS 内で完結——既存 AWS インフラ資産があるなら大きな利点。
  • Decisions API: Luna を固定選択肢の質問に特化させ、テキスト・画像コンテキストで分類や次アクション判定を高速回答。限定プレビュー中。
「ブラウザを操作するAPI」「AWSで動くエージェント」「一瞬で判断するAPI」——用途別に3本の矢が揃った！
09
PRIVATE INTELLIGENCE機密データ向け「プライベート推理」05:51
  • 機密情報を扱う企業向けに Private Intelligence を発表——承認済みゼロデータ保持顧客向け。
  • Private Safety Processing: OpenAI の従業員が内容にアクセスせず自動安全チェックを実行。
  • Private Inference は今秋プレビュー予定——機密計算と検証可能な統制を組み合わせる別枠。
  • 「企業が自社要件に対して評価する具体的なデプロイ選択肢」と位置づけ。
「安全確認のためだけに中身を見られる」問題への回答——金融・医療業界の門戸を開く布石。
10
PLUGINS / SITES / MCPプラグイン拡張とイベント駆動06:16
  • プラグイン拡張: 会話の横にサイドバーアプリ・パネル・独自のファイルビューア／エディタを構築可——道具に本物のUIを持てる。
  • Composer メンションは現状デスクトップのみ。Web拡張（Free・Go向け）は近日。プラグイン作成・提出フィードバック・ランキング経由の発見も改善。
  • 共有プロフィールでサイトとプラグイン活動を披露——制作物を見せて見つけてもらいやすく。
  • MCP Events: 接続サービスが ChatGPT に変更を通知し、「新しいissue→調査タスク→計画準備」のような自動化が組める。
「UIを持つプラグイン」＋「イベントで発火するChatGPT」——プラットフォーム化が一歩前進。
11
SPACE / PAGES / TEAMS共同作業の場とチーム運用07:54
  • ChatGPT Space は共有ファイルとナレッジを一箇所に、Pages は人とエージェントが一緒に編集する文書——執筆・調査・チャート・コメント・@ChatGPT／@dots での変更依頼が可能。
  • 共同スライドは数週間以内——会話やテンプレートから始めてPowerPoint・Google Slides に出力。
  • チーム共有タスクは週次更新やイベント駆動の定型業務を担当（ワークスペースクレジット消費）。
  • Slack・Teams 展開では全員が個別ライセンス不要でチャンネル内参加可。Meetings プラグイン（Mac OSベータ）は音声から議事録・アクションを Space に生成し、ノート完成後は音声を削除。
「ドキュメント・文脈・AI支援が同じ場所にある」——ChatGPT が職場の作業床になる構え。

SIGN-IN & MARKETPLACEChatGPTログインとマーケットプレイス09:29
  • Sign in with ChatGPT: 対象の Plus・Pro ユーザーは提携ツールで ChatGPT の利用枠を使える——アプリごとの使用量制御つき。
  • 提携先は DevinNotionVercelT3 など。使用量はプラン枠にカウント——「既に持っている枠をより多くの場所で」という整理。
  • OpenAI Marketplace: 企業は既存のOpenAIコミットメントをパートナー製品に充当可能——デザイン・サポート・セキュリティ等の初期提携。
API従量課金の代わりに「サブスク枠を使い回す」——課金の中心がアカウントに寄っていく！
