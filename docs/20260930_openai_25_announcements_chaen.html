DEVDAY 2026 OVERVIEW25個の発表から押さえるべき3つ

01
BREAKING25個発表は「多すぎて追えない」00:00
  • OpenAI が DevDay 2026 で25個以上の発表を一挙投入。「いや多すぎ。追えない」とチャエンさん——この動画では全25個をサラッと俯瞰しつつ、押さえるべき3つ＋αに絞って解説。
  • 25個の発表を コワーク系競合・モデル・料金系開発者向けエコシステムの4つの箱に分類して整理。
  • 良いニュースと「炎上案件」の両方を包み隠さずネットの反応と一緒に紹介するのが当チャンネルらしい速報スタイル。
発表の量が多くても「自分の仕事に効く3つ」から押さえる——取捨選択の軸が最初に示されるのがこの動画の入口。
02
HEADLINE 1最大の目玉は24時間稼働の「dots」01:23
  • 1番の驚きは 24時間クラウド上で働き続ける自分専用AIエージェント「dots」。GrokbotMetaのミューズと同じ“パーソナル型”カテゴリの登場。
  • 専用のクラウドPCを持ち、PCを閉じても動作し続ける。4,000以上のアプリに接続可能。
  • 中身はなんと最上位の GPT-6 Astra。ルーティンワークからメール巡回まで“分身”のように任せられる。
「パソコンを閉じても24時間動いてくれる」——パーソナルエージェント戦争が一気に激化する発表だった！
03
HEADLINE 2GPT-6.1 Sol は「Astraの賢さを1/5の金額」06:09
  • 同時発表の GPT-6.1 Sol——GPT-6 Astra の賢さに迫り、金額は約1/5というコスパ帯モデル。
  • ChatGPT／Codex系 API は安くて速いのが特徴。Claude はやや遅めなので、その点が開発者には魅力的と分析。
  • ベンチマークでは GPT-6.1 の方が GPT-6 より3D系が明らかに向上。一部では Astra に勝つ場面も。
「賢さはAstra級・値段は1/5」——日常使いの実用モデルとして一気に選択肢に入ってきた。
04
HEADLINE 3プラン大改変: 500ドル新設・200ドルは半分07:16
  • 月額500ドルの「Pro 500」プランが新登場。チャエンさんは撮影終了後すぐ課金予定（3アカウント運用を500ドルに切り替えゴリゴリ開発するらしい）。
  • ところが従来の200ドル(Pro)プランは利用量が半分に——これが大炎上。「みんな Claude Code に乗り換えた」之声も。
  • チャエンさんの評:「これは発表しなければ良かった。後にしたら良かった」——良い発表の数々がこの件で少し残念な空気に。
値上げではなく「枠の半減」——課金ユーザーへの配慮を問われる、DevDay唯一の炎上案件！

FIRST LOOK初見実機デモ: カレンダー・Codex連携03:08
  • Google を軽く接続しただけで自分のカレンダーを見てくれるデモを披露（画面はモザイク対応で配慮）。

「基本 Codex みたいなことができる」＋24時間クラウド稼働——開発者の quotidien にそのまま溶け込む設計。
06
HOW IT WORKS話しかけ方も任せ方も何でもあり03:08
  • ChatGPT や SlackTeams に入れるとお電話での会話も可能——話しかけ方・任せ方は自由。
  • 暇な時は接続アプリを読み込んで見回り——メールチェックなどの巡回を自律的にこなす。
  • コード作業は Codex に任せ、バグの仕分けやプルリク依頼（「これ直しといて」）まで実演。
  • まとめ:「自分の分身のように仕事を任せられる」&「チャットにも入り込める」エージェント。
公式デモでは bugs を仕分けてプルリクを出すところまで披露——開発の下流工程から上流まで任せられる！
07
REQUIREMENTSdots の利用条件を整理04:09
  • プロプランなら追加料金なしで1体利用可能。ただし1体だけ（複数は不可）。
  • 最初の1ヶ月は利用枠を消費しない——お試し枠が用意されている。
  • 作成は デスクトップアプリ か ブラウザ のみ——スマホからは作れない点は注意。
  • 日本でも既に使用可能（チャエンさんが当動画で実際に起動して確認済み）。
「プロなら1体無料お試し」——まず触って判断できる設計は日本ユーザーにも追い風。
08
COMPARISONミューズ・Grokbot との違いは「仕事向け」か05:29
  • Meta ミューズ: 無料で使える個人向け（米国限定の可能性）。日本ではまだ使えず。
  • xAI Grokbot: dots に最も近い存在。チャエンさんも日頃からヘビー利用。
  • dots は有料プラン限定だが“仕事向け”——ミューズは個人向け、Grokbot／dots は業務寄りという棲み分け。
  • 「この流れならClaude にも絶対同じものが来る」——無理して乗り換えず待つのも戦略と助言。
パーソナルエージェントは今年のトレンド——でも「待てば Claude にも来る」、焦るなかれという冷静な読み！

SOL / ULTRAFAST / NEW FEATURESモデル・速度・新機能の要点

09
MIGRATIONチャエン氏、Claude Code から Codex へ移行検討06:09
  • 「最近は Claude Code をめっちゃ使ってる。Opus 5.5 が良くて減らせない」——それでもGPT-6.1 Sol の安さ・速さに注目し、Codex 併用を宣言。
  • 現在 SaaS を開発中で1週間で160本ほどプルリクを出すペース——量が多いほど安くて速い Sol の旨味が増す計算。
  • 「一部では Astra に勝つ」「1/5でこの数値なら十分使える」——長いソフト開発(SWE系)では Astra が上位も十分筋。
Opus 5.5 愛を語りつつ「量が多い開発」では Sol を試す——実務者のリアルなツール選びが見どころ。
10
CONTROVERSY200ドル半減炎上と「飛ばし」事件07:16
  • 200ドルプランの利用量半減に対し「マジかよ…」の声が殺到。乘り換えを表明するユーザーも続出。
  • さらに発表前にコデックス開発者のティボさんの“フライング投稿”が散発——せっかくの良い発表の流れがいまいちになったと指摘。
  • チャエンさんの提案:「ああいう人の X は会社がちゃんと管理した方がいい」。
  • その後、全員の利用枠がリセットされる事態にも——運営の混乱が透けて見えた一夜。
良い発表だらけの DevDay が「200ドル半減」一つで台無し风险——PRの難しさを物語るエピソード！
11
ULTRAFASTUltrafast の速さは「確かにいいかも」07:59
  • 「ウルトラファスト、めっちゃ速いですよ」——500ドルプランの目玉機能としてチャエンさんが心を動かされた一件。
  • トークン生成速度が最大8倍(Codex)——デモの動きを見て「この速さは確かにいいかも」と実感。
  • 注意点も明記: 「最大8倍」は生成速度の話で、作業全体が8倍で終わるわけではない（説明欄より）。
「速さは正義」も何がどの速度なのか正しく理解してから課金するのが賢い利用法。
12
RANK 6-8Decisions API・Space・プラグイン08:40
  • Decisions API: ルナ(Luna)ベースで選択肢から超高速判断——話題の高速モデル Jev 的ポジション。
  • ChatGPT Space: 自分の作ったページ・サイト・画像などのアウトプットがライブラリ的に管理される場所。実機でも確認。
  • プラグイン／エクステンション: ChatGPT の中にアプリ画面そのものを出せる仕組みが進化。
  • このほかスライド共同編集（Figma のようと評）、ミーティング音声のボットなし書き起こし等は「以前からあった機能の進化」と整理。
派手な新機能より「Space に成果物が集約される」地味な進化の方が日常を変えるかもしれない。

ENTERPRISEBedrock・ChatGPTログインなど開発者向け08:40
  • Bedrock マネージドエージェント: AWS の中で OpenAI エージェントが使える——「社内は AWS 固定」という大企業案件で嬉しい。
  • ChatGPT ログイン: 提携アプリで ChatGPT アカウントでサインイン可能に。
  • エージェントAPI の PC操作(コンピュータユース)対応——アプリからブラウザ操作を任せられる。
  • Codex のクラウド化（PCを閉じても動き続ける）は「前からあったのでは?」と物申しつつスルー——全部が真新しいわけではない点も公平に評価。
エンタープライズ向けラインナップが一気に厚く——「会社のクラウドの中で使えるか」が選定の鍵に。
