DEVDAY 2026 — KEYNOTES主要発表: dots・GPT-6.1 Sol・Ultrafast

03
HEADLINE 1常時稼働エージェント「dots」登場
  • クラウド上のコンピュータで24時間稼働し続ける「Always-On」エージェント。新しい発表の目玉。
  • ChatGPT Pro／Business Premium プランに1個の dots が同梱される構成。
  • チャット画面を閉じていても作業が進む——「AIに仕事を任せっぱなし」が現実になる最初の一歩。
「使っている間だけ動くAI」から「常に動いているAI」へ。開発者の仕事の進め方そのものが変わる可能性。

  • agentic codingcomputer useなどエージェント業務・専門業務向けに最適化。
価格対性能で前夜の Sonnet 5.5 に真っ向勝負——開発者のモデル選びがまた少し難しくなるね！
05
SPEEDUltrafast: 最大8倍・300トークン/秒
  • GPT-6 Astra に新しい速度ティア「Ultrafast」が追加。
  • Codex での作業は最大8倍高速、応答は最大300トークン/秒と報じられた。
  • 「待ち時間ゼロ」のエージェント作業へ——体感速度が次の競争軸に。
「賢さ」に続き「速さ」が選ばれる理由になる。UIやエージェントの設計も速度前提で組み直される。
06
PRICING月額500ドル「Pro 500」と賛否
  • 月額500ドルの新プラン「Pro 500」が発表。
  • Ultrafastなどの最上位機能を束ねる構成とされ、ヘビーユーザー・企業向けの位置づけ。
  • Reddit では「高すぎる」と大論争に——価格発表のたびにコミュニティが沸騰するのはお約束。
月500ドルは「企業ならともかく、個人には…」——価格と価値の天秤が今回も白熱だ！
07
DEVELOPERCodex everywhere: クラウド・CLI・ローカル
  • 「Codex in the Cloud」——クラウド上で動き続ける Codex が登場。
  • 新しい Codex CLI と /agents コマンドでローカルの開発体験も強化。
  • IDE・クラウド・CLI のどこでも同じエージェント体験を目指す「Codex everywhere」構想。
コーディングエージェントの主戦場は「どの環境でも動くか」へ。開発日誌的な使い方がさらに加速しそう。
08
APIAgents API 拡張・Decisions API・MCP Events
  • Agents API が拡張され、エージェント構築の部品が公式に揃う。
  • 新Decisions API——エージェントの意思決定を外部から制御する仕組み（TypeSafe の Jev と比較される）。
  • MCP Events でツール連携がイベント駆動に。エージェント同士の協調も組みやすく。
「モデルを呼ぶAPI」から「エージェントを組み立てるAPI」へ——開発者向け発表の中核。
09
CHATGPTSpace・Pages・Slides で「協働の場」へ
  • ChatGPT Space——AI と共同作業するための新しいワークスペース。
  • PagesSlides などドキュメント系機能も拡充。
  • プラグインと ChatGPT 内アプリ（Figma など）の拡張も発表。
チャットbotから協働プラットフォームへ——ChatGPT の居場所がどんどん広がっていくね！
10
ECOSYSTEMSign in・Marketplace・Private Intelligence

  • 企業向け Private Intelligence（プレビュー）やAdobe × ChatGPT 連携強化も報じられる。
