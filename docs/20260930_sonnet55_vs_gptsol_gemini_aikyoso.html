  • しかし実際のビジネスの主戦場は、日常的に大量消費される中堅モデル同士の企業API戦争

華やかな頂上決戦より、こちらが本当の売上を決める戦いです。

②Sonnet 5.5はAnthropicの「本命」

  • Opusが高難度の難問を、Haikuが超高頻度の安価な処理を担う中、Sonnetは企業APIの売上と利用量の本丸
  • Sonnet 5.5は能力がOpus 5.5に迫る水準まで向上し、Sonnet 5より大幅に賢くなりました
  • 「最高知能」ではなく「企業で最も使えるAI」を目指した実務派モデルです
中堅と呼ばれながら、実はビジネス上の主力エンジン。
3/18

③GPT-6 Solは「同価格」で切り込んできた

  • Opus 5.5と同時リリースされたGPT-6 Sol。API料金はSonnetと同じ$2/$10（入力/出力・100万トークンあたり）
  • 世間はOpus対Solだと思ったけれど、価格帯からして狙いはSonnetそのもの
  • Solの登場からわずか6日後という異例の速さでSonnet 5.5を投入。Anthropicの危機感がスピードに表れています
6日で返してきた。この応酬自体が熾烈な API 戦争の証拠です。

⑤弱点は「構造理解」と「確認不足」

  • ただし構造も確認手順もスキルや文脈で教えれば固定できるので、運用で補正可能
おっちょこちょいは「教えてスキル化」すれば落ち着きます。

⑥指示への忠実さと賢さは本物

  • 画面をちゃんと見ながらツールを多用し、必要な実行だけ記載してストップする適切な判断も確認できました
  • 自分でやると大変な大量入力作業を代行してくれる「業務が一気に軽くなる」体験が魅力
速い・賢い・言うことを聞く。三拍子揃った使い心地です。

ベンチマークで見る三つ巴

3
7/18

⑦知能（IQ）はSonnet 5.5が上回る

  • Artificial Analysis系の総合知能ベンチマークではSonnet 5.5がGPT-6 Solを上回ると紹介されます
  • ただし「知能」は各種テストの複合値で、Solが最も強いフィードバック力・正確性は採点対象に入っていない
  • 数値の読み方次第で評価が変わる、油断できない勝負だという見立てです
ベンチマークに載らない強みが、Solには眠っています。
8/18

⑧実務系「新ビッグスリー」の劇的進化

  • Terminal-Bench 4.0：10.3% → 70.6% へ爆発的進化
  • OSWorld（PC画面操作）：57.0% → 80.1%
  • Chartography（図表・構造理解）：15.6% → 61.6%
IQテストより「働けるか」を測る試験で、一気に躍進。
9/18

⑨速度と「タスクあたり費用」は分担

  • 生成速度はSonnet 5.5が体感で上。Sonnet 5時代からSolより速く、5.5でもこの差を維持
  • 一方でタスクあたり費用はGPT-6 Solが断然効率的。少ない推論トークンで高い精度を出す「推論効率」型
  • AutomationBench-AA・AA-Briefcase・GDPval-AAなど長期実務プロジェクト系でも実働力を示します
「速いSonnet」「安く終わらせるSol」。得手不得手がくっきり分かれます。

3社の効率化戦略マトリックス

4
10/18

⑩三者三様の「効率」の狙い方

Claude＝タスク効率 Sol＝推論効率 Gemini＝スループット
  • Claude：無駄な試行錯誤を排し、少ないステップ・少ないトークンで正確に完了させるタスク効率型
  • GPT-6 Sol：内部推論の最適化とキャッシュ再利用で少ない思考トークンで収束させる推論効率型
  • Gemini（現行3.8 Flash）：圧倒的な低単価と生の生成速度で大量処理を捌く計算効率型
同じ「効率」という言葉でも、三家が狙う場所がまったく違います。
11/18

⑪速度対決：Gemini最速に肉薄するSonnet

  • 生成速度のベンチマークはGeminiが依然トップ。Sonnet 5.5より速い数値が出ています
  • ただし今回の約30%の高速化で、ある局面ではGeminiにも食い込める可能性があると分析
  • Geminiは高速だが精度に難・いい加減なところがあるため、速さだけでは勝負が決まらない
速くて雑、速くて丁寧。仕事で欲しいのは当然後者です。
12/18

⑫「定価は下げず、実効コストを下げる」

  • Anthropicは表向きの定価$2/$10を値下げしない方針を貫きます
  • 代わりに能力とタスク効率を高め、「1つの仕事を正しく終える総コスト」を下げる戦略
  • 価格競争に巻き込まれずClaude＝プロフェッショナル向け高品質AIのブランドを堅持
「値下げせず、効率で安くする」。高度なブランディング戦略です。

用途別・モデルの使い分け指針

5
13/18

⑬結論：タスクの難易度で選ぶ

  • 単純なタスクを大量に回すならGeminiが最適。速さと安さが効きます
  • 難易度が高く間違えられない仕事はGPT-6 Sol。間違いなく正確に終わらせるモデルを選ぶべき
  • 総合・企業タスクはClaude（Sonnet 5.5）が最強と、総合評価でまとめられます
「どのモデルをどの席に座らせるか」が勝負の分かれ目です。
14/18

⑭エージェント用途の現実解

  • エージェント（AT）で画面操作・ツール操作をさせると使い物にならない場面も。ここは現状Solが有力
  • 個人の利用では使用回数（レート）の制約が現実問題。Opusは消費が激しく、Sonnetが実用的
  • 試したLunaは十分に賢いがスピードが足りない。ツール操作が上手く、粘り強いモデルと評価
「どれだけ賢いか」より「その席で仕事が終わるか」。
15/18

⑮新時代のKPIは「仕事の完了コスト」

  • モデル選定の基準は「最高知能の高さ」から「仕事の完了コスト」へ完全に移行
  • 問うべきは「1つの業務を正しく終えるのに何秒・何トークン・何ステップ・何ドルかかるか」
  • 生成速度（tokens/sec）とタスク完了速度（実効速度）は別物。迷走とリトライがコストを膨らませます
「速く喋るAI」より「早く仕事が終わるAI」を選ぶ時代です。

次なる戦場と最終評価

6
16/18

⑯次なる戦場は「Haiku対Luna」

  • Haikuは精度は高くないもののとにかく速い。低価格帯でGemini Flashの市場に食い込む可能性
  • Lunaは粘り強く賢く、ツール使いも上手な「Astraの小さい番」的な存在。ただしスピードが足りない
  • Sonnet 5.5で確立した無駄のないタスク効率がHaiku 5.5に継承されれば構図が動きます
速いHaikuがGeminiを、賢いLunaが上位を狙う。次の舞台も見逃せません。
17/18

⑰Gemini 4が来たらどうなるか

  • 現行Gemini（3.8 Flash）でも最速クラス。Gemini 4登場時のスピードとパワーが最大の見所
  • 速さと引き換えの精度の甘さをどこまで克服するかが焦点
  • 各社とも多数の企業に採用されており、実務での評判が次の選定を動かします
大量処理の王者がより賢くなれば、三つ巴はさらに熾烈に。
18/18

⑱最終評価：速くてバランスの良い本命

  • 実使っての結論は「スピードが速く、バランスが良い」
  • コストもEffort（思考レベル）を上げなければ低く抑えられ、安定・高速・高効率
  • 少しのおっちょこちょいはスキルで補えば安定。爽快感のある使い心地で非常におすすめと総括
賢さ・速さ・操作性。三軸すべて及第点の本命モデルです。
