① 導入 — Copilotの大変革が始まった

00:00〜 Intro
  • Microsoft がCopilotの定義そのものを変更——小さな更新でも新ボタンでもない
  • アプリ構築・タスク実行・睡眠中の稼働までこなす存在へ
  • 「あなたのチャットボットが仕事を獲得した」——ジョーク交じりの衝撃的な比喩
  • ラストの機能が最も驚きだったと予告
チャットボット AIワークフォース 3本柱へ
「Co-pilot is now an AI workforce」——パイロットの補助役じゃなく、もう1つの働く戦力だよ！

② 大転換 — 「話す相手」から「任せる相手」へ

00:20〜 何が変わったか
  • 従来のCopilot＝聞けば答えるチャット相手
  • 新Copilot＝本物の仕事を丸ごと受け取る存在
  • これはUI刷新ではなく役割の変更——使い手側の意識改革が必要
  • 作業時間の使い方が根本から変わるポテンシャル
従来: 質問 回答 ／ 新時代: 指示 → 完遂
「チャットで済ませる」癖がついている人ほど、最初の壁はここだよ！

③ 全体像 — 3つの新ピース

3本柱の構造
  • Home —— Copilotの新しい起点・コマンドセンター
  • Code —— 自然言語でアプリやダッシュボードを構築
  • Autopilot —— 目標を与えれば自律して継続稼働
  • この中で最も衝撃的なのは Autopilot と予告
Home Co-work（仕事委任） Code（構築） Autopilot（自律）
Home と Co-work は表裏一体——Home が入口で、Co-work がその働き方なんだ！

④ Copilot Home — 新しいコマンドセンター

00:59〜 Copilot Home
  • Home はCopilotを開いたときの新しいスタート地点
  • 起動するとChat と Co-work の2モードが登場
  • 「あなたのコマンドセンター」という位置づけ
  • やりたいことの規模でモードを使い分ける設計
Copilotを開く Home Chat ／ Co-work を選択
まず「今日はどっちのモードで働くか」を選ぶ——それが新しいCopilotの所作！

⑤ Chat と Co-work はここが違う

01:11〜 Co-work
  • Chat＝軽い質問・速い回答——例「AI自動化ビジネスのマーケ案を5つ」
  • Co-work＝仕事の丸投げ——例「調査し、戦略を組み、メッセージを書き、ローンチ計画を完成させろ」
  • Co-work は毎ステップの監視が不要—— babysit しなくていい
  • 「質問する」から「課題を任せる」への発想転換
Chat: 聞く 答えをもらう ／ Co-work: 任せる 成果物を受け取る
同じ依頼でも「ヒントが欲しい」か「完成品が欲しい」かでモードを分けるのがコツ！

⑥ マインドシフト — あなたは「作業者」から「ボス」へ

01:11〜 続き
  • Chat の世界ではあなたが作業者——考えるのも手順も自分
  • Co-work ではあなたがボス——望む結果を言うだけ
  • ステップ実行はCopilotが担当
  • 結果——時間とエネルギーの大幅節約
あなた: 何を望むか Copilot: どうやるか
「AIの使い方を覚える」より「部下への出し方を覚える」方が大事になる時代！

⑦ Word・Excel・PowerPoint がCopilotに直結

01:51〜 Office files
  • チャット内で本物の Word 文書を生成
  • 本物の Excel スプレッドシートもそのまま作成
  • 本物の PowerPoint デッキまで Copilot の中で完成
  • ファイルは接続されたまま——後から実アプリで開いても変更が同期、コピペ不要
チャットで依頼 ファイル生成 実アプリで継続編集
「AI出力を人力で整形する」手間が消える——ここが地味に大きい！

⑧ 実演 — 1つのアイデアから3つの実ファイル

01:51〜 続き
  • 「中小企業向けAIサービスの1枚ローンチブリーフを作って」→ Word が完成
  • 「これを7スライドのプレゼンにして」→ PowerPoint が完成
  • 「リード・転換率・予測を含むExcel シートを作って」→ 表が完成
  • 数時間かかった作業が数分に——1会話で完結
1つのアイデア 3つの実ファイル（1会話で）
「白紙を凝視する恐怖」から解放される——始めにアイデアがあれば、ファイルのほうから現れる！

⑨ Microsoft の戦略 — 「既に使う道具」の中にAIを

03:20頃〜 裏の狙い
  • 多くの人は新しいツールを学びたくない——仕事が終わればいい
  • みんな既にWord・Excel・PowerPointを使っている
  • だから既存ツールの中にAIを組み込むのが正解
  • 複数アプリやタブを行き来せず1か所で完結——後から実ファイルで普通に編集
学習コスト最小 定着しやすい 仕事が速くなる
「AIアプリを探させる」んじゃなく「AIを既存の仕事場に届ける」——勝ち筋が違う！

⑩ Code — プログラミング不要でアプリが立つ

03:47〜 Code
  • この機能には解説者も顎が外れたと衝撃を表明
  • やり方は平易な英語（自然言語）で描写するだけ——コード知識不要
  • アプリ・ダッシュボード・ツールをその場で構築
  • 成果物はモックでも計画書でもなく実際に使える道具
アイデアを言葉にする Copilot が構築
「Build me a...」と話しかけるだけで開発が始まる——プログラマーではない人ほど恩恵が大きい！

⑪ 実例 — リード管理ダッシュボードを口頭で発注

03:47〜 続き
  • 項目指定——リード名・会社・流入元・ステータス・次回フォローアップ日
  • ステータスと流入元のフィルターを追加
  • リード合計のサマリーと流入元別のグラフもリクエスト
  • 仕上げの指定——「非技術者の経営者にも分かるシンプルさで」
描写する Copilot が構築 クリックできる道具が完成
「欲しい道具の説明」さえできれば、誰でも発注者になれる——これがCodeの本質！

⑫ 何が変わる — 開発者待ち・往復・断念の撤廃

04:30頃〜 意義
  • 以前は自社ツールの制作に開発者・時間・何往復もの調整が必要
  • これからはアイデア → 説明 → 完成の3ステップ
  • ビジネス・エージェンシー・コミュニティ運営者は技術チームを待たない
  • 頭の中で眠っていた小さな道具のアイデア（タスク管理・リード一覧・チーム用ツール）が言葉にするだけで形になる
断念していたアイデア 動く道具
「大きすぎる・難しすぎる」と諦めていた道具たちが、声に出すだけで試せる時代！

⑬ Autopilot — 最も驚いた機能はこれ

05:19〜 Autopilot
  • Copilot がデジタルチームメイトに変わる瞬間
  • 毎回プロンプトを打つ必要なし——待つのではなく自分で動く
  • 設定は3つだけ——名前・役割・目標
  • 会話を監視・フォローアップ・繰り返し作業を実行——話しかけていなくてもプロジェクトを継続
名前 役割 目標 自律稼働
新人採用と同じ——「君は誰で・何の担当で・何が成功か」を伝えて、あとは働いてもらう！

⑭ AIフォローアップアシスタント — 実務ユースケース

06:07〜 Follow-Up Assistant
  • Microsoft 公式例——サプライヤーレビュー業務を委任: スケジュール構築・計画・会議準備・フォローアップ・重要事項の報告を丸ごと
  • 実務版——「あなたはフォローアップアシスタント、目標は週次リードフォローアップの管理」と任命
  • 未接触のリードを把握し、優先度順のメッセージ下書きを準備——重要案件は要通知
  • 毎週監視を継続——1回きりでない「続く仕事」をAIが保持
うっかり防止: 忘れていたメッセージ・フォロー・会議準備 AIが継続カバー
「裂け目に落ちて消える仕事」を担当させる——これが Autopilot の一番しっくりくる使い方！

⑮ Microsoft IQ — チーム横断のビジネス文脈

07:00〜 Microsoft IQ
  • 「Autopilot は何が重要かをどう知るのか？」への答え
  • Microsoft IQ はCopilotにビジネス文脈を接続
  • 現在のチャット内だけでなくチーム横断のデータを理解
  • 判断の材料が組織まるごとの文脈に広がる
チャット内の知識 組織全体の文脈 的確な自律判断
自律的に動くAIほど「何を根拠に動くか」が命——IQ はその土台を渡す仕組み！

⑯ ロールアウト — 誰が今使えるのか

07:15〜 Rollout & Preview
  • Home と Code はゆっくり段階展開中
  • Code はFrontier Firstプログラム経由で先行提供——今年中により広く
  • Autopilot はプライベートプレビュー——当面は限られた少数のみ
  • 手元のアカウントに無くても使い方を間違えているわけではない——解説者は誇大宣伝なしの誠実な情報提供を宣言
提供状況: Home／Code＝順次展開・Autopilot＝Private Preview
「まだ使えない」を隠さず最初に教えてくれる——こういう誠実なアップデート解説が信用できる！

⑰ Copilot Command Center「Today」も準備中

07:28〜 Command Center
  • Today＝メール・カレンダー・会議・タスクを横断眺望するコマンドセンター
  • そのうえで本当に注意が必要なものだけを教えてくれる
  • まもなくプレビュー予定と Microsoft が言及
  • さらに Teams 内の共有 Copilot（アプリ）も拡大——チャットや会議で文脈と権限をチーム共有
メール カレンダー 会議 タスク 「今日何をみるべきか」
個人アシスタントの完成形がもう見えてる——情報を「探す」から「指し示される」へ！
