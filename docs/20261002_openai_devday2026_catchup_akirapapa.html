③ Dots — ChatGPTの中に住むAI秘書

01:29 Dots
  • DevDay 2026の目玉発表の一つ——ChatGPTの中に住むAI秘書として位置づけられる「Dots」

ChatGPTに住む 指示を出す 秘書が処理

④ Space — Notionのようなページ

05:09 Space
  • Dotsと合わせて発表された「Space」——Notionのようなページを作れる機能
  • Dotsが情報を集めてSpaceにまとめてくれる——秘書の作業結果がページとして残る

  • 既存ツールとの比較——どこが同じでどこが新しいかを整理
Dotsが働く Spaceに残る 人が編集・活用
AIの仕事の成果物が「ページ」として形になる——DotsとSpaceはセットで捉えたい！

⑤ Spaceの編集とDotsの電話

11:58 Edit & Call
  • 生成されたSpaceは人間側でも編集可能——AI任せきりにしない協働スタイル
  • 目を引いたのがDotsの電話機能——AIが実際に音声で電話をかけて用件を伝える
  • レストランの予約など音声での実務タスクをAIが代行する未来が一気に近づく
  • デモの品質と実用性を冷静に評価——盛り上がりすぎず本当に使えるかを見極め
ページ編集 電話代行 実務の自動化
AIが電話をかける時代——「便利」と「怖い」の両方がリアルに感じられたシーン！

⑥ Dotsの使いどころ・料金

19:01 Use-cases & Pricing
  • 向く場面：情報の収集・整理・予定の調整など「繰り返し起こる雑務」
  • 向かない場面：判断の責任が重い業務や機微な対応は人間のままで
  • 料金体系の解説——使い込むといくらになるか、イベント連動の提供条件も言及
  • 提供範囲・料金は当日時点の情報で変更されうる——公式情報の併用確認を推奨
任せるタスク選び 料金を試算 投入判断
「便利そう」で飛びつく前に、料金と向き不向きを冷静に計算する視点が大事！

⑦ 新モデル GPT-6.1 Sol と Ultrafast

22:06 New Models
  • GPT-6.1 SolとUltrafastという2系統の新モデルが発表
  • 考え方の軸は「深く考えるモデル」と「とにかく速いモデル」の使い分け
  • Ultrafastは即答系・大量処理向け——応答速度が体感を変える場面で活きる
  • Solは複雑な推論・長い思考が要るタスク向け——使い分けの目安を具体的に提示
速さ要る場面 → Ultrafast ／ 考える場面 → Sol
「どちらのモデルを使うか」自体が新しい設計判断になる——使い分けの目安が判りやすい発表！

⑧ Decisions API — 選択肢から判断するAPI

25:10 Decisions API
  • 「選択肢から判断する」ための新API——分岐の決定をAPIに任せる考え方
  • 従来はプロンプトで「選んで」と書いていた部分を構造化されたAPI呼び出しに置き換えられる
  • ワークフローの途中でAかBかを機械的に決める箇所に fits する設計
  • 「判断」をどこまで外部委託するかの設計思想の変化として注目
// イメージ
POST /v1/decisions
{ "options": ["A案", "B案"],
  "context": "前提…" }
「判断」までAPIになる——プロンプト設計の常識がアップデートされそうな発表！

⑨ Agents API — コンピュータ・ユース

27:08 Agents API
  • DevDay 2026のもう一つの柱——Agents APIのコンピュータ・ユース
  • 画面操作をAPIで呼び出せる——人間がブラウザやアプリを叩く操作をエージェントが代行
  • スクリーンショットを見て解釈し、クリック・入力・遷移を繰り返してタスクを完遂する流れ
  • APIがないサービスとも自動化できる可能性が大きく広がる点が本セミナー後半の主題
指示 画面を見る 操作する 完遂
「APIがないサイト」も操作できる——自動化の守備範囲が一気に広がる発表だった！

⑩ Sign in with ChatGPT

29:30 Sign in with ChatGPT
  • 「Sign in with ChatGPT」——ChatGPTアカウントで他サービスにログインできる仕組み

  • 開発者側はログイン導線の新選択肢——影響範囲は開発者全体に及ぶ可能性
ChatGPTアカウント 他サービスへログイン
認証の世界にChatGPTが入ってくる——地味に巨大なインパクトかもしれない発表！
