④ セットアップと使用量の確認

02:11 セットアップ・使用量確認
  • セットアップはシンプルな手順で完了——複雑な初期設定に悩まされない

導入 使用量を見える化 安心して運用

⑥ ブラウザ連携 — 作りながら即プレビュー

03:06 ブラウザ連携
  • エディタ画面と横に浮かせたブラウザでプレビューしながら作業を進められる
  • アプリを切り替えず同一画面で確認——Web開発の往復作業が消える
  • エージェントが書いたコードの結果をすぐ目で確認できるフィードバックループ
  • 「保存→切替→リロード」の時短の積み重ねが開発体験を大きく変える
指示 エージェントが編集 横で即プレビュー
地味に嬉しいのはブラウザを「横に浮かせられる」こと——作業導線が1本になる！

⑦ フローティングプレビューと Diff 表示

04:09 プレビュー・Diff表示
  • フローティングプレビュー——小窓が浮いて、作業中も常に結果が見える
  • エージェントの変更はDiff（差分）表示で確認——何を変えたか一目瞭然
  • Diffを見てから受け入れるか判断——暴走を防ぐ安全装置
  • プレビュー×Diffの組み合わせでレビュー速度が向上
変更提案 Diffで確認 プレビューで実挙動チェック
エージェントの成果物は「信じる」んじゃなく「見る」——その作法をDiff表示が支える！
