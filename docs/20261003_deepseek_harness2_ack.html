⑤ HTML レポート自動生成

同じ会話の続き
  • 結果を 自己完結型の report.html にまとめて生成
  • ジェネレータ build_report.py を同時に作成——--check オプション付き
  • 計算根拠は calculations.md に文書化
  • すべて修理済みの計算ロジックを再利用——計算の二重実装を回避
# 生成物の関係（イメージ）
report.html        # 自己完結レポート
build_report.py    # 生成スクリプト + --check
calculations.md    # 計算の根拠
「直した計算をレポートでも使い回す」のが秀逸——数字の整合性が1ソースで保たれる！

⑧ Automation tasks の検証

⑨ 4つのモードを整理

モード解説セグメント
  • Standard：普段使いの標準モード
  • PTC：権限・確認を制御するモード
  • Minimal：機能を絞った軽量モード
  • Creator：plugin などを「作る」ためのモード
  • 用途に応じてモードを使い分けるのが Harness 流
Standard（使う）⇄ PTC（制御）⇄ Minimal（軽く）⇄ Creator（作る）
「使うモード」と「作るモード」が分かれているのがポイント——拡張性が設計に組み込まれてる！

# 見積もりの感覚（イメージ）

# × 会話あたりのリクエスト数がコストを左右
