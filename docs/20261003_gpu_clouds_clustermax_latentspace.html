構成 性能 信頼性 障害対応

④ どう評価するのか — 3本柱の調査プロセス

評価方法 Methodology
  • ハンズオンテスト: 実ワークロードをデプロイし、GPU性能からマルチノード学習、ネットワーク・ストレージ・負荷下の信頼性まで検証
  • ドキュメントレビュー: 技術文書・セキュリティ認証・SLA・コンプライアンス体制を分析
  • 顧客フィードバック: 各業界の実際のユーザーから実運用の性能とサポート品質を収集
  • 評価は相対評価: ピア比較で頂点に立つPlatinum/Goldを決定
実機テスト 資料査読 顧客の声 総合評価
「実際にクラスターを回して壊してみる」——これがミシュランとの違い、ClusterMAX流！

⑥ 6段階+αのティア制 — メダルは簡単に貰えない

評価ティア Rating Tiers
  • Platinum 業界最高峰。革新的でユーザーとのフィードバックループも活発
  • Gold 全カテゴリで高評価・改善の余地は小。最良の$/GPU-hrと供給で勝つ
  • Silver まずまずだがGoldとの差は明確 / Bronze 最低基準を満たす「直接推奨の最下位」
  • Underperforming 重大問題あり / Unavailable 未検証（売切れ等）
Platinum Gold Silver Bronze 新ティア「Participation Ribbon」
3.0ではBronzeとUnderperformingの間に新ティア「Participation Ribbon（参加賞）」を新設——その名も「最低限しかやらない」連中へ！

⑦ Platinum — CoreWeaveとNebiusの2強

結果 Results: Platinum
  • CoreWeave は引き続き他が追うべき技術的バーを設定
  • Nebius がPlatinumに新規参入——一貫してプレミアム価格を維持するプロバイダーに成長
  • Nebiusの強い経営判断で、売り手市場の価格でネオラボ一群を丸ごと獲得
  • Platinumの実力: $/GPU-hrが高くてもTCO（総所有コスト）で勝つからプレミアムが取れる
技術のCoreWeave ビジネスのNebius Platinum 2社
「時給が高くても、止まらない・壊れない・直るのが早い」——結局トータルで安い！

⑧ Gold — Google Cloudが参入、Oracleは維持

結果 Results: Gold
  • Google Cloud がGoldティアに新規ランクイン（ハイパースケーラーの本気）
  • Oracle はGoldティアを維持——前回からの安定評価
  • Azure はGoldからSilverに降格
  • ハイパースケーラー vs ネオクラウドの地図が塗り替わる瞬間
Google Cloud昇格 Oracle維持 Gold拡大 AzureはSilverへ
「巨大クラウドだから安心」はもう過去の常識——評価は実力のみで決まる！

⑨ Silver陣営 — Lambda・Fluidstack・Crusoeの明暗

結果 Results: Silver / Bronze
  • Lambda・Firmus・TensorWave はSilverティアを維持
  • GMI はBronzeからSilverに昇格
  • Crusoe はBronzeに降格、Fluidstack はUnavailable（検証不能）へ
  • Silver→Bronze以下への降格ラッシュも多発——全体にハードル上昇
GMI昇格 Lambda維持 Crusoe降格 Fluidstack検証不能
有名どころでも容赦なし——評価は「ブランド」ではなく「クラスターの中身」で！

⑩ メダル獲得は全世界で19社のみ

ハードル上昇 Raising the Bar
  • 評価77社のうち、メダル（Platinum〜Bronze）取得はわずか19社
  • 新ティアParticipation Ribbonに15社——「最低限しかやってない」層を正確に表現
  • 基準は毎回引き上げられ、業界のベストプラクティスが基準線に
  • 意味: 「GPUがある」は差別化にならず、運用品質が全て
77社評価 メダル19社 参加賞15社 残りは要改善
約4社に1社しかメダル無し——「参加賞」ティアの皮肉が効きすぎる！

⑪ セキュリティの衝撃 — SutskeverのPSA

セキュリティ Security
  • 公開前の「R指定のセキュリティ実話」ティザーが話題化 → Ilya Sutskever氏がPSA（注意喚起）を投稿
  • 「ネオクラウドのサイバーセキュリティは限定的。次にエージェントが暴走した時、ネオクラウド乗っ取りを試みるだろう」
  • SemiAnalysisはネオクラウド各社のセキュリティ慣行を実際にプロービングして暴露
  • 対策の柱: SOC 2 / ISO 27001などの基本認証、設定ミス（PCIe ACS有効のまま等）の排除
実地テスト 脆弱性発覚 業界全体のPSA Security基準強化
「Secure by Default」じゃないクラウドは、この先エージェント時代に生き残れない——SCARIESTカード！

⑫ ブラックウェルからベラ・ルービンへ

ハードウェアトレンド Hardware Trends
  • Blackwell / Grace-Blackwell世代のデプロイ状況を全プロバイダー横断で調査
  • 次世代Vera Rubinへの移行計画が既に評価対象に
  • Underperformingの典型: 古いGPUしか提供できない事業者
  • GPU供給はほぼゼロまで逼迫——調達力（Availability）が死活問題に
Hopper完売 Blackwell展開 Vera Rubin予約 勝者は調達力
「最先端GPUを、望むタイミングで、正しく設定されて届く」——この3点揃うだけで上位ティア！

⑬ スケールアウトネットワーク戦争

ネットワーキング Scale Out Networks
  • 大規模学習にはマルチノード間のネットワーク性能が死命的
  • GPUDirect RDMA未有効やPCIe ACSが有効のまま等の設定ミスが失点対象
  • 評価項目: ネットワーク性能・ストレージスループット・負荷下の信頼性を実測
  • Bronze下降格の典型的要因: 不安定なネットワークと曖昧なSLA
実測ベンチ 設定監査 RDMA/ACS検査 ネットワーク格
「GPU台数自慢」より「ノード間が繋がっているか」——マルチノード学習者には命綱！

⑭ 信頼性 — 「GPU 7が止まる」問題

信頼性 Reliability
  • 理想の顧客像: 「ノード19のGPU 7がジョブを止めている理由を調査する工数ゼロ」でいたい
  • 最悪シナリオ: クラスタの4分の1が黙って消えるような運用
  • 良いプロバイダー: 堅牢なヘルスチェック・最新のマシンイメージ・便利な監視を専任チームで維持
  • 悪辣な課金: クラスター構築中やダウンタイム中もGPU時間課金は減点（Underperforming行き）
ヘルスチェック 自動検知 迅速復旧 研究者は研究に専念
「止まった時にどう動くか」でクラウドの良し悪しは決まる——ここぞという時の6時間が全て！

⑮ なぜマネージドクラスターなのか — 経済学

スコープ Scope / 経済性
  • 理想の読者像: 7〜10桁の資金はあるが、UbuntuのバージョンもNATも管理したくないラボ
  • 経済論: ネオクラウドは管理インフラのコストを巨大フリートで償却できる
  • win-win構造: ラボはマークアップを払って良い商品を買い、実験に専念
  • 対象外: 電力付き更地・自前イメージ運用・トークンAPIサービス（マネージドクラスタのみ評価）
フリート規模の経済 専任運用チーム ラボは研究に集中 全員ハッピー
「インフラを背景に消し去りたい」——Stanford中退のSFエンジニア、お察しします（笑）

⑯ 安い時給は罠 — TCOで選べ

価格とTCO Pricing
  • 伝統的な比較軸「$/GPU-hr（GPU時間単価）」だけでは実態を取り違える
  • Platinumプロバイダーは単価が高くてもTCOが良いからプレミアムを取れる
  • 隠れコスト: ダウンタイム・障害調査工数・遅いサポートが積み上がる
  • ClusterMAXはTCO計算機も公開——単価だけでなく総コストで比較可能
激安時給 障害多発 工数爆発 実は高くつく
「1時間あたり数十円の差より、1回の障害で溶ける数百万円」——ケチる場所を間違えるな！
