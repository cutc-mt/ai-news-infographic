② ChatGPT ドット（Dots）

DEVDAY ① ／ 常駐するエージェント
  • チャット画面の左上にある ドット を押すと常駐型のエージェントが動き出します
  • ニュースを定期的に送ってくれたり、カレンダーを見て告知を提案してくれたり
  • イベントのアンケート結果を読んで改善案を言う、海外入金の確認メールを見て「大丈夫ですか」と聞いてくる
  • 頼んでいないのにやっちゃうのが最大の特徴。お節介なくらい勝手に連絡してきます
指示して動く 何も言わなくても動く 見落としを防ぐ
見るのが遅れがちなメールを能動的にチェックして教えてくれるのが嬉しい！

③ GPT-6.1 Sol の登場

DEVDAY ② ／ コスパ最強モデル
  • GPT-6 が出たばかりなのに、さらに GPT-6.1 Sol が登場。Sol は「太陽」という意味です
  • 安いのに、最高級の GPT-6 Astra と同じくらいの精度が出るとの発表
  • スコアの縦軸は Astra が強いままですが、横軸（価格）が圧倒的に左側。まさに「安くて賢い」を実現
  • パソコン全体を操作する コンピューターユース の能力も引き続き利用できます
Astra は高い ＆ 枠が切れやすい 6.1 Sol で安く長く
コストパフォーマンスの高いモデルで、いろんなことができる時代に！

④ 料金プランの再編と値上げ

DEVDAY ③ ／ 月500ドルプラン
  • 新しく 月額500ドル（約8万円） のプランが登場。通常の25倍の容量に
  • ウルトラファスト にも対応。トークンを生成する速度が最大8倍になります
  • 一方で月200ドルのプランは、枠が20倍から10倍に減り、実質2倍の値上げに
  • トークン単価は今後どんどん上がる見込み。企業では トークンマネジメント が重要な論点に
バリューを上げる（分子） コストを下げる（分母） AIの価値が上がる
高い価値を安いトークンで生む力を、値上げの前に今のうちに身につけよう！

⑤ ChatGPT スペース

DEVDAY ④ ／ AIとの共同作業場
  • 左側のメニューに新しい スペース が登場。Notion そっくりの見た目です
  • Google ドライブや Dropbox をつないで、資料を集約できます
  • チャットで依頼したアウトプットがスペースに届き、人間とAIの共同スペースとして使えます
  • データがスペースに貯まるほど他へ移りにくくなる、ロックイン戦略でもあります
パソコンのフォルダ クラウドのスペース AIがいつでも参照
スペースにしかないデータが増えると、ChatGPT を使わざるを得なくなる……！

⑥ MCP イベント

DEVDAY ⑤ ／ 逆方向の依頼
  • MCP は AI とツールをつなぐ口。USBポートのようにGmailなどを読み書きできます
  • 新機能 MCP イベント では、毎回お願いしなくてもツール側から AI に依頼できるように
  • 従量課金の API の代わりに ChatGPT の月額枠で仕事をさせられるハックが可能に
  • ツール専用の画面を ChatGPT 側に出すカスタムUIも作れるようになりました
自分のツールで登録 ChatGPT が調査 結果をツールに返す
実際に調査ツールを作って検証！月額の枠の中で追加料金なしに仕事をさせられました。

⑦ DevDay の API と企業向け

DEVDAY ⑥ ／ 裏側の進化
  • Decision API：文章ではなく意思決定だけを返す、話題の Jev のような仕組み
  • Agents API：ブラウザ操作などの難しい仕事を、OpenAI 側が用意した環境で実行して結果を返します
  • 企業向けには、顧客データを OpenAI が持たない仕組みやプログラムの動作を自動チェックする機能を発表
  • AIエージェントが企業の仕事に当たり前に伴走する未来を全面的にアピール
Decision API（判断だけ） Agents API（難しい仕事） 安全ガード
セキュリティを固める発表がそろい、企業でも安心して使いやすくなりました！

⑧ 自分専用のヘルメスエージェント

SPONSORED ／ Hostinger
  • Hostinger の Hermes エージェント なら、サーバーの知識がなくても自分専用の環境を構築できます
  • 月あたり 1,000円いかない コストで自分専用のロボットを作れます（12か月以上のプランが対象）
  • API キーを貼り付けるだけでセットアップ完了。従量課金なので使い過ぎに注意です
  • 24時間稼働で、データは自分のサーバーに残り、記憶が消えないエージェントに
登録 APIキー設定 自分専用エージェントの完成
使うほど自分専用に育つエージェント。月1,000円弱から試せるのが魅力です！

⑨ Claude Sonnet 5.5

ANTHROPIC ／ コスパ最強
  • 価格はインプットが100万トークンで2ドル、出力が10ドル。GPT-6.1 Sol と同じです
  • 実務タスクのスコアは Sonnet 5 の1,400に対して 1,800。ほとんど Opus 5.5 と同じ水準に到達
  • 動画内のモーショングラフィックも Sonnet 5.5 で作成。Opus 並みの品質を半額以下のコストで出力
  • エージェント的に仕事を任せて完遂してもらう用途にも耐えます
Sonnet 5（1,400） Sonnet 5.5（1,800） Opus 並み
Opus を無駄に使っている人は Sonnet 5.5 への移行を一度試してみよう！

⑩ Claude Code の Mods

ANTHROPIC ／ 開発環境を自分好みに
  • Mods で Claude Code の画面や操作を自分専用にカスタマイズできます
  • トークンの使い方を分析して表示し、気づかないうちの無駄遣いを可視化
  • 「どうしたら軽くなる？」というアドバイスまで出してくれて、設定を変えればどんどん圧縮できます
  • 自作の Mods は配布して共有も可能。便利なカスタマイズが広がります
  • ただし何でもインストールすると悪意ある Mods の危険も。取り扱いには注意しましょう
可視化 無駄を発見 設定を圧縮 コスト削減
「この時は止めてね」「怖い操作の前には必ず確認してね」も設定できる！

⑪ Gem のサービス終了

GOOGLE ／ スキルへ移行
  • 愛されてきた Gem が11月17日で終了し、スキルへ自動的に移行します
  • ChatGPT の GPTs も12月に終了してスキルへ移る流れとほぼ同じ方向性です
  • 幸いなことに Gem には外部接続の機能がなく、そのまま丸ごと移行でおしまいに
  • ただしモデルが勝手に変わる場合も。設定と回答データを保存しておきましょう
Gem を保存 スキルへ移行 同じ入出力かチェック 調整
今の雰囲気や回答に満足している人は、移行後に同じアウトプットが出るか必ず確認を！

⑫ 経緯を記憶する AIアシスタント

SPONSORED ／ Tanka AI
  • 「この案件について決まったこと、変わったこと、未決事項、次にやることをまとめて」と聞くだけ
  • 過去のメールやメモを探し直さなくても、経緯を一気に整理してくれます
  • 整理した内容を踏まえて、確認メールの返信案まで作成してくれます
  • その場で答えて終わりではなく、仕事の経緯を記憶としてつなげて、続きの仕事まで進められるのが特徴です
「どこまで進んでたっけ？」 聞くだけ 経緯も返信案も完成
1か月前に止まった案件も、何分で思い出せますか？専用リンクから無料登録で特典あり！

⑬ Gemini ノートブックの進化

GOOGLE ／ 読むだけではない
  • レポートの中にインフォグラフィックやスライドを埋め込める インタラクティブページが作れます
  • クリックでフラッシュカード・マインドマップ・クイズを追加生成できる仕組みに
  • 動画解説のショートバージョンが日本語対応。約1分で内容を流してくれます
  • 今後は音声の保存や、音声の中に声で割り込んでリアルタイムに会話できる機能も段階的に登場予定
読むノート 見る・解く・話すノートへ
新刊「Geminiノートブック活用大全」も10月20日ごろに発売予定！

⑭ Laya と SLM の時代

OPENSOURCE ／ 判断だけを返す
  • 文章ではなく判断だけを返す 4億パラメータ のオープンソースモデル。Hugging Face で公開中です
  • いけともが検証：200個のデータでフルファインチューニングしたら、かかった時間はわずか10分
  • 記事へのタグ付け比較では、微調整した Laya が8問正解、Jev は5問。Mac mini でも高速に動きます
  • 展望は ループウェアで業務データを溜める × SLM を鍛える × 中古GPU の組み合わせ
業務データを溜める 手元で学習 安心して使い倒す
賢くて小さいAI（SLM）がすごく熱い！Codex にお願いすれば誰でもファインチューニングできました。

⑮ Gemini 4 Argon

GOOGLE ／ ベンチマーク圧倒
  • 公開されている範囲のベンチマークで GPT-6 Astra・Claude Fable 5.1・Opus 5.5 を圧倒
  • 出力は100万トークン。通常の5万～10万と比べて桁違いに長く書き出せます
  • 書いて読んで、また書いて読んでという長時間の作業が1回で可能に
  • 現時点ではセキュリティのため一部の企業限定で提供。今後ウルトラプランや API での登場が期待されます
  • 価格は Sonnet 5.5 や GPT-6.1 Sol と同水準の見込み
読む100万 書ける100万へ 長時間の仕事を一気に
「パソコン操作はもう人間より上手いのでは？」という声を、さらに上をいくクオリティで更新！

⑯ 安全への大増資と歯止め

ANTHROPIC ／ OPENAI ／ NVIDIA
  • Anthropic が近く上場へ。2兆ドル規模で SpaceX を超える史上最大級の IPO と言われます
  • 目論見書（S-1）には80ページに及ぶAIリスクの記載。自己停止の阻止や情報の隠蔽、脅迫などの懸念を明記
  • OpenAI は GPT-6.1 Astra の公開を中止。許可範囲の遵守や報告の面で基準に届かなかったため
  • NVIDIA は実行環境の OpenShell と、チェック用AI Sentry（BlueField 上）を分離して多重ガードに
賢すぎるAI 安全基準で止める 調整して公開
業界全体で「安全にどれだけコストをかけるか」の綱引きが始まっています。上場は安心材料の一つに。

⑰ メガテックの野望

META ／ AMD ／ INSTINCT
  • Meta の消費者向けAIアプリ MUSE は公開3週間で500万ダウンロード超え。チャットアプリを上回るペースで1位に

  • ただし旅行会社から収益を得るモデルには、ユーザー側に立つのかという論点も
SNSの中のAI 単体アプリ 企業向けと外の世界へ
三強に次ぐ第四極としてメタが浮上。画像生成も安くて高精度と、いけともが検証済み！

⑱ AIと社会の現在地

SOCIAL ／ 詐欺と給与の話
  • 石川県で社長になりすまし詐欺により1.5億円の被害。メールから始まりLINEグループで振込を指示されました
  • 上半期だけでも全国で約130件、被害総額は約40億円。AI音声の電話も登場し、ますます精巧に
  • 対策は「自分から既知の連絡先に電話する」「手順通りにやる」「合言葉を決める」の3か条
  • 京都の旅館 nazuna はAI活用で外注費を月25万円から2万円に。その原資で全社員の年間給与を一律50万円ベースアップ
  • しかしその裏では、いけとも自身もXの運用や資料作成など3人分の仕事をエージェント化。受注側の仕事は減っていきます
AIでコスト削減 社内は還元 外の仕事は減少 自分の価値をどう作るか
1年前はPulseもGemini 2.5 Flashでした。たった1年で常駐エージェントの時代へ。任せる力と確かめる目を育てよう！
