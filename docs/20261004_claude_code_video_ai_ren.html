① 実験のきっかけ

00:00 オープニング
  • Claude Codeなどで顔出しなしのショートを作らせると、声も見た目も似てしまい、「AIで作ったな」と分かってしまう
  • そこで今回は、画像も動画も声も作れるHiggsfieldをつないでみることに
  • 自分の声は35秒読むだけで覚えてくれて、あとは待つだけで、その声で話す解説が完成
  • 絵柄を変えるだけで、見た目がガラッと変わった
AIっぽい見た目 自分の声とキャラで チャンネルらしいショート
この作り方が分かると、顔出しなしでも自分らしいショートが作れるようになります。使ったプロンプトは概要欄で配布中

② Higgsfieldとは

03:58 Higgsfieldとは
  • Higgsfieldは、画像と動画と声を作る生成AIを1つの窓口で使えるサービス
  • 窓口の向こうには色々な生成モデルがあり、用途に合わせて切り替えながら使う
  • その窓口をClaudeから呼べるようにしたものがHiggsfield MCP
  • 公式の案内では、ClaudeのほかにOpenClawやHermesといったエージェントから同じURLでつなげる
窓口が1つ 中のAIを切り替え Claudeから呼び放題
つまりClaudeは、画像も動画も声も「頼めば作ってくれる手」を持つことになる、という仕組みです

③ 絵の型は22種類

01:25 絵の型は22種類
  • Higgsfieldには解説動画の絵の型が22種類ある
  • 雑誌のような絵から、フェルトのぬいぐるみのような絵まで、幅がとても広い
  • 今回はその中から代表の5つを選び、同じ台本の動画を作ってみた
  • 型の選び方は指示に一言書くだけ
型雰囲気
Editorial雑誌のような固め
Mixed Mediaバランスが良く洗練
Whiteboard Doodleホワイトボードのお絵描き
Studio 3D立体感のある3D
Felt Toyフェルトのぬいぐるみ
今回はこの中から「Whiteboard Doodle」で実験することに。直感的に一番斬新でした

④ 5本を見比べた感想

01:47 5本を見比べた感想
  • 一番好きなのはWhiteboard Doodle。ホワイトボードで見る感じの絵が斬新で面白い
  • Studio 3Dは立体感のあるアクションが素晴らしい。ただ少し子供向けの印象
  • Editorialは固めのチャンネル向け。Mixed Mediaはバランスが良く洗練された感じ
台本も声も全く同じ 絵の型だけ変更 別の動画に見える
Claudeにそのまま作らせると似たような動画になりがち。型を選べば独自性が出せる —— これはかなり押しポイントです

⑤ 役割の分担ははっきり

03:58 分担の話
  • Claudeは台本を書き、プロンプトを組み、できたものを点検して最後にまとめる段取りの役
  • Higgsfieldは画像と、10秒の動画を3本同時に、そして声を作る生成の役
  • 動画3本はHiggsfieldの側で同時に作られる
  • だからClaudeは、手順を組んでできたものを確かめる役にも回れる
Claude（段取り・点検） Higgsfield（画像・動画3本・声）
業務の分担がはっきりしているので、私は最初に指示を出すだけで済むのが楽でした

⑥ 中で動くAIを選ぶのはClaude

04:42 中のAI
  • 画像はSeedream 5.0 Pro
  • 動画はMiniMax H3
  • 声はElevenLabsのエンジン
  • どれを使うかは私が選んだわけではなく、Claudeがコンシェルジュのように用途に合うものを選んで頼んでくれた
モデル名を知らなくても 作りたいものを伝えるだけで 最適なAIに発注
AI動画や画像を触っている人なら聞いたことがある名前ばかり。それが1つの窓口で自動で選ばれます

⑦ 30秒でつなぐ

05:58 30秒でつなぐ
  • ClaudeのデスクトップアプリでSettingsを開き、Connectorsを選ぶ
  • Add custom connectorを押して、URLに mcp.higgsfield.ai/mcp を貼る
  • 「続ける」を押して、アクセスを許可すれば接続済みになる
  • Claudeは無料プランでも1つまでカスタムコネクタを追加できる（生成にはHiggsfieldのクレジットを使う）
Settings Connectors URLを貼る 完了
ブラウザ版のclaude.aiでも同じ手順で30秒で終わります。Higgsfieldへのリンクは概要欄の1行目にあります

⑧ Claude Codeなら2行

06:26 長く使うならこの2行
  • デスクトップアプリのコネクターは、作業の途中で2回切れてしまった
  • そこでClaude Codeに直接つなぐことに。この方法にしてから接続が安定した
  • この2行はClaude Codeにそのまま教えれば、つなぐところまで進めてくれる
# 1つ目: Higgsfield MCPを追加
claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp
# 2つ目: サインイン
claude mcp login higgsfield
長く使うなら断然こちら。2行のコマンドとプロンプトは、全部概要欄に置いてあります

⑨ 声を選ぶ落とし穴

07:04 「太郎」の落とし穴
  • 名前が太郎でも、日本語の声とは限らない。実際に読ませてみると外国人っぽい声だった
  • モデル名や数字をそのまま書くと崩れる。「Claude Opus」がクラウダスと読まれたりする
  • そこでカタカナで「クロード・オーパス・5.5」と書くと、その通りに読んでくれた
  • 試した中で日本語が安定したのはElevenLabsのエンジン。男性の声はKen、女性の声はHanaを選んだ
英字と数字はカタカナ 読みが崩れない 日本語が安定
日本語で作るなら「カタカナで書くこと」と「エンジンと声の選び方」がとても大事、という教訓です

⑩ 35秒の録音で自分の声に

07:45 声の聞き比べと35秒の録音
  • 「自分のAIクローンを作って」とClaude Codeに言うと、録音画面を作ってくれた
  • Start Recordingを押して、35秒読むだけ。そしてCreate Voiceで完了
  • 「こんにちは、れん学長です」も、ちゃんとチャンネルの口調で読み上げてくれた
  • イントネーションの切り方が完全ではないけれど、まあまあ自然に仕上がった
35秒読む Create Voice 自分の声で解説
ホワイトボードに頼めば、こんな画面もすぐ作ってくれる。これもClaude Codeの実力です

⑪ 指示はたった1回

09:33 指示は1回・実際のプロンプト
  • 書くことは素材への型（パス）、声、字幕の4つ
  • 今回の素材は、前回のクロード・オーパス5.5の動画の文字起こしを1つ渡しただけ
  • 事実は素材にあることだけを使い、数字や固有名を創作しないと先に決めておく
  • 作る途中で質問されそうなことは最初に全部書いておくので、そのまま最後まで進む
素材と設定を書く 質問なしで進める 完成まで放置
縦型（9:16）30秒・字幕あり・サムネイルなし、といった設定も「質問せずにこの値で進める」と書いておくのがコツ

⑫ 日本語で作るための決まり

09:52 日本語のための決まり
  • 読み上げの文では、英字の製品名と数字をカタカナで書く（例: クロード・オーパス・5.5）
  • 1場面（10秒）の読み上げは40〜50字に収める。長ければ文を削る（早回しはしない）
  • 語数・話す速さ・字幕の一致度の検査は日本語では不合格になるので外して、読み上げの時間と文字起こしで中身を確かめる
  • 読み上げの文と、画面に出す字幕の文は分ける。字幕は1枚20字以内
  • 生成する絵の中には文字を描かせない。待つときはターンを終えずに待つ
この決まりを番号付きで並べておけば、プロンプト1回で最後まで進んでくれます

台本と画像を用意 動画3本同時生成 声と動画をつなぐ 字幕を入れて完成

⑮ シェルティ君を1枚渡すと

12:46 シェルティ君を1枚渡すと
