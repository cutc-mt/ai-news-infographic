⑤ 「スキル」とは何か

02:50 スキルの正体
  • スキル＝編集の手順書。ルール・工程の順番・実行コードをまとめたセット
  • Claude Code／Codexがスキルを読み込み、道具を順番に動かす
  • スラッシュコマンドで呼び出し、YouTubeエディット／ショートなど動画種別で使い分け
  • よく使う工程は全部スキル化 量産体制に
# スキル呼び出しのイメージ
/chaen
> youtube-edit   # 長尺の編集
> short-clip     # ショート切り抜き
> news-short     # ニュース動画
「スキルをたくさん作れば量産できる」——プロンプトの使い回しではなく、仕事の手順書を資産化する考え方が肝！

⑥ Claude Code＝作業ハブ

03:40 仕組みの全体像
  • Claude Code／Codex が司令塔（エージェント）として動作
  • 台本や素材をハブに投入し、各種APIを順に呼び出し
  • 持ち込み → カット → 字幕 → 合成まで自動実行
  • 人がやるのは最初の設定と好みを伝えること＋最後の確認だけ
初期設定 素材・好みを投入 AIが全工程実行 人が最終確認
エージェントが各種APIを呼び出して勝手に作ってくれる——人間の仕事は「入口の指示」と「出口のチェック」だけに凝縮！

⑦ API構成マップ

04:30 どの工程にどのAPI
  • 映像生成: Seedance（ニュース冒頭映像など）
  • 音声: ElevenLabs → 最近はGemini 3.8 TTS（より安い）
  • 文字起こし: Whisper（無料だが精度低め → Gemini系にチューニング）
  • 図解: Manim（OSS）／画像: OpenAI画像生成
  • 合成編集: FFmpeg ＋ Python
APIの性能 ↑ 動画クオリティも ↑ ——モデル選びは要チェック
文字起こしや編集には生成API代があまりかからないが、エージェント（Claude Code等）のトークン消費は別途発生——微調整しながら選定！
