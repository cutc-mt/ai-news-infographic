① AIエージェントに動画編集を任せる

オープニング
  • AIエージェントのClaude Codeを使うと、動画の編集をまるごと自動で任せることができるというのが今回のテーマ
  • できるのはカット・フィラーの削除・無駄な余白の削除といった下ごしらえから
  • さらにテロップ挿入・Bロール的なイメージ映像や図の差し込み・画面切り替えのモーションまで自動で入れられる
  • 今回はぶっつけ本番で、脳内編集のまま撮った素材から「ちゃんと編集された動画」ができるまでの流れをすべて見せる
素材を渡す AIが編集 完成動画を受け取る
「AIで動画編集できるようになった」の実力を、事実ベースで包み隠さず検証する回です！

② 見せるのは「指示・時間・料金・出来栄え」

検証の4項目
  • その1：どういう指示を投げたら編集済みになったのか。指示の中身を丸ごと公開
  • その2：どのぐらいの時間がかかったのか。スタートから完成まで実際の時計で測定
  • その3：どのぐらいの料金がかかったのか。クレジット残高の減りをそのまま表示
  • その4：どのぐらいのクオリティになったのか。編集後の動画をノーカットで再生
指示 時間 料金 クオリティ すべてノンフィクションで
嘘偽りなく現状のクオリティをお見せします——それがこの動画の約束です！

③ 秘密兵器は「自作の編集スキル」

スキルの紹介
  • カットの手法・テロップの入れ方・Bロールの差し込み方をまとめたオリジナルのスキルを自作してある
  • スキルの中にはテロップのパターン・モーション・Bロール用の図・切り替えの手法が大量に登録済み
  • 使うときは一覧から好きなものを番号で選ぶだけ。意図したデザイン通りの仕上がりになる
  • このスキルはメンバーシップ向けに無料でそのまま配布。作り方の考え方は無料パートで解説する
編集手法を蓄積 スキル化 番号で選んで使う
「自分が使っているもの」をそのまま配る——メンバーシップへのギブを強化中です！

④ 指示は「動画に向かって」話しかける

指示の入り口
  • 今回の指示の仕方はユニーク。編集してほしい内容を、撮影中の動画に向かって口頭で伝える
  • 「きれいなテロップを入れる」「注目の要素をバーっと拡大する動きをつける」「背景にうっすら音楽を流す」——すべて音声で指定
  • 細かい注文も口頭で：注目してほしい箇所は赤字で少し大きく・テロップは画面下中央から動かさない・シュッと流れる感じで
  • 「4つの項目を出すときの図をアニメーションで作って、撮影素材はワイプで小さく隅に置いて」などの演出指定も可能
動画を撮りながら指示 動画自体が指示書になる そのまま丸投げ
文章で指示を書かなくていい——動画そのものが指示文を含んだ素材になるんです！

⑤ 編集パターンは「番号」で指定

スキルの使い方
  • テロップの動きはM005を指定。「M005のテロップの動きでやってほしい」と伝えるだけ
  • 図の差し込みはBR002のホワイトボード手書きを選択。Bロール的な説明映像が入る
  • 画面の切り替えは最初「下から押し出し」を考えたが、画角の机との違和感で却下。ぼかしクロスに決定
  • エフェクト類も追加で指定。迷ったら「適当でいい」と投げるのもAI編集ならではの楽さ
パターン一覧を見る 番号を口頭指定 デザイン通りに仕上がる
「番号を指定してやっていくタイプ」——好みのデザインを番号で呼び出せるのが強い！

⑥ Opus 5.5に「そのまま丸投げ」

実行の宣言
  • 使うのはClaude Code の Opus 5.5。スキルを指定して動画を渡すだけで、追加の指示はしない
  • なぜなら撮影中に話した指示が、動画の中にすべて入っているから。動画をポンと渡すだけで完結
  • モデルは1Mコンテキスト版を使い、エフォートレベルは「ハイ」に設定
  • 「1発でうまくいくと思うけど、うまくいかなかったらそのまま出します」とノンフィクションを宣言
スキルを選ぶ 動画素材を渡す 完成を待つだけ
撮って話すだけ→あとは丸投げ。ここにAI編集の本丸があります！

⑦ 料金を測るために従量課金へ

クレジット購入
  • 料金を正しく測るため、サブスクではなくClaude Console のクレジットを使う方式に切り替える
  • クレジットを200ドル分購入。残高は210ドルになった
  • Claude Code のログインで「Anthropic Console アカウント」を選び、APIキーによる従量課金モードに変更
  • 動作確認に「こんにちは」と入力すると残高が少し減り、課金が反映されたことを確認
クレジット購入 従量課金へ切替 測定開始（残高209ドル）
209ドルの状態からスタート——ここからいくら減るか、しっかり見届けます！

⑧ 一覧サイトで選んで「指示文をコピー」

スキル選択の実演
  • 自作スキルにはテロップのパターンを一覧表示するウェブサイトが付いている
  • 使いたい項目でプラスボタンを押すと選択状態に。テロップ・図・切り替え・エフェクトを順に追加
  • 最後に右下の「指示文をコピー」を押して、Claude Code にそのまま貼り付け
  • これでスキルと個々の動き・切り替えの指定が選択済みの状態で AI に渡る
一覧から選ぶ 指示文をコピー 貼り付けて実行
今回は動画内指示だけでも動くけど、念のためコピー方式もおさらい！

⑨ 渡す素材は「映像と音声」の2つだけ

素材の説明
  • 普段の撮り方はカメラで撮ったきれいな素材と、音声だけを録音した素材の2つを用意
  • 音声は画面収録の全編黒画面・音声のみのファイル。「音声は黒画面のほうを使って」と一言追加で指示
  • 動画素材の長さは9分30秒。この長さの編集にどれだけ時間と料金がかかるかを検証
  • 開始時刻は午前10時半。ここから秒数を測っていく
カメラ映像 音声ファイル 送信 計測スタート
指示はこれだけ——あとは編集が完了するのを待つだけです！

⑩ 待っている間は「外出してOK」

待機の工夫
  • 編集にはかなりの待ち時間があるので、画面は早送りで放置することに
  • Claude Code にはリモートコントロール機能があり、スマホから承認作業ができる
  • 承認をスマホでポチポチすればいいので、放置している間は外出してオッケー
  • 実際にこの間、外に出て過ごしていたとのこと。パソコンの前に張り付く必要がない
送信して離席 スマホで承認 完成通知を待つ
張り付き作業が不要——これが「丸投げ編集」の大きな魅力です！

⑪ 裏では文字起こしツールが必須

環境構築の注意
  • AIが裏で動かしていたのは文字起こし処理。WhisperやGeminiのAPIなどがバックグラウンドで使われる
  • 自分で作る人は文字起こしの環境も用意しておかないと動かないので注意。無料で使えるものでも可
  • 今回はClaudeの料金だけを測る検証なので、文字起こし側の料金は計算に入れない
  • どちらが使われるかは指示していないので不明。環境の用意自体もClaude Codeに依頼すればOK
音声素材 Whisper / Gemini で文字起こし 編集に活用
実は裏方の文字起こしが生命線——環境を忘れずに用意しましょう！

⑫ スキルの作り方は「AIと詰める」だけ

作り方の解説
  • 手順1：サンプル素材を用意して「テロップを入れて」「エフェクトを入れて」「Bロールを入れて」と指示。ある程度はそのまま動く
  • 手順2：フィラーカット・余白削除・言い間違いのカットもお願いすると、これも概ねうまくいく
  • 手順3：参考にしたYouTube動画からテロップの表現を10パターンほどコピーして「スキルに保存して」と伝える
  • 手順4：一覧表示するウェブサイトを作ってと頼めば、選択画面つきのUIができあがる
ざっくり指示 パターンを蓄積 選択UI化 誰でも作れる
どのAIが何を得意とするか把握してから、AIと一緒に詰めていく——これが作り方のすべて！

⑬ 「ジェットカット」の概念を仕込む

カット指定の工夫
  • YouTube動画は余白が少なくパパッと切るジェットカットの概念を、スキルにしっかり入れてある
  • 一方で繰り返しの強調で同じ言葉を何度も言う場面は、あえてカットしない指定に
  • カットするのは本当に言い間違えて取り直した「シーン」だけという判断基準を仕込む
  • ポッドキャスト風ならジェットカットしなくていい、など形式による調整もAIとのやり取りで詰める
言い間違いだけ切る 強調は残す 形式に合わせて調整
「どこを切ってどこを残すか」——感覚の部分こそスキルに刻んでおく価値あり！

⑭ うまくいった流れは「再利用」する

スキルの育て方
  • 「このパターンがめちゃくちゃうまくいった」となったら、その流れを一覧にYouTube動画編集用として保存
  • 次からはそこを1個選択するだけで同じ流れを再現できる
  • 特徴的なテロップや図を差し込みたくなった時だけ、別の要素を選んで同じように編集させる
  • 使うたびに良い流れをストックしていくので、スキルがどんどん賢くなる
実行する 良い結果を保存 次は1クリックで再現
編集の「当たり パターン」をため込むほど楽になる仕組みです！
