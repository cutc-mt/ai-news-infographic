大企業の96%が情報漏洩——ランサムウェアの入口は「認証情報」

ホワイトハッカー西尾素己さん×ジョーシス松本恭攝さんが明かす、サイバー攻撃の実態とAI時代の対策を18枚のカードにまとめた
🎬 【大企業の96%が情報漏洩】パスワード変更は無意味？／ランサムウェアの入口は認証情報／ホワイトハッカーが明かすサイバー攻撃の実態とAI時代の対策 — PIVOT公式チャンネル（2026年10月5日時点の内容）

① ホワイトハッカーと経営者の対談

00:54 オープニング
  • PIVOTのインタビュー番組& questions。今回はジョーシスの提供で、「日本企業が知るべきサイバー攻撃の実態と対策とは」をテーマに対談が始まる
  • 西尾素己さん：東京大学先端科学技術研究センターの客員研究員。10代前半からホワイトハッカーとして活動し、200以上の脆弱性を報告してきた
  • 松本恭攝さん：ジョーシスの社長。2009年にラクスルを創業し、上場とMBOを経験したシリアルアントレプレナー
  • 番組は3つのキーワードに沿って進行：現在値・攻撃の実態・対策
攻めるより守る方が難しい 脆弱性を先に見つけて報告 ホワイトハッカーの精神
「悪さをするより、守る方がかっこいい」という教育を受けて育ったホワイトハッカー！

② ラクスル創業者が挑む「認証情報」

02:00頃 ゲスト紹介
  • ジョーシスはSaaS管理で知られる会社だが、今大きく変革の最中。松本さんがラクスルの次に選んだ課題がサイバーセキュリティだった
  • 日本企業がランサムウェアに狙われる大きな原因の一つが認証情報。つまりIDとパスワードの漏洩
  • 社員・業務委託先まで、あらゆるソフトウェアのIDについてルールを決め、AIがモニタリングして攻撃されない状態を保つ「アイデンティティセキュリティ」を提供する
  • 海外では大きなマーケットで、クラウドとリモートワークの時代にこそ重要になる領域
IDのルールを決める AIがモニタリング 攻撃されない状態を維持
「解決したい課題」の延長線上にセキュリティがあった——ラクスルと同じ発想！

③ なぜ今、日本が狙われるのか

04:03 日本のランサムウェア被害
  • かつてサイバー攻撃の被害は英語圏に集中していた。言語の壁が攻撃のコストになっていたため
  • しかしAIの発達で攻撃者は日本語のフィッシングメールを一瞬で書けるようになった。かつて「日本語が変だな」と感じた怪しいメールが、最近はほぼ消えた
  • 観光のたとえ：看板の英語表記や翻訳アプリで言葉の壁が消え、日本への観光客が増えたのと同じ構造がサイバー攻撃でも起きている
  • 「意外と日本、攻撃成功したよ」という噂が広まり、今まさに日本ブームが起きている
AIで日本語の壁が消える 攻撃成功の噂が広がる 攻撃者の日本ブームへ
サイバー攻撃界隈での「日本ブーム」——まったく嬉しくないブームです……

④ 対策が甘いのに経済規模が大きい

05:30頃 ブームの背景
  • 日本には島国文化がある。地上で国境を接さないため、攻め込まれた歴史の意識が薄く、危機感が育ちにくかった
  • その結果、サイバーセキュリティ対策が甘い。一方で意識の高い企業の対策水準は伸びている
  • 対策が甘いにもかかわらず経済規模が非常に大きい。攻撃者から見れば「すごい金脈」に見えてしまう
  • 狙う側のリターンが大きく、守る側のコストが追いついていない構造的な問題
危機感の薄さ 対策の遅れ 大きな経済 × 甘い防御 = 狙われる
「聖域」だったのはもう昔の話。インターネットに国境はありません！

⑤ 国内の状況は「悲惨」、格差が拡大

07:00頃 国内の現在地
  • 国内の状況を聞かれて西尾さんが即答したのが「悲惨」。手を打つ会社と打たない会社でセキュリティ格差が急速に広がっている
  • 意識は日々のニュースで明確に高まった。ランサムウェアで事業が止まった事例が続いているため
  • サイバーセキュリティは範囲が非常に広い：パソコン、サーバーのデータ、ネットワーク、認証情報、製品のコードなど多岐にわたる
  • 多くの企業が悩んでいるのは「何から順番に手を打つか」。全体の完成図（ブループリント）がなかなか描けない
意識は高まる でも範囲が広すぎる 優先順位の設計に悩む
買い物かごにセキュリティ製品を放り込む前に、完成図を描くことが先！

⑥ 日経225企業の96%が情報漏洩

08:28 大企業の96%が情報漏洩
  • 日本を代表する大企業である日経225企業の96%が、過去3年以内に情報漏洩を経験していた
  • しかもそのうち75%（168社）は深刻な漏洩。深刻というからには認証情報なども含まれるとみられる
  • セキュリティ投資を大量にしている大企業ですらこの数字。日本には中小企業の方が多いのだから、規模を問わず向き合う必要がある
  • 適切なところに投資しなければ、情報はすぐに漏れてしまうという現実
投資はしている それでも96%が漏洩 「投資の場所」が問われる
上場企業のリーダー格ですら96%——「うちは大丈夫」はもう通用しません！

⑦ 漏れて一番困るのは認証情報

10:00頃 漏れてはいけない情報
  • 「漏れて一番困る情報は何か？」——専門家の答えは大昔から変わらず認証情報
  • 認証情報が漏れたら、それを使って攻撃の一番の入り口から侵入されるから
  • 身近なのはIDとパスワード。会社単位では資格情報など、ID・パスワード以外も含まれる
  • 今のサイバー攻撃の多くは、漏れた情報を再利用する攻撃。中でも再利用しやすい認証情報を使った攻撃が非常に活発
認証情報が漏れる 正規ユーザーとして侵入 攻撃の起点になる
合鍵を渡すようなもの。扉や窓を補強しても、鍵を盗まれたら意味がない！

⑧ サプライチェーン経由の攻撃

11:00頃 「中小だから狙われない」は誤解
  • 「うちは小さいから狙われない」「漏れても大した情報がない」——そんな声に西尾さんが返す答えが、サプライチェーン攻撃を意識すること
  • 有名な事例：ある国が欲しかったのは他国の新型戦闘機の設計図。国防省を攻撃するのも一次請け企業を攻撃するのもハードルが高い
  • そこで狙ったのが下請けレベルのメールアドレス。マルウェアをばらまいて複合機に送られる印刷キューのPDFから情報を抜き取った——今も当たり前のように行われている
  • 自分の会社は困らなくても、繋がっている人たちが被害を受ける。大企業は取引先のセキュリティ体制まで見切らないと危ない
標的は防衛省ではなく下請け 複合機の印刷キュー 設計図が流出
グループ1万8000台のPCに10個のアカウント……数えるだけでも気が遠くなります！

⑨ 「サイバー攻撃は人を殺す」

13:42 国内のマルウェア被害
  • 大手飲料会社のインシデント：多くの専門家が認証情報の漏洩からの侵入だったとみている
  • 失われた時価総額は約2200億円。完全に出荷できない状態が6か月続き、売上にも大きく響いた
  • 西尾さんの知り合いの大阪の製造業はランサムウェア被害で会社が倒産。約100人の従業員が路頭に迷った
  • 「サイバー攻撃は人を殺すんですよ。平気で殺します」——ただ、被害を受けないと実感できないのが怖いところ
出荷停止6か月 時価総額2200億円消失 倒産と失職
数字のインパクトだけでなく、その裏にある人生まで見る——対談の核心！

⑩ 攻撃の入口は「脆弱性」から「認証情報」へ

16:43 サイバー攻撃の実態
  • かつての主流は脆弱性を突いて侵入すること。しかしセキュリティ製品の性能が上がり、脆弱性攻撃はやりにくくなった
  • そこで攻撃者は考え方を変えた：認証情報を手に入れて、正面から入ればいい
  • 転機はコロナ禍。リモートワークのために各社が導入したVPN装置は、会社のネットワークへの「中継ドア」
  • 攻撃者から見ればインターネット越しにノックできるドアができたのと同じ。裏口を探さなくても、IDカードがあれば正面から入れる
脆弱性を突く 防御が強化される 認証情報を盗む方針へ転換
VPNは便利な正面玄関——ただし、合鍵（認証情報）さえあれば誰でも入れる！

⑪ インフォスティーラーの脅威

18:50 インフォスティーラーの脅威
  • 侵入経路は昔と変わらない：怪しいメールの添付ファイル、怪しいサイトの閲覧。しかし一度入るとずっとパソコンの中に潜む
  • 作動するのは認証した瞬間。IDとパスワードを入力してエンターを押した時や、VPNの接続ボタンを押した時に、攻撃者のサーバーへ転送する
  • やることが「認証情報を送るだけ」と単純なので、アンチウイルスに引っかかりにくい。エラーも固まりもない、分かりにくい感染
  • 第1世代は2019年ごろに散布されたとされる。それ以来買い替えていないパソコンは、7年間取られ放題の状態もあり得る
添付ファイルで感染 静かに潜伏 ログインの瞬間に窃取 外部へ転送
// パソコンの中での様子（イメージ）
while (true) {
  if (user.login()) {
    send(認証情報, 攻撃者のサーバー); // これしかしない
  }
}
一日400回パスワードを変えても意味なし——ずっと居座られていたら吸われ続けます！

⑫ パスワード定期変更とMFAの本当の話

22:00頃 パスワード変更は無意味？
  • 潜伏されている限り、定期変更はほぼ無意味。「パスワードを変えました」という処理ごと持っていかれ、新しい認証情報を吸い上げられる
  • ただし「盗まれる → 売られる → 使われる」の間にはラグがある。2週間に一度変えていれば、そのラグの分は救われる可能性がある
  • 多要素認証（MFA）も実は盗まれる：認証完了の証である通行許可（クッキー）ごと持っていかれ、翌日はID入力なしで入れてしまう
  • だから答えは通行許可の有効期限を短くすること。長いもので1か月あるCookieの期限が短ければ、盗まれても入り込まれにくい
盗まれる 売られる（ラグ） 使われる 期限内なら変更にも意味がある
MFAをかけて安心ではない——でも「かけていたら入れられない」のは事実。まずは多要素！

⑬ ダークウェブで売られる認証情報

24:00頃 闇市場と分業
  • インフォスティーラーはエコシステムになっている。まず「作って売る業者」がいて、多くの攻撃者がそれを購入する
  • 集めたメールアドレスにばらまけば、そのうち何人かは感染する。大企業に勤める人の認証情報がどんどん集まっていく
  • 集めた認証情報はインフォスティーラーログとして、ダークウェブと呼ばれる闇市場で販売される
  • 買った側はIAB（イニシャルアクセスブローカー）。認証情報で侵入し、絶対に見つからないバックドアを仕込む。それを買うのがランサムウェアギャング（とそのアフィリエイター）
作る業者 ばらまく人 闇市場で販売 IABが侵入 ランサムウェアギャング
闇バイトみたいな分業——ランサムウェア実行役は、実は侵入すらしていない！

⑭ シフトレフト：左側で戦う

28:17 シフトレフト
  • 攻撃者の産業構造にも脆弱性がある。分業化したために盗んだ情報がマーケットに出る——ここが狙い目
  • 自分の組織の認証情報が闇市場で売られていないか監視することは、非常にダイレクトで投資対効果の高い対策
  • 侵入された後（右側）で戦うのは、攻撃者の方が圧倒的に有利。西尾さんはアンチウイルスエンジンを書き、防御製品の回避テストもしてきた実務の研究者
  • だからガバナンスを先に整え、侵入される前（左側）で止める。ITセキュリティはガバナンスが前提
認証情報の窃取 権限昇格 ランサムウェア発動——この「左端」で止める！
「鍵が闇市場で売られていないか見る」——めちゃくちゃ分かりやすい第一歩！

⑮ 意識と実態のギャップ

31:51 企業の対策の実態
  • 中堅・大手企業のCIO200名への調査：84%が認証情報の漏洩を経営リスクとして認識していた
  • 7割が「社内の認証情報はすぐ出ます」と回答。しかし実際にすべての認証情報の一覧を出せた会社はほぼなかった
  • 退職した社員の66%のアカウントが30日以上放置。業務委託先100アカウントのうち33が契約終了後も残存。通販会社の事故は業務委託先の特権管理が原因
  • 投資の上位はネットワーク・エンドポイント・データ。最も遅れているのが認証情報のセキュリティで、「できている」という誤認が被害を生む
84%が経営リスクと認識 実際に一覧を出せるところはほぼゼロ 投資の場所を変える
100ある中の99はできている——でも残る1つの放置アカウントから入られます！

⑯ 見えない・追いつかない・気づかない

34:00頃 認証情報管理の3つの壁
  • 見えない：情報システム部の管理するMicrosoftやTeamsは見えても、営業・マーケ・開発が独自に使うSaaSや個人が作ったAIエージェントは部署ごとに点在する
  • 追いつかない：大手では1週間に1000件以上のアラート。9割は重要でなくても対応が必要で、人がいくらいても足りない
  • 気づかない：96%が漏洩しているのに、漏れている会社自身がインフォスティーラー感染に気づいていない
  • 攻撃者がAIを使い、何十万・何百万の対象に一斉に攻撃できる時代。守る側もAIを使うしかない
Shadow IT アラートの山 気づかない流出 AIによるガバナンスへ
AIエージェントにもカレンダーへのアクセスが——「アイデンティティ」はもう人間だけじゃない！

⑰ ポリシー×AIで24時間365日守る

38:10 ポリシー×AI
  • ジョーシスのサービスは2つの柱：ポリシー（あるべき姿）を決めることと、AIがそのルールを徹底すること。問題があればAIが自動で修正する
  • 対象は社員・子会社・海外拠点・取引先・AIエージェントまで、すべてのアイデンティティ。毎日モニタリングし、違反があれば是正する
  • ダークウェブをモニタリングして流出した認証情報と自社の一覧を突き合わせ、誰の情報がどこで流出したかを可視化。流出した瞬間にアクセスを停止するルールも組める
  • 導入事例（SIer・従業員3000名）：1万7000アカウント・17アプリ・30ポリシーで2か月間に2412件の違反を発見。退職者アカウントの残存やMFA未設定をAIが自動是正した
棚卸し（一元化） ポリシー設定 365日の監視 AIが自動是正
人が全部のダッシュボードを見に行くのは無理——監視と是正はAIに任せる時代！

⑱ 持ち帰りの一言

40:00頃 エンディング
  • 西尾さん：攻撃者が狙う場所は時代とともに変わる。攻撃手法が廃れるのは「対策が進んだ」証拠。基礎的な攻撃を続けるチームも残るので、攻撃者の構造とお金の流れに注目してほしい
  • 松本さん：ランサムウェアから企業を守るのに必要なのは、高度なセキュリティの完備よりも「当たり前のことを当たり前に」やり続けること
  • そのために、あらゆる従業員とあらゆる取引先のIDをしっかり管理すること。日本企業のIDを守ることをミッションに掲げる
  • まずは今日、自社の認証情報の一覧が出るか確かめてみるところから始められる
攻撃者を知る 当たり前を積み重ねる IDの管理から始める
高度な対策の前に、足元の合鍵の置き忘れに注意——まず手持ちの鍵を数えよう！
