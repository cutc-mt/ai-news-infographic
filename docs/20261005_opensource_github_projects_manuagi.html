③ Tile Language：GPUカーネルDSL

01:36 tile-ai/tilelang
  • GPU・CPU・アクセラレータ向けの高性能カーネルを書く、PythonライクなオープンソースDSL
  • 対象はGEMM・量子化解除GEMM・FlashAttentionなど。CUDAを手で調整する代わりに、タイル単位で計算とメモリ移動を記述
  • タイルを共有メモリにコピーしてタイルレベルのGEMMを実行すれば、あとはコンパイラがスケジュールを最適化
  • @tile_lang.jitデコレータでカーネルをPyTorch関数化。NVIDIA・AMD・CPU・MPUに自動最適化。TVM上に構築
pip install タイルで記述 PyTorch関数のできあがり
tile-ai/tilelang
CUDA職人の技をPythonっぽい構文で書ける——カーネル書きには直撃の一本です

④ UniMate：あらゆる骨格を動かす

02:19 Friedrich-M/UniMate
  • テキストプロンプトからあらゆる3Dスケルトンをアニメーション化できるオープンソース基盤モデル
  • 人間・動物・鳥・昆虫・蛇、さらには関節付きオブジェクトまで。スケルトンごとの再学習も推論時の最適化も不要
  • アクションを記述すれば、トポロジーを認識する拡散トランスフォーマーが動きを生成
  • キーフレーム間のブレンド、特定の関節を固定したままのテキスト編集、プロンプト連結によるクリップ延長、FBX/GLBエクスポートに対応
テキストで動作を記述 拡散Tが動きを生成 FBX/GLBへ
Friedrich-M/UniMate
13,000本のクリップで学習済み・MITライセンス。まだ初期段階ながら伸びしろ大です

⑤ Agent Substrate：K8sで agents

03:02 agent-substrate/substrate
  • Kubernetes上に構築された、エージェント的ワークロードを高密度・低遅延で実行するオープンソースシステム
  • アイドル状態のアクターをワーカーポッドのプールにマッピングし、状態を保持したまま一時停止・再開して多重化
  • Kubernetesのコントロールプレーンをリクエスト経路から外し、gVisorでワークロードを分離
  • ADKやLangChainを問わず、kubectlプラグイン経由でどのクラスタでも利用可能
アクターをポッドにマッピング 一時停止/再開で多重化 スケール
agent-substrate/substrate
エージェントを大規模運用するときの「アイドルのムダ」を削る発想が新しい。初期段階の注目株です

⑦ fmt：高速で安全なC++整形

04:18 fmtlib/fmt
  • cstdioやC++のIOストリーム代替となる、高速かつ安全なC++フォーマットライブラリ
  • Python風の構文と位置引数を持つシンプルなAPI。C++20 std::formatとC++23 std::printを実装
  • フォーマット文字列はコンパイル時にチェックされ、ライブラリは完全に型安全
  • 正確に丸められた浮動小数点、Unicode対応、カラー出力・ファイル出力を装備。外部依存ゼロ・ヘッダーオンリーモードも
include して fmt::print 型安全な出力
fmtlib/fmt
C++標準の源泉となった定番 — 追加して出力を整形しよう

⑧ SkillSpector：スキル診断

05:00 NVIDIA/SkillSpector
  • NVIDIAが公開した、AIエージェントのスキルがインストールしても安全かを判定するスキャナー
  • 対象はGitリポジトリ・URL・zip・ディレクトリ・skills.md。指定するだけ
  • 数十種の脆弱性パターン、プロンプトインジェクション、データ流出、悪意のあるコード、サプライチェーンリスクをチェック
  • 2段階パイプラインで静的解析＋オプションのLLM評価を実行し、調査結果・リスクスコア・推奨事項を返す。Claude Code / Codex / MCP対応、CI組み込み可
スキルを指定 静的解析+LLM評価 リスクスコア
NVIDIA/SkillSpector
「便利なスキル」を入れる前にまずスキャン——エージェント時代のウィルス対策みたいな立ち位置です

⑨ FreeLLMAPI：無料枠を統合

05:40 tashfeenahmed/freellmapi
  • 34のLLMプロバイダーの無料枠——635のエンドポイント・月間数十億トークンを1つの/v1エンドポイントに統合するOpenAI互換プロキシ
  • 自動ルーティングとフェイルオーバーを内蔵。カタログが新しいモデルと割り当てを同期
  • プロバイダーのキーはSQLite内でAES-256-GCM暗号化。アプリからは1つの統一トークンに見える
  • ランチャーが認証情報をClaude CodeやCodexの設定から分離。個人利用向けローカルファースト設計
インストール 接続先を指定するだけ 無料枠を束ねる
tashfeenahmed/freellmapi
「どの無料枠が使えるんだっけ？」を1本のAPIにまとめてしまう発想。試すハードルが一気に下がります

⑩ Coucou：ノッチの見守り役

06:22 Louis-CFM/coucou

常駐 ピルで状態表示 ノッチから即承認
Louis-CFM/coucou
待ち時間のターミナル往復がなくなる——地味に効くデスクトップの小道具です

08:42 Droid-Deck/DroidDeck

  • ValveのARM64 Linux版SteamクライアントをBig Pictureモードで実行。独自のインアプリ・コンポジターを採用

Android端末 ARM64 Steam + Proton/Fex Big Pictureでプレイ
Droid-Deck/DroidDeck
