パーソナルAIエージェント比較 — OpenClaw・Grok Bot・dots

寝ている間も自分の代わりに働き続けるAI、どれに任せる？「明かりの消えない3つの基地」に例えて、公式資料だけで4つの軸で検証——18枚で網羅解説
🎬 【パーソナルAIエージェント比較】OpenClaw・Grok Bot・dotsを公式資料で検証 — あきらパパのAI活用学習部屋（2026年10月4日）

① 寝ている間も働くAIが手に入る

導入: 0:00
  • 夜パソコンを閉じて寝ている間も、自分の代わりにメールを片付け、調べ物を進め、朝には報告を置いておいてくれるAIがもう手に入る
  • 登場するのはOpenClaw、Grok Bot、OpenAI の dotsの3つ
  • どれも1度きりの質問応答ではなく、仕事を持ち帰って、指示なくとも実行を続ける「パーソナルエージェント」
  • しかし3つは似ているようでどこが違うのか、ふと気になる——そこで今回の問いが生まれた
寝ている間 AIが仕事を進める 朝に報告 さあ、どれに任せる？
「1回聞いて終わり」のAIとは違い、働き続けるのがパーソナルエージェントです！

② 「明かりの消えない3つの基地」に例えて

検証の見取り図
  • 3つのエージェントを明かりの消えない基地に例える。確かめるのは「どこに立っているか」「燃料はいくらか」「危ない扉の鍵を誰が持っているか」
  • 検証1: 何を任せられて、どこで動き続けるのか（1:09）
  • 検証2: 始めるまでの手間と、毎月いくらか（2:51）
  • 検証3: 危ない操作の扉を、誰が開けるのか（4:13）／検証4: 覚えたこととデータがどこに残るのか（5:23）
基地の場所 燃料（料金） 扉の鍵 記憶の置き場所
4つの軸で並べれば、似ているようで違う3つがくっきり見えてきます！

③ OpenClaw — 自分の家に立つ基地

検証1: OpenClaw
  • 元の名前はClawdbot。そこからMoltbotを経て、2026年1月に OpenClaw へ
  • オープンソースで、今は非営利の財団が運営
  • 自分のパソコンか自前サーバーで「ゲートウェイ」という常駐の仕組みを動かす
  • 指示はTelegram・WhatsApp・Slackなどメッセージアプリから送る。シェルの実行・専用ブラウザの操作・定期実行までこなす
自宅PC／サーバー ゲートウェイ常駐 メッセージアプリで指示
基地が立つのは「自分の家」。パソコンを止めると基地も止まります！

④ Grok Bot — クラウドで働くボット軍団

検証1: Grok Bot
  • Cursor を作る会社（Anysphere）が開発。Cursor はSpaceX に買収されており、App Store の販売元は X Corp.
  • 名前と役割を持ったボットが、ブラウザ・ファイル・端末のついたクラウドのパソコンで働く
  • ノートパソコンを閉じても仕事は止まらない
  • 決まった時刻やメール・Slackの通知をきっかけに動くルーティンも作れる。ボットは何人も並んで働けるが、クラウドPCは自分のボット全員で1台を共有
ボットを何体でも クラウドPCを1台共有 通知・時刻で起動
手元のパソコンは閉じてOK。ボットは会社のクラウドで働き続けます！

⑤ dots — ChatGPT の中の専用クラウドPC

検証1: dots
  • OpenAI の dots はChatGPT の中で働く
  • dot ごとに1体ずつ専用のクラウドのパソコンを持って作業する
  • 自分のパソコンを使わせる機能は最初はオフ
  • 繋いだアプリの情報を自分から読みに行って覚えていく——能動的に学ぶ設計
ChatGPT 内 専用クラウドPC アプリの情報を読んで記憶
「繋ぐ・覚える・働く」のすべてが ChatGPT の中で完結するのが dots です！

⑥ 検証1 判定 — 違うのは「基地の場所」

どこで動き続けるのか
  • 3つとも「閉じても動き続ける」を目指している点では同じ
  • 違うのは基地の場所——OpenClaw は自分の家、Grok Bot と dots は会社のクラウド
サービス基地の場所手元PCの電源
OpenClaw自分のPC／自前サーバー止めると基地も止まる
Grok BotCursor のクラウドPC（米国）閉じても動き続ける
dotsOpenAI の専用クラウドPC閉じても動き続ける
自分の家 会社のクラウド どこに任せるかで第一の選択
場所の選択が、後の「鍵」と「記憶」のあり方をほぼ決めます！

⑦ 検証2 — 始めるまでの手間

2:51 導入の容易さ
  • Grok Botはアプリを入れて Cursor のアカウントでサインインするだけで、最初のボットが用意されている
  • dotsはChatGPT Pro のデスクトップから作る
  • OpenClawはターミナルで1行のコマンドでインストールし、「オンボード」という初期設定へ
  • 使うAIのキーやログイン、メッセージアプリの接続も自分で用意。公式の目安は5分だが、組み立てるのは自分
サインインのみ（Grok Bot） デスクトップから作る（dots） 自分で組み立て（OpenClaw）
手軽さなら Grok Bot と dots。OpenClaw は「自分で建てる」楽しさと手間がセットです！

⑧ 検証2 — 燃料代（毎月いくらか）

入り口の値段
  • OpenClawは本体は無料（オープンソース）。ただしAIのモデル代は別で、API の従量課金か契約中サブスクの枠を使う
  • Grok Botは Cursor の Pro 以上の有料プランに含まれる。Pro は月20ドル／App Store 日本の表示で4,000円から。スーパーグロックの契約をついで使う道も
  • dotsは ChatGPT Pro（月100ドル／App Store 日本の表示で16,800円）から
サービス入り口の値段内訳
OpenClaw本体無料モデル代は別（従量課金等）
Grok Bot4,000円〜／月Cursor Pro（月20ドル）に含まれる
dots16,800円〜／月ChatGPT Pro（月100ドル）から
無料＋モデル代 4,000円〜 16,800円〜（表示元ごと、為替換算なし）
OpenClaw の「無料」は、モデル代と組み立ての手間を自分が持つという意味です！

⑨ 検証3 — dots の4区分ルール

4:13 扉の開け方（dots）
  • dots の操作は「聞かずに実行」「事前承認なら実行」「実行前に聞く」「本人に引き継ぐ」の4つから選べる
  • パスワードの変更と送金は必ず本人に引き継ぎ、パスワードの変更はルールでも外せない
  • 危ない扉の前の見張りは最初からいる設計
聞かずに実行 事前承認で実行 実行前に聞く 本人に引き継ぐ
送金とパスワード変更の扉だけは、最初から本人の鍵で固定されています！

⑩ 検証3 — Grok Bot の承認と本人渡し

4:13 扉の開け方（Grok Bot）
  • 大事な操作の前に「1回だけ許可」「いつも許可」「拒否」を選ばせる
  • パスワード・2段階認証・キャプチャ・支払いは、ボットが入力せず本人に画面を渡す
  • これも最初から見張りがいるタイプ。危ない扉の前に番人が立っている
大事な操作 許可を求める 認証系は本人に画面を渡す
「許可を聞く」か「本人に任せる」か——Grok Bot は扉の前で必ず立ち止まります！

⑪ 検証3 — OpenClaw は鍵の管理が自分

4:13 扉の開け方（OpenClaw）
  • ここが大きく違う——公式の既定ではシェルの実行は確認なし・サンドボックスはオフ
  • 知らない相手からのメッセージは承認するまで止まるが、扉の鍵の設定は自分でする
  • 公式も個人当てのメッセージを完全に自動で送ることは進めていない。下書きを作らせて送るのは自分——この使い方が1番安全
既定は自由 鍵の設定は自分 下書き＆本人送信が安全
自由な分、鍵の管理は自分持ち。見張りは自分で置くタイプです！

⑫ 検証4 — 覚えたことはどこに残るか

5:23 記憶とデータ
  • OpenClawの記憶は自分のパソコンの中のテキストファイル。開いて読めて、書き直せる。ただしAIに送った内容はモデルの会社側にも届く
  • Grok Botは好みや役割、仕事を覚える。ファイルやブラウザーのログインはアメリカにあるクラウドのパソコンに残る
  • dotsの記憶は1つずつ見たり消したりできず、消す時はdot ごと削除
サービス記憶の場所確かめ方
OpenClaw手元のテキストファイル開いて読める・書き直せる
Grok Bot米国のクラウドPCbot を消しても中身は残る
dotsOpenAI 側で管理個別消去不可・dot 単位で削除
記憶を手元で目で確かめたいなら OpenClaw。ここの違いは値段より先に見ておきたい！

⑬ 検証4 — 消し方を始める前に知っておく

データの消去と残存
  • Grok Bot はボットを消しても、そのクラウドPCの中身は消えない
  • Grok Bot で繋いだアプリを外しても、取り込んだ情報は残る
  • dots は記憶を1つずつ消せず、dot ごと削除になる
  • 判定: クラウドに任せるなら「消し方」を使い始める前に知っておくことが大事。ここは値段より先に見ておきたいところ
bot を削除 クラウドPCには残る 消し方を先に確認
「消したつもり」で残るデータがある——使い始め前に消し方を確認です！

6:14 検証の限界

  • 画面に出した実物は、手元に残っていた改称前の旧版 clawdbot（2026.1.24-3）のヘルプ表示だけ

  • 性能の優劣は比べていない。価格は表示元（Cursor 公式・App Store 日本・本体無料）ごとに示し、為替換算はしていない
実演なし 公式資料ベース 性能比較は対象外

⑮ 答え — 「住まい」と「鍵」で選ぶ

6:42 最終回答
  • 答えは性能の順ではない。「どこに住ませて、危ない扉の鍵を誰が持つか」で選ぶ
  • 基地の場所——自分の家（OpenClaw）か会社のクラウド（Grok Bot・dots）か
  • 鍵の持ち主——最初から見張りがいる（Grok Bot・dots）か、自分で見張りを置く（OpenClaw）か
住まいはどこか 鍵は誰が持つか そこから選ぶ
「どれが一番優れているか」より「どこに置くか・誰が鍵を持つか」！

⑯ 3つの使い分け — あなたはどれ型？

結論の使い分け
  • OpenClaw 型: 自分の機械で、鍵の管理まで自分でやりたい人へ
  • Grok Bot 型: パソコンを閉じても、手軽にボットを何人も動かしたい人へ
  • dots 型: ChatGPT の中で深く任せたい人へ
タイプ重視すること向いている人
OpenClaw自宅運営・鍵の自己管理自分で組み立てたい人
Grok Bot複数bot・24時間稼働手軽に任せたい人
dotsChatGPT 統合・深い委任普段から ChatGPT 派
どれかが正解ではなく、自分の運用スタイルに合うかで選びます！

⑰ どれを選んでも——この扉は自分が持つ

最後の安全ルール
  • どれを選んでも、送金とパスワードの扉だけは自分が持つ——これが大原則
  • dots では送金・パスワード変更が必ず本人に引き継がれ、ルールでも外せない
  • Grok Bot では認証系・支払いの入力を本人に画面ごと渡す
  • OpenClaw でも個人宛メッセージは下書きを作らせて自分で送るのが最も安全な使い方
どんなエージェントでも 送金・パスワードは自分の鍵 手放さない
任せていい仕事と、絶対に手放さない扉を最初に決めておきましょう！
