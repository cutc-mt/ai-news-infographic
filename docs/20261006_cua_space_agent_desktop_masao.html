Cua Spaceで「エージェント専用デスクトップ」を作ろう

AIエージェントに自分のPCとは別の仮想デスクトップ「スペース」を丸ごと与えて作業させる新ツール「Cua Space」——マルチカーソル、テレポート、macOS VMを約24秒で作る速さ、海外のバズった反応、セキュリティ懸念、MITライセンスの基盤技術まで、1本の動画を18枚のカードにまとめました
🎬 【これは新しい】Cua Spaceを使えば、「エージェント専用デスクトップ」が作成可！実際に使ってみた — まさおAIじっくり解説ch（2026年10月6日）

① Cua Spaceとは何か

イントロ — 概要紹介
  • Cua SpaceはAIエージェント用の専用デスクトップ環境を提供するサービス。登場したばかりの新ツールです
  • 自分のコンピューターとは別の仮想デスクトップ——スペースと呼ばれる環境を丸ごとエージェントに与えて作業させます
  • 想定される主役はClaude CodeやCodexのようなコーディングエージェント。隔離された環境で自由に動かせます
  • そして無料で使い始められるのが大きな特徴。まず試してみるハードルが低いツールです
登録 スペース作成 エージェントに操作させる 自分のPCは守られる
「エージェントに丸ごとデスクトップを貸す」時代がついに来た！

② なぜ今、注目するのか

イントロ — 注目の背景
  • 最近のGrokボットの話題で「ボット1体にデスクトップ1個を割り当てる」運用が注目されていました
  • あれを自作でもやりたい——そう思ったときの選択肢としてCua Spaceが使えそう、というのが解説の出発点です
  • エージェントが画面を操作するコンピューターユースを、安全に・手軽に回すための「手札」になる期待
  • 動画では実際にまさお氏が使い込んだ様子を デモ込みで紹介してくれる構成です
Grokボットの事例 自作でもやりたい Cua Spaceで実現
巨大手の動きを、個人でも真似できるってこと！

③ スペース＝クラウド上に作るVM

機能解説 — スペースの正体
  • スペースの実体は仮想マシン。macOS / Linux / WindowsからOSを選んで作成できます
  • 作ったスペースはクラウド上で一覧管理。用途ごとに複数立てて使い分けるイメージです
  • 手元のMacBookからMac Studioなどの別Macを紐付けて、そこにスペースを作ることも可能
  • 実際のデモでは約24秒でスペースが完成——この速さが後のカードで登場します
OSを選ぶ 作成先のMacを指定 スペース完成 一覧で管理
VM構築が「ボタン1つ」の世界——これは楽すぎる！

④ マルチカーソルで共同作業

機能解説 — 独自リモートデスクトップ
  • 独自のリモートデスクトッププロトコルで、同じデスクトップ上に人間とエージェントそれぞれのカーソルが表示されます
  • エージェントが作業中でも途中から人間が操作を交代できる——奪い合いにならない設計です
  • AIエージェントがデスクトップをコンピューターユースで操作する様子を、同じ画面で見ながら確認できます
  • メニューバーや設定画面も素通りできず、細部まで作り込まれている点も言及がありました
エージェント操作中 自分のカーソルで割って入る そのまま交代して作業継続
カーソルが2つ並んで動く様子は、一度見ると癖になる！

⑤ テレポート機能 — 環境ごと転送

機能解説 — テレポート
  • アプリのセッション——開いているタブ、プロファイル、ログイン状態をひとまとめにして転送できます
  • 自分のMacで開いている状態のまま、そのアプリをスペース側へ「テレポート」できるのが強力
  • Linuxマシンへファイルを送りたい場面でも、ポンと投げるだけでファイルごと転送可能
  • 複数スペース間でコンテキストを受け渡ししたいとき、エージェント経由でやり取りできるのも便利と好評
手元のMacでログイン テレポート スペースでも同じ状態で作業
「ログインし直し」の地味なストレスから解放される！

⑥ 機密項目はタッチIDでガード

機能解説 — 機密情報の保護
  • テレポートや操作の途中で機密項目を扱う場面では、タッチID（生体認証）を要求する設計があります
  • パスワードなどの機密は無条件に渡さず、人間の承認を挟むことで安全性を担保する考え方です
  • とはいえエージェントにコンテキストを渡しやすいので、機密性と利便性のバランスが良い、と解説
  • ただし後のカードで触れる通信内容が読めるリスクの話と合わせて、運用には注意も必要です
機密項目に到達 タッチIDで本人確認 初めて渡される
便利さと秘密の扉の鍵は、ちゃんと分けてある！

⑦ コンピューターユースの現在位置

考え方 — ハーネス視点
  • 実際のところ、コンピューターユースを毎日重宝している人はまだ少数派——使っていない人も多い、という現状認識
  • しかしこれからは人間の代わりに操作するフェーズが来る前提で備えるべき、という立場です
  • 着目点はハーネス（操作枠組み）の変化：Claude Codeがミクロの目標でタスクをこなす様子を、人間が上から操作する形をシミュレーション
  • その構成部品としてCua Spaceのような選択肢を持っておくと面白い、という文脈です

⑨ 始め方 — 登録不要のデスクトップアプリ

使い方 — 導入
  • 驚きのアカウント登録不要——デスクトップアプリを入れるだけで使い始められます
  • スペースの作成はアプリ内のプラスボタンから。Linux・Windows・macOSを選んでポチッと押すだけ
  • 作成先のMacを指定したあとは、CPUコア・メモリ・ディスク容量をスライダー感覚で調整可能
  • まさお氏の環境ではMac Studioに接続した状態でスペースを作成し、MacBookから操作していました
アプリ導入 プラスボタン OSとスペックを選ぶ 完成まで約24秒
登録0・設定ほぼ0・待ち時間24秒——導入の軽さがエポックメイキング！

⑩ 実機デモ — 並列作業の実演

デモ — macOS VMを立てる
  • まさお氏が実際にmacOSのVMを立ち上げ、作業の様子を実演してくれます
  • 画面の左側であるタスクを進めながら、右側では別タスクを並走させる多重作業スタイル
  • エージェントに頼んでスクリーンショットを撮らせることにも成功——細かい指示も通ります
  • ただし動作の不安定さは残るとのこと。まだ登場直後のツールである点は割り引いて見ましょう
スペース起動 左：自分の作業 ／ 右：エージェントの作業 干渉せず並列進行
自分が作業している“隣の部屋”でエージェントが働く！

⑪ エージェントがSafariとテキストエディットを操作

デモ — 具体的な操作例
  • エージェントに声をかければSafariを開いて検索するところまで自動で実行してくれます
  • テキストエディットの操作も可能——アプリをまたぐ一連の流れをこなせます
  • 不安定な場面はClaude Codeなどに状況を伝えて対処すればよく、運用でカバーできる範囲と楽観視
  • 初期設定のmacOSから検索で情報を引き出すデモもあり、素の環境からの立ち上がりも確認できました
「Safariで検索して」 ブラウザ起動 入力・検索 結果を確認
「ちょっと開いて」が通る世界は、やっぱり気持ちいい！

⑫ テレポート実演 — アプリごと転送

デモ — スペース間連携
  • 今Macで開いているアプリをそのままの状態で送れるのがテレポートの真骨頂
  • Linuxマシンにファイルを送りたいときも対象をポンと指定するだけ。ファイル単体の転送ももちろん可能
  • こうしたスペース間のコンテキストやり取りをエージェントに任せられるのも高評価
  • 手元 → スペース → 別スペース、と環境をまたぐワークフローが一気に書き換わる潜在力を紹介
手元のMacで準備 テレポートで転送 スペースでそのまま続きから
「作業環境ごと引っ越し」が数秒で終わる！

⑬ 海外の反応 — バズったツイート

反応 — ポジティブ多数
  • このツールのツイートは海外で大きくバズり、注目が集まっていました
  • 喜びの声トップは「カーソルの取り合いが消えた」——手元を乗っ取られずに済むのが最大のメリットに
  • 余ったMacの有効活用ができる、2台目以降のMacが資産になる、という声も
  • 話題になったものに、ハーネス系ツール（動画で以前紹介）がTailnet上の別Macのコンピューターユースに対応した話も。2台目のMacでシミュレーターが8個動く運用例が紹介されていました
バズったツイート 「取り合い解消」「Mac活用」 自作ハーネス派にも浸透
世界中のエージェント勢が同じ痛み（取り合い）を持っていた証拠！

⑭ 懸念点 — 良い話ばかりではない

反応 — ネガティブ要素
  • まず動作の不安定さ。登場直後のため、まだ挙動が荒い場面があるのは事実です
  • テレポートが本当に信頼できるか——ログイン状態を渡す仕組みへの疑問も上がっています
  • 最大の論点は通信の中身が読めてしまう可能性。便利な反面、その分だけ危険な側面があると指摘されています
  • とはいえポジティブな部分もネガティブな部分も多いと着地——使い所を見極めるのが肝心です
便利さ リスク 機密度に応じて使い分ける
大事なアカウントは、通す前に一呼吸考えて！

⑮ 環境設定 — QRコードと事前セットアップ

設定 — オプション選択
  • QRコードによる接続はコンピューターユース定番の手法で、汎用エージェントの裏側でも使われてきました
  • Cua関連のスキルやMCPサーバーのセットアップをあらかじめ済ませてくれるオプションが用意されています
  • チェックを入れて進めてもよし、まさお氏のように外して自分で組むのもよし——状況次第で選択
  • 自作ハーネス派にとっては余計な初期化作を省けるのが地味に嬉しいポイントです
セットアップ画面 オプションを選ぶ すぐ使える状態で完成
道具はお任せで揃えるか、自分で選ぶか——好みの分かれる味付け！
