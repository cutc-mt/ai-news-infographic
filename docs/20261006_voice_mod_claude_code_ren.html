② Modsとは？ ゲームのMODみたいな仕組み

0:57 Claude Code の Mods とは
  • ModはゲームのMODのようにClaude Codeを改造できる仕組み——自分だけの機能を足したり動きを変えたりできます

  • 入力欄の上の帯やペインの追加など、画面の部品を足すことも可能です
  • バージョン2.1.287以上に更新すれば最初から有効。自分で書かなくても頼めばClaudeが作ってくれます

⑫ 一番の収穫 — サブスクの枠内で使える

10:14 裏話：API キーの壁と WebRTC への書き換え
  • 道を替えて1番良かったのは、追加のAPI料金なし・サブスクの枠内で使えるようになったこと
  • 元のWebSocket方式は途切れにくい可能性がある一方、APIキーが必要で使った分だけ課金されます

  • APIキーのない環境ではWebSocket方式は試せず。それでも追加料金なしで声で頼めるのは結構大きいという評価です

⑬ 使う前の注意 — Modはサンドボックスに入らない

12:26 使う前の注意と、試し方
  • Modはサンドボックス（隔離された場所）に閉じ込められず、Claude Codeと同じ権限で動きます
  • ファイルの読み書きや通信など、Claude CodeにできることはModにもできてしまう——入れる前に中身を確かめてください
  • 本来なら確認が出る操作をModが代わりに許可できてしまう点にも注意。個人環境の禁止ルールをMODが通してしまう可能性も
  • おすすめはclaude plugin validateで、そのModが引っかけるイベントと呼ぶ操作を一覧してから入れること
中身を確かめる validateで一覧 それから導入
便利さと同じ速さで権限も受け渡される——導入前の点検を！

⑭ 声のModならではの注意点

12:26 使う前の注意と、試し方
  • 声はそのままあなたの依頼として実行されます。周りの声や聞き間違いも依頼になってしまう点がユニークなリスク
  • 確認を全部省く設定だと、聞き間違いの依頼でも確認なしで動いてしまうので要注意
  • 会話中はマイクの音と作業の答えの全文がOpenAIに送信されます。答えにはファイルの中身が入ることも
  • 秘密のあるフォルダでは使わない——これが運用の鉄則です
周りの声 そのまま依頼として解釈 実行される
聞き間違いも「ご注文」になる——声のUIは慎重に！
