② WikiFix for Confluence

00:58 Confluenceの誤り修正
  • Wiki内の古くなったページや矛盾するページを見つけ、数クリックで修正できるConfluenceアプリ
  • インシデント時にランブックが間違っていたり、新入社員のセットアップガイドが機能しない、Rovoのようなコパイロットがドキュメントの誤りを大規模に再生するといった「静かなズレ」を解決
  • 選択したスペースを監視し、日付だけでなく内容を読み取って矛盾ページにフラグ。各主張をソース引用と並べて表示し正誤を判断できる
  • 重複ページや所有者が離職したページも検知。承認まで変更されず、ワンクリックで元に戻せる。自分のAnthropicキーを使用可
スペース監視 矛盾を検出 修正案を承認 ワンクリックで巻き戻し
wikifix.ai — Atlassian Marketplaceからインストール
ターゲットはConfluence管理者・ナレッジ管理リーダー。既存環境のまま移行なしで動きます

③ Thinking Orbs

01:53 動的ステータスインジケーター
  • AIアプリ向けの動的ステータスインジケーターをまとめたオープンソースのReactコンポーネントライブラリ
  • 「エージェントが何をしているか表示する」という小さくても繰り返し発生する作業を解決——開発者が思考中・検索中アニメーションをゼロから作らなくてよくなる
  • NPMまたはShadcnでコピー。推論中・検索中・圧縮中・再試行中・待機中の状態を指定。Propsでサイズ・速度・形状・密度・傾き・色を制御
  • 必要なものだけインポートでバンドルサイズはGZippedで4KB未満。純粋なJSビルドなら依存関係ゼロ。MITライセンスで無料
npm install Orbを配置 状態とバリアントを指定 完成
thinkingorbs.com
AIインターフェースを作るエンジニアの地味に効く一品。4KBは美德です

  • AIエージェントはサイト・ドキュメント・FAQで学習済みで回答精度が高く、初回返信を自動化。必要時は文脈を保持したまま人間に引き継ぎコストを削減
  • 分析機能が会話の結末・満足度をトピック・応答時間・CSATと紐付けて可視化。インボックス・ウィジェット・チャネルはすべて無料、クレジットカード不要

⑤ Sente：380+モデルのCLI

03:47 コーディングエージェントCLI
  • TEAI.ioのコーディングエージェントCLI——プラットフォーム上の380種類以上のモデルをターミナルのエージェントに変える。プロバイダーロックインをcurlコマンド1つで解決
  • オープンソースのOpenCodeを動かす軽量ランチャー（フォークではない）。上流の改善をすべて継承し、変換レイヤーなしのOpenAI互換通信がネイティブ動作
  • コストと品質のバランスを1行コマンドでモデル切替。「Ttalk」で音声タスク依頼・読み上げ返答、Sente CloudならMacのスリープ中もブラウザで作業継続
  • 3段階の安全モデルでリスク操作前に必ず確認。失敗応答は課金なし、オプトインのローカルPIIスクラビングが機密データを送信前にマスキング
curlでインストール 380+モデルを切替 ファイル読み書き・実行・報告
teai.io/sente-en — 100クレジット付きで無料
macOS・Linux・WSL対応。モデルの使い分けでコストを握れるのが最大の魅力です

⑧ qarunbook：AIテスト計画

06:52 コードをテスト計画へ
  • コードを明確なテスト計画に変換し、チームとAIが実行できるようにするアプリテスト用ランブック
  • QA最大の難問「何をテストすべきか」を解決——これはテスト自体より大きな作業になることも。コマンド実行でAIがテスト項目を抽出し手順と期待結果をドラフト
  • チームやAIがWeb・Android・iOSで計画を実行し、チェックと結果を一元管理。問題は発見元のチェック項目に紐付き、修正確認まで合格が解除されない
  • MCPで約1分で接続——Claude・Codex・Cursorが計画を読み込み、結果を記録し、修正まで追跡
コマンド実行 AIが項目抽出 全OSで実行 修正まで自動追跡
qarunbook.com — 無料でテスト開始

⑨ ZooWork：専門知識を配信

07:45 エキスパート向け配信基盤
  • ドメインエキスパートと現場エンジニアのためのAIエージェント配信プラットフォーム——有能なモデルでも「あなたの業務を知らない」溝を解消
  • 知識・手法・SOP・納品基準・ツール権限をパッケージ化してエージェントのスキルへ。職務記述書を完全把握した状態で始動し、マニュアルを24時間体制で実行、繰り返すたびに進化
  • タスクをステップごとに計画し実際のシステムを操作。金銭やデータが動く前は承認ゲートで停止。資料・文書・注文という実務そのものをこなす
  • あらゆるフロンティアモデルで動作しベンダー依存なし。MCPでGoogle Workspace・Microsoft 365・Slack・Jira・GitHubと接続。同僚のようにSlack・Teams・WhatsAppで働く
専門知識をパッケージ化 エージェントが24時間実行 承認ゲートで安全に納品
zoowork.ai — テナント分離・学習にデータ不使用
企業・専門チーム向け。プロンプトのゼロ打ちからおさらびする未来がここに

⑩ eu/jev：EUホスト推論

08:48 システム1意思決定モデル
  • Bevelが構築したシステム1意思決定モデルのためのEUホスト型推論サービス——GDPR下で欧州内にデータを保持したまま高速な意思決定を実行
  • 文章を生成せず、単一APIでコンテキストを「選択肢」「確率」「スコア」へ変換。テキスト分類・選択肢比較によるルーティング・感情分析・モデレーションの構造化決定を返す
  • リクエストはドイツのHetznerサーバーへ直送。中間プロキシや外部モデルAPIを通さず、プロンプトと回答はドイツで処理・保存されない
  • DPAとサブプロセッサーリストをワンクリック確認可能。Jev形式のリクエストとAPI互換で、出力トークンは無料
状態と質問を送信 ドイツで処理 選択肢/Yes-No/スコアで即答
eu-jev.com — 5時間分クレジット付き無料APIキー
EUの開発者向け。コンプライアンスと速度を両立する珍しい構成です

⑭ Singularity：チケット駆動開発
