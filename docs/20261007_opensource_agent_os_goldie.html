2026-10-07 ／ Julian Goldie SEO ／ 18 Cards
動画：This Open-Source AI Agent Is Becoming an Operating System

DeepSeekのオープンソース「エージェントハーネス」の最新版 v0.2 がデスクトップアプリとして登場。「すべてはプラグイン」という設計で、エージェントのOSと呼ばれる理由から、公式プラグイン6種、Creator Mode、モデル差し替え、定期タスク、そしてインストール前のプライバシー注意点まで、18カードで整理します。

~/cards/01-terminal.txt
CARD 01

ターミナルを抜け出したエージェント

「あなたのAIエージェントは、まだ黒いターミナルウィンドウの中に閉じ込められていませんか？」— 動画はこの問いかけから始まる。

紹介されたオープンソースAIエージェントは、ついにデスクトップの上に直接住むようになった。しかもプラグインで動く構造で、ちょうどコンピュータがアプリで動くのと同じ方式だ。

イントロ
~/cards/02-what-is.txt
CARD 02

DeepSeek Harnessとは何か

DeepSeek Harness は、DeepSeekが公開したオープンソースの「エージェントハーネス」。

ハーネスとは「AIモデルを包み込むプログラム」のこと。モデルにファイル操作・コマンド実行を許し、タスクを最後まで完結させる役割を担う。今回のアップデート v0.2 でデスクトップアプリが加わった。

基本概念
~/cards/03-brain-body.txt
CARD 03

モデルは頭脳、ハーネスは身体

動画のたとえ：モデル＝頭脳（ブレイン）、ハーネス＝身体（ボディ）。

ハーネスが備わることで、LLMは単なるチャット窓存在ではなく、あなたのPCの上でファイルを触り、コマンドを走らせ、仕事を終わらせる「エージェント」になる。

頭脳×身体
~/cards/04-v02-app.txt
CARD 04

v0.2 デスクトップアプリ登場

Mac（Appleシリコン向け）と Windows（64ビット版）向けのデスクトップアプリがリリースされた。

他のアプリと同じようにダウンロードしてインストールするだけ。しかも専用のNodeランタイム同梱なので、事前に追加の開発ツールを整える必要がない。

Mac / Windows
~/cards/05-setup.txt
CARD 05

セットアップはコマンド不要

手順はシンプル：①サインイン → ②PC上のフォルダを選ぶ（＝ワークスペース） → ③エージェントにタスクを渡す。以上。

以前はターミナルで起動し、ブラウザで開くという2段階の手順が必要で「少し雑然としていた」が、v0.2がこれを解消した。

3ステップ
~/cards/06-sync.txt
CARD 06

旧セッションはそのまま同期

以前からDeepSeek Harnessを使っていた人も安心の設計。過去のセッションは同期されており、以前のプロジェクトとチャットがそのまま待っている。

移行コストを気にせず、デスクトップ版へ乗り換えできる丁寧な作り。

移行なし
~/cards/07-os-idea.txt
CARD 07

なぜ「OS」と呼ばれるのか

理由は設計思想にある：「すべてはプラグイン」。

PCではOSが土台で、アプリを追加して仕事を増やす。Harnessも同じ構造で、ベースは小さく、能力はプラグインが追加する。単一アプリではなく「エージェントのオペレーティングシステム」と呼ばれる所以だ。

Everything is a plugin
~/cards/08-plugins.txt
CARD 08

公式プラグイン6種を一括管理

プラグインマネージャーに並ぶ公式プラグインは、エージェントチーム／音声入力／シェル／エージェントループ／サブエージェント／Web検索の6種。

それぞれON/OFFを切り替え可能。うちエージェントチームと音声入力には現在「ベータ」表記が付いている。

プラグインマネージャー

エージェントチーム＝複数のエージェントが協力して作業。音声入力＝タイプせず話しかけて操作。シェル＝PC上でコマンドを実行。Web検索＝オンラインで調べもの。

サブエージェント＝仕事の小さい一部を引き受ける助っ手エージェント。

~/cards/10-voice-review.txt
CARD 10

音声入力とレビュー設定

音声入力をONにすると声で話しながらコードを書ける。手が塞がっている時や、口に出して考えた方が早い時に便利。

もう一つの鍵はレビュー設定：エージェントに自律的に書かせるか、確認ループに自分を残すかを選べる。学習中はレビューON、挙動が分かったら緩めるのが賢い使い方。

自律度の制御
~/cards/11-community.txt
CARD 11

60%がサードパーティ製プラグイン利用

「プラグイン追加」ボタンで初期セットに囚われない。GitHubにはカテゴリ別に整理された厳選リストがあり、メモリー強化・テーマ・モデル／プロバイダー変更などもプラグインで実現できる。

DeepSeekによれば、公式API経由のユーザーの約60%がサードパーティ製プラグインを使用。プラグインはオマケではなく主役だ。

community plugins
~/cards/12-creator.txt
CARD 12

Creator Mode — 言葉でプラグインを作る

最も興味深い機能がCreator Mode（クリエイターモード）。まだ実験的だが、考え方はシンプルだ。

欲しいプラグインを言葉で記述すると、Harnessが作成やセットアップを支援してくれる。開発者でなくてもカスタマイズの入口に立てる。

experimental
~/cards/13-modes.txt
CARD 13

4つのセッションモード

新規セッション開始時に選べるモードは standard / PTC / minimal / creator の4つ。道具を自分で組みたいならcreator、通常利用ならstandard。

動かし方を保存したエージェントプリセットも登録可能。プラグインリストの再読み込みで自作・コミュニティ製を即追加でき、試して合わなければOFFに戻すだけ。何が入っているか・動いているかは一画面で確認できる。

presets
~/cards/14-models.txt
CARD 14

モデルとプロバイダーは差し替え自由

公式ページのデフォルトモデルは DeepSeek V4.1 Flash。モデルセクションではプロバイダー一覧を切り替えられる。

他のモデルを試すならOpenCode や OpenRouter にAPIキーを追加するだけ。ハーネス自体がオープンソースなので、モデルの選択は自由だ。

OpenCode / OpenRouter
~/cards/15-files.txt
CARD 15

ファイル機能が大幅強化

デスクトップアプリの利点が最も出るのがファイル周り。ファイル表示・内容のプレビュー・コード変更の提示が改善された。

ドキュメント・スプレッドシート・PDFの編集、情報整理・データ分析・チャート作成、スライド資料の作成まで可能。プロジェクト編集とコード実行もこなすので、コーダー以外の日常業務にも使える。

PDF・表・スライド
~/cards/16-schedule.txt
CARD 16

定期タスクがバックグラウンドで走る

オートメーションタスク・プラグインを使うと、定期的に実行されるタスクを組める。例：「毎週月曜に、最新AI自動化ニュースのスライドを作成」。一度設定すればスケジュールで動く。

実行履歴は保持され、アプリ再起動後も生き残り、ウィンドウを閉じても実行中タスクは止まらない。終了がタスクを中断する場合は警告も出る。

scheduled tasks
~/cards/17-privacy.txt
CARD 17

【要注意】インストール前のプライバシー

動画が「最後に必ず伝えたい」と強調した点：DeepSeekは中国の企業であること。

共有したくないプライベートなデータは、この種のツールに入れないこと。共有して問題ない仕事に使い、プライベートなファイルは外に出す — 自分で賢く判断するための明確な助言だ。

privacy check
~/cards/18-roadmap.txt
CARD 18

ロードマップと始め方

今後の展望：サンドボックス／セキュリティ強化、エージェントチーム改善、長期メモリーの個別化、GUI・ブラウザ自動化、モバイルアクセス、プラグインマーケットプレイス。モデル進化と並走して調整され続ける。

始め方：公式ページからアプリDL → サインイン → セッション開始 → フォルダ選択 → モード選択 → モデル確認。プラスボタンでチャット追加し、並行コーディングも可能。プロジェクトごとにチャットと履歴が分離される。
