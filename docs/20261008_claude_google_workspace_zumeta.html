Claude for Google Workspace — ドキュメントでClaudeが直接編集

Anthropicの「Claude for Google Workspace」で、Googleドキュメント・スプレッドシート・スライドのファイル横にClaudeが常駐し、コピペ往復なしでファイルを直接編集できるように。有料プラン限定のベータで、使える条件は「プラン×ブラウザ×Googleアカウント設定」の3つが揃うこと。どこまで任せていいか、編集は誰の名前で残るのか、逆方向のコネクターとの違いまで、1本の動画を18枚のカードにまとめました
🎬 【Claude】GoogleドキュメントでClaudeが直接編集 Claude for Google Workspace — ずんめたラボ（2026年10月8日）

① GoogleドキュメントにClaudeが来た

イントロ — 何が変わるか
  • AnthropicがClaude for Google Workspaceを発表。Googleドキュメントの中でClaudeが働く拡張機能です
  • これまではClaudeの答えをコピペで貼り、書き直し、また聞いての往復——この往復が大きく減ります
  • ファイルの横にClaudeの窓が出て、そのままファイルの中を直接直してくれる
  • ただし有料プラン限定のベータ版。大学のアカウントでは入れられないケースも
コピペで往復 ファイルの横で直接編集 貼り戻しが不要に
ゼミのレポート、コピペ地獄からおさらばなのだ！

② 対象は3アプリ・有料向けベータ

概要 — 対象と位置づけ
  • 使えるのはGoogleドキュメント・スプレッドシート・スライドの3つ
  • 有料プランの人向けにベータ版として公開——まだお試し段階です
  • 確かめる順番は3つ：①どこに入るのか ②誰が使えるのか ③どこまで任せるのか
  • 中でも3つ目が最重要——寝てる間に書き換えられる心配があるかどうか
どこに入る？ 誰が使える？ どこまで任せる？
3番目が1番気になるのだ——勝手に書き換えられたら困るのだ！

③ ファイルの横に細長い窓

仕組み — どこに入るのか
  • Googleのファイルを開くと、ファイルの横に細長い窓が出てそこにClaudeがいます
  • Claudeは開いているファイルを読み、あなたが選んだ文・表の範囲も見ます
  • 直す時はファイルの中を直接書き換え——コピペで書式が崩れる地味な困りごとが解消
  • 公式には文を1つ直しても周りの組版は崩さないと明記されています
# 動作イメージ
Googleファイルを開く
 → 横にClaudeの窓
 → 選択範囲も読める
 → ファイルを直接編集
選んだところを見て、どこの話か分かってくれるのよ。

④ Claude Docsとは別物 — 向きが逆

比較 — よくある混同
  • Claude Docs＝Claudeの中で作る文章。Claude側の機能です
  • 今回はその逆——Googleドキュメントの中にClaudeが来る形です
  • 「どちらがどちらに入るか」という向きの違いだけ押さえれば混同しません
  • 既存のGoogleファイル資産をそのまま扱いたいなら今回の拡張機能が適任
Claude Docs: Claudeの中で文書 Workspace拡張: Googleファイルの中にClaude
向きが逆なのだ——Claudeがこっちに来るのだ！

⑤ 見えるのは開いているファイル1つだけ

仕組み — アクセス範囲
  • 最初の状態で見えるのは開いているファイル1つだけ。ドライブの他のファイルは見えません
  • 他サービスとの連携コネクターは窓の中で自分でオンにした時だけ見える範囲に追加
  • 他のファイルを開く・新しく作る・書き換えることは拡張機能ではできません
  • 開いている1つのファイル専用の助手と捉えるのが正確です
既定＝開いているファイルのみ 連携オン時のみ範囲が拡大
見えないところは触れないところ——後で出てくる大事な原則よ。

⑥ 使える条件は3つ

条件 — 誰が使えるのか
  • ①Claudeのプラン：Pro・Max・Team・Enterpriseの有料プラン。無料プランは対象外
  • ②ブラウザ：Chrome・Edge・Safariに対応。Firefoxは非対応
  • Firefoxでは窓は開くのに操作が終わらない状態に——最初から対応ブラウザで開くのが吉
  • ③Googleアカウント：マーケットプレイスからアプリを入れられるアカウントであること
# 使える条件チェックリスト
[ ] Claudeプラン  → Pro / Max / Team / Enterprise
[ ] ブラウザ    → Chrome / Edge / Safari
[ ] アカウント  → アプリ導入が許可されていること
僕は無料なのだ……月のお小遣いと相談なのだ。

⑦ 大学・会社アカウントはGoogle側次第

注意 — 組織アカウント
  • 大学や会社のアカウントは管理者が入れられるアプリを決めている。多くの組織は初期状態で停止とヘルプに記載
  • 止められていると「管理者が許可していない」と出て入れません
  • 有料プランに入っても解決しない——可否はClaudeではなくGoogle側の管理者設定で決まります
  • 対策は2つ：管理者にお願いするか個人のGoogleアカウントで試す。ただし大学資料の移動は先に学校のルール確認を
お小遣いを払っても 学校の設定で止まることはある 順番に確認
大学の資料を個人アカウントに移していいかは、先にルール確かめなのよ。

⑧ 入れ方は短い — 3ステップ

手順 — セットアップ
  • Google Workspace MarketplaceでClaudeをインストール
  • 開いていたファイルを読み込み直すだけで準備完了
  • あとは拡張機能メニューからClaudeを開いてログインするだけです
  • 1回入れれば3アプリ全部で使える——ドキュメント・スプレッドシート・スライド
# セットアップ手順
1. Marketplace → Claudeをインストール
2. 開いていたファイルを読み込み直す
3. 拡張機能メニュー → Claude → ログイン
※ 以降、3アプリ共通で利用可能
入れ方自体はほんの数分——壁はそこじゃないのよ。

⑨ ドキュメント — 小さな直しと提案カード

実践 — ゼミのメモ整理
  • 文を1つ直す・見出しの形を揃える程度の小さな直しはその場でやってくれる
  • 大きく書き直す時は提案カード——変わる部分に印がつき採用／却下を選べます
  • Googleの提案モードとは別物：提案カードはClaudeの窓の中で確認し、採用した直しは普通の編集として入る
  • 公式ヘルプの例：「次にやること」を担当・内容・期日の表にして——タスク整理にそのまま使えそう
  • 注意：ドキュメントのコメントは読めない・返信もできない。コメントの文を窓のチャットに貼れば対応可
小さな直し→即実行 大きな直し→提案カード 採用で通常編集
直しはGoogleの版の履歴に残るから、困ったら元に戻せばいいわ。

⑩ スプレッドシート — 集計の強い味方

実践 — アンケート集計
  • 計算式の変更や新しいタブの追加をその場で——毎回ネットで調べている人には朗報
  • 集計表（ピボットテーブル）やグラフ作成も可能——学年ごと・回答ごとに数え直す表です
  • 散らかったデータはPythonで範囲を整理してシートに書き戻すことも。ヘルプの例はまさに日付の書き方3種類を統一
  • 「この合計がどう計算されているか説明して」＝書き換えずに聞くだけの使い方も——最初の一歩に最適
  • ただし出てきた数字はいくつか自分で計算し直してから使うこと
説明だけ聞く 小さな直し ピボット＋グラフ生成
日付の書き方がバラバラなの、まさに僕のアンケートなのだ！

⑪ スライド — テーマ沿いの生成と検品

実践 — 発表資料づくり
  • 今あるレイアウトとテーマに合わせて新しいスライドを作成——ページごとにデザインがバラけるのを防ぐ
  • 見直しも可能：重なっている部品・スライドからのはみ出し・読みにくい文字を指摘
  • ヘルプの例：文字だらけの1枚をデザインはそのままで2枚に割って——前夜のはみ出し事故を防げる
  • 要注意：スライドに入るグラフは画像。スプレッドシートの数字を変えても自動では変わらない——集計を直したら作り直しを頼む
テーマ維持で生成 自動検品 発表直前の修正はグラフ再生成を忘れずに
前の日の夜、文字が枠外に出てるのに気づくやつ……なのだ。

⑫ 任せ方は2モード — 危険操作は必ず停止

設定 — どこまで任せるか
  • 編集前に確認（初期設定）：Claudeがこれから何をするか短く説明し、許可まで待つ
  • 全ての編集を受け入れる：普通の書き直しは止まらず進む——速度重視ならこちら
  • どちらのモードでもリンクを出す・ネット上の画像を入れる・誰かのアクセスを外すは毎回止まって確認
  • ファイル共有・権限を渡すこと・持ち主の変更はそもそも不可——頼んでも断られます
# モード別の挙動
確認モード  → 全編集前に説明＋許可待ち
全受け入れ  → 通常編集は連続実行
共通       → 危険操作は毎回確認
不可能     → 共有 / 権限付与 / 所有者変更
勝手にファイルの外へ共有される心配はないのよ。

⑬ 窓を閉じたら停止・1回6分まで

制限 — 動く範囲
  • 寝てる間に全部書き換えられる心配はない——Claudeの窓を開いている間だけ頼まれたことをやります
  • 窓を閉じると作業は途中で停止します
  • 1回の作業はGoogleの決まりで6分までという上限あり
  • 大きい仕事はタブ1つずつ・スライド10枚ずつのように分けて頼むのがコツ
大きい仕事 分割して依頼 窓を開いている間だけ実行
寝てる間には動かないわよ——ほっとしたのだ！

⑭ 逆方向の入り口 — コネクター

発展 — 同時発表のもう1つ
  • 逆方向の入り口：Claudeのチャット側からGoogleファイルを作ったり直したりする連携用コネクター（同時発表）
  • 公式では新しいファイルが要る時・複数ファイルにまたがる時はClaude側から始めるのが向いていると案内
  • コネクターはドキュメントのコメントや提案も読める——拡張機能が読めなかった部分です
  • 頼む時は「Googleのスライドで作って」と付ける——付けないとダウンロードして使うファイルになります
  • 会話の横にファイルを並べる表示はWeb版Claude in Chromeかデスクトップアプリの内蔵ブラウザー。Team／Enterpriseはオーナー事前有効化が必要。対応プランは公式ページに未記載
# 拡張機能 vs コネクター
拡張機能   → 開いているファイルにClaudeが来る
コネクター → Claudeの会話からファイルを作る/直す
読める範囲 → コネクターはコメント・提案もOK
メモ・集計・スライドをまとめて頼むなら、チャット側からなのだ。

⑮ データの扱い — 学習不使用・30日削除

プライバシー — ヘルプの記載
  • 拡張機能に送った内容について、ヘルプは「モデルの学習に使わない」と明記
  • 入力と答えは原則30日以内にAnthropicのシステムから削除
  • 会話の履歴はファイルごとにブラウザの中だけ——別PC・別ブラウザ・ファイルのコピーでは出てきません
  • 他人から届いたファイルは注意：白い文字・小さな文字で指示が隠されていることがある
  • Claudeは文書の中身を命令ではなく資料として扱い、隠れた文字に印をつける——それでも提案を読んでから許可を
学習に不使用 30日以内に削除 履歴はブラウザ内のみ
見えない命令……怖いのだ。外からのファイルは確認してからなのよ。

⑯ 制限は意図的・編集はあなたの名前で

核心 — 責任の所在
  • 「1ファイルしか見えない」不便さは狙ってのもの——ヘルプにも制限は意図的と記載
  • 権限を渡すと拡張機能が触れる範囲も広がる——連携をオンにしなければ、見えない範囲＝守られている範囲
  • Claudeの直しはGoogle上であなたの編集として記録。共有ファイルではあなたが直したように見える
  • Claudeが間違いを入れてもあなたが入れたように見える——共有ファイルでは確認モードが推奨
直接編集 あなた名義の履歴 提出者の責任はあなたに
クロードが直した部分は、あなたの名前で残るのよ。

⑰ 総評 — 試す価値のある人・ない人

総評 — 判断の目安
  • 有料プラン＋対応ブラウザ＋入れられるアカウントがあるなら、自分のファイルで1つの作業から試す価値あり
  • 無料プランや大学アカウントで停止中の人は、今は従来のやり方で十分
  • 先輩の運用：共有ファイルでは「編集前に確認」のまま使う
  • 最初は書き換えずに質問するところから——道具がすぐ横に来た分、使う側の確認がより大事に
