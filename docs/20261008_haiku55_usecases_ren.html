OFFICIAL ANNOUNCEMENT
01

小型モデルの新主力「Claude Haiku 5.5」

Anthropic の便宜重視の小型モデルが約1年ぶりに更新。要点は3つ。

  • Haiku 4.5 より平均で約75%安い
  • 標準の速さで比べると Claude で最速
  • パソコン操作の評価が 15.7% → 72.4% に急伸
公式の使いどこころ像は「要約・分類のような量が多く費用を抑えたい仕事」と「顧客対応のような速さが要る仕事」

検証 — Model Arena の8課題 × effort 5段階、AI 採点と自分の目

HANDS-ON BENCHMARK
08

検証の設計 — Sonnet 5.5 の回と完全に同じ条件

  • 8課題: ショート動画 / 3分スライド / 12枚スライド / ホームページ / ダッシュボード / Note 記事 / 迎合テスト / メール判定
  • Sonnet 5.5 検証時と同じプロンプト・素材・起動条件のまま Claude Code 2.1.293 で走らせた（2026年10月8日）
  • 成果物6課題は effort 5段階×1本、メール判定は3回、迎合テストは2回
  • 採点は作り手のモデル名を伏せた AI 採点者＋比較アプリで画面を並べた私の目の二重判定
4つの観点: Luna 置換 / Sonnet との差 / フロンティア比較 / 速さ
09

総括 — AI 採点では8課題中5つで Luna を置換可能、しかし…

  • AI 採点: effort を選べば ショート動画・3分/12枚スライド・ダッシュボード・メール判定の5課題で Luna を置換できる結果
  • Sonnet 5.5 とは、ダッシュボード・迎合テスト・メール判定で並んだが、作り込みが要る課題では差が残存
  • ところが画面を並べるとAI の採点と私の目が食い違った — それがこの検証の最大の発見
AI の点数だけで決めず、自分の目で確かめる。判定を AI に任せている人は採点方法の調整が必須

残る4課題 — HP・Note 記事・メール判定・迎合テスト

  • ホームページ: max はまあまあ、high はデザイン力がイマイチ → Opus / Sonnet 5.5 / Fable へ
  • Note 記事: 読みやすいが、スキルで指定した記事の型に従わず → 指示に従う力はまだ弱い
  • メール判定: medium が3回とも49通すべて正解・$0.034（Luna は $0.038）。ただし上の段では48通の回も → たまたまの可能性
  • 迎合テスト: max が15本中3位 — 逆らいうる Claude 系の性質をそのまま継承
私の選択: メールは安さなら判定専用 AI「Jev」、正確さなら Sonnet 5.5。文章は Opus 5.5 か Fable

分析 — フロンティア比較・effort の罠・費用と速さ

DEEP ANALYSIS
14

最上位モデルと比べると — 同点の課題と5〜9点届かない課題

相手は Opus 5.5 / Fable 5.1 / GPT-6 Astra / GPT-6.1 Sol の4フロンティア。

  • ダッシュボード・3分スライドは最上位と同点（ただし目で見ると Sol の max の方が「何が重要で何が判断待ちか」分かる作り）
  • メール判定は全問正解で並ぶ。迎合テストは Opus 5.5 に届かず Fable 5.1 とほぼ同点
  • Note 記事・12枚スライド・ホームページは5〜9点届かない
  • 費用は8課題すべてで最上位の実行より安い（ただし Sol も安いので12枚スライドは Haiku が高くつく）
注意: Haiku は5段階の最良値を選んでおり、Haiku にやや有利な比べ方
15

effort の罠 — 上げれば良いというものではない

  • effort を上げるほど点が上がり続ける課題は1つもなかった
  • ホームページは max だけ low 比 +15点で、初めて Luna 水準に到達
  • 3分スライド・ダッシュボードの max が最高だが、low からの伸びは6〜7点で1回の採点のぶれと区別できない
  • ショート動画・Note 記事は上の段でむしろ減点
AI 採点の目安: 動画・DB・メールは medium、12枚スライド・Note は high。ただし目で見ると動画は xhigh が良かった
16

結論 — 私の使い分けと公式ガイドの要点

仕事任せるモデル
スライドHaiku 5.5 max（20分・1ドル弱）
ダッシュボードGPT-6.1 Sol（Haiku なら medium）
ショート動画Opus 5.5 / Sonnet 5.5
ホームページ・文章Opus 5.5 / Sonnet 5.5 / Fable
メール判定Jev（安さ）or Sonnet 5.5（正確さ）
  • effort は既定 medium から開始し、2〜3段を自分の課題で比較（low=単純依頼、high=知識作業・厳密な指示）
  • 検索の道具には今日の日付を渡す。変わりやすい事実は「検索して」の一文
  • low は途中で止まる・コードを確かめず完了 → 続行文と確認文を追加
  • 移行時の400エラー: 思考予算の数指定・既定外の温度は外す。思考も出力上限に含まれる
  • 計画・レビューまで Haiku にしない（GitHub 提案）/ AWS はレビュー役も可
最終結論: 高品質が必要ならフロンティア（Opus 5.5・Sonnet 5.5・Fable・GPT-6.1 Sol）。安いモデルへの置き換えは AI の判定を頼らず自分の目で
