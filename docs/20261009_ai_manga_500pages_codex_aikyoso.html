02Codexで500ページを一気に生成

03一貫性の実検証: 第1話→第41話

大量生成で最大の懸念はキャラの一貫性崩壊。実際に第1話・第2話・中盤30話付近・最終41話を見比べても崩れていませんでした。

  • メインキャラ: 船長バズ（髭）・リナ・カイ・ステラ・整備士スパーク・レブ・ノリス
  • 途中登場の新キャラ（ハゲたおじさん、空、シルバー髪の人物）も登場時から崩れない
  • 戦闘シーン・バザーの場面・アクセサリーの描き込みまで一貫
41話最終ページでも船長バズ・リナ・カイ・ステラ・スパークが全員そろったまま——これがエコンテ＋キャラ資料の威力！

04最重要はエコンテ: 投入する内容

手法はシンプル: エコンテを作って投入 → キャラクターをフォルダごと投入 → 「書いて」と依頼。これで大量ページが書けます。

  • 背景の配置と人物の位置関係がエコンテの核心
  • 質感・画質にこだわるならその指定も
  • 演出・エフェクトも入れられる——ただし全部入れるとテキストが巨大化するので何を入れるか選定する
  • キャラクターはフォルダごと放り込むのがコツ

05サブエージェント戦略: 1話1担当

500ページともなると生成だけでも膨大な時間がかかります。そこで1話ごとにサブエージェントを1つ担当させる運用を採用。

  • 並列担当で時間短縮——今回の制作時間は約7時間
  • 担当を分けると話の内容の繋がりを理解しながら書いてくれる
  • サブエージェントを大量に使って第41話まで完走

06キャラクター生成: 3面図と身長

キャラ生成もスレッドを分けて専用で行います。物語のテキストからキャラクター設計を起こすのが基本フロー。

  • 身長を入れる——急に背が伸び縮みする矛盾を防ぎ、キャラ間の高低差をAIが判断
  • 3面図を作成。背中や横に紋章・マークがあるキャラは特に必須（毎回変わるのを防ぐ）
  • 名前は画像の中に入れる（ファイルでも可）——キャラ名の紐づけ漏れを防ぐ
  • 脇役・モブ（猫も）まで一括生成され、個性的なキャラが揃う
女の子とウサギの名前が入替わる事故も——名前を画像に入れておくと紐づく！

07ナノバナナプロ基礎: 3スレッド分離

ナノバナナプロ（Gemini）は日本語が書けるようになった画像生成モデル。長編で一貫性を保つ鍵はスレッドの3分離です。

  • シナリオスレッド: 物語の骨格。Geminiの回数制限対策でChatGPTに任せる戦略も可
  • イラストスレッド: メイン。連続で画像を生成し続ける
  • 修正スレッド: 修正だけを行う専用スレッド
  • 短編なら「3ページ分のエコンテを考えて」→「1ページ目を書いて」で矛盾なく完成。長編を1スレッドで続けると破綻する

08一貫性の仕組み: アテンション管理

一貫性はモデルの自己アテンション（文脈の記憶）で保たれます。逆に言えば、余計な文脈が混ざると壊れる。

  • イラストは対話を挟まず画像でプロンプトチェーンを繋ぐ——会話が挟まると途切れる
  • 本スレッドで修正指示は聞きにくい→真っさらな修正スレッドなら過去文脈がなく自己アテンションがかからず直る
  • 同じ生成を2回繰り返すとアテンションが強まり、以後の生成に影響する
  • 間違った生成は残さず削除（「修正して」「OKだけ返して」で生成を止める）
  • キャラが極端に小さい画像は読み取りが弱く一貫性が崩れる→次に描くキャラを添付し直す

09文字潰れ対策: 3コマ戦略

AI漫画で最頻出の悩みがセリフの文字潰れ・文字化け。セリフとコマの大きさの関係をコントロールします。

  • セリフは短く、文字は大きく——長いと潰れて文字化けする
  • コマの大きさを決める（セリフの量と連動）。迷ったら3コマ戦略でゆったり描く
  • 会話は分ける、コマも分ける——1コマに詰め込まない
  • プロンプトは「文字が潰れないようにゆったり目に書いて」と理由も添える
5〜6コマにすると細かくなって文字が潰れやすい。文字なしのコマなら5〜6コマでもOK！

10エフェクトとアテンションバジェット

「迫力あるエフェクトで」「エフェクトをつけて」の一言で炎や光の演出が付きます。重要なのは順番です。

  • まず普通にキャラクターを描く（骨格にアテンションを全振り）
  • その後でエフェクトを付ける——一気にやると破綻しやすい
  • アテンション量＝計算リソースは有限。これをアテンションバジェットと呼び、注意を分散させない
  • 演出も「演出入れて」でお任せでOK——背景や雰囲気が変わる。大事な場面だけ指定
実例: 剣士を普通に描く →「この剣士にエフェクトをつけて」→ 炎と光の流れる一枚に。「演出入れて」で背景も変化。

11吹き出しで感情を表現

吹き出しの形を指定すれば感情を視覚的に伝えることができます。通常の楕円＋尻尾はプロンプト不要で自然に付きます。

  • 思考: 雲型＋尻尾は丸を複数／点線枠でも思考を表現
  • 叫び・強調: 破裂枠・ギザギザでバーンと強調
  • 心の声: 放射線状（集中線）
  • 怯え・震え: 波線の吹き出し
  • ナレーション: 四角枠——変になる時は明示指定
「尻尾なしで」「バルーン（楕円）で」など形状ワードを使い分けると、その通りに描いてくれる！

12コマ順のプロンプトエンジニアリング

海外モデルは英語の読み方（左→右）がデフォルト。日本漫画の逆Zパターン（右上→左下）を教え込む必要があります。

  • 教え方は3つ: コマに番号123456を振る／「右上がスタート、左下が最後」と文章で／画像を見せる
  • 中央に斜め線があるコマは縦に読む（縦移動）——この例外パターンも学習させる
  • コマ例の画像をGeminiに読ませ「なぜこうなるか」を考察させ、その回答をソースへ——フュー ショット（例示）で画像とロジックがリンクし完全に理解
読み順: 右上 1 → 2 → 3 → 左下（最後）
例外: 中央斜め線のコマは縦に移動
→ スクショ画像＋解説テキストをソースに投入

13NotebookLM: コンテキストファースト

NotebookLMを漫画制作のストーリーエンジンとして使う方法。100ページ級の長編がコピペレベルで作れます。

  • ChatGPT＝プロンプトファースト（指示が先、文脈が後）／Gemini＝コンテキストファースト（文脈が先、プロンプトが後）
  • ソースに必要なものを全部ぶち込む→ボタン1つで生成（カスタムプロンプトなしでも動く）
  • この手法は創発プロンプティング——仮想学習したソースからAIが直接シーンを構築
  • やたらプロンプトを入れるとそこだけ不自然になる→基本はAIに任せ、ダメな時だけ人間が調整
  • 制約: 横長スライド形式のみ・PDF出力。パソコン／ブログ向け漫画に最適

14ソースの作り方: 詰め込むもの

創発の質はソース（仮想学習教材）の質で決まります。思い当たるものを全部入れ込むのがコツ。

  • 基本: あらすじ・エピソード（第1話、第2話…）・世界観・世界の歴史・キャラの関係性・生活・性格・よく使うセリフ
  • 画像: 3面図・アクセサリー・表情バリエーション・2人が並んだ姿（→扉絵に自動採用される）
  • コンセプトアートを作ると世界観の質が一段上がる
  • 同じ背景を毎回使いたいなら人物＋背景のファイルを作って投入→一貫性が出る
  • 小説をコピペするだけでも運用可——無料ユーザーでも1日数ページ書ける

15複数生成とモンタージュで成功率UP

1枚で当てるより同じストーリーで3つ作って良いものを選ぶ方が結果的に早い。文字化け対策にもなります。

  • ABCと3つ生成→当たりを採用、ハズレのページはB/Cと入れ替え
  • 入れ替えがバレないのは一貫性があるから——一貫性こそ最大の下準備
  • 部分修正は場所の指定だけ: 「左下のコマの文字を修正」「顔を書き直して」「ソースを見て一貫性を持たせて」
  • 複数生成はクレジット消費に注意——修正で戦うか複数作るかは好みで
主人公の容姿が崩れたページは「変更」→「ソースを見て」で若返り修正——違和感なく差し替え完了！

17コマ回りのマジック: 空間の操作

迫力はコマ割り（空間レイアウト）で作れます。これらは装飾ではなくプロンプトに組み込むパワーワードです。

  • コマ間の余白（ガター）＝時間操作: 狭い=速い、広い=ゆったりな「間」が生まれる
  • インサート: コマ内にコマ→視線の強制誘導（例: ペンダントが光る）
  • ぶち抜き・断ち切り: コマ外にキャラがドーン→解放感・圧倒的存在感。必殺技に
  • 斜めコマ・X斜め線: スピード感・緊張感。平行線=ゆっくり、水平線の変化で静けさも作れる
  • 基本は水平線の段構成（横分割優先）→読み順→時間操作の順で組み立てる
分からなければ「コマ割りの方法をディープリサーチして」——それをプロンプトエンジニアリング代わりにするのが結論！

18まとめ: AIは作画、あなたが演出家

全ワークフローの統括。コマ順を覚えさせ、3面図と背景を用意し、エコンテから1コマずつ生成、修正スレッドで直し、最後は手作業で仕上げる——この分担が完成度を決めます。

  • 全体フロー: アイデア → コマ順を学習 → 3面図・背景 → エコンテ生成 → 1コマずつ生成 → 修正 → 完成
  • 潰れた文字の修正など手動が早い部分は手動で——全部AIに頼まない
  • 横長のみの制約は3〜4枚を縦に並べれば縦漫画も理論上可能（手間大・未検証）
  • 良い漫画が書けたらマネタイズも狙える——ぜひ活用を
空間のマジックを操る演出家になったつもりで、壮大なドラマチックな漫画を紡ぎ出そう！
