【AI活用の最前線】Claude CodeでKPIを伸ばすツール
「ライジングループ」

AIで「作る」のは一瞬になったのに、数字は動かない——その運用部分を人間が回すために自作した司令塔ツール「ライジングループ」を、実際の画面と生データで公開。ゴール→ボトルネック→試作の実行→試作の評価という4つのループを、YouTubeチャンネルとゲームサイトの実運用で回す様子を18枚のカードに整理します。

📅 2026年10月9日公開 |  🎬 YouTubeで視聴 |  🚀 ツールは無料公開中

① ギリギリ開発会議とは

京都と鎌倉を拠点に活動する開発チーム「ボイスアップラボ」が、最新テックやAIの話題をエンジニア目線で「ギリギリ言える範囲」でぶっちゃける番組です。

  • メンバー3人でのゆるいトーク形式で進行
  • 「コードは書かないけど最新ITは気になる」そんな人にぴったり
  • 今回はメンバーが自作したClaude Code活用ツールの実践報告回
「エンジニアがAIをちゃんと活用した結果、何が起きたか？」を生の画面で見せる珍しい回！

② 課題発見: 作るのは一瞬、運用がループになっていない

Claude Codeの進化で動画・プレゼン資料・画像・アプリ・Webサイトまで一瞬で作れるように。しかしその運用自体が全然ループエンジニアリングになっておらず、それが個人的にすごく嫌だったと振り返ります。

  • 動画・画像・LP（ランディングページ）も一瞬で完成
  • 作ったものを「ちゃんとみんなに使ってもらって運用したい」
  • 運用こそヒューマンインザループで回したい——これが開発の動機

③ 「作ってXで自慢して終わり」問題

作るのが簡単になるほど、広める・売上につなげる部分はAIがまだやってくれないことが浮き彫りに。エンジニアは「作ってXで自慢して終わり」になりがちだと自己分析。

  • 広め方・売上化には人間の経験が不可欠
  • 小さな作業はAIに任せられるが、中心となる大きなループは別
  • 「作るのが簡単になったからこそ運用の差が明るみに出た」
エンジニアあるある…「作って満足」からの終了、心当たりありますよね？

④ 増えたのは「1個上のレイヤー」の判断

実装はAIに任せられるようになり、エンジニアの1個上のレイヤー＝経営的な意思決定が急増。それがループに見えたからこそ、改善の対象にできます。

  • 広告に10万円かけて20万円回収できるか
  • 値上げしたらお客さんは離れるか離れないか
  • 無料から有料への転換のタイミング
  • 新機能を作るべきか、集客に時間を使うべきか
「これって経営ですよね」——ループに見えるなら、回して改善できる！

⑤ 前回の「ループエンジニアリング」の肝を転用

以前紹介したループエンジニアリングの肝は、CLAUDE.mdのルールをどんどん変えていく・メモリーをちゃんと貯めていくことをClaude自身に改善させること。この形を「自分の求める数字を伸ばす」ことに応用したいと考えました。

  • CLAUDE.mdのルールを継続的に更新
  • メモリーを貯めて学習材料にする
  • 同じ構造をKPI改善ループに拡大する発想

⑥ 「ライジングループ」とは

Claude Codeで数字を伸ばすためのループアプリ。自作の業務プロダクトとして開発し、現在も実運用中。作業はAIエージェントに任せ、人は判断材料として指標を見て指示を出します。

  • 人間: 指標を見て「何を試すか」を決めて指示
  • AI: 分析・提案・実行・評価を担当
  • その繰り返しを人間が回しやすいUIにした
  • 番組内で無料公開が発表された

⑦ 中核は「4つのループ」

ループエンジニアリングをアレンジした構造で、ゴールの数字を目指して徐々に上げていくサイクルを回し続けます。

ゴール 数字を目標に設定 分析
ボトルネック 達成に必要なものをAIが分析 提案
試作の実行 人がAIと相談して決定→AIが実行
試作の評価 AIが自動評価→学習材料に再びゴールへ

⑧ UIの正体: 1枚のHTML＋Claude Code

画面を開くとループが埋め込まれた1枚のHTMLがあり、その右側にあるチャットは実はただのClaude Code。自分のマシンにインストールされたClaude Codeがそのまま表示されます。

  • 左の指標ダッシュボードを見ながら
  • 右のClaude Codeにひたすら命令・実装してもらう
  • オリジナルダッシュボードは「数字が並ぶだけ」で役に立たなかった経験
  • Webアプリとしての大機能はなく表示に徹する設計

⑨ 自身のYouTubeチャンネルで実運用開始

番組冒頭で生の累計収益データを公開しながら、実際にライジングループで回している2つのループを紹介。

6,990人チャンネル登録者（10月6日現在）
470ドル推定広告収益
  • ループ1: 2週間で登録者+500人を目指す
  • ループ2: 週の推定収益200ドルという「欲望の数字」
「こんな（収益データ）出しちゃっても大丈夫ですかね？」という掛け合いから始まる生々しい公開回！

⑩ AIがゴール数字を自動分析

ゴールを見たAIが勝手に分析レポートを生成します。かつては集計するだけでも大変だった分析が自動化されました。

  • 8月中旬に827人増加、うち554人はバズったループエンジニアリング解説動画経由と判明
  • テーマが定まった「保存版」動画は再生あたり5〜10人が今も登録してくれる
  • 注目指標はシェア数——友達や同僚に回された回数の証拠

⑪ ボトルネック分析: 視聴者と登録理由

ゴール達成に「今何が必要か」をAIが分析。YouTube APIを全て接続済みなので、コメントまで取得して分析してくれます。

  • 視聴者は40〜50代とミドル層が中心
  • 登録理由の約半分は「知っていたことに名前と手順をくれる実践者への信頼」
  • コメントもAPIで取得し詳細に分析
「登録の理由はこれ面白いですよね」——数字の裏にちゃんと視聴者の顔が見える！

⑫ 試作案も同時に自動提案

問題点や傾向が分かると、試作案までAIが同時に出してくれます。ダサい案は自分で消して考え直すことも。ボタン1つで右のAIに指示を渡せます。

  • 手順をまとめた1枚の資料を動画ごとに配る
  • ニュースは登録に繋がらないので減らし、その枠で役に立つ保存版を出す
  • 「講座」コメントを集めて続きの回で取り上げる——コメントが増える好循環

⑬ 試作の実行: ショート動画制作まで完結

採用した試作は「登録率の高い保存版をショート動画化して入り口を作る」。バズった動画から2場面を選び、ショート2本の制作から公開までClaude Codeが完結させました。

  • 題材は「5分で実践 超簡単ループエンジニアリング」
  • 「この順番でショート動画を作って」と依頼するだけ
  • 1本目・2本目とも公開まで自動で完了
  • 2本目はプロジェクトのJSONL履歴を検索してCLAUDE.mdの改善点を探す内容
「ここで実行までできちゃうんですよ」——ダッシュボードから出ることなく施策が世に出る！

⑭ 試作の評価: A〜Eの自動採点

実行した試作は評価フェーズへ移動し、AからEまでの評価が自動でつく仕組み。施策が効いたかどうかが一目で分かります。

  • 試作の変遷と結果が時系列で並び、A判定/B判定の流れが見える
  • 評価が芳しくなければ施策を選び直し→実行→評価を繰り返す
  • 常に上の数字（ゴール）を見ながらループを継続

⑮ ゲームサイト運営でも実践中

元々は自社運営のゲームサイトをちゃんと運用したいのが開発の起点。こちらはループがいっぱいある、より本格的なユースケースです。

  • 来訪者を新規とリピーターに分類、曜日別の来訪傾向も可視化
  • 9月11日に2,300人へ通知のABテストを実施→狙い通り来訪が増加
  • メッセージ用画像の作成はClaude Code（＋Codex）へ依頼
  • 「セットして」と言えばブラウザを操作してコードまで設置
  • 目標は現在の来訪者数を10倍に伸ばすこと

⑯ 株の運用にも転用できる汎用性

共同開発者への提供も開始。なんと株の運用に使うメンバーも——グラフを出してどれが良さそうか・危なそうかを分析してもらえます。

  • 基本はClaude Codeをつなぐだけというシンプルさ
  • 左画面は「常に数字を見に行く」ルールの表示のみ
  • 実作業は全て右のAIに投げる使い方
「このアプリだけで全部完結しちゃう、すごい世界」——KPIなら何にでも適用可能！

⑰ なぜ画面が必要? 「知見を貯める」ため

ライジングループ以前は「Analyticsデータを持ってきて改善点を教えて」とClaude Codeに聞いても、セッションが切れたら終わり。前回何を話したか・何を試したか忘れて振き返らず、また新しい方法を聞き直す状態でした。

  • 従来: セッション断絶で知見が溜まらない
  • ライジングループ: 成功も失敗もログとして貯まる
  • CLAUDE.mdのようにエンジニアリング的に履歴を蓄積

⑱ 人間の役割と正体は「スキルの集合」

正直に語られた限界:AIの試案はほとんど当たらず、ありきたりな一般論で攻めてくる。だからこそ人間のアイデアと経験が必須で、使い込むうちに判定精度が上がり人間のスキルアップツールにもなります。

  • 中身はほぼロジックなしのスキルとして実装——表の挿入や判定アプリ組み込みも柔軟に可
  • 「筋が悪い」と判別できるのは経験を積んだエンジニアの強み
  • 無料公開中・概要欄からアクセス、フィードバック歓迎
  • 結論: 作業はAIに、人にしかできないループはライジングループで
「ちゃんと使えれば商売になる」——手法が広く受け入れられるか、皆の反応を知りたいそうです！
