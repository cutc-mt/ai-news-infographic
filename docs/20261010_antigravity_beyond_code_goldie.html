① もはや「ただのコーディングツール」ではない

冒頭でJulianは問いかけます。「Antigravityはコーディングツールだと思っているなら、Googleが追加してきた機能を見逃しています」と。

  • エージェントがファイルを読み、
  • リサーチを行い、
  • スケジュール実行もできる
  • 新機能の中にはインターネット接続なしで動くものまで登場
「ほとんどの人はスクロールして見過ごす。でも最後の機能が大きなやつだ」

② Antigravity 2.0とは何か

Antigravity 2.0はAIエージェントを管理するデスクトップアプリ。Googleのドキュメントによれば「複雑なナレッジワークとコーディングタスク（ディープリサーチを含む）」のために設計されています。

  • エディタではない。エージェントを起動し、作業を見て、ライブまたはバックグラウンドで操縦する場所
  • エージェントはコマンド実行・ファイル読み書き・ウェブ検索が可能
  • SkillsとMCP（エージェントと他アプリを接続する標準規格）で外部ツール連携
  • サブエージェント管理・Chromeでの作業・プラン作成にも対応
「コード以上のことができる」という表現はGoogle自身の言葉

③ エンジンはGemini 3.8 Flash

フードの下にはGemini 3.8 Flash。Antigravity SDKと、Geminiマネージドエージェント内のAntigravityエージェントのデフォルトモデルです。

  • 100万トークンのコンテキストウィンドウ
  • 思考レベルは低・中・高の3段階
  • 正直な注意点: 長く難しいタスクでは設計上トークンを多く消費することがある、とGoogle

④ 新エージェントハーネス——トークン40%削減

9月17日、Googleは新しいエージェントハーネスを発表。antigravity-preview-9-2026という識別子で、Antigravityのツールと挙動をGoogle AI StudioとInteractions APIに持ち込みます。

  • ハーネスとは、モデルの周りのレイヤーで計画→実行→結果確認→繰り返しを可能にするもの
  • Google社内テストでファイル編集時に出力トークン40%減（あくまでファイル編集のみ）
  • 約13.5万トークンで長いセッションを自動コンパクト化し、長時間ジョブが継続可能
  • 1実行あたりのトークン上限を設定可能
  • 新しいcredentials APIで接続先ツール（GitHub・Slack等）を選択。モデルはアクセストークン自体を見ない
-40%ファイル編集の出力トークン

⑤ /plan——書く前に計画をレビュー

/planと入力すると、エージェントは何も書く前に計画のドラフトを作成します。9月22日のバージョン2.17で登場しました。

  • まずファイルを読み、不明点があれば質問を返す
  • 読んで編集できる計画を提示。各ステップにコメントを残せる
  • 問題なければproceedで実行へ
  • plan review policy設定: すべての計画をレビュー／エージェントが必要と判断時のみ／レビューをスキップ
ファイル読取 質問 計画ドラフト レビュー・コメント proceed
ファイルが変更される前に間違った方向を捕捉できるのが価値

⑥ サブエージェント——ライブカードで監視

サブエージェントとは、メインエージェントが作業を委任するヘルパーエージェント。バージョン2.16以降、各サブエージェントはライブカードとして表示されます。

  • 状態は実行中・待機中・完了がひと目で分かる
  • カードから直接停止も可能
  • 9月30日のv2.19では、メインエージェントを経由せずメッセージボックスから直接サブエージェントに指示できるように
ヘルパーのミスをその場で修正できるようになった

⑦ 操縦のためのスラッシュコマンド群

エージェントを操縦するコマンドが多数登場。会話の流れを壊さずに深化させられます。

  • /btw + 質問: 会話を既に知るヘルパーに質問を送る
  • /boost: 複数エージェントを使うより深い推論パス
  • エージェントチームを実行するコマンド（プレビュー版、動画内では聞き取りが不明瞭）。Google曰く「長期プロジェクト・移行・オープンエンドなリサーチ向け」
  • Cmd+K / Ctrl+Kで過去の会話を内容で検索
  • エージェント作業中も入力を続けられ、フォローアップはキューに溜まり、設定次第ですぐ送信も可能

⑧ プラグインストア——アプリストアのように

9月28日のv2.18で、アプリ内にマーケットプレイス付きのカスタマイズタブが追加されました。

  • プラグインはSkills・MCPサーバー・ルール・サブエージェントを1つにパッケージしたもの
  • 閲覧してプラスをクリックするだけでインストール完了
  • デスクトップアプリで追加したプラグインはコマンドライン版にも反映
  • Google公式ピックス: Firebase・Android・Flutter・Chrome DevTools・BigQuery
ブラウズ → クリック → 導入。3ステップ

⑨ コード以外①: オートメーション

10月7日、スケジュールされたタスクはオートメーションへと生まれ変わりました。動画タイトルの「コード以外」の核心です。

  • 今すぐ実行にもスケジュール実行にも対応
  • create with promptを選ぶと、エージェントが設定手順を案内してくれる
  • 定型業務を自動回帰ルーチン化できる
プロンプトで作成 トリガー設定 自動実行 完了通知

⑩ コード以外②: ドキュメントをネイティブ読解

バージョン2.16以降、Word・Excel・PowerPointファイルをプロンプトにドラッグするだけで、Geminiモデルがネイティブに読み取ります。

  • PDFも対応
  • 音声ファイルもそのまま投入可能
  • 資料の要約・分析・翻訳などをコードを書かずに実行できる
Office資料をドラッグするだけ——変換の手間なし

⑪ コード以外③: リモートコントロール

自分のコンピュータ上で動くエージェントセッションを、任意のブラウザから運転・監視できます。

  • 出先のブラウザからセッションをドライブ＆ウォッチ
  • エージェントが完了した時・手助けが必要な時に通知が届く
  • 手元のマシンの作業を離れた場所から制御

⑫ コード以外④: PDF出力・チャート・画像生成

成果物のアウトプットも多様化。リサーチ文書・チャート・画像・定時実行をコード以外で扱えます。

  • Chart.js・Plotly製チャートがチャット内にそのまま表示
  • コマンドライン版では画像リクエストが内蔵の画像生成ヘルパーに送られ、結果を最大3回チェック

⑬ 目玉機能: エージェントのオフライン実行

冒頭で予告された「大きなやつ」。Antigravity SDKがローカルモデルに対応しました。Googleのドキュメントによれば、APIキーもインターネット接続もなしで自マシン上でエージェントを実行できます。

  • 方法1: GoogleのLiteRTでモデルファイルを端末上で直接実行。ドキュメント例はGemma 4 26B（約16.8GBダウンロード）
  • 推奨環境: ビデオメモリ／ユニファイドメモリ24GB以上
  • 方法2: LM Studio・vLLMなど既存のローカルサーバーに接続
  • Googleのサンプルコード: クラウドのGeminiプランナー＋端末上でコードを監査・パッチするローカルGemmaエージェントの組み合わせ
  • 注意: SDK利用には少しのPythonが必要（サンプルはGoogle提供）
エージェントはもうクラウドだけに住む必要がない

⑭ 安全性: サンドボックスと権限管理

エージェントはコンピュータ上でコマンドを実行するため、制限が重要。9月19日のv2.15で、Windowsにファイル＆ネットワークサンドボックスが導入されました。

  • サンドボックスはコマンドがアクセスできる範囲をフェンスで囲む仕組み
  • サンドボックスコマンドにはシールドバッジが付き、囲まれていたことが一目で分かる
  • 権限リクエスト時はコマンドが強調表示され、承認前に読みやすい
  • 承認済み権限はその会話の残りで記憶される
  • 10月5日のCLI更新: Windowsのサンドボックスコマンドが管理者権限不要に。Python・Git・npmが最初からサンドボックス内で動作

⑮ カスタムエージェント——Markdown 1枚から

自分専用のエージェントはシンプルなMarkdownファイルとして書けます。

  • 独自のルールとフックを記述できる
  • 既存のSkills・ルール・サブエージェントを再利用可能
  • 特定の仕事に特化したヘルパーを1ジョブ用に育てることができる
Markdownを書くだけで、専属ヘルパーが育つ

⑯ 全体像: 1つのエンジン、4つの顔

Julianの読み解き: Googleは1つのエージェントエンジンを構築した。同じハーネスのアプローチが、デスクトップアプリ・コマンドライン・SDK・Gemini APIのマネージドエージェントの背後にあります。

  • その上にプラグイン（アプリストアのように）・オートメーション・リモートコントロール・ローカルモデルが載る
  • Googleは「OS」と呼んでいない——しかしひとつのエンジンがあらゆる場所でエージェントを動かすとき、それは仕事の基盤層に見えてくる（Julianの個人的見解）
  • 変更ログは数日ごとの新リリース。v2.21が10月7日に登場
