Claude Docs・Slides・Design
〜無料プランでも正式提供へ・設定と「作り放題じゃない」枠〜

Anthropicが、Claudeの中で書類を作るClaude Docs・Claude Slides・Claude Designの試験公開（ベータ）を終え、無料プランを含む全プランでの正式提供を発表。頼むと会話の答えではなく、Claudeの横に「そのまま使える書類」が開くようになります。待たずに使える設定の確認方法から、普段のClaudeと共通の「作り放題じゃない」枠の仕組み、無料では使えない機能、単体Designサイト終了の時まで解説。学園祭・模擬店の企画書を例にした使い方を18枚のカードに整理します。

① 今回のニュース: 書類作成が全プランで正式提供に

Anthropicがアメリカ時間の10月8日、Claude内で文書・スライド・デザインを作る3機能の試験公開（ベータ）を終了し、無料を含む全プランで正式提供すると発表しました。

  • 対象はClaude Docs・Claude Slides・Claude Designの3つ
  • 提供先は無料のFreeプランを含む全部のプラン
  • 今までは有料プラン限定の試験公開だった機能が、無料ユーザーにも開放
  • 本動画の問い: 無料のまま資料作りをどこまでClaudeに任せられるか

④ 3つの役割: Docs・Slides・Design

3機能の役割分担はシンプル。作りたいものの形で使い分けます。

  • Claude Docs: Claudeと一緒に書いて直していく文書——企画書のようなもの
  • Claude Slides: 発表の資料を作る
  • Claude Design: チラシや試作の画面など見た目が大事な資料
  • 動画の例: 学園祭の模擬店なら——企画書はDocs、発表はSlides、チラシはDesign
文書=Docs 発表資料=Slides チラシ・画面=Design

⑤ 何が変わるか: 横に「そのまま使える書類」

今までの答えは会話の文章で返ってきて、WordやPowerPointに貼り直す必要がありました。今回はClaudeの横に書類がそのままの形で開くのです。

  • 前: 会話の答え → コピペ → 文字の大きさがバラバラ → 夜中に修正
  • 後: 文章なら文章、スライドならスライドの形で最初から書類として出てくる
  • 動画冒頭の実例: 学園祭の企画書を深夜に1枚ずつ貼っていた手作業が不要に
「貼ったら文字の大きさがバラバラになって夜中に直してたのだ」これまでの手間

⑥ アーティファクト: 専用タブに自動保存

作ったものは画面の横の一覧にある専用のタブにまとめて保存されます。別の会話からでも開き直せるのがポイント。

  • このタブの名前が「アーティファクト」——Claudeが作った書類の総称
  • 会話が終わっても書類は残るので、後から再開できる
  • 企画書→スライド→チラシを同じ会話の中から繋げて発展させられる
会話で作成 アーティファクトに自動保存 別の会話からも開ける

⑦ 頼み方: 特別な呪文は不要

特別な呪文はいりません。いつもの会話で頼むだけ。入力欄の「出力」から選んでも、アーティファクトのタブにある見本から始めてもOK。

  • 普段どおりの言葉でOK——公式例: 「このメモを月別のスライドにして」
  • 入力欄の「出力」メニューから種類を指定してもいい
  • アーティファクトのタブの見本（テンプレート）を起点にしてもいい
  • コツ: 何のための文章で誰が読むのかを伝えると話が早い
「特別な呪文がいるのです？ ——いつもの会話で頼むだけよ」

⑧ Docs: まず質問してから書き始める

Docsに企画書を頼むといきなり書き始めません。最初にいくつか質問をしてきた上で下書きを出してきます。

  • 先行き確認: 目的や読み手を先に聞いてくる——人間の先輩みたい
  • 答えると画面の上に下書きが出てくる
  • しかも「なぜそう書いたのか」をコメントで横に残す——直す時に迷わない
  • バラバラの書きかけメモでもOK: メモを渡して下書きを作らせ、中身は自分で直す使い方
頼む 質問に答える 下書き+根拠コメント 自分で仕上げ

⑨ Docs: 直し方と書き出し先

直し方は複数あり、部分的に頼むことも自分で書き換えることも可能。書き出し先も実務で困らない4形式が揃います。

  • 直し方: ①自分で直接書き換える ②会話で「注意点の節を足して」等で依頼 ③文字を選んでそこだけ直させる ④コメントでClaudeを呼ぶ
  • 書き出し先: Word・PDF・Markdown
  • さらにGoogleドキュメントにも書き出せる
  • 「実行委員会がWordで出して」と言われても困らない
4形式Word / PDF / MD / GDoc
部分的修正文字選んで直す
根拠コメントなぜそう書いたか残る

⑩ Slides: 企画書をそのまま発表資料へ

Docsで作った企画書に対して「そのままスライドに作り替えて」と頼めます。PowerPointで1から組み直す必要がないのです。

  • 文書 → スライドの作り替え（変換）が一発でできる
  • スライドは1枚ずつ直接直せるし、Claudeの中でそのまま発表も可能
  • 書き出し先: PowerPoint・PDF・Googleスライド（編集できる形）
  • 今回の発表では書き出した時の見た目が編集画面の通りになると明記——「書き出したら崩れる」が一番困るので助かる
  • スマホのアプリから直せるようにもなった
企画書（Docs） 「スライドにして」 発表もClaude内で PPTX / PDF / GSlide

⑪ Design: チラシ・試作画面を作る

模擬店のチラシはDesignの出番。チラシや1枚ものの紙、試作の画面のような見た目が命の資料を作ります。

  • 用途: チラシ・一枚もの・UIの試作画面
  • 企画書・スライド・チラシが同じ会話の中身から全部繋がる——一貫した流れで作れる
  • 「できたら模擬店のメンバーにも見せたい」→ 共有機能で対応（次カード）
  • 使いこなし方は自分で作って確かめるのが一番
「企画書、スライド、チラシ——同じ会話の中身から全部繋がるのだ」
一気通貫の強み

⑫ 共有: リンク共有と権限は2種類

作った文章は最初はあなたにしか見えません（勝手に公開されない）。共有は無料・Pro・Maxプランならリンクで可能です。

  • 初期状態: 非公開——勝手に公開されず安心
  • リンクを知っている人と共有できる（無料/Pro/Max）
  • ただし開く相手にもClaudeのアカウントが必要
  • 共有相手の権限は「見るだけ」と「編集できる」の2つ——コメントだけ付けられる権限はまだない
  • メンバー全員がClaudeを使っているとは限らない→WordやPDFに書き出して渡すのが現実的な選択肢
2権限閲覧のみ / 編集
要アカウント閲覧者もClaude登録
書き出しWord / PDFで共有

⑬ 注意: 削除すると元に戻せない

ここが注意点。文章を消すとゴミ箱がないため、共有した相手からも見えなくなります。

  • 削除前には必ず1回立ち止まる——元に戻す手段がない
  • ここまでの共有の決まりは公式ヘルプに書かれている内容
  • 大事な資料は書き出して手元に残す運用が安全
削除 ゴミ箱なし 共有相手も閲覧不能 消す前に一呼吸

⑭ 設定: 無料は待たずにOK・スイッチ1つ確認

「10月15日まで待つ」という日付の話は会社向けエンタープライズプランだけの話。無料・Pro・Maxは最初からオンです。

  • 10月15日にオンになるのはエンタープライズのみ——しかも管理者が先にオンにすることも可能
  • 無料・Pro・Max・Team: 何もしなくてOK
  • 使えない時だけ確認: 設定 → 機能 → 「クラウドコード実行とファイル作成」がオフだと使えない
  • スマホのアプリからも頼める——ただし共有設定の変更はWeb/デスクトップアプリから
設定 機能 クラウドコード実行とファイル作成 オンならすぐ使える

⑮ 枠: 普段のClaudeと同じ＝作り放題じゃない

公式ヘルプではDocsもDesignも普段のClaudeと同じ枠から減ると明記。専用の回数枠はない——これが「作り放題じゃない」の正体です。

  • 資料作成も相談（チャット）と同じ枠を消費
  • 大きな頼み事ほど枠を減らす——公式例: いくつも資料から長い文章を下書きさせる等
  • Designは以前は専用枠があったが、今は普段の枠と一本化
  • 「無料だと何本まで？」→ 制作時点の公式ページに数字は未記載。作りすぎに注意
「作りすぎには気をつけるのだ。相談の分まで減っちゃうのだ」枠の使い方

⑯ 無料では使えないもの・新機能2つ

無料プランで使えないのは①他のサービスを書類に繋ぐこと、②書類の中にデータを貯めておくことの2つ（有料プランから）。

  • 外部サービス連携・データ保存は有料プランから
  • 新機能Dashboards（会社のデータからグラフ一覧画面を作る）は有料プランの試験公開
  • 新機能Motion（解説アニメをMP4動画で書き出し）はTeam・Enterpriseのみの試験公開
  • 無料ユーザーはこの2つは見送り

⑰ 単体のDesignサイトは12月14日で終了

前から単体のClaude Designサイトを使っていた人には期限の話が重要。そのサイトは12月14日で終了します。

  • 期限: 12月14日——それまでは今まで通り利用可
  • 終了後は開くとClaudeの方へ飛ぶ（自動リダイレクト）
  • 移行したいのはデザインシステム（色・フォント・部品の決まりをまとめたもの）——Claudeのアーティファクトページに「デザインシステムを映すボタン」あり。個人プランなら押したら確認なしですぐ移行開始
  • 注意: 単体サイトでのClaudeとの会話とコメントは移行されない——サイト終了で見られなくなる。大事な会話は今のうちに控えを取る。公開リンクもそこで切れる
  • 単体サイトを使っていない人はここは気にしなくてOK
デザインシステム 移行ボタン1個 Claudeへ 会話・コメントは要バックアップ

⑱ まとめ: 任せるのは清書、決めるのは自分

全部Claudeに作らせたら楽にはなる。でも整った書類ほど「もう完成したように見える」落とし穴がある——中身を決めたのはClaudeではなくあなたのはず。

  • Docs・Slides・Designは無料でも正式に使える。10月15日を待つのは会社向けプランだけ
  • 使えない時は設定→機能→クラウドコード実行とファイル作成のスイッチ1個を確認
  • 枠は普段の相談と同じ。作れる本数は公式ページに未記載——作りすぎ注意
  • 単体Designユーザーは12月14日までに移行・会話の控えを取得
  • 任せるのは清書と作り替え（メモ→企画書→スライド）。値段や個数など中身と最後の一言は自分で決める
「3つ作ってみんなで1つ選びなさい」「選ぶのは僕たちの仕事なのだ」——資料作りの夜更かしはきっと減らせる
