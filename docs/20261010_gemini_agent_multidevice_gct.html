① 主役は1つの永続的なクラウドエージェント

今年前半に「モデルとチャットする」時代から「エージェントに仕事を任せる」時代へ移行。今日、Geminiエージェントはその魔法を企業の誰もにも届けます。

  • プレゼンターはAdam Fisher。Gemini at Work 2026のオンステージ実演
  • 使い方は「タスクを記述する」だけ。エージェントが自分のセキュアなコンピュータで仕事を遂行
  • 対応サーフェス: デスクトップWebモバイルCLIほか
  • 13分58秒に収めた実演中心のセッション
「あなたがタスクを記述する。Geminiエージェントが仕事を成し遂げる」——デモ全体を貫くメッセージ

② デスクトップ: すべては1つのプロンプトボックスから

デスクトップアプリには「1つのきれいなスタート地点」があります。質問も、タスクの委任も、コード作成も、すべて単一のプロンプトボックスから始まります。

  • 質問 / タスクの委任 / コード作成を1つの入力欄で受け付け
  • Web・モバイル・CLIなど他のサーフェスでも同じ体験
  • 最初の題材はローンチレビュー資料の作成。普段ならファイル漁り、20個のチャットスペース読み、スライドのピクセル調整で数時間
  • 多くの顧客はMicrosoft環境→まずMicrosoft 365で構築していく

③ タスク実行: ゴール理解→計画→サブエージェント

「PowerPoint、収益モデル、製品動画が必要」と伝えるだけ。Geminiはゴールを理解し、計画を立て、独自のサブエージェントを生成して着手します。

  • 依頼内容: PowerPoint＋収益モデル＋製品動画
  • エージェントは計画を構築し、実行をサブエージェントへ委任
  • ジョブはバックグラウンドで実行し、タスクインボックスで進捗を監視
  • フル開示: デモではタイピングを見せないようプロンプトを貼り付けて実演
ゴール理解 プラン構築 サブエージェント生成 バックグラウンド実行

④ モデル選択: autoモードとサードパーティモデル

モデルピッカーで使用するモデルを選択できます。デフォルトのautoモードは、タスクごとに最適なモデルを自動選択します。

  • autoモード: 速度・品質・コストのバランスを考慮しタスクごとに最適モデルを指定
  • Gemini系モデルを明示的に選ぶことも可能
  • サードパーティモデルも選択肢に用意
速度auto判断軸①
品質auto判断軸②
コストauto判断軸③

⑤ プロジェクトとスキルで文脈を装備

ファイルやフォルダ、さらに「プロジェクト」を添付できます。プロジェクトは、適切なファイル・スキル・エージェントの組み合わせで、Geminiが仕事を遂行しやすくします。

  • デモ例: Q4プロダクトローンチプロジェクト
  • スキル=シンプルな指示。会社から、GitHubリポジトリから、または自作で簡単に作成
  • ファイル／フォルダ単位の添付にも対応し、特定のワークストリームごとに整理
「プロジェクトとは、適切なファイルと適切なスキル、さらには適切なエージェントの組み合わせだ」

⑥ コネクタ: 日常の業務システムに直結

Geminiは、企業が毎日使うシステムとデータに直接接続しています。個別の設定作業はデモ中に一切登場しません。

  • Google Workspace
  • Microsoft 365
  • Slack
  • Jiraなど、その他多数
  • エージェントの全作業はタスクインボックスで常に監視できる

⑦ 見える化された「思考プロセス」

出力の中身の前に、Geminiの思考プロセスそのものが表示されます。ゴールを理解し、計画を立て、サブエージェントへ委任していく様子が追えます。

  • ゴール理解→プラン→委任の流れをそのまま可視化
  • スキルをロード（例: コーポレートブランドのGenkitスキル）
  • 資料構築のためにコードまで自ら記述
  • 実行中ジョブと過去バージョンを切り替えて閲覧

⑧ 成果物: ブランド準拠のPowerPoint＋動画

できあがったPowerPointは、箇条書きを書き並べただけのものではなく、ブランドガイドラインに沿った美しい資料でした。

  • ブランドガイドラインを適用したスライドデザイン
  • 構築したExcel収益モデルから正しい数値を取得
  • タイムラインも資料に反映
  • Omniで製品ローンチ動画まで生成

⑨ Google Workspace: 同僚のように働く

Workspaceでは、Geminiアプリは「同僚（coworker）」として振る舞います。自分のWorkspaceアカウント、メールアドレス、文脈を持ち、チームは他の誰かと同じようにやり取りします。

  • 専用のWorkspaceアカウントとメールアドレスを持つ
  • チームはタグ付け・メール・共有で自然に協働
  • 「与えたものしか知らない」——情報は明示的に共有された範囲のみ
「チームはエージェントを、他のどんな人と同じように扱っている」

⑩ グループチャットのイベントエージェント

グループチャットにイベントエージェントを追加し、コメントでタグ付け。「リージョナルローンチを手伝って」と頼むと、即座に駆けつけます。

  • こちらが用意したスキルとコネクタで過去の作業から文脈を取得
  • まとめた内容: ワークストリーム状況＋チェックリスト＋リスク評価
  • ドキュメントは自分が選んだテンプレートを使用
  • エグゼクティブサマリー、アクションアイテムと担当者、詳細チェックリストを完備

⑪ コメント1つで修正——代理編集と返信

「最近の会議アップデートが抜けている」を見つけて、ドロップしたコメントは1つ。するとエージェントが提案された編集を実行し、自分の名前で返信コメントまで残しました。

  • 人間はキーボードに触れる必要なし
  • 編集＋自分の名前での返信コメントを自動実行
  • ドキュメントはそのままレビュー可能な状態へ
「見たか? 編集も返信も自分の名前で済ませたよ。私はキーボードに触れてすらいない」

⑫ 会議調整: よく情報の行き届いたアシスタント

「リードたちを集めて」と頼むだけ。名前もアドレスも教える必要がありません。チームが誰で、どのタイムゾーンにいて、普段はカレンダー代理経由かまで知っています。

  • 誰かに連絡する前に人間の承認（approval）を取得
  • 下書きは「短くて要点を得たもの」→「許可します」で送信
  • 裏でリードへ代理メールを送り、内部・外部チーム双方に適する日時を提示して調整
  • 通常は返信待ちが長いが、バックステージチームの協力で即日確定——すべての日程調整をGeminiが処理
1回必要だった承認

⑬ プロアクティブな受信箱の整理

受信箱の仕分けとタスク処理は常に大量の仕事。Geminiは重要なものを識別し、効率よくアクションできるよう支援します。

  • トップカード: 重要なリーダーシップ会議、そして基幹ステークホルダーのMattが前日不在
  • 「私はGeminiに何も教えていない」——カレンダー・チーム・ファイルを既に把握。接続も自動化の設定も不要
  • Start with Geminiをクリックで、Matt向けエグゼクティブサマリーを準備
  • 必要な文脈に加え、知っておくべきリスクと更新までハイライト
「重要な情報を表示するだけでなく、その場で実行まで持っていく——これがWorkspaceインテリジェンスだ」

⑮ 無いツールは作る: ライブマイクロサイト

毎週何時間もかかるステータスレポート——複数のSheets、Jiraのブロッカー、他のデータソースの横断集計。Geminiに聞くと3つの提案があり、そのおすすめはライブマイクロサイトでした。

  • 複数のホスティング選択肢から「速さ重視」でHTMLモックアップを選択
  • コードを1行も書かず（読まずに）プロトタイプが完成
  • 複数データソースに分散していたインサイトを1か所に。レイアウトと便利なフィルターを評価
  • チーム管理が容易に。Geminiはここから本番へのデプロイも可能

⑯ CLI: 同じGemini、ターミナルから

同じことをエンジニアがターミナルから行うとどうなるか。同じGemini、同じ仕事がCLIでも動きます。

  • 動的なサブエージェントチームをスピンアップ
  • 持っているスキルでSheetsを読み、データを接続し、コードを記述
  • 完了後はシステムのテストとデバッグも実行
  • データを最新に保ち、readinessスコアなどを追加し続ける
「結論: サーフェスはあなたが選ぶ。エージェントは同じままだ」

⑰ ドリームモード: 好みを学習するエージェント

Geminiは時間とともに「どう働き、どこで働くか」を学習します。ドリームモードが会話を記憶と嗜好に変換し、何も教えなくても個人に合わせていきます。

  • 組織内で自分が誰で、どこに位置するかを学習
  • ステークホルダー別に変わるコミュニケーションスタイルをメモ
  • 嗜好の例: 「emダッシュは使わない」「エグゼクティブサマリーは結論を先頭に」
  • 毎朝のスケジュールジョブ: 新着メールを読み返信の下書きを作成。1本編集して送信すれば差分を復習して改善
  • 翌日には修正の手間が減り、より多くをバックグラウンドで代行——複利的な利益。役割が何であれ、チーム全員が必要なスキル・ツール・嗜好で利用可能
「Geminiが私のスタイルを学ぶにつれ、ナッジは減っていく。私は他の優先事項に集中できる」

⑱ ガバナンス: CIOを安心させる統制

パーソナライズと引き換えに統制を失う、ではありません。管理者はConsoleで、会社全体のユーザーとエージェントを完全に可視化・制御します。

  • 各エージェントに一意のID→人間のアクションとエージェントのアクションを区別
  • トレース: 過去のランで呼ばれたエージェント、LLM呼び出し、ポリシーツール呼び出しを全部確認可能
  • ポリシー例: 外部メールには人間のレビュー（human in the loop）を必須化、機密データの共有を自動ブロック
  • 予算管理: プロジェクト／ユーザー単位の支出、固定キャップ、超過アラート。タスクやバックグラウンド処理が予算を超えない
