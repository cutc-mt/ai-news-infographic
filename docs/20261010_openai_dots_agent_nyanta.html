OpenAIの新機能「dots」は
24時間働くAIエージェント — 課金すべきか解説

先週のAI Dev Day（AIデベロッパーカンファレンス）で発表された目玉機能「dots」。指示しなくても自分で考えて仕事をしてくれる「24時間働くAI社員・AI秘書」として話題です。利用には月額約1万7000円（100ドル）のProプラン以上が必要で、Plusプランからの乗り換えに悩む人も多いはず。本動画では使用感を実際にデモしながら、①24時間OpenAIサーバーで稼働 ②10月末までGPT-6 Astraがクラウド側で無制限 ③クラウド＋自分のPCの両方を操作 ④セッション管理が不要 ⑤音声対話で指示できるという5つの良さを解説。最後に「全員におすすめできるレベルではない」という正直な課金判断まで、18枚のカードに整理します。

①dotsとは？ AI Dev Dayで発表された目玉新機能

先週開催されたAI Dev Dayで数々の新機能がリリースされ、その中の目玉として登場したのがOpenAI dotsです。

  • 「24時間働くAIエージェント」として呼ばれ、非常に話題に
  • お客さんに言うと伝わる例え: 「AI社員」「AI秘書」のようなAIチャットボットサービス
  • 現在は月額1万7000円ぐらいのProプラン以上でないと使えない
  • 本動画では使用感とどういう人が課金した方がいいかを解説

②ChatGPTと何が違う？ 指示なしで勝手に仕事をする

ざっくり言うと、ChatGPTは皆さんの指示や質問をもとに仕事をするAI。dotsは指示をしなくても自分で考えて仕事をしてくれるAIです。

  • Gmail・Googleカレンダーを連携しておけば、メールを勝手に確認して返信が必要なものを教えてくれる
  • 予定を確認して通知してくれる——「返信文を考えて」と言わなくていい
  • ChatGPTのデスクトップアプリ／Webアプリのサイドバーから利用可能
  • dotのキャラクター・ペットを選択でき、チャットしながら仕事をお願いできる

③現在は1つのdotだけ — 複数のdot連携という構想

名前が複数形の「dots」となっている点に注目。現在は1つのdotしか作れないものの、命名から将来の構想が読み取れます。

  • 現在作成できるのは1つのdotのみ
  • 将来的には役割別のdot——例えば経理に強いdotやホーム（家事）に強いdotなどを作れる可能性
  • それらのdot同士を連携させながら仕事を進めるのが構想ではないかと推測
複数の専門dotが協働する未来が来れば、「AI社員のチーム」を持つ時代になるかもしれません。

④良い点1: OpenAIのサーバー上で24時間稼働

dotsは自分のパソコン上ではなくOpenAIのサーバー上で動いているため、こちらから指示をしなくても勝手に様々な作業を進めてくれます。

  • にゃんとのdotは毎朝8時にYouTube動画のネタを提案——海外の動向も含めて11案を提示
  • 朝起きてパソコンを開いたら、dotの方から通知が来ている
  • Gmail連携で定期的にメールを確認し、返信が必要そうなものだけ通知
  • 手元のPCの電源を切っていてもクラウド側で動き続けるのが強み

⑤既存のスケジューリング機能と何が違う？「学習させやすさ」

「定期実行」なら従来のスケジューリング機能（ChatGPTでもClaude Codeでも使える）でも可能でした。1時間おきのメール確認や毎朝8時のネタ探しも設定できました。

  • dotsは提案がイマイチの時「もっとこうして」と気軽に伝えると学習し、次回の提案に反映してくれる
  • スケジュール機能でも毎回フィードバックを与えてドキュメントを更新する運用なら同じことは可能——ただめんどくさい
  • 気軽にAIを育てていけるのがdotsの良さの一つ

⑥良い点2: 10月末までGPT-6 Astraが無制限（最重要ポイント）

にゃんとがdotsを使うか判断する上で1番重要と位置づけるポイント。OpenAIの最高精度モデルGPT-6 Astraが、10月末までdotsの中なら利用量無制限で使えます。

  • GPT-6 Astraは体感Claude Fable並みの精度。大事なタスクに使いたいモデル
  • 欠点は消費がめちゃくちゃ激しいこと——難しいタスクをやらせるとあっという間に制限到着
  • 試したいことがあると勿体なくてAstraを使えず、普段はGPT-6.1 Sol（ソル）などで代用していた
  • 注意: 無制限なのはクラウド環境で処理されたもののみ
10月末までGPT-6 Astra無制限
クラウド側のみ無制限の適用範囲

⑦良い点3: クラウドと自分のPC、両方の環境を操作

dotsはOpenAIのサーバーだけではなく、皆さんのパソコンにもアクセスして処理を行えます。キャラクターをクリックすると「コンピューターズ」欄が表示されます。

  • OpenAI dotsコンピューター: OpenAIが管理するサーバー上のマシン。画面も見える
  • お使いのコンピューター: 自分のPCは現在1台まで接続可能（初回は接続ボタンから）
  • 「私のPCのファイルをまるまる編集して」「このプロジェクトの提案書を作って」と指示すればPCを見て作業してくれる
  • ただし自分のPCで作業させる場合はCodexやChatGPT Workと同じなので利用枠を普通に消費

⑧前回Dev Dayの「Proプラン利用量半分」問題との関係

前回のOpenAI Dev Dayでは月額200ドルのProプランの利用量が半分になるという発表があり、結構ネガティブな反応が多かったと言います。

  • Proユーザーからは不満の声が多かった利用量半減発表
  • 「無制限（で使える機能）にするなら、Proの200ドルを半分にしないでよ」と思う人も多いのでは、と指摘
  • 使い方次第では制限実質ゼロでGPT-6 Astraを使い倒せる今が狙い目
「クラウド側でタスクを処理して」GPT-6 Astraが実行利用量を消費しない

⑨実演: パワポをクラウド側で3パターン作成

仕事で使うパワポもdotsにお願いすれば作ってくれます。実際に「dotsを紹介するパワーポイントをクラウド側で作って」と依頼すると…

  • 「3パターン作って」と言うと3つのパワポをちゃんと作成——A・B・Cパターン
  • クリックして開ける完成品のクオリティもかなりいい
  • 手元に持ってきたい時は右上のダウンロードボタンから取得し、ローカルで編集可能
  • 消費ゼロで贅沢にAstraを使えるからこそ複数案の大量生成が気軽

⑩Dev Dayの新機能「ChatGPTスペース」との連携

同じAI Dev Dayで、ChatGPTスペースというノート的な、チームで共有しながら作業できる機能も追加されました。

  • dotsで作った資料を「スペースに追加して」と言えばアップロードしてくれる
  • 左側のスペースボタンから作成されたパワポなどの成果物を確認できる
  • 調査系などクラウド環境で完結する仕事は現在dotsを使うのがおすすめ

⑪実演: 紹介アニメ動画の作成とWeb開発にも

アニメーション作成もお願いするとクラウド側で作ってくれ、実際にOpenAI dotsの紹介動画を作ってもらいました。

  • クオリティはOpus 5.5の方が圧倒的に上ものの、AI動画制作はクオリティが高く流行中——試すのに無制限枠が最適
  • 開発にも使える: クラウド側でWebサイトを作成→ローカルに送ってもらうことも可能
  • 途中まで自作していたサイトの後ろの動画をBlenderで作ってもらった実例も（まだ完成形でないも無料なら嬉しい）
  • 課題: クラウド側ブラウザでのサイト表示・ネット公開確認がなぜかブロックされてできない
クラウドで作成 GitHub経由 or ローカルに転送 手元で確認（現状は一手間必要）

⑫良い点4: 1つの会話履歴で複数処理 — セッション管理不要

パワポ作成もWebサイト制作も全部1つのチャットセッションで依頼できています。裏ではdotsが必要に応じて他のAIを立ち上げ、別々の処理を同時実行しています。

  • これまではタスクごとにセッションを開き、自分でセッションを管理して終わったセッションを見に行く運用
  • dotsは1つのセッションでお願いすればAIが勝手に必要なセッションに分割してタスク管理
  • dotをクリックするとアクティビティで別タスクの進行を確認可能（必ず表示されるわけではない）
  • セッション管理された方が整理しやすいという人も。サイドバーにあった方が認知負荷が低いと感じるかは人による

⑬良い点5: 電話機能 — 音声対話で仕事を依頼

OpenAIの音声会話モードが内蔵され、人と話すような感じで仕事を依頼できます。動画では実際にdotへ電話をかける実演が行われました。

  • 実演1: 「WebサイトのデザインをAIっぽくなくしたい」→現状を確認して具体的な改善案を提案
  • 実演2: 「紹介スライドを1本にまとめてプレゼンできる形に」→既存12枚版を土台に説明の流れと発表者ノートまで整えると回答
  • 実演3: 「うちのチャンネルの最近の動画を調べてプレゼン化」→複数タスクを並行処理
  • これまでアクアボイスで指示していたが新規セッション→起動→入力→エンターと手間がかかっていた。思いついたことをどんどん話すだけでいい体験は新しかった
「音声入力」の次は「音声対話」でAIを使う時代が流行る可能性がある、と手応えを語りました。

⑭まとめ: にゃんとが感じたdotsの5つの良さ

動画前半の使用感レビューを、にゃんとが5つの良い点にまとめています。

  • 24時間OpenAIのサーバーで動いているので、指示しなくても動いてくれる
  • 10月末までGPT-6 Astraがクラウド側で無制限で使える
  • dotsはクラウド側とローカル環境の両方にアクセスできる
  • 仕事をお願いする時に自分でセッションを管理しなくていい
  • 音声対話でのAIへの指示がすごく使いやすい

⑮課金判断: Plusのままの人は無理しなくていい

月額20ドルのPlusプランではdotsが使えない中で、100ドルのProプランに上げるべきか？ にゃんとの結論は「まだ全員におすすめできるレベルではない」。

  • 「dots楽しそうだから使ってみたい」人はどんどん使ったらいい
  • 「24時間動く」はスケジュール機能で定期実行を設定すれば代替可。常時動かしたいならパソコンをつけておけばいい
  • セッション管理が楽な点も、常時やるタスクは大体3〜4個なので自分で管理しても手間ではない
  • 機能面の理由でわざわざProに上げる必要はまだないというのが個人的見解

⑯一方で課金すべき人: 試したいことが山ほどある人

dotsに課金した方がいいのは、「試したいことがめちゃくちゃあるのに使用料が気になって全然できない」人です。

  • 10月末までは無制限なので、1ヶ月だけ契約してめちゃくちゃタスクをやらせるのはアリ
  • dotsのコンピューターにはBlenderなど3Dモデリングソフトも入っており、使用量を気にせず試せる
  • ただし、そこまで使い倒す人はすでにProプラン契約済みであることが多い
  • 「これからdotsのためにProにするのはどうか」というのが正直な気持ち。おすすめの使い方があればコメントで教えてほしい

⑰パーソナルAIエージェント競争: dots・Grok・ヘルメスエージェント

OpenAIは現在28日間連続で機能を改善する取り組みを実施中。dotsにもアップデートが入り、視聴時点でさらに便利になっているかもしれません。

  • にゃんとは最近Grokボットにも課金して使用中。ヘルメスエージェントにもボットがあるらしい
  • 予想: 日本ではdotsやGrokボットよりヘルメスエージェントの方が普及するかも
  • 会社で使う場合、会社データをOpenAIのクラウドへアップロードするのはセキュリティ的に上げられないデータが出てくる
  • ヘルメスエージェントは自分でサーバーを用意してデータを置ける——入力は外部送信されるがデータの置き場所を自分で管理できる
  • トレンド: AIエージェントに仕事の文脈を参照させ、成果物を見せながら判断基準を教える使い方が増加中
