PIVOT公式チャンネル（斎藤隆×真中満×PIVOTデータ班＋トラジェクト・スポーツ）

大谷翔平も使う投球ロボットが
「唯一再現できない球種」とは？

MLBは今、AI×トラッキングデータで練習現場を再構築しつつあります。回転数・回転軸・球速・リリース角度・アームスロットまで実測データ通りに再現する「ピッチングロボット トラジェクト・アーク」は、全世界120台・MLB30球団中28球団・NPB12球団中7球団が導入。価格は72万ドル（約1億1000万円）ですが、ソフトウェア更新は無償です。前半には山本投手の「安定」と佐々木投手（ドジャース）の「ポテンシャル」をデータで読み解き、後半は大谷翔平が球場の外でバッティングしなくなった理由、そしてクイズ「唯一再現できない球種」の正解＝アンダースローまで、AI×データで進化するMLBの現場を18枚のカードに整理します。

①ポストシーズンを10倍楽しむ: 山本の「安定」、佐々木の「ポテンシャル」

前半はPIVOTデータ班・岡田さんによる「ポストシーズンを10倍楽しむデータ」。投手編ではまず山本投手の安定感、そして注目は佐々木投手（ドジャース）です。

  • 山本投手は基本的に安定した内容を維持
  • 佐々木投手はボールの質・コマンドなどを見ると、ボール自体は山本投手に負けないぐらいの評価
  • 後半戦の良かった時期の投球がまさにポテンシャルの証明。「まだまだ楽しみなところがある」
  • 与四球（BB）が増えて印象は落ちても、投げているボールの質の高さは変わらない——印象とデータのギャップが面白い

②データで取れないもの: 「緊張」と勝負どころの1打席

データの得意分野の一方で、数値化が難しいものも登場します。「代打で決まって回ってくる勝負どころの1打席」は取れるのか？

  • 「緊張した時にどうなるか」はベンチにいる人しか分からない——データ班への禁句に(笑)
  • 代打の1打席はシチュエーション・気持ち・試合ごとに全部違うためデータ化が困難
  • それでも9月・10月の数字を出せば「後半に強い人」は見えてくる
  • メジャーで大事にするのはまさに9月以降の数字。「ここからすごい人」はプロが見ている
データの限界を認めることも、データで野球を楽しむ第一歩です。

③ピッチングマシンから「ピッチングロボット」へ: トラジェクト・アーク

岡田さんの「すごいロボットがある」という一言から本題へ。実際のピッチャーの投球を再現できるトラジェクト・アーク。同社はこれを「ピッチングマシン」ではなく「ピッチングロボット」と呼びます。

  • 従来機（アーム式・ローラー式）は決まった方向・角度から発射し、回転や軸を一切無視。投手の肩の負担軽減が主目的だった
  • トラジェクト・アークはAIとトラッキングデータでリリース角度・回転数・回転軸・球速・アームスロット（腕の角度）を精密に再現
  • 右投手・左投手の実際の数値を入力すると、映像と共にその投手のボールが再現される
  • 本体はレール上を移動——文字通り「動くロボット」

④創業2019年: ウォータールー大学の学生2人が生んだ会社

トラジェクト・スポーツは2019年創業・7年目の若い会社。カナダのウォータールー大学の学生2人が、計測時代の野球で「投手以外にも何かやりたい」とマシンを編み出しました。

  • 設立7年でここまで実績を伸張。社員もとても若い
  • 日本側のゲストは幼少期を米国で過ごしリトルリーグでバージニア2位（本人談「野球のピーク」）。帰国後は神奈川の高校でプレー
  • 大学と社会人でアメフトを30歳頃まで継続。その後はスポーツメーカーでグラブ・バット制作やマーケティングを経て、計測器ラプソードの日本立ち上げにも関与
  • 岡田さんとご近所同士という縁で番組に出演

⑤導入実績: 全世界120台、MLB28/30球団、NPB7/12球団

2026年10月現在の導入実績がこちら。メジャーは30球団中28球団、日本プロ野球も12球団中7球団が導入済みです。

120台全世界の導入台数
28/30MLB球団
7/12NPB球団
  • 未導入の2球団は初期に精度が低く離脱した元導入球団。現在は交渉中で「多分今年中には」復帰見込み
  • 大谷翔平も使用と報じられた球団も当然導入済み
  • 米国の大学（NCAA）にも5台。高校生・大学生向けには価格的にまだ厳しい
  • NPBは「横の情報」を意識して導入が増加傾向。7球団中には複数台導入の球団も

⑥価格は72万ドル（約1億1000万円）: 外国人選手1人分

気になる価格は72万ドル＝約1億1000万円。「控えめな外国人選手1人を獲るぐらい」という感覚です。

$720,000本体価格（約1.1億円）
50万〜200万円従来のアーム式マシン
  • 真中さん「700万ドル級の外国人を取るか怪しいなら、こっちを買った方がいい」
  • ソフトウェアのアップデートはすべて無償。メンテナンスは定期的なサポートで対応
  • 導入前後で結果の変化が出ており、価格に見合う価値があると同社は強調
  • 2台・3台購入の球団には割引の相談も（営業トークが炸裂）

⑦ボールの科学: 軽量球で怪我防止、タイミング練習には十分

「軽い150キロ・重い150キロ」は再現できるのか？という質問から、ボールの工夫が登場します。

  • MLB公式球は5.25オンス（約140g）。その他に耐久性を上げたトラジェクト専用球を用意
  • ローリング（Rawlings）と契約した軽量ボール——最大の理由は選手の怪我とバット破損の恐怖を減らすため
  • 今後はプラスチック製ディンプルボールも。ただ柔らかすぎると打球データが測りづらくなるトレードオフ
  • 斎藤隆の現役視点: 試合なら1試合4打席程度の集中に対し、練習では20球・30分〜1時間打つ。軽くても軌道とタイミング確認には十分

⑧用途は打撃練習だけじゃない: 捕手研修と投手の「自己分析」

巷では「試合前の準備用」と言われるトラジェクト。実際は育成・ファーム、そして意外な用途にも広がっています。

  • キャッチャーのトレーニング——高卒捕手がいきなりプロの変化球を受ける機会はほぼない
  • かつて工藤公康の球を城島健司が取り切れなかった例も。捕手の受けの練習にも活用
  • 急増中なのは投手の自己分析——自分の投球をバッターボックスから見る。斎藤隆「これは画期的。今まで見れなかった」
  • 試合前に「当日の先発投手の球の軌道を見るだけ」の選手も。ガンガン振るだけが練習ではない

⑨大谷翔平が球場の外でバッティングしなくなった理由

岡田さんが解説した新機能を見た真中さん・斎藤さんが思わず反応したのが、この「大谷翔平の変化」です。

  • 大谷翔平が球場の外でバッティングしなくなった理由はこれ——つまりデータ環境の充実
  • これだけ細かくデータが出るなら、外部での実戦的打撃練習は不要になる
  • 数値が良くても「打者から見て本当に打ちづらいか」は投手自身には分からない——自分の球を打席から体感できるのが決定的な差
  • 修正後の映像・データを入力し直せば「1週間後に修正した球」も体験可能
トップ選手の練習習慣を変えるほどの説得力が、このロボットにはあるということです。

⑩設置場所はブルペン・マイナー・キャンプ地・ドミニカへ

どこに置かれているのか？メジャーの本拠地球場には必ず設置されており、用途別に広がっています。

  • メジャー球場はブルペンを1つ潰して設置。ただし1スタジアムに2台は構造上難しい
  • マイナー施設・キャンプ地（アリゾナ／フロリダ）に加え、最近はドミニカ共和国の施設にも
  • 1番多い球団は8台——キャンプでは複数台を並べたい要望が当然出る
  • 日本にも既に2台導入の球団が存在。球団名は「編集で伏せます」という余裕の演出に(笑)

⑪クイズ正解: 唯一再現できないのは「アンダースロー」

「トラジェクトを持ってしても再現できないことが1つだけある」——このクイズに真中満が即正解しました。答えはアンダースロー（下手投げ）のリリースです。

  • 真中満「アンダースローで投げる球」——大正解。「ダメじゃん、先に言わせてよ」と斎藤隆も悔しがる
  • 理由はカメラの構造上、アンダースローの角度に対応できないため。リリースポイントは上下に動くが低い角度は撮れない
  • サイドスローは真横（肩のラインあたり）までOK。その下が現在の技術的限界
  • ラプソードやトラックマンの時代もアンダースローはカメラ・レーダーの死角で計測困難だった。社内でも「アンダー対応」は議論中
逆に言えば「それしかできないことはない」——実質すべての投法を再現できる証左でもあります。

⑫リリース位置は「MLB平均のエクステンション」に固定

機構上の工夫も披露されました。現在前後方向には動かず、MLB平均のエクステンション（リリース位置）に合わせて設計されています。

  • 上下左右はすべて対応。ただし手前・奥（リリース前）にはまだ動かない
  • だから18.44mよりやや前の平均エクステンション位置に設置——「前に投げてくる投手」を前提に再現
  • 将来的に前後にも動くようになればさらにリアルな再現に（ただし開発費が…）
  • 斎藤隆「ピッチャーは前で勝負しているからね」——リリース位置の重要さを裏付ける解説

⑬映像＋トラッキングデータ＋AI学習で「誰の球」でも再現

再現の仕組みは、球団が投手の投球フォームを後ろから録画し、リリースやアームスロットに合わせて入力。そこにトラッキングデータを組み合わせてAIに学習させます。

  • きめ細かい取り込みは「かなり大変な作業」。省略するチームと、全パターンを入力して選手に体験させるチームに分かれる
  • 映像とトラッキングデータがあれば過去の投手の再現も可能——斎藤隆「俺のメジャー時代は打てないよ(笑)」
  • 斎藤隆×真中満「これで（ゲストの）球を投げてみたい」——でもガチの実戦と同じで怪我に注意
  • 通常のピッチングマシンで起きる「ボールが暴れる」ことがないのも大きな特徴

⑭ABS対応の正面カメラ: 打った後に自分のスイングを確認

ソフトウェア機能も進化中。ABS（自動ストライク判定）対応の画面では、打者が正面から見る映像を確認できます。

  • 実は正面からの打者視点は練習後にも珍しい。打った後に自分で反省・確認できる
  • 現在は選手が直接映像を見られず、アナリストが確認してフィードバックする運用
  • 将来的にはタブレットで選手が直接閲覧できるよう改良中——バット横に置いてすぐ振り返り

⑮来年度追加: 打球3Dシミュレーションとバットトラッキング

来年度はヒットトラックス（HitTrax）のような3Dシミュレーションが追加予定です。

  • 実際の打球がメジャーリーグの球場でどう飛んだかを可視化——ゴルフのシミュレータのような体験
  • 選手は自分の打球のイメージを作りやすくなり、練習の質が変わる
  • さらにバットのトラッキング——スイングデータやコンタクト率も測定可能に
  • 「もうホークアイに近いデータが取れるようになる」——投球だけでなく打撃の計測装置へ進化

⑯球団の利用データは全て把握: 毎年進化するソフト

ハードはほぼ変わらず、ソフトウェア機能がどんどん進化する理由は、球団との太いフィードバックループにあります。

  • 同社社員は各球団の利用データをすべて閲覧可能——誰がどの投手の球をどれだけ打てているか（当然ながら非公開）
  • ウインターミーティングで毎年「来年はどうやっていきましょうか」と協議
  • 現場のアナリストの「こんな機能を足してくれ」をエンジニアが即商品化
  • 各球団ごとに育成方針・評価基準が違い、練習メニューも球団独自に設計されている

⑰完璧な精度は難しい: 空気抵抗と18.44mの壁、WBCの短期決戦

「ボールは暴れない」トラジェクトでも、縦横の変化量には多少のずれが残ると正直に明かされます。

  • ボールは18.44mを飛び空気抵抗を受ける。屋内・屋外、風の有無でも変わる——完璧を求める球団もあるが物理的には難しい
  • 真中満「WBCのような短期決戦は、これを持っているかどうかの勝負になる」
  • 「侍ジャパンに3台買えば?」→「侍はそんなに予算ないです」/「ヤクルトは?」→「俺ただのOBです」(笑)
導入の有無がそのまま国際大会の戦力差になり得る——それほどの武器という評価です。

⑱未来図: スイングロボット、ロボット野球、そして50代の山本由伸(笑)

最後は夢の話。「バッターの再現（投手が投げ込む相手）も可能?」という質問に「できるちゃうね」と即答が返ります。

  • バージョンアップすればスイングロボットも実現可能——斎藤隆「5年・10年後には叶う可能性が十分ある」
  • 真中満「ロボット9人を並べたらプロ野球選手はいらなくなる」→「それはあんまり面白くない」で合意(笑)
  • 夢はロボット・ベースボール・スクール——アマチュアが「今日はプロの投球と練習できる」環境を作りたい
  • 締めのオチ: 山本由伸のシミュレーションと対戦？→斎藤隆「50代の山本投球にしてくださいよ」→「それは将来予測になっちゃう」(笑)
