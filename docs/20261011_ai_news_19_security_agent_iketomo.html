① Claude Haiku 5.5 公開

Anthropicが低価格モデル「Claude Haiku 5.5」を公開。これまでのClaudeは安いモデルでも「まあまあ高かった」のが、今回一気に価格競争力がつきました。

  • OpenAI最安のGPT-6 Solと全く同じ価格でリリース
  • 価格が同じでもベンチマークスコアはHaiku 5.5が上回る場面が多い
  • 安いモデルの価値はサブエージェントやAPI連携など大量利用する場面で発揮
「安いのにまあまあ賢い」——コスト効率の観点でモデル選定の常識が変わりつつある

② Claude Dashboards・Motion ベータ提供

Claudeに「作って終わらない」機能が登場。チャットで依頼するだけでインタラクティブな画面が作れるようになりました。

  • Dashboards：損益シミュレーションなど数値を変えると結果が変わる画面を簡単生成

  • Motion：動きのあるモーショングラフィックスでプレゼン表現（現状チーム／エンタープライズ限定）
文章では見づらいデータも、可視化＋操作できることで一気に扱いやすくなる

③ Claude Cowork がクラウド実行へ移行

デスクトップアプリのローカル実行だったClaude Coworkが、新規タスクはすべてクラウド上で実行する仕様に変わります。

  • PCがなくてもブラウザ・スマホから同一環境で処理できる
  • ローカルの指定フォルダは必要時のみクラウドへコピー→処理後に削除
  • エンタープライズではローカル保持の選択肢あり。一般ユーザー向けは完全クラウドへ
位置づけが変化——元々「Claude Code for everyone」だったのが「Claudeチャットの拡張版」に。ローカルでがっつりやりたい人はClaude Codeへ

⑧ 企業向け Gemini agent 発表

Googleがいよいよエージェントアプリ「Gemini agent」をリリース。Gemini Enterprise契約で利用でき、現状はアーリーアクセス提供です。

  • エージェントごとに固有のメールアドレスとIDが付与される（Copilotも同様の方針）
  • 「自分がやった」ことにならない——閲覧だけ・下書きだけなど権限を絞って運用できる
  • 企業ではCopilotかGeminiしか使えないケースも多く、法人向けエージェント登場は大きい
権限管理付きエージェントが標準になれば、企業内での小さなトライアルが始めやすくなる

⑪ Windows のハイブリッドAI構想

MicrosoftがローカルAIとクラウドAIの役割分担を本格化。エージェントの権限を定義する仕組み「MXC」の一般提供を発表しました。

  • Windows側で処理をローカルで終えるかクラウドへ渡すかを判定・実行
  • CodexやGitHubなど各ツールへ適用し、クラウド前提一辺倒からの脱却へ
  • 権限管理の3段階：Permissive（許可して観察）→Learning（範囲を絞って試行）→Enforcement（仕様確定・遮断）
いきなり全開放でも全面禁止でもない「段階的に任せる」考え方は、エージェント導入全般に応用できる

⑫ Personal Agent Protocol

MetaとSierraが、個人と企業をつなぐ標準規格「パーソナルエージェントプロトコル（PAP）」の開発を発表。業界標準化を目指します。

  • ユーザー側：自分のエージェントに読み取りのみ／書き込み可／ログイン可のどこまでを許すか決める
  • 企業側：Web操作を許すか、APIで情報提供するか、自社エージェントと対話させるかを選択
  • 背景には「エージェント経由の買い物をEC側がBANする」摩擦の多発——主導権争いの構図
MetaのAIアプリが米国で急成長し、某ECサイトでのエージェント経由購入を試みたら規約違反で停止——こうした衝突を調停する規格

⑬ バイブコーディングの脆弱性

バイブコーディングで作られた公開Webアプリ200件を調査したところ、91%に脆弱性が見つかったとの研究結果が発表されました。

  • 記憶の欠陥：新機能だけ対応し、TODO・既存対策を忘れる
  • 目標の欠陥：シークレットをブラウザに置く、エラー回避の迂回ルートで安全策を崩す
  • 知識の欠陥（最多）：安全前提のずれ、存在しない暗号の使用、必須対策の省略
公開アプリでこれだけあるなら個人ツールはもっと危険。「AIで作れた」を判定できる人がいないまま外に出すのはリスク大

⑯ 行政のAI内製化とFDE予測

大阪・河内長野市が、外部コンサルに委託していた行政計画の策定（基礎調査・データ整理・計画の骨組み）を職員がAIで行う方針を表明しました。
