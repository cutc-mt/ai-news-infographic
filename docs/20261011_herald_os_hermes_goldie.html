② Herald OSとは何か

Herald OSは、Hermesエージェントをインターフェースとして使用するエージェントネイティブなオペレーティングシステムです。

  • メニューをクリックして操作する代わりに、Hermesと会話したり入力したりしてPCを操る
  • 無料でオープンソース、MITライセンスでGitHubで公開
  • 開発者のLucaはXでHermes関連の投稿を多数発信
「OSの中身」→「セットアップ」→「失敗ポイント」の順に解説

③ フォークではない——Hermesの上に載る設計

Julianが特に気に入っている点：Herald OSはHermesをフォークしていません。

  • 通常のHermesエージェント環境でそのまま動作
  • システムツールは通常のHermesプラグインとして追加される仕組み
  • Hermesエージェント自体はNous Researchが開発したもの
本体を書き換えないから安全に試せる

⑥ ダッシュボード——起動直後にすべて把握

起動するとすぐにダッシュボードが表示されます。これがHerald OSの顔です。

  • 名前で挨拶し、その日の活動状況を表示
  • すぐに音声を吹き込んで、そのまま話しかけることも可能
  • 当日の予定はHerald OS内のスケジュールタスクから読み込み
  • 注目すべき事項を表示するセクションも用意
  • 最近デスクトップで撮影したスクリーンショットも反映され、取り組んでいた内容を思い出せる

⑮ アクティビティ履歴——バックグラウンドを掌握

Hermesを使っていると、バックグラウンドでいろいろな設定が行われ、忘れてしまうことがよくあります。

  • アクティビティ履歴を見れば何が起きたか分かり、何が動いているか常に把握できる
  • 承認設定：自動承認をオフにすれば、ツールに慣れるまで自分でコントロールを維持
  • これらの設定はグループ（チーム）で使うと最適——承認・バックグラウンドエージェント・スペース・メモリをまとめて解説
チーム運用なら「承認 → バックグラウンド → スペース → メモリ」の順で設定するのがおすすめ
