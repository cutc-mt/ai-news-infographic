⑤ openGym：自分で管理するジム記録

02:50 セルフホスト型ワークアウト
  • openGymはセルフホスト型のジム・自重トレーニングトラッカー。データは自分が管理するフォルダに保存されます
  • ルーチンの計画とワークアウトの記録が可能で、スーパーセット・ウォーミングアップ・有酸素運動にも対応します
  • 筋トレマップでどの部位が鍛えられ、疲れ、衰えているかを可視化。各セッションの重量を自動設定し、その理由も解説します
  • レップ不足は負荷を維持し、停滞時にはデロードを提案。FitNotes・Strong・Heavyからインポートでき、パスキーでサインイン・同期するオフラインアプリとしても入れられます
Dockerでセルフホスト 記録を自分のフォルダへ 重量設定はお任せ
github.com/DuarteSantos8/openGym
筋トレする開発者向け。健康データをクラウドに預けない選択肢が地味に嬉しい

⑥ OpenCodeReview：AlibabaのAIレビュー

03:27 AIコードレビューCLI
  • OpenCodeReviewはAlibaba提供のAI搭載コードレビューCLI。決定論的パイプラインとLLMエージェントを組み合わせたハイブリッド設計です
  • Gitの差分を読み取り、エージェントがファイル全体を解析しコードベースを検索して変更を精査、行単位でコメントを返します
  • 多言語対応のルールセットでnullポインタ・スレッドセーフ・XSS・SQLインジェクションなどを検出し、自動修正も可能です
  • OpenAIやAnthropicで動作し、Claude CodeやCodex用のプラグインも備えています
差分を解析 ルール＋LLMで精査 行単位コメントと自動修正
github.com/alibaba/open-code-review
レビューが追いつかないチーム向け。決定論とLLMの二段構えが信頼感の源です

04:07 セルフホスト型エージェント管理
  • paperclipはAIエージェントチームを管理するセルフホスト型アプリ。エージェントを従業員とするなら、paperclipは会社です

  • Postgres上でセルフホスト可能。デプロイしてエージェントを管理しましょう
エージェントを雇用 目標と予算を設定 承認ゲート付きで運用
github.com/paperclipai/paperclip

⑧ WeKnora：ドキュメントを知識に

04:42 Tencentのナレッジ基盤
  • WeKnoraはTencentによるLLM搭載ナレッジプラットフォーム。ドキュメントを3つの方法で知識化します
  • 1つ目はRAGベースのQ&A検索。2つ目は検索・MCPツール・Web検索を駆使してマルチステップタスクをこなすReactエージェントです
  • 3つ目はWikiモード——エージェントがドキュメントを知識グラフ付きの自己メンテナンス型Markdown Wikiに要約します
  • 10以上のフォーマットを取り込み、Feishu・Notion・UKから自動同期。20以上のLLMプロバイダーとベクトルDBも切り替え可能で、Dockerでセルフホストできます
取り込み RAG・エージェント・Wikiの3方式 社内知識を検索可能に
github.com/Tencent/WeKnora
社内文書に困っている人向け。自動Wikiが自己メンテナンスする点が将来性ありです

⑨ colibri：巨大MoEを純Cで動かす

05:24 ディスクから実行する推論エンジン
  • colibriは依存関係ゼロ・純粋なC言語による推論エンジン。手持ちのハードウェア上でMoEモデルを動作させます
  • MoEモデルはトークンごとに自身の一部しか使用しないため、colibriはその部分だけをRAMに保持し、残りをディスクから読み込みます
  • その結果、数千億パラメータのモデルが一般的なPCで動作。単一のCファイルで、BlazeもPythonランタイムも不要です
  • OpenAI互換のAPIを提供するため、既存ツールからそのまま呼び出せます
Cファイル1つ 活性部分のみRAM 巨大MoEが普通のPCで
github.com/JustVugg/colibri
ローカルLLM派向け。ハイスペックGPUなしで巨大モデルを狙える今週の一番星です

⑩ i-have-adhd：本題から話させる

05:58 回答を隠させないスキル
  • i-have-adhdはAIコーディングアシスタントが回答を曖昧にするのを防ぐオープンソーススキルです
  • 長々とした前置きや「お役に立てば幸いです」といった言葉の代わりに、アシスタントに次の行動から始めさせます
  • マルチステップタスクには番号を振り、リストの上限を定め、具体的な時間を見積もり、明確な次のステップで締めくくらせます
  • 8HDツールキットから適応された10のルールで、Claude CodeやCodexにインストールして呼ぶだけです
インストール 前置きを禁止 番号付きの本題だけ返す
github.com/ayghri/i-have-adhd
エージェントの長文に疲れた人向け。10ルールで口調を矯正する妙な実用性があります

⑪ SCSKiller：シェーダーカクつき解消

06:30 プレイ前のコンパイル対策
  • SCSKillerはゲームプレイ前のシェーダーコンパイルによるスタッターを排除する無料のオープンソースWindowsツールです
  • このカクつきはGPUドライバーがフレームの途中で新しいシェーダーをコンパイルする際に発生。SCSKillerはゲーム同梱のシェーダーを読み取り、ゲーム終了時にドライバーキャッシュへ事前コンパイルします
  • 起動時には準備が整い、ドライバー更新後の再コンパイルにも対応。アンチチート導入ゲームを回避し、すべてをPC内で完結させます
  • NvidiaおよびAMDでのシェーダーカクつきを修正します
一度プレイ 終了時にシェーダーを事前コンパイル 次回はノースタッター
github.com/BlueHeisenberg/SCSKiller
PCゲーマー向け。最初の数分の不快感を消しに行く地道な一本です

⑭ decider：文章を書かない意思決定LM

08:20 調整済み確率のSystem1
  • deciderは単一のフォワードパスで調整済み確率付きの型指定された回答を返す、オープンソースの意思決定モデルファミリー。テキストを生成しない言語モデルです
  • 状態と型指定された質問を入力すると、質問ごとの確率・最大255の選択肢からの回答・2〜10のスコア・イエス/ノーを返します
  • System1クラスのオープンな再現であり、8Bモデルから35BのMoE、さらに画像から判断するビジョンモデルまで揃います

⑯ Fieldwatch＆REDox：観測と解析

09:31 ／ 10:08 電波観測と.NETデータ基盤
  • FieldwatchはAndroid向けの受信専用Wi-Fi／Bluetooth LE観測ツール。周囲の電波を受動的に傍受し送信は一切行わない設計です
  • ドローンのリモートIDブロードキャストをデコードしてIDと座標を記録し、パケットごとにアドレスが変わる無線などの異常も検知。WigleやCSV形式でエクスポート可能なサイドロードAPKです
  • REDoxはカプコン技術研究部門による.NET向けトークンベース構造化データエンジンで、次世代ゲームエンジン基盤技術「Rex」の中核です
  • 単なるJSONシリアライザーではなく、JSON・JSON5・CBOR・MessagePack・TOML・XML・HTML・INI・CSV・高速バイナリの読み書きと変換を担い、System.Text.Json／Newtonsoft.Json互換のNuGetパッケージです
電波を受動監視 異常を検知 一方.NETでは全データ形式を統一処理
OffGridPete/Fieldwatch CAPCOM-TD-OSS/REDox

⑱ Muse Gadgets＆strands-decider：締めの2本

12:03 ／ 12:36 自作ハードウェアと高速判断
  • Muse GadgetsはMeta（facebookincubator）によるSDK＆ファームウェア。ESP32ファームウェアを書き込みディスプレイ・ボタン・センサーを接続するか、Linux SDKでRaspberry Piをガジェット化します
