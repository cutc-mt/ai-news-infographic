CARD 01

今回はOpenAIの新機能が2つ

今回の動画で取り上げるのは、OpenAIとChatGPTに追加された、毛色の違う2つの便利な機能です。

  • Decisions API文章と画像を高速で判定する、OpenAIの新しい機能
  • インテリジェントUIChatGPTの画面上で、操作できる見た目をリアルタイムに生成する機能
  • どちらもデモを交えながら、仕組みと活用のアイデアを紹介します
判断を任せるAIと、見せ方を作るAI。仕事がはかどる2つの新機能、最後まで見て試してみましょう！
CARD 02

Decisions APIとは？

文章を書かせるのではなく、「判定」だけを任せるAIです。以前紹介した、判断に特化したAIサービスのOpenAI版という位置づけです。

  • 高速な処理で、確率・選択肢・点数だけを返します
  • 何千件という文章を、まとめて一気に判定できます
  • 旧サービスは文章の判定のみでしたが、今回は画像の判定も可能に
  • 画像を判定できるため、今後いろいろな場面で活用が進みそうです
「文章を作るAI」ではなく「答えだけを出すAI」。無駄な出力がないぶん、速くて安いのがポイントです。
CARD 03

入力できるものと、返ってくるもの

APIに渡せるものと、判定結果として返ってくるものを整理します。

  • 入力：文章画像質問（判定の軸）
  • 出力：92%のような確率
  • 出力：請求か返金かのような、2択の選択
  • 出力：最大2のうち1.6のような、点数
  • 裏側で動くのは、最速でお安いGPT-6 Lunaがベースらしい
説明文は返さず、決められたルールの中で「どうだったのか」だけを出力する設計です。
CARD 04

質問は3つのタイプが基本

判定を頼むときの質問の形は、次の3パターンが基本になるらしいです。

  • 確率「この写真の商品に破損はある？」→ 92%くらい
  • 選択肢「この問い合わせはどの担当？」→ 担当を選んで返す
  • 採点「緊急度は最大2のうちいくつ？」→ 1.6

CARD 05

料金は驚きの安さ

判定だけに特化しているため、費用はかなり抑えられます。

  • 出力は無料。入力は100万トークンあたり0.1ドルらしい
  • 文章の判定：1件 約0.0076円→1000件で8円、1万件で76円
  • 画像の判定：1万件で221円ほど
  • 大量に画像を判定したい場面でも、十分に使える水準です
1万件処理してもお弁当1個より安い。判定の壁が一気に下がりましたね。
CARD 06

デモ①：商品の破損チェック

マグカップの画像をドラッグ＆ドロップすると、ノーカットの一瞬で状態を判定してくれました。

  • 無傷のマグカップ → 破損なし食器・キッチン用品 100%
  • 少し欠けたもの → 目に見える破損あり 100%
  • ダンボールがぐちゃぐちゃでも、マグカップ自体が無事なら破損なし 0%…ではなく「破損なし」と判定
  • まったく関係ないOBSのスクリーンショット → その他に正しく分類
見る対象を決めておけば、梱包の崩れは無視して商品だけを check してくれます。入庫検品に使えそうです。
CARD 07

デモ②：レシートの経費判定

レシートの画像から、経費の科目を瞬時に判定してくれます。

  • 交通系の会社の明細 → 旅費交通費 100%
  • 居酒屋の4名様 → 交際費 95%（会議食事費でしょう）
  • 文房具 → 消耗品と即答
  • 経理の入力作業を、画像の判定で大幅に減らせそうです
「これは何の科目かな？」と悩む時間がゼロに。月末の経理がぐっと楽になりますね。
CARD 08

デモ③：客室の清掃レベル採点

ホテルの客室写真を4段階で採点するデモ。速さと費用も実測されていました。

  • 清掃済みのきれいな部屋 → 0.01（かなり綺麗）
  • 処理は0.43秒、費用は0.0217円でした
  • 少し乱れた部屋 → 0.55。バスタオルが投げられてる感じも判定
  • かなり散らかた部屋 → 大掃除レベルと即答
点数で均一に評価できるので、清掃の品質管理やチェックリストにそのまま使えそうです。
CARD 09

デモ④：フリマ出品のランク付け

フリマアプリの出品画像を、状態のランクとして点数で判定します。

  • 新品同様のスニーカー → 0.10。新品未使用のランクと判定
  • 使い込んだバッグ → 傷や汚れあり 98%
  • ソールが破れた靴 → 状態が悪いと一瞬で判定
  • 中古販売の目利きを、誰でも同じ基準でできるようになります
出品前の自分の商品を check すれば、過小評価も過大評価も防げそうですね。
CARD 10

デモ⑤：工事現場の安全チェック

現場の写真から、保護具の着用状況を判定します。判定の軸を1つに固定する例がよく分かるデモです。

  • 全員が安全服を着用 → 全員着用済み
  • 1人だけ未着用 → 2着用あり・要注意
  • 足場がぐちゃぐちゃでも、ヘルメット着用の判定軸なら着用はOK
  • 軸を固定すれば、欲しい判定だけを確率で出してくれます
見たい項目を質問として設計するのがコツ。安全点検の記録が写真1枚で済みそうです。
CARD 11

デモ⑥：冷蔵庫から献立を判定

冷蔵庫の中身の写真から、作れる料理を確率で提案してくれます。

  • 野菜と肉が揃っている → カレー 88%野菜炒め 8%
  • 材料が足りない場合 → 買い出しが必要 3%にも言及
  • パスタ向けの食材を置くと → パスタ 86%
  • ほぼ空っぽなら → 買い出しが必要 100%と面白い判定に
「今日なに作ろう？」の悩みを、冷蔵庫の写真を撮るだけで解決できてしまいます。
CARD 12

デモ⑦：詐欺メッセージの判定

届いたメッセージが詐欺かどうかを、確率で判定してくれます。

  • 「お荷物の受け取りについて」の通知 → 詐欺の疑いあり
  • 母との鍋の相談 → 詐欺 0%
  • 母を名乗る新しい番号からのやり取り → 詐欺の確率 99%
  • 身内になりすました怪しい連続も、しっかり見抜きます
「もしや」と迷ったら判定に頼る。家族のスマホに仕込んでおきたい機能ですね。
CARD 13

文章の判定①：問い合わせの振り分け

画像だけでなく、文章の判定デモも用意されています。まずは問い合わせの仕分けです。

  • 「請求がおかしい」→ 返金を求められています
  • 「設定メールが届かない」→ 使い方の不具合
  • 「明日のイベントに間に合わない」→ 配送をすぐ希望
  • 漠然とした文 → その他。そして「解約したい」→ 解約プラン 100%
本文と質問をセットで送れば、緊急度の順にリストへ並べ替えられます。サポート窓口の時短に直結します。
CARD 14

文章の判定②：返信要否と炎上リスク

  • 「見積もりは9日までに回答」→ 今すぐ返信が必要
  • 日程の調整 → 今すぐ返信が必要
  • ウェビナーやメルマガの案内、CCで届いた議事録 → 返信不要
  • 普通の紹介文 → 炎上リスクなし
  • 決めつける投稿や根拠のない断定 → 批判が出そう炎上の可能性
投稿前に自分の文章を check すれば、炎上予防にも使えます。送る前の一手間が保険になります。
CARD 15

活用のヒント：判断を挟んで賢いモデルへ

KEITOさんのおすすめは、Decisions APIを業務の途中に組み込む使い方です。

  • Claude Codeのスキルに組み込むアイデア
  • 業務の流れの途中に判定の軸を挟み、分岐させます
  • 分岐された時点からは、賢いモデルで業務を進める流れがおすすめ
  • 安くて速い判定と、賢い判断の役割分担で、仕事がより速く正確に

CARD 16

インテリジェントUIとは？

ChatGPTに追加された、回答の見せ方までChatGPTが決めてくれる機能です。

  • 自然な言葉でお願いすると、その場で操作できる画面を作ってくれます
  • 例：「AIセミナーのアンケートフォームをその場で作って」→ 満足度のチェックボックス付きフォームが即完成
  • 公開は有料のプラスプラン以上から始まり、無料プランも10月8日から利用可能
  • 古いデスクトップアプリは要アップデート。APIからは使えず、デスクトップアプリかWeb版で利用します
作った画面は共有もできます。「インタラクションを構築して」「その場で使える機能にして」と頼むのがコツです。
CARD 17

デモ集：その場でツールが続々

動画では12種類を超えるデモが紹介されました。どれも会話だけでその場で完成します。

  • 自転車が進む仕組みを、パーツごとの図で分かりやすく表示
  • 割勘計算（3万8400円を6人、部長だけ多めに）をスライダーで調整
  • 毎月3万円を年利5%で20年 → 約1233万円。グラフ付きで試算
  • 京都1泊2日の観光ルートを、マップにピンで表示
  • 勤怠管理システムの3社見積もりをカードとグラフで比較（44人以上ならC社など）
  • 納品遅れのお詫びメールや、5問のセキュリティ小テスト（その場で正誤判定）も
  • カフェの値上げシミュレーション、3拠点の会議時間帯の探索、カフェイン残存のグラフ
  • 6畳の間取りを動かせるツールに。ピザで分数を学ぶ教材まで作成
「画像で出して」と言った後に「動かせるツールにして」と追加でお願いするのも賢いやり方ですね。
CARD 18

まとめ：出すぎたUIは設定で調整

インテリジェントUIは、設定で出てくる頻度を調整できます。

  • UIが出てくる場面が多すぎると感じたら、設定のパーソナライズを開きます
  • レイアウトアビジュアルズを「シンプル」や「デフォルト」にすると、出現が落ち着きます
  • 絵文字が不要なら、その設定だけを切ることも可能です
  • Decisions APIで速い判定、インテリジェントUIで見やすい画面。2つ合わせて仕事を加速させましょう
どちらも無料で試せます。皆さんの仕事の中で、どこに判定の軸を挟めるか、ぜひ考えてみてください！
