② RAD Debugger：ネイティブの図形デバッガ

01:02 Epic Gamesのツールチェーン
  • RAD DebuggerはEpic Gamesによるユーザーモード・マルチプロセス対応のオープンソース・ネイティブグラフィカルデバッガです
  • デバッグ情報形式を統一してデバッグを簡素化することを目指し、PDBやDWARFの代わりに独自のRDI（RAD Debug Info）形式を採用。双方からのコンバーターも同梱します
  • プロジェクトにはMSVCリンカーの高速なドロップイン代替「RAD Linker」も同梱され、式評価のビジュアライザーも搭載しています
  • 現在はWindows x64に対応し、Linuxサポートはアルファ版で提供中です
PDB/DWARFを変換 RDIで統一 ネイティブにデバッグ
github.com/EpicGames/raddebugger
低レベル開発者向け。Epic Games本気のデバッグ基盤が無償で手に入ります

③ OpenRig：コーディングエージェントの常設チーム

01:41 tmux上のハーネス
  • OpenRigはClaude Code・Codexなどコーディングエージェントの永続的チームを構築するためのオープンソース・ハーネスです
  • YAMLでチームを定義し、1つのコマンドで起動。Rigがあなたのハーネスをラップします
  • リーダーエージェントと会話すると、専門家たちがコンテキストを共有して作業を各ターミナルで引き継ぎ、いつでも会話に介入できます
  • tmux上のデーモンCLIおよびUIで動作し、GitHubリンクからスターターチームを利用可能です
YAMLで編成 1コマンドで起動 専門家チームが並走
github.com/mvschwarz/openrig
エージェント multiply 派向け。1体だけじゃ物足りない人のための指揮系統です

deadinside28/bloodborne_pc FlashML-org/FreeVideo

⑭ mygo：ブラウザを同梱しないGo製デスクトップアプリ

⑱ gdp-ts：承認チェックをコンパイル時に証明

12:36 型で守る権限
  • gdp-tsは小さなTypeScriptライブラリ・ESLintとOxlintリンター・AIスキルの組み合わせで、承認（権限）バグをコンパイル時に検出します
  • 開発者やコーディングエージェントが重要な呼び出しの前に権限チェックを忘れるリスクを解決します
  • 関数はその正確な引数に結び付けられた証明を要求し、証明なしの呼び出しは型チェックでエラーになります
  • あらゆるTypeScriptコードベースとランタイムで動作し、実行時コストはほぼゼロ。APIセキュリティを強化したいチームに適しています
証明を型に埋め込む 未承認の呼び出しはビルド失敗 本番で事故らない
github.com/rauchg/gdp-ts
TypeScriptチーム向け。権限忘れを型で封じる締めの一本です。ご視聴ありがとうございました！
