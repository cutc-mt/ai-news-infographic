CARD 02

OpenSwarm

エージェントが“群れ”となる無料AIデスクトップ

Mac向け・無料のAIデスクトップ。多数のエージェントが同時に作業し、単一エージェントツールの限界を突破する。

  • 各エージェントに専用ブラウザ・アプリ・ツールを割り当て、実際の環境で最後まで完遂
  • 無限キャンバスで全エージェントを監視——移動・拡大縮小・随時介入が可能
  • 一度の指示で複数ブラウザが並行起動し、それぞれ別ページを読み込む
  • ツールを言葉で説明すればエージェントがランチャーに構築してくれる
  • エージェントマーケットプレイスにはリード検索・投稿収集などのマルチエージェントアプリが並ぶ
条件モデルとAPIキーは自前で用意／多段階リサーチ・アウトリーチ・運用を委任したいMacユーザー向け。無料ウェイティングリストで参加受付中
「スウォーム(群れ)」の名の通り、指示は一度でいい——あとは群れが働く。
CARD 03

Claude Haiku 5.5

Anthropic史上最速・エフォート調整可能な小型モデル

大量のコスト重視ワークロード向け小型モデル。大モデルで反復作業を回すと高額になる問題を解決する。

  • Anthropic史上最速——ライブカスタマーサポートやブラウザ操作など速度勝負に最適
  • エフォート調整を備えた初のHaiku級モデル——コストと知能を最適化し、前世代よりはるかに安価
  • Opus/Sonnetのサブエージェントとして連携——大モデルが資料を作る傍ら、長文書から正確な数値を抽出
  • アライメントが大幅向上し、コンピューター/ブラウザ操作SDKを同梱
用途要約・圧縮・DBクエリ・分類などの大量反復タスク
提供Claudeプラットフォーム／AWS／Google Cloud／Azure
対象大規模開発を行うエンジニア
「速く・安く・賢く調整できる」——サブエージェント運用の定番になり得る1本。
CARD 04

Griffin by Tavus

表情・視線・間を読む対面会話モデル

Tavus初の対人対話モデル。人間が機械に合わせていた会話を、機械が人間に合わせる世界へ。

  • ビデオtoビデオの統合システム——知覚・応答タイミング判断・音声と映像生成を同時実行
  • 言葉だけでなく表情・視線・間を読み、遮っても遮られても状況を見失わない
  • 自然なタイミングで相槌・頷きを挟む対話を実現
  • 参照画像1枚からシーン全ピクセルをリアルタイム生成
約10秒の音声で声をクローン　→　約半数が「人間」と誤認(1分間通話の実証実験)
現在は先行研究プレビュー版「Griffin Light」をウェイトリスト経由で提供中。
CARD 05

Cekura Bench

音声to音声モデルを「実通話」で検証するベンチマーク

リアルタイム音声対音声(S2S)モデルを実際の電話通話で試すオープンベンチマーク。ベンダーの宣伝文句では分からない実力を数値化。

  • 同一のOSS電話エージェントでプロンプト・ツール・シナリオを固定し、モデルだけ入れ替えて比較
  • シナリオはクリニック予約とメディケア受付——シミュレーション発信者が各3回ずつ実通話
  • 合格条件は正しい結果+全保存フィールド一致——厳格な判定
  • 詳細スクリプト・スコア・2モデル比較ツールも公開
評価軸信頼性／タスク成功率／データ精度／停滞回数／応答時間／コスト
成果物リーダーボード＋各結果への詳細リンク
対象音声エージェントのモデル選定チーム
CARD 06

NOVA CLI v1.0

ターミナルに常駐する自律型AI開発者

コードベースを理解し、ターミナル内で構築・テスト・修正まで完結。IDE・ブラウザ・Git間の絶え間ないコンテキストスイッチを撲滅。

  • CLI認証→リポジトリをマッピング——構造とファイル相関を把握し、読み込みなしで構築開始
  • 自己修復ループでバグを自動検出・修正。スタックトレースも読み取る
  • 変更はクリーンでアトミックなDiff——ターミナル上で即確認
  • セッション間でコンテキスト保持。大規模複数ファイルのコードベースに対応
160種類以上のAIモデルをCLIから直接操作　／インストールは数秒
「説明し直す手間」をゼロに——開発フローの中に住み着くAI開発者だ。

Claude for Google Workspace

Docs・Sheets・Slidesの中でClaudeが働く

一度インストールするだけで3アプリすべてにClaudeが追加。文書の外へ出てAIに質問→貼り付け、という断絶を解消。

Docs文章の起草・推敲・構成案の作成
Sheets財務モデル構築・データ分析・リアルタイム数値の読み込み
Slidesレイアウトに基づくスライド生成・重なり要素の指摘
  • 提案された編集・ハイライトされたセル・新スライドを承認してから適用
  • テーマ・見出しスタイル・周囲の書式はそのまま維持
  • コネクタで外部コンテキスト取込／プロセスをスキルとして保存／PDF・CSV・Officeも読ませられる
  • アクセスは開いているファイル+有効コネクタのみ。管理者によるインストール制御も可
提供すべての有料Claudeプランでベータ版／Google Workspace Marketplaceからインストール

Polylane for Vercel

Vercel障害を検出・診断・修正するAI監視

アラートを追い、ログを読み、手作業で原因を突き止める——本番障害対応の重労働をAIが丸ごと引き受ける。

  • OAuthで約1分の統合。SDK・APIキー・アラート設定は一切不要
  • 各プロジェクトの通常挙動を学習し、異常があれば問題を提起
  • ビルド失敗や重複アラートをまとめ、通知は各問題1回のみ
  • リクエストログ・メトリクス・最近のデプロイと設定変更を調査し、何がなぜ壊れたかを提示
  • 原因がコードならPRを自動作成——ただし書き込み操作は全て承認待ち
仕掛けプロジェクト・ドメイン・ストレージ・ファイアウォールを単一グラフ化し、あらゆるコーディングエージェントからクエリ可能／無料で開始

Articos MCP

AIアシスタントから“合成ユーザー調査”を実行

Articosの合成リサーチ機能をAIアシスタントに統合するMCPサーバー。数週間かかる従来調査を、チャットから直接。

  • Big Five+30特性に基づく多様なAIペルソナがインタビューを実施
  • 仮説を伝えずに実行するため、望む答えではなく反論をあえて提示
  • モチベーション・反論・不明点・優先順位付き推奨事項の構造化レポートを30分以内で返す
  • 調査の開始・承認・状況確認→保存対象者の再利用→追跡調査・パネル質問まで一連のフロー
接続Claude・ChatGPTなどMCP互換クライアント／対象: SaaSチーム・代理店・コンサルタント。最初の調査は無料
CARD 11

Tonefold

曲を言葉で描写し、すべての音を編集——OSS作曲

Mac/Windows向け無料・オープンソースのAI作曲ツール。「生成して終わり」のAIと「全部手作業」の間を埋める。

  • 平易な言葉の説明でコード・メロディ・ベース・ドラムをピアノロールに書き込み、内蔵シンセで即再生
  • 11種類の編集可能レイヤー/セクション——気に入ったコードを固定してベースだけ再生成も可能
  • プロデューサーモード——承認があるまで1音も書き込まない(プロンプトではなくアプリ側で強制)。専門エージェントが各パートのみ作成
  • MIDI・ステレオミックス・ステムを書き出し、DAW用プラグインも提供
処理生成・再生・編集・エクスポートは全て端末上。モデル利用はチャット機能のみ(Claudeログイン or ローカルOllama)／GPL 3.0
プロデューサーやミュージシャンへ——「最後の一押しは人間」を体現した設計だ。
CARD 12

音声AI活用の2本立て

ClawCall(発信代行)× Epilude Narrator(読み上げ)

ClawCall —— 電話を代行するAI

  • 米国の番号と用件を伝えると発信→メニュー操作→保留→応対まで自動、トランスクリプト付きで報告
  • 意思決定が必要ならあなたの電話へ転送し、承認した場合のみ接続。無許可の合意は絶対なし
  • 尋ねられればAIであることを告知。ChatGPTプラグイン・Claude・Grok・REST API・ホスト型MCPに対応

Epilude Narrator —— Macのあらゆるテキストを読み上げ

  • アプリ内テキストを選んでホットキー一発で読み上げ開始。PDF・EPUB・DOCX・Web・画像・クリップボードもOK
  • フローティングプレイヤーが文・単語をハイライト、RSVPモード(1単語ずつ表示)、速度0.5〜3倍
  • EP1音声はMac上で処理されテキストは端末に留まる。クラウド音声時は実行場所を事前表示
「かける電話」「読む文章」——両方ともAIが引き取る時代が目の前だ。

Semwright

エージェントとソフトをつなぐセマンティック層

AIエージェントに実ソフトウェアへの型付きインターフェースを与えるOSSセマンティックレイヤー。「画素クリック」や「広権限シェル」の危険を排除。

  • 座標を推測してクリックする代わりに、ブローカー経由で名前付き操作(アプリ/シーンのオブジェクト、文書ノード、タイムラインクリップ)を呼ぶ
  • 全リクエストが範囲と権限を検証するポリシーを通過——機能を発見しても権限は自動で付かない
  • 入力・クリップボード・キャプチャ・アプリ変更などの機密操作は個別の明示許可が必要
  • 参照でオブジェクト識別、ジョブで進捗可視化、結果には読み戻しデータと実行証拠が伴う
ドライバーFigma／Chromium／Blender／MLTビデオ
経路MCP・CLI・SDK(持ち込みエージェントは読み取り専用で開始)
環境Linux・macOS・Windows(オープンソース)

CARD 15

Strac Comply

エージェントから実行できるコンプライアンス管理

営業電話を介さず監査準備を整える、セキュリティファーストのコンプライアンス基盤。

  • SOC 2・ISO 27001・PCI DSS・HIPAA・NIST CSFの手作業を自動化
  • AWS・GitHub・Oktaなど100以上の連携で接続すれば、毎日100以上のテストが実環境で実行
  • 失敗時は修正箇所と設定手順を具体的に提示。監査人はアカウント不要のポータルから証跡確認
  • どのAIツールがデータに触れるかを可視化し、ベンダーリスクをスコアリング
MCP全工程がMCPサーバー経由—— OKClaude Code OKCodex OKGemini CLI OKCursor OKOpenCode
が証拠の記録・チェック再実行・監査人への回答をエージェント名義で実行できる
CARD 16

エージェント安全性の2本立て

AgentGuard(スキル診断)× SineFrame M3(MCPテスト)

AgentGuard —— スキル導入前スキャナー

  • SKILL.mdを貼り付けるだけで数秒で信頼性レポート(セキュリティ/品質スコア・リスク・実機能)
  • 決定論的検査+AI分析の合わせ技で、シェル実行・ファイル/環境アクセス・外部DL・資格情報・疑わしいURL・難読化・プロンプトインジェクション・破壊的操作を暴露
  • 無料・アカウント不要。実際に検出された問題のみ報告

SineFrame M3 —— 実エージェントでMCPを試験

  • サーバーが正しくてもエージェントが記憶で答えてツールを呼ばない問題は、モデルAPI単体では検出不能
  • Claude Code・Codex・OpenCode・Piのバイナリを実際に実行し、全MCPツール呼び出しを記録——スキップ/誤呼出で失敗
  • バージョン固定で早期検出、CIでテスト0のPRをブロック。ローカルファーストのOSS
「動くか」ではなく「正しく安全に動くか」——検査ツールの進化が目立つ週だった。
CARD 17

チーム×エージェント協働の2本立て

Velozity(マルチプレイヤーAIオフィス)× Databench by Alkera

Velozity —— マルチプレイヤーAIオフィス

  • キャビンに入ればプレゼンス・通話・文字起こし・タスク・ゲストが同一ウィンドウ——エージェントが常に状況を把握
  • Claude Code/Codexなど既存サブスクでエージェント起動。Macやクラウド上で動き、無許可の送信・支払い・署名はなし
  • 内蔵エージェントSpeedは追加課金なし——メール/文字起こし/ファイル読取、深い調査、朝ブリーフィング。100+統合とレガシーアプリ用クラウドPC

Databench by Alkera —— 人とエージェントのデータワークスペース

  • セルフホスト可のWebデータワークスペース。チャットをリアルタイム共有し、エージェントは選択マシンのサンドボックスで実行
  • 共同編集できるリアクティブPython/SQLノートブック(Marimo互換)＋表・グラフ・非同期DB接続
  • モデルゲートウェイは独自キーでAnthropic/OpenAIのみ——他のデータはネットワーク外へ出ない。Apache 2.0
CARD 18

まとめ：今週の5つの教訓

20案件から読み取るエージェント界の方向
  • ①エージェントは「1体」から「群れ」へ——OpenSwarm・Velozityが同時実行の未来を提示
  • ②コスト最適化はサブエージェントで決まる——Haiku 5.5のエフォート調整が鍵
  • ③「実環境での試験」が標準化——Cekura Bench(実通話)・SineFrame M3(実エージェント)
  • ④ローカルファーストが潮流に——Tonefold・Narrator・Databenchはデータを手元に留める
  • ⑤権限と証拠の管理が前提に——Semwright・AgentGuard・Stracがガードレールを供給
紹介20案中10以上が無料/OSS——まず触ってみるのが今週の正解だ。
