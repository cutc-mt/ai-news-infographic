『1.2億分の1』とは

  • 開発者MNM氏が10月14日に公開した統計データ基づきの人生シミュレーター
  • 大ヒット中『80億分の1』（Jin Hwi-eus氏）の日本特化版「日本バージョンを作成。本家に敬意を持って作ってます」
  • ブラウザから無料でプレイ可能
3

生まれる場所の決め方

『80億分の1』では日本人として生まれるのは困難だったが、本作は日本のどこかで生まれることが確定。2つのモードがある。

いま生まれる赤ちゃん都道府県ごとの年間出生率に基づき決定
いま生きている1.2億人人口の割合に応じて決定
4

生まれる時代を6択から選択

『80億分の1』の「生まれた年を任意指定」と違い、本作は時代を区切って選ぶ方式。

大正 1920年 戦時中 1940年 昭和 1955年 平成 1990年 いま 2026年 これから 2050年
5

日本史に沿った歴史イベント

時代ごとに日本に焦点を当てた出来事が発生。例えば大正1920年生まれの場合――

  • 幼い頃：関東大震災
  • 若き日：戦争の苦境
  • のちに：高度経済成長・東京オリンピック
6

『80億分の1』との3つの違い

  • ① 日本出生の確定 — 世界版では難しかった「日本人として生まれる」が保証される
  • ② 時代選択制 — 任意の年ではなく6つの時代から選ぶ
  • ③ 日本史イベント — 関東大震災など日本に焦点を絞った出来事
7

統計に基づく「もう1人の自分」

生まれる家庭の暮らし向き・家族構成・病気・結婚・出産などの出来事は日本の統計データに基づきランダムに決定。進路選択や結婚などの決断を乗り越え、「もしもまったく別の日本人として生まれていたら」を疑似体験できる。

8

現時点の不具合も話題

  • 生まれる兄弟に同じ名前がつけられる
  • 子が生まれていないのに孫が誕生する
  • 昭和初期に存在しない「青春18きっぷ」で旅行する時代錯誤

開発者いわく「ひとまず作ってみた段階」。プレイヤーは解釈で補完して楽しむ様子。

6新言語への展開

フランス語・ドイツ語・ヒンディー語・メキシコスペイン語・韓国語・日本語の6言語に対応。各言語2ボイスずつで、単一の「公式アクセント」を押し付けるのではなくある程度の個別選択を可能にする設計。

GPT-Live-1.1 Quip（mini版）

同時アップデートでChatGPT音声シーン専用の小型版「GPT-Live-1.1 Quip」が登場。テキストモデルと同じ「旗艦＋mini」の二転戦略を音声でも採用し、性能と軽量の両輪を揃えた。

14

API対応は「近日」

音声APIのエンドポイントは「まもなくサポート予定」との公式コメント。ただし具体的な日程は未定で、開発者は当面従来モデルを利用し続ける状況。

Realtime API / Live API ユーザーには影響なし。移行時期は追加告知を待つ形。
15

「checking…」改善の技術的意味

外部検索時のネットワーク遅延は物理的に排除できず、従来は単一の「checking…」が機械的に繰り返されていた。GPT-Live-1.1ではより広いフレーズライブラリで多様化し、プロンプト自体は残しつつ体感を改善するアプローチ。
