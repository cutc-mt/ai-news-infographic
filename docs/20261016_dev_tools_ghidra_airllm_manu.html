プロジェクト No.1〜6：エージェントスキルとリバースエンジニアリング

コーディングエージェントの整合性を保つスキル集、ソースコードなしでアプリを解析するMCPサーバー、WebGPUエフェクト、リモート実行環境、スキルCLI、小型GPUでLLM。

1

Skills for Real Engineers

mattpocock/skills

コーディングエージェントの整合性を保つ、小さく構成可能なスキルセット。

  • エージェントの一般的な失敗を修正：不整合冗長な出力壊れたコード
  • インストール先：Claude CodeCodexCopilotGemini CLICursor
  • あらゆるモデルで動作する小さく構成可能な指示ファイル
  • GrillMe：コーディング前にあなたにインタビュー
  • TDDスキルはレッド→グリーン→リファクタを推進
設計上の改良点を見つけてコードベースの
アーキテクチャを改善！
2

REA

morluto/rea

アプリの動作からバイナリまで、エージェント主導のリバースエンジニアリング。

  • AIエージェントがソースコードなしでアプリをリバースエンジニアリング
  • オープンソースのMCPサーバー兼CLI
  • 調査対象：ネイティブバイナリ / JavaScript / Electron / Webサイト
  • エージェントがREAを呼び出し、証拠に基づいた調査結果を返す
  • ネイティブ解析は Hopper / Ghidra / IDA、すべてローカル実行
  • セットアップ：Claude CodeCodexCursorGemini CLI
お気に入りの機能がどう動くか、
エージェントに聞いてみよう！
3

Shaders

shader-effects-inc/shaders

あらゆるフレームワークに対応した、コンポーネントとしてのWebGPUエフェクト。

  • WebGPU視覚エフェクトをReactVueSvelteSolidJavaScriptのドロップインに
  • 子コンポーネントがGPU上でブレンドされたレイヤーとして機能
  • エフェクト：グラデーションノイズガラスカーソルトレイル
  • ビジュアルエディタのエフェクトはCLIでコードベースと同期
  • MCPサーバーでコーディングエージェントへのインストールも可能
シェーダーコードを書かずにGPUエフェクト！
フロントエンド開発者に朗報
4

Shipyard

cosscom/shipyard

リモートの開発環境で、コーディングエージェントを実行・制御。

  • デスクトップアプリ・CLI・デーモン「Birth」のOSSリポジトリ
  • VPS・クラウドVM・デスクトップ上の各デーモンが管理：ワークツリーtmux開発サーバー自動化
  • Macアプリは相互TLSで接続
  • ノートPCがスリープ/オフラインでもエージェントは動き続ける
  • 複数エージェントの一元管理が可能に
マシンをペアリングして、
最初のエージェントを起動！
5

skills

vercel-labs/skills

あらゆる場所でエージェントスキルを導入するためのCLI。

  • コーディングエージェント間でスキルをインストール・管理する Vercel Labs のOSS CLI
  • スキルは SKILL.md形式の指示ファイル
  • CLIがGitHubGitLabまたはローカルフォルダから取得
  • インストール済みエージェントを検出して各ディレクトリに配置：Claude CodeCodexCursorOpenCode
  • プロジェクト単位やグローバルスコープで利用可
npx skills add を実行して
スキルを選択するだけ！
6

airllm

lyogavin/airllm

小さなGPUで巨大なLLMを動かす、メモリ節約Pythonライブラリ。

  • モデルをレイヤーごとにディスクへ分割
  • 一度に1層ずつGPUへ読み込む階層ストリーミング
  • 量子化なしで 70Bモデル を 4GBカード で実行可能
  • 人気のHuggingFaceモデルはautomodelで読み込み可能
  • Apple Siliconでも動作、LoRA微調整もサポート
控えめなハードウェアでもローカルで
巨大モデルが動く！

プロジェクト No.7〜12：クロスプラットフォームとセキュリティ解析

Mac不要のiOSビルド、PS5移植、Cursor公式プラグイン、NSA発のリバースエンジニアリングフレームワーク、AI学習カリキュラム、等角投影イラスト生成。

7

xtool

xtool-org/xtool

iOSアプリ構築のためのクロスプラットフォームなXcode代替。

  • 動作環境：LinuxWindows (WSL)macOS
  • オープンソースのCLIおよびSwiftライブラリ
  • SwiftPMパッケージをiOSアプリに変換、署名してデバイスにインストール
  • コマンド：xtool newxtool devで作成・実行
  • XKitライブラリがApple開発者サービス・iOSデバイスと通信
Macを持たないSwift開発者でも
iOSアプリをリリースできる！
8

AnyPS5

boykopovar/AnyPS5

PS5の実行ファイルをLinuxとWindowsに移植する移植ツール。

  • PS5実行ファイルをLinux/Windows用のネイティブプログラムに変換
  • リンカーが実行ファイルをターゲット形式に書き換え、再実装されたPS5システムライブラリを動的リンク
  • エミュレータ不要・個別ランタイム不要
  • シェーダー再コンパイラがVulkan用SPIR-Vを出力
  • 入力：SDLコントローラーまたはキーボード＆マウス
ゲーム保存・移植研究者へ。
ゲームごとのブロッカーマップで進捗確認！
9

Cursor plugins

cursor/plugins

公式のプラグイン仕様と、Cursor用プラグインの公式リポジトリ。

  • 各プラグインは独立フォルダで、エージェントスキルCursorルールMCP定義をまとめたJSONマニフェストを持つ
  • ルートのマーケットプレイスファイルで一覧化
  • 開発者用：ブランチレビュー並列クラウドエージェントスキャフォールディング
  • 統合：GitHubPlaywrightGmailSalesforce
フォルダを参照してプラグインを追加するだけ。
すぐ使えるワークフローが手に入る！
10

Ghidra

NationalSecurityAgency/ghidra

NSAが開発した、コンパイル済みソフトを解析するOSSリバースエンジニアリングフレームワーク。

  • 多数のプロセッサ命令セット・実行形式のバイナリに対応
  • 逆アセンブル逆コンパイルグラフ化を実行
  • 対話モードまたは自動モードで実行可能
  • JDKでWindows / macOS / Linuxで動作
  • 拡張：PyGhidraEclipseVS CodeからJava/Pythonでスクリプト記述
セキュリティ研究者・マルウェア解析担当が
未知のプログラムを理解する定番ツール！
11

AI Engineering from Scratch

rohitg00/ai-engineering-from-scratch

すべての要素を自分で構築することでAIを学ぶ、実践型OSSカリキュラム。

  • 線形代数から自律エージェントまで、全20フェーズ
  • 実行可能コード：PythonTypeScriptRustJulia
  • 各レッスンはPyTorchの前に生の数学からアルゴリズムを構築
  • 再利用可能なプロンプトスキルエージェントMCPサーバーを提供
  • そのスキルがClaude CodeやCodexを家庭教師に変貌させる
仕組みの裏側を深く学べる！
クローンして最初のレッスンを実行
12
wheresryan22/anatomy

Anatomy

アイデアをインタラクティブな等角投影イラストとして説明するエージェントスキル。

  • 概念を説明すると、エージェントが仕組みを視覚化する物理オブジェクトを発明
  • SVG内の小さなシェーディングパーツで構築
  • オプションでWebGLシェーダーや3Dモーションも使用可
  • ヘッドレスChromeがすべてのジョイントをチェック
  • 動作環境：Claude CodeCodexOpenCodeAntigravity
ドキュメント・解説ライターは
自分だけの図解を手に入れる！

プロジェクト No.13〜18：パーソナルAIとハードウェア制御

Cloudflare上のプライベートアシスタント、常駐ボットチーム、GPU駆動Manim、ESP32によるiPhone実機操作、Macの意味検索、Rust版TSコンパイラ。

Talorys

rociiu/talorys

自身のCloudflareアカウント内で動作するパーソナルAIエージェント。

  • コマンドひとつでデプロイ：Pages上のReactアプリ＋プライベートワーカー
  • Durable Objectにチャット・メモリ・タスク・メモ・プロジェクトをSQLite保存
  • Workers AIがツール呼び出し付きストリーミングチャットを処理
  • Durable Object通知がリマインダールーチンを実行
  • テレメトリなしのシングルユーザー専用
データの完全な所有権を保持！
npx create-talorys
14

DeepSeek Bot

Fei2411/DeepSeek-Bot

DeepSeek Harnessを常駐型ボットチームへ変えるプラグイン。

  • 各ボットは独自のモデルメモリツールを持つDSHセッション
  • メインボット「チーフ」が他ボットやグループチャットをセットアップ
  • 管理ボットが応答し、他ボットを呼び出し／直接追加
  • すべてのデータはあなたのコンピュータ内に留まる
連携のとれたボットチームを構築！
チーフに話しかけてみて
15

ManimGX

academa-labs/manimgx

数学・3DアニメのためのGPU駆動Manimエンジン。

  • Rust＋WGPUのGPUコア上でManim CEのAPIを使用
  • Pythonでシーン記述 → manimgx render でMP4生成
  • 対応：LaTeX/Typst数式サーフェスカメラワーク同期ナレーション
  • macOS/Linux/Windowsでpipインストール可、WebGPUでブラウザでも動作
高速で型安全な動画レンダリング！
エージェントに概念のアニメ化を依頼
16

ESP32 iPhone Agent

onehumanbeing/esp32-iphone-agent

ESP32-S3ボードでAIに実機のiPhoneを操作させるエージェント。

  • エージェントはAirPlayミラーリングで画面を認識
  • ボードはUSBマウス・キーボードとしてiPhoneに接続
  • AssistiveTouchがクリックをタップに変換
  • OpenAI互換の視覚モデルがクラウド/ローカル、Mac/Linux上で計画と実行
  • 開発者アカウント不要Xcode不要脱獄不要
ボードに書き込んでタスクを与えるだけ！
iPhone自動化の新手法
17

DigUp

ARahim3/DigUp

Macのファイルを内容から（意味で）検索できるメニューバーアプリ。

  • DeepMindの埋め込みモデル Gemma 2 をllama.cpp上で実行
  • 写真・PDF・録音・動画・コードを1つの共有ベクトル空間に配置
  • 必要なものを説明すると、該当ページ・瞬間・行の結果が開く
  • すべてApple Silicon Mac内で完結
  • 起動：Shift + Command + Space
ファイル名ではなく意味で探す！
Macユーザー必携
18

ts-rust

pingdotgg/ts-rust

LLMが記述した、TypeScriptコンパイラのRust版。

MicrosoftのネイティブTSコンパイラ（tsgo）をLLMがRustへ移植した実験的プロジェクト。

  • Go版のアルゴリズムを踏襲し、同じCLI言語サーバーAPIを提供
  • 同一の診断結果を目指す＋エフェクト診断組み込み
  • より多くのチェッカーを回す高速モードも搭載
  • Linux / macOS / Windowsで動作、npmからインストール可能
そのまま差し替え可能な型チェッカー！
TS開発者は要チェック

ASCII

bas3line/ascii

Webページ向けのASCIIアニメーションコンポーネント。

  • 同梱パーツ：回転する図形物理シミュレーションシーン言語ロゴLinuxディストロ
  • テキスト系パーツはpre要素、カラーパーツはcanvasでレンダリング
  • ReactAstroコンポーネント、またはビルド不要のHTMLタグとして使用可
  • ミニマルなターミナル風サイトに最適
タグを1つ追加してドーナツを試してみよう！
外観を損なわずに動きを追加

OpenFilm

openfilm/openfilm

コーディングエージェントが編集可能な動画を作成するツール。
