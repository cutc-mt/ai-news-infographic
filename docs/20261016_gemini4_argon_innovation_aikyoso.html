開幕：名古屋城とバトンタッチ

名古屋城をアルゴンで

  • 前回作成の名古屋城を発展させ、昼・夜・朝の美しいシーンを生成
  • 「景色をつけて」と言ったら全部作ってくる積極性（おいおい、という程の爆発力）
  • しかしアルゴンは途中でエラー停止 — 作りかけで動かなくなる
ここで「じゃあ繋いでいけばいいか」と発想を切り替えるのがワンダー佐藤流。

アルゴン→Opusバトンタッチ

  • Argonで土台を作らせる
  • エラーで止まったらOpusに投げて仕上げ
  • 3D制作でも図面作成→3D化→Opus仕上げの3段階が有効と判明
  • 単独最強ではなくチームプレーで使うのがコツ
「Argonで作っといて他のAIに投げる」— このバトンタッチが今回の型です。

今回の主役はワークフロー

  • 前回は3Dモデル制作。今回は3Dではなくワークフロー系
  • 実務でAIエージェントとしてどう使うか／エージェントでなくともワンポイント使い
  • 実務的な使い方に絞った本命解説

4パラメータでスコアリング

  • A=Sol、B=Opus、C=Grok、D=Argon の4ファイルで比較
  • 採点者はGPT-5.6 Sol（※6.1ではなく6で実施、6.1ならもう少し高い可能性）
  • 評価軸は新規性・網羅性・厳密性・指示追従の4つ
比較編：4モデル総力戦

総合ランキング

  • 1位Opus（Claude Opus）— 総合点が高い・バランス抜群
  • 2位Sol（GPT-6 Sol）— 硬い回答。6.1なら更に上かも
  • 3位Grok — 新規性・網羅性は強いが数学的に危険な箇所あり
  • 4位Argon（Gemini 4）— 新規性最強・網羅性高いもバランス悪く最下位
総合点はOpus。でも「最下位だから使えない」のではなく、役割が違うのが今回の肝。

4モデル性格診断表

モデルタイプ強み注意点
Sol監査・収束型最も硬い回答・レビュー最強—
Opus総合優勝型総合点・構成力・網羅性—
Grok探索発明型面白い個性的な答え数学的に危険な箇所
Argon拡張突破型新規性最強・1点突破過剰主張・自己修正不能
「Solは全く正反対」— ArgonとSolは対極。だからこそ組み合わせると強い。

Argonの破壊的強み

  • 新規性が最強 — 4モデル中トップ
  • 網羅性も高く壮大な回答が出てくる
  • 意外にも数学的には強い（スコアリングで判明）
  • 「高温的な生成」で魅力のある危ない回答を連発
使っていて「すごく面白い」— ワンダー佐藤が今回一番好きと言った理由。

Argonの危ない癖

  • 過剰主張 — 証明できていないのに「解決した」と強く言う
  • 厳密性が低い — バランスの悪さが総合点を下げる
  • セルフレビュー・デバッグ命令を自己修正できない
  • 「定理・証明・一挙解決・大統一」とでかいことを言い出す
実証編：論文レビューで穴を突く

舞台：LFT量子場理論の論文

  • ワンダー佐藤が執筆中の科学論文（LFT量子場理論）を実験台に
  • 基本論文は1・2・3の3本。普通のAIはまず基本から読む
  • Argonは初手でマニアックな周辺文献まで大量読み込み（今まで見たことないレベル）
「こんなにファイルを読むAIは見たことない」— 1ターン目から爆読してきます。

微細構造定数の穴を発見

  • 本論文外の微細構造定数の記述箇所に本当に穴があった
  • SolもOpusも見逃していた弱点をArgonは1発目で指摘
  • Opusで確認→事実だったため穴を塞ぐことに成功
  • 応用先はセキュリティホール・小さなバグの検出
積み上げなしで「いきなり穴だけ」を突く — これが他のAIにないArgonの型です。

予想外の挙動まとめ

  • 頼んでもいないのにシミュレーションをやってくる
  • 生成のバリエーション豊富で面白い
  • デバッグ後に勝手にYouTube検索 — 全く関係ない挙動（動画には無関係のNotion等まで出現）
  • 操作性が非常に悪いのが難点

スキルを自動作成

  • 見ている間にLFTペーパーライターというスキルを自動生成
  • Opusはスキルを勝手に作らない。CodexやSolは「スキルに反映しますか？」と確認するだけ
  • 1からスキルを作るのはArgonが初めての体験
「見ててスキル作ってんな」— 自主的に仕事を発明してくる新世代の気配。
運用編：操縦のコツ

Googleドライブ保存のコツ

  • Geminiアプリ×Googleドライブ保存との相性は良い（参照・保存とも）
  • しかし長い生成の最後に保存しようとするとオーバーフローで失敗
  • 解決策: 最初に保存→保存しながら考えさせる。軽い生成なら問題なし
# 長いエージェントタスクの型
1. 最初にドライブへ保存（先行保存）
2. 生成しながら随時保存
3. 長い計算は最後の一括保存に頼らない
# 弱点: 文脈積み上げが弱くなる
# → 文脈と保存を完全に分ける運用もあり

雷電並みの操縦難易度

  • ChatGPT / Claude Desktop / Claude Opus なら普通にできることがGeminiだとできない
  • 比喩: Argonは雷電、ChatGPTは零戦、Claude Opusは紫電改
  • 破壊力は最強だが操縦が難しい — コツを掴めば強力な戦力
  • OpusとSolが使いやすすぎて慣れが必要
「破壊力抜群だけど操作性が悪い」— タイトルの意味がここで分かります。

自宅レビューAI陣の採点

  • レビューAI「レブ」（Opus 5.5）は辛口。Gemini 3.8はボコボコ＝戦力外評価
  • Argonはなかなかの好評価 — Grokがようやく戦力入れる程度の中で
  • Opusが挙げた強み: 計算の正確さ・読む速さと広さ・発想の量
  • 弱点: 生成を重ねるほど膨らんで抑えが効かなくなる

最強の使い方：1発勝負

  • 初回の1発目が最良 — 以降は膨らむほど悪くなる
  • キャプテン翼の岬君のように短期間ワンポイント出場
  • 一気に読み込ませて1発で作らせるのが強みを活かす型
  • 長い自由探索は膨張のもと。1テーマ×短く×1つの穴
「1回に1テーマ、短く」— Opusのレビューと本人の実感が一致した結論。

使い方の極意：3つの型

  • 断定を禁止 — 「絶対こうだ」を言わせず仮説・候補レベルに謙虚にさせる
  • 反対意見（判例）を1つ出させる — 言いすぎが抑えられ統合答えが出ることも
  • 結論は他のAIに判定させる — レビューを重ねればArgonは化ける
# Argon向けプロンプトの型
- 「断定せず仮説として列挙せよ」
- 「反対仮説を必ず1つ添えよ」
- 出力 → Sol/Opus にレビューさせる
# 好み: 発散させず1つの穴に集中させる

まとめ：破壊的イノベーションの相棒

  • Opus×Sol の最強コンビにワンポイントで入ってくる新戦力がArgon
  • Fable似の壮大・大胆な生成。穴を突く力はFable超えの可能性
  • ビジネス活用: 0→1企画・未来構想・大胆な戦略立案・破壊的アイデア出し
  • 破壊力は恐らく1番。操縦に慣れれば破壊的イノベーションを起こせる
「是非このアルゴンで破壊的イノベーションをやっていただきたい」— 締めの言葉そのままに。
