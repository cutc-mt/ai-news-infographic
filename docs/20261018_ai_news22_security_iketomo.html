【衝撃】10月だけで情報漏洩1億件超──AI攻撃時代の現在地2026年10月17日間で公表ベース141件・ソースネクス最大2,200万件、スカイチケット1,500万件

SECURITY / 要警戒
  • 17日間で141件の情報流出事件が公表。大企業から中小まで含むため、未公表を含めると実態はさらに大きいと推定される。
  • 巨大案件ではソースネクス最大2,200万件、スカイチケット1,500万件のほか、バーガーキング・焼肉キング・大黒天物産など千万事例が連発。
  • 怖いのは基盤系サービスの侵害。SPIXA・Riden・IDCフロンティア、Web制作プラットフォーム「スタジオ」では、その上に乗る各社サイトのフォームデータが二次感染的に流出。
  • 流入経路は約6割が委託先・サプライチェーン経由。ほかにWebサイト・APIの不備、ランサムウェア、認証情報の盗用が主流。
  • 「AIで攻撃した」と明言された事例はないが、脆弱性診断・API攻撃・機能悪用はAIで明らかに効率化する。攻撃側がAIを使っている時点で、守る側もAIを使わない選択肢はない。
よもぎ
よもぎ:「エージェント怖いから使わない」はもう通用しない、というのが今回の教訓ですね。リモートワークと同じで「使わないと怖い」時代へ。池友さん自身も全アカウントのパスワード見直しと2段階認証を一周したそうです…!
