2026年10月、LLM戦国時代の現在地1ヶ月半で環境はガラッと変わった

環境総括Claudeリード環境へ

前回の9月版から約1ヶ月半。その間にOpus 5.5、Gemini 4 Argon、DeepSeek V4.1 Flash(10/17版)などが登場し、ランキングは大きく入れ替わった。今の環境を俯瞰すると、Claude(Anthropic)のモデル群が開発・エージェント・コストの全方位でリードしており、「クロード環境」と呼べる状況に。Grok 4.7は世間ではイマイチと言われるが、実態はどうか、ArgonはOpus 5.5と比べてどうか、といった視点で26モデルを評価していく。

CARD 03

Claude Opus 5.5GOD RANK / 総合・開発・エージェント・コストすべて最強

GOD10月環境で一択
  • Artificial Analysisの性能ベンチも高水準で、総合・開発・エージェント・コストの4軸すべてで首位クラス
  • ClaudeサブスクでもTPS(トークン/秒)100以上が出るなど、体感の速さも強み
  • トークン効率も向上し、「サブスクの利用枠が減る」との案内が出たものの、使い切る方が大変なレベルに
  • マルチエージェント運用に向くモデル。動画制作・開発などあらゆる用途で「今はOpus 5.5環境」
よもぎ
よもぎ:少し前までは「Claude Fableだろう」って空気でしたが、今は完全にOpus 5.5一択なんだとか。
CARD 04

Claude Fable 5.1SS RANK / 深い思考は随一、コストが課題

SSGOD→SSに降格
  • めちゃくちゃ良いモデルだが、サブスク内の習慣制限などコスト面が気になる
  • 守備範囲の広いOpusに対し、Fable 5.1は1世代前。文章表現の認知負荷も指摘される
  • 一方でメタ的な深さではOpusが拾えない部分を補ってくれる
  • Claude Codeのスラッシュコマンドで「/advisor」的にOpusの仕事ぶりへFableがアドバイスする運用が実用的。難しい対話はOpus/Fable/Argon/AstraのBest-of-Nでも
  • Fable 5.5が登場すればGOD級になる可能性大——ただしコスト懸念は残る
よもぎ
よもぎ:コストを見るなら、あえてOpusをウルトラコードで使う方が良いケースもあるそう。使い分けが大事ですね。
CARD 05

Claude Sonnet(現行)SS RANK / コスパが大幅改善した主力

SSエージェントS+相当
  • コスパがめちゃくちゃ良くなった。エージェントA・開発SS・コストSSの評価
  • 外 loop(アウターループ)的な普段使いでも良く、1Mトークンあたりのコストが安くTPSもしっかり出る
  • Opusよりコスパが良いバランス型で、まさお氏いわく「めっちゃ好き」
  • 唯一の注意点は認知ドリフト(長期利用時の drift)がやや気になること
よもぎ
よもぎ:「Opus 5.5を使い切るのが大変」な人は、Sonnetで本数を張るのが今月の勝ちパターンかも。
CARD 06

GPT-6.1 SolS RANK / SSを付けたくなるほどのコスパ

Sコスパ最強クラス
  • 「SSを付けたいかもしれないが、ライバルが強いのでS」——コスパの良さは突出
  • Artificial Analysisのコストパー(コスト/タスク)×知能では、GLM・HaikuのいたラインをGPT-6.1 Solが持っていった
  • 深掘り・縦の視点はClaudeが持っていないもので、マルチレビューやBest-of-Nに挟む価値あり
  • ただし認知ドリフト/認知負荷が気になり、メインのコデックス使いはしていない(スキルハーネスで対策)
よもぎ
よもぎ:コデックスリセットを繰り返す運用とセットで初めて真価が出る、職人向けモデルという印象。
CARD 07

GPT-6.1 AstraS RANK / Opus 5.5登場まで名を馳せた実力者

Sスペックは今も一線級
  • Opus 5.5が出るまでは「アストラ、アストラ」と言われるほどの期待モデルだった
  • 資格系のタスクでBlenderを使いながらコードでゲームを作れるなどの幅も披露
  • ウルトラファストやChatGPTハーネス系でも勝負している
  • モデル純粋性能はSランク。ただしコスパは今ひとつ(やや割高)
  • こうした機能の一部はOpusやSonnetにも追い付かれつつある
よもぎ
よもぎ:華やかなデモの記憶が強いモデルですが、純粋性能で今もS。「もう一人の主力」枠です。
CARD 08

GPT-6.1 LunaB+ RANK / コデックスアップサーバー経由で輝く

B+Codex経由ならA相当
  • 正直なところB+評価。コデックスで使えるという文脈ならB+〜Aでもよい
  • サイエンス系の質問は(同系統の)別モデルの方が好みという主観あり
  • DeepSeekも十分良いため、Lunaを積極的に選ぶ場面はコデックスアップサーバー経由が中心
よもぎ
よもぎ:「どのハーネスで使うか」でランクが変わる、時代を感じる評価になってきました。
CARD 09

Gemini 4 ArgonS RANK / 特定領域で圧倒的に強い変化球

S動画・音声入力の精度がすごい
  • 特定の専門性が高い質問に対してめちゃくちゃ強い時がある「地味に独特」なモデル
  • 動画・音声を入れた際の応答精度のすごさも大きな強み
  • コストはやや高いが、性能を考えればSランクに値する
  • 動画系の検証段(プロトタイプ)として挟むならArgonが第一候補
よもぎ
よもぎ:「唯一無二ではないけど、代替が効かない場面がある」——Argonはそういうポジションなんだとか。
CARD 10

Gemini Flash(現行)B+ RANK / 日本語ライティングと高速処理の道具

B+AI評価はB
  • 上に出力(余計な装飾)がない強さを活かし、日本語ライティングの下書き・更新に使われる
  • 動画など多様なインプットに対応し、とにかく速い
  • 前の環境ならAランクを渡しても良かったが、今は競争相手が強くBの少し上に
よもぎ
よもぎ:「速くて素直な文章」が欲しいだけなら、まだまだ現役です。趣味は人それぞれ、ですね。
CARD 11

DeepSeek V4.1 Flash(10/17版)B+ RANK / 昨日登場のコスパ怪獣

B+コスパだけならA
  • Opus 5(旧)比でコスト面のベンチが大幅優秀——開発系ベンチはかなり強い
  • SWEベンチマークやターミナルベンチはOpus(旧世代)よりわずかに上を取ることも
  • 10月17日版はDeepSeekハーネス(飼育ハーネス)への最適化と、サーチ系APIの追加で話題
  • モデル純粋評価はB+/B。コスパだけ見ればAランクで、OpenCode 5系と併用すると本領発揮
  • ただし「安かろう悪かろうはダメ。安くて強力が重要」で、一般利用ならB+が無難
よもぎ
よもぎ:周りがOpus 5.5を使っている状況でDeepSeekに切り替えると時間を無駄にする場面も——「1個げ(下位互換)」扱いするかが判断の分かれ目。
CARD 12

Kimi K3B RANK / 提供の安定感で選ばれる実務派

B安定供給が強み
  • コストパー×知能のラインはGPT-6.1 Solに持っていかれた形
  • それでも強力かつ安いので選択肢には入る
  • まさお氏はインテリジェンススコアの好みでGLM 5.3寄りだが、提供面の安定感はKimiが上→Bランク
  • K3.5/K4が出てくれば各種コンポーザーのベースが上がり、再評価の可能性
よもぎ
よもぎ:派手さはないけど「ずっと使える」安心感で残るタイプ。次のK4に期待しましょう。

GLM 5.3 / GLM FlashB / B+ RANK / 更新スピードが速すぎる悩み

GLM5.3 BFlash B+

  • GLM Flashはコスト・開発とも良好だが、エージェント用途はC評価
  • 一昔前はGLM・Haikuがコスパ枠だったが、今や0.5世代前になりつつある
  • GLM 5.5〜6が登場すれば環境が再び動く可能性大

CARD 14

Muse Spark 3.1.3 / Muse WonderB+ / A RANK / メタ系マルチモーダルの本命

Spark B+Wonder A
  • Muse Sparkはコストが激安でTPSもしっかり出る。データ生成用途の声も
  • ただしSpark 3.1.3はマルチモーダル入力が厳しい(コストが落ちてもB行き)
  • Muse Wonderはマルチモーダル入力に対応し、動画映像を渡した時の返答がかなり良い→Aランク
  • Wonderはコスト高め・TPSも出る、全体としては無難で悪くないモデル
  • ミューズ+ジェミニ系(とMimo)はインプットに動画・音声を持てる貴重なグループ
よもぎ
よもぎ:「動画を食わせて何かさせたい」ならWonder一択感。惜しいのはお値段だけ、ですね。

Flash APro B+
