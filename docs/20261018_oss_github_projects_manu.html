XERJ — エージェント向け検索エンジン

Elasticsearch互換。ファイルを読み込ませず「質問」させる
1フォルダを指定してコマンド1発
2コード・ドキュメント・ログ・PDFを自動インデックス
3エージェントは検索で質問→コンテキスト節約
  • コードはtree-sitterのシンボルと行番号付き、CSV・JSON・SQLite・DOCX・メールも
  • Auto Indexがファイル種別を判別し、データセットごとに索引を生成
  • Elasticsearch API互換なので既存クライアントがそのまま動く
  • XERJ KnitがClaude Code・Cursorへ簡単接続

Text-to-CAD — CADの超能力

エージェントにCADスーパーパワーを与えるスキル集
  • 「部品をモデリングして」と頼むとPythonでパラメトリックCADを書いて編集
  • 基盤はOpen Cascade上のBuild123D
  • STEP・STL・3MF・GLB・DXF形式でエクスポート
  • ブラウザビューアでプレビュー、ロボット記述・逆運動学・G-codeのスキルも
  • 安定したCAD参照で精密編集を指示可能

Agent Substrate — K8sで大規模実行

Kubernetes上でエージェント・ワークロードを高密度・低レイテンシで
  • アイドル状態のアクターをワーカーPodプールにマッピングし、状態を保持したまま一時停止／再開で多重化
  • K8sコントロールプレーンをリクエスト経路から除去して低レイテンシ化
  • gVisorでワークロードを隔離
  • ADK・LangChain・Claude Code・MCPに依存しないフレームワーク非依存設計
  • kubectlプラグインで任意のクラスタに導入（まだ初期段階）

Open Shell — セキュア・サンドボックス

NVIDIA製・セキュア・バイ・デザインのエージェント実行ランタイム
  • Claude Code・Codex・OpenClawなどを改変なしでカーネルレベルのサンドボックスで実行
  • 宣言的YAMLポリシーで「触れるもの」を定義するとOpen Shellが強制
  • 資格情報はエージェントに見せず、承認済みエンドポイント宛のみ注入して持ち出しを遮断
  • ポリシー変更は形式検証され、危険なアクセスは承認待ち
  • オンプレのDocker・Kubernetes＋SDKで展開
「デプロイして、エージェントをサンドボックスに入れよう」

Orchard — AppleシリコンでVM編成

OpenAI発のTart VMオーケストレータ（Go製）
  • コントローラ＋ワーカー構成で、Macクラスタ上のmacOS VMフリートをCLI／REST APIで作成・実行・管理
  • ローカル開発モードなら1台でコントローラとワーカーを同時起動
  • v2でLinuxワーカーに対応し、1クラスターでCPUアーキとOSを混在可能
  • 書いたのはGo、導入はHomebrewで簡単

OpenPencil — プログラマブルなFigma代替

AIネイティブ・ローカルファースト・MITライセンスのデザインエディタ
  • ネイティブの.figファイルを読み書きし、独自の.pen形式にも対応。Figmaとノードをコピペで行き来
  • 内蔵AIアシスタント搭載、しかも全部プログラム可能
  • ヘッドレスCLIで検査・クエリ・lint・PNG/SVG/PDF/HTML書き出し
  • MCPサーバー経由でClaude Code・Codex・Geminiから操作、View SDKで専用エディタも構築可
「インストールして、ローカルでデザインしよう」— 今週の目玉。

BRUTAL — C#ゲームフレームワーク

ゲーム制作も自作エンジンも、商用無料・ロイヤルティなし

GPT with taste
  • GPT・Codexに判断力とセンスを与える行動レシピ

記憶と再生 — Remory × AgentPlay

エージェントの「経験」を残し、可視化する2作品
Remory
  • コンテキスト圧縮で失われる詳細を、履歴から学習したソフトメモリで補完
  • メモリネットワークが隠れ状態を読み、残差メモリをSQLiteに保存
  • Codexの圧縮と並走。Qwen・GLMチェックポイント提供、80GB GPU×2が必要
AgentPlay
  • コーディングエージェントのセッションを地図＋タイムラインで再生
  • 失敗したテスト・試した手法・直したエラーの軌跡が見える
  • Claude Code・Codex・Cursor・Copilot対応。ローカル実行でデータは外部に出ない
  • 「最終回答」に隠れたエージェントの苦労の物語を見せるのがAgentPlayの狙い

デスクトップが文字どおり「机」になるWayland環境

  • 通知は郵便受けに届く。何も記号ではなく「物」として操作
