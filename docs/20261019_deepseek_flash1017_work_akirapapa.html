半額の時間帯を日本時間に直す平日の UTC 変換

JST 10-13時 / 15-19時

検証4 ソースからビルド: 道具と4歩手元の実画面で検証

  • 道具: Node.js 22.19以上（または24以上）と pnpm。この2つが揃えば組める
  • npxでdshのバージョンを聞くと0.2.0-rc.2が返ってきた（初回取得込み45秒）
1本目公式リポジトリを取得git clone
→
2本目部品を全部揃えるpnpm install
→
3本目鐙を組む工程・少し時間がかかるpnpm run build
→
4本目工房から鐙が出てくるpnpm dsh web
  • 組み上がった版を聞くと0.2.1-rc.2。画面の左上にも同じ版。店先より1つ先＝公式の指定を満たす
よもぎ
よもぎ:clone → install → build → dsh web の4歩。これで今日から走る準備が整います。
CARD 15

Web UI の使い方設定 → ワークスペース → セッション

  • ブラウザで 127.0.0.1:3080 を開く
  • 設定のモデルでDeepSeekのAPIキーを入れて保存。サーバー再起動不要で即利用可
  • 次にワークスペースを選ぶ（dshを起動したフォルダーを追加）。ここを選ぶまで入力欄は閉じたまま
  • あとはセッションで頼むだけ: 要約・パッケージ把握・ファイル読み・コマンド実行・計画。許可が要る操作は効いてくる
よもぎ
よもぎ:「どの馬場で走らせるか決める」のがワークスペース選択、というのが分かりやすいです。
