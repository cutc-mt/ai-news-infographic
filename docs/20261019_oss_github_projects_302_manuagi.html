CARD 02

caveman：エージェントに原始人の話し方をLESS TOKEN, MORE CODE

TOKEN SAVER

「少ないトークンでいいなら、なぜ多く使う？」コーディングエージェント向けスキル兼プロキシ。応答を簡潔な原始人スタイルに圧縮し、コード・コマンド・エラーはそのまま。/caveman・ultracave・megacaveで圧縮率調整。1コマンドでClaude Code・Codex・Gemini・Cursor・Copilotなど30以上のエージェントに導入可能。

github.com/JuliusBrussee/caveman

よもぎ
よもぎ エージェントの返事が「ココ 直す。出来た。」みたいになるのかな？トークン代が浮くのはうれしい！
CARD 03

VoiceStudio：完全ローカルの音声合成スタジオELEVENLABS ALTERNATIVE

646 LANGUAGES
  • アカウント・APIキー不要でPC上で完結するElevenLabs代替
  • 短いサンプルからの声クローン、説明文からの新規音声生成
  • 動画の吹き替え・文字起こし・フローティングディクテーション・646言語のオーディオブック
  • Pythonバックエンドのデスクトップアプリ。macOS / Windows / Linux、GPU or CPU。ローカルAPIとMCPも公開

github.com/debpalash/VoiceStudio

CARD 04

Context Mode：ツール出力をサンドボックス化CONTEXT OPTIMIZER

17 PLATFORMS

GitHubイシュー20件のような巨大なツール呼び出し結果をコンテキストに放り込まずサンドボックス化し、エージェントが後から検索・問い合わせ可能に。MCPとフックでセッションをまたいだメモリを保持し、ツールルーティングを強制。Claude Code・Codex・Cursor・Gemini・Copilotなど17プラットフォーム対応。

github.com/mksglu/context-mode

CARD 05

tokenspeed：エージェント向けLLM推論エンジンINFERENCE ENGINE

SPMD LOCAL
  • 使いやすさ重視のオープンソース推論エンジン
  • 静的コンパイラが配置アノテーションから集合通信を自動生成（手動並列化不要）
  • C++制御プレーンとPython実行プレーンを分離したスケジューラ
  • リクエスト lifecycle・KVキャッシュ所有権・重複タイミングを有限オートマトンでエンコード、型システムで安全なKV再利用を強制

github.com/lightseekorg/tokenspeed

CARD 06

billion-context：セッションを数日維持CONTEXT COMPRESSION

DAYS-LONG SESSIONS

コーディングエージェントとモデルAPIの間に介在し、Anthropic・OpenAIのストリームを書き換えるコンテキスト圧縮プラグイン。消費済み会話を階層的要約へ圧縮するため小さなコンテキスト窓でも追随でき、中断なしで数日間のセッション継続が可能。Claude Code・Pi・OpenCodeなどでネイティブプラグイン・ランチャー・プロキシ経由で動作。

github.com/ranxianglei/billion-context

よもぎ
よもぎ 長期の開発セッションを切らずに続けられるのはでかい！文脈の圧縮、よもぎも相談したいくらいだよ〜。
CARD 07

Octop：チーム向けセルフホストAIアシスタントBY TENCENT CLOUD

SELF-HOSTED
  • マルチユーザー・マルチエージェント対応のOSSアシスタント
  • エージェントを構築しMCP・ACP経由でツールを付与
  • Feishu・DingTalk・WeCom・Discordなど既存チャットアプリに接続
  • ナレッジベース・RAG・ワークフロー・共有メモリ、自インフラ上の任意モデル

github.com/TencentCloud/Octop

CARD 08

agent-skills：シニアエンジニアの流儀をコード化BY ADDY OSMANI

25 SKILLS

実運用レベルのエンジニアリングスキルパック。定義・計画・構築・検証・レビュー・リリースの全ライフサイクルで、シニアのワークフロー・品質ゲート・慣習にエージェントが従います。仕様/テスト駆動開発、コードレビュー、セキュリティ監査、デバッグを網羅する25スキルを自動選択。Markdown形式で1コマンド、70以上のエージェントへ導入可能。

github.com/addyosmani/agent-skills

CARD 09

handwired：JavaScriptをニューラルネットに変換BY CHENGLOU

DIFFERENTIABLE JS
  • 通常のJSを正確なニューラルネットワークに変換、学習不要で完全微分可能
  • if-else・ループ・状態を行列演算にコンパイル（32ビット浮動小数点）
  • ブラウザ上で動作しGPU不使用、DOMは通常表示でソースはNNの数値

github.com/chenglou/handwired

よもぎ
よもぎ 書いたJSがそのままニューラルネットになるって、発想がすごすぎる…！デモは必見だよ。
CARD 10

tamagui：React UIを一度書いてネイティブとWebへWRITE ONCE, RUN ANYWHERE

UI KIT

一つのコードベースでiOS・Android・Webを対象にするReact用UIキット兼スタイルシステム。React Native と React Native Webベースで、最適化コンパイラがスタイルとコンポーネントをネイティブに近い出力に平坦化。パフォーマンスを犠牲にせず共有デザインシステムを実現します。テーマ設定可能なコンポーネント、型付きデザイントークン、アニメーションドライバー付き。

github.com/tamagui/tamagui

CARD 11

snapcn：shadcn CLIで入れる動画デモ部品BY SHADCN LABS

REMOTION x21
  • 製品デモ動画用Remotionコンポーネントのshadcnレジストリ
  • AIチャットストリーム・ターミナル・デバイスフレーム・キャプション・ロゴアニメ・シーン全体をカバー
  • shadcn CLIでインストール、完全所有できる21種のコンポーネント
  • エージェントスキルがカタログ・プロップ・タイミングを学習し動画を正しく組立

github.com/shadcn-labs/snapcn

CARD 12

nono：セットアップ不要のカーネル強制サンドボックスZERO TRUST / ZERO SETUP

RUNTIME SECURITY

AIエージェント向けOSSランタイムセキュリティ。デーモン・コンテナ・VMなしで数秒でサンドボックス化。LinuxのLandlockとmacOSのSeatbeltによるカーネルレベル強制で、適用後の不正アクセスは構造的に不可能。委任ツールも個別のサブサンドボックスで分離し、クレデンシャルプロキシがトークンの範囲を制限。Claude CodeやCodexと連携。

github.com/nolabs-ai/nono

よもぎ
よもぎ エージェントに任意コードを実行させる時代、これは必須級かも。「ゼロレイテンシ」なのもいいね！
CARD 13

FSearch：macOSのディスク全体を瞬間検索WHOLE-DISK, NEAR-INSTANT

TRIGRAM INDEX
  • 名前でどんなファイルも瞬時に発見、タイプミスを許容
  • トライグラムインデックスでファイル内検索も可能
  • クエリ言語で名前・拡張子・フォルダ・サイズ・日時・正規表現・glob・シンボルを組み合わせ
  • 初回クロール後はFSイベントで最新維持。CLI＋小型デーモン、Rustクレート、コーディングエージェント用MCPサーバーとしても利用可

github.com/noahdunnagan/fsearch

CARD 14

scout：実ブラウザを操作するエージェントBROWSER AGENT

DEVTOOLS PROTOCOL

平易な言葉で目標を与えると、ページを読み、クリックし、入力し、スクロールして作業を完了し回答を返すOSSブラウザエージェント。完了できない場合は何が不足かを報告します。モデルは内蔵されていないため自分で用意。DevToolsプロトコル経由でブラウザを操作するTypeScriptプロジェクトでNPMから利用可能。

github.com/outcrawlai/scout

CARD 15

gloss ＋ claudemy：読書と学習を変える2作READING & LEARNING

TWO PICKS
  • gloss：記事・PDF・Xのブックマークを保存し、行を選んで質問するとTogether AIのオープンモデルがソースを引用して余白に回答。列・表・数式を含むPDFもきれいに解析
  • claudemy：トピックを指定するとClaudeがWebを調査し出典付きの約2分音声レッスンでコースを構成。学習レベル調整・意見の相違の提示・特定著者のSubstackからの構成も可能
よもぎ
よもぎ claudemyは「Udemy・Coursera代替」をうたってるよ。音声レッスンで通勤中に勉強できるのがいいね！
CARD 16

sgrep ＋ indra：意味で探す、CPUで読むSEMANTIC GREP & FAST OCR

RUST POWERED
  • sgrep：単語と意味で探せるRipgrep拡張（context.dev）。Rust＋静的埋め込みで意味的類似性とBM25を融合、インデックス不要でオフライン動作。エージェントを安価かつ正確に
  • indra：DataLabのCPU優先OCRエンジン。行検出・CTC文字認識・レイアウト分類・読み取り順序を特定し、スキャン/PDFをMarkdown・テキスト・JSONに変換。ONNX Runtime上で動作しPyTorch不要
CARD 17

graphicle ＋ house-control ＋ yobiru：締めの3作GRAPH / HOME / MESH

FINAL THREE
  • graphicle：コーディングエージェントにリポジトリのコードグラフ＋永続メモリ・ドキュメント・決定事項・過去セッションを提供するRustツール。MCP経由でファイル・行番号付きの抜粋を返す
  • house-control：自宅をライブ3DモデルとしてMacメニューバーとiPhoneに表示。ランプやエアコンをクリックすると実機がオンに。SmartLife・Home Assistant・Hue・Apple Home対応
  • yobiru：Tailscale経由でエージェント同士が通信。メッセージ・構造化データ・ファイル・制御可能なウェイクアップをPC間で転送し、作業の引き継ぎが可能。中央サーバーなし
