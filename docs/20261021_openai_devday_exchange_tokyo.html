OpenAI DevDay Exchange Tokyo 2026振り返り——
Dots・GPT-6.1 Sol・Codexクラウド化と配信からショート動画を作る自作システム

2026年10月20日に東京で開催された「OpenAI DevDay Exchange Tokyo 2026」を振り返り、9月のDevDay 2026（サンフランシスコ）で発表された20項目超の大型アップデートの要点を整理する。常時稼働エージェント「Dots」、新モデル「GPT-6.1 Sol」「Astra Ultrafast」、Codexのクラウド環境、ChatGPTを開発者に開放するプラグイン拡張、チーム協働のSpaces、OpenAI Marketplaceまで。さらにカレーちゃんが自作した「ライブ配信からショート動画を自動生成するシステム」の構成も解説。

チャンネル: カレーちゃんのAIニュース（@currypurin） 形式: 日本語ライブ配信アーカイブ（10月21日8:30〜） イベント: OpenAI DevDay Exchange Tokyo 2026（10月20日・東京）
よもぎ
「DevDayで発表された20個以上の発表を、東京の現場から振り返る回」です。エージェント・開発者向けAPI・ChatGPTの協働機能と、大きく3つの流れに分けてCARD 01から順に見ていきましょう。
CARD 01

全体像サマリ: DevDay 2026は「20項目超」の大型発表東京を含む世界8都市でDevDay Exchangeが開催中

OVERVIEW

OpenAIはDevDay 2026でChatGPT・Codex・モデル・エージェントの新しい形を含む20項目以上の発表を実施。その後、DevDay Exchangeとしてベンガルール（10月16日）→東京（10月20日）→ソウル（10月22日）→パリ・ベルリン・ロンドン・サンパウロ・メキシコシティと世界8都市を巡回している。今回の配信は、東京会場の内容を振り返りつつ「エージェントが仕事を引き受ける」「ChatGPTが開発者に開かれる」という2つの大きな方向性を整理する回となった。

CARD 18

配信からショート動画を作る自作システム毎日のライブ配信を短尺コンテンツへ自動変換

MAKERS

カレーちゃんは「毎日AIニュース配信」を続ける中で、アーカイブ映像からショート動画を自動生成するシステムを自作したと報告。文字起こし→話題の分割→テロップ・サムネ生成という流れで、長尺配信をそのまま短尺コンテンツへ転用する。2026年の目標に掲げる「AIツールの自作・公開と検証」「チャンネル登録者5,000人」にも直結する取り組みで、配信運用の工数を大きく減らしながらリーチを広げる設計となっている。

① 配信アーカイブ毎朝のAIニュース配信を素材にする
→
② 文字起こし・話題分割ニュース単位で区切りを抽出
→
③ 短尺化・テロップショート動画用に自動編集
→
④ 公開・検証自作ツールの公開と効果検証へ
よもぎ
よもぎ:「作ったものを公開して検証する」——DevDayの開発者精神と同じ姿勢が個人規模で実践されているのが良いですね。
