設計評価シンプルながら参考にすべき点が多い——外ループ系を自作する人へのヒントに

作りを眺めた結果として、実行エンジン（CLIエージェント）を差し替え可能にしつつ、外ループに必要な「記録・定期実行・記憶」をアプリ側で統一して持つ構成。この分離が、モデル差し替え（CARD 07）を容易にしていると考えられます。
