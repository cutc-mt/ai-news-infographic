Software Factory構想: 丸一日〜数日自律で回る工場計画を前倒しし、manager agent監視のもとループを回す

SOFTWARE FACTORY
①リリース計画エージェントと大粒のリリースを計画
②issue分割計画を自律的にissueへ分解
③ループ実行実装→検証をmanager agent監視下で回す
④バッチレビューstaging環境で一括確認・テスト

  • 自作しない人にもカスタマイズ容易な既製品ソリューションがそのうち登場する見込み
  • ビルダー気質なら自作が最速・最も自分仕様——実際の作り方は専用動画で解説
