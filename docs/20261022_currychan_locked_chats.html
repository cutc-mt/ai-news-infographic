CARD 05

使い方: 3ステップで会話をロックチャットの「•••」メニューから

HOW TO
  • STEP 1: ロックしたい会話を開き、上部の「•••」（その他オプション）メニューをタップ
  • STEP 2: 「Lock chat」を選択して確認。初回は4桁のPINを2回入力して作成
  • STEP 3: ロックされた会話は Projects ＞ Locked chats に移動。開くにはPIN（または生体認証）が必要
  • PINはOpenAIアカウント単位で、サインイン済みの対応デバイスならどこでも使える
  • 解除は「Unlock chat」を選ぶだけで、会話は通常の履歴に戻る
よもぎ
よもぎ:ロールアウトは段階的なので、まだ「•••」に Lock chat が出ていない人もいるはず。数日待つのが正解です。
CARD 06

どこにしまう？: 専用セクションに隔離通常の履歴・ピン留め・検索から消える

BEHAVIOR
  • ロックすると会話は専用の「Locked Chats」セクションへ移動。通常のチャット履歴・ピン留め・会話検索の結果からは表示されない
  • サイドバーには「Locked chats」というプロジェクト自体は見えても、個々の会話タイトルは非表示
  • Temporary Chats（履歴に残らない使い捨てセッション）と違い、Locked Chats は後から何度でも戻れる
  • 「サプライズ旅行の計画」や個人的な相談など、デバイスを人に渡す場面を OpenAI は想定例に挙げる
よもぎ
よもぎ:「消す」のではなく「しまう」。検索結果からも引っかからなくなるので、うっかり見られる事故が減る設計です。
CARD 07

認証方法: 4桁PIN ＋ Face ID / Touch IDデバイスのロック解除方法も使える

AUTH
  • 基本は4桁のアカウントPIN。Web / デスクトップではこのPINでロックを開く
  • モバイル（iOS / Android）ではFace ID・Touch ID・デバイスの画面ロック解除を利用可能
  • 生体認証はデバイスごとのオプション設定。PINが常にフォールバックとして残る
  • PINの変更は「設定 ＞ セキュリティとログイン ＞ Account PIN ＞ Change PIN」から既存PINを入力して実行（変更では会話は消えない）
よもぎ
よもぎ:指1本で開ける手軽さと、PINによるクロスデバイス互換の両立。ただし生体認証は端末ごと、と覚えておきましょう。
CARD 08

Memory も分離される: ロック会話専用の記憶通常チャットの Memory に漏れない

MEMORY
  • Memory が有効な場合、Locked Chats にはセクション内で共有される専用の Memoryが用意される
  • ロック後に送ったメッセージはこの専用 Memory のみを更新し、通常の Memory には反映されない
  • つまりロック会話で得た新しい情報が、通常の会話に「漏れて」記憶されることはない
  • 逆に、ロック前に Memory 化済みの情報はロックしても過去分は消えない点に注意
よもぎ
よもぎ:「隠した会話の内容が普通のチャットで話題に出てしまう」というMemory越しの漏洩を塞いでいる、地味に重要な設計です。
CARD 09

注意点①: 「暗号化の金庫」ではないこれはプライバシースクリーン

CAUTION ①
  • Locked Chats はエンドツーエンド暗号化や独立の暗号化ボールトを提供しない（OpenAI明記）
  • 会話の保持期間や「モデル改善のための利用」設定も変わらない——裏側では通常の会話と同じ扱い
  • Enterprise / Edu では、コンプライアンスプラットフォームのメッセージログにはロック会話も出てくる
  • ロックを開けることができる人（＝PINを知る人）は、中身をコピーもできる
よもぎ
よもぎ:「画面に見えなくなる」ことと「秘密が保護される」ことは別です。機密度の高い業務データの扱いは、そもそも別の規約・ツールの話になります。
CARD 10

注意点②: PINのリセット＝全削除サポートでも復元できない

CAUTION ②
  • PINを忘れて「Reset PIN」でリセットすると、以前のPINで保護されていた全ロック会話・ファイル・記憶が完全削除される
  • この削除は元に戻せず、OpenAIサポートでも復旧不可
  • 一方で PIN の「変更（Change）」なら会話は消えない——既存PINを入力すれば安全に更新可能
  • 「忘れても大丈夫」ではなく「忘れたら諦め」。PINは確実に管理するのが運用の前提
よもぎ
よもぎ:ショート動画でもバズっていた注意点（「PINをリセットすると全部消える」）。便利さの裏にある割り切りとして配信でも触れられやすいポイントです。
CARD 11

使える人・使えない会話: 対象プランと適用除外Free〜Enterprise まで対象、Healthcare は除外

AVAILABILITY
  • 対象プラン: Free / Go / Plus / Pro / Business / Enterprise / Edu（無料ユーザーでも使える）
  • ChatGPT for Healthcare では利用不可
  • ロックできない会話: Temporary Chats・アーカイブ・グループチャット・共有リンクから作成した会話・スケジュールタスク付き・Meeting 録画付き
  • Codex の会話（クラウド含む）やローカル Work の会話はロック不可
  • Voice はWeb・モバイルのロック会話で使えるが、デスクトップアプリでは不可
  • Android ではロック会話のスクリーンショットが真っ白になることがある（覗き見対策）
よもぎ
よもぎ:「無料プランにも開放」が今回の肝。プライバシー機能の民主化というより、見られて困る会話を持つのは無料ユーザーも同じ、という判断ですね。

COMPARE
観点Locked ChatsTemporary Chats

検索・ピン留め通常の検索・ピンからは非表示そもそも対象外

よもぎ:「消すか、鍵をかけて残すか」。相談を続けたいなら Locked Chats、試すだけなら Temporary——使い分けが整理されました。
