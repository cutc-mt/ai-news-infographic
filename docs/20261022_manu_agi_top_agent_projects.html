CARD 02

ShipifyAI: チケットをプルリクエストに変える自律AIソフトウェアチームのためのAIデリバリーエージェント

FEATURED ①
  • ボードから割り当てたチケットのみを取得し、隔離されたサンドボックス環境でコードの作成とテストを実行（手元のPCは汚さない）
  • レビュー可能なプルリクエストを作成し、レビューコメントにも対応して解決していく
  • タスクのステータスはボードと自動同期。更新情報は完全な監査証跡付きで Slack / MS Teams へ通知
  • 製品チームは増員なしでより多くを出荷できる——ボードを接続して試用開始
よもぎ
よもぎ:「サンドボックスで作り、PRで出す、記録は全部残す」——エンタープライズがコーディングエージェントに求める3つの条件を満たす設計です。
CARD 03

Kai Resolve: 難問チケットを調査するAIサポートエンジニアGleep 内の Tier2 調査を自動化

FEATURED ②
  • 一次サポートでは対応できない技術チケットを調査——ログを読み、設定を確認し、コードのバグを追跡する Tier2 担当者の手作業を自動化
  • スレッド・デバイス・SDKバージョン・コンソール/ネットワークログ・クリック履歴・画面録画、許可された場合のアカウントデータやリポジトリなど証拠から調査を開始
  • リポジトリをサンドボックスに読み取り専用でクローンし、ソースを追跡して参照ファイルを提示
  • 原因特定後は顧客へ回答、または診断付きでチームにエスカレーション、確認済みバグは証拠付きコーディングタスクへ変換（Kai Code / Claude Code / Codex / Cursor に送信し人間がレビューしてマージ）
  • コミットは一切行わず、破壊的操作はブロック。結論が出なければ「出ない」と正直に伝える
よもぎ
よもぎ:「AIが勝手に直す」のではなく「AIが証拠を集めて人間に渡す」スタンス。SaaS・ソフトウェアサポートチーム向けに、無料トライアルあり。
CARD 04

FrameFields: コーディングエージェントが動画を作って出荷できるエージェントとその開発者のためのビデオエンジン

FEATURED ③
  • TypeScript で操作できる単一の NPM パッケージ——モーショングラフィックス、文字、チャート、3D、音声を生成
  • エージェントは独自のフレームをチェックし、GPU 上で直接 MP4 ファイルをレンダリング可能
  • ヘッドレスブラウザもデスクトップアプリも不要——動画生成の定番の重い仕組みが要らない
  • Claude Code・Codex・Cursor・Gemini CLI にインストール可能。「インストールして、エージェントに動画を作らせましょう」
よもぎ
よもぎ:「エージェントの成果物はテキストとコードだけ」だった世界に動画が加わるのは新しい路線。デモ動画やデータ可視化の自動生成につながります。
CARD 05

Own 1（OwnOne）: ローカルで動くパーソナルAIコンピュータモデル・エージェント・データはデフォルトでデバイス内

FEATURED ④
  • オープンな言語・視覚・音声モデルをデスク上でローカル実行するAIコンピュータ
  • モデル、エージェント、データはデフォルトでデバイス内に留まる——プライバシーが構造的に守られる
  • 大きな電力が必要なタスクは OwnCloud にルーティング。ホストされたAPIはあなたの承認がある場合のみ使用
  • 「プライベートなAIをほぼゼロの運用コストで」求める開発者・AIパワーユーザー向け。現在予約受付中
よもぎ
よもぎ:ローカル-first＋クラウドは承認制、という設計は今週のトレンドそのもの。「安い・速い・外に漏れない」を両立させようとしています。
CARD 06

CrawlForge MCP: AIエージェントにWebアクセスを与える31の道具オープンソースのMCPサーバー

FEATURED ⑤
  • AIエージェント向け Web スクレイピングツール——データの取得・検索・クロール・抽出を行う31種類のツールを提供
  • あらゆるURLからクリーンな Markdown や構造化された JSON を一度の呼び出しで返却
  • Claude・Cursor・LangChain などのクライアントに単一の設定項目で追加でき、APIキーでツールを呼び出す
  • 開発者はスクレイパーを書くことなくライブの Web データを取得可能。プレイグラウンドで試験できる
よもぎ
よもぎ:MCP の普及で「Web取得」が設定1行の時代に。エージェントの情報収集力を手軽に底上げできるのが価値です。
CARD 07

Beam: Mac のウィンドウを別の Mac にそのまま表示デスクトップ画像の転送ではない「本物のウィンドウ共有」

PROJECT 01
  • 従来の画面共有はデスクトップ全体のフラットな画像を表示するだけ——Beam はウィンドウそのものを転送する Mac アプリ
  • 独自サイズで配置され、専用のDockアイコンや Command+Tab の居場所を持ち、ローカルと同様にサイズ変更・入力・ショートカット操作が可能
  • ディスプレイの正確な解像度でストリーミングされるためテキストは Retina 品質。アプリ音声も伝わり、Mac 間のファイルドラッグもできる
  • ヘッドレス Mac mini のウィンドウも一覧表示でき、ビルドやエージェントにワンクリックでアクセス
  • 同一 Wi-Fi や Tailscale 経由で暗号化された直接通信。ゲストはブラウザで閲覧可。無料ダウンロード
よもぎ
よもぎ:複数 Mac を使う人向けの気の利いた道具。特にヘッドレス Mac mini でエージェントを走らせている人には刺さります。
CARD 08

Reflection AI のオープンウェイトモデル: エージェントワーク用の疎MoE少ない推論コストで最先端級の能力を

PROJECT 03
  • Reflection AI 初のオープンウェイトモデル。コーディング・推論・エージェントワークロード用に構築
  • 欧米のオープンモデルのギャップを埋める目的。最先端級の能力をわずかな推論コストで提供し、低コストなエージェント運用を可能にする
  • トークンごとにパラメータの一部のみ活性化する疎な混合エキスパート（MoE）が効率性の源泉——同等のオープンモデルより数倍少ない計算量
  • 推論の工夫レベルを設定でき、タスクや予算に応じて短時間応答と深い思考を使い分け。最大100万トークンのコンテキスト
  • 大規模強化学習で訓練され、学習の枠を超えてブラウジング・検索・ツール利用を汎用化。Apache 2.0 ライセンスでウェイト公開、APIキーも取得可能
よもぎ
よもぎ:「エージェントを1日中走らせ続ける」には推論コストが壁。疎MoEによる低コスト化は、まさにその壁を崩すアプローチです。
CARD 09

Willow: 話すだけでどこでもクリーンなテキストにAI音声入力エージェント＋執筆モード「Scribe」

PROJECT 04
  • Slack・Gmail・Cursor・Notion などあらゆるアプリでカーソルを置き、ホットキーを押しながら話すだけでテキスト化
  • フィラーワード（えー、あのー）を除去し、句読点を自動修正
  • Scribe モードはラフなアイデアを「あなたの声」で洗練された文章に書き換え
  • データ保持ゼロ・エンドツーエンド暗号化・オフラインのオンデバイスモードを提供
  • プロフェッショナルや開発者の執筆・プロンプト作成を高速化。Mac・Windows・iPhone 対応
よもぎ
よもぎ:音声入力の課題は「書き起こし」ではなく「そのまま使える文章」であること。フィラー除去と Scribe がそこを狙っています。
CARD 10

Tory: カスタマーサクセスチームのAIサポートエージェントURLを貼るだけでヘルプ内容を学習

PROJECT 07
  • ヘルプドキュメント・製品ページ・社内知識を活用し、複雑な顧客質問に回答するAIサポートエージェント
  • URLを貼り付けるだけで Tory が内容を学習。チャットをヘルプセンター・アプリ・ウェブサイトに埋め込み可能
  • あなたのトーンでソース付きの回答を返し、不明点にはフラグを立て、完全な文脈と共にチームへ引き継ぎ
  • TalkJS を基盤とし、ISO 27001 認証を取得。無料トライアルあり
よもぎ
よもぎ:「ソース付き回答＋分からないことは素直にエスカレーション」という誠実設計がサポートAIの信頼条件ですね。
CARD 11

Buddylist: コーディングエージェントと一箇所でチャットレトロなメッセンジャー風の無料デスクトップアプリ

PROJECT 08
  • Claude Code・Codex・Gemini・OpenCode などのコーディングエージェントを連絡先リストのようにまとめる
  • 各チャットは自身のログイン情報を使った各エージェントのセッションになる
  • 会話はコンピュータに保存。各エージェントは専用の Git ワークツリーで作業する
  • 複数エージェントをグループチャットに招待し、互いに作業を引き継がせることも可能。ダウンロードして「挨拶」しよう
よもぎ
よもぎ:エージェントの並走を「メッセンジャー」のUIに見立てたのが秀逸。Git ワークツリー分離で衝突も防いでいます。
CARD 12

Quello: 既存ツール全体に質問し、回答を検証Notion・Google Drive・GitHub・PDF を一つのワークスペースへ

PROJECT 10
  • Notion・Google Drive・GitHub・PDF を同期された一つのプライベートワークスペースに接続
  • チャットや音声で質問すると、すべての回答が正確なソース箇所にリンクされる
  • MCP 経由で Claude・ChatGPT・Perplexity の中でも動作
  • チームや個人が検証可能な回答を得られる。無料トライアルあり
よもぎ
よもぎ:RAG の弱点は「出典が分からない」。全回答にソースリンクを付けることで、社内QAを「検証可能」にしています。
CARD 13

Lightfield: 自己更新するAIネイティブCRM手動入力を削減し、エージェントが記録を活かす

PROJECT 14
  • メール・カレンダー・Slack・LinkedIn を連携し、すべての顧客インタラクションを自動キャプチャして構造化
  • 自動更新される記録を基にエージェントがアウトバウンド活動を行い、リスクのある取引にフラグ、承認用のフォローアップ案を作成
  • 記録はAPI・MCP・CLI 経由で外部から利用可能
  • 手動データ入力を減らしたい営業チームに最適。デモリクエスト受付中

よもぎ:CRM の本質が「記録の鮮度」にあるとすると、自己更新＋エージェント活用は自然な帰結。営業の生産性向上に直結します。

PROJECT 16

プロジェクト概要
Framer（AIデザインエージェント）キャンバス上でウェブサイトを設計・構築。ページをその場で生成・改善し、変更は可視化され常に編集可能。CMS管理やカスタムコード記述も行い、Slack・GitHub・Claude Code・Codex・Cursor からサイトを操作可能。ホスティング・SEO・分析機能内蔵でアイデアから公開まで。無料で開始
B（Frontier & Eclipse）会話を要約・タスク・リマインダーに変換するパーソナルAIデバイス。Frontier は手首や衣服に装着するウェアラブル、Eclipse は磁石でスマホに取り付け。Gmail・Googleカレンダー・Outlook・Alexa Plus と連携し、ハンズフリーでフォローアップ作成や要約の共有が可能。音声はリアルタイム処理後に削除され、録音はボタンで制御
Tomoあらゆるトピックをパーソナライズされたゲーム形式のコースに変えるAI学習アプリ。トピックを入力すると約2分でセクション・レベル・クイズを構築。1日5分のレベルでXPを稼ぎストリークを維持。学習スタイルの選択も可能で、ChatGPT 内でも利用可能
DownsietaCodex と Claude Code のクォータ管理ガイド。macOS ネイティブのメニューバーアプリで、トークンを消費せず各エージェントの残量を読み取り、「続ける・ペースを落とす・切り替える」を提案。根拠数値も表示され、アカウント登録やテレメトリ収集なし
RustcheerioRust エンジン搭載の cheerio 互換 API。パース・セレクター・シリアライズを Rust で実行するオープンソースのHTML解析ライブラリ。インポート置き換えだけで導入でき、macOS・Linux・Windows 向けビルド済みバイナリも提供。アップストリームの cheerio テストをすべてクリアし、より高速にページを処理
よもぎ
よもぎ:単発の道具ではなく「エージェント時代の周辺機器」（ウェアラブル、quota管理、スクレイピング基盤）が揃ってきた、というのが今週の空気です。
