META MUSE / 日本上陸

MetaのパーソナルAIエージェント「Muse」が遂に日本公開
Instagram・Messenger連携と「ハーネスに直接介入できる」設計を解説

海外で評判のMeta製パーソナルAIエージェントMuseが日本でも利用可能になりました。まさお氏が実際にApp Store・Macアプリ・ブラウザで触りながら確認したのは、Instagram・Messenger・Metaビジネスマネージャーとコネクタで接続して「誰と最後に連絡したか」「返信漏れはないか」を任せられる体験、1人1台のクラウドPC（VM）で動き、外への通信をセンチネルが承認する安全設計、そしてIDENTITY.mdやMEMORY.mdといったシステムファイルを直接書き換えられるハーネス介入性の高さです。Grok Botとの比較にも踏み込みます。

Museとは何か: Meta版の「専属AIスタッフ」チャットUIの外側まで仕事を任せるパーソナルエージェント

WHAT IS MUSE
  • Metaが提供するパーソナルAIエージェントサービス。単なるチャットbotではなく、提案・実行・確認を担う
  • 海外ですでに公開され評価が高く、今回日本でも利用可能に
  • 背後にはMeta純正のモデル（Muse Spark系）。ここ最近でかなり良くなってきていると実感
  • Instagram運用者・Messengerを使うビジネスパーソンにとって相性が特に良い
よもぎ
よもぎ:「モデルの良さ」と「Metaアカウント資産への接続」の掛け算が強みですね。

  • 「メールを確認していませんよ」のようなリマインド型の働きかけも

CARD 05

買い物を任せる: Stripeリンクとワンクリック購入サイトによっては対応しきれない部分も正直に

SHOPPING
  • 特定のサイトでStripeのリンクを紐づけておくと、ボタンひとつで「このボットで購入」「Webで見る」を選べる
  • まさお氏が実際に買い物を試そうとしたが、自分のアカウントはまだStripeリンク未設定
  • Amazonはアクセスできなかったなど、サイトによっては買い物不可のケースもあり
  • 対応サイトでは購入体験そのものをエージェント経由で完結できる
よもぎ
よもぎ:「全部買える」ではなく「決済基盤と繋がった所から」という段階的普及、という誠実な実態報告です。

アバターとキャラクター: 名前と見た目は自由に変更未来観のある相棒キャラと一緒に

CARD 08

内蔵ブラウザ: フォーム入力を代行エージェントが自分の目でWebを操作

BROWSER
  • Museは内部にブラウザを持っており、サイトのフォームを代わりに埋める動作を確認
  • 公式に紹介されている動きで、入力・送信の手間を肩代わり
  • 外の世界を「見る」だけでなく「操作する」エージェントであることが分かる
  • この操作系が次カードの「承認」設計に繋がる
よもぎ
よもぎ:ブラウザ内蔵＝エージェントの行動範囲が一気に広がる仕組みです。

購入前の承認: 危険な操作は止めて確認させる金銭が動く前に人間の指を通す

APPROVAL

  • 「任せきり」ではなく人間が確認できるポイントを確保

INPUT

  • 動画入力にも対応——映像を見てもらった上でのやり取りが可能

CARD 11

仕組み: 1人1台のクラウドPC（VM）で動く外への通信を見張る「センチネル」の存在

ARCHITECTURE
  • Museは1人1台のクラウドPC（仮想マシン）の中で動作
  • 外への通信を監視するエージェント「センチネル」が常駐
  • センチネルが承認しない限りネットに出ないという安全の仕組み
  • まさお氏が「面白いところ」と評価する部分——エージェントの行動を系として制御
よもぎ
よもぎ:エージェント専用の「部屋」と「門番」。サンドボックス設計の教科書的な構成です。
