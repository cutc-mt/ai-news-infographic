CARD 02

vLLM & Headroom: 推論を速く、入力を軽く高速LLMサービングとコンテキスト圧縮の基盤2枚

群A / INFERENCE
  • PagedAttentionでアテンションメモリを管理し、連続バッチ処理・プレフィックスキャッシュ・量子化・投機的デコードを統合
  • Hugging Faceのモデルを直接読み込み、テンソル/パイプライン並列でGPUをスケール
  • OpenAI互換APIサーバーを提供し、NVIDIA/AMD/Intel GPU・CPU・TPUで動作
  • 自前ホストチームは高速・低コストな推論基盤に。pipで即導入

Headroom: LLMに送る前に文脈を圧縮する — ツール出力・ログ・ファイル・RAGチャンク・会話履歴をローカル環境で圧縮するオープンソースのコンテキスト圧縮レイヤー。JSON・コード・文章を圧縮機へルーティングし、オリジナルはローカルにキャッシュ。Python/TSライブラリ、プロキシ、MCPサーバー、Claude CodeやCodexをラップするコマンドとして利用でき、長時間セッションのトークン消費を直接削減します。

よもぎ
よもぎ:vLLMが「推論を速く」、Headroomが「入力を軽く」。料金と速度の両面から攻める基盤2枚です。
CARD 03

Orca: エージェントの群れを並列ワークツリーで1プロンプトを複数エージェントに競合させる

群B / ORCHESTRATE
  • Claude Code・Codex・OpenCodeなどのCLIエージェントをそれぞれ専用Gitワークツリーで動かすデスクトップアプリ
  • 同一プロンプトを複数エージェントに並行処理させ、最良の結果をマージ
  • ターミナル分割・差分アノテーション・モバイルアプリを統合
  • macOS / Windows / Linux。各自のサブスクリプションをそのまま利用
CARD 04

Ponytail: 「必要なコードだけ」書かせるスキル再利用優先でレビュー量を削減

群B / SKILL
  • AIコーディングエージェントに影響を受けるコードを読ませ、段階的に接近させるエージェントスキル
  • 既存コードの再利用→標準ライブラリ/プラットフォーム機能の活用→最小限の新規記述、の順序
  • バリデーション・セキュリティ・アクセシビリティは犠牲にしない
  • /ponytail-review と /ponytail-audit で差分とリポジトリを検査
  • Claude Code・Codex・Cursorで動作。開発者のレビュー負担が直接減る
CARD 05

OpenCode: ターミナルのOSSコーディングエージェントBuild/Planの2モード+汎用サブエージェント

群B / AGENT
  • ターミナル用OSSエージェント。macOS/Windows/Linuxのデスクトップアプリもベータ提供
  • Tabキーで2エージェントを切替: Build（フルアクセス）／Plan（読み取り専用・Bash実行前に確認）
  • 汎用サブエージェント「@general」が複雑な検索や多段タスクを処理
  • npmまたはHomebrewでインストール可能
CARD 06

Agents: 全コーディングツール対応のプラグイン市場単一Markdownソースから各形式へ自動生成

群B / MARKETPLACE
  • プラグイン・専門サブエージェント・スキル・コマンドをツール間で共有するOSSマーケットプレイス
  • 各プラグインはPython/JS開発・レビュー・テスト・インフラ・セキュリティなど作業単位でまとまる
  • すべて単一のMarkdownソースで管理し、アダプターが各ツール用の形式を生成
  • 対応: Claude Code、Codex、Cursor、OpenCode、GitHub Copilotほか
  • どのエージェントを使っていても同じワークフローを利用可能
よもぎ
よもぎ:「エージェントツールの乱立」への回答がプラグイン互換層。整理されつつある市場を感じます。

Agents: 全コーディングツール対応のプラグイン市場 — プラグイン・専門サブエージェント・スキル・コマンドをツール間で共有するOSSマーケットプレイス。Python/JS開発・レビュー・テスト・インフラ・セキュリティなど作業単位でまとまり、すべて単一のMarkdownソースで管理。アダプターがClaude Code、Codex、Cursor、OpenCode、GitHub Copilotなど各ツール用の形式を生成し、どのエージェントを使っていても同じワークフローを利用できます。

よもぎ
よもぎ:「エージェントツールの乱立」への回答がプラグイン互換層。整理されつつある市場を感じます。
CARD 07

AI Memory: エージェントに共有長期記憶をセッションをGit管理のMarkdown Wikiに

群B / MEMORY
  • ツールやマシンを跨いだ共有長期記憶を提供するセルフホスト型メモリサーバー
  • ライフサイクルフックがプロンプトとツール呼び出しを捕捉・サニタイズ
  • 各セッションをGit管理の可読Markdown Wikiへ変換
  • 次のエージェント（Claude Code、Codex、Cursor、Gemini CLI）が作業の続きから引き継ぎ、MCP経由で全文検索
  • エージェント切替時に文脈を説明し直す必要が消える
CARD 08

CLI Anything: あらゆるソフトウェアにCLIを生やすGUIクリックを本格操作に置換

群B / EXTEND
  • 既存ソフトウェアにコマンドラインインターフェースを生成するエージェントプラグイン
  • GIMPやBlenderのようなコードベースに「/cli-anything」を実行すると7段階パイプラインが解析
  • JSON出力対応のPython CLI構築・テスト作成・インストールまで自動
  • CLIHubから既製CLIの検索・導入も可能
  • エージェントが不安定なGUIクリックではなく確実なソフトウェア操作を行えるように
CARD 09

Supabase: オープンソースのPostgresバックエンド基盤REST自動生成・Realtime・認証・ベクトル

群C / BACKEND
  • 全プロジェクトに専用Postgresデータベースを提供する開発プラットフォーム
  • 自動生成REST API、WebSocketでDB変更を配るRealtime、認証のGoTrue
  • S3互換ストレージ・エッジ関数・AI用ベクターツールキットを統合
  • ホスト型・セルフホスト・ローカル開発のいずれにも対応
  • オープンな道具の上で「Firebase的な体験」をWeb・モバイル・AI開発者が獲得
CARD 10

Twenty: CRMを「コードとして」構築・出荷TypeScript SDKでオブジェクト定義をバージョン管理

群C / CRM
  • チームがカスタムCRMをコードとして作るための構成要素を提供するOSS CRM
  • TypeScriptとTwenty SDKでオブジェクト・フィールド・ビューを定義し公開
  • ワークフローとAIエージェントを内蔵。定義はすべてバージョン管理下
  • クラウド利用 or Docker Composeでセルフホスト
  • 導入は npx create-twenty-app の1行から
CARD 11

AIJobSearch: Claude Codeで求人応募を自動化/setup → /scrape → /apply の3コマンド

群C / JOBS
  • 自マシンで動くClaude Codeベースの求人応募フレームワーク
  • フォークして「/setup」でプロフィール登録→「/scrape」で求人検索→「/apply」で適合評価
  • LaTeX形式の履歴書・カバーレターを自動生成
  • 2人目のレビュー担当エージェントがドラフトを評価→PDFコンパイル→ATS（採用管理システム）対応確認
  • 存在しないスキルは捏造しない。求職者がコントロールを保持
CARD 12

FreeHire: 企業採用ページ直撃の求人エンジンWorkday/Greenhouse/Leverをクロール・重複排除

群C / JOBS
  • IT求人を企業の採用ページから直接取得するセルフホスト可能な検索エンジン
  • ワーカーがWorkday・Greenhouse・LeverなどのATSをクロールし全求人を正規化・重複排除
  • MeiliSearchにインデックスし、地域・勤務形態・経験レベル・スキル・給与でファセット検索
  • 履歴書ビルダー・応募追跡・キー不要の公開API・Claude用MCPサーバーを追加予定
  • 転職サイト再掲なしのオリジナル求人リストを入手（freehire.me / Docker）
よもぎ
よもぎ:採用ページから直接拾うので「募集終了済みの古い求人」が混ざりにくい、というのが実利です。
CARD 13

Graphify: コードベースをクエリ可能な知識グラフへTree-sitterでローカル解析、LLM不使用

群D / ANALYZE
  • コード・ドキュメント・PDF・設定ファイルをクエリ可能なナレッジグラフに変換するCLI+スキル
  • コード解析はLLMを使わずTree-sitterでローカル実行。各エッジには「抽出/推論」のタグ付き
  • 「/graphify」1つでインタラクティブなグラフ・レポート・graph.jsonを生成
  • jsonにはクエリ・パス探索・解説コマンド用の構造が含まれ、Claude Code / Cursor / Codex / Gemini CLIで利用可
  • 開発者もエージェントも手探りが必要なくなる
CARD 14

REA: エージェント駆動のリバースエンジニアリングHopper/Ghidra/IDAをローカルで使用

群D / REVERSE
  • ソースコードなしでアプリを解析するエージェント用MCPサーバー兼CLI
  • 対象: ネイティブバイナリ・JavaScript・Electronアプリ・.NETアセンブリ・Webサイト
  • エージェントが呼ぶと根拠に基づいた調査結果を返す。解析はすべてローカル実行
  • ネイティブ解析にHopper、Ghidra、IDAを使用
  • 「お気に入りの機能がどう動いているか、エージェントに聞いてみて」が現実の使い方
CARD 15

Hyperframes: HTMLを書いて動画にレンダリングHeadless Chrome + FFmpegで決定論的出力

群D / RENDER
  • HTML・CSS・メディア・シーク可能なアニメーションをMP4に変換するフレームワーク
  • タイミングとトラックをデータ属性で定義し、GSAP・CSS・Lottie・Three.jsでアニメーション
  • レンダラーがHeadless Chromeで各フレームをシークし、FFmpegでエンコード
  • 同じ入力から常に同じ動画が生成される決定論的設計
  • 開発者やClaude CodeなどのエージェントがプレーンHTMLから動画を作成可能。npx hyperframes init
CARD 16

周辺ツール4連: ComfyUI / CleanYourTV / ts-rs / Mineflayer生成・快適化・高速化・遊び

群D / ETC
ツール内容
ComfyUI画像・動画・音声・3D・テキストをノードグラフで構築するローカルAI生成エンジン。変更部分のみ再実行、NVIDIA/AMD/Intel/Appleシリコン対応、アプリ向けローカルAPI提供
CleanYourTVWi-Fi経由でAndroid TV/Google TVのプリインストールアプリを無効化（ADB使用・ルート化なし）し、ホーム画面をApple TV風ランチャーに。Claude Codeなどにプロンプトを貼るだけで実行、1スクリプトで復元可能
ts-rsOx系プロジェクトによるTypeScriptコンパイラ/言語サーバーのRust製ドロップイン実装。MS本家リポジトリmain対象の完全互換を目指し、少メモリで高速な型チェック。開発依存に追加するだけで導入可
MineflayerMinecraftボット構築用JavaScript API。チャット・掘削・建築・クラフト・戦闘・インベントリを高レベルAPIで。プラグインで経路探索・ブラウザビューア・MCPサーバーを追加しLLMがボットを制御。Voyagerなどでも利用
CARD 17

今週の読み解き: エージェント運用が「個人」から「編成」へ20本に共通する3つの筋

ANALYSIS
  • ① 並列と隔離: Orcaのワークツリー群、T3の複数エージェント操縦——1人1チャットの枠を外し、壊し合わせない構造が標準化されつつある
  • ② 共有と継承: Agentsのプラグイン市場、AI Memoryの長期記憶——文脈とスキルをエージェント間で引き継ぐ道具が揃った
  • ③ 入力の経済: Headroomの圧縮、ts-rsの高速型チェック、vLLMのスループット——トークンと計算の単価を下げる層が厚くなっている
  • 週次ペースでこの密度のOSSが出る現在、「何を組み合わせるか」自体が開発スキルになりつつある
よもぎ
よもぎ:個々のツール紹介動画に見えて、実はエージェント編成の三層（実行・記憶・経済）が整備された週だった、という読み方ができます。
