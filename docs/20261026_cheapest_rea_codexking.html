CARD 02

前提: REAとは何だったのか27万以上のスターを獲得した「何でも解析」ツール

CONTEXT
  • REAは「何でもリバースエンジニアリングする」を看板にGitHubで爆発的に普及し、27万以上のスターを獲得
  • 実体は207個のツールを備えたMCPサーバー——Electron用のasar、Macバイナリ用のotoolやnm、Go用のgo version -m、Android用のjadxなどを呼び出す
  • その後、チャンネル主は「実はそれほど便利ではない」という検証動画を公開
  • その改善版として生まれたのが、スキルファイル1個で同じ仕事をより速く・安くこなすLeanREA
CARD 03

今起きている問題: エージェントがREAを拒否正当な依頼までもが同じ網にかかる

PROBLEM
  • Claude CodeやCodexがREA形式のプロンプトをブロックし始めた
  • アプリの解析や機能の仕組み追跡を依頼すると、作業どころか停止して拒否してしまう
  • 急速かつ巨大に普及したためモデル提供側が反応したのはある意味当然とチャンネル主も理解を示す
  • 問題は、こうした作業の多くが完全に正常なものであること——正当なリクエストまで一括で遮断されている
CARD 04

ブロックが困る正当なユースケース「解析」＝怪しい作業ではない

USE CASES
  • Electronアプリがネイティブアドオンとどう通信しているかを理解したい
  • 配布するバイナリにどのバージョンのライブラリが含まれているか確認したい
  • ソースコードがないものをデバッグしたい
  • いずれも日常的な開発・保守業務だが、同じ網にかかって拒否されるのが現状
よもぎ
よもぎ:セキュリティ調査にも悪用にも使える道具は両刃剣。提供側が線引きを厳しくすると、正常利用者が最初に犠牲になる——この構図はAIツール全般に共通ですね。
CARD 05

要素①: LeanREA——8KBのスキルファイル207ツールのMCPサーバーを丸ごと置き換える

PIECE 01
  • REAのツール層をすべて取り除いた、わずか8KBのスキルファイル
  • ターゲットごとに最適なコマンドをエージェントに指示——コピペして実行できる形で提示
  • モデルが見落としがちな小さな罠もリストアップ
  • あとはエージェントが通常のシェルで実際のツールを実行するだけ——MCPサーバー不要
  • ツール定義を読み込まないため、コンテキストをほとんど消費しない
CARD 06

LeanREAのベンチマーク: 速い・安い・精度は同じSonnet 5.5比較でターン数も56%削減

BENCHMARK
指標REA（207ツールMCP）LeanREA（スキルファイル1個）
速度基準38%高速
コスト基準35%安価
精度基準同じ
ターン数基準56%削減
単純な応答1つの消費トークン約40万トークン（全ツール定義を読み込むため）約3万4千トークン
よもぎ
よもぎ:この最後の数字が今回の肝。安いモデルに乗り換えるとき、開始前に40万トークンもツール定義で浪費していたら元も子もありません。コンテキストの軽さ＝コストの軽さです。

  • 以前のV4 Proの結果を上回り、Gemini 3.8 Flashと同率

  • 通常の逆エンジニアリング作業に恐をなすことがない——アプリの抽出・コード検索・逆アセンブルの読解・発見内容の説明を難なくこなす

CARD 09

価格比較: 「かなり驚くべき」コスト差エージェントの命運を分けるのはキャッシュ読み取り

PRICING
モデル入力（100万トークン）出力（100万トークン）キャッシュ入力（100万トークン）
Sonnet 5.52.00ドル10.00ドル0.20ドル
Opus 5.54.00ドル20.00ドル—
DeepSeek V4.1 Flash（オフピーク）0.15ドル0.60ドル0.003ドル
DeepSeek V4.1 Flash（ピーク）0.30ドル1.20ドル—
  • オフピーク時、DeepSeekはSonnet比で入力約13倍・出力約17倍安く、キャッシュ入力は約67倍安い
  • Opus比較ならさらに差は2倍に広がる
  • エージェントはターンごとに同じコンテキストを再送信するため、トークンの大半がキャッシュ読み取り——まさにその点でDeepSeekが最大の差を生む
よもぎ
よもぎ:単価だけ見がちですが、エージェント作業の実コストはキャッシュ読み取り単価で決まると言っても過言ではありません。0.003ドルという数字はここで効いてきます。
CARD 10

具体試算: 2.17ドルの作業が16〜17セントに実際はさらに安くなる見込み

ESTIMATE
  • 全LeanREAベンチマークをSonnetで実行した際のコストは2.17ドル
  • 同じベンチマークをDeepSeekではまだ未実行・トークン使用量もモデルごとに異なるため、あくまで参考値と明示
  • 最も控えめな13倍の比率で計算してもわずか16〜17セント
  • 実際のアクセスの大半はキャッシュなので、実数値はさらに低くなるはず
  • 「タスク拒否」から「わずかな費用で遂行」へ——この差は驚異的

CARD 12

セットアップ②: dshのインストールとAPIキー登録検出は自動、キーはPCのキーチェーンに保存

SETUP 02
  • ターミナルでDeepSeekハーネスを導入——npm install -g @deepseek-ai/dsh
  • PandaCodeが自動的にdshを検出し、バックグラウンドで実行してくれる
  • DeepSeekのAPIキーはPandaCodeの設定「Providers」を開いて貼り付け
  • 環境変数DEEPSEEK_API_KEYとして設定することも可能
  • キーはPCのキーチェーンに保存され、DeepSeekとの通信にのみ使用される
$ npm install -g @deepseek-ai/dsh
$ npx skills add aicodeking/leanrea  # 全プロジェクトで使うなら -g を追加
# PandaCode 設定 → Providers → APIキー貼り付け
# または環境変数 DEEPSEEK_API_KEY を設定
よもぎ
よもぎ:コマンド2本＋キー登録で環境完成。ハーネスの検出は自動なので、手作業は実質これだけです。

CARD 14

実演タスク: 検索機能の仕組みを解明させる「証拠を見せて」の一言が効く

LIVE DEMO

依頼は「/leanrea このアプリの検索機能はどうやって動いているの？」に続けて「証拠を見せて」。エージェントは①ファイルの種類を確認 → ②app.asarを展開 → ③隠しフォルダも探索する-uuフラグ付きripgrepでコード検索 → ④ネイティブ関数・制御クラス・IPCチャンネルを特定 → ⑤各主張を「確認済み」「推論」「不明」に分類——という流れで進行します。

よもぎ
よもぎ:主張に確度ラベルを付けるのがLeanREA流。「言った」で終わらず証拠と推論を分けるのは、そのまま実務の品質チェックになります。
CARD 15

なぜ速い: チェックをバッチ処理小さな確認を1つのシェル呼び出しにまとめる

WHY FAST
  • スキルの指示により、小さなチェックを1つのシェル呼び出しにまとめてバッチ実行
  • 一度に大量のコマンドを実行するため、タスクが短時間で完了
  • PandaCode上で実行コマンド・触れたファイル・消費トークン数をすべて確認可能
  • API料金に基づくコスト概算も画面表示——推測する必要がない
CARD 16

正直な弱点①: 最賢モデルではない最難関タスクは依然Opus 5.5優位

CAUTION 01
  • DeepSeek V4.1 Flashは現時点で最も賢いモデルではないと明言
  • 非常に困難なタスクでは依然としてOpus 5.5が優秀
  • 深い分解作業が必要な場合はやり取りを増やすか、より細かい指示が必要になる可能性
  • 「安さ」と「賢さ」のトレードオフをあらかじめ割り切るのがこの構成の前提
CARD 17

正直な弱点②: 送信先と料金変動導入前に確認すべき2点

CAUTION 02
  • コードはDeepSeekのサーバーに送信される——企業の非公開プロジェクトでは、まず問題ないか確認を
  • ピーク／オフピークで料金が2倍変動（入力0.15→0.30ドル、出力0.60→1.20ドル）
  • 大きなジョブは料金が半額になるオフピーク時に実行するのが得策
  • 機密性・コストの2軸で、案件ごとに使い分けが現実的な運用
よもぎ
よもぎ:「安い」構成ほどデータの行き先の確認が重要です。公開リポジトリや個人プロジェクトから試すのが安全な入り方ですね。
CARD 18

よもぎの総評: 拒否されない、安い、十分賢い——現時点のベストプラクティスClaude Code / Codexと使い分けるのが答え

SUMMARY

チャンネル主の結論は「現時点で、この種の作業にはこれが最善」。LeanREAはコンテキストを無駄にせずモデルに適切な指示を与え、DeepSeek V4.1 Flashはそれを活かす十分な賢さを持ち、通常の解析作業を拒否せず、コストはSonnetやOpusのわずか数分の1。PandaCodeならコスト追跡からファイル変更の確認まで1ウィンドウで完結します。一方でClaude CodeやCodexも素晴らしいツールであり今も活用中——この構成は「置き換え」ではなく「逆エンジニアリング作業に特化した最適解」という位置づけです。機密性と最難関タスクの壁だけ踏まえれば、試す価値は十分にあります。

よもぎ
よもぎ:まずは自分の手元のアプリ1つで「検索機能はどう動く？」を試してみるのがおすすめ。証拠付きで返ってくるかを実感すれば、この構成の価値はすぐ分かります。
