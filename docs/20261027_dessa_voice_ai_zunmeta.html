BLOCK / 音声会話AI DESSA 研究プレビュー

文字も学習済みモデルも使わず、声だけで学んだ会話AI「Dessa」
——笑い・相槌・話の重なり。「人間っぽさ」の正体を ChatGPT の声・Gemini Live と聴き比べる

ジャック・ドーシー氏が率いる Block（スクエアやキャッシュアップの会社）が、会話AI「Dessa」を研究プレビューとして発表しました。最大の特徴は学び方——人の会話の声だけで一から学ばせ、文字も学習済みモデルも使っていません。声だけで学んでリアルな会話ができるAIは、知る限り世界初とされます。本動画（ずんめたラボ）の解説を、Dessa と ChatGPT の声・Gemini Live の比較、使える人の範囲、人に近い声ならではの注意点まで18枚のカードに整理します。

OVERVIEW

Dessaとは何か——Block が発表した「声だけ学習」の会話AI2026年10月・研究プレビューとして公開

Twitter の共同創業者ジャック・ドーシー氏が率いる Block（スクエアやキャッシュアップを展開する会社）が、社内の小さな研究所から会話AI「Dessa（デッサ）」を研究プレビューとして発表しました。最大の特徴は学び方で、文字も、学習済みのモデルも使わず、人の会話の声だけで一から学習。声だけで学んでリアルな会話ができるAIは、Block によれば知る限り世界初です。開発主体はトロントのAI会社出身者らによるBlock内の研究組織で、共同創業者のドーシー氏に直接報告する体制といいます。

WHY VOICE

なぜ「声だけ」で学ばせたのか——3つの理由好奇心・相互理解・安全

声だけで学ぶのは技術的にとても難しいにもかかわらず、Block は3つの理由を挙げています。

  • 好奇心：楽しいから、という純粋な動機
  • 相互理解：人とAIがもっと分かり合うため
  • 安全：声のAIが安全に使えるかを理解するため
よもぎ
よもぎ:研究の動機に「安全」が入っているのがポイント。人に近い声のAIほど、悪用面の検証が重要になります。
BABY ANALOGY

赤ちゃんに例える学習方法文字なしで話せるようになる人間の再現

Block は学習の考え方を赤ちゃんに例えています。ChatGPT のようなAIは大量の文字を読んで学びますが、赤ちゃんは一度も文字を読まずに聞くだけで話せるようになる——AIでも同じことができるか試したのです。結果、Dessa は文字ベースのAIと比べてごく少数の単語で会話できるようになりました。ただし同じ単語でも話すたびに声が少しずつ違い、音声データは文字よりずっと大きいなど、声で学ぶことの難しさにも触れています。

よもぎ
よもぎ:「少ない語で話す」という特性は、むしろ人間の発達に近い振る舞いとして注目されています。
SPEC

動かす環境——学習も推論も「1台」で完結クラウドを通さない手元動作

学習に使ったのはNVIDIA のAI向け大きな計算機（GB200 NVL72）1台。推論はM4 Max 以上の MacBook Proで動かせるとされ、会話の処理にクラウドを通さない構成です。手元の端末で動くことは、後述の「なりすまし」や「声の記録」といった安全性の話とも関わってきます。

HUMAN-LIKE 01

声を文字にしない——感情が落ちない皮肉・笑い声・ため息まで聞き取る

よくある音声AIは、まず声を文字に変換してから処理します。ところが文字にすると感情・皮肉・笑い声・ため息のような情報が落ちてしまう、と Block は説明します。「いいよ」も嬉しい「いいよ」としぶしぶの「いいよ」では文字にすると同じです。Dessa は声のまま聞いて、声のまま返すため、声に乗った感情をそのまま聞き取れるといいます。

よもぎ
よもぎ:文字化を挟まない設計そのものが「人間っぽさ」の土台。なるほどという差分です。
HUMAN-LIKE 02

聞きながら同時に話せるトランシーバー型ではない「重なり」のある会話

もう一つの特徴は聞きながら話せること。順番に交代するトランシーバー型ではなく、人の会話のように相槌や笑いで声が重なるやり取りができます。Dessa はいつ口を挟むか・いつ相槌を打つかを学習し、返事も待たせない速さ。相手が考えている途中で答えが始まることもあり、「人と話す時みたいに待ってほしい」という感想も出るほどです。

よもぎ
よもぎ:「待つ・被せる」の塩梅こそ人間らしさの核心。面白い側面と、慣れるまで違和感のある側面の両方があります。
DEMO

公式デモで聞けた「人間っぽい」振る舞い台本なし・Dessa 自身が何を言うかを選択

公式ページには人と Dessa の会話の録音が並び、台本はなく何をどう言うかは Dessa が選んでいるといいます。デモで確認できた振る舞いは次のとおり。ただしデモは英語の会話で、録音も Block が選んで載せたものである点には注意が必要です。

  • 話の途中ですぐ笑う：他のモデルは話し終わるのを待ってから笑うのに対し、Dessa は面白いと途中で笑う
  • 「大きな声で」と頼むと声が大きくなる：これは誰も教えていない振る舞い
  • 映画の題名を補う：相手が思い出せない題名を補って続きを言う
  • 人生相談で共感：本当に共感しているように聞こえる応答
よもぎ
よもぎ:「教えていないのに声が大きくなる」——声だけで学んだことの副産物として興味深い挙動です。
MISCONCEPTION

よくある誤解——「聞きながら話す」のは Dessa だけではないGPT-Live も同時話者可能。違いは「学び方」

ここで誤解を一つ解いておきます。聞きながら同時に話せるのは Dessa だけではありません。OpenAI の開発者向け資料でも、ChatGPT の声を動かすGPT-Live は聞きながら同時に話せるとされています。Block が公式ページに載せた Dessa と ChatGPT の声（GPT-Live-1）の会話録音では、ChatGPT 側も相手の話の途中で「OK」と相槌を重ね、言葉に詰まる間も見せました。つまり両者とも同時に話せる——本当の違いは「文字を使わず声だけで学んだこと」にあります。なお GPT-Live が内部で声を文字にするかは OpenAI の公開資料には書かれていません。

よもぎ
よもぎ:「同時会話＝Dessa独自」だと短絡しないのが、今週の賢い視点です。

A/B LISTEN

聴き比べの結果——同時に話せるAI同士でも相槌が違うBlock 公式録音「Dessa in conversation with GPT-Live-1」を引用

動画第3章では公式ページの録音から2か所（各10〜14秒）を引用して聴き比べました。Dessa 側は相談の答えが間髪入れず返るのに対し、ChatGPT の声（GPT-Live-1）は相手の話の途中でも「OK」と相槌を重ね、言葉に詰まる間も見せつつ、ここでは待つ場面もあった——同時に話せるAI同士でも、相槌のタイミングと味付けが違うのです。音は切り出しと音量調整のみで加工なし。どちらの声もAIが作ったものです。

よもぎ

STRENGTHS

Dessaの「得意」と、まだ分からないことすべて Block 自身の説明ベース

Dessa の話は〈得意なこと〉と〈ないこと〉に分けて聞くのがコツです。得意とされるのは声の感情を聞くことと手元で動くこと——どちらも Block 自身の説明です。一方で調べ物ができるかは書かれておらず、公式のデモ録音も Block が選んで載せたもの。私たちはまだ自分で話して試せない、という限定条件つきです。

よもぎ
よもぎ:「自社説明ベース」という但し書きを忘れずに。外の目での検証はこれからです。
AVAILABILITY

誰が使える？——今は少数の安全研究者のみ時期・料金・日本語対応はすべて未発表

公式ページでは、少数のAI安全の研究者に先に使ってもらい、想定していない危険を探してもらうとされています。研究者は大学や会社のメールで申し込む形式。一般向けには待機リストのボタンと「開始のリンクは近日」という表示だけで、時期も料金も日本語対応の可否も発表がない状態です（公式デモは英語）。日本のApp Storeに Block の Dessa アプリはなく、似た名前の別アプリがあるので入れ違いに注意です。

よもぎ
よもぎ:「近日」だけで時期が書かれていない——楽しみは持ちつつ、冷静に待つ回でした。
CAUTION

人に近い声のAIで気をつける3つのことなりすまし・頼りすぎ・声の記録

声が人間らしくなるほど、従来の文字AIとは違うリスクが浮上します。

  • 成りすまし：声だけでAIと気づきにくい。笑ったり相槌を打ったりされると、なおさら信じやすくなる
  • 頼りすぎ：人生相談デモのように共感して聞こえる相手は、つい頼りたくなる。大事な悩みは人にも話すこと
  • 声の記録：声には感情まで乗る。Gemini Live のヘルプには「録音の前に相手の許可を求める」とあり、Dessa は手元で動くとされるものの一般向けの条件は未発表。使えるようになったら記録の扱いを最初に確かめること
よもぎ
よもぎ:「優しく聞こえる相手」ほど境界が曖昧になる——電話詐欺対策と同じ構造です。
DEFENSE

お金の話が来たら「かけ直す」自然な声の成りすましへの具体的な防衛

なりすまし対策として、決まった動き方を家族で決めておくのが有効です。自然な声でお金の話が出たら、一度切って、自分が知っている番号にかけ直す。お金の話でなければ会話を楽しんで良いけれど、大事なことはその場で決めない——この3点セットを守るだけで、声の巧妙な詐欺への耐性が大きく上がります。

よもぎ
よもぎ:身近な人ほど「もしもの合言葉」を今のうちに共有しておくと安心です。
ACTION

今日からできる3つのこと待っている間に備える

Dessa が使えるようになるのを待つだけでなく、今できる備えが3つあります。

  • 会話の練習：今使える声のAI（ChatGPT／Gemini）で会話練習をし、Dessa の録音との相槌の違いを比べてみる
  • 電話ルールの共有：お金の電話はかけ直すと決めて、家族とも先に話しておく
  • 設定の確認：使っている声のAIの設定で、会話の記録の扱いを確かめる。Dessa が来ても同じように確かめる
よもぎ
よもぎ:「知る」で終わらせない3枚の宿題。どれも5分でできます。
WHICH ONE

自分はどれを選ぶ？——用途別の使い分け日本語・カメラ・リアリティの3軸

動画の結論を用途別に整理するとこうなります。

  • 日本語で今すぐ話す練習：ChatGPT か Gemini
  • カメラを見せながら話す：Gemini Live（日本語ヘルプにカメラで話す手順あり）
  • 声の細かい感じまで人に近いAI：Dessa——ただし使えるようになるまで待つしかない
よもぎ
よもぎ:「最先端を見たい」のか「今日使いたい」のかを分けて考えると混乱しません。

黒板でまとめ——持ち帰りの3行すごいのは学び方／日本ではまだ待つ／自然でも確かめる

よもぎ
よもぎ:「声が自然でも、話の中身は確かめる」——めたんさんの一言が今回全体の締めです。
TAKEAWAY

全体まとめ——人に近づく声AIと、変わらない原則便利さと警戒のバランスを手に入れる

Dessa は文字を使わず人の声だけで学んだ、まだ研究段階の会話AI。感情や相槌まで含めた「人間らしい会話」の研究最前線を示しつつ、聞きながら話す能力自体は ChatGPT の声（GPT-Live）にもあること、そして日本で今すぐ使えるのは ChatGPT と Gemini Liveであることが整理できました。両者はどちらも人に近づいていきます。近いからこそ、成りすましには「かけ直す」、大事な悩みは人にも話す、記録の扱いは最初に確認する——この3つの習慣が、これからの声AI時代の安全運転になります。
