GEMINI ENTERPRISE / 自分専用 AI エージェント

「AI を使う」から「AI と働く」へ
——MC野嶋のためだけのカスタムエージェント3種を、ノーコードの Workflow Builder で構築

グーグル・クラウド・ジャパン提供の番組「Gemini 企業活用 SKILL SET」第2弾。同社カスタマーエンジニアのスワッチ（諏訪悠紀）さんが、PIVOT のMC野嶋の業務ヒアリングをもとにテーマ調査／番組準備アシスタント／台本レビューの3つのカスタムエージェントを実際に構築。自然言語だけでワークフローを組める「Workflow Builder」や、スラッシュで呼び出す「スキル」まで、企業でのAI定着の処方箋を18枚のカードに整理します。

OVERVIEW

企業AIの最大の壁は「定着」——番組の題材と構成「AI を使うから AI と働くへ」を3部構成で掘り下げる

番組「Gemini 企業活用 SKILL SET」第2弾のテーマは「AI を使う」から「AI と働く」へ。前回は組織の働き方をどう変えるかというビッグテーマだったのに対し、今回は自分の業務にカスタムエージェントを作るところまで落とし込む実践編です。企業からの声で一番多いお困りごとは、ずばり「定着させることが難しい」こと。導入直後は試して「便利だね」で終わり、実際の業務で継続して使われない——この壁を乗り越える知見が詰まった回になっています。

ARCHITECTURE

Gemini Enterprise の全体像AIポータル×エージェント群×コネクタ

ユーザーがエージェントと会話する入口がAIポータル。そこから呼び出せるエージェント群には、Deep Research や Gemini ノートブックなどの標準機能に加え、パートナー製エージェントの購入、そして自作のカスタムエージェントという3系統があります。さらに下層のコネクタで Gmail・ドライブ・カレンダーなど Google の各種データを接続。「ココまではやっている」という人も、エージェント開発の段になると一気に減るといいます。

よもぎ
よもぎ:コネクタ活用までは「AI を使う」段階。今日の主戦場はその先の「自作エージェント」です。
MATURITY

定着度が上がる4段階のステップチャット → プロンプト → スキル → エージェント

活用の深度は〈チャットで質問〉→〈プロンプトをカスタマイズ〉→〈スキル〉→〈エージェント〉の順で進化します。スキルは繰り返しやる手順を固めたもの、エージェントはワークフローも含めて業務に合わせた専用の働き手。一歩先に進むほど定着度は上がっていきます。

PAIN POINTS

MC野嶋の仕事の実態——「AI で楽になってません」事前ヒアリング（約30分）で洗い出した3つの課題

番組企画・収録・編集を並行して回す野嶋さんの業務をヒアリングすると、AI 時代ならではの悩みが浮かび上がります。共通するのは「AI のせいで情報と判断の量が増えただけ」という構図。判断を AI に任せ、仕事を最後まで終わらせてほしい——これが今回の要望の核心です。

  • リサーチ過多：調査は楽になったが情報が多すぎて、何が重要かの精査がむしろ大変になった
  • 資産の迷子：ドライブの整理が追いつかずファイル名もバラバラ。過去にやった仕事をまたゼロからやり直す「不毛な時間」が発生
  • 収録中の空白：収録中はPCを使えず、2〜3時間後にはメールが50件溜まっている。企画は常に7件弱が並行で、優先順位の管理で頭がパンク気味
よもぎ
よもぎ:「AI を入れたのに忙しくなった」のは野嶋さんだけじゃない。業務フローの可視化がエージェント設計の第一歩です。
DESIGN

課題に当てた3つのカスタムエージェントテーマ調査／番組準備アシスタント／台本レビュー

ヒアリングした業務フローのうち課題が集中する箇所に絞って、3つのエージェントを構築。いずれも〈予見整理・調査・情報収集〉→〈企画・設計〉→〈レビュー・仕上げ〉という業務フローの骨格は、営業・マーケ・コンテンツ制作など職種を問わず共通です。野嶋さんいわく「ワークフローのブレイクダウンが一番難しい」ので、この分割の仕方こそがスクショ推奨の参考になります。

AGENT 01

テーマ調査エージェント実演「来週のFOMCについて企画を考えたい」→数分で完了

何も考えていない状態で投げた雑な依頼に対し、エージェントは数分で調査を完了。来週の予定の要点まとめに加え、3つの切り口候補（金融政策の読み解き方／住宅ローン・変動金利の防衛ライン／雇用と名目中立金利の衝撃）を立案してくれました。

よもぎ
よもぎ:切り口ゼロの状態から3案まとめてくるのは企画職にとって大きい味方です。エンターを押して収録に出かけている間に処理が終わります。
GROUNDING

過去500本弱の動画で「私風」を再現過去回との紐付けも自動で

事前に PIVOT の過去動画データを Gemini Enterprise にグラウンディング。「経済指標の読み方」「日銀レジーム転換」など野嶋さんが過去に扱った回との関連を提示し、切り口ごとの結びつきまで示してくれます。野嶋さん自身も言語化できていない文体の癖を、データさえあれば再現できてしまうとのこと。

よもぎ
よもぎ:「私風に」の依頼が一番難しいのに、過去資産を渡せばクリアできてしまうのが地味に衝撃ポイント。
FACT CHECK

ファクトチェックまで一人で完結「確認済み／要再チェック／報道記事のため未確認」を区別

出力内の事実確認は一次情報の確認済み／再度チェックが必要／報道記事のため未確認にきれいに分類されます。通常のシンプルなエージェントだと「ここどうなの？」と毎回深掘りする必要がありましたが、チェック基準を最初に組み込んでおけるのがカスタムエージェントの利点。確認の手間が繰り返し発生しません。

よもぎ
よもぎ:報道記事をそのまま「確認済み」と出すAIに悩まされてきた人こそ旨味がある設計です。
VISUAL

サムネ案・インフォグラフィック・グラフまで一発出力画像生成モデル（ナノバナナ）との連携

調査で組み上がった文脈をもとに、サムネイル案や分かりやすいインフォグラフィック、グラフ類まで生成。日本語が含まれる図を綺麗に出せるのが画像生成モデルの強みで、野嶋さんは「テレビで見たことがあるクオリティ」「ここまで行ける」と驚きました。処理は1件だけではなく寝ている間などに複数並行で回せるとのこと。

よもぎ
よもぎ:調査→図解→サムネまでを一つのワークフローに閉じ込めた点が「仕事を終わらせる」感の正体です。
CONNECTOR

コネクタで自社データを接続——「何でもいけます」Gmailや営業ツール、自社開発システムまで

リマインドのメール通知でも触れた通り、Slack・Outlook など繋がっているものなら基本的に何でも接続可能。自社で開発したシステムとも連携できます。例えば過去のメール内容を全部グラウンディングしたり、営業ツールと繋いで調査させるなど、コネクタ経由のデータ活用は自由にカスタマイズできます。接続先が増えるほど、より社内事情に即したアウトプットが作れます。

よもぎ
よもぎ:アクセスできるデータが増えるほどエージェントの解像度が上がる——社内導入の説得材料にもなるポイントです。
HOW IT WORKS

テーマ調査エージェントの中身——裏側は4つの工程依頼理解 → 情報収集 → 切り口設計 → 資料化

1発でここまで出せている裏側では、大きく4つの処理が回っていました。

  • ① 依頼を理解する：リクエストから何を調査すべきかを整理
  • ② 情報を集めて確かめる：一般情報のグラウンディングに加え、Gemini Enterprise 内のデータも収集して事実確認
  • ③ 切り口を設計する：明確に異なる3つの方針を立案し、調査報告書としてまとめて要点メモ化。過去回との結びつきも提示
  • ④ 伝わる資料を制作する：長文を読ませるのではなく、図を先に出して一発で分かる形に。日本語で綺麗に出せる点がポイント
よもぎ
よもぎ:「Deep Research ＋ 野嶋の知識」を超えて台本やサムネまで落とし込むには？——次のエージェントへの引き継ぎが鍵です。
AGENT 02

番組準備アシスタント——企画から質問リスト・タイトル案まで人間に「どれで行く？」を聞いてくる設計

切り口3案のどれで進めるか、生成の途中で実際に野嶋さんへ質問が飛んでくる設計になっています。「B（住宅ローン）で」と答えると、数分で番組の設計図が出力されました。選ばれたのは30代向けの変動金利・ローン回。マクロな金融政策を実生活の防衛ラインにつなげる構成です。ロジック・レビューのメモには「なぜこの順番で話すべきか、何が確認済みで何が未確認か」が残ります。

  • 質問リスト：PIVOT 1回あたりの大きな質問7問程度と同じ粒度で、導入→展開→金利→反論→リスク→家計の対処、と自動生成
  • タイトル案：過去番組のタイトルの口調やフォーマットを意識して10案を生成（普段1時間かかる作業が収録前に終わる）
  • 点検：ファクトチェックの確認、要注意表現・コンプラ上の配慮、インフォグラフィック設計案まで同時に出力
  • 完了のリマインド：処理終了はメールで通知。チャットが下に流れて忘れる「あるある」を防止
よもぎ
よもぎ:音声や動画など形式的になっていない情報からも番組の作り方を読み取っている、という指摘も興味深いところ。
NO-CODE

Workflow Builder——プログラムのコードが一切出てこない手順を1つずつ組み立てるノーコード構築

これらのエージェントは Gemini Enterprise のWorkflow Builderで作られています。画面には日本語のステップ名だけが並び、コードは一切出てこないシンプルな構成。各ステップの裏側で AI が動き、結果を次のステップへ引き継ぎながらワークフローを組み上げます。「ここで止まってユーザーに確認する」という確認タイミングも明示的に設定可能です。

よもぎ
よもぎ:自律的に進ませる部分と絶対に確認させたい部分を切り分ける——エージェント運用の肝そのものです。
AUTO BUILD

自然言語でワークフローを自動構築「作りたいものを伝えたら勝手に作ってくれた」

ステップを1つずつ手で組むのはまだテクニックが必要。そこで今回使われたのが、自然言語でリクエストすると Gemini Enterprise が自分で考えながらワークフローを組んでくれる機能です。実際の構築もこの方式で行われ、「それなら私でもできそうです」と野嶋さん。非エンジニアの参入障壁を大きく下げる機能です。

よもぎ
よもぎ:「作りたいものを伝えるだけで良い」——これが今回いちばん実用的な技かもしれません。
AGENT 03

台本レビューエージェント——星で総合判定、スマホでも動くルール違反の指摘から用語メモ参照まで

3つ目は「謝ったことを言えない」メディアの命綱となるレビュー担当。総合判定を星で表示し、番組冒頭の表記ルールへの違反や、用語メモのデータを参照した「間違っています」といった指摘まで出します。収録中でもスマホから使えるため、出先での確認にも対応。台本レビューのサブエージェントとして〈視聴者代表／プロデューサー／過去の自分／デスク／法務〉といった観点がぶら下がる構成です。

よもぎ
よもぎ:提案書レビュー・マーケティング企画・送信前メールなど、職種を問わず横展開できる形が見えます。
SELF EDIT

エージェントも自然言語で修正できる2行の指示で「編集者」観点を追加

足りないと感じた編集者の視点（どこで切るか・チャンクの作り方・編集点の付け方）を加えるデモも。3点メニューから編集画面を開き、変更リクエスト欄に「視聴者代表などと並列で編集者ボックスを作ってほしい」と2行ほど書くだけ。数分で新しい観点のボックスが真横に生成され、中のプロンプト（カット箇所・テロップの入れ所まで）も AI が自動で書いてくれました。

よもぎ
よもぎ:既存の構成を全体として理解した上で追加してくれる——保守性の高さが長期運用に効きます。
SKILL

軽い繰り返しは「スキル」で——スラッシュで即起動過去番組ルックアップの実演

依頼内容が固まっていない軽い作業には、スキルという簡易仕組みが用意されています。作ってもらったのは過去番組を調べるルックアップ。チャットでスラッシュを打つとスキル一覧が出て、選択して「今まで収録したAIの動画をまとめて。直近だけでいいよ」と聞くだけ。直近の企画トレンドまでまとめて返ってきました。コネクタを開いて設定するような手順なしで気軽に使えます。

よもぎ
よもぎ:エージェント＝業務全体を任せる、スキル＝繰り返しを軽く叩く。この使い分けが定着のコツです。
GOVERNANCE

ガバナンスも Gemini Enterprise の傘の中で決裁の議論だけで終わらせない

「リスクが心配で使えなかった」という組織向けの答えも用意されています。Gemini Enterprise の機能として、既存の権限管理・ID管理・会社が許可した範囲のみの参照・利用状況の把握が可能で、各種ポリシーを企業ごとにカスタマイズしながらガバナンスを全社で効かせられます。新人研修で権限を段階的に与えてきたのと同じようにAI にも権限を設計すれば、本当の意味での同僚として働ける——そう野嶋さんはまとめました。

よもぎ:AI を道具として少し業務改善するのではなく、同僚として迎え入れて業務を1から再設計する——今回一番大きいメッセージです。
