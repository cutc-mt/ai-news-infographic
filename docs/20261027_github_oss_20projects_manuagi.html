VoxCPM: トークナイザー不要の多言語音声合成テキスト記述で音声をデザインし、参照クリップからクローンも

TEXT-TO-SPEECH github.com/OpenBMB/VoxCPM

拡散自己回帰設計を用いてトークナイザーなしで音声を生成する、オープンソースのPython音声合成モデルです。

  • 30言語をサポートし、48kHzの音声を出力
  • テキスト記述による音声デザインと、リファレンスクリップからのクローンに対応
  • Python API・CLI・Webデモ経由でGPU上でローカル実行
  • 音声アプリ開発者に最適。なりすまし・詐欺目的は禁止
編集部
pipでインストールしてすぐ生成できる手軽さが魅力。多言語対応の音声アプリを開発する人の第一候補になります。
CARD 03

android/skills: コーディングエージェント向けAndroid公式ガイダンスskill.mdファイルでベストプラクティスをエージェントに届ける

AGENT SKILLS github.com/android/skills

特定のAndroidワークフローでLLMのパフォーマンスが低下する問題を、公式ガイダンスを記載したskill.mdファイルの提供で解決する、モジュール式の命令ライブラリです。

  • Android CLI、またはClaude CodeやCodexのプラグインとしてスキルをインストール
  • インストール後はエージェントが自動的にスキルを有効化
  • 例:「アプリをエッジ・トゥ・エッジ対応に」と指示するだけで公式手順に従う
編集部
「公式がエージェント用の教科書を出す」時代の到来です。Android開発でコーディングエージェントを使う人には必須級。
CARD 04

Cursor plugins: 公式プラグイン・マーケットプレイススキル・ルール・MCPサーバー定義を独立ディレクトリでパッケージ化

AGENT PLUGINS github.com/cursor/plugins
  • Cursorのコーディングエージェントを拡張する公式プラグインの仕様とリポジトリ
  • スキル・ルール・MCPサーバーの定義を、それぞれ独自マニフェストを持つ独立したディレクトリにパッケージ化
  • コードレビューや並列エージェントなどのワークフローをカバー
  • GitHub・Playwright・Gmail・Salesforceなどとの統合プラグインも用意
編集部
Cursorをカスタマイズしたい人・独自プラグインを作りたい人の出発点。ディレクトリを眺めるとできることが見えてきます。
CARD 05

hindsight: 想い出すだけでなく学習するエージェントメモリ保持（retain）・想起（recall）・内省（reflect）の3操作

AGENT MEMORY github.com/vectorize-io/hindsight

過去のチャットを思い出すだけでなく、エージェントが時間をかけて学習できるようにするオープンソースのメモリシステムです。

  • 保持=事実を保存、想起=検索、内省=事実について推論
  • Docker・pip、またはKubernetes＋Postgresでセルフホスト可能
  • SDK・MCP・LLMラッパー経由で多くのLLM/コーディングエージェントに接続
  • 長期間稼働するエージェントの構築に適する
編集部
「内省」があるのがポイント。溜めた記憶をLLM自身に推論させる一段上のメモリです。
CARD 06

Hy-Memory: チャット・作業・コーディングの3系統を担ぐデュアルシステムメモリTencent混元発。事実・経験・コード差分の進化チェーン

AGENT MEMORY github.com/Tencent-Hunyuan/Hy-Memory

LLMエージェントに長期記憶を与えるPython SDK兼エンジン。チャットの記憶は事実・要約・スキーマの階層に整理し、コーディングや作業タスクには事実と経験の2層メモリを提供します。

  • コードの実際の差分とエージェントの要約を保存するバージョン進化チェーンで情報の損失を防止
  • ベクトル: ChromaDB / Qdrant / Faiss。グラフ: Kuzu / Neo4j
  • OpenAI互換のあらゆるLLMに接続可能
  • コンパニオンアプリ「MemHub」がClaude Code・Cursor・Codex間でメモリをローカル統合
編集部
hindsightと合わせて読むと「エージェントメモリの今」がわかる1週間でした。
CARD 07

PageIndex: ベクトル不要の推論ベースRAGドキュメントツリーをLLMが推論して関連セクションを発見

RAG github.com/VectifyAI/PageIndex

階層的なツリーインデックスを構築し、LLMがそのツリーを推論して関連セクションを見つける、オープンソースのPython SDK。ベクトルデータベースもチャンク化も不要で、長く複雑なドキュメントに対する類似検索の限界を解決します。

  • 自分のLLMキーでローカル実行
  • スキャンされたドキュメント向けに「PageIndexクラウド」も用意
  • レポートや公的書類のドキュメント質問応答構築に適する
編集部
「埋め込みを作らなくていいRAG」という割り切りが新鮮。ドキュメント構造がしっかりした資料ほど効きそうです。
CARD 08

yomado: Mac上にエージェント専用の仮想画面スクリーンショットを読み、マウスとキーボードで直接操作

COMPUTER USE github.com/chekusu/yomado

ビジュアル・コンピューターユース向けに仮想ディスプレイを作るネイティブmacOSアプリ。ダミープラグや有料ディスプレイユーティリティ不要で、アプリのウィンドウを自分の画面とは別の名前付き仮想画面にドラッグできます。

  • 付属スキルでコンピューター使用エージェントが仮想画面を自動作成・命名・管理
  • Appleシリコン対応。人間が承認する必要のある時間制限付きリースでマウス/キーボード制御を要求
  • MCP統合のないBlenderなどのアプリでビジュアルAIエージェントを動かすのに最適
編集部
「エージェントに専用デスクトップを与える」という発想が秀逸。自分の作業画面を荒らされません。
CARD 09

EAGLE-4: あらゆるハードウェアでLLM推論を加速するドラフター投機的デコーディングでターゲットモデルと同一の出力を維持

INFERENCE github.com/eagle-hq/EAGLE-4

投機的デコーディングによるLLM高速化の推論コード。固定のドラフト戦略と変化するハードウェアの不整合を解決します。

  • セットアップ時のコストを測定し、バッチサイズやワークロードごとに最適な推論範囲を適応
  • EAGLEハーネスはSGLang・vLLM・TokenSpeedに組み込み可能
  • 生成速度を上げたいLLM提供チームに最適
編集部
「同一の出力のまま速くする」のが投機的デコーディングの約束。クイックスタートから初回デプロイまで試せます。
CARD 10

ElyOffice: Rustでネイティブ構築されたオフライン・オフィススイートアカウント不要・クラウド不要。ファイルはローカルフォルダーに保存

OFFLINE OFFICE github.com/ELY-Open-Source/ElyOffice

RustとGPUIで構築されたオフラインファーストのデスクトップアプリスイートです。クラウド依存のオフィスソフトの問題を解決します。

  • 同梱: ワープロ・スプレッドシート・プレゼン・PDFエディタ・Gitクライアント・Markdownエディタ
  • LibreOfficeKit・MuPDF・Tesseractを活用
  • 現在はmacOSでビルド可能。Linux・Windows向けパッケージ化が進行中
  • プライバシー重視のローカルオフィス環境を求めるユーザーに最適
編集部
今週の目玉:「文書をクラウドに預けない」という選択肢を本気で作っているプロジェクト。オフィス機能にGitクライアントが入っているのも面白い。
CARD 11

pandacode: すべてのコーディングエージェントを並行実行するネイティブ・ハブClaude Code・Codex・GitHub Copilot CLIなどを1つのウィンドウで

AGENT WORKSPACE github.com/aicodeking/pandacode

コーディングCLIをプロジェクト・Git・ターミナル・ブラウザと共に1つのウィンドウで実行できる、無料のオープンソース・デスクトップワークスペースです。ツールを使い分ける際の断片化を解決します。

  • 各タスクに共有ボード・ワークツリー・承認プロンプトを提供
  • アーキテクトが複数のワーカーエージェントを調整することも可能
  • データはSQLiteでローカル保存。テレメトリ不要・アカウント登録不要
  • エージェントはローカルVMやクラウドサンドボックスでも実行
編集部
「エージェントを使い分ける」から「エージェントを並べる」へ。複数CLIを日常使いする人には待望の統合環境です。
CARD 12

pele ＋ ondine: Mermaid図を軽くする2つのアプローチ実行時レンダリング（pele）とビルド時コンパイル（ondine）

DIAGRAMS github.com/obsidianmd/pele ／ github.com/wevm/ondine
  • pele: MermaidダイアグラムをSVGにレンダリングする小型で高速なJSライブラリ。軽量・同期処理可能・実行時依存関係ゼロ。Mermaid 12.1.0の全ダイアグラムタイプ対応。NPM/CDNから導入し、CSS変数でテーマ設定
  • ondine: Mermaid構文をブラウザで描くのではなくビルド時にSVGへ変換するRustコンパイラ。ランタイムはわずか210バイト
  • ondineはViteプラグイン・CLI・Nodeコンパイラ・MDX remarkプラグイン・WASMとして利用可能
  • どちらもドキュメント/ウェブアプリに図を埋め込んで軽量・高速化したい開発者向け
編集部
同じ「Mermaidを軽くしたい」という問題への2解。実行時派かビルド時派か、好みで選べます。
CARD 13

Snitch ＋ net-merge: 通信を見える化し、回線を束ねるネットワークまわりの「診断」と「高速化」のペア

NETWORK github.com/aixisstudio/Snitch ／ github.com/rohit267/net-merge
  • Snitch: PCのすべての通信をライブのノードグラフと世界地図で表示するクロスプラットフォーム可視化ツール。ポートスキャンやビーコニングのような異常を検知し、各接続の元となるアプリを特定。libpcapでローカルキャプチャ、履歴はSQLite、デフォルトでオフラインのジオロケーションで外部呼び出しゼロ
  • net-merge: Go製の無料アプリ。Wi-Fi・イーサネット・USBテザリング・スマホ回線を同時に使い分散。TUN/wintunでWindows・macOS・Linux対応。アカウント・プロキシ・サーバー構築は不要で、ダウンロードやゲームが合計速度の恩恵を受ける
編集部
「何が通信しているか知りたい」ならSnitch、「回線をもっと速くしたい」ならnet-merge。1行スクリプトで入る手軽さも共通。
CARD 14

zero-breach ＋ tv-detox: 端末の「診断」と「軽量化」広告経由スパイウェアの検出と、古いAndroid TVのデトックス

SECURITY github.com/interplains/zero-breach ／ github.com/Ansub/tv-detox
  • zero-breach: AdFactionやCandyRuといったスパイウェアキャンペーンの痕跡を検出する読み取り専用のPythonスキャナー。ブラウザ履歴・キャッシュ・自動起動・ファイル指紋を338個の公開指標と照合。管理者権限不要・オフライン動作で、結果はSTIX/MISPフィードやDNSブロックリストに出力
  • tv-detox: 30MBのAndroid TVホーム画面＋Claude Code/CodexのADB経由クリーンアッププロンプトの組み合わせ。エージェントが無効化しても安全なブロートウェアを特定し、広告行をオフに。アプリは削除せずundo.shで全復元可能
編集部
セキュリティ研究者向けの本格ツールと、古いテレビの悩みをAIエージェントで解く実用ツール。守る対象は違っても思想は「読み取り専用・元に戻せる」。
CARD 15

ra-jit: Rustコードをミリ秒でホットリロードCargoの約169msに対し、スワップは約7ms（1ファイル編集の測定例）

DEV SPEED github.com/indexable-inc/ra-jit

rust-analyzerをフロントエンド、Craneliftをコード生成器とする実験的なホットリロードツール。LLVMやリンカーを一切経由しません。

  • rust-analyzerのMIRを即座にマシンコードへ変換
  • 変更があった関数のみを再コンパイルし、関数スロットを再割り当て
  • 状態はホストプロセス内に保持され、スワップのたびに引き継ぎ
  • 現時点で対応はRustのごく一部の機能のみ（実験段階）
編集部
速いイテレーションに飢えたRust開発者へ。Nixで実行し、デモを編集してホットスワップを体感できます。
CARD 16

open-screen-sharing: Appleの画面共有プロトコルを改良iPhone・iPadもVNCサーバー化できる、より良いクライアント/サーバー

APPLE / VNC github.com/nekohasekai/open-screen-sharing

macOSの画面共有やVNCで使われる非公開プロトコルに対し、より優れたサーバーとクライアントを構築するプロジェクトです。

  • Apple純正アプリの制限を解消。ローカル/パブリックネットワーク向けに最適化
  • Tailscale経由でのスムーズな動作や言語切り替え問題の修正を含む
  • iOSのデベロッパーデバッグプロトコル経由でiPhone/iPadをVNCサーバー化し、macOSネイティブアプリから接続可能
編集部
リモート作業の快適さを追い求めたAppleユーザー向けの一押し。
CARD 17

earshot ＋ ascii-sharks: エージェントに「耳」を、ページに「サメ」をCPUだけの音響ツールキットと、遊び心のASCIIアート

AUDIO & FUN github.com/Leonxlnx/earshot ／ github.com/stackedlol/ascii-sharks
  • earshot: CPUのみで動作するオープンソースのツールキット。AIエージェントが音声を聴いて反応できるようにする。ファイルの音の説明、記述との照合、録音からベスト瞬間の発見、プロの動画との音響デザイン比較、コードだけで音を合成して聴きながら調整、録音の編集可能なコードレシピ化に対応。CLI・Python API・Claude Code用MCPサーバーとして動作
  • ascii-sharks: HTMLキャンバス上でASCII文字のサメや魚が泳ぐ依存関係ゼロのTypeScriptライブラリ。「オーシャンエンジン」クラスにキャンバスと生物リストを渡すだけ。画像やアニメーションライブラリを使わず、テキスト文字として直接描画し、遊び心ある視覚アクセントを追加
編集部
「AIが音を聴く」時代の道具と、1分で試せるネタ枠。どちらも開発の息抜きに最適です。
