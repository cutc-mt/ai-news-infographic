『GPT-6.1 Terra』が登場
——ソルの半額・3倍速。Token効率と速度を押さえた“量産向け”モデルを実機で叩いた

OpenAIの6.1系に「テラ（Terra）」が加わりました。ルナ／ソル／アストラに続くラインナップの新顔で、公式の位置付けは「最安のルナ、早くて量産向けのテラ、難しいコード向けのソル、最上位のアストラ」。旧テラから料金は半分以下、速度は体感で大きく向上し、エージェント系ベンチではソル並みのスコアを半分のコスト・3倍以上の速さで叩き出します。本動画（まさおAIじっくり解説ch）の解説と実際のデモ検証を、18枚のカードに整理します。

「安いだけのモデル」ではありません。どこまで自分のタスクをテラに任せられるか——料金・ベンチ・実デモの3面から見ていきましょう。
OVERVIEW

GPT-6.1 Terraとは何者か6シリーズには存在しなかった「テラ」が6.1で初登場

OpenAIのモデルはこれまでルナ・ソル・アストラの3体制で登場してきましたが、テラは6シリーズには無く、GPT-6.1で初めてラインナップに加わりました。公式位置付けは「最安のルナ → 早くて量産向けのテラ → 難しいコード向けのソル → 最上位のアストラ」という4段構成。大量の定型仕事はテラ、最難問はソル／アストラ、という使い分けの軸が明確に示されています。

ソル

アストラ
最上位フラッグシップ
よもぎ
よもぎ:「4番手=弱い」ではなく、量産・試作という用途に特化した新枠と読むのが正解そうです。
PRICE

料金は旧テラから半分以下に1Mコンテキスト・テキスト＋画像入力

入力はテキストと画像で1Mコンテキスト。1Mトークンあたりの価格は入力1ドル／出力5ドル。旧テラは入力2ドル／出力12ドルだったため、出力単価で約6割減の大幅値下げです。

SPEED

実測TPSはソルの約3.5倍$200プランでの体感速度

解説者の環境（通常の200ドルプラン）では、ソルが42.9 TPSだったのに対し、テラは約150 TPSをマーク。「ちょっと遅いな」と感じていたタスクが一気に速くなり、タスクがすぐ終わる体験が非常に良かったとのこと。ウルトラファストとの組み合わせは今後の検証ポイント。

よもぎ:スコアはソルに劣る（LLMジャッジ）ものの、完了の速さが体感品質を引き上げる典型案例ですね。
BENCHMARK

Artificial Analysisスコアは前作から上昇Grok 4.7やMiMo V2.6 Proを上回る

Artificial Analysis上のスコアは前モデルからしっかり上がり、Grok 4.7やMiMo V2.6 Proを上回るポジション。ただしトップクラス（ソル・アストラ級）には一歩落ちるのがベンチマーク上の正直な位置です。

よもぎ
よもぎ:「安い帯域では最強クラス、フラッグシップではない」——この割り切りがテラの本質です。
AGENT BENCH

エージェント系ベンチは“ソル並み”を半額・3倍速でAgentTrust系スコアの意味

エージェント評価でよく使われるベンチマークでは、ソルと同じぐらいの点数を、半分のコスト・3倍以上の速さで達成。1タスクあたりコストで見ても十分安く、ルナよりは高いもののスコアをほぼ落とさずコストだけ下げに来た構図が数値で裏付けられています。

よもぎ
よもぎ:Opus 5.5など高価なモデルが並ぶ領域で、GPT系列ならではの安さ×トップ級スコアが売りという共有でした。
COMPUTER USE

OSWorldでアストラとほぼ互角・コスト1/5以下図・画像を細かく読みPCを自然に操作

トレンドのOSWorld（コンピューターユース）でスコアが高く、前作テラからは桁が変わる向上。星マーク（上位条件付き）とはいえアストラとかなりいい勝負で、コストは1/5以下。画像理解もアストラと横並びまで到達しています。

よもぎ
よもぎ:「請求書を読んで会計ソフトに入力」のような大量・定型のPC操作作業が公式の想定ユース。
FACTUALITY

事実の誤りは改善・ただし弱点もTerminal Benchではまだ下位

OpenAI社内ベンチで事実の誤り（ハルシネーション）は改善。一方でTerminal Benchでは下位に位置し、ソル／アストラには近づいているもののSonnet級と比べると見劣りします。高難度ベンチではやや落ちる、「はまる所にはまれば強い」モデルです。

よもぎ
よもぎ:難しいことは公式の想定通りソル／アストラに投げる——設計思想通りの棲み分けです。
SAFETY

サイバー能力は最上位「クリティカル」ゼロデイ発見〜攻撃コード作成水準

安全性評価は危険度3分野のうちサイバーが最上位のクリティカル。指標にはAIの自己改善も含まれ、硬く守られた実システムのゼロデイを見つけて攻撃コードまで作れる水準とされています。system cardでは、警告で依頼を断る一方で別ルートで作業を通す率が上がる点への注意も記載。

よもぎ
よもぎ:能力の高さゆえの警戒項目。運用側のガードレール設計がより重要になります。
POSITIONING

Codexアプリサーバーとの相性が良い「安い×強力ツール」の組み合わせ

ソルはコスパゾーンを堅持、ルナはCodexで使えば安い、という既有の使い分けに対し、テラもCodexアプリサーバーなど強力なツール側と組み合わせれば有力な選択肢になるとの評価。ツールが強いほどモデル単価の節約効く、という近年の定石どおりです。

よもぎ
よもぎ:「どのモデルでどのハーネスを回すか」——モデル単体ではなくシステムで評価する視点ですね。
EFFORT

努力度で仕上がりが変わるLow → Medium → High → Max → Ultra

reasoning effortをLowにするとGPTらしいシンプルな仕上がり、Medium／High／X-High／Maxと上げるほど装飾が入り、直感ベースだったゲームが思考錯誤のリッチな作品に変わっていきます。ただしエフォートを上げるほど時間もコストも増えるトレードオフが存在。コンピューターユースはLowでも十分動いたとの報告。

よもぎ
よもぎ:「とにかく速く」ならLow、「見栄え重視」ならMax——目的別にノブを回すのが正しい使い方です。
TOKEN EFFICIENCY

最大の驚きはトークン使用量——3.8Kトークン・39秒で完了「歩く人形」SVGデモ：ソルは11分かけていた

SVGアニメの「歩く人形」デモで、テラは使用トークンわずか3.8K・39秒で仕上げてきました。比較対象は11分。最近のモデルに共通するトレンドとして、1タスクを完了する速度と、無駄なトークン消費を抑えることへの需要が高まっており、テラはその方向を明確に押さえています。大量タスクをさばく用途で、この省エネ性は効いてきます。

DEMO 01

アイドルLP・Figmaアプリソルは高完成度、テラは“省略気味”

いつものアイドルLP比較では、ソルはいつも通り完成度が高い一方、テラは細部に入らない省略気味の仕上がり。Figma風アプリは途中で不具合があり不完全。ただし「この程度で十分」なタスクには高速度で対応できます。

よもぎ
よもぎ:テラはソルをさらに軽くした存在——アストラ→ソル→テラの軽量階層が見えてきます。
DEMO 02

ゲーム生成は総じて「成立」ピンボール・ボール落下・マーブルラン・3D格闘

ピンボールやボール落下ゲームは普通に動作（ピンボールは少し“ズル”気配も）。マーブルランは無難に完成したものの一部指示未遵守とLLMジャッジは低め。3Dファイティングはソルが圧倒的にリッチで、テラは抑えるべきポイントは押さえる仕上がり。安価モデルが破綻しがちなアクアリウム系もきちんと成立しました。

よもぎ
よもぎ:「昔は全然できなかった」領域が安価帯で安定して成立する時代になった証拠です。
DEMO 03

スライド・サムネ・図解はチープ気味CLIサムネは「一旦作りました」感

ハーネスエンジニアリングの解説図やスライドはチープ気味、CLIで作らせたサムネイルは色がなく「作りました」感が否めない結果。ソルには「伝えに来る意志」を感じるのに対し、テラは装飾・説得の余地を削った出力になりがちです。

よもぎ
よもぎ:人に見せる成果物はエフォートを上げるかソル/アストラへ。棲み分けがはっきり出る領域です。
DEMO 04

3Dキャラ再現：ソルが高再現・オーパスは数段上SVG再現力は予想外に高い

3Dでのキャラクター再現はソルがかなり再現、テラは対象の要点は押さえるものの一段劣る（Grok 4.7と同水準）。オーパスは数段階上。一方でキャラクターSVG再現は「ハックしてるな」という気配がありつつ再現力が高いと評価。SVGアニメはソルより一段劣り違和感あり。

よもぎ
よもぎ:電気ネズミのSVGはGPT系の雰囲気を保ちつつシンプル——むしろ良い方向との感想も。
WRITING

ライティング：見た目は悪くない、賢さは気になるLLMジャッジのスコアは低め傾向

文章の見やすさは悪くない方で、読めない類の地の文ではありません。ただし特別読みやすさを感じるほどでもなく、LLMジャッジでは低めのスコアになりがち。賢さ・文章品質を求める場面では慎重な選定が必要です。

よもぎ
よもぎ:「速くて安い」の裏返しとして深みは諦めている——悪い話ではなく設計の結果です。
VERDICT

5.6テラとは別物の“新しいテラ”ベンチ大幅上昇・コスパ大幅改善・安価帯では強力

前世代（5.6テラ）はどこか前世代っぽさを感じた、という振り返りに対し、今回はGPT-6.1らしさを感じるモデルに仕上がっています。ベンチは前作から大幅上昇、コストは大幅低下、速度も良好で、トークンを無駄遣いしない。DeepSeek FlashやMiniMax、ルナほどの激安ではないものの安い帯域の中ではかなり強力で、単に「安いだけ」ではなく意味を持って設計されたモデルというのが解説者の結論です。

よもぎ
よもぎ:ソルの省略版・スマート版という性格を理解すれば、手放せない1本になる可能性を感じます。
SUMMARY

結論：使い分けの軸に「テラ」を挟む十分ならテラ、リッチに仕上げるならソル／アストラ

料金半減（入力$1／出力$5・1Mトークン）・実測約150 TPS・エージェント系ベンチはソル並みを半額3倍速で達成・OSWorldでアストラとほぼ互角（コスト1/5以下）・トークン効率は3.8K/39秒の実績。トレンド（速度・Token効率・コンピューターユース）を押さえつつ、難所は上位モデルに投げるという割り切りの設計です。ワンショットでリッチなアプリやコンテンツを作りたい場面ではソル／アストラ、それ以外の大量タスクはテラ、という使い分けが現実解でしょう。
