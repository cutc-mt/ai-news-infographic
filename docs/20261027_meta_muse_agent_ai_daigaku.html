METAの無料パーソナルAIエージェント / Muse 日本上陸

Metaの「Muse（ミューズ）」が日本上陸
——Gmail・カレンダー連携から動画・画像生成まで“丸投げ”できる無料AIエージェントの全貌

2026年10月23日、Metaは無料で使えるパーソナルAIエージェント「Muse」の日本での展開を開始しました。クラウド上の専用コンピューターで稼働し、GmailやGoogleカレンダーと連携してメール返信やスケジュール調整を代行。動画・画像生成機能も搭載で、先行リリースの米国では公開わずか40日でモバイルアプリ1000万ダウンロードを突破しています。本動画（AI大学【AI&ChatGPT最新情報】）の全3章構成の解説を、18枚のカードに整理します。

OVERVIEW

Museとは——10月23日に日本展開開始された無料AIエージェント米国では9月先行リリース、40日で1000万DL

MuseはMetaが9月に米国で先行リリースし、10月23日に日本での展開が始まった、安全性に配慮したパーソナルAIエージェント。クラウド上に用意された専用のコンピューターで稼働し、GmailやGoogleカレンダーなどのアプリと連携してメールの返信やスケジュール調整を代行してくれるほか、動画や画像を作る機能も実装されています。

BRAIN

頭脳は高性能モデル「Muse Spark」チャット感覚で依頼するだけ

Museの中身には高性能AIモデル「Muse Spark（ミューズ・スパーク）」が搭載されています。メール送信やレストランの予約といった日常業務から、大きな目標の計画・実行・交渉・安全な決済まで自立的にこなすのが特徴。クラウド側で動くためアプリを閉じても作業は継続し、一度話した大事なことを記憶して先回りして提案してくれる機能も持ちます。

よもぎ
よもぎ:「丸投げ」という言葉がしっくりくる設計です。閉じても動き続け、そのうちに秘書が先回りしてくる——遠隔にいる部下のような存在ですね。
CONNECT

Gmail・Instagramなど多くのサービスと連携連携先の機能を丸ごとコントロール

GmailやInstagramをはじめ多くのサービスと連携でき、連携先の機能をコントロール可能。Gmailならメールの確認や返信、カレンダーなら予定の追加など、日々使うサービスの操作をMuseに代行してもらえます。連携の管理は設定画面の「コネクター」から行います。

よもぎ
よもぎ:連携できるサービスの数がそのままMuseの手足の数。まずはGmailとカレンダーから試すのが定番コースです。
CREATE

画像・動画・ポッドキャスト生成も内蔵エージェント＋生成AIの一体型

作業代行だけでなく、画像や動画、ポッドキャストを生成する機能も実装済み。チャット経由で作りたいイメージを伝えるだけで素材ができあがり、作った成果物はライブラリで一括管理できます。エージェントと生成AIが1つのアプリに同居している形です。

よもぎ
よもぎ:「予定を組んで、案内文を書いて、宣伝画像も作って」が1つのチャットで完結するのは大きいです。
SECURITY ①

隔離されたクラウドコンピューターで稼働認証情報は「中身を見ないまま」利用

Museは専用の隔離されたクラウドコンピューター上で動作します。連携サービスのデータや認証情報はすべてこのクラウドコンピューターに保管され、共有された認証情報は安全なストレージに収められ、Museは中身を見ないまま利用。チャットに直接入力するパスワードについても同様の扱いです。

よもぎ
よもぎ:「パスワードを預けるのに覗かれない」設計はエージェントサービスの信用の要。ここを最初に説明する構成は正直です。
SECURITY ②

実行前には必ずユーザー確認全操作履歴のチェックとアクセス範囲の設定

メール送信など実際に何らかの操作を実行する際には、事前にユーザーの確認を取る設計。過去の操作とこれからの予定操作はすべて履歴としてチェックでき、接続するサービスとアクセスを許可する範囲はユーザーが自分で設定可能です。

よもぎ
よもぎ:「見える化された承認フロー」があるから丸投げできる。ガードレールを自分で調整できるのも良い設計です。
PLATFORM

対応プラットフォーム：Web・iOS・Android・Mac近日中にMetaのAIグラスにも対応予定

動画制作時点で、Webブラウザー版のほかiOS・Androidアプリが利用可能で、Macのみデスクトップアプリも用意されています。1つアカウントを作れば全プラットフォーム共通で利用可能。Metaによると近日中にMetaのAIグラスでもMuseが使えるようになるとのことです。

LOGIN

ログイン方法：Instagram / Facebookならワンタップ無い場合は電話番号かメール＋年齢確認

公式サイトにアクセスし、すでにInstagramやFacebookのアカウントを持っていればログイン画面にアカウント名が表示されるので、押していくだけでログイン完了。アカウントを持っていない場合は携帯電話番号かメールアドレスでアカウントを生成し、年齢確認のためにクレジットカードを登録すれば使えるようになります。

よもぎ
よもぎ:クレジットカードは年齢確認用とはいえ登録が必要。始める前に把握しておきたいポイントです。
SETUP ①

初期設定：設定画面の「一般」と「コネクター」無料プランの利用上限は週単位で管理

ログイン後、画面左下の2本線ボタン→設定で各種設定へ。「一般」では利用状況を確認でき、無料プランには1週間の利用上限が設定されています。「コネクター」ではGmailやGoogleカレンダーなど各種アプリとの連携を追加できます。

よもぎ
よもぎ:「今週あとどれだけ使えるか」が見えるのは無料プランでは嬉しい設計。上限を気にしながら試せます。
SETUP ②

インストール直後にやるべき2つの設定学習オプトアウトと余計な連携の解除

①「データコントロール」の「AIモデルの改善にご協力ください」がデフォルトでオンになっているはず。このままではユーザーとMuseのやり取りがMetaのAIモデル学習に使われる可能性があるため、学習に使われたくない方はオフ推奨。②Instagram / Facebookアカウントでログインした場合、これらがデフォルトで連携されているので、気になる方はコネクターで連携を外しておきましょう。

よもぎ
よもぎ:「便利さと引き換えにデータ差し出す」構図は無料サービスの宿命。最初の5分で決めておきたい設定です。
UI

画面構成：左サイドバーの6つのアイコンチャット・検索・フィード・アイデア・目標・ライブラリ

初回ログイン時はチャットが立ち上がり、Museが話しかけてくるので、話しながら名前をつけたりアプリ連携したりできます。以後は基本的にチャットで依頼する形。サイドバーの6アイコンは上からチャット／チャット検索／興味のある情報を自動表示するフィード／実行できる作業一覧のアイデア／健康や人間関係などの目標／作成物を確認するライブラリです。

  • フィード: 興味を入れておくと関連情報を自動表示
  • アイデア: Museでできる作業のカタログ
  • 目標: 健康・人間関係などの目標設定
  • ライブラリ: ドキュメント・画像・動画・ポッドキャスト
よもぎ
よもぎ:「アイデア」を見るだけでMuseの実力の輪郭がつかめます。最初はここを眺めると良いですよ。
PERSONA

名前・人格・長期記憶はユーザーが直接編集できるアバター画面の本人確認/ソウル/メモリー

チャット画面右側のアバター部分では、アクティビティ（直近の作業）/承認（承認した作業）/予定（定期実行の作業）を確認可能。さらに本人確認でMuseの名前・性格・話し方や振る舞いを、ソウルで価値観や行動習慣などの人格を、メモリーで会話から学んだユーザーに関する長期記憶を、それぞれ確認できるだけでなく直接編集して変更できる点が特徴です。

よもぎ
よもぎ:人格と記憶が「編集可能なファイル」になっているのは画期的。チューニングの余地が明示されています。
USE CASE ①

活用の入口は「アイデア」ページ気になるアイデアを「やってみよう」で即チャットへ

Museで何ができるか知りたい場合は、左サイドバーのアイデアボタンから。健康・フィットネス、生産性、財務管理、人間関係・繋がり、ショッピングなど様々なアイデアが並んでおり、「やってみよう」ボタンを押すとアイデアがチャットに自動送信され、そのまま会話しながら育てられます。

よもぎ
よもぎ:「何を頼めばいいか分からない」を解消する導線。エージェント初心者のつまずきポイントをちゃんと潰しています。
USE CASE ②

定番の自動化：毎朝のメールチェックとカレンダー登録コネクター連携で“仕掛けておく”運用

設定画面のコネクターで各アプリと連携しておくと、Gmailのメールを毎朝チェックしてもらう、スケジュールを自動でGoogleカレンダーにセットしてもらうといった定期作業を実行できます。1回きりの依頼ではなく、習慣として仕込めるのがMuseらしい使い方です。

よもぎ
よもぎ:「朝、重要メールだけまとめて教えて」を毎日実行できるだけで、日常がかなり軽くなりそうです。
USE CASE ③

画像・動画生成の実践手順テキスト指示・画像アップロード編集・ライブラリで確認

Museはチャット経由で画像や動画を作れます。作りたいイメージをテキストで送信すると動画や画像を生成し、チャットのプラスボタンから画像をアップロードして編集することも可能。作った成果物は左サイドバーのライブラリで確認できます。なお、どの画像生成・動画生成AIモデルが実装されているかは現時点で不明です。

よもぎ
よもぎ:中身のモデルが非公開なのが少し残念。ただ「編集までできる」ので実用には十分そうです。
PLAN

無料でもある程度使える＋上位プラン「Muse Wonder」設定→一般→アップグレードから登録

Museは無料でもある程度利用可能ですが、動画や画像をたくさん作ったり大量の定期作業を実行するユーザー向けに、上位AIモデル「Muse Wonder（ミューズ・ワンダー）」などが使えるサブスクリプションプランも用意されています。登録は設定画面の「一般」にあるアップグレードから可能です。

SUMMARY

まとめ：「無料で丸投げできる秘書」の時代に突入設定だけは最初にやっておこう

Meta「Muse」は、隔離クラウド上で安全に稼働し、Gmail・カレンダー連携で実務を代行し、画像・動画生成までこなす無料のパーソナルAIエージェントです。米国での爆発的な普及が示す通り、ハードルは一気に下がりました。導入時に押さえるべきは、①データコントロールで学習への協力をオフにするか決める ②コネクターで連携範囲を自分で設定する ③人格や長期記憶は編集可能という3点。動画で紹介された記事やツールのリンクは概要欄にまとまっています。

よもぎ
よもぎ:AIツールは自分の手で試してこそ価値が出ます。まずは無料のMuseで「何を丸投げできるか」体験してみてはいかがでしょうか。
CHECKLIST

はじめてのMuse セットアップチェックリストこの順で押さえれば迷わない

  • 公式サイトからログイン（Instagram/Facebookまたは電話番号・メール＋クレジットカードで年齢確認）
  • 設定→データコントロールで「AIモデルの改善にご協力」を確認（学習拒否ならオフ）
  • コネクターでGmail・Googleカレンダーを連携。不要なInstagram/Facebook連携は外す
  • 初回チャットで名前を決め、「アイデア」からやってみようボタンで試運転
  • 毎朝のメールチェックなど定期作業を1つ仕掛けて様子を見る
よもぎ
よもぎ:小さく始めて徐々に任せる範囲を広げるのが、AIエージェントと上手に付き合うコツです。
