DIAGNOSIS

この下落は「何」なのかバブル崩壊か、一時的な調整か

大川さんの見立ては明快です。「崩壊の始まり」と語る専門家は少数派であり、本人は「挑戦のうちにも入らない」レベルの調整と評価します。6万2000円は今年初めには「高すぎる」と言われていた水準であり、7万円をつけた後の落ち着きにかかる段階。石、コアウィーブ、メタ——何かが壊れた話ではないことが認識の前提になります。

よもぎ
よもぎ:「何が崩れたのか」を確認してから恐れる——順番が大事、ということですね。
OUTLOOK

年末の日経平均想定レンジ上は7万チャレンジ、下は5万円台も

正直なところ見通しは難しいとした上で、上はもう一度7万円にチャレンジする可能性、下は5万円台（5万5000円程度）もあり得るという幅のある想定を示しました。ただし「大暴落が止まらない」タイプの下落は想定しておらず、7万円超えから8万円へ向かうエネルギーも今はない——その中間でレンジ幅5000円程度の振れを繰り返すイメージです。

RATES

米長期金利5%台でもハイテクは売られなかった成長力が金利圧力を上回っていた

米長期金利が5%台に上昇し追加利上げも意識される中、本来なら負債を多く抱えるデータセンター関連は売られるはずでした。しかし圧倒的な成長力が金利上昇を相殺し、配当株も売られませんでした。ただし全体感としてはそうでも、個別に見ると「じゃないよね」が出てきた——その筆頭がコアウィーブだった、という文脈です。

よもぎ
よもぎ:金利は「全員のリスク」ではなく「財務の弱い個別企業を炙り出す装置」になっていた、という見方です。
COREWEAVE

コアウィーブとは何者かハイパースケーラーと同業のAI基盤貸し

Google・Amazon・Meta・Microsoftが手掛けるデータセンター事業とほぼ同じことを専門に提供する会社。AI開発・クラウド事業向けの計算基盤（ハードウェア）を貸し出すビジネスで、特別な事業をやっている一角ではなく、データセンタービジネスの一プレーヤーです。前回騒がれたのはオラクルで、今年半ばの高値以降下落が続いていました。

TRIGGER

ショックの発端は財務不安自己資本比率約6%の過剰な借入

「財務がやばいのでは」との指摘が強まり、株価が9%〜15%の急落。社債価格が下がりスプレッドが急拡大する、いわゆる信用不安の高まりでした。背景には自己資本比率およそ6%という、同業の中でも際立って低い資本構成。少し前まで債務超過だった時期もあるほど借入でデータセンターを展開してきた会社です。決算を見たイーロン・マスク氏がSNSで懸念を投稿したことも下落に拍車をかけました。

VERDICT

AIブーム終わりのサインになり得るか答えは「なり得ない」——強者の勝ち残る事業

仮にコアウィーブが事業に失敗しても、出資するNVIDIA・銀行・投資ファンドには打撃が出るものの、その上に乗る客は他へ流れるだけ。品質・価格・経営健全性で勝つ者が客を集める「強者の勝ち残り」のビジネスであり、飲食店と同じ構図です。実際、複数のAIサービスを使い分ける利用者が、質と価格とセキュリティで最終的に優良な台数に集約されるのは自然。コアウィーブは健全な投資と回収の両面で疑問がついただけです。

よもぎ
よもぎ:「1社が傷ついても誰も困らない」——崩壊譚ではなく選別の話、というのが大川さんの読みです。
SETTLEMENT

ショック収束の時期定期的に盛り上がる「忘れた頃の話題」

「もうそろそろ収束するのでは」が大川さんの見解。この種の債務懸念は忘れた頃に浮上するネタであり、オラクルも巻き込まれ続けてきました。重要なのは、何かが崩壊する時期ではなく強いところと弱いところが分かれる時期という理解。債務懸念を払拭してビジネスが回る企業と、抱え続ける企業に分化していきます。

MEMORY

メモリ高騰は「永続しない」中国勢・CXMTの台頭で需給は緩む

ハイパースケーラーの投資拡大でメモリ・HBM需給が逼迫し価格が上昇してきましたが、対抗してきたのが中国勢。メモリ大手CXMTが上場し、3期先には他社より高い成長率が出る想定です。各メモリメーカーの成長率を集計すると3期先に全体がフラット、4〜5期先にはマイナス成長へ。時期は誰にも分かりませんが、「遅かれ早かれ終わる」ことだけは確か、という整理です。

WINNERS

メモリ価格下落の恩恵と影響作る側は数社、使う側はほぼ全部

メモリを作る企業より使う企業の方が圧倒的に多い——スマホ、PC、ゲーム機、各種サービスまで、価格下落を喜ぶ側がほとんどです。SKハイニックスなど韓国・台湾のメモリ勢は影響を受ける一方、日本の検査装置・製造装置（アドバンテスト、東京エレクトロン等）は価格ではなく個数で稼ぐため影響が小さく、中国勢の供給拡大はむしろ数量増でプラスに働き得ます。

よもぎ
よもぎ:「メモリが高いから最新スマホがあの値段」——下落は消費者と多数の製造業に追い風です。
ELECTION

11月3日 米中間選挙：基本は追い風過去サンプルは「後1年でほぼ100%上昇」

中間選挙を挟んだS&P500の過去サンプルでは、選挙後120営業日・250営業日（1年）までに上昇した割合がほぼ100%。ただしこれは「アメリカはショック以外ほぼ上がる」ことの反映でもあり、選挙のおかげと確定して買うと偉い目に合う——統計的事実と因果の区別が必要です。今回は例外的に「少し向い風」と大川さんは見ます。

SCENARIO

民主党勝利ならAI・データセンター関連が売られる2党の政策が「完全に逆」

トランプ政権はデータセンター建設を全力推進しAI規制に否定的。民主党は電力上昇→インフレ、国民に不利として強く反対するなど、AI・データセンター政策が完全に逆です。下馬評は民主党優勢で、民主党勝利ならAI/データセンター関連が下落する可能性——最近の調整にはある程度織り込み済みとの見方。大統領の拒否権で法案は止まっても、議論が高まること自体がリスクで、一部州では建設禁止法案が可決された例もあります。

よもぎ
よもぎ:問題の核心は「AI・データセンターの時価総額が大きくなりすぎた」こと。世論が少し傾くだけで指数に響く規模になった、ということです。
WATCHLIST

選挙後に注意すべき銘柄群トランプ銘柄・資源・AI関連

センチメントで一時的に売られ得るのは①データセンター関連全体②トランプ銘柄（パランティア、暗号資産関連）③石油・ガス等の資源株。民主党は再生エネルギー推進・化石燃料否定派のためです。一方、原子力・電力系はデータセンターに関係ないエネルギー需要であり止まらない見込み。エアポケット的な急落はあっても基本面で崩れるわけではない、という整理です。

  • 要注意：AI・データセンター関連／パランティア等トランプ近縁／ビットコイン等暗号資産／石油ガス
  • 比較的堅い：原子力・電力系（独立の需要）
RESILIENCE

それでもAI開発は止まらない「規制して喜ぶのはアメリカ以外」

仮に民主党政権になってもAI・データセンター開発が失速する見方は「ほぼしない」。AIの猛進を憂いて規制を抑えれば、喜ぶのは中国をはじめアメリカ以外だけ。経済成長を押し上げてきた原動力を止める選択肢は現実的でなく、消費者向けAIエージェントが普及し始めた今、開発を止める方向にはならない——というのが大川さんの主張です。日本のAI・データセンター関連は3期先まで2桁の増収増益が予想されており、短期の政策ブレーキと中長期の成長は別論点です。

PRICING

サイゼリヤ報道だけでストップ高「値上げ」が新たな材料になった内需株

実質消費が9ヶ月連続マイナスの日本で、値上げをポリシーとしてきたサイゼリヤが夏に値上げ報道が出た際、報道だけでストップ高。そして今回、決算で値上げが確定すると再び急上昇しました。外食・小売のディフェンシブ銘柄に残された道は「値上げ」か「海外」の2つだけ。オリエンタルランドも値上げ路線で利益率改善を図っています。コスト上昇の中で値上げしないと利益率は悪化するためです。

DATA

値上げ発表銘柄の統計：7〜8割が上昇発表日から60営業日の平均騰落

大川さんが値上げを発表した企業を集計したところ、発表日を1とした株価は右肩上がりに上昇し、約3ヶ月（60営業日）で7〜8割が上昇。しかも予想売上高だけでなく予想営業利益も引き上げられており、アナリストの見通しが改善しています。背景には「インフレに慣れてきた」消費者マインド。値上げ後の売上と利益率を決算で確認できれば「回っている」証拠です。

よもぎ
よもぎ:「急激な値上げ」は客離れを呼ぶので除く、という注釈付き。ミラノ風ドリアが300円→480円になったら誰も行かない、の比喩が秀逸でした。
DEFENSIVE

内需・ディフェンシブの逆襲ファストリ・ニトリの「海外」×値上げ

分散投資先として大川さんが好むのが内需小売り。ファーストリテイリングは値上げを発表して上昇、海外売上高比率はユニクロベースで約60%。追随するニトリは海外比率約40%で、売上高1兆円突破以上に「海外を増やす宣言」が評価されました。海外は国内より値上げしやすく利益率改善期待が湧くためです。AIに資金を吸われて売られ続けた反動として、値上げできる内需株はしばらく期待が持てるテーマと分析します。

GOLD

池水雄一の金相場視点金は株とドルの動きを見てから動く

貴金属スペシャリストの池水さんは、ゴールドについて「どちらかと言えば株価やドルの動きを見てから動く」と分析。トランプ氏が勝てばこのまま上昇、民主党勝利なら最初は株と一緒に売られる可能性を指摘しました。かつての「保険的なクッション」の役割ではなく、今は株と似た動きをしているのが実態です。なお、AIハード関連ではルテニウム・イリジウム等のプラチナ仲間が高騰しており、個人が投資できる金・銀・プラチナ・パラジウムとは違う需要動向が見どころだと補足します（詳細は後編で）。

よもぎ
よもぎ:「金だけ安全」ではなく、股市場との連動性で考える——地金を買う際もセットで押さえたい視点です。
ACTION

まとめ：今週は「待つ」、下がれば「押し目」イベント嵐の入口では慌てない

中間選挙の前には日米の金融政策決定会合、アドバンテスト・キオクシア・東京エレクトロン等の大手決算が集中し、イベント過多な状態。どちらが勝つか予想するのはリスクでしかないので、選挙終了まで待ってからでいい、というのが大川さんの結論です。今の決算はどの銘柄も異常に強く、良くても売られる局面ではありますが、業績が堅い銘柄は最終的にファンダメンタルズが反映されて戻る——SaaSが「死」と言われて下落した後に高値を更新したのが実例です。下がった検査装置・製造装置は押し目と考え、内需分散は値上げ×海外のディフェンシブで。
