VibeiDE: コーディングエージェントを並列実行するデスクトップ指揮センタータブ切替のストレスと作業中断を解消

FEATURED ①
  • プロジェクト全体でコーディングエージェントを走らせるデスクトップのコマンドセンター——複数エージェントを別々のターミナルで管理する際のタブ切替を解消し、作業の中断や結果の消失を防ぐ
  • 独自の Claude Code・Codex・OpenCode を持ち込み、自分のサブスクリプションでサインイン。各タスクに対して適切なプロジェクトで実際のターミナルを開いてエージェントを起動
  • 複数プロジェクトの作業をキューに入れると、次のタスクの待機中に複数エージェントが同時実行。「アニメーションオフィス」またはバッテリーに優しいグリッドの1つのビューで全状況を監視
  • 各プロジェクトはカラーコード付きキューを保持し、プロバイダーの利用制限が一目で分かる。1タスク＝いつでも再開できる1セッション
  • 結果は完了前にレビューを待つ構造——レビュー作業自体はコンピュータ上で完結しトークン課金が発生しない。macOS / Windows 対応、14日間の無料トライアルあり
よもぎ
よもぎ:「エージェントを走らせる」より「並べて監視し、人間がレビューで蓋をする」部分の体験を磨いた設計。課金なしでレビューできるのも実用的です。
CARD 03

Strawberry 1.0: AIチームメイトを内蔵したブラウザチャットボットのコピペ作業を終わらせる

FEATURED ②
  • 実作業に手を染める組み込みAIコンパニオンを備えたブラウザ——回答をタブ間でコピペし、毎回作業を説明し直す従来のチャットボット運用を解決
  • ブラウザ自体が共有ワークスペースとなり、ユーザーが見ているものを認識。ログインの壁の後ろでも、18億のWebサイトすべてでサインイン済みアカウント内で動作
  • コンパニオンはユーザーの習慣を学習し、リード調達・1000件のレコードからなるスプレッドシートの充実・ボットなしでの会議文字起こし・ブランド資料の作成・繰り返し作業の自動操縦をエンドツーエンドで処理
  • 既製コンパニオンを「雇う」か独自に作成。作業アプリを接続し、記憶とコンテキストを次のタスクに引き継ぎ
  • 取り返しのつかないアクションの前に確認を求め、パスワードはデバイス上で暗号化。SOC 2 / GDPR 準拠。macOS / Windows 対応で無料ティアあり
よもぎ
よもぎ:「ブラウザ＝エージェントの作業環境」という発想の転換が鍵。既存ログインをそのまま使えるのが最大の差別化ポイントです。

AI Bridge: コーディングエージェントをチームのように運用散らばった端末の混乱を整理するMacアプリ

FEATURED ③
  • AIコーディングエージェントをチームのように実行するMacアプリ——コンテキストが混ざり合い、どのエージェントが自分を必要としているか分からない状態を解消
  • 作業を「プロジェクト」と「ワークスペース」で整理——プロジェクトは全エージェントに届く指示を含む業務、ワークスペースは独自のルール・ファイル・リポジトリ・ツールを持つ責任領域。各エージェントは最初から仕事内容を把握した状態で動く
  • 全エージェントは実際のターミナルで動く本物の Claude Code・Codex・Grok・OpenCode CLI。状態ブリッジが作業の必要性を追跡し、準備状態や休止を確認して翌日中断位置から再開
  • 1つの受信ボックスに自分宛ての要求が集約。グリッドは主要セッションを1つの壁に並べ、Kubernetes・Postgres・MongoDB・Slack チャンネルを承認待ちの権限・返信と共に配置
  • すべてはテレメトリなしのプレーンな YAML / Markdown として自分の Mac 上で実行。開発者とそのチーム向け、現在ウェイティングリスト受付中
よもぎ
よもぎ:「エージェントの部署・仕事領域・報告線」をアプリで表現したような設計。状態がファイルとして残るのは運用面で大きいです。

ManyAgents: 多数のコーディングエージェントを1つのMacウィンドウでClaude Code × Codex のチーム同時実行

FEATURED ④
  • Claude Code と Codex のエージェントチームを同時実行するネイティブMacアプリ——別々の端末で多数のエージェントを管理する煩雑さ、作業の衝突、質問の見落としを解消
  • オーケストレーターにやりたいことを伝えるとリクエストがタスクに分割され、それぞれにタブが開き、誰が何をしているかを追跡。既存の Claude Code / Codex プランで動くため追加のAI料金なし
  • 各ワーカーは独自の作業ツリーで1つのタスクを担当し互いに干渉しない。思考担当が難しい設計判断を担い、レビュー担当が別プロバイダーで読み取り専用のチェックを行い自己レビューの見落としを検出
  • チャット横の組み込みブラウザでエージェントがクリック・フォーム入力・テスト実行を行え、iPhone アプリ向けの iOS シミュレーターも内蔵
  • エージェントが必要とする決定は推奨事項付きで1つのニーズキューリストに集約。カードビューで各状態を表示し待機中を最上部に。コードは分析なしで Mac 上に保持。14日間無料
よもぎ
よもぎ:「実行者・思考役・レビュー役」の役割分担を自動化したのが面白い点。自己レビューの限界を別プロバイダーで補う発想は参考になります。
CARD 06

Moli by Lexmount: エージェント専用にゼロから作られたクラウドブラウザエンジンChrome より高速起動・低メモリ

FEATURED ⑤
  • Lexmount のクラウドブラウザプラットフォーム上で提供される、AIエージェント向けにゼロから構築されたブラウザエンジン「Moli」——Chrome の重い起動・実行コストとインフラの維持管理の負担を解消
  • Chrome より起動が速くメモリ使用量も少なく、Lexmount がインフラを処理しながらプロキシ対応の分離ブラウザセッションを提供。セッションはコードから制御可能
  • プラットフォームはクエリをランク付け済みリンクに変換する Web 検索 API、URL を構造化コンテンツに変換する Web フェッチ API、ブラウザタスク全体を委任するエージェント製品とペアリング
  • 使い分けも明確——Moli はドキュメント読み取り・フォーム送信・スクリーンショットなどの構造優先タスクに、Chromium は永続コンテキスト・拡張機能・互換性重視のタスクに
  • ライブセッションはコンソール・ネットワーク・スナップショットビューで検査可能。SDK・API・コーディングエージェント・Playwright 経由で接続。プレイグラウンド / 無料アカウントあり
よもぎ
よもぎ:「エージェント用の軽量ブラウザ」と「人間用 Chromium」の二本柱を明示したのが明快。ブラウジングの垣根が下がります。

  • エージェントスキルと画像処理APIも提供——Claude Code・Cursor・Codex などのスキルMD対応エージェントが、デッキ生成・背景削除・画像内テキスト翻訳・インペイントを実行可能

よもぎ:生成AIの弱点は「部分修正」。レイヤー分解＋ロゴ固定で実務品質に持っていくアプローチはマーケターに刺さります。
