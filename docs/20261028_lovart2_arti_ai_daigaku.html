OVERVIEW

Lovart 2.0とは——「デザイン作業の全工程」をこなすAIデザインエージェント10月下旬リリースの最新版に専属エージェント「Arti」が搭載

Lovartは様々な画像生成AIモデル・動画生成AIモデルを標準実装したAIデザインエージェント。お店や会社のロゴからSNS画像、広告動画まで、デザインに関わる作業を丸ごとこなします。2026年10月下旬にリリースされた最新版「Lovart 2.0」の目玉機能が、ユーザー専用のパーソナルデザインエージェント「Arti」です。デザイン作成を指示すると自ら動いて複数の工程をまとめ、本番で使える完成品として納品してくれます。

CONCEPT

Artiは「指示待ちしないAIデザイナー」作業手順・好み・ブランドルールを学習して記憶

Artiを一言で表すと「指示待ちしないAIデザイナー」。ユーザーの作業手順や好み、ブランドのルールを学習して記憶し、使えば使うほどユーザーに合ったスタイルで的確に作業するようになります。デザイン作成を依頼すると必要な作業を先回りして進め、複数の工程をまとめて本番で使えるデザインとして提出してくれるのが最大の特徴です。

よもぎ
よもぎ: 従来の画像生成AIは「1枚依頼→1枚受け取り」。Artiは briefing を聞いて、工程ごとに自分で組み立てて納品します。
SKILL

繰り返し作業を「スキル」に変えて再利用使えば使うほど賢くなる仕組み

Artiはユーザーが繰り返し行う作業手順をそのまま再利用できる「スキル」に変換してくれます。次回からはそのスキルを使って、同じような作業をより簡単に進められるようになるのが「使えば使うほど賢くなる」の正体。ナレッジが人からAIへ移り、作業がどんどん軽くなっていきます。

01同じ作業を何度か依頼する
02Artiが手順をスキル化
03次回はスキルで時短
AUTONOMOUS

依頼した作業は「裏で」進むユーザーが他のことをしている間に完成

Artiにデザイン作業やデザイン関連のリサーチを依頼すると、ユーザーが他のことをしている間にArtiが作業・リサーチを実行し、結果を出力してくれます。「待ち時間ゼロで納品が届く」エージェントらしい挙動で、放置してよい作業と確認すべき作業を分ける運用が可能になります。

SHARE & FIX

共有デザインへの修正コメントもArtiが管理要約を頼めば整理し、指示一出すだけで修正完了

Lovartの共有機能でシェアしたデザインに他のユーザーから修正コメントが寄せられると、Artiがその内容を知らせてくれます。Artiに要約をお願いすると分かりやすく整理してくれるので、ユーザーは内容を確認して修正指示を出すだけ。Artiがデザインの修正を実行し、完了品を納品してくれます。

GETTING STARTED

始め方は公式サイトからログインするだけ無料ユーザーでもArtiは利用可能

Lovartは公式サイトの左下にあるログインボタンから、Googleアカウントなどでログインすると利用できます。Artiは無料ユーザーも使えますが、全ての機能を使うにはサブスクリプションへの登録が必要です。まずは無料で試して、価値を感じたら課金する流れがスムーズです。

  • アクセス: 公式サイト → 画面左下のログインボタン
  • 認証: Googleアカウントなどでログイン
  • 料金: Artiは無料枠あり / 全機能はサブスク
ARTI PAGE

Artiのホームは左サイドバーの「Arti」過去ユーザーは「過去のプロジェクトから学ぶ」で即スタート

ログイン後の画面左サイドバーに「Arti」という項目があり、その先のページでArtiを管理します。過去にLovartを使っていたユーザーは、ページ上部の「過去のプロジェクトから学ぶ」を押せば、Artiが過去プロジェクトを確認して好みなどを覚えてくれます。既存の資産がそのままArtiの学習材料になるのは大きいです。

ONBOARDING

初回は「あなたのことを教えて」で好みを登録呼び方・デザイン目的・作業スタイルを質問形式で

初めて使うユーザーは「あなたのことを教えて」のボタンから始めます。ユーザーの呼び方、Lovartで主に何をデザインしたいか、デザイン制作における作業スタイルや好みを聞かれるので、それに答えていくだけでArtiがこれらの情報を記憶してくれます。難しい設定ファイルは不要、対話だけで初期教育が完了します。

質問されること: 呼び方 / デザインしたいもの / 作業スタイルと好み —— 答えるだけでArtiのメモリーに蓄積されます。
SETTINGS

自律動作のオンオフと「成長ログ」の確認メモリーは対話でいつでも編集可能

Artiページ内の「Artiが自分からできること」では、Artiが自立的に動く要素のオンオフが可能。「Artiが学んだこと」では、メモリー・作ったスキル・学んだ内容の成長ログを確認できます。「Artiと話してメモリーを編集」ボタンを押すとフォームが出現し、好みやスタイルを後から伝え直して記憶を更新できます。

  • Artiが自分からできること: 自律動作のトグル
  • Artiが学んだこと: メモリー/スキル/成長ログ
  • メモリー編集: フォーム経由で好みを追加
PRACTICE 1

実演: ブランドアセットをArtiに記憶させるSNS素材制作の前準備は「よく使うアセット」の登録

実例としてAI大学YouTubeチャンネルブランドのSNS素材を作成。まずArtiページ内の「よく使うアセット」のプラスボタン →「ライブラリーから選択」と進み、以前Lovartで制作したブランドのロゴなどの素材を読み込みます。名称（例: AI大学YouTubeチャンネルブランド素材）を入力して追加ボタンを押すと、Artiがブランド素材を情報源として記憶します。

STEP 1よく使うアセットの「＋」を押す
STEP 2ライブラリーからロゴ等を選択
STEP 3名称を入力して追加→記憶完了
PRACTICE 2

キャンバスを開いて指示を出す新規プロジェクト→チャットで画像生成AIモデルをセット

準備が済んだら、Lovartの左サイドバーの「＋新規プロジェクト」ボタンで、チャット経由で画像や動画を作れるキャンバス画面を開きます。チャットで画像生成AIモデルをセットし、Artiのメモリーに設定したアセットから使いたい画像や表示したい文字を織り交ぜて「ブランドのポスター画像を作ってください」のように入力・送信するだけです。

よもぎ
よもぎ: プロンプトの書き方も「素材を参照させる」点がコツ。ブランド名を呼ぶだけでロゴやカラーを引っ張ってきてくれます。
PRACTICE 3

ヒアリングに答えるだけで「本番仕様」が完成サイズ・方向性・内容・テーマを聞かれる

送信するとArtiはユーザーのメモリーを読み込んだうえで、パンフレットのサイズ、ビジュアルの方向性、内容、テーマなどを質問してきます。それに順に答えていけば画像生成がスタートし、最終的にブランドのロゴやカラーを反映したパンフレット画像が完成。以降、登録ブランドのバナーやポスター、パンフレットなども同じ流れで作れるようになります。

OUTPUT

サムネイル・UI画像・アニメ動画も同じ要領で編集・アップスケール・ダウンロードもLovart内で

同じ感じでYouTubeやブログのサムネイル画像、ブランドWebサイトのUI画像、ブランドのアニメーション動画なども生成可能。作った画像や動画はLovartの編集機能で細かく編集したり、アップスケールしてダウンロードできます。生成から微調整・出力まで1つのツールで完結するのが強みです。

  • サムネイル: YouTube / ブログ用
  • UI画像: ブランドWebサイト向け
  • 動画: ブランドアニメーション
  • 後処理: 編集 → アップスケール → DL
DELEGATION 1

「お任せデザイン」で定期作業をスケジュール委任1度設定すればArtiがスケジュール通り自動実行

Lovart 2.0には定期的なデザイン作業を一度設定するだけで、Artiがスケジュール通り自動実行する「タスク委任機能」が実装されました。左サイドバーの「お任せデザイン」→ ページ上部の「新規タスク」ボタンから設定画面を開き、タスク名の入力、プラスボタンからの素材アップロード、指示文の入力、実行タイミング・保存先・利用クレジットの上限をセットして作成ボタンを押せば依頼完了です。

SET 1新規タスクでタスク名を入力
SET 2バナーやロゴ等の素材を追加
SET 3指示と実行条件を設定して作成
DELEGATION 2

実例: 英語・中国語へのローカライズを委任指定時刻に自動実行、すぐ試すなら「テスト実行」

実演では、作成済みのバナーやロゴなどの素材をアップロードし、「英語と中国語で配信したいので、アップロードした素材を英語と中国語にローカライズしてください」という指示を投入。実行タイミング・保存先・クレジット上限をセットして作成すると、指定した時間にArtiが自動でローカライズ作業を実行し、多言語化された素材を納品してくれました。なお、すぐ動作確認したい場合は設定画面の左下にある「テスト実行」ボタンで即時実行できます。海外展開のデザイン作業がほぼ自動化されます。

指示例: 「英語と中国語で配信したいので素材をローカライズして」 + 実行時刻 + 保存先 + クレジット上限 —— これだけで完了です。
WEEKLY RESEARCH

定期リサーチもArtiの仕事「毎週月曜の朝にサムネイル傾向を調査」もセット可能

お任せデザインでは制作だけでなく調査も委任できます。例えば「毎週月曜日の朝、YouTubeの特定分野のサムネイル人気傾向を調べて、クリックされやすいサムネイル画像のアイデアをリストアップして」とセットしておけば、毎週月曜の朝にArtiが自動起動して作業を実行し、調査結果をレポートしてくれます。デザイン系の定期タスクをどんどんArtiへ移せるのが2.0の肝です。

SUMMARY

まとめ——Artiは「好みを記憶し、先回りし、定期運用まで担う」専属デザイナーデザイン分野にもエージェント時代が到着

Lovart 2.0の目玉は、作業手順・好み・ブランドルールを学習して記憶するパーソナルデザインエージェント「Arti」です。依頼すれば必要な工程を先回りしてまとめ、本番で使えるデザインとして納品。繰り返し作業はスキル化されて再利用され、共有デザインの修正コメントの通知・要約・修正実行まで担います。さらに「お任せデザイン」で多言語ローカライズや週次リサーチをスケジュール委任できるようになり、デザイン業務の大部分をArtiへ移せる段階に入りました。コードのエージェントと同じ「委任」の作法が、デザインにも使える時代です。

よもぎ: 問われるのは「デザインが上手いか」ではなく「自分の好みとブランドをどこまで言語化できるか」。その投資がArtiを育てます。
