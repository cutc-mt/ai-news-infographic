10｜本MVで一番見たかった「絶叫シーン」の難しさSHOT 2 / 複合パートは破綻しやすい

最難関カット

このシーンは大きく分けて2つのパートで構成されており、1回の生成にまとめると破綻しやすいとのこと。

A人物の動きかごめが視線（かんざし）を外す → 髪が肩へ落ちる → 絶叫する
Bカメラワークかごめを中心に捉えながら、横顔 → 後ろ横顔 → 正面と360°旋回する

こうした「演技＋大がかりなカメラワーク」の複合シーンで活用できるのが、次に解説する3Dプレビズ機能です。

11｜3Dプレビズなしで挑戦すると…SHOT 2 fail / クロスディゾルブ化

失敗例

まず3Dプレビズを使わず、プロンプトだけでどこまでできるか検証。結果——

  • 視線を取った（かんざしを抜いた）後、トランジションのようにクロスディゾルブになってしまった
  • 求めているのはカットの連続なので、これは生成失敗扱い
✕
検証結果: 複雑なカメラワーク＋演技をプロンプトだけに任せると、意図しない編集（ディゾルブ）が入って破綻しがち…

12｜3Dプレビズとは — 模型でカメラを固める機能3D PREVIZ / 仕組み

機能解説

3Dプレビズは、簡単な3D模型を作り、カメラワークを指示してアングルを先に固め、それをリファレンスとして動画生成できる機能です。

  • キャラの動きをつけつつ、カメラワークも同時に制御できる
  • プロンプト欄の下にある「AI 3Dプレビズ」項目から入る — 画面内に使い方のガイドも表示されて親切
  • チャット欄の＋ボタンで画像素材を添付して依頼

13｜3Dプレビズの作り方 — タイムコード指定が鍵3D PREVIZ / 実践手順

実践

事前にAIで作ってもらった動きのプロンプトを添付。内容は——

  • 「8秒ワンカットで360°オービットショット＋クラッシュ」— キャラの動きは指定せずカメラの動きのみを記述
  • 画像素材とプロンプトを送信して約6分で簡単な模型が完成
  • プロンプトにタイムコードで指定していたので、その通りにキーフレームを打ってカメラが動く
  • 焦点距離も変更可能（ただしキーフレームごとの焦点距離変更は不可 — アップデートに期待）
