MONEY MONEY / 東大卒ポーカー王者 × 株式投資

【MONEY MONEY】AI株はあと2年で下落？ 東大卒ポーカー王者・木原尚弥さんが語る「AIで儲かる未来が見えない」理由と負けない投資術

プロポーカープレイヤーであり個人投資家の木原尚弥さんを迎え、AI株・半導体株を買わない理由、AIの性能差が気にならなくなる未来、フィジカルAIの本質、そして「芸人の価値が上がるAI社会」まで徹底討論。ゲームの世界でAIに追い抜かれてきた経験から導いた、独自の投資哲学を18カードにまとめました。

チャンネル: PIVOT公式チャンネル 公開: 2026年10月 出演: 木原尚弥（プロポーカープレイヤー・個人投資家）
♠
ポーカーも株も「確率のゲーム」。上位プレイヤーの思考法は「勝ちに行く」ではなく「負けない」。AIバブルの正体を、ブレスレット3個のトッププロが読み解きます。

03｜ポーカーと投資は「同じゲーム」COMMON GROUND / 確率と読み合い

共通点

「プロポーカープレイヤー×個人投資家」は一見珍しい組み合わせですが、実は世界的には珍しくありません。

  • ポーカープレイヤーからファンドにヘッドハンティングされる人も多数
  • ポーカーも本質的には「投資のゲーム」である
  • 確率を計算し、相手の手を読み、ベットサイズを管理する思考プロセスが共通
木
木原さん: ポーカーと投資はゲーム性がすごく似ています。ポーカーも実は投資のゲームなんですね。だからこそ、両方の世界に親和性があるんです。

04｜どっちが勝ちやすい？ ポーカーと株の難しさの違いPOKER vs STOCK / 「食える」までの距離

比較

両方を極めた木原さんの実感では、難しさの段階が違うといいます。

段階ポーカー株式投資
お小遣い稼ぎポーカーの方が近いバイバイを繰り返す必要があり難しい
生活費を稼ぐさらに上が必要株の方が簡単
✓

株は「お小遣い稼ぎから食えるまでの差が小さい」。一度勝てるレベルに達すれば、生活費を出すのは株の方が楽になります。

05｜プロの本業は大会ではなく「キャッシュゲーム」CASH GAME / 分散を抑える収益設計

収入構造

テレビで映る華やかな大会は、実はプロの主戦場ではありません。

  • 1万ドルの大会に10回出て10連敗 → マイナス10万ドル（約1,600万円）もザラ
  • 大会は「金も大きいが分散も大きい」ので、プロは基本的に出ない
  • 収入のメインはカジノでのキャッシュゲーム。人は基本的にプロ同士で戦っている
  • ポーカーはカジノと戦わず人と人が戦うから勝てる（カジノは運営手数料だけ取る）
木
木原さん: カジノと戦うゲーム（バカラ・ルーレット等）は絶対に勝てない。実力で強い弱いが出る競技は、カジノではポーカーだけです。

06｜AI株を買わない理由「儲かる未来が見えない」WHY NOT AI STOCKS / 上がる前を買って待つ

投資スタイル

AI関連株が大きく上昇する中、木原さんは日経平均が急騰する日はむしろちょいマイナスになるといいます。

  • 投資スタイルは「これから儲かると思うものを買い、長期で結果が出るまで待つ」
  • 純粋に「AIでこれから儲かる未来が自分には見えない」から買わない
  • 半導体大手や有名AI株には手をつけておらず、デイトレもほぼやらない
!?
木原さん: AI産業がダメだと言いたいわけではありません。あくまで「自分に関心がない」。自分が分かる範囲でしかやりたくないんです。

07｜将棋・麻雀・バックギャモン「全部AIに任せた」GAME HISTORY / ボードゲームから学んだAI観

体験談

木原さんは囲碁・将棋から始まり、バックギャモン、麻雀、そしてポーカーと、あらゆる頭脳ゲームを極めてきました。しかしそのすべてが今やAIに任されたゲームになりました。

  • AIと人間の関わり方を、ゲームを通して肌で体感してきた
  • それは生成AIについても全く同じことが言えると分析
  • その経験の帰結こそが「今、AIを買う気がない」
木
木原さん: むしろ自分は、みんなが思っている以上にAIはすごいと思っています。だからこそ、です。

08｜「互角の時期」だけが注目される法則PARITY WINDOW / 抜かれたら誰も見ない

歴史の教訓

AIと人間がちょうど互角だった時代、トップ同士の対戦イベントが組まれ、めちゃくちゃ視聴率が取れました。

1互角期チェスは1995〜97年、将棋は2010〜15年ごろ。人間 vs AI の対戦に注目が集まる
22年後に逆転AIが人間を抜き、勝ち目が完全になくなる
3関心が消える人間対AIはおろか、AI対AIの勝負にすら興味を失う
木
木原さん: 人間が9秒5で走るとして、AIが7秒、6秒、5秒になっていったら「もう勝手にやってろ」で終わりです。今のAIがまさにその直線の中にいます。

09｜AIの性能差が「気にならなくなる」未来COMMODITIZATION / 電卓とスマホの二の舞

価格の未来

今はChatGPTとClaudeの「どっちが上？」に世界中が熱狂し、良いAIに高額課金しています。しかし完全に抜かれたら——

  • 「どっちも大して変わらないね」となり、課金単価が下がる
  • 電卓と同じ。「計算できれば100均のでいいや」という状態が来る
  • iPhoneの例え：8→17に進化しても買い換えなくなった。特別な機能が加わらない
MC
MC: 僕まだiPhone 8ですけど全然困ってないですよ……。カメラも1個で。（会場大爆笑）

10｜需要は増える、しかし「動くお金」は減るDEMAND vs UNIT PRICE / 単価下落シナリオ

予測

重要なのは、AIの需要がなくなるわけではないということ。需要の数はむしろ増える。しかし——

  • 当たり前になりすぎて単価が下がり、動くお金が減る
  • かつて6,000〜7,000円だったゲームソフトが、今は500円で買える時代に
  • 「AIが当たり前に作れる」ようになった時、同じ圧力が課金価格にかかる
✓

「需要は上がる。しかし単価が下がる」——この一言が、AI関連事業への見立ての核心です。

11｜半導体メモリー価格は「インフレバブル」MEMORY BUBBLE / 2年前の5倍

価格分析

半導体の製造そのものは今後も伸びると確信しつつ、木原さんが買わない最大の理由がメモリー価格です。

5倍
現在のメモリー価格（2年前比）
1.5倍
普通のインフレなら妥当な水準
  • 例えば100円のものが本来150円になるところ、500円になっている
  • 500円から150円に戻っても不思議ではない——これが下げリスク

12｜「あと2年でAI株は下がる」予想の根拠2-YEAR FORECAST / 人間が降参する日

予想

なぜ2年なのか。それは「人間がAIに降参するのが2年後」だと見ているからです。

  • 今はAIと人間が「本当のいい勝負」をしている時期
  • 2年後には他のゲームと同じスピードで差がつき、ほとんどの人が白旗を上げる
  • 短期間にもまだ上がる余地はあるが、「どこで下がくるかわからない」
  • 2年後に下がるとしても、そのルート（半年後に下がる/1年上がってから下がる等）は無数にある
木
木原さん: 2年後に下がると思っているなら、今入るのはどのみち怖い。感情ではなく、確率でそう判断します。

13｜孫正義さんのOpenAIへの投資「怖い」SOFTBANK FUND / 上場しないと困る構図

警戒材料

ソフトバンクが新たに約1兆円規模のファンドを組成し、想定利回り4.75%程度で資金を回してOpenAIに出資するという報道に言及。

  • 1,000万円預けたら年47万5,000円を払い戻す必要があり、会社はさらに回さなければならない
  • OpenAIが上場してくれないと孫さんは困る立場
  • 「もしChatGPTがClaudeに負けたら？」——すでに借金して突っ込んでいる
  • 孫さんの行動は異次元すぎて何とも言えず、正しい可能性もあると注明
木
木原さん: 孫さんは勝負に出られている。ChatGPTに信頼を寄せているからこそ、外から見ていると怖さがあります。

14｜負けない打法＝ローリスク・ミドルリターンRISK CONTROL / チャンピオンの逆襲

投資哲学

ポーカーの達人が一貫して回避するのは「下げうんのリスク」。100円のものを150円にできれば十分で、また別の「100→150」を探しに行きます。

  • AI株は上がる可能性も十分あるが、1/3に下がるリスクを取る必要がない
  • 麻雀でも「AIに勝てるかもしれないが負けることも十分ある」局面は触らない
  • 目指すはローリスク・ミドルリターン。感情的になるやつから負けていく
木
木原さん: チャンピオンというのは「勝てるかもしれない打ち筋」ではなく、「負けない打ち筋」を選ぶ人です。

15｜持つのは小型の半導体関連「200億円クラス」SMALL CAP / 数で勝負する銘柄選び

実践

実はAI関連を全否定ではありません。まだ報われていないが、数が伸びれば利益が出てくる小型の関連銘柄をいくつか保有しているといいます。

  • 時価200億円程度の小さい銘柄で、大きな企業の一分野では意味がない
  • 読みの例：半導体は微細化・小型化が進み壊れやすくなる→そこから連想して関連需要を先読み
  • 1人あたり売上5,000万〜1億円の従業員100〜200人企業なら、当たれば10倍（テンバガー）もあり得る
✓

兆単位の大企業は10倍になっても株価への反映が小さい。小型だからこそインパクトが大きい、という規模の論理です。

16｜フィジカルAIは「従来の製造業」と大差ないPHYSICAL AI / コピペできない肉体

構造分析

頭脳労働から先に奪われるという予想外の逆転が起きたのは、頭脳はコピペできるから。しかしフィジカルAIは違います。

  • 肉体部分はコピペできず、結局モノを作らなければならない
  • それは伝統的な日本の製造業とあまり変わらない
  • 「AI」という名がついたことでブームになり、株価が先行して上がっている
  • 絶対に伸びる分野だが、ローリスクになりづらい——ここが怖い
木
木原さん: フィジカルAIは「AI」という名前がついたから注目されていますが、中身は製造業。だからこそ値上がり済みの銘柄には手を出しにくい。

18｜結論｜「芸人の価値が上がる」AI社会に一番投資しているCONCLUSION / ライブとコアファンの経済圏

最終テーマ

フェイク動画と本物の動画の区別がつかなくなる時代。実際に来て、生で人を笑わせられる芸人は「本物」の保証人です。普通の仕事が失われるからこそ、生のライブ・サービス業の価値が上がる——いま木原さんが一番投資しているのは「人」に関わるライブやファン経済なのだといいます。

  • 教師はなくならない：ダイエットと同じで、「ハートの部分」は人間にしかできない
  • お寿司屋さん：人間が握るから3万円。機械が握ったら5,000円でいい——職人の価値の証明
  • 天然物と養殖の関係と同じで、「本物」への払う意志はなくならない
  • 職業としては失われないが、その中で「面白くない芸人」は削られていく競争社会に
  • ファンが500人のコア層だけで食える時代に。事務所ではなく個人が仕事を取る
木
木原さん: 芸人は上位の「食料」です。M-1のエントリーが過去最高の1万2,000組超え。職業が減っていくから、これからも芸人は増え続けますよ。
