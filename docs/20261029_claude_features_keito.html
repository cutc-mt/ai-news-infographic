意外と知らないClaude の超便利機能まとめ —— Motion・Design・Dashboard まで一気解説

Web版Claudeに続々追加される細かな新機能6本——Documents・Slides・Design・Design System・Dashboard・Motion——を、KEITOが次々と実演してくれる動画の完全まとめ。Claude Code やデスクトップの Cowork を使わず、ブラウザのチャットだけでここまでできるようになっています。

要点
6機能のうち5つはWeb版Claudeのスラッシュコマンドからすぐ使える。中でも「デザインシステム」は色・書体・部品の決まりを1箇所にまとめ、スライドやデザインに反映できるおすすめNo.1機能。Motionだけはチームプラン限定というのが唯一の壁です。

最近のClaudeには細かい機能が次々追加され、動画を作らないと追いつかないレベルになっている、とKEITO。今回の6機能はすべてWeb版Claudeで利用可能で、Claude CodeやデスクトップアプリのCoworkを持ち出す必要がありません。深く理解しなくても使える手軽さが魅力です。

視聴メモ:「全部Web版で動く」のが今回最大のポイント。インストール不要・ブラウザだけで、文書・スライド・デザイン・分析・動画まで作れてしまいます。
DOCS 1

Claude ドキュメントスラッシュコマンド「/ドキュメント」で起動

Web版チャットでスラッシュを打つと新しく「ドキュメント」が現れます。右側のパネルでClaudeと一緒に編集する文章が作れる機能で、Notionのような操作感で使えます。

  • 見出し1を当てればタイトルに。リスト化も自由自在
  • 画像の挿入も可能（動画では顔写真を入れて実演）
  • 手入力編集とチャット指示を混ぜて作業できる
/ドキュメント ← Web版チャットで入力すると専用パネルが開く
DOCS 2

ドキュメントの共有とエクスポート「Claudeがついた状態」で渡せるのが新しい

ドキュメントはそのまま共有でき、しかもClaudeがついた状態で共有されるので、受け取った相手もチャットで編集指示を出せます。ここが従来のドキュメントツールとの違いです。

📤 エクスポート先Word / PDF / マークダウン / Google ドキュメント / Notion
🤝 共有相手もチャットで編集指示が可能。ドキュメント作成機能として十分な充実ぶり
活用のコツ:「図を入れて」と頼めば、Claude標準のArtifacts機能で見栄えの良い図を描き、そのままドキュメントへ流し込んでくれます。
SLIDES 1

Claude スライド頼んだ内容が16:9のスライドに即上がる

スラッシュコマンド「/スライド」でスライド専用パネルが開き、自然言語の指示だけで資料が組み上がります。その場で発表モードに入れるのもポイント。

  • 例:「白・黒・青のみの色を使い、図がたくさん使われたスライドを作って。テーマはClaudeスライドの機能解説」
  • 生成は右パネルでリアルタイムに進行。待ち時間も気持ちいい
小ネタ:生成中に「アカウントにデザインシステムがあります。白黒青の指定とぶつかる可能性が」とClaude側から質問が返ってくることも。ここで「使わない」と答えると指定通りに作られます。
SLIDES 2

スライドの編集・出力・連携PPTX / HTML / Googleスライド / Canva まで行ける

出来上がったスライドはその場で編集可能。色・レイアウト・要素の大きさをある程度変えられ、図形・アイコン・グラフ・画像も自動で使ってくれます。「人の手で作ったら時間がかかるクオリティ」（KEITO）。

⬇ ダウンロードPDF / HTML / 画像 / パワーポイント（PPTX）
🔗 書き出しGoogleスライド / Canva など他アプリへ直接エクスポート
発表もOK:右上のプレゼンテーションモードでそのまま発表可能。PowerPointファイルをローカルで作る従来の流れを、Web版だけで代替できるレベルとの評価です。
DESIGN 1

Claude デザイン1枚のキャンバスに複数画面を並べて作る

スラッシュコマンド「/デザイン」で開くデザイン制作機能。1枚のキャンバスの上に複数の画面を並べて作れます。

  • Webサイトやスマホアプリのモック（mockup）をがっつり作り込む
  • 広告・ポスターなどのクリエイティブデザイン
  • 動画・記事用のサムネイル制作

デザイン系の個別サービスでしかできなかったことが、Claudeの中で完結するようになりました。

DESIGN 2

デザイン実演：広告×LP×サムネイルの統一制作「共通のデザインで」と一言添えるだけ

動画では「セミナー用の広告クリエイティブとLPのデザイン、そしてサムネイルも共通のデザインで作って」と指示。縦長広告・横長広告・サムネイル・ランディングページが全部統一されたデザインで上がってきました。

✅ できたもの広告2種 / サムネイル / LPデザイン — すべて同トーンで統一
🎨 当たり前だが…デザイン指定なし提到のため「よくあるAIっぽいデザイン」に。意図したデザインはデザインシステムで解決（後述）
用途:複数コンテンツを発信する人はブランドの統一デザインセット作りにそのまま使える、というのがKEITOの実感です。
BEST

デザインシステム —— 今回のイチオシ機能色・書体・部品の決まりを1箇所にまとめる

「今回紹介する中で1番いい」とKEITOが断言するのがデザインシステム。色・書体・部品の決まりを1箇所にまとめ、スライドとデザインがそれを読んで作ってくれる仕組みです。

  • スライド・デザインの見た目を「意図したデザイン」に寄せられる
  • 1〜2個持っておくと、いつでも同じクオリティの同じデザインで作れる
なぜ重要?デザイン指定なしの生成物はどうしても無難な仕上がりに。システムさえ作れば毎回ブランド通りの見た目になる——これがコンテンツ量産の効率を一段上げます。
DS 1

デザインシステムの作り方サイドパネル「もっと見る」→ デザイン

場所がやや分かりにくいのが難点。Claudeのサイドパネルの「もっと見る」の中にある「デザイン」からデザインシステムのページへ進みます。

1手動で作るカラーを1色ずつ指定して決めていく。ただし全部手で決めるのは大変
2チャットで作る（推奨）シャドウ・余白・タイポグラフィまで細かく作り込める。AIに任せるのが実用的
参考サイトのURLを貼ってデザインシステム化 / 「赤と青ベース、 フォントは大きめ、影を強め、余白は詰めて」など 自分の言葉で指定してもOK
DS 2

写真からデザインシステムを作る寿司の写真で実験 — 「見て良いと思ったもの」をシステム化

今回は誰でも思いつくURL指定をあえて外し、街中で見かけたおしゃれなものを撮影した写真からデザインシステムを作る実験を実施。「この画像からデザインシステムを作ってください」の一点張りです。

🍣 結果寿司写真の配色が抽出され、カラーコードとタイポグラフィが自動生成
📌 応用飲食店のLPなら「自分の料理の写真」からブランドイメージに合ったシステムが作れる
発想:夜景など「見た目で良いなと思ったもの」を写真に撮ってシステム化する使い方は、デザインのボキャブラリーがなくても成立するのが面白いところです。
DS 3

デザインシステムの中身Overview から Assets まで丸ごと生成

初回生成だけではシャドウやコンポーネントが不足したため、「不足なく全部作り込んで」と追加指示。完成したシステムには次の要素が揃います。

  • オーバービュー — テキストベースの全体像
  • カラー — 使用カラーコード一式
  • タイポグラフィ / スペーシング — 書体と余白の規則
  • 丸み・シャドウ — 角丸・影・透明度・レイヤー構造
  • コンポーネント・アセット — ロゴ・アイコン・ボタン等
DS 4

反映ワークフロー：「@デザインシステムで」スライドとデザインが一斉に着替える

作ったデザインシステムは、各成果物にメンションで反映できます。実演では先ほどのスライド資料とClaudeデザインの両方に適用。

@デザインシステムで 寿司のデザインシステムを 反映させてください

「〜のデザインシステムを読み込んでデッキに反映します」と応答が返り、バナー・広告・スライドがすべて寿司デザインに変わりました。一度作れば何度でも同じ見た目で量産できます。

作例:KEITO自身はデザイナーに作り込んでもらった自社コーポレートサイトをデザインシステム化し、資料を毎回そのデザインで統一しているそうです。
DS 5

デザインシステムの活用範囲資料・マニュアル・LP・レポート全部これ

スライド資料だけでなく、活用シーンは広いと強調されます。

  • マニュアル類 — 細かく作る毎回の見慣れたデザインで統一
  • ちょっとしたLP — いつも通りのブランドデザインで即席
  • レポート — 見やすくまとまった成果物に
⬇ 書き出し「共有」→「プロジェクトHTML」でZIPフォルダとしてダウンロード可能
🔁 再利用Claude Code でも使い回せ、他社AIツールに読み込ませて画像生成のルールにすることも可能
DASH 1

Claude ダッシュボードCSVを渡すだけの即席レポート

Web版チャットのスラッシュコマンドに「ダッシュボード」が追加されています。ドキュメントやスライドと同じく専用パネルが開き、その場でダッシュボードを作成。

  • 実演:月額売上（サービス別）と上位顧客のCSV2つを添付し「月売上ダッシュボードを作って」と指示
  • 結構いい感じに自動で組み上げてくれる
  • マウスを乗ると数値の内訳がツールチップで見られる
向けている人:売上データなど分析結果をチームで共有するシーンがあるなら、まず試したい機能です。
DASH 2

ダッシュボードはチャットで改造できる「条件を満たす行に色をつけて」が即反映

ダッシュボードも左側チャットで編集可能。実演ではYouTubeチャンネル分析ダッシュボードを作り、こんな指示を出しました。

視聴率が45%を下回る動画の行に色をつけてください

即座に該当行がハイライトされ、注目すべき箇所を目立たせたまま共有できるようになりました。分析→加工→共有までワンパネルで完結します。

共有:右側の共有ボタンから仲間にそのまま渡せます。作る・直す・見せるの全部がチャットパネルの中で回るのが強みです。
MOTION 1

Claude モーションここだけチームプラン限定の新機能

最後は最新機能のモーション。個人プランでは使えず、チームプランへの加入が必要です。Artifacts のメニューに「モーション」が追加され、右パネルで動画を作れます。

⚠ プラン制限現状チームプランのみ。個人プランへの提供に期待
📦 ちなみにチームプランには Claude Science など
限定機能が他にも多数（別動画で解説予定）
注意:「気になる方はチャンネル登録しておいて」とのこと。プラン差の全容は次回動画でまとめられる予定です。
MOTION 2

モーション実演：CSVから15秒アニメBGM付き・編集可能・MP4/GIF で保存

売上推移のCSVを渡し「12月の売上データを役員会資料に入れる15秒のアニメーションを作って」と指示。BGM付きのアニメが完成しました。

💾 書き出しMP4 / GIF でダウンロード。他アプリへの接続にも対応
✂️ 編集できる再生バーの長い部分をカットして早送り風に変更できた

2本目の検証は架空SaaSアプリのオンボーディング用操作ガイド動画。「操作手順でコンテンツを追加できる」ような説明動画が自動生成できました。

最重要ポイント:モーションは動画生成AIではなくプログラムで作られた動画——だからこそ途中から編集できる。ここが他の動画生成ツールとの決定的な違いです。
SUMMARY

まとめ：全部Web版Claudeで完結する時代意識的に使うだけで仕事の仕方が変わる

  • ドキュメント — Claudeつきのまま共有できる共同編集文書
  • スライド — 自然言語で資料を作り、そのまま発表・PPTX化
  • デザイン — 広告・LP・サムネイルを統一トーンで量産
  • デザインシステム — 見た目の規則を1箇所管理して全成果物へ反映
  • ダッシュボード — CSVからの即席分析とチャット加工
  • モーション — 編集可能なプログラム動画（チームプラン限定）

どれもWebのClaudeで使える簡単な機能なので、普段の作業に意識的に組み込んでみてください、というのが動画の結論です。なお動画末尾では、非エンジニア向けのClaude Code基礎研修（全12回・第1回は11月24日）も告知されました。安全な設定・スキル作成・請求書作成・オリジナルデザインのスライド資料・「ハーネス」という考え方まで学べる講座で、詳細は動画概要欄の公式LINEで案内されています。

最後に:機能の追加ペースが速いClaude。「知っているかどうか」だけで生産性が変わるので、この機会にスラッシュコマンドを一つずつ試してみるのがおすすめです。動画内のスライド資料はメンバーシップ向けDiscordで配布されます。
