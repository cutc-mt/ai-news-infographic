01

Grok Botとは何かOverview

xAIが提供するAIエージェント型のボットサービス「Grok Bot」。画像生成・資料作成・動画作成に加え、クラウドコンピューター（クラウドPC）を持ち、様々なアプリとの接続が可能です。デスクトップアプリとWebアプリがあり、指示を出すと中央のボットがまとめ役・情報収集・作業担当をこなします。動画主のKEITO氏はもともと「勝手にやられてる感」があるボット系サービスが苦手だったものの、真剣に使ってみた結果「めちゃくちゃ便利」と評価が一変したといいます。

GPTのボット機能やMetaのボットサービスなども話題だが、まずはGrok Botから活用を始める価値がある、というのが動画の結論です。

02

最大の特徴は「クラウドPC」を1台持つことCloud Computer

Grok Botの最大の特徴は、その裏側に自分の目の前のパソコンと同じような実デスクトップPCを1台持っていることです。

  • Google Chromeが入っているのでブラウザーを立ち上げられる
  • ファイル管理システムでいろんなファイルを保存できる
  • ターミナルも入っており、Claude Codeなどを起動して裏で作業させられる

このクラウドPCの存在が、後述するすべての活用テクニックの土台になります。

03

パソコンを閉じていてもスマホから指示できるRemote Control

作業環境がクラウド側にあるため、手元のパソコンを閉じていても、スマホのGrokアプリから指示を出せばクラウドPC上で作業を続行できます。「Claude Codeを常時稼働させるには、どこかのパソコンをずっと起動しておく必要がある」という課題が、この構成で解決します。外出先からスマホでAIエージェントに仕事を任せたい人にとって大きなメリットです。

04

Xコネクターがサブスク内で無料にX Connector

注目のアプリ連携はX（旧Twitter）コネクターです。従来はX APIという重量級（高額）のAPIを接続する必要がありましたが、つい最近、Xのサブスクリプションに入っていればX連携がそのまま使えるようになりました。自分のXアカウントと接続するだけで、X上の情報収集をボットに任せられるようになります。

05

1Password連携でログイン作業の悩みを解消1Password Connector

パスワードマネージャー「1Password」とのコネクターが、クラウドPCとの相性抜群です。従来のクラウドPC利用では「チャットで承認を取り、操作権限を人間に渡してID・パスワードを手入力し、終わったらボットに戻す」という面倒な往復が必要でした。1Passwordを接続するとその往復が不要になり、ボットの承認要求に対してFaceID・指紋認証で許可するだけでログインを任せられます。認証情報はマスキングされた文字列で渡されるため、画面に漏れにくい設計です。この快適さに感動して、KEITO氏はボット系サービスを使うようになったといいます。

06

ターミナル内蔵 → クラウドPC内でClaude Code / CodexTerminal & CLI Agents

クラウドPCにはターミナルが入っているため、Claude CodeやCodexといったCLI型AIエージェントを中で使わせることができます。Claude Codeのインストールも「インストールして」と依頼すればGrok Bot自身が実施してくれ、アカウント紐付けは通常どおりログインと承認で完了します。なおデスクトップ版のダウンロードはうまくいかなかったため、基本はCLIで使うのがおすすめとされています。

07

自発的に動く：毎朝の通知とタスク実行Proactive Routines

Grok Botは、接続済みアプリや過去のやり取りを参照して自立的にタスクをこなしたり通知を送ったりします。KEITO氏はGoogleカレンダーとGmailを接続しており、「今日・明日・今週にやるべきこと」「準備はできていますか」という通知を毎朝受け取っているといいます。この「自発的に動く」性質は、一度やり方を覚えさせれば以降は自動で回せることを意味し、セットアップ後、数日〜数週間使うことで価値が実感できるとされています。

08

実践①：X調査を頼む ＆ 専用ボットを作るHands-on: X Research

まず実践したのはXの情報収集です。左上のプラスマークから「X調査用」のような専用ボットを新規作成し、アプリ接続でXアカウントを連携。中央のボットに「XからGrok BotのAI活用についての事例を集めてまとめてください」と依頼すると、リンク付きで事例を収集・整理してくれました。自分で処理できる場合は中央ボットが直接やり、必要に応じて専用ボットへタスクを投げる、という分担が自動で行われます。

09

実践②：ボットの「チーム」を作って毎朝9時に通知AI Team & Routines

「AIの最新アップデートや事例を毎日10件集め、毎朝9時に通知して。そのためのチームを作って」のように自然言語で伝えるだけで、専用ボットのチームが自動編成されます。実際に「X情報収集担当」「X情報リライト担当」というボットが次々と誕生し（いわゆるサブエージェント）、人間が見やすいよう構造化して通知する体制が完成。定期実行は右パネルの「ルーティン」でオン／オフを管理できます。通知が多すぎないよう、量の調整は各自で行いましょう。

10

実践③：スライド作成チームでPowerPoint納品Hands-on: Slide Decks

「スライド資料作成チームを作って」と指示し、デザインシステム担当・構成案担当・画像生成担当・ビジュアル担当・PowerPointで仕上げる担当という分業チームを編成。実際に「Grok Botを分かりやすく説明する8ページのスライドを作って」と依頼すると、画像生成とビジュアル担当が並走して動き、完成後はPowerPointデータのダウンロードリンクを提示してくれました。情報量を絞りビジュアルで見せる、いわば「Claude Codeっぽい」シンプルで分かりやすい資料に仕上がったといいます。

なおボットをプロジェクトごとのフォルダーに自動でまとめる機能は現状なく、セクション手動整理で運用するのが実務的な落とし所でした。

11

実践④：1Password経由で初回ログインを実演Hands-on: Authenticated Login

Notionは既にログイン済みだったため、未ログイン先としてUdemyで実演。クラウドPC上でChromeが立ち上がりログイン画面が出ると、1Passwordの確認要求 → 指紋認証（Touch ID）で承認という流れでID・パスワードが自動入力されました。Gmailに届いた6桁コードの入力だけは自分で行いましたが、パスワード自体は1Password経由で無事に通過。毎回ブラウザー操作権限を引き継いで手動ログインしていた手間がなくなりました。そしてFaceID・指紋認証を通さない限りボットは認証情報を使えない仕組みなので、勝手に使われる心配はありません。

12

実践⑤：ログイン先の情報をNotionにまとめるHands-on: Notion Integration

Notionコネクターを使うと、クラウドPC上でログインした先の情報を収集してNotionにまとめることも可能です。実演では「今開いているUdemyでまだ見ていない動画をまとめ、リンク付きでNotionに整理して」と依頼。ボットが講座を1つずつ確認し、未視聴の講座リストをNotionページにリンク付きで書き出してくれました。Notion以外のアプリや、ログインが必要な他サービスの情報整理にも応用できます。

13

実践⑥：メールコネクターでオリジナルメルマガ配信Hands-on: Email Newsletter

メールコネクターではGrok Bot専用のメールアドレス（例: keito-aiweb@mail.grokbot.com のような形式）を取得できます。このアドレスに指示を送ればボットが動き、逆に自分のアドレス宛へ情報をメルマガっぽく定期送信させることも可能。実演では「AI・IT・Web・Web3・仮想通貨・株式のニュースをトピックとしてまとめたオリジナルメールマガジンを、毎日朝8時に送って」と依頼し、ルーティンが自動作成され、テスト送信にも成功しました。

14

コミュニティで話題の活用事例Community Use Cases

  • 航空券・ホテルの予約やチケット購入、翌日の最安ホテル予約を任せる
  • 作るAIと見直すAIを分ける：資料はClaudeで作り、Grok Botの複数ボットにレビューさせる
  • 自社の口コミを毎日収集・分類し、競合のキャンペーンを毎朝シートに記録する競合観測
  • YouTubeへのアップロード作業を任せる：サムネイル・タイトル・説明文・チャプターを考え、非公開でアップ → 本人が公開ボタンを押す
  • iPhoneのショートカットに登録し、「Hey Grok」と声だけで指示するSiri的な使い方

Xコネクター経由で収集した事例です。口コミ観測は「Grokならでは」の使い方とKEITO氏は評しています。

15

セットアップ：Xプレミアムプラン（約5,280円/月）で利用可能Setup & Pricing

Grok Botの利用にはXのプレミアムプラン以上への加入（月30ドル ≒ 約5,280円）が必要です。従来はxAI側のAI課金プラン等への加入が必須でしたが、最近になってXの有料課金と紐づき、Xプレミアムだけで使えるようになりました。手順は、Xの「サブスクリプション管理」からプレミアムへ加入 → Grok Botアプリ（またはWeb版）をXアカウントでサインイン → クラウドPCを起動 → ボット作成とアプリ接続を1つずつ手動で設定、という流れです。

16

推奨構成：重いタスクはClaude Code / Codexに任せるRecommended Architecture

プレミアムプランだとGrok Bot自体の使用量が少なく大規模タスクは難しいため、重い作業は別のAIに任せる構成がおすすめです。クラウドPC上にClaude CodeやCodexを導入しておけば、Grok Botのコンテキストと使用量を節約できます。

重いタスク → Claude Code / Codex ログイン → 1Password ナレッジ → Google Drive / Notion / Obsidian

共有ナレッジを溜める場所を用意し、それを扱うのがGrok Bot、という分担が推奨されています。

17

最終実演：クラウドPC内のClaude Codeでコードベース動画を生成Final Demo: Claude Code Inside

ラストの実演では、自作PCのパスを指定して動画生成スキルをクラウドPC内のClaude Codeに保存させ、「このスキルを使って『Claude Codeってすごい』という紹介動画をテンプレートで作って」と依頼。ファイルシステム上に動画ファイルが完成し、再生すると「ターミナルで動くAIコーディングエージェント」「複数ファイルをまとめて変更」「テストを回して失敗したら自分で直す」といったナレーション入りのモーション動画に仕上がりました。スキル特有の表現が確認できたことから、内部のClaude Codeが確かに使用されていたと検証されています。動画生成ではなく、コードベースでグラフィックを組むこの手法はGrok Bot単体では困難です。

18

総評：Grok Botは「AI社員」の採用入口Final Verdict

従来は「人間を1人雇い、その人にAIを使わせる」発想でしたが、その人間の代わりをGrok Botが務め、様々なAIやツールを使いこなす「AI社員」を作るという考え方が現実的になってきました。スマホからClaude Codeを遠隔稼働させる問題もクラウドPCで解決します。ボット系サービスに苦手意識があった人ほど、まずX調査・スライド作成・1Passwordログインあたりから試す価値があるでしょう。セットアップ後は数日・数週間、放置して運用してみることで、自発的な通知と定期タスクの価値が実感できるはずです。
