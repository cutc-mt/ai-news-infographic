Node.jsオープンソースのクロスプラットフォームJavaScriptランタイム

RUNTIME
  • Linux・macOS・Windows向けのオープンソースJavaScriptランタイム。3つのトラックで提供

  • LTS 長期サポート版は安定性とセキュリティを重視。Nightlyビルドで最新コードも追跡可能
  • すべてのリリースが署名済みで、公開チェックサムにより検証できる
  • OpenJS Foundation支援のもと、オープンガバナンス体制で運営

CARD 2

ThinkRailPiエージェント中心に構築されたJetBrainsの自律型IDE

AGENT IDE
  • Piコーディングエージェントを中核に構築されたJetBrainsのオープンソース自律型IDE
  • 各タスクが独自のGitワークツリーで実行されるため、チェックアウト状態を変えずに複数エージェントを並行実行できる
  • プロジェクトの永続的な知識をspec.mdファイルや再利用可能なスキルとして保持
  • デスクトップアプリ、またはブラウザ上のCLIとして独自のモデルプロバイダーで実行可能
要点
自分のプロジェクトを学習していくエージェントワークスペース。CLIをインストールしてリポジトリを開くだけで使い始められる。
CARD 3

Macroメール・チャット・ドキュメント・CRMを統合するOSSワークスペース

TEAM WORKSPACE
  • メール・チャット・ドキュメント・タスク・通話・エージェント・CRMを1つのインターフェースに統合したオープンソースのチームワークスペース
  • すべてが双方向グラフでリンク。顧客からのメールを、プルリクエストとリンクしたタスクに変換できる
  • ドキュメントはMarkdown形式で共同編集可能
  • AIエージェントはチームレベルのメモリを共有し、MCP経由でClaude CodeやCodexから利用できる。セルフホストも可能
要点
小規模チームなら、バラバラの複数ツールをこれ1つのシステムに置き換えられる。サインアップまたはローカル実行で開始。
CARD 4

Project Maya巨大オープンモデルを自前GPUでプライベート実行

LOCAL LLM ENGINE
  • 大規模なGLM FlashやDeepSeek FlashのMoEモデルを、自身のGPUでプライベートに実行するためのオープンソースエンジン
  • 対話で最も使用するエキスパートをVRAMに、次をRAMに、残りをNVMe SSDに保持
  • Nvidiaカード1枚から16枚まで、ハードウェアに合わせて自動調整
  • 独自の量子化、ブラウザチャット、OpenAI・Anthropic互換APIを備える

開発者はデータセンターを介さずに巨大モデルを扱える。クローンしてsetup.shを実行するだけ。
CARD 5

HorizonMinecraft Java EditionをRustでゼロから再構築

RUST REMAKE
  • Minecraft Java EditionをRustでゼロから再構築した、オープンソースの非公式リメイク
  • Java版と同じワールドを読み込み、同じ地形を生成
  • 何百もの差分テストプログラムでバニラ版との整合性を検証
  • シングルプレイヤーサーバー、リソースパック、データパック、独自のWebAssemblyモッドを実行可能
要点
Minecraftのコードやアセットは含まれないため、ゲーム本体のコピーは自分で用意する必要がある。Horizonランチャーをダウンロードしてプレイ。
CARD 6

Lanternコード変更を段階的に解説するアニメーションツール

TS LIBRARY
  • コードの変更点をアニメーション付きで段階的に解説するためのオープンソースTypeScriptライブラリ
  • Manimのコアモデルを依存関係なしで移植。ブラウザ・Cloudflare Workers・Node環境でSVGとしてレンダリング可能
  • シーンをステップごとにクラスとして記述すると、各ステップに固有のリンク・テキスト形式・AIエージェントが読み取れる状態トレースが付与される
要点
開発者がプルリクエストを視覚的に説明できるようになる。リポジトリをクローンしてnpm run devで試そう。

CARD 7

AI Design SkillsAIエージェントがランディングページを作るのを支援

DESIGN SKILL
  • AIコーディングツール向けデザインスキルのオープンソースコレクション
  • ランディングページ・デザインスキルでゼロからページを作成:ヒアリング→ページ構造の計画→コンバージョンを促す文章→ビジュアルシステムの適用

CARD 9

TasteSkillコーディングエージェントに真のデザインセンスを

DESIGN SKILL
  • コーディングエージェントがありふれたランディングページの組み立てではなく、ウェブサイトやアプリの画面をデザインできるようにするエージェントスキル

CARD 10

Motion Sites Web Builder映画のように動きのあるランディングページを作るClaudeスキル

CLAUDE SKILL

創業者や開発者は洗練されたページを手にできる。インストールして作成を依頼するだけ。

AGENTS & LEARNING — 自律エージェントと学習を支えるツール

CARD 11

Deep Tutor独自の教材で構築するセルフホスト型AIチューター

SELF-HOSTED
  • パーソナライズされたAIチューターとして機能する、オープンソースのセルフホスト型学習ワークスペース
  • チャット・クイズ・引用付きリサーチ・ステップごとの問題解決・視覚化・習得パス・ドキュメントや動画の没入型読解がすべて1つのエージェントランタイムで共有される
  • 独自の知識ベースに基づいて回答し、教材をクイズやアニメーション付きの「生きている本」に変換
  • 3層のメモリで学習状況を確認できる
要点
自分の教材に基づいたチューターを利用できる。Dockerイメージを実行してDeep Tutorを開くだけ。
CARD 12

Cindy自分のコンピュータで動作するオープンソースAIエージェント

DESKTOP AGENT
  • あなたのコンピュータ上のファイルやアプリを使って実際に作業を行うオープンソースAIエージェント
  • Claude CodeやCodex上で動作し、モデルの混合やタスク途中での切り替えが可能。メモリやスキルは引き継がれる
  • ブラウザ・コンピュータ・スマホを操作し、チャットアプリやスケジュールからタスクを受け取る
  • 既存のコーディングプラン、独自のAPIキー、またはローカルモデルを使用できる
要点
Cindyをダウンロードして、日常のタスクを丸ごと任せてみよう。
CARD 13

T-Stackプルリクエストを出荷するための日常エージェントスキル

PR SKILLS
  • プルリクエストの出荷に特化した、Claude CodeとCodex向けのオープンソース日常エージェントスキルセット
  • fullsend と言うと、エージェントが変更を証明し、レビューし、PRを作成→CIを監視→マージまで実行
  • fullstop を使うとマージ前に一時停止
  • Council:異なるプロバイダーの3つのモデルから合意に至るまでレビューを取得
  • Takeoverは他人のPRを完了させ、Babysitは実際の指摘事項を修正
要点
PRまわりの煩雑な作業をエージェントに委任できる。スキルをエージェントフォルダにコピーするだけ。

Elephant Goldfish Model深いコンテキストのエージェントで設計し、新しいエージェントでレビュー

GOOGLE PLUGIN
  • コードを書く前にAIエージェントでソフトウェアを設計するための、Googleのオープンソースプラグイン
  • エレファントエージェントがプロジェクトのコンテキストを保持して仕様書を作成
  • ゴールドフィッシュ・サブエージェントがそれまでの会話の記憶なしにレビューを行い、隠れた前提やリスクを洗い出す
  • スキルにはブレインストーミング→ドラフト作成→レビュー→発見事項の解決が含まれる。トレードオフの判断と設計承認は人間の役割
  • Claude Code・Codex・Antigravityで動作

WRAP-UP — そのほかの注目プロジェクトとまとめ

CARD 18

まとめ: 今週の3つのキーワードと、そのほかの注目3選Beautiful Rust・LinkSwift・Learn Harnessed + 新チャンネル告知

WRAP-UP
プロジェクト概要
Beautiful Rust 慣用的かつ堅牢で保守性の高いRustをClaudeに書かせる、オープンソースのClaude Codeプラグイン。Rust・Cargo・クレート・ボローチェッカー関連のタスクで自動的に読み込まれる。GoogleのRustスタイルガイド・Rust APIガイドライン・Effective Rust・Rustデザインパターン・Microsoftの実践的ガイドラインから、所有権・エラー・非同期・unsafeコード・テストに関する知見を抽出。プラグインマーケットプレイスからインストール
LinkSwift 百度網盤・AliyunDrive・Quark・123クラウドなど中国のクラウドストレージのファイルを直接ダウンロードするオープンソースのユーザースクリプト。各サービスの公開APIを基に構築され、ドライブのページによりクリーンなインターフェースとテーマを追加。リンクのコピーや、IDM・Aria2・BitComet・AB Download Managerへの送信が可能。Tampermonkey経由でインストール
Learn Harnessed AIエージェントを使って難しいトピックを教えてくれるオープンソースのデスクトップアプリ。まず理解度を測定し、目標への計画をマッピングし、思考に適応した練習セッションで推論のステップを一つずつ教える。考えを声に出して説明すると永続的な知識グラフを構築。独自のAPIキーで動作しデータはローカル保存
  • デザインスキル元年 AI Design Skills・Hallmark・TasteSkill・Motion Sites と、エージェントが作るページの見た目を鍛えるスキルが一挙に揃った週に
  • 自前で動かす Project Maya・Deep Tutor・Cindy など、データを手元に置いてセルフホストで完結させる流れが加速
  • 検証と品質 Horizon の差分テスト、Hallmark の57項目チェック、Elephant Goldfish の相互レビューなど、出力の正しさを保証する仕組みが普及中
  • 動画冒頭では、AIエージェントのプロジェクト・チュートリアル・ツール専門の新チャンネル「AI Agent Studio」の開設を告知——リンクは概要欄
要点
20プロジェクトを通覧すると、今週の争点は「どれだけ賢いか」より「どうデザインし、どう検証し、どこで動かすか」へ移っている。来週のラウンドアップも要チェック。
