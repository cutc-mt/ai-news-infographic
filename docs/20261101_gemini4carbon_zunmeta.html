こんにちは、「よもぎ」です！Gemini 4 Carbon（カーボン）は2026年10月に発表された、Googleで一番強いモデルさん。でも「一番強いのに、まだ普通には使えない」不思議なモデルなのだ。18枚のカードで整理するわよ。
CARD 01

アルゴンより2週間で交代

「Gemini 4 Argon が一番強い Gemini」と思っていた矢先、アプリ登場からわずか2週間後に、Googleがさらに強い「Carbon」を発表。最強モデルの座があっという間に入れ替わりました。

🌿たった2週間で最強が交代なのだ…。
CARD 02

Carbon はどんなモデル？

2026年10月発表。Googleの発表文では「Googleで一番強いモデル」と紹介されています。モデルとはAIの頭脳部分のことで、GPTやClaude、Geminiなどのこと。得意分野はセキュリティと長い時間をかける作業と、強さの方向性がはっきりしています。

🌿強さの方向がはっきりしてるのだ。
CARD 03

総合点ではほぼ横並びの1位

CARD 04

Google自己評価の17項目表

Googleが出した評価表では17項目の試験で他社モデルと比較し、Carbon は15項目で1位。ただし2項目は GPT と Claude が上。さらにこの数字は Google 自身が出したものである点にも注意が必要です。

🌿「一番強い」でも全部1位じゃないのだな。
CARD 05

でも一般にはまだ配られていない

「じゃあすぐ乗り換えたい」と思っても、どこを探しても Carbon が見つかりません。まずはサイバーセキュリティなど「守る側」の人たちの一部にだけ配られています。

🌿一番強いのに使えないのだ！
CARD 06

得意その1：数日かけてやり抜く「長い作業」

公式ブログによると、Google 社内チームでは Carbon が数日間動き続けました。行き止まりにぶつかっても諦めずに別の道を試し、大きなプログラムの見つけにくい不具合を直すといった、難しい開発作業をやり抜いたといいます。ただしこれは社内で見られた話で、一般向けはまだ先の話です。

🌿数日任せられるのだ！…これはまだ社内の話なのだ。
CARD 07

長い作業のイメージ

  • 大きなプログラムの中を調査
  • 「ここが原因」→ 実は違う、行き止まり
  • 諦めずに別の道を試す
  • 本当の原因を特定
  • 直し方をコードで書く

Claude Code や Codex のような「開発を任せる道具」の頭脳として動くのが想定されています。

CARD 10

Web 開発では…4位

同じページには Web サイト作りの指標も。人が作品を見比べて選ぶ「WebDev Arena」では89点上がって4位に。得意は長い作業と守りの方で、何でも1位というわけではありません。

🌿あれ?ここは1位じゃないのだ。
CARD 11

得意その2：セキュリティ — 守る人の仕事は3つ

ソフトの弱点は、家で言えば「壊れた鍵」。守る人の仕事は3つに分かれ、Carbon はそれぞれで高い成績を残しました。

  • ①弱点を見つける：88.2%（GPT-6、Argon 83.4%を抑え1位。見つからない弱点は直せない）
  • ②本当に悪用できるか確かめる：どれから直すかの優先順位づけに使う
  • ③原因から直す：71.0%（Argon 68.0%、Claude Opus 系67.0%）

なお試験では Codex や Claude Code などの道具と組み合わせ、Carbon は Google の Antigravity 上で動かして検証されています。

CARD 12

Chrome チームの実感「10倍以上」

ブラウザ Chromium を開発するチームの報告では、直し方（修正案）を作る力が他社の大きなモデルと比べて10倍以上良かったとされています。ただし比較相手の名前は非公開で、Google 社内報告である点は覚えておきましょう。

🌿10倍以上?どのモデルと比べたのだ?
CARD 13

得意その3：ずるをしない

AI は試験で点を取るための近道（ずる）をすることがあります。Carbon はコマンド試験でずるの成功率0.0%、ずるを試したのもわずか0.4%。社内の開発現場では重い警告が8割近く減りました。

CARD 14

仕事の相棒としての3つの変化

  • 根拠のない自信が Argon より大きく減少。分からない時は資料を調べ、食い違いを先に伝える
  • 頼まれた範囲からはみ出しすぎない
  • 隠れた命令（プロンプトインジェクション）に騙されない：攻撃成功率0%（Argon は0.7%）

Web ページやメールにこっそり書かれた命令で AI が乗っ取られる攻撃を、試された分ではすべて防ぎました。

🌿悪い人に渡る前に、守る側が先なのだ。

CARD 18

まとめ：持ち帰りはこの3つ

  • ①長い作業と弱点を直すのが得意：数日動き続けて不具合を直すような作業をこなした
  • ②今アプリで使うなら Argon で十分：返事を待つ時間も Argon の方が短い
  • ③一番強くても全部で1位じゃない：数字は Google が出したものだった

「最強の発表」に焦らず、今は Argon で使い慣れておくのがおすすめ。長い開発や守りの作業は Carbon が一般に開放されてから試せばいい、というのが動画の結論です。
