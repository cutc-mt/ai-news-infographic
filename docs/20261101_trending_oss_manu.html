① Lightpanda BrowserFEATURE PICK 1・AIエージェント専用ヘッドレスブラウザ

注目ピック

ChromiumやWebKitのフォークではなく、Zig言語でゼロから書かれたヘッドレスブラウザ。グラフィカル描画をスキップしつつV8・DOM・AjaxでJavaScriptをサポートし、大規模実行時のリソース消費を激減させます。

  • CDP対応でPuppeteer / Playwrightのスクリプトがそのまま動く
  • 自然言語で指示するエージェントモードは決定論的・モデル不要なスクリプトを出力
  • MCPサーバーとしても動作可能
よ
ブラウザ丸ごと動かすよりメモリが全然違うんだって！スクレイピングやクロールを大量に回したい人には朗報だね。

② KeroFEATURE PICK 2・エージェント専用ネイティブターミナル

注目ピック

macOS / Windows / Linux対応のネイティブターミナル。Claude Code・Codex・開発サーバー・テスト監視を個別セッションで走らせられます。

  • バックグラウンドデーモン「carod」がセッションを保持 — ウィンドウを閉じてもスクロールバックが消えない
  • libghosttyでレンダリング、Ghosttyのテーマ・設定がそのまま使える
  • CLI経由でエージェント自身がセッションを開始・入力・読み取り可能（SSH/Tailscaleのリモートホストも）
よ
ターミナルを間違えて閉じて長いログが消えた…みたいな悲劇を防いでくれる、地味にうれしいやつだよ！

③ FloorplanFEATURE PICK 3・Claude Codeプラグインでコードの地図

注目ピック

コードベースをスキャンし、Claudeが全体構造の対話型マップを作成するClaude Codeプラグイン。専門用語ではなく日常の言葉で全パーツと接続関係を説明します。

  • アプリ全体→単一ファイルへズーム、決済フローなどを別リポジトリ間で追跡
  • マップに質問して解説を受けられる
  • 機密情報の公開・開放エンドポイントのヘルスチェック、Claudeが変更した箇所を強調表示
  • ローカルでNodeスクリプトとして動作、Gitコミット不要
よ
「アプリは動くけど仕組みは誰も理解してない」を埋めるための地図、か。レガシー攻略にぴったりだね！

④ DuckpadFEATURE PICK 4・リネージ付きビジュアルSQLワークスペース

注目ピック

DuckDBベースのオープンソースSQLワークスペース。バラバラなデータソースを単なるスクリプトではなく視覚的なパイプラインに変換します。

  • 出力セルをクリックすると、その結果を生んだ結合やソースを辿れる完全リネージ
  • ガイド付きフォーム or 統合SQLエディタでパイプラインを構成
  • Git保存・ブランチ作成・レビュー経由のマージ、環境別接続とアクセス制御
  • 独自インフラ上で実行、pipでインストール
よ
「この数字どこから来たの？」問題をクリックで解決しちゃうの、データチームの救いだね…！

⑤ HobFEATURE PICK 5・完全オフラインのローカルAIチャット

注目ピック

Mac / Windows / Linux向けの無料デスクトップアプリ。GemmaやGPT-OSSなどのオープンウェイトモデルを自分のマシン上で実行する、ClaudeやChatGPTのプライベートな代替です。

  • ハードウェアに最適なモデルを自動選択、llama.cppで全設定を自動化
  • ドキュメント読み取り・PDF記入・スプレッドシート要約などのタスク対応
  • 機能拡張のためにMCPをサポート
よ
ネット接続がなくても動くAIアシスタント。機密文書を扱う人はクラウドに出せないから、これは嬉しいね！

エージェント・チーム系AGENT TEAMS・OpenMossBot & OpenRig

グループ解説

OpenMossBotは、連絡先全員がClaude・Codex・Grokを独自性格でローカル実行する本物のエージェントというチャットアプリ。危険操作の前に承認カードを表示する数百の連携を備え、macOS / Windows / Ubuntuで動作、トランスクリプトや鍵はローカル保存。

OpenRig（AIN）は、乱雑なClaude Code / CodexのターミナルをYAML定義の永続チームに変えるローカルデーモン+CLI+TUI。リードエージェントと会話し、tmux上のエージェントとsend / broadcastで通信、状態を名前付きスナップショットに保存・復元。

規律・スキル系DISCIPLINE・Skills for Real Engineers & Mish ECC

グループ解説

Skills for Real Engineersは、Claude Code・Codex・Copilot・Gemini CLI向けの実践スキル集。TDD・コードレビュー・設計を網羅し、レッド・グリーン・リファクターループと共有用語集でエージェントの失敗モードを防ぎます。

Mish ECCは「コーディングエージェントのためのエンジニアリングOS」。計画→テスト→実装→レビュー→検証→記憶の各ステップをゲートで管理して証拠を残すことで、エージェントが工程をサボる問題を解決。永続コンテキストを共有メモリボルトに保存します。

Voice StudioLOCAL AUDIO・完全ローカルの音声スタジオ

単独紹介

音声クローン・吹き替え・ディクテーションを賄うローカルファーストな音声ツール。ホスト型音声サービスの代替です。

  • 646言語対応、音声デザイン・動画吹き替え・文字起こし・オーディオブック作成
  • CUDA / Apple Silicon / ROCm / CPUで16種のTTS・11種のASRエンジンを動かす
  • デスクトップアプリ・OpenAI互換API・MCPサーバーを提供、音声はデフォルトでマシン内

Claude Code拡張系EXTEND CLAUDE CODE・Plugin Directory & Bama

グループ解説

Claude Code Plugin Directoryは、Anthropic内部製とパートナー・コミュニティ製を集めた厳選プラグイン集。メタデータ・MCP設定・スラッシュコマンド・エージェント・スキルの標準構造で、コマンド1つでインストールできます。

BamaはClaude Code / Codex向けスキルセット。Xcodeを開かずSwift + SwiftUIでネイティブmacOSアプリをアイデアから完成ビルドまで導き、参考アプリのスクリーンショットをユーザーストーリー化して1ストーリー1コミットで構築、ライト/ダーク両モードの証跡も保存します。

Agent ReachDATA ACCESS・検索が届かない場所を読む

単独紹介

AIエージェントがログインの裏にあるプラットフォーム（BiliBili・V2EX・GitHub・YouTube・小紅書・Redditなど）を読み取り・検索可能にするPython CLI。

  • プラットフォームごとにツールをランク付けしてリスト化、失敗時は自動フォールバック
  • ログインが必要な場所は独自バックグラウンドブラウザで、パスワード保存ではなくユーザーのブラウザから既存ログインをコピー
  • すべてのアクションは読み取り専用

TelescopeANDROID TV・スマホからテレビを掃除

単独紹介

PCもroot権限も不要で、ADB経由のWi-FiでAndroid TV / Google TV / NVIDIA Shield / Fire TVに接続する無料Androidアプリ。

  • 検証済みの不要アプリリストと照合して安全に無効化（元に戻す機能付き）
  • APKインストール・ファイル送信・クリーンなランチャー切り替え
  • CPU / RAM / ネットワークをリアルタイム表示、処理はローカルネットワーク内で完結・広告なし・登録なし

DossierSELF-HOSTED・セルフホスト型ジョブサーチ

単独紹介

経歴プロフィールを保持し、求人ごとに最適化した履歴書・カバーレターを作成できるセルフホスト型の就活アプリ。

  • 求人を貼り付けるだけでプロフィールと照合し、入力済み情報のみでドラフト作成
  • ドラフトから内定までの応募状況をボードで管理
  • Next.js + PostgresをDockerで実行、Llama / LM Studioなどのローカルモデル or 任意のホスト型モデルに接続、Gmail・カレンダー連携は任意

遊び＆ハードウェア系FUN & HARDWARE・PrintMyProfilePic & SPLabsWeb

グループ解説

PrintMyProfilePicは「スターを付けるとレシートプリンターがあなたの顔を印刷する」ジョークWebhook。Cloudflareトンネル経由でRaspberry Piに届き、PHPがGitHubアバターを取得、escpos-phpでエプソン感熱プリンターから出力、「Hall of Fame」ボードにピン留め。

SPLabsWebはESP32 Desk 3ハードウェアラボのベンチガイドを、ライブピン配置・レッスン・内蔵シミュレーター・ファームウェアリーダー・ベンチログ付きのReactアプリ化。React Router + TanStack Query + Viteで動作します。

ZeroBreach ToolkitSECURITY・スパイウェアの痕跡をオフライン検査

単独紹介

PC・Android・iPhoneのローカルバックアップをスキャンし、Pegasus・Predator・Graphite・Candiruなど公開済みスパイウェアの痕跡を探す無料のPythonツール。

  • ブラウザ記録・システムログ・アプリ・ファイル指紋を約12,400個の公開指標と照合
  • スキャン中のネットワーク通信なし（指標更新除く）・読み取り専用・管理者権限不要
  • 「安全の証明はしない」と出典動画でも明言 — ジャーナリストや活動家向けの確認手段

Video→GameSKILL・AI動画を遊べるゲームに変換

単独紹介

短いゲームプレイ動画を本物のThree.jsゲームとして再構築するようコーディングエージェントに教えるスキル。

  • 動画モデルが外観・カメラ・コアメカニックを先に処理、エージェントがフレーム単位で学習し画像・3Dモデル・音を生成
  • 成果物はHTMLファイル1つに書き出し
  • エージェントはスクリプト化されたキー操作で自分のビルドをプレイし、ベスト数秒を動作証明として記録
  • Claude Code・Codex・Cursor・Gemini向けにプラグイン / スキルとしてインストール

AI PhoneVOICE AGENT・Macで動くAI電話エージェント

単独紹介

Appleシリコン上で動くSIP電話デーモン。AIエージェントが独自の指示で着信応答・発信を行えます。

  • MLXで音声認識と合成をローカル処理、別契約の通話処理サービス不要
  • 会話はローカルモデル / Claude Code・Codexサブスク / OpenAI互換エンドポイントで実行
  • リレーモードなら外部エージェントが通話の各ターンを直接制御、全発信にAI通話である旨の通知を同梱
