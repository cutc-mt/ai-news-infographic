① RufloFEATURE PICK 1・Claude Code向けマルチエージェント・スウォーム

注目ピック

Claude Codeのためのオープンソース・マルチエージェント・オーケストレーションハーネス。マシン・チーム・信頼境界をまたいで専門エージェントのスウォーム（大群）を展開します。

  • 自己学習メモリ＋分散通信＋ベクトルRAGを重ね合わせ、企業ポリシー制御も添付
  • フックがタスクを自動ルーティングし、エージェントを生成して成功例から学習。普段どおりClaude Codeを使うだけで良い
  • CLIがスウォーム・エージェント・メモリを管理。ポリシー層が支出と同時実行数を制限し、機密アクションを制御して全決定を監査
よ
「Claude Codeはそのままに、裏でエージェント軍団が動く」っていう夢みたいな構成！お財布の上限も一緒に守ってくれるのが地味に嬉しいね。

② StrataFEATURE PICK 2・大型AIモデルを民生ハードでローカル実行

注目ピック

強力なAIモデルを普通のPCでローカル実行するためのオープンソースの無料エンジン。大型オープンMoEモデルを、控えめなGPU搭載PCでも動かせるようにします。

  • よく使われるエキスパートをメモリに保持し、残りをSSDからストリーミングする省メモリ設計（動画ではQN 3.8 Flash Next・DeepSeek V4.1 Flash などに対応）
  • localhostでOpenAI / Anthropic互換APIを提供 → そのままコーディングツールと連携、画像処理にも対応
  • Windows・Linux・Macでアプリまたはターミナルとして動作
よ
巨大MoEを「よく使う部分だけメモリに置く」発想が秀逸！クラウドAPIと互換性があるから、ツール側の設定を変えるだけでローカルに切り替えられるんだ。

③ FlutterFEATURE PICK 3・1つのコードベースであらゆる画面へ

注目ピック

GoogleのオープンソースUIツールキット。モバイル・Web・デスクトップ・組み込み向けアプリを単一コードベースから構築できます。今週もGitHubトレンド常連に返り咲きました。

  • Dartで記述し、すべてをウィジェットで構成。独自にピクセルを描画するためプラットフォーム間で一貫した見た目と高速なUIを実現
  • ステートフル・ホットリロードで変更が即座に反映。豊富なMaterial / Cupertinoウィジェットとネイティブコード連携
  • Google内外の数多くの実アプリを支える実績
よ
AIエージェントがコードを書く時代だからこそ、Flutterみたいな「1コードで全部」のツールキットと相性抜群なんだよね。ホットリロードの気持ちよさは一度使うと戻れないよ！

④ KinetographFEATURE PICK 4・ブラウザ不要のプログラマブル動画エンジン

注目ピック

エージェント向けに構築されたオープンソースのプログラマブル動画エンジン。コードで定義した動画をネイティブRust製GPUコンポジターでブラウザなしレンダリングします。

  • TypeScript / Remotion プロジェクト、Hyperframes のHTMLをそのまま処理
  • Canvas・Skia・WebGPUシェーダー・動画デコード・フォント・GSAPタイムライン・Recharts / D3 / motion をネイティブ実行
  • CLIでレンダリング・静止画・モーショントラッキング・依存関係の固定を管理、レンダリングは完全オフライン。エージェント向けMCP対応
よ
「動画をコードで書く」の決定版になりそう！MCP対応だから、Claude Codeに「このデータで解説動画作って」って頼める未来がすぐそこだよ。

⑤ KensakuFEATURE PICK 5・ローカルOCRで「意味」まで探せるファイル検索

注目ピック

無料・OSS・ローカルファーストなファイルランチャー。名前・ファイル内テキスト・さらに「意味」に基づいてPC内のあらゆるものを検索します。

  • ドキュメント、コード、スクリーンショットやスキャンPDFまでOCRで読み取り、キーワード検索＋セマンティック検索を組み合わせてランク付け
  • ホットキー一発で呼び出し可能。クラウド送信もテレメトリも一切なし
  • MCP経由でAIエージェントに読み取り専用の検索バックエンドを提供、ワンクリック接続のCLIも同梱。クロスプラットフォーム対応
よ
「あの資料、スクショに撮った気がする…」も検索できるようになる神ツール！エージェントにも自分のPCの中身を探させる画面（MCP）が用意されてるのが今週っぽい。

⑥ OpenBot × LeverAGENTS & FEEDBACK・Copilot系エージェントの導入と改善

エージェント活用

OpenBot（CopilotKit）は、ブラウザ・ターミナル・ファイルを統合操作する、自分のPCで動かすオープンソースのパーソナルエージェント。Lever は、曖昧な不満を「測定可能なフィードバックループ」に変えるGitHub Copilotプラグインです。

  • OpenBot: AGUIプロトコルで人間が介在する承認を実現、MCPでツール連携。ポリシーと監査レイヤーが実行可能な操作を管理し全動作をログ記録。モデルは自前、セルフホストで拡張
  • Lever: 何を測るか・ノイズ許容度・成功条件を定義して「ループカード」に書き込むだけ。人が目視してCIを再実行する手作業を排除
  • Leverの動詞セットは brief / refactor / shepherd / automate — 提案のみからマージ・リリースまで自律性レベルを調整。プラグイン or リポジトリごとのスキルファイルで導入

エージェント活用

Tarik Research 開発の、トレーディング会社をモデル化するオープンソースのマルチエージェントLLMフレームワーク。

  • トレーダーとリスクマネージャーが議論を意思決定に変換。LangGraph基盤

⑧ Text-toCAD × Android SkillsSKILLS・エージェントに専門技能を授ける

スキル系

Text-toCAD はエージェントにCADのスーパーパワーを与えるスキルライブラリ。Android Skills はGoogle公式のAndroid開発向けエージェントスキル集です。

  • Text-toCAD: パーツのモデリングを依頼するとPythonでパラメータCADを作成・編集。OpenCascade上のBuild123DでSTEP / STL / 3MF / GLB / DXFをエクスポート
  • ブラウザビューアで結果・ロボットファイル・Gコードをプレビュー。ロボット記述・逆運動学・暗黙的CADなどのスキルも
  • Android Skills: skill MDファイルがdeveloper.android.comのベストプラクティスに基づき学習。XML→Compose移行、Gradleプラグイン更新、Wear OSビルドを処理
よ
「文章で頼んだら機械部品の3Dモデルが出てくる」時代！Claude CodeやCodexにインストールして遊んでみてね。

⑨ FreeOLLM APILOCAL LLM・無料ティアを1つのエンドポイントに統合

ローカルファースト

34のLLMプロバイダー・635のエンドポイント・月間数十億トークンの無料枠を、1つのOpenAI互換プロキシの背後に統合します。

  • 自動ルーティングとフェイルオーバー。サイクルカタログが新しいモデルやクォータを同期
  • プロバイダーのキーはSQLite内でAES-256-GCM暗号化。アプリからは1つの統合トークンとして見える
  • ランチャーでClaude Code / Codexの設定に認証情報を保持不要。個人利用向けローカルファースト設計

⑩ Danji（flare）LOCAL LLM・NVIDIA製DGX Sparkローカル推論サーバー

ローカルファースト

DGX SparkのようなSM120 / SM121ワークステーションGPU向けに、NVIDIAがコードネーム「flare」で提供するオープンソースのローカル推論サーバー。Rust製です。

  • 長時間対話・コーディングエージェント・重いツール使用など、デスクトップの負荷が高いワークロード向けに構築
  • ワークステーションのメモリ・帯域幅・演算能力を最大限活用しつつ高速レスポンスを維持
  • 1〜2台のSpark上で大型モデルを実行。DockerイメージとDebianパッケージで提供

⑫ カレンダーアプリ × BIGIDESIGN & LIFE・デザイン学習と家具組み立て

フロントエンド

人事向け休暇管理カレンダーは、人事・労務ワークスペースのUIをFigmaで忠実に再現したデザインプロトタイプ。BIGI はIKEA家具の組み立てを音声案内付きインタラクティブ3DでガイドするWebアプリです。

  • カレンダー: 休暇申請・残日数確認・週次/月次カレンダーのほかダッシュボードやケース検索も。バックエンドなしの純フロントエンドでデータはローカルストレージ。Next.js / React / TypeScript / Tailwind
  • BIGI: 商品名や商品番号を入力すれば3Dで読み上げられる手順に従える。全IKEA製品対応
  • BIGI: 紙マニュアルをスキャンするとAIが組み立てガイドに変換（独自APIキーが必要）
よ
アレンキーとの格闘が3Dナビで終わる日が来るなんて！カレンダーの方はFigmaのデザインカンプをコードに落とす勉強に最適だよ。

⑬ MiniCPM-OCROCR・解析結果を“自ら検証”するオープンOCRスイート

ドキュメント処理

OpenBMBによるオープンソースOCRスイート。ドキュメントを解析したうえで、その結果を検証するところまでを担います。

  • コンパクトなOCRモデルが中国語・英語のテキスト、表、数式、グラフ、印鑑を読み取り
  • 併用される2Bの判断モデル「Jev」が正確性を0〜1でスコア化。信頼できる部分は自動承認、残りは人間確認か複数エンジンから最適解を選択
  • どちらも重み公開。llama.cpp / vLLM / Llama でローカル実行可能

⑭ SurvivalLLMOFFLINE・ネット不要のサバイバル知識ライブラリ

ローカルファースト

PC内で動くオフラインライブラリを活用した、無料・OSSのローカルAIアシスタント。セットアップ後はインターネット接続が不要です。

  • 約150万件の記事・Wikipedia・iFixit修理ガイド・サバイバル/ハウツー知識から回答を生成
  • AIの誤答に備えてすべての回答に出典（ソース）を表示・確認可能
  • 独自ファイルの追加も可能。MacとWindowsで動作
よ
災害時の「オフラインで使える知識の棚」作りにぴったり！出典つきなのが地味に大事で、AIの答えを鵜呑みにしない設計なんだ。

⑮ LinuxRunneriPHONE・脱獄不要でarm64 Linuxを起動

モバイル

脱獄・仮想マシン・JITなしで、iPhone / iPad上でarm64 Linuxのユーザー空間アプリやデスクトップ環境を実行できるオープンソースのiOSアプリ。

  • カーネルを起動するのではなく、カスタムarm64インタープリターとLinux互換レイヤーがLinuxプログラムを読み込み、システムコールを処理
  • ストレージ・ネットワーク・デスクトップを接続。apt / apk / pacmanでDebian・Arch・Alpineをインストール
  • KDE PlasmaのようなデスクトップやFirefoxのようなアプリも動作。IPAをサイドロードして使う
よ
iPhoneの中にLinuxの世界が入っちゃうの、すごくない？脱獄しなくていいから安全性も保てる設計なんだって。

⑯ AARA × LightPostAROUND YOU・車載とSNSをつなぐ自作ツール

ライフスタイル

AARA はAndroid Autoのスマホ側機能を再実装したOSSの概念実証。LightPost は全SNSアカウントへの投稿を1つのダッシュボードから行うセルフホスト型システムです。

  • AARA: スマホで実行しUSB経由で車のヘッドユニットを制御。地図・メディア投影、オーディオ転送、車のGPS取り込み、タッチスクリーン入力に対応
  • AARA: 自己署名証明書のためオープンソースヘッドユニットや一部純正のみ動作（Google純正は不可）。Android Autoと共存インストール可（※初期段階。運転中に頼り切らないこと）
  • LightPost: 投稿を1つ作って画像を添付すれば複数プラットフォームへ一括・予約投稿。データは単一のSQLiteファイル、Linux向けsystemdサービスも選べる
