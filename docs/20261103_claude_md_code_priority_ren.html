CLAUDE.md とは何かBASIC・AIが毎回読む指示ファイル

基礎知識
  • AI が作業の前に毎回読む、指示を書いたファイル
  • コード（プログラム本体）が変わっても勝手には書き換わらない
  • 例えるなら「社内マニュアルは古いまま、現場はもう新しいやり方」の状態
  • つまり CLAUDE.md は書いた日から古くなっていく運命のファイル
  • AI がどちらに合わせるかで、出来上がるプログラムが変わる
よ
一回書いて満足しちゃいがちなファイルだよね。メンテされないマニュアルと同じで、放っておくと現場とズレていくんだ…！

AIは気づいているのに従うBEHAVIOR・Opus 5.5 の実際の返事

実験1の生の反応
「今回新しく書いた部分は CLAUDE.md に従っています。前からある部分は従っていません」 — 実験1・Opus 5.5 のバックアップ課題の返事
  • 食い違いに気づいて書いているのに、新規部分は今のコードではなく古い指示に合わせた
  • 結果、1つのツールの中に指示の書き方とコードの書き方が混在。後で直す人がどちらが正しいか迷う状態に
  • 最後には「残りの部分も CLAUDE.md に合わせたければ、やります」と、前からあるプログラムの書き換えまで申し出る
  • Opus 5.5 は16課題すべてで食い違いを返事に書いていた＝気づいていても従ってしまう

実験3: 日本語訳でも効くRESULT 3・原文とほぼ同じ効果

日本語訳の結果
  • 同じ一文を日本語に訳して足した場合も、古い指示に従った割合は3モデルとも最高でも2.8%
  • いちばん大きい差でも72か所中2か所＝たまたまの違いと区別できないレベル
  • 英語でも日本語でも、同じように効くと考えてよさそう
よ
「英語で書かないと効かないかも」って心配は要らないみたい。日本語で自分の言葉で書いても大丈夫なんだね！

実験4: 自分のルールは効かなかったRESULT 4・「前提を疑え」だけでは止まらない

私のルールの結果
  • 評判の良かった私のルールを入れても、結果は実験1とほとんど同じ
  • Sonnet 5.5 は84.7%とまったく同じ値。Opus 5.5・Fable 5.1 もわずかに下がるのみで、課題16個では偶然の差と区別できない
  • ただしルールが読まれていないわけではない: プロンプトは全部英語なのに、48回中17回、返事が日本語で返ってきた（他の実験ではほぼ0回）
  • 日本語のルールにつられて日本語で返事＝ちゃんと読まれていた
MEMO
読まれてるのに効かない、というのが面白いところ。読まれることと、従う対象が決まることは別なんだね。

効くのは「疑え」より「どっちに従うか」INSIGHT・足りなかった1要素

今回の核心
  • 自有ルールが頼んでいたのは「怪しいところがあったら指摘して」
  • でも指摘は、ルールがなくてもAIはもともとしていた
  • 足りなかったのは、食い違ったときに「どっちに従うか」の指定
  • 論文の一文は、そこを「今のコードに従って」とはっきり書いている
  • 結論: 「疑え」より「どっちに従うか」を書いたほうが効く
よ
「怪しいよ」と言うだけじゃダメで、「じゃあどっちに合わせる？」まで決めてあげるのがコツなんだね。なるほどー！
