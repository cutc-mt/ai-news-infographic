01Canvaは「デザインのミールキット」

Canva（キャンバ）はオーストラリア生まれのオンラインデザインツール。2013年のリリースで、日本には2017年に上陸しました。現在では世界中で月2.2億人以上が利用しています。テンプレートを選んで文字・写真・色を差し替えるだけで、デザインの知識がなくてもそれっぽく仕上げられるのが魅力です。

みきさん材料とレシピが全部揃ったミールキットみたいに、好みに仕上げるだけでOKなんです。

02作れるデザインは1000種類以上

SNS投稿からプレゼン資料、動画作成やウェブサイト作成まで、Canvaで作れるデザインは1000種類以上。トップページのアイコンで作りたいものを選ぶとサイズが自動で決まるので、サイズ知識がなくても直感的に作成を始められます。ブラウザでもアプリでも無料で使えます。

03初心者に選ばれる理由は5つ

  • テンプレートが豊富 ― 選んで編集するだけで高クオリティ
  • ドラッグ&ドロップ操作 ― 置きたい場所に動かすだけ
  • 素材が無料版でも470万点以上 ― 写真・イラスト・音源など
  • Canva AI搭載 ― キャプション案の作成などデザイン作業を支援
  • クラウド自動保存 ― PCで作ってスマホで仕上げられる

04料金プランは4つ、まずは無料版でOK

料金プランは無料・Pro・ビジネス・エンタープライズの4つ。まずは無料版からスタートし、使い込むうちにProの価値が分かってきたら検討するのがおすすめです。Canva Proは月額1,180円（年払いで11,800円）。30日間無料お試しクーポンが2026年12月まで提供されているので、概要欄をチェックしましょう。

05始め方とホーム画面の回り方

テンプレートから探したいときは左側の「テンプレートを探す」ボタン。よく使うのはプレゼンテーションやSNSなどのアイコンボタンで、例えば「SNS → Instagram投稿」を選ぶと4:5の編集画面が開きます。検索欄にキーワードを入れると候補が出て、自分が過去に作ったデザインも表示されます。

06編集画面は6つのエリアで構成

  • 上部のメニューバー（ファイル・リサイズ・戻る など）
  • 左側のメニュー（デザイン・素材・テキストを挿入）
  • パネルとキャンバス（作業エリア）
  • 下部のページとZoomコントロール
  • 右上の共有ボタン（ダウンロードはここから）

編集画面の左側「テンプレート」からキーワード（例: エステ）で検索してデザインを差し込むこともできます。

07素材①: 図形とイラストの使い方

左メニューの「素材」から図形（ライン・四角・丸など）を置き、サイズ調整と配置ができます。図形の色は選択して上部のカラーから変更可能で、グラデーションや「新しいカラーを追加」での微調整にも対応。イラストはキーワード検索で探せ、王冠マーク付きはPro専用、マークなしは無料版で使える素材です。色の変更も自由です。

08素材②: テキストの入れ方とエフェクト

「テキスト → テキストボックスを追加」で文字を入れられます。フォント変更・サイズ調整・カラー変更に加え、エフェクトで影・グロー・エコ・袋文字・背景などの加工が可能。特に人気なのは袋文字で、色と太さを調整すると背景が写真でも文字が読みやすくなります。三角形アイコンのフォントは太さ（フォントファミリー）も選べます。

09この2つでCanvaの60%は使える

Canvaで頻繁に使うのは左メニューの「素材」と「テキスト」の2つ。この2つをマスターすればCanvaの60%は使いこなせるとのこと。自分の写真や動画を使いたい場合は「アップロード」からファイルを追加します。またCanvaは自動保存なので保存作業は不要。あとから振り返りやすいよう、デザイン名に日付や名前を入れておきましょう。

みきさん「素材」と「テキスト」、まずはこの2つを触り込むのが上達への近道ですよ。

10超便利な「フレーム」機能

素材の中にあるフレームは、角丸四角・丸・スマホ型などさまざまな型に写真をドラッグするだけでトリミングできる機能。フレーム内の写真はダブルクリックで位置や大きさの調整もできます。写真を形よく収めたい場面で非常に便利なので、ぜひ活用したい機能です。

11重なり順・複製・ページ操作

要素を前面に出したいときは右クリック → レイヤー → 最前面へ移動で重なり順を変更。要素の複製で文字を揃えて編集でき、テキストボックスの角を引っ張れば折り返しを1行に調整できます。ページは「ページを複製」で背景のA/B比較をしたり、真っ白なページを追加したり、投稿のリサイズ（例: プレゼン比率4:3）も可能です。

12完成したら共有ボタンからダウンロード

デザインが完成したら右上の「共有 → ダウンロード」。ファイル形式（PNG・画像など）を選び、全ページか現在のページのみかを指定して保存します。Instagram投稿ならPNGがおすすめです。編集画面の操作方法は、概要欄から無料配布されている復習資料（85ページ超）にも詳しくまとめられています。

13Canva AI①: リデザインとゼロからの生成

ホーム画面や編集画面の左側にある「Canva AI」ボタンを開くとチャット形式でやり取りできます。「このページをリデザインして」と頼むと「同じコンテンツを維持しつつ新鮮かつモダンな外観に」といった意図でデザインを再構築。さらに「カフェの秋の新メニューモンブランを告知するInstagram投稿を作って」のようにゼロからデザインを生成してもらうこともできます。

14Canva AI②: キャプション作成と写真AIツール

Canva AIはキャプションも考えられるのが強み。「このデザインに合うInstagramのキャプションを3案考えて、ハッシュタグもつけて」と依頼すれば、内容に沿った文案を生成します。写真系AIツールも充実しており、背景透過はワンクリックで髪の毛の細部まで認識して切り抜き、別背景と合成できました。マジック消しゴムなどの加工機能もあります。

15Canva AI③: 無料で使える「マジックレイヤー」

1枚画像のテキストは普通は編集できませんが、マジックレイヤーを使うとCanva AIが画像を読み込んで素材を分解し、文字をテキスト化してくれます。フォントの変更や不要なバナーの削除、素材の再配置が可能になり、ChatGPTで生成した画像を調整したいときにも使えます。背景も分離されるので、Instagramサイズに作り直すこともでき、しかも無料で使える機能です。

みきさん1枚画像が編集できるようになるのは衝撃ですよね。しかも無料でここまでできます。

16商用利用ルール: OKとNGを押さえよう

  • OK: お店やビジネスの発信に使う / オリジナルデザインの販売 / クライアントのデザイン制作
  • NG: 素材をほぼそのまま単体で売る / テンプレを少し変えただけで販売
  • NG: 素材をロゴや商標の一部に使う / 素材でクリップアートを作って売る

デザインを仕事や副業に活かすなら、この商用利用の境界線だけは必ず押さえておきましょう。
