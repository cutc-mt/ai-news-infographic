01 RELEASE

OpenAIが画像生成モデルの最新版「ChatGPT Images 2.6」を公開2026年11月5日、ChatGPTとCodexに実装

OpenAIは11月5日、テキストから画像を生成したり、アップロードした画像をテキストの指示で編集できる画像生成AIモデルの最新版ChatGPT Images 2.6を公開した。

  • テキスト・参照画像からの画像生成と画像編集に対応
  • ChatGPT・GPT・AIエージェントのCodexで利用可能
  • 動画は「概要」→「使い方」の2章構成で解説
02 SPEED +50%

画像生成スピードが50%向上体感でも「前のモデルより早い」

ChatGPT Images 2.6は従来モデルと比べ画像の生成スピードが50%アップ。API版のGPT-Image-2.6系モデルも「前モデルと比べ高速」と公式にアナウンスされている。

50%↑
生成速度の向上
最短6秒
低画質時のFlare生成
検証品質は前のモデルとほぼ変わらないのに、画像が出てくるのが体感でも明らかに早くなっていました。
03 GIF ANIMATION

静止画だけでなく「GIFアニメ」が作れるキャラクターアニメや商品紹介に活用

ChatGPT Images 2.6では、動きのあるGIFアニメーションが作れるようになった。テキストや参照画像からアニメを作成可能で、公式には速度調整やフレーム単位の編集にも対応。

  • キャラクターのアニメーション
  • 商品紹介動画的なコンテンツ
  • ループするGIFとして書き出し・シェア
04 REFERENCE IMAGES

新機能「参照画像」――保存した画像を繰り返し再利用ライブラリに名前をつけて登録

リリースと同時に、ChatGPTのライブラリ部分に「参照画像」という項目が追加された。プラスボタンから、自分・ペット・友人など所有する画像に名前をつけてアップロードできる。

  • フォームで「@＋名前」で呼び出し
  • 生成時に参照画像として繰り返し利用可能
  • 毎回アップロードし直す必要がない
✅
この機能はWebブラウザー版とモバイルアプリ版の両方のChatGPTで動作確認できました。
05 WHO CAN USE

利用できるのはChatGPTのサブスクリプションユーザーGPTとAIエージェント「Codex」でも利用可能

公式アナウンスでは、ChatGPTのサブスクリプション（有料）ユーザーがChatGPT Images 2.6を使える。あわせてGPTとAIエージェントのCodexでも利用できるようになっている。

Webブラウザー版では公式ページ上部のログインボタンから、Googleアカウントや電話番号でログインすれば利用できる。

06 API MODELS

API版は2モデル構成「GPT-Image-2.6 Flare / Sunburst」価格は前のモデルと同等

ChatGPT Images 2.6はAPIでも提供され、GPT-Image-2.6 FlareとGPT-Image-2.6 Sunburstの2モデルが用意されている。

  • 価格は前のモデルと同等
  • 各種AIプラットフォーム（falなど）で利用可能
  • 2モデルともSVG形式のエクスポートに対応
ポイント速さを取るか、品質と一貫性を取るか。この2モデルの使い分けが今回のキモになります。
07 FLARE

GPT-Image-2.6 Flare――高速生成に特化広告・ポスター・商品画像のレイアウト品質も向上

Flareは画像をより高速に生成できるモデル。広告やポスター、商品画像などのレイアウト品質が向上している。

  • 画質「低」設定ならわずか6秒で画像を生成
  • デザイン系ユースケースに強い
  • 最初のドラフトを素早く出す用途に最適
08 SUNBURST

GPT-Image-2.6 Sunburst――高品質と一貫性に特化繰り返し編集しても画像が劣化しにくい

Sunburstはより高品質な画像生成が得意なモデル。細部の表現や、繰り返し編集する際に画像が劣化しないよう一貫性を重視している。

  • 細かいディテールが求められる作業に適する
  • 何度編集しても品質をキープ
  • 画質「中」または「高」設定が推奨
09 SVG EXPORT

2モデルともSVG形式のエクスポートに対応ベクターデータとして拡大縮小・再編集可能

新たにSVG形式のファイル出力に対応した。ロゴやアイコン、イラストなどをベクターで書き出せるため、拡大縮小しても劣化せず、色や形状の編集もしやすい。

ブランドカラーに合わせたアセットが必要な場面や、複数サイズで同じ素材を使いたい場面で威力を発揮する。

10 QUALITY 3 LEVELS

画質は「低・中・高」の3段階で設定可能速度と品質の使い分けガイド

Flare ＋ 画質「低」

  • 最速6秒で生成
  • ラフ・ドラフト用途
  • スピード最優先

Sunburst ＋ 画質「中/高」

  • 細かいディテールを重視
  • 正確性が求められる作業
  • 品質・一貫性最優先

より細かいディテールや正確性が求められる作業には、画質を中または高に設定したSunburstが適している。

11 BENCHMARK

Arenaベンチマーク――2.5シリーズに次ぐスコア画像編集ランキングでは上位に食い込む

ユーザー投票でモデル能力を図るランキングサイトArenaにおいて、FlareとSunburstはテキストから画像生成・画像編集・複数枚の画像編集の各ランキングで、前モデルのGPT-Image-2.5シリーズには及ばないもののスコアはほぼ互角。

画像編集ランキングでは、Microsoft AIのMai Image 2.7 プレビューを除くと、画像生成AIモデルの中でGPT-Image-2.5シリーズに次ぐ数字を出している。

12 HOW TO USE

ChatGPTでの使い方――プラスボタンから「画像を作成」フォームにイメージを入力して送信だけ

STEP 1フォームのプラスボタンを押す
STEP 2「画像を作成する」を選択
STEP 3作りたいイメージをテキスト入力して送信
STEP 4生成後に続けて指示して編集

生成した画像はチャットで続けて指示することで編集できる。プラスボタンから画像をアップロードして、その画像を編集することも可能。

13 EDIT TOOLS

画像の詳細ページでできることクリックすると編集オプションが並ぶ

生成画像をクリックすると詳細ページに遷移し、次の編集ができる。

  • 画像のダウンロード
  • 背景の削除
  • 画像の一部を選択して部分修正
  • 画像を別の比率で作り直し
14 GIF TEST

実験①：GIFアニメを実際に作ってみた「GIFアニメを作ってください」だけで高品質

「GIFアニメを作ってください」と指示して、テキストと参照画像からGIFアニメを作ってもらったところ、非常に品質の高いGIFアニメが完成した。

検証プロンプトはごくシンプルでも、ぬるぬる動くクオリティのアニメができあがりました。キャラクターの動きも自然です。
15 QUALITY TEST

実験②：人物・動物・風景・日本語サムネ・ポスター品質は前モデルとほぼ同等、速度は向上

人物画像、動物画像、風景画像、日本語の入ったブログのサムネイル画像、ポスターやチラシを作って検証。

  • 品質：前のモデルとほぼ変わらず
  • 速度：明らかに高速化
  • 日本語テキストの載ったデザインにも対応
16 CODEX STATUS

CodexではGIFアニメがまだ作れない動画制作時点では画像生成機能のみ

ChatGPTのサブスクリプションユーザーはAIエージェントのCodexでもChatGPT Images 2.6を使えるようになる予定。

ただし動画を作ったタイミングでは画像生成機能だけで、GIFアニメは作れなかったため、Codex側のGIF対応はまだ実装されていない様子。

⏳
公式にはChatGPT・Codexの全プランで利用可能と発表されています。GIFまわりの実装は今後のアップデートに注目です。
17 ON FAL

AIプラットフォーム「fal」でもAPIモデルが使える従量課金でクレジットを追加するだけ

さまざまなAIモデルを従量課金で使えるAIプラットフォームfalにログインし、クレジットを追加すれば、API版のFlare／Sunburstで画像の生成・編集ができる。

  • 画質は低・中・高から選択、出力形式をGIFにするとGIFアニメが作れる
  • SVG形式のファイルも作成可能
  • 生成速度は前のモデルより高速
  • 編集箇所を正確に伝える注釈（マークアップ）付き参考画像に対応
