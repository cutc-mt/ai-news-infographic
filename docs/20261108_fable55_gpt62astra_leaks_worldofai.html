01 DUAL LEAK

2社同時に次期モデルのリークGPT-6.2 Astra × Claude Fable 5.5

今週、OpenAIとAnthropicの両社をめぐるリークが一気に活発化。OpenAIは新しいモデル「GPT-6.2 Astra」、Anthropicは「Claude Fable 5.5」をリリースする可能性があるという情報がもたらされた。

  • OpenAI：サム・アルトマン氏の発言＋名称目撃情報
  • Anthropic：ルーティング先の変化＋Azureの記録に出現
よもぎ両社とも公式発表はまだありません。でも、これだけ兆候が重なると、そわそわしちゃいますね。
02 CODEX SIGHTING

Codexの使用内訳に「GPT-6.2 Astra」が出現裏側で秘密テストの痕跡

一部のユーザーがCodexの使用内訳の中に「GPT-6.2 Astra」という名称を発見。ただしモデル選択画面では、依然として「GPT-6 Astra」へとルーティングされていた。

使用内訳「GPT-6.2 Astra」の名称を確認
選択画面実際の処理はGPT-6 Astraのまま
解釈裏側で6.2を静かにテスト中

静かな数週間を過ごしてきたOpenAIだが、水面下では着実に準備を進めていたと考えられる。

03 ANTHROPIC SIDE

Fable 5.1の先には「Fable 5.5」が見えるAzureのモデル記録にも出現済み

Anthropic側では、すでにFable 5.1がより強力なモデルへとルーティングされており、それが「Claude Fable 5.5」になる見込み。興味深いことに、このモデルは以前Azureのモデル記録にも現れていた。

  • Azureへの出現は通常、リリースが近いことのサイン
  • Metis 5.1／Fable 5.1でも同じパターンがあった
よもぎAzureの記録に名前が載るのは、デプロイ準備が進んでいる合図なんだとか。あと一歩のところまで来ているのかもしれません。
04 SAM IN ABU DHABI

アルトマン氏がアブダビで語った「難問を解いたモデル」ナビエ・ストークス方程式を4日がかりで

本日、アブダビでのカンファレンスに登壇したサム・アルトマン氏は、数学の難問ナビエ・ストークス方程式を解いたモデルについて言及。このモデルはまもなくリリースされる予定だという。

4日間
休みなく問題に取り組んだ

司令塔エージェントなし

1万ものエージェントが協力し合う仕組みながら、オーケストレーターとなる司令塔は存在しない――完全にフラットな構成だった点が特徴。

05 SEPT 8 GRAPH

9月8日のグラフに載っていた社内モデルと同一最低計算量でAstraを凌駕

このモデルは、OpenAIが9月8日に公開したグラフにあった社内モデルと同一だとされる。注目すべきは、最も低い計算量でありながら、すでに最高レベルのAstraを凌駕しているという点。

  • 計算効率の割に性能が突出
  • そのモデルも近いうちに登場するとの見方
よもぎ安い計算量でフラッグシップ超えって、リリースされれば値段設定も楽しみなところですね。

「我々史上最も強力なモデル」の正体は「Bell」か次世代ベースの最初の産物シナリオ

アルトマン氏は「我々史上最も強力なモデルをリリースする」と述べた。これは数ヶ月前に言及していたものと同じモデルで、社内コードネーム「Bell」である可能性が高いと動画主は推測する。

シナリオA：Bellベース初号機

シナリオB：6.1 Astraのポストトレーニング版

  • 着実だがインパクトは小さめ

現時点で確実なのは「近いうちにリリース予定」という初期段階の確認のみ。正確なスケジュールや競争力は未知数だ。

07 METIS = FABLE

Metis 5.5こそFable 5.5の正体消費者向けに安全策を講じた微調整版

コードベースに「Metis 5.5」が登場すれば、そのモデルがデプロイ準備段階にあるという高い確信が持てるという。Fable 5.5は明らかにMetis 5.5となるはずだが、サイバーセキュリティ防御用とは異なり、消費者向けにより安全策を講じた微調整版になるとみられる。

  • Metis 5.1／Fable 5.1でも同じ二段構えを採用
  • 内部名（Metis）→消費者向け（Fable）の流れを再現か
08 SPONSOR

スポンサー: Switch――エージェントの文脈をチームで共有Slack・Teams・Discordと接続する「ルーム」

動画中盤のスポンサーパートでは、オープンソースのSwitchが紹介された。Claude Codeで1時間バグ追跡しても、その文脈はセッション内に閉じ、チームメイトには見えない――その問題を解決する。

  • Claude Code・Codex・OpenCodeなどをチーム共有ルームに持ち込める
  • ルームはSlack・Teams・Discordなどと接続、チャンネルでエージェントをタグ付け
  • 会話履歴・指示・リソースはルームに保存され、後からの参加者も遡って確認可能
  • 共有されるのはルームの文脈であってエージェント個人の記憶ではない
  • ロール・権限設定とセルフホストにも対応
09 PURE CODE OUTPUT

拡散された映像は「全部コード」――動画モデルではないモデルが一発で生成した衝撃

Xで拡散されたFable 5.5の出力が画面に映し出された。あらゆる要素が動画モデルや画像モデルではなく、純粋なコードであり、モデルがこの動画を一発で生成したものだという。

よもぎ一見すると映像にしか見えないんですよね。よく見ると、全部モデル自身がプログラミングしたものなんです。

投稿者はGitHubでソースコード全体も公開しており、誰でも検証できる状態にある。

13 PORT SIM GAME

three.js製のライブコンテナポートゲームクレーン・船・AGVまで完全モデル化

誰かが構築したというライブコンテナポート・シミュレーションも紹介された。戦略ゲームのようなもので、見えているクレーン・船・AGV（自動搬送車）などのすべてがモデル化され、three.jsで動作している。

  • Fable 5.5を使えばゲーム開発は間違いなくずっと簡単になる

14 PRICING UNKNOWN

ただし価格と効率が「全く分からない」提供できることを願るしかない現状

唯一の問題は、このモデルがどれほど高価になるのか全く分からないこと。効率性と、Anthropicがどう提供するのかも予想がつかない。リリースされれば多くの人が使いたがるはずだからこそ、供給面が心配される。

よもぎ性能がすごすぎても、手が届かなきゃ意味がないですからね。価格発表も注目ポイントです。
15 6-MONTH DELTA

Sonic 4.6「犬が馬に乗る」を見て進化を実感ペリカン自転車テストに執着する理由

2026年のAI進化の速さを実感するため、動画ではSonic 4.6の「犬が馬に乗っている」映像が振り返られた。6ヶ月前にこれを見たときは「2026年のAIはこんなに進化したのか」と驚いたものだが、半年後の出力と並べると差は歴然。

  • ペリカンが自転車に乗るテストに執着するのは、AI開発スピードを測る良い指標だから
  • 同じ題材で時系列比較すると能力の伸びが可視化される
16 COMBAT & SVG

戦闘アニメと「クマ×船×パンダ」SVGテスト最高設定で21分で完成

Fable 5.5が生成した戦闘アニメーションはまるで完成されたゲームのよう。Anthropicには専用の動画・画像モデルがなく、すべてコードだけで実現している点が高く評価されている。別のSVGテストでは、船を食べるクマ、竹を食べるパンダ、ホッキョクグマが描かれ、投稿者いわく最高設定で21分の仕上がり。

よもぎ画像や動画モデルならもっと上手くできるはず。それをコードだけでやるからこそ、衝撃なんですよね。
