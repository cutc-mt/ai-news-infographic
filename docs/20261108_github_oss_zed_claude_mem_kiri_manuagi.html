Zed: Rust製の高速マルチプレイヤーコードエディタAtomとTree-sitterの開発者がゼロから構築

EDITOR github.com/zed-industries/zed

GPUレンダリングによる高速化を図った、オープンソースの高性能コードエディタです。

  • 巨大なファイルでも編集・スクロールがスムーズ
  • リアルタイムコラボレーションを内蔵——一緒にコードを書き、ワークスペースを共有
  • AIアシスタントをターミナル・言語サーバー・Vimモードと連携可能
  • macOS・Linux・Windowsで動作
よもぎ
よもぎ:「インストールして、その速さを体感して」というのが動画の締め。GPU描画のエディタは触ってみると差が歴然です。
CARD 03

rust-lang/rust: システムプログラミング言語の本丸コンパイラ・標準ライブラリ・Cargoがすべて入った公式リポジトリ

LANGUAGE github.com/rust-lang/rust
  • パフォーマンス・信頼性・GCなしでのメモリ安全性を追求したシステム言語
  • 借用チェッカーがコンパイル時にメモリとスレッドの安全性を保証
  • 開発はRFCプロセスでオープンに進行
  • OSからウェブサービスまであらゆるものを支える
よもぎ
よもぎ:今週のラインナップにRust製ツールが多いのは、この言語そのものの成熟が下支えしています。「クローンしてコンパイラをビルドしてみよう」とのこと。
CARD 04

Angular: Google製のTypeScriptファーストなWebフレームワークSPAからエンタープライズシステムまで、LTS付きの完全なフレームワーク

FRAMEWORK github.com/angular/angular
  • コンポーネントモデル・強力なルーター・フォーム・HTTPクライアントをフルセットで提供
  • 依存性の注入とSignalsによるリアクティビティ
  • CLIが雛形作成・ビルド・テストを自動化、SSRで初回読み込みを高速化
  • 単なるライブラリではなく長期サポート（LTS）を備えた完全なフレームワーク
CARD 05

Google Agent Skills: Google Cloud向けの公式エージェントスキルポータブルなSkill MD形式で、Googleの専門知識をエージェントに

AGENT SKILLS

Google製品向けエージェントスキルのオープンソースリポジトリです。

  • オープンなエージェントスキル標準に準拠したSkill MD形式で移植性が高い
  • プログレッシブ・ディスクロージャーで必要な部分だけを読み込み
  • BigQuery・Cloud Run・Firebase・GKE・Gemini APIに加え、セキュリティ・信頼性・コスト管理の設計ノウハウまで網羅
  • Gemini CLI・Cloud Code・Cursorなどで動作
よもぎ
よもぎ:GCPでエージェントを動かす人には直撃の素材集。公式のベストプラクティスがそのままエージェントの指示に入るのは大きいです。
CARD 06

基盤技術デュオ: LZ4とetcd超高速圧縮ライブラリと、Kubernetesのバックボーン

INFRA github.com/lz4/lz4 ／ github.com/etcd-io/etcd
  • LZ4: Yann Collet氏による圧縮率を犠牲に速度を優先したロスレス圧縮。解凍が非常に速くリアルタイム利用に最適
  • 高圧縮モードのLZ4_HCと、ストリーム相互運用のためのフレーミング形式を提供。Linuxカーネル・DB・ファイルシステムに組み込み済み（BSDライセンス）
  • etcd: 分散システムの最重要データ向けの分散キーバリューストア。CNCFプロジェクトでKubernetesのバックボーン
  • Raftコンセンサスでクラスタ間複製。ノード故障時も整合性と可用性を維持。Go製でウォッチ・リース・トランザクションを提供
CARD 07

claude-mem: エージェントのためのセッション間永続メモリ何度も同じ説明を繰り返すのは、もうやめ

AGENT MEMORY

コーディングエージェントにセッションをまたぐ永続的な記憶を与えるオープンソースプラグインです。

  • 作業中のエージェントの行動を静かに記録し、AIで要約して保存
  • 関連情報を将来のセッションに自動注入——Claudeはゼロから始めなくてよい
  • 過去の作業を尋ねるとメモリ検索スキルがそれを見つけ出す
  • すべてローカルのSQLiteに保持。Claude Code・Codex・Gemini・Copilotで動作
よもぎ
よもぎ:「インストールして、何度も説明するのはやめにしましょう」——今週いちばん刺さるコピーかも。エージェントの文脈喪失問題への現実解です。
CARD 08

DeepTutor: エージェントネイティブな学習ワークスペース個別指導・問題解決・クイズ・調査・可視化を1つに統合

LEARNING
  • WebアプリとCLIを提供、pip・ソース・Dockerでローカル実行
  • 回答は複数の検索エンジンを通じてナレッジベースから引き出す
  • モデルプロバイダー・MCPサーバー・Claude Codeのようなコーディングエージェントとも接続
  • メモリは人間が読めるファイル形式で保存。検証可能なAI個別指導を求める学習者に最適
CARD 09

PR-Agent: プルリクエスト向けAIコードレビューツールdescribe・review・improve・askの4コマンド体制

CODE REVIEW

プルリクエストに対して動作する、オープンソースのAIコードレビューエージェントです。

  • describe・review・improve・askのコマンドは、PRコメントまたはCLIから実行
  • 各コマンドは1回のLLM呼び出しだけで完結し、コストが読みやすい
  • GitHub・GitLab・Bitbucket・Azure DevOps・Giteaをサポート
  • LiteLLM経由でOpenAI・Anthropic・Googleなどのモデルと連携。GitHub Actions・Docker・セルフホストで運用可能
よもぎ
よもぎ:PRレビューの自動化はチームのボトルネックを直接削る領域。「ワークフローに追加してみよう」とのことです。
CARD 10

NekoPS5: PS5実行ファイルをLinux/Windowsへネイティブ移植エミュレーターではなく、リリンカーが実行ファイルを書き換える

EMULATION
  • PS5のシステムライブラリ（グラフィックス・フォント・オーディオ・セーブデータ・入力）を再実装
  • シェーダーリコンパイラがPS5のシェーダーをVulkanに変換
  • 目的は相互運用性・研究・保存。著作権保護ソフト・ファームウェア・キーは一切不含——実行ファイルは自己用意
  • C++製、開発初期段階のコミュニティ主導プロジェクト
よもぎ
よもぎ:「エミュレーターではない」という設計思想が面白いところ。権利関係に配慮した作りになっている点も注目です。
CARD 11

エージェントの機材係: HerderとTerminalMac複数エージェントの監視と、エージェント専用のMac環境

DESKTOP
  • Herder: ターミナルとコーディングエージェントのためのRust製デスクトップアプリ。エージェントが動くHerderランタイムへの窓口
  • ターミナルやエージェントセッションを自由に入れ替えできるレイアウトで、複数エージェントを一括監視
  • TerminalMac: ターミナル内でmacOS仮想マシンを実行。自分のMacとは別にエージェント専用のMac環境を提供
  • Appleの仮想化フレームワークベース。コンピュータユース機能（スクショ・クリック・タイピング）をMCPで公開しClaude Codeに接続。無料のAppleシリコン専用・初期段階
よもぎ
よもぎ:「エージェントにMacを持たせる」という発想の転換が秀逸。サンドボックス化された専用環境は安全面でも理にかなっています。

LiveLive Player: リップシンク対応の2.5D WebキャラクタープレイヤーWebGL2で、奥行きを持って首を振るレイヤード2Dアート

AVATAR
  • ブラウザ上でマイク音声によるリップシンクとWebカメラによる顔追跡を実現

GAME

CARD 14

OmniDiff: コードと画像のための構文認識diffツール行単位ではなく、コードの構造を理解して比較

DIFF

Rustで書かれた高速でオープンソースな構文認識型差分ツールです。

  • 各変更を挿入・削除・更新・移動に分類
  • 移動したブロックをペアリングし、関数やクラス名を特定——多言語の改名・並び替えを正確に把握
  • 「バイナリが異なる」ではなく画像自体の差分を表示
  • Gitのdifftoolとして、またはVS Code・Neovimで利用可能（AGPL）
よもぎ
よもぎ:リファクタリングレビューの見落としが減るタイプの道具。「移動」を検出できるdiffは実務で地効きます。
CARD 15

DSH Super Agent: 単一リポジトリ向けプロアクティブなコーディングエージェントDeepSeek Harnessバンドルの研究用プロトタイプ

AUTONOMOUS
  • 単一のGitHubリポジトリ向けに設計された自律コーディングエージェント。GitHubを（オプションでfishuも）監視
  • 許可されたユーザーの依頼で作業項目を開き、専用セッションで実行し、PRなどを添えて同じ会話スレッドで回答
  • ウェブパネルで人手が必要なタスクを確認
  • 研究用コードであり本番向けでない点に注意。低頻度介入のエージェントワークフローを試すチーム向け
CARD 16

Kiri: Rust製の軽量Docker Desktop代替Docker CLI・compose・buildxがそのまま使える

CONTAINER

macOS・Windows・Linux向けの軽量コンテナランタイムです。

  • 小さなLinux VM内でコンテナを実行（Linuxではカーネル上で直接動作）
  • Docker Engine API対応で、Docker CLI・compose・buildxがそのまま使える——Docker DesktopやOrbStackを代替
  • コマンド一つでKubernetesクラスター・Linuxマシン・ネイティブウィンドウを構築
  • 軽量なローカルコンテナを求める開発者に最適
よもぎ
よもぎ:「ダウンロードして、最初のイメージを実行してみよう」。Docker互換APIを保ったまま軽量化する方向性は、Macユーザーに特に刺さります。
CARD 17

Mago Studio: 自分のGPUで動くローカルファーストAI動画編集プロジェクトも動画ファイルも、すべてユーザーのPC内に

VIDEO AI
  • Windows・macOS・Linuxで使えるAI動画編集デスクトップアプリ
  • Mago Director: 脚本から配役・ショットリスト・絵コンテ・一貫性のあるシーンを生成
  • Mago Transform: マスクとフレーム範囲でフレームごとに映像スタイルを変換
  • レンダリングはComfyUI経由でローカルGPU、またはサインインしてMago Cloud——ローカル管理を求めるクリエイターに最適
CARD 18

ラスト2つ: DJsとSand3D——LLMのための実行エンジンと3DモデリングAIが書いたスクリプトを安全に回し、3Dアセットを短いプログラムで生む

LLM TOOLING
プロジェクト内容ここが効く
DJs
JS/TSエンジン		no_std Rustで書かれた小規模なJavaScript/TypeScriptエンジン。WASM-32をターゲットにし、PyrsコードモードでQuickJSを置き換えるモデルが書いたスクリプトがツールを呼び出しデータを返す。VMの状態が1つのバイトアリーナに存在するためスナップショットは単純コピー。命令の合間で中断・再開が可能で、ネイティブとWasmビルドで常に決定論的
Sand3D
Python 3D		BlenderのBPyをベースに、LLMが3Dオブジェクトを短いプログラムとして記述できるPythonライブラリプロファイル・ソリッド・ジョイント・アセンブリを定義し、座標ではなく名前でパーツを指定。同じプログラムから毎回同じメッシュが生成。1回の呼び出しでGLB・URDF・USD・OBJ・STLをエクスポート。API全体が1つのプロンプトに収まる
よもぎ
よもぎ:どちらも「LLMが扱える形式に世界を合わせる」アプローチ。決定論的なJS実行とプロンプトサイズに収まる3D API——エージェント時代の道具設計として参考になります。
