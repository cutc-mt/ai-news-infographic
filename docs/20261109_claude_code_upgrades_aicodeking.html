02 新モデル

Claude Haiku 5.5 登場10月7日公開、Claude CodeのデフォルトHaikuに

新モデルHaiku 5.5が10月7日に登場し、Anthropic API上のClaude CodeでデフォルトのHaikuになった。100万トークンのコンテキストウィンドウを持ち、料金は驚きの安さ。

$0.10入力100万トークンあたり
$0.50出力100万トークンあたり
  • プロンプトが10万トークン超の場合は$0.50 / $2.50に上昇——それでも十分安い
03 効用

裏方ジョブが高速・低コストにHaikuは検索や簡易サブエージェントを支える模型

HaikuはClaude Codeの中で軽いバックグラウンド処理——素早い検索や単純なサブエージェント——を数多く担当している。何もしなくても、速くて安い助っ人に入れ替わるのがこの更新の恩恵だ。

🐼Panda CodeではモデルメニューからHaikuを選ぶだけ。エージェントチームでは、ルーターが「最も安く成功しそうなモデル」から順に試すので、単純なワーカーのタスクがHaiku 5.5に割り当てられ、ほぼ無料で回る。チェック不合格なら強いモデルへ昇格。
04 魔法の言葉

Ultrathinkがついに本当に動く対応モデルのeffort（思考の力み）を一時的に最大引き上げ

プロンプトにultrathinkと打つと、そのターンが超高effortで実行されるようになった。対象はOpus 5.5・Sonnet 5.5・Haiku 5.5・Fable 5.1。Claude動作中に打っても、そのターンの残りに反映される。

  • 虹のエフェクトは実際にeffortが上がる場合だけ表示——引用やファイルパスに含まれていても騙されない
  • 不要なら環境変数で無効化できる
05 サブエージェント

effortの連鎖バグを修正親の設定をコピーせず、各モデルの保存値を使う

これまで別モデルのサブエージェントは親のeffortをそのまま引き継いでいた。今回、そのモデル自身の保存済みeffortを使うよう修正され、さらにサブエージェントのeffortを指定する新しい環境変数も追加された。

🐼Panda Codeは魔法の言葉ではなく、effortピッカーがモデルの横に鎮座。選択中のモデルが本当に対応するレベルだけを表示して、--effortフラグで渡してくれる。虹はないけど、常に自分が何で動いているか分かるのが強み。
06 節約王

アイドル・コンパクション動画いち押しの「最もお金を節約する」アップデート

Claude Codeは会話を1時間だけプロンプトキャッシュに保持する。大きな会話を放置して戻ってくると、全履歴を再処理してリミットを食っていた——それが変わる。20万トークン超の会話が約54分アイドルになると、キャッシュ期限の直前に自動で要約され、戻ってきた次のメッセージは短い要約だけで済む。

① 大きな会話200kトークン超のセッションを放置
② 54分経過キャッシュ期限の直前に自動要約
③ 帰ってくる次の発言は要約だけ読むので激軽い
  • ターミナルで始まり、今はVS CodeとデスクトップのCodeタブにも展開済み
  • /configの「idle compaction」行でオフにも可能
07 リミット周り

レジューム警告と「5時間制限」改名/usageがトークンを静かに燃やす犯人も教えてくれる

Pro / Maxユーザーが古い会話を再開しようとした際、5時間リミットの大きく消費されるときは事前に警告が出るようになった。そのまま再開してもよし、新規会話にしてもよし（古い会話は言及すれば参照可能）。分かりにくかった「セッション制限」は「5時間制限」に改名。

  • /usageがmax effort・ワークフロー・常時コンテキスト・巨大ツール結果などのトークン燃焼要因を警告
08 Panda Code流

使用量パネルと「リセット時に再開」複数エージェントのリミットを一望

Panda Codeは逆方向から攻める。エージェント使用量パネルに、インストール済み全エージェントのリミットとリセット時刻が一箇所に集約され、大仕事の前に「もう80%です」が分かる。

  • タスク途中でリミット到達しても、resume at resetがリセット後に自動で続きを実行
  • Claude Codeは「ムダに焚べない」、Panda Codeは「今どの立ち位置か見せる」という役割分担
09 バックグラウンド

MCPツールがターンをブロックしない/tasksに「earlier in this session」行も追加

MCPサーバーのツール呼び出しがタスクとして実行されると、Claude Codeは即座にバックグラウンドへ移動し、完了したら結果を届ける。遅いMCPツールのせいでターン全体が止まることはもうない。

  • /tasksの新行で、終了したサブエージェントを再起動後も再オープンして再メッセージ可能
  • バックグラウンドエージェントへのメッセージは、実行コマンドを待たずすぐ届くように
  • バックグラウンドのサブエージェントは3分でシェルコマンドをバックグラウンド化——長いビルド中にキャッシュが切れない
10 Panda Code流

本物のスレッドで並行作業/btw・予約メッセージ・エージェントチーム

Panda Codeのバックグラウンド処理は実スレッド方式。/btw＋質問でサイドスレッドが開き、主タスクのキューに触れずに回答が返ってくる。

  • 任意スレッドに予約メッセージ：「20分後にデプロイを確認」「あのタスクが終わったらここを続けて」
  • エージェントチームの各ワーカーが独立スレッドとして閲覧可能
  • 1つのターミナルに留まりたいならClaude Code、5〜6個同時ならPanda Codeが追いやすい、という住み分け
11 権限とautoモード

放置運転を安全にする4つの設定新コマンド /auto-mode:setup ほか

/auto-mode:setupプロジェクトと最近のセッションを読んで、autoモードが適切な質問をするように学習
deny instead of prompting確認待ちになるツール呼び出しを拒否して処理継続——無人長時間運行に最適
作業フォルダ外の書き込みブロック全権限モードで共通の安全策
メール送信の事前確認web・シェルコマンドがアカウントのメールアドレスを送る前に尋ねる（プライバシー配慮）
🐼Panda Codeは権限ピッカーをコンポーザーに内蔵。「standard（都度確認）」「accept edits（編集許可）」「approve for me（autoモード）」を平易な言葉で選べるよ。autoモードでは安全レビュアーがルーチン作業を承認し、必要時だけプロンプト箱の上に細いバーで承認／拒否を求めてくる。
12 ターミナル改良

細かいけど効く改良の山ステータス表示・Vimモーション・mods拡張

  • Program Status Protocol対応：対応ターミナルのタブに、Claudeが「作業中／入力待ち／完了」のどれかを表示
  • キュー済みメッセージの「send now」ヒントをクリックで即送信
  • Vimモードに％モーション（対応する括弧へジャンプ）
  • Agent Viewで新セッションのeffortとfastモードを設定可能
  • 空入力でCtrl-Dを2回で終了
  • mods（Claude Code自身のUIを変えるプラグイン）が強化：ネイティブ通知・複数行テキストボックス・自作modの共有支援
13 Panda Code流

サイドバーとクイックランチャーターミナルが追いついた領域

あのステータス連携は、Panda Codeのサイドバーがずっとやってきたことだ。全スレッドが作業中／待機中／完了を表示し、Command＋Shift＋Spaceのクイックランチャーは、Macのどこからでもアクティブまたは待機中のエージェントだけを抽出する。

📌「ターミナルがようやくここに追いついてきた」という評価——GUIアプリの利便性がCLIに還流した好例だね。
14 デスクトップ

Claude DesktopのCodeタブが大進化フォーク・サブエージェント・安全策・バグ修正

  • アイドル・コンパクションがCodeタブにも搭載。サブエージェントはターミナル同様常にバックグラウンド実行、フォークサブエージェントがデフォルトON——全コンテキスト持った分身を分裂できる
  • bypass permissionsモードで危険なrmコマンドを即時拒否し、書き直しのヒントを提示（無人セッション停止を防止）
  • cloudセッションのCodeタブから/code reviewを実行すると、素のリストではなく正式なfindingsカードを表示
  • バグ修正：1ターン目で切れるプロジェクトMCPサーバー、.zshrc変数が見えないコマンド、作業中に添付した画像がフルサイズで送られて長チャットをエラーにする問題など

16 注意点

知っておきたい制約エンタープライズ向け項目は山ほどある

  • 目玉更新の多くはターミナルが先で、他アプリへの展開は後。Bedrock・Vertexやテレメトリ無効では挙動が異なる場合も
  • 変更ログは非常に長く技術的で、enterprise gateway関連だけの項目も多数——良さそうな項目を埋もれがち
  • アイドル・コンパクションは「要約がClaudeの記憶」になるということ。正確な詳細が重要な会話ではオフに
  • Panda Codeは対応エージェントのみ実行可能で、新機能が使えるようになるにはPanda Code側の更新待ちとなることも
17 比較

Codeタブ vs Panda Codeどちらも「デスクトップでコーディングエージェント」だが方向性が違う

🟣 Claude DesktopのCodeタブ

  • Claude Code専用なら最良——チャットやco-workと同じアプリで完結
  • Anthropic純正ならではの統合体験

🟠 Panda Code

  • Claude Code 2に加えCodex・Kimi Code・OpenCodeなども同じウィンドウで、チームにも混在可能
  • ターンごとのdiff、コミット用のchangesパネル、ワークツリーの数クリックマージ、内蔵ブラウザ、タスクボード

1つのエージェントを極めたいならCodeタブ、複数エージェントと全変更を俯瞰したいならPanda Codeが筋、という結論。
