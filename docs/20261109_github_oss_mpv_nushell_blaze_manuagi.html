よもぎ
今週の軸は「ローカルで完結させる」と「エージェントに創作系の仕事を任せる」の二本柱。動画スタジオになったコーディング助手、GPUで直接描画するメモ帳、USBなしで隣に置けるLinuxまで、自分のマシンの中で完結する道具が目立ちます。
CARD 01

mpv: 無料・強力・拡張可能なメディアプレーヤー品質と操作性を重視したクロスプラットフォームの定番プレーヤー

MEDIA PLAYER github.com/mpv-player/mpv
  • MPlayer／MPlayer2から派生したオープンソースのプレーヤーで、FFmpeg経由でほぼすべての音声・動画形式を再生
  • GPUアクセラレーションによる高品質なビデオ出力
  • デフォルトはミニマルな1ウィンドウ＋キーボードショートカット。設定ファイルやLua・JavaScriptスクリプトで深くカスタマイズ可能
  • 他アプリへの組み込み用ライブラリlibmpvも提供
よもぎ
よもぎ:「インストールして、どんなファイルでも再生しよう」——対応形式の広さが最大の売りです。
CARD 02

Prometheus: オープンソースの監視システム＋時系列DBCNCF卒業プロジェクトの監視定番

MONITORING github.com/prometheus/prometheus
  • HTTP経由でサービスからメトリクスを収集し、タイムスタンプとラベル付きで保存
  • 強力なクエリ言語PromQLでデータを抽出
  • プル型モデルとサービスディスカバリで監視対象を自動検出、Alertmanagerがルールベースの通知を管理
  • Go製。ノートPCから大規模システムまでスケールし、Grafanaとの組み合わせが定番
CARD 03

Nushell: すべてを構造化データとして扱うシェルプレーンテキストではなく「表」で考える新しいCLI

SHELL / RUST github.com/nushell/nushell
  • コマンド出力が表形式で返り、パイプラインでフィルタ・並び替え・変換できる
  • ファイル・API・システム情報をデータセットにクエリを投げる感覚で操作
  • JSON・CSV・YAMLなどをネイティブで読み込み、型付きの関数型言語がエラーを早期検出
  • Rust製でLinux・macOS・Windowsで動作
よもぎ
よもぎ:「シェルの概念を再定義する」—今週の目玉の一つです。grepやjqと格闘していた日々が変わるかも。
CARD 04

OpenSSL: インターネットを守る暗号ツールキットTLSの事実上の基盤であるC言語のライブラリ

SECURITY github.com/openssl/openssl
  • HTTPSの基盤となるTLS/SSL用のlibSSLと、暗号・証明書用のlibcrypto、管理用コマンドを同梱
  • あらゆるプラットフォームの無数のサーバー・アプリ・デバイスに組み込まれている
  • 開発はオープンで、FIPS認定済みビルドも利用可能
  • 「インターネットの多くを支える」インフラ級プロジェクト
CARD 05

Hallmark: AIっぽさを排除するWebデザインツールClaude CodeやCursorが作るページから「AI特有の不自然さ」を消す

DESIGN github.com/Nutlope/hallmark
  • コーディングエージェント向けに50種類のテーマを用意し、目的別にページを構築
  • 実際のブラウザでAI特有の不自然さがないか自動検証
  • 専用レビューアが最終ページをチェック、既存プロジェクトのリデザインと監査コマンドも搭載
  • 導入はNPXで完了
よもぎ
よもぎ:「どこかで見たAI生成ページ」を卒業したい人に。エージェントに個性的なページを作らせたい開発者向けです。
CARD 06

OpenMontage: コーディング助手を動画スタジオに変える調査から書き出しまで、エージェントが一貫制作

VIDEO AGENT github.com/calesthio/OpenMontage
  • 動画の概要を指示すると調査→台本→構成→素材準備→編集→書き出しをエージェントが実行
  • Claude CodeやCursorに対応し、RemotionとFFmpegでローカルレンダリング
  • ローカル完結なのでAPIキー不要・無料
  • 検証可能な動画制作を求めるクリエイターに最適
よもぎ
よもぎ:タイトルにも名前が載った注目株。「クローンして動画を作ろう」と動画でも推されていました。

ArtCraft: AI画像・動画のためのビジュアルIDE生成する前に2D構成・3Dステージング・カメラを決める

VISUAL IDE github.com/storytold/artcraft
  • 視覚的ツールで生成前に2D構成・3Dステージング・キャラ配置・カメラ設定が可能
  • Veo・Kling・Soraなど画像・動画・音楽・3D・ワールドモデルと幅広く連携
  • Windows・macOS向け安定版あり、Linuxはソースからビルド
  • 再現性を重視するアーティスト・デザイナー・映像作家向け

rerun: チーム業務を任せるセルフホスト型AI同僚役割・記憶・スキル・コンピュータを持つ同僚を構築

AI COWORKER github.com/rerun-build/rerun
  • 現場監督エージェントがユーザーと対話しながらチームを計画・構築
  • 各同僚には役割・記憶・スキル・コンピュータが割り当てられ、スケジュールやWebhookで稼働
  • Gmail・Slack・Notion・GitHub・MCPサーバーと連携、送信や決済の前に確認を挟む安全設計
  • Docker＋Supabaseでセルフホスト可能。定型業務の自動化に

quiet-md: GPUで直接描画するローカルファーストなメモ帳WebGUIもElectronも使わないRust＋GPU UI

NOTES / LOCAL-FIRST github.com/s1dashu/quiet-md
  • macOS・Windows向けデスクトップメモアプリ。インターフェースをGPU上で直接描画
  • アカウント不要。メモは普通のフォルダにXMLファイルとして保存（FaceID保護対応）
  • Markdownをインポートでき、表・コード・数式・テーマをサポート
  • 高速でプライベートなエディタを求める人に
よもぎ
よもぎ:「ダウンロードして書き始めよう」—ローカルファースト派のツボを押さえた1本です。

hop: USBメモリなしでWindowsの隣にLinuxをインストールWindowsアプリ単体でデュアルブート導入を実現

DUAL BOOT github.com/Arjun-Ingole/hop
  • システム・ドライブ・容量を選んでインストールをクリックするだけ

  • 「Linuxを試したいWindowsユーザー」に最適。hop.exeをダウンロードして実行

nectarlink: AndroidスマホとWindows PCを直結クラウドなし・E2E暗号化のオープンソースアプリペア

PHONE LINK github.com/thtbee/nectarlink
  • 通知・メッセージ・通話・クリップボード・ファイル・写真を同期
  • スマホ画面をミラーリングし、アプリを個別ウィンドウで表示

  • アカウント・クラウド不要。QRコードでペアリング

stack-diagram: 一行の説明から公式ロゴ入りのアーキテクチャ図を生成ドキュメント作成をエージェントスキルで自動化

DIAGRAM github.com/caru-ini/stack-diagram
  • 技術スタックを説明した一行の文章をアーキテクチャ図に変換するエージェントスキル

AGENT SKILLS github.com/benjitaylor/skills
  • AIコーディングエージェント向けスキル集で、デザイン・モーション制作に特化

CARD 14

Blaze: Rustのインクリメンタルビルドをミリ秒単位に高速化Cargoと並行動作するメモリ常駐型ビルドツール

BUILD TOOL github.com/indexable-inc/blaze
  • Cargoと並行して動くRust用CLIビルドツール。build・run・testなど同じコマンドを使用
  • プロジェクトをメモリ上でコンパイルし続け、変更された関数のみ再コンパイルしてCargoのビルドに書き込み
  • AppleシリコンのmacOSとLinuxでローカル動作
  • インストールはcurlコマンド1回。リビルド待ちに悩むRust開発者に
よもぎ
よもぎ:タイトルに名前が載った今週の主役級。Rustの「ビルド待ち」問題に真正面から切り込みます。
CARD 15

uncut: コンテキストを一切削らないヘッドレス・コーディングエージェント不完全な回答は返さない「予測可能」な設計

CODING AGENT github.com/Balanov/uncut
  • シェルパイプライン・CIジョブ・ローカルモデル向けの小型CLIコーディングエージェント・ハーネス
  • モデル呼び出しごとに会話全体を送信し、ファイル内容やコマンド出力を決して切り詰めない
  • プロバイダー側で打ち切りが起きたらエラーとして扱い、不完全な回答を返さない
  • Ollamaを含むOpenAI互換エンドポイントで動作。JSONイベントとセッション再開対応の単一Goバイナリ
CARD 16

asm: アセンブリ言語のためのパッケージレジストリ＋CLIasm.toml一つで低レベルコードを共有

PACKAGE REGISTRY github.com/stubbi/asm
  • アセンブリプロジェクト向けパッケージレジストリとコマンドラインツール
  • asm.tomlファイル1つでプロジェクトを作成し、パッケージを追加してビルド・実行・テスト
  • 依存関係をロックし、パッケージはソースと検証結果を含むリリース記録を保持
  • Linux x86-64／arm64・AppleシリコンMacでネイティブ動作。asm newで開始

Poki: 脱獄なしでAIエージェントに実機iPhoneを操作させるMac上で動くローカルMCPサーバー兼ターミナルエージェント

MCP / IPHONE github.com/JosssphZhou/poki
