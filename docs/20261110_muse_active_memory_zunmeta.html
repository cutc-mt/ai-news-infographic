Active Memoryとは

覚えて・必要な時に使う

2つの力
  • 大事なことを覚えておく力
  • 必要な時に思い出す力
  • 前に行った説明を毎回やり直さなくていい
記憶 想起 説明の手間ゼロ
覚える力と思い出す力、
2つそろって初めて便利 💾

何でも覚えない賢さ

情報の種類を見分ける

3種類の情報
  • 今回だけ：「週末は雨」のような一時情報

  • 古くなった：引っ越し前の住所など時間で古くなるもの

一時情報 恒久情報 期限切れ

Active Focusとは

つまずいても目標に向かう

  • 立て直す
  • 別のやり方を探す
  • 1人で進めるか一緒に進めるかも見分ける
  • Metaはこの「詰まりどころ」でモデルを鍛えた
諦めて帰ってこない
AIになったのだ ⛰️

例えるならケーキの予約

満席でも止まらない

Memory.mdの見方・消し方

覚えた内容は見られる

Memory.mdを開いて確認

確認の手順
  • 覚えたことはメモ帳Memory.mdに書かれる
  • 今覚えていることはMemory.mdを見るかAIに聞けば確認できる
  • 「覚えるのはAI、確かめるのは自分」がセット
  • 内容は直すことも可能
寝坊の話が載ってたら
恥ずかしいのだ 📝

消し方①「忘れて」と頼む

一番やさしい消し方

お願いして消す
  • Museに「これを忘れて」と頼む
  • 決まった話題を探してできるだけ消してくれる
  • 小さくピンポイントで消せる方法
お願いベース 話題単位
「寝坊のことは忘れるのだ」
って頼むのだ 🧽

消し方②サイドチャット削除

会話まるごと消す

削除の手順
  • 話題ごとに分かれたサイドチャットを丸ごと削除
  • チャットのタブから選んで消す
  • メッセージ1つだけなら長押しで削除
  • AIアプリなら設定からチャットを全部消すことも
会話の単位で
ざっくり消せるのだ 🗑️

消し方③全部消すリセット

元に戻せない注意

最後の手段
  • 設定のデータコントロールからリセット
  • 会話もファイルも進行中の仕事も全部消える
  • ヘルプに「戻せない」とはっきり書いてある
押す前に一呼吸必要
全部消えるのは
覚悟が要るのだ ⚠️

消しても残る場合がある

ヘルプの注意書き

知っておきたいこと
  • ヘルプに「消した後もそこから学んだ情報を覚えている場合がある」と記載
  • 元の会話は消えても学んだことは残り得る
  • 何がどこに残るかまではヘルプにも書かれていない
  • だからMemory.mdで確かめるのがセットなのだ
消したのに覚えてる、
ということなのだ 👻

2つは別物
  • Memory.md＝あなたに合わせて答えるための記憶

  • Museを初めて使う時はオンになっている
  • 設定のデータコントロールからオフにできる
見る・直す→MD 学習→スイッチ
使われたくなければ
オフにしておくのだ 🔘
