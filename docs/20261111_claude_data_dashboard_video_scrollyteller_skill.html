CLAUDE DATA × DATA STORYTELLING — 2026.11.11

研究データがグラフ・解説動画・スクロールストーリーに一発変換 —— Claude Dataを実演、音声問題修正スキルも配布

Claude Opus 5.5・Fable 5.2・GPT-6.1 Solに同じ研究課題を渡して採点した比較データを題材に、Claude Dataの3つの見せ方を検証。ダッシュボード（グラフ・表、エディターによる手作業編集、デザイン切替、棒グラフ→折れ線グラフ）、Visual short（音声付きの5章構成解説動画）、Scrollyteller（スクロールで説明とグラフが切り替わるストーリー）を順に試し、日本語読み上げが章ごとに変わる問題の原因を突き止めて修正、スキル化して配布する。

① 導入

Claude Whiteboard・Claude Sheet・そして「Claude Data」データをインタラクティブに、さらに動画で見せる新機能

クロードのホワイトボード、クロードシート、そしてクロードデータと立て続けに新機能が登場。今回取り上げるのはデータの方。表データをインタラクティブに見せるのはもちろん強力だが、動画として見せるという使い方もなかなか面白い、というのが出発点です。

  • データの可視化＋α（動画）という新しい見せ方
  • ただし難点もあり、後半で克服してスキル化までいく
データがグラフになるだけじゃなく、動画にもなるんだって！これは見ないわけにはいかないよね〜
② 題材データ

前回のLLM採点比較データを流し込むClaude Opus 5.5 / Fable 5.2 / GPT-6.1 Sol の3モデル対決

題材は前回スコアリングしたデータ。Claude Opus 5.5・Fable 5.2・GPT-6.1 Solに同じ研究課題を渡し、毎回同じ物差しで採点した3モデル×複数回の得点率です。このデータをClaude Data（フローダータ形式）に渡すと、あっという間にきれいにグラフ化・表化してくれます。

③ ダッシュボード①

グラフと表に自動変換 —— 3回分がきれいに出る投げたデータがそのまま見やすいダッシュボードに

データを渡すだけでグラフで出したり表で出したり、3回分の結果がちゃんと整理されて表示されます。「非常に見やすい」というのが第一印象。数値の羅列だったものが、構造化されたダッシュボードに早変わりです。

  • グラフ表示と表表示をそろえて自動生成
  • 複数回のデータも1画面に整理
コピペしただけで表とグラフが両方できちゃうの、魔法みたいだね！
④ ダッシュボード②

エディターで手作業編集 —— 見出し変更・順序入れ替えプロンプトと手作業の「ハイブリッド」が効く

エディターを使うと画面に直接書き込みができる。見出しを微妙に変えたい、カードの順序を入れ替えたい——こうした修正はコーディングではすぐに書き換えられないことも多いですが、手作業なら一発です。「プロンプトでやった方が早い時」と「手作業が絶対早い時」を使い分けるハイブリッドこそClaude Dataの良いところ、と解説します。

  • 見出しの文言をその場で修正
  • パネルの並び順をドラッグで入れ替え
AIに頼むほどでもない直しがサッとできるの、地味にありがたい〜
⑤ ダッシュボード③

デザイン切替 —— デフォルト / ホワイト / オーシャン / ラージ雰囲気に合わせてワンクリックで着せ替え

「デザイン」を押すとテーマが切り替わる。「オーシャン」にすると確かに海っぽい配色になり、デフォルトやホワイトとも印象ががらりと変わります。文字サイズをラージにする指定も可能で、発表の相手や会場に合わせた見せ方調整が簡単です。

  • オーシャンなど複数テーマを内蔵
  • サイズ指定（ラージ等）にも対応
海みたいな青いテーマ、落ち着いてて発表にぴったりかも〜
⑥ ダッシュボード④

棒グラフ→折れ線グラフへ —— 時系列で見える「成長」形式を変えるだけで語るストーリーが変わる

棒グラフだと分かりにくい点も、「折れ線グラフにできる？」と頼むと生成し直してくれます（ツール読み込み→下書き生成まで1分30秒ほど）。時系列で見ると、コンテキストがない回では Fable 5.2 でもスコアが低いものの、コンテキストを追うごとに成長していく様子がくっきり見えます。OpusとSolは最初から高水準です。

  • Fable 5.2はコンテキストが増えるほどスコア上昇
  • Opusは一部の回で少し下がる場面も
同じデータでも「どの形式で見るか」で伝わることが変わるんだね。グラフ選びって大事！
⑦ ダッシュボード⑤

平均点も自動で —— 一番安定しているのは誰か安定度: Sol ＞ Opus ＞ Fable 5.2

平均点も出してくれました。結果はGPT-6.1 Solが一番安定していて得点も最高、次にClaude Opus 5.5、そしてFable 5.2。折れ線グラフ上でも「Solが安定」「Opusはここだけ下がっている」「Fable 5.2は上がってきている」という読み取り方ができる、と解説します。

⑧ Visual short①

Visual short —— 音声付きの解説動画ができた「ショート動画のようなもの」という予想を超えてきた

続いて動画のマークが付いたビジュアルショートを試します。プレゼンでビジュアルを見せると興味が出る——そんな期待を込めて実行。資料を読み込み、5章構成の短い動画を書き上げていきます。生成を待つ間、Claude（Opus）が資料を「読んで」理解している様子が画面からも分かります。

  • 作り方の資料を読み込んでから生成
  • 5章立ての短い解説動画になる
資料をちゃんと読んでから作ってるあたり、勉強してから発表する学生さんみたいで感心しちゃう

⑩ Visual short③

再生 —— なんと喋る！音声付きだった章ごとに採点結果を読み上げる解説ナレーション

再生してみると音声付き——「これ話すのか！ すごいね」と驚きの声。平均得点率はおよそ90%、1本の棒が1人1回分の得点率、最新回の合計点、項目ごとの3人の点の開き（一番開いたのは再現性で3点差）、3人の平均得点率、さらに「次は次の課題を超えられるかを見る」と続きの予告まで、データがナレーションで語られる構成です。

  • 音声の停止なども操作可能
  • 動画番組的な使い道も見えてくる
グラフが自分の成績を自分で説明してる…！これはプレゼンの武器になるよ〜
⑪ 問題発見

難点 —— 読み上げの声が章ごとに変わる聞きやすい日本語と、聞き取りにくい声が混在

冒頭で予告されていた難点がここで判明。章が変わると声質が変わるのです。片方の章は聞きやすいのに、もう片方は英語を男性声で読んでいるようなニュアンスの声になり、全然聞き取りにくい——長時間視聴には堪えない状態でした。

  • 章ごとに別々の声で読み上げられる
  • 音声同士の対話や音声指定ができると良いのに
せっかくの良い機能なのに、声がコロコロ変わると残念だね…。ここを直していこう！
⑫ 原因調査

ダッシュボード自身に聞く —— 原因は「英語表記」にあり章ごとの切り替えは直せないが、回避策はあった

Claude Dataのダッシュボードに聞くと「音声は選べない、読み上げは1種類だけ」との回答。再び問い直すと見えてきたのは——声が変わる場所が「章」なら直せないが、英語の文字が入る時に英語っぽい男性の声になる可能性がある、という指摘でした。つまり原因は字幕中の英語表記にあり。

STEP 1音声の変更を依頼→「選べない・1種類」と回答
STEP 22種類の声が混ざると再指摘
STEP 3英語文字が原因ではと特定
犯人は英単語だったんだ！日本語だけの世界にすればいいんだね〜
⑬ 修正実行

字幕をひらがな交じりに —— 英語訛りを見事解消「モデル名」の表記を変えるだけで声が統一された

提案に従い、読み上げ字幕の英語表記をひらがな交じりの表記（例: モデル名をカナ表記にする）へ変更して作り直し。下書きの中に英語になりうる要素が残っていないか調整すると、2番・3番の章にあった英語訛りが完全に消えました。「ちゃんと治ってるかどうか見ていただきたい」という冒頭の再生は、この修正後の音声だったのです。

  • 字幕の英語表記をカナ・ひらがな交じりに変更
  • 全章で日本語の声に統一することに成功
表記を変えるだけで声まで変わるなんて、字幕って奥が深い…！
⑭ 試行の裏側

失敗もある —— Opusでもコーディングに失敗する時下書き3案・セーブは1つ、戻す操作も駆使して完成へ

修正までの道のりは一筋縄ではいきませんでした。Scrollyteller生成時には正規表現まわりでつまずいて書き直し——「Opusのコーディング失敗は久しぶりに見た」と言及。変更時にはビジュアルショートの画面を開いた状態で選び直す必要があったり、下書きが3案できてセーブで採用できるのは1つ、元に戻す操作もありながら、試行錯誤で完成させました。

  • 正規表現のエラーで一度失敗→自動で書き直し
  • 下書き3案から1つをセーブ、必要なら戻す
AIだって失敗するんだね。でも諦めずに直し続けるのがコツなんだ〜
⑮ Scrollyteller①

Scrollyteller —— スクロールでストーリーが進む読み進めるたびに説明とグラフが切り替わる

3つ目の形式スクロールテラー。スクロールするたびにストーリーの章が現れ、グラフが切り替わっていく構成です。前回の平均→3人の平均（Solがトップ）→回ごとの得点率→第3回の結果→項目ごとの最大と最小の差（一番開いたのは再現性）→最後の合計点、と物語のようにデータが展開します。

  • スクロール連動でグラフが次々に切替
  • 自分で見るより「見せる」向きの形式
下までスクロールしたくなる設計、まさにデータの絵本って感じ！
⑯ Scrollyteller②

動画化のレシピ —— スクロール＋音声で一本の動画に自動操作と組み合わせれば番組制作にも使える

ScrollytellerもAIに自動で操作させて録画し、音声を入れれば1つの動画になる、と解説。Visual short同様、番組作りやプレゼンに使えそうな手法です。「動くものは見ていて『やってるな』と感じさせる」という効果にも言及し、プレゼン・番組向けの見せ方として高く評価します。

  • AIの自動操作＋録音で動画化可能
  • 音声学習・ビジュアル学習にも好適
動くグラフには人を引き込む不思議な力があるよね。発表が映える〜！
⑰ スキル配布

音声問題の修正手法を「スキル化」して配布同じ問題に遭遇したら、このスキルで直せる

今回の原因特定と修正（字幕をひらがな交じりにして英語訛りを消す手法）をスキル化。同じように章ごとに声が変わってしまった場合は、このスキルを使ってもらえれば修正できるはず、としてノート（説明欄）から配布します。動画タイトルの【スキル配布】がまさにこれです。

困りごと章ごとに読み上げの声が変わる
原因字幕に含まれる英語表記
対策表記をカナ・ひらがな交じりに変更
スキル化ノートから配布・再利用可能
スキルは動画のノート（説明欄）から入手できるよ。「音声が変になった…」という時に試してみてね！
⑱ まとめ

「人に伝えたい時」の強力な道具 —— 次はClaude SheetとClaude Whiteboardへその場でグラフ化・動き付け・即修正できるインタラクティブ機能

今回一番面白かったのは、データが音声付きの動画にできること——だからこそ音声修正に時間をかけた、という締めくくり。単純なグラフ化もその場で即でき、動きも付けられ、修正もすぐ。Claude Dataには非常に良いインタラクティブ機能が実装されたという印象で、「何か人に伝えたい時はこういうものを使うといい」と総括します。次回は残りのClaude Sheet、そして面白そうなClaude Whiteboardも紹介予定です。
