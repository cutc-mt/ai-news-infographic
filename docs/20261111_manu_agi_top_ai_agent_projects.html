01

Arcjet

RUNTIME SECURITY FOR AI AGENTS

AIエージェントのランタイムセキュリティ基盤。コード内に組み込んでエージェントの各アクションを実行前に審査し、allow・block・redact・hold-for-reviewを返す。プロンプトインジェクション検知、個人情報のマスキング、ツール呼び出し制限、トークン支出の上限設定が可能で、Claude Code・Codex・Cursorなどのコーディングエージェントを守る。判断記録は監査証拠として残る。

セキュリティ / 監査ログ対応
エージェントが暴走する前にここでストップ！セキュリティチームも安心じゃん☆
02

ProtoMap

GRPC & PROTOBUF CONTEXT ENGINE

gRPC・Protobufコードを扱うAIコーディングエージェント向けのコンテキストエンジン。リポジトリをスキャンしてサービス・メソッド・メッセージ・フィールドのグラフを構築し、マージのたびに更新。Claude CodeやCodexはMCP経由でそのグラフを検索でき、ファイルを再探索する必要がない。セルフホストでソースは自環境から出ない。

API変更の安全性UP / トークン削減
Protoの依存関係をグラフで把握とか、地味にマジで助かるやつ〜！
03

MCP1

ONE URL FOR EVERY MCP SERVER

チーム向けのMCPゲートウェイ。すべてのMCPサーバーをたった1つのURLの背後に置く。管理者はカタログやURLからサーバーをインストールし、トークンはMCP1内に封印されてノートPCには置かれない。グループ単位で読み取り専用・破壊的ツール制限・レート制限を制御し、Claude・Cursor・ChatGPT・Codexが接続。全呼び出しは監査ログに記録される。

トークン管理 / 監査ログ完備
MCPサーバー乱立で token管理ぐちゃぐちゃ問題、これで一発解決じゃん！
04

Voyager

AGENTIC FILE BROWSER FOR MAC

macOSにAIエージェントを組み込むエージェント・ファイルブラウザ。タブや保存済み検索でファイルを選び、エージェントに比較などを依頼できる。使うのは普段使いのエージェントで、タスクごとに選択。ファイルはMacのローカルに留まり、エージェントに渡すコンテキストは事前に確認できる。

ローカル完結 / 無料ダウンロード
フォルダの中にエージェントいるの、めっちゃ未来っぽくない？ゆる〜く使えるし◎
05

Egoist AI Passport

ONE PRIVATE MEMORY LAYER FOR EVERY AI

すべてのAIアプリを横断するパーソナルコンテキスト層。好み・履歴・アイデンティティをAIアシスタント間で持ち歩ける。ファイル・メモ・ボイスメモを追加し、共有前に新規情報をレビュー。どのアプリに何を・どれだけの期間見せるかを自分で決められ、アクセスはワンクリックで撤回できる。

プライバシー重視 / ポータブル記憶
アプリごとに設定振り出しのストレス、パスポート1枚で持ち歩けるの画期的〜！
06

ClipsPal

AI VIDEO EDITOR THAT CUTS RAW CLIPS

Mac・Windows対応のAI動画編集エージェント。トーキングヘッドの生素材を仕上げ動画に変換する。失敗テイクや沈黙をカットし、字幕・ズームイン・ビジュアルを追加、ショート動画や記事も生成。ディレクターへの指示は普通の言葉でOKで、Claude Code・CodexもMCPで接続可能。動画と文字起こしは手元に留まる。

クリエイター向け / ローカル処理
しゃべった素材ほったらかしたら動画になるの、編集へたっぴの味方だわ〜！
07

Clarify

THE AUTONOMOUS CRM

エージェントが営業の雑務を回すAIネイティブCRM。通話の録音・記録更新・購買シグナルの監視・見込み客の情報補完・フォローアップ下書きを自動化し、CRMの手入れをなくす。HubSpot・Salesforce・Slack・Googleと同期し、MCPサーバー経由でClaude・ChatGPT・Cursorからも操作できる。

営業自動化 / MCP対応
CRM入力サボってた人がいるでしょ…エージェントに丸投げすればいいのよ☆
08

Watchflows

DESCRIBE A CHORE, YOUR MAC AUTOMATES IT

AIノード内蔵のmacOS用ビジュアルワークフロー自動化アプリ。複数ステップや判断が必要なMacの繰り返し作業を、普通の言葉で説明するだけでフロービルダーがキャンバス上にフローを起草。フローはローカル実行でファイルはMacから出ない。Apple Intelligence・Ollama・Claude・ChatGPTなどに対応。

ノーコード / 無料トライアルあり
「こうして」って喋ったら自動化が生えるの、ZapierっぽいけどMac内完結がえらい！
09

Higgsfield Miracle

EDIT ANY VIDEO CLIP WHILE IT PLAYS

再生中の動画クリップをその場で編集できるAI動画ツール。新世代モデルではなく、オブジェクトの再着色やライティングの変更などタイプした部分だけが変わり、顔やカメラワークはそのまま。Claude向けMCPとChatGPT向けプラグインを提供。現在は早期テスト段階でウェイトリスト受付中。

部分編集 / ウェイトリスト受付中
テイクを撮り直さなくていいの!? マーケター的に超アリなんだけど〜！
10

Sage 2

BY LEVANTO LABS · LANGUAGE → LIVE DECISIONS

人間の言葉をソフトウェアの動作につなげるランタイムモデルAPI。メッセージを金額・日付・期間などの型付きフィールドに変換し、それぞれ出典テキストに紐づける。会話が変わればストリーミングで判断を更新。LLMが返答し、Sageがフィールドと判断、コードが次ステップを実行する構成で、推論やWebグラウンディングもサポート。

開発者向け / プレイグラウンド公開
「来週の金曜までに3万円」が型付きデータになるの、地味にスゴくない？
11

Inkling 2 Small

BY THINKING MACHINES LAB · AGENTIC MODEL

Thinking Machines Labの、長時間動くエージェントワーク向けAIモデル。コーディング・ナレッジワーク・画像入力をこなし、MCP経由でツールを呼び出す。Mixture of Experts設計で総594B中17Bのアクティブパラメータ、努力度レベルも調整可能。Tinkerプレイグラウンドで試してから、サンプリングやファインチューニングができる。

MoE 594B/17B active / Tinkerで調整可
594Bの巨大モデルを17Bだけ賢く使うの、省エネで頭いい〜！
12

Nomad Mac

A DISPOSABLE CLOUD MAC FOR YOUR AGENT

AIエージェントのためのオンデマンドクラウドmacOS。Appleアプリ開発にMacが必要な場面で、エージェントが約1分で本物のMacを起動し、Xcodeでビルド・テストして削除まで行う。Claude・ChatGPT・Codex・CursorがMCP・CLI・API・SSHで接続。各セッションは分離実行で、暗号化ドライブはセッション間で保持される。

Mac不要の開発者に / 分離実行
Mac持ってない人もエージェントがMac借りてビルドまでやるの、発想がヤバい〜！
13

outages.live

FREE LIVE OUTAGE FEED FOR AGENTS

コーディングエージェント向けの無料障害監視フィード。失敗が自分のコード起因かプロバイダー起因かの当てずっぽうをなくす。クラウドAI・開発者サービスの公式ステータスページを数分ごとにマージし、RSS・JSON API・MCPサーバーでログイン・キーなしで読める。

無料 / キー不要でMCP接続
「俺のコードのせい？クラウドのせい？」の万年論争、これで即解決なの笑
14

AgentClan

SEE & CONTROL YOUR CODING AGENTS

Claude CodeやCodexのエージェントをインタラクティブな3Dキャラクターにするデスクトップワークスペース。各エージェントが画面の隅に鎮座し、リングが作業中・完了・待機を表示。手のジェスチャーでエージェントを選び、音声でタスクを渡し、ファイルをドラッグで投げられる。ジェスチャー認識と音声認識はローカル実行。無料ダウンロード。

3Dキャラ / ジェスチャー操作
エージェントがペットみたいに画面の隅にいるの、絶対楽しいじゃん！！飼う〜！
15

ChatGPT Images 2.6

FASTER IMAGES, MORE EDIT CONTROL

OpenAIの画像生成・編集システム「ChatGPT Images」の新バージョン。生成が高速化され、編集ラウンドごとの制御が細かくなった。プロンプトや写真からマスコット・商品ループのようなアニメGIFも作れ、開発者は編集対象のリージョンをマークしたりSVGを書き出したりできる。ChatGPT・Codex・APIに組み込み済み。

GIF生成 / SVG書き出し対応
GIFまで余裕なの!? プロダクトチームの資料づくりが捗りすぎ〜！
16

Muse Realtime Avatar

LIVE EXPRESSIVE AVATARS DRIVEN BY VOICE

Museのリアルタイム音声をインタラクティブなキャラクターに変えるリアルタイムアバターシステム。顔も体もない会話AIという課題を解決する。音声モデルと同じ音声トークンストリームを使うためリップシンクと表情がずれない。参照メディアから肖像・イラスト・動物・物体をアニメーション化し、1秒未満で動画応答。身体性AIの構築者に刺さる。

1秒未満応答 / リップシンク完璧
喋りのトークンそのまま使うから口がずれないの、こだわり感じる〜！
17

Trace by context.dev

WEEKLY OPEN BENCHMARK FOR WEB SCRAPERS

AIエージェント向けWebスクレイパーがどれだけ確実にページを読めるかを測るオープンベンチマーク。ベンダー主張を計測結果で置き換える。毎週約2,500の新鮮なページをキャッシュオフで主要スクレイピングAPIに送り、アクセス率・速度・ページあたりコストを報告。データとコードは公開。スクレイパー選びの根拠になる。

週次更新 / データ完全公開
宣伝文句じゃなく数字で比較できるの、開発者的に清々しいまである〜！
