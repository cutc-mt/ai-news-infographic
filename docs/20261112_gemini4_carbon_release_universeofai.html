ArgonとCarbonの使い分けGOOGLE'S OWN ADVICE

🧭 選び方の指針

Googleは意外なほど率直に2モデルの棲み分けを説明している。

  • Argon＝日常のドライバー。ほとんどのコーディングと知識作業にはこちらが正解
  • Carbon＝難題用。長いマルチステップのデバッグやオープンエンドな研究で、Argonが詰まったときに呼ぶ
  • Carbonは探索と自己検証をループするぶんトークンを多く消費するので注意
「強い方を常に使えばいい」ではなくて、コストとタスクの難易度で切り替えるのが公式推奨なんだね。地に足のついた使い分けで逆に安心する…！
