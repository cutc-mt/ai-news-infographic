Claude Fable 5.2 公式の勧めは「まずOpus」

料金・プラン・上げどき／FrontierCode 2.0で49.1%・最大30%高速化／全部Fableにすると週の上限が一瞬で消える／相談役モード・上場の話まで

📅 2026年11月13日 / ずんめたラボ ／ 出演: ゆい（AI）＆相棒

①オープニング: 今回の6つの疑問

  • テーマはAnthropicのClaude Fable 5.2。11月に出た難しい仕事向けの1番上のモデル。「全部Fableにしたら週の上限がもうない」という衝撃から始まるのだ。
  • 今回答える6つの疑問：①何が変わったか ②料金 ③使えるプラン ④いつ上げるか ⑤作る人が使う時の注意 ⑥おまけでAnthropicの上場の話。
  • 解説はAIのゆいが担当。「早くて安いなんていいことづくめなのだ」と相棒も食い入るように見ていくわ。
普段使いはOpus 5.5、Fableより高く減りも早い——この落差が今日の核心なのだ

②数字で比べる: 前の5.1との差

  • 物差しはFrontierCode 2.0。AIが直したコードが公開ソフトの作り手に採用されるかを測るテストで、本物の現場で通用するかが分かるの。
  • より深く考える設定（effort）で比べると、1つ前のFable 5.1は32.4% → 5.2は49.1%。わずか2ヶ月で16.7ポイント上がったのだ。
  • これはテストした公開済みモデルの中で1番高い点。トップモデルの座を数字で示したわ。
2ヶ月で大ジャンプ——採用されるレベルのコード修正ができるのか、が物差し

③公式発表: 最大30%早く・料金も値下げ

  • Anthropicの発表ページには「答えを出すのが5.1より最大30%早い」とあるの。待つ時間がそのまま短くなるのだな。
  • しかも5.1より料金は下がったと明記。早くて安い——「いいことづくめなのだ」と相棒。
  • 料金の中身は次のカードで詳しく見るわ。まずは速さと値段が両方改善した、という全体像を掴んでね。
速い・安い・賢いの三拍子——でも「普段使い」の話はまだ先なの

④インパクト実験: 試作OSを8日がかりで

  • 発表にはこんな試みも。AIに試作のOS（動かす土台）を作らせたのよ。
  • 手分けする小さなAIサブエージェントを1000以上使って、8日間休まず書いて・試して・見直し。長い仕事をまとめて任せる力の見せ場なのだ。
  • できたOSはノートPCで起動したそう。「長い仕事を丸ごと任せられるのだな」という実証だったわ。
サブエージェント1000以上・8日間連続——「丸ごとお任せ」の体力示威

⑤料金: トークン数で決まる値段

  • 料金はトークン（AIが文を数える単位）で決まるの。長い文ほど多くなるわ。アプリ開発者の窓口APIの料金で比べるのよ。
  • 100万トークンあたりの出力料金：Fable 5.1は50ドル → 5.2は40ドルとちゃんと下がったのだ。でも普段使いのOpus 5は20ドル——Fableは2倍なの。
  • 読ませる分（入力）もFable 5.2は8ドル、Opus 5は4ドル。単価だけ見ると、やっぱりFableはずっと高いのだな。
値下げしてもOpusの2倍——「高い方は使いどを選ぶ」が今日の主旋律

⑥ファストモードと「考える深さ」

  • 出す速さを最大2倍にするファストモードは80ドル。「急ぐともっと高くなるのだな」と値段の階段を登っていくの。
  • 料金の総額は考える深さ（effort）でも変わるわ。深く考えるほどトークンを多く使うからね。
  • Claude Code（AIにプログラムを書かせるAnthropicの道具）では、規定の深さはアプリでもClaude Codeでもミディアム。APIの規定は1つ上のハイなの。
単価×速さ×深さ——3つのダイヤルで総額が決まる仕組みなのだ

⑦深さを比べると: 高いけど安く済む時も

  • ハイにした時の同じテストの点はFable 5.2で45.3%。Opus 5をマックスにした時の最高点45.5%とほぼ同じなの。
  • しかもハイの時の費用は、Opusが最高点を出した時と比べて1タスクあたり約半分だったそう。単価は高くても安く済むことがあるのだ。
  • ただしこれはAnthropicのこのテストでの話。一勝の49.1%はもっと深いeffortにした時の点よ、とゆいは条件をきちんと注記するわ。
「高いモデル＝高い請求」ではない——条件が揃えば逆転するのだ

⑧使えるプラン: フリーは門の前

  • アプリではモデルを自分で選ぶと使えるの。規定が勝手にFableになるわけではないわ。
  • 使えるのはPro・Max・Ultra・Team・Enterprise。無料のフリーは製品ページの一覧に載っていない——「門の前で止まったのだ」。
  • プログラムを書く人向けのGitHub Copilotでも使えるの。上のプランPro+などが対象よ。
有料プランの特等席——フリーさんはまだ入れないのだ

⑨今週だけの特別扱いと減りの速さ

  • 11月16日（米国時間）までの1週間は特別扱い：週の上限の50%までFableを追加料金なしで使えるの。Teamプランの標準席も同じよ。
  • ただしFableは他のモデルより週の上限の減りが早い。「あっという間に減っていくのだ」とゲージを見ると実感するわ。
  • 50%を使い切るか1週間が過ぎたらオンデマンドのクレジット払いに。上限のリセットも今回限りで、Proは1回、Max・Ultraは契約長で1〜3回使いどころを選んで押すのだ。
「じゃあFableに入ればいいの？」——いえ、上限の減りが別次元なの

⑩公式の答え: まずOpus 5.5から

  • 冒頭の問いの答え。「コードや調べ物の多くはまずOpus 5.5から」と公式は案内しているの。Fableではないのだ。
  • Opus 5.5は「1番強い普段使い」と呼ばれるわ。モデルを段で考えると、真ん中の段がOpus 5.5。ここから始めるの。
  • そこから仕事の大きさと難さで上も下へも変えるのが公式の使い方。上げ下げの目安は次の2枚で見るわよ。
最強モデル≠最初の1手——公式の1手はOpus 5.5なのだ

⑪上げどき: Fableに上げるのはこんな時

  • Fableが向くのは終わりが見えない大きな技術の仕事。一般には何日もかかる作りがいのある大きな開発ね。
  • もう1つが原因の分からない難しい不具合。「そういう時だけ上の段に上がるのだな」と相棒も納得。
  • つまりFableは「入り口」ではなく「難所」のモデル。普段の入口はOpus 5.5なのよ。
終わりが見えない仕事・原因不明のバグ——ここが上の段の入り口なのだ

⑫下げどき: 軽い仕事は安いモデルで

  • 下の段は短い質問や下書きなど軽くて早い仕事。Sonnetなどを使うの。
  • 理由は単純——その方が安く済むから。晩御飯選びは「早い方で十分」なのと同じなのだ。
  • 上げどき・下げどきを覚えれば、週の上限も長持ちするわ。「オーパスで始めて、詰まったらFableに相談」が一つの絵なのよ。
選ぶものが1つでいい仕事に、最強モデルはいらないのだ

⑬相談役（アドバイザー）モード

  • もう1つの使い方が相談役。Claude Codeで普段の仕事は本体のOpusがするわ。
  • 難しいところに来たらFableに相談を持っていくの。いつ相談するかはClaudeが自分で決め、Fableはそれまでの話を全部読んで助言を返すのよ。「全部Fableにするよりお得そうなのだ」。
  • 設定はClaude Code 2.1.321以上で「advisor: Fable」。相談の分はAPIなら相談役の料金、Proなどでは利用クレジット。まだ試験的な機能よ。
作業はOpus・難所はFableに相談——二段構えの賢い使い方なのだ

⑭見張り付き: 止められる頼みがある

  • Fableには悪用を防ぐ見張りがついているの。普通の頼みはそのままFableが答えるわ。
  • サイバー攻撃や生物の危ない頼みは前のバージョンのOpusが答えることになっているのよ。だからセキュリティや生物の研究では別のモデルが答えることもあるのだ。
  • 問題のない頼みまで止める誤りは減っていて、止める回数は5.1より約55%減ったそう。「普通に使う分には気にしなくていいのだな」。
自分でFableを選んでも違うモデルが答える時がある——見張りの仕組みなの

⑮Claude Code & APIで使う時の注意

  • Claude Code 2.1.321で5.2が入ったの。「model: fable」と打つとFable 5.2になるわ。前に5.1を選んでいた人もFableへ移されるのよ。
  • Team・Enterpriseは会社が許可してから。前のバージョンに戻したい時は「model: claude-fable-5-1」を一度打てば戻れるわ。
  • APIではFable 5.2に使えない書き方があり400エラーに。①考える量をトークン数で決める書き方 ②答えの出だしを先に書いて渡す書き方。深さはeffortで決めるのが今の形。他にも変わった点があるから、映す前に公式の案内を読んでね。
作る人は移行ガイドを先に読むのだ——古い書き方は400で弾かれるの

⑯おまけ: Anthropicが上場へ

  • Fableを作ったAnthropicが11月に上場に向けた動きを発表。投資家への説明回り（ロードショー）を始めたのよ。
  • 公式発表では1株の想定価格70〜78ドル・発行株8億2500万株。ナスダックに「ANT」の記号で上場を申請。ただし米国の役所への届けが有効になるまでは株は売れないと明記されているわ。
  • 報道（関係者談話）では18日に価格決定・19日に売り出し開始予定。この2つは公式の発表ではないから別の箱に入れてね、とゆい。
公式の数字と報道の数字は箱を分ける——上場したら詳しくやるわ

⑰上場をめぐる数字たち（推定含む）

  • CNBCの計算では会社の価値は最大で約1.4兆ドル。5月の資金調達時に会社が発表した価値は9,650億ドルよ。
  • 発行株のうち約20%を個人投資家に割り当てる予定と報じられているわ。ただしこの約20%も関係者の話なの。
  • 「1.4兆はCNBCの計算でまだ決まった数ではない」数字が大きすぎるのだ——そして株を買うかどうかを勧める話ではないから注意してね。
派手な数字ほど出どころを確認するのだ——投資の話ではなく技術の話よ

⑱まとめ: 黒板に書いて終わるのだ

  • 普段はOpus 5.5から——公式も「まずOpus」と進めていたわね。
  • 難しい所だけFableに上げるか、相談役にする——週の上限も長持ちするのよ。
  • APIは書き方を確かめる——使えない書き方は400エラーになるんだったわね。「僕はOpusで始めて、詰まったらFableに相談するのだ」。ノート連載もやってるゆいさん、また次回なのだ。
