WEEKLY DEV TOOLS ROUNDUP

週刊オープンソース開発ツールまとめ：Rails、VS Code、Ruff、MuJoCo、Sherlock ＆ Agent Browser など全20プロジェクト

動画：「Top Dev Tool Projects : Rails, VS Code, Ruff, MuJoCo, Sherlock & Agent Browser」
チャンネル：Manu AGI - AutoGPT Tutorials（公開：2026-11-12）／ YouTubeで視聴する
毎週公開される注目のオープンソース開発ツールをまとめて紹介する週刊シリーズ。今週はWebフレームワーク、コードエディタ、リンター、GUIライブラリ、デザインシステム、物理エンジン、セキュリティスキャナなど全20プロジェクトをピックアップ。主要18トピックをカード形式で整理します。
01 WEBフレームワーク

Rails —— RubyのフルスタックMVCフレームワーク

データベース駆動型アプリ構築に必要なすべてを備えたRuby用オープンソースWebアプリフレームワーク。ActiveRecordがDBの行をオブジェクトにマッピングし、Action Viewがテンプレートをレンダリング、ActionPackがリクエストをコントローラに振り分けます。メール、バックグラウンドジョブ、WebSocket、ファイルストレージ、リッチテキスト用ツールも統合。

Gemをインストールして「rails new」を実行、ローカルサーバーを立てればlocalhostで開発開始
02 コードエディタ

VS Code（code-oss）—— 編集・ビルド・デバッグの拡張エディタ

Microsoftとコミュニティが「code-oss」リポジトリでオープンに開発するコードエディタ。エディタのシンプルさと編集・ビルド・デバッグのコアサイクルを組み合わせ、コード編集・ナビゲーション・軽量デバッグ・豊富な拡張機能を提供します。組み込み拡張で多くの言語の文法やスニペットが追加され、Windows / macOS / Linuxで動作。多言語で開発するエンジニアに最適です。

ダウンロードしてすぐプロジェクトを開いて使い始められる
03 リンター／整形

Ruff —— Rust製の超高速Pythonリンター兼フォーマッタ

Rustで記述されたPython用リンター＆コードフォーマッタ。Flake8・Black・isortなどを1つのCLIに置き換え、「ruff check」で構文チェック、「ruff format」で整形を行います。900以上の組み込みルール、自動修正、キャッシュ機能を備え、pyproject.tomlで設定可能。pre-commitやGitHub Actions、VS Codeなどのエディタとも連携できます。

pipまたはuvでインストールして、自分のプロジェクトをチェック
04 エージェントスキル ×2

Impeccable ＆ TasteSkill —— コーディングエージェントにデザインセンスを

Impeccableはコーディングエージェントにインターフェース構築用の設計語彙を与えるスキル兼CLI。LLMやAPIキー不要の62個のチェック項目を持つルールベース検出器が、boulder・critique・audit・polishといったコマンドで一般的なAIの設計パターンを指摘します。TasteSkillはアートディレクションを自動選定し、著作権表記付きの実在写真で洗練された画面を構築。実ブラウザで3つの幅を確認し、スクリーンショットから問題を自動修正します。

Impeccableはnpmでインストール、TasteSkillは「npx skills add」で追加。Claude Code・Cursor・Codex CLI・Copilotに対応
05 GUIライブラリ

Raven —— C言語で書かれたマルチスレッドGUIライブラリ

エディタやツール構築のためのC言語製マルチスレッドGUIライブラリ。XMLでウィンドウを定義し、C・Rust・C++・C#・Python・Go・Zig・Luaから読み込んでアクションのバインドやウィジェット検索が可能。Windows / macOS / LinuxでVulkanにより描画し、テキストエディタ、ドッキング、ガラス素材、ビジュアルIDE「Raven Designer」を同梱。ツール開発者に最適です。

CMakeでビルドして、サンプルを試す
06 デザインシステム

Asterix —— MetaのReactデザインシステム（人間とエージェント向け）

人間とAIエージェントの両方がReactインターフェースを構築できるよう設計された、Metaによるオープンソースデザインシステム。150以上のアクセシブルな型付きReactコンポーネントを提供し、CSSカスタムプロパティ、ダークモード、テンプレート、ドキュメントやスキャフォールディング用CLIを備えます。ビルドプラグイン不要のCSSインポートで利用でき、Tailwind・CSSモジュール・通常のCSSでスタイルを上書き可能。

インストールして次のアプリを構築
07 ファイナンス／自動化

dailystockanalysis —— 監視銘柄のAI生成デイリーレポート

AIで監視銘柄の日次分析レポートを作成するオープンソースシステム。中国A株・香港・米国・日本・韓国・台湾・ETFの株価、チャート、指標、ニュース、ファンダメンタルズを取得し、スコア・トレンド・リスクアラート・アクションチェックリストを生成。GitHub Actionsでスケジュール実行もでき、レポートはTelegram・Slack・Discord・メールへ送信されます（調査用であり投資助言ではありません）。

フォークして自分のウォッチリストを追加
08 Web標準／AIスキル

modern-web-guidance —— AIエージェントに現代のWebコードを教える

Google Chromeチームが提供しMicrosoft Edgeがサポートする、AIコーディングエージェント向けのWebスキル集。Webプラットフォームの専門知識・ベストプラクティス・ブラウザ互換性データをスキルとしてパッケージ化し、肥大化したJavaScriptからネイティブAPIへの移行へとエージェントを誘導。CLIがCSSレイアウト・パフォーマンス・フォーム・アクセシビリティのガイドを検索・取得してコンテキストに組み込みます。

「npx modern-web-guidance@latest install」を実行
09 ワークフロー

AgentSkills —— エージェントをシニアエンジニアのように働かせる

AIコーディングエージェントを熟練エンジニアのように機能させる、エンジニアリングワークフローのオープンソース集。各スキルは仕様・計画・TDD・デバッグ・コードレビュー・セキュリティ・パフォーマンス・CI/CD・出荷を網羅した手順と検証チェック付きのMarkdownファイル。「/spec」「/plan」「/build」「/ship」などのスラッシュコマンドが各フェーズに対応し、4人のレビュアーペルソナが成果物をチェックします。

Claude Code・Codex・Cursor・Gemini CLIで動作。「npx @skills/add」で導入
10 ブラウザ自動化

Agent Browser —— AIエージェントのためのブラウザ操作CLI（Vercel Labs）

Vercel Labsが公開した、AIエージェントが実際のブラウザを操作するためのRust製CLI。要素参照付きページスナップショットを返すため、セレクタを書かずに参照でクリックや入力が可能。フォーム入力、スクリーンショット、PDF、ネットワーク検査、アクセシビリティ監査、セッション保存に対応し、MCPサーバーとしても動作します。

npmでインストールし「agent-browser install」を実行
11 パーソナルファイナンス

Farsure —— コミュニティ維持のセルフホスト型個人財務アプリ

開発終了したMaybe Financeのフォークとしてコミュニティが維持するオープンソースの個人財務アプリ。ダッシュボードでキャッシュフロー・純資産・支出を追跡し、オプションのAIアシスタントがお金に関する質問に回答。Dockerでセルフホストするか、Render・PikaPodsへデプロイでき、Web・デスクトップ・モバイル・API・AIエージェントから利用できます。

Dockerを使ってデプロイして開始
12 スマートホーム／MCP

HAM MCP —— AIアシスタントでHome Assistantを構築・管理

AIアシスタントに単なるデバイス操作にとどまらない、Home Assistantのスマートホーム構築・管理を可能にする非公式のオープンソースMCPサーバー。エンティティ検索、サービス呼び出し、自動化・スクリプト・シーン・ダッシュボード作成のほか、トレースやログ・履歴の読み取りによるデバッグ、バックアップや更新の管理も行えます。編集前の読み取り専用モードと自動バックアップを備えたDocker実行も可能。

HACS経由でインストール（カスタムコンポーネント／アドオンとしても動作）
13 セキュリティ

Codex Security —— OpenAI製の脆弱性発見・検証・修正ツール

コード内のセキュリティ脆弱性を発見・検証・修正する、OpenAIによるCLIおよびTypeScript SDK。リポジトリ・パス・git diffに対してスキャンすると、検出結果・レポート・検証済み問題への修正パッチを生成。security.mdの作成、脅威モデル構築、重大度評価、SARIF形式エクスポートが可能で、GitHub Actionsとしても動作し、セキュリティチームの脆弱性自動レビューを実現します。

npmでインストールしてスキャンを実行
14 学習リソース

The Algorithms Java —— 学習用Javaアルゴリズム＆データ構造集

学習目的でJavaにより実装された、オープンソースのアルゴリズムとデータ構造のコレクション。ソート・検索・古典的アルゴリズム問題を網羅し、各実装をリスト化したディレクトリファイルが用意されています。学習向けに書かれているため、Java標準ライブラリより実行速度が遅い場合がある点は要注意。読みやすいリファレンスコードとして学習者に最適。

ワンクリックでGitpodから開ける。まずはディレクトリを参照
15 Claude Code拡張 ×2

Game Studios ＆ Claude SEO —— Claude Codeを開発スタジオ／監査ツールへ

Claude Code Game Studiosはセッションを組織化されたゲーム開発スタジオに変えるテンプレート。ディレクター・部門リーダー・デザイナー・QAテスターの役割を専門エージェントが担い、フックとルールでハードコード値や危険なコマンドを検知。Godot・Unity・Unrealに対応。Claude SEOは技術的SEO、Core Web Vitals、スキーマ、バックリンク、ChatGPTやPerplexityでのAI回答表示をチェックする監査プラグインで、26のサブスキルと19の専門エージェントが並行動作し優先順位付きアクションプランを出力。

Game Studiosはクローンして「/start」、Claude SEOはプラグイン導入後「/seo-audit」を実行
16 物理エンジン

MuJoCo —— DeepMindのロボティクス／AI研究用物理エンジン

環境と接触する関節連結物体の高速かつ正確なシミュレーションを行う、Google DeepMindのオープンソース物理エンジン。ロボティクス、バイオメカニクス、グラフィックス・アニメーション、機械学習の研究に活用されています。最適化されたAPI、組み込みXMLモデルコンパイラ、対話型ビューアを備え、公式のPython・Unity・JavaScriptバインディングに加え、JAX製のMJXも利用可能。Linux / Windows / macOSで動作。

「pip install mujoco」を実行してすぐに始められます
17 OSINT／セキュリティ

Sherlock —— SNS全体からユーザー名の存在を一括検索

何百ものソーシャルネットワークやWebサイトで特定のユーザー名が存在するかを確認するオープンソースCLIツール。1つまたは複数のユーザー名で実行すると、アカウントが見つかった場所を報告し、結果をテキスト・CSV・Excelに保存。特定サイトリストやユーザー名のバリエーションにも対応。セキュリティ研究者やOSINT調査官のほか、自分のデジタルフットプリント監査にも便利。

pipxでインストールして自分のユーザー名をチェック
18 iOSユーティリティ

GestaltX —— iOSの隠れたデバイス設定を安全に編集

デバイス機能を制御するiOS構成データ「mobileGestalt」を表示・編集するiPhone / iPad用オープンソースアプリ。シンプルなUIでDynamic Island、常時表示ディスプレイ、起動音、充電制限、アクションボタン、ステージマネージャ、Apple Pencilの設定を調整できます。すべての変更に前後比較レビュー・権限検証・いつでも復元可能な自動バックアップが適用される安全設計（所有デバイス研究用）。
