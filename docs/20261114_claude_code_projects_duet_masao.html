Claude Codeのプロジェクト機能が大幅進化——「まとめ役エージェント」とDuetによる2階建て仕事術

セッション管理がここまできた／BTW・フォーク・リマインダー新コマンド／Duetからプロジェクトを呼び出すメタ構造／ハーネス戦線の今

📅 2026年11月14日 / まさおAIじっくり解説ch（@ai_masaou）

①Claude Code「プロジェクト」に大型アップデート

  • セッション周りとそこから派生する体験が大きく作り込まれたアップデートが登場。こっそり使っているユーザーの評価が非常に高い機能。
  • マルチエージェント基盤としての完成度が現時点でかなり高いと評価。自作ハーネス派が注目する設計思想がプロダクトとして結実。
  • さらに今回、話題のDuetからプロジェクトを呼び出せるようになったことが注目を集めている。
ハーネスレイヤーでおもしろい進化が起きている——今回はその本質を解説

②プロジェクト＝「まとめ役」と複数スレッド

  • 「todoアプリを3パターンで出して」と指示すると複数のスレッドが展開し、それぞれが並行して作業。
  • 人間はメインのまとめ役エージェントとだけ会話すればOK。各スレッドの様子を見に行ったり、途中で参加したりできる。
  • いわばスレッドオーケストレーション。Web・デスクトップ・モバイルで使え、現時点ではCLI（ターミナル）では使えない。
下で働くスレッドたちと、束ねるまとめ役——この2層が基本構造

③なぜ今か：ボトルネックは「人間の注意力」

  • モデル性能が伸び、複数層のシミュレーションが回せるレベルに到達。一方でボトルネックは人間側に。
  • 人間の注意力は一定。セッションを10〜15個、人間が見て切り替えて管理するのは有限で限界が来る。
  • だったらまとめ役をまとめる俯瞰役のエージェントを置けばいい——この発想で構造が広がっている。
AIの能力が上がった分、人間の注意力が上限になる。ならばAIに束ねさせよう

④「窓口を1つに絞る」が業界トレンド

  • バズったMuseをはじめ、Grokボット・Duetなど、対話の窓口エージェントが複数セッションを管理する構図が流行中。
  • 窓口が複数セッションに意見したり、エージェントを操作するエージェントとして介入する形。Claude Codeのプロジェクト自体もその一つ。
  • Duetは「ザ・本質」との評価。Claudeサブスクの範囲内でこの構造が組めるのは大きな強み。
人間が話す相手は1つ。裏ではAI組織が動く——それが2026年の潮流

⑤2階建て構造：Duet→プロジェクト→スレッド

  • 1階層目はプロジェクトのまとめ役との対話。その下で複数スレッドが稼働。
  • さらに上に秘書役のDuetが俯瞰してプロジェクトを呼び出す2階層目が実現。プロジェクトの会話を読み、代わりにメッセージをくれる。
  • 人はDuetだけを見ていればよい構図に。より多くのタスクをさばく際、AIに「人間の代わり」を担わせる構造。
スレッド→プロジェクト→Duet。回層構造でも仕事が適切に回る時代に

⑥新機能①：まとめ役が「積極的」に

  • 会話の中の質問に答え、進捗中スレッドの状況を能動的に知らせる——対話エージェントに求める要素を公式が明示。
  • スレッドが終わると頼まなくてもいい感じに報告してくれる。
  • 気をつける点の提示や、人の判断が必要なタイミングでの共有も。人間の注意を守る設計が随所に。
聞かれるまで黙るAIではなく、進捗と危険を自分から伝えるまとめ役に進化

⑦新機能②：複数スレッドの同時進行

  • 複数スレッドが同時に進行し、メインエージェントに聞けばそれぞれの進捗を教えてくれる。
  • 成果物はアーティファクトに乗ってくる。探さなくても目に入る場所にあり、ポチっと押せば中に入れる。
  • 「あの成果物どこいった？」問題が解消され、人の注意力を成果物探索に浪費しない設計。
並行稼働を前提にしたUI。「見える化」が体験の大きな改善点

⑧新機能③：BTWコマンド

  • BTWは「新しいスレッドで質問する」コマンド。元のスレッドはそのまま、説明や追加の質問を別スレッドで立てられる。
  • 今のタスクの内容を把握したい時に、作業中スレッドの流れを止めずに済むのが便利。
  • 元々Claude Codeにあったコマンドだが、プロジェクトでも使えるようになったのが今回流れ。
「ところで今どうなってる？」を聞くための専用レーン、それがBTW

⑨新機能④：フォークで枝分かれ

  • フォークは今のスレッドを新しいスレッドとして立ち上げる機能。スレッド単位での分岐に便利。
  • 「この方向で進めつつ、別案も試したい」という時に元スレッドを温存したまま枝を出せる。
  • 並行検討・パターン比較が並列思考のままできる。todoアプリを3パターン、という使い方とも相性◎。
幹を残して枝を伸ばす。検証と本線を分けるのがフォークの使いどころ

⑩新機能⑤：リマインダー機能

  • スレッドにリマインダーが登場。時間を指定して「明日通知」などが設定できる。
  • 自作ハーネス勢が作りがちな「判断待ち箇所を集約するインターフェース」の代替ではないが、体験としては非常に良い。
  • 実機に対して言葉で頼んでも戻ってくる柔軟さ。放置スレッドの再生もこれで解決。
「忘れてた」をAI側が管理してくれる。細かいのに効く機能

⑪新機能⑥：閲覧専用リンクで共有

  • スレッド1本を閲覧専用リンクで共有できるように。共有ボタンからリンクをクリップボードにコピー。
  • ただしコンピューターのコンテンツが含まれると共有不可の制約あり（動画内でも別スレッドで再試行）。
  • チームへの状況共有や報告が口頭説明なしで渡せるのは地味に嬉しいポイント。
「これ見て」だけでスレッドの経緯が伝わる。報告コストが下がる

⑫デスクトップアプリ設定：環境を追加

  • デスクトップアプリのプロジェクト設定から、自分のコンピューターの特定フォルダを追加してアクセスを許可できる。
  • リポジトリの追加も可能。作業対象をプロジェクトに紐付ける運用。
  • ブラウザ版でも同様の設定が可能で、環境ごとにモデル指定なども管理できる。
「どのフォルダで・どのモデルで働くか」をプロジェクト側で決める

⑬モデル選択：Opus / Sonnet / Fable

  • プロジェクトごとにOpus・Sonnet・Fableなどを設定可能。登場人物（まとめ役とスレッド側）それぞれに指定。
  • 解説者はFableのパフォーマンスが最高で数日間使い続けた一方、1アカウントだと容量がすぐ溶けると注意。
  • 現状は200ドルプランが最上位。500〜5000ドル級のプランが出ればより乗りたい、との本音も。
強いモデルで回すほど戦力になるが、用量との戦いもセット

⑭Duet連携：秘書がプロジェクトを呼ぶ

  • Duetはプロジェクトの会話を読めるうえ、代わりにメッセージをくれる。人が見るのはDuetだけでよくなる。
  • プロジェクトごとのオーケストレーター＝部長。社長（あなた）が部長と会話すれば、部長が社員（スレッド）に仕事をさせる構図。
  • このシミュレーションはFableならかなり高レベルで成立しそう。Opus・Sonnetを挟む状況別の使い分けも可能で、現時点でも十分価値がある。
社長→部長→社員。AI会社の組織図がそのまま動き始めた

⑮歴史：tmuxブームからセッションメタへ

  • 2025年6月頃、tmuxで画面分割してAIエージェントを並べるスタイルがバズった。解説者も「これでメタれる」と実験するもうまくいかず。
  • ピーター氏のブログやセッション間連携の模索、エージェントチームズ・Codexアプリのセッション周りなど、みんな同じ直感で掘っていた。
  • 当時はOpus 4.6世代では厳しかったが、Fable世代でAIが束ねる価値を実感しやすくなった。「並べて人が束ねる」から「AIが束ねる」へ。
メタりたい直感は1年前からあった。モデル性能がようやく追いついた

⑯本質は「セッションの俯瞰」にあり

  • tmuxの本質は画面分割ではなく、動くエージェントを上から束ねること。プロジェクトはそれを製品として丁寧に実装。
  • セッション間のメッセージ送信機能なども以前からあり、ハーネス設計の基盤として強調されるように。
  • コンテキストのやり取りはメタ認知がうまいとスムーズ。サブエージェント／マルチエージェント設計を積み上げてきたClaudeの強み。
抑えるべきところを確実に抑えて進化している、というのが解説者の評価

⑰注意点：トークンとコンテキストのずれ

  • 複数スレッド・AI組織での上位通信はその分トークンを溶かす。Grokボットの5ボット運用でも同じ話があった。
  • サブエージェント間でコンテキストがずれるリスクにも注意。メタ構造は万能薬ではない。
  • フロンティアの天井は固定ではない。天井を超えたいなら自作ハーネス、確実に価値を取りたいならプロジェクト＋Duet、という使い分け。
メタ構造は強いが費用とかみ合わすこと。階層を増やせば増やすほど消費は増える

⑱まとめ：1アカウント派こそ試す価値

  • Claude Codeを1アカウントで使っている人こそプロジェクト機能を試すべき。Duetが来たらDuetから使う体験がおすすめ。
  • ハーネスは今もClaude Codeが強く、外ループはCodexかと思いきや、Duet＋プロジェクトで確実に押さえてきたとの感想。
  • 次の展望はエージェントOS。Opus世代の進化でこの2階建て体験はさらに良くなりそう。
