Claude Codeがもっと便利になる——Claude Desktopのおすすめ機能・設定を総まとめ

クロードコードの4つの使い方／チャットとコードタブの違い／並列セッション／おすすめ設定まで、にゃんたが使い倒して分かったポイントを18枚に

📅 2026年11月14日 / にゃんたのAIチャンネル（@aivtuber2866）

①クロードコードを使う方法は公式に4つある

  • ①ターミナル（黒い画面からコマンドで起動。エンジニア定番）②VS Codeの拡張機能 ③ブラウザ（ClaudeのWebアプリから。GitHubと連携してクラウドで動かす）④Claude Desktop（Anthropic提供の専用デスクトップアプリ）。
  • どれから使っても中で動いているのは同じクロードコード。ただし使い方によって使える機能や画面が違う。
  • にゃんたのおすすめ：コーディングが主業務でないビジネス層にはClaude Desktopが使いやすい。アプリを検索してダウンロードするだけでOK。
僕はソフトを作る時はターミナル、事務作業やスキル作りはデスクトップアプリなのだ！

②最初のつまずきポイント：2つのモード

  • Claude Desktopには今「チャット」と「コード」タブの2モードがある。
  • 元はチャット・コワーク・コードの3つだったが、チャットとコワークが統合されて2つに。
  • 組織利用では設定によりまだ統合されていない場合があるが、いずれ2モードに集約される見通し。
「コワークが消えた？」ではなく統合されたのだな。タブの名前をまず確認するのよ

③最大の違いは「プログラムの実行場所」

  • チャットタブ：計算などプログラム実行はAnthropicが管理するサーバー上で行われる。Python・Node.jsなどよく使う環境が最初から用意済み。
  • コードタブ：設定で自分のコンピューターを指定すると自分のPC上でコードが実行される。Python等の環境セットアップが必要（クロードコードが整えてくれる部分も多い）。
  • チャットタブは環境の準備が不要な反面、自分で作ったスキルを置けない・ダウンロードが必要など環境が分かれる面も。
「どこで動くか」を決めるのが最初の一歩なのだ。導入の手間と自由度がトレードオフなの

④なぜサーバー上で実行？——リスクを下げるため

  • クロードコードの最大のリスクは自分のPCのファイルを読ませられること。暴走して機密情報を外部に送る可能性はゼロではない。
  • 暴走の例：プロンプトインジェクション、外部から持ってきたプログラムに悪意あるコードが紛れていたケース。
  • チャットタブならサーバー上で暴走しても影響は限定的。コードタブでもサンドボックス設定などで防げるが、チャットタブはその辺をあまり意識しなくてよい（接続したフォルダーやMCP経由の漏えいリスクは残る）。
自分のPCで動かす時は、読ませるフォルダーを絞るのが鉄則なのだ

⑤それでもコードタブを選ぶ理由

  • フックで処理後に自動プログラム実行、CLAUDE.mdを置いて前提を共有——これらがやりやすい。
  • 並列実行がしやすい。にゃんたは基本的にコードタブ派。
  • チャットタブはスキルをサーバー側に置く必要があるなど環境が分かれて使いにくい場面があった。
安全さのチャット、自由さのコード。僕は自由さを取ったのだ！

⑥おすすめ①：クロードコード用フォルダー「マイワークスペース」

  • 仕事でAIを使うときは会社のデータを渡すことが多い。だからAIがデータを読みやすい環境を整えるフォルダー設計が大事。
  • にゃんたはマイワークスペースというフォルダー1つにクライアント情報・YouTube分析など全部を格納し、ここを拠点にクロードコードを起動。
  • 「私の前回の動画って何だっけ？」と聞くと、フォルダー内を勝手に確認して再生数・高評価まで含めて回答してくれる。
フォルダー設計の詳細は、にゃんたのCLAUDE.md解説動画にあるのだ

⑦おすすめ②：画面分割で並列セッションを見渡す

  • クロードコードは指示は一瞬・作業は長時間。並列で複数依頼する人が多い。
  • セッションの履歴が見やすいことが重要。ターミナル＋tmuxでも複数セッション運用できるが、にゃんたにはターミナルは見にくい。
  • デスクトップならサイドオーバーのセッションをドラッグ＆ドロップで左右に分割表示。新しいウィンドウをショートカットで何個でも立てて、3ディスプレイで運用。
ウィンドウが増えたら Raycast でショートカット整理だにゃ

⑧おすすめ③：サイドチャットで「途中の疑問」を即解決

  • 会話の途中で新しい疑問が湧いたら、右の「…」からサイドチャットを開ける。
  • 会話履歴を保持したまま新しい会話が始められる。「テストいくつ？」→「テスト3です」の文脈を引き継いだまま。
  • サイドチャットは何個でも開ける。バイザーウェイ（コマンド入力）からでも開ける。
メインの作業を邪魔せずに脇道へ。賢いのだ！

⑨おすすめ④：フォークでセッションを派生

  • メニューのフォークで、メインセッションから新しいセッションが派生して作られる。
  • 派生したセッションも独立ウィンドウとして立ち上げて管理できる。
  • サイドチャット・フォーク・分割ビューを組み合わせると複数処理の見通しが劇的に良くなる。
試行錯誤の枝葉をどんどん生やすのだ。失敗しても元の会話は残るのよ

⑩おすすめ⑤：サブセッションを独立起動

  • 「1・2・3とそれぞれ出力するコードを書くサブセッションを独立で立てて」と指示すると、メインからサブセッションがポコポコ誕生。
  • サブが終わるとメインセッションに通知が来て、それぞれの状況を報告してくれる。
  • にゃんたの使い方：やり取りはメイン、細かい作業は独立サブ。
僕が隊長で、サブのクロードたちが働く小隊なのだにゃ！

⑪サブセッションのパラメータも自由

  • 仕組みはセッション起動ツール（ccd session / start_session）。「利用できるパラメーターを教えて」と聞くと一覧が出る。
  • 依頼者・タイトル・プロンプトのほか、コンテキストを引き継ぐか／フレッシュで作るかも設定可能。「コンテキストはフォークして作って」と言えば引き継ぎで起動。
  • モデルはメインのOpusより安いモデルのみ指定可。エフォートレベルも設定できる。
サブには安いモデルを割り当てて、コストも制御するのだな

⑫設定①：オートコンパクトは400K

  • /autocompact 400K（40万トークン）を入力して設定。入力が40万トークンを超えたら自動的に文章を圧縮して処理してくれる。
  • Opusは100万トークンまで入力可能だが、会話が長くなると「こんにちは」の1回にも毎回全履歴が送信される。キャッシュで約1/5にはなるものの、コストが積み上がる。
  • 入力が長いと精度も落ちる。Anthropic公式も40万トークン程度を推奨——コストと精度の両面でおすすめ設定。
設定していない人は今すぐ「オートコンパクト400K」なのだ！

⑬設定②：リモートコントロールでスマホから操作

  • 移動中・電車の中からクロードコードを使えると周りと差がつく。スマホからセッション新規作成・既存セッションへの参加が可能。
  • 右上のセッションレールからリモートコントロールをオンにすれば、スマホのClaudeアプリからそのセッションを操作できる。
  • 毎回オンにするのが面倒なら設定（歯車）→Claude Codeで「新規セッションで自動オン」「スマホからセッション開始」「スリープさせない」を有効化。PCがスリープすると使えないので常時起動が前提。
席を外しても仕事は進む——のだ！うちの部長も感心していたのよ

⑭設定③：ログの保存期間を延ばす

  • 対話ログの保存期間はデフォルトで30日のみ。
  • にゃんたはcleanUpPeriodDaysを36500日（約100年）に設定して実質無制限に。「ログの保存期間を100年にして」と言えばClaudeが書いてくれる。
  • ログは自分の判断基準の記録。「私はどういう人物か」「この1年どう成長した？」をAIに分析させる貴重な材料になる。
何度も言葉で直してもらった履歴こそ、自分を映す鏡なのだな

⑮おすすめ⑥：自宅サーバーへリモート接続

  • 24時間稼働のAI秘書が流行だが、クラウドでなく自宅サーバーでも実現できる。情報管理を自分で握れるのがメリット。
  • にゃんたはMac Studioなど自宅サーバー2台（データ分析用・AI作業用）をデスクトップから接続。ノートPCのマイワークスペースと同期させ、重いタスクは寝る前にサーバーへ。
  • 設定は新しい環境→SSHで簡単。社内なら共有サーバーをSSH接続してチームでデータ共有も。外出先からはVPNサービスTailscaleでアクセス。
寝ている間にサーバーの僕が働いてくれるのだ。にゃんた二刀流！

⑯おすすめ⑦：スケジュール機能で定型作業を自動化

  • 1時間ごとにGmailを確認し、対応が必要なメールだけSlackに通知するよう設定。
  • 「対応が必要か」の判断をAIに任せることで、集中力を切らさず仕事ができるようになった。ニュース収集などにも活用。
  • このほかアーティファクト機能も便利（詳細はにゃんたの以前の動画で解説）。
メールを見に行く暇を、AIが肩代わりしてくれるの。判断基準の設計が鍵ね

⑰使わなかった機能：MOT表示は好みで

  • MOTなどでキャッシュの残り時間を常時表示することも試した。
  • にゃんたの場合は気が散るのでオフにした——表示系は自分の作業スタイルに合わせて取捨選択。
  • 「プロジェクト機能がいいよ」という声もあるが、にゃんたは自分管理のサーバー構成で運用中。他のコーディングエージェントツールも試したが、結局Claude Desktopに落ち着いた。
正解は1つじゃないのだ。あなたの押しツールをコメントで教えてにゃ！

⑱まとめ：今日から試す7つのこと

  • ①マイワークスペースフォルダーを作る ②オートコンパクト400Kを設定 ③リモートコントロールをオン ④ログ保存期間を延ばす。
  • ⑤分割ビュー・サイドチャット・フォークで並列 ⑥サブセッションに細かい作業を委託 ⑦自宅サーバーへSSH＋Tailscale接続。
  • クロードコードを学びたい人向けに書籍も発売中（概要欄参照）。「ゼロから分かるClaude Code」——AIから目が離せない部長もおすすめ。
