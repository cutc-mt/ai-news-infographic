クロードが会議に参加して、話しながら資料を作る——「Claude Meetings」まるごと解説

誰が使える？／料金は？／会議の中身はどこに残る？／うちの会社で今すぐ使える？——5つの疑問に答えるAIニュース

📅 2026年11月14日 / ずんめたラボ（@zunmeta_lab_ch）

①今日のテーマはAnthropicの「Claude Meetings」

  • Anthropicが発表したクロードがオンライン会議に参加する新しい機能「Claude Meetings（クロードミーティングス）」。
  • 今回の動画では5つの疑問に答えていく形で解説。①何をしてくれるか ②どうやって呼ぶか ③誰が使えるかと料金 ④会議の中身はどこに残るか ⑤うちの会社で使えるか。
  • 冒頭のお題は「会議でメモを取っていて話に入れなかった」という悩み。メモ係をクロードに任せて、人は話に集中するのが狙い。
会議にAIが来るのだ！僕の会社でもすぐ呼びたいのだ！——まずは呼び方と使える人を確かめましょう、という回

②会議画面では「参加者の1人」として並ぶ

  • 対応するのはGoogle Meetのオンライン会議。参加者が並ぶ枠（タイル）の1つとして、クロードが参加者の1人のように表示される。
  • クロードのタイルには今何をしているかが表示され、本当に会議に「座っている」感覚。
  • 返事は基本会議のチャットに文字で返ってくる。
枠を1つ占拠して本当に会議に座っているのだ！

③話しかけ方は「声」と「チャット」の2つ

  • 呼びたい時は声で「クロード」と呼ぶだけでOK。
  • Meetのチャットに書いて聞いてもいい。答えはチャットに文字で返ってくる。
  • あらかじめ繋いだ道具（コネクタ）も会議の中で使える。例えばSlackでメッセージを送るなど。最初は道具を繋いだ本人に「使っていいか」を聞いてくる。
声で呼んでも、チャットに書いても。繋いだ道具の使用は本人の許可を確認してからなの

④話しながら文書もホワイトボードも作れる

  • 会議中の作成依頼の例：「イベントの予定をホワイトボードに」でお願いすると、月カレンダー付きの予定表ができていく。
  • 招待された仲間なら誰が頼んでもOK。しかもその場で書き直せる。文書もホワイトボードもいくつでも頼める。
  • 作ったものは会議の後もまとめて見られる。
話しながら資料ができていくのだ！記録係というより「一緒に作る係」なの

⑤公式記事に載っていた使用例：イベント予算

  • イベントの予算を話している会議で、「前の年のイベントの費用は？」とクロードに質問。
  • クロードはまず「調べていいか」を確認し、許可されると調べて答えを会議のチャットに出す。
  • さらに今の計画と比較してくれる——会議を止めずに調べてもらえるのがポイント。
「勝手に調べる」のではなく、必ず許可を取ってから動くのがクロードの流儀なの

⑥従来の議事録AIとの違いは「会議の中で働く」こと

  • 既存のAIツールの多くは会議の記録と要約を会議の後に読む道具。
  • Claude Meetingsは会議の中で働く。質問に答え、文書やホワイトボードを一緒に作る。
  • 会議中に働く道具は他にもあるが、クロードは話しながらその場で形にしていくのが特徴。会議が終わると議事録とやることリストも残る。
「後で読む記録」ではなく「その場で一緒に作る」——ここが新しいのだ！

⑦入退場のルール：最長8時間、断られたらしつこくしない

  • クロードは大抵確認なしで会議に入ってくる。ただし入っていいかを聞かれることもあり、その時は主催者が決める。
  • 主催者に断られると、誰かが呼び直すまで戻ってこない。
  • 会議にいられるのは最長8時間。帰る前にやることをまとめてくれて、聞くのをやめて頼めば止まり、「帰って」と頼めば会議から出ていく。
断られたらしつこく入ってこないのだな。お行儀がいいのよ

⑧呼び方はアプリから4ステップ

  • クロードのアプリで「Claude Meetings」を開く。
  • Googleカレンダーを接続。事前に会社の管理者がカレンダーを使えるようにしておく必要がある。
  • カレンダーからクロードを呼びたい会議を選ぶ。
  • 「クロードを追加」で会議に入ってくる——会議の予定からそのまま呼べる。
毎回会議のたびに呼ぶのは面倒……という人は自動参加設定を使うの

⑨自動参加設定は「本人」が決める

  • 呼びたい会議だけ都度呼ぶか、自動で参加させるかを選べる。
  • 自動なら「1対1の会議を除いた全部」か「全部の会議」かを選択。
  • この設定は自分で決めるもので、管理者が代わりに決めることはできない。
1対1の相談には来ないようにできるのだな。プライベートな話を聞かれないで済むの

⑩使えるのは「会社のプラン」だけ——個人のProでは使えない

  • 対象は会社・組織で入るTeam（チーム）とEnterprise（エンタープライズ）の2プランのみ。
  • Free・Pro・Max・Ultraなど個人で入るプランは対象外。「僕がプロを払ってもダメなのだ？」——ダメ。先に会社がチームかエンタープライズに入っていることが条件。
  • Teamならミーティングスは初期状態でオン（管理者がオフにも可能）。Enterpriseは管理者がオンにして有効化。まだ試験提供段階で順に広げている最中。やり取りをAnthropic側に残さない特別な契約の会社などは対象外。
「会社の誰かが払えばみんな使える」の正体はこれ。個人課金では届かないの

⑪料金：Teamは「席」課金で米国価格は1席20〜25ドル

  • Teamは2人から150人のチーム向けプラン。料金は使う人1人分の枠＝「席（シート）」単位。
  • 米国の価格で標準の席は年払いなら1人1月20ドル、月払いなら25ドル。使う人の数だけ席が必要。
  • 日本の価格は申し込み画面で確認を。ミーティングス利用で追加の料金の見え方は次のカードで。
席の数だけ料金が積み上がる。日本円の金額は公式の申し込み画面で確かめてね

⑫使用量は「ゲージ」で管理。道具を使うと減る

  • ミーティングスの料金は使用量のゲージで確認。使用量とはプランで決まった「クロードを使える量」のこと。
  • ベータ期間中は議事録と文字起こしが追加料金の対象。会議の中の質問への回答に追加料金はかからないが、繋いだ道具を使った回答は使用量にカウントされる。
  • 使った量次第で会社の料金が増えることも。なお会議で作った文書とホワイトボードは2027年2月10日まで無料。その後の料金はまだ公表されていない。
道具を使うとゲージが減るのだな。無料期間の後の料金は「まだ書かれていない」のに注意ね

⑬会議の中身は「会議ページ」にまとまる

  • 会議ごとにクロードの中に会議ページが作られ、議事録・やることリスト・文字起こし・作ったものがまとまる。
  • 見られるのは招待された同じ会社の人。同じ会社の中なら他の人への共有もできる。
  • 招待された社内の人にはまとめのメールも届く。「会議の終わりにまとめをチームへ送って」と頼むことも可能。後からクロードのチャットで過去の会議について質問できる。
後でまとめて見返せるのだな。終わった後もクロードに聞けるのよ

⑭録音はしない——残るのは文字と説明文だけ

  • 残すものは決まっている：文字起こし・議事録の要約、そして画面に映ったものを文章で説明した「画面の説明文」。
  • 音声そのものは残さない。声のデータは保存されない。
  • 画面に映した資料は説明文として記録に残る。
「会議の声はずっと録音される」ではなく、音声データは残らないのだ！

⑮社外の人がいる会議での挙動はプランで逆になる

  • Enterpriseは何も変えなければ社内の会議だけ。社外の人が招待されていたら入らないし、途中で社外の人が入ってきたら会議から出ていく。
  • 他社の議事録ボットが入ってきても、クロードは会議から出ていく。
  • Teamはヘルプによると何も変えなければ逆で、社外の人がいても入れる。その時の動きは3つ：①ゲストの話も聞く ②チャットに参加の知らせは出すが、そこで聞かれても返事はしない ③会議ページとまとめのメールはゲストには届かない。
お客さんの前で勝手に答えないのは安心なのだ。どっちが安心かは会社の決め方次第なの

⑯呼ぶ前に確認する3つのこと

  • 1つ目：全員の同意。「文字起こしされても良いか」を参加者全員に確認。Anthropicも呼ぶ前に全員に確かめるよう案内している。
  • 2つ目：社外の人がいるか。会社の設定と合わせて確認。
  • 3つ目：繋いだ道具の使い方。クロードは最初に聞いて、1度「はい」と言うとその後も使う。道具はその道具を持つ本人の許可で使われ、声で頼まれた場合は今のところ毎回「誰が頼んだか」を確認する。
他の人が僕のSlackを勝手に使えないのだな。黙っているのは同意じゃないわよ、という話も

⑰うちの会社で使える？——今はGoogle Meetだけ

  • 使える会議は今のところGoogle Meetのみ。Google Meetならクロードが来てくれる。
  • 他の会議サービスは「近日対応」とだけ記載。どれに対応するかは書かれていない。
  • Meet以外の会議では今の議事録道具を続けることに。なおAnthropicは議事録ツール各社（Gong・Grain・Otter など）と提携し、会議の文字起こしをいつもの道具へ送れるようにする予定（時期は近日とのみ）。
Google Meetを使っていない会社はまだ使えないのだ。連携で今使っている道具とも繋がる予定なの

⑱会社で始めるには：管理者が決める3つの設定

  • 管理者はクロードの管理画面で組織の設定→製品を開き、Claude Meetingsの設定を3つ決める。①使える人（オフ／決めた役割の人だけ／全員）②社外の人がいる会議に入れるか（入れるか／社内の会議だけ）③繋いだ道具を会議の中で使えるか。
  • 前提としてGoogleカレンダーも先に使えるようにしておく。
  • まとめ：①会社のプラン（Team／Enterprise）で使う ②呼ぶ前に全員に確認 ③音声は残さない（残るのは文字起こし・要約・画面の説明文）。次の会議はメモを取らずに話に入ろう。
