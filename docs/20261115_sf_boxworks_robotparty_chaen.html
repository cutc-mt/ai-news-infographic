シリコンバレーの「リアル」を见てきた——BoxWorksでジェンスン・フアン生観戦、夜のロボパーティー潜入、アポなしハッカソン突撃

中国のロボット10社と提携した直後のアメリカ出張。米ロボットはどこまで進んでる？ 中国とどっちが上？【シリコンバレー出張 前編】

📅 2026年11月15日公開／チャエン【AI研究所】（11月4日出発・サンフランシスコ4日間）

①中国から直接アメリカへ

  • 11月4日夕方の羽田空港。中国出張→帰国後セミナー・仕事・打ち合わせをこなし、そのまま空港へ流れ込む強行スケジュール。
  • 日本時間AM4時ごろの10時間フライト。「めっちゃ眠い」中、ご飯と仕事でやり過ごす。
  • 目的地はサンフランシスコ。久々の快晴の空に「中国と全然違う」と一目で感動。
中国→日本→アメリカ、怒涛の出張ルートなのだ

②サンフランシスコ着：第一印象

  • 入管はほぼ並ばずスムーズ。市内まで車で30分・安くても50ドル（約8,000円）と日本感覚ではお高め。
  • ハイウェイ沿いにはAI企業の広告が並ぶ——シリコンバレーの空気をいち早く感じる。
  • 泊まったのはユニオンスクエア（東京でいう渋谷）の近く。平日だからか人は少なめ。
街の景色から「AIの街」感が滲み出ているの

③1日目は仕事の街

  • キングベッド＋サンフランシスコの景色を備えたホテルに到着。昼はラーメン。
  • その後は日本とのリモート打ち合わせが続く「ホテル缶詰め」の1日。
  • 振り返り：「サンフランシスコは仕事の街。中国の方がカオスで人の温もりがある。でも仕事に集中できる」。
観光ではなくガッツリ稼働の出張なのだ

④BoxWorksに参戦

  • Boxジャパンからの招待でBoxWorks（Box主催のカンファレンス）に参加。Boxは言わずと知れたファイルストレージサービス。
  • 朝いちでコーヒーをゲットし、9時からの基調講演へ。会場は堅めの人だらけで「めちゃくちゃアウェイ」。
  • 会場には続々と企業・団体の名前が映し出され、明日はジェンスン・フアン氏が来るらしい——という流れに期待値MAX。
呼ばれたからには全力で見てくるしかないの

⑤ジェンスン・フアンを生で見た

  • ステージに現れたのはNVIDIAのジェンスン・フアン氏。聞き手はBoxのアーロン・レヴィ氏。
  • 「やっぱりジェンスンさんが来たらすごい盛り上がってましたね」——大拍手の基調講演に。
  • 感想は「話がうまい」。社長のアーロン氏も含め、米国企業トップの語りのレベルを肌で感じた。
レジェンドの話芸を生で聴けるのが現地の強みなのだ

⑥講演で見えた大企業のAI活用

  • テーマの一つは大企業はデータをセキュアに使えずAIを活用しづらいという現実。
  • 「ベンチャーはガンガン使うのに大企業はできない——その溝を埋めるのがBoxの価値」という文脈に得心。
  • チャエン視点：Box程度の規模のツールでここまでAI対応しているのは珍しいし、ジェンスンを呼べるパワーもすごい。
セキュリティ×生成AIが米大企業の喉の刺さりにしているの

⑦昼は街へ：高すぎるランチ事情

  • 昼はマーケット通りへ。20%オフで約105,000円分の割引を勝ち取り大喜び。
  • 定番のチャーハンは3,000円弱——「高いね」という率直な感想。
  • 午後は展示会場へ。開発者ゾーン（デブゾーン）の方が盛り上がっていることを確認し、そちらを重点的に回る戦略。
割引には強い、しかし物価には泣かされるの

⑧謎の車とAWSの展示

  • デブゾーンにはなぜか車が展示されており、Boxとの関係が謎のまま「全然分からんけど楽しそう」。
  • 正体はおそらくスポンサーAWSの紹介ブース。
  • 開発者向けエリアの熱量を間近で見て、米国のイベント文化を体感する1日となった。
理由は分からないけどワクワクすれば正解なのだ

⑨3日目：時差ボケとの戦い

  • 時差ボケで起きたらAM10時——掃除の方が入っていてチェックアウト済みの大ピンチ。
  • 12時間ほど寝たのにまだ眠い体を引きずり、ホテルを移動。
  • 新ホテルは360°サンフランシスコを見渡せる絶景。「海沿いに泊まるとテンションと幸福度が上がる」を実感。
時差ボケは計算済みでも牙を剥く恐ろしい相手なの

⑩3日目のスケジュール

  • 日本の会議 → 中国のロボット企業とのオンライン会議 → 夜のロボットイベント、という3本柱。
  • 当日は自社でもロボット事業を進行中——中国では約10社と提携してロボットを仕入れてきたばかり。
  • 今回のミッションは明確：アメリカのロボットがどこまで進んでいるか、この目で確かめること。
中国仕入れ済みの男が米国に偵察に来たのだ

⑪夜のロボットパーティーに潜入

  • 夕方5時過ぎ、日が暮れる海沿いのフェリービルディング前から夜のイベント会場へ。
  • 到着早々サイバートラックが鎮座し、入った瞬間に消防車まで登場。「全然ロボットイベントちゃうやん、ただのクラブやって」。
  • 会場にはお酒が大量に——「これがサンフランシスコのイベントか」と驚きの連続。
ロボットより先にパーティ感が来たのだ

⑫白いアームロボット「xArm7」

  • 会場で発見したのはUFactoryのxArm7——主催のDimensional OS（パーティ主催者）が貸与したもの。
  • 同社のresidency programでは、ロボティクスStartupにハードウェアを無償提供。
  • 展示されていた2台目のプロトはわずか3日で製作。青い部品は2日前に3Dプリントしたばかり——個人開発者の速度に驚愕。
「3日で作りました」が飛び出すのが米ロボ現場なの

⑬ロボット開発の技術スタック

  • 構成はVLA（視覚言語行動モデル）＋ROS/Rustのクラシック制御コード。Jetson Thorのエッジデバイス上で動作。
  • さらにオープンソースの小型エージェントがコードを調整・オーケストレーションし、インターネットなしで完結。ネットがあればフロンティアモデルも利用可。
  • 開発者の説明は「System 3 / System 2 / System 1」の三層構造——LLMとクラシック制御の使い分けがKey。
「考える層」と「動かす層」の分業が今の主流なのだ

⑭会場で日本語が飛び交う

  • 会場には日本語で話しかけてくれる人も——AI・ロボットの授業を担当する岡村さんと遭遇。
  • 岡村さんはシルバーアシストという会社でロボットのデータ収集が事業。授業も行い、販売と買取を兼ねるマーケットプレイスのような活動。
  • 「ロボット買いにサンフランシスコに来た」と言うと「先週は中国！」と意気投合——日本人もロボット調達で世界中を飛び回っている。
海外のパーティで日本語の輪ができるのだ

⑮Dimensionalのオフィスと犬型ロボ

  • Dimensionalはオープンソースのロボティクスソフトを開発——将来は「すべてのロボットソフトが同社製で書かれる」ことが目標。
  • オフィスは下の階がロボットのフィールド、上の階でアルゴリズムを書くという夢の構造。アーム・犬型・ヒューマノイドまで常駐。
  • フロアでは犬型ロボットのデモも開催。なおUnityにも行ったが「エンタメ寄りで、ちょっといけてなかった」直言も。
遊び場と開発場が一体のオフィスが最高なの

⑯フィジカルAI業界のリアル

  • 会場にはレジェンド級のロボット系インフルエンサーも登場。Figureや1Xなどロボット企業の話題でも盛り上がる。
  • 実際に歩き回る人型ロボを見て「すごい」の連発——しかし正体はまだシミュレーション映像かも、という冷静な目線も。
  • チャエンの総括：現場は個人開発者がちょこちょこいる段階で、大量生産・商用化は「これから」——中国の方が進んでいる印象を率直に告白。
「アポなしで見た実態」が一番ホンネなのだ

⑰人脈の作り方：パーティ攻略法

  • 結論：人脈を作るならとりあえずパーティーに行け。イベント情報はLumaというサイトで確認、ChatGPTに聞けば全部わかる。
  • 動画を撮っている（ふりを）するとみんな寄ってくる——「ユーチューバーちゃうけど、おすすめです」。
  • そして武器を1つ持つこと——AI詳しい、フィジカルAI好き、シリコンバレー在住、何でもいい。武器があれば皆すごく気に入ってくれる。
気合と根性と「1個の武器」でなんとかなるのだ

⑱アポなしハッカソン突撃＆後編予告

  • 4日目、承認が来ていないまま「Founders Ink」のロボットイベントにアポなし突撃——意外とそのまま入れてもらえる。
  • 中ではシミュレーションでヒューマノイドの安全性を検証するプロダクト（DreamLab活用、自然言語でゼロショット生成）の開発者も。参加者は朝から晩まで10時間ロボット作りの缶詰め——「アームばかり、アメリカ」。
  • 後編ではハッカソン発表会・運転席に誰もいないWaymo・夜のFigure本社へ。AIは「半導体・クラウド・モデル・アプリ」の4層＋現場に届ける5つ目の層＝AI商社デジライズの活動も紹介。
約束のない飛び込みで出会いが生まれる——続・シリコンバレーなのだ
