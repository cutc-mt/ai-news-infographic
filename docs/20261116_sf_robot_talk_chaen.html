①今日の主役：SF現地収録の対談企画

  • チャエンがサンフランシスコのbtraxオフィスに飛び込み、現地の起業家とAIの現在地を語り合う対談回。約40分の収録を35分にまとめた編集版。

  • 主要テーマはソフトの次はロボット／日本企業の生き残り／ChatGPT活用／残業代問題／SIerの行方／AI生成物への嫌悪感の6本柱。
AI最先端の街・サンフランシスコの空気ごと届く回なの

②ホスト：ブランドン・ヒル（btrax CEO）

  • btraxはサンフランシスコを拠点とするデザイン会社。日本企業のUS進出支援などで知られ、現地のスタートアップ文化に接する立場にある。
  • ブランドン・ヒルはポッドキャスト「サンフランシスコ・デザイントーク」のホスト。今回チャエンは同番組への出演という形で対談が実現した。
  • デザイン×テクノロジーの現場から見るAIの波の捉え方が、日本発のAI情報発信とは違う角度を提供する対談相手になっている。
現地で事業を営む起業家の「生の目線」がこの対談の価値なのだ

③ゲスト側：チャエン／デジライズ

  • チャエン（茶圓将裕）は株式会社デジライズ代表取締役CEO。Xフォロワー20万人超の国内トップクラスのAIインフルエンサーで、著書『AI脳』もある。
  • デジライズはAI教育・AI開発・コンサル・ロボット導入まで一気通貫で支援し、累計600社超・5万人以上のAI活用を支援（2026年8月末時点）。
  • 法人向けAIリスキリングサービスは導入社数No.1（東京商工リサーチ調べ・2026年3月末時点）という実績を持つ。
「発信者」じゃなく「導入支援の最前線にいる経営者」の視点なの

④「ソフトの次はロボット」（3:05〜）

  • 対談前半の核は「ソフトの次はロボット」という見立て。生成AIでソフトウェア開発が激変した次の波は、物理世界に出るフィジカルAIだとする。
  • ソフトウェアはコピーで広がるが、ロボットはハードウェア・製造・現場導入という別の壁がある。だからこそ勝ち筋も違ってくるという文脈。
  • チャエン自身もデジライズでロボット導入支援事業（国内外37社・95機種からメーカー中立提案）を展開しており、対談の主張には事業裏付けがある。
「AI=画面の中」から「AI=動くモノ」へ。波が物理に来るの

⑤フィジカルAIと中国のサプライチェーン

  • ロボット議論では中国のサプライチェーンが話題に。ハードウェア量産の中心は依然として中国側にあり、フィジカルAI競争は製造基盤の地政学と絡む。
  • ソフトは米国発のモデルが席巻しても、ロボットの量産・部材調達では中国の存在感が大きい——対談で交わされた構図の骨格。
  • 日本はものづくりの地力を持つ立場として、米中のはざまでどう位置取るかが日本企業の生き残り議論（次カード）へつながる。
フィジカルAIの覇権は「工場を持つ者」のゲームでもあるのだ

⑥日本企業はどう生き残る（8:06〜）

  • 「日本企業はどう生き残る」の章では、全面的にAIへ飛びつくのではなく、地の利と強みを活かす戦い方がテーマになる。
  • 製造・現場・業務プロセスに蓄積された日本ならではのドメインを、AIで包み直せるかが分岐点という文脈。
  • サンフランシスコの起業家の目に映る日本の強みと遅れの両面が、外部視点として語られるのがこの章の見どころ。
「真似」じゃなく「持ち場でどう使うか」を決めるのが勝負どころなの

⑦「まずはChatGPTでいい」（10:56〜）

  • AI導入の入口についてチャエンが繰り返す持論が「まずはChatGPTでいい」。難しいツール選びより、全員が触れる汎用ツールから始める実践論。
  • 社内にAIに触った人を増やすことがリスキリングの第一歩であり、道具の差より使う習慣の差が効くという発想。
  • 600社超の支援で見えてくる段階的な導入の型——最初は汎用、効いてきたら専用ツールとClaude Code等での内製化へ、という順路が対談の背景にある。
完璧な道具探しより「みんなで使い始める」が先なのだ

⑧空いた時間と残業代（14:44〜）

  • AIで業務が速くなったとき空いた時間をどうするか——生産性向上の果ての経営テーマとして「残業代」の問題が登場。
  • 残業が減れば人件費は下がるが現場の収入は減る可能性がある。AI効率化と雇用・賃金の調整は表裏一体という指摘。
  • 空いた時間をより価値の高い仕事・学びに振り向ける文化を作れるかが、日本企業のAI活用の成否を分ける論点。
「時短」を誰の得にするか——ここを決めないと現場がついてこないの

⑨Claude Codeによる内製化

  • 説明欄が挙げる対談トピックの一つがClaude Codeによる内製化。AIコーディングツールで社内開発の内製化が現実的になった近年の流れ。
  • 外部委託一辺倒だった企業が自社に開発力を持つことで、改善スピードとノウハウの社内蓄積が変わる——次章のSIer論への布石。
  • デジライズ自身もAI教育から開発・コンサルまで一気通貫で支援する立場として、内製化支援の現場感を語れる数少ない語り手。
「社内にエンジニア文化を植える」のがAI時代の内製化なの

⑩SIerはなくなるのか（19:59〜）

  • タイトルにも掲げられた大きな問いが「SIerはなくなるのか」。AIによる開発の自動化が進む中で、システム受託ビジネスの存続が問われる。
  • 従来型の人月ビジネス・仕様書請負はAIで大幅に圧縮される可能性が高い一方、要件定義や責任の所在など消えない仕事も残るという見立てが対談の軸。
  • 「なくなる」のではなくビジネスモデルの転換を迫られる——結論の方向性は消失ではなく変化の描写にある。
「消えるか」より「何に生まれ変わるか」を考える問いなのだ

⑪SIerのこれから：残る価値

  • AIがコードを書く時代でも、業務理解・要件の言語化・現場との調整は人間の領域として残る——SIerに求められるのはこの部分へのシフト。
  • 「手を動かす人」からAIを操りながら設計する人へ。スキルの置き換えが進む業界構造の変化が語られる。
  • 一方で転換に遅れたプレイヤーは淘汰される厳しさもセット。日本のIT業界全体の課題として対談で共有される。
技術じゃなく「顧客の業務を訳す力」が残る財産なの

⑫アメリカで広がるAI生成物への嫌悪感（26:28〜）

  • 意外なトピックが「AI生成物への嫌悪感」。AI活用が進むアメリカ側で、生成コンテンツへの反発・忌避感が広がっているという現地観察。
  • 「AIで作りました」が品質や誠実さの疑念につながる風潮——便利さと受容の間にある温度差が語られる。
  • 日本では「使い倒す」文化と、米国の「嫌悪も併存」する空気の温度差そのものが、グローバル展開やマーケ視点の気づきになる。
「進んでる国ほど反発も育つ」という裏面の話なのだ

⑬次の主戦場はフィジカル（30:35〜）

  • 対談の締めくくりテーマは「次の主戦場はフィジカル」。画面の中のAI競争から、現実世界を動かす競争へと舞台が移る見通し。
  • ロボット・工場・物流・店舗——物理世界へのAI適用が次なる投資と事業機会の集中先になるという共有認識。
  • 日本はものづくりの蓄積という出発位置にいる。フィジカル時代は日本企業にとって追い風にもなりうる、という対談の含意。
ソフトで遅れた分、フィジカルで先行できるか。勝負はこれからなの

⑮対談の交差点：デザイン×AI×日本

  • btrax（デザイン・US進行支援）×デジライズ（AI導入・ロボット）という組み合わせは、「体験設計」と「技術導入」の交差点にある。

  • AI生成物への嫌悪感の話ともつながる「人間が作った感」の価値は、デザイン業界出身者ならではの論点。
技術の話が「文化と体験」の話に接続する回なの
