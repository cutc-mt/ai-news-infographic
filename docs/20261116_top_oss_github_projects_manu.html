AIコードレビューからエージェントチーム運用、ネイティブUI、iPhone上のmacOSまで……開発者の生産性を上げるOSSが満載の週間セレクション #309

①今週のラインナップ：実用本位のOSS 20選

  • Manu AGIが毎週紹介するトレンドGitHubプロジェクト第309回。今週は全20プロジェクトを一気見。
  • 選定基準は開発者の実用性。自分のマシンで動くローカルツール、AIエージェント／コーディングワークフロー改善、ネイティブアプリ構築とジャンルは多岐にわたる。
  • Alibabaのopen-code-review（5万超スター）、LobeHub（8.5万スター）、HeyGenのhyperframes（8.4万スター）など大型案件から新鋭まで揃う。
コードレビュー、エージェント運用、ネイティブ開発——全部に効く1週間分なのだ

②open-code-review：Alibaba製AIコードレビュー

  • Alibabaが公開したCLIで動くAIコードレビューtool。Apache-2.0ライセンス、Go実装で、Alibaba規模で実戦テスト済み。
  • 特徴は決定論的パイプライン＋LLMエージェントのハイブリッド構成。NPE・スレッドセーフ性・XSS・SQLインジェクション等多言語ルールセットを内蔵。
  • 行単位のピンポイントコメントを生成し、OpenAI・Anthropic互換APIで利用可能。CIのGitHub Actionにも対応。
「なんか変」ではなく「この行がこう危ない」と言えるレビュアーなの

③plannotator：エージェントのレビュー作業台

  • Claude Code・Codex・Copilot CLI・Gemini CLIなど主要コーディングエージェントに直接接続するローカルのブラウザベースレビュー画面。
  • 新機能Plannotator Inboxは、エージェントが提案する決定事項・プラン・プロトタイプ・成果物を一箇所に集約。「エージェントの何を確認すればいいか分からない」を解消する。
  • プランや仕様書・Markdown・HTMLに注釈を書いてワンクリックでエージェントへ差し戻し。diff・PRレビューにも対応。
マルチエージェント時代の「人間のチェック工程」を形にしたツールなのだ

④claude-trading-skills：投資家のClaudeスキル集

  • 個人投資家のためのClaude Codeスキルベースのトレーディングワークフロー集（MITライセンス）。時間のない投資家向けに設計。
  • 市場分析・テクニカルチャート・経済カレンダー・スクリーナー・戦略開発のスキルが同梱。長期投資＋ETFを核にスイングトレードを衛星にする運用を想定。
  • コンセプトは「売買判断のAIへの丸投げ」ではなく市場レビュー・リスク管理・トレード記録・振り返りの仕組み化。シグナル配信サービスではない点が誠実。
AIで「儲ける」のでなく「判断プロセスを鍛える」姿勢が良いのだ

⑤chrome-devtools-mcp：エージェントにChromeを

  • Google Chrome DevToolsチーム公式のMCPサーバー兼CLI。Antigravity・Claude・Cursor・Copilotなどコーディングエージェントから生きたChromeを直接操作・検査できる。
  • パフォーマンストレースを記録して改善示唆を自動抽出。ネットワーク通信の分析、スクリーンショット、ソースマップ付きコンソールログ確認も可能。
  • Puppeteerベースの信頼性の高い自動操作で、エージェントによるWebアプリのデバッグ・動作確認が格段に安定する。スター5.6万超の定番。
エージェントが「目で見て」フロントエンドを直せるようになる強力な武器なのだ

⑥auto-ontology：NVIDIAの意味レイヤー

  • NVIDIAが公開した企業メタデータからオントロジー（意味グラフ）を自動構築するPythonフレームワーク。Apache-2.0、スター1.2万超。
  • エージェントのAnalyticsの信頼性問題に正面から挑む：指標・エンティティ・関係の正しいビジネス意味を与え、システム間で矛盾する定義を調停。
  • 自然言語質問をSQLに変換して実行し、認定済み定義とリネージでクエリを検証・出所付きで回答。MCP・CLI・APIでエージェントに提供。
「速いけど数字が間違ってる」を防ぐ文脈レイヤーという発想なの

⑦LobeHub：チームにスーパーエージェントを

  • スター8.5万超の大型OSS。キャッチコピーは「Super-Agents on Your Team」——チームが既に使っているチャットにスーパーエージェントを追加する。
  • エージェントが自ら仕事を引き受け、毎週賢くなる運用を実現。個人アシスタントを超えたチームワーク支援が主戦場。
  • Dockerでセルフホスト可能で3,200回以上のリリースを実施する活発なプロジェクト。動画ではエージェントチーム運用の実演が紹介された。
「AIを導入する」のではなく「同僚として迎える」設計なのだ

⑧hyperframes：HTMLを書いて動画にする

  • HeyGenがApache-2.0で公開した「Write HTML. Render video. Built for agents.」なツールキット。スター8.4万超で急成長中。
  • HTMLを書くとそのまま動画としてレンダリング。コードで動画を作るという、プログラマブル動画生成の新しい定番になりつつある。
  • 名前の通りAIエージェントからの利用を最初から想定。npmパッケージで提供され、Claude等にインストール可能な公式スキルも同梱。
Web制作のスキルがそのまま動画制作に転用できる時代なの

⑨knowledge-work-plugins：Anthropic公式

  • Anthropicが公開したClaude Cowork／Claude Code用プラグイン集（Apache-2.0、スター3.6万超）。役職別に特化した11個を収録。
  • ラインナップはproductivity・sales・product-management・marketing・legal・financeなど。Slack・Notion・HubSpot・Jira等のコネクタが束ねられている。
  • 各プラグインはスキル＋コネクタ＋スラッシュコマンド＋サブエージェントの詰め合わせ。自社のツール・用語・プロセスに合わせてカスタマイズして使う。
「部署ごとのClaude」を公式が配り始めたのが大きなニュースなのだ

⑩modern-web-guidance：Web最新流儀を注入

  • Google Chrome・Microsoft Edge・Mozilla Firefox・MDNチームが共同で管理するコーディングエージェント向けスキルセット（スター1.7万超）。
  • LLMは学習データの古いコードに引きずられがち。レガシーパターンを検出してモダンなWeb標準へ誘導し、無駄に太ったJavaScriptを避ける。
  • npxでインストールするだけ。ガイドはトークン効率を最適化済みで、View Transitions・コンテナクエリ・oklchなど近年の新機能を網羅。
ブラウザベンダー総出で「AIのWeb知識の鮮度」を保つ試みなの

⑪exact：Expoのマルチネイティブ開発

  • Expo（React Nativeの運営元）による新プロジェクト。アプリを一度書けばWeb・macOS・iOS・Linuxでネイティブ動作（Android・Windowsは鋭意開発中）。
  • WebはDOMとCSS、iOSはUIKitのネイティブコントロール、macOSはAppKit——という具合に、各プラットフォームの正統なUIで動く。
  • 最大の目玉はAIエージェントが全プラットフォームでビルド・実行・目視確認・テストできる設計。MITライセンスで公開当初から注目を集める。
「一回書く」×「全部ネイティブ」×「エージェント時代」の三重唱なのだ

⑫supermimic：ヒューマノイドの全身制御

  • HybridRoboticsが公開したヒューマノイドの全身モーショントラッキング学習フレームワーク。Apache-2.0、物理シミュレータmjlab上に構築。
  • 目標動作を模倣するポリシーを、1つの微分可能なワールドモデルで学習。従来の複数段階パイプラインを単一モデルに集約したのが革新性。
  • 論文はarXivで公開中で、プロジェクトページと併せて追試可能。ロボティクス×AIの最前線がオープンにされている。
人間の動きをロボットに教える研究がOSSで見られる贅沢なの

⑬Henge：iPhone・iPadでmacOSを動かす

  • その名の通り「ストーンヘンジ」。iOS／iPadOS上でmacOSをエミュレートする驚きのプロジェクト（GPL-2.0）。
  • iOSにはハイパーバイザーAPIが無いため、独自のJIT＋MMU＋仮想デバイスを自作。QEMUもVirtualization.frameworkも使わない正統派エミュレータ。
  • Appleのリストアイメージを端末上でそのままインストールし、グラフィックスは仮想GPUのコマンドをMetalで再生。画面がMagic Trackpad化しSafariやDiscordが動く。
技術的にもライセンス的にも「App Storeには出せない」ロマンの塊なのだ

⑭devvm：プロジェクトごとの隔離VM

  • 「One VM for every project」——プロジェクト専用の隔離サンドボックスVMを一発で用意するツール（MIT、Go実装）。
  • フォルダに入ってdevvmと打つだけ。プロジェクトのファイルから必要なツールチェーンを推論し、人間にもコーディングエージェントにもすぐ開発を始められる環境を渡す。
  • Lima＋QEMU基盤でmacOS（Appleシリコン）とLinuxに対応。リリースはminisign鍵で署名、ドクターコマンドで環境診断など安全性にも丁寧。
ホストを汚さないエージェント開発環境の「箱」がようやく普通になったの

⑮CUI：C言語でネイティブUI

  • C言語用のネイティブUIコンポーネントライブラリ。約190個のコンポーネントにスプリングアニメーションと完全なキーボード操作対応。
  • ブラウザもランタイムも内蔵せず、完成アプリは約250KB。依存関係ゼロでWindows・macOS・Linuxに加えWeb（WebAssembly＋WebGL2）まで出せる。
  • インストール前に公式のライブドキュメントで全コンポーネントをブラウザ上で試せる親切設計。C99単一コードベースなのも驚き。
「CだからUIは無理」という常識をひっくり返す軽さなのだ

⑯pinky：AIにスマホを使わせる

  • 人気OSS開発者DIYgod（RSSHub作者）による「AIにiPhone・Androidを使わせる」ツール。Go実装で開発が非常に活発。
  • macOS・Windows・Linuxの任意のMCPエージェントからスマホを操作でき、Pinky単体をスマホ上で動かすことも可能。
  • コンセプトは「with you in the loop」——AIが勝手にやり切るのではなく、人間が見守りながら渡していくスタンス。
コンピュータ操作自動化の次はポケットの中なの

⑰graphicle：エージェントに地図と記憶を

  • コードグラフ＋メモリを1つのRustプログラムでコーディングエージェントに与えるツール（Apache-2.0）。APIはMCP経由。
  • Claude Code・Codex・CursorなどMCPクライアント全般で利用可。macOS・Linux・Windows（プレビュー）対応。
  • 巨大コードベースでエージェントが迷子になる問題に、リポジトリ全体の構造地図と作業記憶で挑む。動画ラスト付近で詳しく紹介された注目株。
エージェントの「道に迷う」問題に真正面から答える1本なのだ

⑱その他4選＆まとめ

  • mygo-music（egoist）：プラグインで拡張するGo製ネイティブ音楽プレーヤー。chrome-capture（paulirish）：Chromeタブの動画・音声を60〜120fps／2160pでキャプチャ。
  • phoneuse（lxe）：Linux PCから非改造iPhoneをAirPlayミラー＋Bluetooth HIDで閲覧・操作。CLIとエージェント用スキルも同梱。
  • ding：本物のバネ物理で踊るトースト通知ライブラリ。1つのトーストがその場でモーフィング、依存ゼロでReact・Svelte・Vue・素のDOMに対応。
