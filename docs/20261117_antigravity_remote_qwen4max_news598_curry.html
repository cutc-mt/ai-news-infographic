②Antigravity Remote Controlとは

  • GoogleのAI開発環境「Antigravity」の新機能。手元のマシンで動くセッションを、ブラウザさえあればどこからでも操作できるようにするもの。
  • ノートPC・デスクトップ・サーバーなど複数マシンをダッシュボードで切り替え、複数のエージェントを同時に管理できる。
  • ファイル・ワークスペース・ビルドツール・認証情報・環境変数はホスト側に残る。環境を作り直さずセッションを続けられるのが肝。
「デスクから離れても、仕事は机の上で動き続ける」——それがRemote Controlなの

③アプリでの有効化とブラウザ接続

  • デスクトップアプリのSettings → Application → Enable Remote Controlをオンに。Device Nameを付けておくとマシン判別が楽になる。
  • あとは別デバイスのブラウザで同じGoogleアカウントにログインし、インスタンス切り替えで対象マシンを選ぶだけ。
  • スマホではWebアプリをホーム画面に追加するとプッシュ通知が届く——エージェントが手番を終えた時や入力を求める時に便利。
設定はトグルひとつ、あとは同じアカウントでログイン——導線がとにかく短いの

④CLI版Remote Controlの2つの形

  • 対話モード：起動中のCLIで/remote-controlと打つか、agy --remote-controlで起動。セッション単位でトンネルが張られ、URLが発行される。
  • 常駐デーモン：agy remote-control startでOSのサービスとして登録。電源が入っている間はいつでも接続可能になる。
  • 対話モードはターミナルを閉じると自動で切断。ブラウザとローカルの表示は双方向にライブ同期され、ツール承認はどちらからでも可能。
「ちょっと外出する」なら対話モード、「いつでも触りたい」ならデーモン——使い分けが大事なの

⑤ブラウザからの操作と記事作成の実演

  • 配信ではスマホや別端末のブラウザからAntigravityに指示を出し、記事を書かせる実演を実施。
  • ブラウザからは会話の閲覧・新しいタスクの開始・実装計画のレビュー・アーティファクト（成果物）の確認ができる。
  • ネットワークが一時的に切れてもブラウザ側は自動再接続。ホストがオンラインの限り、裏のエージェント処理は止まらない。
外出先の小さな画面から記事が育っていくのは、なかなか未来的な光景なの

⑥Qwen4-Maxの正式リリース

  • AlibabaのQwenチームが11月16日、新アーキテクチャ「Qwen4」の最上位モデル「Qwen4-Max」を正式発表・提供開始。
  • 総パラメータ数2.4TのMoE型で、別途328BのN-gram Embeddingを持ち、1トークンあたりのアクティブは71B。
  • 画像や動画の入力に対応し、コンテキスト長は100万トークン。3Dモデリングや製造、金融・法務・医療まで実務向けに設計。
2.4兆の巨大さの割に、動く部分は71B——MoEの旨味が効いているの

⑦Qwen4-Maxの効率と提供・公開方針

  • 前世代のQwen3.8-Max比でWork360は約24〜35%、Terminal-Bench 4.0では約48〜49%トークンを削減と公表。
  • 提供はQwenCloudのToken Plan / APIのほか、QwenWork・Qoder・QwenStudioでも利用可能に。
  • Max自体の重みは非公開だが、同世代の技術で作った小規模モデルをオープンウェイト化する方針も予告された。
「トークンが減る＝コストが減る」——開発者の財布に優しい進化なの

⑧ChatGPT for Healthcareの拡充

  • OpenAIが11月16日、医療向けの発表。コンピューター操作エージェントがEHRや保険者ポータルなど既存医療ソフトをまたいで多段の作業を実行。
  • 医療エビデンスを検索・評価・引用する信頼できる臨床検索の改善と、20以上の新プラグインも追加。
  • PHIはモデル学習に使われず、BAA締結によるHIPAA準拠ワークフローをサポート。デモではMRI依頼のフォローアップを音声で依頼し、指示案と患者返信を下書き。
「システム間の張り付き」から医師を解放する——AIの次の職場は病院なの

⑪経営報道の焦点：CEO交代と株価

⑫Antigravity規約・第6条の落とし穴

  • Antigravity追加規約の第6条は、Googleが提供しない製品との組み合わせ利用を禁止。違反は自動検知でサービスが停止される。
  • 実際の停止の多くは、Gemini CLIやAntigravityのログイン情報をClaude Code等の外部ツールで使い回す行為が引き金。
  • 停止範囲はAntigravity・Gemini CLI単体で、Gmail等には及ばないとみられる。異議申立ては1アカウント1回まで。
「無料枠が大きいから」と流用すると、ある日突然使えなくなります……なの

⑬規約の安全ライン整理

  • 明確にNG：他ツールへの認証情報の流用、複数アカウントの自動切替、アカウント共有——いわば「死刑」級。
  • グレー：外部AIエージェント経由の利用や、公式が想定しない自動化。消費者プランでは無人・常時のバックグラウンド実行も非サポート。
  • 安全：Antigravity CLI/IDEの通常利用、CIでのagy -p、人が手動で回すスクリプト。公式の自動化機能の範囲内なら安心。
「人間が操作しているか」「公式の経路か」——この2問でだいたい判別できるの

⑭Gemini・Antigravityのデータと責任

  • 利用データ（Interactions）はGoogleが記録・保存し、AI評価・製品改善のために従業員も閲覧しうる。削除申請は設定またはサポートメールから。
  • AIエージェントの行動の責任は利用者自身。アクセス権限の付与と、本番環境での監督が利用条件とされている。
  • 第三者のモデルを主エージェントに選んだ場合はそのモデルの規約適用。AntigravityからAnthropicモデル利用時はAnthropic商用規約にも同意したものと扱われる。
「見られたくないものは入れない」——無料ツールの大原則を再確認なの

⑮Claudeの国別利用指標「AUI」とは

  • Anthropic Economic Indexが公開するAUI（Anthropic AI Usage Index）は、利用シェアを生産年齢人口シェアで割った指標。1.0で人口相応。
  • 2026年5月時点の上位はオーストラリア6.40シンガポール5.81スイス5.02。日本は1.91で32位。
  • 用途はほぼ全ての国でソフトウェア開発が最多。国ごとの「偏り」にその土地の経済構造が表れるのが面白いところ。
「総量の順位」と「人口当たりの順位」は別物——そこを読み違えないの

⑯国別指標の読み方・所得との関係

  • 国際比較では1人あたりGDPが1%高いとAUIは約0.7%高いという強い相関。豊かな国ほど多く使う構図。
  • ただし所得で全ては説明できない。エストニア3.05やポルトガル2.23など、所得以上に使う国も。米国の州間比較では傾きが約1.8%とより急に。
  • 上位州の用途は必ずしもコーディング中心ではない（首位DCは文書編集・情報検索が突出）。AI普及がもたらす経済格差の議論にもつながる。
数字の背後に産業構造が透ける——指標は「国の鏡」なの

⑰今日のまとめ：3つの持ち帰り

  • Remote Controlで開発の在り方が変わる——環境を再構築せず、どこからでもエージェントを続けられる。
  • 規約とコストのリテラシーが試される時代に。認証情報の流用は厳禁、モデル選びはトークン効率と提供条件で比べる。
  • 噂（Gemini Neon）は楽しみつつ、指標（AUI）は構造を読む道具として使う。情報の「質の違い」を見分ける目を養いたい。
新機能・噂・数字——全部「自分で触って確かめる」が今日の教訓なの
