INTRO #01

Topview T1とは：Topviewが初めて自社開発した動画生成モデルTopview's First In-House Video Model

Topview T1は、AI動画生成プラットフォーム「Topview」が独自に開発・公開した初の自社製動画生成モデル。これまでTopviewはSeedanceシリーズなど外部モデルを提供するプラットフォームでしたが、T1の登場で「自社モデル」のラインナップが加わりました。シネマティックなストーリーテリングと映像制作のために設計されており、ショートドラマ・映画・アニメなど、ショット数とイテレーション数が増えがちな制作現場を主戦場としています。

#06

出力解像度と生成時間の柔軟性720p / 1080p, 4-30 sec

T1は720pと1080pの2段階の解像度を出力可能。生成時間は最短4秒から最長30秒まで指定できます。公開されているクレジット価格は1080p基準なので、下見には720p、仕上げには1080pと使い分ければさらにコストを抑えられます。

  • 720p — テスト・下書き向けの軽い解像度
  • 1080p — 本番納品用のフルHD
  • 4〜30秒 — シーンの長さに合わせて指定可能
#07

入力は3モード：テキスト・画像・マルチモーダルText / Image / Multimodal Input

生成の入口はテキスト→動画、画像→動画、そして複数素材を組み合わせるマルチモーダル入力に対応。キャラクター設定画や参考動画、音声素材をまとめて渡せるため、世界観を固定した連続したショット作りに強みがあります。

テキスト+ 画像+ 動画・音声参照→ 物語のある映像
#08

参照素材は最大50点Up to 50 Reference Assets

1つの生成に使える参照素材は合計50点まで。内訳は画像が最大30点、動画が最大10点、音声が最大10点で、この上限はSeedance 2.5と同一です。登場人物の顔や衣装を参照で固定しやすいのは、連続シーン制作での大きな利点になります。

#09

映像と一緒に生まれる「ネイティブ音声」Native Audio Output

T1は生成映像にネイティブ音声を付けられるモデル。効果音や環境音、声を含む音付きの映像をそのまま書き出せます。BGMを別途AI生成して合わせるワークフローとも相性が良く、MVやショートドラマの制作工程を大きく短縮できます。

  • 映像と音声を一体化して出力
  • 音声参照（最大10点）で雰囲気を指定可能
  • AI BGM生成と組み合わせればMV制作も完結
#10

アスペクト比も自由自在Landscape / Portrait / Square

横画面・縦画面・正方形に加え、対応アダプティブプリセットにも対応。YouTube向けの16:9、ショート動画向けの縦型9:16など、投稿先ごとのフォーマットを同じモデルから出力できます。複数のSNSへ横展開する制作では、作り直しの手間が減ります。

使い分けの指針：何をT1に任せるかWhich Model for Which Job?

動画で示される運用イメージは「T1を1080p制作の予算ベースに、動きの激しい場面はSeedance 2.5に振る」という併用。T1は物語主導で単価が読みやすい反面480p Draft Modeは非対応。下書きを安く大量に回したいならSeedanceの Draft Mode、仕上げの画質勝負ならT1、という棲み分けです。

  • T1 — 1080p本番・ストーリー主導・予算固定
  • Seedance 2.5 — 細かい時間軸指定・480p下書き・派手なアクション
  • 両モデルは同じTopview上で切り替え可能
