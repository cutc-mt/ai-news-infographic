① GLM-5.4が登場NEW RELEASE

作り方そのものが変わった

Z.aiからGLM-5.4が登場。今回は性能が上がっただけでなく、モデルの作り方そのものが変わっています。キーワードは「Loop Transformer」。層をループさせることで、パラメータを増やさずに考える段数を増やした、という仕組みです。

② なぜ「計算の深さ」が重要なのかWHY DEPTH MATTERS

深さの壁

モデルが賢くなるには、層を積んで計算の深さを増やす必要があります。しかし層を増やすとパラメータも増え、学習コストと推論コストが一気に跳ね上がります。「深さだけ増やして重さは増やさない」方法はないか——その答えがループでした。

③ Loop Transformerの仕組み78層のうち真ん中の28層を2周

新設計の核心
前半25層→ 真ん中28層→ 後半25層→ 出力

GLM-5.4は全78層のうち真ん中の28層を2周させます。1周目で作った中間表現を、同じ重みでもう一度通すことで、パラメータ数はそのままに「考える段数」だけを増やせます。同じ層を2回使うので、重みの追加はゼロです。

④ なぜ学習済みGLM-5を作り変えたのかCONTINUED PRETRAINING

追加学習でループ型へ

ゼロからループ型を学習するのではなく、学習済みのGLM-5に追加学習してループ型へ作り変えました。すでに高い能力を持つモデルの知識を活かしつつ、2周目の使い方だけを新たに教える方が効率的で、大規模な再学習を避けられるという判断です。

⑤ 工夫① 出力を自動で調節するゲートGATE

重くならない工夫 1/3

単純に2周させると、1周目の情報がそのまま流れ込んで処理が冗長になります。そこでゲートを設け、2周目にどれだけ1周目の情報を混ぜるかを自動で調節。必要な分だけ繰り越すので、余計な計算が増えません。

⑥ 工夫② KVキャッシュの使い回しKV CACHE REUSE

重くならない工夫 2/3

2周目で注目すべき過去の情報は1周目とほぼ同じ、という性質を利用します。KVキャッシュを使い回すことで、2周分の計算をやり直さずに済み、ループによる速度のペナルティを大きく抑えられます。

⑦ 工夫③ スパースアテンションの目印を使い回しSPARSE ATTENTION

重くならない工夫 3/3

スパースアテンションで「どこを見るか」の目印を付けておき、2周目でも同じ目印を再利用します。注目先の再探索が不要になり、ループを回しても重くなりにくい。ゲート・キャッシュ・目印の3点セットが速さの鍵です。

30Bの実験モデルでの検証では、数学ベンチマークAIMEが+11.3点向上。さらにトークン出力量が10〜14%減し、無駄に長く書かずに済むようにもなりました。深く考えるほど精度が上がる一方、出力はむしろ引き締まる、という結果です。

⑨ 速度と、推論基盤との同時設計SPEED & CO-DESIGN

速さも設計済み

Loop Transformerはモデルと推論基盤を同時に設計しています。KVキャッシュの再利用などを実運転の速度に効く形で組み込んだ結果、ループ型でも体感速度は十分実用的。動画ではGLM Coding Plan経由で使った速度の体感も紹介しています。

⑩ Generalized CodingとはZ.aiのビジョン

コードの先へ

Z.aiが掲げるのは「Generalized Coding」。コードだけでなく、動画・ゲーム・3D・機械の設計まで、広い意味での「書ける・作れる」をモデルに担わせる構想です。GLM-5.4の深い思考は、この構想を支える基盤という位置づけです。

⑪ 公式も認める弱点: marathon thinkingMARATHON THINKING

考え込みすぎる

計算時間を伸ばすほど精度が上がる一方、考え込みすぎて時間を使い切ってしまう「marathon thinking」という弱点を公式自身が認めています。深さは武器ですが、止め時を誤るとタイムアウトに達する、というトレードオフが残ります。
