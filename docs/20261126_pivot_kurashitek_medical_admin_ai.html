PROBLEM 01

医療事務の三重苦①加算漏れ算定できるのに取りこぼす「見え損」

タイトル冒頭に挙げられる最初の課題が「加算漏れ」。診療報酬は本体の算定に加え、特定の条件を満たした場合に上乗せできる加算が多数あります。訪問看護や在宅医療では訪問回数や患者の状態など条件を満たしていても、事務側が該当加算を見落として請求しない「取りこぼし」が起こりえます。1件ずつの金額は小さくても積み重なると経営を圧迫する、まさに「見えにくい損失」です。SHISHIが「未然に防ぐ」とうたうのは、この取りこぼしをAIが条件照合で拾い上げる趣旨と考えられます。

MEMO
加算は「制度上は取れるのに、取りに行けていない」パターンが多いのが特徴。人間の記憶とチェック表に頼る限界をAIが補う——これが「未然に防ぐ」の核心だよ。

PROBLEM 02

医療事務の三重苦②返戻審査で弾かれたレセプトの手戻りコスト

2つ目の課題は「返戻」。レセプト（診療報酬明細書）は支払機関の審査にかけられ、記載ミスや算定エラーがあると差し戻されます。返戻されると訂正・再請求の手続きが発生し、事務スタッフの労力と入金の遅れという二重のコストを生みます。繁忙期の医療機関では返戻対応に追われて本来の業務が圧迫されることも珍しくありません。提出前に誤りを機械的に検知できれば、この手戻りループ自体を減らせるというのがAIに期待される役割です。

レセプト作成→ 提出→ 審査✕ 返戻＝訂正・再請求

PROBLEM 03

医療事務の三重苦③期限切れ書類・資格・届出を過ぎてからの発覚

3つ目の課題は「期限切れ」。医療・介護の世界では、保険者への届出、加算の算定要件、職員の資格更新など締め切りが錯綜します。期限を過ぎてから気づくと、さかのぼっての適用が効かないケースもあり、単なる事務ミスが収益の直接減につながります。一岡さんが理事長を務めた介護・医療法人での実体験がこの問題意識の下地にあると、経歴から推察できます。AIによる期限の前方監視・リマインドは、この「過ぎてから動く」を「来る前に動く」へ変える発想です。

MEMO
