OVERVIEW

1OpenMausBotとは？スペシャリスト・ボットのチーム基盤

OpenMausBotは「チームで働く専門ボット（スペシャリストボット）」を作るためのオープンソース・プラットフォーム。各ボットに固有のモデル・権限・作業用コンピュータを割り当て、Electronアプリ＋ローカルサーバーの2プロセス構成で動かします。コードは公開されているため、自前で監査・改造できる点が特徴です。

解説メモ
「1体ですべてやる」んじゃなくて、「役割を持ったボットのチーム」を組む発想が轴やね。オープンソースだから中身を自分で確かめられるのが一番大きいで。
PRIVACY

2ローカルファースト設計チャットは自分のマシンに保持

2プロセス構成（Electronアプリ＋ローカルサーバー）により、ボットとの会話ログは自分のディスク上に保存されます。チャットデータが外部のクラウドに集約されないため、「何を話したか」を手元で管理・監査できます。オフラインのローカルモデルとも組み合わせれば、さらに閉じた運用が可能です。

一言でいうと
「AIに見られたくない会話は、自分のパソコンの中だけに置いとく」——それを標準装備にしてるのがこの設計ってことや。
COST

すでに契約しているClaude Code・Codex・Grokのアカウントを、追加の転送料（トークンマークアップ）なしでそのままボットに使わせられます。新しく専用課金を契約し直す必要がなく、「支払い済みの枠」をボットチームに再活用できるのが最大の経済的メリットです。

MEMORY

54層Markdownメモリ編集のアンドゥも可能

ボットごとに4層構造のMarkdownメモリを持つのはOpenMausBotの大きな特徴。記憶がジャーナル（編集履歴）付きで管理されるため、ボットが覚えたくないことや誤って書き込んだことを後から取り消せます。記憶の中身が平易なMarkdownなので、人間が読んで確認・修正するのも簡単です。

ここ大事
AIの「記憶」って普通はブラックボックスやけど、こっちはジャーナル付きで「いつ何を覚えたか」が追えて、アンドゥもできるんや。記憶の誤りを直せるのはでかいで。
HANDS

6ボットに「手」を与える4種類の実行環境

会話だけのボットではなく、実際にパソコンを操作するボットにできます。選べる実行環境は次の4つ。

  • boat.devクラウドデスクトップ：クラウド上にボット専用のデスクトップを用意
  • BYO VPSモード：自分のLinuxサーバーを持ち込む
  • Local VMコンテナ：ローカルに閉じたコンテナ環境
  • ホストCua制御：実行マシンそのものを操作させる（強力だが要注意）

用途に応じて「閉じた環境」から「フル権限」まで段階的に選べるのがポイント。

BROWSER

73段階のブラウザWeb操作も細かく制御

Web上のタスクには3種類のブラウザモードを切り替えて使えます。

  • built-in：内蔵ブラウザで手軽に利用
  • My Chrome：いつも使っている自分のChromeをボットに使わせる
  • headless：画面なしで高速・自動化向きに動かす
使い分けの目安
ログイン済みサイトの操作はMy Chrome、大量の定型処理はheadless、みたいな棲み分けができるんや。
ROOMS

8Roomsで仕事を回すJev / Clefがルーティング

「Rooms」というチャット空間では、JevまたはClefがルーターとして働き、届いたメッセージを適切な専門ボットへ振り分けます。ユーザーは「誰に頼むか」を意識せず仕事を投げるだけで、チーム側で担当が決まるのが基本の流れです。

あなたの指示→Jev / Clef→専門ボット→成果物
TEAM

9Chief of Staffと一時停止組織のような制御

Chief of Staff（参謀役）のボットが、ルーティングを補佐しつつ作業を各専門家へ委譲します。さらにボット単位・部門（デパートメント）単位で一時停止できるので、「今このボットには触られたくない」「請求処理チームは今週止めておく」といった運用が可能です。

たとえるなら
1体のAIに全部任せるんと違うて、「上司役」がいて部署があって、部署ごとに勤務を止められる——ほんまに小さな組織みたいな作りやな。
DEV

10CLIと19ツールMCPサーバーヘッドレスな自動化

GUIアプリだけでなく、CLIと19ツールを備えたMCPサーバーが用意されています。ターミナルからボットチームを操作したり、MCP対応のエディタ・ツールから直接呼び出したりと、コード中心のヘッドレスワークフローが組めます。CIやスクリプトへの組み込みもしやすい設計です。

INTEGRATION

11500以上のComposioアプリ外部サービスと接続

Composio経由で500以上の外部アプリとボットを接続できます。カレンダー・メール・SNS・各種SaaSなど、日常業務で使うサービスをボットの作業対象にできるため、「ブラウザを操作する」以外の正規APIルートでの統合が一気に広がります。

CONTROL

125つの承認モード危険な操作にブレーキ

ボットが実行する操作には5段階の承認モードを設定できます。ちょっとした読み取りは自動で通し、ファイル変更や外部送信のような影響の大きい行為は人間の承認を必須にする——といった具合に、自動化の速さと安全性のバランスを操作ごとに調整できます。

全自動↔条件付き承認↔全部手動

ただし承認のカバレッジ（どこまで効くか）はエンジンごとに差がある点に注意（カード16参照）。

  • ⏰ 定時実行：スケジュール駆動の定期タスク

  • 📞 電話・音声：離れた場所から音声でやり取り

CAUTION

16注意点を3つ導入前に必ず確認

  • スリープでローカル停止：ラップトップがスリープするとローカルのスケジュール（自動化）は止まる。常時稼働にはMausBot Cloudか自前サーバーが必要
  • Full access初期設定：個人向けインストールの新規ボットはFull access権限が初期値になりがち。不要なボットは権限を下げること
  • 平文シークレット：カスタム設定や一部MCPの認証情報が平文（暗号化なし）で残る場合がある。取り扱いに注意

承認モードのカバレッジもエンジンごとに異なるため、外部へ操作させる前に実効性を確認。
