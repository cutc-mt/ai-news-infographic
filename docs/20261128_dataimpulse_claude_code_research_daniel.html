BACKGROUND

前提：エージェントの最大の敵は「コード」じゃない0:00〜0:50 — 実験の問い

2026年いま、Claude Codeのようなコーディングエージェントは「壊れたスクレイパーの直し方」すら自律的に学習しつつあります。コードを書く部分はどんどん容易になっている一方で、動画が指摘するのは別のポイント。Webリサーチの律速段階はIP制限だということです。同一IPからの短時間の大量アクセスはブロック・CAPTCHA・IPバンを引き起こし、自動実行を途中で止めてしまう——これがエージェント活用の実務上の壁です。

  • コード生成の壁はエージェントがほぼ解決済み
  • 残る壁は「どのIPから、どの国から、アクセスするか」
  • 実験の問い：IPレイヤーを変えれば信頼性は上がるか

PROBLEM

AIパワーWebリサーチの問題点0:50 — 自動アクセスが踏み抜く3つの地雷

エージェントに価格収集や市場比較を任せると、大量のリクエストが特定サイトに集中します。サイト側の防御は概ね3段階。①要求頻度をみてブロック（403等）、②bot判定でCAPTCHAを差し込む、③そして最重度のIPバン。スクレイパー自体はエラーで停止し、エージェントはやり直しのループに陥ります。クラウド事業者のIP帯域は特に厳しく拒絶されがちで、これはAPIの文字起こし取得でもよく見られる現象です。

①集中アクセス→ ②403／CAPTCHA→ ③IPバンで実行中断

WHAT IS

DataImpulseとは何か住宅プロキシ網と従量課金の料金モデル

DataImpulseは、ISP契約の実在IPで構成される住宅プロキシ網を中心に据えたプロキシプロバイダです。公称90M以上の倫理調達とされるファーストパーティの住宅IPを195カ国以上で提供し、トラフィック従量制（住宅プロキシは$1/GB、大容量なら割引、 データセンターは$0.50/GB、モバイルは$2/GB）の料金体系です。サブスクなし、購入したトラフィックは無期限という「必要な分だけ買って置いておく」モデルが特徴です。

TARGETING

地理ターゲティングの使い分け国指定は無料・細かい絞りは従量2倍

3カ国テストの鍵になるのがターゲティングです。国レベルの指定（選択・除外）は基本料金に込みで無料。一方、州・都市・ZIP・ASN単位のフィルタや、地図上の領域を指定するGeohashターゲティングはトラフィックが2倍で課金されます（プレミアム住宅プランでは込み）。エージェントの価格リサーチなら、国指定＋IPローテーションで十分回せる構成を組むのがコスト面の定石になります。

  • 国指定：無料（動画の3カ国テストはこれでカバー可能）
  • 都市・州・ZIP・ASN・Geohash：従量2倍の課金
  • 指定条件にIPが無い場合は「503 NO_RAY」で条件変更が必要

SESSIONS

ローテーション vs スティッキーセッションエージェント実行の2つのIP戦略

セッション設計も重要な選択です。ローテーションはリクエストごとに新しいIPを割り当て、同一IPの集中アクセスを原因から消せるので、大量収集時のブロック回避に有効。スティッキーセッションは平均30分（最大120分）同じIPを保持し、ログイン後の巡回や状態を保ちたい操作に向きます。価格収集のような大量・反復アクセスでは基本ローテーション、サイト側でセッション整合を見る場合だけスティッキー、という使い分けが動画の運用パターンです。

CHAPTER 04

3カ国リサーチテストの実行7:31〜10:01 — 地域差が数字で出る

FINDING

地域価格差リサーチの実務価値なぜ「国をまたいだ比較」が効くのか

この種のリサーチは、実務では価格監視・市場調査・競合分析に直結します。同一製品の価格や表示が国ごとに違うのは普通で、マーケットごとの戦略を考える上で「今この瞬間の生の価格」を機械的に揃えられることの価値は大きい。エージェント＋プロキシの構成なら、需要が生まれるたびに国を追加するだけで比較対象を拡張できます。

CHAPTER 05

反復実行の安定性を検証10:01〜11:49 — 1回だけじゃなく「繰り返し」走れるか

動画が最後に問うのは、継続性です。リサーチエージェントの価値は1回の実行ではなく、繰り返し実行しても安定して走り続けることにあります。素の構成では2回目以降にブロックやIP制限が積み重なり、実行が中断されがちでした。住宅IPのローテーションを通すと毎回の出口IPが変わるうえ、90M+の巨大プールがIPの重複を構造的に抑え、自社インフラによるIP健全性のリアルタイム監視と安定したTCP/TLS接続がエージェントの再試行ループ自体を減らします。IPレイヤーの耐性が反復実行を支える、というのが検証の結論側の見立てです。

CAVEATS

プロキシは銀の弾丸ではない見落としがちな限界と注意点

公平に押さえておきたい限界もあります。①プロキシを通しても、CAPTCHAやアンチボットはIP以外の指紋（ヘッダ、挙動）で判定されることがある、②細かい地理ターゲティングは従量2倍で、コスト積算は実測が必須、③課金は転送バイトベースなので画像や再試行もカウントされ、1GBあたりの「有用な結果単価」を自分で測る必要がある、④対象サイトの利用規約と、住宅IPの入手経路の倫理性の確認は利用者側の責任です。

  • IPを変えてもbot指紋対策は別レイヤーの課題
  • 都市・ASN絞り込みは課金2倍、実コストは要実測
  • 対象サイトの規約・IPの出所倫理は自分で確認

TAKEAWAY

この実験の要点整理押さえておくべき3つの論点
