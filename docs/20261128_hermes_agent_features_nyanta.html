Hermes Agentとは？Nous Research開発のオープンソースAIエージェント

Hermes Agentは、AI研究団体Nous Researchが開発するオープンソースのAIエージェントです。特定のIDEに縛られたコーディング補助でも、単一APIのチャットボットラッパーでもなく、「使い続けるほど賢くなる」自律型エージェントという位置づけ。にゃんたが日頃から愛用している点も紹介されています。

  • 開発元：Nous Research（オープンソース公開）
  • IDEにも単一APIにも縛られない自律エージェント
  • 動かす場所を選ばない（ノートPC〜格安VPS〜サーバーレス）

FEATURE

「自己改善する」エージェント経験から学び、使いながら育つ

Hermes Agentの最大の特徴は、学習ループを内蔵していること。実行した作業からスキル（手順記憶）を作り、使用しながら改善し、知識を継続的に保存し、セッションをまたいで「自分が誰で何をしているか」の理解を深めていきます。従来の「会話が終われば忘れる」チャットUIとの違いがここにあります。

作業を実行→ スキル化→ 使用しながら改善→ 知識を永続化
よもぎちゃん
「『使うほど賢くなる』が口説き文句じゃなくて設計思想になってるの。これがHermes Agentの肝だよ！」

理由①：複数モデルを一つの環境でClaudeもGPTもこれ一つ

動画タイトルの由来でもある第一の理由。ClaudeやGPT（ChatGPT系モデル）など、異なるプロバイダーのモデルを同一環境で切り替えて利用できる点が挙げられます。用途やコストに応じてモデルを選べ、サービスごとに画面や設定を切り替える手間がなくなります。プロバイダーごとのAPI設定を行えば、同じ操作感のまま使えるようになります。

  • 用途・コストに応じてモデルを切り替え
  • サービス単位のUIや操作の切り替え不要
  • 設定ファイルでプロバイダー・モデルを管理
よもぎちゃん
「『Claudeで文章、GPTで資料作り』みたいな使い分けも、ツールひとつで完結。ストレス減るよ！」
3:08

理由②：スキルの自動作成と改善作業を記憶して再利用する

第二の理由は、作業内容を記憶し、スキルを自動で作成・改善してくれること。一度やった作業を手順として保存し、次からは「お願い」だけで再現できます。繰り返し使ううちに手順自体が磨かれていくため、業務の定型化がどんどん進みます。

  • 一度実行した作業をスキルとして保存
  • 再利用のたびに手順が自動改善
  • 定型業務の再現コストが下がる

  • デスクトップ表示のカスタマイズ性も魅力

どこで動かす？ノートPCの外へ — 24時間動くサーバー

Hermes Agentは「置いた場所で生きる」エージェント。5ドル程度の格安VPS、GPUクラスタ、アイドル時ほぼ無料のサーバーレス基盤など、どこでも稼働でき、ラップトップに縛られません。メッセージアプリ経由で話しかければ、自分がSSHで入る必要のないクラウドVM上で作業を続けてくれます。

自宅PC（PC起動時のみ）→ VPS上で常時稼働→ メッセージアプリから指示

デスクトップアプリの始め方とモデル設定まずは手元で使い始める

サーバー運用の前に、まず手軽なのはHermes Desktop。Windows / macOS向けの公式インストーラーがあり、コマンドラインとデスクトップアプリの両方がまとめて入ります。コマンドラインのみの導入も公式スクリプトで可能。インストール直後のセットアップではOAuth認証ひとつでモデルと主要ツール群（Web検索・画像生成・TTS・ブラウザなど）がまとめて有効化できます。

  • 公式インストーラーでCLI＋デスクトップアプリを導入
  • Linux / macOS / WSL2 / Windows / Android(Termux) に対応
  • 初期セットアップでモデル＋主要ツールを一括有効化

プロファイルとBot①：プロファイル用途ごとに独立したメモリ管理

プロファイルは、Hermes Agentのメモリ・スキル・設定を用途ごとに分けて管理する仕組み。仕事用・プライベート用・実験用など、プロファイルを分ければ、それぞれに独立した記憶とスキルを持たせられます。文脈が混ざらないので、長く使っても破綻しにくいのが利点です。

  • プロファイルごとに独立したメモリ・スキル・設定
  • 仕事／私用／実験で記憶を分離
  • 長期運用でも文脈が混ざらない

プロファイルとBot②：Botモード名前を持った個別のエージェント

Botは、それぞれ名前・モデル・メモリ・スキル・定期タスク・チャットを持つ個別エージェント。家族用・チーム用など、複数のBotを並行して運用できます。メッセージアプリ経由のゲートウェイと組み合わせれば、TelegramなどからBotに話しかけて作業してもらう形が作れます。

  • Botごとに名前・モデル・メモリ・スキルを個別設定
  • 定期タスク（ルーティン）を持たせられる
  • メッセージアプリ経由での対話に対応

プラグインで機能を追加エコシステムで拡張する

Hermes Agentはプラグイン（拡張機能）で能力を足せる設計。公式ドキュメントには60以上の組み込みツールと、MCP（Model Context Protocol）サーバー接続による安全な拡張が用意されています。外部サービス連携や新しいツール群を、本体を書き換えずに導入できるのがポイントです。

  • プラグイン方式で機能を追加
  • 60以上の組み込みツールを利用可能
  • MCP統合で外部ツールを安全に接続

SECURITY

安全に使うための仕組み承認と権限の管理

自律度が高いエージェントだからこそ重要なのがセキュリティ。Hermes Agentにはコマンド実行前の承認（承認制）や権限管理、必要に応じたコンテナ分離といった安全機構が備わっています。何を許して何を禁止するかを設定で制御できるため、24時間稼働させる運用でも安心材料になります。

  • コマンド実行の承認機構
  • 権限・認可の設定による制御
  • コンテナ分離などの隔離手段

「『勝手に動く』けど『確認を通す』仕組みはちゃんとあるの。常時稼働にするほど、ここを押さえておくほど安心だよ。」
