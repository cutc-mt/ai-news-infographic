=== 参考: Anthropic公式ブログ (2026-09-24, Michael Segner) の要点 ===
- Claude Opus 5.5 は典型的なトークン課金ワークロードで Opus 5 比較 約40% 実行コスト減
- Claude Code の集計 (2026年3月〜9月): プロンプトあたり 3.3倍 長く動作、モデル呼び出し 40%超増、介入 68%減
- リクエストあたりコンテキスト 2.6倍増、入出力トークン比 189:1 → 324:1
- トークン課金の入出力トークン価格 20%減、キャッシュ読み込み価格 60%減 (キャッシュリードがエージェント/コーディング費用の大半)
- Claude Code ハーネス側もキャッシュが壊れにくい改善
- 公式おすすめの習慣: セッション途中でモデルを切り替えない / 離席前に /compact / 長いセッションには1時間キャッシュライフタイム設定
